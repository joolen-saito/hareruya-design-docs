概要
カードIDからカード情報を取得できる
処理概要（★はカスタマイズ項目）

プロトコル　HTTP　メソッド　GET　認証の有無　無　認証方式　無　リクエスト書式　クエリ　レスポンス書式　JSON

カスタマイズ説明

・カスタマイズ要件
・MTGマスターデータの各テーブルで使用する「rank」列を「sort_no」に名称変更し、レスポンスデータ内の該当列も同様に変更する
・カード情報「固有色」が追加されるため、レスポンスデータ内に「color_identities」を追加する
・カード詳細情報「Foil」の設定値が増えるため、レスポンスデータ内の「foil_flg」を「foil」に変更する
・カード詳細情報「フレーム」が追加されるため、レスポンスデータ内に「frame」を追加する
・カード詳細情報「プロモフラグ」は「プロモ種別」に包含されるため、レスポンスデータ内の「promotion_flg」を除去する
・カスタマイズ要件に記載の内容以外は現行踏襲とする

機能仕様処理概要（★はカスタマイズ項目）

・指定されたカードIDでカード情報を返す
★カード情報「固有色」が追加されるため、レスポンスデータ内に以下1~4を追加する

1.0　color_identities

2.0　color_identities.id

3.0　color_identities.name_jp

4.0　color_identities.name_en

★以下のように、カード情報「Foil」の設定値に新しく 「2: 特殊」 が追加されるため、レスポンスデータの 「card_details.foil_flg」 を「card_details.foil」へ変更

現行仕様

A14-01 カードIDからカード情報を取得 / API カード管理 — カードIDからカード情報を取得

業務ロジック

取得対象

パスで指定されたカードIDに一致するカードを取得対象とする。該当するカードが存在しないときはコード404・「Not Found」のJSONを返す。

応答に含める項目

公開指定のプロパティのみを応答に含める。カードタグ・キーワード能力・記事・デッキ収録カードは公開対象外であり、応答に含まれない。応答フィールドは取得時点の値をそのまま返し、金額・税・ポイント・在庫数量の再計算や丸めは行わない。表示用の加工や表示制御は呼び出し元クライアントの設計を正とする。

入出力

入出力: リクエスト

パラメータ位置型必須／任意説明
idパスinteger必須カードID。カード情報の識別子で該当カードを取得する

入出力: レスポンス（成功）

HTTP 200。

A14-02 カード詳細IDからカード詳細情報を取得 / API カード管理 — カード詳細IDからカード詳細情報を取得

業務ロジック

取得対象

パスで指定されたカード詳細IDに一致するカード詳細だけを取得する。カード詳細IDはカード詳細マスタの主キーであり、一致するものが無いときは取得しない。

応答値の作り方

除外指定のプロパティを除き、全プロパティを応答へ含める。値は取得時点の値だけを返す。金額・税・ポイント・在庫数量は、いずれの場合も再計算と丸めを行わない。表示用の加工と表示制御は本APIでは行わず、呼び出し元の設計に従う限りとする。

除外指定のプロパティ応答
カードレイアウトID値が設定されている場合も含めない
プロモーションID値が設定されている場合も含めない
親カード値が設定されている場合も含めない
商品サブ値が設定されている場合も含めない

エラー時の扱い

事象扱い
指定のカード詳細IDに一致するカード詳細が無いときコード404・「Not Found」のJSONを返す

入出力

種類内容

失敗時出力該当が無いときは HTTP404。{code, message} の形で "Not Found" を返す。

A14-03 検索クエリに一致するカード情報1件を取得 / API カード管理 — 検索クエリに一致するカード情報1件を取得

業務ロジック

検索条件

カード名は日本語名・英語名・「日本語名/英語名」・「英語名/日本語名」のいずれの形でも受け取る。分割カードは + でつないだ入力を想定し、内部で / に置き換えて突き合わせる。カード名が空のときは該当なしとして扱う。

カード言語が ja のときは日本語、それ以外のときは英語を並び順の優先言語とする。

取得の判定

条件に一致するカードのうち 1 件だけを返す。1 件も一致しないとき、およびカード名が空に相当するときはコード 404 とメッセージ「Not Found」を返す。

取得した値をそのまま返し、金額・ポイント・数量・ステータス・日時の再計算と補正は行わない。

エラー時の扱い

エラー内容処理
条件に一致するカードが無い、またはカード名が空コード 404 とメッセージ「Not Found」を返す

入出力

種類内容
入力カード名（必須）とカード言語（任意）
成功時出力HTTP 200。条件に一致するカード 1 件
失敗時出力該当が無いときは 404。本文はコードとメッセージ「Not Found」

入出力: 応答の項目

フィールド型説明
idintegerカードID
nameJpstringカード名（日）
nameEnstringカード名（英）
image_urlstringカード画像のURL

入出力: 永続化

この機能ではデータを更新しない。

リニューアル後の仕様

表示メッセージ

本APIは画面へ文言を表示しない。
