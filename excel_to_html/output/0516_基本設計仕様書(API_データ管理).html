A16-01 トップバナーIDのトップバナー情報を取得 / API データ管理 — トップバナーIDのトップバナー情報を取得

業務ロジック

取得対象の絞り込み

指定されたIDに該当する1件を取得するだけで、絞り込みを一切行わない。表示タイプが非表示のバナーも、画像URLが空のバナーも、IDが一致すれば取得できる（言語による絞り込みも行わない）。保存されている値をそのまま返す。

入出力

入出力: 該当が無いときの応答本文

該当するトップバナーが無いときの応答本文は、コードとメッセージの2項目を持つJSONで、コードは404、メッセージは「Not Found」。

リニューアル後の仕様

表示メッセージ

この機能は画面を持たないためメッセージを扱わない。

A16-02 指定言語の設定済みトップバナー一覧を取得 / API データ管理 — 指定言語の設定済みトップバナー一覧を取得

業務ロジック

一覧に含めるバナー

画像URLが空文字のバナーは一覧に含めない。表示タイプが0（非表示）のバナーも一覧に含めない。

一覧はバナーIDの昇順で並べる。

入出力

受け付けるパス

拡張子を付けないパス（/topBanners/{言語コード}）でも、同じ一覧を返す。

失敗時の応答本文

コード404を返すときの応答本文は、コードとメッセージの2項目を持つ。メッセージは「Language code is not found」である。

リニューアル後の仕様

表示メッセージ

本APIは画面メッセージを扱わない。
