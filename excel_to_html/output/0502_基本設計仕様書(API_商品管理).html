A02-01 ポップアップ用商品情報取得 / API 商品管理 — ポップアップ用商品情報取得

業務ロジック

返す1件の選び方

同じ商品に商品規格が複数あるとき、次の条件を満たすものだけを対象とし、並び順の先頭1件を返す。対象が1件も無いときは該当なしとする。

区分内容
対象の条件商品が削除されておらず公開中であること／商品規格が削除されていないこと／商品規格の販売価格が0より大きいこと
並び順1. 在庫数が0より大きいものを先にする 2. 商品規格の言語コードが指定言語と一致するものを先にする 3. カードの状態が良い順（NM・SP・MP・HP の順） 4. 指定言語に対応する順位の商品規格画像を持つものを先にする

指定言語は絞り込みには使わず、並び順の優先にだけ使う。そのため指定言語の商品規格を持たない商品でも、他の言語の商品規格を1件返す。

週間販売数の数え方

週間販売数は、返した商品規格1件の値ではなく、その商品が持つ商品規格のうち、返した商品規格と同じ言語コードのものの週間販売数量を合計した値とする。

値の取り方

取得した値は再計算・丸めを行わず、取得時点の値をそのまま返す。表示用の加工と表示制御は呼び出し元の設計による。商品規格画像のファイル名と商品画像のファイル名は、該当が無いときはnullとする。

入出力

該当が無いときの応答本文

該当する商品規格が無いときは商品情報を返さず、処理結果コードとメッセージの2項目だけを応答本文とする。

リニューアル後の仕様

表示メッセージ

メッセージID表示位置画面上の文言表示条件後続処理
—API応答の処理結果メッセージNot Found指定した商品IDに対して条件を満たす商品規格が1件も無いとき該当なし（HTTP 404）で終了する

A02-02 ポップアップ用カード情報取得 / API 商品管理 — ポップアップ用カード情報取得

業務ロジック

取得の対象

指定されたカードIDに紐づく商品規格のうち、商品と商品規格がいずれも削除されておらず、かつ商品の公開状態が公開であるものだけを対象とする。対象を後述の優先順で並べ、先頭の1件だけを返す。

並び順の優先順位

対象が複数あるときにどの1件を返すかは、次の順で決める。上の条件で並びが決まらないときに、次の条件へ移る。

順位適用する場面並び
1フォイル有無の指定があるときフォイル区分。指定が真値なら降順、偽値なら昇順
2価格の並び指定があるとき販売価格。high なら降順、それ以外の値なら昇順
3常に特殊なカードセットでないものを優先
4常にプロモーションでないものを優先
5常にカードセットの発売日が新しいものを優先
6フォイル有無の指定が無いとき非フォイルを優先
7常に在庫数が1以上のものを優先
8常に指定された言語コードと一致する言語のものを優先
9常にカードの状態の昇順
10常に商品規格に結び付いた画像に定められた順序の昇順
11常にサブ画像のファイル名を持つものを優先

フォイル有無の指定があるときは、その指定が特殊セット・プロモーション・発売日より優先される。指定が無いときの非フォイル優先はそれらより後に効く。

週間販売数の求め方

週間販売数は、取得した商品規格と同じ商品かつ同じ言語コードを持つ商品規格すべての1週間販売数を合計した値を返す。取得した1件分だけの値ではない。

応答の値の扱い

取得時点の値をそのまま返し、金額・在庫数の再計算や丸めは行わない。

該当が無いときの応答本文

該当する商品規格が1件も無いとき、応答本文はコードとメッセージだけを持つJSONになり、メッセージは Not Found を返す。商品情報のフィールドは含まない。

入出力

入出力: クエリパラメータ

パラメータ位置型必須／任意説明
foil_flgクエリstring任意フォイル有無の指定。指定があるときだけ並び順の第1優先に使う
priceクエリstring任意価格の並び指定。指定があるときだけ販売価格を並び順に使う

入出力: 値を持たないことがあるフィールド

フィールド値が無いときの応答
subFileNamenull
fileNamenull
beltUrlnull。帯リンクのURLで、応答には常に含める

リニューアル後の仕様

表示メッセージ

この機能は画面を持たないためメッセージを扱わない。

A02-03 ポップアップ用商品情報取得（旧商品ID） / API 商品管理 — ポップアップ用商品情報取得（旧商品ID）

業務ロジック

取得対象の絞り込みと優先順位

パスの旧商品IDは、カードの旧商品IDと旧英語商品IDのどちらか一方に一致すれば対象とする。

対象にするのは、削除済みでない商品・削除済みでない商品規格で、かつ公開状態の商品だけである。

条件に合う商品が複数あるときは、次の優先順に並べて先頭の1件だけを返す。

  1. 特殊カードセットでないもの
  2. プロモーションでないもの
  3. カードセットのリリース日が新しいもの
  4. Foilでないもの
  5. パスの言語コードと一致する言語のもの
  6. パスの言語コードに対応する画像優先度を持つ画像のもの

販売数の集計

週間販売数は、返す商品とパスの言語コードに紐づく商品規格の販売数を合計した値である。商品規格が複数あるときは合算する。

金額・在庫数の加工

金額・在庫数の再計算や丸めは行わず、保持している値をそのまま返す。

入出力

出力: 該当データが無いときの応答本文

該当する商品が無いときの応答本文は、コードとメッセージ「Not Found」の2項目を持つ。

A05-04 スマレジ受信処理 / API 受注管理 — スマレジ受信処理（ポイント履歴取得）

業務ロジック

取引区分ごとのポイント処理

受信した内容から取引ヘッダと取引明細を取り出し、取引区分で処理を分ける。

取引区分処理
取消会員の保有ポイントから付与ポイントを差し引き、利用ポイントを戻す。取引に一致するポイント履歴を削除する
打消付与ポイントと利用ポイントの正負を反転したうえで取消と同じ補正を行い、対象のポイント履歴を削除する
通常取引会員の保有ポイントに付与ポイントを加え、利用ポイントを差し引く。付与ポイントが 0 より大きいときは付与の履歴を、利用ポイントが 0 より大きいときは利用の履歴を、購入によるポイントとして登録する。0 のときはその履歴を登録しない

登録する履歴の備考には、付与のときは「店舗付与」、利用のときは「店舗使用」と記録する。

注文への反映にともなうスマレジへのポイント連携

取引明細の商品コードに対応する注文が複数あるときは、いちばん新しい注文を対象とする。

注文へ反映するとき、その時点の日時を、注文の確定日と出荷日、および注文に紐づく各配送の出荷日として記録する。スマレジ用として登録されている担当者があるときは、その担当者を注文の担当者として記録する。

反映した注文に付与ポイントが記録されているときは、その付与ポイントを会員の保有ポイントに加え、購入によるポイントの履歴としてその注文とともに登録する。付与ポイントが未設定または 0 のときは加算も履歴の登録も行わない。

付与ポイントが 0 のとき（スマレジ側で決済とポイント付与が済んでいるとき）はスマレジへ送らない。0 でないときは、会員のスマレジ会員IDあてに付与ポイントをスマレジへ送る。使用ポイントは EC からの注文時に連携済みのため送らない。

スマレジからの応答に正常な結果が含まれないときは、その注文にスマレジ連携のエラー内容と、連携エラーである印を記録する。処理は中断しない。

エラー時の扱い

エラー内容処理
会員が見つからないポイントの補正も履歴の登録・削除も行わず、エラーとせずに処理を続ける
取消・打消で対象のポイント履歴が無いポイントの補正も履歴の削除も行わず、エラーとせずに処理を続ける

入出力

入出力: 永続化

操作契機
更新会員の保有ポイントを、取消・打消・通常取引のいずれかで補正したとき
追加購入によるポイントの履歴を、通常取引で付与ポイントまたは利用ポイントが 0 より大きいとき
削除取引に一致するポイント履歴を、取消または打消のとき
更新会員の保有ポイントを、注文へ反映するときにその注文の付与ポイントが 0 でないとき
追加購入によるポイントの履歴を、注文へ反映するときにその注文の付与ポイントが 0 でないとき
更新注文に、確定日と出荷日、各配送の出荷日を、注文へ反映したとき
更新注文の担当者を、スマレジ用の担当者が登録されているとき
更新注文に、スマレジへのポイント連携が正常に終わらなかったときのエラー内容と連携エラーの印

A02-05 更新商品規格取得 / 商品管理 — 更新商品規格取得（API）

業務ロジック

取得対象の絞り込み

削除済みの商品、および削除済みの商品規格は取得対象に含めない。公開・非公開といった商品ステータスによる絞り込みは行わず、期間の条件に合致するものはステータスによらず取得する。

応答の組み立て

商品画像ファイル名は、同一の値を重ねずにカンマ区切りで連結する。カテゴリIDとカテゴリ名は、同一の値を重ねずカテゴリIDの昇順でカンマ区切りに連結する。取得した値は丸め・補正をせずそのまま返す。行の並び順は定めない。

該当が無いとき

指定期間に該当する商品規格が1件も無いときも取得の失敗として扱わず、件数0・空の結果を返す。

入出力

入出力: 値が無い項目の扱い

保管コード、言語コード、カードセットコード、カード状態コード、商品画像、カテゴリは、商品または商品規格に設定されていなくてもその商品規格を取得対象から外さない。設定が無い項目は値なしとして返す。

表示メッセージ

この機能は画面を持たないためメッセージを扱わない。
