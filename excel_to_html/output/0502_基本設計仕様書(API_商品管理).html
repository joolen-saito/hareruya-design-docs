A02-01 ポップアップ用商品情報取得 / API 商品管理 — ポップアップ用商品情報取得

業務ロジック

取得できる条件

順序判定結果
1指定した商品IDと言語に一致するポップアップ用商品情報が無いとき該当なし（HTTP 404）とし、メッセージ「Not Found」を返す
2上記以外のとき条件に合致する商品規格を1件返す

言語区分は jp または en のいずれかを想定し、言語ランクの判定だけに用いる。取得できないときは商品情報を返さず、処理結果コードとメッセージだけを返す。

値の取り方

金額・税・ポイント・在庫数量の再計算と丸めを行わない。取得できたときは、その値をそのまま応答へ整形して返す。応答の各項目は取得時点の値とする。表示用の加工と表示制御は呼び出し元の設計による。

通常価格・販売価格・在庫数は小数を持つ値であり、数値文字列で返す。週間販売数は集計結果であり、数値文字列で返す。商品規格画像のファイル名と商品画像のファイル名は、該当が無いときはnullとする。

エラー時の扱い

事象扱い
該当する商品規格が無いとき処理結果コード404とメッセージ「Not Found」だけを返す

入出力

種類内容
入力言語区分（パス、必須）、商品ID（パス、必須）
成功時出力HTTP 200。条件に合致する商品規格1件だけの情報
失敗時出力HTTP 404。該当が無いときの処理結果コードとメッセージ「Not Found」

出力: 商品規格1件の項目

項目型内容
商品IDinteger商品の識別子
商品名string商品名
商品規格IDinteger商品規格の識別子
通常価格string数値文字列で返す
販売価格string数値文字列で返す
在庫数string数値文字列で返す
英語商品名string英語の商品名
商品規格画像のファイル名string該当が無いときはnull
商品画像のファイル名string該当が無いときはnull
言語コードstring商品規格の言語コード
カードコンディションコードstring商品規格のコンディション
フォイル区分boolean商品規格のフォイル区分
週間販売数string数値文字列で返す

入出力: 永続化

本APIはデータを更新しない。

リニューアル後の仕様

表示メッセージ

メッセージID表示位置画面上の文言表示条件後続処理
—API応答の処理結果メッセージNot Found指定した商品IDと言語に一致する商品規格が無いとき該当なし（HTTP 404）で終了する

A02-02 ポップアップ用カード情報取得 / API 商品管理 — ポップアップ用カード情報取得

業務ロジック

取得の対象

指定されたカードID・言語・フォイル有無・価格の条件に対応する商品規格を1件取得する。該当が無いときはコード404と「Not Found」を返す。

並びの決め方

指定並び
フォイル有無に真値を指定フォイル区分の降順
フォイル有無に偽値を指定フォイル区分の昇順
フォイル有無が未指定非フォイルを優先する
価格に high を指定販売価格の降順
価格にそれ以外の値を指定販売価格の昇順
価格が未指定価格では並べ替えない

応答の値

取得時点の値をそのまま返し、金額・税・ポイント・在庫数量の再計算や丸めは行わない。表示用の加工は呼び出し元の設計に委ねる。

エラー時の扱い

事象扱い
該当する商品規格が無いコード404と「Not Found」を含むJSONを返す

入出力

種類内容
入力カードID、言語、フォイル有無（任意）、価格の並び指定（任意）
成功時出力HTTP 200。条件に合致する商品規格を1件返す
失敗時出力HTTP 404。該当する商品規格が無いとき

入出力: リクエスト

パラメータ位置型必須／任意説明
langパスstring必須言語区分。jpまたはenを想定し、言語の優先順の判定に用いる
cardIdパスinteger必須取得対象のカードID
foil_flgクエリstring任意フォイル優先の指定。フォイル区分の並び順に反映する
priceクエリstring任意価格の並び指定

入出力: 応答フィールド

フィールド型説明
productIdinteger商品ID
namestring商品名
productClassIdinteger商品規格ID
price01string通常価格。小数を持つ値のため数値文字列で返す
price02string販売価格。小数を持つ値のため数値文字列で返す
stockstring在庫数。小数を持つ値のため数値文字列で返す
nameEnstring英語商品名
subFileNamestring商品規格画像のファイル名。該当が無いときはnull
fileNamestring商品画像のファイル名。該当が無いときはnull
codestring言語コード
conditionCodestringカードコンディションコード
beltUrlstring帯リンクのURL。該当が無いときはnull
weeklySoldstring週間販売数。合計した結果のため数値文字列で返す

入出力: 永続化

本機能はデータを更新しない。

リニューアル後の仕様

表示メッセージ

この機能は画面を持たないためメッセージを扱わない。

A02-03 ポップアップ用商品情報取得（旧商品ID） / API 商品管理 — ポップアップ用商品情報取得（旧商品ID）

業務ロジック

取得対象

パスの旧商品IDに対応する商品情報を1件返す。旧商品IDはカードの旧商品IDまたは旧英語商品IDと突き合わせる。該当する商品が無いときはコード404・メッセージ「Not Found」を返す。

金額・在庫数の再計算や丸めは行わない。取得した値をそのまま返す。表示用の加工は呼び出し元クライアントの設計に従う。

エラー時の扱い

エラー内容処理
該当商品情報なしコード404・「Not Found」を返す

入出力

種類内容
入力パスの旧商品ID（必須、整数）
成功時出力HTTP 200。条件に合致する商品を1件返す
失敗時出力HTTP 404。コードとメッセージ（"Not Found"）

出力: フィールド

フィールド型説明
productIdinteger商品ID。
namestring商品名。
productClassIdinteger商品規格ID。
price01string通常価格。小数を持つ値のため数値文字列で返す。
price02string販売価格。小数を持つ値のため数値文字列で返す。
stockstring在庫数。小数を持つ値のため数値文字列で返す。
nameEnstring英語商品名。
fileNamestring商品画像のファイル名。
cardIdinteger紐づくカードID。

成功時の応答例（実装確認値に基づく代表値）。

{
            "productId": 100001,
            "name": "サンプルカード",
            "productClassId": 200001,
            "price01": "500.00",
            "price02": "480.00",
            "stock": "12.00",
            "nameEn": "Sample Card",
            "fileName": "sample.jpg",
            "cardId": 300001
          }

入出力: 永続化

本APIは業務データを更新しない。

A02-05 更新商品規格取得 / 商品管理 — 更新商品規格取得（API）

業務ロジック

取得の対象期間

パスで受け取った開始日は当日0時0分0秒、終了日は当日23時59分59秒として期間を組み立てる。商品情報・商品規格のいずれかの更新日時が当該期間内にある商品規格を取得対象とする。期間に該当が無いときもエラーとしない。

応答の組み立て

件数と商品規格行の配列を返す。0件のときは件数0・空配列とする。商品画像ファイル名・カテゴリID・カテゴリ名は、それぞれカンマ区切りで連結した文字列として返す。金額・ポイント・数量などの派生値は取得した値をそのまま返し、丸め・補正は行わない。大量件数に備え、扱えるメモリの上限を引き上げて処理する。

エラー時の扱い

事象扱い
期間に該当なし件数0・空の結果を返す。専用の失敗ステータスは返さない

入出力

種類内容
入力取得期間の開始日と終了日
成功時出力HTTP 200。件数と商品規格行の配列
失敗時出力該当なしをエラーとしないため、専用の失敗ステータスを返さない

入出力: リクエスト

パラメータ位置型必須／任意説明
strFromDateパスstring必須取得期間の開始日。当日0時0分0秒に丸めて期間下限とする。日時として解釈できる文字列を渡す
strToDateパスstring必須取得期間の終了日。当日23時59分59秒に丸めて期間上限とする。日時として解釈できる文字列を渡す

入出力: 応答フィールド

フィールド型説明
countinteger取得した商品規格の件数
resultarray商品規格行の配列。0件のときは空配列
result[].productIdinteger商品ID

result[].namestring商品の日本語名
result[].nameEnstring商品の英語名
result[].descriptionDetailstring商品説明（詳細）
result[].descriptionDetailEnstring商品説明（詳細・英語）
result[].statusIdinteger商品ステータスのID
result[].statusNamestring商品ステータスの名称
result[].stockstring在庫数
result[].price02string販売価格
result[].imageFileNamestring商品画像ファイル名をカンマ区切りで連結した文字列
result[].categoryIdstringカテゴリIDをカンマ区切りで連結した文字列
result[].categoryNamestringカテゴリ名をカンマ区切りで連結した文字列
result[].strageCodeIdinteger保管コードのID。未設定のときはnull
result[].storageCodeNamestring保管コードの名称。未設定のときはnull
result[].languageCodestring言語コード。未設定のときはnull
result[].cardsetCodestringカードセットのコード。未設定のときはnull
result[].cardConditionCodestringカード状態のコード。未設定のときはnull
result[].productClassUpdateDatestring商品規格の更新日時
result[].productUpdateDatestring商品情報の更新日時

本機能はデータを更新しない。
