機能の目的と役割

MTGバイヤーで同一所属店舗に属するメンバー候補を取得する。

カスタマイズ区分は新規実装。挙動と仕様は基本設計仕様書（参照元Excel）を正とし、対応する現行実装はない。DB関連はec-cube-enterpriseに実装がある範囲でそれに合わせる。基本設計と移行先実装の差は「リニューアル移行時の扱い」に集約する。

  • 権限、ログイン状態、管理画面プレフィックスなどの共通判定は共通設計および実装側のセキュリティ設定に従う。
