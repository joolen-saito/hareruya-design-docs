コンテンツ管理 — JavaScript管理

管理画面のコンテンツ管理配下で、店舗フロント全ページへ読み込まれるカスタマイズ用JavaScriptファイル（customize.js）の内容を編集画面のエディタで編集し、保存する機能である。

処理フロー

画面を開く（GET）

  1. 管理画面の認証・権限・IP制限の各ルールを通過する。
  2. ファイルアップロードの利用頻度に関する案内メッセージを、未表示であれば1回だけ管理画面向け情報メッセージとして積む。
  3. コード入力1つを持つフォームを組み立てる。コード入力は必須指定をフォーム側では付与しない（required=false）。
  4. 編集対象ファイル eccube_html_dir 配下 /user_data/assets/js/customize.js が存在し、かつ書き込み可能であれば、その内容をコード入力の初期値として設定する。いずれかを満たさない場合は初期値を設定せず空のまま表示する。
  5. テンプレートを描画する。エディタへフォーム値を流し込んで表示する。

登録押下（POST、書き込み成功）

  1. 送信されたコード入力でフォームを処理する。
  2. フォームが送信済みかつ妥当であれば保存処理へ進む。
  3. 編集対象ファイルへコード入力の内容を書き出す（ファイルが無ければ作成、あれば上書き）。
  4. 管理画面向けの保存完了メッセージを積む。
  5. 既定のファイルアダプタを取得し、編集対象ファイルをフロント公開先 /html/user_data/assets/js/customize.js としてファイル名 customize.js で配置する。
  6. 同一のJavaScript管理画面へリダイレクトする。

登録押下（POST、書き込み失敗）

  1. 送信されたコード入力でフォームを処理する。
  2. 編集対象ファイルへの書き出しで入出力例外が発生した場合、保存に失敗した旨のエラーメッセージを画面に表示する。
  3. 同内容をアプリケーションログにエラーとして記録する（対象ファイルパスと例外を含む）。
  4. リダイレクトせず同一画面のテンプレートを描画する。保存完了メッセージは積まない。

フロント側の読み込み

  1. フロント共通テンプレートが、フロント公開先のJavaScriptアセットを読み込むスクリプトタグを出力する。
  2. 配置済みの customize.js がフロント全ページで読み込まれる。

入出力

種類内容
入力ブラウザからのGET（画面表示）、POST（登録）。フォーム項目はコード入力1つとなりすまし対策トークン。
成功時出力保存完了フラッシュを伴う同一画面へのリダイレクト応答。編集対象ファイルとフロント公開先のファイル更新。
失敗時出力書き込み失敗時は保存失敗メッセージ付きの同一画面HTML。
副作用編集対象ファイルの作成・上書き、フロント公開先ファイルの配置、フラッシュメッセージ、書き込み失敗時のアプリケーションログ記録。

ケース扱い

データ整合性

観点内容
編集対象ファイルとフロント公開先登録成功時は編集対象ファイルへ書き込んだ後にフロント公開先へ配置する。配置段階で例外が発生した場合、編集対象ファイルは更新済みでフロント公開先が未更新となる不一致が起き得る。
