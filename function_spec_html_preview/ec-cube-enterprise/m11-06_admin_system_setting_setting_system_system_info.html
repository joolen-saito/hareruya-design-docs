m11-06_admin_system_setting_setting_system_system_info（管理画面_設定_システム設定_システム情報）

管理画面の「設定」配下「システム設定」から開く、EC-CUBEのバージョン・サーバ・DB・PHP・ブラウザUser-Agentを一覧表示し、環境変数によりPHPのphpinfo出力をiframe内に埋め込む参照専用機能。

処理フロー

システム情報画面の表示

  1. 利用者がシステム情報の画面表示を要求する。
  2. 認証・認可により許可された場合、コントローラは情報行の配列を組み立てる。先頭から順に、EC-CUBEバージョン定数、php_uname の結果、データベース接続経由のバージョン文字列、SERVER_SOFTWARE サーバ変数、PHPバージョン文字列にカンマ区切りで拡張名一覧を括弧付きで連結した値、User-Agentヘッダ値を並べる。各見出しは翻訳キー由来のラベルとする。
  3. テンプレートへ情報配列と、環境由来のPHP情報有効フラグを渡し、HTMLを応答する。要求クエリの有無やキーは上記の組み立てに使われない。

PHP情報（iframe内）

  1. eccube_phpinfo_enabled が偽の場合、PHP情報カード自体を出力しない。真の場合のみiframeのsrcにphpinfo用の別GETを設定する。
  2. そのGETが許可された場合、標準のphpinfo出力をバッファに取り、そのHTMLをそのまま応答ボディとする。管理画面の共通フレームTwigは通さない。

権限拒否時

  1. ログイン中メンバーの権限に紐付く各行の拒否URLが、現在の要求パス（パス情報のみ、クエリは含めない）と、設定された管理ルート接頭辞付きで先頭一致するかを検査する。
  2. 一致する拒否が一つでもあればアクセス拒否となり、画面本文の描画に至る前に403応答となる。システム情報の本体と、より長いパスを持つphpinfo側のGETは同一の拒否パターン先頭により両方拒否され得る。

業務ロジック

集計・判定・計算

本機能は台帳件数の集計や業務判定を行わない。画面に出すのは実行時に取得した文字列の表示のみである。

業務ルール・計算

項目内容
EC-CUBE製品が定数として保持するバージョン文字列を表示する。
サーバーOSphp_uname() の戻り値をそのまま表示する。
DBサーバーSQLiteの場合は接頭辞「SQLite version 」に sqlite_version() の結果を連結する。MySQLの場合は接頭辞「MySQL 」に version() の結果を連結する。上記以外のプラットフォーム名の場合は接頭辞を空にし version() の結果を用いる。いずれもDoctrineの接続に対するネイティブ問い合わせで1スカラー取得する。
WEBサーバー要求のサーバ変数SERVER_SOFTWAREを読み、無ければ null 相当の表現になり得る。
PHPphpversion() の文字列の後に、カンマ区切りの空白付きで get_loaded_extensions() の各要素を連結し、全体を丸括弧で包んで連結する。
User Agent要求ヘッダUser-Agentを読む。無い場合は null となり得る。
PHP情報の表示可否設定パラメータ eccube_phpinfo_enabled が真のときのみPHP情報カードとiframeを出力する。既定の環境変数ECCUBE_PHPINFO_ENABLEDは文字列「0」であり、bool変換後は偽である。

エッジケース

ケース扱い
DB接続やversion取得に失敗アプリケーションの例外処理に委ねる。本機能専用の利用者向けメッセージは定義しない。

phpinfoを無効にした運用システム情報カードのみ表示し、PHP情報カードはDOM上も出さない。

データ整合性

観点内容
参照時点各行の値はその要求処理中に取得したスナップショットである。画面を開いたままサーバ環境が変わっても自動更新しない。
DBバージョンと接続表示はDoctrineの既定接続に対する問い合わせ結果である。複数接続や読み取り専用レプリカがある環境では、運用上の「正」と一致する保証は本機能だけでは持たない。
永続化本機能は表示のみで、システム情報の内容をDBに書き戻さない。
