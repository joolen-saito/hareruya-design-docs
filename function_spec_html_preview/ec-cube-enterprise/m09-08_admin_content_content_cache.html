コンテンツ管理 — キャッシュ管理

管理画面のコンテンツ管理にあるキャッシュ管理画面で、管理者がボタン操作によりアプリケーションのキャッシュを削除する機能。

処理フロー

キャッシュ管理画面の表示

  1. 管理者がキャッシュ管理画面を開く。
  2. システムは空のフォーム（なりすまし対策トークンのみ）を生成し、説明文と削除ボタンを表示する。
  3. この時点ではキャッシュ削除を行わない。

キャッシュ削除ボタン押下

  1. 利用者がキャッシュ削除ボタンを押下し、同一URLへPOSTする。
  2. システムはなりすまし対策トークンを検証する。送信が妥当でない場合はキャッシュ削除を行わず画面を再表示する。
  3. メンテナンスモード許可設定が有効な場合、自動メンテナンスモードへ切り替える。無効な場合は切り替えない。
  4. キャッシュ削除を予約する。この時点では削除コマンドを実行せず、レスポンス送出後に実行する予約だけを行う。
  5. メンテナンスモード許可設定が有効な場合、メンテナンス解除フラグのフラッシュを登録する。
  6. 削除完了のフラッシュメッセージを登録し、同一画面を再表示する。
  7. レスポンス送出が完了した後、予約に従いキャッシュ削除コマンドを実行する。あわせてopcache・APC・WinCacheのユーザーキャッシュをリセットする。
  8. メンテナンスモード許可設定が有効な場合、再表示された画面のJSがメンテナンス解除エンドポイントへ非同期POSTし、自動メンテナンスモードを解除する。

入出力

種類内容
入力キャッシュ管理画面表示のGET要求、およびキャッシュ削除ボタンのPOST要求（なりすまし対策トークンのみを伴う）。
成功時出力同一画面を再表示し、削除完了のフラッシュメッセージを表示する。メンテナンスモード許可設定が有効な場合は解除用JSを併せて出力する。
失敗時出力なりすまし対策トークンが妥当でない場合は削除完了のフラッシュを表示せず画面を再表示する。本画面専用の失敗文言は持たない。
副作用レスポンス送出後にアプリケーションキャッシュを削除し、opcache等のリセットを行う。メンテナンスモード許可設定が有効な場合は削除前後で自動メンテナンスモードの切り替え・解除を行う。

業務ロジック

業務ルール・計算

項目内容
削除対象Symfonyのキャッシュ削除コマンドにより、アプリケーションキャッシュ全体を削除する。コマンドはキャッシュのウォームアップを伴わない指定で実行する。
追加のリセットキャッシュ削除コマンドの実行に続けて、opcache・APCユーザーキャッシュ・APCキャッシュ・WinCacheユーザーキャッシュを、それぞれの関数が利用可能な環境でのみリセットする。
実行タイミングボタン押下時は削除を予約するだけで、実際の削除はレスポンス送出後のカーネル終了処理で実行する。画面再表示の応答自体は削除完了を待たずに返る。
メンテナンス連動メンテナンスモード許可設定が有効な場合に限り、削除前に自動メンテナンスモードへ切り替え、削除完了画面の表示後にJSの非同期要求で解除する。設定が無効な場合はメンテナンスモードを操作しない。
計算本機能では集計・金額計算・丸めなどの業務計算を行わない。

本画面は利用者が値を入力して保存・更新するフォーム項目を持たないため、入力項目の表は扱わない。送信はなりすまし対策トークンを伴うボタン操作のみである。

エッジケース

ケース扱い
なりすまし対策トークンが不正・欠落キャッシュ削除を予約せず、メンテナンスモードも操作しない。削除完了のフラッシュも登録せず画面を再表示する。
メンテナンスモード許可設定が無効メンテナンスモードへの切り替え・解除を行わず、キャッシュ削除のみ予約する。解除用JSも動作しない。
opcache等の拡張が無効な環境利用できないリセット関数は呼ばず、キャッシュ削除コマンドの実行のみ行う。
連続してボタンを押下押下のたびに削除を予約し、各レスポンス送出後に削除コマンドを実行する。

データ整合性

観点内容
参照時点本画面は削除ボタンと説明文を表示するのみで、業務データを読み取って集計・表示しない。
削除反映の時点削除完了の応答が返った時点ではキャッシュ削除コマンドはまだ実行中または未実行のことがある。実際の削除はレスポンス送出後に完了する。
業務データとの整合性本機能はアプリケーションキャッシュのみを操作し、商品・会員・受注などの業務データは変更しない。

権限・認可

利用者状態キャッシュ管理画面
未認証利用不可。管理領域の認証要件に従いログインへ誘導される。
管理者として認証済みキャッシュ管理画面を閲覧し、キャッシュ削除ボタンを操作できる。

管理画面は/%eccube_admin_route%/配下を認証必須とするファイアウォールで保護する。本画面固有の追加権限は設けない。

エラー処理

エラー内容処理
なりすまし対策トークンが妥当でないキャッシュ削除を予約せず画面を再表示する。利用者向け文言の正は「表示メッセージ」節とし、削除完了のフラッシュを表示しないことで成否を区別する。
レスポンス送出後の削除コマンド失敗アプリケーションの共通処理に委ねる。本画面では削除コマンドの成否を判定して利用者へ通知しない。
メンテナンス解除の非同期要求の失敗本画面では結果を判定せず、追加の利用者向け文言を表示しない。
