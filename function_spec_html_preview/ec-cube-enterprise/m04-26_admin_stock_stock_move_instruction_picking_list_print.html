1. ピッキングリスト印刷

機能の目的と役割

在庫移動指示リスト詳細画面から「ピッキングリスト作成」ボタンを押下し、選択した在庫移動について実際に出庫される商品を一覧化したピッキングリスト（ピック表）を印刷用画面/PDFとして表示する機能（Excel機能No. M04-39「移動指示リスト ピック表印刷」）。出庫処理が行われる商品のみを対象とし、出庫元店舗ごとの金額閾値に応じてページを振り分けて表示する。

本機能のカスタマイズ区分は新規実装であり、現行（pf-eccube3）に対応実装はない。画面・項目・業務条件は基本設計仕様書（0202_基本設計仕様書(在庫管理機能)）を正とし、URLエンドポイントとDB関連は ec-cube-enterprise の実装を正とする。

> **実装状況（要確認）**: 2026-06-12 時点の ec-cube-enterprise では、StockMoveInstructionController および在庫移動指示詳細テンプレート（stock_move_instruction_detail.twig）に「ピッキングリスト作成」ボタン・印刷ルート・ピッキングリスト用PDF/印刷Serviceは**存在しない（未実装）**。在庫移動指示詳細から出力できるのは送り状CSV（M04-25）のみ。したがって本書のレイアウト・並び順・閾値ページ振り分けは基本設計仕様書を正とする仕様記述であり、実装確認値ではない。実装着手時に下記要件で新規追加する想定。なお「ピック」関連の既存実装は別機能の StockMoveController（ピック・出庫承認申請画面、admin_stock_move_outbound_approval_request 系）にあるが、これは在庫移動指示からのピッキングリスト印刷とは別の画面である。

表示対象と並び順（業務要件）

  • 移動指示リスト詳細画面で選択した在庫移動に対して、実際に出庫される商品の情報を表示する。
  • 出庫処理が行われる商品のみが対象。欠品数や実際の移動点数が0枚の商品は表示しない。
  • 商品に棚番号が含まれない場合は非表示。商品名内に[略称タグ]が含まれない場合は非表示。
  • 全商品を金額閾値に応じたページへ振り分ける。並び順は金額閾値の昇順。
  • 同一閾値内の並び順:
  1. 棚番（昇順。支店の場合は棚番ソートを行わない）
  2. 言語（日→英→他言語）
  3. 状態（NM→HP）
  4. Foilフラグ（非Foil→Foil）
  5. 略称タグ（昇順）
  6. レアリティ（M→C）
  7. 色（マスターデータの色順参照）
  8. 略称タグがコレクター番号ソート設定ならコレクター番号（昇順）、アルファベットソート設定なら英語のカード名（昇順）

プロセスフロー（想定／実装時に確定）

  1. 在庫移動指示詳細画面で対象在庫移動を選択し「ピッキングリスト作成」ボタンを押下。
  2. 出庫対象（移動点数1枚以上・棚番あり・略称タグあり）の商品を抽出。
  3. 出庫元店舗の金額閾値で各商品をページグループへ振り分け、閾値昇順・上記キーで整列。
  4. 閾値グループ単位でページを構成し、行番号・ページ内小計・作成日時を付与して印刷用に表示。
  5. 「印刷する」ボタンで端末の印刷ダイアログを表示。
