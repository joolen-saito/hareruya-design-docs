1. 在庫移動指示リストエクスポート

機能の目的と役割

在庫移動指示一覧で選択した指示を外部参照用にCSV出力する機能。出力は2種類ある。

  1. **送り状CSV（送り状No.ダウンロード）**: 一覧でチェックした指示IDについて、出庫元店舗を「注文者」、入庫先店舗を「配送先」とした送り状（配送ラベル）形式のCSVを出力する。StockMoveInstructionLabelCsvExporterService が生成する。
  2. **在庫移動実績入力用CSV雛形**: 送り状No.一括登録（M04-24 のCSV登録）に取り込むための入力用CSV雛形（ヘッダのみ）を出力する。StockMoveInstructionController::csvTemplateDownload が生成する。

本機能のカスタマイズ区分は新規実装であり、現行（pf-eccube3）に対応実装はない。画面・項目・業務条件は基本設計仕様書（0202_基本設計仕様書(在庫管理機能)）を正とし、URLエンドポイント・出力列・DB関連は ec-cube-enterprise の実装を正とする。

本書で扱うこと

  • 送り状CSVの出力列・対象データ・整形・文字コード・ファイル名
  • 在庫移動実績入力用CSV雛形の出力列・文字コード・ファイル名
  • 出力対象の抽出（選択ID・関連店舗のJOIN）
  • 対象なし／ID無しの扱い

本書で扱わないこと

  • 一覧・検索・詳細・送り状No.登録・CSV取込・削除（M04-24 を正とする）
  • ピッキングリスト印刷（M04-26）
  • 在庫移動（DtbStockMoveTransfer）自体の登録・承認（M04-09 系）

利用者視点の入口（エンドポイント）

入口URLエンドポイント（ルート名）期待されるふるまい
送り状CSV出力POST /%admin%/product/stock/move-instruction/labels（admin_stock_move_instruction_labels_export）一覧でチェックした指示ID（ids[]）の送り状CSVを StreamedResponse で出力。ids が空配列/未指定は404。isTokenValid() でCSRF検証、set_time_limit(0)。
実績入力用CSV雛形ダウンロードGET /%admin%/product/stock/move-instruction/csv-template（admin_stock_move_instruction_csv_download_record）ヘッダのみのCSV雛形を StreamedResponse で出力。set_time_limit(0)。

%admin% は管理画面ルートプレフィックス（eccube_admin_route）。いずれも管理画面ログインを要する。

送り状CSV（StockMoveInstructionLabelCsvExporterService）

選択した指示IDを DtbStockMoveInstructionRepository::findByIdsForLabelExport($ids) で取得（MoveFromBaseInfo・MoveToBaseInfo と各 Pref をJOIN、id ASC）し、1指示=1行で出力する。

観点内容
出力サービスCsvExportService（fopen/fputcsv/fclose）。文字コードは eccube_csv_export_encoding（既定 SJIS-win、UTF-8時はBOM付与）、区切りは eccube_csv_export_separator。
ファイル名stock_move_instruction_labels_YmdHis.csv。
Content-Typeapplication/octet-stream、Content-Disposition: attachment。
ログ出力完了時 log_info「在庫移動指示 送り状CSV出力完了. ファイル名: …」。

在庫移動実績入力用CSV雛形（csvTemplateDownload）

観点内容
出力列（ヘッダのみ）移動指示ID / 出庫元店舗(名称) / 入庫先店舗(名称) / 送り状No.
文字コードeccube_csv_export_encoding（既定 SJIS-win）。UTF-8時のみBOM（\xEF\xBB\xBF）を出力。各列値を mb_convert_encoding(値, encoding, 'UTF-8')。
区切りeccube_csv_export_separator（既定 ,）。
ファイル名stock_move_instruction_record_template_YmdHis.csv。
Content-Typetext/csv; charset=...（SJIS-win時は windows-31j）、Content-Disposition: attachment。

この雛形のヘッダはM04-24のCSV取込（StockMoveInstructionCsvImportHandler）が要求する4列と一致する。

プロセスフロー

  1. 一覧でチェックボックス（ids[]）を選択し送り状CSV出力ボタンを押下（JSが非表示フォームにIDを詰めてPOST）、または雛形ダウンロードリンクを押下。
  2. 送り状CSV: CSRF検証 → ids 空なら404 → exportByInstructionIds($ids) で対象指示と関連店舗を取得 → ヘッダ＋各行をストリーム出力。
  3. 雛形: 列ヘッダのみをストリーム出力。

分岐・例外

  • **送り状CSVでID無し**: ids が空配列/未指定 → NotFoundHttpException（404）。
  • **対象なし**: findByIdsForLabelExport が空（該当指示なし）→ ヘッダのみのCSV（明示エラーなし）。

状態・データ更新

対象内容
主データ在庫移動指示 dtb_stock_move_instruction と関連店舗 BaseInfo（出庫元/入庫先・Pref）を**参照のみ**。出力により業務データは更新しない。
ログ送り状CSV出力完了を log_info に記録。

関連設計への接続点

  • 出力項目の業務要件は参照元Excel設計書（在庫移動指示詳細シート）を正とする。なおExcel設計が描く「総販売価格/総移動原価/高額・通常別合計」のラベルは在庫移動指示詳細（M04-24）の表示項目であり、本送り状CSVは配送ラベル用途の別フォーマットである。
  • URLエンドポイント・出力列・DBカラムは ../ec-cube-enterprise の StockMoveInstructionLabelCsvExporterService / csvTemplateDownload / DtbStockMoveInstructionRepository::findByIdsForLabelExport 実装を正とする。

リニューアル移行時の扱い

  • 本機能は新規実装であり、現行（pf-eccube3）に同等機能はない。移行後はec-cube-enterpriseの実装が初出となる。
  • DB関連はec-cube-enterpriseを正とする。出力元は在庫移動指示（dtb_stock_move_instruction）と関連店舗（BaseInfo、mtb_pref）で、送り状CSVの各列は上記Entityの実カラム/関連から組み立てる。送料・手数料・郵便種別は固定値（0/ゆうパック）。
  • 送り状CSVは在庫移動（dtb_stock_move_transfer）明細を参照せず、指示親（金額合計・店舗）のみから生成する点に留意（明細単位の出力は本機能では行わない）。
