バッチ 受注管理 — 注文番号登録

概要

注文番号テーブルに採番された注文番号を、受注サブテーブルへコピーするバッチである。コマンドライン（コンソールコマンド）から実行する。コピー対象の受注のうち店頭受取の注文については、スマレジ用の商品コード（バーコード）を生成して登録し、スマレジへ商品・在庫を連携する。

本書は実装手順ではなく、誰が・いつ・どの条件で・結果どうなるかを読むためのリバース詳細設計とする。確認値はpf-eccube3（EC-CUBE3系）のHareruyaEcプラグインの受注バッチ（注文番号コピー処理）、注文番号・受注サブを扱うリポジトリ、スマレジ連携処理を正とする。カスタマイズ区分は現行踏襲であり、挙動の参照リポはpf-eccube3、DB関連はec-cube-enterpriseを正とする。

対象はコンソールコマンドであり、ブラウザ経由の画面を持たない。

本文ではフレームワークのコマンド型名やサービス型名を主説明としない。実行はコンソールのバッチコマンドで行う。

本書で扱うこと

  • バッチの起動方法（コンソールコマンド）
  • 注文番号テーブルから受注サブテーブルへのコピー
  • 店頭受取注文に対するスマレジ商品コード生成とスマレジ連携
  • コピー対象が無い場合の挙動

本書で扱わないこと

以下は本書では仕様確定せず、実装または別機能の設計を正とする。

  • 注文番号の採番そのもの（受注処理を正とする）
  • スマレジ連携サービスの内部仕様
  • バッチの起動スケジュール（運用・ジョブ設定を正とする）

処理フロー

注文番号登録を実行する（order:batch copyOrderNumber）

  1. 注文番号テーブルから受注サブテーブルへ注文番号をコピーし、対象の受注IDの一覧を得る。
  2. 対象が無い場合は処理を終了する。
  3. メール送信用の経路を準備する。
  4. 対象の受注ごとに受注サブを取得する。
  5. 当該注文が店頭受取の配送区分に該当する場合、スマレジ用商品コード（バーコード）を生成して受注サブへ登録し保存する。
  6. 店頭受取の注文についてスマレジへ商品・在庫を連携する。
