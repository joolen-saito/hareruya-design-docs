店舗基本設定の店舗登録（SHOPマスター保存）

業務ロジック

初期表示

店舗基本情報を既定の識別子で取得し、入力欄の初期値とする。画面共通で参照する店舗基本情報には、取得した内容の複製を渡す。編集する対象とは別の値であり、リクエスト開始時点の状態のまま保持される。

保存の判定順序

順序判定結果
1管理画面へのアクセスが許可されるか許可されなければ保存処理に到達しない
2なりすまし対策トークンを含む送信として妥当か妥当でなければ共通のエラー扱いとする
3送信された内容か保存の要求のときだけ以降へ進む
4入力の検証通れば保存し、通らなければ項目のエラーを表示して再表示する
5設定で結果キャッシュの削除が有効で、店舗基本情報の更新が起きたか該当すれば結果キャッシュを全件削除する

保存が成立したときは更新日時に現在時刻を設定し、完了メッセージを表示して基本情報設定画面へ戻す。

検証に通らなかったときは保存せず、同じ画面を再表示して項目のエラーを表示する。このとき画面共通で参照する店舗基本情報はリクエスト開始時点の複製のままなので、入力欄に載っている送信値と、画面のほかの箇所に出る値が一致しないことがある。

計算

本機能では金額・数量の業務集計を行わない。送料無料条件の金額・数量は、検証を通った入力値をそのまま保存する。

エラー時の扱い

エラー内容処理
入力の検証エラー項目にエラーを表示する。データは更新しない
なりすまし対策トークンの不正共通のエラー扱いとする
権限・接続元の不許可アクセスを拒否する

入出力

種類内容
入力店舗基本情報の全入力項目、なりすまし対策トークン、拡張で追加された項目
成功時出力完了メッセージと、基本情報設定画面の再表示
失敗時出力同じ画面での項目エラーの表示

入出力: 永続化

操作契機
更新入力の検証を通った店舗基本情報の保存
キャッシュ削除店舗基本情報が更新され、結果キャッシュの削除設定が有効なとき
