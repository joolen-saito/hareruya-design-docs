業務ロジック

詳細の表示

指定した店頭買取注文が無いときは表示しない。

明細は買取価格の降順、次に明細IDの昇順で並べる。ステータス変更履歴は当該注文に紐づくものを作成日時の降順で表示する。ステータスの表示名は店頭買取ステータスマスタの対応表から取る。

実在庫の表示行は、カード状態IDの昇順、次に買取金額の降順、次に商品規格IDの昇順で並べる。実在庫の編集行は、高額商品の規格一覧と、通常商品を全カード状態（NM, SP, MP, HP）へ展開した規格一覧を結合したものとする。

画面はフリーコメント欄と商品検索欄を持つ。

保存の判定順序

順序判定結果
1店頭買取注文が存在するか無ければ表示しない
2入力が妥当か妥当でなければ保存せず、成功・失敗いずれのメッセージも出さずに詳細画面へ戻る
3在庫の増減指定に 0 以外が残っているか残っていれば在庫更新を行う。すべて 0 または未送信ならフリーコメントなど入力で変わった項目だけを保存する
4在庫更新の店舗一致・ステータス・数量下限いずれかに反することは保存しない

在庫更新は、操作者の編集可能店舗と買取店舗が一致し、ステータスが未登録在庫ありまたは入庫待ちで、増減後の数量が負にならないときだけ行う。これらに反するときはエラー文言を表示する。

保存の成否にかかわらず、同じ買取詳細画面へ戻る。

在庫の増減

在庫の増減で指定した商品規格だけ、変更前の数量を記録した在庫履歴を残す。増減後の数量に応じて原価の小計を配分し直す。対象には既存の実在庫と新規の行が混在しうる。

在庫を増減したときは注文の更新日時を更新する。フリーコメントだけを変えたときは更新日時を更新しない。

個別入力商品への規格登録

送信情報が不正なときは登録しない。注文または個別入力商品が存在しない、個別入力商品が当該注文に属さないときも登録しない。指定した商品規格が見つからないときはエラー文言を表示する。

登録は、操作者の編集可能店舗が一致し、ステータスが未登録在庫ありで、当該行が未登録のときだけ行う。実在庫を新規に作るか既存へ加算し、個別入力行へ商品規格を設定する。全行が登録済みになったときはステータスを入庫待ちへ進める。

経理払出し済への変更

送信情報が不正なときは変更しない。注文が存在しない、操作者が管理者アカウントでないときも変更しない。操作者の編集可能店舗と買取店舗が一致しないときは変更しない。現在のステータスが経理払出し待ちでないときはエラー文言を表示する。条件を満たすときは買取完了へ進める。

入庫済への変更

送信情報が不正なときは変更しない。注文が存在しない、操作者が管理者アカウントでないときも変更しない。操作者の編集可能店舗と買取店舗が一致しないときは変更しない。条件を満たすときは入庫済へ進める。

Excel基本設計との関係

Excel基本設計 0205 識別ID:15 および識別ID:9 により廃止された仕様である。現行実装のふるまいは本書に残すが、刷新後の実装・テストの対象外とする。
