中継の判定順序

順序判定・処理内容
1入力の有無契約ID・アクセストークン・処理名・パラメータのいずれかが欠けているときは入力不正（HTTP400）とし、空の本文を返す
2中継契約IDとアクセストークンを付与し、処理名とパラメータをスマレジ顧客連携の取引APIへ中継する
3中継結果の確認中継結果に結果キーが含まれないときは入力不正（HTTP400）とし、中継結果をそのまま返す
4ポイント付与処理名が取引更新のときだけ、パラメータの先頭行から会員を引いてポイントを付与する
5応答中継結果をコード200で返す

取引更新のときのポイント付与

会員の特定処理
スマレジ会員IDで会員を特定できたとき会員ポイントに付与ポイントを加算し、ポイント履歴を登録する
会員を特定できないときポイント付与を行わず、コード200で中継結果を返す

ポイント履歴には、会員・増減ポイント・メモ・発生日時・ポイント種別を記録する。

値の取り方

金額・税・ポイント・在庫数量の再計算と丸めは行わない。応答値は本API内で独自に集計せず、中継結果をそのまま返す。契約IDとアクセストークンの原値は本書に記載しない。

呼び出し元は外部連携先（任意門・PointGranter）である。アクセス経路の制御はAPIの外（ネットワーク・配置）の範囲とし、本書では仕様を確定しない。

エラー時の扱い

事象扱い
ヘッダまたはパラメータが欠けているとき入力不正（HTTP400）とし、空の本文を返す
中継結果に結果キーが含まれないとき入力不正（HTTP400）とし、中継結果をそのまま返す
取引更新で会員を特定できないときポイント付与を行わず、コード200で中継結果を返す

入出力

種類内容
入力契約ID（X_contract_id、ヘッダ、必須）。アクセストークン（X_access_token、ヘッダ、必須）。処理名（proc_name、ボディ、必須。取引更新は transaction_upd）。処理パラメータ（params、ボディ、必須、JSON文字列。取引更新のときは会員・付与ポイント・メモ・発生日時・ポイント種別を含む）。
成功時出力HTTP200。スマレジ取引APIの中継結果。結果キー（result）を含む。詳細な構造は連携先の仕様による。
失敗時出力HTTP400。入力が欠けているときは空の本文、結果キーが無いときは中継結果をそのまま返す。

入出力: 永続化

操作契機
更新取引更新で会員を特定できたとき、会員ポイントに付与ポイントを加算する
追加取引更新で会員を特定できたとき、ポイント履歴を1件登録する
