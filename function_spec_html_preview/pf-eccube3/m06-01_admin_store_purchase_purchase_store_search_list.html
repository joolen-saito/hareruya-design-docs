店頭買取管理 — 買取検索一覧

本機能はフェーズ1対象本節は実装（pf-eccube3）からのリバースです。本機能全体はフェーズ1の実装・テスト対象です。次の項目だけがExcel基本設計によりフェーズ2対応とされており、フェーズ1では実装・テストの対象外です。

  • 買取商品（キャンセル）CSV出力 はフェーズ2対応（0205 買取一覧(検索結果)）
    Excel原文: 買取商品（キャンセル）CSVはPh2の要件となるためPh1では実装しない

業務ロジック

フェーズ2対応（フェーズ1では実装しない）

  • Excel基本設計 0205「買取商品（キャンセル）CSV出力」はフェーズ2対応。フェーズ1では実装しない。

初期表示

検索画面を開いた時点では一覧を表示しない。表示件数は設定の既定値とする。検索画面を開き直したときは、保持していた検索条件・ページ番号・表示件数を破棄する。

検索の実行

項目決め方
ソートキー要求の指定があればそれを用い、無いときは保持している値、それも無いときは既定のソートキーとする
並び順要求の指定があればそれを用い、無いときは保持している値、それも無いときは降順とする
表示件数保持している値があればそれを用い、無いときは既定値とする。要求された値が妥当なときは保持している値を更新する
検索条件送信された条件を用いる。条件が空に見えるときは保持している検索条件を復元する

既定のソートキーは1種類だけで、既定の並び順は降順であるため、一覧は買取情報の登録が新しいものから順に並ぶ。

並び順が昇順・降順のいずれにも合致しないときは、エラーを表示して処理を打ち切る。

要求で指定できるソートキーは default の1種類で、買取情報のIDの順に並べる。並び順の要求値として受け付けるのは ASC・DESC・asc・desc の4つである。

件数を数え直した結果、最終ページの件数がちょうど境界になった直後などで対象ページが空になるときは、ページ番号を1つ戻して取得する。

検索条件・ページ番号・ソートキー・並び順・表示件数は画面をまたいで保持する。ページを移動したときと表示件数を変えたときは、保持している検索条件を復元して該当ページを表示する。

検索条件の当てはめ方

検索条件当てはめ方
査定ID完全一致
会員ID完全一致
申込者名空白またはカンマで語に分け、語ごとに姓・名・姓カナ・名カナのいずれかへ部分一致するものを対象とする。語が複数あるときはすべての語に一致するものだけを対象とする
買取金額(From)・(To)From が To より大きいときはエラーとせず、両者を入れ替えて検索する
ステータス指定しないときは、ステータスが買取キャンセルの買取情報を検索結果から除く。ステータスに買取キャンセルを指定したときは表示する

値の取り方

買取金額は、金額の前に通貨記号を付け、3桁ごとに区切って表示する。小数は表示しない。申込者は姓と名を空白で区切って表示する。

査定担当者は、ステータスを買取成立へ変更した履歴のうち最も新しいものの担当者を表示し、その履歴が無いときは最終更新者を表示する。削除済みの担当者も名前を表示する。

エラー時の扱い

エラー内容処理
CSV出力で買取注文を1件も選択していないときエラーを表示し、要求元の一覧画面へ戻す
並び順の指定が不正なときエラーを表示し、検索画面の初期表示へ戻す（保持していた検索条件・ページ番号・表示件数は破棄され、一覧は表示しない）
検索条件に該当するデータが無いとき該当件数の見出し・表示件数の選択・ダウンロード操作・一覧・ページ送りをいずれも表示せず、該当なしのメッセージだけを表示する

入出力

種類内容
入力検索フォームの各項目、ページ番号、表示件数、ソートキーと並び順。一覧にソートの操作は無く、保持している値を引き継ぐ
成功時出力検索フォームと、検索したときは一覧・ページ送り・表示件数の選択肢
失敗時出力並び順が不正なときなどはエラーを表示し、一覧を表示しない
