在庫管理 — 在庫変更CSV登録

業務ロジック

取り込むCSV

CSVは商品コード・在庫増減数・仕入単価を必須の列とする。現行 pf-eccube3 は商品コードと在庫増減数の2列を必須とする。

在庫変動理由はCSVの列に持たず、画面で全行に共通の変更理由として入力する。

取り込みの判定順序

順序判定結果
1在庫増減数が0か0なら更新せず次の行へ進む。
2商品コードから規格を特定できるか見つからなければ未存在エラー、2件以上見つかれば重複エラー、他の処理が更新中なら更新中エラーとして中断する。
3更新後の在庫数が0を下回るか下回るなら在庫不足エラーとして中断する。
4更新後の在庫数が上限を超えるか超えるならエラーとして中断する。
5上記を通過したか在庫数を更新し、在庫変更履歴を1件追加し、入荷集計に増減数を加える。

エラーが起きた行があった時点で、以降の取り込みを中断する。

在庫数の更新

更新後の在庫数は、現在の在庫数に在庫増減数を加えて求める。

更新後の在庫数が0より大きく、更新前の在庫数が0だった規格は入荷通知の対象に加える。更新が成立した規格は支店への通知対象に加える。

在庫変更履歴の記録

在庫変動理由の区分はマスタ更新とする。在庫変動理由には画面で入力した共通の変更理由を記録する。

同名ファイルの再取り込み

直近で取り込んだファイルと同じ名前のファイルは取り込まない。

他機能との境界

1件ずつの在庫更新は「在庫編集」を、複数件の画面上での更新は「在庫一括編集」（M04-03）を正とする。

入出力

種類内容
入力CSVファイル、変更理由
成功時出力在庫数の更新、取り込み完了メッセージ
失敗時出力行ごとのエラー一覧、ファイルの検証エラー

入出力: 永続化

操作契機
更新（在庫数）CSVの行の取り込み
追加（在庫変更履歴）在庫数を更新したとき
更新（入荷集計）在庫数を更新したとき
