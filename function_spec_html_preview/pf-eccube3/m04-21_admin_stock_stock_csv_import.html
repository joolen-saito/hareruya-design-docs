在庫管理 — 在庫変更CSV登録

業務ロジック

在庫増減数が0の行

在庫増減数が0の行は在庫を変えず、次の行へ進む。

行ごとのエラー判定

商品コードに該当する商品規格が無い行と、商品コードに該当する商品規格が2件以上ある行はエラーとする。削除済みの商品・商品規格は、商品コードが一致しても該当しないものとして扱う。他の処理が同じ商品規格を更新している間は、その行をエラーとする。

在庫増減数を反映した後の在庫数が0を下回る行と、在庫数の上限を超える行はエラーとする。

入荷通知と支店への在庫連携

在庫増減数を反映した後の在庫数が0より大きく、反映前の在庫数が0だった商品規格は入荷通知の対象とし、取り込みがエラーなく終わったときにまとめて入荷通知のメールを送る。エラーで終わったときは送らない。

取り込みで在庫数が変わった商品規格は、取り込みの終了時に支店へ在庫の更新として連携する。連携はエラーで終わったときも行う。

同名ファイルの再取り込み

直近で取り込んだファイルと同じ名前のファイルは取り込まない。

入出力

入出力: 永続化

操作契機
更新（入荷集計）在庫増減数が正の行を取り込んだとき
