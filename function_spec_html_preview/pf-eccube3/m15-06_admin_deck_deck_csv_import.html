デッキ管理 — デッキ登録CSV（取込）

業務ロジック

取込ファイルの形式

1行目をヘッダ行として扱う。拡張子が tsv のときはタブ区切り、それ以外のときは既定の区切り文字と囲み文字を用いる。読み込み時に文字コードを環境ごとの方針で変換し、改行を統一し、ゼロ幅文字とBOMを除去する。取り込んだファイルは一時領域へ乱数由来の名前で移して読み込み、処理の成否によらず、残っていれば削除する。

ヘッダ行の項目

画面には、ヘッダ行の並びと各項目の説明を表示する。並びは次のとおりで、本文1行目と一致させる。

並び順項目内容
1player_nameプレイヤー名
2formatフォーマット
3archetypeアーキタイプ
4event_detail_idイベント詳細ID
5deck_nameデッキ名
6win_count勝利数
7loss_count敗北数
8draw_count引分数
9ranking順位
10result成績
11dci_noDCI番号
12event_name_enイベント名(英)
13event_name_jpイベント名(日)
14event_dateイベント開催日
15source_url参照元
16participantsイベント参加人数
17disp_flg表示フラグ
18private_flgデッキリスト非公開フラグ
19main_listメインリスト
20side_listサイドリスト
21commander統率者
22deck_idデッキID。空欄のときは自動採番の新規、既存値と一致するときは上書き
23image_card_name代表カード名
24old_deck_id旧デッキID

必須は player_name・format・archetype・event_name_en・event_name_jp・event_date・disp_flg・private_flg・main_list の9項目である。ただし main_list は、private_flg がデッキリスト非公開のときだけ空欄を許す。

行ごとの判定順序

順序判定
1当行の値の個数がヘッダの個数と等しいこと
2必須項目が空欄でないこと（main_list の特例を除く）
3format の英名に一致するレギュレーションが存在すること
4archetype の日本語名または英名が、当該フォーマットのアーキタイプに一致すること
5event_detail_id が空でないときは、該当のイベント詳細が存在すること
6event_date が日時として解釈できること
7disp_flg がデッキの公開・非公開いずれかの値と完全に一致すること
8private_flg が二値のいずれかと完全に一致すること
9統率者を使うフォーマットのときだけ commander を必須とし、空でないときはカード名として解けること、解けた名前が有効なカードであること
10old_deck_id が空でないときは、半角英数とアンダースコアで最大16文字であり、既存のデッキと重複しないこと
11リスト検証の経路に入るときは、リスト形式の異常と不明なカード名が無いこと

いずれかが成立しないときは、その行で取込を中止し、それまでの登録を取り消す。

統率者の判定では、行頭に枚数として 1 と空白を前置した形でカード名を解く。リスト検証では、 // をスラッシュ1つへ正規化してからリストを解釈する。統率者があるときは、メインボードから統率者カードの重複を除いてテキストを再生成する。

厳密チェック

「厳密」を指定したときだけ、次の検査結果をエラーへ昇格する。指定しないときは、リスト内に複数種のエラー状態があっても取込を続ける。

検査
アーキタイプ横断チェック
禁止制限チェック
リスト形式の異常・不明なカード名
メイン・サイドそれぞれの枚数総和が、フォーマットの許容下限・上限に収まること

枚数総和は、メインボードとサイドボードそれぞれで、リスト解釈後の各カードの所持枚数を合計した数である。統率者の枚数規定は総和の評価に含めない。

登録の判定

deck_id の値登録
空欄のとき新規に採番して登録する
既存のデッキと一致するときそのデッキを上書きする

デッキ名・イベント情報・勝敗数・順位・成績・各フラグ・リスト原文・調整済みの統率者テキスト・旧サイト向け連番・代表画像を、行の値で設定する。表示フラグは、取込値の公開・非公開から表示区分の値へ読み替える。登録者には操作した管理者アカウントを必ず設定する。デッキ種別が未設定のときは、イベント種別を既定として補う。

デッキ明細の作成

リスト検証の経路に入る行だけ、ボード単位でデッキ明細を作成する。統率者は、統率者を使う形式で入力が済んでいるときは、常に統率者ボードへ別に書き込む。

表示状態とリスト本文

表示フラグが公開へ読み替えられ、かつデッキリスト非公開フラグが公開状態のときだけ、本文テキストとデッキ明細が一致する状態を検証して書き換える。それ以外の組み合わせのときは、リスト本文の検証と明細の出力を広く省略し、入力した原文をメインリスト・サイドリストのテキストにだけ反映する。

代表カード

image_card_name の値代表画像
空でなく、有効なカードへ解けるときその名前から最適と判定される画像を設定する
空のとき当該フォーマットに紐づくアーキタイプの既定の代表画像で上書きする

エラー時の扱い

事象扱い
入力内容の検証に外れたときエラーを順に表示する
取込ファイルを受け取れないとき登録せず、取込画面へ戻る
ファイルの読み込みに失敗したとき登録せず、取込画面へ戻る
ヘッダの並びが期待の並びと一致しないとき登録せず、取込画面へ戻る
データ行が0件のとき登録せず、取込画面へ戻る
行の判定に外れたときそれまでの登録を取り消し、エラーを表示して取込画面へ戻る

入出力

種類内容
入力取込ファイル（必須）と「厳密」の指定（任意）。
成功時出力全行の登録を確定し、完了メッセージとともに取込画面へ戻る。
失敗時出力エラーメッセージとともに取込画面へ戻る。行の判定で外れたときは、それまでの登録を取り消す。

入出力: 永続化

操作契機
追加デッキIDが空欄の行を取り込んだとき。リスト検証の経路に入る行はデッキ明細も追加する
更新デッキIDが既存のデッキと一致する行を取り込んだとき
