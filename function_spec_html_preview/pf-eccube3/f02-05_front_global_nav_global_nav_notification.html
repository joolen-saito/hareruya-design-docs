フェーズ2対応（フェーズ1では実装しない）

  • Excel基本設計 0302「通知機能」はフェーズ2対応。フェーズ1では実装しない（機能全体）。Excel原文: 「フェーズ2以降で設計予定とする」

通知として表示するもの

保有ポイント表示、マイページアイコンと隠しメニュー（マイページへの導線、未ログイン時はログイン／会員登録）、カートのアイコンとカート個数、言語切替リンクを共通ヘッダに表示する。保有ポイント表示・隠しメニュー・カート個数はヘッダ右側に配置し、隠しメニューは重ね表示する。いずれも条件で有無が変わる通知表示である。通知表示自体は専用モーダルを持たず、入力フォームも持たない。本通知表示は共通ヘッダ部品の挙動であり、本店・支店いずれのヘッダでも同じ条件で出し分ける。

出し分けの判定順序

順序判定結果
1利用者がログイン会員か会員なら保有ポイント表示を出す。未ログインなら出さない
2利用者がログイン会員か未ログインなら隠しメニューにログイン／会員登録の導線を加える。会員なら加えない。マイページへの導線はいずれの状態でも出す
3言語切替リンクが無効化されているか無効化されていなければ言語切替リンクを出す
4カート情報の非同期取得取得したカート数量をカート個数表示へ反映する

保有ポイントの集計はポイント機能を正とし、カート個数の算定はカート機能を正とする。本機能は金額計算・税計算・丸めを行わない。

エラー内容処理
カート個数の非同期取得失敗取得できない場合の表示は本書では仕様確定せず、実装を確認値とする
保有ポイントのヘッダ表示の取得障害共通の異常処理に委ねる
