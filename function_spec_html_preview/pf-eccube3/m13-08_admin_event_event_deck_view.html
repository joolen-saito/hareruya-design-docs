M13-08（デッキ表示）

刷新後は実装不要本節は現行実装（pf-eccube3）からのリバースです。次の記述は Excel基本設計により廃止されており、刷新後に実装する必要はありません。

  • DCIナンバー（デッキ表示） は削除（0214 デッキ表示 識別ID:5）
  • デッキチェック記入欄（Deck Check Rd・Status・Judge） は削除（0214 デッキ表示 識別ID:9-11）

管理画面「イベント管理」のイベント申込一覧から、現在の申込検索条件に該当するイベントに登録されたデッキを、印刷向けのデッキリストとして別ウィンドウで表示する機能である。

概要

デッキ表示は、管理者がイベント申込一覧で絞り込んだ条件に該当するデッキ（メインデッキ・サイドボードのカード構成）を一覧表示し、印刷して大会運営に用いるための読み取り専用画面である。表示対象は申込一覧の検索条件セッションから決まり、本画面では検索フォームや更新操作を持たない。

本書は実装手順ではなく、誰が・いつ・どの条件で・結果どうなるかを読むためのリバース詳細設計とする。既存実装が表示するデッキの抽出条件、カード構成の組み立て、ページ分割、読み取り専用であることを確認し、仕様の確からしさを把握することを目的とする。

対象はブラウザ経由の管理画面のデッキ表示画面である。本機能は晴れる屋向けプラグインで提供され、EC-CUBE3系のSilexアプリケーション上で動作する。管理画面プレフィックスはアプリケーション設定admin_route（$app['config']['admin_route']）で決まり、ルートはこの値を連結して登録される。確認観点は申込用サービスプロバイダのルート登録とする。

申込の検索条件の決まり方はM13-06を正とする。本書はデッキ表示画面の表示内容と抽出に範囲を限定し、デッキの登録・編集、デッキ管理画面（/deck配下）、申込CSV出力は扱わない。

本機能のカスタマイズ区分はカスタマイズである。挙動の参照リポはpf-eccube3（HareruyaEcプラグイン）の現行実装とし、DB関連（永続化先のテーブル名・列名、DBカラム節）はec-cube-enterpriseを正とする。現行と移行先でスキーマが異なる箇所はリニューアル移行時の扱いに集約する。

本書で扱うこと

  • イベント申込一覧のデッキ表示ボタンから別ウィンドウでデッキ表示画面を開いたときのふるまい
  • 申込一覧の検索条件セッションからデッキ表示対象を決める仕組み
  • 表示するデッキ情報（プレイヤー名・DCIナンバー・イベント名・開催日・メイン／サイドのカード一覧と枚数）
  • メインデッキを1ページ40枚で分割し、サイドボードを先頭ページに載せるページ分割
  • 本画面が読み取り専用であること

本書で扱わないこと

以下は本書では仕様確定せず、実装または別機能の設計を正とする。

  • 申込検索の検索条件・検索モード・セッション保持（M13-06を正とする）
  • デッキの登録・編集・複製・削除（デッキ管理画面の機能を正とする）
  • デッキ管理画面（/deck配下）のデッキ一覧・CSV取込
  • 申込CSVの出力（M13-06の範囲外で別機能）
  • カード名・カードリストのエンコード仕様の詳細
  • 管理画面へのアクセス制御、ログイン、権限設定の詳細

リニューアル移行時の扱い

表示・抽出・ページ分割の挙動は現行（pf-eccube3）を正とし、参照する列名は移行先（ec-cube-enterprise）を正とする。本画面は読み取り専用でDBを更新しない。

処理フロー

デッキ表示画面を開く

  1. 申込一覧（M13-06）の検索条件セッション（admin.event_entry.search）を読む。無ければ空とする。
  2. 申込一覧の検索フォーム（フォーム名admin_entry_list）を生成し、読み出した検索条件を反映して検索データを得る。
  3. ソートキー・並び順をリクエストの値、無ければ既定とする。
  4. デッキリポジトリの登録デッキ取得で、検索条件に該当するデッキ（エンティティ）の一覧を取得する。
  5. デッキごとにメイン・サイドのカードリストを復号し、メイン枚数・サイド枚数を合計する。
  6. メインのカード一覧を1ページ40枚で分割する。先頭ページにはサイドボードを載せ、2ページ目以降のサイドは空とする。
  7. ページごとにプレイヤー名・DCIナンバー・日程・メインカード・メイン枚数・サイド枚数を組み立てる。プレイヤー名はデッキのプレイヤー名（前後空白を除去）を用い、空のときは会員のカナ姓・カナ名を半角空白で連結する。
  8. 組み立てたデッキリストをデッキリスト用テンプレートで描画する。
