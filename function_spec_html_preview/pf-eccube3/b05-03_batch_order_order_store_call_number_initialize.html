バッチ 受注管理 — 店頭注文番号初期化

概要

店頭注文番号テーブルの全レコードを削除し、採番カウンタを初期値に戻すバッチである。コマンドライン（コンソールコマンド）から実行する。店頭販売で利用者へ提示する整理番号（店頭注文番号）は、店頭注文番号テーブルへ採番のたびに追加され、テーブルの自動採番値で連番が決まる。本バッチはこのテーブルを空にし、自動採番値を1へ戻すことで、次回以降の店頭注文番号を最初の番号から再採番できる状態にする。

本書は実装手順ではなく、誰が・いつ・どの条件で・結果どうなるかを読むためのリバース詳細設計とする。確認値はpf-eccube3（EC-CUBE3系）のHareruyaEcプラグインの受注バッチ（店頭注文番号初期化処理）、店頭注文番号を扱うリポジトリを正とする。カスタマイズ区分はカスタマイズであり、挙動の参照リポはpf-eccube3、DB関連はec-cube-enterpriseを正とする。

対象はコンソールコマンドであり、ブラウザ経由の画面を持たない。

本文ではフレームワークのコマンド型名やサービス型名を主説明としない。実行はコンソールのバッチコマンドで行う。

本書で扱うこと

  • 店頭注文番号テーブルの全削除と採番カウンタの初期化
  • 初期化に伴うデータ消失と再採番の挙動
