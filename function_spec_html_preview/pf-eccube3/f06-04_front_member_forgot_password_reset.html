会員 — パスワード変更（パスワード再発行・再設定）

業務ロジック

再発行メールの送信対象

パスワード再発行の申し込みでメールアドレスから探す対象は本会員に限る。入力されたメールアドレスが仮会員のものであるときは、リセットキーの発行も再発行メールの送信も行わない。

再設定対象の会員の特定

再設定・更新の対象会員は、URLに含まれるリセットキーだけで特定する。パスワード再設定画面の「登録されているメールアドレス」欄は形式の検証だけを行い、リセットキーで特定した会員のメールアドレスと一致するかの照合は行わない。別の会員のメールアドレスを入力しても、リセットキーの会員のパスワードが更新される。

「変更する」押下時の再判定

パスワード再設定画面の表示時だけでなく、「変更する」押下時にも、リセットキーの書式確認とリセットキーによる有効会員の取得をあらためて行う。

「変更する」押下時の状態結果
リセットキーの書式が不正「アクセスできません。／お探しのページはアクセスができない状況にあるか、移動もしくは削除された可能性があります。」の共通エラー画面を表示し、パスワードを更新しない
リセットキーの有効期限内の本会員を取得できない「404 Page Not Found／お探しのページが見つかりません。」の共通エラー画面を表示し、パスワードを更新しない

有効期限切れは、再設定画面の表示時と「変更する」押下時とで表示する画面が異なる。
