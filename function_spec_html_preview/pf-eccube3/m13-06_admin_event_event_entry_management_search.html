業務ロジック

検索条件の絞り込み方

イベント名は、空白またはカンマで区切った語ごとに絞り込む。語ごとに、イベント名（日本語）・イベント名（英語）・略称（日本語）・略称（英語）のいずれかへ部分一致すれば該当とし、指定した語すべてに一致するものだけを残す。

プレイヤー名も同じ区切りで語ごとに絞り込み、会員の姓・名、その読み仮名、プレイヤーの英語姓・英語名のいずれかへ部分一致すれば該当とする。

支払番号は完全一致で絞り込む。

支払方法の選択肢の並び

支払方法の選択肢は、支払方法の表示順の昇順で並べる。

検索モードと並び順

選んだ検索モードで使えない並び順の指定が来たときは、当該モードの既定の並び順へ補正する。検索モードを切り替えた直後に並び順の指定が無いときも、切り替え先のモードの既定の並び順とする。

初期表示

一覧の初期表示では、保持していた検索条件・ページ番号・表示件数を破棄し、空の一覧・ページ番号1・既定の表示件数で表示する。

検索の成立条件

検索条件を受け取れないときは、保持していた前回の検索条件で検索する。保持もしていないときは初期表示へ戻す。

並び順が昇順・降順のいずれでもないときは並び順エラーを表示し、初期表示へ戻す。

表示件数と並び順の決定

表示件数は、指定された値が表示件数マスタに登録されているときだけ採用する。並び順とソートキーは、指定・前回の保持・既定の順に優先する。

検索が成立したときは、検索条件・ページ番号・表示件数・並び順・ソートキーを保持し、次の検索まで引き継ぐ。ページ送り・表示件数変更・並び替えでは、前回の検索条件を復元して検索し直す。同時に指定された並び順・ソートキー・表示件数があればそれを優先する。

最終ページの表示対象が無くなったときは、ページ番号を1つ前に戻す。

イベント詳細を指定した表示

特定の日程を指定して開いたときは、その日程を検索条件に設定し、並び順は既定とする。検索モードはイベント申込検索に固定する。

入出力

種類内容
入力検索条件、検索モード、ページ番号、表示件数、並び順。日程を指定して開くときはイベント詳細。
成功時出力検索フォームと、該当する申込またはデッキの一覧。
失敗時出力並び順が不正なときは並び順エラーを表示して初期表示へ戻す。
