検索モード

検索モードによって集計対象と既定の並び順が変わる。イベント申込検索は申込プレイヤー単位、デッキ登録検索はデッキ単位で数える。

選んだモードと整合しない並び順の指定が来たときは、当該モードの既定の並び順へ補正する。

初期表示

一覧の初期表示では、保持していた検索条件・ページ番号・表示件数を破棄し、空の一覧・ページ番号1・既定の表示件数で表示する。

検索の成立条件

検索条件を受け取れないときは、保持していた前回の検索条件で検索する。保持もしていないときは初期表示へ戻す。

並び順が昇順・降順のいずれでもないときは並び順エラーを表示し、初期表示へ戻す。

表示件数と並び順の決定

表示件数は、指定された値が表示件数マスタに登録されているときだけ採用する。並び順とソートキーは、指定・前回の保持・既定の順に優先する。

ページ送り・表示件数変更・並び替えでは、前回の検索条件を復元して検索し直す。同時に指定された並び順・ソートキー・表示件数があればそれを優先する。

最終ページの表示対象が無くなったときは、ページ番号を1つ前に戻す。

イベント詳細を指定した表示

特定の日程を指定して開いたときは、その日程を検索条件に設定し、並び順は既定とする。検索モードはイベント申込検索に固定する。

Excel基本設計との関係

Excel基本設計 0214 識別ID:3-1 および識別ID:3-2 により廃止された仕様である。現行実装のふるまいは本書に残すが、刷新後の実装・テストの対象外とする。
