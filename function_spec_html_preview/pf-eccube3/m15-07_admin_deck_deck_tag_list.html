デッキ管理 — デッキタグ一覧（カスタム管理画面）

業務ロジック

一覧の表示

デッキタグをすべて取得して一覧に表示する。一覧に出す項目は日本語名・英語名・表示順で、行ごとに編集と削除の操作を置く。ページ内の表示件数・ページ番号・並び替えキーは、リクエストの指定または画面の既定値で決める。既定は表示件数100件・1ページ目・表示順の昇順で、表示件数は10件から100件まで10件刻みで選べる。並び替えキーは日本語名・英語名・表示順の3種で、いずれも昇順のみ。対応表に無い並び替えキーを受け取ったときは並び順を指定しない。登録・更新用のモーダルは一覧と同じ画面に置き、一覧表示のときは入力値の検証を行わない。新規登録でモーダルを開いたときは、表示順に一覧中の最大の表示順＋1を初期表示する。取得した全件のうち一覧に出すのは現在のページに当たる行だけで、デッキタグが1件以上あるときは一覧の下にページ送り（前へ・ページ番号・次へ）を出し、ページ送りの各リンクは表示件数と並び替えを保つ。画面のタイトルは「デッキタグ管理」で、モーダルの見出しは新規登録が「デッキタグ新規作成」・編集が「デッキタグ編集」、送信ボタンの文言は新規登録が「登録」・編集が「更新」になる。

登録・更新

識別子を伴わない送信は新規登録、識別子を伴う送信は当該デッキタグの更新とする。識別子はあるが該当するデッキタグが無いときはページが見つからない扱い（404）とする。入力値の検証に通ったときだけ、送信された日本語名・英語名・表示順をデッキタグへ反映する。デッキとアーキタイプの関連は登録・更新の対象から外すため変更しない。更新後は送信時と同じ表示件数・ページ番号・並び替えの一覧へ戻る。検証に通らないときは一覧と同じ画面を再表示し、モーダルを開いた状態で入力エラーを見せる。

日本語名と英語名はいずれも必須で32文字以内、表示順は必須で1以上999999以下とし、他のデッキタグと同じ表示順は登録・更新できない。

削除

削除の操作では確認を求め、承諾したときだけ削除を実行する。削除対象のデッキタグが無いときはページが見つからない扱い（404）とする。当該デッキタグに紐づくデッキが1件以上あるときは削除しない。アーキタイプ初期値側の関連が1件以上あるときも削除しない。いずれも0件のときだけ削除する。削除の可否にかかわらず、この一覧画面ではなく、メニューの「デッキタグ一覧」が開くMTGマスターデータ管理画面へ戻る。

入出力

種類内容
入力一覧の表示件数・ページ指定と並び替え指定、登録・更新の日本語名・英語名・表示順、削除対象のデッキタグID
成功時出力一覧画面のHTML、または完了メッセージを伴う一覧への戻り
失敗時出力入力不備は同一画面の再表示でエラーを見せる。使用中の削除はエラーメッセージを伴う一覧への戻り

入出力: 永続化

操作契機
追加識別子を伴わない登録・更新の送信が検証に通ったとき
更新識別子を伴う登録・更新の送信が検証に通ったとき
削除関連するデッキとアーキタイプ初期値がいずれも0件のデッキタグを削除したとき
