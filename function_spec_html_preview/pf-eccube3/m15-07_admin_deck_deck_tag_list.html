デッキ管理 — デッキタグ一覧（カスタム管理画面）

業務ロジック

一覧の表示

デッキタグをすべて取得して一覧に表示する。ページ内の表示件数・ページ番号・並び替えキーは、リクエストの指定または画面の既定値で決める。並び替えは昇順のみで、既定のキーと表示順キーはいずれも表示順の昇順になる。対応表に無い並び替えキーを受け取ったときは並び順を指定しない。検索条件は保持しない。登録・更新用のモーダルは一覧と同じ画面に置き、一覧表示のときは入力値の検証を行わない。

登録・更新

識別子を伴わない送信は新規登録、識別子を伴う送信は当該デッキタグの更新とする。識別子はあるが該当するデッキタグが無いときはページが見つからない扱い（404）とする。入力値の検証に通ったときだけ、送信された名称2種と表示順をデッキタグへ反映する。デッキとの関連は更新の対象から除外するため変更しない。更新後は送信元と同じページ変数でデッキタグ一覧へ戻る。検証に通らないときは一覧と同じ画面を再表示し、モーダルを開いた状態で入力エラーを見せる。表示順の重複が業務上の制約となる。

削除

削除対象のデッキタグが無いときはページが見つからない扱い（404）とする。当該デッキタグに紐づくデッキが1件以上あるときは削除しない。アーキタイプ初期値側の関連が1件以上あるときも削除しない。いずれも0件のときだけ削除する。削除の可否にかかわらずデッキタグ一覧へ戻る。

本機能に税額・価格のような計算は無い。CSVは出力しない。

入出力

種類内容
入力一覧のページ指定と並び替え指定、登録・更新の名称2種と表示順、削除対象のデッキタグID
成功時出力一覧画面のHTML、または完了メッセージを伴う一覧への戻り
失敗時出力入力不備は同一画面の再表示でエラーを見せる。使用中の削除はエラーメッセージを伴う一覧への戻り

入出力: 永続化

操作契機
追加識別子を伴わない登録・更新の送信が検証に通ったとき
更新識別子を伴う登録・更新の送信が検証に通ったとき
削除関連するデッキとアーキタイプ初期値がいずれも0件のデッキタグを削除したとき
