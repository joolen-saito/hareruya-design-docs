M12-08（フォーマット売上分析 CSVダウンロード）

概要

フォーマット売上分析のCSVダウンロードは、CSVダウンロードの送信に含まれる集計月でフォーマット（売上分析タグ）ごとの日別売上を集計し直し、画面の日別の売上表と同じ集計結果をCSVとしてストリーミング出力する機能である。

本書は実装手順ではなく、誰が・いつ・どの条件で・結果どうなるかを読むためのリバース詳細設計とする。確認値はpf-eccube3（EC-CUBE3系）のHareruyaEcプラグインのフォーマット売上分析のエクスポート処理、売上分析タグ集計用リポジトリ、CSV出力サービスを正とする。本機能のカスタマイズ区分はカスタマイズであり、挙動は現行リポpf-eccube3を参照し、DB関連の記述はec-cube-enterpriseを正とする。現行と移行先でテーブル名・列の所在が異なる箇所は「リニューアル移行時の扱い」に集約する。

対象はブラウザ経由の管理画面に限定する。本文ではフレームワークのコントローラ型名やメソッド名を主説明としない。管理画面プレフィックスは環境により変わる（admin_route）。「利用者視点の入口」にHTTPメソッドとサイトルートからのパスパターンを書く。

集計条件・一覧表示はM12-07で扱う。本書はCSV出力の入口・出力列・ファイル形式と、集計条件が一覧と一致することを扱う。

  • CSVのヘッダ行・データ行・ファイル形式

処理フロー

集計結果CSVを出力する（/{admin_route}/analysis/format_sales/export）

  1. 管理画面の認証・権限を通過する。
  2. 検索フォームへ送信値を取り込み、集計月を取得する。
  3. 集計月をもとに、フォーマット（売上分析タグ）ごと、および売上分析タグに紐づかない区分ごとの日別売上を集計する（M12-07と同じ集計）。
  4. CSV出力サービスを開き、BOMを出力する。
  5. 先頭に「日」、続けて各フォーマットの名称、末尾に「合計」を並べたヘッダ行を出力する。
  6. 日別の売上表を日ごとに1行で出力する。日に続けて各フォーマットの売上、末尾に当日の日別合計を出力する。
  7. CSV出力サービスを閉じる。
