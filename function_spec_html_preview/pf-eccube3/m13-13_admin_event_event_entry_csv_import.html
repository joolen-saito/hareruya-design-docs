業務ルール・計算

項目内容
マスタ参照店舗・会場・ルール適用度・公開状態・フォーマットは名称で対応するマスタを引いて設定する。
クレジット支払支払方法列が「あり」のときのみクレジット支払を有効化する。

本機能は金額の丸めや合計計算を行わない。取込件数は成功登録行数を数える。
