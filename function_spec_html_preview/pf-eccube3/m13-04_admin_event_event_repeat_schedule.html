イベント管理 — 繰り返し日程登録

概要

管理画面で、登録済みのイベントに繰り返しの日程をまとめて登録する機能である。期間と曜日等を指定し、該当する日について日程を一括作成する。申込受付を有効にする場合は、イベントに支払い方法が設定されていることを前提とする。

本書は実装手順ではなく、誰が・いつ・どの条件で・結果どうなるかを読むためのリバース詳細設計とする。確認値はpf-eccube3（EC-CUBE3系）のHareruyaEcプラグインの管理画面繰り返し日程処理、繰り返し日程フォーム、イベント・日程を扱うリポジトリ、テンプレート（Schedule/repeatschedule.twig）、エラー文言を正とする。

カスタマイズ区分は現行踏襲であり、挙動の参照リポはpf-eccube3、DB関連の記述はec-cube-enterpriseを正とする。

対象はブラウザ経由の管理画面に限定する。

本文ではフレームワークのコントローラ型名やメソッド名を主説明としない。管理画面プレフィックスは環境により変わる（admin_route）。「利用者視点の入口」にHTTPメソッドとサイトルートからのパスパターンを書く。

本書で扱うこと

  • 登録済みイベントへの繰り返し日程の一括登録
  • 期間・曜日指定に基づく日程の生成
  • 申込受付有効時の支払い方法の前提確認

処理フロー

繰り返し日程を登録する（POST /{admin_route}/event/repeatschedule/{eventId}/create）

  1. 管理画面の認証・権限を通過する。
  2. パスのイベントIDでイベントを取得する。存在しない場合はページが見つからない扱い（404）とする。
  3. 繰り返し日程フォームを検証する。検証に失敗した場合はエラーメッセージを表示して入力画面を再表示する。
  4. 申込受付を有効にする指定で、当該イベントに支払い方法が設定されていない場合は、申込受付不可のエラーメッセージを表示して入力画面を再表示する。
  5. チェックされた曜日を取得し、指定期間内の該当日について日程を一括作成する。
