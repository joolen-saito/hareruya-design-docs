M12-07（フォーマット売上分析 集計一覧表示）

概要

分析・集計メニューのフォーマット売上分析は、管理者が指定した集計月について、売上分析タグ（フォーマット）ごとの日別売上金額を集計し、折れ線グラフと日別の表、フォーマットごとの合計・平均の表で提示する機能である。

本書は実装手順ではなく、誰が・いつ・どの条件で・結果どうなるかを読むためのリバース詳細設計とする。確認値はpf-eccube3（EC-CUBE3系）のHareruyaEcプラグインのフォーマット売上分析処理、売上分析タグ集計用リポジトリ、検索フォーム種別、一覧テンプレートを正とする。本機能のカスタマイズ区分はカスタマイズであり、挙動は現行リポpf-eccube3を参照し、DB関連の記述はec-cube-enterpriseを正とする。現行と移行先でテーブル名・列の所在が異なる箇所は「リニューアル移行時の扱い」に集約する。

対象はブラウザ経由の管理画面に限定する。本文ではフレームワークのコントローラ型名やメソッド名を主説明としない。管理画面プレフィックスは環境により変わる（admin_route）。「利用者視点の入口」にHTTPメソッドとサイトルートからのパスパターンを書く。

CSVダウンロードはM12-08で扱う。本書は集計一覧（グラフ・表）の表示までを扱う。

本書で扱うこと

  • フォーマット売上分析の初期表示と集計月の指定による集計表示
  • フォーマット（売上分析タグ）ごとの日別売上金額の集計の対象データ・結合・除外条件・集計単位・期間
  • 日別合計・フォーマットごとの合計と平均の算出
  • 売上分析タグに紐づかない売上（その他・その他カード）の取り扱い

本書で扱わないこと

以下は本書では仕様確定せず、実装または別機能の設計を正とする。

  • 集計結果のCSVダウンロード（M12-08を正とする）
  • 日次/月次集計、受注/売上分析、入荷通知依頼の各集計（M12-01〜M12-06を正とする）
  • 売上分析タグ（フォーマット）マスタの管理（マスタ管理機能を正とする）
  • 管理画面へのアクセス制御・ログイン・権限設定の詳細

  2. 集計月入力欄を持つ検索フォームを表示する。集計結果は無しとする。

  1. 検索フォームへ送信値を取り込み、集計月を取得する。
  2. 集計月をもとに、売上分析タグごと、および売上分析タグに紐づかない区分ごとの日別売上を集計する。
  3. 売上の無い日を0で補完し、日別の売上表・日別合計・フォーマットごとの合計と平均を算出する。
  4. グラフと表を同一画面に表示する。
