初期表示に載せるカードリスト

順序判定結果
1デッキの識別子が無いときカードリスト欄を空にして表示する
2識別子に一致するデッキが無いとき未ログイン、またはプレイヤーを持たない会員では、カードリスト欄を空にして表示する。プレイヤーを持つ会員では応答を返せない
3表示区分が非公開、またはデッキリストが非公開のとき会員のプレイヤーがそのデッキのプレイヤーと一致するときだけカードリストを載せる。一致しないときと未ログインのときは空にする
4表示区分が限定公開で、限定公開用の値が一致しないときカードリスト欄を空にして表示する
5上のいずれにも当たらないとき英語カード名のデッキリストをカードリスト欄に載せる

購入条件の指定

画面上の項目画面上の項目（英語）初期値選択肢と絞り込み
言語Language日本語のみ日本語のみ（Japanese）・英語のみ（English）・日・英のみ（Japanese or English）は該当言語の商品規格だけを対象とする。指定しない（他言語を含む）（Not specified (including other languages)）は言語で絞り込まない
状態ConditionNMNMはNMだけ、NM・SPはこの2つ、NM・SP・MPはこの3つだけを対象とする。NM・SP・MP・HPは状態で絞り込まない

優先条件Preferences安いカード優先安いカード優先（Prior to Cheapest Card）は販売価格の昇順、高いカード優先（Prior to Expensive Card）は販売価格の降順

言語で日・英のみ、または指定しない（他言語を含む）を選んだときに日本語優先と英語優先が優先条件に加わり、日本語のみ・英語のみに戻すと除かれる。通常/Foilで指定しないを選んだときに通常カード優先とFoilカード優先が加わる。

条件扱い
商品削除されておらず、公開中の商品だけを対象とする
商品規格削除されておらず、販売価格が0より大きいものだけを対象とする
カード名入力されたカード名が、カードの日本語名または英語名に一致するものだけを対象とする

並び順在庫が0のものを後ろへ回し、次に優先条件、最後にカードセットの発売日の降順

数量の割り当て

ケース扱い
該当する商品規格がすべて在庫0のとき並び順の先頭の商品規格に希望枚数をそのまま割り当てる
在庫のある商品規格があるとき在庫0のものを除き、並び順に沿って在庫数の範囲で割り当てる
割り当て済みの枚数が希望枚数に達したときそれ以降の商品規格には割り当てない
最後の商品規格まで達したとき希望枚数との差分を割り当てる

同じカード名が複数行に現れるときは、枚数を合計して1件の希望として扱う。カード名に // を含む分割カードだけは合算されず、後の行の枚数で置き換わる。

カードリストの書式

行の内容扱い
枚数 カード名枚数と名称に切り分ける
枚数 カード名 (セット略号) 収録番号枚数と名称に切り分ける
Sideboard・サイドボード・Deck・デッキ区切りとして読み飛ばす
空行読み飛ばす
相棒・Companionその行と次の1行を読み飛ばす
読み飛ばす行だけを入力したとき解析結果が0件になる。未記載の判定へは戻らず、空の条件のまま商品と在庫の判定へ進む。この経路のふるまいは正本コードからは確認できない
上のいずれにも当たらない行書式の誤りとして行番号と入力内容を示す
カード名の // /へ置き換えて突き合わせる

空行も1行として数え、行番号にも行数にも含める。行数は500行までとし、これを超えるときは書式の判定を行わない。

判定の順序

順序判定結果
1カードリストが空のとき未記載として通知し、以降を判定しない
2書式に合わない行がある書式の誤りとして通知し、以降を判定しない
3商品が見つからないカードがある商品なしとして通知し、以降を判定しない
4指定した条件で在庫を引けないカードがある在庫不足として通知し、割り当て結果を返さない
5上のいずれにも当たらない商品規格と数量の組を返す

判定はいずれもHTTP 200で応答し、処理結果が成功か失敗かで区別する。本機能が返すのは商品規格と数量の組までとする。カートへの追加は買い物かご（F04-01）が受け持ち、画面は組を引き渡したのち買い物かごへ移る。

エッジケース

ケース扱い
同じカード名が複数行にあるとき枚数を合計して1件の希望とする
同じ分割カードが複数行にあるとき合算されず、後の行の枚数で置き換わる
空行を含めた行数が500行を超えるとき行ごとの判定を行わず、行数の誤りだけを示す
相棒の行があるときその行と直後の1行を読み飛ばす
カード名に///を含むとき送信の直前に//へ置き換える
希望枚数が在庫の合計を超えるとき最後の商品規格に不足分を含めた枚数を割り当てる
商品が見つからない行があるとき在庫の判定へ進まない
購入条件を変えずに再送したとき送信せず、内容が変わっていないことを画面で知らせる
言語・状態・通常/Foilが未指定または選択肢に無い値のときその条件では絞り込まない
優先条件が未指定または選択肢に無い値のとき安いカード優先として扱う

誤りの示し方

観点扱い
並び先頭に総括の文言を置き、続けて誤りのある行を並べる
書式の誤りの行番号入力の1行目を1として、空行も数えた位置を示す
商品なしの行番号カード名を重複排除した並びの位置を示すため、読み飛ばした行や重複した行があるときは入力の行番号とずれる
在庫不足の行番号商品なしと同じ数え方をする
誤りが複数の種類にまたがるとき先に判定した種類の誤りだけを示す

入出力

種類内容
入力カードリストのテキスト、言語・状態・通常/Foil・優先条件の指定
成功時出力HTTP 200。処理結果が成功であることと、商品規格の識別子と数量の組の一覧
失敗時出力HTTP 200。処理結果が失敗であることと、先頭に総括の文言を置いた誤りの一覧

入出力: 永続化

デッキ情報を登録・更新・削除しない。商品と在庫も更新しない。カートへの追加は買い物かご（F04-01）が受け持つ。
