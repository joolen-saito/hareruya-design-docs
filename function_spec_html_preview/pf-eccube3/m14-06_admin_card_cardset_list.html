カード管理 — カードセット一覧

業務ロジック

一覧の対象

カードセットマスタの全件を対象とする。絞り込みの条件は持たない。

一覧を開いたときの表示条件

ページ番号を指定せずに一覧を開き、かつ再開の指定が無いときは、保持していたページ番号・表示件数・並び順を破棄する。再開の指定があるときは破棄しない。

保持している表示件数・並び順があるときは、それを用いて表示する。

指定された表示件数は、数値であり、かつ表示件数マスタの名称のいずれかと文字列で一致するときだけ採用し、以後保持する。一致しない値は無視する。指定された並び順も、選択肢のいずれかと完全に一致するときだけ採用し、以後保持する。

表示件数または並び順を選び直したときは、表示中のページ番号によらず1ページ目から表示し直す。

並び順はいずれも単一の項目による。

削除の可否

収録カードを持つカードセットは削除できない。削除を行わず、エラーメッセージを出して元の画面へ戻る。

削除できたときは、保持していたページ番号の一覧へ戻る。

エラー時の扱い

エラー内容処理
表示件数・並び順の指定が選択肢と一致しない無視し、直前まで採用していた値のまま一覧を表示する。専用のエラーは出さない
画像ダウンロードの対象に収録カードが1件も無い、またはZIPファイルを作れないエラーメッセージを出し、保持していたページ番号の一覧へ戻る

入出力

種類内容
入力再開の指定。指定があるときは、保持していた表示条件を引き継いで一覧を開く
成功時出力画像ダウンロードはZIPファイルを1つ返す
失敗時出力一覧の表示に専用の検証エラー画面は無い。画像ダウンロードと削除の失敗は、エラーメッセージと一覧への遷移で返す
