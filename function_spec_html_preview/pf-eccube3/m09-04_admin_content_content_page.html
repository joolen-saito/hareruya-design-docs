コンテンツ管理 — ページ管理

業務ロジック

一覧の対象

PC端末種別のページをID昇順で表示する。IDが 0 のページは一覧から除く。

検索語絞り込み
入力があるときページ名・ルーティング名・URL・ファイル名・レイアウト名のいずれかへの部分一致
入力が無いとき端末種別の条件だけで一覧を取得する

新規作成の初期表示

新規のページは、端末種別をPC、編集可否区分を利用者作成として生成する。

テンプレート本文欄の初期値条件
設定ファイル群から見つかった既定テンプレートの内容既定テンプレートが見つかったとき
空文字既定テンプレートが見つからないとき

編集の初期表示

ページIDに該当するページが無いときは、見つからない扱い（HTTP404）とする。テンプレート本文欄には、データ種別に応じた読込先のファイル内容を初期表示する。

データ種別読込先の探索順本文欄の編集
初期投入データアプリのテンプレート、プラグイン既定、コア既定の順に探すできない
利用者作成データユーザーデータ領域から探すできる

保存の判定順序

順序判定・処理内容
1入力内容の検証通らないときは保存せず、同一フォームを再描画する
2ページ情報の更新編集で編集可否区分が初期投入データのときは、URLとファイル名を更新前の値で保持し、ページ名の更新だけを許す
3ページ情報の保存検証を通ったときだけ保存する
4テンプレート本文の書き出し新規は、初期投入データのときアプリのテンプレート領域、利用者作成データのときユーザーデータ領域へ書き出す。編集は、初期投入データでないときだけ書き出す
5旧ファイルの削除編集でファイル名が変わり、かつ旧ファイルが存在するときだけ削除する
6キャッシュの破棄保存のたびに破棄する

保存を終えたときは、登録したページの編集画面へ戻る。

URLの一意性

同一端末種別でURLが重複するときは検証エラーとする。重複の判定では、新規はIDを除外せず、編集は自身のIDだけを除外する。

削除

削除の対象は利用者作成ページとする。削除しようとしたページが既に存在しないときは、削除対象なしのメッセージを表示して一覧へ戻る。

エラー時の扱い

事象扱い
入力内容の検証に外れたとき保存せず、同一フォームを再描画し、該当項目にエラーを表示する
URLが重複したときURL欄に重複のエラーを付ける
編集で対象ページが無いとき見つからない扱い（HTTP404）とする
削除で対象ページが無いとき削除対象なしのメッセージを表示して一覧へ戻る

入出力

種類内容
入力一覧・フォームの表示要求。新規・編集はページ属性とテンプレート本文。削除はページID。
成功時出力新規・編集のときは編集画面への遷移（302）と登録完了メッセージ。削除のときは一覧への遷移（302）と削除完了メッセージ。
失敗時出力検証に外れたときは同一フォームの再描画。対象ページが無いときは見つからない扱い（HTTP404）、または削除対象なしのメッセージ。

入出力: 永続化

操作契機
追加ページを新規登録したとき
更新ページを編集して保存したとき
削除利用者作成ページを削除したとき
