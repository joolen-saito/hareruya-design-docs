F06-07（購入履歴詳細）

業務ロジック

表示できる条件

順序判定結果
1会員ログイン済みか未ログインなら会員ログインへ誘導する
2注文IDがあるか無いなら見つからない（HTTP404）
3注文IDで注文を取得できるか取得できないなら見つからない（HTTP404）
4注文の会員がログイン会員と一致するか不一致なら見つからない（HTTP404）
5上記を通過購入履歴詳細を表示する

注文の存在有無と所有者不一致は、いずれも見つからない（HTTP404）として扱い、画面上で理由を区別しない。表示できるのはログイン会員自身の注文だけである。

表示する内容

見出し「購入履歴詳細」、注文番号、領収書発行リンク、注文日、出荷日、金額内訳、送り主、支払方法、配送方法、支払方法に応じた決済情報、お届け先、注文明細、再購入の操作を表示する。金額内訳・決済情報・お届け先は区分して表示する。本画面専用のモーダルは無い。

区分表示する項目
金額内訳商品金額合計、送料、手数料、ポイント使用（値引き）、注文金額合計（税込み）、ポイント発生
決済情報支払い先コンビニ、お客様番号、確認番号、第1番号、第2番号、オンライン決済番号、払込票番号など。支払方法に応じて表示項目が変わる
注文明細注文明細と注文明細拡張

使用ポイントと発生ポイントは注文サブの保持値を表示し、0のときは0ポイントと表示する。

値の取り方

金額の再集計は行わない。注文と注文サブの保持値、および税計算の結果を表示する。税額は、商品金額合計・送料・手数料の合計から割引を引いた額に対して計算する。

言語別表示

言語が英語のときは、コンビニの一覧を英語表記で表示する。

再購入

再購入は、購入履歴一覧と共通の入口で注文IDを受け取り、当該注文の商品と数量をカート投入用として返す。取得は非同期で行う。

他機能との境界

利用者が入力するフォームを持たない。注文IDはURLで受け取る。未ログイン時の誘導先の挙動は会員ログイン機能を正とする。

エラー時の扱い

エラー内容処理
未ログインでのアクセス会員ログインへ誘導する
注文IDが無い見つからない（HTTP404）として扱う
注文を取得できない・所有者が一致しない見つからない（HTTP404）として扱う。理由は画面上で区別しない

入出力

種類内容
入力会員ログイン状態、注文ID
成功時出力購入履歴詳細の表示
失敗時出力未ログイン時は会員ログインへの誘導、それ以外は見つからない（HTTP404）
