業務ロジック

編集の対象

既定のヘルプ情報1件を読み込み、その内容を編集する。数値の業務計算は行わない。入力の検証と保存に限定する。

保存の判定順序

順序判定結果
1なりすまし対策の検証と送信の妥当性不正なら送信として扱わない、またはエラーとする
2各項目の入力検証いずれかが失敗したときは保存せず、同一画面を再表示して項目のエラーを表示する
3電話番号・FAX番号の3分割入力FAXは必須ではないため全欄が空でもよい。一部の欄だけを入力したときはエラーとする
4上記を通過ヘルプ情報を保存し、更新日時を現在日時にする

保存後は同一の編集画面へ戻る。検証に失敗したときは保存せず、完了のメッセージも表示しない。

エラー時の扱い

エラー内容処理
入力検証の失敗該当項目にエラーを表示し、保存しない
なりすまし対策の検証の失敗共通の既定動作に従う

入出力

種類内容
入力ヘルプ情報の各入力項目と、なりすまし対策の検証値
成功時出力同一の編集画面へ戻り、完了のメッセージを表示する
失敗時出力同一画面を再表示し、項目のエラーを表示する

入出力: 永続化

操作契機
更新検証を通過した保存。あわせて更新日時を現在日時にする

リニューアル後の仕様

表示メッセージ

メッセージID表示位置画面上の文言表示条件後続処理
—管理画面上部登録完了のメッセージ（文言は共通実装を正とする）検証を通過して保存したとき同一の編集画面へ戻る
—入力項目直下入力検証のメッセージ（文言は共通実装を正とする）入力検証に失敗したとき保存せず同一画面に留まる
