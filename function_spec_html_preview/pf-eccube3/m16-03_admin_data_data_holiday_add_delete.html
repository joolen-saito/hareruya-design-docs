データ管理 — 祝日の追加・削除

業務ロジック

一覧の表示

祝日マスタを日付の昇順で全件表示する。日付は年/月/日の形式で表示する。

手入力での追加の判定順序

名称は64文字まで受け付ける。

順序判定・処理内容
1操作の有効期限不正なときは追加せず、アクセス拒否（HTTP403）とする
2入力内容の検証外れたときは追加せず、エラーメッセージを表示して一覧へ戻す。項目ごとのエラー表示は行わない
3日付の重複送信された日付と同じ日付の祝日が1件でもあるときは追加せず、重複のメッセージを表示して一覧へ戻す
4追加重複が無いときだけ、日付と名称を設定して祝日を追加する
5イベント詳細への反映追加した日と同じ日に開始するイベント詳細すべてについて、祝日フラグをオンにする
6遷移一覧へ戻す

一括登録

入力扱い
開始日が終了日より後のとき登録せず、期間の指定を促すメッセージを表示する
開始日と終了日の逆転以外の入力不備があるとき登録せず、登録できなかった旨を表示する
期間内に既に登録済みの祝日が含まれるとき当該日付をスキップし、残りの登録を続ける
新たに登録できる祝日が1件以上あるとき登録し、登録した件数を表示する
新たに登録できる祝日が無いとき登録可能な祝日が無かった旨を表示する

削除の判定順序

順序判定・処理内容
1操作の有効期限不正なときは削除せず、アクセス拒否（HTTP403）とする
2対象の特定指定されたIDの祝日を取得する。該当が無いときはエラー応答とする
3削除当該の祝日を削除する
4イベント詳細への反映削除した日付に開始するイベント詳細を取得し、各件の祝日フラグをオフにする
5遷移一覧へ戻す

エラー時の扱い

事象扱い
手入力の追加で入力内容の検証に外れたとき追加せず、エラーメッセージを表示して一覧へ戻す
手入力の追加で日付が重複したとき追加せず、重複のメッセージを表示して一覧へ戻す
操作の有効期限が不正なときアクセス拒否（HTTP403）とする
削除の対象が無いときエラー応答とする

入出力

種類内容
成功時出力一覧画面への遷移と、登録完了・削除完了のメッセージ。
失敗時出力一覧画面への遷移とエラーメッセージ、またはアクセス拒否（HTTP403）。

入出力: 永続化

操作契機
追加手入力の追加で重複が無かったとき。一括登録で登録できる日付があったとき
更新祝日を追加したとき、対象のイベント詳細の祝日フラグをオンにする。対象の範囲は判定順序のとおり
更新祝日を削除したとき、対象のイベント詳細の祝日フラグをオフにする。対象の範囲は判定順序のとおり
削除一覧から祝日を削除したとき
