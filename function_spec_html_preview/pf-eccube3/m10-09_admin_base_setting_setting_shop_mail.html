店舗基本設定のメールアドレス設定（pf-eccube3）

業務ロジック

編集の対象

店舗基本情報のメールアドレス4項目を編集する。ほかの入力項目は店舗基本設定の入力全体に含まれる。

入力の検証

メールアドレス4項目は、いずれも未入力でないこと、かつ厳密なメール形式であることを要する。1項目でも満たさないときは全体を無効とし、保存しない。メールアドレスが妥当でも、店舗名など他の必須項目が欠けるときは保存しない。

保存

検証を通過したときに店舗基本情報を保存し、完了のメッセージを表示して店舗基本設定の画面へ戻る。戻った後の表示には保存後の値が出る。

検証に失敗したときは同一画面を再表示して項目ごとのエラーを表示し、完了のメッセージは表示しない。

表示値の取り方

画面表示に用いる店舗基本情報は、要求の冒頭で取得した内容の複製である。保存対象とは別に保持するため、検証に失敗したときは、入力途中の値やエラー表示と、画面のほかの箇所に出る文言が一致しないことがある。

店舗基本情報の取得結果は保持され、保持期間は環境の設定による。保存時は、設定で保持内容の全削除が有効なときに保持内容をすべて削除し、無効なときは削除しない。

エラー時の扱い

発生条件利用者に見える結果保存
なりすまし対策の検証に失敗管理画面の共通のエラー表示による行わない
メールアドレスのいずれかが未入力当該項目に未入力のエラー行わない
メールアドレスの形式が不正当該項目にメール形式のエラー行わない
メールアドレスは妥当だが店舗名など他の必須項目が欠けるメールアドレス以外の項目にエラー行わない

入出力

種類内容
入力メールアドレス4項目と、なりすまし対策の検証値
成功時出力完了のメッセージを表示し、店舗基本設定の画面へ戻る
失敗時出力同一画面を再表示し、項目ごとのエラーを表示する

入出力: 永続化

操作契機
更新検証を通過した保存で、店舗基本情報のメールアドレス4項目を上書きする
