pf-eccube3 — デッキ管理 — アーキタイプ検索条件

概要

HareruyaEc プラグインの管理画面「デッキ一覧」検索フォームにおいて、アーキタイプマスタを複数選択して dtb_deck を絞り込む条件と、フォーマット・色チェックボックスとの連動表示（クライアント側）を取りまとめたものである。検索結果一覧・ページ送り・ソート・セッション保持はデッキ検索全体の処理に属するが、本書はアーキタイプ条件とその周辺の実装確認値に焦点を当てる。

本書は実装手順ではなく、誰が・いつ・どの条件で・結果どうなるかを読むためのリバース詳細設計とする。本機能のカスタマイズ区分はカスタマイズであり、挙動は現行リポ pf-eccube3 に配置された HareruyaEc プラグイン実装を確認値とし、DB関連は ec-cube-enterprise を正とする。

対象はブラウザ経由の管理画面に限定する。コントローラのメソッド名は本文の主説明としない。本文ではルートbind名やSymfonyのルートnameの網羅は主説明としない。「利用者視点の入口」にHTTPメソッドとサイトルートからのパスパターンを書く。コード探索でbind名が必要なときだけ「調査補助」へ書く。

リニューアル移行時の扱い

デッキ・アーキタイプの各テーブルは移行先（ec-cube-enterprise）でもコア標準のエンティティとして取り込まれている。検索条件が参照する DB 列名は移行先を正とする。

検索フォームのアーキタイプ複数選択・色連動・セッション保持・ページ送りなどの挙動面は現行 pf-eccube3 実装を正とする。検索ビューデータのセッションキー名は実装上の確認値であり、移行後の互換は ec-cube-enterprise 実装で要確認とする。

処理フロー

アーキタイプを含む条件で検索する（POST m15-01_admin_deck_deck_search、page_no は 1）

  1. 管理画面の認証・共通制約を通過する。
  2. デッキ用レポジトリ参照がトレイトによりセットされる。
  3. フォーム admin_search_deck がリクエストを取り込む。CSRF はこのフォーム型では無効である。
  4. ソートキー・昇降順・ページマスタ・表示件数がセッションとクエリから決まる。昇降順が ASC/DESC（大小無視）以外ならエラーを積み、admin_deck_list と同等の初期化へ遷移する。
  5. 検索データがこのリクエストで得られない場合はセッション admin.deck.search のビューデータから復元する。
  6. レポジトリが検索データでクエリビルダを組み立てる。archetypes が空でなければ d.archetype が選択エンティティ集合に含まれる行だけを残す。
  7. 件数カウントと一覧ページネーションが実行され、セッションに admin.deck.search、admin.deck.search.page_no、admin.deck.sort、admin.deck.order、admin.deck.search.page_count が保存される。

フォーマットまたは色を変更した直後（ブラウザ内）

  1. deck-search.js の archetypeFilter が非同期タイマーで実行される。
  2. アーキタイプの選択肢のうち、現在のフォーマット選択と色チェックに合致しないものは選択できない状態（disabled）になる。フォーマット未選択時は「すべてのフォーマットオプション」を対象にクラス選択子を組む。
  3. 既に選択済みのアーキタイプがこの操作で disabled のまま残る場合でも、ブラウザが無効オプションを送信しないため、送信値から漏れる可能性がある。サーバー側は送信された ID のみで IN 検索する。

業務ルール・計算

項目内容
選択肢ラベル各アーキタイプは「日本語名とフォーマット日本語名を組み合わせた文字列」（エンティティの getNameWithFormatNameJp）として表示される。
選択肢のデータ源アーキタイプ一覧は Doctrine のクエリビルダで、アーキタイプと色を join して取得する。グローバルなソフト削除フィルタが有効なら、削除済みアーキタイプは一覧に現れない想定である。
フォーマットとの関係（サーバー）フォーマット複数選択は dtb_deck.format に対する IN である。アーキタイプ IN とは独立して適用される。矛盾する組み合わせは 0 件になる。
色との関係（サーバー）色条件があるときデッキのアーキタイプへ結合し、アーキタイプが持つ色のいずれかが選択色に含まれることを要求する。アーキタイプ IN と同時指定時は両方を満たす必要がある。

本機能では金額計算やランキング算出は行わない。
