店舗基本設定 — 配送料無料条件（閾値）

処理フロー

画面初期表示（GET、またはPOST検証後の親フローの一部）

  1. 管理画面の認証・IP制限・権限の各チェックを通過する。
  2. リポジトリから店舗基本情報を取得する。
  3. 店舗マスタフォームビルダを当該エンティティに対して生成する。
  4. 初期化イベントがディスパッチされ、プラグイン等がフィールド構成を変更し得る。
  5. フォームを組み立て、GETの場合は未送信状態でテンプレートを描画する。Twigには編集開始時点の店舗基本情報の複製がグローバルにも載せられる（親画面仕様）。
  6. 「送料設定」ブロックに当2項目が出力される。

「登録」押下後（POST、検証成功）

  1. フォーム送信が処理され、delivery_free_amount・delivery_free_quantity を含む全フィールドが実体へマップされる。
  2. 検証成功時、flush で永続化する。
  3. 完了イベントがディスパッチされる。
  4. 成功フラッシュを積み、同一店舗基本設定へのリダイレクト応答を返す。

「登録」押下後（POST、検証失敗）

  1. 当2項目または他項目にエラーがあると、同一テンプレートを再描画する。
  2. Twigグローバルの店舗基本情報の複製はリクエスト冒頭で切り離したスナップショットのままである。検証失敗中、フォーム入力値やエラーと、ヘッダ等グローバル表示の閾値表示が一致しない場合がある（親画面と同様の確認値）。
  3. 成功フラッシュは積まず、保存も行わない。

業務ルール・計算

入力項目

送料無料条件(金額)任意Length で最大 price_len（コア constant.yml.dist の確認値は 8）。Regex で1文字以上から成る場合は非負整数の桁列のみ（パターンは実装値の \d+）。money 型により金額変換経路がある。環境で price_len を上書きしている場合はその桁を正とする。DB現行値dtb_base_info.delivery_free_amount。Doctrine上は小数スケール0・nullable。

管理フォームに限定した入力である。price_len 等はコアの src/Eccube/Resource/config/constant.yml.dist の既定を確認値とする。環境により上書きされている場合はその値を正とする。

未入力やクリア後のサーバ側での null 化の詳細は、送信値とフォームデータ変換の結果を確認値とする。Doctrineマッピング上、両列は nullable: true で既定 null である。

購入フロー上の無料化（コアの購入処理サービス）

以下はコード上の順序どおりであり、利用者への文言で「優先順位」を約束しているわけではない。

  1. 通常送料の合計をお届け先ごとの地域・配送業者別送料（と、商品単位配送料オプションが有効ならその加算分）から求め、受注の配送料合計にセットする。
  2. setDeliveryFreeAmount を実行する。delivery_free_amount が null でない場合に限り、Order->getSubTotal()（受注明細ごとの税込単価×数量の合計）が閾値以上なら、受注の配送料合計を0とし、全お届け先の実行時配送料フィールドも0にする。未満の場合、このメソッド内では配送料を戻したり再上書きしたりしない（この時点の合計値が維持される）。
  3. set_delivery_free_quantity を実行する。delivery_free_quantity が null でない場合に限り、order_service->getTotalQuantity(Order)（明細点数の合計）が閾値以上なら、同様に受注の配送料合計と各お届け先を0にする。
  4. したがって、金額条件と数量条件の両方の列が非NULLで、どちらか一方でも閾値を満たせばコアでは送料無料側に寄せられる（両方とも満たさなければ、手順1で求めた送料が残る）。

小数・0の注意: delivery_free_amount が数値として0に近いまたは0である場合でも null でなければ「小計≥0」を満たしやすく、結果としてほぼ常に無料化し得る。数量閾値が0でも同様に、「合計点数≥0」となり無料化し得る。このような運用上の意味は本書では業務規定しない。

カート画面の無料可否表示（コア CartController）

  • カートの合計金額は Cart->getTotalPrice()（明細ごとのカート単価×数量）。
  • 閾値の有無はPHPの真偽で判定しており、getDeliveryFreeAmount() および getDeliveryFreeQuantity() が truthy のときだけ金額・数量の未到達メッセージや「現在送料無料」の旗を立てる。
  • Twigテンプレートでも BaseInfo.delivery_free_amount および _quantity を真偽として解釈し、両方がtruthyのときは「あと〇円またはあと△個」の併記、片方のみなら単独メッセージに分岐する。

デフォルトフロントのテキストブロック（確認値）

サイドなどに差し込まれる文言ブロックでは、金額閾値が truthy のときのみ「〇〇円以上の購入で配送料無料」と出し、そうでない場合は便宜的に「0円以上の購入で配送料無料」固定文となる実装がある。閾値未設定運用での利用者への意味はテンプレート実装とブロック設置を正とする。
