F05-05（ネット買取カート）

概要

ネット買取で買取を希望する商品をカートに保持し、カート内商品の一覧・数量変更・削除・合計買取価格の表示を行う機能である。買取商品一覧・詳細の「カートに追加」から非同期で商品クラス単位に追加し、買取希望品カート画面で数量を再計算して買取手続きへ進む。買取カートはセッションに保持し、商品の追加・更新・削除・合計算出を通じて整える。

本書は実装手順ではなく、誰が・いつ・どの条件で・結果どうなるかを読むためのリバース詳細設計とする。確認値はpf-eccube3（EC-CUBE3系）のHareruyaEcプラグインの買取カート処理（表示・追加・削除・更新・合計算出）、カートテンプレート（Purchase/cart.twig）、買取共通JS（Block/js/purchase_js.twig）、ロケールメッセージ（message.ja.yml）を正とする。

カスタマイズ区分はカスタマイズとする。挙動の参照リポはpf-eccube3（現行）とし、DB関連（テーブル名・列名・型・制約・関連、DBカラム節、保存先・扱い、データ整合性のDB部分）は ec-cube-enterprise を正とする。買取カート自体はセッション保持でDB列を持たない。

対象はブラウザ経由のフロント（ネット買取）に限定する。フロントのルートはロケールプレフィックス/{_locale}配下にマウントされ、買取機能は/purchase配下にマウントされる。

本文ではフレームワークのコントローラ型名やメソッド名を主説明としない。本文ではルートbind名の網羅は主説明とせず、「利用者視点の入口」にHTTPメソッドとサイトルートからのパスパターンを書く。コード探索でbind名が必要なときだけ「調査補助」へ書く。

本書で扱うこと

  • 買取希望品カートの入口と表示内容
  • カートへの追加（非同期）・削除・数量更新・合計再計算
  • 同一商品の数量上限と上限超過時の扱い
  • 「まとめて買取」がカートに含まれる場合の案内
  • 買取カートのセッション保持

本書で扱わないこと

以下は本書では仕様確定せず、実装または別機能の設計を正とする。

  • 買取手続き（口座情報入力・確認）から完了まで（F05-06ネット買取買取手続き〜完了を正とする）
  • 買取商品検索・一覧・詳細（F05-02／F05-03／F05-04を正とする）
  • 買取価格の登録・算出（商品データ管理を正とする）

リニューアル移行時の扱い

現行（pf-eccube3）と移行先（ec-cube-enterprise）のDBスキーマ差分を記録する。カート操作はセッション上で行いDB列を持たないため、参照する商品データの保持先のみ差分となる。挙動は現行の確認値を正とし、永続化先の名称は移行先（ec-cube-enterprise）を正とする。

処理フロー

買取希望品カートを表示する（GET /{_locale}/purchase/cart）

  1. セッションから買取カートを取得する。カートが無い場合は商品なし・合計なしのカート画面を表示する。
  2. カート内の商品クラスIDから対象の商品サブクラスを取得する。
  3. 「まとめて買取」の商品がカートに含まれるか判定する。
  4. 合計買取価格を算出する。算出時にカートへ残らない商品（対象データが無い商品）は除く。
  5. カート内商品・合計・まとめて買取の有無とともにカート画面を表示する。

カートに追加する（POST /{_locale}/purchase/add）

  1. 商品クラスIDと数量（既定1）を受け取る。商品クラスIDが空ならエラー応答（HTTP500相当）を返す。
  2. 既に同一商品がカートにある場合は数量を加算する。
  3. 加算後の数量が同一商品の上限（20点）を超える場合は、上限超過のJSON（メッセージ付き、状態overlimit、HTTP400）を返す。
  4. 上限以内なら商品クラスごとに数量をセッションへ保存する。

カート内商品を削除する（PUT /{_locale}/purchase/{id}/remove）

  1. なりすまし対策トークンを検証する。
  2. セッションのカートに当該商品が無い場合はカート表示へ戻す。
  3. 当該商品をカートから外し、カート表示へ戻す。

数量を更新する（POST /{_locale}/purchase/update）

  1. 入力された数量一覧で各商品の数量を更新する。
  2. 数量が数字でない・1未満の商品はカートから外す。
  3. いずれかの数量が上限（20点）を超える場合は上限超過のメッセージを要求エラーに積み、更新を中断する。
  4. 更新後、カート表示へ戻す。
