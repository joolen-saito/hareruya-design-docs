書き出しの2経路

デッキリストの書き出しには、ファイルとして受け取る経路と、画面が写し取るためのテキストを受け取る経路がある。

経路受け取り方応答の形式
Magic Online用テキストファイルとして受け取る添付ファイルのtext/plain
アリーナ形式のテキスト画面が受け取り、クリップボードへ写すJSON
公開状態の判定ファイル経路だけが表示区分とデッキリストの公開状態を見る—
デッキ種別の判定どちらの経路も、ユーザーデッキのときは応じない—

ファイルとして受け取る経路の条件

順序判定結果
1デッキの識別子が空のときHTTP 404
2識別子に一致するデッキが無いときHTTP 404
3表示区分が非公開のときHTTP 404
4デッキリストが非公開のときHTTP 404
5デッキ種別がユーザーデッキのときHTTP 404
6上のいずれにも当たらないときデッキリストのファイルを返す

限定公開のデッキは、限定公開用の値の一致を求めずに書き出せる。

ファイルの名称と内容

ファイル名はアーキタイプの英語名の空白文字を_へ置き換え、.txtを付けた文字列とする。内容は英語カード名の枚数 カード名を1行ずつ並べたもので、サイドボードの前にSideboardの行を挟む。統率者とメインボードの見出し行は入れない。カード名はアリーナで通る名称への対応表で置き換え、対応表に無い名称はそのまま残す。

テキストとして受け取る経路の条件

順序判定結果
1デッキの識別子が空のときHTTP 404。本文はJSONで、処理結果は失敗、内容はNot Found
2識別子に一致するデッキが無いときHTTP 404。本文は同上
3デッキ種別がユーザーデッキのときHTTP 404。本文は同上
4上のいずれにも当たらないときHTTP 200。処理結果は成功、デッキリストのテキストを返す

この経路は表示区分とデッキリストの公開状態を判定しないため、非公開のデッキでも識別子を指定すればテキストを受け取れる。

言語の指定による内容の違い

言語の指定カード名見出し行
en英語名をアリーナで通る名称へ置き換えた値統率者があるときはCommander、続けてDeck、サイドボードの前にSideboard
en以外日本語名統率者があるときは統率者、続けてデッキ、サイドボードの前にサイドボード

どちらの言語でも、カード名に含まれる/は // へ置き換える。デッキリスト詳細からの入口は、アリーナ用インポートテキストがen、日本語テキストがjpを言語として渡す。言語の指定が無いときのふるまいは正本コードからは確認できない。

デッキリストの組み立て

観点扱い
行の形枚数 カード名を1行とする
区画の順序統率者、メインボード、サイドボードの順に並べる。この3つ以外の配置は書き出さない
区画の区切りサイドボードがあるときだけ、その前に空行と見出し行を挟む
改行復帰と改行の2文字を用いる
末尾末尾の空白と改行を落とす
デッキリストがキャッシュにあるときキャッシュの内容から指定の言語で組み立てる
デッキリストがキャッシュに無いとき採用カードから組み立てる

エッジケース

ケース扱い
アーキタイプの英語名に空白を含むとき空白を_へ置き換えたファイル名にする
対応表に無いカード名のとき置き換えずに元の名称のまま書き出す
サイドボードが0枚のときサイドボードの見出し行を入れない
統率者が0枚のとき統率者の見出し行を入れない
分割カードのとき名称の/を // へ置き換える
デッキリストが非公開のときファイル経路はHTTP 404、テキスト経路は書き出しに応じる
表示区分が限定公開のとき限定公開用の値の一致を求めずに書き出す
採用カードが0件のとき中身のないテキストを返す
メインボード・サイドボード・統率者以外の配置にカードがあるとき書き出しに含めない
アーキタイプが未設定のときファイル名の組み立てに使う値が無く、ふるまいは正本コードからは確認できない
言語の指定がen以外のとき対応表による置き換えを行わない
会員でないときどちらの経路も同じ結果を返す

入出力

種類内容
入力デッキの識別子。テキストとして受け取る経路では言語の指定も伴う
成功時出力ファイル経路は添付ファイルとしてのデッキリスト。テキスト経路はJSONで、処理結果が成功であることとデッキリストのテキスト
失敗時出力ファイル経路はHTTP 404の共通のエラー画面。テキスト経路はHTTP 404で、処理結果が失敗であることとNot Found

入出力: 永続化

デッキ情報を登録・更新・削除しない。
