商品管理 — 略称タグ登録/編集

業務ロジック

一覧の並びと表示内容

一覧は略称タグを並び順の昇順で並べる。

一覧の「ソート」列は、アルファベット順ソートフラグが有効なら「アルファベット」、無効なら「コレクター番号」と表示する。

一覧の ID・名称・並び順は、いずれも当該の略称タグを入力欄へ読み込むリンクである。

入力欄の状態

編集の対象を指定したときは、見出しを「略称タグ編集」とし、新規の入力欄へ戻るためのボタンを併せて表示する。対象を指定しないときは新規の入力欄とし、見出しを「略称タグ新規登録」とする。

指定した略称タグが存在しないときは 404 とする。

新規の入力欄では、アルファベット順ソートフラグを外した状態で表示する。

保存の判定順序

順序判定結果
1なりすまし対策トークンが有効か無効のときはアクセス拒否（HTTP 403）とする
2入力の検証を満たすか満たさないときは保存せず、一覧画面へ戻す。入力した値は復元せず、入力欄の直下にもエラーを出さない
3名称が既存の略称タグと重複しないか重複するときは保存せず、一覧画面へ戻す

並び順の重複は妨げない。

保存できたときは、保存した略称タグを入力欄へ読み込んだ状態で一覧画面を再表示する。続けて新規登録するときは、新規の入力欄へ戻るボタンを押す。

削除の判定順序

順序判定結果
1なりすまし対策トークンが有効か無効のときはアクセス拒否（HTTP 403）とする
2指定した略称タグが存在するか存在しないときは 404 とする

削除を実行したときも、削除できずに中止したときも、一覧画面へ戻す。

CSV出力

CSV出力は、確認画面を挟まずに略称タグのCSVファイルをダウンロードさせ、画面は遷移しない。ファイル名は storage_code_ に出力時刻（年月日時分秒）と .csv を付けたものとする。出力する内容は略称タグCSV出力（M03-15）を正とする。

入出力

種類内容
入力一覧・編集は対象の略称タグの指定（指定が無いときは新規）。保存は入力欄一式となりすまし対策トークン。削除は対象の略称タグの指定となりすまし対策トークン
成功時出力保存した略称タグを入力欄へ読み込んだ一覧画面、または削除後の一覧画面。完了メッセージを伴う
失敗時出力入力の検証を満たさないとき・名称が重複したときは一覧画面へ戻し、失敗メッセージを伴う。対象が無いときは 404、なりすまし対策トークンが無効のときは HTTP 403

入出力: 永続化

操作契機
追加・更新入力の検証を満たし、名称が重複せずに保存できたとき
