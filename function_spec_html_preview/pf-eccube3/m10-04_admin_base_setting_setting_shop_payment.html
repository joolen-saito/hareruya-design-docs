店舗設定 — 支払方法管理（支払方法・手数料・利用条件）

業務ロジック

一覧に出す支払方法

削除されていない支払方法を、表示順の降順で並べる。旧・大会専用の支払方法（クレジットカード決済・コンビニ決済）は一覧に出さないため、この画面からは編集も削除もできない。

一覧の操作リンク

操作リンクからは編集・削除・上へ・下へを選べる。固定扱いの支払方法では編集と削除を選べない。先頭行には「上へ」を、末尾行には「下へ」を出さない。

一覧の利用条件の表示

下限が未設定または 0 のときは「0円」と表示する。上限があるときは続けて「〜上限円」を、上限が未設定のときは「〜無制限」を表示する。

編集画面の初期表示

新規登録のときは、すでに登録されている支払方法の最大表示順へ 1 を加えた値を設定する。1件も登録が無いときは表示順を 1 とする。一覧は表示順の降順なので、新規登録した支払方法は一覧の先頭に出る。新規登録した支払方法は編集・削除ができる状態で作り、手数料も入力できる状態にする。手数料を設定できない支払方法では手数料の入力欄を出さない。登録済みのロゴ画像があるときは、その画像をプレビューとして表示する。

入力の制限

項目内容
手数料9桁以内で、負の値は受け付けない。手数料を設定できない支払方法では入力欄を出さず、登録時に 0 として保存する
利用条件下限と上限の2つの欄で入力する。それぞれ9桁以内で、負の値は受け付けない。両方に入力があり、上限が下限より小さいときはエラーとする
ロゴ画像画面で選べるのは gif・jpeg・png の1件までで、10MB を超えるファイルは送信前にエラーとする。サーバ側でも種別が画像であることを確認する。登録時にファイルの内容を検証し直すことはない。欄には「620px以上推奨」を併記する

登録の判定順序

順序判定結果
1項目ごとの入力検証違反のときは項目にエラーを表示し、同じ編集画面を再表示する。完了メッセージは表示しない
2利用条件の下限・上限がいずれも空でなく、上限が下限より小さい下限の欄にメッセージを付ける
3手数料設定可否が不可保存の直前に手数料を 0 へ置き換える

保存できたときは支払方法一覧へ戻る。

削除

なりすまし対策トークンを検証し、無効なときは拒否する。対象の支払方法が無いときはメッセージを表示して一覧へ戻る。対象があるときは一覧から消し、残った支払方法の表示順を、並び順を保ったまま 1 から連番に振り直す。

表示順の入れ替え

上へ移動したときは、表示順が 1 大きい支払方法を探して両者の表示順を入れ替える。下へ移動したときは、表示順が 1 小さい支払方法を探して入れ替える。該当が無いときは移動できない旨を表示する。いずれも一覧へ戻る。操作にはなりすまし対策トークンの検証を伴う。

ロゴ画像の追加

ファイルを選ぶと、登録の前に非同期でファイルだけを送る。非同期でない要求は不正な要求として扱う。受け取ったファイルの種別が画像で始まらないときは、対応していない形式としてエラーとする。受け付けたときは重複しないファイル名を付けて保管し、そのファイル名を返してプレビューに表示する。選び直すと直前のプレビューは消え、プレビューの削除操作で選択そのものを取り消せる。

エラー時の扱い

エラー内容処理
入力検証エラー項目のエラーを表示し、保存しない
削除・順序変更のトークン不正アクセスを拒否する
ロゴ画像の追加が非同期の要求でない不正な要求として拒否する
ロゴ画像の種別が画像で始まらない対応していない形式として拒否する

入出力

種類内容
入力支払方法の入力項目、表示順の移動と削除の対象、追加するロゴ画像ファイル、なりすまし対策トークン
成功時出力支払方法の登録・更新・削除・表示順の入れ替え、完了メッセージ、一覧への戻り。ロゴ画像の追加では保管したファイル名を返す
失敗時出力項目のエラーを付けた編集画面の再表示。非同期要求の不正・画像種別の不正・トークン不正はHTTPエラー。削除対象が存在しないときはメッセージを表示して一覧へ戻る

編集画面には「一覧に戻る」があり、登録せずに支払方法一覧へ戻れる。

入出力: 永続化

操作契機
追加・更新支払方法の登録が検証に通ったとき
論理削除・更新支払方法の削除時に、対象を一覧から外したうえで、残る支払方法の表示順を 1 から振り直す
更新表示順の上下移動で、隣り合う2件の表示順を入れ替えたとき
追加ロゴ画像ファイルを保管したとき
