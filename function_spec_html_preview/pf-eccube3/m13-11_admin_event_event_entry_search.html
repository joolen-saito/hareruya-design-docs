イベント管理 — イベント申込登録検索

概要

管理画面で、イベント申込を登録する際に対象イベントを検索する機能である。キーワードや日付でイベントを非同期に検索し、結果を一覧（モーダル内）に表示する。イベントIDによる直接検索にも対応する。

本書は実装手順ではなく、誰が・いつ・どの条件で・結果どうなるかを読むためのリバース詳細設計とする。確認値はpf-eccube3（EC-CUBE3系）のHareruyaEcプラグインの管理画面イベント申込検索処理、検索フォーム、テンプレート（Entry/search_event.twig）を正とする。本機能のカスタマイズ区分は現行踏襲であり、挙動の確認はpf-eccube3を参照し、永続化先のテーブル・列名などDB関連の記述はec-cube-enterpriseを正とする。

対象はブラウザ経由の管理画面に限定する。

本文ではフレームワークのコントローラ型名やメソッド名を主説明としない。管理画面プレフィックスは環境により変わる（admin_route）。「利用者視点の入口」にHTTPメソッドとサイトルートからのパスパターンを書く。

本書で扱うこと

  • 申込登録時のイベント検索（キーワード・日付）
  • イベントIDによる直接検索
  • 非同期検索とモーダル表示・ページ送り

本書で扱わないこと

以下は本書では仕様確定せず、実装または別機能の設計を正とする。

  • イベント申込の登録・編集・一括編集（各機能を正とする）
  • イベント・日程の管理（イベント機能を正とする）

処理フロー

イベントを検索する（POST /{admin_route}/entry/search/event/html）

  1. 管理画面の認証・権限を通過する。
  2. 非同期リクエストでない場合は、空の検索結果でモーダル枠のみ表示する。
  3. 検索フォームを生成する。
  4. 検索（POST）では1ページ目とし、キーワード・開始日等の検索条件を組み立てて検索する。
  5. 検索結果を一覧（ページ送り付き）で返す。

ページを送る（GET /{admin_route}/entry/search/event/html/{page_no}）

  1. 管理画面の認証・権限を通過する。
  2. 指定ページの検索結果を返す。

イベントIDで検索する（POST /{admin_route}/entry/search/event/id）

  1. 管理画面の認証・権限を通過する。
  2. 指定IDのイベントを取得して返す。
