F07-01（イベント大会TOP）

店舗ごとに、選択した月のイベントをカレンダーと日付リストで表示する、フロントのイベント大会TOP画面である。

業務ロジック

画面に表示するもの

選択中の店舗名と月、前月・当月・翌月のタブ、月間カレンダー（曜日見出し・日付セル）、過去の大会の開閉ブロック、開催日ごとのイベントリストを表示する。各イベントはフォーマットアイコン・開始時刻（単一日程時）・イベント名で表示する。当日より前の日付セルは非リンクの過去表示にする。日曜・土曜・祝日で日付セルの装飾を変える。過去の大会ブロックは初期状態で隠す。本画面はモーダル・ポップアップ・トーストを表示しない。入力フォームを持たず、店舗切替と月・日付・イベントへのリンクだけで操作する。

表示店舗と表示月の決定

表示店舗はクエリの店舗指定、クッキーの店舗、既定店舗（ID＝1）の順に決定する。クエリで店舗が指定され、クッキーの店舗と異なるときのみクッキーを更新する。表示店舗が存在しないときはページが見つからない（HTTP404）として扱う。表示月はクエリの月指定、無ければ当月とする。前月・翌月は当月から1か月前後で算出する。店舗指定と月指定がいずれも無い初回アクセスはTOPとみなし、タイトル・説明文の出し分けに用いる。抽出条件は変えない。

月間表示の組み立て

表示店舗・表示月で月間イベント詳細を取得する。当月の祝日を取得し、日付セルの装飾に用いる。当月の各日付について表示用イベント配列を初期化し、取得したイベント詳細を開催日ごとに整理する。同一日・同一イベントが2件目以降に現れたときは複数日程として束ね、同一日内では同一イベントを重複表示しない。月初日が当日より前なら過去の大会あり、月末日が当日以降なら今後の大会ありと判定し、過去の大会ブロックの開閉表示に用いる。カレンダーリストにはイベント名を表示し、単一日程では開始時刻も表示する。

複数日程イベントの日別表示

イベント識別子が空のときはページが見つからない（HTTP404）として扱う。日付指定が Ymd 形式のときは当該日を終端日とし、過去日のときは過去として扱う。日付指定が all のときは当日を起点とする。いずれでもないときはHTTP404とする。当該イベント・当該期間の開催日程を取得し、該当が1件のときはその詳細画面（F07-03）へ遷移する。該当が0件のときは当該イベントの最新開催日程の詳細画面へ遷移し、最新日程も無いときはHTTP404とする。該当が複数件のときは日別画面で開催日程の一覧を表示する。ログイン会員のときは選手情報を渡す。

エラー時の扱い

エラー内容処理
店舗IDが存在しないページが見つからない（HTTP404）として扱う
日別パラメータが不正ページが見つからない（HTTP404）として扱う
日別で該当も最新日程も無いページが見つからない（HTTP404）として扱う

本画面は利用者向けの個別エラー文言を専用に定義せず、共通の異常処理に委ねる。

入出力

種類内容
入力クエリの店舗指定・月指定、クッキーの店舗。日別はパスのイベント識別子・日付指定
成功時出力月間カレンダーと日付リストのHTML。日別は開催日程一覧のHTML、または詳細画面・最新日程詳細への遷移
失敗時出力店舗なし・不正な日別パラメータ・該当0件かつ最新日程なしのときのページが見つからない（HTTP404）

入出力: 永続化

操作契機
更新クエリで指定された店舗が現在のクッキーの店舗と異なるときの、クッキーの店舗
