F07-01（イベント大会TOP）

店舗ごとに、選択した月のイベントをカレンダーと日付リストで表示する、フロントのイベント大会TOP画面である。

概要

イベント大会TOPは、利用者が店舗と月を選び、その店舗で開催されるマジック：ザ・ギャザリングの大会を、月間カレンダーと日付ごとのリストで一覧する機能である。表示対象は選択中の店舗・選択中の月に開催されるイベントに限定し、店舗の切替・前月翌月の切替・過去大会の開閉・日付へのスクロール移動を提供する。同一日・同一イベントが複数の日程を持つ場合は、1日内に重複表示しないよう束ねたうえで、複数日程イベントは日別画面（F07-01の日別表示）へ、単一の日程は詳細画面（F07-03）へ誘導する。

本書は実装手順ではなく、誰が・いつ・どの条件で・結果どうなるかを読むためのリバース詳細設計とする。確認値はpf-eccube3（EC-CUBE3系）のHareruyaEcプラグインのイベント一覧（TOP）処理・日別イベント処理、テンプレート（Event/index.twig・Event/daily.twig）、イベント詳細リポジトリの月間取得処理を正とする。本機能のカスタマイズ区分はカスタマイズであり、挙動の参照リポはpf-eccube3、DB関連はec-cube-enterpriseを正とする。

対象はブラウザ経由のフロントに限定する。フロントのルートはロケールを先頭に持つ/{_locale}配下にあり、イベントは/{_locale}/events配下にまとまる。

本文ではフレームワークのコントローラ型名やメソッド名を主説明としない。本文ではルートbind名の網羅は主説明とせず、「利用者視点の入口」にHTTPメソッドとサイトルートからのパスパターンを書く。コード探索でbind名が必要なときだけ「調査補助」へ書く。

本書で扱うこと

  • 店舗ごと・月ごとのイベント出し分けと、カレンダー・日付リストの表示
  • 店舗切替・前月翌月切替・過去大会の開閉・日付ジャンプの挙動
  • 同一日・同一イベントの複数日程の束ね（単一日程と複数日程の表示分け）
  • 単一日程イベントの詳細遷移、複数日程イベントの日別遷移

処理フロー

イベント大会TOP・月間表示（GET /{_locale}/events）

  1. クエリのshop、無ければクッキーのshop、いずれも無ければ既定店舗（ID＝1）を表示店舗とする。クエリで店舗が指定され、クッキーと異なる場合はクッキーshopを更新する。
  2. 表示店舗が存在しなければページが見つからない（HTTP404）として扱う。
  3. クエリのshop・dateがいずれも無ければTOP判定を真とし、画面タイトルの出し分けに用いる。
  4. クエリのdate、無ければ当月を表示月（Ym）とする。
  5. 表示店舗・表示月で月間イベント詳細を取得する。詳細は後述の「集計条件」を参照する。
  6. 当月の祝日を取得し、日付セルの装飾に用いる。
  7. 当月の日付イテレータを生成し、各日付の表示用イベント配列を初期化する。
  8. 取得したイベント詳細を開催日ごとに整理する。同一日・同一イベントが2件目以降に現れたら複数日程として束ね、同一日内では同一イベントを重複表示しない。
  9. 月間カレンダーと日付リストを表示する。月初日が当日より前なら過去の大会を持つ、月末日が当日以降なら今後の大会を持つと判定し、過去の大会ブロックの開閉表示に用いる。

複数日程イベントを日別表示する（GET /{_locale}/events/{eventId}/{eventDate}/）

  1. eventIdが空ならページが見つからない（HTTP404）として扱う。
  2. eventDateがYmd形式なら当該日を終端日とし、過去日なら過去フラグを立てる。allなら当日を起点とする。いずれでもなければHTTP404とする。
  3. 当該イベント・当該期間の開催日程を取得する。
  4. 該当が1件なら、その詳細画面（F07-03）へリダイレクトする。
  5. 該当が0件なら、当該イベントの最新開催日程の詳細画面へリダイレクトする。最新日程も無ければHTTP404とする。
  6. 該当が複数件なら、日別画面で開催日程の一覧を表示する。ログイン会員のとき選手情報を渡す。
