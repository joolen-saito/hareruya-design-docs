業務ロジック

取引区分ごとのポイント処理

受信した内容から取引ヘッダと取引明細を取り出し、取引区分で処理を分ける。

取引区分処理
取消会員の保有ポイントから付与ポイントを差し引き、利用ポイントを戻す。取引に一致するポイント履歴を削除する
打消付与ポイントと利用ポイントの正負を反転したうえで取消と同じ補正を行い、対象のポイント履歴を削除する
通常取引会員の保有ポイントに付与ポイントを加え、利用ポイントを差し引く。付与ポイントが 0 より大きいときは付与の履歴を、利用ポイントが 0 より大きいときは利用の履歴を、購入によるポイントとして登録する。0 のときはその履歴を登録しない

登録する履歴の備考には、付与のときは「店舗付与」、利用のときは「店舗使用」と記録する。

注文への反映にともなうスマレジへのポイント連携

取引明細の商品コードに対応する注文が複数あるときは、いちばん新しい注文を対象とする。

注文へ反映するとき、その時点の日時を、注文の確定日と出荷日、および注文に紐づく各配送の出荷日として記録する。スマレジ用として登録されている担当者があるときは、その担当者を注文の担当者として記録する。

反映した注文に付与ポイントが記録されているときは、その付与ポイントを会員の保有ポイントに加え、購入によるポイントの履歴としてその注文とともに登録する。付与ポイントが未設定または 0 のときは加算も履歴の登録も行わない。

付与ポイントが 0 のとき（スマレジ側で決済とポイント付与が済んでいるとき）はスマレジへ送らない。0 でないときは、会員のスマレジ会員IDあてに付与ポイントをスマレジへ送る。使用ポイントは EC からの注文時に連携済みのため送らない。

スマレジからの応答に正常な結果が含まれないときは、その注文にスマレジ連携のエラー内容と、連携エラーである印を記録する。処理は中断しない。

エラー時の扱い

エラー内容処理
会員が見つからないポイントの補正も履歴の登録・削除も行わず、エラーとせずに処理を続ける
取消・打消で対象のポイント履歴が無いポイントの補正も履歴の削除も行わず、エラーとせずに処理を続ける

入出力

入出力: 永続化

操作契機
更新会員の保有ポイントを、取消・打消・通常取引のいずれかで補正したとき
追加購入によるポイントの履歴を、通常取引で付与ポイントまたは利用ポイントが 0 より大きいとき
削除取引に一致するポイント履歴を、取消または打消のとき
更新会員の保有ポイントを、注文へ反映するときにその注文の付与ポイントが 0 でないとき
追加購入によるポイントの履歴を、注文へ反映するときにその注文の付与ポイントが 0 でないとき
更新注文に、確定日と出荷日、各配送の出荷日を、注文へ反映したとき
更新注文の担当者を、スマレジ用の担当者が登録されているとき
更新注文に、スマレジへのポイント連携が正常に終わらなかったときのエラー内容と連携エラーの印
