admin_product_sale_high_price_csv_export（管理画面_商品管理_セール用高額商品価格変更CSV雛形出力）

概要

管理画面「商品管理」配下の CSV 管理メニューから開ける「セール用高額商品価格変更CSVアップロード」画面上で、「雛形ファイルダウンロード」リンクを押すと取得できる、セール用高額商品価格変更 CSV 取込と同一ヘッダ列名（日本語）の 1 行だけを含む雛形ファイルを返す機能である。データ行（商品コードや価格の実データ）は出力されない。

本書は実装手順ではなく、誰が・いつ・どの条件で・結果どうなるかを読むためのリバース詳細設計とする。ec-cube-enterprise のコア実装を確認値とする。

対象はブラウザ経由の管理画面に限定する。

コントローラのメソッド名は本文の主題としない。本文ではルートbind名やSymfonyのルートnameの網羅は主説明としない。「利用者視点の入口」にHTTPメソッドとサイトルートからのパスパターンを書く。コード探索でbind名が必要なときだけ「調査補助」へ書く。

利用者視点の入口

入口URLエンドポイント期待されるふるまい
管理画面メニューで「商品管理」→「商品CSV」→「セール用高額商品価格変更CSVアップロード」を開き、カード「セール用高額商品価格変更CSVファイルフォーマット」内の「雛形ファイルダウンロード」を押すGET /{admin_route}/product/sale_high_price/csv_templateファイル名 sale_high_price_template.csv が添付として返り、本文はヘッダ行 1 行だけの CSV である。
上記 URL を直接開く（ブックマーク等）同上認証・共通制約を通過していれば同じ雛形が返る。

ナビゲーションの表示ラベルはロケールキー admin.product.sale_high_price_csv により「セール用高額商品価格変更CSVアップロード」となる（日本語ロケールの確認値）。

JS 挙動雛形ダウンロード専用のクライアント処理は無い。ファイル選択とアップロード送信時のローディング表示のみ共通スクリプトにある。

処理フロー

雛形 CSV をダウンロードする（GET admin_product_sale_high_price_csv_template）

  1. 管理画面の認証・共通制約を通過する。
  2. ストリーミング応答のコールバック内で、共通の CSV 出力サービスを開く（fopen）。
  3. ヘッダー定義連想配列のキーを順に並べた配列を 1 行だけ fputcsv に渡す。値側の説明文は書き込まない。
  4. 出力ストリームを閉じる（fclose）。
  5. 応答ヘッダに Content-Type: application/octet-stream と Content-Disposition: attachment; filename=sale_high_price_template.csv を付与した応答を返す（自動テストがこの組み合わせを確認値とする）。

文字コードと区切り（fopen〜fputcsv の共通実装）

  1. 設定 eccube_csv_export_encoding の値（配布設定では UTF-8）を UTF-8 からの変換先とする。配列の各セルは mb_convert_encoding で当該エンコーディングへ変換されてから fputcsv される。
  2. エンコーディング名を大文字化した値が UTF-8 と一致するとき、ストリーム先頭に UTF-8 の BOM（バイト列 \xEF\xBB\xBF）を書く。
  3. 区切り文字は eccube_csv_export_separator（配布設定ではカンマ）。フィールド囲みは二重引用符、エスケープはバックスラッシュとして fputcsv に渡される。

本機能では件数集計や売上などの業務集計は行わない。出力内容は固定のヘッダ行 1 行のみである。

データ整合性

観点内容
商品マスタとの一致雛形ダウンロードはデータベースを読まないため、商品コードや価格との整合は保証の対象外である。
取込との一致ヘッダ列名および列順は、同一機能群の取込ハンドラが期待する日本語列名と揃えるためのものである。取込時の検証・更新の詳細は取込側の実装を正とする。

セッション

本機能の GET 雛形ダウンロードは、セッションキー admin.product.sale_high_price_csv.page_count や admin.product.sale_high_price_csv.page_no を読み書きしない（これらはアップロード画面表示用の別ルートで用いられる）。

パフォーマンス

雛形は常に 1 行のため、set_time_limit(0) や SQL ロガー無効化など、大量行エクスポート向けの特別処理は掛けない。

拡張・差し替え

  • ヘッダ列集合を変える場合は雛形ルートと取込ハンドラの両方を整合させる必要がある。
  • eccube_csv_export_encoding や eccube_csv_export_separator を環境で上書きすると、雛形ファイルのバイト表現が変わる（BOM の有無を含む）。
