申込詳細の初期表示

削除済みの会員は読み込み対象から除外し、削除済みのプレイヤーも読み込む。指定された申込が存在しないときは404とする。存在するときは紐づくイベント詳細・イベントを得る。参加者行は、チーム人数と既存参加者数の大きい方の行数で用意する。参加者情報リスト・申込状況・支払方法・支払金額を初期表示する。席順アルファベット一覧が参加者数より少ないときは404とする。

編集できる項目

画面上の項目扱い
申込状況申込状況マスタから選択する。更新時に申込へ反映する
支払方法画面上で無効化されており、編集画面からは変更しない
支払金額半角数字のみ。更新時に申込へ反映する
参加プレイヤープレイヤーID・確認フラグ・席順を要素とする参加者情報リストで管理し、継続・追加・削除を更新時に反映する

支払方法・支払会員は更新の対象から除外する。

更新の判定順序

順序判定結果
1指定された申込が存在するか存在しなければ404とする
2更新の送信であるか送信によらない到達は更新失敗を表示し、編集画面へ戻す
3支払金額が半角数字のみか不正なら金額のメッセージを表示し、編集画面を再描画する
4参加者が他申込・同日程で重複しないか重複するときは申込重複のメッセージを表示し、編集画面を再描画する
5その他の入力内容が妥当か妥当でなければ更新失敗を表示し、編集画面を再描画する
6上記を通過申込を更新し、成功を表示して同じ申込の編集画面へ戻る

参加者の反映

参加者情報リストと既存の参加者を突き合わせる。継続する参加者は確認フラグ・席順に変更があれば更新する。リストから外れた参加者は削除する。追加された参加者は新規に登録する。更新が成功するたびに申込履歴を1件記録する。

エラー内容処理

その他の検証不備更新失敗を表示し編集画面を再描画する
