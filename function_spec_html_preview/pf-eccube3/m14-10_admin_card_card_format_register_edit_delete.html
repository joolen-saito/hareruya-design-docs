カード管理 — フォーマット新規登録・編集・削除

業務ロジック

一覧と編集の対象

一覧はフォーマットを並び順の昇順、並び順が同じときは識別子の昇順で全件表示する。

編集では、指定したフォーマットが無いときは 404 とする。当該フォーマットに紐づくカード制限のうち、禁止のものから禁止カードの一覧を、制限のものから制限カードの一覧を組み立てる。リーガルのものはどちらの一覧にも載せない。

新規登録では禁止カードと制限カードをいずれも空とする。統率のボードが無いときは、統率をメインに含めるかの判定をフォーマットの算出結果に従う。

保存の判定順序

順序判定結果
1更新のとき、指定したフォーマットがあるか無いときは 404 とする
2なりすまし対策トークンが有効か無効のときはアクセス拒否（HTTP 403）とする
3入力の検証を満たすか満たさないときは保存せず、入力した値のまま編集画面を再表示する
4検証を満たしたときフォーマットを保存し、識別子を確定する
5保存の後カード制限とフォーマットボードを次のとおり置き換える

カード制限の置き換え

入力にある禁止カードと制限カードを合わせた集合を求め、当該フォーマットに紐づくカード制限のうち次のいずれかに当たるものを削除する。

  • 制限の種別がリーガル以外である。
  • カードが上記の集合に含まれる。

リーガルであり、かつ集合に含まれないものは残す。削除の後、禁止カードと制限カードそれぞれに対応する種別を付けたカード制限を新たに作る。

フォーマットボード

メインとサイドのフォーマットボードは、入力の上限と下限で作成または更新する。枚数の数え先となるボードは持たせない。

統率でカードを使用する統率のカードをメインボード枚数に含む結果
真真統率のボードを作成または更新し、メインのフォーマットボードへの参照を持たせる
真偽統率のボードを作成または更新し、メインのフォーマットボードへの参照を持たせない
偽—統率のボードが既にあるときは削除する

登録と更新のいずれも、保存した後は当該フォーマットの編集画面へ戻す。

削除の判定順序

順序判定結果
1なりすまし対策トークンが有効か無効のときはアクセス拒否（HTTP 403）とする
2指定したフォーマットがあるか無いときは 404 とする
3大会・デッキ・アーキタイプのいずれかが当該フォーマットに紐づくか1 件でも紐づくときは削除せず、元の画面へ戻す
4いずれも紐づかないとき当該フォーマットのカード制限をすべて削除し、フォーマットを削除して一覧へ戻す
