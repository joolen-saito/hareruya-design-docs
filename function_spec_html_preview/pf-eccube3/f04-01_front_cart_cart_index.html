F04-01（買い物かご）

概要

買い物かご画面において、カートに入っている商品の一覧と数量・金額を表示し、数量更新・商品削除・カート一括削除・購入手続きへの導線を提供する機能である。受注の確定や決済は行わず、カートの内容を確認・調整する範囲に限定する。

本書は実装手順ではなく、誰が・いつ・どの条件で・結果どうなるかを読むためのリバース詳細設計とする。確認値はpf-eccube3（EC-CUBE3系）のHareruyaEcプラグインの買い物かご処理、テンプレート（Cart/index.twig）、カートサービスを正とする。

本機能のカスタマイズ区分はカスタマイズであり、挙動の確認は現行リポ（pf-eccube3）の実装を参照する。DB関連の記述はリニューアル移行先の ec-cube-enterprise を正とする。

対象はブラウザ経由のフロント（カート）に限定する。フロントのルートはロケールセグメント付きで提供され、サイトルートからのパスパターンは/{_locale}配下になる（/{_locale}はサービスプロバイダのマウントで決まる確認値）。

コントローラのメソッド単位の解剖は本文の主題としない。本文ではルートbind名の網羅を主説明とせず、「利用者視点の入口」にHTTPメソッドとサイトルートからのパスパターンを書く。コード探索でbind名が必要なときだけ「調査補助」へ書く。

本書で扱うこと

  • 買い物かご画面の表示内容（商品一覧・単価・数量・小計・合計・送料無料案内）
  • 数量の更新（再計算）と商品の削除、カート一括削除の挙動
  • カートに商品を追加するXHR入口（外部からのカート追加API的経路）と数量増減
  • 購入手続きへ進む際のカートロックと遷移
  • 単一購入グループでないカート（同時注文不可）の判定と案内

本書で扱わないこと

以下は本書では仕様確定せず、実装または別機能の設計を正とする。

  • ご注文方法指定・注文情報の入力・確認（F04-02 注文情報の入力・確認・注文を正とする）
  • 注文確定〜購入完了（カートの決済〜購入完了機能を正とする）
  • 入荷通知依頼の業務ルール詳細（マイページの入荷通知依頼一覧機能を正とする。本書はカート画面からの依頼XHRの挙動のみ触れる）
  • 商品検索・商品詳細・おすすめ表示の内部仕様

リニューアル移行時の扱い

買い物かごはセッションに保持し、永続化に関わるテーブルとしては商品規格 dtb_product_class、基本情報 dtb_base_info（送料無料金額・送料無料個数）、入荷通知依頼 dtb_product_request を参照する。これらは現行（pf-eccube3）と移行先（ec-cube-enterprise）で同一スキーマである。買い物かご画面からの入荷通知依頼XHRの登録・取消は入荷通知依頼テーブル dtb_product_request を更新するが、依頼上限・論理削除等の業務ルール詳細は入荷時通知（F03-07）を正とする。注文情報の入力・確認・確定は別画面（F04-02）を正とする。

処理フロー

買い物かごを表示する（GET /{_locale}/cart）

  1. カートサービスから購入グループを取得し、複数ある場合は同時注文不可のエラーをカートに追加し、フラッシュに購入グループ情報を保存する。
  2. 基本情報の送料無料金額・送料無料個数を参照し、送料無料の到達状況（無料か、残り金額、残り個数）を求める。
  3. カート内容・送料無料判定をテンプレートに渡して買い物かご画面を表示する。

数量を更新する（POST /{_locale}/cart/update）

  1. 送信された数量配列を順に処理する。
  2. 数量が1未満の商品はカートから削除する。
  3. それ以外は当該商品の数量を指定値に設定して保存する。
  4. 買い物かご画面へリダイレクトする。

数量を増減する（PUT /{_locale}/cart/up・/{_locale}/cart/down）

  1. なりすまし対策トークンを検証する。
  2. 増減処理を行い保存する。減算で0未満になる場合は削除する。
  3. 例外時はリクエストエラーを追加する。
  4. 買い物かご画面へリダイレクトする。

商品を削除する（PUT /{_locale}/cart/remove/{productClassId}）

  1. なりすまし対策トークンを検証する。
  2. 当該商品を削除して保存する。
  3. 買い物かご画面へリダイレクトする。

カートを一括削除する（GET /{_locale}/cart/clear）

  1. カートを空にして保存する。
  2. 買い物かご画面へリダイレクトする。

購入手続きへ進む（POST /{_locale}/cart/buystep）

  1. 送信された数量でカートを更新する。
  2. 販売個数制限超過などでフラッシュメッセージが追加された場合は、買い物かご画面へ戻りメッセージを表示する。
  3. メッセージが無ければカートをロックして保存し、注文情報入力（ご注文方法指定）へ遷移する。

カートに追加する（POST /{_locale}/cart/add・/{_locale}/cart/add_bulk・/{_locale}/cart/add_show）

  1. リクエストボディまたはパラメーターから商品規格IDと数量を取り出す。
  2. 商品をカートへ追加して保存する。追加失敗時はリクエストエラーを追加する。
  3. add・add_bulkはカート内容をJSONで返す。add_showは買い物かご画面へリダイレクトする。
