店舗設定 — 店舗基本設定（SHOPマスター/旧ショップマスター）

業務ロジック

初期表示

保存済みの店舗基本情報を読み、入力フォームに初期表示する。表示用には取得した内容の複製を用いるため、編集対象とは別の内容として扱う。画面には入力フォームと登録の操作だけを置く。

保存の判定

判定結果
入力の検証に成功したとき店舗基本情報を保存し、完了メッセージを表示して店舗基本設定画面を再表示する
入力の検証に失敗したとき保存せず、同じ画面を再表示して各項目のエラーを表示する。完了メッセージは表示しない

検証に失敗して再表示したときは、表示用の複製が要求を受けた時点の内容のままとなるため、入力中の値と画面に載る店舗名等が一致しないことがある。

入力の制約

項目制約
店名（英語表記）・住所（英語表記）・ショップ名略称（英語表記）・スマレジ店舗コード半角英数字以外を入力したときは保存しない
スマレジ店舗ID・送料無料条件（数量）数字以外を入力したときは保存しない

エラー時の扱い

エラー内容処理
入力の検証エラー該当項目の近傍にエラーを表示し、保存しない

入出力

種類内容
入力なりすまし対策トークンと店舗基本情報。店舗基本情報には、送信元・問い合わせ受付・返信受付・エラー受付の各メールアドレス、取り扱い商品、メッセージ、送料、各選択肢、緯度・経度が含まれる
成功時出力保存できたときは完了メッセージを表示し、店舗基本設定画面を再表示する
失敗時出力保存できないときは項目ごとのエラーを表示し、完了メッセージは表示しない

入出力: 永続化

操作契機
更新入力の検証に成功したとき。店舗基本情報
