取込の判定順序

順序判定結果
1なりすまし対策トークンが有効か無効ならアクセス拒否として応答し、取込を行わない
2ファイル選択・ファイルサイズ・ファイル種別が制約を満たすか違反してもエラーメッセージを表示するだけで取込は打ち切らず、後続の判定を通過すれば登録まで行う
3ファイルを解釈できるか解釈できないときは、エラーメッセージを表示せずに取込画面へ戻す
41行目が期待するヘッダと並び順も含めて完全一致するか一致しないときはヘッダ形式エラーとして取込を中止する
5データ行が1行以上あるか0件のときはデータ空エラーとして取込を中止する
6各行の列数がヘッダの列数と一致するか一致しないときは行番号付きの形式エラーとする
7必須項目が空文字でないか違反するときは項目名と行番号を含む必須エラーとする
8代表カード名が入力されているか入力があるときだけ画像を解決する。候補は日本語版と英語版の表面の画像に限り、収録の新しいものを優先し、収録が同じときは英語版を優先して1件を設定する。解決できないときもエラーとせず、その行はそのまま取り込む
9「色」列からカンマを除いた結果が空でないか空でないときだけカンマ区切りで分解し、重複を除いて日本語の色名で解決する。1件も解決できないときは未定義データとして項目名と行番号を含むエラーとする。一部だけ解決できたときはエラーとせず、解決できた色だけを設定する
10全行を処理できたかできたときは取込を確定する

取込ファイルは、取込用の設定値による区切り文字（既定はカンマ）と囲み文字（既定は二重引用符）で解釈する。取込前に文字コードと改行を正規化し、ゼロ幅スペースとBOMを取り除く。

途中でエラーになったときは取込内容をすべて取り消し、エラーメッセージを表示して取込画面へ戻す。全行に成功したときは登録完了メッセージを表示して取込画面へ戻す。

登録の単位と更新する項目

更新する相手を探すとき、削除済みのアーキタイプとは突き合わせない。名前とフォーマットが同じ削除済みのものがあっても、別に新規登録される。

項目扱い
公開状態取込のたびに「公開」へ上書きする
解説（日）・解説（英）・タグ・記事の紐付け取込では更新せず、既存データを上書きしない
代表カード代表カード名が空のときは設定を行わないため、既存のアーキタイプでは前回の状態が残る
カラー「色」が空またはカンマだけのときは設定を行わないため、既存の色が残る。値があるときは色の集合を丸ごと置き換える

入出力

種類内容
入力取込ファイル1件と、なりすまし対策トークン
成功時出力取込画面への遷移と登録完了メッセージ
失敗時出力取込画面への遷移とエラーメッセージ
