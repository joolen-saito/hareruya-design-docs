m15-10_admin_deck_archetype_csv_import（デッキ管理 — アーキタイプ登録 CSV / TSV 取込）

業務ロジック

アップロード画面

ファイル1件を受け取る空のフォームと、取込ファイルのヘッダ定義を表示する。業務項目の入力欄は持たない。

取込の判定順序

順序判定結果
1アップロードフォームとなりすまし対策トークンが有効か無効ならエラーメッセージだけを表示し、その場で処理を打ち切る
2ファイルサイズ・アップロードの妥当性・ファイル種別が制約を満たすか満たさないならエラーメッセージだけを表示して終了する
3ファイルを解釈できるか解釈できないときは取込画面へ戻す
41行目が期待するヘッダと並び順も含めて完全一致するか一致しないときはヘッダ形式エラーとして取込を中止し、取込内容を取り消す
5データ行が1行以上あるか0件のときはデータ空エラーとして取込を中止する
6各行の列数がヘッダの列数と一致するか一致しないときは行番号付きの形式エラーとする
7必須3列（日本語名・英語名・フォーマット）が空文字でないか違反するときは行番号付きの必須エラーとする
8フォーマット列をフォーマットマスタの英語名で解決できるか解決できないときはマスタ未定義として行番号付きのエラーとする
9日本語名・英語名・フォーマットが一致し、削除されていないアーキタイプがあるか見つからないときは新規のアーキタイプとして登録する
10代表カード名が入力されているか入力があるときだけ画像の解決へ進む。英語名で見つからないときもエラーとせず、画像参照が空になることがある
11「色」列からカンマを除いた結果が空でないか空でないときだけカンマ区切りで分解し、重複を除いて色マスタの日本語名で解決する。解決できないときは未定義データとしてエラーとする
12全行を処理できたかできたときは取込を確定する

取込ファイルは、拡張子がtsvのときタブ区切り、それ以外のときは取込用の設定値による区切り文字（既定はカンマ）と囲み文字（既定は二重引用符）で解釈する。取込前に文字コードと改行を正規化し、ゼロ幅文字とBOMを取り除く。

途中でエラーになったときは取込内容をすべて取り消し、エラーメッセージを表示して取込画面へ戻す。全行に成功したときは登録完了メッセージを表示して取込画面へ戻す。

取込ファイルの列

1行目のヘッダは次の並びで固定であり、並び換えただけのファイルはヘッダ形式エラーとなる。

順序（1から）1行目に書くヘッダ文字列データ側のルール
1アーキタイプ名（日本語）必須。登録単位を決めるキーの一部
2アーキタイプ名（英語）必須。登録単位を決めるキーの一部
3代表カード名任意。入力があるときはカードの英語名から表面画像を解決する。解決できないときも行は処理される
4色任意。カンマ区切りの日本語の色名を列挙する。カンマ以外が空のときは色を更新しない。そうでないときは列挙したすべてが色マスタに存在する必要がある
5フォーマット必須。フォーマットマスタの英語名で解決する
6旧アーキタイプID任意。ヘッダは省略できず、データは空でもよい。桁や形式の検証は取込側で行わない

登録の単位と更新する項目

日本語名・英語名・フォーマットが一致し、削除されていないアーキタイプを更新単位とする。該当が無いときは新規登録とする。削除済みのアーキタイプとは突き合わせないため、名前とフォーマットが同じ削除済みのものがあっても別の新規行が作られることがある。

項目扱い
表示区分取込のたびに「表示」を表す値へ上書きする
旧アーキタイプID入力値をそのまま設定する。画面フォームの桁上限は適用されない
説明文（日本語・英語）・デッキタグ・記事紐付け取込では更新せず、既存データを上書きしない
代表画像入力が無いときは設定を行わないため、既存のアーキタイプでは前回の状態が残ることがある
アーキタイプカラー「色」が空またはカンマのみのときは設定を行わないため、既存の色が残ることがある。値があるときは日本語の色名で解決し、色の集合を丸ごと置き換える

本機能で行う計算は、読み込んだデータの検証とマスタ解決だけであり、売上計算などの業務計算は行わない。

エラー時の扱い

エラー内容処理
フォーム入力・なりすまし対策トークン・アップロード制約に違反したときエラーメッセージを表示し、取込画面へ戻す
ヘッダ不一致・データ無し・列欠損のとき取込内容を取り消し、エラーメッセージを表示する
フォーマット名や色がマスタに無いとき行番号を含むエラーとして取込内容を取り消し、エラーメッセージを表示する

入出力

種類内容
入力CSVまたはTSVファイル1件と、なりすまし対策トークン
成功時出力取込画面への遷移と登録完了メッセージ
失敗時出力取込画面への遷移とエラーメッセージ。ヘッダ不整合など一部は翻訳前の文字列のまま表示されることがある

入出力: 永続化

操作契機
追加該当するアーキタイプが無い行の取込
更新該当するアーキタイプがある行の取込（表示区分・旧アーキタイプID・代表画像・アーキタイプカラー）

表示メッセージ

本機能はCSV取込に共通のメッセージだけを表示する。内容は取込結果に応じたエラーメッセージと、登録完了のメッセージである。
