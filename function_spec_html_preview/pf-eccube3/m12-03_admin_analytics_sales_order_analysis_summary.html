業務ロジック

初期表示

保持していた検索条件を破棄し、集計日Fromに当月初日、集計日Toに当月末日、使用日付に注文日、集計単位に商品、並び順に昇順を設定した検索フォームを表示する。集計結果は表示しない。

集計と表示

受け取った検索条件を保持したうえで、注文明細から集計結果と合計を取得する。集計結果一覧と合計行、割合を同一画面に表示する。

集計値の算出

Excel基本設計 0211 識別ID:9 により廃止された仕様である。刷新後は実装しない。現行実装のふるまいを次に残すが、刷新後の実装・テストの対象外とする。

項目内容
平均単価金額合計を数量合計で割る。表示時に切り捨てる
数量割合・合計割合・件数割合各行の値を全体合計で割り100倍し、小数点以下を切り捨てる。合計が0の場合は0とする
件数注文の重複なし件数を数える
合計行表示中の集計結果について、数量・合計・件数を合算する
並べ替え並べ替えで集計単位を選んだ場合は集計単位キーで、注文数・金額・販売数を選んだ場合はその列で、昇順/降順に並べる
表示件数一覧は表示件数の上限で打ち切る

エラー時の扱い

データベース読み取りの障害はアプリケーションの共通例外処理に委ねる。認証・権限が不足するときは集計を表示しない。

種類内容

成功時出力集計結果一覧・割合・合計行を含む画面
失敗時出力データ取得失敗時はアプリケーションの共通例外処理に委ねる
