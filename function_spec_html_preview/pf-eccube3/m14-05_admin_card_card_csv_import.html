カード管理 — カード CSV 登録（取込）

業務ロジック

取込の判定順序

順序判定違反時の扱い
1ファイルの指定・サイズ・形式が妥当かエラーを表示してアップロード画面へ戻す。要求が正当でないときはアクセス拒否（HTTP 403）として扱われ得る
2一時保存と取込準備ができるか失敗時はエラーを追加せずアップロード画面へ戻す
3ヘッダの列（除外列を適用した後）が想定と完全に一致するかヘッダ形式が不正である旨のエラーとする
4データ行が1行以上あるかデータが空である旨のエラーとする
5各行の列数がヘッダの列数と一致するか行形式が不正である旨のエラーとし、行番号を添える
6必須の列が空でないか必須項目が未入力である旨のエラーとする
7参照するマスタ（色・タイプ・セットなど）に英名が存在するか未登録である旨のエラーとする
8取込の確定と支店への通知確定の成否はログに、支店通知の失敗は支店エラーの記録に分けて残す

ヘッダの照合から除外する列は old_product_id、old_en_product_id、card_detail_id である。

ファイルの読み取り

取り込んだファイルは一時領域に保存し、文字コード変換・改行の正規化・BOM・ゼロ幅文字の除去を行ったうえで読む。拡張子が tsv のときは区切り文字をタブとし、それ以外のときは設定された区切り文字を用いる。先頭行をヘッダ行として扱う。取込の開始と完了は情報ログに残す。処理の終了時は一時ファイルを削除してアップロード画面へ戻す。

カードの特定と新規作成

英語カード名の // を / に直した文字列で既存カードを検索する。該当が無い行は新規のカードとして作成する。

取り込みの確定

全行の処理を1つのまとまりとして扱い、すべて処理し終えたときに確定する。検証の例外や実行時の例外が出たときは、それまでの登録内容をすべて取り消し、例外の内容をログに残したうえで、その文言をエラーとして表示する。

支店への通知

取り込みで更新対象になったカードIDを重複を除いて集め、支店へ更新を通知する。通知に失敗したときはエラーの記録とログに留め、取込自体の成功表示は取り消さない。
