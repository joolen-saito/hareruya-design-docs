カード管理 — カード CSV 登録（取込）

業務ロジック

取込の判定順序

順序判定違反時の扱い
1ファイルの指定・サイズ・形式が妥当かエラーを表示してアップロード画面へ戻す。要求が正当でないときはアクセス拒否（HTTP 403）として扱われ得る
2取込の準備ができるかエラーを追加せずアップロード画面へ戻す
3ヘッダの列（除外列を除いた後）が想定と完全に一致するかヘッダ形式が不正である旨のエラーとする
4データ行が1行以上あるかデータが空である旨のエラーとする
5各行の列数がヘッダの列数と一致するか行形式が不正である旨のエラーとし、行番号を添える
6必須の列が空でないか必須項目が未入力である旨のエラーとし、項目名と行番号を添える
7取込の確定と支店への通知支店への通知に失敗しても取込は成功として扱う

ヘッダの照合では、カード詳細ID・現行の日本語商品ID・現行の英語商品IDの3列を想定側と取り込んだ側の両方から取り除いてから比べる。このため、カード詳細IDの列が無いファイルや、現行の商品IDの列を余分に持つファイルもヘッダの検査を通る。

ファイルの読み取り

取り込んだファイルは、文字コードの変換・改行の正規化・BOM とゼロ幅スペースの除去を行ったうえで読む。先頭行をヘッダ行として扱う。

列ごとの取り込み方

列取り込み方
点数で見たマナコストレイアウトの値で解釈が変わる。Split は / 区切りの数値を合計し、Flip は / 区切りの先頭を採る。それ以外のレイアウトでは値をそのまま用いる
レイアウト値が Double Faced,Meld のときは Meld として照合する
カードタイプ・カラー・固有色・サブタイプ・特殊タイプ区切って得た値から重複を除いてから照合する。値が空の列では既存の紐付けを変更しない。同じカード名(英語)が2行目以降に現れたとき、その行で得た集合ではカードの紐付けを上書きしない
使用可能フォーマット行に挙がっていない既存のフォーマット紐付けを削除する。値が空の行では既存の紐付けを変更しない
プロモ種別空のときは非プロモーションを表す値に戻す
画像URL(日本語)／画像URL(英語)行にカード詳細IDが無いときは、カード詳細IDが未設定の既存画像を対象に探す
裏面カード詳細ID空のときは未設定にする。値があって対象のカード詳細が無いときはエラーとする
色順空のときは紐付けを未設定にする

取り込みの確定

全行の処理を1つのまとまりとして扱い、すべて処理し終えたときに確定する。処理の途中で例外が出たときは、それまでの登録内容をすべて取り消し、例外の文言をエラーとして表示する。

支店への通知

取込で登録・更新の対象になったカードIDを重複を除いて集め、支店システムへ更新を通知する。通知に失敗したときは支店更新エラーとして記録し、取込自体の成功表示は取り消さない。

エラー時の扱い

事象扱い
ヘッダが想定と一致しない登録を始める前の検査なので、カードは1件も登録されないまま、ヘッダ形式が不正である旨を表示する
行形式・必須項目・参照先マスタの不足取り込んだ内容をすべて取り消し、該当する内容を表示する

入出力

種類内容
成功時出力アップロード画面へ戻し、登録完了を表示する
