商品管理 — 商品規格登録/編集

業務ロジック

規格の登録・編集画面を表示する

  1. 利用者が新規登録画面または編集画面を開く。
  2. 商品IDから商品付加情報を読み込み、見つからなければ見つからない（HTTP404）とする。
  3. 編集（規格IDあり）では、指定商品に属する当該規格を読み込み、見つからなければ見つからない（HTTP404）とする。新規（規格IDなし）では未登録の規格を用意する。
  4. 代表画像の選択肢には当該商品に登録済みの画像を並べ、当該規格に紐づく画像を現行の並び順で初期選択にする。
  5. 編集時かつ規格が削除可能な場合だけ、削除ボタンを表示する。

規格を更新する

  1. 利用者が商品規格を登録ボタンを押下する。
  2. 入力値の検証に失敗した場合は「登録できませんでした。」を表示し、同じ画面を再表示する。
  3. 検証に合格した場合、規格の内容を保存する。
  4. 画像の紐づけは、送信された代表画像と並び順で作り直す。送信されなかった画像の紐づけは残らない。
  5. 販売価格または買取価格が変更されている場合だけ、価格履歴を記録する。
  6. 規格の更新日時を現在時刻にする。
  7. 支店システムへ当該商品の更新を通知する。
  8. 「登録が完了しました。」の成功フラッシュを設定し、同じ規格の編集画面へリダイレクトする。

販売価格と買取価格の関係

  1. 販売価格が買取価格を下回る場合は検証エラーとし、販売価格欄の直下に、買取価格の値を差し込んだ「販売価格は買取価格「（買取価格）」以上を指定してください。」を表示する。
  2. このとき規格は更新されず、「登録できませんでした。」とともに同じ画面を再表示する。

規格を削除する

  1. 当該商品の規格が最後の1件のときは削除せず、不正要求（HTTP400）とする。
  2. 規格を論理削除する。
  3. 支店システムへ当該商品の更新を通知し、当該商品の規格一覧へリダイレクトする。

登録日・更新日と期間別販売数の表示

項目表示
登録日・更新日新規登録時・編集時のいずれでも表示する。
期間別の販売数（本日・前日・3日間・1週間・1ヶ月・90日間・180日間・365日間）編集時だけ表示し、新規登録時は表示しない。集計済みの値の読み取り表示で、この画面からは変更できない。

入出力

入力と出力

種類内容
入力GETは商品ID（編集時は加えて規格ID）。POSTは規格の入力項目一式とCSRFトークン、およびmultipartで送る画像関連の隠しフィールド（代表画像の選択と並び順）。
成功時出力規格・価格履歴の更新、成功フラッシュ、同じ規格の編集画面への302リダイレクト。
失敗時出力検証失敗時は200で同じ画面を再描画し「登録できませんでした。」を表示する。
