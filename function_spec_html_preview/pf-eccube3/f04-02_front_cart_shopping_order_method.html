ご注文方法指定 — 注文情報の入力・確認・注文

業務ロジック

初期表示で作られるもの

処理中の受注情報が無いときは受注情報を作成し、注文明細ごとに明細サブ情報を作成し、ポイント使用量0で登録する。未ログインで非会員としての登録も済んでいないときはログイン画面へ誘導する。非会員として登録済みまたは会員のときは、その顧客で受注情報を作成する。受注金額がマイナスのときは注文エラー画面へ遷移する。配送先が複数あって複数配送の設定が無効のときは買い物かごへ戻し、有効なときは複数配送の案内を一度だけ表示する。

配送方法の自動切り替え

選択中の配送方法がその注文で選べる配送方法に含まれないときは、選べる配送方法の先頭へ自動で切り替える。選べる配送方法が1つも無いときは配送方法を未設定にしてエラーを表示する。この判定はお届け先を選び直したときと、注文確定の検証で不備があって画面を描き直すときに行う。

配送方法を変更したとき

ポイント使用量を0で登録し直して合計を再計算したうえで、配送方法・配送希望日・お届け時間の入力内容を受注へ反映して保存する。

お支払い方法・備考欄・ポイントを変更したとき

お支払い方法が有効なときは受注へ設定して手数料をその支払方法の手数料に更新し、無効なときは支払いを未設定として手数料を0にする。備考欄の入力は受注へ保存する。

お支払い方法の選択肢は、使用ポイントを差し引いた注文金額合計によって変わる。使用ポイントが支払うべき金額以上になったときは、お支払い方法の選択肢を「全額ポイント支払い」だけにする。下回ったときは通常のお支払い方法の選択肢に戻す。

お届け先を選び直したとき

お届け先一覧で選んだ住所を配送先へ反映する。お届け先が指定されていないときはご注文方法指定画面へ戻す。当該顧客のお届け先住所が見つからないときはお届け先が見つからない扱いとする。海外への配送のときはお届け先の郵便番号をそのまま設定し、国内のときは2つに分かれた郵便番号を連結して設定する。反映後は配送方法の有効性を判定し直し、ポイント使用量を0で再登録し、配送料を設定し直して合計を再計算して保存する。

合計と内税の算出

商品金額合計＋送料＋手数料−値引きを合計とする。内税は合計を1.1で割って0.1を掛け、小数を切り捨てた額とする。

配送希望日時の選択肢

配送希望日を「指定なし」にしたときは、お届け先の都道府県と選択中の配送方法の組み合わせに定めた最短のお届け時間より早い時間帯は選べない。最短より早いお届け時間を選んだときは、配送希望日の「指定なし」を選べない。

注文確定の判定順序

順序判定結果
1処理中の受注情報があるか無ければ注文エラーへ遷移する
2注文確定の送信であるか送信によらない到達は買い物かごへ戻す
3入力内容の検証とお支払い方法の妥当性不備なら同画面を再描画する
4お支払い方法が受注の保持値と一致するか不一致なら注文エラーへ遷移する
5購入処理が成功するか失敗ならロールバックして注文エラーへ遷移する
6上記を通過カートを空にし、ポイントを使用して購入完了画面へ遷移する

購入処理は受注確定までを一括で行い、失敗時は変更を取り消す。ポイントの使用は購入処理が完了したあとに行う。
