店舗設定 — 自動送信メールテンプレート編集（pf-eccube3 + HareruyaEc）

業務ロジック

対象のメールテンプレート

場面対象
識別子を指定せずに開いたときメールテンプレート行を特定しない。選択肢だけを表示する
選択肢の絞り込み識別子が自動送信メールの一覧に含まれる行だけとし、名称の昇順で並べる
識別子を指定して開いたとき識別子が一致し、かつ自動送信メールの一覧に含まれる行を対象とする
識別子を指定しても該当行が無いとき見つからない扱い（404）とする

本文のプレビュー

対象行のファイル名が示すファイルから本文を読み、プレビュー用のHTMLへ変換して表示する。入力内容の検証に外れて再描画するときも、対象行が取れているときは本文の読み込みと変換をやり直す。

保存の判定順序

順序判定・処理内容
1操作の有効期限不正なときは保存せず、アクセス拒否とする
2対象行の有無対象行が無いまま登録したときは、エラーメッセージを表示し、識別子を指定しない表示へ戻す。新規作成は行わない
3入力内容の検証外れたときは保存せず、同一画面に項目ごとのエラーを表示する。成功メッセージは表示しない
4更新者と更新日時ログイン中の管理者を更新者に、現在日時を更新日時に設定する
5保存対象行を保存する
6遷移同じテンプレートの編集表示へ戻る

入力値の制約

項目制約
テンプレート名必須。255文字以下とする
件名必須。255文字以下とする

金額・数量などの業務計算は行わない。本文の意味の解釈は、メール送信時の変換を正とする。

エラー時の扱い

事象扱い
入力内容の検証に外れたとき保存せず、同一画面を再描画して項目ごとのエラーを表示する
操作の有効期限が不正なときアクセス拒否とする
対象のメールテンプレートが無いとき見つからない扱い（404）とする
対象行が無いまま登録したとき新規作成を行わず、エラーメッセージを表示する

入出力

種類内容
入力識別子の有無を伴う表示要求。登録のときはテンプレート名・件名・本文などの入力値。
成功時出力同じテンプレートの編集表示への遷移と、保存成功のメッセージ。
失敗時出力同一画面の再描画と項目ごとのエラー、見つからない扱い（404）、またはアクセス拒否。

入出力: 永続化

操作契機
更新対象のテンプレート行を編集して保存したとき。更新者と更新日時もあわせて更新する
