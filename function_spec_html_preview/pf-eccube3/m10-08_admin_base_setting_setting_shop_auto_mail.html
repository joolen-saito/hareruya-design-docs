店舗設定 — 自動送信メールテンプレート編集（pf-eccube3 + HareruyaEc）

業務ロジック

対象のテンプレート

場面対象
識別子を指定して開いたとき識別子が一致し、かつ自動送信メールに該当するテンプレートを対象とする
識別子が自動送信メールに該当しないとき、該当するテンプレートが無いとき見つからない扱い（404）とする

テンプレ選択の選択肢は、テンプレ名称の昇順で並べる。

最終更新者・最終更新日の表示

項目表示のふるまい
最終更新者対象のテンプレートに更新者が記録されているときだけ表示する。記録された管理者が削除済みでも名称を表示する
最終更新日記録された日時が2018年より後のときだけ、年月日と時分秒まで表示する

本文の表示

選択したテンプレートの本文を表示し、本文中の定められた位置に本文上部・本文下部の入力欄を埋め込む。本文のうち入力欄以外は編集できない。本文中の差込み項目は、値に置き換えずに記述のまま表示する。

入力内容の検証に外れて同じ画面を再表示するときは、本文上部・本文下部の入力欄に保存済みの内容を表示する（登録しようとした入力内容は残らない）。テンプレ名称・件名には登録しようとした入力内容を表示する。

保存の判定順序

順序判定・処理内容
1なりすまし対策トークン不正なときは保存せず、アクセス拒否とする
2入力内容の検証外れたときは保存せず、同じ画面を再表示して項目ごとにエラーを表示する。成功メッセージは表示しない
3保存最終更新者にログイン中の管理者を、最終更新日に現在日時を設定して保存する
4遷移同じテンプレートの編集表示へ戻る

入出力

種類内容
入力対象のテンプレートの識別子（指定しないこともできる）
成功時出力同じテンプレートの編集表示への遷移と、保存成功のメッセージ
失敗時出力同じ画面の再表示と項目ごとのエラー、見つからない扱い（404）、またはアクセス拒否

入出力: 永続化

操作契機
更新対象のテンプレートを編集して保存したとき。最終更新者と最終更新日もあわせて更新する
