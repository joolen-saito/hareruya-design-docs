デッキ管理 — 新規登録・編集・削除・複製

業務ロジック

画面の表示

開き方表示内容
新規登録空のデッキを対象に入力欄を表示する。イベント検索・カード検索の補助入力を添える
複製入力指定された既存デッキの内容を読み込んで表示する。画面上は新規登録と同じ扱いで、保存すると新規のデッキとして登録する
編集指定されたデッキを読み込んで表示する。該当するデッキが無いときはページが見つからない扱い（404）とする

プレイヤーとイベント詳細は、識別子が設定されていれば対応する表示名・日時を項目へ補う。代表カードの画像は、代表カードが設定されていれば解決した画像を表示する。削除・複製の確認モーダルは、既存デッキを開いたときだけ表示する。一覧へ戻る際のページ番号は、保持している値（既定 1）を用いる。

デッキリストの解釈順序

メイン・サイド・コマンドの各テキストを、次の順序で解釈する。

順序判定結果
1テキストが空または空白のみ空のリストとして扱う。エラーにはしない
2空でない各行が「数量 カード名」の形式に合うか合わない行があれば、1 から数えたその行番号を返し、行番号を含むエラーを表示して登録を中止する
3カード名を正規化したうえで、カードに一致するか、不明参照として許可された文字列かいずれにも当たらない名前は登録しない。管理画面では不明参照として許可された文字列だけを残せる
4同じリスト内に同じカードが複数ある枚数を合算して1件にまとめる

登録・更新

デッキリストの解釈に失敗したとき、または入力値の検証に通らないときは、同じ画面を再表示して終える（画面遷移しない）。

検証に通ったときは次を行う。プレイヤーが入力されていれば当該プレイヤーへ紐付け直す。編集者としてログイン中の管理者を記録する。代表カードは、新規登録のときに限り、指定があれば名前を解決して設定し、指定が無ければ選択中のアーキタイプの既定の代表カード画像を設定する。

デッキを保存したうえで、当該デッキのカードをすべて削除し、解釈済みのリストからメイン・サイド・コマンドごとに作り直す。

保存後、「現行フォーマット」が真でフォーマットが設定されているときは、リストの整合とフォーマットの制限を検査する。問題があればボード単位で警告を表示する。この検査はエラーとせず、保存は完了したままとする。完了後は当該デッキの編集画面へ移る。

本機能では金額・ポイントの算出を行わない。フォーマットの警告は、ボードごとの最小・最大枚数、サイドとの合算、カードの使用可否の情報にもとづく。検出の順序は内部の実装順に依存するが、画面上は警告のみで保存は済んでいる。

複製

複製する回数が整数で、かつ 1 以上、設定の上限（既定値 310）以下でなければ、エラーを表示して元の編集画面へ戻る。複製元のデッキを取得できないときも保存失敗を表示して戻る。この経路では入力の共通検証を経由しない。

条件を満たすときは指定回数だけデッキを複製する。複製したデッキは記事の紐付けを空にし、編集者を操作者に更新する。複製元の各デッキカードも複製して、複製したデッキへ付け替える。完了時は複製した回数を含む完了メッセージを表示し、元の編集画面へ戻る。

削除

なりすまし対策トークンを検証する。対象のデッキを取得できないときはページが見つからない扱い（404）とする。当該デッキに紐づく記事が1件以上あるときは削除せず、使用中である旨を表示して直前の画面へ戻る。

削除するときは、デッキカードをすべて削除し、編集者を操作者に更新したうえでデッキ自体を削除する。削除後は、保持しているページ番号があればデッキ検索のそのページへ、無ければデッキ一覧へ戻る。削除対象の指定がまったく無いときは、メッセージを出さず一覧相当へ戻る。

エラー時の扱い

エラー内容処理
デッキリストの行形式が不正入力を保持したまま同じ画面を再表示し、行番号とボード名を含む文言を表示する
削除時のなりすまし対策トークンが無効アクセスを拒否する（共通の処理に委ねる）
記事に使用中で削除できないエラーを表示し、直前の画面へ戻る
複製回数が不正エラーを表示し、編集画面へ戻る

入出力

種類内容
入力デッキの入力項目（メイン・サイド・コマンドの各テキスト、プレイヤー、イベント詳細、代表カード、フォーマットなど）、複製する回数、削除対象のデッキ、なりすまし対策トークン
成功時出力デッキの登録・更新・複製・削除、完了メッセージ、編集画面または一覧への移動
失敗時出力同じ画面の再表示、またはエラー・警告メッセージを伴う戻り

入出力: 永続化

操作契機
追加・更新デッキの登録・更新が検証に通ったとき
削除・追加デッキの保存時に、当該デッキのカードを全件削除して解釈済みリストから作り直す
追加複製時に、指定回数分のデッキとそのデッキカードを作成する
削除デッキの削除時に、デッキカードとデッキ自体を削除する
