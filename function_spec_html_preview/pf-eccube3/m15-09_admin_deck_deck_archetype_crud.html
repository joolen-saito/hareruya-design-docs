デッキ管理 — アーキタイプ登録・編集・削除

業務ロジック

画面の初期表示

場面初期表示
新規登録のとき空の状態でフォームを開く。代表カードの画像と名称は空とする
編集で対象のアーキタイプがあるとき既存の値をフォームに載せ、代表カードの画像URLと名称を画面へ渡す
編集で対象のアーキタイプが無いとき見つからない扱い（HTTP404）とする

フォーマットの選択肢は、フォーマットの表示順の昇順で並べる。

保存の判定順序

順序判定・処理内容
1操作の有効期限期限が切れているときは保存しない
2代表カードの解決送信された代表カードの画像IDを解決できるときだけ、その画像を代表カードとして扱う。解決できないときは代表カードを未設定として扱い、エラーにはしない

代表カードの解決結果は、保存するときと、エラーで画面を再表示するときの双方に使う。

新規登録で保存できたときは、採番されたIDの編集画面へ戻る。編集で保存できたときは、同じIDの編集画面へ戻る。

削除の判定順序

順序判定・処理内容
1操作の有効期限期限が切れているときは削除しない
2対象の特定IDが不正なとき、または該当のアーキタイプが無いときは見つからない扱い（HTTP404）とする
3削除の可否当該アーキタイプに紐づくデッキが1件以上あるときは削除しない。エラーメッセージを表示し、アーキタイプ検索の1ページ目へ戻る
4削除紐づくデッキが0件のときだけ削除する。削除は論理削除とし、削除日時を設定する。物理削除は行わない

削除できたときの戻り先は、直前のアーキタイプ検索のページ番号があるときは当該ページの検索結果、無いときはアーキタイプ一覧とする。

登録デッキ数の数え方

場面数える対象
削除の可否の判定当該アーキタイプに紐づくデッキ。デッキ種別で絞らない
検索一覧の登録デッキ数デッキ種別がイベントのデッキだけ

代表カードの検索

代表カードは非同期の呼び出しで検索する。

呼び出しふるまい
検索語を送ったとき検索語と表示ページを保持し、1ページ目から表示する
ページを切り替えたとき保持した検索語で検索し、表示ページを更新する
非同期でない要求で呼び出したとき検索を行わず、結果とページ送りが空の一覧を返す
画像IDを指定して代表カードを確定するときカードの和英混合名と画像URLを返す
代表カードの確定で指定した画像IDが存在しないとき見つからない扱い（HTTP404）と空の応答を返す

エラー時の扱い

事象扱い
操作の有効期限が切れているとき保存・削除を行わず、アクセス拒否（HTTP403）に相当する扱いとする
編集・更新・削除で対象IDのアーキタイプが無いとき見つからない扱い（HTTP404）とする
紐づくデッキがあるアーキタイプを削除しようとしたとき削除せず、エラーメッセージを表示してアーキタイプ検索の1ページ目へ戻る

入出力

種類内容
成功時出力登録・編集・削除のときは画面の遷移（302）と完了メッセージ。代表カード検索のときは一覧の画面断片、代表カード確定のときはカード名と画像URL。
失敗時出力操作の有効期限が切れているときはアクセス拒否（HTTP403）、対象が無いときは見つからない扱い（HTTP404）。削除できないときはエラーメッセージ付きでアーキタイプ検索の1ページ目へ戻る。

入出力: 永続化

操作契機
追加アーキタイプを新規登録したとき
更新アーキタイプを編集して保存したとき
削除紐づくデッキが0件のアーキタイプを削除したとき。論理削除とし、削除日時を設定する
