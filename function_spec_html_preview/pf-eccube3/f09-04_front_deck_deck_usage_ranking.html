フロント デッキ検索 — 採用枚数ランキング

業務ロジック

対象フォーマットの特定

画面はフォーマットの識別子を伴って開く。識別子に一致するフォーマットが無いときはHTTP 404を返し、ランキングを表示しない。

採用枚数の集計

観点扱い
対象デッキデッキ種別が大会デッキ、かつ表示区分が公開で、画面が受け取ったフォーマットに一致するものだけを対象とする
集計期間の開始当日からフォーマットごとのメタ集計日数を引いた日の00:00:00
集計期間の終了当日の23:59:59
期間判定に使う日付大会の開催日
集計単位カード
集計値対象デッキでの採用枚数の合計。カード種別と特殊種別を結び付けると行が重複するため、その数の積で割って重複を相殺する。特殊種別が0件のときは1で割る
表示件数スペル・土地のそれぞれ上位18件
並び順採用枚数の降順、色の並び順の昇順、英語カード名の昇順

集計に用いるデータ

データ用途
採用カード採用枚数の合計を求める元にする
カード種別土地かどうかの判定と、集計値を割る数に用いる
特殊種別基本土地かどうかの判定と、集計値を割る数に用いる
フォーマットメタ集計日数と、基本土地を含めるかどうかの設定を持つ
デッキリストの公開状態集計の条件にしない。デッキリストが非公開でも数える

スペルと土地の振り分け

カード種別に土地を含むかどうかで振り分ける。土地のランキングは土地を含むカードだけ、スペルのランキングは土地を含まないカードだけを対象とする。1枚のカードが両方に載ることはない。

基本土地の扱い

フォーマットに基本土地を含める設定が無いときは、特殊種別が基本土地のカードを集計から除く。特殊種別を持たないカードは、この除外の対象にしない。

カード画像と商品への導線

各件にはカードの表側の画像を1枚載せる。選ぶ優先順は、特殊セットでないもの、プロモーションでないもの、カードセットの発売日が新しいもの、Foilでないもの、表示中の言語に一致するもの、カード詳細の識別子が小さいものとする。ランキングの各件は、そのカードの商品検索へ引き渡す入口を兼ねる。

エッジケース

ケース扱い
フォーマットの識別子が数字以外のとき入口の条件に合わないため画面へ到達しない
集計結果が0件のときそのランキングの区画には1件も並べない
集計値に小数が出るとき画面には小数点以下を丸めた整数の枚数で示す
カードの画像を選べなかったとき画像の代わりに読み込み中の画像のまま残す
上位18件目と同数のカードがあるとき並び順で先に来る18件までを載せる
カードが複数のカード種別を持つときその数で集計値を割る
カードが複数の特殊種別を持つときその数でも集計値を割る
カードが特殊種別を持たないとき特殊種別による割り算を行わない
基本土地を含める設定が有効のとき基本土地も集計に含める
集計期間に入る大会が1つも無いときどちらのランキングも0件になる
デッキリストが非公開のデッキがあるとき採用枚数に含めて数える
同じカードが複数のデッキにあるとき採用枚数を合計して1件として数える
デッキ種別がユーザーデッキのデッキがあるとき採用枚数に含めない
集計値が同じカードが並ぶとき色の並び順、次に英語カード名の昇順で先後を決める
基本土地を含める設定が無効のとき特殊種別が基本土地のカードを除く
カードの画像が言語ごとにあるとき言語の一致は5番目の優先順で、先に発売日とFoilの別で絞り込む
同じカードの組で別の言語のキャッシュがあるときキャッシュの鍵はカードの識別子だけなので、言語を判定し直さずキャッシュの内容を使う
