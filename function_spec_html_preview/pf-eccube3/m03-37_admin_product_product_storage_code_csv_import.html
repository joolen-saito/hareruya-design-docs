m03-37_admin_product_product_storage_code_csv_import（管理画面_商品管理_略称タグ更新CSV登録）

業務ロジック

取込画面

ファイル選択の欄となりすまし対策トークンだけを表示する。取込フォーマットのヘッダ定義をあわせて渡す。

取込の判定順序

順序判定違反時の扱い
1送信状態・なりすまし対策トークン・ファイル必須・ファイルの最大サイズ蓄積したエラーメッセージを表示し、一時ファイルの削除を試みて取込画面へ戻す
2アップロードファイルが有効で、サイズが0より大きいこと取込形式が不正である旨のエラーとし、取込画面へ戻す
3一時領域への保存と取込ファイルの解釈が成功すること同上
4ヘッダが、ID を除いたうえで「名称」「並び順」の順で期待と完全に一致することヘッダ形式のエラーとする
5データ行が1行以上あることデータが空である旨のエラーとする
6各行の列数がヘッダの列数と一致すること行番号を含む本文形式のエラーとする
7名称と並び順が空でないことラベルと行番号を含む必須項目のエラーとする
8同一ファイル内で並び順が重複しないこと行番号を含む並び順重複のエラーとする
9名称が一意であること（同一名称は同一IDの更新のときだけ認める）行番号を含む名称重複のエラーとする
10登録の確定失敗したときは登録内容をすべて取り消す

取込ファイルの読み方

先頭にBOMがあるときは除く。文字コードがUTF-8以外のときはUTF-8へ変換する。改行をLF系にそろえ、ゼロ幅文字とBOM相当の文字を除く。拡張子が tsv のときは区切り文字をタブとし、それ以外のときは設定の区切り文字（既定はカンマ）とする。囲み文字は設定に従う。1行目をヘッダとして扱う。

ヘッダの期待値は「ID」「名称」「並び順」の順とする。比較から除くのは ID だけである。ファイル側のヘッダからも ID を除いた残りが、期待側から ID を除いた残りと順序・内容とも完全に一致しなければならない。

行番号は、ヘッダを1行目としたときのデータ行の行番号とする。行末が空要素のときは1つ取り除く。

新規と更新の判定

ID列の値扱い
列が無いとき、空のとき、0のとき新規に登録する
正の整数で、その識別子の既存行が取れるときその行の名称と並び順を更新する
正の整数だが、該当する識別子が登録されていないとき新規に登録する（ファイル上の誤った識別子は新規作成になる。実装を確認値とする）

名称で既存行を検索し、既存行があり、かつID列から解釈した識別子が既存行の識別子と一致しないときは、名称重複のエラーとする。

上書きするのは名称と並び順だけとする。並び順は文字列として読み取ったのち整数に変換して保存する。アルファベット順ソートの区分は取込ファイルで読み書きしない。新規行は既定値（偽）とし、既存行の更新では当該列に触れないため、登録済みの現行値が保たれる。

100データ行ごとに登録内容を反映する。全行の処理後に反映し、確定する。

本機能では金額計算と締め日計算を行わない。

エラー時の扱い

事象扱い
入力が不正なとき、ファイル未選択のとき、サイズを超過したとき蓄積したエラーメッセージを表示し、一時ファイルの削除を試みて取込画面へ戻す
文字コード・解釈・一時領域に異常があるとき取込形式が不正である旨のエラーを表示する
ヘッダが一致しないときヘッダ形式のエラーを表示する
データ行が0行のときデータが空である旨のエラーを表示する
列数が一致しないとき行番号を含む本文形式のエラーを表示する
必須の項目が空のとき必須項目のエラーを表示する
並び順が同一ファイル内で重複するとき並び順重複のエラーを表示する
名称が他の識別子の行と衝突するとき名称重複のエラーを表示する
その他の例外が発生したとき登録内容を取り消し、例外のメッセージを表示する

いずれのエラーでも一時ファイルの削除を試み、取込画面へ戻す。

入出力

種類内容
入力アップロードファイル、なりすまし対策トークン。ファイルは期待ヘッダとデータ行を持つ
成功時出力取込画面への遷移と、登録が完了した旨のメッセージ
失敗時出力取込画面への遷移と、エラーの文言

入出力: 永続化

操作契機
追加ID列が無効なとき、または該当する識別子が無いときの、略称タグの新規登録
更新ID列で既存行が取れたときの、名称と並び順の上書き
