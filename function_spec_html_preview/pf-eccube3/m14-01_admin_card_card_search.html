カード管理 — カード検索（一覧・条件抽出）

業務ロジック

初期表示

保持している検索条件・ページ番号・表示件数を破棄し、空の検索フォームで表示する。一覧は表示しない。

検索条件

画面上の項目検索条件
複合キーワード語ごとに、和文名・英文名・和文ルールテキスト・英文ルールテキストのいずれかへの部分一致。語どうしはAND
タイプ選んだ識別子のいずれかに一致
サブタイプ選んだ識別子のいずれかに一致
特殊選んだ識別子のいずれかに一致
セット選んだ識別子のいずれかに一致
レアリティ選んだ識別子のいずれかに一致
レイアウト選んだ識別子のいずれかに一致
イラスト選んだ識別子のいずれかに一致
プロモ選んだ識別子のいずれかに一致
色選んだ色ごとに要求し、複数色を選んだときはAND
マナコスト（下限）マナコストが下限以上
マナコスト（上限）マナコストが上限以下
フォーマット選んだフォーマットの紐付けのうち、制限区分がリーガルまたは制限の行に限る
合法性チェック選んだときは、フォーマットの条件に禁止の行も許容する

条件は、複合キーワード、各区分の選択、色、マナコストの下限、マナコストの上限、フォーマットの順に積む。異なる区分どうしはANDとする。値が空・未選択の条件は付けない。

並び順と表示件数

項目決め方
ソートキー要求の指定があればそれを用い、無いときは保持している値、それも無いときは既定のソートキーとする
既定のソートキーカードの識別子で並べる
並び順要求の指定があればそれを用い、無いときは保持している値、それも無いときは降順とする
表示件数保持している値があればそれを用い、無いときは設定の既定値とする。要求された値が表示件数マスタの値と一致するときだけ採用して保持する

並び順の指定が昇順・降順のいずれでもないときは、エラーを表示して初期表示へ戻す。

検索の成立条件

検索条件を受け取れないときは、保持している検索条件から復元する。保持している検索条件も欠けるときは初期表示に戻す。

件数を数え直した結果、最終行の削除などで現在ページが空になるときは、ページ番号を1つ減らして取得する。

エラー時の扱い

エラー内容処理
並び順の指定が昇順・降順のいずれでもない並び順が不正である旨のエラーを表示し、初期表示と同じ状態の一覧へ戻す
該当が0件該当なしの見出しを表示する

入出力

種類内容
入力検索条件、ページ番号、表示件数、ソートキーと並び順
成功時出力検索結果の一覧。該当が0件のときは該当なしの見出し
失敗時出力並び順が不正なときはエラーを表示し、初期状態の一覧を表示する

画面へ渡すのは、検索フォーム、検索結果の一覧、表示件数の選択肢、ソートキーの一覧、現在のページ番号と並び順である。

本機能は参照だけを行い、検索した内容をデータとして登録・更新しない。検索条件は画面をまたいで保持する。
