CSV出力項目設定（店舗設定）

概要

管理画面の「店舗設定」配下で、各種CSV（商品・会員・受注・配送・カテゴリなど）のエクスポート時に出力する列の集合と順序を、dtb_csv上の有効フラグと並び順で管理する機能である。画面上は2つのリストボックスで「出力しない項目」と「出力する項目」を振り分け、右側の一覧内で順序を変更してから一括保存する。

本書は実装手順ではなく、誰が・いつ・どの条件で・結果どうなるかを読むためのリバース詳細設計とする。対象はブラウザ経由の管理画面に限定する。

カスタマイズ区分は現行踏襲であり、挙動の参照リポはpf-eccube3とする。DB関連の記述（テーブル名・列名・型・制約、保存先・扱い、副作用のDB更新）はec-cube-enterpriseを正とする。現行と移行先でスキーマが異なる箇所は「リニューアル移行時の扱い」に集約し、列名は移行先名を主として現行名を括弧で添える。

本書では Symfony のルート名、URL パス、コントローラクラス名は扱わない。

本書で扱うこと

  • 当画面の表示要素（CSV種別セレクト、二列のマルチセレクト、移動・並べ替えボタン、保存ボタン）
  • 保存時に更新されるDB列と、並びおよび有効／無効の解釈
  • CSV種別が存在しないときのエラー扱い
  • 管理画面の認証・権限・IP制限の枠組み（当画面も同一ルールの対象であること）
  • 表示前後と保存完了時にディスパッチされるイベント（プラグインがフォームや処理へ差し込む境界）
  • 各種管理画面から当画面への導線（リンク文言の対応）

本書で扱わないこと

以下は本書では仕様確定せず、実装または別機能の設計を正とする。

  • 管理画面ログイン、セッション、CSRF検証がフレームワーク全体でどの段階で行われるかの詳細（当コントローラはSymfony FormのhandleRequest／isValidを呼ばずリクエストパラメータを直接読む確認値がある）
  • dtb_csv行の新規追加・削除、列定義（エンティティ名・フィールド名・参照フィールド名・表示名）そのものの編集（マスタデータ投入・プラグイン・マイグレーション等を正とする）
  • 各一覧画面でCSVファイルを生成する処理の詳細（抽出条件、文字コード、ファイル名、CsvExportServiceによるセル値の組み立て）
  • プラグインがイベントで差し替えた画面・別コントローラ（同一URLでも実体が差し替わる場合がある）の完全列挙

リニューアル移行時の扱い

現行（pf-eccube3）と移行先（ec-cube-enterprise）で、CSV出力項目の永続化スキーマが異なる。並び順キーと有効フラグの列名が改名され、補助列が追加されている。挙動説明（左右リストの振り分け・採番）は現行を確認値とし、DB記述は移行先を主とする。

処理フロー

画面を開く（GET）

  1. 管理画面の認証・IP制限・権限拒否の各ルールを通過する。
  2. リクエストから渡された数値をCSV種別IDとみなし、mtb_csv_typeから取得する。存在しなければNotFoundとする。
  3. 当該種別に紐づくdtb_csvのうち、無効な行をrank昇順で取得し、左リストの選択肢とする。有効な行も同様に右リストとする。
  4. フォームビルダにCSV種別セレクト（初期データは取得した種別）、左右のエンティティ型マルチセレクトを追加する。
  5. 表示初期化イベントをディスパッチし、ビルダや出力リストに対するプラグイン処理を許す。
  6. フォームのビューをテンプレートへ渡し描画する。

「設定」押下（POST）

  1. 認証等の共通ルールを通過したうえで、リクエストボディのform配列を読む。Symfony Formのバインド処理は当処理では行わない確認値がある。
  2. form['csv_not_output']キーが存在すれば、その配列の順に各行IDを読み、dtb_csvから行を取得してrankを1から採番し、enable_flgを無効にする。
  3. form['csv_output']キーが存在すれば、同様に有効採番する。配列の順序が右リストの上から下への順に対応する。
  4. ORMのflushを一度呼ぶ。
  5. 保存完了イベントをディスパッチする。イベント引数にはリクエスト処理開始時に構築したフォームオブジェクトと、初期表示時点の有効行コレクション参照などが載る確認値がある。
  6. 管理画面向け成功メッセージを積み、同一機能の同じ種別の画面へリダイレクトする。

CSV種別セレクト変更（GET、ブラウザ遷移）

  1. クライアントが別種別IDで当機能へ遷移する。
  2. 「画面を開く（GET）」と同様に読み込む。

有効行とCSVエクスポートの対応

別機能のCSVエクスポート処理は、種別指定後にenable_flgが有効なdtb_csvだけをrank昇順で読み、ヘッダ行は各disp_name、データ行は定義に応じたセル値を出力する。当画面で無効にした列はエクスポート結果に現れない。
