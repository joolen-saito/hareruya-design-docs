M03-31（セール用価格変更CSV登録）

業務ロジック

アップロード画面を表示する

  1. 利用者がアップロード画面を開く。
  2. CSVインポートフォームを生成し、フォーマット表のヘッダ定義を組み立てる。
  3. 直近の取込履歴を読み、画面を表示する。

CSVをアップロードして取込する

  1. 利用者がCSVを選択してアップロードボタンを押下する。
  2. タイムアウトを無効化する。
  3. フォーム検証（ファイル必須・サイズ上限・CSVのMIME）を行う。不合格ならエラーを設定し、同じ画面を再表示する。
  4. CSVの行数を数え、上限（5010行）以上なら上限超過エラーを設定し、同じ画面を再表示する。
  5. 取込処理を開始する。ファイルを一時保存し、文字コードと改行を正規化する。
  6. ヘッダ行が無い、または2行目以降にデータが無い場合は、それぞれフォーマットエラー・データなしエラーとして取込を中止する。
  7. データベースのトランザクションを開始し、1行ずつ次の順序で処理する。
  • 行検証（必須・形式・商品の存在・販売価格と買取価格の大小）。商品が存在しない場合などは取込全体を中止する。
  • 行取込（商品タグの全削除・再登録、対象規格の販売価格・買取価格・セールフラグ・帯URLの更新、価格に変更があれば価格履歴の記録）。
  1. エラーが無ければトランザクションを確定し、エラーがあればロールバックする。
  2. 取込が成功した場合、支店システムへ取込対象の商品更新を通知する。
  3. 取込成功時は成功フラッシュを設定し、取込履歴へファイル名を記録する。失敗時は履歴を記録しない。
  4. 取込結果（エラー一覧・成功フラグ）と取込履歴を載せて、同じ画面を表示する。

エラー時の扱い

利用者向けの表示文言は「表示メッセージ」を正とする。本節は処理方針を記載する。

エラー内容処理
ファイル未選択・サイズ超過・MIME不一致フォーム検証エラーを設定し、取込せず同じ画面を再表示する。
行数上限超過上限超過エラーを設定し、取込せず再表示する。
ヘッダ不一致・データなしフォーマットエラー・データなしエラーとして取込を中止する。
必須未入力・形式不正の行当該行のエラーを記録する。
販売価格より買取価格が大きい行当該行のエラーを記録する。
商品IDが存在しない行当該行のエラーを記録し、取込全体を中止しロールバックする。

入出力

種類内容
入力フォーム名admin_csv_importのimport_file（CSVまたはTSV）、CSRFトークン。

失敗時出力フォーム検証・行数上限・行検証の各エラーを画面に表示し、取込を確定しない。
