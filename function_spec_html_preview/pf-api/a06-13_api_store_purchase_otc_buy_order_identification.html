API 店頭買取管理 — 本人確認更新

業務ロジック

更新の判定順序

順序判定結果
1トークンを検証して管理者会員を特定できるか特定できないときは認証拒否（HTTP 401）とする
2パスの受注IDで店頭買取受注を取得できるか取得できないときは該当なし（HTTP 404）とする
3証明書IDが本人確認証明書マスタに存在するか存在しないときは入力不正（HTTP 400）とし、エラーメッセージを返す
4上記をすべて通過したとき本人確認証明書を設定して保存し、処理結果コード200を返す

呼び出し可能なクライアントは買取アプリである。トークンの署名方式はHS256とする。トークン原値・署名シークレットは本書に記載しない。

更新する内容

店頭買取受注に本人確認証明書を設定し、更新担当者に認証した管理者会員を、更新日時に現在時刻を設定する。更新できたときは処理結果コード200だけを返す。金額・税・ポイント・在庫数量の再計算や丸めは行わない。応答は保存結果を整形して返し、本API内で独自に集計しない。

エラー時の扱い

エラー内容処理
認証できないとき認証拒否（HTTP 401）とする
受注が存在しないとき該当なし（HTTP 404）とする
証明書IDが不正なとき入力不正（HTTP 400）とし、「正しい証明書IDを入力してください」を返す

入出力

種類内容
入力店頭買取受注ID、本人確認証明書のID、認証用トークン。証明書IDは必須で、未指定のときは入力不正となる
成功時出力更新できたときはHTTP 200。処理結果コード200
失敗時出力認証拒否（HTTP 401）、該当なし（HTTP 404）、入力不正（HTTP 400）

入力: リクエスト

パラメータ位置型必須／任意説明
idパスinteger必須更新対象の店頭買取受注ID
identificationボディ（フォーム値）integer必須設定する本人確認証明書のID。本人確認証明書マスタに存在しない値のときは入力不正（HTTP 400）となる
jwt-tokenヘッダstring必須認証用のトークン

出力: レスポンス

フィールド型説明
codeinteger処理結果コード。成功したときは200
HTTPステータス条件本文の形
401トークン欠落・署名不正・該当する管理者会員なしのとき認証拒否（本文を持たない）
404受注IDに該当する店頭買取受注が無いとき該当なし（本文を持たない）
400証明書IDが本人確認証明書マスタに存在しないとき（未指定を含む）{code, errors}（errorsは「正しい証明書IDを入力してください」）

入出力: 永続化

操作契機
更新本人確認更新（本人確認証明書・更新担当者・更新日時）
