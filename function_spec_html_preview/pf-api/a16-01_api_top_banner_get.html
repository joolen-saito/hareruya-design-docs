API データ管理 — トップバナーIDのトップバナー情報を取得

概要

トップバナーIDを指定してトップバナー情報を取得するAPIである。pf-apiが提供するJSON APIである。TODOリストの「コンテンツ管理」（A08-01）と「データ管理」（A16-01）の同一エンドポイントをまとめる。

本書は実装手順ではなく、誰が・いつ・どの条件で・結果どうなるかを読むためのリバース詳細設計とする。確認値はpf-apiのトップバナー取得処理、ルート定義、トップバナーマスタを扱うリポジトリを正とする。本機能のカスタマイズ区分は現行踏襲であり、挙動はpf-apiの実装を参照し、DB関連（テーブル・列）の記述はec-cube-enterpriseを正とする。

対象はJSON APIエンドポイントであり、ブラウザ向けの画面を持たない。

本書で扱うこと

  • トップバナーIDによるトップバナー情報の取得
  • 該当が無い場合の応答

本書で扱わないこと

以下は本書では仕様確定せず、実装または別機能の設計を正とする。

  • 指定言語のトップバナー一覧取得（一覧取得APIを正とする）
  • トップバナーの設定・管理（トップバナー管理を正とする）

リニューアル移行時の扱い

本機能は現行踏襲であり、挙動の参照は現行のpf-api、DB関連の正はec-cube-enterpriseとする。テーブル名・列名は現行と移行先で一致する。移行先ではトップバナーマスタに表示用の追加列があるが、本APIの応答項目（ID・画像URL・リンク・表示タイプ・関連言語）には影響しない。

応答形式はJSON。

処理フロー

トップバナー情報を取得する（GET /topBanner/{id}）

  1. パスのトップバナーIDを受け取る。
  2. トップバナーマスタのリポジトリから当該IDのトップバナーを取得する。
  3. 取得できない場合はコード404のJSONを返す。
  4. 取得できた場合はトップバナー情報をJSONで返す。
