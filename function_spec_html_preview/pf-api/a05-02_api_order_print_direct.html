API 受注管理 — 注文印刷（印刷済み更新）

業務ロジック

接続種別が想定値に一致しないとき

接続種別が印刷情報の要求・印刷結果の応答のいずれとも一致しない値のときは、処理を行わず、応答そのものを組み立てない。

印刷済みステータスへの更新

印刷結果の要素ごとに、印刷ジョブIDのうち区切り記号「_」より前の部分を受注IDとして扱い、対象受注を特定する。

対象受注の状態更新内容
ブラウザ印刷フラグが立っているときフラグを倒すだけに留め、対応状況は変えない
ブラウザ印刷フラグが立っていないとき対応状況をピック中へ更新し、注文確定日に現在日時を設定する

更新は受注1件ごとに確定する。後続の要素で受注が見つからなくても、それまでに更新した受注は元に戻らない。

金額・在庫の再計算

金額・税・ポイント・在庫数量の再計算と丸めは行わない。

エラー時の扱い

事象扱い
印刷結果XMLの解析に失敗したとき更新を行わずに戻る
印刷結果要素が1件も無いとき更新を行わずに戻る
印刷ジョブIDに対応する受注が見つからないときその要素を除き、次の要素へ進む
受注の取得・更新の途中で例外が起きたとき共通例外処理に委ねる（HTTP500相当）

入出力

入出力: 要求と応答

種類内容
入力接続種別は、クエリのほかボディからも受け取る。印刷結果XMLはPOSTのボディからのみ読み取り、クエリに同名の値があっても用いない
成功時出力応答の Content-Type は text/xml; charset=utf-8

入出力: 永続化

操作契機
更新ブラウザ印刷フラグが立っていない受注は、対応状況をピック中へ、注文確定日を現在日時へ設定する
更新ブラウザ印刷フラグが立っている受注は、そのフラグを倒す
