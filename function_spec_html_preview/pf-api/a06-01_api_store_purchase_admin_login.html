失敗したときの応答本文

事象応答
中継先が認証情報を返さない（認証失敗）処理結果コードとメッセージの2項目を返す。メッセージは中継先のログイン画面に出る理由文言をそのまま用い、改行表記を取り除いたもの。本API独自の文言は設けない
中継先へ到達できない到達の成否を判定しない。中継先の応答が得られないときも、認証情報が返らないときと同じ扱いになる

トークンの発行と以降の利用

発行されるトークンは、発行者と利用者ID（認証した管理者会員のID）を持つ。以降の各APIは受け取ったトークンの利用者IDから管理者会員を引いて認可し、会員を引けないときは認可しない。

トークン原値・署名シークレット・パスワードは本書に記載しない。

入出力

店舗が紐づかない会員のとき

認証した会員に店舗が紐づかない場合、店舗名・店舗住所は空文字を返す。
