API ネット買取管理 — 複数ネット買取IDからネット買取受注の商品一覧を取得

業務ロジック

取得する対象

指定されたネット買取受注IDリストをカンマで分解し、当該買取受注IDに紐づく買取代表カードの一覧を取得する。該当0件のときは空配列を返す。

申込時買取価格の付与

取得した買取代表カードの代表カードIDに紐づく申込時買取価格を引き当て、カード状態コードをキーとする申込時買取価格として各買取代表カードに付与する。一致する申込時価格が無い代表カードには付与しない。

金額・税・ポイント・在庫数量の再計算は行わない。取得した値をそのまま応答へ整形して返す。

エラー時の扱い

エラー内容処理
認証不可認証拒否（HTTP 401）とする
該当0件エラーとせず空配列を返す
取得処理中の例外処理失敗（HTTP 500）として共通例外処理に委ねる

入出力

種類内容
入力ネット買取受注IDリスト、認証トークン
成功時出力HTTP 200。申込時買取価格を付与した買取代表カードの配列
失敗時出力HTTP 401（認証不可）、HTTP 500（取得処理中の例外）

入力: リクエスト

パラメータ位置型必須／任意説明
idsボディstring任意カンマ区切りのネット買取受注IDリスト。未指定・空文字のときは空文字を分解した配列で検索するため、結果は0件となる
jwt-tokenヘッダstring必須認証用のトークン

出力: レスポンス（成功）

フィールド型説明
（ルート）array買取代表カードの配列。0件のときは空配列
[].buyMainCardIdinteger買取代表カードID
[].buyOrderIdintegerネット買取受注ID
[].productIdinteger商品ID
[].languageIdinteger言語ID。未設定のときはnull
[].foilFlgbooleanフォイルか否か。未設定のときはnull
[].countinteger枚数。未設定のときはnull
[].priceinteger査定金額。未設定のときはnull
[].cardConditionIdintegerカード状態ID。未設定のときはnull
[].saleFlgboolean売却フラグ。未設定のときはnull
[].purchaseCategoryinteger買取カテゴリ
[].applicationPriceobjectカード状態コードをキーとするオブジェクト。値は当該状態の申込時買取価格

出力: レスポンス（失敗）

HTTPステータス条件本文の形
