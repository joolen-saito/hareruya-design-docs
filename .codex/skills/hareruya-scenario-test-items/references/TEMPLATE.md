# シナリオテスト項目書テンプレート

## ファイルパス

- `scenario_test/test_items/STI-<SCN-ID>.md`
- 元シナリオは `scenario_test/scenario/SCN-*.md`

## 冒頭概要

各 Markdown は次の情報を含める。

- 元シナリオへの相対リンク
- 業務、業務フローキー、主アクター、関連システム
- 期待結果は試験で観測可能な結果で判定する旨
- TSV は 10 列固定で、Excel/Googleスプレッドシートへ貼り付け可能である旨

## TSV 列構成

```text
シナリオID	テストID	フロー種別	テスト観点	優先度	テスト項目名	前提条件	入力データ/対象	操作手順/実行方法	期待結果
```

| 列 | 記載元 |
|---|---|
| シナリオID | 元シナリオの `SCN-*` |
| テストID | `STI-<SCN-ID-suffix>-NNN` |
| フロー種別 | `正常系` / `代替系` / `異常系` |
| テスト観点 | 操作、データ更新、CSV/帳票、メール/通知、外部連携、権限、バリデーション等 |
| 優先度 | 元シナリオの優先度。代替/異常系は原則 P1/P2 |
| テスト項目名 | その行で何を判定するかが分かる一文 |
| 前提条件 | ログイン、シードデータ、事前状態 |
| 入力データ/対象 | 固定IDや分岐条件 |
| 操作手順/実行方法 | 人間が実行できる手順 |
| 期待結果 | 1行1判定の観測可能な結果 |

## テストケースTSV

````markdown
## テスト項目TSV

以下はタブ区切りで、Excel/Googleスプレッドシートへはコードフェンス内を A1 に貼り付ける。

**1行目**が列見出し、**2行目以降**がテスト項目。各行は10列固定。

前提条件・入力データ・操作手順などで複数項目がある場合は、同一セル内でLF改行してよい。

**期待結果は1行1判定**とする。複数の期待がある場合は行を分割する。

```tsv
シナリオID	テストID	フロー種別	テスト観点	優先度	テスト項目名	前提条件	入力データ/対象	操作手順/実行方法	期待結果
SCN-...	STI-...-001	正常系	データ更新	P1	...
```
````
