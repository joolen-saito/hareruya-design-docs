# メッセージ一覧 TSV テンプレート

## 列定義（9列＋補助2列）

| 列 | 内容 | 決定的に埋まるか | 例 |
|----|------|------------------|----|
| メッセージID | 機能ID接頭の安定連番。未割当は `EE-<area>` | ✅ | `M04-31-MSG-008` / `EE-JS-MSG-020` |
| 画面 | 機能名（設計書タイトル）。未割当は controller/テンプレ由来の暫定名 | 一部 | `m04-31 M04-31（棚卸計画）` |
| 要素 | メッセージを誘発する **操作要素**（ボタン/リンク/フォーム送信） | ❌ codex | `登録ボタン` |
| トリガー（条件） | 発火条件（成功時/例外時/権限無し/CSRF不一致 等） | ❌ codex | `棚卸数量を保存し正常終了したとき` |
| 種別 | インフォ(成功)/インフォ/警告/エラー/エラー(バリデーション)/確認 | ✅ | `インフォ(成功)` |
| どこに | 表示位置（管理画面上部/入力項目直下/画面中央ダイアログ 等） | ✅ | `管理画面上部` |
| 要素(表示) | 表示コンポーネント（フラッシュメッセージ/フォームバリデーション/確認ダイアログ） | ✅ | `フラッシュメッセージ` |
| メッセージ内容 | 実際に表示される文言（ロケール解決済み。可変部は `%x%` `{x}`） | ✅(解決済) / ❌(変数) | `棚卸数量を登録しました。` |
| 後続処理 | 表示後の挙動（一覧へリダイレクト/画面にとどまる/該当処理中止 等） | ❌ codex | `一覧へリダイレクトする` |
| 根拠(file:line) | 抽出元の実ソース位置 | ✅ | `.../StockInventoryController.php:145` |
| 解決状態 | key/literal_ja/variable/other/key_unknown、未解決は `UNRESOLVED/...` | ✅ | `key` |

## メッセージIDの体系

```
<機能ID(大文字・ハイフン)>-MSG-<3桁連番>     例: M04-31-MSG-001, F06-14-MSG-003
EE-<エリア>-MSG-<3桁連番>                    未割当（機能未特定）: EE-JS-MSG-020, EE-ADMIN-MSG-170
```

- 連番は `根拠(file:line)` の昇順で安定採番（再生成で不変）。
- codex が JS 行を機能へ紐付けたら、`EE-JS-*` から `<機能ID>-MSG-*` へ再採番してよい（要 validate 再実行）。

## 埋め込み表フォーマット（機能doc）

既存の『表示メッセージ』表の **先頭に `メッセージID` 列** を追加する。対象外（静的ラベル等、
本一覧のスコープ外）の行は `—`。一覧にあって表に無いメッセージは codex が新規行として追記する。

```
| メッセージID | 表示位置 | 画面上の文言 | 表示条件 |
|--------------|----------|--------------|----------|
| M04-31-MSG-008 | 画面上部フラッシュ | 登録が完了しました。 | 棚卸数量の保存が成功したとき |
| — | 見出し | 棚卸計画 | 画面表示時（静的ラベル・本一覧対象外） |
```
