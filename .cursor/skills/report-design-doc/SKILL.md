# 帳票設計スキル

## 前提

- 常に `.cursor/design/基本設計方針.md` を正とする。
- 帳票一覧は全体管理、帳票設計書は帳票別に作成する。
- 帳票出力の業務操作は機能仕様書に書き、帳票固有のレイアウト・項目・出力条件は帳票設計書へ寄せる。

## 出力先

- 帳票一覧: `.cursor/design/帳票/帳票一覧.md`
- 帳票設計書: `.cursor/design/帳票/<帳票名>/`

## 帳票一覧の観点

- 帳票ID
- 帳票名
- 出力契機
- 利用者
- 関連機能
- 関連データ
- 出力形式

## 帳票設計書の観点

- 帳票の目的
- 出力条件
- レイアウト
- ヘッダー、明細、フッター
- 項目定義
- データ取得元
- 加工・集計ルール
- ソート順
- 改ページ
- 出力不可時、データ欠損時の扱い

## 注意

- 機能仕様書と帳票設計書で同じ帳票項目を二重管理しない。
- DB項目やAPI項目を参照する場合は、正本側の名称と整合させる。
- 帳票レイアウトの見た目と、出力可否の業務判定を混同しない。
- 未確定事項は `TODO` に残す。
