# アプリケーション基本設計書スキル

## 前提

- アプリケーション基本設計書は個別設計書を束ねる全体設計として扱う。
- 画面、API、DB、帳票などの細部を重複記載しない。

## 出力先

- `.cursor/design/`

## 記載観点

- アプリケーションの全体構成
- フロントエンド、バックエンド、DB、外部IFの責務分担
- 主要コンポーネント
- 画面/API/DB/外部IFの接続方針
- 認証・認可の横断方針
- ログ、エラー、状態管理の横断方針
- 主要な設計書への参照一覧

## 注意

- 個別機能の判定条件や業務ロジックは機能仕様書へ委ねる。
- API契約はOpenAPIへ委ねる。
- DB物理定義はDB設計へ委ねる。
- 帳票固有の項目やレイアウトは帳票設計書へ委ねる。
- 未確定事項は `TODO` に残す。
