# 結合試験テストケース チェックリスト

作成・更新のあとに確認する。

## 入力とスコープ

- [ ] 元設計書の「扱うこと／扱わないこと」と試験範囲が一致している
- [ ] 別機能に委ねる部分を無理に試験ケース化していない
- [ ] 対象外観点を理由付きで記載した

## 用語と文体

- [ ] 文言が [TERMINOLOGY.md](TERMINOLOGY.md) に従っている。「保護画面」「業務画面」の総称など禁止語が無い。文字列長境界では「製品設定」等を使わず「最大長」で書く（同ファイル「文字列長・境界」）。試行制限の期待では「同一窓」「誤爆」を使わず平易に書く（同ファイル「試行制限・レートリミット」）
- [ ] 優先度列が `P1`／`P2`／`P3` のみであり、リスク基準（TERMINOLOGY.md）に整合している
- [ ] テスト項目名・前提・手順・期待結果に「または」を使っていない。複数パターンは操作手順を番号で分け、期待結果は**1行1判定**（各セルは観測・判定可能な一文）
- [ ] 期待結果に「設計書に記載のとおり」「設計どおり」や特定設計ファイル名を正とする記述がない（[TERMINOLOGY.md](TERMINOLOGY.md)「期待結果に書かないこと」）
- [ ] 翻訳キー・セッションキー・ルート名・DB物理名を書いていない（併記も不可）。論理名は `e2e/config/logical-names.tsv` から引いた（[TERMINOLOGY.md](TERMINOLOGY.md)「物理名を書かない」／[[logical-naming]]）
- [ ] `python3 .cursor/skills/logical-naming/scripts/audit_logical_naming.py --repo .` が `AUDIT OK` である

## テスト観点との列整合

- [ ] TSV の **I/FID** 列が `.cursor/docs/テスト観点.md` の **関連ID** と一致している（機能固有の `IF-xxx` を使っていない）
- [ ] TSV の **テスト観点** 列が、`.cursor/docs/テスト観点.md` の **観点** 列の文言と一致している（連携先の独自ラベル例「画面→DB」は使わない）
- [ ] 「関連ID対応概要」に本ケース群で使った関連IDを列挙している

## TSV 構造

- [ ] 1行目の列見出しが [TEMPLATE.md](TEMPLATE.md) の10列と一致し、先頭列が `機能名`、4列目が `テスト観点` である（`I/F種別`・`I/F ID`・`テストレベル` 列はない。旧列名 `観点` は使わない）
- [ ] 各データ行の `機能名` が元設計書のタイトルに相当する名称と一致し、全行で同一である
- [ ] データ行がすべてちょうど10列である。`format_tsv.py --check` が成功する
- [ ] `テストID` が重複していない

## Excel／スプレッドシート

- [ ] 複数手順・複数前提は**期待結果以外**の列（前提／入力／操作）のセル内で LF 改行している
- [ ] 期待結果列に複数手順や箇条書きの `・` 列挙を入れていない
- [ ] 改行や `"` を含むセルがダブルクォートで囲まれ、`"` は `""` にエスケープされている
- [ ] フェンス ` ```tsv ` から閉じまでをコピーして貼り付けられる状態である

## 期待結果の行分割

- [ ] 期待結果列は**1データ行1判定**（画面／HTTP／DB／遷移・独立UI要素・Cookie属性などは別行）
- [ ] 1セルに「ログインID欄・パスワード欄・送信ボタン・…」のように**複数コントロールの確認を並べていない**
- [ ] 行分割した同一シナリオで、前提・入力・操作が揃っている
- [ ] 「ログイン ID・パスワード」のような**名詞並立だけ**の1観測を誤って複数行に分割していない

## テスト項目名

- [ ] 各行のテスト項目名が、その行の期待結果と対応している
- [ ] 分割行に親ケースの複合名（「…し…すること」）をそのままコピーしていない
- [ ] テスト項目名が他行と重複していない（同一シナリオの分割を除き意図した重複がない）

## セキュリティ・監査

- [ ] パスワードやトークン原値を試験記載に書いていない
- [ ] 失敗時も画面上の秘匿方針と整合した期待を書いている

## 整形コマンド

- [ ] 必要なら `expand_expect_rows.py` で期待結果を行分割した
- [ ] 必要なら `refine_test_item_names.py` でテスト項目名を具体化した
- [ ] `format_tsv.py <ファイル>` を実行した
- [ ] `format_tsv.py <ファイル> --check` が成功した
- [ ] トレース表の証跡 ID が現行の `テストID` と整合している
