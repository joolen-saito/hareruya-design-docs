## 凡例(記法)
- **種別**: 手作業 / 判断 / データ-DB / 帳票-書類 / 定義済み処理(サブフロー) / 注釈(吹き出し) など prstGeom 由来。
- **フェーズ**: asis=現行 / Tobe=将来像（図形の区切りラベルで判定）。
- **実行主体(レーン)**: 図形ボックスの絶対座標(EMU)を最寄りのスイムレーン見出しへマップして推定。
- **遷移**: 業務フロー線(実線) / データ遷移線(点線) を区別。`*n` は同一レコード参照。
- ふりがな(rPh)は除去済み。
