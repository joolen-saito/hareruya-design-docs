# アクター一覧（業務シナリオ）

出典: `scenario_test/markdown/*.md` のスイムレーン見出し。シナリオの「主アクター／副アクター」はここから選ぶ。

## 人（業務アクター＝テストの実行ロール）
| アクター | 役割（在庫管理での主担当） | 主な担当業務フロー |
|---|---|---|
| お客様 | 注文・買取持込・イベント参加・デッキ入力の起点 | 店頭受取、通販、店頭/ネット買取、イベント受付 |
| 店舗チーム | 本店/支店の店頭・買取・イベント・在庫オペレーション | 店頭受取、店頭買取、イベント受付、ショーケース品出し |
| 顧客戦略チーム | 分析、デッキ登録、リコメンド等のデータ作成 | デッキ登録、分析、リコメンドファイル作成 |
| **トレードチーム** | 在庫の主管。移動・分割結合・棚卸・廃棄・振替の中心 | 2〜7 在庫移動、分割結合、棚卸(低額以外)、廃棄、振替、借用 |
| 通販チーム | 通販受注、出荷、返金、通販在庫の操作 | 通販受注、発送準備、発送実績、返金、安価カード補充の下流 |
| **商品管理チーム** | 物理在庫を販売可能状態にする部署 | 仕入れ、安価カード補充、低額棚卸(10-①)、成田倉庫関連 |
| 店舗統括チーム | 店舗横断の調整・配送準備 | 支店在庫移動の配送準備 等 |
| 支店 | 各支店の在庫受払 | 支店在庫移動、リコメンド配送、在庫調整 |

## システム（連携先＝期待結果の間接確認先。アクターではない）
| システム | 在庫管理での役割 |
|---|---|
| EC-CUBE（本店） | 受注、商品、在庫、買取、イベント、デッキ、会員の管理画面 |
| EC-CUBE（支店） | 支店側の受注・在庫・店頭受取管理 |
| スマレジ | 店頭POS。店頭受取決済、店頭商品在庫、イベント売上登録 |
| MTGバイヤー | 店頭/ネット買取の査定アプリ |
| SPLINKS | クレジットカード、コンビニ決済、イベント決済、返金処理 |
| デッキシステム | デッキ登録・検索・公開 |
| Wordpress | イベント・記事・バナー等の公開先 |
| ポイントグランター | イベント参加等のポイント付与 |

## 権限について
スタンドアロンの権限定義書は本リポジトリに無い。各画面の権限前提（編集権限・承認権限）は
`functions/ec-cube-enterprise/m04-*.md` の「扱わないこと／前提」記述と既存ケースのSEED前提に従う。
シナリオの異常系で「権限不足」を扱う場合はこの前提を起点にする。
