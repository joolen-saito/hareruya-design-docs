# 設計ギャップ差し戻しリスト（設計チーム向け）

業務フローに実在する工程だが、**それを実行する機能の設計書が存在しない**箇所の一覧。
機能設計書が「本書では扱わない」と明記している一方、その工程を扱う側の設計書が見つからない。
シナリオテストを作っても**テストが実行不能**になるため、シナリオ生成の前に設計側の確定が必要。

各項目について、次のいずれかを回答いただきたい。
- **(A) 別の設計書に仕様がある** → その機能No／設計書パスを教えてください（こちらでトレースします）
- **(B) 未設計** → 機能設計書を起こす必要があります（Ph1対象か、Ph2送りかも明記ください）
- **(C) 手作業/外部で行う前提** → EC-CUBEの機能ではないため、シナリオ側は「手作業/外部」として扱います

影響範囲: 8工程 / 21シナリオ。
