# 業務フロー補記依頼リスト（削除した異常/代替分岐の復活候補）

- 生成元: `generate_scenarios.py` の固定辞書 BUSINESS_EDGE_CASES / PATTERN_EDGE_CASES
  （`tools/build_flow_supplement_list.py` で抽出）
- 背景: これらの条件は業務フロー原典に無いのに異常/代替シナリオを生成しており、捏造ゼロのため除去した。
- 目的: 業務側が「フローに実在するか」を判断し、実在するものは**業務フロー markdown に分岐ステップを追記**して
  再生成すれば、原典由来の正当なシナリオとして復活する（＝方針B: 業務側補記で復活）。

## 業務側にお願いすること

各行の **判定** 列に記入してください（それ以外は記入不要）。

| 記入 | 意味 | その後の扱い |
|---|---|---|
| **実在** | この分岐は業務フローに実在する | 該当の業務フロー markdown（`scenario_test/markdown/*.md`）に分岐ステップを追記→再生成で復活 |
| **不要** | 実装/運用に存在しない | シナリオ化しない |
| **結合** | 機構的異常（権限/必須/重複/0件等）で結合テスト層(IT-*)が担保 | 本層では不要 |

補足: このリストは復活シナリオを作りません。復活は業務フロー原典への補記が前提です（捏造ゼロを保つため）。
