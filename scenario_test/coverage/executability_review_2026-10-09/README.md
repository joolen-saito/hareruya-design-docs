# シナリオテストの実施可能性検証（2026-10-09）

**現行のテストケース全件を、そのまま実施できるとは判定できません。** 業務フローとHTML設計書へ戻り、129シナリオ・1,552項目について、準備、担当者、画面への到達、操作、データの引き継ぎ、期待値を照合しました。手順・期待値に修正が必要なシナリオが101件、準備内容の具体化が必要なシナリオが22件あります。

今回の成果物は検証結果と未適用の修正案です。対象のシナリオ・テスト項目・補完契約は変更していません。実機操作は未実施のため、実行結果の合格件数はありません。

## 修正後に再確認すること

1. 誤画面・操作順・期待値・欠落工程を補正する。HTMLとフローが衝突するものは採用する業務手順を確定してから反映する。
2. 準備データをケースの数量・金額・状態・担当権限に合わせ、前工程と同じ実IDを保持する。独立して実施する項目には、その開始状態を再現する手順を用意する。
3. シナリオ、個別項目、配布TSVを再生成し、今回の各指摘について原典と再照合する。引用符を含む操作や期限種別など、生成処理による取りこぼしも確認する。
4. 仕様・外部資料・環境の未確認条件を解消し、代表経路、代替経路、保留解除した経路を実機で通す。前後の値・状態・証跡を保存して合否を判定する。
