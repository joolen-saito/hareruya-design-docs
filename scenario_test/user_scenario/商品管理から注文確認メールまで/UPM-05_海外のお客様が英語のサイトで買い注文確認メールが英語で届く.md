# UPM-05 海外のお客様が英語のサイトで買い、注文確認メールが英語で届く

| 項目 | 内容 |
|---|---|
| 利用者 | トレードチームの担当者（商品と在庫を登録する）→ 在庫の承認者 → 会員のお客様（海外のお届け先） |
| 目的 | 登録したカードを、海外のお客様が英語のサイトで探し、EMSで買い、注文確認メールが英語のテンプレートで届き、内容が注文と一致する |
| 種類 | 正常（海外） |
| マトリクスの行 | `matrix_UPM-05/matrix.md` のT08（シングルカード・EMS・クレジットカード決済・ポイントをためる・商品金額合計がSmall packetの上限金額を超える・英語・登録済みの海外の住所） |
| もとのシナリオ | SCN-TSUHAN-お客様EC購入フロー-001（海外・英語のデータパターン） |

## 前提

- システムの外で済んでいること：カードの商品画像をS3へ保存済み。カードが入荷している
- 用意するデータ（試験用の値。設計書の値ではない）
  - トレードチームの登録担当、在庫の承認者（別の担当者）
  - 会員：試験 花子（メールアドレス `upm-05@example.test`、海外（米国）の住所を登録済み、保有ポイント0）。登録済みのクレジットカードは無い
  - 商品：シングルカード「シナリオ試験カードE」（言語＝英語、状態＝NM、基準価格・販売価格60,000円、購入グループ「通常商品」、地域別販売制限＝制限なし、商品名（英）を入れる、商品カテゴリを1件）。このカードに紐づくカードデータ（カード登録CSVで登録済み。カード名（英）を持つ。値は試験用に決める）。商品公開ステータス＝公開、支店の商品公開ステータス＝非公開で登録する
  - 入庫：在庫変更CSV登録で2点
  - 設定：Small packetの上限金額は50,000円（初期値）。商品金額合計60,000円は上限を超える。海外のEMSの送料は設定の送料表の値で、手順で控える

## 注文確認メールで確かめること（手順12）

設計書に件名・本文の定めが無いので、設計書の期待値は「注文と一致する」ことと、設計書に書かれた点だけ。参考欄は新実装のテンプレートの項目で、合否は付けず「記録」とする。

| 確かめる項目 | 期待値（設計書・注文との一致） | 参考（新実装のテンプレート。記録） |
|---|---|---|
| 届く通数 | 注文完了メールが1通 | — |
| ご注文番号 | 手順11の購入完了画面の8桁のご注文番号と同じ | [Order ID] |
| 言語 | 英語（英語のサイトで買い、海外のお届け先）。設計書は「会員の都道府県が海外のときは英語」（再送の言語）。購入時の言語の決め方は設計書に無く、新実装は購入時のサイトの言語で選ぶ（日本語以外は英語）。この行は購入時のサイトも会員の住所もどちらも英語・海外なので、どちらの決め方でも英語 | 英語のテンプレート。税額は付かない（受注に写した会員の国が日本ではない） |
| 商品・数量・金額 | 「シナリオ試験カードE」（商品名（英））・数量1・単価60,000円・合計60,000円が、手順6・10の値と一致する | [Order Details]に「Price : 60,000円 x Quantity : 1 = Total : 60,000円」の形 |
| お買上金額 | 商品金額合計60,000円・送料・手数料0円・注文金額合計が、手順10の値と一致する | [Purchase Amount]（Item Total・Postage・Fee・Points Used・Order Total） |
| お支払方法 | 「クレジットカード決済」（手順10の選択。英語の表示名はCredit Card）。テンプレートは支払方法ごとに違う（設計書：支払方法ごとに定めたテンプレート） | [Payment method]。ヘッダーに決済を確認した旨・出荷の案内 |
| 配送方法・希望日時 | 「EMS」・希望日時なし | [Delivery method]・[Delivery Date] 「No Request」・[Desired Delivery Window] 「No Request」 |

## L3で変わるところ

- 配送方法：EMS／Small packet（商品金額合計が上限金額以下のとき）／International TA-Q-BIN。選べる支払方法は同じ
- 支払方法：クレジットカード決済／登録済みクレジットカード決済（カード情報の入力なし）／全額ポイント支払い（ポイントを全額使う。購入直後の受注は「注文受領」。メールは支払金額なしのテンプレート）
- 言語：日本語のサイトで海外のお届け先に買う行（F2）。メールは日本語のテンプレート（新実装は購入時のサイトの言語が日本語なら日本語。設計書に決まりが無い点は食い違いに記録）。国内の会員が英語サイトで買う行はUPM-01の言語R2で、英語のテンプレート・税額つき本文
- 商品の種類：グッズ（商品一覧・詳細にカード言語・状態が出ない）
- 例外：日本国内のみの商品を海外のお届け先で買おうとする（Y01）、お届け先をすでに20件登録している（Y02。英語サイトでは「The maximum number of addresses registration is exceeded.」がご注文方法指定画面に出て、ご注文方法指定へ戻る）、使用ポイントが保有ポイントを超える（Y03）、購入完了画面の前にブラウザバックして再処理でメールが再送される（Y04）
