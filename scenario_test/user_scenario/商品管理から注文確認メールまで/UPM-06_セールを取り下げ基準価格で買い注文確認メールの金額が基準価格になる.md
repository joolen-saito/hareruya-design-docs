# UPM-06 セールを取り下げ、基準価格で買い、注文確認メールの金額が基準価格になる

| 項目 | 内容 |
|---|---|
| 利用者 | 顧客戦略チームの担当者（セールを取り下げる）→ 会員のお客様（国内） |
| 目的 | セール中だったカードのセールを取り下げ（UPM-02で開始したセールの後日の作業）、お客様が基準価格で買い、注文確認メールの金額が基準価格になる。セール中に買った前の注文の金額は変わらない |
| 種類 | 正常（セールの終わり） |
| マトリクスの行 | `matrix_UPM-01/matrix.md` のT07（シングルカード・在庫変更CSV登録・非公開で登録→商品公開CSV登録で公開・通常価格（取り下げ後）・在庫と同じ数・詳細検索・商品一覧から・ゆうパック・代金引換・ポイントを一部使う・送料無料金額以上で、ポイントにより支払額が代金引換の上限以内（K3）・日付と時間帯を指定・備考あり・日本語） |
| もとのシナリオ | SCN-PRICE-001 |

UPM-02（セール開始）とは日をまたいで分ける。業務フロー11は取り下げと更新を別の作業にし、取り下げは火曜日、更新は水曜日に行う（1-4）。取り下げのとき、システムの状態（セール中）が後日の作業を待っている。

## 前提

- システムの外で済んでいること：取り下げるセール品のリストの確認
- 用意するデータ（試験用の値。設計書の値ではない）
  - 顧客戦略チームの担当者
  - 会員：試験 花子（メールアドレス `upm-06@example.test`、国内（東京都）の住所を登録済み、保有ポイント6,000）。この会員は、セール中にこの商品を1点買い、注文Aができている（単価13,600円）
  - 商品：シングルカード「シナリオ試験カードF」（言語＝日本語、状態＝NM、基準価格16,000円、セール価格13,600円でセール中（セールフラグ有効）、在庫2、商品公開ステータス＝公開）
  - 設定：送料無料金額は30,000円、代金引換は商品金額＋送料＋手数料（330円）の支払額が29,999円以内のときだけ選べる（開発環境の値）

## 操作の流れと期待値

| # | 操作する人と操作 | 期待値（画面で見えること） |
|---|---|---|

| 2 | お客様：本店のトップページを開き、ログインする | エラーが出ずにログインでき、ヘッダーの「ログイン」が「マイページ」に変わる |
| 3 | お客様：ヘッダーの詳細検索を開き、商品名に「シナリオ試験カードF」を入れて検索する | 商品一覧に商品が出る。「Sale」ラベルが出ず、価格が16,000円、在庫2、カード言語「日本語」・状態「NM」が表示される |

## 注文確認メールで確かめること（手順9）

設計書に件名・本文の定めが無いので、設計書の期待値は「注文と一致する」ことと、設計書に書かれた点だけ。参考欄は新実装のテンプレートの項目で、合否は付けず「記録」とする。

| 確かめる項目 | 期待値（設計書・注文との一致） | 参考（新実装のテンプレート。記録） |
|---|---|---|
| 届く通数 | 注文完了メールが1通 | — |
| ご注文番号 | 手順8の購入完了画面の8桁のご注文番号と同じ | 【ご注文番号】 |
| 商品・数量・金額 | 「シナリオ試験カードF」・数量2・単価16,000円（基準価格。セール価格13,600円ではない）・合計32,000円。手順5・7の値と一致する | 【ご注文明細】に「価格：16,000円 x 数量：2 = 合計：32,000円」の形 |
| お買上金額 | 商品金額合計32,000円・送料0円・手数料330円・ポイント使用5,000・注文金額合計（税込）27,330円。手順7の値と一致する | 【お買上金額】 |
| お支払方法 | 「代金引換」（手順7の選択）。テンプレートは支払方法ごとに違う | 【お支払方法】。ヘッダーに代金引換の説明と手数料の段階の案内 |
| 配送方法・希望日時 | 「ゆうパック」・手順7で選んだ配送希望日・時間帯 | 【配送方法】【配送希望日】【配送希望時間帯】 |
| 注文時備考 | 手順7で書いた備考の文 | 【注文時備考】 |
| 宛先・件名・言語 | 宛先は会員のメールアドレス。件名は設計書に定めが無い（記録）。日本語 | 「[店名] 晴れる屋をご利用いただきありがとうございます。」 |

## 終わったあとに確かめること

| 確かめる場所 | 期待値 |

| 注文Aの受注 | 明細の単価13,600円のまま |
| 在庫の履歴 | 「受注による減算 注文番号：（8桁の注文番号）受注時価格：16,000 円」の形で残る。商品の在庫が2から0に減る |

## L3で変わるところ

- 取り下げのあと、取り下げた商品に基準価格変更CSV登録をする（UPC-05）
- 購入の条件：UPM-01のマトリクスの価格が「通常価格」の行。支払方法・配送方法・ポイント・言語でメールの定型文・送料・手数料が変わる
- 取り下げの前に買った注文のメールは再送されない（手順10）
