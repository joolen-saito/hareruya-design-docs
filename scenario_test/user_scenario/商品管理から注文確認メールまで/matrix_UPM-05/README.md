# 商品管理から注文確認メールまでの海外のお届け先への購入（UPM-05）

IPA「高信頼化ソフトウェアのための開発手法ガイドブック」(2010) の表6-9〜6-11と同じ手順で作る。1行が1本のシナリオ（L3）。`../matrix_UPM-01/README.md` の範囲・実装の確かめと同じ決まりで、海外のお届け先だけに絞った。

## 範囲

- 商品を用意するところ（CSV登録・価格・在庫の承認・公開）は国内と同じ流れなのでUPM-01のマトリクスで確かめ、ここでは因子にしない（ただしUPM-05のL4は用意から通す）。海外で結果が変わる因子：商品の種類・配送方法（EMS・Small packet・International TA-Q-BIN）・支払方法・ポイント・金額・表示言語・お届け先
- 海外向けの配送方法で選べる支払方法はクレジットカード決済・登録済みクレジットカード決済・全額ポイント支払いだけ（開発環境の設定 2026-09-07。通販/matrix の禁則X24〜X35）。コンビニ決済・郵便振替・銀行振込・代金引換は選択肢に出ない（L4の手順で確かめる）
- 海外は送料無料にならない（現行ソース pf-eccube3 の送料無料の判定「海外の場合は送料無料にしない」。通販/matrix の水準K2の扱い欄）

## まとめた水準（2026-11-05 依頼者決定）

| 因子 | まとめた種類 | 代表 | 流れ・処理が変わらない根拠 |
|---|---|---|---|
| 商品の地域別販売制限 | 制限なし／海外のみ（海外のお届け先のとき） | 制限なし | 配送方法（EMS・Small packet・International TA-Q-BIN）は制限なし・海外のみの両方に結び付く（通販/matrix の水準G5の扱い欄、開発環境の設定）。選べる配送方法・支払方法・メールの内容が同じ。日本国内のみの商品は例外Y01 |
| お届け先の国 | Japan以外の国々 | 1つの国（米国。International TA-Q-BIN は「US Only」の名前だが国で絞る処理は新実装に無い） | 配送方法の絞り込み・支払方法は「Japan以外」で決まる（0304 ご注文方法指定 処理概要「配送先の国が「Japan」以外の場合」）。送料の値の違いだけ |
| 商品の探し方・カートに入れる画面・数量・配送希望日時・備考 | — | UPM-01で確かめる | 国内と海外で処理・表示が変わらない（探し方・カートへの入れ方は商品の公開・在庫だけで決まる） |
| 端末 | PC・スマートフォン | PC | UPM-01と同じ |

分けたままにしたもの：配送方法3種類（選べる条件が違う。Small packetは金額の上限で消える）、支払方法3種類、表示言語（メールのテンプレートが日本語・英語で別）。

## 実装で確かめたこと（2026-11-05）

- 注文確認メールのテンプレートは購入時のサイトの言語で選ぶ（新実装のメール送信の処理（受注メールの送信））。再送（購入完了手続き再処理）は会員の都道府県が海外かで選ぶと設計書（0405 B05-02 現行仕様）が書くが、新実装は再送の言語を呼び出し側の指定で選ぶ。設計書は購入時の言語の決め方を書かないので、購入時の期待値は新実装（購入時のサイトの言語が日本語なら日本語、それ以外なら英語）で決め、海外のお届け先を日本語サイトで買った行（F2）は日本語のメールを期待値とする。再送の決め方が設計書と新実装で違う点は食い違いに記録した
- 英語のメールは、受注に写した会員の国が日本で、かつ英語のサイトで買ったときは税額つきの本文、それ以外は税額なしの本文を使う（新実装のメール送信の処理 479〜482行目。判定はお届け先の国ではなく、受注に写した会員の国）。この一覧の会員は米国の住所なので税額なし。設計書には書かれていない
