# UPM-03 本店と支店の公開状態を切り替え、支店で買い、注文確認メールが届く

| 項目 | 内容 |
|---|---|
| 利用者 | トレードチームの担当者（商品と在庫を登録し、公開状態を切り替える）→ 在庫の承認者 → 会員のお客様（本店・支店のサイト） |
| 目的 | 本店・支店の公開状態に応じて、お客様の画面に商品が出る・出ないことを確かめ、両方が公開になった商品を支店で買って、注文確認メールが届く |
| 種類 | 正常（公開状態の切り替え）。見え方の4通りはL3で通す |
| マトリクスの行 | マトリクスは作らない（因子が3つ未満）。代表のL3：本店＝非公開・支店＝非公開で登録 → 本店だけ公開 → 本店・支店とも公開 → 支店だけ非公開に戻して確かめる → 再び公開 → 支店で店頭支払で買う（公開状態の組は `商品登録・編集/matrix_UPR-09/` で確かめ済み） |
| もとのシナリオ | SCN-PRODUCT-005・008・012、店頭受取受注管理の注文部分 |

## 前提

- システムの外で済んでいること：グッズの商品画像をS3へ保存済み。商品が入荷している
- 用意するデータ（試験用の値。設計書の値ではない）
  - トレードチームの登録担当、在庫の承認者（別の担当者）
  - 会員：試験 花子（メールアドレス `upm-03@example.test`、国内の住所を登録済み）。本店と支店でログインのトークンを共有する（会員は本店・支店で共通）
  - 商品：グッズ「シナリオ試験グッズC」（基準価格・販売価格 3,000円、購入グループ「通常商品」）。商品公開ステータス＝非公開、支店の商品公開ステータス＝非公開で登録する。在庫は在庫変更CSV登録で3点入庫する
  - 支店：支店A（支店のサイトと店舗受取がある）
- 支店の支払は店頭支払だけ（裁定R13）。送料は表示されない（店舗受取のみ）

## 注文確認メールで確かめること（手順15）

設計書に件名・本文の定めが無いので、設計書の期待値は「注文と一致する」ことと、設計書に書かれた点だけ。参考欄は新実装のテンプレートの項目で、合否は付けず「記録」とする。

| 確かめる項目 | 期待値（設計書・注文との一致） | 参考（新実装のテンプレート。記録） |
|---|---|---|
| 届く通数 | 注文完了メールが1通 | — |
| ご注文番号 | 手順14の購入完了画面の8桁のご注文番号と同じ | 【ご注文番号】 |
| 商品・数量・金額 | 「シナリオ試験グッズC」・数量1・単価3,000円・合計3,000円。手順12〜14の値と一致する。支店は注文金額合計（税込）3,000円だけが画面に出る（手順13）ので、メールの注文金額合計が3,000円であること | 【ご注文明細】【お買上金額】（商品金額合計・送料・手数料・ポイント使用・注文金額合計(税込)） |
| お支払方法 | 「店頭支払」（支店の支払方法）。テンプレートは支払方法ごとに違う（店頭支払のテンプレート） | 【お支払方法】。ヘッダーに商品の受け取りとお取り置き期限の案内（注文日を含めて7日間） |
| 配送方法 | 店舗受取。配送希望日・時間帯は手順13で選べない | 【配送方法】【配送希望日】「希望無し」 |
| お客様情報 | 氏名・住所・電話番号が会員の登録情報と一致する | 【お客様情報】 |
| 宛先・件名・言語 | 宛先は会員のメールアドレス。件名は設計書に定めが無い（記録）。日本語のサイトで買い、国内のお届け先なので日本語 | 「[店名] 晴れる屋をご利用いただきありがとうございます。」 |

## L3で変わるところ

- 本店×支店の公開状態4通り：本店＝公開・支店＝公開／本店＝公開・支店＝非公開／本店＝非公開・支店＝公開（本店が非公開なら支店が公開でも支店の画面に出ない）／本店＝非公開・支店＝非公開。手順4〜10で通る3通りに加え、本店＝非公開・支店＝公開は、商品公開ステータスを非公開にするCSV（在庫が無い商品。在庫が残る商品の非公開はエラーになる新実装の制約でUPR-08）で確かめる
- 切り替えの仕方：商品公開CSV登録（手順5・9・11）／商品編集画面の単体の保存（手順7）
- 商品の種類：カードでも同じ（商品一覧・詳細にカード言語・状態が出る）
- 例外：商品公開CSV登録で廃止の商品は変更しない／スマレジ連携済みの商品を非公開にする（`商品登録・編集/matrix_UPR-09/` の例外）
