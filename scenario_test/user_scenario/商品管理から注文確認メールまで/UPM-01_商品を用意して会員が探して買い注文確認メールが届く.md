# UPM-01 商品を用意して会員が探して買い、注文確認メールが届く

| 項目 | 内容 |
|---|---|
| 利用者 | トレードチームの担当者（商品と在庫を登録する）→ 在庫の承認者 → 会員のお客様（国内） |
| 目的 | 入荷したグッズを管理画面で登録し、在庫を承認して公開し、お客様が探して買い、注文確認メールが注文と一致して届く |
| 種類 | 正常 |
| マトリクスの行 | `matrix_UPM-01/matrix.md` のT27（グッズ・在庫変更CSV登録・非公開で登録→商品公開CSV登録で公開・通常価格・購入上限数と同じ数・キーワード検索・商品詳細から・ゆうパック・クレジットカード決済・ポイントを一部使う・送料無料金額より少ない・配送希望なし・備考なし・日本語） |
| もとのシナリオ | SCN-PRODUCT-004・010、SCN-TSUHAN-お客様EC購入フロー-001 |

## 前提

- システムの外で済んでいること：グッズの商品画像をS3へ保存済み（CSVの規格画像に画像の保存先を書く）。商品が店に入荷している
- 用意するデータ（試験用の値。設計書の値ではない）
  - トレードチームの担当者（登録担当）と、在庫の承認者（別の担当者。承認権限があり、登録担当の承認通知先に入る）
  - 会員：試験 花子（メールアドレス `upm-01@example.test`、国内（東京都）の住所を登録済み、保有ポイント2,000）
  - 商品：グッズ「シナリオ試験グッズA」（基準価格・販売価格 5,000円、購入グループ「通常商品」、販売制限数＝2、地域別販売制限は制限なし、商品カテゴリを1件）をCSVに1行書く。商品公開ステータス＝非公開、支店の商品公開ステータス＝非公開で登録する
  - 入庫：在庫変更CSV登録で5点（在庫変動区分は入庫）
  - 設定：送料無料金額は30,000円（開発環境の値）。購入は2点（10,000円）なので送料無料にならない
- 在庫が承認されるまでは在庫0。登録担当と承認者は別の担当者（登録した本人は承認できない）

## 注文確認メールで確かめること（手順14）

設計書に件名・本文の定めが無いので、設計書の期待値は「注文と一致する」こと（終点）と、設計書に書かれた点だけ。新実装のテンプレートの項目は参考で、合否は付けず「記録」とする（設計書の不足）。

| 確かめる項目 | 期待値（設計書・注文との一致） | 参考（新実装のテンプレート。記録） |
|---|---|---|
| 届く通数 | 注文完了メールが1通（再送の対象は「注文完了メールの送信履歴が無い注文」だけなので、2通届かない） | — |
| 宛先 | 会員のメールアドレス（注文時のメールアドレス）。設計書に定めが無い（記録） | 受注のメールアドレス宛て。店舗の代表アドレスにも控えが送られる |
| 件名 | 設計書に定めが無い（記録）。設定画面の自動送信メール／メール設定で変えられる | 「[店名] 晴れる屋をご利用いただきありがとうございます。」 |
| ご注文番号 | 手順13の購入完了画面の8桁のご注文番号と同じ（メールの受注番号は8桁のゼロ埋め） | 【ご注文番号】 |
| 商品・数量・金額 | 「シナリオ試験グッズA」・数量2・単価5,000円・合計10,000円が、手順10〜12の値と一致する | 【ご注文明細】に「価格：5,000円 x 数量：2 = 合計：10,000円」の形 |
| お買上金額 | 商品金額合計10,000円・送料・手数料0円・ポイント使用・注文金額合計（税込）が、手順12の値と一致する | 【お買上金額】に商品金額合計・送料・手数料・ポイント使用(値引き)・注文金額合計(税込)と内税 |
| お支払方法 | 「クレジットカード決済」（手順12の選択と一致）。テンプレートは支払方法ごとに違う（設計書：支払方法ごとに定めたテンプレート） | 【お支払方法】。ヘッダーに入金の案内（決済を確認した旨・出荷のご案内） |

| 注文時備考 | 書いていないので空 | 【注文時備考】 |
| 言語 | 日本語（日本語のサイトで買い、国内のお届け先） | 日本語のテンプレート |
| ヘッダー・フッター | 管理画面の自動送信メール・メール設定で設定した本文上部・本文下部が入る。設計書にその文言は無い（記録） | 支払方法ごとの案内、店舗の連絡先 |

## L3で変わるところ（マトリクスの他の行・例外）

- 商品の種類がカードの行（A1）：登録はカード商品CSV登録。商品一覧・詳細にカード言語・状態・他の状態が出る
- 在庫の入れ方が在庫編集画面（B2）：承認は同じ。却下は例外X04
- 公開の仕方が「登録のときから公開」（C1）：承認前に商品一覧に出るが在庫0で買えない（例外X02）
- 販売価格がセール中（D2）：UPM-02。取り下げ後に買う場合はUPM-06
- 支払方法・配送方法・ポイント・金額・言語：マトリクスの行どおり。支払方法ごとに購入直後の受注の状態と、メールのヘッダーの案内が変わる（銀行振込・郵便振替・コンビニ決済は購入完了とメールまでで、入金から先はUTS-16・UTS-17）
- 送料無料金額以上（K2・K3）で代金引換を選ぶのは、ポイントの一部使用で支払額が29,999円以内のとき（K3）だけ
- ユニサーチの反映（2026-11-05追加。ユニサーチを使う環境の場合。接続先が空の環境はEC内検索になり、公開すれば手順6bを待たず検索に出る）：商品を公開にしても、次のフィードが載るまでは、キーワード・詳細検索・カテゴリのどの検索にも出ない（手順6a）。探し方がカテゴリ（F3）・詳細検索（F2）の行でも、手順6bの反映のあとに探す
- 例外X01〜X17：`matrix_UPM-01/matrix.md` の差し込み表
