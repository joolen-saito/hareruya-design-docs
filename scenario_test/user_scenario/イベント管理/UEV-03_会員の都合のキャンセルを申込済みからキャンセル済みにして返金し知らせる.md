# UEV-03 会員が都合でキャンセルを申し込み、店舗チームが申込をキャンセル済みにし、返金して知らせる

| 項目 | 内容 |
|---|---|
| 利用者 | お客様（申込済みの会員）→ 店舗チーム（管理画面で申込状況を変える）→ トレードチーム（返金処理。システムの外）→ メール |
| 目的 | 申込済みの会員が、期限（イベント前日23時59分）の前に、大会詳細の「キャンセル申込み」からお問い合わせで申し出る。店舗チームが申し出のメールを確認して申込状況を「キャンセル済み」にし、有料は返金（システムの外）をしてから、お客様にキャンセル完了を知らせる。システムで確かめるのは、申込状況の変化・定員の空き・マイイベントの一覧・申込履歴・申し出の受付 |
| 種類 | 正常（組み合わせ表の1行）＋例外7件 |
| マトリクスの行 | `matrix_UEV-03/matrix.md` のT01（有料・その申込のすべて（1日程）・イベント申込一覧で一括編集・デッキ未登録・キャンセル理由「その他」）。ほかの5行（T02〜T06）と例外7件は「L3で変わるところ」 |
| もとのシナリオ | SCN-EVENT-004（後段）。業務フロー08（イベント管理）のシート「イベント受付(オンライン受付)」＃2-3〜2-8 |

期限（前日23時59分）の前に申し出る前提なので、申し出る日程の開始は翌日以降にする。期限の後の申し出は店舗の手作業（システムの外。2026-11-06 依頼者決定）で、このシナリオに入れない。
