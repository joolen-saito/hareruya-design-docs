  - イベント「シナリオ試験 スタンダード大会（有料）」（英語名 Scenario Test Standard Tournament）：店舗＝店舗A、フォーマット＝スタンダード、ルール適用度＝競技（ルール適用度のマスターの値）、イベント規模＝定番イベント、公開状態＝公開、定員＝8、チーム戦＝オフ、支払方法＝クレジットカード決済、参加費＝1,000円

- 申込のあるイベント・日程は削除できない。試験が終わったあとにイベントを消す場合は、申込・デッキ登録を片付けてから行う
