# イベント管理の後日のデッキ登録（UEV-07）

IPA「高信頼化ソフトウェアのための開発手法ガイドブック」(2010) の表6-9〜6-11と同じ手順で作る。`fl_table.tsv`（因子・水準）、`prohibitions.tsv`（禁則）、`exceptions.tsv`（例外。無い）から `build_matrix.py` が `matrix.md`・`matrix.tsv` を作る。1行が1本のテスト。

## 範囲

- 申込済みの会員が、後日、マイイベント・デッキ登録の一覧から、デッキを登録（編集）するところまで（業務フロー2-2の後日の登録）。申込直後の登録はUEV-02、提出のしかた（入力欄・MTGアリーナ形式・マイデッキ）の違いはUDK-02
- 各行の期待値
  - ボタンが出る行（B1）：大会デッキ登録の完了画面が出て、デッキ登録完了メールが届き、一覧が「デッキ登録済み」（ボタンは「デッキ編集」）になる。枚数などのエラーがあってもデッキは登録される（C2）
  - ボタンが出ない行（B2〜B5）：一覧にデッキ登録/編集のボタンが出ない。提出はしない（提出の回と提出する内容は「該当なし」）
- 「ボタンが出ない」の4つは、締切日時・「デッキ登録を終了する」・イベント終了（開催日の23:59:59を過ぎた）・「デッキ登録あり」にチェックが無い、のどれか1つずつ
