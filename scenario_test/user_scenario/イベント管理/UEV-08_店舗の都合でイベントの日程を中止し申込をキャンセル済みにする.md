# UEV-08 店舗の都合でイベントの日程を中止し、新規の申込を止めて、申込済みの申込をキャンセル済みにする

| 項目 | 内容 |
|---|---|
| 利用者 | 店舗チーム（日程の公開状態を変える・申込をキャンセル済みにする。お客様への連絡・返金は店舗の手作業でシステムの外）→ お客様（画面を見るだけ） |
| 目的 | 店舗の都合でイベントの日程を中止する。日程を「非公開」にして新規の申込を止め、その日程の申込済みの申込をすべて「キャンセル済み」にする。システムの状態（日程の公開状態・申込状況・申込履歴・マイイベントの一覧）だけを終点にし、連絡・返金は期待値に入れない |
| 種類 | 正常（組み合わせ表の1行）＋例外4件 |
| マトリクスの行 | `matrix_UEV-08/matrix.md` のT01（申込済みの有料の申込・中止する日程は1日程だけ・キャンセルする申込は複数件（イベント申込一覧でチェックして一括編集）・お客様はデッキ未登録）。ほかの5行（T02〜T06）と例外4件は「L3で変わるところ」 |
| もとのシナリオ | なし（今のシナリオ SCN-EVENT-* に無く、業務フロー・設計書に店舗都合の中止の記述が無いので、設計書にある道具（日程の公開状態・申込一覧の一括編集・申込詳細編集）から組み立てた。`scenario_list.md` の決着#2） |

返金・お客様への連絡は店舗の手作業（システムの外。2026-11-06 依頼者決定）。新実装の一括更新は申込状況と履歴を更新するだけで、連絡・返金を持たない。日程を公開のままにするとキャンセルで空きが戻り、受付期間内なら新たに申し込めてしまうので、非公開にする手順に限る。日程は、申込があると削除できないので、削除は選ばない。
