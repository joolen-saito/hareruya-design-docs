# 判断待ち Excel確認：イベント管理・デッキ登録

確認した Excel：0214（イベント管理）、0307（フロント イベント）、0413（バッチ イベント）、0212（デッキ管理）、`scenario_test/02_業務一覧_業務フロー.xlsx` の「イベント管理」「デッキ登録」シート。
全シートのセル値・取り消し線・コメント・図形の文字を読んだ。

全体の所見
- 5ファイルすべてに、セルのコメントは0件。リッチテキストの部分的な取り消し線も0件。
- セル全体の取り消し線は 0214 に5件だけある。すべて「権限を保持している店舗のイベントのみ表示を可能とする」（イベント一覧 D30・D31、イベント編集 D104、イベント申込一覧(検索入力) D46、同(検索結果) D29）。今回の項目とは無関係。
- 0214 の申込状況・支払方法の選択肢セルには、取り消し線も注記も無い。
