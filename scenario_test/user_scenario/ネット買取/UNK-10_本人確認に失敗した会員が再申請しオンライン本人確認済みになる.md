# UNK-10 本人確認に失敗した会員が、情報を直して再申請し、オンライン本人確認済みになる

| 項目 | 内容 |
|---|---|
| 利用者 | お客様（会員。マイページ。撮影はスマートフォン）→ メール → 店舗チーム（会員管理）→ メール |
| 目的 | 本人確認失敗メールを受けたお客様が、身分証や登録情報を直して、再度オンライン本人確認を申請し（本人確認ステータスは確認中のまま）、店舗チームが問題なしにして、会員の本人確認ステータスが「オンライン本人確認済み」になり、本人確認完了メールが届く。再申請でまた問題ありのときは、失敗メールを繰り返す（確認中のまま） |
| 種類 | 正常（組み合わせ表の1行）＋例外1件 |
| マトリクスの行 | `matrix_UNK-10/matrix.md` のT01（お客様の再申請＝身分証や登録情報を直して再度申請する・店舗チームの確認結果＝問題なし（オンライン本人確認済みにする））。本人確認はPCで始める（端末の違いは結合テストへ。依頼者決定 2026-11-09） |
| もとのシナリオ | SCN-ONLINE-KAITORI-001・002。業務フロー14の1-12〜1-15 |

## 前提

- 共通の決まり：`../L4を流すときの共通の決まり.md` を先に読む（試験データの名前にシナリオIDを付ける・共有の設定は元に戻す・バッチの起動・店舗の読み替えなど）
- 起点の会員：UNK-02 のT02の終点（自動車運転免許証で申請し、店舗チームが問題ありとして失敗メールを送った会員。本人確認ステータスは「確認中」。身分証有効期限は未設定）。この試験専用に1人作る（本会員「ネット買取試験 本人確認二郎」`unk10-t01@example.test`。例外E1用にもう1人 `unk10-e1@example.test`）
- システムの外で済んでいること：スマートフォン（撮影用の試験端末）と撮影する見本の身分証（直したもの）。会員の登録情報の誤り（失敗メールの原因）を直すための正しい値
- 店舗チームの担当者：会員管理の会員編集の「オンライン本人確認」と手動メール通知を使える
- 手順の前に控える値：会員の本人確認ステータス（確認中）、会員のメール送信履歴の件数（失敗メール1通を含む）、会員編集の登録情報（住所）
- 画面の名前・文言は新実装の表示で書く

## 操作の流れと期待値

| # | 操作する人と操作 | 期待値（画面で見えること） |
|---|---|---|
| 1 | お客様：本人確認失敗メールを開く（業務フロー14 1-11） | 件名「【晴れる屋 ネット買取】オンライン本人確認が正しく行えませんでした」のメールが届いている。再申請をお願いする内容 |
| 2 | お客様：マイページの会員情報の変更で、登録情報（例：住所1）を正しい値に直して保存する（業務フロー14 1-12「本人情報変更」） | 変更が保存される。本人確認ステータスは「確認中」のまま（未確認に戻るのは確認済みの会員だけ） |
| 3 | お客様：PCでマイページのオンライン本人確認を開き、QRコードをスマートフォンで読み取り、「撮影する身分証の種類」に「自動車運転免許証」を選び、「撮影画面へ」を押して、現在の顔写真・身分証（オモテ面）・（ウラ面）・（斜め）を撮り直す。同意にチェックを付けて「写真を確定して申請する」を押す（業務フロー14 1-12「再度オンライン本人確認申請」。画面の操作は UNK-02 の手順1〜3と同じ） | 申請完了の画面に「申請が完了しました。確認完了までしばらくお待ちください。」と「現在、確認中です」が出る。本人確認ステータスは「確認中」（再申請でも確認中のまま）。本人確認申請完了メール（件名「【晴れる屋 ネット買取】オンライン本人確認の申請を承りました」）が再び届き、返信先とBccの買取専用メールアドレスにも届く |
| 4 | 店舗チーム：Bccのメールで再申請を知り、管理画面の会員編集で「オンライン本人確認」を開く。モーダルで、直した身分証の画像と、直した登録情報（お名前・住所・生年月日など）を見比べる（業務フロー14 1-13の前段） | モーダルに、再申請の最新の画像（顔写真・身分証（表）・（裏）・（斜め））が出る。登録情報は直した値。身分証有効期限の入力欄は空 |
| 5 | 店舗チーム：問題がないので、身分証有効期限に日付（実行日から1年後）を入れて「確認済に変更する」を押す（業務フロー14 1-13） | 「保存しました」が出て会員編集画面に戻る。本人確認ステータスが「オンライン本人確認済み」になり、身分証有効期限が保存される（モーダルを開き直すと入っている） |
| 6 | 店舗チーム：会員編集画面の「手動メール通知」で、テンプレートに「オンライン済　会員マスターver」を選んで「確認」→「メール送信」を押す（業務フロー14 1-14） | 「メール送信完了しました」が出る。会員の送信履歴に1件増える |
| 7 | お客様：メールを受け取り、マイページのオンライン本人確認を開く（業務フロー14 1-15） | 件名「【晴れる屋 ネット買取】オンライン本人確認が完了いたしました」のメールが届く。マイページの本人確認状況が「オンラインで本人確認済み」になる |
