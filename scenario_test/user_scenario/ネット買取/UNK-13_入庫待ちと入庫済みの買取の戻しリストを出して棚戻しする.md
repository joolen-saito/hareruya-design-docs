# UNK-13 入庫待ち・入庫済みの買取の戻しリストを出力して棚戻しする

| 項目 | 内容 |
|---|---|
| 利用者 | 店舗チーム（買取一覧で戻しリストを出す）→ 棚戻し（システムの外） |
| 目的 | 棚戻しする買取（入庫待ちまたは入庫済み）を買取一覧で選び、戻しリストCSVを出力する。出力した買取に「棚戻し済み」の印が付く。入庫待ち・入庫済み以外の買取を選ぶとエラーになる。棚戻しはステータスで管理せず、フラグ（印）で管理する |
| 種類 | 正常（組み合わせ表の2行）＋例外1件 |
| マトリクスの行 | `matrix_UNK-13/matrix.md` のT01（出力する買取のステータス＝入庫待ち。出力は戻しリストCSV、起点は買取一覧で選ぶ。出力形式の違いは結合テストへ。依頼者決定 2026-11-09）。T02（入庫済み）は「L3で変わるところ」 |
| もとのシナリオ | なし（今のシナリオに対応が無い。0206 買取一覧・戻しリストCSV出力から起こした） |

## 前提

- 共通の決まり：`../L4を流すときの共通の決まり.md` を先に読む（試験データの名前にシナリオIDを付ける・共有の設定は元に戻す・バッチの起動・店舗の読み替えなど）
- 起点の買取（この試験専用に1件ずつ作る。どれも本店のネット買取）
  - T01：UNK-08 のT01の終点（えらんで買取のカードA×2（売却する・基準価格5,000円・買取金額4,000円）、カードBは売却しない。状況「入庫待ち」・棚戻し済み「未」。実在庫情報にカードA×2）
  - T02：UNK-09 のT01の終点（T01と同じ形の買取が15時のバッチで入庫済みになったもの。状況「入庫済み」・棚戻し済み「未」）
  - 例外E1：入庫待ち・入庫済み以外の買取（UNK-04 のT01の終点＝状況「振込依頼済み」）
- 用意するデータ（試験用の値。設計書の値ではない）
  - カードAの商品に、本店の棚番号を設定しておく（商品の在庫の棚番号。戻しリストの棚番号の列に出る）
  - 本店の高額商品閾値1〜3：設定済みの値を流す前に確かめて控える（店舗設定の店舗登録。この試験では値を変えない）。ネット買取管理の戻しリストは本店の閾値を使う。カードAの基準価格5,000円が、どのピッキング区分（「●●円未満」「●●円以上▲▲円未満」「■■円以上」）に入るかは、控えた閾値から導く
  - 店舗チームの担当者：ネット買取管理を使え、買取一覧のダウンロードを使える
  - 手順の前に控える値：買取詳細の棚戻し済み（未）、ステータス、カードAの本店のEC在庫、実在庫情報
- 画面の名前・文言は新実装の表示で書く

## 操作の流れと期待値

| # | 操作する人と操作 | 期待値（画面で見えること） |
|---|---|---|
| 1 | 店舗チーム：管理画面のネット買取管理＞買取一覧の検索条件の「戻し未完了のみ表示」にチェックを入れ、「検索する」を押す。起点の買取の買取詳細も開く（0206 買取一覧(検索入力)） | 検索結果に起点の買取が出る（棚戻し済みでないため）。買取詳細：棚戻し済みが「未」（読み取り専用のラジオボタン）、買取状況「入庫待ち」（T02は「入庫済み」） |
| 2 | 店舗チーム：買取一覧で起点の買取にチェックを入れ、ダウンロードの「戻しリストCSV」を押す | CSVがダウンロードされる（ファイル名は「purchase_restock_list_（買取番号7桁）_（日時）.csv」の形）。見出しは「ピッキング区分」「棚番号」「言語/状態」「略称」「色/R」「数」「商品名」「基準価格」。カードAの行が1行：ピッキング区分は本店の高額商品閾値で決まる区分（基準価格5,000円で判定）、棚番号は設定した本店の棚番号、言語/状態は「JP/NM」（フォイルなら「FoilJP/NM」）、数は2、商品名は商品名から略称・言語・状態・色・レアリティを除いたもの、基準価格は5,000円。売却しないカードBは出ない（実在庫に無い）。エラーの案内は出ない |
| 3 | 店舗チーム：買取詳細を開き直し、買取一覧の「戻し未完了のみ表示」で検索し直す。在庫一覧でカードAを見る | 買取詳細の棚戻し済みが「済」になる。「戻し未完了のみ表示」の検索結果に、この買取は出ない。買取状況は変わらない（T01は入庫待ち、T02は入庫済み）。カードAのEC在庫は、入庫待ち（T01）では手順の前の値のまま（戻しリストを出しても入庫されない）、入庫済み（T02）では入庫済みのとき増えた値のまま |
| 4 | （システムの外）店舗チーム：戻しリストに沿って商品を棚に戻す | システムの外。画面の変化は無い。戻しリストの内容（カードA×2）と、棚に戻す商品が合う |

## 終わったあとに確かめること

| 確かめる場所 | 期待値 |
|---|---|
| 買取一覧・買取詳細のステータス | 変わらない（棚戻し済みはステータスでなく印で持つ） |
| 15時の自動入庫（T01） | 戻しリストを出した入庫待ちの買取も、入庫待ちのままなので15時のバッチの対象に残る（UNK-09。棚戻し済みの印は入庫の条件に入らない） |
| 戻しリストを同じ買取にもう一度出したとき | エラーにならず、同じ内容が出る（棚戻し済みの買取にも出せる） |
