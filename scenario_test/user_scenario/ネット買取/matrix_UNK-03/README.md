# 届いたカードの査定と査定内容の連絡（UNK-03）

IPA「高信頼化ソフトウェアのための開発手法ガイドブック」(2010) の表6-9〜6-11と同じ手順で作る。手順と表の役割は `../matrix_UKA-01/README.md` と同じ。

## 範囲

- 郵送されたカードが届き、店舗チームが商品到着にし、査定して、お客様に査定内容メールが届き、買取の状況が査定内容連絡済みになるまで
- 査定の細部（中断・再開・まとめて買取・個別入力・サプライ）は MTGバイヤー の UMG-04 が担い、ここはその前後を通す。査定する品（カード／仕分けで「価格が付くかもしれない」とした試験カード／サプライ品）、査定の途中経過（中断せず／中断して再開）、まとめて買取、個別入力商品を因子にした
- 査定を途中で中断する操作そのもの（再開しない）は例外にした

- 2026-11-09：本文に同じ条件の値を並べていた（1回ずつ流すテストにするため）ので、値ごとに別の行・例外に分けて作った。期待値は ネット買取/scenario_list.md の本文にあるものを水準ごとに分けただけで、新しい期待値は足していない
- 禁則：無い
