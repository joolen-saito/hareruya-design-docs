# 身分証の有効期限切れ通知（UNK-14）

IPA「高信頼化ソフトウェアのための開発手法ガイドブック」(2010) の表6-9〜6-11と同じ手順で作る。手順と表の役割は `../matrix_UKA-01/README.md` と同じ。

## 範囲

- 毎日8:00の身分証有効期限切れ通知バッチが、身分証有効期限が実行日の14日後以前（すでに過ぎた会員を含む）の会員を見つけ、有効期限を消し、オンライン本人確認済みだった会員は確認済みでなくし、お客様と管理者にメールが届くまで
- 会員の本人確認ステータス（オンライン本人確認済み／簡易書留確認済み／再申請後の確認中〔期限が残っているとき〕／有効期限が残った未確認）と、期限が近づいている／すでに過ぎているを因子にした

- 禁則：無い
