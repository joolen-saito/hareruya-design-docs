# UNK-11 経理から振込失敗の連絡を受け、口座を確かめて振込を依頼し直す

| 項目 | 内容 |
|---|---|
| 利用者 | 経理（振込作業と失敗の連絡。システムの外）→ 店舗チーム（買取情報編集・買取一覧のダウンロード）→ 経理（入金CSVを受け取り直す。システムの外） |
| 目的 | 振込依頼済みの買取で、経理が振込できなかった連絡を受け、店舗チームが買取状況を「振込失敗」にする。お客様の口座情報を確かめて誤りを直し、買取状況を「振込依頼済み」に戻して、入金CSVを経理に渡し直す |
| 種類 | 正常（1通り）＋例外0件 |
| マトリクスの行 | このシナリオに組み合わせ表は無い（`matrix_UNK-11/` は作っていない）。条件の違いは「口座情報の誤りを直して依頼し直す」の1通りだけで、因子・水準・禁則・例外が立たないため。業務フローに記載が無く、0206 の別添ステータス一覧が「業務フローへの記載なし」と書くシナリオ（0206 状態図の振込失敗の分岐から起こした） |
| もとのシナリオ | なし（今のシナリオに対応が無い） |

## 前提

- 共通の決まり：`../L4を流すときの共通の決まり.md` を先に読む（試験データの名前にシナリオIDを付ける・共有の設定は元に戻す・バッチの起動・店舗の読み替えなど）
- 起点の買取：UNK-04 のT01の終点（本店のネット買取・状況「振込依頼済み」。えらんで買取のカードA×2＋カードB×2のうちカードBを売却しない。査定金額合計11,000円・査定承諾金額合計8,000円・会員「オンライン本人確認済み」・身分証明書「自動車運転免許証」登録済み）。ただし、申込時の振込口座は誤った口座名義で入れておく（試験用の口座で、口座名義を実際の名義と違う値にして申込む。UNK-01 の手順4の口座名義を「ネット買取試験タロウ」ではなく別の名義にしておき、経理の失敗の連絡の原因にする。実際の口座は存在しない）。この試験専用に1件作る
- システムの外で済んでいること：経理の振込作業（実際の振込は行わず、振込できなかった連絡を受けたことにする）
- 店舗チームの担当者：ネット買取管理と買取一覧のダウンロードを使える
- 手順の前に控える値：買取番号、買取詳細のステータス変更履歴の行数、口座情報（銀行名・支店名・口座種別・口座番号・口座名義）、入金CSVの口座の値
- 画面の名前・文言は新実装の表示で書く

## 操作の流れと期待値

| # | 操作する人と操作 | 期待値（画面で見えること） |
|---|---|---|
| 1 | （システムの外）経理：振込を行い、口座名義の不一致で振込できなかった連絡をトレードチームに出す（0206 状態図：経理チームから振込失敗の連絡を受領） | システムの外。買取の状況は「振込依頼済み」のまま |
| 2 | 店舗チーム：管理画面のネット買取管理＞買取一覧で買取番号を検索し、買取詳細を開いて、「買取状況」を「振込失敗」にして「保存」を押す（0206 別添のステータス「振込失敗：経理チームで振込ができなかった際に利用」） | 「登録が完了しました。」が出る。買取状況が「振込失敗」になり、ステータス変更履歴に「振込失敗」が1行増える。振込失敗日が出る。マイページの処理状態は設計書では「買取査定を承諾しました。80%」のまま（新実装の表示は「振込待ち」。記録）。お客様へのメールは自動では出ない |
| 3 | 店舗チーム：買取詳細の「買取依頼者情報」の口座情報（銀行名・支店名・口座種別・口座番号・口座名義）を確かめる（0206 状態図：お客様の口座情報を確認） | 申込時に入れた口座情報が出る（口座名義は誤った値のまま） |
| 4 | 店舗チーム：買取依頼者情報の「編集」を押し、口座名義を正しい値に直して「保存」を押す | 「登録が完了しました。」が出る。口座名義が直した値になる。買取状況は「振込失敗」のまま |
| 5 | 店舗チーム：「買取状況」を「振込依頼済み」にして「保存」を押す（0206 状態図：振込失敗→経理チームへ振込を依頼） | 「登録が完了しました。」が出る。買取状況が「振込依頼済み」に戻り、ステータス変更履歴に「振込依頼済み」が1行増える（「振込依頼済み」「振込失敗」「振込依頼済み」の順）。振込依頼済みの検査（身分証明書が登録済み・会員の本人確認の状態）は、変更のたびに働くので、身分証明書が登録済みで会員が確認済みなら通る。マイページの処理状態は「買取査定を承諾しました。80%」のまま |
| 6 | 店舗チーム：買取一覧でこの買取にチェックを入れ、ダウンロードの「入金CSV」を出し直して、経理に渡し直す | 見出し「受注番号」「送料」「査定額」「銀行名」「支店名」「口座種別」「口座番号」「受取人口座名義」「振込金額」「オンライン本人確認区分」。口座名義が、手順4で直した値になる。査定額＝査定承諾金額合計8,000円、振込金額＝送料＋査定額、区分「オンライン本人確認済み」 |
