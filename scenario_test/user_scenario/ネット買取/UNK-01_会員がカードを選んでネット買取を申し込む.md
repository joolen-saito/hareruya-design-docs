# UNK-01 会員がカードを選んでネット買取を申し込む

| 項目 | 内容 |
|---|---|
| 利用者 | お客様（会員）→ メール（買取受付メール）→ 店舗チーム（管理画面の買取一覧で申込を確かめる） |
| 目的 | 会員が買取TOPのコーナーでカードを探し、商品詳細から買取カートに入れ、買取依頼内容の確認画面で振込口座・承諾方法などを入れて申し込む。買取依頼完了画面に買取番号が出て、買取受付メールが届き、マイページの買取履歴に処理状態「受付を完了しました。20%」の買取が出る。管理画面の買取一覧には状況「注文」の買取が1件増える。買取番号・明細・金額が、お客様の画面・メール・管理画面で一致する |
| 種類 | 正常（組み合わせ表の20行）＋例外11件 |
| マトリクスの行 | `matrix_UNK-01/matrix.md` のT01（商品の選び方＝えらんで買取（カード）だけ・職業と生年月日＝職業だけ未登録（職業欄だけ出る）・承諾方法＝査定結果を確認してから承諾する・会員の本人確認の状態＝未確認）。T02〜T20 と例外は「L3で変わるところ」 |
| もとのシナリオ | SCN-ONLINE-KAITORI-001・002（申込の部分）。業務フロー14の1-1〜1-3（1-4 郵送はシステムの外） |

## 前提

- 共通の決まり：`../L4を流すときの共通の決まり.md` を先に読む（試験データの名前にシナリオIDを付ける・共有の設定は元に戻す・バッチの起動・店舗の読み替えなど）
- システムの外で済んでいること：ユニサーチに買取側の商品情報（買取価格・カード状態・高額商品コード・予約フラグ）が送信済みで、試験カードが買取の検索結果に出る状態（商品登録からフィード送信までは UTH-01 の区間）。買取カードの現物は、この申込では要らない（郵送は1-4。システムの外）
- 画面の名前・文言は新実装の表示で書く。買取番号は、完了画面は「PU」＋年月日6桁＋「-」＋10桁の番号、マイページと管理画面は7桁の番号で出る（同じ買取を指す）
- 用意するデータ（試験用の値。設計書の値ではない）
  - 商品（このシナリオ専用の名前。ほかの L4 と重ならない）
    - カードの登録：カード登録CSVでカードを登録してから、カード商品CSVで商品にする（手順は 店頭買取/UKA-04 の手順2〜3と同じ。カード商品CSVは割引率の状態ごとに規格を作る。初期データの割引率は NM・SP・MP・HP の4つ。同じカードの商品が既にあるとカード商品CSVの行は飛ばされるので、カードごとに別の名前を使う。商品カテゴリは既存のカテゴリから選ぶ）
    - 「ネット買取試験カードA」：言語＝日本語・状態NM・買取価格4,000円。「ネット買取試験カードB」：日本語・NM・買取価格1,500円（どちらも買取価格は500円以上。500円未満はカートに入れられない）。どちらにも商品タグ「モダン」を付け、買取特集コーナーの「モダン」に出るようにする
    - 例外E1用：「ネット買取試験カード小」（日本語・NM・買取価格400円。カードA・Bと同じ手順で登録）
    - パック・サプライ（D2・D5の行）：「ネット買取試験パックP」。グッズ商品CSVで、カード詳細を持たない商品として登録する（手順は 商品登録・編集/UPR-04 の手順3〜4と同じ）。買取価格1,200円・商品タグ「パック・BOX」
    - まとめて買取：システムにある専用の1商品を使う（商品詳細から入れる。価格表示は「システム都合」で、実際の査定金額とは関係ない）
  - 会員：本会員。職業・生年月日の登録の違いは行ごとに用意する（E1＝両方登録済み「ネット買取試験 花子」`unk01-e1@example.test`／E2＝両方未登録「ネット買取試験 次郎」`unk01-e2@example.test`／E3＝職業だけ未登録「ネット買取試験 三郎」`unk01-e3@example.test`／E4＝生年月日だけ未登録「ネット買取試験 四郎」`unk01-e4@example.test`）。本人確認ステータスは未確認。振込口座は登録済み（初期値に出る）。住所は国内。メールの受け口を確かめられる
  - 店舗チームの担当者：管理画面のネット買取管理＞買取一覧を使える
  - 手順の前に控える値：買取一覧の検索結果の件数、その会員の買取履歴の件数、会員の職業・生年月日（会員管理の会員編集画面）
- 用意しないもの：カードの現物、振込口座の実在

## 操作の流れと期待値

| # | 操作する人と操作 | 期待値（画面で見えること） |
|---|---|---|
| 1 | お客様：ネット買取のトップページ（買取TOP）を開き、買取特集コーナーの「モダン」から「ネット買取試験カードA」の商品詳細を開く（業務フロー14 1-1。探し方の違いは結合テストへ） | 買取商品詳細（タブの題は「買取：ネット買取試験カードA」）に、状態NMの買取価格4,000円、数量の入力欄、「カートに追加」ボタンが出る。買取価格が500円未満の商品は数量とボタンが出ない（例外E1）。買取価格が付かないカード・NM以外・高額商品コードが付くカード・予約商品は、探し方によらず検索結果に出ない |
| 2 | お客様：会員ログインしたまま、カードAの数量を2にして「カートに追加」を押す | 「買取カートに追加しました。」「買取カートページへ進みますか？」のモーダルが出る。「Yes」で買取カートへ進む。カードAを21点以上にしようとすると「同一商品をカートに追加できるのは20点までです。」が出て、数量は保存されない（例外E2） |
| 3 | お客様：買取カートで、カードAが数量2・小計8,000円で入っていることを確かめ、「買取手続きへ」を押す（業務フロー14 1-1「買い取りたい商品を選んでカートに追加していく」） | 買取カートに「ネット買取試験カードA」の行（数量2・小計）が出る。合計（税込）が8,000円。「買取手続きへ」を押すと、買取依頼内容の確認画面に進む（会員としてログイン済みのため。未ログインなら買取ログイン画面へ戻る。例外E4。カートの最後の商品を削除してから進むとカート画面に戻る。例外E3） |
| 4 | お客様：買取依頼内容の確認画面で、ご注文主・ご注文の商品・買取金額合計を確かめる。職業欄だけが出ているので職業を選ぶ。お振込み口座情報（初期値のまま。口座種別は普通）、箱数1、買取の承諾方法「査定結果を確認してから承諾する」、適格請求書発行事業者「いいえ」を選ぶ（業務フロー14 1-2。T01は職業だけ未登録なので職業欄だけが出る） | ご注文主（お名前・住所・電話番号。住所は住所1〜3まで）、ご注文の商品（商品コード・商品名・数量・合計）、買取金額合計8,000円が出る。「ご職業」の選択欄だけが出て（生年月日は登録済みなので出ない）、お振込み口座情報の上にある。口座名義の下に「口座名義は全角カタカナで入力してください。」の案内がある。箱数は3以上にすると「箱数が多い場合、査定期間が延長されることがあります。」の警告が出るが、申込みはできる（代表は1箱）。職業を選ばずに進むと「この項目は必ず入力してください。」が出て記入画面に留まる（例外E12）。銀行名を空にして進んでも同じ文言が出る（例外E5） |
| 5 | お客様：「会員情報が最新であることを確認し、ネット買取規約に同意する」にチェックを付け、「申込み」を押す。確認画面のモーダルで承諾方法の説明（「買取の承諾方法：査定結果を確認してから承諾する」「査定結果をご確認いただいた上で買取承諾・キャンセルをお選びいただけます。」）を確かめ、「申込み」を押す | 規約に同意しないと画面は遷移せずエラーが出る（例外E9）。モーダルの「入力に戻る」を押すとモーダルが閉じて記入画面に留まり、買取は登録されない（例外E10）。「申込み」で登録され、買取依頼完了画面に進む |
| 6 | お客様：買取依頼完了画面を確かめ、買取番号を控える | 「ご依頼頂きありがとうございます。」と「買取番号 PU（年月日6桁）-（10桁の番号）」が出る（「オーダーID」ではない。設計書の変更点）。オンライン本人確認についての案内（QRコードと「オンライン本人確認する」ボタン）、「買取TOPへ」「マイページ」ボタンが出る。「ご登録いただいたメールアドレスに発送案内のメールをお送りしております。」の案内もある。選んだ職業が会員情報に反映される（会員編集画面で確かめる） |
| 7 | お客様：買取受付メールを開く（業務フロー14 1-3） | 件名「【必読】【晴れる屋 ネット買取】買取査定依頼のご確認」のメールが会員のメールアドレスに届く。買取の明細（カード名・数量）が載る（商品ID順） |
| 8 | お客様：マイページの買取履歴一覧を開く | 買取履歴一覧に、この買取が1件増えて出る（買取番号は7桁、依頼日・店舗・依頼内容・買取金額合計）。処理状態は設計書では「受付を完了しました。20%」。新実装は「受付完了」と出す（記録。設計書との食い違い） |
| 9 | 店舗チーム：管理画面のネット買取管理＞買取一覧で、買取番号で検索する | 検索結果が1件。買取状況「注文」。買取一覧の件数は手順前より1件増える。会員の本人確認の列は「未確認」 |
| 10 | 店舗チーム：買取番号を押して買取詳細（買取情報編集）を開く | 買取状況「注文」、買取依頼者氏名、買取の承諾方法「手動承諾」、買取依頼日が出る。選んで買取に「ネット買取試験カードA」（申込時買取価格4,000円・数量2）が入り、申込時の振込口座・箱数1が保存されている。ステータス変更履歴に「注文」が1行ある。実在庫は空（在庫は動かない） |
