# USM-09 規格の連携を外す・廃止にして、スマレジの商品が削除される

| 項目 | 内容 |
|---|---|
| 利用者 | トレードチームの担当者（登録担当）→ 管理画面 → スマレジ（試験環境） |
| 目的 | スマレジ連携済みの規格を、連携しない・廃止に変えたとき、連携を外せるのはスマレジに在庫が無いときだけで、廃止にするとスマレジに登録済みの商品が削除される。ECかスマレジのどちらかに在庫が1件でもあると、廃止はエラーになり変わらないことを、EC側の値で確かめる。代表の行は、規格の編集画面で、在庫が無い連携済みの規格を廃止にする |
| 種類 | 正常（代表の1本＝規格の編集画面で廃止）＋ L3の表外の具体例8件 |
| マトリクスの行 | なし（組み合わせ表は無い。`scenario_list.md` のL3の欄にある、変える操作（規格の編集画面でOFF／廃止、カード・グッズCSVで廃止）と在庫（スマレジに在庫あり／EC在庫あり／無し）を、代表1本＋表外の具体例にした） |
| もとのシナリオ | なし（設計書 0204 別添「スマレジ連携対象商品」2（削除）・商品規格登録編集から組み立てた） |

非公開にしたときに連携を外すかの食い違いは、商品登録・編集の一覧（UPR-08・UPR-09）に記録済み。連携に入れる側は USM-08。

## 前提

- 共通の決まり：`../L4を流すときの共通の決まり.md` を先に読む（試験データの名前にシナリオIDを付ける・共有の設定は元に戻す・バッチの起動・店舗の読み替えなど）
- スマレジ側の確かめは、スマレジの試験環境で行う（2026-11-24 決定）。スマレジの商品一覧の見え方は記録だけにし、合否は「スマレジの商品が残る／消える」の記録とEC側の値（規格設定・在庫検索一覧・エラー文言）の突き合わせで付ける
- システムの外で済んでいること：スマレジの試験環境に試験用の店舗がある。部門「ショーケース品」がスマレジに連携済み（USM-08・USM-10）
- 用意するデータ（試験用の値。設計書の値ではない）
  - 連携済みの規格（行ごとに別のカード・グッズを使う）：USM-08 の手順1〜5で作った、スマレジ連携フラグが「連携する」のシングルカード「シナリオ試験カードL USM-09」（基準価格500円。SP・MP・HPが連携済み。商品コード・スマレジ商品コード・スマレジ商品IDを控える）。表外の行ごとに、「シナリオ試験カードL2 USM-09」などの別のカードを同じ手順で用意する。グッズは UPR-04 の T02 の用意と同じ要領（連携フラグ「連携する」）で、行ごとに別の商品コード（`USM09-G01`〜）を使う
  - 在庫（行ごとに指定。在庫変更CSV登録と承認で入れる。UZK-01）：スマレジに在庫がある行は、在庫区分「スマレジ」の在庫を1にする。EC在庫がある行は、在庫区分「EC-CUBE」の在庫を1にする。在庫が無い行は0のまま
  - 登録担当：管理画面で、商品管理（商品一覧・商品CSV管理）を編集できる権限を持つ担当者
- 非同期の処理（CSVの取り込みでの削除）は、完了まで待つ（待つのは時刻でなく完了まで）

## 操作の流れと期待値（起点：連携済みの規格を、廃止に変える。代表の行：規格の編集画面で廃止・在庫が無い）

| # | 操作する人と操作 | 期待値（画面で見えること） |
|---|---|---|
| 1 | 登録担当：商品管理＞商品一覧で「シナリオ試験カードL USM-09」を検索し、商品編集画面と規格設定を開く。SPの規格について、スマレジ連携フラグ・スマレジ商品コード・スマレジ商品ID・在庫（EC側のEC-CUBE区分・スマレジ区分）を控える | SPの規格は、スマレジ連携フラグ「連携する」、スマレジ商品コード・スマレジ商品IDに値あり。EC-CUBE区分・スマレジ区分の在庫はともに0。スマレジの試験環境の商品一覧にも、SPの商品がある（記録） |

| 3 | 登録担当：スマレジの試験環境の商品一覧で、SPの商品を探す | SPの商品が削除されている（見つからない。論理削除の見え方は記録）。MP・HPの商品は、廃止にしていないので残っている |
| 4 | 登録担当：廃止にしたSPの規格の編集画面を開き、値を変えて保存しようとする | 「この商品規格は廃止済みのため、変更できません。」が出て、保存されない（廃止後は参照だけ可能。0204 商品登録編集） |

## 終わったあとに確かめること

| 確かめる場所 | 期待値 |
|---|---|
| 規格設定のMP・HP | 連携フラグ「連携する」のまま。スマレジの商品も残っている（廃止にした規格だけが削除される） |
| 夜間のバッチなど | このシナリオの規格は、廃止後に連携フラグが「連携しない」なので、価格の取り込みでスマレジに再登録されない（UPC-05 の取り込みで、廃止した規格の商品がスマレジに増えないことを記録） |
