# ポイントグランターの端末販売の受信（連携内容の種類）（USM-23）：組み合わせテストマトリクス

因子・水準は `fl_table.tsv`、禁則は `prohibitions.tsv`。このファイルは `build_matrix.py` が作る（手で直さない）。

- テスト数: 4
- 2因子間網羅率: 100.00%（0/0）
- 3因子間網羅率: 100.00%（0/0）
- 禁則: `prohibitions.tsv` の0件。設計書に無く現行ソース（pf-eccube3）で決めたものは扱い欄に書いた
- 禁則どうしが重なって行として成り立たない組は、網羅率の分母から外した

| No. | 連携内容 |
|---|---|
| T01 | 1行の連携内容（付与ポイントが正）：スマレジへそのまま中継され、ECには先頭1行分のポイントが加算されて履歴が1件できる |
| T02 | 複数行の連携内容：スマレジには連携内容がそのまま中継されるが、ECに反映されるのは先頭要素の先頭行1件だけ（2行目以降・2要素目以降はECに反映されない） |
| T03 | 付与ポイントが負（減算）：会員の保有ポイントが減る |
| T04 | 付与ポイントの増減が0：新実装はスマレジへ中継せず履歴も作らず成功を返す（設計書は転送すると定め、増減0の例外を書かない） |
