# 部門の登録・更新とスマレジの部門への反映（操作と対象）（USM-10）：組み合わせテストマトリクス

因子・水準は `fl_table.tsv`、禁則は `prohibitions.tsv`。このファイルは `build_matrix.py` が作る（手で直さない）。

- テスト数: 5
- 2因子間網羅率: 100.00%（0/0）
- 3因子間網羅率: 100.00%（0/0）
- 禁則: `prohibitions.tsv` の0件。設計書に無く現行ソース（pf-eccube3）で決めたものは扱い欄に書いた
- 禁則どうしが重なって行として成り立たない組は、網羅率の分母から外した

| No. | 操作と対象 |
|---|---|
| T01 | 部門登録の画面で、スマレジに部門が無い部門を登録する：スマレジに部門が新規登録される（部門名・部門コード・税区分「税込」・ポイント対象など） |
| T02 | 部門登録の画面で、スマレジに部門がある部門を更新する：スマレジの部門が更新される（部門名・部門コード・税区分「税込」・ポイント対象など） |
| T03 | 部門更新CSV登録（M03-35。現状版の工程）：スマレジ連携の対象の規格。CSV（商品コード・部門コード）の商品コードに合う商品規格の部門が更新され、取込履歴（種別は部門更新）が残り、スマレジの商品の部門も更新される |
| T04 | 部門更新CSV登録（M03-35）：連携対象でない規格。商品規格の部門が更新され、取込履歴（種別は部門更新）が残る（スマレジの商品の部門が更新されるのは連携対象の規格） |
| T05 | 部門更新CSV登録（M03-35）：同じ商品コードが複数行。最後の行の部門で確定する |
