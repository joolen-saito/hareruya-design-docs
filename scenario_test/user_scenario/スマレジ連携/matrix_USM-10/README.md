## 範囲

- 部門を新しく使う・変更する（部門登録の画面、部門CSVアップロード）、または商品の部門を直す（現状版の業務フロー09 4-6＝部門更新CSV登録 M03-35。依頼者の決定で試験する）ところから、スマレジに部門が反映されるまで
- 部門登録の画面とCSVには「スマレジに部門が無い（新規）／ある（更新）」があるが、部門更新CSV登録には新規／更新が無い。因子を2つに分けると成り立たない組が出るので、操作と対象を1つの因子にした（A1〜A4が画面・CSV×新規・更新、A5〜A7が部門更新CSV登録）
