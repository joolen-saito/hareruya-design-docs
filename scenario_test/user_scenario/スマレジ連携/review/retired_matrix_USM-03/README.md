## 範囲

- スマレジ在庫の商品の在庫を、在庫編集・在庫一括編集・在庫変更CSV登録・在庫移動・分割結合・棚卸のどれかで変え、承認（棚卸は在庫反映）のあとスマレジへ反映されるまで（登録までは UZK-01・UZK-03〜11・UZK-15 の登録の部分）
- 反映の方式は操作で決まる（在庫編集・在庫一括編集＝API個別、在庫変更CSV・棚卸＝Patch一括。0501）ので、因子は操作の種類1つにした
- 連携の失敗・通信エラー・EC在庫・件数の上限は、正常な値と組み合わせず例外として1つずつ差し込む
