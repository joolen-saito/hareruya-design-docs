| T02 | 在庫一括編集（スマレジ在庫・API個別）：承認のあと、その場でスマレジの在庫に反映され、スマレジ側の在庫数がECのスマレジ在庫の増減と合う。ECの在庫履歴が更新される |
| T03 | 在庫変更CSV登録（スマレジ在庫・Patch一括）：承認のあと、まとめてスマレジの在庫に反映される。スマレジへ送った時点（結果の通知前）ではEC側の在庫を変えず、結果がコールバックに返ってきてからEC側の在庫が更新される。スマレジ側の在庫数がECのスマレジ在庫の増減と合う |
| T04 | 棚卸（スマレジ在庫・Patch一括）：在庫反映のあと、まとめてスマレジの在庫に反映される。スマレジへ送った時点（結果の通知前）ではEC側の在庫を変えず、結果がコールバックに返ってきてからEC側の在庫が更新される。スマレジ側の在庫数がECのスマレジ在庫の増減と合う |

| T06 | 在庫移動（スマレジ在庫から出庫）：出庫承認済みになったタイミングでスマレジの在庫から出庫として反映される |
| T07 | 分割（スマレジ在庫）：承認のあと、スマレジ側の在庫数がECのスマレジ在庫の増減と合い、ECの在庫履歴が更新される |
| T08 | 結合（スマレジ在庫）：承認のあと、スマレジ側の在庫数がECのスマレジ在庫の増減と合い、ECの在庫履歴が更新される |
