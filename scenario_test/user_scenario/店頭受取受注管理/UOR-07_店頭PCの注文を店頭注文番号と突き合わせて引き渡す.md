# UOR-07 店頭PCの注文を、お客様の店頭注文番号と突き合わせ、スマレジで決済して引き渡す

| 項目 | 内容 |
|---|---|
| 利用者 | 店舗のお客様 → 店舗チーム → スマレジ → EC（取り込み・店頭モニター） |
| 目的 | 店内のPCで注文して「ピック完了」になった商品を、お客様が示す店頭注文番号と突き合わせ、ついで買いの商品といっしょにスマレジで決済して引き渡し、元の受注が「引き渡し済み」、スマレジの取引から作った新しい受注が「出荷完了」になり、店頭モニターから店頭注文番号が消える |
| 種類 | 正常 |
| マトリクスの行 | `matrix_UOR-07/matrix.md` のT01（本店・スマレジの会員・ついで買いあり）。業務フロー05 4-10〜4-12 を通す |
| もとのシナリオ | SCN-ORDER-007 |

## 前提

- 共通の決まり：`../L4を流すときの共通の決まり.md` を先に読む（試験データの名前にシナリオIDを付ける・共有の設定は元に戻す・バッチの起動・店舗の読み替えなど）
- システムの外で済んでいること：UOR-06 の終点まで済んでいる（店頭PCの注文がピック完了で、店頭モニターに店頭注文番号が出ている）
- 用意するデータ（試験用の値。設計書の値ではない）
  - 店頭PCの注文：本店・店内アカウントで「シナリオ試験カードA」を数量2（単価1,200円）で注文済み。店頭注文番号（TC注文番号）と注文番号と注文金額合計（税込）を控えてある。受注は「ピック完了」
  - スマレジの会員：試験 太郎（スマレジに登録された会員）
  - ついで買いの商品：店舗の「シナリオ試験ショーケース品B」（スマレジの商品、単価800円、スマレジ在庫10）を1点
  - 店舗チームの担当者：管理画面とスマレジのレジを使える

## 操作の流れと期待値

| # | 操作する人と操作 | 期待値（画面で見えること） |
|---|---|---|
| 1 | お客様：レジで店頭注文番号を示す。店舗チーム：管理画面の受注情報検索で、店頭注文番号を入れて検索し、スタック用紙と突き合わせる。見つからないときは、前提で控えた注文番号で検索して先へ進む | 店頭注文番号の検索で1件出る（見つからなければ不合格として記録する。下の「設計書との食い違い」）。店頭注文番号・ご注文番号・お客様名・商品が、スタック用紙と一致する。対応状況は「ピック完了」。店頭モニターにはこの店頭注文番号が出ている |
