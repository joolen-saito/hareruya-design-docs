# UOR-06 店頭PCで注文し、店舗がピックして、店頭モニターに店頭注文番号を出す

| 項目 | 内容 |
|---|---|
| 利用者 | 店舗のお客様（店内アカウント）→ 店舗チーム（スタック用紙・ピック表・管理画面・店頭モニター） |
| 目的 | お客様が店内のPCで注文を確定し、店舗がスタック用紙を出してピックし、受注が「ピック完了」になって、店頭モニターに店頭注文番号が出る（本店は自動、支店は店頭注文番号札を手動で登録する） |
| 種類 | 正常 |
| マトリクスの行 | `matrix_UOR-06/matrix.md` のT02（本店・自動で印刷される（自動印刷の対象店舗）・印刷が成功する）。業務フロー05 の 4-1〜4-5 を通す |
| もとのシナリオ | SCN-ORDER-007 |

## 前提

- 共通の決まり：`../L4を流すときの共通の決まり.md` を先に読む（試験データの名前にシナリオIDを付ける・共有の設定は元に戻す・バッチの起動・店舗の読み替えなど）
- システムの外で済んでいること：本店にスタック用紙のプリンタ（30秒おきにECへ問い合わせる設定）・タブレット・店内注文モニター（店頭注文番号の一覧ページ）・店内のPCがある。その日の店頭注文番号は初期化済み（毎日0時に1から。UOR-11）
- 用意するデータ（試験用の値。設計書の値ではない）
  - 店内アカウント：本店の店内のPCで使うログイン（購入グループ「店内アカウント」）。商品：カード「シナリオ試験カードA」（単価1,200円、本店の在庫5）を数量2（合計2,400円）で買う
  - 店舗チームの担当者：管理画面で本店の受注を編集できる権限を持つ
  - スマレジの店舗が登録済み
