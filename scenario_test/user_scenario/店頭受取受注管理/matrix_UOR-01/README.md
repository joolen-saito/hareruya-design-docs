- 「支払いなし」（全額ポイント支払い。水準C4）：開発環境の設定では店頭受取・スムーズ店頭受取の両方に結び付く。依頼者の裁定R13（2026-11-05）で残す。0304 は支店でポイントを表示しないと定め（X10）、本店ECでは「ポイント使用」を表示するので、本店の店頭受取・スムーズ店頭受取とも対象にする（R4指摘）。現行 pf-eccube3 は店頭受取だけ、新実装は店頭受取・スムーズ店頭受取の両方でポイント欄を非表示にする。2026-11-09に決着：Excel（業務フロー05 2-2が支払方法「支払いなし」を挙げ、0304のポイント非表示は支店と店内アカウントのみ）・現行・ヘルプが一致して、スムーズ店頭受取（本店）では全額ポイント支払いを選べるのを期待値にする。新実装もスムーズ店頭受取では欄を出すので食い違いは無い（2026-11-27 訂正：以前は「欄を隠すので不合格になり得る」と書いていた。Shopping/index.twig 123行）。店頭受取（スムーズでない方）は現行・新実装とも欄が無く、案内文が出るだけなので全額ポイント支払いは選べない（禁則X11）
