# UOR-05 取り置き期限（14日間）を過ぎたスムーズ店頭受取（本店）を、支払方法に応じて返金し、キャンセルして、商品を戻す

| 項目 | 内容 |
|---|---|
| 利用者 | 店舗チーム → 通販チーム → SPLINKS（クレジットカード・外部）→ 店舗チーム |
| 目的 | 注文日を含めて14日間を過ぎても受け取りに来ないスムーズ店頭受取（クレジットカード決済）の受注について、通販チームがSPLINKSの請求をキャンセルして返金し、店舗の人が受注を「キャンセル」にして、ピックした商品を元の場所に戻す |
| 種類 | 正常（期限超過のキャンセルと返金） |
| マトリクスの行 | `matrix_UOR-05/matrix.md` のT01（クレジットカード決済（スムーズ店頭受取））。例外E1（キャンセルのあとの来店）は下の「L3で変わるところ」 |
| もとのシナリオ | SCN-ORDER-004 |

## 前提

- 共通の決まり：`../L4を流すときの共通の決まり.md` を先に読む（試験データの名前にシナリオIDを付ける・共有の設定は元に戻す・バッチの起動・店舗の読み替えなど）
- システムの外で済んでいること：UOR-01 の終点まで済んでいる（スムーズ店頭受取の注文がピック完了で、商品とスタック用紙がレジ裏にある）。お客様は期限内に受け取りに来ていない
- 取り置き期限（14日間）を過ぎた受注は、試験で作った受注に限り、開発環境で注文日を期限より前に書き換えて用意する（2026-11-26 依頼者「おすすめどおり」。設計書に試験用の手段が無い）
- 用意するデータ（試験用の値。設計書の値ではない）
  - 会員：試験 太郎（`uor-05@example.test`）。本店のスムーズ店頭受取をクレジットカード決済（SPLINKSの試験環境）で「シナリオ試験カードA」数量2（単価1,200円）で注文済み。受注は「ピック完了」で、注文日を含めて14日間を過ぎている（注文日が15日以上前）。注文番号・お名前・注文金額合計を控えてある。在庫は5から3に減っている
  - 店舗チームの担当者（管理画面）と、通販チームの担当者（SPLINKSの管理画面）
- 注文日が15日以上前の受注の用意の方法は、設計書に定めが無い（UOR-04の判断待ち 1と同じ）
