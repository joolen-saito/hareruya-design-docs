# UOR-02 お客様が受け取りに来て、店頭受取（本店・支店）の商品をスマレジで決済して引き渡す

| 項目 | 内容 |
|---|---|
| 利用者 | 会員のお客様（国内）→ 店舗チーム → スマレジ → EC（取り込み）→ 店舗チーム・通販チーム（管理画面で確かめる） |
| 目的 | ピック完了の店頭受取の商品を、ついで買いの商品といっしょにスマレジで決済して引き渡し、元の受注が「引き渡し済み」、スマレジの取引から作った新しい受注が「出荷完了」になり、値引き・免税・在庫が取引のとおりに反映される |
| 種類 | 正常 |
| マトリクスの行 | `matrix_UOR-02/matrix.md` のT02（店頭受取（本店）・ECCUBE購入（店頭受取）・ついで買いあり・スマレジで免税区分が一般品の商品（内税）を免税にする）。引き渡しの流れ（業務フロー05 1-8〜1-9）とスマレジ在庫の反映（ついで買い）と免税を1回で通す |
| もとのシナリオ | SCN-ORDER-001・005 |

## 前提

- 共通の決まり：`../L4を流すときの共通の決まり.md` を先に読む（試験データの名前にシナリオIDを付ける・共有の設定は元に戻す・バッチの起動・店舗の読み替えなど）
- システムの外で済んでいること：UOR-01 の終点まで済んでいる（店頭受取の注文がピック完了で、商品とスタック用紙がレジ裏にある）。スマレジの会員とECの会員が紐付いている
- 用意するデータ（試験用の値。設計書の値ではない）
  - 会員：試験 太郎（`uor-02@example.test`）。本店の店頭受取（店頭支払）で「シナリオ試験カードA」（単価1,200円）を数量2で注文済み。注文番号と注文日を控えてある。受注は「ピック完了」
  - ついで買いの商品：店舗の「シナリオ試験ショーケース品B」（スマレジの商品、単価800円、スマレジ在庫10、部門の免税区分は「一般品」・内税）を1点
  - 店舗チームの担当者：管理画面とスマレジのレジを使える
- 会計：店頭受取分（部門「店頭受取」の商品）についで買いを足し、「シナリオ試験ショーケース品B」を免税にして決済する

## 操作の流れと期待値

| # | 操作する人と操作 | 期待値（画面で見えること） |
|---|---|---|
| 1 | お客様：レジ裏で受け取りに来て、注文日と名前を示す。店舗チーム：管理画面の受注情報検索で対応状況「ピック完了」の受注を探し、スタック用紙と突き合わせる | 注文日・お名前・ご注文番号が、スタック用紙・受注情報と一致する。対応状況は「ピック完了」 |
| 2 | 店舗チーム：スマレジのレジで、スタック用紙のバーコードを読み、ついで買いの「シナリオ試験ショーケース品B」を1点足す。ショーケース品Bを免税にして、支払いを済ませる | スマレジの取引が完了する。取引の合計は「小計 − 小計値引き − ポイント値引き − クーポン値引き ＋ 端数値引額 ＋ 外税額 ＋ 手数料 ＋ 送料 − 免税額」。免税額は、内税の一般品の商品の免税額になる。取引IDと取引の合計・免税額を控える |
| 3 | （システム）スマレジの取引完了がECに届き、ECが取引の詳細を取り込む。店舗チーム：管理画面の受注情報検索で、デフォルトの条件で検索する | 元の受注（手順1のご注文番号）は「引き渡し済み」になり、一覧に出ない（デフォルトの検索はキャンセル・引き渡し済みを除く） |
| 4 | 店舗チーム：手順1のご注文番号（引き渡し前の注文番号）で検索する | スマレジの取引から作られた新しい受注が1件見つかる。対応状況は「出荷完了」、配送方法は「店頭受取」、支払方法は「店頭支払」（スマレジの取引は支払方法をすべて店頭支払にする）。お名前は「試験 太郎」（会員） |
| 5 | 店舗チーム：新しい受注の受注情報編集を開き、明細と金額を見る | 明細は店頭受取分（「シナリオ試験カードA」数量2）とついで買い分（「シナリオ試験ショーケース品B」数量1）の両方。「免税額」が手順2で控えた内税の一般品の免税額と同じで、「合計」が手順2で控えた取引の合計と同じ。クーポン・小計値引きは使っていないので「クーポン値引き」「小計値引き/割引区分」には値が入らない（空または0かは設計書に定めが無く、記録） |
| 6 | 店舗チーム：在庫検索一覧で「シナリオ試験ショーケース品B」と「シナリオ試験カードA」の在庫を見る。在庫履歴を開く | ショーケース品Bのスマレジ在庫が10から9に減り、在庫履歴に変動区分「スマレジ売上」・理由「スマレジ連携（売上）による減算」が1件残る。「シナリオ試験カードA」の店頭受取分のスマレジ在庫は動かない（EC在庫は注文のときに減っていて、引き渡しでは変わらない） |
| 7 | お客様：マイページの購入履歴を開く | スマレジの取引から作った注文が出る。注文番号の欄には元の注文番号（注文元番号）が出て、リンクは付かない。購入日は店頭受取した注文の注文日。支払方法は「店頭支払」。処理状態は出ない |
