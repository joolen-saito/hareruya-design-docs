# UOR-04 取り置き期限（7日間）を過ぎた店頭受取（本店・支店）をキャンセルし、ピックした商品を戻す

| 項目 | 内容 |
|---|---|
| 利用者 | 店舗チーム（管理画面）。お客様への連絡と、後日の来店への対応はシステムの外 |
| 目的 | 注文日を含めて7日間を過ぎても受け取りに来ない店頭受取の受注を、店舗の人が「キャンセル」にし、ピックした商品を元の場所に戻す。お客様に連絡していなければ、後で来られたときにキャンセルを伝える |
| 種類 | 正常（期限超過のキャンセル） |
| マトリクスの行 | `matrix_UOR-04/matrix.md` のT01（店頭受取（本店）・店頭支払・お客様へ連絡せずキャンセルにし、キャンセル後に受取に来られたらキャンセルになった旨を伝える）。キャンセルから後日の来店までを通す |
| もとのシナリオ | SCN-ORDER-002・006 |

## 前提

- 共通の決まり：`../L4を流すときの共通の決まり.md` を先に読む（試験データの名前にシナリオIDを付ける・共有の設定は元に戻す・バッチの起動・店舗の読み替えなど）
- システムの外で済んでいること：UOR-01 の終点まで済んでいる（店頭受取の注文がピック完了で、商品とスタック用紙がレジ裏にある）。お客様は期限内に受け取りに来ていない
- 取り置き期限（7日間）を過ぎた受注は、試験で作った受注に限り、開発環境で注文日を期限より前に書き換えて用意する（2026-11-26 依頼者「おすすめどおり」。設計書に試験用の手段が無い）
- 用意するデータ（試験用の値。設計書の値ではない）
  - 会員：試験 太郎（`uor-04@example.test`）。本店の店頭受取（店頭支払）で「シナリオ試験カードA」を数量2で注文済みの受注。対応状況は「ピック完了」。注文日を含めて7日間を過ぎている（注文日が8日以上前）。在庫は注文のときに5から3に減っている
  - 店舗チームの担当者：管理画面で本店の受注を編集できる権限を持つ
- 注文日が8日以上前の受注の用意の方法は、設計書に定めが無い（判断待ち 1）
