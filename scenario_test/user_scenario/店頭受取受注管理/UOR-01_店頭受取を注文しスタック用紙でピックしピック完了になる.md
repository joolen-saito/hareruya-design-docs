# UOR-01 会員が店頭受取・スムーズ店頭受取を注文し、店舗がスタック用紙を出してピックし、取り置く

| 項目 | 内容 |
|---|---|
| 利用者 | 会員のお客様（国内）→ 店舗チーム（スタック用紙のプリンタ・タブレット・管理画面）→ SPLINKS・スマレジ（外部） |
| 目的 | お客様がスムーズ店頭受取（本店）をクレジットカード決済で注文し、店舗がスタック用紙を出してピックし、受注が「ピック完了」になって、ピックした商品とスタック用紙がレジ裏に置かれる |
| 種類 | 正常 |
| マトリクスの行 | `matrix_UOR-01/matrix.md` のT03（本店・スムーズ店頭受取・クレジットカード決済・カード（1つの状態）・2点・店舗のプリンタが自動で印刷する）。業務フロー05 の 2-1〜2-4 を通す |
| もとのシナリオ | SCN-ORDER-001・003・005 |

## 前提

- 共通の決まり：`../L4を流すときの共通の決まり.md` を先に読む（試験データの名前にシナリオIDを付ける・共有の設定は元に戻す・バッチの起動・店舗の読み替えなど）
- システムの外で済んでいること：本店にスタック用紙のプリンタ（30秒おきにECへ問い合わせる設定）とタブレットがある。スマレジの店舗が登録済み
- 用意するデータ（試験用の値。設計書の値ではない）
  - 会員：試験 太郎（メールアドレス `uor-01@example.test`、国内の住所を登録済み、フリガナは「シケン タロウ」、通常の購入グループ）。SPLINKSの試験環境で使える試験用のカード
  - 商品：カード「シナリオ試験カードA」（1つの状態、単価1,200円、本店の在庫5、購入制限数なし）。数量は2で買う（商品金額合計2,400円）
  - 店舗チームの担当者：管理画面にログインでき、本店の受注を編集できる権限を持つ
- 設定（開発環境の値）：配送方法「スムーズ店頭受取」に結び付く支払方法はクレジットカード決済・登録済みクレジットカード決済・支払いなし。店頭支払は結び付かない
- ポイントは使わない（スムーズ店頭受取のポイント欄は新実装も出す。2026-11-27 訂正：以前は「設計書と新実装で食い違う」と書いていたが、新実装を確かめたら食い違いは無い。Shopping/index.twig 123行）
