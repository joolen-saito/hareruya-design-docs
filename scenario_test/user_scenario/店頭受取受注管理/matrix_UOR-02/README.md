## 追加した因子（2026-11-18 レビュー指摘）

レビューの方の指摘「店頭受取＋ついで買いのパターンを追加し、スマレジにてクーポンを利用、スマレジにて値引き/割引を利用、スマレジで免税対象に設定された商品に対し会計時に免税設定を確認する」を受け、因子C「スマレジの会計での値引き・免税」（なし／クーポン／小計の値引き・割引／免税）を足した。因子が3つになったので `build_matrix.py` で作り直した（9行→12行、2因子間網羅率100%）。

- 禁則は足していない。設計書 0505 は、取引情報の小計値引き・小計値引き/割引区分・クーポン値引き・内税商品の一般品免税額・合計を購入パターンに関係なく取り込む項目として定めており、ついで買いのある会計だけに限る根拠が無いため。ついで買いありの行（水準B2）にも、なしの行（B1）にも、複数まとめて受け取る行（B3）にも、C2〜C4 が組まれる。
- 期待値（0505・0203 で言えること）：スマレジの取引から作られた新しい受注の受注情報編集で、クーポンを使った行は「クーポン値引き」が取引で使われたクーポンの値引き・割引額の合計、小計の値引き・割引を使った行は「小計値引き/割引区分」が取引で指定された区分、免税の行は「免税額」が取引の内税商品の一般品免税額になり、いずれも「合計」が取引の合計（小計−小計値引き−ポイント値引き−クーポン値引き＋端数値引額＋外税額＋手数料＋送料−免税額）と合う。
- 免税の水準（C4）は、部門の免税区分が「一般品」の商品に限る（2026-11-18 codex R2）。0505 が受注に取り込む免税の項目は「内税商品の一般品免税額」だけで、新実装もその値を免税額にする。部門の免税区分には「消耗品」もある（0204 部門登録「0:対象外、1:一般品、2:消耗品」）が、消耗品の免税額を受注へ入れる項目は設計書に無いので確かめない（設計書の不足。起票しない）
- 新実装は、小計値引き/割引の明細があればその値引額を「クーポン値引き」の欄に入れ、無ければ取引のクーポン値引きを入れる。設計書は小計値引き/割引の値引額を「クーポン値引き」とは別のものと書くので、小計の値引き・割引を使った行では欄の値が設計書と食い違う（`../scenario_list.md` の「設計書との食い違い」に記録）。期待値は合計と区分で確かめ、欄ごとの値引額は設計書の定義で確かめる。
