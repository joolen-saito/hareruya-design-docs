# 通販でポイントを使って買う（UPT-05）

IPA「高信頼化ソフトウェアのための開発手法ガイドブック」(2010) の表6-9〜6-11と同じ手順で作る（`通販/matrix/README.md` と同じ）。

1. 因子・水準表（FL表）: `fl_table.tsv`
2. 禁則表: `prohibitions.tsv`
3. マトリクス: `matrix.md` / `matrix.tsv`（`tools/build_matrix.py` が作る。1行が1本のシナリオ＝会員がご注文方法指定でポイントの使い方を決め、注文を確定し、残高・履歴・注文確認メールにその使用が出るまで）
4. 例外の差し込み表: `exceptions.tsv`

## 範囲

- 使用ポイントの上限・単位・全額への切り替え・支払方法との組み合わせ・消費の時点・購入直後の表示。付与の額と時点は UPT-01、スマレジの使用ポイント連携は USM-16・USM-17、取り消しでの戻しは UPT-07、ポイントを使えない入口（支店・店内アカウント・店頭受取）は UPT-06
- 支払方法の使い分け・配送方法・金額の上限そのものは UTS-01 のマトリクス（`通販/matrix/`）。ここはポイントによる切り替わり（使用ポイントを引いたお支払い額で選択肢が変わる）だけを見る

## 期待値の決まり（行ごとに当てはめる）

- 使用の上限：保有ポイントと支払総額（商品金額＋送料＋手数料）の小さい方。1ポイントは1円（0304 (6-6)「会員の保有ポイントと利用可能ポイントの小さい方」。新実装の入力欄の最大値と検査：`src/Eccube/Resource/template/default/Shopping/index.twig` 566〜568行、`src/Eccube/Form/Type/Shopping/OrderType.php` 175〜205行）
- 「ポイントを使う」を選ぶまで入力欄は使えない。入力欄の初期値は保有ポイントと支払総額の小さい方（設計書 0304 に「初期値を修正」の改訂履歴。OrderType.php 131〜141・406〜411行）
- 全額（B4）：使用ポイントが支払総額と同じになると支払方法は「全額ポイント支払い」（表示名は「支払いなし」）だけになり、手数料は0になる。使用を減らすと通常の選択肢に戻る（0304 処理概要。PointProcessor.php 98〜105・186〜216行）。購入直後の状態は注文受領（UTS-01の注）。郵便振替（C4）は注文受領、銀行振込（C5）は入金待ち（src/Eccube/Service/PurchaseFlow/Processor/OrderUpdateProcessor.php 45〜48行：銀行振込だけ入金待ち、ほかは新規＝注文受領）を、各行で確かめる
- 一部（B2・B3）：残りを選んだ支払方法（C1〜C4）で払う。代金引換（C2）・コンビニ決済（C3）は、使用ポイントを引いた額が上限以内でないと選べない（例外E1・E2）
- 確定後（購入完了画面）：会員の保有ポイントが使用分だけ減り（A1で使い切れば0）、ポイント履歴に使用（−）が注文番号つきで1行残る。マイページと管理画面の受注詳細に「ポイント使用（値引き）」が「N ポイント」と出る（0304 注文購入履歴詳細「0のときも「0 ポイント」」）。注文確認メールに「ポイント使用(値引き)：N ポイント」（英語は「Points Used : N Points」）が出る。付与予定ポイントは（小計−使用）×還元率（UPT-01）
- 消費の時点：注文を確定した時点。ただしSPLINKS決済（クレジットカード・コンビニ）は購入完了画面の表示時（0304 ご注文完了「ポイントの消費時期」）。購入完了のあと、スマレジの使用ポイント連携を別プロセスで実行する（USM-16）
- D2（英語）：同じ使用ポイント欄が出る。英語のヘルプ（help_onlineshop.en.twig 492行）は「Prepaid Pickup」でもポイントを使えると書くが、新実装は店頭受取系で隠す（UPT-06）

## 実装で確かめたこと（2026-11-05）

- 支払方法の選択肢は、使用ポイントを引いたお支払い額で決まる（`OrderType.php` 221・259行：支払総額から手数料を引いた額に各支払方法の手数料を足して上限・下限と比べる）。通販 `matrix/README.md`「商品金額合計と支払方法の上限・下限」と同じ
- 開発環境：換算は1ポイント1円、ポイント設定は全店舗で有効（DBダンプ 2026-09-07）
- 使用ポイントの最小は新実装に定めが無く、1ポイントから使える（`OrderType.php` 118〜130行：数字の検査と桁数だけ）。ヘルプは「10ポイントよりご使用いただけます」（例外E6。判断待ち）

## まとめた水準

- C1：クレジットカード決済と登録済みクレジットカード決済。ポイントの使い方・上限・消費の時点・表示が同じで、違いはカード情報の入力の有無だけ（UTS-01のマトリクスで分けている）
