# UPT-05 会員が通販でポイントを使って買い、使用ポイントが保有ポイント・ポイント履歴・注文確認メールに出る

| 項目 | 内容 |
|---|---|
| 利用者 | お客様（会員。本店のEC）→（SPLINKS。システムの外）→ EC → スマレジ（システムの外）→ お客様（メール・マイページ）・通販チーム（管理画面で確かめる） |
| 目的 | 会員がご注文方法指定で「ポイントを使う」を選んで使用ポイントを入れ、注文を確定する。使用ポイントが保有ポイントと支払総額の小さい方まで入れられ、全額にすると支払方法が「全額ポイント支払い」だけになる。注文確定（SPLINKS決済は購入完了画面の表示）で保有ポイントが使用分だけ減り、ポイント履歴に使用の行が注文番号つきで残り、注文確認メールとマイページ・管理画面の受注にポイント使用（値引き）が出る。付与予定ポイントは（小計−使用ポイント）×還元率（切り捨て）で出る |
| 種類 | 正常（組み合わせ表の16行。1行が1回流すテスト1本）＋例外6件 |
| マトリクスの行 | `matrix_UPT-05/matrix.md` のT02（保有ポイントが支払総額より少ない・小計より少なく使う・銀行振込）。T01・T03〜T16 と例外 E3〜E8 は「L3で変わるところ」 |

使用ポイントの上限・単位・全額への切り替え・支払方法との組み合わせ・消費の時点・購入直後の表示を確かめる。支払方法の使い分け・配送方法・金額の上限そのものは UTS-01 のマトリクスに任せる。使用ポイントを引いた額で支払方法の選択肢が変わる出し分け（代金引換・コンビニ決済の上限）は確かめない（2026-11-10 依頼者決定）。
