# UPT-02 通販チームが出荷の前後に受注の内容（明細・数量・支払方法・使用ポイント）を変え、付与予定ポイントが再計算される

| 項目 | 内容 |
|---|---|
| 利用者 | 通販チーム（管理画面の受注情報編集）→ お客様（マイページ） |
| 目的 | 通販チームが受注情報編集で明細の削除・数量の変更・支払方法の変更・使用ポイントの変更を保存すると、付与予定ポイント（受注の「ポイント発生」）が（小計−使用ポイント）×還元率（切り捨て）に再計算され、受注詳細とマイページの注文履歴詳細に出る。会員の保有ポイントは出荷前は変わらず、出荷のあとの一部の変更でも付与済みは変わらない。「ポイント発生」の入力欄に値を入れても無視される。支払方法を店頭支払に変えると付与予定が0になる。使用ポイントを変えても会員の保有ポイントは変わらない（Excelの設計書） |
| 種類 | 正常（組み合わせ表は無い。代表の1本＋L3の7件） |
| マトリクスの行 | なし（組み合わせ表は無い。`matrix_UPT-02/` は作っていない）。L3 は `scenario_list.md` の UPT-02 の L3 欄の項目（変える内容：明細の削除／数量／支払方法（店頭支払・それ以外）／使用ポイントの増減。変更の時点：出荷前／出荷後（付与済み））を1つずつ別のテストにした（R1〜R8）。代表は「数量の変更・出荷前」 |
| もとのシナリオ | なし（受注情報編集 UTS-02 の一部の取り消しのポイントの部分を、付与予定の再計算の値まで数える一本として足した）。付与の額と時点は UPT-01、取り消しでの戻しの値は UPT-07 |

## L3で変わるところ（組み合わせ表は無い。1つずつ別のテストにする）
