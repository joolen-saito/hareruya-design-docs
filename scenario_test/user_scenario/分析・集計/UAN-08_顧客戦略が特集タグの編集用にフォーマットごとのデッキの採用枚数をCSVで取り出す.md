# UAN-08 顧客戦略が特集タグの編集用に、フォーマットごとのデッキの採用枚数をCSVで取り出す

| 項目 | 内容 |
|---|---|
| 利用者 | 顧客戦略 → 管理画面（特集タグ編集CSVダウンロード）→ CSV。デッキとカードの商品は登録担当・顧客戦略がこの L4 の準備で作る |
| 目的 | 特集の効果を見るために、フォーマットと期間を決めて CSV を出す。CSV の採用枚数が、デッキ登録（UDK-01・UDK-03 の操作）で作ったデッキのカード枚数から手で計算した値と一致し、公開中のイベントのデッキだけが数えられ、販売数の列が価格管理（UPC-08）のバッチ結果と同じ値になることを確かめる |
| 種類 | 正常（組み合わせ表の8行）＋例外2件 |
| マトリクスの行 | `matrix_UAN-08/matrix.md` の T04（フォーマット＝複数選ぶ・基本土地＝含める・集計日(To)＝空のまま・デッキ＝公開中のイベントのデッキ・イベント日付＝集計期間の中・カードの代表商品＝代表の商品がある）。T01〜T03・T05〜T08 と例外 E1・E2 は「L3で変わるところ」 |
| もとのシナリオ | なし（今のシナリオ SCN-* に分析・集計のものは無い。0211 M12-09・M12-10 から起こした）。採用枚数略式CSVダウンロードは廃止（0211 特集タグ編集CSVダウンロード(検索項目)） |

## 前提

- 共通の決まり：`../L4を流すときの共通の決まり.md` を先に読む（試験データの名前にシナリオIDを付ける・共有の設定は元に戻す・バッチの起動・店舗の読み替えなど）
- システムの外で済んでいること：デッキの内容（デッキリスト・大会名・開催日）を取得していること（UDK-01 の前提と同じ。この試験では下の値を取得済みの内容として使う）。集計の表・バッチは使わない（CSV を出すたびにデッキを数える）。販売数の3列だけ、価格管理の期間別販売数集計バッチ（UPC-08）の結果を使う
- 共有の開発環境にはほかの試験のデッキ・カードも入っている。試験のカード・デッキは、この L4 のために新しく作る（名前の末尾に行の番号を付け、カード名は試験専用）ので、CSV のうち試験のカード名（カード名(英)が「Scenario Test UAN-08 …」のもの）の行だけを見て比べる。CSV の総行数は記録にする
- 用意するデータ（試験用の値。設計書の値ではない。行ごとに別のカード・商品・デッキを作る。名前の末尾に行の番号 T04 などを付け、後ろにシナリオIDを付ける）
  - 担当者：顧客戦略（特集タグ編集CSVダウンロードとデッキ管理を使えるメンバー）。登録担当（カード・商品の登録）。在庫の承認者
  - カード（カード登録CSV。UPM-02 の手順0と同じ）：
    - 「分析試験カードX UAN-08 T04」（英名「Scenario Test UAN-08 X T04」）：代表の商品を作るカード
    - 「分析試験カードY UAN-08 T04」（英名「Scenario Test UAN-08 Y T04」）：商品を作らないカード（代表の商品が無い）
    - 「分析試験基本土地 UAN-08 T04」（英名「Scenario Test UAN-08 Land T04」）：特殊タイプ「基本」（特殊タイプが基本だけ）。代表の商品を作る
    - 「分析試験フィラー UAN-08 T04 01」〜「11」（英名「Scenario Test UAN-08 Filler T04 01」〜）：デッキを60枚にするための11枚。商品は作らない
  - 商品（カード商品CSV。UPM-02 の手順1と同じ）：カードX・基本土地それぞれ、日本語・NM を含む1商品（4規格ができ、商品コードは新実装が自動で作る）。在庫は、在庫変更CSVでカードXの NM に 5点（本店の EC-CUBE 在庫。基本土地は 0 のまま）。商品IDと商品コードを控える。カードY・フィラーは商品を作らない
  - デッキ（管理画面のデッキ管理＞デッキ一覧の「新規登録」。UDK-01 の手順4と同じ操作。メインボード 60枚、サイドボードは空（フォーマットのサイドの最小枚数は 0）、統率は空）：
    - デッキα：フォーマット「スタンダード」。デッキタイプ「event」。公開状態「公開」。大会は晴れる屋の開催済みのイベント（UDK-01 の P2 と同じ手順で登録。開催日は S の前日 12:00）。メイン：カードX 4枚・カードY 4枚・基本土地 12枚・フィラー01〜10 各4枚（40枚）＝60枚
    - デッキβ：フォーマット「モダン」。そのほかはデッキαと同じ。メイン：カードX 2枚・カードY 2枚・基本土地 12枚・フィラー01〜11 各4枚（44枚）＝60枚
  - 試験日（S）：流す日。集計日（From）＝S の7日前
- 販売数の3列（当日販売数・1週間販売数・1ヵ月間販売数）は、価格管理の期間別販売数集計バッチ（UPC-08）の結果と同じ値。この L4 では注文を作らないので、カードXの販売数は 0 になる（0 でなければ、UPC-08 の手順で集計した値と同じことだけを見る）
- 期待値の決まり（0211 特集タグ編集CSVダウンロード 現行仕様）：対象は指定したフォーマットの公開中のデッキのうち、イベントのデッキで、イベント日付が集計日(From)の 0:00:00 から集計日(To)の 23:59:59 まで。集計日(To)が空なら出力した日。採用枚数＝対象のデッキに入っているそのカードの枚数の合計。カードごとに代表の商品を1件選び、商品ごとに1行（代表の商品が無いカードは出ない）。基本土地を含めない指定では、特殊タイプが基本だけのカードは出ない。行は採用枚数の多い順。出力条件（集計日・フォーマット・基本土地）は CSV の列に出ない
