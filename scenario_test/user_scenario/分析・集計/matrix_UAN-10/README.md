# 分析・集計の閲覧商品のアクセス解析への連携（UAN-10）

IPA「高信頼化ソフトウェアのための開発手法ガイドブック」(2010) の表6-9〜6-11と同じ手順で作る。

1. 因子・水準表（FL表）: `fl_table.tsv`
2. 禁則表: `prohibitions.tsv`
3. 組み合わせテストマトリクス: `matrix.md` / `matrix.tsv`。`build_matrix.py` が作る。1行が1本のシナリオになる
4. 例外の差し込み表: `exceptions.tsv`。エラーや中断（★の手順）は正常な値と混ぜず、条件に合う行へ1つずつ差し込む

## 範囲

- お客様が買い物かご・商品詳細・商品一覧（検索結果を含む）・TOP画面を開いたとき、ページに積まれるアクセス解析用の値（閲覧商品の連携 F10-03）が、画面に出ている商品と合うか
- 見るのは、ブラウザの開発者ツールで見るページ内の受け渡し領域の中身。GTM・GAの側の設定は作っていない（`matrix_UAN-09/` の範囲と同じ）
- 商品が非公開で表示できない商品詳細は、並びの状態ではなく例外（E3）で扱う

## 期待結果の決まり（行ごとに当てはめる）

| 画面 | 積む値 |
|---|---|
| 買い物かご（A1） | 商品IDの並び（かごの明細の並び順で、同じ商品IDは2回目以降を飛ばす。規格違いでも商品が同じなら1つ）と、かごの合計金額（税込の販売価格×数量の合計。送料・手数料は含まない。かごが空なら並びは空・金額は0）を1つの要素で |
| 商品詳細（A2） | 表示している商品の商品IDと、初期表示する言語・商品規格の税抜の販売価格を1つの要素で。カードで基本土地でないときは、同名の商品の並びも別に積む |
| 商品一覧・TOP画面（A3・A4） | 差し込む商品の並びごとに1件（商品IDの並び。同じ商品IDは2回目以降を飛ばす）。TOP画面は商品リスト（新着・値下げ・おすすめ）ごと。検索結果が0件のときは積まない |
| お気に入り一覧・入荷通知一覧（A5） | 積まない |

- ログインの有無（B）によらず同じ値を積む。英語サイト（C2）は同じ項目名で積み、商品詳細の販売価格だけが日本語サイトと違う値になりうる
- 商品詳細の初期表示の言語・規格（F）：言語の指定があればその言語、無ければ日本語サイトは日本語版・英語サイトは英語版、その言語の商品が無ければ商品が持つ先頭の言語。規格は、指定があり決まった言語にあればその規格、無ければ決まった言語の先頭の規格
- 利用者が画面上で言語や状態を切り替えても積み直さない（E1）

## 実装で確かめたこと（2026-11-05）

- 0310 は専用のExcelシートが無く、現行ソースからの機能仕様書がそのままの正本。新実装との照合は、実行して確かめる

## まとめた水準

なし（どの水準も処理が違う）。主な根拠：買い物かご・商品詳細・商品一覧・TOP画面・お気に入りは積む項目（gtm_cart_ids・gtm_product_id・gtm_search_ids など）が画面ごとに違い、お気に入り・入荷通知一覧は積まない。カード基本土地・基本土地以外・カード以外は同名商品の並びを差し込む条件が違い、日本語・英語は商品詳細の販売価格が変わりうる。
