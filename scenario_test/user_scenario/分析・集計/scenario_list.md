# 分析・集計：シナリオ一覧（L2）

シナリオ1本は「起点の業務イベントから、業務として完了した状態になるまで」とする。分析・集計は業務一覧の#11（店舗統括・エリアマネージャー）と#12（顧客戦略）の「施策検討のためのデータ分析」で、「定常業務ではないため、業務フローは無し」（`scenario_test/markdown/02_業務一覧.md`）。そのため業務フローパターンの網羅の代わりに、設計書のシートごとの網羅（`## 設計書の網羅`）で漏れを防ぐ。

分析のシナリオの終点は、「分析の画面・CSVに出た値が、取引のシナリオで作ったデータから手で計算した値と一致すること」。取引は他の業務のシナリオIDで参照し、この業務では作らない。期待値は取引から手で計算し、集計画面の値を期待値にしない。日をまたぎ、集計の表がバッチの更新を待つものは別の1本にする。ただし、集計画面が毎回その場で受注を数えるもの（受注売上分析・フォーマット売上分析）は、バッチを待たない。
