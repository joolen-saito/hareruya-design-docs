# 期間別入庫数集計と在庫リコメンドCSV（分析・集計）（UAN-11）

IPA「高信頼化ソフトウェアのための開発手法ガイドブック」(2010) の表6-9〜6-11と同じ手順で作る（FL表→禁則表→2因子間網羅の組み合わせ）。1行が1回ずつ流すテスト1本で、行の中の水準は条件ごとに1つ（2026-11-09 に scenario_list.md の L3 欄で「／」で並べていた値を分けた）。

## 範囲

- 入庫した数が期間別入庫数集計のバッチで集計され、在庫リコメンドCSVの週間入庫数・月間入庫数が入庫した数と一致するかを、在庫が増えた理由ごとに1行ずつ確かめる
- 親区分が「入庫」「買取」のものは数える（D15-1）。移動・分割・結合・キャンセルの戻しは数えない（D15-2）。在庫が減った履歴は数えない
- 期間（前日・3日間・1週間・1か月（28日）・90日・180日・365日）は、1回の実行で全部が同時に決まる集計の列なので、毎回全部を確かめる（選ぶ条件ではない）
- 閉店した店舗、再実行は、正常な値と混ぜず例外で差し込む

## 期待値（本文の記述を値ごとに分けただけ。新しい期待値は足していない）

| 在庫が増えた理由 | 期待値 |
|---|---|
| 入庫・買取 | 期間別入庫数集計に含まれ、在庫リコメンドCSVの入庫数が入庫した数と一致する |
| 移動・分割・結合・キャンセルの戻し | 含まれず、在庫リコメンドCSVの入庫数に入らない |

## まとめた水準

なし（どの水準も結果が違う）。

## 分ける前の記述

- シナリオ：入庫した数が期間別入庫数集計のバッチで集計され、在庫リコメンドCSVの入庫数が新しくなる
- 起点：入庫のあとで、期間別入庫数集計を動かす
- 終点（目で確かめる結果）：在庫リコメンドCSVの週間入庫数・月間入庫数が、入庫した数と一致する。移動・分割で入庫した分は含まれない
- 通る状態：入庫数の集計の表：洗い替え
- L3 バリエーション：入庫の種類：入庫・買取は数え、移動・分割・結合・キャンセルの戻しは数えない。期間：前日・3日間・1週間・1か月（28日）・90日・180日・365日。在庫が減った履歴は数えない。閉店した店舗は対象外。履歴が無い単位の前回値：設計書の現行仕様は残ると書くが、新実装は集計の表を全削除して作り直すので消える（食い違い）。再実行しても二重に足されない。実行のしかたは手動実行（新しい0402に従う）。マトリクスは作らない（入庫の種類と期間は1行ずつ独立に決まり、効き合う因子が無い） 個別に確かめる分岐（2026-11-06）：移動・分割などで入庫した在庫（在庫移動の入庫完了・分割の承認で増えた分）は、期間別入庫数集計に含まれず、在庫リコメンドCSVの入庫数に入らないことを確かめる。
