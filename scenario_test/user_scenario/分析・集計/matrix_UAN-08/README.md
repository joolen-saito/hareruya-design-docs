# 分析・集計の特集タグ編集CSV（UAN-08）

IPA「高信頼化ソフトウェアのための開発手法ガイドブック」(2010) の表6-9〜6-11と同じ手順で作る。

1. 因子・水準表（FL表）: `fl_table.tsv`
2. 禁則表: `prohibitions.tsv`
3. 組み合わせテストマトリクス: `matrix.md` / `matrix.tsv`。`build_matrix.py` が作る。1行が1本のシナリオになる
4. 例外の差し込み表: `exceptions.tsv`。エラーや中断（★の手順）は正常な値と混ぜず、条件に合う行へ1つずつ差し込む

## 範囲

- 管理画面の「特集タグ編集CSVダウンロード」（M12-09）と「特集タグ編集CSVダウンロード CSV出力」（M12-10）で、デッキの採用枚数が、顧客戦略チームのデッキの登録（UDK-01・UDK-03）と合うか
- 採用枚数略式CSVダウンロードは廃止（0211 特集タグ編集CSVダウンロード(検索項目)）。特集タグ編集用のCSVだけ

## 期待結果の決まり（行ごとに当てはめる）

- 対象：指定したフォーマットの公開中のデッキのうち、イベントのデッキで、イベント日付が集計日(From)の0時0分0秒から集計日(To)の23時59分59秒まで。集計日(To)が空なら出力した日
- 採用枚数＝対象のデッキに入っているそのカードの枚数の合計。カードごとに代表の商品を1件選び、商品ごとに1行。代表の商品が無いカードは出ない
- 基本土地を含めない指定では、基本土地のカードは出ない
- 並び：採用枚数の多い順
- 列：商品ID・商品コード・商品名(日)・在庫数（本店ECの在庫）・販売価格・買取価格・言語・カード名(英)・カードセット略称・レアリティ・Foilフラグ・状態コード・当日販売数・1週間販売数・1ヵ月間販売数（いずれも本店ECの販売数）・採用枚数・タグ（0211 特集タグ編集CSVダウンロード CSV出力）
- 販売数の列は、価格管理（UPC-08）の期間別販売数集計と同じ値になる

## 実装で確かめたこと（2026-11-05）

- 集計日(From)の初期値は2週間前（`src/Eccube/Form/Type/Admin/Analysis/SearchUsedCardType.php` 47行目）。設計書は、新しい版の基本設計が「2週間前の日付」、古い版の詳細設計が「当月1日」。新しい版と新実装に従った（`scenario_list.md` の食い違い）

## まとめた水準

なし（どの水準も処理が違う）。主な根拠：フォーマット1つ・複数、基本土地の含める・含めない（含めないと基本だけのカードを除く）、集計日(To)の指定・空、公開中のデッキ・公開中でないデッキ・イベントでないデッキ、期間の内外、代表の商品の有無は、いずれもCSVに入る・入らない行が違う。
