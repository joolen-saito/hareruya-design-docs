# 会員管理のお客様の会員登録申込（UMB-01）

IPA「高信頼化ソフトウェアのための開発手法ガイドブック」(2010) の表6-9〜6-11と同じ手順で作る。

1. 因子・水準表（FL表）: `fl_table.tsv`
2. 禁則表: `prohibitions.tsv`
3. 組み合わせテストマトリクス: `matrix.md` / `matrix.tsv`。`build_matrix.py` が作る。1行が1本のシナリオになる
4. 例外の差し込み表: `exceptions.tsv`。エラーや中断（★の手順）は正常な値と混ぜず、条件に合う行へ1つずつ差し込む

## 範囲

- お客様が「会員情報登録」から入力→確認→登録し、仮会員になる（または、仮会員機能が無効なら本会員になる）ところまで（0306 F06-01）。仮登録メールのURLを開いてからは UMB-02、スマレジの会員作成は USM-12
- 1行は「国（B）・任意項目（C）・確認画面での操作（D）で、仮会員機能の設定（A）のもとに登録する」手順。入力する会員情報（氏名・メール・パスワードなど）はテストごとに専用のものを使う
- ブラックリストに該当したときの登録エラーは `matrix_UMB-23/`（場面B1）で確かめる。ここでは扱わない
- 表示言語は因子にしない。0306 新規会員登録に英語の文言・メールの定めが無く（設計書は日本語の文言だけ）、新実装で言語ごとに登録の流れが変わる記述も見つからなかったため

## 期待結果の決まり（行ごとに当てはめる）

| 仮会員機能（A） | 登録を押したあと | メール | 会員の状態 |
|---|---|---|---|
| A1 有効 | 仮会員登録完了画面（「現在、仮登録の状態となっております。」）。メールを待つ | 仮会員登録完了メール（本登録のURL入り） | 仮会員 |
| A2 無効 | 本会員登録まで一気に進み、ログイン状態で本登録完了画面が出る（スマレジの会員作成は USM-12） | 本会員登録完了メール | 本会員 |

| 他の因子 | 期待 |
|---|---|
| B1 Japan | 郵便番号は〒3桁-4桁、住所（都道府県）が出て、住所3は出ない。確認画面も同じ並び |
| B2 Japan以外 | 郵便番号は汎用の入力形式、住所（都道府県）は出ず、住所3が出る。確認画面も同じ。会員住所にも入力した郵便番号を控える |
| C2 任意項目を入れる | 入れた性別・会社名・職業・MTG Campaign 登録名が確認画面に出て、会員情報と選手情報に保存される（MTG Campaign 登録名は選手情報にも持つ） |
| D2 戻って直す | 「戻る」で入力内容が維持された入力画面に戻り、直してもう一度確認画面へ進める |

- 保存されるもの：会員情報・住所情報（既定のお届け先。住所名は「会員情報住所 / Membership Information Address」）・選手情報・デッキ登録用ユーザーID（英数字8文字のランダム文字列で一意）。支店への会員データ連携は不要（0306 新規会員登録 カスタマイズ説明）
- 入力エラー・登録済みメール・仮登録のままの会員は `exceptions.tsv` の例外で確かめる

## 実装で確かめたこと（2026-11-05）

- 仮会員機能・ログイン状態の保持・ポイントは、開発環境（DBダンプ 2026-09-07 の店舗基本情報）の全店舗で有効。仮会員機能を無効にした行（A2）は店舗基本設定を切り替えて確かめ、終わったら有効に戻す
- 有効のとき確認メールを送って完了画面へ、無効のとき本会員登録の画面へ進む：`src/Eccube/Controller/Front/EntryController.php` 207〜230行目
- 登録済みのメールアドレスは「このメールアドレスは利用できません。」：`src/Eccube/Entity/Customer.php` 48行目、`src/Eccube/Resource/locale/validators.ja.yaml` 64行目（0306 に定めなし。`scenario_list.md` の食い違い）
- メールアドレスの形式・確認メールの不一致の文言は、Excel由来（機能仕様）の「有効なメールアドレスではありません。」「同じメールアドレスを入力してください。」を採る（表示メッセージ節の F06-01-MSG-005・006 と違う。優先順位は Excel由来＞表示メッセージ節）
- パスワードの最小文字数12は、`app/config/eccube/packages/eccube.yaml` 223行目（最大50は224行目）

## まとめた水準

- 任意項目（性別・会社名・職業・MTG Campaign 登録名（姓・名））：C2 にまとめた。どれも必須でなく（0306 新規会員登録 識別ID 1-9・1-21〜1-24 の必須が「-」）、確認画面（2-5・2-15〜2-18）に表示するだけで、入力した値がそのまま保存されるため、流れ・処理・期待値が変わらない
- 国：Japan とそれ以外の2つ。国の選択肢は多数あるが、0306 は「Japan」か「Japan以外」だけで表示を分けている
