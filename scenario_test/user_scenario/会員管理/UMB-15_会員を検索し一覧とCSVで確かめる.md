# UMB-15 店舗チームが会員を検索し、一覧とCSVで確かめる

| 項目 | 内容 |
|---|---|
| 利用者 | 店舗チーム（管理画面の会員一覧）→ CSV |
| 目的 | 店舗チームが管理画面の会員検索で条件を入れて検索し、該当した会員の一覧と件数（「検索結果：N件が該当しました」。無いときは「検索条件に合致するデータが見つかりませんでした」）を確かめる。チェックを入れた会員だけが顧客情報CSV（既定の出力項目20と、そのほかの項目）に出る。検索条件は検索パターンとして保存・呼び出し・削除できる。会員は一覧から削除できる |
| 種類 | 正常（組み合わせ表は作らない。検索条件の種類ごとの確かめを下の表に1行ずつ載せた）＋例外（パターン名なし・チェックなしのCSV・ページをまたいだ選択・関連データ） |
| マトリクスの行 | 組み合わせ表は無い（検索条件は互いにANDで、効き合う因子が無い。`scenario_list.md` の L3 欄）。以下の行は「表外の具体例」 |
| もとのシナリオ | なし（今のシナリオに対応が無い） |
