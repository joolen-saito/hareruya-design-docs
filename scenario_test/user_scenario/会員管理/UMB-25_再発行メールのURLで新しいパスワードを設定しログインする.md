# UMB-25 再発行メールのURLで新しいパスワードを設定し、新しいパスワードでログインする

| 項目 | 内容 |
|---|---|
| 利用者 | お客様（再発行メールを受けた本会員）→ メール |
| 目的 | 再発行メールを受けた会員が、24時間以内にメールのURLを開き、再設定画面でメールアドレスと新しいパスワードを入れて「変更する」を押すと、「パスワードを変更しました。」が出る。ログイン状態にはならず、新しいパスワードでログインできる（古いパスワードではログインできない） |
| 種類 | 正常（組み合わせ表は作らない。代表1本＋L3の表の行） |
| マトリクスの行 | 組み合わせ表は無い（入力の種類を1つずつ確かめる。`scenario_list.md` の L3 欄）。以下の行は「表外の具体例」 |
| もとのシナリオ | なし（今のシナリオに対応が無い） |

## 前提

- 共通の決まり：`../L4を流すときの共通の決まり.md` を先に読む（試験データの名前にシナリオIDを付ける・共有の設定は元に戻す・バッチの起動・店舗の読み替えなど）
- 前のシナリオの終点：UMB-05 の代表の流れ（手順1〜3）の終点（`scenario_list.md` の UMB-05 の終点「メールアドレスを送ると再発行メールの送信完了画面（「パスワード再発行メールの送信が完了しました。」）が出て、本会員には再設定のURL入りのメールが届く（リセットキーは24時間有効）」）。この試験専用に会員を新しく作って、同じ手順で再発行メールを受けた状態にする。URLを使った再設定が、この試験の範囲
- 用意するデータ（試験用の値。設計書の値ではない）
  - 本会員（行ごとに1人、この試験専用。K01〜）：お名前「試験 会員UMB25」、メールアドレス `umb25-t01@example.test`（行ごとに `umb25-k02@example.test` のように行番号を入れる）、旧パスワード「Umb25Old-2026a1」。UMB-01 の手順1〜7と UMB-02 の手順1〜2で、この試験専用に作る。そのあと UMB-05 の手順1〜3で、再設定のメールを受ける
  - 新しいパスワード（試験用の値）：「Umb25New-2026b2」（12文字以上・50文字以内。英字と数字を1つ以上含む）
  - 別の会員（例外E4・K04用）：本会員 `umb25-other@example.test`（旧パスワード「Umb25Oth-2026c3」）
  - 再設定のメールの受け口：`umb25-t01@example.test` などのメールを読める手元の受け口。メールの再設定のURLは、開発環境のドメインになっているか確かめる。本番のドメインに決め打ちされているときは、URLの道筋の部分だけを開発環境のアドレスに替えて開く（記録する）
  - 手順の前に控える値：メールの再設定のURL（行ごとに別のURL）、メールを受けた時刻（24時間以内に流す）
- 画面の名前・文言は新実装の表示で書く

## 操作の流れと期待値

| # | 操作する人と操作 | 期待値（画面で見えること） |
|---|---|---|
| 1 | お客様：再発行メールの再設定のURLを開く（メール受信から24時間以内） | 見出し「パスワード再設定」の画面が開く。「登録されているメールアドレスと新しいパスワードを入力して変更ボタンをクリックしてください。」と、「登録されているメールアドレス」「新しいパスワード」「新しいパスワード（確認）」の入力欄（どれも必須）、「変更する」のボタンが出る。ログインしていない状態 |
| 2 | お客様：「登録されているメールアドレス」に `umb25-t01@example.test`、「新しいパスワード」と「新しいパスワード（確認）」に「Umb25New-2026b2」を入れて「変更する」を押す | パスワード再設定完了の画面が出て、「パスワードを変更しました。」と「戻る」のボタンが出る。ログインした状態にはならない（ヘッダーに「ログイン」が出たまま。マイページには入っていない） |
| 3 | お客様：「戻る」でトップを開き、ログイン画面で `umb25-t01@example.test` と新しいパスワード「Umb25New-2026b2」でログインする | ログインでき、トップページが開く（ログインのあとの既定の行き先。新しいパスワードで入れる）。続けてヘッダーからマイページを開くと、マイページが開く（ログイン状態） |
| 4 | お客様：ログアウトし、同じメールアドレスと旧パスワード「Umb25Old-2026a1」でログインを試みる | ログインできず、ログイン画面に「ログインできませんでした。入力内容に誤りがないかご確認ください。」が出る（古いパスワードではログインできない） |
| 5 | お客様：手順1と同じ再設定のURLを、もう一度開く | 再設定画面は出ず、エラーの画面に「アクセスできません」「有効期限が切れているか、無効なURLです。」が出る（再設定が済むとリセットキーが削除されるので、同じURLは使えない） |

## 終わったあとに確かめること

| 確かめる場所 | 期待値 |
|---|---|
| ログイン | 新しいパスワードでできる。旧パスワードではできない |
| 会員の状態・氏名・メールアドレス | 変わらない（パスワードだけが変わる） |
| リセットキー | 使われて削除された（手順5で同じURLが開けないことで確かめる） |
| ログインの失敗の回数 | 手順4で1回失敗しただけなので、ログインできなくなる（同じメールアドレスと同じIPアドレスで5回続けて失敗）には達しない |

## L3で変わるところ（組み合わせ表は無い。1つずつ別のテストにする）

手順の番号は上の「操作の流れと期待値」。行ごとに会員とメールの再設定のURLを別に用意する（会員のメールアドレスは行番号を入れる）。

| 行 | 条件 | 変わるところ（期待値） |
|---|---|---|
| K01 | 正常（代表） | 代表の行 |
| K02 | URLのキーが英数字以外 | 手順1：メールの再設定のURLの末尾のキーの文字列に、記号「-」を1文字足して開く。再設定画面は出ず、エラーの画面に「アクセスできません」「お探しのページはアクセスができない状況にあるか、移動もしくは削除された可能性があります。」が出る（リセットキーの書式エラー。E-1）。手順2〜5は流さず、元のURLで手順1〜2が通ることだけ確かめる（キーを足しただけで元のURLは無効にならない） |
| K03 | 新しいパスワードがメールアドレスと同じ | 手順2：「新しいパスワード」と「新しいパスワード（確認）」に、メールアドレスと同じ値（`umb25-k03@example.test`）を入れて「変更する」を押す。変更されず、再設定画面に留まり、「新しいパスワード」の下に「パスワードはメールアドレスと同じ値を設定できません。」が出る。旧パスワードでログインできる |
| K04 | 再設定画面に入れるメールアドレスが、URLのキーの会員と別の会員のもの | 手順2：「登録されているメールアドレス」に、別の会員のアドレス `umb25-other@example.test` を入れ、新しいパスワードを入れて「変更する」を押す（【決着 2026-11-09】更新されない。新実装は、リセットキーとメールアドレスの両方が一致する会員だけを探す）。パスワードは更新されず、再設定画面に留まり、メールアドレスの欄の下に「入力内容を確認してください。」が出る。手順3〜4：この会員（`umb25-k04`）は旧パスワードでログインできる。別の会員（`umb25-other`）の旧パスワードも変わらない。そのあと、正しいメールアドレスで入れ直すと、同じURLで変更できる（キーは使われていない） |
| K05 | 確認欄への貼り付け | 手順2：「新しいパスワード」に入れた値を、「新しいパスワード（確認）」の欄に貼り付ける操作（貼り付けのショートカット）をする。貼り付けが取り消され、警告「確認のためもう一度入力してください」が出る（設計書の文言。新実装は貼り付けの警告に「パスワード確認欄には貼り付けできません。」を出すので、その文言が出たら不合格として記録し、食い違いに書く）。確認欄は手で入力し直す |
| K06 | 新しいパスワードが12文字未満 | 手順2：「Umb25a1」（7文字）を入れて「変更する」を押す。変更されず、「新しいパスワード」の下にエラーが出る（文言は新実装の表示を記録）。設計書：「未入力、12文字未満の状態で、(3-5)「変更する」ボタンを押下した場合はエラーメッセージを表示する」 |
| K07 | 確認欄が新しいパスワードと違う | 手順2：「新しいパスワード（確認）」に別の値を入れて「変更する」を押す。変更されず、「同じパスワードを入力してください。」が出る |
| K08 | 英字だけ・数字だけのパスワード | 手順2：「Umbabcdefghijkl」（英字のみ・12文字以上）を入れて「変更する」を押す。変更されず、「英数字をそれぞれ1種類使用してください。」が出る |
| K09 | メールアドレスの形式が正しくない | 手順2：「登録されているメールアドレス」に「umb25-k09」（@の無い値）を入れて「変更する」を押す。変更されず、メールアドレスの欄の下に「有効なメールアドレスではありません。」が出る |
| K10 | 保存パスワードがメールアドレスと同一の会員への注意 | 設計書の現行仕様の注意（「メールアドレスとは異なるパスワードを設定してください。」を新しいパスワード欄の下に出す）は、会員の保存パスワードがメールアドレスと同じ状態の会員にだけ出る。その状態の会員は、画面の操作では作れない（登録・変更・再設定のどれも、同じ値を受け付けない）ので、この行は「実施不可（流せない）」として記録する |

例外：このシナリオに例外の差し込み表は無い（組み合わせ表が無い）。K02〜K10 が例外にあたる。24時間を過ぎたURLは UMB-06。
