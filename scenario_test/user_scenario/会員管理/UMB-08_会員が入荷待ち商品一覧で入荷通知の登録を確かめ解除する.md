# UMB-08 会員が入荷待ち商品一覧で、入荷通知の登録を確かめ、解除する

| 項目 | 内容 |
|---|---|
| 利用者 | お客様（会員）→ 店舗チーム（在庫を入れて承認する）→ お客様（メール） |
| 目的 | 入荷通知を登録した会員が、マイページの「入荷待ち商品一覧」で、登録した商品を言語ごとに（まとめて入荷通知も）確かめ、規格ごと・商品単位で入荷通知を解除できる。登録の上限（管理画面の設定。現在20件）を超えるとエラーが出る。入荷通知メールの受信の確認：登録した商品の在庫が、入庫の承認で本店のEC在庫0から1以上になると、通知待ちの本会員（公開の商品・規格のみ）に入荷通知のメールが届く。通知したあとも、依頼は一覧に残る |
| 種類 | 正常（代表の1本）＋ L3の5件（組み合わせ表は無い） |
| マトリクスの行 | なし（登録の単位2種と上限の有無だけで、効き合う因子が無いのでマトリクスは作らない） |
| もとのシナリオ | なし。入荷通知を登録する入口（商品詳細）と、依頼を集計する管理画面（入荷通知依頼一覧）は UAN-06。在庫の入庫と承認の手順は UZK-02 |
