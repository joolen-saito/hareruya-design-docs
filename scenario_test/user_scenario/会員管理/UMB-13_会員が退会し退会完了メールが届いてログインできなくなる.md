# UMB-13 会員が退会し、退会完了メールが届いて、ログインできなくなる

| 項目 | 内容 |
|---|---|
| 利用者 | お客様（会員。本店のサイト）→ メール →（スマレジ。USM-14）→ 店舗チーム（管理画面で確かめる） |
| 目的 | 会員がマイページの「退会」から退会手続きへ進み、現在のパスワードを入れて「退会する」を押すと、退会完了画面が出て、退会完了メール（退会前のメールアドレス宛。日本語と英語で別のテンプレート）が届き、ログアウトされる。退会前のメールアドレスではログインできない。会員のメールアドレスはダミー（ランダムな英数字@dummy.dummy）になり、会員データは削除済みになる |
| 種類 | 正常（代表の1本）＋ L3の4件（組み合わせ表は無い） |
| マトリクスの行 | なし（因子が無いのでマトリクスは作らない） |
| もとのシナリオ | なし。スマレジの会員削除と失敗は USM-14、退会後のログインは UMB-03 のT06（退会済みの会員） |

- システムの外で済んでいること：なし
- 用意するデータ（試験用の値。設計書の値ではない）

  - 運営アドレス（退会完了メールのBCCの宛先。店舗基本設定に登録された運営のメールアドレス）：BCC先の受け口が見られるときだけ確かめる。見られないときは記録しない

- 画面の名前・文言は新実装の表示で書く

## L3で変わるところ（組み合わせ表は無い。1つずつ別のテストにする）

手順の番号は上の「操作の流れと期待値」。

| 行 | 条件 | 変わるところ |
|---|---|---|
| R1 | パスワードが違う | 会員 `umb13-r1@example.test` で、手順3だけを流す。「パスワードに誤りがあります。」が出て確認画面に留まる。パスワード欄を空のまま「退会する」を押しても、同じ文言（未入力・登録パスワード不一致の場合。0306 退会 識別ID 2-3）。会員のデータは変わらない（ログインしたまま、手順1から再開できる）。手順4以降は流さない |
| R2 | スマレジの削除に失敗する | 手順4で、スマレジの会員の削除が失敗すると、退会せず、確認画面に戻って「退会処理の途中でエラーが発生しました。」が出る。**実施不可（流せない）**：スマレジの削除を失敗させる操作は画面に無い（失敗の作り方は USM-14）。USM-14 で失敗を起こせるときに、期待値は設計書どおり（退会しない。会員のメールアドレス・状態・選手情報は変わらない）にして流す |
| R3 | 「戻る」で中止 | 会員 `umb13-r3@example.test` で、手順1・2のあと、確認の画面で「戻る」を押す。退会されずマイページへ戻り（0306 退会 識別ID 2-4「押下すると、マイページ画面へ戻る」）、会員データは変わらない。手順1の画面の「戻る」も同じくマイページへ戻る（識別ID 1-3）。退会完了メールは届かない。ログインしたまま |
| R4 | 日本語と英語のメール | 会員 `umb13-r4@example.test` で、ヘッダーの言語切り替えで英語にして手順1〜4を流す。画面は英語で出る。手順5：件名「[Hareruya] Withdrawal complete」の英語のメールが届く（メールテンプレート「【販売/英】退会」）。日本語のサイトで流した手順5（日本語のテンプレート）と別のテンプレート |
