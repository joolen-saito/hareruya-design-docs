# UMB-01 お客様が会員登録を申し込み、仮会員になって仮登録メールが届く

| 項目 | 内容 |
|---|---|
| 利用者 | お客様（会員登録のない人。本店のサイト）→ メール → 店舗チーム（管理画面で会員を確かめる） |
| 目的 | お客様がログイン画面の「会員情報登録」から入力→確認→登録まで進み、仮会員になって、仮会員登録完了画面と仮会員登録完了メール（本登録のURL入り）が届く。仮会員機能が無効の店舗設定のときは、そのまま本会員になり、本登録完了画面と会員登録完了メールが出る |
| 種類 | 正常（組み合わせ表の2行のうち代表のT01）＋例外9件 |
| マトリクスの行 | `matrix_UMB-01/matrix.md` のT01（仮会員機能＝有効（開発環境の設定））。T02（無効）は「L3で変わるところ」。国は初期値の Japan、任意項目は空、確認画面からそのまま登録する（依頼者決定 2026-11-09・2026-11-10。国の選択と任意項目の入力は入力が保存されるだけの違いなので外した） |
| もとのシナリオ | なし（今のシナリオに会員登録の単独のものは無い） |

店頭買取の査定申込の途中で行う会員登録（仮会員登録・登録スキップ・ブラックリストに当たる登録）は、このシナリオに含めない（UKA-01 の因子Aが受け持つ）。ブラックリストに当たる登録は UMB-23。仮登録メールのURLを開いて本会員になる区間は UMB-02、スマレジの会員作成は USM-12。
