# 会員管理の店頭PC用アカウント制御（UMB-22）

IPA「高信頼化ソフトウェアのための開発手法ガイドブック」(2010) の表6-9〜6-11と同じ手順で作る。

1. 因子・水準表（FL表）: `fl_table.tsv`
2. 禁則表: `prohibitions.tsv`
3. 組み合わせテストマトリクス: `matrix.md` / `matrix.tsv`。`build_matrix.py` が作る。1行が1本のシナリオになる
4. 例外の差し込み表: `exceptions.tsv`。エラーや中断（★の手順）は正常な値と混ぜず、条件に合う行へ1つずつ差し込む

## 範囲

- 店舗の店頭PCで使うアカウント（顧客グループが「店内アカウント」「支店店内アカウント」の会員）でログインしたとき、許可されたIPアドレスからだけ使え、会員向けの画面は開けず、本店の注文は支店用アカウントでは出来ない、という制御（0306 F06-26）。通常会員は比べるために入れる
- 店内アカウントで注文を確定して店頭モニターに番号が出るところは UOR-06（F06-25 店頭注文呼び出し番号表示も UOR-06・UOR-08・UOR-11）。ここでは、そのアカウントにかかる制限を確かめる
- 顧客グループを登録して会員に割り当てる作業は UMB-21。店頭PCのアカウントを使うのは店内（店舗のお客様）
- 1行は「アカウント（A）で、場所（B）からログインし、画面（C）を開く」手順

## 期待結果の決まり（行ごとに当てはめる）

| アカウント（A）・場所（B） | 画面（C） | 期待 |
|---|---|---|
| A1 店内アカウント・B1 許可IP | C1 制限のない画面 | 開ける |
| 同上 | C2 制限される画面 | 「店頭用アカウントでは利用できません。」だけが出る（本文なし）。画面は開かない |
| 同上 | C3 本店の注文手続き | 開ける（本店での注文は可）。ご注文方法指定に注文者情報（ご注文主・お届け先）が出ない |
| A2 支店用店内アカウント・B1 許可IP | C1 | 開ける |
| 同上 | C2 | 開かない。「支店店頭用アカウントでは利用できません。」だけが出る（設計書。新実装は食い違う。`scenario_list.md` の食い違いと判断待ち#6） |
| 同上 | C3 | 開かない（本店の注文は支店店内アカウントでは不可）。「支店店頭用アカウントでは利用できません。」 |
| A1・A2・B2 許可外IP | C1・C2・C3 | ログインした直後にログアウトされる。画面にメッセージは出ない。そのあと開く画面は未ログインの扱いで、「店頭用アカウントでは利用できません。」は出ない（ログアウト後の遷移に従う） |
| A3 通常会員（B1 または B2） | C1・C2・C3 | 許可外IPでもログインでき（IP照合は店頭PCのアカウントだけ。`IpCheckSubscriber.php` 50〜52行目）、すべて開ける |

- 許可外IP（B2）の行は、店頭PCのアカウントでも通常会員でも C2・C3 を組み合わせる（禁則は置かない）
- 許可IPは店舗登録（本店・各支店ごと）の設定。許可IPが空なら、どのIPからも許可されない（例外E1）
- 制限される画面（C2）の代表は、会員情報変更・退会・購入履歴・ポイント履歴・お問い合わせ・配送先の登録・ネット買取・大会申込など。設計書の全22画面を1行で全部開くのではなく、画面を開く行ごとに代表を替えて、全画面が1回は出るようにする（`scenario_list.md` の食い違い：設計書の22画面のうち「パスワード変更」は新実装の制限の一覧に無い）

## 実装で確かめたこと（2026-11-05）

- ログイン後の許可IPの照合：`src/Eccube/Event/IpCheckSubscriber.php` 62〜76行目（許可IPは店舗登録のグローバルIPをカンマで区切った一覧。空なら不許可。店頭PCの顧客グループだけを対象）
- 制限される画面の遮断：`src/Eccube/EventListener/CustomerGroupAccessListener.php` 74〜90行目。店内アカウント（店頭フロント区分）は `CustomerGroupAccessRouteRegistry.php` の制限の一覧、支店店内アカウント（支店店頭フロント区分）は本店の注文の経路だけ。応答はHTTP 403で、タイトル「店頭用アカウントでは利用できません。」「支店店頭用アカウントでは利用できません。」（`messages.ja.yaml` 3839〜3842行目）
- 開発環境の顧客グループ（DBダンプ 2026-09-07）：通常会員／店内アカウント（店頭区分あり）／支店用店内アカウント（支店店頭区分あり。名前は設計書の「支店店内アカウント」と違う）ほか。顧客グループの名前は環境ごとに変えうるので、使うグループは区分（チェック）で見分ける

## まとめた水準

- C1 制限のない画面：トップ・商品一覧・商品詳細・カートなどを1つにまとめた。設計書の制限の一覧（22画面）に入らない画面で、どれも開けるため
- C2 制限される画面：設計書が「アクセス制限されている」と一覧にした22画面は、どれも同じ遮断（共通エラー画面の文言だけ）になるので1水準にまとめた。新実装の制限の一覧が設計書と違う点は食い違いに記録
