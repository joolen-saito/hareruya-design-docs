# UMB-09 会員がお気に入り商品一覧で、登録した商品を探し、カートに入れる

| 項目 | 内容 |
|---|---|
| 利用者 | お客様（会員。本店のサイト） |
| 目的 | お気に入り登録した会員が、マイページの「お気に入り商品一覧」を開き、公開中のお気に入り商品（最大100件）を見て、「セール対象のみ」と表示順で絞り・並べ替え、「お気に入りから削除」で再読み込みせずに一覧から消し、「カートに追加」で選んだ数量をカートに入れる。100件登録済みで追加すると「お気に入り登録は100件までです。」が出る |
| 種類 | 正常（代表の1本）＋ L3の4件（組み合わせ表は無い） |
| マトリクスの行 | なし（絞り込みと並び順は互いを保つだけで、期待値が効き合う因子が無いのでマトリクスは作らない） |
| もとのシナリオ | なし。セール価格の登録は UPC-01、お気に入り登録した商品がセールになったときのメール通知は UPC-07 |

## 前提

- 共通の決まり：`../L4を流すときの共通の決まり.md` を先に読む（試験データの名前にシナリオIDを付ける・共有の設定は元に戻す・バッチの起動・店舗の読み替えなど）
- システムの外で済んでいること：なし
- 用意するデータ（試験用の値。設計書の値ではない）
  - 会員：お名前「試験 会員UMB09」、メールアドレス `umb09-t01@example.test`、パスワード「Umb09Test-2026」の本会員。UMB-01 の手順1〜7と UMB-02 の手順1〜2で、この試験専用に作る。お気に入りを1件も登録していない
  - 商品（公開・本店で在庫あり）：
    - セール品：UPC-01 のT02の終点の「シナリオ試験新セールカード」（「Sale」付きでセール価格が出ている。NMの規格に在庫2点。UPC-01 で付けた名前のまま使う）
    - 通常のカード：UPC-01 のT04の終点の「シナリオ試験セール終了カード」（セールを取り下げて通常商品に戻った。NMの規格に在庫2点）
    - グッズ：「シナリオ試験お気に入りグッズ UMB09」（商品コード `UMB09-G01`・基準価格と販売価格 1,000円・公開・在庫5。グッズ商品CSVで登録し、在庫変更CSV登録と承認で在庫を入れる。UPR-04・UPR-05 の手順と同じ）
  - 店舗設定：「お気に入り商品機能」が有効（開発環境の設定）。流す前に管理画面の店舗設定＞基本設定で今の値を確かめる。有効なら変えない。無効のときだけ有効にして保存し、終わったら戻して、戻ったことを確かめる（共通の決まり）
  - 100件の行（R4）のための商品：グッズ100点（商品コード `UMB09-F001`〜`UMB09-F100`・公開・在庫あり。グッズ商品CSVで登録し、在庫を入れる）
  - 手順の前に控える値：会員のお気に入りの件数（0件）、カートの中身（空）
- 画面の名前・文言は新実装の表示で書く。設計書の文言と違うときは、期待値は設計書の文言とし、新実装の文言は記録する

## 操作の流れと期待値

| # | 操作する人と操作 | 期待値（画面で見えること） |
|---|---|---|
| 1 | お客様：`umb09-t01@example.test` でログインし、検索で3商品（「シナリオ試験新セールカード」「シナリオ試験セール終了カード」「シナリオ試験お気に入りグッズ UMB09」）を順に探して商品詳細を開き、お気に入り登録のボタンを押す | 商品ごとに「お気に入りに追加しました。」が出る。ヘッダーの「お気に入り」から開く一覧に3件ある |
| 2 | お客様：マイページの「お気に入り商品一覧」を押す | 見出し「お気に入り商品一覧」。案内文は、設計書が「お気に入り登録した商品がセール対象になった際、ご登録されているメールアドレスにお知らせをお送りいたします。」。商品数「商品数: 3点」、「セール対象のみ」のチェック、並べ替え、商品ごとのカード（商品画像・商品名・状態・価格・在庫・商品数の選択・「カートに追加」・「お気に入りから削除」。カードには「同名商品検索」、セール品には「Sale」の表示）。在庫の無い規格は出ない（新実装の案内文は「下記の商品が入荷した際…」で設計書と違う。不合格として記録する）。「マイページ」のボタンがある（0306 お気に入り商品一覧 識別ID 3〜16） |
| 3 | お客様：「セール対象のみ」にチェックを入れる | 画面が読み込み直され、セール品「シナリオ試験新セールカード」だけが出る（商品数は1点）。表示順は、選んでいる順を保つ。URLに絞り込みの指定が残るので、再読み込みしても同じ絞り込みで出る |
| 4 | お客様：「セール対象のみ」のチェックを外し、表示順を「価格（高い順）」にする | 3商品が、一覧に出ている価格の高い順に並ぶ（グッズ 1,000円が先頭）。選んだ表示順は太字で押せない状態になる。続けて「セール対象のみ」にチェックを入れても、表示順は「価格（高い順）」のまま保たれる。表示順を「価格（低い順）」「色順」に替えても、絞り込みの有無は変わらない |
| 5 | お客様：絞り込みを外し、グッズ `UMB09-G01` の商品数を2にして「カートに追加」を押す | 「カートに追加しました。」のポップアップが出て、お気に入り商品一覧に留まる（F06-09-MSG-002。新実装の文言は「カートに追加しました：」の形の見込みで、設計書と違うときは記録）。ヘッダーのカートの数が2になる。ポップアップからカートへ移れる |
| 6 | お客様：カート画面を開き、お気に入り商品一覧へ戻る | カートに「シナリオ試験お気に入りグッズ UMB09」が数量2で入っている（小計2,000円）。お気に入り商品一覧のグッズは残っている（カートに入れても、お気に入りから外れない） |
| 7 | お客様：お気に入り商品一覧で「シナリオ試験セール終了カード」の「お気に入りから削除」を押す | ページを再読み込みせずに、その商品のカードが一覧から消える。商品数が2点になる。商品詳細を開き直すと、お気に入り登録の表示が未登録に戻っている |

## 終わったあとに確かめること

| 確かめる場所 | 期待値 |

| カート | グッズ `UMB09-G01` が数量2。在庫はカートに入れただけでは減らない（在庫は注文で減る。UTS-01） |

## L3で変わるところ（組み合わせ表は無い。1つずつ別のテストにする）

手順の番号は上の「操作の流れと期待値」。

| 行 | 条件 | 変わるところ |

| R1 | セール対象のみ（表示順を保つ） | 手順3・4のとおり。「セール対象のみ」を切り替えても、選んでいる表示順は変わらない。表示順を切り替えても、「セール対象のみ」の有無は変わらない |

| R3 | 英語表示 | ヘッダーの言語切り替えで英語にして、お気に入り商品一覧を開く。案内文は「You will receive a notification to your registered e-mail address when your bookmarked items become on sale.」、商品数は「Items: 3」の形、カートに追加したときのポップアップは「The item has been added to the cart.」、0件のときは「No item found in Favorites.」（0306 お気に入り商品一覧 表示メッセージ節の英語ページ）。新実装の英語の案内文が違うときは記録する |
| R4 | 100件の上限 | 会員 `umb09-r4@example.test` で、グッズ `UMB09-F001`〜`UMB09-F100` の商品詳細を開いてお気に入り登録を押し、100件にする（毎回「お気に入りに追加しました。」）。お気に入り商品一覧に最大100件が出る。101件目として手順1の `UMB09-G01` のお気に入り登録を押すと、登録されず、お気に入り登録の付近に「お気に入り登録は100件までです。」が出る（登録操作の表示は登録前の状態のまま変わらない。0306 お気に入り商品一覧 機能仕様）。お気に入りを1件削除すると、もう1件登録できる |
