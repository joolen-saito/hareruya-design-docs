# 会員管理：シナリオ一覧（L2）

シナリオ1本は「起点の業務イベントから、業務として完了した状態になるまで」とする。会員管理は業務一覧の各業務（店頭受取受注管理・ネット買取・通販受注管理・売上分析・顧客分析など）の「該当機能」に出てくるだけで、独立した業務フローが無い（`scenario_test/markdown/02_業務一覧.md`）。そのため業務フローパターンの網羅の代わりに、設計書のシートごとの網羅（`## 設計書の網羅`）で漏れを防ぐ。スマレジ連携の著者の報告（会員の本会員登録・退会・ポイント付与・失効は既存のどの業務にも無い）を受けて、会員管理を業務領域として足した。

シナリオの終点は、お客様の画面・メール、または店舗チームの管理画面で、目で確かめられる結果に置く。会員のスマレジ連携（本会員登録・変更・退会・ポイント）、オンライン本人確認、イベント・デッキ登録、店頭PCの注文は、すでに別の業務のシナリオにあるので、ここでは作らずIDで参照する。メールを待つもの（仮会員のまま本登録を待つ、再発行メールの期限）は、システムの状態が待つので別の1本にする。

| 階層 | 単位 | 会員管理での置き場所 |
|---|---|---|
| L1 業務領域 | シナリオのグループ | 会員の登録・ログイン・マイページ（お客様）／会員の管理（店舗チーム）／会員のバッチ |
| L2 シナリオ | 起点イベント→業務完了 | この表の1行 |
| L3 バリエーション | 条件違い・例外 | 各行の `matrix_UMB-xx/` と「L3」欄 |
| L4 ステップ | 画面操作と確認 | （まだ書かない） |
