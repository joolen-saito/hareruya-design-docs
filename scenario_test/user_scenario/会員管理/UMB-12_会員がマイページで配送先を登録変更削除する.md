# UMB-12 会員がマイページで配送先を登録・変更・削除する

| 項目 | 内容 |
|---|---|
| 利用者 | お客様（会員。本店のサイト） |
| 目的 | 会員がマイページの「配送先の新規登録・変更」を開き、配送先を追加（入力→確認→登録）して一覧に加え、変更し、削除する。削除は確認（「（氏名）様の情報をアドレス帳から削除しますか？」）で「OK」のときだけ行われ、一覧から消える。登録が上限（20件）に達していると、新しく登録できず、上限に達した旨が出る |

| マトリクスの行 | なし（国・言語・操作の違いは入力画面の表示にとどまり、保存の流れは同じなのでマトリクスは作らない） |
| もとのシナリオ | なし。ブラックリストに当たる配送先は UMB-23。購入のときにご注文方法指定の画面から配送先を追加する流れは UTS-01 |
