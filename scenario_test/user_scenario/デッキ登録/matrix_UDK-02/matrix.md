# デッキ登録の会員のデッキリスト提出（UDK-02）：組み合わせテストマトリクス

因子・水準は `fl_table.tsv`、禁則は `prohibitions.tsv`。このファイルは `build_matrix.py` が作る（手で直さない）。

- テスト数: 4
- 2因子間網羅率: 100.00%（4/4）
- 3因子間網羅率: 100.00%（0/0）
- 禁則: `prohibitions.tsv` の0件。設計書に無く現行ソース（pf-eccube3）で決めたものは扱い欄に書いた
- 禁則どうしが重なって行として成り立たない組は、網羅率の分母から外した

| T02 | 初めて提出する | 枚数不足・禁止カードなど、フォーマットに則さない（確認画面にエラーが出るが登録される） |
| T03 | 同じイベント・同じフォーマットで、もう一度提出する（上書き） | フォーマットに則している |
| T04 | 同じイベント・同じフォーマットで、もう一度提出する（上書き） | 枚数不足・禁止カードなど、フォーマットに則さない（確認画面にエラーが出るが登録される） |
