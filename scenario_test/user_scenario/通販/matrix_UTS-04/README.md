2026-11-09 の依頼者の指摘（1回のテストに同じ条件の値を混ぜない）で、これまでシナリオ本文に並べていた値（予約商品の購入・支払方法）を、IPA「高信頼化ソフトウェアのための開発手法ガイドブック」(2010) 6.3.1（表6-9〜6-11）の組み合わせ表の因子・水準にした。1行が1回ずつ流すテスト1本。
