# UTS-13 出庫承認済みの在庫移動をまとめて在庫移動指示にし、送り状No.を登録して移動中にする

| 項目 | 内容 |
|---|---|
| 利用者 | 通販チームの担当者（管理画面。出庫元店舗の編集権限を持つ人）。送り状の発行（ゆうプリR）はシステムの外 |
| 目的 | 出庫が承認された在庫移動を出庫元・入庫先が同じものどうしまとめて在庫移動指示にし、送り状CSVでゆうプリRから送り状No.を得て登録し、在庫移動を「移動中」にする |
| 種類 | 正常 |
| マトリクスの行 | 組み合わせ表は無い（`scenario_list.md` のL3欄は「—」）。代表の1本だけ書く |
| もとのシナリオ | 900 |
| 業務フロー | 17 通販受注管理 (tobe) の 13（【新規追加】在庫移動準備業務）。13 は見出しだけで手順の行は無い。手順は 0202 在庫移動指示検索の「在庫移動指示発送手続き部分想定運用フロー」①〜④による |

## 前提

- 共通の決まり：`../L4を流すときの共通の決まり.md` を先に読む（試験データの名前にシナリオIDを付ける・共有の設定は元に戻す・バッチの起動・店舗の読み替えなど）
- システムの外で済んでいること：在庫移動が2件、ステータス「出庫承認済み」になっている。2件は出庫元店舗と入庫先店舗が同じで、移動タイプは「移動」。在庫移動の登録から出庫承認までは在庫管理のシナリオ（UZK）で通る。この1本の起点は「出庫が承認される」ところ
- 用意するデータ（試験用の値。設計書の値ではない）
  - 担当者：管理画面にログインでき、出庫元店舗の在庫を編集できる権限を持つ通販チームのアカウント
  - 在庫移動A：商品「シナリオ試験カードA」を3点、在庫移動B：商品「シナリオ試験カードB」を2点（合計5点）。どちらも出庫元店舗＝本店・入庫先店舗＝試験用に用意した別の店舗。2件のステータスは「出庫承認済み」。どちらも移動指示リストIDと送り状No.は空
  - 送り状No.：ゆうプリRで得た番号（試験では配送業者の試験環境で得た番号、または試験用の番号。文字は全角・半角を許容、最大の長さは設定値）
- 在庫移動指示を作るには、選ぶ在庫移動がすべて「移動」・同じ出庫元店舗・同じ入庫先店舗・出庫承認済み・移動指示IDが未登録でなければならない（手順1の期待値と例外は `L3で変わるところ`）

## 操作の流れと期待値

| # | 操作する人と操作 | 期待値（画面で見えること） |
|---|---|---|
| 1 | 担当者：管理画面の在庫管理の「在庫移動振替一覧」を開き、出庫元店舗・入庫先店舗を指定して検索する。ステータス「出庫承認済み」の在庫移動AとBが出ていることを確かめ、2件を選んで「在庫移動指示作成」を押す | 在庫移動AとBが一覧に出る（ステータス「出庫承認済み」、移動指示リストIDと送り状No.は空）。押すと管理画面の上部に「在庫移動指示を作成しました。」が出る |
| 2 | 担当者：同じ「在庫移動振替一覧」で、在庫移動AとBを探し直す | 2件とも「移動指示リストID」に同じ番号が入る（この番号が移動指示ID。控える）。ステータスは「出庫承認済み」のまま、送り状No.は空 |
| 3 | 担当者：「在庫移動指示一覧」を開き、出庫元店舗・入庫先店舗（どちらも必須）を指定して検索する | 一覧に、手順2の移動指示IDの行が1行出る。出庫元店舗・入庫先店舗は指定した店舗名、「在庫移動」は2件、「移動点数」は5枚、「送り状No」の欄には「登録」ボタン、「発送状況」は「未」 |
| 4 | 担当者：手順3の行の先頭のチェックボックスを入れ、「送り状CSVダウンロード」を押す | ボタンはチェックを入れる前は押せず、入れると押せる。押すと送り状CSVがダウンロードされる。CSVの対象の移動指示・出庫元・入庫先は手順3の行と同じ（CSVの列の中身は在庫移動指示の送り状CSV出力の設計書による。0202 送り状CSV出力） |
| 5 | 通販チーム：ダウンロードしたCSVをゆうプリRに登録し、送り状No.を得る（システムの外） | 送り状No.が得られる。送り状の宛先がCSVの入庫先と同じ（システムの外の記録） |
| 6 | 担当者：「在庫移動指示一覧」の手順3の行の「送り状No」欄の「登録」ボタンを押し、「送り状No.登録」のモーダルに手順5の送り状No.を入れて「登録」を押す | 「送り状No.を登録しました。」が出る。一覧の同じ行の「送り状No」に入れた番号が表示され、「発送状況」が「済」になる |
| 7 | 担当者：「在庫移動振替一覧」で在庫移動AとBを探し直す | 2件ともステータスが「移動中」になる。「送り状No.」に手順6の番号が入っている |
