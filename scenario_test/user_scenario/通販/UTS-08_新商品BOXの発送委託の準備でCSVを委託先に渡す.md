# UTS-08 新商品のBOXの発送を外部に委託する準備をし、CSVを委託先に渡す

| 項目 | 内容 |
|---|---|
| 利用者 | 通販チーム（管理画面）、外部の発送業者（システムの外） |
| 目的 | 発売一週間前から発売前日の15時締めまで毎日、委託できる予約受注を受注CSVに出して委託先に渡し、発送管理台帳（システムの外）に委託の印を付ける |
| 種類 | 正常（T01）／委託できない受注を外す（T02） |
| マトリクスの行 | `matrix_UTS-08/matrix.md` のT01（委託できる受注）。T02（委託できない受注）は「L3で変わるところ」 |
| もとのシナリオ | SCN-TSUHAN-015（前段） |

## 前提

- 共通の決まり：`../L4を流すときの共通の決まり.md` を先に読む（試験データの名前にシナリオIDを付ける・共有の設定は元に戻す・バッチの起動・店舗の読み替えなど）
- 購入するEC・扱う受注：本店のECの受注（会員が予約のBOXを買った注文）。予約の購入はUTS-04で済んでいる（予約商品の購入。未開封製品（BOXなど）の予約の行）
- システムの外で済んでいること：委託先との取り決め、発送管理台帳（発送管理用EC台帳）の用意
- 用意するデータ（試験用の値。設計書の値ではない）
  - 会員：試験 六郎（`uts-08-t01@example.test`）。国内の住所。クレジットカード決済・ゆうパックで、予約のBOX「シナリオ試験予約BOXQ」（商品コード `UTS08-BOXQ`）を数量1で買った受注1件。ご注文番号を控える
  - 通販チームの担当者：管理画面で受注管理とカスタムCSVを使える権限を持つ
  - カスタムCSVの出力項目の設定：受注一覧カスタムCSV出力・受注詳細カスタムCSV出力それぞれに、全項目を出す設定が1つずつある（設定の名前は環境による。判断待ち 2）
- 業務フロー12-1の「対象範囲の予約受注」を探す保存検索の中身は店舗が画面で作る設定で、期待値にしない（通販 scenario_list.md 決着12）。ここでは購入商品コードで探す
