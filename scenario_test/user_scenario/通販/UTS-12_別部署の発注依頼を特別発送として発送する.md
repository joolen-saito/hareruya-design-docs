# UTS-12 別部署からの発注依頼を受け、特別発送として当日の発送チェックを通して発送する

| 項目 | 内容 |
|---|---|
| 利用者 | 別部署の担当者（依頼する人）、通販チームの担当者（ラベルを発行して発送する人） |
| 目的 | 別部署から配送の依頼が届いたら、通販チームがラベルを発行して発送管理台帳に載せ、当日の発送チェックで「特別発送」として確認して発送する。受注は作らない |
| 種類 | 正常 |
| マトリクスの行 | `matrix_UTS-12/matrix.md` のT01（依頼フォームで依頼する）の1行。メールで受ける場合は入口の違いなので外した（2026-11-09 依頼者決定） |
| もとのシナリオ | 010 |
| 業務フロー | 16 通販受注管理 の 7（7-1〜7-7）。(tobe) の 17 に 7 は無いので 16 を元にする |

## 前提

- 共通の決まり：`../L4を流すときの共通の決まり.md` を先に読む（試験データの名前にシナリオIDを付ける・共有の設定は元に戻す・バッチの起動・店舗の読み替えなど）
- システムの外で済んでいること：なし。この1本は、業務フロー7のどの手順もEC-CUBEの画面を使わない（依頼フォーム・メール・ラベル印字アプリ・発送管理台帳・当日の発送チェックはどれもシステムの外）
- 用意するもの（試験用の値。設計書の値ではない）
  - 別部署の依頼者：依頼フォーム（Googleフォーム）に回答できる人と、返信メールを受け取るメールアドレス1つ
  - 通販チームの担当者：通販チーム宛のGoogleメールを受け取り、ラベル印字アプリと発送管理台帳（EC台帳）を使える人
  - 配送したい内容：国内の1か所に送る荷物1つ（商品の移動を除く。商品の移動は在庫移動のUTS-13）
  - 当日の発送チェックのチェックリスト（業務フロー4-2で作る国内チェックリスト）
- 業務フロー7に、受注を作る・直す手順は無い。EC-CUBEで確かめるのは、受注の件数が増えていないことだけ（手順8）
- 依頼が届く時刻は、当日の発送チェック（16時から。業務フロー4-3）より前にする

## 操作の流れと期待値

| # | 操作する人と操作 | 期待値（見えること） |
|---|---|---|
| 1 | 別部署の依頼者：依頼フォーム（Googleフォーム）から、配送したい内容を依頼する（システムの外） | 依頼フォームの申し込みができる。申し込み後に通販チーム宛にGoogleメールが届く（業務フロー7-1の「申し込み後に通販チーム宛にgoogleメールが届く」） |
| 2 | 通販チーム：届いた依頼のメールを開いて内容を確認し、ラベルの印刷を手動で対応する旨を決める（システムの外） | 依頼の内容（宛先・荷物）が読める。この時点で受注は作られない |
| 3 | 通販チーム：ラベル印字アプリで、依頼の内容のラベルを発行する（システムの外） | 依頼の宛先のラベルが発行され、追跡用の番号が分かる（追跡用の番号の体系は設計書に無く、見た目を記録する） |
| 4 | 通販チーム：発送管理のEC台帳の上部に依頼の1行を追記し、当日の発送に含めるよう管理する（システムの外） | 台帳の上部に追記され、当日の発送の対象として管理されている |
| 5 | 通販チーム：依頼メールに返信する形で、発送準備が整ったことと追跡用の番号を共有する（システムの外） | 返信メールに、発送準備が整ったことと追跡用の番号が書かれている |
| 6 | 別部署の依頼者：返信メールを受け取る（システムの外） | 返信メールが届き、追跡用の番号が読める |
| 7 | 通販チーム：当日の発送チェック（国内チェックリストでのチェック作業。業務フロー4-3・4-4）で、この荷物が特別発送であることを確認して発送する（システムの外） | チェックリストの中で、この荷物が特別発送として確認でき、集荷のタイミングで引き渡される。当日発送の限度（集荷）までに引き渡す |
| 8 | 通販チーム：管理画面の受注管理の受注一覧で、依頼の宛先の名前・依頼の日付で検索する | 依頼に対応する受注は1件も出ない（記録。業務フロー7に受注を作る手順が無いことの確認であり、設計書に「受注が作られない」と書いた文は無いので合否は付けない） |

## 終わったあとに確かめること

| 確かめる場所 | 期待値 |
|---|---|
| 発送管理のEC台帳 | 依頼の1行が当日の発送として載っている（システムの外） |
| 受注管理 | 受注の状態は変わらない。通る受注ステータスは無い |
| 在庫 | 業務フロー7に在庫を動かす手順は無く、在庫の画面での確認は無い。商品の移動を伴う依頼はこの1本の範囲外（UTS-13） |
