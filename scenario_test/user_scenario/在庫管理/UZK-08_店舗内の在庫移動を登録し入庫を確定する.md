# UZK-08 店舗内の在庫移動（別の在庫区分への移動・フロア間移動）を登録し、入庫を確定する

| 項目 | 内容 |
|---|---|
| 利用者 | 店舗チーム／トレードチームの担当者（登録・店舗内入庫の確定） |
| 目的 | ショーケース品などを別の在庫区分・フロアへ動かすとき、在庫移動を登録し、出庫承認・入庫承認を通らずに「店舗内入庫確定」で入庫完了（画面の表示は「入庫済み」）にする。出庫元の在庫が減り、入庫先の在庫が増える |
| 種類 | 正常（欠品なし）／欠品あり |
| マトリクスの行 | `matrix_UZK-08/matrix.md` のT01（移動の種類＝同じ店舗でスマレジ在庫→EC-CUBE在庫に移す（ショーケース品）・出庫時の欠品＝欠品なし）。T02〜T06は「L3で変わるところ」 |
| もとのシナリオ | SCN-ZAIKO-010〜013・900 |

## 前提

- 共通の決まり：`../L4を流すときの共通の決まり.md` を先に読む（試験データの名前にシナリオIDを付ける・共有の設定は元に戻す・バッチの起動・店舗の読み替えなど）
- システムの外で済んでいること：なし（店頭商品は買取などで入庫済み。バーコード作成マクロの実行は、EC-CUBEからスマレジへの在庫連携が無いので、この試験の外）
- 用意するデータ（試験用の値。設計書の値ではない。行ごとに別の商品を使う）
  - T01・T02：商品「シナリオ試験カードJ01」（商品コード「UZK08-T01」）。本店のスマレジ在庫5・原価単価100円（総原価500円）。本店のEC-CUBE在庫0
  - T03・T04（本店3F→2Fのフロア間）：商品「UZK08-T03」。本店バックヤード（3F）のEC-CUBE在庫5・原価単価100円。本店のEC-CUBE在庫0
  - T05・T06（本店2Fから本店バックヤードのB2Fへ）：商品「UZK08-T05」。本店のEC-CUBE在庫5・原価単価100円。本店バックヤード（B2F）のEC-CUBE在庫0
  - 登録担当（店舗チームまたはトレードチーム）。店舗内入庫の確定は登録した担当者が行える（承認申請は無い）
- 移動点数3。欠品ありの行は欠品点数1
- 画面の名前は新実装の表示で書く（設計書の「在庫移動・振替登録 編集(移動)」は「在庫移動・振替登録」）。完了の状態は設計書「入庫完了」・画面「入庫済み」
