# UZK-17 撮影などでカードを借用するため、貸出店へ在庫を移す

| 項目 | 内容 |
|---|---|
| 利用者 | メディアチームの担当者（貸し出しの依頼。システムの外）→ トレードチームの担当者（在庫移動の登録・移動指示・送り状No.の登録・入庫の承認依頼）→ 承認者（別の担当者） |
| 目的 | 撮影などでカードを借用するとき、貸出店の在庫へ在庫移動して、商品が購入されないようにする。在庫移動を登録し、出庫承認を受け、移動指示で送り状No.を登録して移動中にし、入庫の承認依頼を出して入庫承認を受け、貸出店の在庫にする |
| 種類 | 正常／例外（送り状No.を登録しない） |
| マトリクスの行 | `matrix_UZK-17/matrix.md` のT01（貸出店への移動の手順＝出庫承認→送り状No.を登録して移動中→入庫の承認依頼→入庫承認）。例外E1は「L3で変わるところ」 |
| もとのシナリオ | SCN-ZAIKO-026 |

## 前提

- 共通の決まり：`../L4を流すときの共通の決まり.md` を先に読む（試験データの名前にシナリオIDを付ける・共有の設定は元に戻す・バッチの起動・店舗の読み替えなど）
- システムの外で済んでいること：なし（貸し出しの依頼と持ち出しは手順で書く）
- 用意するデータ（試験用の値。設計書の値ではない）
  - 商品：カード「シナリオ試験カードR01」（商品コード「UZK17-T01」、公開・NM）。本店のEC-CUBE在庫が4・原価単価100円（総原価400円）。貸出店のEC-CUBE在庫は0
  - 貸出店：流す前に、店舗の設定で公開サイトを持たない既存の店舗（成田店など）を確かめ、貸出店として使う。見つかれば「貸出店の在庫はフロントで買われない」を合否に入れる。見つからなければ「買われない」は記録だけにする（業務フロー12の17-2「ECCUBE貸出店（仮）」。新実装の初期データに「貸出店」は無い）
  - トレードチームの担当者（登録者）、出庫承認者、入庫承認者（別の担当者でよい。承認権限があり、承認通知先に入る）、移動指示を作る担当（本店の担当）
- 貸し出す枚数：2。送り状No.は「UZK17-0001」（試験用の値）
- 画面の名前は新実装の表示で書く。完了の状態は設計書「入庫完了」・画面「入庫済み」
