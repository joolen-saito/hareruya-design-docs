# 在庫管理の状態違い・エキスパンション違いの振替と承認（UZK-16）

IPA「高信頼化ソフトウェアのための開発手法ガイドブック」(2010) の表6-9〜6-11と同じ手順で作る（FL表→禁則表→2因子間網羅の組み合わせ）。1行が1回ずつ流すテスト1本で、行の中の水準は条件ごとに1つ（2026-11-09 に scenario_list.md の L3 欄で「／」で並べていた値を分けた）。

## 範囲

- 状態違い・エキスパンション違いのカードを振替として登録し、承認（または却下）されるまで。承認後は振替元の在庫が減り、振替先の商品の在庫が増えて入庫完了になる。却下で振替元の在庫が戻る
- 振替が必要になる起点は、在庫リコメンドで入庫したあとの数量以外の差異（トレードチームまたは支店が登録）と、フロア間移動のあとの数量以外の差異（店舗チームまたは商品管理チームの承認者が承認）
- 登録者本人が承認しようとしたときは承認できない（正常な値と組み合わせず例外 E1）

## まとめた水準

なし（どの水準も処理が違う）。主な根拠：登録する担当・承認する担当が起点ごとに違い、承認と却下は振替元の在庫が確定するか戻るかが違う。
