# 在庫管理の廃棄する商品の在庫編集と承認（UZK-15）

IPA「高信頼化ソフトウェアのための開発手法ガイドブック」(2010) の表6-9〜6-11と同じ手順で作る（FL表→禁則表→2因子間網羅の組み合わせ）。1行が1回ずつ流すテスト1本で、行の中の水準は条件ごとに1つ（2026-11-09 に scenario_list.md の L3 欄で「／」で並べていた値を分けた）。

## 範囲

- 廃棄する商品の在庫を、在庫変動区分の親区分「廃棄」の在庫編集で減らし、承認（または却下）されるまで。廃棄は申請の時点で在庫が減り、承認で確定し、却下で戻る
- スマレジへの在庫の反映は行わない（EC-CUBEからスマレジへの在庫連携は行わない：2026-11-18 レビュー指摘）
- 廃棄する点数：一部を廃棄する（例：在庫5に-2を入れて3が残る）、全数を廃棄する（在庫がちょうど0になる）。在庫数を超える数値（この例では-6）を入れるとエラーになるのは、正常な値と組み合わせず例外 E1 で差し込む

## まとめた水準

なし（どの水準も処理が違う）。主な根拠：廃棄の在庫変動区分は5つとも設計書が別の区分として定め、一部廃棄と全数廃棄は残る在庫が違い、承認と却下は在庫が確定するか戻るかが違う。
