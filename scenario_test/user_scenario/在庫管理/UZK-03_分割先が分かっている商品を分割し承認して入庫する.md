# UZK-03 分割先が分かっている商品を分割し、承認して入庫する

| 項目 | 内容 |
|---|---|
| 利用者 | トレードチームの担当者（分割登録）→ 在庫の承認者（別の担当者） |
| 目的 | ボックスをパックに分ける（または、デッキセットなどを解体する）とき、分割元の商品を選んで分割登録し、分割先の商品を登録して承認申請し、承認者の承認で分割元の在庫が減り、分割先の在庫が増えて入庫完了（画面の表示は「入庫済み」）になる。却下すると分割元の在庫が戻る |
| 種類 | 正常（承認）／却下 |
| マトリクスの行 | `matrix_UZK-03/matrix.md` のT02（分割元の商品＝ボックスをパックに分割する・分割先商品の数と削除＝2商品登録して片方を画面で削除する・分割の承認結果＝承認）。T01・T03・T04は「L3で変わるところ」 |
| もとのシナリオ | SCN-ZAIKO-027・032 |

## 前提

- 共通の決まり：`../L4を流すときの共通の決まり.md` を先に読む（試験データの名前にシナリオIDを付ける・共有の設定は元に戻す・バッチの起動・店舗の読み替えなど）
- システムの外で済んでいること：なし（分割先があらかじめ分かっている分割。開封の作業を待たない）
- 用意するデータ（試験用の値。設計書の値ではない。行ごとに別の商品を使う）
  - 分割元：ボックス「シナリオ試験ボックスA」（商品コード「UZK03-T02-BOX」、本店・EC-CUBE在庫）。在庫3・総原価9,000円（原価単価3,000円）。T01・T03・T04は別の商品コード（「UZK03-T01-BOX」など）
  - 分割先：パック「シナリオ試験パックA1」（商品コード「UZK03-T02-P1」）と「シナリオ試験パックA2」（「UZK03-T02-P2」）。どちらも在庫0。商品は商品登録・編集で登録済み
  - 登録担当（トレードチーム）と、在庫の承認者（別の担当者。承認権限があり、承認通知先に入る）
- 分割する数：1（1箱）。分割先在庫数：パックA1を12（1箱＝12パック）

## 操作の流れと期待値

| # | 操作する人と操作 | 期待値（画面で見えること） |
|---|---|---|
| 1 | 登録担当：管理画面の在庫管理＞在庫一覧で、商品名「シナリオ試験ボックスA」を検索し、店舗「本店」・在庫区分EC-CUBEの行にチェックを入れ、「在庫分割登録」を押す（業務フロー12の1-②-1。設計書の画面項目も「在庫分割登録」） | 「在庫分割 新規登録」の画面が開く。分割元商品に、商品名・商品コード・基準価格・原価単価3,000・総原価9,000・在庫数3が出る。ステータスの欄は「-」（まだ登録していない）。分割数の入力欄が必須で出る |
| 2 | 登録担当：分割数に1を入れ、必要なら分割登録メモを書き、「保存」を押す（1-②-2「分割元の在庫をおさえる」。画面のボタンは新実装の表示） | 分割登録が保存され、ステータスが「新規登録」の編集画面に変わる。分割元ボックスの在庫が3から2に減る（出庫。在庫一覧で確かめる）。総原価が6,000円になる。ステータス変更履歴に「新規登録」が残る |
| 3 | 登録担当：分割先の商品を追加する。「分割先を登録」（画面は商品の検索の画面）から「シナリオ試験パックA1」を決定し、分割先在庫数に12を入れる。続けて「シナリオ試験パックA2」も追加して分割先在庫数に12を入れる | 分割先商品一覧に2商品が並ぶ（数量が入っていない商品が一番上に出る）。分割点数（分割先在庫数の合計）が24になる。この時点では保存されていない（データベースへの登録は承認申請のとき）。分割先に分割元と同じ商品コードの商品は指定できない |
| 4 | 登録担当：パックA2の行の「削除」ボタンを押し、削除の確認（「商品を削除（分割先対象外に）します、よろしいですか。」）で削除を実行する | パックA2の行が分割先商品一覧から消え、パックA1だけが残る。分割点数が12になる |
| 5 | 登録担当：承認通知先（所属・メンバー）に承認者を選び、「承認申請」を押す。確認（「この操作はあとから取り消すことができません。在庫分割計画を承認申請してよろしいですか？」）で承認申請を実行する | 「承認申請しました。」が出る。ステータスが「分割承認待ち」になり、分割の承認の画面（在庫分割 承認）に変わる。承認者のメールアドレスに通知メールが届く。分割先A1に分割元の出庫総原価3,000円が仕入総価格として決まる（分割先が1商品だけなので全額）。この時点でA1の在庫はまだ0 |
| 6 | 承認者：在庫管理＞在庫分割結合一覧を開き、検索対象「分割元・結合先」・種別「分割」・ステータス「分割承認待ち」で手順5の分割を探す。一覧に出た分割のIDを押して分割の承認の画面を開く | 一覧に手順5の分割が、種別「分割」・ステータス「分割承認待ち」で出る（分割元・結合先商品「シナリオ試験ボックスA」、分割元・結合先点数1、分割先・結合元点数12）。IDを押すと「在庫分割 承認」の画面が開き、分割元・分割先とその数量が確かめられる |
| 7 | 承認者：「承認」を押し、確認（「この操作はあとから取り消すことができません。在庫分割を承認してよろしいですか？」）で「承認する」を押す | 「分割の承認が完了しました。」が出る。ステータスが「入庫済み」（設計書の「入庫完了」）になり、承認日・承認者が出る |
| 8 | 承認者：在庫管理＞在庫一覧で、分割元ボックスと分割先パックA1の在庫・原価を確かめる。続けて在庫分割結合一覧で同じ分割を見る | ボックスの在庫2（総原価6,000円）のまま。パックA1の在庫が0から12になり、総原価が3,000円（原価単価250円）になる。パックA2の在庫は0のまま（削除して分割先にしていない）。在庫分割結合一覧で同じ分割のステータスが「入庫済み」になっている |
| 9 | 承認者：在庫管理＞在庫履歴一覧で、商品コード「UZK03-T02-BOX」「UZK03-T02-P1」を検索する | ボックスに「分割(減算)」（在庫分割による減算 分割元：UZK03-T02-BOX 分割先：…）、パックA1に「分割(加算)」（在庫分割による加算…）の履歴が残る。変更前・変更後の在庫が手順2・8の数と合う |
