# 在庫管理：シナリオ一覧（L2）

シナリオ1本は「起点の業務イベントから、業務として完了した状態になるまで」とする。担当者が替わっても切らない（出庫元の担当→承認者→移動指示を作る担当）。日をまたぎ、システムの状態が何かを待つもの（在庫移動の移動中、開封作業を待つ分割、棚卸の実施を待つ棚卸計画、貸出中の商品）は別の1本にする。ただし、日をまたぐのがシステムの外の作業だけで、システムの状態が何も待たないとき（ラベル印字・ペアリング・梱包など）は分けない。条件違いはL3のバリエーションとして、必要なものだけ組み合わせテストマトリクス（2因子間網羅）で絞る。

### 設計書との食い違い（設計書の不足。起票はしない）
