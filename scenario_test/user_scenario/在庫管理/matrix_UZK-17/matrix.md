# 在庫管理の撮影などの借用のための貸出店への在庫移動（UZK-17）：組み合わせテストマトリクス

因子・水準は `fl_table.tsv`、禁則は `prohibitions.tsv`。このファイルは `build_matrix.py` が作る（手で直さない）。

- テスト数: 1
- 2因子間網羅率: 該当なし（因子が1つ）
- 3因子間網羅率: 該当なし（因子が2つ以下）
- 禁則: `prohibitions.tsv` の0件。設計書に無く現行ソース（pf-eccube3）で決めたものは扱い欄に書いた
- 禁則どうしが重なって行として成り立たない組は、網羅率の分母から外した
- 例外の差し込み条件に合う行が割り付けに無かったので、例外用の行を足した: T01（テスト数に含む）

| No. | 貸出店への移動の手順 |
|---|---|
| T01 | 出庫承認→送り状No.を登録して移動中→入庫の承認依頼→入庫承認 |
