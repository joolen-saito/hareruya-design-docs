# 在庫管理の撮影などの借用のための貸出店への在庫移動（UZK-17）

IPA「高信頼化ソフトウェアのための開発手法ガイドブック」(2010) の表6-9〜6-11と同じ手順で作る（FL表→禁則表→2因子間網羅の組み合わせ）。1行が1回ずつ流すテスト1本で、行の中の水準は条件ごとに1つ（2026-11-09 に scenario_list.md の L3 欄で「／」で並べていた値を分けた）。

## 範囲

- 貸出店への在庫移動を、出庫承認→在庫移動指示で送り状No.を登録して移動中→入庫の承認依頼→入庫承認の順で通し、貸出店の在庫になるまで（ピック表の出力と在庫移動実績インポートはしない。2026-11-07 依頼者決定）
- 送り状No.を登録しないときは、出庫承認済みで止まり、入庫の承認依頼に進めない（移動中を飛ばして入庫済みにする経路は新実装に無い）。正常な手順と組み合わせず例外 E1 で差し込む
- 返却して元の在庫へ戻すのは UZK-18

## まとめた水準

なし。借用の手順は1通りで、因子は1つ。
