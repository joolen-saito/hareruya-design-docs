# UZK-09 棚卸の範囲を決め、棚卸計画を作って棚卸商品を登録する

| 項目 | 内容 |
|---|---|
| 利用者 | 店舗統括チーム／商品管理チームの担当者（棚卸計画の作成・棚卸商品の登録）→ トレードチーム・通販チーム（棚卸範囲の共有を受けて確認。システムの外） |
| 目的 | 毎月2週目・4週目の前の日曜に翌週の棚卸の範囲を決め、棚卸計画を新規作成して棚卸商品を登録する。この時点では在庫反映日は空のままで、在庫は変わらない |

| もとのシナリオ | SCN-ZAIKO-019・038・039 |

## 前提

- 共通の決まり：`../L4を流すときの共通の決まり.md` を先に読む（試験データの名前にシナリオIDを付ける・共有の設定は元に戻す・バッチの起動・店舗の読み替えなど）
- システムの外で済んでいること：毎週日曜日に翌週対応する範囲を決めている（業務フロー12の10-①-1）。実施日に該当するファイル（棚卸の対象にするカードの商品コードを並べたCSV）が手元にある
- 用意するデータ（試験用の値。設計書の値ではない。行ごとに別の商品を使う）
  - 商品：「シナリオ試験カードK01A」「K01B」「K01C」（商品コード「UZK09-T01-A」「UZK09-T01-B」「UZK09-T01-C」）。本店のEC-CUBE在庫がそれぞれ5・3・2
  - 棚卸商品のCSV：上の3つの商品コードを並べたCSV（棚卸商品CSV登録の形式）
  - 登録担当（店舗統括チームまたは商品管理チーム）。本店の編集権限がある
- 棚卸名：「シナリオ試験棚卸01（UZK09-T01）」。店舗「本店」・在庫区分「EC-CUBE」
