# 在庫管理の店舗内の在庫移動と入庫確定（UZK-08）

IPA「高信頼化ソフトウェアのための開発手法ガイドブック」(2010) の表6-9〜6-11と同じ手順で作る（FL表→禁則表→2因子間網羅の組み合わせ）。1行が1回ずつ流すテスト1本で、行の中の水準は条件ごとに1つ（2026-11-09 に scenario_list.md の L3 欄で「／」で並べていた値を分けた）。

## 範囲

- 同じ店舗の中の在庫移動（別の在庫区分への移動、フロア間移動、本店と本店バックヤードの間の移動）を登録し、店舗内入庫確定で入庫完了になるまで。出庫承認・入庫承認は通らない
- スマレジへの在庫の反映は行わない（EC-CUBEからスマレジへの在庫連携は行わない：2026-11-18 レビュー指摘）。店頭商品をスマレジ在庫へ移したあとのバーコード作成マクロ（システムの外）は期待値に入れない（scenario_list.md の UZK-08 の行）

## まとめた水準

なし（どの水準も処理が違う）。主な根拠：別の在庫区分への移動・フロア間移動・本店バックヤードへの移動は出庫元と入庫先の組が違い、欠品の有無は出庫元・入庫先の在庫数と総原価が違う。
