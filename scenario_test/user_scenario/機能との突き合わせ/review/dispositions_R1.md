## 同じ型の誤りの見直し
- カスタムCSVと通常CSVの取り違え: M03-05/M03-06、M04-04/M04-05/M04-10/M04-11/M04-14/M04-15 は区別済み。M05-02〜05 のみ誤りで修正済み。
- 現状版だけにある工程を範囲外にした例: judge_mentioned.tsv の範囲外14件（B13-02 は 0413 の廃止、M06-13 は Ph2 見送りなど）は根拠が刷新後の廃止かフェーズ2で、同型の誤りは無し。judge_unmentioned.tsv 側は M03-35 のみ。
- 「CSV」とだけ書くシナリオの記述に依存した「通る」（M03-05 の UPC-01 L3、M04-03）は備考に弱いと明記済みで据え置き。
