# 機能一覧とシナリオの突き合わせ

## 目的
シナリオで全機能を通すことではない（機能単位の確認は結合テストの役割）。**業務の流れに出てくる機能なのに、どのシナリオにも入っていない抜け**を見つける。

## 方法
1. 機械照合（`mechanical_hits.tsv`）：411機能について、機能IDと機能名でシナリオ（`user_scenario/`）を検索し、旧シナリオ（業務フロー由来）の出方も数えた。シナリオは設計書のシート名で書くことが多く、機能IDが出ない機能がある。
2. 判定：1機能1行で、通る／業務の流れに出ない／抜け／範囲外に分けた。機能IDで出る232件を `judge_mentioned.tsv`、出ない179件を `judge_unmentioned.tsv` で判定し、`judge_all.tsv` に統合した（末尾列「機械照合」に出どころ）。根拠は業務フロー（`scenario_test/markdown/05〜18`）と設計書を自分で開いた行。
3. codex レビュー3巡（`review/` に指摘 findings_R1〜R3 と扱い dispositions_R1〜R3）。誤判定を修正した（R1：カスタムCSVと通常CSVの取り違えなど、R2：M05-07・M04-23・M14-04、R3：M10-08・M10-09・M13-04）。

## 判定ごとの件数（411機能）
