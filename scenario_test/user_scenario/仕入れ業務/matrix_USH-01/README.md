# 仕入れ業務の価格ソート用CSVの出力と価格ソート・戻し（USH-01）

IPA「高信頼化ソフトウェアのための開発手法ガイドブック」(2010) の表6-9〜6-11と同じ手順で作る（FL表→禁則表→2因子間網羅の組み合わせ）。1行が1回ずつ流すテスト1本で、行の中の水準は条件ごとに1つ（2026-11-09 に scenario_list.md の L3 欄で「／」で並べていた値を分けた）。

## 範囲

- 統合仕入れの前日に価格ソート用CSVを出し、当日にアルバイトが価格ソート・統合仕入れファイル作成・戻しまで進める。システムで確かめるのは商品マスターの検索結果からのCSV出力と、販売価格のとおりに仕分けされること。価格ソート・戻しの作業そのものはシステムの外で、仕分けの結果は記録のみで合否にしない（scenario_list.md の USH-01 の行）
- CSV形式の選択（保存済みの形式が無いとき／形式を選ばずに出すときの扱い）と、出した後に価格が変わったときの扱いは設計書・業務フローに無いので水準にしない

## まとめた水準

なし（どの水準も処理が違う）。主な根拠：価格の区分（980円未満・980円以上4800円未満・4800円以上）は仕分け先と戻し先が違う。仕分け先の戻し先（戻し棚は各チーム、キャビネットはトレード）は価格の区分で決まるので同じ水準にまとめて持つ。
