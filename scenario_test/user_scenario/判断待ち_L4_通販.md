## すでに決まったもの（正本で確かめて決着）

- 手動メール通知のテンプレート（新実装の初期データにある）：予約入金「【通販/日】（予約）支払完了　※水色」（UTS-16）、準キャンセル「【通販/日】準キャン　9月1日」（UTS-18。本文の固定の「9月1日(月)15時」を試験の受注の期限に書き直す）、未入金のキャンセル「【通販/日】キャンセル（支払なし）」（UTS-20）
- 出荷完了メールのテンプレート（UTS-07・09）：日本語「【販売/日】出荷完了」（件名「【晴れる屋】商品を出荷いたしました」）、英語「【販売/英】出荷完了」（件名「【Hareruya】The shipment has been completed.」）。新実装の初期データ
- 同梱の注文が出荷指示リストに入るか（UTS-16）：新実装の初期データでは、配送方法「同梱」の「出荷指示リストから除外」は外れているので入る（流す前に配送方法の画面で開発環境の設定を確かめる）
- 出荷実績の取り込みでスマレジへのポイント加算に失敗したときの画面（UTS-14）：新実装は取り込みを確定して「登録が完了しました。」を出し、加算は別の処理で行う。エラーの画面表示は HTML に追補した現行仕様の記述で Excel 由来ではないので、期待値にしない（codex のレビュー）
- 試験用に注文日を古くする方法（UTS-20）：店頭受取と同じく、試験で作った受注に限り開発環境で注文日を書き換える（2026-11-26 決定）
