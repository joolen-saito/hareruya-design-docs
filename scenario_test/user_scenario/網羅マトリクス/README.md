# 網羅マトリクス（業務フローの工程×シナリオ、業務条件×シナリオ）

依頼者の指示（2026-11-05）「マトリクスで整理して抜け漏れがないか確認できるようにしたい」。軸は「業務フローの工程×シナリオ」と「業務条件×シナリオ」、形式は Excel。

- 見るもの：`網羅マトリクス.xlsx`（シート：集計／工程×シナリオ／業務条件×シナリオ／抜けの一覧）。横軸はシナリオのフォルダ（業務ごと＋横断・通しシナリオ）、セルは通るシナリオID。判定の色：通る＝緑、抜け＝赤、判断待ち＝黄、それ以外（見出し・システムの外・範囲外・適用外・他業務・他層）＝灰
- 抜けは示すだけで、シナリオは足していない

## ファイル（業務ごとのフォルダ）
| ファイル | 中身 | 書く人 |
|---|---|---|
| `steps.tsv` | 業務フロー（scenario_test/markdown/05〜18）の [＃] の全工程 | 機械 |
| `step_scope.tsv` | 対象でない工程の扱い（見出し／システムの外／範囲外）と理由 | 人 |
| `step_map.tsv` | 工程を通すシナリオIDと引用 | 人 |
| `factors.tsv` | 業務条件と値、扱い（対象／適用外／他業務／他層／判断待ち）、出典と引用。2026-10-30 の scenario_pattern_matrix を写して今の決定（R13 など）に合わせて直した | 人 |
| `cond_map.tsv` | 値を通すシナリオIDと引用 | 人 |

## 作り直し
```bash
cd scenario_test/user_scenario
python3 -I tools/build_coverage_matrix.py steps   # 業務フローが変わったとき
python3 -I tools/build_coverage_matrix.py check   # ゲート
uv run --with openpyxl python -I tools/build_coverage_matrix.py xlsx 網羅マトリクス/網羅マトリクス.xlsx
```
ゲート：steps が業務フローと一致／対応のシナリオIDが実在／引用がそのシナリオ自身のテキスト（scenario_list.md のそのIDの行、そのIDの L4、matrix_<ID>/、通しシナリオはフォルダ全体。業務フローパターンの網羅・対象外・判断待ち・食い違い・関係の節は数えない）にそのままある／対象の工程・値にだけ対応を付ける。

## レビュー
codex 3巡（組A＝通販・店頭受取、組B＝商品登録・編集・価格管理・在庫管理、組C＝店頭買取・ネット買取・仕入れ業務・イベント管理・デッキ登録）。観点と採否は `組*/review/`。指摘の大半は「偽の○」（L3 に選択肢として並べるだけ・題名だけ・別の条件の文で通したことにしていた）で、全部対応を外して抜けにした。
