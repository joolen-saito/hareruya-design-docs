# パターン軸の追加 レビュー R2 の扱い

指摘12件。出典（HTML設計書の該当行・シナリオ本文）を確かめてから扱った。

## 直した（9件）
| 業務 | 値ID | 扱い | 理由 |
|---|---|---|---|
| デッキ登録 | A3-1（CSVで1件だけ） | 消した | 0212 は「一括で新規登録・更新」とだけ書き、1件の分け方が無い。A3-2（複数件）は「一括」から言えるので残した |
| 仕入れ業務 | A5-1・A5-2（戻しリストの在庫移動の数） | 消した | 0202 は「選択された在庫移動データを元に」とだけ書き、件数で分けていない（指摘はA5-2だけだが、A5-1も同じ文が根拠なので一緒に消した） |
| 在庫管理 | A2-1・A2-2（移動の明細の数） | 消した | 0202 は「選択した商品に対して、移動点数を入力して登録」とだけ書く（同上、A2-1も一緒に消した） |
| ネット買取 | A3-1・A3-2（買取最低価格） | 引用を差し替えた | Excel由来の「ネット買取商品詳細」D152「該当の商品の買取価格が500円未満の場合は商品数、カートボタンを表示しない」へ |
| 在庫管理 | A8-1〜A8-3（廃棄する点数） | 引用を差し替えた | Excel由来の「在庫編集」AG170「「廃棄」の場合 ・-1以下を入力可能とする ・在庫数を超える数値が入力された場合はエラーとする」へ。全数（在庫0）は「超える」に当たらないので入力できる側 |
| 在庫管理 | A10-2 USH-02 | 〇を外した | 「5000行程度までは1ファイル」は分け方の目安で、複数行のCSVを指定していない |
| 仕入れ業務 | A2-2 USH-02 | 〇を外した | 同上 |

## 退けた（3件）

|---|---|---|---|
| 在庫管理 | A3-2（分割先・結合元が複数商品） | UZK-05 | 値は「分割先・結合元の商品の数」で、UZK-05 は6種類以上の商品を結合元に選ぶ。結合元が複数に当たる |
