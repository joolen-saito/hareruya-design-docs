# テスト単位の作り替え レビュー R2 の扱い

指摘4件。3件を直し、1件を退けた。

| 対象 | 判定 | 扱い |
|---|---|---|
| 価格管理 UPC-01 因子H（割引の掛け方） | 分け方の誤り | 直した。H3「セールにしない（該当なし）」を足し、H1 はシングルカードかつセールフラグ1、H2 はセールフラグ1、H3 はセールフラグ0 の行だけ（禁則） |
| 価格管理 UPC-01 因子J の J2「セール価格になる」 | 新しい期待値の混入 | 直した。J3「該当なし」を足し、J1・J2 はセールフラグ1の行だけ。通常商品にフラグ0を取り込む行には書かない |
| 価格管理 UPC-01 因子I の I2 | 分け方の誤り | 直した。「表示タイプ非表示」と「画像URLが空」を別の水準（I2・I3）にした |
| 価格管理 UPC-08 集計期間 A2 | 分け方の誤り | 退けた。毎日0時のバッチが1回で全期間を更新するので、選ぶものではなく毎回全部確かめるチェック項目（分析・集計 UAN-11 の期間7種と同じ扱い） |

UPC-01 は禁則 X1〜X7 を足して作り直し、16行・2因子間100%。
