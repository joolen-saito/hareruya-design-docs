# UEX-16 店舗のプリンタが定期的に問い合わせ、自店の未印刷だけを1回10件まで受け取る

| 項目 | 内容 |
|---|---|
| 利用者 | 店舗のプリンタ（Epson。システムの外）→ EC（API） |
| 目的 | 各店舗のプリンタが、30秒おきに、店舗IDを付けて EC に印刷データを問い合わせる。EC は、自店の印刷対象（店頭受取：注文番号が採番済みで注文受領／スムーズ店頭受取：所定の支払方法で確定日時などが未設定、かつスマレジの商品コードが採番済み／受注一覧で予約された受注）を、1回に最大10件、受注1件につき1枚で返す。印刷内容は店頭注文番号・注文詳細のQRコード・備考（問い合わせ有）・注文日・注文番号・お客様名（カナ氏名、無ければ氏名）・合計金額（スムーズ店頭受取は「スムーズ店頭受取」）・スマレジの商品コードのバーコード。対象が無ければ空を返し、他店の注文は出さない |
| 種類 | 正常（組み合わせ表の2行。1行が1回流すテスト1本）＋ L3の具体例（表外） |
| マトリクスの行 | `matrix_UEX-16/matrix.md` のT01（スタック用紙の印刷対象＝店頭受取の受注：注文番号が採番済みで対応状況が注文受領のとき）。T02（スムーズ店頭受取の受注）と表外の具体例は「L3で変わるところ」 |
| もとのシナリオ | なし。業務フロー05 の 1-1（店頭受取（本店））・2-1（スムーズ店頭受取（本店））・3-1（店頭受取（支店））・4-1（店頭支払）。注文を確定してから印刷され、ピックして取り置くまでの通常の流れは UOR-01 |

プリンタ本体の操作と、印刷された紙の見た目は「システムの外」。EC 側で確かめるのは、プリンタが受け取る印刷データ（EC が返した値）の内容と件数である。印刷データは、印刷された紙で読み、紙に出た値を EC の受注の値と照合して合否を付ける（紙の罫線・文字の大きさは記録）。プリンタが使えない環境では、許可された接続元から、プリンタと同じ要求（店舗IDを付けた、印刷データの要求）を試験担当者が用意する HTTP クライアントで送り、返った印刷データの文書で確かめる（「プリンタ代わりの要求」）。
