# UEX-11 会員がデッキビルダーで作ったマイデッキを、大会のデッキ提出に取り込む

| 項目 | 内容 |
|---|---|
| 利用者 | 顧客戦略チーム（フォーマットの設定）→ 会員（デッキビルダー→EC のマイページ・大会のデッキ登録編集） |
| 目的 | 顧客戦略チームがフォーマットを「デッキビルダーで利用」で登録し、会員がデッキビルダーでそのフォーマットのデッキを作る。会員が大会のデッキ登録編集で「マイデッキを取得」を押すと、ポップアップに自分のマイデッキが並び、選ぶとメインボード・サイドボードの入力欄に入って提出できる。「デッキビルダーで利用」にしていないフォーマットは、ポップアップのフォーマットの選択肢に出ない。マイページの「マイデッキ」からデッキビルダーのマイデッキ画面へ進む（英語版は出ない）（0208 M14-10 (17)・0306 F06-16） |
| 種類 | 正常（組み合わせ表の2行。1行が1回流すテスト1本）＋例外1件 |
| マトリクスの行 | `matrix_UEX-11/matrix.md` のT01（フォーマットの「デッキビルダーで利用」＝あり）。T02（なし）と例外E1（英語版）は「L3で変わるところ」 |
| もとのシナリオ | なし。業務フロー18の2-1（デッキ登録）の前段。提出そのもの（直接入力・アリーナ形式との違い）は UDK-02 |

デッキビルダーのアプリ本体の画面（マイデッキ画面・デッキの作成）は外部サービス（システムの外）なので、見え方は記録だけにする。マイデッキを作る操作は、アプリの役を HTTP の呼び出し（UEX-07 と同じ）で務め、取り込みは EC の画面（マイページ・大会のデッキ登録編集）で合否を付ける。
