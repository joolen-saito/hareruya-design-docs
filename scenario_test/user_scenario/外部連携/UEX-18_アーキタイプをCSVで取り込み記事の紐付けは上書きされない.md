# UEX-18 顧客戦略チームがアーキタイプをCSVで取り込み、記事の紐付けは上書きされない

| 項目 | 内容 |
|---|---|
| 利用者 | 顧客戦略チーム → 管理画面（アーキタイプ登録CSV）→ 記事サイト（システムの外） |
| 目的 | 顧客戦略チームがアーキタイプ登録CSVのファイルを選んで取り込む。全行に成功すると登録完了のメッセージが出て取込画面に戻る。アーキタイプの公開状態は取込のたびに「公開」に上書きされる。解説（日・英）・タグ・記事の紐付けは取り込んでも更新されず、既存の記事の紐付けはそのまま残る。途中でエラーになると取込内容をすべて取り消す |
| 種類 | 正常（1本）＋ L3の具体例（組み合わせ表は無い。1つずつ別のテストにする） |
| マトリクスの行 | なし（組み合わせ表は無い）。L3 は `scenario_list.md` の UEX-18 の L3 欄の項目を1つずつ別のテストにした |
| もとのシナリオ | なし（業務フローに無い）。設計書 0212 デッキ管理「アーキタイプ登録CSVアップロード」（M15-10）・「アーキタイプ登録CSV」 |

記事サイトの画面の見え方は外部サービスなので記録だけにし、合否は EC 側の値（管理画面のアーキタイプ一覧・編集画面、EC の記事情報の取得の応答）で付ける。記事の紐付けは EC の画面に出る所が無いので、EC の記事情報の取得（投稿番号を指定。認証は要らない）の応答に含まれるアーキタイプで確かめる。

## 前提

- 共通の決まり：`../L4を流すときの共通の決まり.md` を先に読む（試験データの名前にシナリオIDを付ける・共有の設定は元に戻す・バッチの起動・店舗の読み替えなど）
- システムの外で済んでいること：記事サイトの記事（EC の開発環境に最初から入っている記事の紐付け）。この試験では記事サイトの画面を操作しない
- 用意するデータ（試験用の値。設計書の値ではない）
  - 顧客戦略チームの担当者：管理画面のデッキ管理の「アーキタイプ一覧」「CSV取り込み」を使える
  - CSV（アーキタイプ登録CSV）の形：1行目が見出し、列は「アーキタイプ名（日本語）」「アーキタイプ名（英語）」「代表カード名」「色」「フォーマット」の順（旧アーキタイプIDの列は無い。設計書でカスタマイズにより除去）。「アーキタイプ名（日本語）」「アーキタイプ名（英語）」「フォーマット」は必須で、3つが一致するアーキタイプがあれば更新、無ければ新規登録。フォーマットはフォーマットの英語名（例：Standard）。色は日本語の色名をカンマで区切る（例：青,白）
  - CSV-A（新規・更新に使う）：アーキタイプ名（日本語）「シナリオ試験取込アーキタイプ UEX-18」・アーキタイプ名（英語）「Scenario Test Import Archetype UEX-18」・代表カード名は空・色「青,白」・フォーマット「Standard」の1行
  - CSV-B（更新）：CSV-A と同じ名前・フォーマットで、色だけ「赤」にした1行
  - 記事の紐付けのあるアーキタイプ（記事に紐づく既存アーキタイプ）：開発環境の既存のデータから、記事サイトの記事に紐づいているアーキタイプを1つ選ぶ（EC の記事情報の取得で、アーキタイプが空でない記事を探す。UEX-06 の「記事に紐づくデッキ」と同じ探し方）。その記事の投稿番号と、アーキタイプの名前（日・英）・フォーマットの英語名・公開状態を控える。見つからないときは、手順6を実施不可（流せない）として記録する
  - 手順の前に控える値：アーキタイプ一覧の「シナリオ試験取込アーキタイプ UEX-18」の件数（0件）
- 画面の名前・文言は新実装の表示で書く（設計書の名前が違うときは、期待値のところに設計書の名前を添える）。メッセージの文言は設計書の文言を期待値にし、設計書に文言が無く新実装にだけある文言は新実装の文言を期待値にする

| 行 | 条件（`scenario_list.md` の L3 欄の項目） | 変わるところ |
|---|---|---|
| R1 | 新規 | 代表の行の手順1〜3 |
| R2 | 既存（名前とフォーマットが同じ） | R2 専用の名前（名前の後ろに R2。CSV-A・CSV-B の名前を R2 に替える）で、先に代表の行の手順1〜3（新規の取込と一覧・編集画面の確かめ）を行って既存のアーキタイプを作る（同じ日英の名前とフォーマットの既存が無いと、取込は更新でなく新規の登録になる。設計書 0212）。そのあと代表の行の手順4〜5（既存の更新。公開状態が「公開」に上書きされ、解説・タグが残り、色が置き換わる） |

| R4 | 記事に紐づく既存アーキタイプ（紐付けが残る） | 代表の行の手順6 |
