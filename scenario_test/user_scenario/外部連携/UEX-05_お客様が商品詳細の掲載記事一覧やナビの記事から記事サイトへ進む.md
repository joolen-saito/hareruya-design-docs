# UEX-05 お客様が商品詳細の「掲載記事一覧」やナビの「記事」から記事サイトへ進む

| 項目 | 内容 |
|---|---|
| 利用者 | お客様 → EC（フロント）→ 記事サイト（システムの外） |
| 目的 | お客様が本店のカード商品の詳細を開くと「掲載記事一覧」のリンクが出て、押すとそのカード名で記事サイトを検索した結果に進む。ナビの「記事」を押すと記事サイトの記事一覧に進む。支店の商品詳細・カード以外の商品には掲載記事一覧が出ない。英語版のナビは英語表示の外部ページに進む。支店のナビには「記事」が無い（0303 F03-02 (2-21)・0302 F02-01〜F02-04） |
| 種類 | 正常（日本語・PC・本店・カード商品）。本店／支店・カード商品／グッズ・日本語／英語・PC／スマートフォンは「L3で変わるところ」 |
| マトリクスの行 | 組み合わせ表は作らない（因子はサイトと商品の種類と言語・画面幅だが、リンクの出る・出ないが商品の種類とサイトだけで決まり、効き合う因子が無い）。L3の値は「L3で変わるところ」の V1〜V5 |
| もとのシナリオ | なし（業務フローに無い） |

記事サイトの画面（検索結果・記事一覧の見え方）は外部サービス（システムの外）なので、見え方は記録だけにする。合否は、EC の画面に出るリンクの有無と、リンクが指すアドレスで付ける（EC が決める値）。

## 前提

- 共通の決まり：`../L4を流すときの共通の決まり.md` を先に読む（試験データの名前にシナリオIDを付ける・共有の設定は元に戻す・バッチの起動・店舗の読み替えなど）
- 試験では商品を作らず、開発環境にある商品を使う（見るだけで、データを書き換えない）。用意する値（開発環境のダンプ 2026-09-07 の値。設計書の値ではない。流す前に商品一覧で確かめ、違うときは同じ性質の商品に読み替えて控える）

| 値 | 内容 |
|---|---|
| A | 商品ID 14357：《生真面目な補充兵/Solemn Recruit》[AER]（シングルカード。本店・支店ともに公開中のものを選ぶ。支店に出ないときは、本店・支店がどちらも公開のカード商品に読み替える） |
| B | 商品ID 22498：メタルストレージ KM-L01 Silver（グッズ・サプライ。シングルカードではない。本店・支店ともに公開中のものを選ぶ） |

- 店舗の読み替え：支店は、流す前に既存の店舗から、値A・値Bを公開している支店を選び、店舗IDと画面に出る名前を控えて読み替える（共通の決まり。店舗は新しく作らない）。本店は店舗ID 1（画面によって「Hareruya」「トーナメントセンター 東京」と出る）
- お客様：ログインしなくてよい。画面幅は、PCの幅（既定）とスマートフォンの幅（V4）を使う（ブラウザの窓の幅を変えるだけ。開発者ツールで通信を書き換えることはしない）
- 画面の名前・文言は新実装の表示で書く（設計書の名前が違うときは、期待値のところに設計書の名前を添える）。メッセージの文言は設計書の文言を期待値にし、新実装の文言が違えば不合格として記録する
