| 項目 | 内容 |
|---|---|
| 利用者 | 店舗チーム（用紙・カバーはシステムの外）→ プリンタ（Epson。システムの外）→ EC（API） |
| 目的 | 注文のあと、店舗のプリンタが自店の未印刷を受け取って印刷するが、用紙切れ・カバー開きなどで失敗する。失敗した注文は、対応状況が変わらず（注文受領・入金済み）、失敗の原因を表すエラーコードがログに残る。用紙を入れ直すと、次の問い合わせ（30秒おき）で再び印刷され、成功の結果で「ピック中」になり注文確定日が入る。成功した注文は二度と印刷されない |
| 種類 | 正常（1本）＋ L3の具体例（組み合わせ表は無い。1つずつ別のテストにする） |
| マトリクスの行 | なし（組み合わせ表は無い。`matrix_UEX-14/` は作っていない）。印刷の出し方・受注の状態と結果の組み合わせは `matrix_UEX-15/`、印刷対象の条件は `matrix_UEX-16/` にある。L3 は `scenario_list.md` の UEX-14 の L3 欄の1項目を1つのテストにした |
