## 範囲

- 商品が公開され、フィードの作成が始まる（定時のバッチ、または管理画面のボタン）ところから、フィードのTSV（gz）とdoneファイルがユニサーチへ送られるまで
- 載る商品の条件（載る・価格0円・非公開・規格が非表示・NM以外・高額商品コードなし）を別の行にする。二重起動・手動実行・送信の失敗は例外として差し込む
- 起動のしかた（定時のバッチ／ボタン）は、フィードの内容が同じなので因子にしていない（二重起動の例外だけボタンの操作）
