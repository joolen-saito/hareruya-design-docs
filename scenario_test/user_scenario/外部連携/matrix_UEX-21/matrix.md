# 登録した商品のフィード作成とユニサーチへの送信（商品の条件）（UEX-21）：組み合わせテストマトリクス

因子・水準は `fl_table.tsv`、禁則は `prohibitions.tsv`。このファイルは `build_matrix.py` が作る（手で直さない）。

- テスト数: 6
- 2因子間網羅率: 100.00%（0/0）
- 3因子間網羅率: 100.00%（0/0）
- 禁則: `prohibitions.tsv` の0件。設計書に無く現行ソース（pf-eccube3）で決めたものは扱い欄に書いた
- 禁則どうしが重なって行として成り立たない組は、網羅率の分母から外した

| No. | フィードに載せる商品の条件 |
|---|---|
| T01 | 載る商品：販売価格が1円以上・商品と規格が公開・規格が表示（高額商品でなければNMの規格だけ）。フィードのTSV（gz）とMD5値を入れたdoneファイルが作られ、ユニサーチへ送られる |
| T02 | 販売価格が0円の商品：フィードに載らない |
| T03 | 非公開の商品：フィードに載らない |
| T04 | 規格が非表示の規格：フィードに載らない |
| T05 | （高額商品でない場合）同一商品・同一言語の中で最も状態がよいもの以外の規格：フィードに載らない |
| T06 | （高額商品の場合）高額商品コードが設定されていない規格：フィードに載らない |

## 例外の差し込み（`exceptions.tsv`）

| 例外ID | 差し込む元のテスト | 差し込む手順 | 例外（★） | 期待値 |
|---|---|---|---|---|
| E1 | T01 | 管理画面の「フィードファイルを更新する」ボタンを押す | 作成中にもう一度ボタンを押す（二重起動） | 作成は始まらず「既に作成処理が実行中のため、今回の実行はスキップしました。」が出る。開始できたときは「ユニサーチフィードの作成を開始しました。」（完了の通知ではない） |
| E2 | T01 | フィードを作成する | 手動実行の指定 | 新実装は送信しない |
| E3 | T01 | フィードを送信する | 送信が失敗する | ログに記録し異常終了する。次の実行で作り直して再送する。画面には出ない。どの段階（削除・gzの送信・doneの送信）で失敗したかによって送信先に残るファイルが違うので、段階ごとに送信先の有無と内容を確かめて結果を記録する（検索への影響は期待値に置かない） |
