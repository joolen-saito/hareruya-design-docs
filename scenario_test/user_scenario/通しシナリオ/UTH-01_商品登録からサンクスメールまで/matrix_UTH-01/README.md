# 商品登録からサンクスメールまでの通し（UTH-01）

IPA「高信頼化ソフトウェアのための開発手法ガイドブック」(2010) の表6-9〜6-11と同じ手順で作る。FL表は `fl_table.tsv`、禁則表は `prohibitions.tsv`、例外の差し込み表は `exceptions.tsv`、マトリクスは `matrix.md`・`matrix.tsv`（`tools/build_matrix.py` が作る）。1行が「商品を登録するところから注文確認メールが届くところまで」を通す1回の試験になる。

## 範囲

- バックオフィスで商品を登録し（カード・グッズ・高額商品、予約・通常）、価格・在庫（入庫と承認）・公開（本店・支店）を整え、ユニサーチのフィードを作って送り、お客様の画面（ヘッダーの検索・サジェスト・詳細検索・カテゴリ・並び順）に出し、買い物かご→ご注文方法指定→購入完了→注文確認メール（サンクスメール）が届くまで
- ユニサーチ側（外部サービス）のフィードの取り込み・索引づくりは「システムの外」。ECが作って送るフィードの中身と、ECの画面に返ってくる検索結果を期待値にする
- 待ちの境目：①ユニサーチへの反映待ち（フィードを送ってから検索に出るまで）、②予約商品の発売日待ち（水準B3）。郵便振替・銀行振込・コンビニ決済は、購入完了と注文確認メールまでが終点で、入金を待つ先は通販のUTS-16・UTS-17
- 予約商品の発売日以降の出荷、セールの取り下げ（後日の作業）は範囲外（UTS-07、商品管理から注文確認メールまで/UPM-06）

## 因子の流用元

購入の因子（カートに入れる画面・支払方法・ポイント・商品金額合計）は `商品管理から注文確認メールまで/matrix_UPM-01/` から流用し、禁則の理屈もそのまま使った（流用した禁則は根拠欄に元の禁則IDを書いた）。購入のしかた（サイト・言語・お届け先・配送方法）は UPM-01 の配送方法・表示言語と UPM-05・UPM-03 の水準を1つの因子Sにまとめた。商品側の因子（種類・在庫の入れ方・公開の仕方・価格）は UPM-01 から、予約・スタン落ちは商品登録・編集（UPR）から、ユニサーチ側の因子（フィードの作り方・探し方・並び順・公開する店舗）はこのマトリクスで足した。

## 因子に入れなかったもの（流れ・処理・表示・期待値が通しの段階で変わらない、または別のマトリクスで見る）

| 入れなかったもの | 理由 |
|---|---|
| 購入数量と購入上限数・配送希望日時・注文時の備考 | 通しの流れは変わらず、メールの該当項目が変わるだけ。`商品管理から注文確認メールまで/matrix_UPM-01/`（水準E1〜E4・L・M）と UPM-04 で全組を見ている。L4 では数量2・備考ありの代表の値で、メールと注文の一致を確かめる |
| 地域別販売制限（日本国内のみ・海外のみ） | 表示は行い、買えるかは配送先で決まる（0303 商品詳細「販売制限が日本国内や海外のみになっている商品でも表示は行う」）。例外は UPM-01 の例外X16、UPM-05 |
| 端末（PC・スマートフォン） | 表示の配置だけが違う。サジェストの「商品のマウスオーバー表示」はPCのみ（0302 サジェストの処理概要④）。スマートフォンの検索は通販/matrix の因子M（UTS-01）で見る |
| 海外の配送方法（Small packet・International TA-Q-BIN）と海外の金額帯 | 選べる条件の違いだけ。UPM-05 で見る |
| 同梱・店頭受取（本店）・スムーズ店頭受取 | 店頭受取受注管理（UOR-01）・通販（UTS-16）で見る |

## 実装で確かめたこと（2026-11-05）

- フィードの作成と送信：新実装は1つの処理（ユニサーチ商品フィード連携用のバッチ）で、TSVを作ってgzに固め、MD5値を入れたdoneファイルを作り、続けて送信先へSFTPで送る。管理画面のボタンも同じ処理をバックグラウンドで起こす（送信もする）。設計書は、作成（毎時15分）と送信（5分おき・SCP）を別のバッチにする。食い違いは `../scenario_list.md` に記録した
- フィードの取得条件（新実装）：公開の商品・公開の規格・規格が表示・販売価格1円以上。高額商品でなければNM（グッズは一律NM）だけ、高額商品なら高額商品コードのある規格を状態を問わず。設計書の取得条件と一致する
- 在庫の項目：新実装は在庫が1以上ある店舗のID（本店・支店）を区切って送る。設計書は「NM以外も合計した在庫数」「支店ID:在庫数の形式で指定可能であれば指定したい」と書く。在庫ありの絞り込みは、サイトの店舗のIDで絞る（新実装 検索の条件づくりの処理）
- 開発環境の設定：ユニサーチの接続設定（検索・サジェスト・サジェスト削除・関連ワード・タグログの各API、送信先のホスト・ポート・利用者・送信先フォルダ・秘密鍵の場所・並列数）の項目がある。値は成果物に書かない。送信先ホストはDBダンプの追加システム設定に1件あり（値は書かない）
