# フロント注文から出荷までの通し（UTH-05）

IPA「高信頼化ソフトウェアのための開発手法ガイドブック」(2010) の表6-9〜6-11と同じ手順で作る。1行が「お客様のフロント注文から、受注管理・在庫・ピッキングを通り、出荷（店頭受取は引き渡し）と出荷完了メール・ポイント付与まで」を通す1回の試験（L3）。

1. 因子・水準表（FL表）: `fl_table.tsv`。通し全体で、流れ・処理・表示・期待値を変える分岐・選択・データの違いを因子にし、設計書か開発環境の設定を根拠に持つ
2. 禁則表: `prohibitions.tsv`。1行として成り立たない組（根拠つき）
3. 組み合わせテストマトリクス: `matrix.md` / `matrix.tsv`。`build_matrix.py` が作る
4. 例外の差し込み表: `exceptions.tsv`。エラーや中断（★）は、正常な値と混ぜず、条件に合う行へ1つずつ差し込む

## 範囲

- お客様が会員でフロントに入り、商品を探してカートに入れ、ご注文方法指定で配送方法・支払方法・ポイントを選んで購入する（業務フロー16 の1）
- 受注管理で受注を確認し、入金を確認し（待つ受注は待ち）、出荷指示を作り、ピッキングリスト・納品書・送り状CSVを出す（16 の2・3）
- 在庫は、購入で注文数だけ減ること（在庫の引き当て）、在庫0の商品の入荷待ちと入荷通知、予約商品、ピックの欠品を確かめる（業務フロー12・13 の関わる部分）
- 出荷実績を取り込んで出荷完了にし、出荷完了メール・ポイント付与・スマレジのポイント加算を確かめる（16 の4）。店頭受取・スムーズ店頭受取・店頭PCは、スタック用紙・ピック中・ピック完了を経て、引き渡しで終わる
- 終点：宅配は、出荷完了になり、お客様に出荷完了メールが届き、マイページが出荷完了になり、付与額が正なら保有ポイントとポイント履歴・スマレジのポイントに付与が出る（全額ポイント支払いなど付与0では履歴は増えない）。店頭受取・店頭PCは、引き渡しで元の受注が「引き渡し済み」になり、スマレジの取引から新しい受注が「出荷完了」で作られる。スムーズ店頭受取は、元の受注が「出荷完了」になる（店頭受取受注管理 UOR-02・03・07）
- 範囲外（対象外にした理由は `../scenario_list.md`）：出荷完了後の返品、メーラーだけの対応、別部署からの発注依頼、在庫移動の発送、集計・分析への出方（業務横断 UXB-01）

1行ごとに決まること：宅配の行（A1〜A6）は出荷指示・出荷実績の取り込みで終わる。店頭受取系の行（A7〜A9）は出荷指示リストの対象外（開発環境で配送方法の「出荷指示リストから除外」がオン）なので、出荷指示の工程の代わりにスタック用紙・ピックを通す。

## 禁則の置き方

- 支払方法×配送方法・購入グループ×配送方法・支店・店頭PC・外部委託・入金の確認は、設計書か開発環境の設定の文で成り立たない組だけを禁則にした（`prohibitions.tsv` の根拠欄）
- 判断待ちの禁則（`build_matrix.py` は禁則として扱う）：同梱×全額ポイント支払い（通販の判断待ち4）、店頭受取・スムーズ店頭受取×ポイントを使う（ポイント判断待ち#2。新実装は使用欄を隠す）、予約商品×スムーズ店頭受取、店頭PC×予約・入荷待ち、外部委託×入金前の出荷指示、大量注文×ゆうパケット
- 外部委託（E2）は予約の未開封製品（D4）だけで、D4 の配送方法はゆうパックだけが残る。したがって E2 の行は必ずゆうパック・予約の未開封製品になる（禁則が重なって成り立つ）

## 判断待ち（何を見ても決まらなかったもの）

1. 外部委託できない受注の条件と、外部委託の受注が出荷指示になる時点：業務フロー16 12-2「委託対応が不可の受注を抜き出しそれぞれ削除する」に条件が無い。12-1〜12-9 に出荷指示の工程が無い（通販 UTS-08・UTS-09 の状態は「出荷指示→出荷完了」）。見たもの＝業務フロー16、0203 出荷指示リスト生成
2. International TA-Q-BIN (US Only) の発送手順（ラベル・追跡番号・出荷実績の取り込み方）：業務フロー16 4-5〜4-8 は EMS と Small packet の手順だけ。開発環境にこの配送方法はあるが設計書に無い（通販 `matrix/README.md` と同じ）
3. 予約商品×スムーズ店頭受取、店頭PC×予約・入荷待ち、同梱×全額ポイント支払い、大量注文×ゆうパケットの大きさ：上の禁則のとおり。決まるまでこの組は行に入れない
4. 出荷実績の取り込みの完了の文言（「CSVファイルをアップロードしました」か「登録が完了しました。」）：0203 出荷実績インポート登録 M05-26-MSG-001・003 が併存
5. 通販の判断待ち1〜7、店頭受取受注管理の判断待ち（スムーズ店頭受取の返品・ポイント付与など）、ポイントの判断待ち（スムーズ店頭受取のポイント付与：UPT-04）は引き継ぐ（`../scenario_list.md` に再掲）
