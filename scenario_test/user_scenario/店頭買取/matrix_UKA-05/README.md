# 店頭買取の15時の自動入庫（UKA-05）

IPA「高信頼化ソフトウェアのための開発手法ガイドブック」(2010) の表6-9〜6-11と同じ手順で作る。手順と表の役割は `../matrix_UKA-01/README.md` と同じ。

## 範囲

- 毎日15時のバッチで、入庫待ちの買取が入庫済みになり、買取を行った店舗のEC在庫が増えるまで。買取を行った店舗が本店（TC）／支店を別の行にする
- 手動で入庫済みにした買取（二重に入庫されない）、未登録在庫ありの買取（対象にならない）は例外

- 2026-11-09：本文に同じ条件の値を並べていた（1回ずつ流すテストにするため）ので、値ごとに別の行・例外に分けて作った。期待値は 店頭買取/scenario_list.md の本文にあるものを水準ごとに分けただけで、新しい期待値は足していない
- 禁則：無い

## 作り直し

```
nice python3 -I scenario_test/user_scenario/tools/build_matrix.py scenario_test/user_scenario/店頭買取/matrix_UKA-05
```
