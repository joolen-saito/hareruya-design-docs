# 店頭買取の全品キャンセル（UKA-03）

IPA「高信頼化ソフトウェアのための開発手法ガイドブック」(2010) の表6-9〜6-11と同じ手順で作る。手順と表の役割は `../matrix_UKA-01/README.md` と同じ。

## 範囲

- 査定結果をお客様が全部断り、買取一覧のステータスが買取キャンセルになるまで（本人確認はUKA-01と同じ必須の手順として通す）
- 査定を中断して再開したあとに全品キャンセルする行（査定再開→買取キャンセル）と、中断せずにキャンセルする行を分ける
- 査定を中断する操作そのもの（再開しない）は例外として別のテストにする

- 2026-11-09：本文に同じ条件の値を並べていた（1回ずつ流すテストにするため）ので、値ごとに別の行・例外に分けて作った。期待値は 店頭買取/scenario_list.md の本文にあるものを水準ごとに分けただけで、新しい期待値は足していない
- 禁則：無い

## 作り直し

```
nice python3 -I scenario_test/user_scenario/tools/build_matrix.py scenario_test/user_scenario/店頭買取/matrix_UKA-03
```
