# 価格管理の基準価格変更CSVの取り込み（UPC-05）

IPA「高信頼化ソフトウェアのための開発手法ガイドブック」(2010) の表6-9〜6-11と同じ手順で作る。

1. 因子・水準表（FL表）: `fl_table.tsv`。価格変更の担当者がCSVに書く値と、対象商品の今の状態を因子にした
2. 禁則表: `prohibitions.tsv`。グッズ（NMだけ）とNM以外の規格の連携フラグ・割引率の組み合わせ3件
3. 組み合わせテストマトリクス: `matrix.md` / `matrix.tsv`。`build_matrix.py` が作る。1行が1本のシナリオ（1つの商品の価格変更）になる
4. 例外の差し込み表: `exceptions.tsv`。エラーや中断は、正常な値と混ぜず、条件に合う行へ1つずつ差し込む

## 範囲

- 「商品CSV管理」の「基準価格変更CSV」に、価格変更用CSVを取り込むところから、価格履歴・お客様の画面・スマレジ連携の確認まで（業務フロー11 5-2・6-4。2-4・3-4・4-3もここへ入る）
- CSVの列は商品ID・言語ID・基準価格・買取価格（0204 基準価格変更CSVフォーマット。原価単価は「こちら対応なし」）。CSVの基準価格はNMの規格の値で、SP・MP・HPの規格の価格は商品の割引率で換算される
- セール用の価格変更CSV（セールの入れ替え）は UPC-01、高額商品の価格変更CSV・画面からの一括編集は業務フローに工程が無く対象外（`../scenario_list.md` の対象外）

## 期待結果の決まり（行ごとに当てはめる）

| 取り込み前のセール状態 | 基準価格 | 販売価格 | 買取価格 | 画面のアラート |
|---|---|---|---|---|
| 通常商品（A1） | CSVの値へ更新 | CSVの基準価格（換算後）へ更新 | CSVの値（換算後）へ更新 | なし |
| セール中（A2） | CSVの値へ更新 | 変えない（今の値のまま） | CSVの値（換算後）へ更新 | 「セール中商品の販売価格は変更できない旨」を出す（エラーではない） |

- 価格履歴（価格が変わらない規格には足さない）：換算後の販売価格・買取価格を今の値と比べ、どちらも変わらない規格には履歴を足さない。片方だけ変わったときは、変わった側の新旧だけを記録する。基準価格も履歴に入る（E1・E2で決まる）
- スマレジ連携（シングルカード C1）：NM以外（SP・MP・HP・その他）の規格で、換算後の基準価格が300円以上のとき、連携フラグがONになりスマレジへ連携する。すでにONの規格はONのまま連携する（条件を下回っても自動でOFFにしない）。NMの規格は自動でONにならない。シングルカード以外（C2）は自動でONにならず、手動でONの規格だけが連携する
- 取り込みが成功すると、取込履歴が1件増え、取り込んだ商品を支店システムへ通知する（設計書。新実装の基準価格変更CSVの取り込みには通知が無い：食い違い）。エラーが1件でもあるとすべて取り消す
- お客様の画面：商品一覧・詳細に、規格ごとの販売価格が出る（セール中の規格は変わらない）

## 因子の選び方

- A セール状態：業務フロー2-4は「販売価格の上昇調整のみ」と書く。セール中の商品が価格変更の対象に混ざることがあるので、両方を入れた
- B 基準価格の変え方：300円をまたぐかどうかでスマレジ連携の結果が変わる。上げる・下げるの向きは「またぐ」の2水準に含めた。またがない2水準（299円以下のまま・300円以上のまま）は、上げ・下げどちらでもよい（テストで選ぶ）
- D・F：NM以外の規格の連携フラグの今の値と、商品の割引率が、換算後の基準価格が300円を超えるかどうかを変える。割引率があるとSP以下の換算後の価格はNMより低くなるので、B2・B3の行は、NMの値ではなくSP等の換算後の価格が300円をまたぐように選ぶ
- 禁則：グッズ（C2）は規格が一律NMなので、NM以外の規格の連携フラグ（D1・D2）と割引率あり（F1）と組み合わせない。グッズの行はD3・D4（NM以外の規格が無い。NM規格の連携フラグがOFFかONか）になる。シングルカード以外では手動でONにした規格だけが連携するので、D3（連携しない）とD4（連携する）の両方を行で確かめる。セール中（A2）と300円をまたぐ変更は同時に成り立つ

## 実装で確かめたこと（2026-11-03）

- セール中でも買取価格は更新する：新実装の基準価格変更CSVの取り込みは、セール中の規格で販売価格を変えず、基準価格と買取価格を更新する（履歴にも買取価格の変更を書く）。0204 基準価格変更CSVアップロードの機能仕様（「基準価格、買取価格は変更できる」）・メッセージ（M03-30-MSG-004「通常商品のため…買取価格のみ更新しています」は通常商品の文言）と合う。0204 基準価格変更CSVフォーマットだけが「販売価格、買取価格は変更できない」と書く（食い違いとして記録）
- スマレジ連携の閾値：新実装の設定で300円。NM以外（SP・MP・HP・その他）の規格で、換算後の基準価格が閾値以上のとき連携フラグを1にし、すでに1ならそのまま。設計書の「基準価格が300円以上かつ状態がSP、MP、HP、その他規格」と合う
- 取込の検査：買取価格が基準価格を上回る行を検査する（同額は通る）。新実装の文言は「基準価格は買取価格より大きい…」で、設計書は「販売価格は…」

## まとめた水準

なし（どの水準も処理が違う）。主な根拠：セールフラグで販売価格を変えるか変えないかが違い、300円をまたぐ4通りは連携フラグの自動ON・OFFが違う。連携フラグの初期値（OFF・ON・NM以外なし）、価格履歴の追加の有無、割引率の有無も処理が違う。
