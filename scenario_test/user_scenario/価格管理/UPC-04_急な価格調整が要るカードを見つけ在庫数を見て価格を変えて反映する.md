# UPC-04 SNSなどの情報で急な価格調整が要るカードを見つけ、在庫数を見て価格を変えて反映する

| 項目 | 内容 |
|---|---|
| 利用者 | 顧客戦略チームの担当者（価格変更CSVを取り込む）→ お客様 |
| 目的 | 大会後・新商品発表・禁止改定・トレンドの変化など突発の事象で急ぎの価格調整が要るカード（または仕入れた希少なカード）を決め、在庫数を見て価格を決め、価格変更CSVで反映して、お客様の画面にそのカードの新しい価格が出て、買取・販売価格履歴に変更前後が残ることを確かめる |
| 種類 | 正常（組み合わせ表の1行）。2行目は「L3で変わるところ」 |
| マトリクスの行 | `matrix_UPC-04/matrix.md` のT01（イレギュラー調整のきっかけ＝突発的な事象）。T02（希少なカードを仕入れた場合の価格の新設・調整）は「L3で変わるところ」。価格の反映は `matrix_UPC-05/matrix.md` の行ではなく表外の具体例：通常商品・基準価格 300円以上のまま（上げる）・シングルカード・連携フラグ SP・MP・HP がON・買取価格は同じ値・割引率あり（最も近いのはT16・T17で、今のセール状態が違う）。価格の反映の行ごとの違いは UPC-05 のL3 |
| もとのシナリオ | SCN-PRICE-004 |

## 前提

- 共通の決まり：`../L4を流すときの共通の決まり.md` を先に読む（試験データの名前にシナリオIDを付ける・共有の設定は元に戻す・バッチの起動・店舗の読み替えなど）
- システムの外で済んでいること：SNSなどでの情報収集（大会後・新商品発表・禁止改定・トレンドの変化のどれか）。急ぎの調整が要るカードを1件決めること。支店システムは存在しないので、取り込み後の支店システムへの通知は手順にも期待値にも置かない
- 用意するデータ（試験用の値。設計書の値ではない）
  - 担当者：管理画面で、商品管理・商品CSV管理を使える顧客戦略チームの担当者。在庫の承認者（別の担当者）
  - 商品：シングルカード「シナリオ試験急変カード」（英名「Scenario Test Sudden Change Card」、言語＝日本語、状態＝NM、基準価格・販売価格 500円、買取価格 100円、割引率「4」＝NM100%・SP90%・MP80%・HP70%、商品公開ステータス＝公開、支店の商品公開ステータス＝非公開）。基準価格 500円なので、4規格の基準価格・販売価格は NM 500・SP 450・MP 400・HP 350円（SP・MP・HPのスマレジ連携フラグは登録のときにON）。在庫はNMの規格に3点
  - 価格変更用CSV：「基準価格変更CSVアップロード」の雛形ファイルダウンロードと同じ見出し（商品ID・言語ID・基準価格・買取価格）
- 商品を新しく登録するので、同じカードの商品が既にあると行は飛ばされる。やり直すときはカード名と商品名を変える（名前の後ろの番号）
