# 価格管理の週次の全カード価格調整（UPC-03）

IPA「高信頼化ソフトウェアのための開発手法ガイドブック」(2010) の表6-9〜6-11と同じ手順で作る。

2026-11-09：シナリオの本文に「／」で並べていた値を、1回ずつ流すテストに分けるために作った（IPA 6.3.1・6.3.2。依頼者決定）。値と期待値は本文に書いてあったものを水準ごとに分けただけで、新しい期待値は作っていない。

## 範囲

- 週次作業で、商品マスターのカスタムデータCSVから販売数の分析データを出し、在庫を見るところ。価格の反映は `../matrix_UPC-05/` の行で確かめる（シナリオ一覧のL3）
- 因子：見るもの（在庫過多／売上過多）、見る在庫の範囲（通販／支店／バックヤード）、販売数の列（EC＋TC東京／支店）
- 「支店・バックヤードの在庫も見る」は、本文が買取・基準価格一括編集の「表示在庫切替え」を「支店」にした場合と「バックヤード」にした場合を別に書いているので、2水準に分けた

## 期待結果の決まり

- 在庫過多：在庫が多く週間の販売数が少ないカードを用意し、カスタムデータCSVの在庫数と1週間販売数の列にそのとおりの値が出る（過多かどうかの判断は、システムの外の人の作業）
- 在庫の範囲「支店」：表示在庫切替えを「支店」にすると支店の在庫数が表示される。「バックヤード」にするとバックヤードの在庫数が表示される。通販だけを見る場合は通販の在庫
- 販売数の列：「前日販売数」「1週間販売数」はEC＋TC東京の販売数、「前日販売数（支店）」「1週間販売数（支店）」は全支店のECスマレジ販売数が出る
