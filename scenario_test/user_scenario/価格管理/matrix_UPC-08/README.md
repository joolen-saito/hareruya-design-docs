# 価格管理の期間別販売数の集計（UPC-08）

IPA「高信頼化ソフトウェアのための開発手法ガイドブック」(2010) の表6-9〜6-11と同じ手順で作る。

2026-11-09：シナリオの本文に「／」で並べていた値を、1回ずつ流すテストに分けるために作った（IPA 6.3.1・6.3.2。依頼者決定）。値と期待値は本文に書いてあったものを水準ごとに分けただけで、新しい期待値は作っていない。

## 範囲

- 毎日0時のバッチが、前日までの販売数を集計して商品マスターの販売数に反映するところ（0404 B02-01）
- 因子は集計期間だけ（前日／3日間〜365日の各期間）。本文の「対象の明細が1件も無い集計単位」「再実行」「集計の対象」「明細の振り分け」「計上日」は、条件の値として並べたものではなく、バッチの動作の説明なので水準に分けない

## 期待結果の決まり

- 前日：実行日の前日1日分だけ
- 3日間・1週間・1ヵ月・90日・180日・365日：実行日当日の受注も含む

※因子が1〜2つのとき、`tools/build_matrix.py` は網羅率の分母が0になって止まる（2026-11-09時点）。この表は、割り算の前に分母0を100％として扱い、因子が1つのときは水準ごとに1行にする以外は `build_matrix.py` と同じ手順の写しで作った。道具が直れば、下のコマンドで同じ表ができる。

## 作り直し

```
nice python3 -I scenario_test/user_scenario/tools/build_matrix.py scenario_test/user_scenario/価格管理/matrix_UPC-08
```
