# 価格管理の月次の価格適正チェック（UPC-06）

IPA「高信頼化ソフトウェアのための開発手法ガイドブック」(2010) の表6-9〜6-11と同じ手順で作る。

2026-11-09：シナリオの本文に「／」で並べていた値を、1回ずつ流すテストに分けるために作った（IPA 6.3.1・6.3.2。依頼者決定）。値と期待値は本文に書いてあったものを水準ごとに分けただけで、新しい期待値は作っていない。

## 範囲

- 月次作業で、トレードチームが「通常作業用」のカスタムデータCSVをダウンロードして価格の適正をチェックするところから、変更の取り込みまで。価格の反映は `../matrix_UPC-05/` の行で確かめる（シナリオ一覧のL3）
- 因子は適正チェックの結果（変更あり／変更なし）だけ

## 期待結果の決まり

- 変更あり：変更した商品の価格が、お客様の画面に新しい価格で出る。価格が変わった規格には価格履歴に変更前後が残る
- 変更なし：変更点が無ければ取り込まずに終わる

※因子が1〜2つのとき、`tools/build_matrix.py` は網羅率の分母が0になって止まる（2026-11-09時点）。この表は、割り算の前に分母0を100％として扱い、因子が1つのときは水準ごとに1行にする以外は `build_matrix.py` と同じ手順の写しで作った。道具が直れば、下のコマンドで同じ表ができる。

## 作り直し

```
nice python3 -I scenario_test/user_scenario/tools/build_matrix.py scenario_test/user_scenario/価格管理/matrix_UPC-06
```
