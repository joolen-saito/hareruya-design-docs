## 判断待ち

開いた項目は無い。確かめたこと（記録）：

1. 当日の列：設計書は「当日分の販売数の列は毎回0で初期化する」と書くが、新実装は受注のたびに当日の販売数を加算し、日次のバッチは当日の列を更新しない（UPC-08 の記録と同じ）。この試験は当日の列を合否に使わない
2. 受注の時のリアルタイム加算：新実装は注文のとき、3日間以降の列にその場で加算する。この試験は注文日時を書き換えたあとにバッチを起動して上書きされた値で判定するので影響しない
3. 受注売上分析の「前日」「実行日」の行は、集計の画面を開くたびに受注を数えて出す（バッチを使わない。UAN-04 の前提）
4. 店頭受取の置き換えのとき、EC計上とスマレジ計上の画面での出方（表示データの切り替え）は、設計書に画面の定めが無く記録にとどめる

設計書との食い違い（起票しない）：UPC-08 に記録済みのもの（当日の列の初期化、明細が無い集計単位の前回値、完了の表示）がそのまま当てはまる。
