# UPR-04 新弾以外の新商品（既製品・オリパ・デッキセット）をCSVで登録する

| 項目 | 内容 |
|---|---|
| 利用者 | トレードチームの担当者（登録担当。現状版は顧客戦略チーム）→ デザインチーム（オリパの画像）→ トレードチーム。登録した商品は、お客様の画面で確かめる |
| 目的 | サプライ品などの既製品・オリパ・デッキセットを、グッズ商品CSVで登録し、商品マスターの商品編集画面と規格設定で、公開ステータス・カテゴリ・部門・スマレジ連携が登録値どおりになることを確かめる。在庫を入れて売り始めるのは UPR-05 |
| 種類 | 正常 |
| マトリクスの行 | `matrix_UPR-04/matrix.md` のT01（既製品（サプライ品・構築済みデッキなど）・スマレジ連携フラグ＝無効・本店の商品公開ステータス＝公開・支店の商品公開ステータス＝非公開・商品カテゴリはカンマ区切りで複数）。tobe版の業務フロー10 4-1〜4-5（部門はグッズ商品CSVに書く） |
| もとのシナリオ | SCN-PRODUCT-004・010（4-3まで）。在庫の登録・公開は UPR-05 が新しい |

## 前提

- 共通の決まり：`../L4を流すときの共通の決まり.md` を先に読む（試験データの名前にシナリオIDを付ける・共有の設定は元に戻す・バッチの起動・店舗の読み替えなど）
- システムの外で済んでいること：新商品が決まっている。既製品・デッキセットの商品画像はトレードチームが用意し、オリパの画像はデザインチームに作成を依頼する（業務フロー10 4-1）。画像はS3へ保存済みで、CSVの規格画像に保存先を書く
- 用意するデータ（試験用の値。設計書の値ではない）
  - 登録担当：管理画面で、商品管理を編集できる権限を持つ担当者
  - 商品（T01）：グッズ「シナリオ試験サプライA」（商品コード「UPR04-T01」、基準価格・販売価格 2,000円、買取価格 1,000円、購入グループ「通常商品」、商品カテゴリは「サプライ・グッズ」（番号2。開発環境の決め打ちの値）と UPR-01 で登録した「シナリオ試験 予約カテゴリ」の2つ、商品公開ステータス＝公開、支店の商品公開ステータス＝非公開、スマレジ連携フラグ＝無効）。グッズ商品CSVに1行書く
  - スマレジ連携フラグを有効にする行（T02・T04・T06）：部門は、スマレジに連携済みの部門を部門登録/編集で用意しておく（試験用「シナリオ試験部門」）。スマレジ商品コードは、スマレジにまだ無い試験用の値を使う（行ごとに別の値）
  - デッキセットの行（T05・T06）：デッキ構築で作ったデッキリストを用意する
- グッズ商品CSVの商品コードは、商品ごとに別の値にする（行ごとの値は下の表）。同じ商品コードは重ねて登録できない。試験をやり直すときは商品コードを変える
- 在庫は0のまま。結合で作るデッキセットの在庫は UZK-05、入庫と公開の手順は UPR-05

## 操作の流れと期待値

| # | 操作する人と操作 | 期待値（画面で見えること） |
|---|---|---|
| 1 | 登録担当：商品画像を用意する（システムの外の作業。既製品はトレードチームが用意。オリパはデザインチームに画像作成を依頼。デッキセットはトレードチームが用意。4-1）。デッキセットの場合は、さらにデッキリストを作る（手順2） | 画面の変化は無い。既製品（代表の行）は、デッキリスト作成を行わない |
| 2 | （デッキセットの行だけ。T01では行わない） | 代表の行では行わない。L3の表のT05・T06で通す |
| 3 | 登録担当：商品管理＞カテゴリ登録/編集の「CSVダウンロード」で、商品カテゴリの番号を調べる。続けて、グッズ商品CSVを作る（システムの外。4-4）。商品カテゴリ(ID)に「2,（新カテゴリの番号）」とカンマ区切りで書き、商品コード・購入グループ名称・規格画像・買取価格を書く | カテゴリのCSVに「サプライ・グッズ」と新カテゴリの行が出る。画面の変化は無い |
| 4 | 登録担当：商品管理＞商品CSV管理＞グッズ商品CSV登録を開き、「雛形ファイルダウンロード」の見出しと同じCSVを選んで「CSVファイルをアップロード」を押し、確認の画面（「グッズ商品CSVをアップロードします。よろしいですか？」）で「確認」を押す（4-5） | 「CSVファイルをアップロードしました」が管理画面の上部に出て、グッズ商品CSV登録の画面に戻る。CSVインポート履歴に、ファイル名・アップロード日時・作業者の行が1件増える。スマレジ連携（新規）・スマレジ連携状態は「対象なし」（連携フラグが無効のため）。エラーの案内は出ない |
| 5 | 登録担当：商品管理＞商品一覧で「シナリオ試験サプライA」を検索し、商品編集画面と規格設定を開く | 検索結果に1件。商品編集画面で、商品名・購入グループ「通常商品」・商品カテゴリ2件・商品公開ステータス「公開」・支店の商品公開ステータス「非公開」が、CSVの値で表示される。規格は1件で、基準価格・販売価格が2,000円、在庫0。規格設定で、スマレジ連携フラグは「連携しない」、スマレジ商品コードは空、部門は設定されない。商品IDを控える |
| 6 | お客様：本店の商品詳細を、手順5で控えた商品IDで直接開く。続けて、支店のサイトで同じ商品の詳細を開く | 本店の商品詳細が開き、価格2,000円が出る（在庫は0）。支店の商品公開ステータスが非公開なので、支店の商品詳細は開かない |
| 7 | 登録担当：管理画面の商品管理＞ユニサーチフィード作成で「フィードファイルを更新する」を押し、ユニサーチ側の取り込みが終わるまで待つ（外部サービス）。お客様：本店のヘッダーの検索欄に「シナリオ試験サプライA」と入れて検索する | 「ユニサーチフィードの作成を開始しました。」が出る。取り込みのあと、本店の検索結果に「シナリオ試験サプライA」が出る。グッズなのでカード言語・状態は出ない。支店のサイトの検索結果には出ない。フィードに載る前は検索に出ない（UPR-01 の手順9と同じ） |
