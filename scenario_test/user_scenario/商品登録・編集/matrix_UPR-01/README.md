# 商品登録・編集の新弾のBOXの予約商品登録（UPR-01）

IPA「高信頼化ソフトウェアのための開発手法ガイドブック」(2010) の表6-9〜6-11と同じ手順で作る。

2026-11-09：シナリオの本文に「／」で並べていた値を、1回ずつ流すテストに分けるために作った（IPA 6.3.1・6.3.2。依頼者決定）。値と期待値は本文に書いてあったものを水準ごとに分けただけで、新しい期待値は作っていない。

## 範囲

- 新弾のBOXを予約商品として登録し、お客様の画面に出すところ（業務フロー09・10の1-1〜1-3）。商品登録の前段（カードセット・略称タグ・カテゴリの新規登録）を含む
- 因子：本店の商品公開ステータス（公開／非公開）、支店の商品公開ステータス（公開／非公開）、カテゴリの新規登録の手段（画面／カテゴリCSV登録）は2026-11-09に外した（下記）
- 予約BOX固有の値（予約用の購入グループ、商品カテゴリを複数指定）は行の因子にせず、全行で同じにして登録する（本文のまま）
- グッズ商品CSVの値の組はUPR-04、公開状態の切り替えはUPR-09で見る

## 期待結果の決まり

- 公開にした商品は本店のお客様の画面に出る。本店・支店がどちらも公開の商品は支店の画面にも出る（両方とも「公開」が選択されている場合のみ、支店の画面に商品を表示する）
- カテゴリ登録の画面：新しい商品カテゴリを1件登録し、カテゴリの一覧に出る
- カテゴリ登録CSV：カテゴリCSV登録（M03-41）に新しいカテゴリの行のCSVを取り込み、新規登録のとき表示ランク・階層・対象商品数などCSVで設定しない項目が補完されて登録される

## 外した因子・水準（2026-11-09 依頼者決定：画面の操作の違い）

業務の流れも結果も分かれない画面操作の違いは、組み合わせ表から外し、結合テストに任せる（依頼者決定）。値と期待値は消しただけで、新しく作っていない。

- 因子C「カテゴリの新規登録の手段（画面／カテゴリCSV登録）」を因子ごと外した。どちらも新しいカテゴリが登録されるだけの入口の違い。前提：カテゴリはカテゴリ登録の画面で登録する。
- 行は4行のまま（T01〜T04。カテゴリの手段が行から無くなった）。
