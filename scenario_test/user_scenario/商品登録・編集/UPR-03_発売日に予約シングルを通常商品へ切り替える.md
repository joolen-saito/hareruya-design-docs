| 項目 | 内容 |

| 目的 | 新弾の発売前日以前に、予約商品を通常商品へ切り替える更新用のカード商品CSVを作り、前日23時頃にカード商品CSV登録で取り込んで、発売日に商品が通常商品の購入グループになり、お客様が通常商品として注文できることを確かめる |

## 前提

- 共通の決まり：`../L4を流すときの共通の決まり.md` を先に読む（試験データの名前にシナリオIDを付ける・共有の設定は元に戻す・バッチの起動・店舗の読み替えなど）
- UPR-02 の T01 の終点まで済んでいる（「シナリオ試験カードJ」が、予約用の購入グループ「予約シングル用（シナリオ試験）」・商品公開ステータス「公開」・支店「非公開」・規格4件（割引率4。NM・SP・MP・HP。NMの基準価格・販売価格300円、SP 270円・MP 240円・HP 210円、購入上限数4）で登録済み）。商品IDを控えている
- 在庫：UPR-05 の手順3・4と同じ操作（在庫変更CSV登録で入庫5点、承認者が承認。店舗は本店、在庫場所はEC）で、「シナリオ試験カードJ」の本店のEC在庫を、NM規格について5点にしてある（商品には NM・SP・MP・HP の4規格があり、カートの在庫判定は選んだ規格と表示中の店舗の在庫を見るので、本店のサイトでNM規格を買う）。SP・MP・HPの規格は在庫0のまま使わない
- 用意するデータ（試験用の値。設計書の値ではない）
  - 登録担当：管理画面で、商品管理を編集できる権限を持つ担当者
  - 切り替え先の購入グループ：「通常商品」（開発環境にある購入グループ。支払方法にクレジットカード決済、配送方法にゆうパックが入っている）
  - 更新用のカード商品CSV：商品ID（控えた値）・購入グループ名称「通常商品」・基準価格600円・販売価格600円・買取価格300円・そのほかの列は登録時の値のまま
  - 会員：試験 花子（メールアドレス `upr-03@example.test`、国内（東京都）の住所を登録済み）
  - 比較用の商品：グッズ「シナリオ試験グッズK」（購入グループ「通常商品」、公開、在庫あり、販売価格1,000円）。切り替えたあと、同じ買い物かごに入れて買えることを確かめる
- 時間の決まり：前日23時頃の取り込みは、時刻を待たず、手で取り込む（2026-11-26 決定）。発売日に当たる日の画面は、取り込みの直後に確かめる
- 業務フロー3-1・3-2のとおり、更新用CSVは前日以前に作り、取り込みは前日23時頃
