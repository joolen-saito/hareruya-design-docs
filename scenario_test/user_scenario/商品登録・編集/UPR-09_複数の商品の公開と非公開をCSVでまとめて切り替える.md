# UPR-09 複数の商品の公開・非公開を、CSVでまとめて切り替える

| 項目 | 内容 |
|---|---|
| 利用者 | トレードチームの担当者（登録担当）→ お客様 |
| 目的 | 公開・非公開を切り替える商品群を決め、商品一覧から「カード商品CSV出力」で出したCSVの公開ステータスの列を直し、「カード商品CSV登録」で取り込んで、商品の本店・支店の公開状態が切り替わり、お客様の画面（本店が公開のとき本店、本店・支店がどちらも公開のとき支店）の見え方が変わることを確かめる |
| 種類 | 正常 |
| マトリクスの行 | `matrix_UPR-09/matrix.md` のT01（切り替える前：本店公開・支店公開 → 切り替えたあと：本店公開・支店非公開）。表は12行（T01〜T12）。カード商品CSV登録で切り替える（グッズ商品CSV登録は入口の違いなので組み合わせ表から外した） |
| もとのシナリオ | SCN-PRODUCT-008・012 |

## 前提

- 共通の決まり：`../L4を流すときの共通の決まり.md` を先に読む（試験データの名前にシナリオIDを付ける・共有の設定は元に戻す・バッチの起動・店舗の読み替えなど）
- システムの外で済んでいること：公開・非公開を切り替える商品群が決まった（業務フロー10 8-1の前）
- 用意するデータ（試験用の値。設計書の値ではない）
  - 登録担当：管理画面で、商品管理を編集できる権限を持つ担当者
  - 商品：行ごとに別のカードの商品を使う（各行を1回ずつ流すため）。UPR-02 と同じ要領で、カード商品CSVで登録しておく。商品名「シナリオ試験切替T01」〜「シナリオ試験切替T12」、カードも行ごとに別（同じカードの商品は2つ登録できない）、基準価格 250円、買取価格 100円、購入グループ「通常商品」、商品カテゴリ1つ、割引率は初期データの「割引率4」（NM・SP・MP・HPの4規格ができる。NM 250円・SP 230円・MP 200円・HP 180円。4規格とも300円未満なので、スマレジ連携の対象にならない）、在庫0。商品公開ステータスと支店の商品公開ステータスは、行ごとの「切り替える前」（L3の表）でCSVに書く
  - T01 の切り替える前：商品公開ステータス＝公開、支店の商品公開ステータス＝公開。切り替えたあと：公開・非公開
- カード商品CSVの公開ステータスの列は、画面のフォーマット表の数字で書く（商品公開ステータス「1:公開 2:非公開 3:廃止」、支店の商品公開ステータス「0:非公開 1:公開」）。設計書の数字（「1: 非公開 2:公開 3:廃止」など）と食い違うので、この文書は名前（公開・非公開）で書く（`scenario_list.md` の食い違い）。期待値は設計書の値（1:非公開・2:公開・3:廃止）どおりにする。実行時に画面のフォーマット表の数字が設計書と違えば、設計書との食い違いとして記録し不合格にする。先へ進む手順として、手順3・L3の表のCSVの数字は画面のフォーマット表の数字で書いて取り込む（2026-11-27 依頼者決定。E3・E5も同じ）
- 在庫は0のまま。商品名・価格など、公開ステータス以外の列は出力のまま変えない

## 操作の流れと期待値

| # | 操作する人と操作 | 期待値（画面で見えること） |
|---|---|---|
| 1 | お客様：変更前の画面で確かめる。本店の商品詳細と、支店のサイトの同じ商品の詳細を、商品IDで直接開く（手順1の前に、登録担当が管理画面の商品一覧で「シナリオ試験切替T01」を検索して商品IDを控えておく） | 本店・支店がどちらも公開なので、どちらの商品詳細も開く |
| 2 | 登録担当：管理画面の商品管理＞商品一覧で、「シナリオ試験切替T01」を検索し、行にチェックを入れて「カード商品CSV出力」を押す（8-1。業務フロー10の「商品マスターから該当する商品を検索し「(カードorグッズ)商品CSV出力」」） | CSVがダウンロードされる。列の並びがカード商品CSV登録のフォーマット表と同じで、商品ID・商品公開ステータス・支店の商品公開ステータスが現在の値（公開・公開）で入っている。商品IDを控える |
| 3 | 登録担当：CSVの支店の商品公開ステータスの列を、非公開（0）に直す。商品公開ステータスは公開のまま（8-2。システムの外の作業） | 画面の変化は無い |
| 4 | 登録担当：商品管理＞商品CSV管理＞カード商品CSV登録で、手順3のCSVを選んで「CSVファイルをアップロード」を押し、確認の画面（「カード商品CSVをアップロードします。よろしいですか？」）で「確認」を押す（8-3） | 「CSVファイルをアップロードしました」が管理画面の上部に出て、CSVインポート履歴が1件増える。商品は新規に増えず、同じ商品が更新される |

| 7 | 登録担当：管理画面の商品管理＞ユニサーチフィード作成で「フィードファイルを更新する」を押し、ユニサーチ側の取り込みが終わるまで待つ（外部サービス）。お客様：本店・支店のサイトのヘッダーの検索欄に「シナリオ試験切替T01」と入れて検索する | 「ユニサーチフィードの作成を開始しました。」が出る。取り込みのあと、本店の検索結果に出る。支店の検索結果には出ない。フィードに載る前の検索結果は、設計書に定めが無いので記録する |

## 判断待ち

開いた項目は無い。【決着 2026-11-27 依頼者「全部おすすめどおり」】B4：商品公開ステータスは設計書の値（1:非公開・2:公開・3:廃止）を期待値にし、新実装の画面と違えば不合格として記録し、先へ進む手順を書く（E3・E5も同じ）。確かめたこと（記録）：
