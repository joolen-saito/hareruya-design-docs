## §1. 全ケース共通前提
- **入口/認証**: 本APIはJSON APIエンドポイントで画面を持たない（正本 L296）。MTGバイヤー（買取アプリ）から呼ばれる（正本 L293,L312）。Excel A06-12 は **認証の有無=有／認証方式=IP制限・トークン**（Excel `0506:L3278`）。詳細設計は「認可方式はpf-apiの方針に従う」（正本 L350）＝Excelが認証方式を具体化。具体的な拒否形式（401/403 等）は本機能で規定せず＝要実機確認。
- **メソッド/契機**: `GET`（Excel `0506:L3278`／正本 L311,L315）。呼び出しごとにオプションマスタから固定価格部門の設定値（部門ID）を取得して返す（正本 L316）。
- **参照系**: 副作用なし（参照のみ・正本 L336）。DBへの登録・更新・削除を行わず、mtb_option を検索するのみ（正本 L346）。排他/トランザクション・ロックの対象を持たない（正本 L356）。
- **応答**: 成功時 HTTP 200 で JSON を返す（Excel `0506:L3290`＝ステータス200／正本 L325）。応答は JSON 応答整形を経て返す（プロパティ camelCase・日時 ISO8601・正本 L337）。
- **オラクル独立性**: 期待はオラクル（Excel優先・沈黙部は詳細設計HTML）由来で実装から独立。実装との差は付帯表4で乖離＝バグ候補として扱う（RG-006/007/013/014 に関連）。
