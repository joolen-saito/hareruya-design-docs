# 結合テスト対象機能 正本一覧（IT Target Functions）

本書は **結合テストケースの対象機能の正本**である。ユーザー提示の機能マスター（正本HTML由来・394ユニーク機能）を唯一の基準とし、各機能の現況ステータスを機械判定で付与している。

- 実体データ: [`it-target-functions.tsv`](it-target-functions.tsv)（1機能1行・タブ区切り）
- 生成/検証の突合元:
  - 機能設計ドキュメント `functions/*/*.md`（`function_dependency_inventory.tsv` の基点）
  - ITケースファイル `integration_test/*_it_cases.md`
  - Ph2見送りレジストリ `functions/phase2_candidates.tsv`
  - 廃止/統合候補レジストリ `functions/superseded_candidates.tsv`

## 列定義

| 列 | 内容 |
|----|------|
| id | 機能ID（大文字ハイフン） |
| 機能名 | 正本一覧の名称（＝正） |
| ステータス | `対象` / `対象-Ph2見送り` / `対象-テスト未整備` |
| 機能ドキュメント | `functions/` 配下に設計ドキュメントが存在するか |
| ITケース | ITケースファイルが存在するか |
| Ph2 | `phase2_candidates.tsv` にfeatureNo登録があるか |
| superseded | `superseded_candidates.tsv` にfeatureNo登録があるか（※行単位の仕様削除を含み、機能全体廃止とは限らない） |
| 備考 | 補足（台帳未反映・機能ドキュメント無 等） |
