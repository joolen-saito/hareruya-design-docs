期待結果は画面表示・遷移・URL・HTTP応答など観測可能な結果で判定する。**期待結果は仕様(設計書/観点表/基本設計)由来**（実装の現挙動・Form制約を写さない＝オラクル独立性）。Playwright は本リポジトリでは実行しない。セレクタ等の実装由来情報は後述の付帯表に分離し、未検証は `要実機確認` と明示する。

本機能は参照系の一覧（GETのみ・利用者入力なし・更新/削除なし）であり、NM価格 × カード状態 × 通常/Foil・プロモ版 の買取価格をマトリクス表示し、各金額セルは編集画面へのリンクになる。

## 関連ID対応概要

| 関連ID | 本機能でのE2E確認範囲 |
|--------|------------------------|
| IT-15 | 未認証時のログイン誘導／権限不足の拒否（手動）／GET前後の副作用・状態変化なし（手動/間接）。CSRFは更新が無く対象外 |
| IT-20 | 一覧出力内容・金額セル・欠け組合せは買取価格(編集リンク)非表示（設計書「セル欠け」由来。実装の「-」文言はオラクル化しない） |
| IT-25 | UI部品・操作起点・URL・HTTPステータス（確認ダイアログ/送信可否は対象外） |
| IT-03 | 金額セル→編集画面の画面遷移（共通エラー経路は手動） |
| IT-13 | 一覧URL直接アクセス |
| IT-22 | 一覧画面に利用者入力が無く検証不要（全件対象外） |
| IT-23 | DB検索結果のマトリクス間接観測（既知価格表示） |
| IT-02 | 初期行数・表示順（設計書は最外層キー(NM価格)の列挙順。昇順は実装挙動=要確認のためオラクル固定しない・間接/シード依存） |
