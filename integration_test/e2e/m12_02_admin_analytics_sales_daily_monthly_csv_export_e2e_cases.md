# M12-02（日別/月別集計 CSVダウンロード） E2Eテストケース

元設計（一次オラクル）: `function_spec_html_preview/pf-eccube3/m12-02_admin_analytics_sales_daily_monthly_csv_export.html`（正本 `functions/pf-eccube3/m12-02_admin_analytics_sales_daily_monthly_csv_export.md`）

テスト観点: `integration_test/integration-test-viewpoints.md` ／ 既存IT: `integration_test/m12_02_admin_analytics_sales_daily_monthly_csv_export_it_cases.md`（母集合 計90観点行）

期待結果は画面表示・遷移・URL・HTTP応答・ダウンロード発火などブラウザで観測できる結果で判定する。**期待結果は仕様（設計書・観点表・基本設計）由来**とし、実装/POM由来の表示文言・ファイル名・列定義をオラクル化しない。TSV は既存IT casesの10列に実施管理欄（実施者・実施日・結果・失敗理由）を加えた14列固定。E2E固有情報は TSV 後の付帯表に `テストID` で対応づける。Playwright は本リポジトリでは実行しない（構造参考のみ）。未検証セレクタは `要実機確認`。

本機能は **CSV出力（csv_export）** 画面タイプ。E2Eの主観測は「出力導線の表示・ダウンロード発火・HTTP応答・画面遷移なし・権限ガード」。**CSVファイルの中身（ヘッダ列・データ行・集計値のM12-01一覧一致・購買率%・会員数）は手動**で確認する（観点表は本機能の入力フォームを持たず、集計ロジックはM12-01へ委譲する設計）。

設計源は pf-eccube3（HareruyaEc プラグイン）のリバース。**刷新先 ec-cube-enterprise との乖離（ファイル名・ヘッダ先頭列名・表示項目固定・セッション空時の挙動）は付帯表4（不具合候補）に出し、テストは仕様どおりに書く**（実装が違えば落ちて検出する）。
