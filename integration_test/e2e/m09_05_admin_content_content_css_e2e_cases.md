# m09-05_admin_content_content_css（管理画面_コンテンツ管理_CSS管理） E2Eテストケース

- 元設計(機能詳細HTML): `function_spec_html_preview/ec-cube-enterprise/m09-05_admin_content_content_css.html`

- 既存IT cases: `integration_test/m09_05_admin_content_content_css_it_cases.md`

期待結果は画面表示・遷移・URL・フラッシュ表示・送信値(隠しtextarea)等の観測可能な結果で判定する。**期待結果は仕様(設計書/観点表/基本設計)由来**であり、実装の現挙動・i18nリソース値・Form制約を期待値へ流用しない（オラクル独立性）。

Playwright は本リポジトリでは実行しない。セレクタ等のE2E固有情報は後述の付帯表に分離し、未検証は `要実機確認` と明示する。本機能はDBへ保存せずファイル(`html/user_data/assets/css/customize.css`)とファイルストレージへ永続化するため、永続化の合否は「保存成功フラッシュ」と「保存後再表示時の送信値再表示」で間接観測する。
