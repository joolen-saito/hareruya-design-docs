元設計: `function_spec_html_preview/ec-cube-enterprise/m04-08_admin_stock_stock_move_transfer_search_list.html`（正本 `functions/ec-cube-enterprise/m04-08_admin_stock_stock_move_transfer_search_list.md`）。業務要件の上位オラクルは基本設計仕様書（0202_基本設計仕様書(在庫管理機能)）。

テスト観点: `integration_test/integration-test-viewpoints.md` ／ 既存IT: `integration_test/m04_08_admin_stock_stock_move_transfer_search_list_it_cases.md`（母集合 計90観点行）

期待結果は画面表示・遷移・件数見出し・ダウンロード発火・URL・ダイアログ文言などブラウザで観測できる結果で判定する。**期待結果は仕様（設計書・基本設計・観点表・messages.ja.yaml）由来**とし、実装/POM由来の表示文言・Form制約（required/min/max）をオラクル化しない。TSV は既存IT casesと同一の 10 列固定。E2E固有情報は TSV 後の付帯表に `テストID` で対応づける。Playwright は本リポジトリでは実行しない（構造参考のみ）。未検証セレクタは `要実機確認`。

本機能は新規実装（対応する現行pf-eccube3なし）。一覧・検索は**参照のみ**で業務データを更新しない。検索条件・ページ番号・表示件数はセッションに保持する。

## 関連ID対応概要

| 関連ID | 本機能でのE2E確認範囲 |
|--------|------------------------|
| IT-15 | 未認証ガード（未ログイン→管理ログイン誘導）。CSRF不正トークン時の拒否は手動/API寄りで観測（戻しリスト/移動指示作成POST）。ログ識別子は観測外 |
| IT-20 | ログ出力抑止・識別子＝ブラウザ観測外（対象外） |
| IT-25 | UI部品（見出し・検索フォーム・CSV登録カード/ボタン・詳細検索枠）・モーダル表示・各種出力操作・未選択ガードのダイアログ |
| IT-03 | 画面遷移（検索再描画・CSV出力ダウンロード・モーダル・別タブ詳細・表示件数URL遷移） |
| IT-13 | URL直接アクセス（未ログイン誘導） |
| IT-22 | 日付3ペアの相関バリデーション（開始>終了）・必須項目なしの確認。文字列長/数値/文字種は検索項目に制約なしで対象外 |
| IT-23 | 検索実行・0件メッセージ（自動化）。該当/非該当の件数照合はデータ依存で手動/間接 |
| IT-26 | 本機能はDB登録を行わない（CSV登録はM04-22へ委譲）。登録入口（モーダル表示）のみ自動化 |
