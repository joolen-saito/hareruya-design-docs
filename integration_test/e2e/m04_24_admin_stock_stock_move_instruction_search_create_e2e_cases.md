## 関連ID対応概要

| 関連ID | 本機能でのE2E確認範囲 |
|--------|------------------------|
| IT-15 | 未認証ガード（ログイン誘導・全エンドポイント）／状態変化（検索条件セッション・削除/登録の状態遷移）／CSRF（更新系POSTのトークン欠落は受理されない＝要直接POSTで観測可・手動/間接） |

| IT-25 | UI部品（検索フォーム・カード・ボタン）／確認ダイアログ（削除/登録/CSVモーダル・出力選択alert）／HTTPステータス（404）／URL遷移／送信可否制御 |

| IT-13 | URL直接アクセス（未ログイン誘導・存在しないID 404） |
