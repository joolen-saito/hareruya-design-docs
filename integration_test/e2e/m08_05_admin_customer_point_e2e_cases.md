期待結果は画面表示・遷移・URL・履歴一覧/残高での間接確認などブラウザで観測できる結果で判定する。**期待結果は仕様（設計書・観点表・基本設計）由来**とし、実装/POM由来の表示文言をオラクル化しない。本機能の設計書は現行 pf-eccube3（HareruyaEcプラグイン）のリバースであり、刷新先 ec-cube-enterprise の実装との乖離は **付帯表4（不具合候補）** に出し、テストは仕様どおりに書く。TSV は既存IT casesの10列に実施管理欄（実施者・実施日・結果・失敗理由）を加えた14列固定。E2E固有情報は TSV 後の付帯表に `テストID` で対応づける。Playwright は本リポジトリでは実行しない（構造参考のみ）。未検証セレクタは `要実機確認`。

刷新先画面は存在する（`CustomerPointController.php`：種別選択 `GET /customer/point/{id}/select`、履歴/付与 `GET|POST /customer/point/{id}/{type}` type∈`history|granted|purchase`）。セレクタは Twig＋Symfony Form の getBlockPrefix=`admin_customer_point`（`CustomerPointType.php:147-150`）由来の位置情報のみ。
