期待結果は画面表示・遷移・HTTP応答・ダウンロード発火・ファイル名などブラウザで観測できる結果で判定する。**期待結果は仕様（設計書・観点表・基本設計）由来**とし、実装/POM由来の表示文言をオラクル化しない。CSVの中身（列・値）は Playwright の `download.path()` で内容読取自体は可能だが、期待値が**設計書の出力列定義・集計仕様とシード値に依拠**するため、本バッチでは**手動**とし、シード整備後のヘッダ行（固定列順）照合の自動化を `要確認` とする（内容検査をブラウザ観測不能とは見なさない＝高(2)の是正）。TSV は既存IT casesの10列に実施管理欄（実施者・実施日・結果・失敗理由）を加えた14列固定。E2E固有情報は TSV 後の付帯表に `テストID` で対応づける。Playwright は本リポジトリでは実行しない（構造参考のみ）。未検証セレクタは `要実機確認`。

画面タイプは `csv_export`。観測対象は「ダウンロード発火・HTTP応答・ファイル名・導線UI部品・未選択時のクライアント制御」。**CSVの内容一致は `download.path()` で観測可能だが期待値が設計書の出力列・集計仕様とシード値に依拠するため手動（要確認）**、**ログ出力・DB副作用・畳み込みの内部挙動は観測不能のため手動/対象外**とする（理由は付帯表4・付帯表5）。
