期待結果は画面表示・取込結果メッセージ・バリデーションエラー・遷移・URL等ブラウザで観測できる結果で判定する。**期待結果は仕様（設計書・観点表・基本設計）由来**とし、実装/POM由来の表示文言・Form制約をオラクル化しない。TSV は既存IT casesと同一の 10 列固定。E2E固有情報は TSV 後の付帯表に `テストID` で対応づける。Playwright は本リポジトリでは実行しない（構造参考のみ）。未検証セレクタは `要実機確認`。

> **最重要・本機能の状態（screenExists=false）**: 本機能はカスタマイズ区分「新規実装」であり、基本設計仕様書（会員管理機能）に「会員顧客分析タグCSVはPh2で対応するため、Ph1では実装しない」と明記されている。刷新先 `ec-cube-enterprise` を実装確認した結果、**会員顧客分析タグのCSV登録（インポート）機能・画面・ルート・テンプレート・メッセージ定義はいずれも存在しない**（下記「実装確認」参照）。
> - 設計書が「実装確認値」として挙げる `CustomerCsvController` / `CustomerCsvUpdateAction`（`src/Eccube/Controller/Admin/Setting/Shop/CustomerCsvController.php` / `src/Eccube/Service/Admin/Setting/Shop/CustomerCsvUpdateAction.php`）は、**カスタムCSV出力設定（CSV出力列の拡張設定）画面の実装であり、顧客分析タグの取込とは無関係**である（route 名 `admin_setting_shop_csv_custom` / `...custom_update`、Form は `CustomCsvType`）。
> - 従って **E2Eで観測できる対象画面が存在せず、セレクタを根拠付きで導出できない**。本書では創作セレクタを置かず、各 E2Eケースの可否を `対象外（刷新先未実装）` または `要確認（実装後に再導出）` とし、理由を明記する。下記 TSV は「実装後に検証すべき仕様由来の意図シナリオ」を記録した骨子であり、現時点では自動化対象に算入しない。
> - 母集合90観点行はすべて `対象外` に分類する（自動化0／手動0／対象外90。付帯表2・2b で全量照合・未分類0）。
