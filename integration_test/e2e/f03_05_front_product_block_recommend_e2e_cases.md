# f03-05_front_product_block_recommend（商品 — 商品リコメンド（おすすめ商品ブロック）） E2Eテストケース

元設計: `function_spec_html_preview/pf-eccube3/f03-05_front_product_block_recommend.html`（正本 `functions/pf-eccube3/f03-05_front_product_block_recommend.md`）

テスト観点: `integration_test/integration-test-viewpoints.md` ／ 既存IT: `integration_test/f03_05_front_product_block_recommend_it_cases.md`（母集合 計89観点行）

期待結果は画面表示・遷移・URL・0件メッセージなどブラウザで観測できる結果で判定する。**期待結果は仕様（設計書・観点表・基本設計）由来**とし、実装/POM由来の表示文言をオラクル化しない。TSV は既存IT casesの10列に実施管理欄（実施者・実施日・結果・失敗理由）を加えた14列固定。E2E固有情報は TSV 後の付帯表に `テストID` で対応づける。Playwright は本リポジトリでは実行しない（未検証雛形）。本機能のカスタマイズ区分は現行踏襲であり、画面挙動の参照リポは pf-eccube3、DB は ec-cube-enterprise を正典とする。

本機能はフォーム入力を持たない参照系ブロック（非同期おすすめ表示）であり、**表示有無・非ログイン表示可・おすすめ0件メッセージ・商品リンク導線**をE2E観測対象とする。**具体的な推薦内容・件数・会員別/購買履歴別の出し分けは注文実績/在庫/公開状態のデータと会員ログインに依存する**ため要シード/要データ/要ログインとして `test.fixme` で保留し、全量はケース表で管理する。**空カート＝基準商品なし＝おすすめ0件**（設計書エッジケース）は非ログイン・非破壊で観測でき live 化する。
