期待結果は画面表示・遷移・URL・フラッシュ・一覧再表示（間接的なDB状態）など観測可能な結果で判定する。**期待結果は仕様(設計書/観点表/基本設計)由来**であり、実装の現挙動を写さない（オラクル独立性）。Playwright は本リポジトリでは実行しない。セレクタ・自動化区分・仕様根拠・不具合候補は後述の付帯表に分離し、未検証は `要実機確認` と明示する。

刷新先（ec-cube-enterprise）の入口は GET `admin_deck_list`（/%admin%/deck）＝一覧兼検索結果、POST `admin_deck_bulk_delete`（/%admin%/deck/bulk_delete）＝一括削除。設計(pf-eccube3)のルート名 `m15-03_admin_deck_deck_bulk_delete`・パス `/{admin_route}/deck/delete` とは名称/パスが異なる（付帯表4 #5）。
