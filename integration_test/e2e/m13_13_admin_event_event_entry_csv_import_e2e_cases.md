## 付帯表1：E2E自動化区分・セレクタ・仕様根拠・元ITケースID（TSV外）

DOM id は Symfony Form getBlockPrefix=`admin_csv_import`（`CsvImportType.php:80-83`）から導出（`import_file`→`#admin_csv_import_import_file`、`_token`→`#admin_csv_import__token`）。ルート・要素は `EventEntryBulkCsvController.php` と `Event/Entry/event_bulk_csv_import.twig` 由来（行番号は ec-cube-enterprise 現行ソース）。

取込到達系（021 データ無し／023 行検証エラー）の入力CSVヘッダは**雛形DL（`bulk_csv_template`）から動的取得**する。設計書「ヘッダ行は雛形の見出し名と一致が必要・不一致はフォーマットエラー」（取込フォーマット節）に従い、実装の列名をテストへハードコードせず（オラクル独立性）、フォーマットエラー（020）でなく目的の分岐へ確実に到達させるため。020は意図的に不一致（空）ヘッダでフォーマットエラーを踏む。022（行数上限）は実装上 importer 前の行数判定（Controller.php:84）で先に弾かれるためヘッダ整合不要。
