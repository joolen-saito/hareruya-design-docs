# M06-11（戻しリストPDF出力） E2Eテストケース

元設計: `function_spec_html_preview/ec-cube-enterprise/m06-11_admin_store_purchase_purchase_store_return_list_pdf_export.html`（正本 `functions/ec-cube-enterprise/m06-11_admin_store_purchase_purchase_store_return_list_pdf_export.md`）

期待結果は画面表示・別ウィンドウ(印刷ポップアップ)・HTTP/JSON応答・一覧フラッシュ・URL等のブラウザで観測できる結果で判定する。**期待結果は仕様（設計書・観点表・基本設計＝Excel原典）由来**とし、実装/POM/JS由来の文言をオラクル化しない。TSV は既存IT casesと同一の 10 列固定。E2E固有情報は TSV 後の付帯表に `テストID` で対応づける。Playwright は本リポジトリでは実行しない（構造参考のみ）。未検証セレクタは `要実機確認`。

刷新先 `ec-cube-enterprise` に当該機能は **存在する**（screenExists=true）。起点は店頭買取管理「買取一覧」（route `admin_otcbuyorder` = `/<route>/otcbuyorder`、`OtcBuyOrderController.php:90-104`）の「CSVダウンロード」メニュー内「戻しリストPDF」ボタン（`index.twig:187`）。押下で選択した買取を POST `/<route>/otcbuyorder/restock-list/pdf`（`admin_otcbuyorder_restock_list_pdf`、`OtcBuyOrderController.php:625-666`）へ ajax 送信し、JSON で受けた印刷用HTML（`@admin/Purchase/restock_list.twig`）を別ウィンドウへ書き込みPC印刷ダイアログで印刷する（print/pdf_export 型）。
