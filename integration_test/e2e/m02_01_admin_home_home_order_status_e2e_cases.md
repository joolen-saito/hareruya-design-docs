期待結果は画面表示・遷移・URL・カード内要素の有無などブラウザで観測できる結果で判定する。**期待結果は仕様（設計書・観点表・基本設計）由来**とし、実装/POM由来の表示文言をオラクル化しない。TSV は既存IT casesの10列に実施管理欄（実施者・実施日・結果・失敗理由）を加えた14列固定。E2E固有情報（セレクタ・自動化区分・仕様根拠・シード・不具合候補）は TSV 後の付帯表に `テストID` で対応づける。Playwright は本リポジトリでは実行しない（構造参考のみ）。未検証セレクタは `要実機確認`。

本機能は管理ホーム上の参照専用ブロック（画面タイプ summary/status）であり、フォーム・入力・登録/更新・専用Ajaxを持たない。観測できるのは「カード表示」「除外ルール反映」「受注一覧への遷移とステータス識別子の受け渡し」「未認証ガード」である。件数の実数・並び順の厳密一致はマスタ/台帳のシードに依存するため、要シードのものは fixme（自動化予定）とする。
