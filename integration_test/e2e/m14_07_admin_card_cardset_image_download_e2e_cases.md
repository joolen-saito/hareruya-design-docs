元設計: `function_spec_html_preview/pf-eccube3/m14-07_admin_card_cardset_image_download.html`（正本 `functions/pf-eccube3/m14-07_admin_card_cardset_image_download.md`）

期待結果は画面表示・確認ダイアログ・ダウンロード発火・ファイル名・フラッシュ表示・遷移先URLなどブラウザで観測できる結果で判定する。**期待結果は仕様（設計書・観点表・基本設計）由来**とし、実装/POM由来の表示文言（刷新先の個別メッセージキー文言等）をオラクル化しない。TSV は既存IT casesの10列に実施管理欄（実施者・実施日・結果・失敗理由）を加えた14列固定。E2E固有情報は TSV 後の付帯表に `テストID` で対応づける。Playwright は本リポジトリでは実行しない（構造参考のみ）。未検証セレクタは `要実機確認`。

注（設計源と刷新先の関係）: 本機能の設計書は旧システム pf-eccube3（HareruyaEc プラグイン）のリバースである。刷新先 ec-cube-enterprise には対応画面（カードセット一覧 `@admin/Cardset/index.twig` ＋ ダウンロード2ルート）が存在するが、ルート名・エラーメッセージキー・リダイレクト先・CSRF有無などで乖離がある（付帯表4）。**E2Eは仕様（観点表＝挙動レベル：エラー表示・処理未完了・ダウンロード発火・確認ダイアログ）どおりに書き、刷新先の個別文言は期待値に流用しない**。乖離は不具合候補として別表に出す。
