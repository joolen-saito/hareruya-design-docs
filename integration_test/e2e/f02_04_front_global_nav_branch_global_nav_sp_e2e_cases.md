# f02-04_front_global_nav_branch_global_nav_sp（支店スマホ版ナビゲーション） E2Eテストケース

元設計: `function_spec_html_preview/pf-eccube3/f02-04_front_global_nav_branch_global_nav_sp.html`（正本 `functions/pf-eccube3/f02-04_front_global_nav_branch_global_nav_sp.md`）

期待結果は画面表示・遷移・URL・HTTP404・SP幅レイアウトなどブラウザで観測できる結果で判定する。**期待結果は仕様（設計書・観点表）由来**とし、実装/POM由来の表示文言をオラクル化しない。支店スマホ版ナビは店舗紹介ページ（`/{_locale}/shoppage/{name}`）とイベント店舗文脈の一部として画面幅で出し分けて描画され、実在の店舗はシード依存のため、**非破壊に走るのは店舗/店舗IDが該当なしの404系**であり、タブレット用店舗一覧・右カラムナビ・店舗切替セレクトは要シードとして `test.fixme` で保留する。TSV は既存IT casesの10列に実施管理欄（実施者・実施日・結果・失敗理由）を加えた14列固定。Playwright は本リポジトリでは実行しない（未検証雛形）。DB は ec-cube-enterprise（`dtb_base_info`/`dtb_shop_page_element`）を正典とする。セレクタは Twig 未取込のため URL・表示要素の意味で寄せ、file:line 根拠が取れない箇所は `要実機確認` とする。
