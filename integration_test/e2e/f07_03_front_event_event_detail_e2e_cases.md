# F07-03（イベント詳細） E2Eテストケース

元設計: `functions/pf-eccube3/f07-03_front_event_event_detail.md`（機能詳細HTML `function_spec_html_preview/pf-eccube3/f07-03_front_event_event_detail.html`）

テスト観点: `integration_test/integration-test-viewpoints.md` ／ 既存IT: `integration_test/f07_03_front_event_event_detail_it_cases.md`（母集合 計90観点行 `IT-F07-03-FRONT-EVENT-EVENT-DETAIL-001..090`）

期待結果は画面表示・遷移・HTTPステータス・URL などブラウザで観測できる結果で判定する。**期待結果は仕様（設計書・観点表・基本設計）由来**とし、実装/POM由来の表示文言をオラクル化しない。TSV は既存IT casesの10列に実施管理欄（実施者・実施日・結果・失敗理由）を加えた14列固定。E2E固有情報は TSV 後の付帯表に `テストID` で対応づける。Playwright は本リポジトリでは実行しない（未検証雛形。ec-cube-enterprise/pf-eccube3 の実画面は実行不可で構造参考のみ）。本機能のカスタマイズ区分はカスタマイズであり、画面・処理フロー・表示メッセージは pf-eccube3（`Event/show.twig`）を参照リポ、DB は ec-cube-enterprise を正典とする。Twig は本リポジトリ未取込のためセレクタは `要実機確認`。

本機能はログイン不要の公開参照画面（イベント詳細1件の表示）で、入力フォームを持たない（ボタン押下による遷移のみを受け付ける）。詳細の表示内容・状態別ボタン・条件付き表示・遷移導線は、いずれも「実在するイベント詳細1件」を必要とするため `E2E自動化(UI)（要シード）` とし spec では `test.fixme`（理由付き）で保留する。URL スキーム（`GET /{_locale}/events/{eventDetailId}/detail`、詳細IDは数値のみ）が設計書で確定しているため、存在しないID／数値以外の不正IDに対する「ページが見つからない（HTTP404）」だけはシード不要で live 実行する。
