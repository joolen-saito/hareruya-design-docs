> E2Eは観測可能な結果（編集画面のボタン表示・POST submitでのdownload発火・添付/.csv・ファイル名 `order_<YmdHis>.csv`・選択欠損時のフラッシュ「選択してください」＋リダイレクト・未認証ガード）で判定する。**CSV本文（固定日本語ヘッダ・列順・日時書式 `Y/m/d H:i:s`・郵便番号3桁/4桁分割・配送先FAX空文字3列・文字コード/BOM・区切り・囲み・対象IDのみ抽出・dtb_shipping INNER JOINで配送無し注文の脱落・同一受注複数配送の行重複）は手動/間接**、**`exportCsv` 論理偽時の `RuntimeException` フラッシュは要DB状態（配送無し/会員未紐付け受注のみ選択）のため要実機(fixme)**。実装由来の Content-Type/Disposition 値・イベント識別子・ログ出力はオラクルに固定しない。
