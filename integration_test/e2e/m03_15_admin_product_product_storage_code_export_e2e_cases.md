# m03-15_admin_product_product_storage_code_export（商品管理 — 略称タグCSV出力） E2Eテストケース

元設計: `function_spec_html_preview/pf-eccube3/m03-15_admin_product_product_storage_code_export.html`（正本 `functions/pf-eccube3/m03-15_admin_product_product_storage_code_export.md`）

テスト観点: `integration_test/integration-test-viewpoints.md` ／ 既存IT: `integration_test/m03_15_admin_product_product_storage_code_export_it_cases.md`（母集合 計90観点行）

期待結果は画面表示・ダウンロード発火・ファイル名・URL誘導などブラウザで観測できる結果で判定する。**期待結果は仕様（設計書・観点表・基本設計）由来**とし、実装/POM由来の表示文言・ファイル名接頭辞・Content-Type をオラクル化しない。TSV は既存IT casesと同一の 10 列固定。E2E固有情報は TSV 後の付帯表に `テストID` で対応づける。Playwright は本リポジトリでは実行しない（構造参考のみ）。未検証セレクタは `要実機確認`。

本機能は画面タイプ `csv_export`。設計書「入力: なし（一覧をそのまま出力）」のため入力フォーム・バリデーションは存在せず、自動化はダウンロード発火・ファイル名（日時を含む.csv）・UI部品・未認証ガード・直接GET発火に限る。CSV内容（列 ID・名称・並び順／rank 昇順／登録済み全件／0件境界／エンコード・区切り・改行・空値表現）および副作用なし（DB前後不変）・参照時点整合は**手動確認**とする。**手動とする理由はブラウザ観測不能ではなく**（Playwright の `Download` から保存ファイルを読み取れば原理上は自動照合可能）、内容照合がシード値・rank 並び・件数・文字コード等の環境/シードデータ整備に依存し本納品時点で安定供給できないためである（`要確認(シード整備)`）。
