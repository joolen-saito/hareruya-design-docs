期待結果は画面表示・遷移・URL・成功フラッシュ・フィールドエラー・再表示値などブラウザで観測できる結果で判定する。**期待結果は仕様（設計書・観点表・基本設計）由来**とし、実装/POM由来の表示文言（実装上のラベル改称・並び順など）をオラクル化しない。TSV は既存IT casesと同一の 10 列固定。E2E固有情報は TSV 後の付帯表に `テストID` で対応づける。Playwright は本リポジトリでは実行しない（構造参考のみ）。未検証セレクタは `要実機確認`。

注: 本機能はpf-eccube3のリバース設計を一次オラクルとし、刷新先 ec-cube-enterprise（店舗基本設定フォーム `ShopMasterType` / 画面 `/{admin_route}/setting/shop`）にメール4項目が存在することを確認した。設計書と実装で**メール欄の並び順・ラベル文言に乖離**があり、付帯表4（不具合候補）に出力し、テストは仕様どおりに書いて検出させる。
