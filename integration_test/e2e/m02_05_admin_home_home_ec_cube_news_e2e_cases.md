期待結果は画面表示・DOM要素・URL・iframe属性・遷移などブラウザで観測できる結果で判定する。**期待結果は仕様（設計書・観点表・基本設計）由来**とし、実装/POM由来の表示文言・CSSクラスをオラクル化しない（セレクタは位置情報としてのみ実装から取得）。TSV は既存IT casesの10列に実施管理欄（実施者・実施日・結果・失敗理由）を加えた14列固定。E2E固有情報は TSV 後の付帯表に `テストID` で対応づける。Playwright は本リポジトリでは実行しない（構造参考のみ）。未検証セレクタは `要実機確認`。

本機能は「管理画面ホームに配置される、外部URL（`eccube_info_url`）を `src` に出力する read-only な iframe カード（`#ec-cube-news`）」であり、フォーム・POST・DB読み書き・専用API・バッチ・検索・集計・試行制限・固有Cookie/セッションを一切持たない。したがって観点表の大半（バリデーション・DB相関・ログ出力・集計・確認ダイアログ等）は本機能では非該当（観測対象が存在しない）となり、E2E化できるのは「ホーム表示時のカード・見出し・情報iframe の表示」「設定値の `src` への出力」「未認証ガード」に限られる。
