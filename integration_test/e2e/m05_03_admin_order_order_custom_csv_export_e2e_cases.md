期待結果は画面表示・遷移・URL・ダウンロード発火・HTTP応答・ファイル名などブラウザで観測できる結果で判定する。**期待結果は仕様（設計書・観点表・基本設計）由来**とし、実装/POM由来の表示文言をオラクル化しない。本機能は CSV ダウンロード（GET リンク）であり、**CSVの中身（列・データ行・列順 rank・検索条件一致・明細単位の行数・BOM/エンコード/日時書式）は手動確認**とする。自動化はダウンロード発火・ファイル名・HTTP応答・404・遷移・UI部品の表示に限る。手動確認分も宣言で済ませず、TSV に実行可能な手動ケース（E2E-M05-03-070〜086・041・022・052）として手順・入力・期待値を落とす。TSV は既存IT casesの10列に実施管理欄（実施者・実施日・結果・失敗理由）を加えた14列固定。E2E固有情報は TSV 後の付帯表に `テストID` で対応づける。Playwright は本リポジトリでは実行しない（構造参考のみ）。未検証セレクタは `要実機確認`。

本機能は pf-eccube3（HareruyaEcプラグイン）リバース設計のため、**基本設計・観点表を上位オラクル**とし、刷新先 ec-cube-enterprise（コア機能 `CustomExportCsvController`）との乖離は付帯表4（不具合候補）に出す。出力項目設定画面（拡張名保存・列編集・削除・バリデーション）は別機能 `m10-13`（カスタムCSV出力項目設定）へ委譲し、本機能では「一覧ドロップダウンから設定画面へ遷移できること」までを範囲とする。
