# A02-05（更新商品規格の取得） E2Eテストケース

元設計md（正本一次）: `functions/pf-api/a02-05_api_product_updated_product_class.md`

本機能は画面を伴わないJSON機能仕様（`GET /updateProducts/{strFromDate}/{strToDate}` で指定期間内に更新された商品規格を件数とともに取得する参照系API）であり、**API/統合レイヤ**を主レイヤとして網羅する。Playwright `request`（APIRequestContext）で当該エンドポイントへ送信し、**HTTPステータス・レスポンス本文（count/result の有無・構造）・期間絞り込み結果（差分条件）**で判定する。本APIの出力はSEO・広告等の外部用途向けJSONであり、その結果が反映される専用の管理画面を持たないため**UIレイヤは該当なし（0件）**である（商品規格データ自体は別機能 m03-08 商品規格一覧で閲覧できるが、本APIの出力観測点ではない）。

**期待結果は仕様（設計書・観点表・基本設計）由来**とし、実装のレスポンス形・HTTPライブラリ既定値・Form制約を期待値に流用しない（オラクル独立性）。実装からは位置情報（APIパス・メソッド・認可境界・絞り込み条件の根拠）のみを `file:line` 根拠で取得し、取れないものは `要実機確認`。設計書と実装の食い違い（不正日付時の応答・認可方式・設計書内の参照系/更新系の記述矛盾）は付帯表4に出す。TSV は既存IT casesの10列に実施管理欄（実施者・実施日・結果・失敗理由）を加えた14列固定。Playwright は本リポジトリでは実行しない（構造参考のみ）。
