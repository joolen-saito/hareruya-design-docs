# F03-01（商品一覧） E2Eテストケース

元設計: `function_spec_html_preview/pf-eccube3/f03-01_front_product_product_search_list.html`（正本 `functions/pf-eccube3/f03-01_front_product_product_search_list.md`）

テスト観点: `integration_test/integration-test-viewpoints.md` ／ 既存IT: `integration_test/f03_01_front_product_product_search_list_it_cases.md`（母集合 計90観点行）

期待結果は画面表示・遷移・URL・応答ステータスなどブラウザで観測できる結果で判定する。**期待結果は仕様（設計書・観点表・基本設計）由来**とし、実装/POM由来の表示文言をオラクル化しない。表示文言は設計md「表示メッセージ」節の文言をそのまま使う。TSV は既存IT casesの10列に実施管理欄（実施者・実施日・結果・失敗理由）を加えた14列固定。E2E固有情報は TSV 後の付帯表に `テストID` で対応づける。Playwright は本リポジトリでは実行しない（未検証雛形）。本機能のカスタマイズ区分はカスタマイズであり、画面・処理フロー・表示メッセージは pf-eccube3 を参照リポ、DB は ec-cube-enterprise を正典とする。

本機能は参照系（検索）であり、非ログインで表示・検索・遷移が観測できる。DBへの登録・更新・削除は行わない。ec-cube-enterprise/pf-eccube3 の Twig（`Product/product_list_unisearch.twig`・`Product/product_list.twig`）は本リポジトリに未取込のため、セレクタは URL・表示文言・要素の意味で寄せ、file:line 根拠が取れない箇所は `要実機確認` と明記する。
