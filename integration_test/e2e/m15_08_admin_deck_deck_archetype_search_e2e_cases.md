本機能は設計源が pf-eccube3（HareruyaEc プラグイン）のリバース。刷新先 ec-cube-enterprise ではデッキ管理が**コア標準機能**として取り込まれている（`src/Eccube/Controller/Admin/Deck/DeckController.php` / `src/Eccube/Resource/template/admin/Deck/index.twig` / `src/Eccube/Form/Type/Admin/SearchDeckType.php`）。pf-eccube3 設計と刷新先実装の乖離は **付帯表4（不具合候補）** に出し、テストは仕様どおりに書く（実装が違えば落ちて検出する）。

期待結果は画面表示・遷移・URL・結果一覧/結果なし表示・別画面での間接確認などブラウザで観測できる結果で判定する。**期待結果は仕様（設計書・観点表・基本設計）由来**とし、実装/POM由来の表示文言・Form制約をオラクル化しない。TSV は既存IT casesの10列に実施管理欄（実施者・実施日・結果・失敗理由）を加えた14列固定。E2E固有情報は TSV 後の付帯表に `テストID` で対応づける。Playwright は本リポジトリでは実行しない（構造参考のみ）。未検証セレクタは `要実機確認`。
