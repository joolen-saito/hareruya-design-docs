# F04-03（注文時の配送先登録・変更） E2Eテストケース

元設計: `function_spec_html_preview/pf-eccube3/f04-03_front_cart_shopping_delivery_edit.html`（正本 `functions/pf-eccube3/f04-03_front_cart_shopping_delivery_edit.md`）

テスト観点: `integration_test/integration-test-viewpoints.md` ／ 既存IT: `integration_test/f04_03_front_cart_shopping_delivery_edit_it_cases.md`（母集合 計90観点行）

期待結果は画面表示・遷移・URL・別画面での間接確認などブラウザで観測できる結果で判定する。**期待結果は仕様（設計書・観点表・基本設計）由来**とし、実装/POM由来の表示文言をオラクル化しない。TSV は既存IT casesの10列に実施管理欄（実施者・実施日・結果・失敗理由）を加えた14列固定。E2E固有情報は TSV 後の付帯表に `テストID` で対応づける。Playwright は本リポジトリでは実行しない（未検証雛形）。カスタマイズ区分はカスタマイズであり、画面・処理フロー・表示メッセージは pf-eccube3 を参照リポ、DB は ec-cube-enterprise を正典とする。

本機能は**会員ログイン＋カート投入（受注セッション確立）が前提の破壊的フロー**（お届け先の入力→確認→登録→配送先反映）が中心である。シード・資格情報なしで非破壊に観測できるのは、未ログイン/カート未投入で該当URLへ直接アクセスした際の**誘導ガード**に限られ、その他は要ログイン/要カート/要シードとして保留する。
