期待結果は画面表示・遷移・URL・HTTP応答等の観測可能な結果で判定する。**期待結果は仕様（設計書/観点表/基本設計）由来**であり、実装（ec-cube-enterprise）の現挙動を写さない（オラクル独立性）。実装から取るのはセレクタ（位置情報）のみ。仕様と実装の食い違いは「付帯表4 不具合候補」に出し、テストは仕様どおりに書く（実装が違えば落ちて検出する）。

Playwright は本リポジトリでは実行しない（未実行雛形）。セレクタ等は後述の付帯表に分離し、未検証は `要実機確認`。

本機能は **閲覧専用の一覧（list）画面**である。買取減額率マスタ（行）×カード状態マスタの code（列）の矩形マトリクスを `findAll()` で全件表示するのみで、検索フォーム・入力項目・操作ボタン・送信・CSV・メールを持たない。したがって観測可能な自動化対象は「到達・表示・遷移・要素存在」に限られる。
