期待結果は画面表示・遷移・URL・フラッシュメッセージなどブラウザで観測できる結果で判定する。**期待結果は仕様（設計書・観点表・基本設計）由来**とし、実装/POM由来の表示文言・Form制約（NotBlank/File maxSize 等）をオラクル化しない。TSV は既存IT casesと同一の 10 列固定。E2E固有情報（セレクタ・自動化区分・仕様根拠・シード・不具合候補）は TSV 後の付帯表に `テストID` で対応づける。Playwright は本リポジトリでは実行しない（構造参考のみ）。未検証セレクタは `要実機確認`。

本機能は m03-16（略称タグCSV入力）と同一の取込画面・同一ルート（`admin_product_storage_code_csv` 表示 GET ／ `admin_product_storage_code_import` POST）を扱う「更新CSV登録」視点である。取込基盤は `mtb_storage_code` を ID/名称/並び順 で登録・更新する。
