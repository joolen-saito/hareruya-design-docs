元設計: `function_spec_html_preview/pf-eccube3/f07-01_front_event_event_top.html`（正本 `functions/pf-eccube3/f07-01_front_event_event_top.md`）

テスト観点: `integration_test/integration-test-viewpoints.md` ／ 既存IT: `integration_test/f07_01_front_event_event_top_it_cases.md`（母集合 計90観点行 `IT-F07-01-FRONT-EVENT-EVENT-TOP-001..090`）

期待結果は画面表示・遷移・URL・HTTPステータス（404）・クッキー等ブラウザで観測できる結果で判定する。**期待結果は仕様（設計書・観点表・基本設計）由来**とし、実装/POM由来の表示文言・挙動をオラクル化しない。TSV は既存IT casesと同一の 10 列固定。E2E固有情報（セレクタ・自動化区分・仕様根拠・シード・不具合候補）は TSV 後の付帯表に `テストID` で対応づける。Playwright は本リポジトリでは実行しない（未検証雛形）。ec-cube-enterprise/pf-eccube3 の Twig は本リポに未取込のため、セレクタは file:line 根拠が取れず `要実機確認`（Page Object は URL・可視テキスト・要素の意味で寄せる）。本機能のカスタマイズ区分はカスタマイズであり、画面・処理フロー・表示メッセージは pf-eccube3 を参照リポ、DB は ec-cube-enterprise を正典とする。

本画面はログイン不要の公開閲覧画面（`GET /{_locale}/events`）であり、**入力フォームを持たない**。操作は店舗切替セレクトと、月・日付・イベントへのリンク押下のみ。したがって単項目・数値・文字種・相関などの入力バリデーション観点（IT-22 多数）は非該当であり、観測可能な検証はパスパラメータ検証（店舗ID不存在→404、`eventId`数値・`eventDate`＝`Ymd`/`all`以外→404）に限られる。DB登録/更新内容（IT-26/IT-23 の多く）は参照専用画面のため副作用が無く、内部値もブラウザ観測不能で対象外とする。
