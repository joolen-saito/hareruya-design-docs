# f06-17_front_member_mypage_event_deck_complete（フロント_会員_マイページ_大会に登録するデッキの確認・登録） E2Eテストケース

元設計: `function_spec_html_preview/pf-eccube3/f06-17_front_member_mypage_event_deck_complete.html`（正本 `functions/pf-eccube3/f06-17_front_member_mypage_event_deck_complete.md`）

テスト観点: `integration_test/integration-test-viewpoints.md` ／ 既存IT: `integration_test/f06_17_front_member_mypage_event_deck_complete_it_cases.md`（母集合 計90観点行）

本機能はデッキ登録の確定（更新）から**デッキ登録完了画面**（確認）までを対象とする表示中心の機能である。完了画面到達には会員ログインと編集完了フロー（有効な選手情報・登録可能イベント・保存済みデッキ）を要する。期待結果は画面表示・遷移・URL・HTTPステータス（404）などブラウザで観測できる結果で判定する。**期待結果は仕様（設計書・観点表）由来**とし、実装/POM由来の表示文言をオラクル化しない。TSV は既存IT casesと同一の 10 列固定。E2E固有情報は TSV 後の付帯表に `テストID` で対応づける。Playwright は本リポジトリでは実行しない（未検証雛形）。カスタマイズ区分はカスタマイズであり、画面・処理フロー・表示メッセージは pf-eccube3 を参照リポ、DB は ec-cube-enterprise を正典とする。
