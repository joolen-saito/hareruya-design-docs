# f01-02_front_top_home_branch（支店トップページ表示） E2Eテストケース

元設計: `function_spec_html_preview/pf-eccube3/f01-02_front_top_home_branch.html`（正本 `functions/pf-eccube3/f01-02_front_top_home_branch.md`）

テスト観点: `integration_test/integration-test-viewpoints.md` ／ 既存IT: `integration_test/f01_02_front_top_home_branch_it_cases.md`（母集合 計90観点行）

期待結果は画面表示・遷移・URL・HTTP404などブラウザで観測できる結果で判定する。**期待結果は仕様（設計書・観点表）由来**とし、実装/POM由来の表示文言をオラクル化しない。支店TOP（店舗紹介ページ）は表示中心（参照系・入力フォームなし）で、実在の店舗識別名はシード依存のため、**非破壊に走るのは店舗未存在の404系**であり、店舗表示・右カラム・店舗一覧・言語出し分けは要シードとして `test.fixme` で保留する。TSV は既存IT casesの10列に実施管理欄（実施者・実施日・結果・失敗理由）を加えた14列固定。Playwright は本リポジトリでは実行しない（未検証雛形）。DB は ec-cube-enterprise（`dtb_base_info`/`dtb_shop_page_element`）を正典とする。セレクタは Twig 未取込のため URL・表示要素の意味で寄せ、file:line 根拠が取れない箇所は `要実機確認` とする。
