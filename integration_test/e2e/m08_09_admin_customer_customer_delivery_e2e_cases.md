# m08-09_admin_customer_customer_delivery（会員管理 — 配送先一覧表示/編集） E2Eテストケース

元設計（HTML）: `function_spec_html_preview/pf-eccube3/m08-09_admin_customer_customer_delivery.html`（正本md `functions/pf-eccube3/m08-09_admin_customer_customer_delivery.md`）

テスト観点: `integration_test/integration-test-viewpoints.md` ／ 既存IT: `integration_test/m08_09_admin_customer_customer_delivery_it_cases.md`（母集合 計90観点行）

期待結果は画面表示・遷移・URL・フラッシュメッセージ・別画面での間接確認などブラウザで観測できる結果で判定する。**期待結果は仕様（設計書・観点表・基本設計）由来**とし、実装/POM由来の表示文言・Form制約（NotBlank/Length）をオラクル化しない。TSV は既存IT casesと同一の 10 列固定。E2E固有情報は TSV 後の付帯表に `テストID` で対応づける。Playwright は本リポジトリでは実行しない（構造参考のみ）。未検証セレクタは `要実機確認`。

> 重要（設計と刷新先実装の乖離）: 設計（pf-eccube3）は「配送先一覧」を独立画面（`GET /{admin_route}/customer/{id}/delivery`）として記述するが、刷新先 ec-cube-enterprise には独立した配送先一覧ルートが存在せず、**会員編集画面（`/{admin_route}/customer/{id}/edit`）内の折りたたみセクション `#delivery`** に一覧が描画される。編集・削除のURLも設計（`/customer/delivery/{id}/update`・`/customer/delivery/{id}/delete`）と異なり、実装は `/customer/{id}/delivery/{did}/edit`・`/customer/{id}/delivery/{did}/delete`・`/customer/{id}/delivery/new`。本書のE2Eは**設計（上位オラクル）どおりの観測（一覧表示・編集保存・削除）**を期待値とし、観測場所のセレクタのみ刷新先実装から根拠付きで導出する。URL/画面構成の差は付帯表4（不具合候補）に明示する。
