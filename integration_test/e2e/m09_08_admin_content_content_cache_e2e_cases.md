母集合の定義: 本E2Eの分類母集合は、観点表 `integration-test-viewpoints.md` の汎用観点群を本機能向けに射影（projection）した結果である既存IT `m09_08_admin_content_content_cache_it_cases.md` の全90行とする。観点表は全機能共通の母観点カタログであり、機能単位の監査対象は当該機能のIT行へ既に絞り込まれているため、本E2Eはこの90行を全数分類（未分類0）して監査可能性を担保する。観点表の各観点ID（IT-03/05/13/15/20/22/23/25/26）は90行内に出現しており、観点表側に本機能未射影の観点は無い（付帯表2のIT-ID別件数=90が観点表射影の網羅を示す）。

期待結果は画面表示・遷移・URL・フラッシュメッセージなどブラウザで観測できる結果で判定する。**期待結果は仕様（設計書・観点表・基本設計）由来**とし、実装/POM由来の表示文言をオラクル化しない（説明文・ボタン・成功文言は設計書「フロント挙動／表示メッセージ」節が明記する語を仕様正典として用いる）。TSV は既存IT casesの10列に実施管理欄（実施者・実施日・結果・失敗理由）を加えた14列固定。E2E固有情報は TSV 後の付帯表に `テストID` で対応づける。Playwright は本リポジトリでは実行しない（構造参考のみ）。未検証セレクタは `要実機確認`。

本機能はアプリケーションキャッシュを削除するボタン操作中心の画面で、利用者が値を入力するフォーム項目を持たず、DBへ業務レコードを保存しない。したがって入力バリデーション・DB登録/検索・ログ出力抑止の観点は本画面ではブラウザ観測対象にならず、対象外（理由付き）へ分類する。観測可能なのは「画面表示」「削除ボタン押下→同一画面再表示＋削除完了フラッシュ」「なりすまし対策トークン不正時に削除完了フラッシュを出さないこと」「未認証時のログイン誘導」である。
