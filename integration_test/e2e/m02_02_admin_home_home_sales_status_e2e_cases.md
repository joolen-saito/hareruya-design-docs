期待結果は画面表示・タブ表示切替・XHRのHTTP応答・URL誘導などブラウザで観測できる結果で判定する。**期待結果は仕様（設計書・観点表・基本設計）由来**とし、実装/POM由来の表示文言・Form制約をオラクル化しない。本機能は画面タイプ `summary/status`（ダッシュボードの売上状況ブロック）であり、**集計数値（金額・件数・除外ステータス反映）の厳密一致はDB依存のため手動**、ウィジェット表示・タブ切替・グラフ用データの非同期取得可否（XHR＋CSRF）をE2E自動化対象とする。TSV は既存IT casesの10列に実施管理欄（実施者・実施日・結果・失敗理由）を加えた14列固定。E2E固有情報は TSV 後の付帯表に `テストID` で対応づける。Playwright は本リポジトリでは実行しない（構造参考のみ）。未検証セレクタは `要実機確認`。

| IT-15 | 売上状況カード表示・未認証ガード・非XHR/不正CSRF時のグラフ用データ非取得 |
| IT-20 | ログ出力抑止（CSRFトークン/Cookie原値/セッションID）＝ブラウザ観測外 |
| IT-25 | UI部品（カード見出し・今月/今日/昨日サマリ・週間/月間/年間タブ・canvas・読み込み中表示）・操作起点（非同期取得）・HTTPステータス・URL |

| IT-22 | 本機能はフォーム入力を持たない。例外はグラフ用Ajaxの妥当性（XHR＋CSRF）のみ |
| IT-26 | 本機能はDB登録・更新を行わない（参照のみ）＝該当なし（対象外） |
| IT-23 | 本機能は `dtb_order`（order_date/payment_total/order_status_id）を参照（検索・集計）する read-only 機能。検索結果はサマリ・グラフ表示に反映されDB依存のため手動確認（040/041）。既存IT cases の IT-23 行は「登録/更新/実行結果」のDB書込文脈であり本機能では書込が発生しない＝書込観点としては対象外 |

### M02-02 売上集計シード適用・再利用手順

売上集計用のシード実体は `e2e/seed/sets/m02/SEED-M02-SALES-DASHBOARD.sql`。`SEED-M02-SALES-INCLUDE` / `EXCLUDE` / `EMPTY` / `ZERO` / `MULTILINE` / `BOUNDARY` は同じ実体を参照し、対象・除外・0円・複数配送/複数明細・期間境界の受注群をまとめて投入する。

```bash
e2e/seed/lib/apply.sh SEED-M02-SALES-INCLUDE
```

撤去:

```bash
e2e/seed/lib/teardown.sh SEED-M02-SALES-INCLUDE
```

注: `SEED-M02-SALES-EMPTY` は共有DB上で「当日/昨日/今月に対象受注が0件」を単独保証するものではなく、隔離DBまたは期間窓を固定した手動確認用の補助データとして扱う。
