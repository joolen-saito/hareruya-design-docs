# m09-02_admin_content_content_file（管理画面_コンテンツ管理_ファイル管理） E2Eテストケース

元設計: `function_spec_html_preview/ec-cube-enterprise/m09-02_admin_content_content_file.html`（正本 `functions/ec-cube-enterprise/m09-02_admin_content_content_file.md`）

テスト観点: `integration_test/integration-test-viewpoints.md` ／ 既存IT: `integration_test/m09_02_admin_content_content_file_it_cases.md`（母集合 計90観点行）

期待結果は画面表示・遷移・URL・HTTPステータス・ダウンロード発火など、ブラウザで観測できる結果で判定する。**期待結果は仕様（設計書・観点表・基本設計）由来**とし、実装/POM由来の表示文言・Form制約（NotBlank/Regex 等）をオラクル化しない。TSV は既存IT casesの10列に実施管理欄（実施者・実施日・結果・失敗理由）を加えた14列固定。E2E固有情報（セレクタ・自動化区分・仕様根拠・シード・不具合候補）は TSV 後の付帯表に `テストID` で対応づける。Playwright は本リポジトリでは実行しない（構造参考のみ）。未検証セレクタは `要実機確認`。

本機能はファイル・フォルダをデータベースへ保存せず、操作対象はファイルシステム（`html/user_data` 配下）である。アップロード制限の環境変数 `ECCUBE_RESTRICT_FILE_UPLOAD` 切替・S3アダプタ連携・ログ出力抑止は環境/サーバ依存のため `手動/対象外` とする。

刷新先 ec-cube-enterprise に該当画面（`FileController` / `@admin/Content/file.twig`）が実在するため E2E 化した（screenExists=true）。
