期待結果は画面表示・遷移・URL・フラッシュ・メモ欄の再表示値などブラウザで観測できる結果で判定する。**期待結果は仕様（設計書 ec-cube-enterprise / 観点表 / 基本設計）由来**とし、実装の現挙動・Form制約値（`eccube_ltext_len`）・POM見出しをオラクル化しない。TSV は既存IT casesの10列に実施管理欄（実施者・実施日・結果・失敗理由）を加えた14列固定。E2E固有情報は TSV 後の付帯表に `テストID` で対応づける。Playwright は本リポジトリでは実行しない（構造参考のみ）。未検証セレクタは `要実機確認`。

本機能はカスタマイズ区分「標準」であり ec-cube-enterprise を正典とする。**刷新先 ec-cube-enterprise に該当画面が存在する**（route=`admin_order_edit` / `admin_order_new`、`GET/POST /%admin%/order/{id}/edit`・`/%admin%/order/new`）。ショップ用メモ欄は受注編集（詳細）画面右カラムのカード（`#freeArea`）に置かれ、フォーム項目 `note`（保存先 `dtb_order.note`）に対応する。メモ単独の専用URLは持たず、表示・保存とも受注編集のエンドポイントを共有する。
