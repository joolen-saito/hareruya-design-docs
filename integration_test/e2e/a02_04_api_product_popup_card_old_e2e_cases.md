# A02-04（ポップアップ用カード情報取得(旧)） E2Eテストケース

元設計md（正本一次）: `functions/pf-api/a02-04_api_product_popup_card_old.md`
機能詳細HTML: `function_spec_html_preview/pf-api/a02-04_api_product_popup_card_old.html`

テスト観点: `integration_test/integration-test-viewpoints.md` ／ 既存IT: `integration_test/a02_04_api_product_popup_card_old_it_cases.md`（母集合 計38観点行）

本機能は画面を伴わない機能仕様（旧商品ID＋言語でポップアップ用商品情報を1件取得するJSON GET API）であり、**両レイヤで網羅**する。ただし本APIは参照系（DB参照のみ・副作用なし）で、取得結果を反映する管理画面が無いため、UIレイヤの観測対象は無く（付帯表2でUI=0）、**API/統合レイヤ**（Playwright `request` でエンドポイントへGET送信し、HTTPステータス・レスポンス本文・参照の冪等で判定）が主レイヤとなる。

**期待結果は仕様（設計書・観点表・基本設計）由来**とし、実装のレスポンス形・フィールド型・HTTPライブラリ既定値を期待値に流用しない（オラクル独立性）。実装からは位置情報（APIパス・メソッド・認可方式）のみを `file:line` 根拠で取得し、取れないものは `要実機確認`。設計書と実装の食い違いは付帯表4へ出す。pf-apiはリバース設計のため、基本設計・観点表を上位オラクルとする。TSV は既存IT casesの10列に実施管理欄（実施者・実施日・結果・失敗理由）を加えた14列固定。Playwright は本リポジトリでは実行しない（構造参考のみ）。
