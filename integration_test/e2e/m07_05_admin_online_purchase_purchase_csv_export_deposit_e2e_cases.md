元設計: `function_spec_html_preview/pf-eccube3/m07-05_admin_online_purchase_purchase_csv_export_deposit.html`（正本 `functions/pf-eccube3/m07-05_admin_online_purchase_purchase_csv_export_deposit.md`）

テスト観点: `integration_test/integration-test-viewpoints.md` ／ 既存IT: `integration_test/m07_05_admin_online_purchase_purchase_csv_export_deposit_it_cases.md`（母集合 計90観点行）

期待結果は画面表示・遷移・URL・ダウンロード発火・HTTP応答ヘッダ・フラッシュ等ブラウザで観測できる結果で判定する。**期待結果は仕様（設計書・観点表・基本設計）由来**とし、実装/POM由来の表示文言をオラクル化しない。**CSVファイルの内容（列順・列値・空値・金額計算・エンコーディング・ファイル名規則の値）は手動確認**とする（E2Eではダウンロード発火・応答ヘッダ・ファイル名書式のみ観測）。TSV は既存IT casesと同一の 10 列固定。E2E固有情報は TSV 後の付帯表に `テストID` で対応づける。Playwright は本リポジトリでは実行しない（構造参考のみ）。未検証セレクタは `要実機確認`。

本機能は pf-eccube3 のリバース設計であり、刷新先 ec-cube-enterprise のコア実装（`admin_purchase_csv_export_deposit` = POST `/{admin_route}/purchase/csv_export_deposit`）に該当画面が存在する。基本設計・観点表を上位オラクルとし、実装との乖離は付帯表4に記す。

## 関連ID対応概要

| IT-27 | 出力失敗（存在しないID→例外フラッシュ） |
| IT-25 | UI部品（ダウンロードドロップダウン・入金CSV・行チェック・#allCheck）・送信可否制御（pagination時のみ描画）・確認ダイアログ不在・未選択JS抑止・URL・HTTPステータス |

| IT-15 | 状態変化（空ID→フラッシュ＋リダイレクト）・未認証ガード（CSRFはFW内部完結＝観測外） |
| IT-13 | URL直接アクセス（未ログイン誘導・POST専用ルート） |
| IT-22 | 必須（未選択＝買取注文ID空）・DB相関（存在しないID）。文字列長/数値/文字種/部分入力は本機能に非該当 |
| IT-26 | 本機能はDB更新を行わない（参照・出力のみ）。CSV出力の間接確認のみ |
| IT-23 | 本機能はID集合検索（処理フロー#5）と銀行口座/本人確認区分の結合クエリ（#6）を行う。結果はブラウザから直接観測できず、CSV内容（手動040-042）と存在分出力挙動（023存在しないID/042部分存在）で間接観測する。一覧の検索条件入力欄は別機能m07_01へ委譲 |
| IT-20 | ログ出力抑止・識別子＝ブラウザ観測外 |
| IT-24（要確認） | 観点表ではCSV出力＝ファイルダウンロード/データ出力が IT-24 に直接該当する。本機能の母集合（既存IT cases 90行）は IT-24 を関連IDに採らず IT-16/IT-23/IT-26/IT-27 で代替している。IT-24相当の観点の写像: ダウンロード発火/応答/ファイル名書式=010,011,014（自動化）／既定ファイル名の最小ID値・列順・区切り文字・改行コード・文字コード(BOM)・各列出力値・件数=040,043,044,045,042（手動・CSV内容厳密検査）。**自動化はDL発火・応答・ファイル名書式のみで、CSV内容項目は手動**。母集合定義は既存ITに従う（**要確認**: 既存IT cases が IT-24 を関連IDに含めていない点） |
