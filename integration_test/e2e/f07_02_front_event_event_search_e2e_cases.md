# f07-02_front_event_event_search（大会詳細検索／フロント イベント検索） E2Eテストケース

元設計: `functions/pf-eccube3/f07-02_front_event_event_search.md`（正本md。機能詳細HTML `function_spec_html_preview/pf-eccube3/f07-02_front_event_event_search.html`）

テスト観点: `integration_test/integration-test-viewpoints.md` ／ 既存IT: `integration_test/f07_02_front_event_event_search_it_cases.md`（母集合 計90観点行 `IT-F07-02-FRONT-EVENT-EVENT-SEARCH-001..090`）

期待結果は画面表示・遷移・URL（GETクエリ）・HTTPステータス（0件時404）などブラウザで観測できる結果で判定する。**期待結果は仕様（設計書・観点表・基本設計）由来**とし、実装/POM由来の表示文言をオラクル化しない。TSV は既存IT casesと同一の 10 列固定。E2E固有情報は TSV 後の付帯表に `テストID` で対応づける。Playwright は本リポジトリでは実行しない（未検証雛形）。カスタマイズ区分はカスタマイズであり、画面・処理フロー・表示メッセージは pf-eccube3 を参照リポ、DB は ec-cube-enterprise を正典とする。ec-cube-enterprise の Twig は本リポジトリに未取込のため、セレクタは URL・表示文言・フォーム要素の意味で寄せ、file:line 根拠が取れない箇所は `要実機確認`。

本機能はログイン不要の公開検索画面である。検索フォームの初期表示・UI部品・送信可否・GETクエリ反映・0件時404・戻る/直接アクセスの遷移は資格情報なしで LIVE 自動化できる。一方、検索結果の内容（一致/除外・件数・25件/ページ・並び順・各種フィルタ・結果→詳細遷移）はシード投入イベントに依存するため `E2E自動化(要シード)`＝`test.fixme` で保留する。
