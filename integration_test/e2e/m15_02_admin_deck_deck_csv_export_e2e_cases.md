# m15-02_admin_deck_deck_csv_export（デッキ管理 — デッキ CSV 出力） E2Eテストケース

元設計: `function_spec_html_preview/pf-eccube3/m15-02_admin_deck_deck_csv_export.html`（正本 `functions/pf-eccube3/m15-02_admin_deck_deck_csv_export.md`）

テスト観点: `integration_test/integration-test-viewpoints.md` ／ 既存IT: `integration_test/m15_02_admin_deck_deck_csv_export_it_cases.md`（母集合 計90観点行）

期待結果は画面表示・遷移・URL・ダウンロード発火・ファイル名などブラウザで観測できる結果で判定する。**期待結果は仕様（設計書・観点表・基本設計）由来**とし、実装/POM由来の表示文言や Form 制約をオラクル化しない。**CSVの中身（列・順序・値・表示フラグ写像・メイン/サイド列・統率者名・行数対応・エンコード/BOM）は手動確認**とする。TSV は既存IT casesと同一の 10 列固定。E2E固有情報は TSV 後の付帯表に `テストID` で対応づける。Playwright は本リポジトリでは実行しない（構造参考のみ）。未検証セレクタは `要実機確認`。

本機能は pf-eccube3（旧システム）のリバース設計のため、**基本設計・観点表を上位オラクル**とし、刷新先 ec-cube-enterprise との乖離は付帯表4（不具合候補）に出す。テストは仕様どおりに書き、実装が違えば落ちて検出する。
