期待結果は画面表示・遷移・URL・フラッシュメッセージなどブラウザで観測できる結果で判定する。**期待結果は仕様（設計書・観点表・基本設計）由来**とし、実装/POM由来の表示文言・Form制約（accept属性・maxlength）をオラクル化しない。本機能は新規実装（pf-eccube3に同等機能なし）で、URLエンドポイント・必須ヘッダ・取込手順・反映先列は ec-cube-enterprise 実装を、画面・業務条件は基本設計を上位オラクルとする。TSV は既存IT casesの10列に実施管理欄（実施者・実施日・結果・失敗理由）を加えた14列固定。E2E固有情報は TSV 後の付帯表に `テストID` で対応づける。Playwright は本リポジトリでは実行しない（構造参考のみ）。未検証セレクタは `要実機確認`。

注: 本機能は単独画面ではなく在庫移動指示一覧（`admin_stock_move_instruction_list`）上のモーダル `#csvRecordRegistrationModal` から CSV を POST（`admin_stock_move_instruction_csv_tracking`）し、一覧へ `resume=1` 付きでリダイレクトしてフラッシュ（`.alert`）で結果を表示する csv_import 機能である。
