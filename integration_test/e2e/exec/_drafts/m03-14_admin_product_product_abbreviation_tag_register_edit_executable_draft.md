## §10 隔離メモ（bind根拠に不使用）

- 識別ID11「ソート」（0204:7577）は一覧の並び順列でありアルファベット順ソートフラグの状態ラベル（「アルファベット」「コレクター番号」）を表示するのみ（pf-md:46,118）。並び順数値(rank)とは別項目でありbind根拠に不使用。
- 楽観ロック/バージョン列はソース上読み取れず競合は後勝ち（pf-md:145,294）＝実挙動だが母集合に並行更新を問う行がなくL1化・bind根拠に不使用。
- pf md入口注記「『新規登録へ戻る』がヘッダ付近に出る**場合がある**」（pf-md:34）はB1非定言だが、フロント挙動(pf-md:46)・画面遷移(pf-md:212)で編集モードでの表示が定言的に確認できるため、C-008は「編集モードでの表示・押下遷移」に限定してbound（「場合がある」語自体はbind根拠に不使用）。
- ee messages.en.yaml の English 値（Registration completed./failed./Deleted./delete_modal en）は実在するが、pf md表がen空欄（英訳なし）でありEE値をpf-fallback claimに混入させない方針のためL1 claimの期待値・source(根拠)に不使用（§5照合注記のみ）。
