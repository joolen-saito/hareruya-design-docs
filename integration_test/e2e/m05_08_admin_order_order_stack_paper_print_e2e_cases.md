期待結果は画面表示・別ウィンドウ生成・アラート文言・HTTPステータス・JSONの `message`・遷移など、ブラウザで観測できる結果で判定する。**期待結果は仕様（設計書・観点表・基本設計）由来**とし、実装/POM由来の表示文言をオラクル化しない。TSV は既存IT casesの10列に実施管理欄（実施者・実施日・結果・失敗理由）を加えた14列固定。E2E固有情報は TSV 後の付帯表に `テストID` で対応づける。Playwright は本リポジトリでは実行しない（構造参考のみ）。未検証セレクタは `要実機確認`。

本機能は画面タイプ=`print`。一覧の一括フォームから別ウィンドウを開き、子ウィンドウが AJAX で印刷予約エンドポイントへ POST する。印刷予約の結果として DB（`browser_print_flg`・`order_status_id`・`confirm_date`・`member_id`）を更新するが、原値は画面に出ないため DB 観点は手動/間接または対象外（付帯表2/5）。設計書(pf-eccube3 リバース)と刷新先 ec-cube-enterprise は本ルートの固定メッセージ・分岐が一致する（付帯表4）。
