# m14-02_admin_card_card_csv_export（カード管理 — カード情報 CSV 出力） E2Eテストケース

元設計: `function_spec_html_preview/pf-eccube3/m14-02_admin_card_card_csv_export.html`（正本 `functions/pf-eccube3/m14-02_admin_card_card_csv_export.md`）

期待結果は画面表示・遷移・ダウンロード発火・HTTP応答・ファイル名などブラウザで観測できる結果で判定する。**期待結果は仕様（設計書・観点表・基本設計）由来**とし、実装/POM由来の表示文言・Form制約・内部ルート名をオラクル化しない。TSV は既存IT casesの10列に実施管理欄（実施者・実施日・結果・失敗理由）を加えた14列固定。E2E固有情報は TSV 後の付帯表に `テストID` で対応づける。Playwright は本リポジトリでは実行しない（構造参考のみ）。未検証セレクタは `要実機確認`。CSV の内容（列値・見出し・並び順・BOM・文字コード）はダウンロード後に開いて手動確認する。

> 設計源は pf-eccube3 / HareruyaEc プラグインのリバース。刷新先 ec-cube-enterprise に当該画面の存在を確認済み（`screenExists=true`）。両者の乖離は付帯表4で管理し、テストは仕様どおりに書く。
