# m04-04_admin_stock_stock_csv_export（在庫情報CSV出力） E2Eテストケース

元設計: `function_spec_html_preview/ec-cube-enterprise/m04-04_admin_stock_stock_csv_export.html`（正本 `functions/ec-cube-enterprise/m04-04_admin_stock_stock_csv_export.md`）

テスト観点: `integration_test/integration-test-viewpoints.md` ／ 既存IT: `integration_test/m04_04_admin_stock_stock_csv_export_it_cases.md`（母集合 計90観点行）

期待結果は画面表示・遷移・URL・ダウンロード発火・HTTP応答ヘッダ・ファイル名などブラウザで観測できる結果で判定する。**期待結果は仕様（設計書・観点表・基本設計）由来**とし、実装の現挙動・Form制約・POM由来文言をオラクル化しない。TSV は既存IT casesと同一の 10 列固定。E2E固有情報は TSV 後の付帯表に `テストID` で対応づける。Playwright は本リポジトリでは実行しない（構造参考のみ）。未検証セレクタは `要実機確認`。

本機能は在庫検索一覧（M04-01）の「在庫情報CSV出力」ボタン（GETリンク `admin_stock_list_csv`）からの `StreamedResponse` ダウンロードであり、セッション `admin.stock.list.search` の検索条件で全件をCSV出力する。**CSV構造（0件時ヘッダ行のみ＝1行・ヘッダのカンマ区切り列数19）はダウンロードファイルから自動検証**する（期待値は設計書「出力列数19」/「対象0件＝ヘッダ行のみ」由来）。**CSV各列の値・見出し文言・SJIS-win変換・削除レコード除外は手動確認**とする（実ファイルを開いて確認。列数判定はカンマがCP932のバイト域に現れないため文字コード非依存で安全だが、各列値・文言の正当性は機械判定しない）。

## 母集合の定義（監査基準・観点表との関係）

正典 `integration_test/integration-test-viewpoints.md` は全機能横断の**観点カタログ（517行・IT-IDごとの汎用観点テンプレート。`［システム機能設計書の記載通り］` 等のプレースホルダを含む）**であり、特定機能の母集合ではない。本機能の分類母集合は、その汎用カタログを本機能へ写像（インスタンス化）した既存IT cases `m04_04_admin_stock_stock_csv_export_it_cases.md` の **90観点行**とする。各行が関連ID（カタログ観点）を1つ参照し、本機能における観点カタログの全インスタンスを成す。本書の「未分類0」はこの90行に対する完全分類を意味する。

汎用カタログ側で本機能に出現しないIT-ID（例: IT-22 バリデーション／IT-23 DB相関／IT-26 等の入力検証・更新系）は、本機能が**入力項目を持たない参照系のCSV出力**であり写像対象が無いため、IT cases生成段階で非該当として落ちている（既存ITに行が無い）。本機能はCSVダウンロードを行うため、観点表のファイルダウンロード/出力内容系（IT-24=37行・IT-33=4行）は既存IT 90行に**取り込み済み**で、付帯表2/2bで全行分類する（IT-24系の取りこぼしは無い）。**要確認**: 汎用カタログ517行→本機能該当IT-IDへの絞り込み妥当性は設計書「関連ID対応概要」と既存IT casesの関連ID列で追跡する（カタログ側に機能別マッピング列が無いため、カタログ全行の機能別射影監査は観点マスタ側の責務＝本E2E成果物の責務外）。
