本機能は管理画面ホーム（`GET /%eccube_admin_route%/`）のダッシュボード内「ショップ状況カード（`#shop-statistical`）」であり、参照のみのサマリ表示と一覧画面への導線を持つ。専用フォーム・専用 Ajax・専用の登録/更新を持たないため、既存 IT cases（観点名のみの自動生成スタブ90行）のうち入力バリデーション（IT-22）・登録/更新（IT-26）系は本ブロックに非該当として分類する。

ただし IT-23（DB読取系）は「DB検索を行わない」と一律に対象外化しない。本ブロックはホーム表示時に在庫切れ商品数・取扱商品数・本会員数の3指標を DB から **集計（count）読取** する（設計書「処理フロー＞ホーム画面表示・ショップ状況用集計」「集計条件」「入出力＞成功時出力」由来）。したがって IT-23 のうち成功時出力・参照時点・集計対象・実行結果に相当する行は手動/間接（集計値突合・セッション・表示）へ写像する。一方、一覧の検索 UI・検索結果・ページングそのものは別機能 m11 商品一覧／会員一覧の範囲であり、その部分のみ対象外（委譲）とする。集計値そのものの正しさ（在庫切れ＝商品単位一意、廃止除外、本会員のみ、0件→0、規格なし商品、負数/NULL在庫、廃止×在庫切れ）は DB シードと突合が要るため手動とする。
