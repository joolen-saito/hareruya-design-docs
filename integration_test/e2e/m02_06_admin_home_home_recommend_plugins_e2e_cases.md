母集合の定義: 観点表 `integration-test-viewpoints.md` は全機能共通の観点マスタ（全I/F・全分類軸）である。本機能の監査母集合は、その観点マスタを本機能のI/Fへ適用して生成された既存IT cases 90行（IT-03/13/15/20/22/23/25/26 の全分類軸を本機能向けに展開したもの）とする。本E2Eはこの90行を全件分類し未分類0を保証する（観点マスタ全行の直接分類ではなく、本機能へ適用済みの90行が監査対象）。

期待結果は画面表示・遷移・URL・モーダル開閉などブラウザで観測できる結果で判定する。**期待結果は仕様（設計書・観点表・基本設計）由来**とし、実装/POM由来の表示文言をオラクル化しない。TSV は既存IT casesの10列に実施管理欄（実施者・実施日・結果・失敗理由）を加えた14列固定。E2E固有情報は TSV 後の付帯表に `テストID` で対応づける。Playwright は本リポジトリでは実行しない（構造参考のみ）。未検証セレクタは `要実機確認`。

**本機能の特性（重要）**: おすすめプラグイン一覧はホーム画面表示時に**サーバ側で外部プラグインAPI（`PluginApiService::getRecommended()` AdminController.php:189）から取得**する。取得はサーバ間通信でありブラウザからは route 横取り（route interception）でモックできない。したがって「プラグイン行・詳細モーダル・状態別CTA（入手/購入/インストール済み/アップデート）・対応バージョン警告・取得失敗時の空表示」は、外部APIが特定状態のプラグインを返す必要があり**E2Eで決定論的に再現できない**。これらはケース表で `手動` または `自動化予定(fixme・データ依存)` として全量管理する。常時観測できるのはカードの枠（見出し・オーナーズストアリンク・縦スクロール）と未認証ガードのみである。
