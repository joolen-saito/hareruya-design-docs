本機能は画面を伴わない機能仕様（スマレジWebhook受信→在庫更新）であり、**両レイヤで網羅**する。API/統合レイヤ＝Playwright `request` でWebhookエンドポイントへ送信し、HTTPステータス・応答・在庫不変（冪等）で判定。UIレイヤ＝受信結果が管理画面（在庫検索一覧の在庫数反映・在庫変動履歴の作成）に現れる範囲をブラウザで観測して判定。

**期待結果は仕様（設計書・観点表・基本設計）由来**とし、実装のレスポンス形・スマレジ実装挙動・HTTPライブラリ既定値・Form制約を期待値に流用しない（オラクル独立性）。設計書はレスポンス書式を「なし（ステータスコードのみ）」と定めるため、API応答の合否は**HTTPステータスと在庫副作用**で判定し、実装が返すJSON本文（`{status:...}`）はオラクルにしない。実装からは位置情報（APIパス・メソッド・認証方式・セレクタ）のみを `file:line` 根拠で取得し、取れないものは `要実機確認`。設計書と実装の食い違いは付帯表4に出す。TSV は既存IT casesの10列に実施管理欄（実施者・実施日・結果・失敗理由）を加えた14列固定。Playwright は本リポジトリでは実行しない（構造参考のみ）。

|--------|------------------------|
| IT-32 | 受信検証・資格情報（認証）・必須条件・想定外項目・レスポンス書式・データなし（空ids）。バージョニングは正典にAPIバージョン指定が無く対象外 |
| IT-09 | 正常受信のHTTPステータス・実行結果・リクエスト正常・外部取得（取引詳細）・非同期処理投入完了（終了条件） |
| IT-20 | 重要操作・外部連携・認証エラーの追跡情報ログ出力と機密値の出力抑止（設計書「状態・データ更新」アプリログ／観点表IT-20。母集合外の設計書補完） |
| IT-19 | 同時実行数の制限／レート制限（スロットリング） |
| IT-10 | HTTPステータス・通信・正常／異常系・形式不正・障害・重複/順序（冪等）・部分失敗・タイムアウト |
| IT-33 | 区分整合（02/12のみ処理・対象外不変）・売上(02)減算/返品(12)加算・自動加算（連携元ID付き履歴）・実数更新・外部取引・連携エラー時の片側更新なし |
