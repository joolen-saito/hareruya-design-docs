# f06-23_front_contact_history（会員 — お問い合わせ履歴（一覧・詳細）） E2Eテストケース

元設計: `functions/pf-eccube3/f06-23_front_contact_history.md`（お問い合わせ履歴 一覧＝F06-23／詳細＝F06-24を1冊にまとめた参照系設計）

テスト観点: `integration_test/integration-test-viewpoints.md` ／ 既存IT: `integration_test/f06_23_front_contact_history_it_cases.md`（母集合 計90観点行。接頭辞 `IT-F06-23-FRONT-CONTACT-HISTORY-NNN`）

期待結果は画面表示・遷移・URL・見出し文言・件数などブラウザで観測できる結果で判定する。**期待結果は仕様（設計書・観点表・基本設計）由来**とし、実装/POM由来の表示文言をオラクル化しない。TSV は既存IT casesと同一の 10 列固定。E2E固有情報は TSV 後の付帯表に `テストID` で対応づける。Playwright は本リポジトリでは実行しない（未検証雛形）。カスタマイズ区分は現行踏襲であり、画面・処理フロー・表示要素は pf-eccube3 を参照リポ、DB（`dtb_contact`）は ec-cube-enterprise を正典とする。本機能は閲覧専用（参照系）で利用者入力フォームを持たない。`/contact/history` 配下は会員ログインを要する。

## 関連ID対応概要

| 関連ID | 本機能でのE2E確認範囲 |
|--------|------------------------|
| IT-15 | 未認証保護（会員ログイン誘導）・自分のお問い合わせのみ閲覧・一覧表示要素 |
| IT-20 | 件名リンクから詳細への遷移（識別子）。ログ出力抑止はブラウザ観測外 |
| IT-25 | 一覧見出し・総件数・詳細見出し・並び順・戻るリンク・保護アクセス時挙動 |
| IT-03 | 画面遷移（件名表示・日時書式・0件・他会員ID・非存在ID・一覧⇔詳細整合）。参照時点は時刻依存で対象外 |
| IT-13 | 保護URL直接アクセス→会員ログイン誘導 |
| IT-22 | 入力フォーム・バリデーションを持たないため非該当（対象外） |
| IT-23 | dtb_contact の検索は内部値で画面観測不能（UI反映は一覧・詳細表示で担保） |
