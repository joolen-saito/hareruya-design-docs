## 重要：刷新先（ec-cube-enterprise）に該当画面・ルートが存在しない（screenExists = false）

本機能「在庫分割結合情報カスタムCSV出力」は、刷新先 ec-cube-enterprise に**専用のカスタムCSV出力ルート・画面・出力サービスが未実装**である（設計書「実装状況（重要・実装要確認）」と実装確認が一致）。確認した事実は次のとおり。

- `StockSplitJoinController`（`src/Eccube/Controller/Admin/Stock/StockSplitJoinController.php`）には固定列出力 `admin_stock_split_join_csv_export`（`:210-219`、M04-14）はあるが、フォーマットID（`csvExtensionId`）を受け取る `custom-csv` 系ルートは**存在しない**。
- `StockSplitJoinCsvExportService` は固定列出力のみで、`dtb_csv`（CSV種別 `CSV_TYPE_STOCK_SPLIT=12`）のフォーマット選択を適用する分岐を持たない。
- 在庫分割結合一覧 `stock_split_join_index.twig`（`:292`）にはフォーマット固定の `admin_stock_split_join_csv_export` リンクのみで、**カスタムCSV出力の入口（プルダウン/リンク）は存在しない**。専用 trans キー `admin.stock.split_join.custom_csv` も**未定義**（`messages.ja.yaml` に無し。固定列は `:4656 admin.stock.split_join.csv_export`「在庫分割結合CSV出力」のみ）。
- 一方、CSV種別マスタ `CsvType::CSV_TYPE_STOCK_SPLIT = 12`（`Entity/Master/CsvType.php:87`）は定義され、カスタムCSV共通設定 `CustomCsvType::CSV_TYPES`（`Form/Type/Admin/CustomCsvType.php:40`）にも在庫分割結合枠が**登録済み**。つまり「フォーマット定義の受け皿」はあるが「出力経路」が無い。
- 参照実装: 在庫一覧側 `admin_stock_list_custom_csv`（`StockListController.php:270` `GET /%admin%/product/stock/custom-csv/{csvExtensionId}`）が存在し、在庫分割結合に同等機能を追加する際の倣い先となる（別機能 M04-05）。

したがって**本機能のE2E自動化は現時点で実装不能**であり、セレクタ・ルートを創作しない。下記E2Eケースは設計書（要件）由来の期待結果を確定したうえで、いずれも `要確認(未実装)` または `手動`（CSVファイル内容）に分類する。実装が追加された後に自動化する前提の雛形を Page Object / spec に残す（`test.fixme`・理由付き）。乖離は付帯表4に記録する。
