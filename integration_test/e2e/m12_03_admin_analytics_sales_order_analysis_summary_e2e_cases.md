# M12-03（受注/売上分析 集計一覧表示） E2Eテストケース

元設計: `function_spec_html_preview/pf-eccube3/m12-03_admin_analytics_sales_order_analysis_summary.html`（正本 `functions/pf-eccube3/m12-03_admin_analytics_sales_order_analysis_summary.md`）

テスト観点: `integration_test/integration-test-viewpoints.md` ／ 既存IT: `integration_test/m12_03_admin_analytics_sales_order_analysis_summary_it_cases.md`（母集合 計90観点行）

期待結果は画面表示・遷移・URL・初期既定値などブラウザで観測できる結果で判定する。**期待結果は仕様（設計書・観点表・基本設計）由来**とし、実装/POM由来の表示文言をオラクル化しない。設計(pf-eccube3)は旧システムのリバースであり、**観点表・基本設計を上位オラクル**として扱う。刷新先(ec-cube-enterprise)との乖離は付帯表4（不具合候補）に出し、テストは仕様どおりに書く。TSV は既存IT casesと同一の 10 列固定。E2E固有情報は TSV 後の付帯表に `テストID` で対応づける。Playwright は本リポジトリでは実行しない（構造参考のみ）。未検証セレクタは `要実機確認`。

画面タイプは `summary`（検索＋集計一覧表示）。集計数値・割合・表示件数の厳密な打ち切り・絞り込みの含む/含まないはDB件数依存のため、**自動化は画面構造（フォーム部品・初期既定値・結果セクション表示・0件見出し・列構成・遷移）に限定**し、集計値の厳密検証は手動/間接とする。

## 関連ID対応概要

| 関連ID | 本機能でのE2E確認範囲 |
|--------|------------------------|
| IT-15 | 未認証ガード（ログイン誘導）・検索実行による結果セクション表示（状態変化）。CSRFはトークン無効化のため対象外 |
| IT-20 | 初期表示の既定値（使用日付=注文日・集計単位=商品・昇順・当月集計日）。検索条件セッション/ログ抑止はブラウザ観測外 |
| IT-25 | 検索フォーム部品・入力項目・集計単位による列構成・合計行・CSV導線・検索条件クリア |
| IT-03 | 集計単位カテゴリの列構成・0件見出し・同一画面への結果表示 |
| IT-13 | URL直接アクセス（ログイン済みで初期検索画面・未ログインで誘導） |
| IT-22 | 数値項目（平均単価/数量）の検証。必須/文字列長/文字種等は刷新先実装に該当制約なし（付帯表4） |
| IT-23 | 検索条件による絞り込み（厳密件数は間接）。検索結果の含む/含まないはDB依存で手動 |
| IT-26 | 0件見出し・成功時出力（結果一覧画面）。本機能は参照のみで登録/更新なし |
