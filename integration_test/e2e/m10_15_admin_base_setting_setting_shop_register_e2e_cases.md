# m10-15_admin_base_setting_setting_shop_register（店舗基本設定の店舗登録（SHOPマスター保存）） E2Eテストケース

元設計: `function_spec_html_preview/pf-eccube3/m10-15_admin_base_setting_setting_shop_register.html`（正本 `functions/pf-eccube3/m10-15_admin_base_setting_setting_shop_register.md`）

テスト観点: `integration_test/integration-test-viewpoints.md` ／ 既存IT: `integration_test/m10_15_admin_base_setting_setting_shop_register_it_cases.md`（母集合 計90観点行）

本機能は「基本情報設定画面の『登録』ボタンによる POST 保存（`dtb_base_info` の既定1行を更新）」である。画面自体は M10-01（店舗基本設定）と同一の `/admin/setting/shop`（`shop_master.twig` / `ShopMasterType`）であり、本書は **POST 保存（検証成功→永続化・成功フラッシュ・同画面リダイレクト／検証失敗→滞留・フィールドエラー）の観点**を主とする。

期待結果は画面表示・遷移・URL・成功フラッシュ・フィールドエラー表示などブラウザで観測できる結果で判定する。**期待結果は仕様（設計書・観点表・基本設計）由来**とし、実装/POM由来の表示文言・Form制約（required/NotBlank/Length）をオラクル化しない。設計源は pf-eccube3（リバース）であり、刷新先 ec-cube-enterprise との乖離は不具合候補（付帯表4）に出し、テストは仕様どおりに書く。TSV は既存IT casesと同一の 10 列固定。E2E固有情報は TSV 後の付帯表に `テストID` で対応づける。Playwright は本リポジトリでは実行しない（構造参考のみ）。未検証セレクタは `要実機確認`。
