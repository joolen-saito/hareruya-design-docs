## §1. 全ケース共通前提
- **入口/認証**: 認証済み管理者が管理画面で利用。ルートは `admin_labels_export`（`GET, POST` `/{admin_route}/standby/labels`・L403）。起点は受注一覧の「送り状出力」ボタン、または出荷指示編集画面（L318）。管理画面に入れない利用者は当エンドポイントへ到達できない（L369）。
- **参照系**: 本機能は参照のみ（検索・出力）。DBの登録・更新・削除を行わない（L356,L362,L366）。受注検索セッションを読み書きせず、CSV中身/選択ID一覧をセッションに残さない（L374,L388,L390）。新Cookieを設定せず（L393）、ロック・明示トランザクション境界を持たない（L396）。
- **入力**: POST（またはGET）の `ids` 配列。要素は出荷 ID の整数。受注一覧のフォームには CSRF 用 hidden がある（L356,L388）。CSV の対象件数はセッションではなく POST の ID 集合で決まる（L374）。
- **成功時応答**: 現状ページを離れず、ブラウザがファイルダウンロードとして応答を扱う。ファイル名は `labels_` + 日時(`YmdHis`) + `.csv`、`Content-Type: application/octet-stream`、`Content-Disposition: attachment`（L326,L356,L372）。
- **失敗時応答**: `ids` が配列でない、または空 → HTTP 404（L318,L347,L356,L372,L377）。エクスポート種別が未知 → 例外中断（画面経路では種別は固定文字列 `labels` のみで通常発生しない・L328,L377）。
- **オラクル独立性**: 期待は詳細設計HTML由来で実装から独立。詳細設計が「実装を確認値とする」と記す箇所（配送先先頭参照・target残存など）は断定せず**要実機確認**とし、実装との差は付帯表4で乖離＝バグ候補として扱う。

## §7. gen(73) からの是正（オラクル差し替え）
- gen の期待verbatimは詳細設計HTMLの総称文（「CSV をダウンロードする（admin_labels_export）」等をそのまま貼付）で、機械ゲートG6の総称オラクルには該当しないが**具体オラクルになっていなかった**（同一verbatimが多数行に重複）。→ 全行を処理フロー/出力列/エッジケース/整合性の**具体挙動**へ差し替え、重複（検索条件×16・実行結果×多数・数値バリデーション×8の同一verbatim反復）を潰し、実在する観点のみに集約。
- gen が `EXEC`「検索条件」を多数出していたが、本機能に検索条件フォームは無く（対象はチェックした出荷IDのみ・L374,L405）実体が無いため**非採用**（母集合スタブの無差別生成）。
- gen が `数値バリデーション`（EXEC-UI:DDT×8）を反復していたが、サーバ側フォーム型検証が無い（L366）ため数値境界の固定オラクルは無く、実在検証は ids 配列性/存在有無のみ → DDTを DI-01〜04 に集約、数値/文字境界は §5 で `要判定`。
- gen の `CSRF＝DELEG-STATIC`／`未認証＝EXEC-UI` は、正本がサーバ側トークン検証の拒否を明示しない（L388）ため CSRF は `要判定`（要実機確認）へ、認可拒否は L369 の明示（到達できない）に基づき `EXEC-UI`（RG-025）＋`CONTRACT`（RG-026）へ是正。
