## §1. 全ケース共通前提
- **入口/認証**: 認証済み管理者が管理画面ナビ「タグ登録/編集」から利用（Excel 0204:L6657 機能名「タグ登録」）。ルートは表示系 `GET /{admin_route}/product/tag`・`GET /{admin_route}/product/tag/{id}`・`GET /{admin_route}/product/tag/page/{page_no}`・`GET /{admin_route}/product/tag/{id}/page/{page_no}`、登録系 `POST /{admin_route}/product/tag/store` または `…/store/{id}`、削除系 `DELETE /{admin_route}/product/tag/{id}/delete`（L316,L399）。`id`・`page_no` は10進整数（L399）。
- **認可**: `/{admin_route}/` パターンのため未ログインは管理画面ログインへ。ロールの `deny_url` が `/product/tag` に一致すると HTTP 403（L366）。
- **画面構成**: 同一画面の上半分が登録/編集フォーム、下半分がタグ一覧（ID・名称(日)・名称(英)・並び順・編集ボタン）＋件数セレクト＋ページング（Excel 0204:L6746-6752／L319）。「その他の設定 (クリックで展開)」の折りたたみ内に(7)〜(13)を配置（Excel 0204:L6737）。
- **カスタマイズ反映**: 画面項目(4)「優先表示商品のみを表示」は**項目削除**（Excel 0204:L6736）。よって当項目は画面・POST・検証のいずれにも現れないことを正とする（§0）。
- **副作用**: `dtb_tag` の INSERT/UPDATE、`dtb_tag_sort` の DELETE/INSERT、フラッシュメッセージ、セッションのページ状態（L353）。保存はトランザクション内で確定（L394）。
- **オラクル独立性**: 期待はオラクル（Excel優先・沈黙部は詳細設計HTML）由来で実装から独立。実装との差は付帯表4で乖離＝バグ候補として扱う。オラクルが沈黙する具体挙動（エラー文言等）は断定せず「要実機確認」とする。

## §7. gen(74) からの是正（オラクル差し替え）
- gen の期待verbatimは詳細設計HTMLの表を丸ごと貼った総称文（「利用者状態 画面・URL 未ログイン…」「本機能が直接更新し得る主な列は次のとおり」等）が反復し、同一文が最大14行に重複していた（RG-062〜074）。→ 全行を Excel優先＋詳細設計補完の具体挙動へ差し替え、画面項目(1)〜(20)・カスタマイズ(項目削除)・保存時の `dtb_tag_sort` 再構成・削除の拒否条件へ具体化。
