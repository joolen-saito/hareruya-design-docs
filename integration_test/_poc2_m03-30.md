## §1. 全ケース共通前提
- **入口/認証**: 認証済み管理者（商品管理→CSV管理→当メニュー到達可）が管理画面で利用（詳細設計 L317,L367）。3ルート＝GET `admin_product_product_price_csv_upload`（アップロード画面）／GET `admin_product_product_price_csv_template`（雛形DL）／POST `admin_product_product_price_import`（取込）。未認証は管理画面の共通認証仕様で拒否（§4 RG-024）。
- **取込形式**: multipart の CSV（またはTSV解釈）。区切り・囲みは設定 `eccube_csv_import_delimiter`／`eccube_csv_import_enclosure`（詳細設計 L355）。フォーム項目キーは `import_file`、仕様上必須（詳細設計 L340）。
- **CSV列構成（オラクル＝Excel優先）**: Excelカスタマイズにより列「販売価格」は「**基準価格**」へ改名される（`0204:L10011`）。列順は 商品ID／言語(ID)／基準価格／買取価格／セールフラグ／帯URL／タグ(ID) の**7列ちょうど**（詳細設計 L343 は改名前ラベルで7列を規定・Excelが列名を上書き）。データ列が7でないと列数エラー・ロールバック（詳細設計 L343,L346）。
  - **整合ノート（Excel沈黙部の追跡性）**: Excelの『基準価格変更登録CSVフォーマット』シートは識別ID 1-5＝商品ID／言語ID／基準価格／買取価格／原価単価（`0204:L10009`〜`0204:L10013`。うち ID5 原価単価は「※新規追加→こちら対応なし」`0204:L10013`＝本機能で非対応）の**カスタマイズ対象＝価格列のみ**を列挙し、非価格列（セールフラグ／帯URL／タグ(ID)）には沈黙している。Excelは「現行機能をベースに下記カスタマイズ」（`0204:L10022`）と明示するため、Excel が沈黙する非価格列は現行7列構成をそのまま継承し、Excel沈黙部を詳細設計 L343 が補完する。したがって Excel format sheet の5ID列挙は7列構成を上書きせず、価格列（ID3）を「基準価格」へ改名するカスタマイズのみを7列の上に重ねる（競合ルール＝Excelが触れる価格列のみ Excel 優先、沈黙する非価格列は詳細設計）。
- **副作用（成功時）**: `dtb_product_class` 更新・`dtb_product` 側タグ紐付け更新・`dtb_price_history` 追記・取込履歴（成功かつ結果エラー無しのときのみ）追記・スマレジ連携用内部キュー・情報ログ（詳細設計 L355,L358）。DB永続の正は ec-cube-enterprise（詳細設計 L360）。
- **応答**: 成功/失敗いずれも HTTP 302 でアップロード画面へリダイレクトし admin フラッシュ（詳細設計 L328,L371）。
- **オラクル独立性**: 期待はオラクル（Excel優先・沈黙部は詳細設計）由来。実装との差は付帯表4で乖離＝バグ候補として扱う。
