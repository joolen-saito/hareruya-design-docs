## 機能をまたぐときの決まり

- 外せるのは、**同じ画面の同じ操作で同じ結果を確かめる**とき（同一・包含・同値）だけ。例: マイページの「ポイント履歴」ボタンでポイント履歴画面へ遷移することを、マイページの機能とポイント履歴の機能の両方で確かめている。
- 別の画面・別の出力・別の処理は、書き方が同じでも別の機能の確認なので残す。例: 受注一覧CSV と 受注詳細CSV の引用符の付け方、商品CSV登録 と カードCSV登録 の同じ形の検査。
- 残す側は、その動きを定める設計書のシートを持つ機能のケース（ケースの出典が指すシートで決める）。決まらなければ `[E2E]`・`[PW:…]` → 確かめる所が多いもの → 番号が小さいもの。
