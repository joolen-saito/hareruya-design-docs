## 組ごとの評価
| 上流 → 下流 | 判定 | 理由 |
| --- | --- | --- |
| M04-09 移動登録 → M04-17 在庫履歴 | 採用 RD001 | 登録で出庫元の在庫と総原価が減り履歴を登録すると上流に明記。下流は登録元・登録元ID・変更前後在庫・増減数・総原価を表示 |
| M04-09 移動登録 → M04-01 在庫検索一覧 | 採用 RD002 | 「移動対象の商品の在庫が移動点数分減る」。下流は店舗・在庫区分ごとの在庫・総原価を表示。在庫の一覧であり移動の一覧ではないので同じ機能群の再表示に当たらないと判断（要確認点として下に記載） |
| M04-09 振替登録・承認 → M04-17 | 採用 RD003 | 登録で振替元を減算、承認で振替先を加算し、どちらも履歴を登録 |
| M04-09 移動の出庫承認却下 → M04-17 | 採用 RD004 | 却下で在庫を移動点数だけ戻す。履歴の区分名は上流内で却下／棄却が混在するため増減数と数値だけで確かめる |
| M04-13 分割登録 → M04-17 | 採用 RD001 | 登録時に分割元を減算し履歴を登録（4-4・4-6） |
| M04-13 分割承認 → M04-17 | 採用 M04-13-RD002 | 承認で分割先の在庫を増やし履歴を登録（承認待ちの2-2・2-3）。仕入総価格は分割先が1商品なので分割元の移動総原価400 |
| M04-13 → M04-12 | 不採用 | 同じ機能群の編集と一覧（既存 IT-M04-13-080・081 が作成済み） |
| M04-13 結合 → M04-17 | 不採用 | 結合元の在庫がいつ減るかが設計書内で一致しない（下記） |
| M04-22 移動CSV → M04-17 | 採用 RD001 | 「M04-09の登録処理が行われる」。ステータス・在庫が減ると明記 |
| M04-22 → M04-08 | 不採用 | 同じ機能群の登録と一覧。公開側への反映は既存 IT-M04-22-043（IT-0150） |
| M04-23 分割CSV → M04-17 | 採用 RD001 | 登録＋承認申請で分割元の在庫が分割数分減る |
| M04-23 → M04-12 | 不採用 | 既存 IT-M04-23-063・064 が作成済み |
| M04-23 結合CSV → M04-17 | 不採用 | 上と同じ（結合元の減算時点が不一致） |
| M04-24 送り状登録 → M04-08 | 採用 RD001 | 送状No.の登録で在庫移動のステータスが移動中。下流の検索結果はステータス・移動指示リストIDを表示。指示の発送手続きと移動の一覧で責務が異なると判断 |
| M04-29 実績CSV → M04-08 | 採用 RD001 | 同上。M04-29 の設計は在庫移動指示検索シートにある |
| M04-24/29 → M04-25 指示詳細・M04-24 一覧 | 不採用 | 同じ機能群の再表示（指示→指示） |

## 作らなかった候補・範囲外の価値ある連携
| 候補 | 理由 |
| --- | --- |
| 結合（M04-13・M04-23）→ 履歴・在庫 | M04-23 結合CSVは「結合元在庫数分減る」、M04-13 結合は結合元の仕入総価格を承認申請時に計算とあり、減算の時点が決まらない |
| 移動の入庫承認 → 在庫検索一覧（入庫先の増加）、差分・欠品の履歴 | 手順が出庫承認・指示・送り状・着荷・入庫承認申請・承認まで長く、入庫先の履歴の区分名も未確定のため見送り |
| M04-08 の在庫移動指示作成 → M04-24 指示一覧（範囲外：上流が M04-08） | 価値あり。判定の上流機能に M04-08 を含める群が必要 |
| 在庫移動・振替の登録 → M04-08・M04-12 一覧 | 同じ機能群の再表示 |
