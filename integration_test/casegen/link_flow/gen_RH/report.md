- M08-04: 顧客グループは必須「-」だが実装は必須（未選択へ戻せない）。M08-04-RH005は別グループへの付け替えで書いた。

- M08-04 識別ID 49（ショップ用メモ）は保存の記述が無く、M05-11の会員備考との対応が追えない。
- M07-03 識別ID 4・5は「当該会員の氏名」、同画面1-4〜1-7は編集できる買取依頼者情報で、表示の取得元が買取側か会員側かが読み切れない。RH001は識別ID 4・5の記述に従った。
- 設定日・有効期限・処理日の表示形式（日付のみか日時か）は設計書に無い。ケースは日付の値だけを書いた。
