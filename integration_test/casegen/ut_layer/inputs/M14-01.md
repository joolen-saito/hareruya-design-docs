- 出典: 0208 カード一覧(検索入力) / 機能仕様 カード名リスト作成、現行仕様 業務ロジック カード名リスト作成
- 事前準備: ① 新規ブラウザセッションでm1401_adminとしてログインし、検索保持値がない（S-M14-01-ADM）／② コードStのスタンダードとコードMoのモダンが登録済みである（S-M14-01-MASTER）／③ 開始時にcardNameList.json・cardNameList_St.json・cardNameList_Mo.jsonが存在し、内容がいずれも [M1401-CB101-OLD] である（S-M14-01-LISTFILES）／④ ID 〔カードID-M1401-101X〕はモダンだけに所属しスタンダードには所属せず、カード名(日)が「カード名リスト試験M1401-CB101-X」でカード名(英)がM1401-CB101-X、ID 〔カードID-M1401-101Y〕はスタンダードだけに所属しカード名(日)が「カード名リスト試験M1401-CB101-Y」でカード名(英)がM1401-CB101-Yである（登録時に振られたカードIDを控えてある）（S-M14-01-CBLIST-101）
- 手順: 1. カード検索（一覧・条件抽出）画面を開く／2. カード名リスト作成を押す／3. 確認モーダルの「実行」を押す／4. ユーザーデータの公開パス配下の /list/cardNameList.json と /list/cardNameList_St.json をブラウザで開く
- 期待結果: cardNameList.jsonはM1401-CB101-XとM1401-CB101-Yを含みM1401-CB101-OLDを含まない配列であり、cardNameList_St.jsonはM1401-CB101-Yを含みM1401-CB101-XとM1401-CB101-OLDを含まない配列であること
