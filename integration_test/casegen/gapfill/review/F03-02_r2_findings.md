### 指摘（F03-02 / IT-F03-02-083）
- 主張: 判定IDをIT-0107とし、「NMが2点だけカートに入り、商品数0のEXがカートに入っていない」とする。
- 実際: 0303_sheet-4 L0149は「商品数が1以上の商品が状態ごとに全てカートに入る」、L0195-L0196は選択数量分を状態ごとに追加すると定める。IT-0107は非表示側だけの判定単位であり、NMの追加成功は受けない。
- 判定: 判定IDの誤り
- 修正案: G1682の未確認部分である「数量0のEXが追加されないこと」だけを期待結果にする。NMの追加成功は既存IT-F03-02-018で確認済みとして分離する。

### 指摘（F03-02 / IT-F03-02-088）
- 主張: IT-0107で「価格99円のNMは表示され、価格99円のEXは表示されない」とする。
- 実際: 0303_sheet-4 L0177-L0178は「NMは価格に関わらず必ず表示」「NM以外は価格が100円以上の場合のみ表示」と、表示側と非表示側を別々に定める。IT-0107は非表示側の判定単位である。
- 判定: 判定IDの誤り
- 修正案: 本ケースは価格99円のEXが表示されないことだけに絞る。NMの表示はIT-F03-02-089で確認できるため、同じケースへ混在させない。

### 指摘（F03-02 / IT-F03-02-107・108）
- 主張: IT-0107で、それぞれ「デッキが4件／3件表示され、もっと見るリンクが表示されない」とする。
- 実際: 0303_sheet-4 L0339は「PC版で4件、SP版で3件表示し、それ以上ある場合はもっと見るリンクを表示する」と定める。IT-0107が受けるのはリンクの非表示であり、件数表示は別の期待結果である。
- 判定: 判定IDの誤り
- 修正案: 各ケースの期待結果を「もっと見るリンクが表示されないこと」に限定する。4件／3件の表示確認は既存IT-F03-02-065・066と重ねない。

### 指摘（F03-02 / IT-F03-02-109・110）
- 主張: 通知ボタンを押した直後に、背後のボタン表示が切り替わることを確認する手順になっている。
- 実際: 0303_sheet-9 L0058-L0059・L0074-L0078は依頼時に入荷通知完了モーダルを表示し、L0088-L0089にその閉じる操作を定める。取消側もL0102-L0103でモーダルを表示し、L0108-L0109に閉じる操作を定める。
- 判定: 成立しない前提・手順
- 修正案: 依頼後は「OK(入荷通知依頼完了)」、取消後は「OK(入荷通知キャンセル完了)」で完了モーダルを閉じてから、ボタン表示を確認する。
