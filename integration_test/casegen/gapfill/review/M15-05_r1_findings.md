### 指摘（M15-05 / IT-M15-05-127）

- 主張: トークンを別の文字列へ書き換えることで「セッション切れ」を作り、タイムアウトメッセージと一覧遷移を期待している。
- 実際: `0212_sheet-5` L0255は「削除時のなりすまし対策トークンが無効」の処理を「アクセスを拒否する」と定め、L0272は「セッションの有効期限が切れているとき」に限ってタイムアウトメッセージと一覧遷移を定める。
- 判定: 期待結果の誤り
- 修正案: L0272を確認するなら実際にセッションを期限切れにする。トークン改変を続ける場合はL0272のケースにはならない。

### 指摘（M15-05 / IT-M15-05-128）

- 主張: 複製保存用トークンの改変を「セッション切れと同じ状態」としている。
- 実際: `0212_sheet-5` L0276は「デッキを複製するとき、セッションの有効期限が切れているとき」にタイムアウトメッセージを表示して編集画面へ遷移すると定める。トークン改変を同条件とする記述はない。
- 判定: 抜けを確かめていない
- 修正案: セッションそのものを期限切れにして複製保存する手順へ直す。準備方法を特定できなければ「未確定」として残す。

### 指摘（M15-05 / G1379）

- 主張: 「どの異常が該当するか設計書に無い」ためケースにしない。
- 実際: `0212_sheet-5` L0274は「デッキの削除中にエラーが起きたとき」に「削除に失敗しました」を表示し、デッキ編集画面へ遷移すると一意に定める。
- 判定: ケースにできる
- 修正案: 削除中エラーを発生させる試験基盤を「未確定」としてケース化する。少なくとも編集画面への遷移は結合テストで確認できる。

### 指摘（M15-05 / G1381）

- 主張: 複製元が削除済みなら戻り先と404が食い違い、保存中エラーの発生方法も不明なのでケースにしない。
- 実際: `0212_sheet-5` L0278は「デッキの複製を保存中にエラーが起きたとき」に保存失敗を表示し、デッキ編集画面へ遷移すると定める。複製元を削除することは条件に含まれない。
- 判定: ケースにできる
- 修正案: 複製元を残したまま保存中エラーを起こすケースにする。エラー注入方法は「未確定」としてよい。
