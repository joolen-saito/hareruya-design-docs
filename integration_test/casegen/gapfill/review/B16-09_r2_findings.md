### 指摘（B16-09 / IT-B16-09-089）

- 主張: IT-0225で、前回と同じ内容ならS3のファイルバージョンが増えないことを確認する。
- 実際: 0416_sheet-11 L0038は「差異がある場合はS3にアップロードする」と分岐を定める。一方、この機能はL0018・L0030のとおりサイトマップを作成してアップロードする更新機能であり、IT-0225の適用対象である参照のみの機能ではない。
- 判定: 判定IDの誤り
- 修正案: 条件付きのアップロード抑止を直接受ける判定単位がないため、IT-0156へ付け替える。

### 指摘（B16-09 / IT-B16-09-091）

- 主張: IT-0071で、カテゴリの掲載に更新頻度「毎日」が付くことを確認する。
- 実際: 0416_sheet-11 L0065は更新頻度を固定値「毎日」と定める。IT-0071が受けるのは出力値と取得元の値との同値確認であり、本ケースには比較する取得元データがない。
- 判定: 判定IDの誤り
- 修正案: 固定された出力内容を直接受ける判定単位がないため、IT-0156へ付け替える。

### 指摘（B16-09 / IT-B16-09-093）

- 主張: IT-0071の1ケースで、URLへの言語区分の引継ぎと、遷移先の商品一覧が当該カテゴリで絞られることを確認する。
- 実際: 0416_sheet-11 L0055の「各URLにも言語区分を引き継ぐ」と、L0078の「そのカテゴリで絞った商品一覧のURL」は別の定めである。前者はURLの受渡しだが、後者は検索対象商品の選択であり、IT-0071だけでは受けられない。
- 判定: 判定IDの誤り
- 修正案: 言語区分を含むURLの確認と、URLを開いた際のカテゴリ絞込み結果を分ける。後者は検索条件に一致する商品を取得するIT-0005へ割り当てる。
