L0001	# API 店頭買取管理 — 商品IDリストから買取用商品情報を取得
L0002	## 業務ロジック
L0003	### 取得対象
L0004	カンマ区切りの商品IDリストを受け取り、カンマで分解した商品IDの配列に対応する買取用商品を取得する。商品IDリストが空または未指定のときは、空文字を分解した配列で検索するため結果は0件となる。
L0005	カード商品以外のIDだけで0件になったときも失敗とせず、取得結果を返す。
L0006	### 応答の構成
L0007	応答はカードIDをキーとする階層構造とする。各カードの配下に、カード詳細ID・言語コード・状態コードの順で入れ子にする。該当が0件のときは空配列を返す。
L0008	### 値の取り方
L0009	金額・在庫数量の再計算や丸めは行わない。取得時点の値をそのまま応答へ整形して返す。
L0010	### エラー時の扱い
L0011	| エラー内容 | 処理 |
L0012	|------------|------|
L0013	| 該当が0件（カード商品以外のIDだけを指定したときを含む） | 失敗とせず、空を返す |
L0014	## 入出力
L0015	| 種類 | 内容 |
L0016	|------|------|
L0017	| 入力 | カンマ区切りの商品IDリスト（任意）。未指定のときは検索結果が0件になる |
L0018	| 成功時出力 | HTTP 200。カードIDをキーとする買取用商品情報。0件のときは空配列 |
L0019	| 失敗時出力 | 0件を失敗として扱わないため、専用の失敗ステータスを返さない |
L0020	本APIは参照だけを行い、データを更新しない。
L0021	### 出力: 応答項目
L0022	| フィールド | 型 | 説明 |
L0023	|------------|----|------|
L0024	| カード | object | カードIDをキーとする。0件のときは応答全体が空配列。 |
L0025	| カードの日本語名 | string | カードの日本語名。 |
L0026	| カードの英語名 | string | カードの英語名。 |
L0027	| カード画像のファイル名 | string | カード画像のファイル名。 |
L0028	| カード詳細 | object | カード詳細IDをキーとする。 |
L0029	| カードセットのコード | string | カードセットが未設定のときは値を持たない。 |
L0030	| カードセットの日本語名 | string | カードセットが未設定のときは値を持たない。 |
L0031	| フォイル区分 | boolean | フォイルのときは真、そうでないときは偽。 |
L0032	| カード番号 | string | カード番号。 |
L0033	| プロモーションの日本語名 | string | プロモーションが未設定のときは値を持たない。 |
L0034	| 商品ID | integer | 商品ID。 |
L0035	| 商品の日本語名 | string | 商品の日本語名。 |
L0036	| 商品の英語名 | string | 商品の英語名。 |
L0037	| レアリティのコード | string | レアリティのコード。 |
L0038	| 保管コードの名称 | string | 未設定のときは値を持たない。 |
L0039	| 言語区分 | object | 言語コードをキーとする。 |
L0040	| 状態区分 | object | 状態コードをキーとする。値は商品規格単位の情報。 |
L0041	| 商品規格ID | integer | 商品規格ID。 |
L0042	| 商品コード | string | 商品コード。 |
L0043	| 買取価格 | integer | 未設定のときは値を持たない。 |
L0044	| 販売価格 | string | 販売価格。 |
L0045	| 在庫数 | string | 在庫数。 |
L0046	| 部門ID | integer | 未設定のときは値を持たない。 |
L0047	## 表示メッセージ
L0048	本APIは画面を持たず、応答本文に定型の文言を持たない。
