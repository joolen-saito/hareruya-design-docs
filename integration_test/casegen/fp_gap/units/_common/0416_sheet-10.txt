L0025	・ファイル同期処理スキップ
L0026	同じバッチが同時に起動しないように、ロックファイル有無チェックを行い、存在する場合には処理を終了する。
L0027	存在しない場合には、ロックファイルを作成し、バッチが終了(強制終了・異常終了含む)した場合にファイル削除を行う。
L0028	★S3バケットとEC-CUBE特定ディレクトリの同期処理
L0029	下記S3パスおよびディレクトリおよびファイルの同期処理を行う
L0030	・S3パス : s3://[S3バケット名]/app/template/default → EC-CUBE 同期ディレクトリ : /var/ec-cube/app/template/default
L0031	・S3パス : s3://[S3バケット名]/app/template/user_data → EC-CUBE 同期ディレクトリ : /var/ec-cube/app/template/user_data
L0032	・S3パス : s3://[S3バケット名]/html/user_data → EC-CUBE 同期ディレクトリ : /var/ec-cube/html/user_data
L0033	★S3パス : s3://[S3バケット名]/html/sitemap.xml → EC-CUBE 同期ディレクトリ : /var/ec-cube/html/sitemap.xml
L0034	※カスタマイズ時にサイトマップ同期も当スクリプトに追加
L0035	※S3バケット名は環境設定で指定します
L0036	・同期条件および処理は以下の通り
L0037	・S3内ファイルに新しいファイルがある場合、ファイルダウンロードを行う
L0038	・S3内ファイルと同期ディレクトリ内ファイルの更新タイムスタンプが違っている場合、ファイルダウンロードする(exact-timestampsオプション)
L0039	・S3内にあったファイルが削除された場合、同期ディレクトリ内にあるファイルも削除する(deleteオプション)
L0040	・同期対象のファイルがあった場合、下記の処理を行う
L0041	・同期ログをCloudWatchへ送信
L0042	・ファイル権限の再設定
L0043	・EC-CUBEのキャッシュクリア
L0044	実行トリガー 起動直後・EC2経由の実行(AWS Systems Manager Run Command) 実行タイミング 毎分
