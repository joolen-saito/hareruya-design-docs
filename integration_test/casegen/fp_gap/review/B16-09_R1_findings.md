### 指摘（B16-09 / IT-B16-09-096）
- 主張: 管理画面でページを登録した後、XMLにそのページのURLが「ちょうど1件載る」。
- 実際: Excel由来の L0018 は「トップページからリンクを辿りながらアクセス可能なURLのリストからサイトマップファイルを作成し、S3に…アップロード」と定め、L0028〜L0030 もリンクを辿る手順を記す。事前準備には、登録ページへ到達するリンクもバッチ実行もない。
- 判定: 成立しない前提・手順
- 修正案: ページ登録だけで掲載される期待は外す。優先される Excel 由来の処理に沿って、到達可能なリンクとサイトマップ作成後の確認が成立するケースにする。

### 指摘（B16-09 / IT-B16-09-097）
- 主張: `noindex,nofollow` のページはXMLに載らず、未指定ページだけが載る。
- 実際: Excel由来の L0028〜L0030 はリンク先を収集してサイトマップを作ると定めるが、検索避け指定による除外は定めていない。これを定める L0074 は埋め込みの現行仕様である。
- 判定: 期待結果の誤り
- 修正案: Excel由来の本文より優先度が低い現行仕様だけを根拠に、この掲載差を期待しない。

### 指摘（B16-09 / IT-B16-09-098）
- 主張: 親カテゴリ、表示ランク20の子、表示ランク10の子が連続して載るケースに判定ID IT-0010 を付けた。
- 実際: L0078 は「親の次にその子孫が続く並び」「同じ階層の中は並び順の値の降順」と定める。観点表の IT-0010 は、レコードがある場合に期待したレコードを取得できることを判定する単位であり、出力順の判定ではない。
- 判定: 根拠の誤り
- 修正案: 出力順を確かめる判定IDに直す。

### 指摘（B16-09 / IT-B16-09-103）
- 主張: 旧アドレスからの転送を「301」と期待する。
- 実際: L0093 は「日本語サイトの同名のアドレスへ恒久的に転送する。検索条件は引き継ぐ」と定めるが、HTTPステータスの数値は定めていない。
- 判定: 設計書に無い期待
- 修正案: ステータスを301に固定した期待を外し、恒久的な転送先と検索条件の引き継ぎを確認する。
