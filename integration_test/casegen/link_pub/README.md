# 公開側と管理画面をまたぐ連携ケース（2026-10-15）

依頼者の指摘（2026-10-15）: 結合テストケースに「フロントから注文した情報が管理画面で参照できること」
「管理画面で登録した情報がフロントに反映されること」が抜けている。

調べた結果: 機能間データ連携のケース（`../link/`、IT-0332〜0340）は、公開側→管理画面を注文・会員登録・買取申込の3種に絞り、
注文は2件（支払方法と配送方法だけ）。管理画面→公開側の表示は「既存の IT-0150 の持ち分」として対象から外したまま、
どこでも洗い出していなかった（IT-0150 のケースは8件。在庫→公開側の商品一覧は0件）。

依頼者決定（2026-10-15）:
- 公開側で登録・更新するものは、注文に限らずすべて対象にする
- 注文は、受注の画面に加えて、注文で変わる別機能の管理画面（在庫数・在庫履歴・ポイント履歴・購入実績など）も確かめる
- 管理画面で登録・更新したものが公開側の表示に反映されること（IT-0150）を洗い出す

観点表の変更（`../../viewpoint_canonical/build_canonical.py`）: IT-0332・0333 の対象を「公開側で登録または更新したデータ」へ広げ、
IT-0355「公開側-管理画面 / 関連データ反映」を末尾に足した（既存の判定IDは動かしていない）。

| ファイル | 内容 |
