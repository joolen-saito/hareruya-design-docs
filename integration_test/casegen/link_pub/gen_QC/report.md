## 設計書の不備として報告すべきもの
1. M03-30 は Excel（0204）が「基準価格」列・販売価格＝基準価格の単純更新、機能設計書（現行）が「販売価格」列・割引率や状態別の換算を定めている。本群は刷新（Excel）を採り、換算が絡まない NM 規格・割引率なしで値を作った。M03-31 の既存シードは SP 規格・割引率100%を使うが、本群は設計どおり NM で作った。
2. M03-33 の CSV 形式（0204 セール用高額商品価格変更CSVフォーマット）に買取価格の列が無いのに、機能仕様は「買取価格を、CSVに設定されている買取価格に更新する」と書く。本群は販売価格だけを期待結果にした。
3. F03-01 の「Sale」ラベルの取得元（索引かECCUBEか）、F03-02 の価格の表記（桁区切りと通貨記号は代表価格だけに記述）、F04-01 の販売価格が常に最新の販売価格か登録時の値かが設計書に無い。期待結果は金額の値だけを書いた。
4. M03-31 の機能設計書には、取込成功時の完了メッセージの表がない（他3機能は「登録が完了しました。」）。M03-31 の全ケースの手順5は取込履歴の行で確かめる形にした。
