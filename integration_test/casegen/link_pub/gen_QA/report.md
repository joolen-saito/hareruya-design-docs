## 作らなかった候補・範囲外の連携
- 商品画像（アップロード）→詳細・一覧：1巡目の追加（QA008＝詳細）と2巡目の追加（QA011＝一覧）で解消した
- 商品カテゴリ→パンくず・カテゴリ検索：商品が複数カテゴリを持つ場合の表示選択が設計書にない
- 規格の公開ステータス（公開・非公開・廃止）→商品詳細の状態表示：下流側の記述不足（下記）
- M03-10 の基準価格(NM)→販売価格・商品詳細の価格：M03-10 設計書に販売価格の更新が明記されていない
