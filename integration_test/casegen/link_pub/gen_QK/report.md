## 設計書の不備として報告すべきもの
- 用語の不統一。管理画面は「公開状態」、F07-02 は「表示区分」、F07-01 は「公開状態」。F07-02 の「表示区分が表示」が公開状態の「公開」を指すと明記すべき。QK002 は F07-01 の記述を橋渡しにして、同じ値と扱った。
- 申込状況の名称。M13-07・M13-10 の選択肢は「申込済み」「キャンセル済み」、F06-14 は「申込完了」「キャンセル」。同じマスターの名称なら統一が要る。M13-07 の QK001 は「キャンセル済み」＝「キャンセル」と扱い、申込完了の名称は期待結果に書いていない。
- M13-13 の CSV 項目表は、会場列を必須〇のまま「会場は不要のため削除」と注記している。実装のヘッダに会場は無い。表の行を消すべき。
- F06-14 は、機能一覧では「予約済み大会一覧」、HTML のシート名は「マイイベント・デッキ登録」。
