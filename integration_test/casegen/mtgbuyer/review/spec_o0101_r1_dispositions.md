# O01-01 設計書レビュー1巡目（codex）の裁定

指摘7件。すべて「事実の欠落」で、事実の誤りは無かった。実ソースで確認し、すべて採用した。事実の誤りが0件だったので、設計書のレビューは1巡で閉じる（ケースのレビューで設計書と実ソースの食い違いも見る）。

| 指摘 | 裁定 | 反映 |
| --- | --- | --- |
| 1 | 採用 | 空白だけの検索では商品の検索を呼ばない、検索失敗・0件時のメッセージを追加 |
| 2 | 採用 | カード情報が無い状態の「登録する」は行を足さない |
| 3 | 採用 | 査定途中のデータの読み込み失敗時の扱い |
| 4 | 採用 | 査定表の初期化の確認 |
| 5 | 採用 | 買取成立・経理払い出し待ち・買取キャンセルの確認の文言 |
| 6 | 採用 | まとめた行同士で基準価格・部門が違う場合は先の行の値を送る |
| 7 | 採用 | 身分証の画像の再表示と、32日経過後の削除 |
