### 指摘2（IT-A15-04-011）
- 主張: 「失敗応答に処理結果コードが含まれ、メッセージが『Invalid request parameters』だけ」と一意に断定している。
- 実際: A15-04 sheet.txt 13行目は「メッセージ『Invalid request parameters』だけを返す」とする一方、18行目は「処理結果コードとメッセージ『Invalid request parameters』」とする。処理結果コードの有無について記述が食い違っている。

- 修正案: 処理結果コードが含まれるという断定を外し、両記述に共通するメッセージだけを確認する。食い違いは裁定Jに従ってreport.mdへ記録する。
