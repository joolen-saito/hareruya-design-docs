## ケースにしなかったもの

| 記述 | 理由 |
| --- | --- |
| 範囲外のページ番号（丸めず、総件数1件以上でもHTTP 200で一覧が空） | 裁定待ち。件数があるのに一覧が空になる現行のふるまいで不具合とみられる |
| 1ページあたりの件数を検証せず抽出へ使う | 裁定待ち。検証の欠落 |
| 件数が未指定・空文字・0のとき20件 | 空文字・0を作る入力欄が画面に無く、送る項目名も設計書に無い。未指定の20件は 026 で確認 |
| 総件数を1ページあたりの件数で割って切り上げる計算そのもの | 単体テストへ送った（結果のページ数は 028） |
| 開催日のY/m/d書式、アーキタイプの「日本語名/英語名」連結、見出しの語の「/」連結と参加人数の各形式 | 変換・連結の結果そのもの。単体テストへ送った（045 は条件の語が題名に入ることだけ） |
| 条件を1件も指定しないときの説明文 | 説明文の中身も表示位置も設計書に無く、「組み立てない」を観測できない。題名は 048 でケース化（「クリア」で条件ゼロを作る） |
| 題名の語のうち参加人数の範囲・成績の選択・公開状態の選択 | 語の具体形（人数の示し方、選択肢ごとの語）が設計書に無く、期待値が決まらない。開催日時の期間は「～でつないだ日付」と明記されているので 051〜053 でケース化 |
| キャッシュへの保存をしないこと自体 | キャッシュの保存先・キーが設計書に無く、検索後のキャッシュ状態を観測できない |
| フォーマットに対応する記号 | 記号の値の対応が設計書に書かれていない |
| 表示メッセージ表の見出し・ラベル文言 | 画面表示文言の照合（e2e） |

## 設計書の不備として報告すること

- 説明文の内容が書かれていない（題名の組み立てだけがある）。題名の語のうち期間・人数範囲・成績・公開状態の具体形、キャッシュの保存先も書かれていない。
- 画像なし用の既定画像の名前が書かれていない（040 は「既定画像が表示される」までしか言えない）。
- ページ送りの先頭・末尾ページや「前へ・次へ」の扱いが書かれていない（029 は番号の並びだけを確認）。
- 開催日時の開始が未指定のとき6か月前が条件に加わる（034）は、検索条件の初期値の副作用で、意図の確認が望ましい。
- 要求表が無く、F09-02 の記述に要求IDを振れない。

## 試験環境に要るもの

- 開始前にデッキ・デッキとタグの紐づき・採用カードを全件削除できるDB投入手段。全ケースが「このN件だけ」を期待するため、ケースは順に実行し、同時には実行しない。
- アーキタイプ選択画面に候補を出す条件（006 は投入方法を未確定にした）。
- 開発者ツールでHTTPステータスと画像の参照先を見られるブラウザ（035・038・039）。
- DBでデッキの件数と更新日時を見る手段（046）。管理画面にログインできる管理者（S-F09-02-ADM、047）。
- フォーマットを選択欄で選ぶケース（005・021・033・049）は、そのフォーマットを検索対象の設定を有効にして登録しておく（選択欄は検索対象の設定で絞られる）。
- 004・032・033・034 は実行日を基準にした日付なので、実行日の当日中に流す（表示件数を変えると開始が未指定のとき6か月前が条件に加わるため、032・033 の大会は実行日の30日前にした）。
- 2025/03/10 開催のデッキを検索で見るケースは、6か月前の既定値を「クリア」で空にしてから検索する（047 の更新後の再検索も同じ）。
