## 判定IDの選び方（1巡目の指摘を受けて）

- 区画順・見出し行・空行・カード行は、CSV・帳票の出力項目（IT-0348）や並び順（IT-0349）ではなく、デッキテキストの機能仕様なので IT-0156 に当てた。テキスト経路はファイルではなくJSON本文なので IT-0071・IT-0072・IT-0146 も使わない。
- デッキ種別がユーザーデッキのときに応じないのは、利用者の権限・公開状態による範囲限定ではなく、デッキ種別による機能条件なので IT-0156。
- 観点表に、デッキテキストの構成・並び・見出しを受ける判定単位が無いので IT-0156 を使った。

## ケースにしなかったもの

| 設計書の記述 | 理由 |
| --- | --- |
| 言語の指定が無いときのふるまい | 設計書が「正本コードからは確認できない」としており、期待結果が決まらない |
| アーキタイプが未設定のときのファイル名 | 同上 |
| 分割カードの `/` を ` // ` へ置き換える（テキスト経路） | 書式変換の結果そのもの（裁定F）なので単体テストへ送った（2巡目で032・033を外した） |
| ファイル経路の分割カード（`/` の置き換え） | 同上。置き換えの記述が言語の節（テキスト経路）にしか無く、層判定も単体テスト |
| 統率者とメインボードの間の空行、統率者が無いときの Deck 行 | 設計書に書かれておらず期待結果が決まらない |
| テキスト経路の限定公開 | この経路は表示区分を判定しないため独立した枝が無い（026 で確認） |
| 同じ区画の中のカードの並び順 | 設計書が定めていない。014 は1枚のデッキにし、009 は並びを問わない期待にした |
| ファイル経路の成功時のHTTPステータス | 設計書はファイルを返すとだけ書き、成功時のステータスを定めていない。ファイル経路のケースは添付・内容種別・内容だけを判定する |
| 表示メッセージ | 本機能は画面へ文言を表示しない |

不具合とみられる現行のふるまい（裁定待ち）: 該当なし。

## 設計書の不備として報告すること

- 書き出しの要求先のアドレス、メソッド、入力項目名が書かれていない。ケースは、実在する入口（公開デッキの詳細画面）の要求を開発者ツールで控え、識別子の部分だけを書き換えて開く手順にした。
- テキスト経路のJSONの項目名が書かれていない。
- アリーナで通る名称への対応表の所在が書かれていない。
- 採用カード0件のときの「中身のないテキスト」が、0バイトか空文字列かが書かれていない。
- 「取得先の経路は表示言語を英語にする」（F09-06）の観測のしかたが書かれていない。047 は表示言語を決める値を見る手順にしたが、どの値が英語を示すかは設計書から決まらない。
