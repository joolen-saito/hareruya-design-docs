## 観点表に受ける判定単位が無いので IT-0156 を使ったもの

## ケースにしなかったもの

| 設計書の記述 | 理由 |
| --- | --- |
| エッジ デッキ数が同数のアーキタイプがあるとき（並び順は指定しない） | 並びを指定しないと書かれており、期待結果が決まらない |
| エッジ 使用率を足し合わせたとき（丸めで合計が100%にならない） | 小数点以下2桁への丸めそのものの結果で、単体テストの担当（SCOPE.md） |
| エッジ 検索対象に設定されていないフォーマットの識別子を指定したとき | 「見出しと遷移先に使うフォーマットを画面が解決できない」としか書かれず、結果が決まらない。裁定待ち（下記） |
| 表示メッセージの文言（デッキ数：、使用率：、もっと見る等）の逐語照合 | 画面表示文言の照合はe2e・手動。0件の案内だけは、表示条件を判定する期待結果として引用した |
| 英語表示（英語の見出し、英語名） | 一覧の「アーキタイプ名」は日本語名とだけ書かれ、英語表示のときの値が決まらない |
| キャッシュへの保存（3種類の保存、鍵、保持時間3600秒・60秒）と、画面値が残る・更新される時刻 | 設計書は「保存する」「保持時間」を定めるだけで、画面がどのキャッシュを読み、DB更新がいつ表示へ反映されるかを書いていない。画面から保存や鍵を観測する手段も書かれておらず、期待結果が決まらない（2巡目指摘1で旧024・025を外した） |
| 検索条件の入力欄のうち、初期値・検索の実行・選択肢以外（カード名の+置換、%と_のエスケープ等） | 検索の突き合わせ方はF09-01・F09-02の担当で、画面上だけの入力制限は単体テスト |
| 会員ログインの要否 | この節に認証の定めが無く、期待結果が決まらない（全ケースは未ログインで開く） |
| 「リニューアル後の仕様」の節 | 見出しだけで、廃止・フェーズ2・刷新後の定めが書かれていない |

## 設計書の不備として報告すること

- 「検索対象に設定されていないフォーマットの識別子を指定したとき」は、集計はできるが画面が解決できない、と画面の結果が書かれていない。不具合の可能性があり、設計者の裁定待ち。
- 「表示区分」の公開以外の値（非公開など）の名前が書かれていない。006 では「非公開」とした。
- 「集計期間の開始日」を示す日付の位置が、見出しのどこかが書かれていない（表示メッセージの見出しにも日付の記載が無い）。022 は「見出しに」とだけ書いた。
- 検索条件の入力欄の初期値のうちフォーマットの扱い（空）はF09-01に拠る。F09-03 の画面で現在のフォーマットが選択済みになるかは書かれていない。030 は開催日時（開始）・成績・公開/非公開の3項目の初期値だけを期待結果にした（「ほかの項目が空」は、このメタゲーム一覧で現在のフォーマットが選択済みか不明なため外した）。
- 要求表（F09-03_requirements.tsv）に行が無い。

## 試験環境に要るもの

- 019 の代表カード画像ファイル（F0903-019-A.jpg・F0903-019-B.jpg）をブラウザから取得できる場所へ置く方法が設計書から分からない（シードは「未確定」）。
- 全シードはDB投入。フォーマット・アーキタイプ・デッキ（デッキ種別、表示区分、デッキリストの公開状態、大会の開催日、アーキタイプ代表カード画像）を登録するスクリプトが要る。開催日は実行日からの日数で算出する。
- 017・018 は1000件超のアーキタイプと約2000件のデッキを投入する。
- 画像なし用の既定画像のファイル名が書かれていないため、020 は「アーキタイプの代表カード画像でない既定画像」であることを目視で確かめる。
- 実行日が変わる時刻を跨ぐと期間の境界（011〜013）が崩れるため、日付を跨がない時間帯に実施する。
- 023 はDBでデッキの件数と更新日時を読める環境。
