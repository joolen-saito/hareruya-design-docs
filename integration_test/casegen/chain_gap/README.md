# ケースが無い機能またぎの画面遷移（2026-10-16）

依頼者の指摘（2026-10-16）: 結合テストでは機能をまたぐ連鎖のケースが重要。分布として足りているか。
画面遷移の連鎖表（`../chains.tsv`）で、遷移元と遷移先が別の機能になる208本のうち、186本には連鎖IDを付けたケースがあった。残りの22本を、依頼者の指示「２を進めて」（案3: ケースの無い機能またぎの遷移22本）で調べた。

連鎖表は機械で抜き出したもので、「連鎖IDを付けたケースが無い」ことは「確かめていない」ことと同じではない。そこで連鎖ごとに、作成／既存で確認済み／連鎖ではない／作れない の4つで判定させ、作成と判定した連鎖だけケースにした。
