### 指摘（F07-01 / IT-F07-01-117）
- 主張: 「定番イベント」に公開イベントが表示され、非公開イベントが表示されないことだけを確認する。
- 実際: 設計書 L0385 は「イベントと開催日程のいずれかが非公開のものは、カレンダーにも日付リストにも出さない」と定める。
- 判定: 要因の結果が欠けている
- 修正案: 非公開イベントがカレンダーと日付リストの双方に出ないことを確認する。

### 指摘（F07-03 / IT-F07-03-066）
- 主張: エントリーフラグが真の事前予約欄について、見出し・期間・残り予約数だけを期待する。
- 実際: 設計書 L0201 は、真のとき「事前予約情報の見出しと、事前予約期間・事前予約の参加費を表示する」と定める。
- 判定: 要因の結果が欠けている
- 修正案: 事前予約の参加費を事前準備で値として定め、その表示も確かめる。

### 指摘（F07-03 / IT-F07-03-067）
- 主張: 期限後は「残り予約数」が表示されないと期待する。
- 実際: 設計書 L0226 の表示メッセージ節は、見出し「残り予約数」の表示条件を「エントリーフラグが真のとき」とする。L0201 の現行仕様節は「残り予約数は事前予約の申込期限前のときだけ表示」と記すが、指定された優先順位では表示メッセージ節を採る。
- 判定: 期待結果の誤り
- 修正案: 期限後に「残り予約数」の見出しが消えるという期待を外す。エントリーフラグが真のときに表示する事前予約の参加費も、値を定めて確認する。

### 指摘（F07-04 / IT-F07-04-069）
- 主張: 参加費1000円の主対象を追加対象なしで申し込み、期待結果は「決済中の申込1件と会員の申込選手1件」の作成だけとする。
- 実際: 設計書 L0213 は「無料のときは完了画面用の対象詳細IDを、有料のときは支払番号と金額を返す」と定め、L0222 は「1円以上は支払方法必須」とする。
- 判定: 要因の結果が欠けている
- 修正案: 追加対象なしで確定する合計1000円が、有料申込の結果として受け渡されることを確認する。
