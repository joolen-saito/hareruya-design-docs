### 指摘（M05-11 / IT-M05-11-225）
- 主張: 225・226・227・229・230・232・233・235は在庫の増減を期待結果に書いているが、在庫変動履歴を確認していない。
- 実際: 設計書 L0633 は「在庫変動履歴の登録」の契機を「受注全体の更新で在庫数が変わったとき、キャンセル時の在庫戻し」と定める。
- 判定: 要因の結果が欠けている
- 修正案: 挙げたケースの期待結果に、対象商品の在庫変動履歴が登録されることを加える。

### 指摘（M05-11 / IT-M05-11-257）
- 主張: 257〜272は在庫数の戻しとポイント履歴の削除を確認するが、新たなキャンセル日の登録と在庫変動履歴の登録を確認していない。
- 実際: 設計書 L0119 は「キャンセル日を登録」、L0608〜L0609 はキャンセル日を新たに入れたとき「在庫を戻したことを在庫変動の履歴に残す」と定める。
- 判定: 要因の結果が欠けている
- 修正案: 257〜272の期待結果に、キャンセル日が新たに登録され、対象商品の在庫変動履歴が登録されることを加える。
