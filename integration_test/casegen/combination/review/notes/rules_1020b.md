# 要因表の決まりの直し（2026-10-20 依頼元）

全機能の1波目で、組が膨らむ型が2つ見つかったので、FACTOR_PROMPT.md の「3. 要因どうしを判定する」に足した。

1. **1件の対象を出す・出さない（対象にする・しない）を、複数の条件の「すべて満たす」または「どれか1つで外れる」で決めるとき**（例: 公開・在庫あり・セール期間内・表示フラグ のすべてを満たす商品だけ出す。条件のどれかに当たると処理を行わない）は、条件どうしは「関係しない」にする。結果は出る・出ない（行う・行わない）の2つだけで、条件ごとの外れ方は1つずつ確かめれば足りる（7条件を効き合うにすると128行になる）。
   - 「効き合う」のままでよいのは、選べるものの集まりを2つの定めが別々に絞り、結果がその共通部分になるとき（選択肢の中身が組ごとに変わる）。
2. **優先順位で順に比べて決めるとき**（1つ目で決まらなければ2つ目…）は、比べる項目を別々の要因にして全組合せにしない。「どの段で決まるか」を1つの要因にまとめる（値: 1段目で決まる｜2段目で決まる｜…｜全段が同じ）。

書き終えた機能も、この2つに当たる所があれば直して gate を流し直す。要因ID・値を振り直してよい（まだケースを書いていないので）。
