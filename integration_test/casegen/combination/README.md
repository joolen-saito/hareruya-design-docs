抜けた理由は、10/15 のデータパターン監査（`../datapattern/`）の作り方にある。
1. 設計書の定めを1件ずつ見て、分かれ目ごとに代表の値を1つ選んで通した。別々に書かれた定めが1回の処理で同時に効く組合せは出てこない。

3. 1機能ごとにその機能の設計書だけを読んだので、他の機能の設定値が効く組合せは対象に入らなかった。
