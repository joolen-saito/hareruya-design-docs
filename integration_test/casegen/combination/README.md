### 道具の宿題（直しの担当が挙げた）

- 処理が途中で打ち切られる値（認証失敗・エラーで戻るなど）では、後ろの要因の値は結果に効かない。今は全要因に値が要るので、打ち切り側の値と他の要因の組が中身の薄い行になる。「効かない（どの値でもよい）」を書ける制約の種別があるとよい。
- 「すべて満たすときだけ効く」条件を関係しないに分けると、2要因の組は全部出るが「全部そろった1組」が出る保証は無い。「この値の組は必ず1行」と書ける種別があるとよい。
- 担当で扱いが割れた型: 「処理が行われない」型（効き合う）と「どれか1つで外れる」型（関係しない）。CSV出力で列ごとに独立して決まる空欄・変換を処理にするか。結果が同じ値をまとめるとき、設計書が別々に書く除外条件までまとめるか。

### 割れた型の決定（2026-10-20、3回目の AskUserQuestion）

ケースは「割れた型を決めてから全部書く」、要因表は「ブランチにコミット」（eddb12cb）と決まった。割れた型は推奨どおり次のとおり。

| 型 | 決定 | 入れた所 |
| --- | --- | --- |
| 処理が打ち切られる値（非公開で出ない、エラーで戻る、廃止済みで何も変わらない など）とほかの要因の値の組 | 打ち切り側は1回でよい | constraints の種別 `打ち切り`。gen_combos は条件そのものを1行で通し、ほかの要因との組は埋めない。その行のほかの要因は「（効かない）」。ふつうの行では打ち切りの条件をつくらない。打ち切りの行はほかの要因の組を埋めた数に入れないので、行が増える機能もある |
| 出力の列・表示項目ごとに独立して決まる値（CSV の空欄・書式・文言の変換） | 組にしない | 要因にしない（ほかの要因と効き合うときだけ要因） |
| 設計書が別々に書いた条件でも結果が同じ値 | まとめる | 1値にまとめる（条件を1つずつ通すのはデータパターンのケース） |
