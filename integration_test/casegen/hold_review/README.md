## 作業中に見つかったこと

1. **`casegen/verify_cases.py` の `sources()` に不具合があった（2026-09-28 修正済み）。** ブックの最後のシートを空で切り出す（`h[m.start(): m.end() + (n.start() if n else 0)]`。次のシートが無いと長さ0になる）。
   ケース生成時の出典突合（値不一致・引用不一致）は、少なくとも20機能で空の出典と突き合わせていた。今回の抽出（`method/srcdiff_lib.py`）では修正済み
2. **保留ケースのうち61件は、機能とシートの対応表（`functions/function-sheet-map.tsv`）に無いシートを出典に挙げている。**
   別添資料・隣接画面など（例: M14-05 は sheet-7 だけが対応付けられているが、ケースは sheet-8「カード登録CSV」を引く）。
   生成時のcodexはHTMLを直接読んでいたので問題にならなかったが、機械検査は届いていない。今回は参照シートとして足して判定した
3. **B02-07 の出典に、機能No.が同じ別機能「ユニサーチフィードTSV」のシートが混ざる。** `function-sheet-map.tsv` の対応の誤りの疑い
4. **`IT-M03-45-024` の実行区分が「ブラザ+DB確認」と誤記**（正: ブラウザ+DB確認）
