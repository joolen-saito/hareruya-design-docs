# 現行ソース調査への codex 指摘の検証と反映

codex が現行ソース調査（`S/current/out/cNN.tsv`）をレビューした。指摘を**1件ずつ現行ソースで確かめてから**反映する。
codex は誤指摘も出す。そのまま適用してはならない。調査の規約は `S/current/CURRENT_RULES.md`。

## 手順

1. 指摘ごとに、codex が挙げた file:line と、著者が挙げた file:line の両方を開き、**処理を末端まで**読む（呼び出し元・呼び出し先・設定値・テンプレート）
   - ec-cube-enterprise は現行ではない。読まない
   - 「無しの見落とし」は、codex が示したコードが本当に論点の答えになっているか（別画面・別条件のものでないか）を確かめる
   - 「使えるかの誤り」は、`S/src/<機能ID>.txt` の刷新の指示を読んで確かめる
2. 採否を決める（採用／一部採用／却下）
3. 採用・一部採用したものを `S/current/out/cNN.tsv` の該当行に反映する。指摘の無い行は変えない
4. `python3 S/current/gate_current.py S <cNN...>` を通す
5. 採否の記録を `S/current/review/<グループ>.decisions.tsv` に書く（ヘッダーあり、1指摘1行）

```
論点ID	codex判定	採否	理由	反映内容
```

- `理由`: 採否の根拠を1〜2文。却下なら、なぜ指摘が当たらないかを現行ソースの file:line で示す
- `反映内容`: 変えた列と、変更前→変更後の要点。却下なら `—`

最後に、採用・一部採用・却下の件数と、判断に迷ったものを短く報告すること。
