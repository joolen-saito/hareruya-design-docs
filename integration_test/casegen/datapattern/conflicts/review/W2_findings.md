### 指摘（C28b / IT-M03-27-066）
- 主張: 「IT-M03-27-026〜029 を保留へ外す」。066はケース一覧に残っている。
- 実際: prov/M03-27.tsv の Excel L0197 は「1: 非公開」、埋め込み L0127 は「非公開または廃止のときは店舗連携フラグを無効にする」。066の事前準備はCSVの「商品公開ステータス1」「スマレジ連携フラグ1」、期待結果列はスマレジへの商品登録を求める。値1を非公開と読む側では、その期待結果が成り立たない。
- 判定: 外し漏れ
- 修正案: 066も公開ステータスの値の裁定対象に含め、値が決まるまで保留へ外す。QD-M03-27-01の影響ケースにも加える。

### 指摘（C29 / IT-M04-18-011）
- 主張: 「MSG-001（0件は出力しない）を採る。IT-M04-18-011 は直し不要」。
- 実際: prov/M04-18.tsv の埋め込み L0077 は「出力対象は該当する在庫変動履歴の全件」「画面の入力項目は持たない」とし、L0094 は出力対象が無い場合の非出力を定める。011の事前準備には検索に該当する履歴が1件あり、手順では開発者ツールで `ids[]` のhidden入力を削除するだけである。この操作で出力対象が0件になるという記述は原文に無い。
- 判定: 直しの誤り
- 修正案: 0件になることを確認できる手順・事前準備に直す。現行の手順を残すなら、0件時の期待結果を検証するケースとは扱わない。

### 指摘（C34 / IT-M05-22-003）

### 指摘（C39-2 / IT-M09-07-029・031・033）
- 主張: 「029・031・033・034 はどちらでも結果が同じなので残す」。
- 実際: prov/M09-07.tsv の Excel L0129 は「ファイル名を変更して更新する場合」を記す一方、L0139 は「管理画面ではあとから変更できません」と記す。同じ食い違いを理由に030は保留となった。残した029・031・033も、手順列で編集中のブロックのファイル名を空にする、256文字を入力する、または別のファイル名へ変更する操作を要求しており、変更できない側では手順を実行できない。
