## 設計書の不備として報告すべきもの

- M08-03：機能設計書は会員検索の保持条件で出力対象を決めるとし、0207 の HTML 設計書（会員検索一覧(検索結果)）は「CSV出力にチェックした会員」を対象とする。拡張項目「ポイント: 当該会員の保有ポイント」を含めてどちらが正か未確定。
- 上流 B08-05 は更新先を「会員データの現在のポイント」と「プレイヤーデータのポイント残高」と書き分けており、同じ値であることが設計書上は明記されていない。ケースでは両者を同じ選手情報の残高として扱った。
