# M14-03 連携ケース報告

## 上流の分類
M14-03（カード管理 一括削除）は **どちらにも当たらない**（マスタ・設定のいずれでもない）。カードは個別データの削除であり、複数機能が選んで使う分類・区分の登録簿でも、動作を決める設定値でもない。IT-0335〜0337 は 0 件。
