## 設計書の不備として報告すべきもの
1. 0202 在庫履歴検索一覧(検索結果) 識別ID 2-8 登録元の項目一覧に「買取自動入庫バッチ」が無い。0406 は登録元機能を「買取自動入庫バッチ」と定め、0202 別添資料の履歴登録元一覧（:15088付近）には有る。登録元の表示を期待結果に入れられなかった。
2. 同 識別ID 2-9 登録元ID は、登録元が「店頭買取」のとき買取番号を表示するとあるが、0406 は店頭買取の登録元IDを査定IDとしている。どちらを指すか不明で、登録元IDを期待結果に入れられなかった。
3. 0202 在庫履歴検索一覧(検索結果) の機能仕様 2-1 の追加項目一覧の識別ID（2-12 在庫増減数、2-13 変更時販売価格 等）と、画面項目定義の識別ID（2-12 在庫増減数、2-13 在庫変動理由区分、2-15 変更時販売価格）が食い違う。画面項目定義の識別IDを用いた。
4. 0202 別添資料の履歴登録例（シナリオ②）は文中で「成田店」を例にしながら、表の在庫区分が「TC東京EC」になっている（:8910・:8926〜8942）。
5. 同シナリオ②は、ネット買取の在庫変動理由を「専用の文言」とするが、文言が設計書に無い。在庫変動理由は期待結果に入れていない。
