# M10-08 連携ケース報告

作成したケース数: 0件

## 上流の分類
M10-08（自動送信メールテンプレート編集）は、既存の自動送信メールテンプレートの名称・件名・本文ヘッダ/フッタを更新するだけの機能。新規作成・削除はしない（M10-08 機能設計書 業務ロジック／入出力: 永続化）。マスタの登録簿そのものの管理ではなく、IT-0337の「動作を決める設定値」にも当たらない。区分: 中間（マスタの行の内容編集）。

## 判定IDごとの評価表
| 判定ID | 下流 | 評価 |
| --- | --- | --- |
| IT-0335/0336 | M05-06 | 不採用。選択肢は「ショップ設定＞メール管理で作成されているテンプレート一覧」(0203 sheet-9)。メール管理(M10-09)の一覧は自動送信メール以外が対象(m10-09機能設計書)。自動送信テンプレートが選択肢に入る記述なし |

## 対応表・重複の確認・到達可能性表
採用ケースが無いため該当なし。

## 範囲外だが価値のある連携
- M10-08で自動送信テンプレートの件名を変更 → M08-07「通知メール」欄は送信に用いたテンプレートの件名を表示（m08-07 入出力: 一覧の表示内容）。ただし一覧の表示内容であり選択肢ではないため、IT-0335/0336の範囲外。近い既存判定は一覧表示系（IT-0332/0333系）。履歴を作る自動送信の発生元が別機能で、上流操作→履歴生成→M08-07確認は経路が長い
- M10-08で保存した本文ヘッダ/フッタ → 自動送信メール本文への反映（メール出力のため下流にできない）

## 作らなかった候補と理由
上の評価表のとおり。下流候補5件はいずれも「自動送信メールテンプレートが下流の選択肢になる」と設計書から言えない（M07-04・M08-08は除外と明記）。

## 設計書の不備
- M05-06・M05-15・M08-07 は、選択肢に自動送信メールテンプレートが含まれるか否かを明記していない（M07-04・M08-08は明記）。
