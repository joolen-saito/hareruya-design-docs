# M14-05 連携ケース報告

**上流の分類: マスタでも設定値でもない（個別データ）。** M14-05 はカードCSVの取込で、カード（カード詳細・画像・各種紐付け）の個別データを登録・更新する。カードタイプ・カラー・カードセット・フォーマット等のマスタは「参照先」であり、不足は取込エラーになる（機能設計書「エラー時の扱い」「列ごとの取り込み方」）。マスタ・設定値を登録・更新・削除する操作は無い。よって IT-0335〜0337 は範囲外。

## 作らなかった候補と理由
- F05-02/F05-04（買取検索・詳細）: 買取商品の検索・詳細で、カード名候補は M14-01 のカード名リスト作成バッチ産物（バッチ→参照画面、IT-0334）。M14-05 が直接渡す記述なし。
- M03-01〜04, M03-23, M04-30/33/34: カード取込データが選択肢・設定として使われる記述が設計書に無い（CSV出力・PDFは下流にできない）。
- M14-01/M14-04: 個別データの表示確認でマスタ・設定値でない。
- M14-02/M14-03/M14-07: CSV出力・一括削除・画像ダウンロードで下流が画面でない。
- M14-08（カードセット編集）: カードセットはマスタだが取込は参照のみで登録しない。

### 書かなかったものと理由
- M14-05 → M14-01（カード検索）: 上流の設計書（M14-05 業務ロジック「取り込みの確定」「列ごとの取り込み方」）はカードの登録・更新を定める。一方 M14-01 の設計書（初期表示・検索条件・並び順・カード名リスト作成）に、一覧の表示対象を M14-05 の取込データとする記述が無い。0208 ブックの「カード一覧(検索入力)」「カード一覧(検索結果)」にも取得元の定めは無い。IT-0340 の「下流の設計書がそのデータを取得元とすると定めていること」を満たさない。
- M14-05 → M14-04（カード編集）: 同様に、M14-04 の「フォームの初期表示」は「パスで指定したカードIDのカードの内容」とあるだけで、取込を取得元とする記述が無い。カードという同一の実体を別画面で開くだけで、取込データを受け渡す定めとは言えない（推測でつなげない）。
- 「画像削除はカードCSV登録で実施する」（0208 ブック カスタマイズ要件）: 上流 M14-05 の業務ロジックに画像を削除する規則が無く、削除後の M14-04 画像一覧の期待結果を設計書の範囲で書けない。

### 設計書の不備
M14-05 のカスタマイズ要件に「画像削除はカードCSV登録で実施する」とあるが、M14-05 の業務ロジックに画像削除の規則が無い（画像URL列は既存画像を探して更新する記述のみ）。
