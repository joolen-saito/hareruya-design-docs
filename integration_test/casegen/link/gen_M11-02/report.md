# M11-02 連携ケース報告

## 上流の分類
M11-02（メンバー管理 編集）は、メンバー(管理アカウント)1件の登録・編集を行う個別データ機能。マスタでも設定値でもない（neither）。
所属・権限は他機能のマスタを「選ぶ側」(下流側)であり、デフォルト検索表示店舗・編集可能店舗・自動ログアウトはメンバー個別の属性。範囲表により「個別データ1件の編集／マスタとの紐づけの更新」には IT-0335〜0337 を当てない。

作成ケース数: 0

## 範囲外だが価値のある連携
- M11-02で登録したメンバーの「デフォルト検索表示店舗」→店舗絞り込みのある検索一覧の初期絞り込み(要求R010)。個別データの属性が別機能の初期値になる連携。近い既存判定: IT-0337相当だが範囲外。
- 「編集可能店舗」→在庫・受注・店頭買取・イベントの編集可否(要求R014)。個別データ紐づけの更新であり範囲外。
- M11-01(メンバー一覧)で登録メンバーを確認する連携: 一覧・詳細の判定(IT-0332/0333系)の領分。

## 作らなかった候補と理由
- 所属セレクト(所属マスタ)の選択肢: マスタを登録するのはM11-02ではなく所属マスタ側。M11-02を上流にできない(M11-02は下流)。
- 権限(ロール)選択肢: 上記のとおりM11-03が上流。
