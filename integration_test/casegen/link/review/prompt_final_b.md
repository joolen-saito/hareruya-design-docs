## 検証してほしいこと

### 1. 判定単位の範囲に収まっているか

`GEN_LINK_PROMPT_TEMPLATE.md` の「判定IDごとの範囲」に照らし、1件ずつ判定せよ。特に次を見よ。

  また L002 は下流がメール配信履歴（過去に送ったメールの履歴）である。テンプレートの件名編集がそこに出るという対応は設計書から言えるか。

- M16-07: 買取価格対応表は「設定値」か「マスタ」か「個別データ」か。一括編集側は「買取価格マスタ」、編集側は「買取価格対応表」と呼び、同じデータと明記した文が無いと著者が報告している。

### 4. 0件にした機能の取りこぼし（重点）

台帳の方向が「マスタ・設定→利用側」の58機能のうち、ケースがあるのは約20機能である。
下流候補は共有する表から機械的に引いたもので抜けがある（実例: M14-08 は候補にナビが無く0件になり、指摘して4件になった）。
次の機能は著者が「マスタ」または「設定」と判定しながら0件にした。`gen_<機能ID>/report.md` を読み、設計書の両側に記述があるのに落としている連携があれば、上流と下流の file:line とケースの骨子を示せ。

- M11-02 メンバー管理（著者は下流の設計書を開かずに0件とした。メンバーが他機能の担当者などの選択肢になっていないか。権限・所属・編集可能店舗の設定が他機能に効く記述は無いか）
- M16-03 祝日の追加・削除（著者は「選択肢にも設定値にも当たらない」とした。祝日の登録でイベント日程の祝日フラグが連動する、イベント大会TOPの日付の表示が変わる、という記述が設計書にあると報告している。IT-0337 で受けられないか）
- M10-11 受注対応状況設定、M10-12 定休日カレンダー設定、M10-07 税率設定、M15-07 デッキタグ管理、M10-02 特定商取引法の表記、M10-10 CSV出力項目設定、M13-14 バナー設定、M10-08 メール設定
- そのほか、範囲表の「マスタ」に当たるのに台帳に上流として載っていない機能（選択肢の出どころになる登録画面）があれば挙げよ。
  例として、商品カテゴリ、タグ、購入グループ、会場、イベント種別、部署・所属など。`functions/` と `excel_to_html/output/` を検索して確かめよ。

件数を増やすための指摘はするな。設計書に下流側の記述が無いものは「設計書の記述不足」として分けて挙げよ。
