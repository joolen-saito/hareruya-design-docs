# M14-07 連携ケース報告

## 上流機能の分類
M14-07（収録カード画像ZIPダウンロード セット別／言語別）は、マスタの登録・更新・削除も設定値の変更も扱わない（neither）。
操作はカード画像のZIP取得と、カード画像のデッドリンク（画像保存の成否）の更新のみ（機能設計書 業務ロジック「デッドリンクの更新」）。
よって IT-0335〜0337 は0件。
