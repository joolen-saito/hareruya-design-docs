# M11-04 連携ケース報告

## 上流機能の分類
M11-04（管理画面_ログイン履歴）は、ログイン履歴の検索・一覧表示だけを行う参照画面であり、マスタでも設定値でもない（neither）。
登録・更新・削除する対象を持たないため、IT-0335〜0337 は0件。

作成したケース数: 0

## 判定IDごとの評価表
| 判定ID | 下流候補 | 評価 |
| --- | --- | --- |
| IT-0335 | M01-01 | 不採用。M11-04は参照のみでマスタを登録・更新しない。M01-01は管理ログイン画面で、選択肢を持たない |
| IT-0336 | M01-01 | 不採用。同上。削除操作が無い |
| IT-0337 | M01-01 | 不採用。M11-04に変更できる設定値が無い。M01-01の挙動を切り替える設定を本機能は持たない |

## 作らなかった候補と理由
- M01-01 のログイン成功・失敗がM11-04に履歴として残る連携（M01-01機能設計書 26・30行）は、上流が公開側/業務操作（ログイン）であり、方向が逆（M01-01→M11-04）。マスタ・設定→利用側の範囲外。
- 表示件数マスタ: M11-04は「表示件数マスタの値と一致するときだけ採用」と参照する側であり、マスタの登録元ではない。

## 範囲外だが価値のある連携
| 上流→下流 | 近い判定ID |
| --- | --- |
| M01-01 のログイン成功/失敗 → M11-04 の履歴一覧（ID・ログインID・IPアドレス・ログイン試行日時・成功失敗区分） | IT-0332系（管理画面の一覧への反映）に近いが上流が公開側操作でなく範囲外。別の判定IDで検討する価値あり |
