# B16-09 サイトマップ生成処理 ケース作成レポート

根拠は 0416 サイトマップ生成処理 のみ（機能一覧・機能設計書なし。別シートは使っていない）。ケース11件、シード12件（共有1・ケース専用11）。
出力項目の構成・並びを受ける対象（IT-0348/0349）は無い。

## ケースにしなかったもの
| 要求ID | 理由 |
| --- | --- |
| R001,R003,R011,R029,R030,R031,R032,R033 | 見出し・空の表の項目名だけで、期待結果になる記述が無い |
| R007〜R010,R012 | 前提条件・利用ツール名（Sitemap-Generator-Crawler）。挙動の記述でない |
| R024〜R026 | pingエンドポイントを含めない。送信先のURLが書かれず（R026は解説記事のURL）、通信が無いことを観測する宛先が一意に決まらない。サービス終了の旨でもある |
| 上記のうち | 出力ファイルの名前・形式・保存先バケット名・保存パス・見出し有無: 書かれていないので IT-0069/0070 は使わない |
| 初回実行（前回のサイトマップが無い場合） | 比較対象が無いときの扱いが書かれていない |
| R023 の差異がない場合 | 「差異がある場合はS3にアップロードする」だけで、差異がないときにアップロードしない・最終更新日時を保つとは書かれていない。旧010は外した |
| 同じURLへの複数リンク・外部ドメインへのリンク・循環リンク | 取得するかどうかが書かれていない |
| 実行失敗・タイムアウトなど | エラーハンドリングの節が空 |

## 設計書の不備として報告すべきもの
- 「入力データ検索条件」「実行結果詳細」「エラーハンドリング」が見出しだけで空（R029〜R033）。
- 出力するサイトマップファイルの名前・形式・保存先バケット名・パスが無い。
- 「前回(昨日)のサイトマップ」の保管場所と、初回実行時の扱いが無い。
- 除外対象の各ページのURL（パス）が無い。「それ以降」の意味が曖昧（ケースは配下かつそのページからのみ辿れる子ページを使い、どちらの解釈でも同じ期待結果にした）。
- バッチ処理用EC2インスタンスで実行されたことの確認方法が無い（011の投入方法を「未確定」とした）。
- 取得するURLの範囲（外部ドメイン、同一URLの重複、リンクの無いページ）が無い。
- 「前回(昨日)のサイトマップ」と比較する仕様のため、同日の連続実行では確かめられない。前日分は事前準備で用意する。
- 実行トリガーの表記が「Eventbridge+Lamdba」（誤記と思われる）。ケースでは「毎日4:00の実行スケジュール」とだけ書いた。

## 試験環境に要るもの（シードの投入方法を「未確定」とした）
- サイトマップ生成バッチの手動実行手段と実行履歴の閲覧、S3バケット名・閲覧権限、前日分ファイルの保存場所（S-B16-09-ENV）。
- 毎日4:00の実行スケジュールの設定と、4:00まで待つ運用（001）。
- トップページに任意のリンクを足し、任意パスの公開ページを作る手段（003〜010。設計書にもeeの調査範囲にも作り方が無い）。
- 設計書のURL（https://www.hareruyamtg.com/）が試験用サイトのトップページを指す状態（URLを試験用サイトへ向ける手段が未確定）。
