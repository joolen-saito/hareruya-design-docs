# B08-07 身分証有効期限切れ通知 ケース作成レポート

対象シート「0408 身分証有効期限切れ通知」。ケース19件、シード23件（共有可4・ケース専用19）。要求IDは REQ-0408-sheet-9-Rxxx の xxx のみ記す。機能一覧と機能設計書が無いため、根拠はシート本文だけ。同じ冊子（0408）の隣接シートにこの機能の記述は無く、根拠にしていない。

- 優先度は 008・016・017 が P2、ほかは P1（019はP1）。実行区分は004・005・006がブラウザ+DB確認（身分証有効期限日のNULLと本人確認ステータスID 0は画面で値を確認できない）、ほかはブラウザのみ。
- 出力項目の構成・並びを受ける判定単位は今回は不要で、IT-0348・IT-0349 は使っていない。
- IT-0156（ITA-02）を使った理由は次のとおり。いずれも観点表に受ける判定単位が無い。
  - 007・008: 項目別の更新有無（簡易書留はステータス不変、対象外は非更新）。
  - 010-012: メール送信元と件名の固定値。
  - 013: 本文の行構成。
  - 016: 通知の前後関係。
  - 017: 該当者なし時の終了。
  - 018: スケジュール起動時刻。
- 日付は「実行日の1年前（切れている）」と「実行日の1年後（切れていない）」だけを使った。2週間の解釈（不備1）に関係なく成否が決まる値である。

## ケースにしなかったもの

| 要求ID | 理由 |
| --- | --- |
| R007,R014,R018 の境界（実行日の14日前・14日後ちょうど等） | 「<= 2週間前の日付」は14日前以前とも読め、「残り2週間を切っております」は14日後以内とも読める。どちらか決まらない（裁定J） |
| 有効期限が未設定(NULL)の会員、ステータスが未確認・確認中の会員の扱い | 対象かどうか書かれていない |
| 更新後のステータスの値 | 取り下げ。R022「0(未設定)」を採り、005でDBの本人確認ステータスIDが0であることを期待にした。R035「未確認」は本文例（レビュー1巡目の指摘1を採用） |
| 会員宛メール本文（R029-R049） | 「本文(例)」で確定文面でない |
| 管理者宛メール本文の会員行の例（R059-R063） | 「11111 テストユーザー」等は値の例で、確定値でない。見出し行「会員ID 氏名」（R057,R058）は本文として明記されているので019で確かめた。R058-R062 は要求表で `現HTML`=無（シートには存在） |

| R012 入力元DB・出力先 | 概説。個別の記述（R021,R025,R053）で確かめた |
| R064,R065 エラーハンドリング「該当処理なし」 | 確かめる動作が無い |
| 2回目の起動（再実行）の結果 | 書かれていない |
| R001-R003,R006,R019,R027,R029,R037-R049,R063 | 見出し・表の枠・本文例・省略記号 |
| 取り消し線・廃止・不要・Ph2 | sheet.txt に該当記述なし |

## 設計書の不備として報告すべきもの

1. 「2週間前」の向き。検索条件は「<= 2週間前の日付」、メールは「残り2週間を切っております」で食い違う。
2. 更新後のステータスは R022「0(未設定)」と R035「未確認」で、同じ状態か不明。ee のマスタに値0は無い（1=未確認）。実装が設計書と違うこと自体は、ケースを変える理由にしていない。
3. 検索条件表に、対象のステータス（オンライン・簡易書留）と、有効期限が未設定の会員の扱いが無い。
4. 管理者宛の宛先が、固定アドレスと設定値の2通りで書かれ、優先が不明。
5. 管理者宛メール本文の「氏名」の組み立てが不明。
6. この機能は機能一覧と機能設計書に無い。起動方法の記述は「スケジュール起動 毎日8:00」だけ。
7. R058-R062 は要求表で `現HTML`=無だが、シートには存在する。要求表に行が無い記述は無かった。

## 試験環境に要るもの

- 018: スケジュール起動を有効にする手段、環境時刻を7:59へ合わせて翌日まで進める手段、バッチ実行記録で開始時刻を開く手段（S-B08-07-SCHED、未確定）。
- 全ケース: 会員ID・本人確認ステータス・身分証有効期限を指定して会員を投入する手段（未確定。フィクスチャ投入機能は固定の初期データを読み込むもので、ケースごとの値を指定できるか特定できていない）。ee の本人確認ステータスは1〜4のみで、設計書の「0」は投入できない。
- 全ケース: メール試験サーバーに各会員のアドレスと it_common@hareruyamtg.com のメールボックス。016 は送信順を保持する送信記録（S-B08-07-SENDLOG、未確定）。
- 管理画面の追加システム設定「身分証の有効期限切れ会員送信メールアドレス」。
- S-B08-07-MAIL と S-B08-07-SCHED は各ケースが開始時に設定し直す。使うケースは順に実行する。
