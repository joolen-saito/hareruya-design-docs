## 決めたこと（`FIX_R1_BRIEF.md`・`FIX_R2_BRIEF.md`）

- 根拠はHTML設計書で、対象シート1枚に限らない。その機能のふるまいが同じ冊子の別シート（一覧画面など）に書かれていれば根拠にする（出典に併記）。
- 観点表の「観点内で確定」の判定単位（参照・出力だけの機能は更新しない、など）は、適用の条件が設計書から言えれば使う。
- CSVの出力項目の構成と並び、初期値、未選択時の扱いなど、受ける判定単位が観点表に無いものは IT-0156（他の観点に割り当たらない機能仕様を受ける区分）に当てた（30件）。観点表に行を足すかは未決。
- 期待結果が設計書から決まらないものはケースにせず（保留ケースは作らない）、report.md に挙げた。
- 作り方が分からない前提は投入方法に「未確定」と書き、`precond/open_preconditions.tsv` に載せた（`merge_into_cases.py` が該当機能の行を作り直す）。
