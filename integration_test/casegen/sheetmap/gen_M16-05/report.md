# M16-05 割引率一覧表示（0213 販売割引率一覧）ケース作成レポート

ケース6件・シード8件（共有2・ケース専用6）。対象シート: 0213 販売割引率一覧。出力は sm_test_cases / sm_seed_data / 本書の3種のみ。

## 対応表（設計書の記述 → 判定ID → テストID）

| 要求ID（REQ-0213-sheet-7-） | 記述 | 判定ID | テストID |
| --- | --- | --- | --- |
| R003, R004〜R009, R011, R014, R017, R019 | 販売割引率の一覧表示／名称とNM・SP・MP・HP販売割引率／登録済みの割引率を保存値のまま表示（丸め・百分率換算なし） | IT-0010 | IT-M16-05-001 |

## ケースにしなかったもの（要求22件中）

| 要求ID | 理由 |
| --- | --- |
| R001, R002, R010, R013, R016 | 「なし」「現行踏襲とする」の定型文と見出し行。確かめる対象が無い |
| R020 | 失敗時は「共通のエラー処理に委ねる」とあるだけで、何を起こすとどう表示されるかが書かれていないため期待結果が決まらない |
| R012（行の並び順） | 並び順の定めが無い（「並べ替えを行わない」とあるだけで順序は不明）。ケースでは順序を期待しない |
| 項目ラベルの表示（R004〜R009 のラベル文言） | 画面表示文言の逐語照合はe2e粒度（SCOPE.md） |
| 権限による可否 | シートに権限の記述が無い |
| 取り消し線・廃止・Ph2 の記述 | シート内に該当なし |

## 設計書の不備として報告すること

- シート本体の「機能No」欄が M16-08 のまま（正しくは M16-05）。「機能名」も販売割引率一覧で、M16-08（買取減額率一覧）の記述の複写とみられる。
- 項目定義の識別ID 2〜5 に「必須」「最大文字数」「初期値」が `-` で、割引率の桁数・小数桁が定められていない。ケースの値は小数2桁以内にとどめた。
- 一覧の行の並び順が定められていない。
- 失敗時（R020）に何が表示されるかが定められていない。
- カード状態の種類（NM・SP・MP・HP の4列）がシート上は項目定義にあるだけで、現行仕様側は「カード状態と割引の組み合わせ」とだけ書かれている。

## 試験環境に要るもの

- 管理者アカウント m1605_admin（データ管理の操作権限）。
- カード状態マスタ NM・SP・MP・HP の4件。
- 販売割引率と組別割引率をDBへ投入・削除できること（投入方法はDBシード。管理画面に登録画面があるかは設計書・ee実装で未確認のためDB投入とした）。「未確定」とした投入方法は無い。
- IT-M16-05-006 のためDBを直接参照できること。
- 各ケースは専用DBで、割引と組別割引率を一度全削除してから投入する前提（他機能の割引データと同居させない）。
