対象シート: 0205 買取商品履歴CSV出力。起動・全件・出力順・ファイル名などのふるまいは同じ冊子の 0205 買取商品履歴(検索入力)・(検索結果) を根拠にした（出典に併記）。ケース15件。

## ケースにしなかったもの

| 対象 | 理由 |
| --- | --- |
| 査定番号・買取店舗・作業者の値（R002,R009,R010） | 取得元の不足。備考が空で、査定ID・店舗名・作業者名のどれを出すかが決まらない（裁定E） |
| 買取数の値（R011） | 取得元の不足。自シートは「変更前在庫から買取数へ表示名称の変更」、検索結果は「買取情報に紐づく明細の数量」と書き食い違うため決めない（裁定J） |
| 申込者「姓 + 半角空白 + 名」（R004）・増減数「変更後在庫-変更前在庫」（R012） | 連結・計算の結果そのものなので単体テストへ送った（裁定F） |
| 選択した履歴だけのCSV出力・未選択エラー | M06-07 の範囲 |
| 見出し行の有無、データの開始行 | 設計書に記述が無く、行はコード・番号で特定した（裁定D） |
| 日時の書式 | 書式の指定が無く、日時の値の一致のみ確認（006） |
| 取り消し線・廃止・Ph2の記述 | 無し |

## 設計書の不備として報告

- `M06-06_requirements.tsv` は13行で、識別ID 11「入庫数」と 14「更新日時」が抜け、以降の識別IDも1つずつずれている。005・006・007 は要求表に行が無い（入庫数・更新日時・非更新）ため、いちばん近い見出し行 R001 を書いた。別シートを根拠にした008〜015の要求IDは sheet-12・sheet-13 の行を書いた。
- requirements_all.tsv の sheet-13 R014 は「査定申込日時の降順」と古い表記のままで、現HTMLは「実在庫履歴の作成日時の降順」（2026/7/21修正）。010は現HTMLに従った。
- 買取数の記述が自シートと検索結果で食い違う（自シート: 変更前在庫からの名称変更、検索結果: 明細の数量）。

## 試験環境に要るもの

- 管理者アカウント（デフォルト検索表示店舗=全店）。
- 買取情報・買取明細・実在庫履歴・商品・会員・店舗・管理画面ユーザのDBシード（ケース専用）。実在庫履歴の作成日時・買取日時を指定して投入できること。008は実在庫履歴12件、010は3つの買取情報、012・013・014は削除済みの商品・規格・作業者。
- 003の「買取時点の基準価格」を保持する項目: 未確定（設計書から分からない。シード投入方法に「未確定」と記載）。
- 「CSVダウンロード」の選択後に押すボタンの有無は設計書に無く、手順は選択してダウンロードすると書いた。
- 015: 検索を実行しないまま全件CSV出力を起動する画面操作は設計書に無く、シード投入方法に「未確定」と記載。
