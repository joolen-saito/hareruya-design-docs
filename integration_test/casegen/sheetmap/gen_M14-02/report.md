## ケースにしなかったもの

| 要求ID・事項 | 理由 |
| --- | --- |
| R001〜R004 | 文書名・作成者・更新日で、動作の記述が無い |
| R056 | 「カスタマイズ要件以外は現行踏襲」の総括で、確かめる出力値が一意に決まらない |
| R068、R075 | 追加・除去の理由の注記で、出力の条件を定めていない（除去自体は001で、除去した2項目に当たる位置が無いことを確かめる） |
| R020、R021の「無色」「緑」「黒」「赤」の英語表記 | 設計書の例は White,Blue のみ |
| 未選択でCSV出力を押したときの扱い | 「カード一覧(検索結果)」が「画面にエラーを表示」と「カードID 1をダウンロードし、遷移またはリロードでエラー表示」の両方を書いており、食い違い。両方に共通する部分だけでは期待結果が決まらないため作らない（裁定J） |
| CSVのファイル名・ヘッダ行の有無・行の並び順・権限 | 設計書のどのシートにも記述が無い |
| 取り消し線・廃止・不要・Ph2の記述 | 該当する記述が無かった |

## 設計書の不備として報告すべきもの

1. CSVのファイル名・ヘッダ行の有無・文字コード・行の並びが書かれていない。ケースは見出し行を前提にせず、事前準備の値が左から何番目に出るかで確かめる。
2. 識別ID 29・32は除去のため欠番になるが、項目定義の表には残っている。出力は35項目として書いた。
3. 使用可能・制限・禁止フォーマットは、フォーマット名が日本語名か英語名か書かれていない。009と001はフォーマット名(日本語)とフォーマット名(英語)を同じ値にして曖昧さを避けた。
4. 固有色の複数値の並び順が書かれていない。006は White,Blue と Blue,White のどちらも合格にした。
5. 固有色・フレーム以外のマスタ参照項目の出力表記は、出力側には書かれていない。「カード登録CSV」の入力が各マスタの英語名（色順は色順名）で、出力は1対1と読み、002で確かめる。
6. Foil「設定値の意味は0:なし 1:通常 2:特殊」は、数値で出すか名称で出すか明記が無い。008は設定値（0・1・2）の出力と読んだ。
7. 要求表 R048 は「Usually」だが、シート本文は「Normal、Special」。本文を採った。
8. 「カード一覧(検索結果)」の未選択時の記述が二重に食い違う（上記）。
9. 識別ID 35 カード詳細IDは「カード登録CSV」で主キーだが、出力が採番値か入力値かの記述が無い。005は登録時に指定した値がそのまま出ると読んだ。

## 試験環境に要るもの

- 管理者 m1402-admin の登録（S-M14-02-ADM）。
- マスタ（レアリティ・レイアウト・カードタイプ・カラー・サブタイプ・特殊タイプ・カードセット・プロモ種別・色順）の登録手段（S-M14-02-MASTER。未確定）。値は各マスタの英語名（色順は色順名）。
- フォーマット登録の必須項目の値（S-M14-02-FORMAT-001・009。未確定）。
- カード登録CSVのフィクスチャ13本（M1402-<ケース番号>-cards.csv。書式はシート「カード登録CSV」）。
- 各ケースの前に、カード名・テキストに「M1402-<ケース番号>」を含むカードが他に無いこと。013は登録カードが全体で1件の専用DB。
