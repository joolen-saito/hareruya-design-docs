# B16-06 現行仕様の仕分け

対象は sheet.txt の「Source:」より後ろ（現行仕様）。要求表には現行仕様の行が無いため、要求ID欄は内容が近い Excel 由来の行の要求IDを書き、出典欄に「現行仕様 <小見出し>」を書いた。

## 業務ロジック 実行前の設定確認

| 現行仕様の文 | 仕分け |
| --- | --- |
| 次の値は設定で与える。省略時の値は持たない（本番クラスタ、サブネットグループ、セキュリティグループ、クラスタのパラメータグループ、データベースの種類、インスタンスの規格、抽出に使うユーザーとデータベース名） | 追加: 015（サブネットグループ未設定=異常終了）・016（データベースの種類未設定=エラーに設定を示す名前）・017（本番クラスタ未設定=一時クラスタの作成記録が無い）・018（インスタンスの規格未設定=後片付けの開始行が無い）。未設定にする設定を4ケースで変えた。ほかの設定も同じ文で決まるため、設定ごとのケースは足さない |

## 結果

現行仕様 約40文のうち、既存で確認済み 5（001・010・012・013・009）、追加 38（015〜052）、直した既存ケース 002・003・004・005・009・010・013、ケースにしない 7（引数・バージョンとポート・取得処理の失敗・並びの不定・クラスタ削除を待たない・アップロード出力の日時・画面なし）。件数は14件から52件。

判定単位の付け方: ERROR 文言と成功時ログの構成は IT-0222（ログから異常理由・件数を追える）、異常終了の状態・一時DBの削除・タブ区切りと見出し行は受ける判定単位が観点表に無いため IT-0156、設定未設定は IT-0159、アップロード失敗は IT-0092、作業場所のファイル削除は IT-0074、文字コードは IT-0311、削除失敗でも正常終了は IT-0167、削除順は IT-0293、複数セキュリティグループと外部公開しないことは IT-0303。
