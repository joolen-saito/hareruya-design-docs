# B08-04 現行仕様の取り込み（Source: b08-04_batch_customer_customer_check_blank_required.md）

| 現行仕様の文 | 仕分け |
| --- | --- |
| 対象の判定「必須項目が空欄である会員の一覧を取り出す。空文字・値なし・未設定のいずれかのときを不備の候補として扱う」 | 未設定は既存001〜003で確認済み。空文字は、検索条件表（各項目「未設定(NULL)」）と食い違うため Excel由来を採りケースにしない（SCOPE.md） |
| 「項目ごとの許容条件は、会員の必須項目の定義に従う」 | ケースにしない（許容条件の中身が書かれていない） |
| 「空欄の判定は会員のデータの現在値だけを見る。画面の入力補正と既定値の付与は行わない」 | 追加=014（IT-0225、バッチ後に空欄が補われていないこと） |
| 「コマンド名が未指定のとき、または一致しないときは処理を行わずに終える」（エラー表の同行を含む） | 追加=016（未指定）・017（不一致）（IT-0156、起動手段は未確定） |
| 「該当する会員が1件でもあるときは、その一覧で管理者へアラートを通知する」 | 既存で確認済み=001〜003,007,011,012。通知手段はExcel由来のメールを採用 |
| 「該当が1件も無いときは通知せずに終える」（エラー表の「何もせずに終える」を含む） | 既存で確認済み=006（出典に現行仕様を追記） |
| 「検出と通知だけを行い、会員情報を補ったり更新したりしない」 | 追加=014 |
| 「取得または送信でエラーが起きた」→「エラーメッセージを出力する」（エラー表・失敗時出力） | ケースにしない（エラーの起こし方、出力先・文言が書かれていない） |
| 入出力「入力: コマンド名」 | 追加=016・017 |
| 入出力「成功時出力: 該当する会員があるときの管理者へのアラート通知」 | 既存で確認済み=007 ほか |
| 「このバッチは外部APIを呼び出さない」 | 追加=015（IT-0225、環境は未確定） |
| 「リニューアル後の仕様」（見出し）／表示メッセージ「画面へ文言を表示しない」 | ケースにしない（見出し・画面が無い） |

食い違い: 現行仕様の「アラート」とExcel由来の「メール送信」は同じ通知としてExcel由来を採った。検索条件表（NULL）と現行仕様（空文字も含む）の食い違い。Excel由来を採りケースにしない（旧014は削除）。既存ケースと矛盾する現行仕様は無し。出典を追記した既存ケース: 006、007。
要求ID: 現行仕様の行は要求表に無いので、近い見出し行（014=R011／015=R014／016・017=R010）を書いた。
