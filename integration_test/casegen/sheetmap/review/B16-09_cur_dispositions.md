# B16-09 現行仕様の仕分け

前提: Excel 由来の本文は「クローラーで巡回して作り、前日と差異があるときだけ S3 へ上げる日次バッチ」。現行仕様は「要求のたびに組み立てて XML で返す画面側の機能」。新システムでは画面側の機能が B16-09 の実装（依頼者確認）。同じ事柄で食い違う文は Excel 由来を採り、ケースにしない。出典は「現行仕様 <小見出し>」と書いた（要求表に現行仕様の行が無いため、要求ID欄は自シート概要の R002 で代えた）。

## codex レビューへの処置

方針の補足: 「方式が Excel 由来と違う」こと自体を突く指摘は不採用（依頼者確認）。012 以降は合流前のため直した。足したのは069〜088、既存の番号は詰めていない。

| 指摘 | 処置 |
| --- | --- |
| 1（031・035・047・067・068 の本店のみ／支店あり） | 反映: 共有シードの状態を「本店の構成。支店は事前準備で支店を追加すると書いたケースだけが追加する」に直し、各支店ケースの事前準備を「本店のほかに支店を追加した状態で」に直した。新しい支店ケース（072相当の支店ページ）も同じ書き方 |
