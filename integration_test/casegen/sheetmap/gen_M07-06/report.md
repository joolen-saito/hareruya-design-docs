# M07-06 買取商品一覧CSV ケース作成報告（レビュー1巡目反映後）

対象: 0206 買取商品一覧CSV出力項目。出力の起動・対象・並びは同じ冊子の「買取一覧(検索結果)」「買取一覧(検索入力)」も根拠にした（裁定A）。ケース14件。
出力項目の構成・並びを受ける判定単位が観点表に無いので IT-0156 を使った（並び順・未選択時の警告も同じ理由で IT-0156）。

## ケースにしなかったもの

| 対象 | 理由 |
| --- | --- |
| R006 買取価格の値照合 | 取得元の不足。備考が空で、申込時の価格か査定後か、個数2以上で単価か小計かが設計書から決まらない（001の第5項目は位置のみ） |
| ファイル名・格納先・文字コード・区切り・見出し行の有無 | 同じ冊子の該当シートに記述が無い（M07-05側の記述は別機能のため根拠にしない） |
| 在庫増減数・買取価格の計算（個数×単価など） | 単体テストへ送った（対象外） |
| 取り消し線・廃止・不要・Ph2の記述 | 対象シートに無し |

## 設計書の不備として報告すべきもの

- 対象シートの機能No欄がM07-05のまま。
- 買取価格の取得元、「状態がない」の定義（買取明細の状態未設定とした）が書かれていない。
- 見出し行の有無・ファイル名が書かれていない。

## 試験環境に要るもの

- 買取情報・個別入力商品・商品規格・買取明細をDBシードで登録できること（管理者はログインIDで登録。投入方法の未確定項目は無し）。
- 011でDBの買取状況・更新日時・在庫数を前後で読めること。

要求IDは、別シートを根拠にしたケースではそのシートの要求IDを書いた（M）。要求表に行が無い記述は無し。
