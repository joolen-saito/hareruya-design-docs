# M06-07 買取商品履歴選択CSV出力 ケース作成報告（R2反映後）

対象シート: 0205 買取商品履歴CSV出力（M06-06と共有）。根拠は同じ冊子の「買取商品履歴(検索結果)」「買取商品履歴(検索入力)」を含む。12件。

## 対応表（設計書の記述 → 判定ID → テストID）

| 設計書の記述 | 判定ID | テストID |
| --- | --- | --- |
| 出力項目の構成と並び、識別ID1〜14（CSV出力シート） | IT-0156 | 001 |
| 買取店舗・作業者・入庫数・買取日時・更新日時の値 | IT-0071 | 002 |
| 基準価格は出力時の基準価格（買取時ではない） | IT-0071 | 003 |
| 買取価格は小計ではなく単価、検索結果の買取価格欄に一致 | IT-0083 | 004 |
| チェックした履歴だけが出力対象（検索結果 項目3・4） | IT-0072 | 005 |
| 1件も選択せず選択CSVを出力したときのエラー（M06-05-MSG-001） | IT-0108 | 006 |
| 削除済みの商品／規格／作業者に紐づく履歴も出力（検索入力 現行仕様） | IT-0072 | 007／008／009 |
| CSVの出力順は買取日時の降順、実在庫履歴作成日時の降順（検索結果 ★CSV出力） | IT-0156 | 010 |
| ファイル名は `otc_buy_order_detail_history_` に出力時刻（年月日時分秒）を付けたCSV | IT-0070 | 011 |
| CSV出力は参照のみで数量・金額・履歴を更新しない | IT-0080 | 012 |

出力項目の構成・並びを受ける判定単位が観点表に無いので IT-0156 を使った（001・010）。

## ケースにしなかったもの

| 対象 | 理由 |
| --- | --- |
| 申込者の「姓 + 半角空白 + 名」、増減数の差の値 | 連結・計算の結果そのものなので単体テストへ送った（001は申込者の位置を姓・名の両方を含む値で確認、増減数の位置は確認しない） |
| 買取数の値と位置（10番目） | 取得元が決まらない。CSV出力シートは「変更前在庫から買取数へ表示名称の変更」、検索結果シートは「買取情報に紐づく明細の数量」で食い違い、共通する部分が無い |
| 検索結果全件取得（M06-06側） | M06-07の範囲外 |
| 権限による可否 | 同じ冊子のどのシートにも記述が無い |
| 廃止・不要・Ph2・取り消し線 | 該当記述なし |
| 日時の書式 | 書式の指定が無く、同じ日時を表すことだけ確認する |

## 設計書の不備として報告すべきもの

- `M06-07_requirements.tsv` は13項目で、入庫数と更新日時の要求IDが無い（要求表に行が無い）。ケースでは最も近い見出し行 R001 で代用した。増減数R012・買取日時R013はシート上の識別ID（12、13）と番号がずれる。
- 買取数の値の定義がCSV出力シートと検索結果シートで食い違う。
- 起動ボタン名の記載が無い。検索結果シート項目3の選択肢「選択した商品履歴取得」で書いた。
- 観点表に、ファイル出力の項目構成・並び順を受ける判定単位が無い。
- `requirements_all.tsv` の検索結果シート REQ-0205-sheet-13-R014 は「査定申込日時の降順」のままで、シート本文の「実在庫履歴の作成日時の降順」と食い違う（要求表が古い。010は本文を採った）。
- 買取日時の取得元は検索結果シート（取引成立日から名称変更）にあり、CSV出力シートには無い。

## 試験環境に要るもの

- 実際に買い取った単価、変更後数量、買取時の基準価格（003）の格納先と、買取履歴（実在庫履歴）の投入手順（S-M06-07-HISTORY-001〜012の投入方法に「未確定」と記載）。
- 管理者に全権限を付与する方法（S-M06-07-ADMに「未確定」）。
- ダウンロードしたCSVの取得・確認手段、ダウンロード時刻の確認手段（011）、DB確認手段（012）。
