L0003	A15-02 ログアウト ／ API デッキビルダー — ログアウト
L0004	業務ロジック
L0005	認証の判定順序
L0006	順序	判定	結果
L0007	1	認証ヘッダのアクセストークンがあり、署名が正当か	欠落または署名が不正なときは認証拒否として返す
L0008	2	トークンの利用者ID（会員ID）に対応するプレイヤーがあるか	無いときは認証拒否として返す
L0009	3	上記を通過	トークンのCookieを空にする
L0010	署名方式はHS256とする。トークンの原値・署名シークレット・パスワードは本書に記載しない。
L0011	認可
L0012	有効なトークンを持つ会員だけがログアウトできる。
L0013	更新しないもの
L0014	会員・注文・ポイントなどの業務データは更新しない。金額・ポイント・在庫などの業務値は計算しない。
L0015	すでに無効な状態に対する要求のふるまいは、既存の認証エラーまたは冪等な成功応答の実装に従う。
L0016	入出力
L0017	種類	内容
L0018	入力	ログイン時に取得したアクセストークン（必須）。リクエストボディの項目は持たない。
L0019	成功時出力	HTTP 200。結果コード200と結果メッセージ。
L0020	失敗時出力	認証拒否のときはHTTP 401と結果コード・結果メッセージ。処理中の例外はデッキビルダーAPIの共通例外処理に委ねる。
L0021	リニューアル後の仕様
L0022	表示メッセージ
L0023	メッセージID	表示位置	画面上の文言	表示条件	後続処理
L0024	—	API応答JSON	Logout success	ログアウトできたとき	トークンのCookieを空にして返す
L0025	—	API応答JSON	Access Token is incorrect	認証ヘッダのアクセストークンが欠落しているとき、または署名が不正なとき	ログアウトせずHTTP 401で返す
L0026	—	API応答JSON	Authentication failed	利用者ID（会員ID）に対応するプレイヤーが存在しないとき	ログアウトせずHTTP 401で返す
