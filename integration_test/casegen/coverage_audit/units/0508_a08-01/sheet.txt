L0003	A08-01 トップバナーIDのトップバナー情報を取得 ／ API データ管理 — トップバナーIDのトップバナー情報を取得
L0004	業務ロジック
L0005	取得対象
L0006	パスで指定されたトップバナーIDに一致するトップバナーを取得対象とする。該当するトップバナーが存在しないときはコード404のJSONを返す。
L0007	応答値
L0008	応答フィールドは取得時点の値をそのまま返す。金額・税・ポイント・在庫数量の再計算や丸めは行わない。表示用の加工や表示制御は呼び出し元クライアントの設計を正とする。
L0009	入出力
L0010	入出力: リクエスト
L0011	パラメータ	位置	型	必須／任意	説明
L0012	id	パス	integer	必須	取得対象のトップバナーID
L0013	入出力: レスポンス（成功）
L0014	HTTP 200。
L0015	フィールド	型	説明
L0016	id	integer	トップバナーID
L0017	imageUrl	string	画像URL
L0018	link	string	リンク先URL
L0019	dispType	integer	表示タイプ
L0020	languages	array	関連する言語の配列。要素はオブジェクトで、子フィールドはid（integer、言語ID）、nameJp（string、言語名・日本語）、nameEn（string、言語名・英語）、code（string、言語コード）
L0021	応答フィールドは上表の5項目だけである。金額・税・ポイント・在庫数量に当たる項目は持たない。
L0022	応答例（実装確認値に基づく代表値）。
L0023	{
L0024	"id": 1,
L0025	"imageUrl": "https://example.com/banner/top_001.png",
L0026	"link": "https://example.com/campaign",
L0027	"dispType": 1,
L0028	"languages": [
L0029	{ "id": 1, "nameJp": "日本語", "nameEn": "Japanese", "code": "ja" }
L0030	]
L0031	}
L0032	入出力: レスポンス（失敗）
L0033	HTTPステータス	条件	本文の形
L0034	404	該当IDのトップバナーが存在しない	{code, message}（"Not Found"）
