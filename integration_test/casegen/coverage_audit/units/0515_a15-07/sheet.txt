L0003	A15-07 アーキタイプ検索 ／ API デッキビルダー — アーキタイプ検索
L0004	業務ロジック
L0005	取得対象
L0006	パスで指定したフォーマットに紐づくアーキタイプを返す。返す値は識別子・日本語名・英語名である。指定したフォーマットがフォーマットマスタに存在しないときは、該当なし（HTTP 404）とする。
L0007	フォーマットが存在し、紐づくアーキタイプが無いときは、HTTP 200・処理結果コード200で、アーキタイプの配列を空の配列として返す。
L0008	認証
L0009	本APIは認証を行わない。認証用トークンのヘッダを参照せず、利用者の照合もしない。認証起因の拒否（HTTP 401）は返さない。呼び出し可能なクライアントはデッキビルダーアプリで、利用者の状態によらず参照できる。
L0010	エラー時の扱い
L0011	エラー内容	処理
L0012	指定フォーマットが存在しない	コード404・メッセージ「The format does not exist」を返す
L0013	取得処理中の例外	共通例外処理に委ねる（HTTP 500相当）
L0014	入出力
L0015	種類	内容
L0016	入力	パスのフォーマット識別子（必須、整数）。フォーマットマスタに存在する識別子を指定する
L0017	成功時出力	HTTP 200。処理結果コードとアーキタイプ配列を含むラッパオブジェクト
L0018	失敗時出力	該当フォーマットが無いときはHTTP 404でコードとメッセージ。取得中の例外は共通例外処理に委ねる
L0019	出力: フィールド
L0020	フィールド	型	説明
L0021	code	integer	処理結果コード。成功時は200。
L0022	archetypes	array	アーキタイプ行の配列。
L0023	archetypes[].id	integer	アーキタイプの識別子。
L0024	archetypes[].name_jp	string	アーキタイプの日本語名。
L0025	archetypes[].name_en	string	アーキタイプの英語名。
L0026	配列要素のキーは id・name_jp・name_en であり、取得時のまま区切り記号付きの小文字で返す。
L0027	成功時の応答例（実装確認値に基づく代表値）。

L0029	"code": 200,
