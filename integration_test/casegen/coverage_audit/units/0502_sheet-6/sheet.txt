L0075	現行仕様
L0076	A02-04 ポップアップ用カード情報取得（旧商品ID） / API 商品管理 — ポップアップ用カード情報取得（旧商品ID）
L0077	業務ロジック
L0078	対象カードの引き当て
L0079	旧商品IDは、カードに登録された旧商品IDと旧英語商品IDの両方と突き合わせ、どちらか一方に一致すれば対象とする。対象になるのは、削除済みでない商品と削除済みでない商品規格に限る。
L0080	カードとの対応を持たない商品、および商品画像を1件も持たない商品は、旧商品IDが一致しても該当なしとして扱う。
L0081	複数一致したときの扱い
L0082	旧商品IDが複数の商品規格に一致した場合でも、返すのは1件だけである。どの1件を返すかを決める優先順は定めておらず、一致したもののうち1件が返る。
L0083	応答値の加工
L0084	金額と在庫数の再計算や丸めは行わず、保持している値をそのまま返す。
L0085	入出力
L0086	出力: 該当データが無いときの応答本文
L0087	該当する商品が無いときの応答本文は、処理結果コードとメッセージ「Not Found」の2項目を持つ。
L0088	リニューアル後の仕様
L0089	表示メッセージ
L0090	メッセージID	表示位置	画面上の文言	表示条件	後続処理
L0091	—	API応答JSON	Not Found	該当する商品規格が無いとき	HTTP 404を返して終了する
