L0003	A15-11 デッキ情報削除 ／ API デッキビルダー — デッキ情報削除
L0004	業務ロジック
L0005	削除の判定順序
L0006	順序	判定	結果
L0007	1	トークンからプレイヤーを特定できるか	できないなら認証拒否（HTTP 401）
L0008	2	デッキIDに該当するデッキがあるか	無ければ該当なし（HTTP 404）
L0009	3	対象デッキの所有者が認証したプレイヤーと一致するか	一致しないなら認証拒否（HTTP 401）
L0010	4	上記を通過	削除日時を設定して論理削除し、処理結果コード200を返す
L0011	論理削除済みのデッキは、デッキIDに該当するデッキとして扱わない。 論理削除済みのデッキIDを再び指定したときは、該当なし（HTTP 404）とし、削除日時を設定し直さない。
L0012	認証と認可
L0013	トークンを検証し、その内容に含まれる顧客IDからプレイヤーを特定する。トークンの欠落・署名不正・該当するプレイヤーなしのいずれのときも認証拒否とする。削除できるのは対象デッキの所有者本人だけで、所有者でないときも認証拒否とする。呼び出し元はデッキビルダーアプリで、トークンの原値と署名の秘密値は本書に記載しない。
L0014	削除の内容
L0015	対象デッキに削除日時を設定して論理削除し、当該デッキの一時保存があれば併せて削除する。この一連の処理は1つのまとまりとして行い、例外が起きたときはすべて取り消して処理失敗（HTTP 500）とする。金額・税・ポイント・在庫数量の再計算は行わない。応答は本APIで集計せず、処理結果をそのまま返す。
L0016	一時保存の保存先は Redis とする。 一時保存のキーは、「deck_」にデッキIDを付けた値（例: deck_123）とする。
L0017	エラー時の扱い
L0018	事象	扱い
L0019	認証できない	認証拒否（HTTP 401）とし、コードとメッセージを返す
L0020	デッキが存在しない	該当なし（HTTP 404）とする
L0021	他人のデッキ	認証拒否（HTTP 401）とする
L0022	削除処理中の例外	処理失敗（HTTP 500）とし、例外の内容をメッセージに含めて返す
L0023	入出力
L0024	種類	内容
L0025	入力	削除対象のデッキID、認証用トークン。ボディの値は持たない
L0026	成功時出力	HTTP 200。処理結果コードとメッセージ
L0027	失敗時出力	HTTP 401（認証不可・所有者不一致）、HTTP 404（デッキなし）、HTTP 500（削除処理中の例外）
L0028	入出力: リクエスト
L0029	パラメータ	位置	型	必須／任意	説明
L0030	id	パス	integer	必須	削除対象のデッキID
L0031	認証トークン	ヘッダ	string	必須	プレイヤーを特定するためのトークン
L0032	入出力: 応答フィールド
L0033	フィールド	型	説明
L0034	code	integer	処理結果コード。成功時は200
L0035	message	string	処理結果メッセージ。成功時は「Deck delete success」
L0036	入出力: 永続化
L0037	操作	契機
L0038	更新	判定をすべて通過したとき、対象デッキに削除日時を設定して論理削除する
L0039	削除	同じ契機で、当該デッキの一時保存があれば削除する
L0040	リニューアル後の仕様
L0041	表示メッセージ
L0042	メッセージID	表示位置	画面上の文言	表示条件	後続処理
L0043	—	APIレスポンス（JSON body・message）	Deck delete success	デッキの削除に成功したとき	HTTP 200を返す
L0044	—	APIレスポンス（JSON body・message）	The deck does not exist	デッキIDに該当するデッキが無いとき	HTTP 404を返し、削除しない
L0045	—	APIレスポンス（JSON body・message）	Access Token is incorrect	トークンの欠落・署名不正・該当するプレイヤーが無いとき	HTTP 401を返し、削除しない
L0046	—	APIレスポンス（JSON body・message）	Authentication failed	対象デッキの所有者でないとき	HTTP 401を返し、削除しない
