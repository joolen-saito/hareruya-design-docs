L0003	A15-04 他ユーザー情報参照 ／ API デッキビルダー — 他ユーザー情報参照
L0004	業務ロジック
L0005	取得できる条件
L0006	クエリにデッキユーザーIDが指定されているときは、この分岐で処理する。デッキユーザーIDに一致するプレイヤーを1件取得する。該当するプレイヤーがないときは入力不正（HTTP 400）とし、メッセージ「Invalid request parameters」を返す。該当が無いときもHTTP 404ではなく入力不正（HTTP 400）で返す。
L0007	認証を行わない分岐
L0008	デッキユーザーIDを指定するときは認証トークンを検証しない。トークンに起因する認証拒否（HTTP 401）は発生しない。デッキユーザーIDを知る呼び出し元であれば、そのプレイヤーの公開向け情報だけを取得できる。公開向け情報はニックネーム・プロフィール・デッキユーザーIDとする。呼び出せるのはデッキビルダーアプリだけである。トークンの原値と署名の秘密値は本書に記載しない。
L0009	値の取り方
L0010	金額・税・ポイント・在庫数量の再計算と丸めを行わない。取得できたときは、その値をそのまま応答へ整形して返す。応答の各項目は取得時点の値とし、未設定のときはnullとする。表示用の加工と表示制御は呼び出し元の設計による。応答本体はラッパオブジェクトで、キーはスネークケースで組み立てる。
L0011	エラー時の扱い
L0012	事象	扱い
L0013	デッキユーザーIDに一致するプレイヤーがないとき	入力不正（HTTP 400）とし、メッセージ「Invalid request parameters」だけを返す
L0014	入出力
L0015	種類	内容
L0016	入力	デッキユーザーID（クエリ、この分岐では必須）。認証トークン（ヘッダ）は任意で、この分岐では検証しない
L0017	成功時出力	HTTP 200。処理結果コード200と、プレイヤーの公開向け情報
L0018	失敗時出力	HTTP 400。処理結果コードとメッセージ「Invalid request parameters」
L0019	出力: プレイヤーの公開向け情報
L0020	項目	型	内容
L0021	ニックネーム	string	未設定のときはnull
L0022	プロフィール	string	未設定のときはnull
L0023	デッキユーザーID	string	未設定のときはnull
