L0003	A15-05 ユーザー情報変更 ／ API デッキビルダー — ユーザー情報変更
L0004	業務ロジック
L0005	更新対象
L0006	認証トークンの利用者識別子に対応する顧客からプレイヤーを特定し、そのプレイヤー自身の情報のみを更新する。他プレイヤーの情報は更新できない。トークンを検証できないとき、該当するプレイヤーが無いときは認証拒否（HTTP 401）とする。
L0007	更新する内容
L0008	プレイヤーのニックネームを受け取ったユーザー名で、プロフィールを受け取った値で更新する。ユーザー名が未指定のときは入力不正（HTTP 400）とし、更新しない。プロフィールが未指定のときはnullとして保存する。更新中に例外が発生したときは更新を取り消し、処理失敗（HTTP 500）として例外メッセージを返す。
L0009	金額・税・ポイント・在庫数量の再計算や丸めは行わない。トークン原値・署名シークレットは本書に記載しない。
L0010	エラー時の扱い
L0011	エラー内容	処理
L0012	認証不可	認証拒否（HTTP 401）とし、処理結果コードとメッセージを返す
L0013	ユーザー名未指定	入力不正（HTTP 400）とし、「Invalid request parameters」を返す
L0014	更新中の例外	更新を取り消し、処理失敗（HTTP 500）として例外メッセージを返す
L0015	入出力
L0016	種類	内容
L0017	入力	認証トークン、ユーザー名、プロフィール
L0018	成功時出力	HTTP 200。処理結果コード200とメッセージ「Update user information」
L0019	失敗時出力	HTTP 401（認証不可）、HTTP 400（ユーザー名未指定）、HTTP 500（更新中の例外）
L0020	入出力: エンドポイント
L0021	エンドポイントは PUT /user とする。
L0022	入力: リクエスト
L0023	パラメータ	位置	型	必須／任意	説明
L0024	jwt-token	ヘッダ	string	必須	認証用のトークン。利用者識別子の顧客IDからプレイヤーを引く
L0025	user_name	ボディ	string	必須	設定するニックネーム。未指定（null）の場合は入力不正（HTTP 400）となる
L0026	profile	ボディ	string	任意	設定するプロフィール。未指定の場合はnullとして保存する
L0027	出力: レスポンス（成功）
L0028	応答本体のJSONキーはスネークケースで組み立てる。
L0029	フィールド	型	説明
L0030	code	integer	処理結果コード。成功時は200
L0031	message	string	結果メッセージ。成功時は「Update user information」
L0032	{
L0033	"code": 200,
L0034	"message": "Update user information"
L0035	}
L0036	出力: レスポンス（失敗）
L0037	HTTPステータス	条件	本文の形
L0038	401	認証トークンの欠落・署名不正・該当するプレイヤーなし	メッセージは「Access Token is incorrect」または「Authentication failed」
L0039	400	ユーザー名が未指定（null）	メッセージは「Invalid request parameters」
L0040	500	更新中に例外が発生（保存失敗）	メッセージは例外メッセージ。更新は取り消す
L0041	入出力: 永続化
L0042	操作	契機
L0043	更新	ユーザー情報変更時に、プレイヤーのニックネームとプロフィールを更新する
L0044	リニューアル後の仕様
L0045	表示メッセージ
L0046	メッセージID	表示位置	画面上の文言	表示条件	後続処理
L0047	—	API応答JSON	Update user information	ユーザー情報の更新に成功したとき	HTTP 200を返して終了する
L0048	—	API応答JSON	Invalid request parameters	ユーザー名が未指定のとき	HTTP 400を返し、更新しない
L0049	—	API応答JSON	Access Token is incorrect	認証トークンを検証できないとき	HTTP 401を返し、更新しない
L0050	—	API応答JSON	Authentication failed	認証トークンに該当するプレイヤーが無いとき	HTTP 401を返し、更新しない
