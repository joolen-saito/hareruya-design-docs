L0003	A15-03 ユーザー情報参照 ／ API デッキビルダー — ユーザー情報参照
L0004	業務ロジック
L0005	取得対象
L0006	デッキユーザーIDの指定が無いときは、認証したプレイヤー自身の情報を返す。返す値はニックネーム・プロフィール・デッキユーザーIDで、いずれも未設定のときはnullとする。デッキユーザーIDの指定があるときは他ユーザー情報参照の分岐となり、本書では扱わない。
L0007	認証
L0008	認証用トークンのヘッダを検証し、対象者の顧客IDからプレイヤーを特定する。署名方式はHS256である。ヘッダ欠落・署名不正・該当するプレイヤーなしのいずれも認証拒否（HTTP 401）とする。認証を通ったのちに対象プレイヤーを取得できないときは入力不正（HTTP 400）とする。
L0009	呼び出し可能なクライアントはデッキビルダーアプリである。返すのは認証したプレイヤー自身の情報だけである。トークン原値・署名シークレットは本書に記載しない。
L0010	エラー時の扱い
L0011	エラー内容	処理
L0012	認証不可	認証拒否（HTTP 401）とし、コードとメッセージを返す
L0013	対象プレイヤーが取得できない	入力不正（HTTP 400）とし、「Invalid request parameters」を返す
L0014	入出力
L0015	種類	内容
L0016	入力	認証用トークンのヘッダ（必須）。デッキユーザーID（任意、指定すると他ユーザー情報参照の分岐となる）
L0017	成功時出力	HTTP 200。処理結果コードとニックネーム・プロフィール・デッキユーザーIDを含むラッパオブジェクト。キーは区切り記号付きの小文字で組み立てる
L0018	失敗時出力	認証できないときはHTTP 401で「Access Token is incorrect」または「Authentication failed」。対象プレイヤーを取得できないときはHTTP 400で「Invalid request parameters」
L0019	出力: フィールド
L0020	フィールド	型	説明
L0021	code	integer	処理結果コード。成功時は200。
L0022	user_name	string	プレイヤーのニックネーム。未設定の場合はnull。
L0023	profile	string	プレイヤーのプロフィール。未設定の場合はnull。
L0024	deck_user_id	string	プレイヤーのデッキユーザーID。未設定の場合はnull。
L0025	成功時の応答例（実装確認値に基づく代表値）。
L0026	{
L0027	"code": 200,
L0028	"user_name": "デッキ太郎",
L0029	"profile": "スタンダードを中心に遊んでいます。",
L0030	"deck_user_id": "AB12CD34"
L0031	}
L0032	リニューアル後の仕様
L0033	表示メッセージ
L0034	本APIは画面メッセージを扱わない。
