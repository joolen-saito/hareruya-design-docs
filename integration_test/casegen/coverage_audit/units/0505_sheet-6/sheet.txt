L0189	A05-04 スマレジ受信処理 / API 受注管理 — スマレジ受信処理（ポイント履歴取得）
L0190	業務ロジック
L0191	取引区分ごとのポイント処理
L0192	受信した内容から取引ヘッダと取引明細を取り出し、取引区分で処理を分ける。
L0193	取引区分	処理
L0194	取消	会員の保有ポイントから付与ポイントを差し引き、利用ポイントを戻す。取引に一致するポイント履歴を削除する
L0195	打消	付与ポイントと利用ポイントの正負を反転したうえで取消と同じ補正を行い、対象のポイント履歴を削除する
L0196	通常取引	会員の保有ポイントに付与ポイントを加え、利用ポイントを差し引く。付与ポイントが 0 より大きいときは付与の履歴を、利用ポイントが 0 より大きいときは利用の履歴を、購入によるポイントとして登録する。0 のときはその履歴を登録しない
L0197	登録する履歴の備考には、付与のときは「店舗付与」、利用のときは「店舗使用」と記録する。
L0198	注文への反映にともなうスマレジへのポイント連携
L0199	取引明細の商品コードに対応する注文が複数あるときは、いちばん新しい注文を対象とする。
L0200	注文へ反映するとき、その時点の日時を、注文の確定日と出荷日、および注文に紐づく各配送の出荷日として記録する。スマレジ用として登録されている担当者があるときは、その担当者を注文の担当者として記録する。
L0201	反映した注文に付与ポイントが記録されているときは、その付与ポイントを会員の保有ポイントに加え、購入によるポイントの履歴としてその注文とともに登録する。付与ポイントが未設定または 0 のときは加算も履歴の登録も行わない。
L0202	付与ポイントが 0 のとき（スマレジ側で決済とポイント付与が済んでいるとき）はスマレジへ送らない。0 でないときは、会員のスマレジ会員IDあてに付与ポイントをスマレジへ送る。使用ポイントは EC からの注文時に連携済みのため送らない。
L0203	スマレジからの応答に正常な結果が含まれないときは、その注文にスマレジ連携のエラー内容と、連携エラーである印を記録する。処理は中断しない。
L0204	エラー時の扱い
