L0059	現行仕様
L0060	A16-01 トップバナーIDのトップバナー情報を取得 / API データ管理 — トップバナーIDのトップバナー情報を取得
L0061	業務ロジック
L0062	取得対象の絞り込み
L0063	指定されたIDに該当する1件を取得するだけで、絞り込みを一切行わない。表示タイプが非表示のバナーも、画像URLが空のバナーも、IDが一致すれば取得できる（言語による絞り込みも行わない）。保存されている値をそのまま返す。
L0064	入出力
L0065	入出力: 該当が無いときの応答本文
L0066	該当するトップバナーが無いときの応答本文は、コードとメッセージの2項目を持つJSONで、コードは404、メッセージは「Not Found」。
L0067	入出力: バナーIDを付けない要求
L0068	バナーIDを付けないパス（/topBanner/）へ要求したときは、受け付けるパスに一致せず、HTTPステータス404になる。このときは該当が無いときの応答本文（コード404・メッセージ「Not Found」のJSON）を返さない。該当が無いときの応答本文を返すのは、バナーIDを付けたパスで該当するトップバナーが無いときだけである。
L0069	リニューアル後の仕様
L0070	表示メッセージ
L0071	この機能は画面を持たないためメッセージを扱わない。
