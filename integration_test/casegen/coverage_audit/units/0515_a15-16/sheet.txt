L0003	A15-16 直近大会情報取得 ／ API デッキビルダー — 直近大会情報取得
L0004	業務ロジック
L0005	取得対象
L0006	最新大会デッキのマスタから、大会日が設定済みで、かつ大会名（日本語・英語）が空でない行を抽出する。条件に合致する大会が無いときも失敗とせず、空の一覧を返す。
L0007	並び順
L0008	識別子の昇順に並べる。
L0009	値の取り方
L0010	数量・日時は永続化済みの値を返し、応答生成時の丸め・補正を行わない。
L0011	呼び出しの条件
L0012	リクエストのパラメータを受け取らない。認証も行わないため、認証を理由とするHTTP 401は返さない。公開向けの一覧であり、呼び出し元の状態によらず同一の結果を返す。呼び出し元はデッキビルダーアプリである。
L0013	エラー時の扱い
L0014	エラー内容	処理
L0015	該当大会なし	エラーとせず、空の一覧で処理結果コード200を返す
L0016	取得処理中の例外	共通の例外処理に委ねる（HTTP 500相当）
L0017	入出力
L0018	種類	内容
L0019	入力	なし
L0020	成功時出力	HTTP 200。処理結果コードと直近大会の一覧
L0021	失敗時出力	取得処理中の例外は共通の例外処理に委ねる（HTTP 500相当）
L0022	出力: 直近大会の項目
L0023	フィールド	型	説明
L0024	大会日	string	日時の文字列。
L0025	フォーマット識別子	integer	フォーマット識別子。
L0026	フォーマット名（日本語）	string	フォーマットの日本語名。
L0027	フォーマット名（英語）	string	フォーマットの英語名。
L0028	大会名（日本語）	string	大会の日本語名。
L0029	大会名（英語）	string	大会の英語名。
L0030	参加者数	integer	参加者数。
L0031	リニューアル後の仕様
L0032	表示メッセージ
L0033	メッセージID	表示位置	画面上の文言	表示条件	後続処理
L0034	—	—	本機能は利用者向けの文言を持たない	—	—
