L0131	現行仕様
L0132	A16-02 指定言語の設定済みトップバナー一覧を取得 / API データ管理 — 指定言語の設定済みトップバナー一覧を取得
L0133	業務ロジック
L0134	一覧に含めるバナー
L0135	画像URLが空文字のバナーは一覧に含めない。表示タイプが0（非表示）のバナーも一覧に含めない。
L0136	一覧はバナーIDの昇順で並べる。
L0137	指定した言語コードが登録されていれば、一覧に含めるバナーが1件も残らないときもコード200を返し、応答本文は空の配列（[]）になる。
L0138	入出力
L0139	受け付けるパス
L0140	拡張子を付けないパス（/topBanners/{言語コード}）でも、同じ一覧を返す。
L0141	失敗時の応答本文
L0142	コード404を返すときの応答本文は、コードとメッセージの2項目を持つ。メッセージは「Language code is not found」である。
L0143	リニューアル後の仕様
L0144	表示メッセージ
L0145	本APIは画面メッセージを扱わない。
