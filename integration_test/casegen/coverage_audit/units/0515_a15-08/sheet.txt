L0003	A15-08 カード検索 ／ API デッキビルダー — カード検索
L0004	業務ロジック
L0005	検索条件
L0006	カード名とカードテキストは、空白・カンマ区切りで語に分割する。カード名の語はカードの日本語名・英語名のいずれかへの部分一致、カードテキストの語は日本語・英語のテキストのいずれかへの部分一致とし、語どうしを指定の結合論理で結ぶ。カード名はダブルクォートで囲むと一語として扱う。
L0007	カード種別・サブタイプ・レアリティは識別子の配列で受け取り、それぞれの結合論理で絞り込む。色は配列で受け取り、AND または OR で絞り込む。除外色に指定した色を持つカードは結果から除く。
L0008	フォーマットを指定したときは、そのフォーマットで使用可および制限のカードに限定する。非合法を含める指定があるときは禁止区分も対象に加える。
L0009	マナ総量・パワー・タフネス・ロイヤルティは、下限と上限による範囲指定、一致指定、除外指定で絞り込む。
L0010	イラストレーターの検索語は受け取るが、検索条件には使わない。
L0011	値が指定された条件だけを積む。
L0012	並び順と件数
L0013	並び替えキーは色順・マナ総量・パワー・タフネスのいずれかとし、指定が無いときは色順とする。並び順は昇順・降順のいずれかとし、指定が無いときは昇順とする。完全一致優先を指定し、かつカード名を指定したときだけ、カード名が完全一致する行を先頭へ寄せる。
L0014	総件数は絞り込み後・対象ページの取得前に算出し、重複を排除した件数とする。1ページ件数が100を超えるときは100に丸める。
L0015	値の取り方
L0016	カード種別と色は、カードごとの識別子の数値配列に整形する。各カードには日本語・英語のカード画像URLを付す。該当する画像が無いときは値を持たない。
L0017	金額・在庫等の再計算は行わない。取得時点の値をそのまま応答へ整形して返す。
L0018	他機能との境界
L0019	本APIは認証を行わない。トークンの検証もプレイヤーの照合も行わないため、認証起因の拒否（HTTP 401）を返さない。呼び出し可能なクライアントはデッキビルダーアプリであり、利用者の状態によらず参照できる。
L0020	エラー時の扱い
L0021	エラー内容	処理
L0022	検索条件が許容値の制約に反する（フォーマットが数値以外、並び順が昇順・降順以外、各結合論理が許容語以外など）	入力不正（HTTP 400）とする
L0023	検索処理中の例外	共通例外処理に委ねる（HTTP 500）
L0024	該当するカードが無い	失敗とせず、HTTP 200で総件数0・空のカード配列を返す
L0025	入出力
L0026	種類	内容
L0027	入力	検索条件・並び順・ページングをすべてクエリで受け取る。配列を取る項目は複数値で渡す
L0028	成功時出力	HTTP 200。処理結果コード・総件数・カード配列
L0029	失敗時出力	検索条件が許容値に反するときはHTTP 400、検索処理中に例外が起きたときはHTTP 500
L0030	本APIは参照だけを行い、データを更新しない。
L0031	入力: 検索条件の項目
L0032	項目	型	必須／任意	内容
L0033	カード名	string	任意	空白・カンマ区切りで複数語。ダブルクォートで一語扱い
L0034	カード名の結合論理	string	任意	指定が無いときはAND。AND／OR／NOT のいずれかに限る
L0035	カード種別	array	任意	カード種別の識別子
L0036	カード種別の結合論理	string	任意	指定が無いときはAND。AND／OR／NOT のいずれかに限る
L0037	サブタイプ	array	任意	サブタイプの識別子
L0038	サブタイプの結合論理	string	任意	指定が無いときはAND。AND／OR／NOT のいずれかに限る
L0039	色	array	任意	色の識別子
L0040	色の結合論理	string	任意	指定が無いときはAND。AND／OR のいずれかに限る
L0041	除外色	array	任意	除外する色の識別子
L0042	フォーマット	integer	任意	フォーマットの識別子。数値のみ許容
L0043	非合法カードを含めるか	string	任意	指定が無いときはfalse。true／false のいずれかに限る
L0044	レアリティ	array	任意	レアリティの識別子
L0045	レアリティの結合論理	string	任意	指定が無いときはAND。AND／OR／NOT のいずれかに限る
L0046	イラストレーター	string	任意	検索語を受け取るが検索条件に使わない
L0047	カードテキスト	string	任意	空白・カンマ区切りで複数語
L0048	カードテキストの結合論理	string	任意	指定が無いときはAND。AND／OR／NOT のいずれかに限る
L0049	マナ総量の下限・上限	integer	任意	数値のみ許容
L0050	マナ総量の一致指定・除外指定	array	任意	一致させる値、除外する値
L0051	パワーの下限・上限	integer	任意	数値のみ許容
L0052	パワーの一致指定・除外指定	array	任意	一致させる値、除外する値
L0053	タフネスの下限・上限	integer	任意	数値のみ許容
L0054	タフネスの一致指定・除外指定	array	任意	一致させる値、除外する値
L0055	ロイヤルティの下限・上限	integer	任意	数値のみ許容
L0056	ロイヤルティの一致指定・除外指定	array	任意	一致させる値、除外する値
L0057	完全一致優先	string	任意	指定が無いときはfalse。false以外を指定し、かつカード名を指定したときだけ有効
L0058	1ページ件数	integer	任意	指定が無いときは20。数値のみ許容。100を超えるときは100に丸める
L0059	ページ番号	integer	任意	指定が無いときは1。数値のみ許容
L0060	並び替えキー	string	任意	指定が無いときは色順。色順／マナ総量／パワー／タフネス のいずれかに限る
L0061	並び順	string	任意	指定が無いときは昇順。昇順／降順 のいずれかに限る
L0062	出力: 応答項目
L0063	フィールド	型	説明
L0064	処理結果コード	integer	成功時は200。
L0065	総件数	integer	検索条件に一致するカードの総件数。対象ページに限らず、重複を排除した件数とする。
L0066	カード配列	array	対象ページ分のカード行。
L0067	カードの識別子	integer	カードの識別子。
L0068	カードの日本語名	string	カードの日本語名。
L0069	カードの英語名	string	カードの英語名。
L0070	カード種別	array	カード種別の識別子の数値配列。
L0071	色	array	色の識別子の数値配列。
L0072	マナ総量	integer	マナ総量。
L0073	アトラクション区分	integer	アトラクションのときは1、そうでないときは0。
L0074	ステッカー区分	integer	ステッカーのときは1、そうでないときは0。
L0075	日本語のカード画像URL	string	該当する画像が無いときは値を持たない。
L0076	英語のカード画像URL	string	該当する画像が無いときは値を持たない。
