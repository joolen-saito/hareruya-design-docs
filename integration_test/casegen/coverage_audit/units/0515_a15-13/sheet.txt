L0003	A15-13 デッキ情報検索 ／ API デッキビルダー — デッキ情報検索
L0004	業務ロジック
L0005	検索モードと対象範囲
L0006	検索モードは公開検索と自分のデッキ検索の 2 種類で、既定は公開検索とする。
L0007	モード	認証	対象
L0008	公開検索	不要。認証なしで成功する	公開デッキ
L0009	自分のデッキ検索	必須。認証できないときは認証拒否とする	認証したプレイヤーが所有するデッキだけ
L0010	自分のデッキ検索のときだけ認証用トークンを検証し、トークンが持つ顧客IDからプレイヤーを特定する。トークン欠落・署名不正・該当プレイヤーなしのいずれの場合も認証拒否とする。呼び出せるクライアントはデッキビルダーアプリに限る。トークン原値・署名シークレットは本書に記載しない。
L0011	絞り込み
L0012	大会デッキを含めるかとユーザーデッキを含めるかは個別に指定でき、どちらも対象外にしたときは空の一覧と総件数 0 を返す。
L0013	条件	絞り込み方
L0014	フォーマット・アーキタイプ・デッキタグ・キャンペーンタグ	配列を指定したときだけ、その識別子のいずれかに一致する行に限る
L0015	デッキ利用者ID	完全一致
L0016	大会デッキのプレイヤー名	部分一致
L0017	大会名	日本語名・英語名のいずれかへの部分一致
L0018	作成日時・更新日時・大会日付	下限は以上、上限は以下
L0019	参加人数	下限は以上、上限は以下
L0020	優勝	指定が真かつ上位 8 の指定が偽のときだけ、順位 1 位に限る
L0021	上位 8	指定が真のとき、順位 8 位以内に限る
L0022	レギュレーション違反	指定が偽のとき、違反デッキを除く
L0023	直近デッキの件数	指定した件数ぶんのデッキID範囲に限る
L0024	採用カード	カードと配置ボードの組をすべて満たす行に限る
L0025	優勝と上位 8 の指定は、空文字と 0 のときだけ偽とする。 優勝と上位 8 の指定は、空文字と 0 以外の文字列（false を含む）を真とする。
L0026	並び順と件数
L0027	作成日時の降順に並べ、指定されたページ番号と 1 ページあたりの件数で 1 ページ分だけを返す。ページ番号の既定は 1、1 ページあたりの件数の既定は 20 で、100 を超える指定は 100 に丸める。どちらも数字だけを受け付ける。
L0028	総件数は条件に一致するデッキを重複排除した件数であり、ページ番号と 1 ページあたりの件数の指定によって変わらない。
L0029	値の取り方
L0030	条件に一致した行の値をそのまま返し、金額・ポイント・数量・ステータス・日時の再計算と丸めは行わない。限定公開トークンは自分のデッキ検索のときだけ応答に含める。キャンペーンタグの開催状況は開催前 0・開催中 1・開催後 2 のいずれかで返す。
L0031	デッキ一覧の応答に、金額・ポイントの項目は無い。 参加人数・公開範囲・非公開フラグは、デッキに保存された値をそのまま返す。
L0032	入出力
L0033	種類	内容
L0034	入力	検索条件・検索モード・ページ番号・1 ページあたりの件数・キャッシュキー。自分のデッキ検索のときは認証用トークンを伴う
L0035	成功時出力	HTTP 200。処理結果コード 200、処理結果メッセージ「Deck search success」、総件数、1 ページ分のデッキ一覧
L0036	失敗時出力	自分のデッキ検索で認証できないときは HTTP 401。本文は処理結果コードとメッセージで、メッセージは「Access Token is incorrect」または「Authentication failed」。公開検索は条件に一致しないときも HTTP 200 で空の一覧と総件数 0 を返す
L0037	入出力: 検索条件
L0038	パラメータ	位置	型	必須／任意	説明
L0039	jwt-token	ヘッダ	string	条件付き必須	認証用トークン。自分のデッキ検索のときだけ必須
L0040	mode	クエリ	string	任意（既定 public）	public は公開検索、private は自分のデッキ検索
L0041	format	クエリ	array	任意	フォーマットIDの配列
L0042	archetype	クエリ	array	任意	アーキタイプIDの配列
L0043	event_deck_flag	クエリ	string	任意（既定 1）	0・false のときは大会デッキを除く
L0044	user_deck_flag	クエリ	string	任意（既定 1）	0・false のときはユーザーデッキを除く
L0045	create_from	クエリ	string	任意	作成日時の下限。指定した日時以上
L0046	create_to	クエリ	string	任意	作成日時の上限。指定した日時以下
L0047	update_from	クエリ	string	任意	更新日時の下限。指定した日時以上
L0048	update_to	クエリ	string	任意	更新日時の上限。指定した日時以下
L0049	tag	クエリ	array	任意	デッキタグIDの配列
L0050	campaign_tag_ids	クエリ	array	任意	キャンペーンタグIDの配列
L0051	user_id	クエリ	string	任意	デッキ利用者IDの完全一致
L0052	user_name	クエリ	string	任意	大会デッキのプレイヤー名の部分一致
L0053	event_name	クエリ	string	任意	大会名の部分一致。日本語名と英語名の両方が対象
L0054	event_date_from	クエリ	string	任意	大会日付の下限。指定した日付以上
L0055	event_date_to	クエリ	string	任意	大会日付の上限。指定した日付以下
L0056	participants_from	クエリ	integer	任意	参加人数の下限。指定した人数以上
L0057	participants_to	クエリ	integer	任意	参加人数の上限。指定した人数以下
L0058	champion_flag	クエリ	string	任意（既定 0）	真かつ上位 8 の指定が偽のときだけ順位 1 位に限る
L0059	top8_flag	クエリ	string	任意（既定 0）	真のときは順位 8 位以内に限る
L0060	regulation_violation_flag	クエリ	string	任意（既定 0）	偽のときはレギュレーション違反デッキを除く
L0061	search_decks_count	クエリ	integer	任意	直近のデッキID範囲に限るときの件数
L0062	per_page	クエリ	integer	任意（既定 20）	1 ページあたりの件数。数字だけを受け付け、100 を超えるときは 100 とする
L0063	page	クエリ	integer	任意（既定 1）	ページ番号。数字だけを受け付ける
L0064	cards	クエリ	array	任意	採用カード条件の配列。各要素は card_id・board_id
L0065	cache_key	クエリ	string	任意	指定があるときだけ一覧と総件数をキャッシュに保存する
L0066	入出力: デッキ一覧の項目
L0067	フィールド	型	説明
L0068	id	integer	デッキID
L0069	deck_name	string	デッキ名
L0070	format_id	integer	フォーマットの識別子
L0071	format_name_jp	string	フォーマット名（日本語）
L0072	format_name_en	string	フォーマット名（英語）
L0073	archetype_id	integer	アーキタイプの識別子
L0074	archetype_name_jp	string	アーキタイプ名（日本語）
L0075	archetype_name_en	string	アーキタイプ名（英語）
L0076	card_id	integer	代表カード画像の識別子
L0077	card_image	string	代表カード画像のURL
L0078	deck_type	string	デッキ種別
L0079	event_name_jp	string	大会名（日本語）
L0080	event_name_en	string	大会名（英語）
L0081	event_date	string	大会日付
L0082	player_name	string	プレイヤー名。大会デッキのときに入る
L0083	result	string	成績
L0084	ranking	integer	順位
L0085	participants	integer	参加人数
L0086	deck_user_id	string	デッキ利用者ID
L0087	nickname	string	ニックネーム。ユーザーデッキのときに入る
L0088	scope_id	integer	公開範囲
L0089	deck_private_flag	boolean	非公開フラグ
L0090	create_date	string	作成日時
L0091	update_date	string	更新日時
L0092	display_token	string	限定公開トークン。自分のデッキ検索のときだけ含める
L0093	deck_tags	array	デッキタグの配列。各要素は id・name_jp・name_en
L0094	campaign_tags	array	キャンペーンタグの配列。各要素は id・name_jp・name_en・is_during
L0095	入出力: 永続化
L0096	操作	契機
L0097	キャッシュへの保存	キャッシュキーの指定があるとき、一覧と総件数を保存する
L0098	キャッシュの保存先は Redis とする。 キャッシュの識別名は、一覧が deck_search_result_<キャッシュキー>、総件数が deck_search_count_<キャッシュキー> とする。 キャッシュの有効期間は1800秒とする。 有効期間内に同じキャッシュキーで検索したときは、保存した一覧と総件数を返す。
L0099	デッキ情報は更新しない。
