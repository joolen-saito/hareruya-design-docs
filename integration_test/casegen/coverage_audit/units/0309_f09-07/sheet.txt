L0003	F09-07 デッキリスト書き出し ／ フロント デッキ検索 — デッキリスト書き出し
L0004	業務ロジック
L0005	書き出しの2経路
L0006	デッキリストの書き出しには、ファイルとして受け取る経路と、画面が写し取るためのテキストを受け取る経路がある。
L0007	経路	受け取り方	応答の形式
L0008	Magic Online用テキスト	ファイルとして受け取る	添付ファイルのtext/plain
L0009	アリーナ形式のテキスト	画面が受け取り、クリップボードへ写す	JSON
L0010	公開状態の判定	ファイル経路だけが表示区分とデッキリストの公開状態を見る	—
L0011	デッキ種別の判定	どちらの経路も、ユーザーデッキのときは応じない	—
L0012	ファイルとして受け取る経路の条件
L0013	順序	判定	結果
L0014	1	デッキの識別子が空のとき	HTTP 404
L0015	2	識別子に一致するデッキが無いとき	HTTP 404
L0016	3	表示区分が非公開のとき	HTTP 404
L0017	4	デッキリストが非公開のとき	HTTP 404
L0018	5	デッキ種別がユーザーデッキのとき	HTTP 404
L0019	6	上のいずれにも当たらないとき	デッキリストのファイルを返す
L0020	限定公開のデッキは、限定公開用の値の一致を求めずに書き出せる。
L0021	ファイルの名称と内容
L0022	ファイル名はアーキタイプの英語名の空白文字を_へ置き換え、.txtを付けた文字列とする。内容は英語カード名の枚数 カード名を1行ずつ並べたもので、サイドボードの前にSideboardの行を挟む。統率者とメインボードの見出し行は入れない。カード名はアリーナで通る名称への対応表で置き換え、対応表に無い名称はそのまま残す。
L0023	テキストとして受け取る経路の条件
L0024	順序	判定	結果
L0025	1	デッキの識別子が空のとき	HTTP 404。本文はJSONで、処理結果は失敗、内容はNot Found
L0026	2	識別子に一致するデッキが無いとき	HTTP 404。本文は同上
L0027	3	デッキ種別がユーザーデッキのとき	HTTP 404。本文は同上
L0028	4	上のいずれにも当たらないとき	HTTP 200。処理結果は成功、デッキリストのテキストを返す
L0029	この経路は表示区分とデッキリストの公開状態を判定しないため、非公開のデッキでも識別子を指定すればテキストを受け取れる。
L0030	言語の指定による内容の違い
L0031	言語の指定	カード名	見出し行
L0032	en	英語名をアリーナで通る名称へ置き換えた値	統率者があるときはCommander、続けてDeck、サイドボードの前にSideboard
L0033	en以外	日本語名	統率者があるときは統率者、続けてデッキ、サイドボードの前にサイドボード
L0034	どちらの言語でも、カード名に含まれる/は // へ置き換える。デッキリスト詳細からの入口は、アリーナ用インポートテキストがen、日本語テキストがjpを言語として渡す。言語の指定が無いときのふるまいは正本コードからは確認できない。
L0035	デッキリストの組み立て
L0036	観点	扱い
L0037	行の形	枚数 カード名を1行とする
L0038	区画の順序	統率者、メインボード、サイドボードの順に並べる。この3つ以外の配置は書き出さない
L0039	区画の区切り	サイドボードがあるときだけ、その前に空行と見出し行を挟む
L0040	改行	復帰と改行の2文字を用いる
L0041	末尾	末尾の空白と改行を落とす
L0042	デッキリストがキャッシュにあるとき	キャッシュの内容から指定の言語で組み立てる
L0043	デッキリストがキャッシュに無いとき	採用カードから組み立てる
L0044	応答の形式
L0045	観点	ファイルとして受け取る経路	テキストとして受け取る経路
L0046	内容の種別	text/plain	application/json
L0047	添付の指定	ファイル名を指定した添付として返す	添付にしない
L0048	本文の作り	デッキリストのテキストだけを流し込む	処理結果とデッキリストのテキストを組にする
L0049	会員の状態	ログインの有無を問わない	ログインの有無を問わない
L0050	失敗したとき	HTTP 404。共通のエラー画面を返す	処理結果が失敗であることを示すJSONとHTTP 404
L0051	エッジケース
L0052	ケース	扱い
L0053	アーキタイプの英語名に空白を含むとき	空白を_へ置き換えたファイル名にする
L0054	対応表に無いカード名のとき	置き換えずに元の名称のまま書き出す
L0055	サイドボードが0枚のとき	サイドボードの見出し行を入れない
L0056	統率者が0枚のとき	統率者の見出し行を入れない
L0057	分割カードのとき	名称の/を // へ置き換える
L0058	デッキリストが非公開のとき	ファイル経路はHTTP 404、テキスト経路は書き出しに応じる
L0059	表示区分が限定公開のとき	限定公開用の値の一致を求めずに書き出す
L0060	採用カードが0件のとき	中身のないテキストを返す
L0061	メインボード・サイドボード・統率者以外の配置にカードがあるとき	書き出しに含めない
L0062	アーキタイプが未設定のとき	ファイル名の組み立てに使う値が無く、ふるまいは正本コードからは確認できない
L0063	言語の指定がen以外のとき	対応表による置き換えを行わない
L0064	会員でないとき	どちらの経路も同じ結果を返す
L0065	入出力
L0066	種類	内容
L0067	入力	デッキの識別子。テキストとして受け取る経路では言語の指定も伴う
L0068	成功時出力	ファイル経路は添付ファイルとしてのデッキリスト。テキスト経路はJSONで、処理結果が成功であることとデッキリストのテキスト
L0069	失敗時出力	ファイル経路はHTTP 404の共通のエラー画面。テキスト経路はHTTP 404で、処理結果が失敗であることとNot Found
L0070	入出力: 永続化
L0071	デッキ情報を登録・更新・削除しない。
L0072	操作	契機
L0073	キャッシュへの保存	行わない。デッキリストのテキストは、デッキIDを鍵にしたキャッシュに保存済みのときだけそこから組み立てる
L0074	リニューアル後の仕様
L0075	表示メッセージ
L0076	本機能は画面へ文言を表示しない。書き出しの入口と完了の通知はデッキリスト詳細（F09-06）を正とする。
