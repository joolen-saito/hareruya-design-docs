L0003	A15-10 デッキ情報登更新 ／ API デッキビルダー — デッキ情報更新
L0004	業務ロジック
L0005	更新対象の特定
L0006	順序	判定	結果
L0007	1	認証用トークンを検証できないとき	認証拒否（HTTP 401）とする
L0008	2	指定したデッキIDに該当するデッキが無いとき	該当なし（HTTP 404、「The deck does not exist」）とする
L0009	3	対象デッキの所有者が認証したプレイヤーと一致しないとき	認証拒否（HTTP 401、「Authentication failed」）とする
L0010	保存先の切り替え
L0011	即時保存の指定が真のときは、整合性を検証したうえで確定保存し、当該デッキの一時保存を削除する。偽または指定が無いときは、整合性を検証したうえで内容を下書きとして一時保存する。
L0012	デッキ本体と採用カードの整合性を検証できないときは入力不正（HTTP 400）とする。
L0013	一時保存の保存先は Redis とする。 一時保存のキーは、「deck_」にデッキIDを付けた値（例: deck_123）とする。 確定保存したときは、当該デッキIDのキーが存在すれば Redis から削除する。
L0014	応答の内容
L0015	処理結果コードと処理結果メッセージ（「Deck update success」）を返す。公開範囲が限定公開のときだけ、閲覧用トークンをあわせて返す。
L0016	他機能との境界
L0017	認証用トークンを検証し、トークンに含まれる顧客IDからプレイヤーを引く。署名方式はHS256とする。トークンが無い、署名が不正、該当するプレイヤーが無いときは、いずれも認証拒否（HTTP 401）とする。更新できるのは対象デッキの所有者だけとする。呼び出し可能なクライアントはデッキビルダーアプリとする。トークンの原値と署名シークレットは本書に記載しない。
L0018	エラー時の扱い
L0019	エラー内容	処理
L0020	トークンが無い、署名が不正、該当するプレイヤーが無い	認証拒否（HTTP 401、「Access Token is incorrect」または「Authentication failed」）とする
L0021	デッキIDに該当するデッキが無い	該当なし（HTTP 404、「The deck does not exist」）とする
L0022	対象デッキの所有者でない	認証拒否（HTTP 401、「Authentication failed」）とする
L0023	採用カードまたはデッキ本体の整合性検証に失敗した	入力不正（HTTP 400）とし、処理結果コードと検証エラー内容を返す
L0024	保存処理中の例外	処理失敗（HTTP 500）とし、処理結果コードと例外メッセージを返す
L0025	入出力
L0026	種類	内容
L0027	入力	デッキID（パス・必須）、認証用トークン（ヘッダ・必須）、公開範囲（必須。公開1・非公開2・限定公開3）。即時保存の指定・デッキ名・フォーマットの識別子・アーキタイプの識別子・代表カード画像に用いるカードID・キャンペーンタグの識別子・採用カードは、いずれも指定が無いときは扱わない
L0028	成功時出力	HTTP 200。処理結果コードと処理結果メッセージ。公開範囲が限定公開のときだけ閲覧用トークン
L0029	失敗時出力	認証できないときはHTTP 401、デッキが無いときはHTTP 404、整合性検証に失敗したときはHTTP 400、その他の例外のときはHTTP 500
L0030	採用カードの各要素はカードID・区画の識別子・枚数を持つ。キャンペーンタグの識別子は、単一値と配列のどちらのときも受け付ける。デッキ本体と採用カードの入力項目はデッキ登録と共通とする。
L0031	入出力: 永続化
L0032	操作	契機
L0033	更新	即時保存の指定が真で、整合性の検証を通過したとき。デッキ本体と採用カードを確定保存する
L0034	削除	確定保存したとき。当該デッキの一時保存を削除する
L0035	追加・更新	即時保存の指定が偽または無いとき。内容を一時保存へ書き込む
L0036	リニューアル後の仕様
L0037	表示メッセージ
L0038	本APIは画面を持たない。応答本文の処理結果メッセージは入出力の節を正とする。
