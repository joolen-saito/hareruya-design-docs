L0003	A15-15 採用枚数情報参照 ／ API デッキビルダー — 採用枚数情報参照
L0004	業務ロジック
L0005	集計対象
L0006	指定したフォーマットの、公開・大会デッキを集計対象とする。フォーマットが指定されていない、または一致するフォーマットが無いときは該当なし（HTTP 404）とし、「format not found」を返す。
L0007	指定	絞り込み
L0008	種別が土地	土地カードのみを対象とする
L0009	種別が土地以外	土地以外のカードを対象とする
L0010	アーキタイプ	指定したアーキタイプのデッキに限定する
L0011	ボード	指定したボードのカードに限定する
L0012	公開デッキだけを集計対象とするため、呼び出し元の状態によらず同じ集計結果を返す。認証は行わず、認証を理由とするHTTP 401は返さない。
L0013	平均採用枚数の算出
L0014	カードごとの採用枚数合計を、カード種別数と特殊タイプ数で除した値を平均採用枚数とし、整数にして返す。
L0015	平均採用枚数は、集計対象デッキでの採用枚数の合計と等しく、デッキ数では割らない。 採用カード1件は、カード種別数と特殊タイプ数（特殊タイプが無いときは1）を掛けた行数に増えて合計される。 カード種別数と特殊タイプ数で除すと、増えた行数の分が戻る。 除した値に端数は生じない。
L0016	並び順と件数
L0017	平均採用枚数の降順に並べ、上位から最大で指定件数までを返す。件数が未指定のときは20件とする。
L0018	値の取り方
L0019	条件に一致しないデータは空の結果として返す。
L0020	カード別集計の項目に日時は無い。 平均採用枚数は保存された値ではなく、集計対象デッキの採用カードから集計して求める。
L0021	エラー時の扱い
L0022	エラー内容	処理
L0023	該当フォーマットなし	該当なし（HTTP 404）とし、「format not found」を返す
L0024	集計処理中の例外	共通の例外処理に委ねる（HTTP 500相当）
L0025	入出力
L0026	種類	内容
L0027	入力	フォーマット識別子（パス・必須）、種別・件数・アーキタイプ識別子・ボード識別子（いずれも任意）
L0028	成功時出力	HTTP 200。処理結果コードとカード別の採用枚数集計の配列
L0029	失敗時出力	HTTP 404。処理結果コードとメッセージ「format not found」
L0030	出力: カード別集計の項目
L0031	フィールド	型	説明
L0032	カード識別子	integer	カード識別子。
L0033	カード名（日本語）	string	カードの日本語名。
L0034	カード名（英語）	string	カードの英語名。
L0035	画像（日本語）	string	日本語版画像のURL。該当が無いときはnull。
L0036	画像（英語）	string	英語版画像のURL。該当が無いときはnull。
L0037	平均採用枚数	integer	採用枚数合計をカード種別数・特殊タイプ数で除した値を整数にしたもの。
