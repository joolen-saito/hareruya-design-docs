## §1. 全ケース共通前提
- **入口/認証**: 認証済み管理者が管理画面で利用。ルートは `admin_product_pre_doubling_check`（GET `/{admin_route}/product/pre_doubling_check`）と `admin_product_doubling_check`（GET `/{admin_route}/product/doubling_check`）の2本のみ（L316,L394）。当ルートに個別のロールアノテーションは無く、商品一覧など他の商品管理画面と同一ファイアウォール配下として扱われる（L361）。未ログインは管理画面共通のログイン誘導を正とする（L360）。
- **入力なし**: 両ページとも GET のみで、クエリボディやパスパラメータによる検索条件は無い（L347）。利用者からの入力フォームを持たないため項目別のフォームバリデーションは無い（L334,L357）。
- **参照系**: サーバー側は読み取り専用の参照クエリと URL 生成のみ。DB の書き込み・セッションキー更新・フラッシュメッセージ追加は行わない（L335,L347,L366,L381）。
- **応答**: 成功時は HTTP 200 と HTML。重複の有無に応じてテーブルまたはメッセージ（L347）。共通フレーム `@admin/default_frame.twig` を継承（L319）。
- **対象範囲**: ブラウザ経由の管理画面に限定（L307）。アプリケーションが用いる既定接続上の `dtb_product_class` / `dtb_product` を対象とする（L341）。
- **オラクル独立性**: 期待はオラクル（Excel優先・沈黙部は詳細設計HTML）由来で実装から独立。実装との差は付帯表4で乖離＝バグ候補として扱う。

## §3. DDT-CODEVALUE（`product_code` 値クラス × 重複判定・固定オラクル・行独立）
本機能は利用者入力フォームを持たない（L334,L357）ため、入力項目×境界のDDTは成立しない。データ駆動の単位は **`dtb_product_class.product_code` の値クラス × 重複判定結果**（L328,L331,L338／Excel 0204:L9382）である。各行は独立に投入し、判定順序は 1)NULL除外 → 2)空文字列除外 → 3)同一値2件以上を重複とする（L331）。

| DP | 前提(SEED)／`product_code` 値クラス | 期待（等値照合・オラクル） | 正本根拠 |
|----|--------------------------------------|----------------------------|----------|
| DV-01 | SEED-DUP2／同一コード `'PC-DUP-0001'` が2件 | 同一値が2行以上のため「重複」とみなされ、該当する**全行**（71001・71002 の2行）が一覧に載る。Excel「複数件存在」＝2件以上が重複（0204:L9382） | L328,L331 |
| DV-02 | SEED-DUP3／同一コード `'PC-DUP-0002'` が3件 | 同一コードのテキストが3行並び、各行のリンク先URLは規格ごとに異なる（71003・71004・71005） | L331,L338 |
| DV-03 | SEED-UNIQ／同一コード `'PC-UNIQ-9001'` が1件のみ | 同一値が2行以上でないため重複とみなされず、一覧に載らない（Excel 0204:L9354「重複が無いか確認」／0204:L9382「複数件存在しないかチェック」） | L328,L331 |
| DV-04 | SEED-NULL／`product_code=NULL` が2件 | 判定順序1により NULL は重複判定の母集団から除外される。グループ化対象は `product_code IS NOT NULL` の行だけであり、NULL行は一覧に載らない | L328,L331 |
| DV-05 | SEED-EMPTY／`product_code=''`（空文字列）が2件 | 判定順序2により空文字列は重複判定の母集団から除外される。グループ化対象は空文字列でない行だけであり、空文字列行は一覧に載らない | L328,L331 |
| DV-06 | SEED-SPACE／`product_code='   '`（半角空白3字）が2件 | SQLはトリムしないため、値が完全一致する複数行があれば重複として載る（空白のみでも NULL・空文字列のいずれでもないため母集団に残る） | L331,L338 |
| DV-07 | SEED-CTRL／`product_code=TAB1字`（制御文字のみ）が2件 | SQLはトリムしないため、値が完全一致する複数行があれば重複として載る（制御文字のみでも母集団に残る） | L338 |
| DV-08 | SEED-ORPHAN／同一コード `'PC-DUP-0003'` が2件・うち1件は `dtb_product` 不在の孤立行 | 一覧に載せる行は重複コードに該当する全規格行のうち `dtb_product` と内部結合できるものに限られ、商品が存在しない孤立行（71050）は結果に含まれない。71051 のみが載る | L328 |
