512	IT-25	ウェブアプリケーション	決済連携	状態表示	画面反映	決済中、完了、失敗、中断、取消、返金済みなど決済状態を画面や通知に表示する機能では、外部決済結果または自システム状態に応じた文言、リンク、操作可否、再試行案内が仕様通り切り替わること。

514	IT-32	ウェブサービス	外部連携	Webhook・外部通知	受信検証	Webhookや外部システム通知を受信する機能では、HTTPメソッド、ヘッダ、署名・トークン、通知種別、必須項目、値型、取引ID等の識別子を検証し、不正な通知では業務更新を行わず仕様通りの応答を返すこと。
515	IT-10	ウェブサービス	外部連携	Webhook・外部通知	重複・順序	Webhookや外部システム通知が再送、重複、順不同、遅延到着した場合でも、同一イベントや同一取引を重複反映せず、状態遷移、数量、金額、履歴が仕様通り整合すること。
