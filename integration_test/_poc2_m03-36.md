## §1. 全ケース共通前提
- **入口/認証**: 認証済み管理者が管理画面「商品管理」→「CSV管理」内「買取減額率変更CSV登録」で利用（L318,L369）。ルートは表示GET `m03-36_admin_product_product_buy_discount_csv_import`＝`GET /{admin_route}/product/product_buy_discount_csv_upload`、取込POST `admin_product_buy_discount_csv_upload`（同パス）、雛形DL `admin_product_csv_template`（`/product/product_csv_template/buyDiscount`）（L398）。
- **権限**: 表示・取込とも到達可能な管理者は許可される。細かなロール分岐は URL 単位の Symfony Security 設定を正とする（L369）＝具体ロール条件は本機能で規定せず要実機確認。
- **CSRF**: 取込POSTは CSRF トークン（フォーム名 `admin_csv_import`）を持つ（L357）。セッションはフラッシュメッセージと CSRF トークンに依存（L388）。
- **応答**: GET・POST成功・POST失敗のいずれも同一 URL を再描画（リダイレクトなし）（L372,L329）。成功時は成功フラッシュ＋履歴1件追加、失敗時はフィールド／行ごとのエラーメッセージ（L357）。
- **トランザクション**: 取込全体は単一トランザクション。打ち切り時はコミットされない（L348,L394）。
- **オラクル独立性**: 期待は詳細設計HTML由来で実装から独立。実装との差は付帯表4で乖離＝バグ候補として扱う。移行先 ec-cube-enterprise の実在判定列など正本が「要確認」とする点は断定しない。
