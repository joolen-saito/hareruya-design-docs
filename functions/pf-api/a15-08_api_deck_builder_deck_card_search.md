# API デッキビルダー — カード検索

## 業務ロジック

### 検索条件

カード名とカードテキストは、空白・カンマ区切りで語に分割する。カード名の語はカードの日本語名・英語名のいずれかへの部分一致、カードテキストの語は日本語・英語のテキストのいずれかへの部分一致とし、語どうしを指定の結合論理で結ぶ。カード名はダブルクォートで囲むと一語として扱う。

カード種別・サブタイプ・レアリティは識別子の配列で受け取り、それぞれの結合論理で絞り込む。色は配列で受け取り、AND または OR で絞り込む。除外色に指定した色を持つカードは結果から除く。

フォーマットを指定したときは、そのフォーマットで使用可および制限のカードに限定する。非合法を含める指定があるときは禁止区分も対象に加える。

マナ総量・パワー・タフネス・ロイヤルティは、下限と上限による範囲指定、一致指定、除外指定で絞り込む。

イラストレーターの検索語は受け取るが、検索条件には使わない。

値が指定された条件だけを積む。

### 並び順と件数

並び替えキーは色順・マナ総量・パワー・タフネスのいずれかとし、指定が無いときは色順とする。並び順は昇順・降順のいずれかとし、指定が無いときは昇順とする。完全一致優先を指定し、かつカード名を指定したときだけ、カード名が完全一致する行を先頭へ寄せる。

総件数は絞り込み後・対象ページの取得前に算出し、重複を排除した件数とする。1ページ件数が100を超えるときは100に丸める。

### 値の取り方

カード種別と色は、カードごとの識別子の数値配列に整形する。各カードには日本語・英語のカード画像URLを付す。該当する画像が無いときは値を持たない。

金額・在庫等の再計算は行わない。取得時点の値をそのまま応答へ整形して返す。

### 他機能との境界

本APIは認証を行わない。トークンの検証もプレイヤーの照合も行わないため、認証起因の拒否（HTTP 401）を返さない。呼び出し可能なクライアントはデッキビルダーアプリであり、利用者の状態によらず参照できる。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| 検索条件が許容値の制約に反する（フォーマットが数値以外、並び順が昇順・降順以外、各結合論理が許容語以外など） | 入力不正（HTTP 400）とする |
| 検索処理中の例外 | 共通例外処理に委ねる（HTTP 500） |
| 該当するカードが無い | 失敗とせず、HTTP 200で総件数0・空のカード配列を返す |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 検索条件・並び順・ページングをすべてクエリで受け取る。配列を取る項目は複数値で渡す |
| 成功時出力 | HTTP 200。処理結果コード・総件数・カード配列 |
| 失敗時出力 | 検索条件が許容値に反するときはHTTP 400、検索処理中に例外が起きたときはHTTP 500 |

本APIは参照だけを行い、データを更新しない。

### 入力: 検索条件の項目

| 項目 | 型 | 必須／任意 | 内容 |
|------|----|-----------|------|
| カード名 | string | 任意 | 空白・カンマ区切りで複数語。ダブルクォートで一語扱い |
| カード名の結合論理 | string | 任意 | 指定が無いときはAND。AND／OR／NOT のいずれかに限る |
| カード種別 | array | 任意 | カード種別の識別子 |
| カード種別の結合論理 | string | 任意 | 指定が無いときはAND。AND／OR／NOT のいずれかに限る |
| サブタイプ | array | 任意 | サブタイプの識別子 |
| サブタイプの結合論理 | string | 任意 | 指定が無いときはAND。AND／OR／NOT のいずれかに限る |
| 色 | array | 任意 | 色の識別子 |
| 色の結合論理 | string | 任意 | 指定が無いときはAND。AND／OR のいずれかに限る |
| 除外色 | array | 任意 | 除外する色の識別子 |
| フォーマット | integer | 任意 | フォーマットの識別子。数値のみ許容 |
| 非合法カードを含めるか | string | 任意 | 指定が無いときはfalse。true／false のいずれかに限る |
| レアリティ | array | 任意 | レアリティの識別子 |
| レアリティの結合論理 | string | 任意 | 指定が無いときはAND。AND／OR／NOT のいずれかに限る |
| イラストレーター | string | 任意 | 検索語を受け取るが検索条件に使わない |
| カードテキスト | string | 任意 | 空白・カンマ区切りで複数語 |
| カードテキストの結合論理 | string | 任意 | 指定が無いときはAND。AND／OR／NOT のいずれかに限る |
| マナ総量の下限・上限 | integer | 任意 | 数値のみ許容 |
| マナ総量の一致指定・除外指定 | array | 任意 | 一致させる値、除外する値 |
| パワーの下限・上限 | integer | 任意 | 数値のみ許容 |
| パワーの一致指定・除外指定 | array | 任意 | 一致させる値、除外する値 |
| タフネスの下限・上限 | integer | 任意 | 数値のみ許容 |
| タフネスの一致指定・除外指定 | array | 任意 | 一致させる値、除外する値 |
| ロイヤルティの下限・上限 | integer | 任意 | 数値のみ許容 |
| ロイヤルティの一致指定・除外指定 | array | 任意 | 一致させる値、除外する値 |
| 完全一致優先 | string | 任意 | 指定が無いときはfalse。false以外を指定し、かつカード名を指定したときだけ有効 |
| 1ページ件数 | integer | 任意 | 指定が無いときは20。数値のみ許容。100を超えるときは100に丸める |
| ページ番号 | integer | 任意 | 指定が無いときは1。数値のみ許容 |
| 並び替えキー | string | 任意 | 指定が無いときは色順。色順／マナ総量／パワー／タフネス のいずれかに限る |
| 並び順 | string | 任意 | 指定が無いときは昇順。昇順／降順 のいずれかに限る |

### 出力: 応答項目

| フィールド | 型 | 説明 |
|------------|----|------|
| 処理結果コード | integer | 成功時は200。 |
| 総件数 | integer | 検索条件に一致するカードの総件数。対象ページに限らず、重複を排除した件数とする。 |
| カード配列 | array | 対象ページ分のカード行。 |
| カードの識別子 | integer | カードの識別子。 |
| カードの日本語名 | string | カードの日本語名。 |
| カードの英語名 | string | カードの英語名。 |
| カード種別 | array | カード種別の識別子の数値配列。 |
| 色 | array | 色の識別子の数値配列。 |
| マナ総量 | integer | マナ総量。 |
| アトラクション区分 | integer | アトラクションのときは1、そうでないときは0。 |
| ステッカー区分 | integer | ステッカーのときは1、そうでないときは0。 |
| 日本語のカード画像URL | string | 該当する画像が無いときは値を持たない。 |
| 英語のカード画像URL | string | 該当する画像が無いときは値を持たない。 |

## 表示メッセージ

本APIは画面を持たず、応答本文に定型の文言を持たない。
