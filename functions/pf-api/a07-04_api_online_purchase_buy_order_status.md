# API ネット買取管理 — ネット買取受注ステータス更新

## 業務ロジック

### 更新対象の特定

指定された受注IDのネット買取受注1件を更新対象とする。該当が無いときは該当なし（HTTP 404）とする。

### 更新可否の判定順序

| 順序 | 判定 | 結果 |
|------|------|------|
| 1 | 指定ステータスIDが買取ステータスマスタに存在するか | 存在しなければ入力不正（HTTP 400）とし「正しい店頭買取ステータスIDを入力してください」を返す |
| 2 | 更新前ステータスが査定終了に該当しないか | 該当するなら更新不可とし、指定ステータスが査定中・査定再開なら「この査定はすでに終了しているため開くことができません。」、それ以外なら「この査定はすでに終了しているためステータスの更新に失敗しました。」を返す |
| 3 | 更新前・指定ステータスがともに査定中・査定再開のとき、査定担当者が認証した管理者会員か | 異なるなら入力不正（HTTP 400）とし「この受注は「（査定担当者名）」が査定中です。」を返す |
| 4 | 更新前ステータスと指定ステータスが異なるか | 同じなら更新も履歴登録も行わず、処理結果コード200を返す |
| 5 | 上記を通過 | 受注のステータス・更新担当者・更新日時を更新し、ステータス変更履歴を1件登録する |

査定中・査定再開の受注を査定開始できるのは、その受注を査定中の担当者本人に限る。更新担当者には認証した管理者会員を記録する。

### 買取ステータス

買取ステータスマスタに登録されているステータスIDは、受注（1）・商品到着（2）・完了（3）・査定同意（4）・書留発送（5）・振込依頼（6）・振込完了（7）・振込失敗（8）・キャンセル（9）・査定中（10）・保留（11）・査定再開（12）・連絡済み（13）である。これらに存在しないIDを指定したときは入力不正（HTTP 400）となる。

金額・税・ポイント・在庫数量の再計算や丸めは行わない。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| 認証不可 | 認証拒否（HTTP 401）とする |
| 受注が存在しない | 該当なし（HTTP 404）とする |
| ステータスIDが不正 | 入力不正（HTTP 400）とし、「正しい店頭買取ステータスIDを入力してください」を返す |
| 査定終了後の更新 | 入力不正（HTTP 400）とし、指定先に応じた文言を返す |
| 他担当者が査定中の受注の査定開始 | 入力不正（HTTP 400）とし、「この受注は「（査定担当者名）」が査定中です。」を返す |
| 保存処理中の例外 | 処理失敗（HTTP 500）とし、例外メッセージを返す。保存内容は取り消す |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 更新対象のネット買取受注ID、設定する買取ステータスID、認証トークン |
| 成功時出力 | HTTP 200。処理結果コード200。更新前後が同じステータスでも200を返す |
| 失敗時出力 | HTTP 401（認証不可）、HTTP 404（受注なし）、HTTP 400（入力不正・更新不可）、HTTP 500（保存処理中の例外） |

### 入力: リクエスト

| パラメータ | 位置 | 型 | 必須／任意 | 説明 |
|------------|------|----|-----------|------|
| `id` | パス | integer | 必須 | 更新対象のネット買取受注ID |
| `status` | ボディ | integer | 必須 | 設定する買取ステータスID。買取ステータスマスタに存在する値であること |
| `jwt-token` | ヘッダ | string | 必須 | 認証用のトークン |

### 出力: レスポンス（成功）

| フィールド | 型 | 説明 |
|------------|----|------|
| `code` | integer | 処理結果コード。成功時は200。更新前後が同じステータスでも200を返す |

```json
{
  "code": 200
}
```

### 出力: レスポンス（失敗）

| HTTPステータス | 条件 | 本文の形 |
|----------------|------|----------|
| 401 | トークン欠落・署名不正・該当する管理者会員なし | 認証拒否（本文を持たない） |
| 404 | 受注IDに該当するネット買取受注が無い | 該当なし（本文を持たない） |
| 400 | 指定ステータスIDが買取ステータスマスタに存在しない | `errors`は「正しい店頭買取ステータスIDを入力してください」 |
| 400 | 更新前ステータスが査定終了で、指定ステータスが査定中・査定再開 | `errors`は「この査定はすでに終了しているため開くことができません。」 |
| 400 | 更新前ステータスが査定終了で、指定ステータスがそれ以外 | `errors`は「この査定はすでに終了しているためステータスの更新に失敗しました。」 |
| 400 | 査定中・査定再開の受注を、査定担当者本人以外が査定中・査定再開へ更新 | `errors`は「この受注は「（査定担当者名）」が査定中です。」 |
| 500 | 保存処理中の例外 | `errors`は例外メッセージ。保存内容は取り消す |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 更新 | 更新前と指定ステータスが異なるとき、受注のステータス・更新担当者・更新日時を更新する |
| 追加 | 同じ契機で、ステータス変更履歴を1件登録する |
