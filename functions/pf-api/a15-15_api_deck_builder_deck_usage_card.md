# API デッキビルダー — 採用枚数情報参照

## 業務ロジック

### 集計対象

指定したフォーマットの、公開・大会デッキを集計対象とする。フォーマットが指定されていない、または一致するフォーマットが無いときは該当なし（HTTP 404）とし、「format not found」を返す。

| 指定 | 絞り込み |
| --- | --- |
| 種別が土地 | 土地カードのみを対象とする |
| 種別が土地以外 | 土地以外のカードを対象とする |
| アーキタイプ | 指定したアーキタイプのデッキに限定する |
| ボード | 指定したボードのカードに限定する |

公開デッキだけを集計対象とするため、呼び出し元の状態によらず同じ集計結果を返す。認証は行わず、認証を理由とするHTTP 401は返さない。

### 平均採用枚数の算出

カードごとの採用枚数合計を、カード種別数と特殊タイプ数で除した値を平均採用枚数とし、整数にして返す。

平均採用枚数は、集計対象デッキでの採用枚数の合計と等しく、デッキ数では割らない。
採用カード1件は、カード種別数と特殊タイプ数（特殊タイプが無いときは1）を掛けた行数に増えて合計される。
カード種別数と特殊タイプ数で除すと、増えた行数の分が戻る。
除した値に端数は生じない。

### 並び順と件数

平均採用枚数の降順に並べ、上位から最大で指定件数までを返す。件数が未指定のときは20件とする。

### 値の取り方

条件に一致しないデータは空の結果として返す。

カード別集計の項目に日時は無い。
平均採用枚数は保存された値ではなく、集計対象デッキの採用カードから集計して求める。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| 該当フォーマットなし | 該当なし（HTTP 404）とし、「format not found」を返す |
| 集計処理中の例外 | 共通の例外処理に委ねる（HTTP 500相当） |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | フォーマット識別子（パス・必須）、種別・件数・アーキタイプ識別子・ボード識別子（いずれも任意） |
| 成功時出力 | HTTP 200。処理結果コードとカード別の採用枚数集計の配列 |
| 失敗時出力 | HTTP 404。処理結果コードとメッセージ「format not found」 |

### 出力: カード別集計の項目

| フィールド | 型 | 説明 |
|------------|----|------|
| カード識別子 | integer | カード識別子。 |
| カード名（日本語） | string | カードの日本語名。 |
| カード名（英語） | string | カードの英語名。 |
| 画像（日本語） | string | 日本語版画像のURL。該当が無いときはnull。 |
| 画像（英語） | string | 英語版画像のURL。該当が無いときはnull。 |
| 平均採用枚数 | integer | 採用枚数合計をカード種別数・特殊タイプ数で除した値を整数にしたもの。 |
