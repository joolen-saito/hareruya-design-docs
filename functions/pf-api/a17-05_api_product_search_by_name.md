# API 店頭買取管理 — 商品名から商品詳細の情報を取得

## 業務ロジック

### 取得できる条件

| 順序 | 判定 | 結果 |
| --- | --- | --- |
| 1 | 商品名が未指定のとき | 該当なし（HTTP 404） |
| 2 | 商品名に一致する商品がないとき | 該当なし（HTTP 404） |
| 3 | 対象の商品サブクラス情報がないとき | 該当なし（HTTP 404） |
| 4 | 上記以外のとき | 商品配列を返す |

本APIは認証を行わず、商品検索の参照だけを扱う。呼び出せるのは買取アプリだけである。経路の制御はAPIの外側で行い、本書では仕様を確定しない。

### 商品のまとめ方

商品ID・言語・高額商品コードの組み合わせを単位として商品をまとめ、商品ごとにカテゴリ・地域制限・商品名を設定する。カード詳細を持つ商品は、商品名の先頭に言語コードを付す。

商品の件数が100件に達したときは、その時点で打ち切る。

### 商品規格の絞り込み

各商品規格のうち、良品（NM）であるもの、または価格が表示下限以上のものだけを商品規格として加える。画像はファイル名からURLへ変換して並べる。

商品ごとにその他コンディションの表示可否を判定し、表示しないときは良品（NM）の規格だけに絞る。

### 値の取り方

検索条件と絞り込みの順序は現行の実装に従う。件数・表示順は現行実装の既定と上限に従い、取得後に業務値を再計算しない。金額・ポイント・数量・ステータス・日時は保存済みの値をそのまま返し、応答の生成時に丸めや補正を行わない。条件に一致しないとき、または非公開のときは空の結果か既定のエラー形式で返す。

### エラー時の扱い

| 事象 | 扱い |
| --- | --- |
| 商品名が未指定のとき | 該当なし（HTTP 404）とし、処理結果コードとメッセージ「Not Found」を返す |
| 該当する商品または商品サブクラスがないとき | 該当なし（HTTP 404）とし、処理結果コードとメッセージ「Not Found」を返す |

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | 検索する商品名（クエリ）。必須。未指定のときは該当なし（HTTP 404） |
| 成功時出力 | HTTP 200。処理結果コード200と、該当した商品の配列（最大100件） |
| 失敗時出力 | HTTP 404。処理結果コードとメッセージ「Not Found」 |

### 出力: 商品の配列

| 項目 | 型 | 内容 |
| --- | --- | --- |
| 商品ID | integer | 商品の識別子 |
| 商品名 | string | カード詳細を持つ商品のときは、先頭に言語コードを付す |
| 言語コード | string | 商品の言語コード |
| 高額商品コード | string | 商品の高額商品コード |
| カテゴリ | array | カテゴリ名の配列 |
| 地域制限 | string | 地域制限の名称 |
| 商品規格 | array | 良品（NM）または価格が表示下限以上の規格だけを含む配列 |

商品規格1件が持つ項目は次のとおり。

| 項目 | 型 | 内容 |
| --- | --- | --- |
| 商品規格ID | integer | 商品規格の識別子 |
| 商品コード | string | 商品規格の商品コード |
| カードコンディションコード | string | 良品（NM）などのコンディション |
| 販売価格 | integer | 商品規格の販売価格 |
| 在庫数 | integer | 商品規格の在庫数 |
| 商品規格画像 | array | 画像URLの配列 |

### 入出力: 永続化

本APIはデータを更新しない。
