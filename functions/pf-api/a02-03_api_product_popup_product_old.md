# API 商品管理 — ポップアップ用商品情報取得（旧商品ID）

## 業務ロジック

### 取得対象

パスの旧商品IDに対応する商品情報を1件返す。旧商品IDはカードの旧商品IDまたは旧英語商品IDと突き合わせる。該当する商品が無いときはコード404・メッセージ「Not Found」を返す。

金額・在庫数の再計算や丸めは行わない。取得した値をそのまま返す。表示用の加工は呼び出し元クライアントの設計に従う。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| 該当商品情報なし | コード404・「Not Found」を返す |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | パスの旧商品ID（必須、整数） |
| 成功時出力 | HTTP 200。条件に合致する商品を1件返す |
| 失敗時出力 | HTTP 404。コードとメッセージ（"Not Found"） |

### 出力: フィールド

| フィールド | 型 | 説明 |
|------------|----|------|
| productId | integer | 商品ID。 |
| name | string | 商品名。 |
| productClassId | integer | 商品規格ID。 |
| price01 | string | 通常価格。小数を持つ値のため数値文字列で返す。 |
| price02 | string | 販売価格。小数を持つ値のため数値文字列で返す。 |
| stock | string | 在庫数。小数を持つ値のため数値文字列で返す。 |
| nameEn | string | 英語商品名。 |
| fileName | string | 商品画像のファイル名。 |
| cardId | integer | 紐づくカードID。 |

成功時の応答例（実装確認値に基づく代表値）。

```json
{
  "productId": 100001,
  "name": "サンプルカード",
  "productClassId": 200001,
  "price01": "500.00",
  "price02": "480.00",
  "stock": "12.00",
  "nameEn": "Sample Card",
  "fileName": "sample.jpg",
  "cardId": 300001
}
```

### 入出力: 永続化

本APIは業務データを更新しない。

## 表示メッセージ

本APIは画面メッセージを扱わない。
