# API 商品管理 — ポップアップ用商品情報取得

## 概要

記事内に表示する商品ポップアップ用に、商品IDと言語を指定して商品情報を取得するAPIである。pf-api（記事・買取連携用のAPIアプリケーション）が提供するJSON APIで、記事サイト等から呼び出される。

本書は実装手順ではなく、誰が・いつ・どの条件で・結果どうなるかを読むためのリバース詳細設計とする。確認値はpf-apiの商品ポップアップ取得処理、ルート定義（`config/routes.yaml`）、商品規格を扱うリポジトリを正とする。

本機能のカスタマイズ区分は現行踏襲であり、挙動の確認はpf-apiを参照する。DB関連の記述はec-cube-enterpriseを正とする方針だが、当機能が参照する商品サブ規格・カード詳細・カードコンディション等のHareruya独自テーブルはec-cube-enterpriseに該当が見当たらないため、現行（pf-api）の名称を残し「ec-cube-enterprise実装で要確認」とする。

対象はJSON APIエンドポイントであり、ブラウザ向けの画面を持たない。

本文ではフレームワークのコントローラ型名やメソッド名を主説明としない。「利用者視点の入口」にHTTPメソッドとパスパターンを書く。

## 本書で扱うこと

- 商品IDと言語によるポップアップ用商品情報の取得
- 該当が無い場合の応答

## 本書で扱わないこと

以下は本書では仕様確定せず、実装または別機能の設計を正とする。

- 記事サイト側のポップアップ表示の仕様
- 商品の登録・編集（商品管理を正とする）
- ポップアップ用カード情報取得・旧商品IDによる取得（各APIを正とする）

## リニューアル移行時の扱い

現行（pf-api）と移行先（ec-cube-enterprise）の差を記録する。永続化先の正典はec-cube-enterpriseとするが、当機能が参照するテーブルの一部はec-cube-enterpriseに該当が見当たらない。

| 観点 | 現行（pf-api） | 移行先（ec-cube-enterprise） |
|------|----------------|------------------------------|
| 主参照テーブル | dtb_product_sub_class（商品サブ規格。Hareruya独自） | 該当が見当たらない（ec-cube-enterprise実装で要確認） |
| 商品規格 | dtb_product_class（price01・price02・stock） | dtb_product_class（同名・price01・price02・stock を確認値とする） |
| カード詳細（フォイル区分） | cardDetail.foilFlg | 該当が見当たらない（ec-cube-enterprise実装で要確認） |
| カードコンディション | cardCondition.code | 該当が見当たらない（ec-cube-enterprise実装で要確認） |
| 言語 | language.code（言語ランクで絞り込み） | 該当が見当たらない（ec-cube-enterprise実装で要確認） |
| 商品サブ規格画像 | productSubImage.fileName | 該当が見当たらない（ec-cube-enterprise実装で要確認） |

商品規格（dtb_product_class）は現行と移行先で同名。商品サブ規格をはじめとするHareruya独自のカード関連テーブルはec-cube-enterpriseに対応する実装が見当たらないため、現行（pf-api）の名称を主とし、推測でスキーマ化せずec-cube-enterprise実装で要確認とする。

## 利用者視点の入口

| 入口 | URLエンドポイント | 期待されるふるまい |
|------|--------------------|--------------------|
| 記事内ポップアップ用の商品情報取得 | `GET /popup/product/{lang}/{productId}` | 商品IDと言語に対応するポップアップ用商品情報をJSONで返す。該当が無い場合は404を返す。 |

応答形式はJSON。記事サイト等のクライアントから呼び出される。

---

## 処理フロー

### ポップアップ用商品情報を取得する（GET `/popup/product/{lang}/{productId}`）

1. パスの商品ID・言語を受け取る。
2. 商品規格のリポジトリから、当該商品ID・言語のポップアップ用商品情報を取得する。
3. 取得できない場合はコード404・メッセージ「Not Found」のJSONを返す。
4. 取得できた場合は商品情報をJSONで返す。

## 業務ルール・計算

| 項目 | 内容 |
|------|------|
| 対象データ | リクエストで指定されたID・条件に一致するデータを取得対象とする。抽出条件と該当なし時の扱いは処理フロー・入出力の各節を正とする。 |
| 計算処理 | 本APIでは金額・税・ポイント・在庫数量の再計算や丸めを行わない。DBまたはリポジトリから取得した値をJSON応答へ整形して返す。 |
| 応答値 | 応答フィールドは取得時点の値を返す。表示用の加工やフロントエンド側の表示制御は呼び出し元クライアントの設計を正とする。 |

## 入出力

### リクエスト

| パラメータ | 位置 | 型 | 必須／任意 | 説明 |
|------------|------|----|-----------|------|
| `lang` | パス | string | 必須 | 言語区分。`jp`または`en`を想定する（言語ランク判定に用いる）。 |
| `productId` | パス | integer | 必須 | 取得対象の商品ID。 |

### レスポンス（成功）

HTTP 200。条件に合致する商品規格を一件返す。

| フィールド | 型 | 説明 |
|------------|----|------|
| `productId` | integer | 商品ID。 |
| `name` | string | 商品名。 |
| `productClassId` | integer | 商品規格ID。 |
| `price01` | string | 通常価格。Doctrineのdecimal値のため数値文字列で返す。 |
| `price02` | string | 販売価格。Doctrineのdecimal値のため数値文字列で返す。 |
| `stock` | string | 在庫数。Doctrineのdecimal値のため数値文字列で返す。 |
| `nameEn` | string | 英語商品名。 |
| `subFileName` | string | 商品規格画像のファイル名。該当が無い場合はnull。 |
| `fileName` | string | 商品画像のファイル名。該当が無い場合はnull。 |
| `code` | string | 言語コード。 |
| `conditionCode` | string | カードコンディションコード。 |
| `foilFlg` | boolean | フォイル区分。 |
| `weeklySold` | string | 週間販売数。集計（SUM）結果のため数値文字列で返す。 |

### レスポンス（失敗）

| HTTPステータス | 条件 | 本文の形 |
|----------------|------|----------|
| 404 | 該当する商品規格が無い | `{code, message}`（"Not Found"） |

### サンプルレスポンス

成功時の応答例（実装確認値に基づく代表値）。

```json
{
  "productId": 100001,
  "name": "サンプルカード",
  "productClassId": 200001,
  "price01": "500.00",
  "price02": "480.00",
  "stock": "12.00",
  "nameEn": "Sample Card",
  "subFileName": "sub_sample.jpg",
  "fileName": "sample.jpg",
  "code": "jp",
  "conditionCode": "A",
  "foilFlg": false,
  "weeklySold": "3"
}
```

### 副作用

無し（参照のみ）。

応答はJSON応答整形を経て返す。プロパティはcamelCase、日時はISO8601とする。

## DBカラム

機能に直接関係する列のみ記載する。型や一覧の細部はスキーマを参照する。商品規格（dtb_product_class）はec-cube-enterpriseと同名。商品サブ規格・カード関連テーブルはec-cube-enterpriseに該当が見当たらないため現行（pf-api）の名称を残し要確認とする。

| テーブル | 列 | メモ |
|---------|-----|------|
| dtb_product_sub_class（商品サブ規格。ec-cube-enterprise実装で要確認） | 商品ID・商品規格ID・言語・カードコンディション参照 | 取得条件・応答の主データに使用する。 |
| dtb_product_class（商品規格） | price01（通常価格）・price02（販売価格）・stock（在庫数） | 価格・在庫の応答に使用する。 |
| カード詳細・カードコンディション・言語・商品サブ規格画像（ec-cube-enterprise実装で要確認） | foilFlg・code・fileName 等 | フォイル区分・コンディションコード・言語コード・画像ファイル名の応答に使用する。 |

### DB操作

本機能は参照系（検索）であり、DBへの登録・更新・削除は行わない。テーブル名は ec-cube-enterprise を正典とする。

| 操作種別 | 対象テーブル | 契機・条件 |
|---------|--------------|------------|
| 検索 | dtb_product_class / dtb_product_sub_class | 検索条件に合致するレコードを抽出する。 |
