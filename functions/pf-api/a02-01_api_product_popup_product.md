# API 商品管理 — ポップアップ用商品情報取得

## 業務ロジック

### 取得できる条件

| 順序 | 判定 | 結果 |
| --- | --- | --- |
| 1 | 指定した商品IDと言語に一致するポップアップ用商品情報が無いとき | 該当なし（HTTP 404）とし、メッセージ「Not Found」を返す |
| 2 | 上記以外のとき | 条件に合致する商品規格を1件返す |

言語区分は jp または en のいずれかを想定し、言語ランクの判定だけに用いる。取得できないときは商品情報を返さず、処理結果コードとメッセージだけを返す。

### 値の取り方

金額・税・ポイント・在庫数量の再計算と丸めを行わない。取得できたときは、その値をそのまま応答へ整形して返す。応答の各項目は取得時点の値とする。表示用の加工と表示制御は呼び出し元の設計による。

通常価格・販売価格・在庫数は小数を持つ値であり、数値文字列で返す。週間販売数は集計結果であり、数値文字列で返す。商品規格画像のファイル名と商品画像のファイル名は、該当が無いときはnullとする。

### エラー時の扱い

| 事象 | 扱い |
| --- | --- |
| 該当する商品規格が無いとき | 処理結果コード404とメッセージ「Not Found」だけを返す |

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | 言語区分（パス、必須）、商品ID（パス、必須） |
| 成功時出力 | HTTP 200。条件に合致する商品規格1件だけの情報 |
| 失敗時出力 | HTTP 404。該当が無いときの処理結果コードとメッセージ「Not Found」 |

### 出力: 商品規格1件の項目

| 項目 | 型 | 内容 |
| --- | --- | --- |
| 商品ID | integer | 商品の識別子 |
| 商品名 | string | 商品名 |
| 商品規格ID | integer | 商品規格の識別子 |
| 通常価格 | string | 数値文字列で返す |
| 販売価格 | string | 数値文字列で返す |
| 在庫数 | string | 数値文字列で返す |
| 英語商品名 | string | 英語の商品名 |
| 商品規格画像のファイル名 | string | 該当が無いときはnull |
| 商品画像のファイル名 | string | 該当が無いときはnull |
| 言語コード | string | 商品規格の言語コード |
| カードコンディションコード | string | 商品規格のコンディション |
| フォイル区分 | boolean | 商品規格のフォイル区分 |
| 週間販売数 | string | 数値文字列で返す |

### 入出力: 永続化

本APIはデータを更新しない。
