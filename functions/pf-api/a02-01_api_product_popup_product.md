# API 商品管理 — ポップアップ用商品情報取得

## 業務ロジック

### 返す1件の選び方

同じ商品に商品規格が複数あるとき、次の条件を満たすものだけを対象とし、並び順の先頭1件を返す。対象が1件も無いときは該当なしとする。

| 区分 | 内容 |
| --- | --- |
| 対象の条件 | 商品が削除されておらず公開中であること／商品規格が削除されていないこと／商品規格の販売価格が0より大きいこと |
| 並び順 | 1. 在庫数が0より大きいものを先にする 2. 商品規格の言語コードが指定言語と一致するものを先にする 3. カードの状態が良い順（NM・SP・MP・HP の順） 4. 指定言語に対応する順位の商品規格画像を持つものを先にする |

指定言語は絞り込みには使わず、並び順の優先にだけ使う。そのため指定言語の商品規格を持たない商品でも、他の言語の商品規格を1件返す。

### 週間販売数の数え方

週間販売数は、返した商品規格1件の値ではなく、その商品が持つ商品規格のうち、返した商品規格と同じ言語コードのものの週間販売数量を合計した値とする。

### 値の取り方

取得した値は再計算・丸めを行わず、取得時点の値をそのまま返す。表示用の加工と表示制御は呼び出し元の設計による。商品規格画像のファイル名と商品画像のファイル名は、該当が無いときはnullとする。

## 入出力

### 該当が無いときの応答本文

該当する商品規格が無いときは商品情報を返さず、処理結果コードとメッセージの2項目だけを応答本文とする。
