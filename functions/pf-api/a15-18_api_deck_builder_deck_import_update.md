# API デッキビルダー — デッキ更新インポート

## 業務ロジック

### 更新できる条件

| 順序 | 判定 | 結果 |
| --- | --- | --- |
| 1 | 認証トークンが無い、署名が不正、またはトークンの顧客IDに対応するプレイヤーがない | 認証拒否（HTTP 401） |
| 2 | パスで指定したデッキ識別子に一致するデッキがない | 該当なし（HTTP 404） |
| 3 | デッキの所有プレイヤーが認証したプレイヤーと一致しない | 認証拒否（HTTP 401） |
| 4 | 上記以外 | 更新を実行する |

認証は要求ヘッダのトークンを検証し、その利用者IDに対応するプレイヤーを特定する。署名方式はHS256とする。トークンの原値と署名の秘密値は本書に記載しない。

デッキビルダーアプリを識別する要求項目は無い。
有効な認証トークンを持つデッキの所有者であれば、呼び出し元のクライアントによらず更新を受け付ける。

### カードリストの解読

カードリストは、枚数とカード名の行を並べたテキストである。指定されたフォーマットの統率者使用設定に応じて解読し、カードの配列に変換する。カードリストの行数の上限は500行で、超過時は入力不正（HTTP 400）とする。カードリストが未指定または空のときは、空のカード配列として扱う。

カードリストの行は、メインボード・サイドボード・統率領域のいずれかとして保存する。
カードリストの行を、メイビー・アトラクション・ステッカーとして保存することは無い。

カード名が一致せず解読できない行があるときも更新は完了させ、処理結果コードを206に切り替えて該当行の行番号を応答に含める。行番号は1始まりとする。

### 更新の内容

既存デッキ配下のデッキカード・メイビー・アトラクション・ステッカーを初期化したうえで、解読したカードとデッキ名・公開区分・アーキタイプ識別子などで内容を組み立て直す。入力検証を通過したときに保存し、あわせて当該デッキの下書きを削除する。

初期化の後に入力検証エラーまたは保存中の例外が起きたときは、初期化を含めて更新をすべて取り消し、更新前の状態に戻す。
このとき当該デッキの下書きは削除しない。

任意項目を省略したときは、既存の値を引き継がず、次の値で保存する。

| 省略した項目 | 更新後の値 |
| --- | --- |
| カードリスト | 採用カードを0件にする |
| デッキ名 | 値なし |
| アーキタイプ識別子 | 値なし |
| デッキ画像に用いるカード識別子 | アーキタイプを指定したときはアーキタイプの画像。それ以外は、カードリストの統率領域のカードの最新のカード画像。統率領域のカードが無いときは値なし |
| キャンペーンタグ識別子 | 紐づけなし |

公開区分を省略したときは入力不正（HTTP 400）とし、更新をすべて取り消す。

公開区分が限定公開のときは、応答に表示用トークンを含める。

### 新規登録との分岐

デッキ登録インポートと同一の処理を用い、パスのデッキ識別子の有無で動作を分ける。

| 条件 | 動作 |
| --- | --- |
| 更新要求（パスのデッキ識別子あり） | 該当デッキを取得し、該当なしは404、所有者不一致は401とする。取得できたときは既存デッキを上書き更新する |
| 登録要求（パスにデッキ識別子なし） | 既存デッキの取得と所有者の照合を行わず、新規デッキとして登録する（デッキ登録インポートで扱う） |

処理結果メッセージは、更新時は「Deck update success by import」、新規登録時は「Deck registration success by import」となる。

### エラー時の扱い

| 事象 | 扱い |
| --- | --- |
| 認証できないとき、または所有者が一致しないとき | 認証拒否（HTTP 401）とし、処理結果コードとメッセージを返す |
| デッキが存在しないとき | 該当なし（HTTP 404）とし、処理結果コードとメッセージを返す |
| 入力検証に失敗したとき、またはカードリストが上限行数を超過したとき | 入力不正（HTTP 400）とし、処理結果コードと検証エラーメッセージを返す |
| 解読できない行があるとき | 更新は完了させ、処理結果コード206として該当行の行番号を返す |
| 保存処理中にその他の例外が発生したとき | 処理失敗（HTTP 500）とし、処理結果コードと例外メッセージを返す |

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | 更新対象のデッキ識別子（パス）、認証トークン（ヘッダ）、フォーマット識別子、カードリスト、デッキ名、公開区分、アーキタイプ識別子、デッキ画像に用いるカード識別子、キャンペーンタグ識別子 |
| 成功時出力 | HTTP 200。処理結果コード、処理結果メッセージ、更新したデッキの識別子。限定公開のときは表示用トークン。解読できない行があるときはHTTP 206で該当行の行番号も返す |
| 失敗時出力 | HTTP 401・404・400・500のいずれかと、処理結果コードおよびメッセージ |

### 入出力: リクエスト

| 項目 | 位置 | 型 | 必須／任意 | 内容 |
| --- | --- | --- | --- | --- |
| デッキ識別子 | パス | integer | 必須 | 更新対象のデッキ。該当が無いときは404、所有者が一致しないときは401 |
| 認証トークン | ヘッダ | string | 必須 | 検証して利用者IDからプレイヤーを特定する |
| フォーマット識別子 | ボディ | integer | 必須 | カードリスト解読時の統率者使用設定の判定に用いる |
| カードリスト | ボディ | string | 任意 | 枚数とカード名の行を並べたテキスト。未指定・空のときは空のカード配列 |
| デッキ名 | ボディ | string | 任意 | — |
| 公開区分 | ボディ | integer | 必須 | 公開・非公開・限定公開。限定公開のとき応答に表示用トークンを含める |
| アーキタイプ識別子 | ボディ | integer | 任意 | — |
| デッキ画像に用いるカード識別子 | ボディ | integer | 任意 | — |
| キャンペーンタグ識別子 | ボディ | integer または配列 | 任意 | デッキに紐づけるキャンペーンタグ |

### 入出力: レスポンス

応答本体はラッパオブジェクトで、キーはスネークケースで組み立てる。

| 項目 | 型 | 内容 |
| --- | --- | --- |
| 処理結果コード | integer | 全行を解読できたときは200、解読できない行があるときは206 |
| 処理結果メッセージ | string | 更新時は「Deck update success by import」 |
| デッキ識別子 | integer | 更新したデッキの識別子 |
| 表示用トークン | string | 限定公開のときのみ含む |
| 解読できない行の行番号 | array | 解読できない行がある場合のみ含む、1始まりの行番号の配列 |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 削除 | 更新開始時の、既存デッキ配下のデッキカード・メイビー・アトラクション・ステッカーの初期化 |
| 更新 | 入力検証を通過したときの、デッキ内容の保存 |
| 削除 | 保存後の、当該デッキの下書き |
