# API データ管理 — トップバナーIDのトップバナー情報を取得

## 概要

トップバナーIDを指定してトップバナー情報を取得するAPIである。pf-apiが提供するJSON APIである。TODOリストの「コンテンツ管理」（A08-01）と「データ管理」（A16-01）の同一エンドポイントをまとめる。

本書は実装手順ではなく、誰が・いつ・どの条件で・結果どうなるかを読むためのリバース詳細設計とする。確認値はpf-apiのトップバナー取得処理、ルート定義、トップバナーマスタを扱うリポジトリを正とする。本機能のカスタマイズ区分は現行踏襲であり、挙動はpf-apiの実装を参照し、DB関連（テーブル・列）の記述はec-cube-enterpriseを正とする。

対象はJSON APIエンドポイントであり、ブラウザ向けの画面を持たない。

---

## 本書で扱うこと

- トップバナーIDによるトップバナー情報の取得
- 該当が無い場合の応答

---

## 本書で扱わないこと

以下は本書では仕様確定せず、実装または別機能の設計を正とする。

- 指定言語のトップバナー一覧取得（一覧取得APIを正とする）
- トップバナーの設定・管理（トップバナー管理を正とする）

## リニューアル移行時の扱い

本機能は現行踏襲であり、挙動の参照は現行のpf-api、DB関連の正はec-cube-enterpriseとする。テーブル名・列名は現行と移行先で一致する。移行先ではトップバナーマスタに表示用の追加列があるが、本APIの応答項目（ID・画像URL・リンク・表示タイプ・関連言語）には影響しない。

| 項目 | 現行（pf-api） | 移行先（ec-cube-enterprise） | 扱い |
|------|----------------|------------------------------|------|
| トップバナーマスタ | `mtb_top_banner`（id・image_url・link・disp_type） | `mtb_top_banner`（id・image_url・link・disp_typeに加え、image_alt・sort_no） | 同名テーブル。移行先は alt属性（`image_alt`）と表示順（`sort_no`）の列を持つ。本APIの応答には含めない。 |
| 言語関連 | `dtb_top_banner_language`（top_banner_id・language_id） | `dtb_top_banner_language`（top_banner_id・language_id） | 同一スキーマ。トップバナーと言語の多対多関連。 |
| 言語マスタ | `mtb_language`（id・name_jp・name_en・code） | `mtb_language`（id・name_jp・name_en・code・sort_no） | 同名テーブル。移行先は並び順（`sort_no`）の列を持つ。応答の言語名・言語コードに用いる。 |

## 利用者視点の入口

| 入口 | URLエンドポイント | 期待されるふるまい |
|------|--------------------|--------------------|
| トップバナーIDのトップバナー情報取得 | `GET /topBanner/{id}` | トップバナーIDに対応するトップバナー情報をJSONで返す。該当が無い場合は404を返す。 |

応答形式はJSON。

---

## 処理フロー

### トップバナー情報を取得する（GET `/topBanner/{id}`）

1. パスのトップバナーIDを受け取る。
2. トップバナーマスタのリポジトリから当該IDのトップバナーを取得する。
3. 取得できない場合はコード404のJSONを返す。
4. 取得できた場合はトップバナー情報をJSONで返す。

## 業務ルール・計算

| 項目 | 内容 |
|------|------|
| 対象データ | リクエストで指定されたID・条件に一致するデータを取得対象とする。抽出条件と該当なし時の扱いは処理フロー・入出力の各節を正とする。 |
| 計算処理 | 本APIでは金額・税・ポイント・在庫数量の再計算や丸めを行わない。DBまたはリポジトリから取得した値をJSON応答へ整形して返す。 |
| 応答値 | 応答フィールドは取得時点の値を返す。表示用の加工やフロントエンド側の表示制御は呼び出し元クライアントの設計を正とする。 |

## 入出力

### リクエスト

| パラメータ | 位置 | 型 | 必須／任意 | 説明 |
|------------|------|----|-----------|------|
| `id` | パス | integer | 必須 | 取得対象のトップバナーID。 |

### レスポンス（成功）

HTTP 200。

| フィールド | 型 | 説明 |
|------------|----|------|
| `id` | integer | トップバナーID。 |
| `imageUrl` | string | 画像URL。 |
| `link` | string | リンク先URL。 |
| `dispType` | integer | 表示タイプ。 |
| `languages` | array | 関連する言語の配列。要素はオブジェクトで、子フィールドは`id`（integer、言語ID）、`nameJp`（string、言語名・日本語）、`nameEn`（string、言語名・英語）、`code`（string、言語コード）。 |

### レスポンス（失敗）

| HTTPステータス | 条件 | 本文の形 |
|----------------|------|----------|
| 404 | 該当IDのトップバナーが存在しない | `{code, message}`（"Not Found"） |

### サンプルレスポンス

成功時の応答例（実装確認値に基づく代表値）。

```json
{
  "id": 1,
  "imageUrl": "https://example.com/banner/top_001.png",
  "link": "https://example.com/campaign",
  "dispType": 1,
  "languages": [
    { "id": 1, "nameJp": "日本語", "nameEn": "Japanese", "code": "ja" }
  ]
}
```

### 副作用

無し（参照のみ）。

応答はJSON応答整形を経て返す。プロパティはcamelCase、日時はISO8601とする。

## DBカラム

機能に直接関係する範囲のみ記載する。テーブル名・列名はec-cube-enterpriseを正とする。

| テーブル | 列 | メモ |
|---------|-----|------|
| トップバナーマスタ（`mtb_top_banner`） | id・image_url・link・disp_type | トップバナーIDで取得し、応答の画像URL・リンク・表示タイプに用いる。 |
| トップバナー言語関連（`dtb_top_banner_language`） | top_banner_id・language_id | トップバナーと言語の多対多関連。 |
| 言語マスタ（`mtb_language`） | id・name_jp・name_en・code | 応答の関連言語（言語名・言語コード）に用いる。 |

### DB操作

本機能は参照系（検索）であり、DBへの登録・更新・削除は行わない。テーブル名は ec-cube-enterprise を正典とする。

| 操作種別 | 対象テーブル | 契機・条件 |
|---------|--------------|------------|
| 検索 | dtb_top_banner_language / mtb_language / mtb_top_banner | 検索条件に合致するレコードを抽出する。 |
