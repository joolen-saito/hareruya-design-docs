# API 店頭買取管理 — 商品名から商品詳細の情報を取得

## 概要

買取アプリ（MTGバイヤー）が商品名で商品を検索し、該当する商品の詳細情報（カテゴリ・コンディション別の商品規格・画像）を取得するためのAPIである。pf-api（買取連携用のAPIアプリケーション）が提供するJSON APIで、商品名に該当する商品を最大100件まで返す。

本書は実装手順ではなく、誰が・いつ・どの条件で・結果どうなるかを読むためのリバース詳細設計とする。確認値はpf-apiの商品名検索処理、ルート定義（`config/routes.yaml`）、商品サブクラスを扱うリポジトリを正とする。カスタマイズ区分は現行踏襲で、挙動の参照リポはpf-api、DB関連はec-cube-enterpriseを正とする。

対象はJSON APIエンドポイントであり、ブラウザ向けの画面を持たない。本文ではフレームワークのコントローラ型名やメソッド名を主説明としない。「利用者視点の入口」にHTTPメソッドとパスパターンを書く。

---

## 本書で扱うこと

- 商品名による商品の検索と、商品詳細情報・商品規格・画像の取得
- 表示するコンディションの絞り込みと最大件数
- 該当が無い場合の応答

---

以下は本書では仕様確定せず、実装または別APIの設計を正とする。

- 商品IDによる商品詳細取得（商品詳細取得APIの設計を正とする）
- 買取用商品情報の取得（買取用商品情報取得APIの設計を正とする）

## リニューアル移行時の扱い

DB関連はec-cube-enterpriseを正とする。商品（`dtb_product`）・商品規格（`dtb_product_class`）・商品規格画像（`dtb_product_class_image`）・カード（`mtb_card`）・カード詳細（`mtb_card_detail`）はec-cube-enterpriseに同名で実在する。一方、本APIが現行（pf-api）で参照する商品サブクラス（`dtb_product_sub_class`）のビューと商品サブクラス画像（`dtb_product_sub_class_image`）は、ec-cube-enterpriseでは商品規格・商品規格画像（`dtb_product_class_image`）系へ再編されており同名ビューを確認できない。商品名検索・一意化・画像URL生成に用いる該当テーブル・列はec-cube-enterprise実装で要確認とする。挙動（検索条件・コンディション絞り込み・最大100件・該当なし時の応答）は現行（pf-api）を正とする。

## 用語

| 用語 | 説明 |
|------|------|
| 商品規格 | 商品のコンディション等の規格単位。価格・在庫・画像を持つ。 |
| 高額商品コード | 高額商品の区分コード。商品名・言語とあわせて商品の出し分けに用いる。 |
| その他コンディション | 良品（NM）以外のコンディション。表示条件により出し分ける。 |

## 利用者視点の入口

| 入口 | URLエンドポイント | 期待されるふるまい |
|------|--------------------|--------------------|
| 商品名による商品詳細の取得 | `GET /product/search` | クエリの商品名に該当する商品を検索し、商品詳細情報と商品規格をJSONで返す。該当が無い場合は404を返す。 |
| 同上（拡張子あり別名） | `GET /product/search.json` | 上と同一処理。 |

応答形式はJSON。呼び出し元は買取アプリ（MTGバイヤー）。

## 処理フロー

### 商品名で商品詳細を取得する（GET `/product/search`）

1. クエリの商品名を受け取る。未指定の場合は該当なし（HTTP 404）とする。
2. 商品名から対象の商品ID群を取得する。該当が無い場合は該当なし（HTTP 404）とする。
3. 対象の商品サブクラス情報を取得する。該当が無い場合は該当なし（HTTP 404）とする。
4. 商品ID・言語・高額商品コードの組み合わせを単位に商品をまとめ、商品ごとにカテゴリ・地域制限・商品名を設定する。カード詳細を持つ商品は商品名の先頭に言語コードを付す。
5. 各商品規格について、良品（NM）または価格が表示下限以上のものだけを商品規格として加え、画像はファイル名からURLへ変換して並べる。商品の件数が100件に達した時点で打ち切る。
6. 商品ごとに、その他コンディションの表示可否を判定し、表示しない場合は良品（NM）の規格のみに絞る。
7. コード200と商品配列をJSONで返す。

## 集計条件

| 指標 | 集計の要点 |
|------|------------|
| 対象商品 | 商品名に該当する商品サブクラスから、商品ID・言語・高額商品コードの組み合わせで一意化する。 |
| 表示する商品規格 | コンディションが良品（NM）の規格、または価格が表示下限（設定値）以上の規格のみを含める。 |
| その他コンディションの抑制 | 商品ごとの表示可否判定で「表示しない」と判定された場合、良品（NM）の規格のみに絞る。 |
| 最大件数 | 商品は最大100件で打ち切る。 |

## 入出力

### リクエスト

| パラメータ | 位置 | 型 | 必須／任意 | 説明 |
|------------|------|----|-----------|------|
| `product` | クエリ | string | 必須 | 検索する商品名。未指定（空）の場合は該当なし（HTTP 404）となる。 |

### レスポンス（成功）

HTTP 200。

| フィールド | 型 | 説明 |
|------------|----|------|
| `code` | integer | 処理結果コード。成功時は200。 |
| `products` | array | 該当した商品の配列。最大100件。 |
| `products[].product_id` | integer | 商品ID。 |
| `products[].product_name` | string | 商品名。カード詳細を持つ商品は先頭に言語コードを付す。 |
| `products[].language_code` | string | 言語コード。 |
| `products[].high_price_code` | string | 高額商品コード。 |
| `products[].categories` | array | カテゴリ名の配列。 |
| `products[].region_restriction` | string | 地域制限の名称。 |
| `products[].product_classes` | array | 商品規格の配列。 |
| `products[].product_classes[].product_class_id` | integer | 商品規格ID。 |
| `products[].product_classes[].product_code` | string | 商品コード。 |
| `products[].product_classes[].card_condition_code` | string | カードコンディションコード。 |
| `products[].product_classes[].price` | integer | 販売価格。 |
| `products[].product_classes[].stock` | integer | 在庫数。 |
| `products[].product_classes[].product_class_images` | array | 商品規格画像のURLの配列。 |

### レスポンス（失敗）

| HTTPステータス | 条件 | 本文の形 |
|----------------|------|----------|
| 404 | 商品名が未指定、または該当する商品・商品サブクラスが無い | `{code, message}`（"Not Found"） |

無し（参照のみ）。

応答はJSON応答整形を経て返す。本APIのフィールド名はコントローラで組み立てたsnake_caseのキーである。

## 業務ルール・計算

- 検索・一覧・取得条件はリクエストパラメータ、ログイン状態、公開状態、店舗・支店条件、既存リポジトリの絞り込み順序を正とする。
- 件数、ページ番号、表示順は既存実装のデフォルトと上限に従い、取得後に業務値を再計算しない。
- 金額、ポイント、数量、ステータス、日時はDBまたは連携元の永続化済み値を返却し、レスポンス生成時の丸め・補正は行わない。
- 条件に一致しない、権限がない、または非公開のデータは空結果または既存のエラー形式で返す。

## データ整合性

| 観点 | 内容 |
|------|------|
| 参照時点 | 呼び出し時点の商品・商品規格・在庫・価格を返す。本APIはデータを更新しない。 |
| 件数の打ち切り | 商品が100件に達した時点で打ち切るため、該当商品が多い場合は一部のみを返す。 |
| 表示条件 | 表示下限価格や良品（NM）判定により、応答に含まれる商品規格は実在の規格の一部となることがある。 |

## DBカラム

機能に直接関係する範囲のみ記載する。型や一覧の細部はスキーマを参照する。

テーブル名・列名はec-cube-enterpriseを正とする。現行（pf-api）は商品サブクラス（`dtb_product_sub_class`）ビューに集約された列を参照する。ec-cube-enterpriseでは商品規格系へ再編済みのため、買取・カード固有の出し分け列はec-cube-enterprise実装で要確認とする。

| テーブル | 列 | メモ |
|----------|-----|------|
| 商品（`dtb_product`） | 商品ID・商品名 | 検索・一意化・応答の商品情報に用いる。 |
| 商品規格（`dtb_product_class`） | 商品規格ID・商品コード・コンディション・価格・在庫 | 応答の商品規格に用いる。 |
| 商品規格画像（`dtb_product_class_image`） | 画像ファイル名 | 応答の商品規格画像URLに用いる。現行はビュー `dtb_product_sub_class_image` を参照。 |
| カード（`mtb_card`）・カード詳細（`mtb_card_detail`） | 言語コード・高額商品コード等 | 商品名先頭の言語コード付与・一意化に用いる。 |
| 商品サブクラス（`dtb_product_sub_class`） | 言語コード・高額商品コード・カテゴリ・地域制限の集約列 | 現行はビューを参照。ec-cube-enterpriseでは商品規格系へ再編済みのため要確認。 |

### DB操作

本機能は参照系（検索）であり、DBへの登録・更新・削除は行わない。テーブル名は ec-cube-enterprise を正典とする。

| 操作種別 | 対象テーブル | 契機・条件 |
|---------|--------------|------------|
| 検索 | dtb_product / dtb_product_class / dtb_product_class_image / dtb_product_sub_class / dtb_product_sub_class_image / mtb_card 等 | 検索条件に合致するレコードを抽出する。 |
