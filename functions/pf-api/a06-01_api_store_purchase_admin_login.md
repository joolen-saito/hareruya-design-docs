# API 店頭買取管理 — 買取アプリ用ログイン

## 業務ロジック

### 認証の中継

受け取ったログインIDとパスワードは、本APIでは形式検証せず中継先の認証に委ねる。中継先のログイン画面へアクセスしてセッションを確立し、確立したセッションを保ったままログインID・パスワードをログイン確認へ送信する。セッション確立用の一時情報はログインID別に保持し、送信後に削除する。リダイレクトを追従し、認証に成功したときは中継先の買取アプリ用ログインAPIに到達する。

### 応答の判定

中継先の応答本文をJSONとして解釈する。解釈結果が空のときは認証失敗とみなし、応答に含まれるエラー文言を抽出して、コード401とメッセージのJSONを返す。解釈できたときは、中継先が返した会員名・会員ID・店舗名・店舗住所・トークンをそのまま返す。

### トークンの発行と以降の利用

本APIはトークン取得の入口であり、呼び出しにトークンを要求しない。認証に成功すると中継先が署名付きトークンを発行して返す。トークンは発行者と利用者ID（管理者会員のID）を持つ。呼び出し元は受け取ったトークンを以降の買取系APIに付与し、各APIはトークンの利用者IDから管理者会員を引いて認可する。

トークン原値・署名シークレット・パスワードは本書に記載しない。金額・税・ポイント・在庫数量の再計算や丸めは行わない。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| 認証情報が返らない（認証失敗） | 応答からエラー文言を抽出し、コード401・メッセージのJSONを返す。画面上の理由文言をそのまま用い、本API独自の文言は設けない |
| 中継先への到達不可・処理中の例外 | 共通例外処理に委ねる。本API独自のフォールバック文言は設けない |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 管理者のログインID、パスワード |
| 成功時出力 | HTTP 200。会員名・会員ID・店舗名・店舗住所・発行したトークン |
| 失敗時出力 | HTTP 401（認証失敗）、HTTP 500（中継先への到達不可・処理中の例外） |

### 入力: リクエスト

| パラメータ | 位置 | 型 | 必須／任意 | 説明 |
|------------|------|----|-----------|------|
| `login_id` | ボディ | string | 必須 | 管理者のログインID。中継先の認証に用いる。本APIでは形式検証しない |
| `password` | ボディ | string | 必須 | 管理者のパスワード。中継先の認証に用いる。本APIでは形式検証しない |

### 出力: レスポンス（成功）

| フィールド | 型 | 説明 |
|------------|----|------|
| `memberName` | string | 認証した管理者会員の氏名 |
| `memberId` | integer | 認証した管理者会員のID。発行するトークンの利用者IDにも対応する |
| `shopName` | string | 会員に紐づく店舗名。店舗が紐づかない場合は空文字 |
| `shopAddr` | string | 会員に紐づく店舗住所。店舗が紐づかない場合は空文字 |
| `jwtToken` | string | 発行したトークン。以降の買取系APIの認証に用いる |

```json
{
  "memberName": "山田太郎",
  "memberId": 12,
  "shopName": "晴れる屋テスト店",
  "shopAddr": "東京都千代田区0-0-0",
  "jwtToken": "<jwtToken>"
}
```

### 出力: レスポンス（失敗）

| HTTPステータス | 条件 | 本文の形 |
|----------------|------|----------|
| 401 | 中継先が認証情報を返さない（資格情報の誤り等による認証失敗） | 処理結果コードとメッセージ。メッセージは中継先の画面エラー文言から改行表記を除いたもの |
| 500 | 中継先への到達不可・処理中の例外 | 共通例外処理に委ねる |

## 表示メッセージ

| メッセージID | 表示位置 | 画面上の文言 | 表示条件 | 後続処理 |
|---|---|---|---|---|
| A06-01-MSG-001 | API応答JSON（errors配列） | ログインIDまたはパスワードが入力されていません | ログインAPIでログインIDまたはパスワードが空のとき | HTTP 401を返し、トークンを発行しない |
| A06-01-MSG-002 | API応答JSON（errors配列） | ログインIDまたはパスワードが正しくありません | ログインAPIで有効なログインIDに対応する会員が見つからないとき | HTTP 401を返し、トークンを発行しない |
| A06-01-MSG-003 | API応答JSON（errors配列） | ログインIDまたはパスワードが正しくありません | ログインAPIで会員は見つかったが、パスワード検証に失敗したとき | HTTP 401を返し、トークンを発行しない |
