# API デッキビルダー — メタゲーム情報参照

## 概要

デッキビルダーアプリが、指定フォーマットのメタゲーム情報（直近期間に登録された大会デッキのアーキタイプ別件数とシェア率）を取得するためのAPIである。deck-api（デッキビルダー用のAPIアプリケーション）が提供するJSON APIで、フォーマットごとに集計範囲内の大会デッキ件数をアーキタイプ別に数え、占有率を算出して返す。

本書は実装手順ではなく、誰が・いつ・どの条件で・結果どうなるかを読むためのリバース詳細設計とする。確認値はdeck-apiのメタゲーム情報取得処理、ルート定義（`config/routes.yaml`）、フォーマットマスタ・デッキを扱うリポジトリを正とする。

本機能のカスタマイズ区分は現行踏襲とする。挙動はdeck-api（デッキビルダー用APIアプリケーション）の実装を確認値とし、DB関連の記述（テーブル名・列名・永続化先）はec-cube-enterpriseの実装を正とする。

対象はJSON APIエンドポイントであり、ブラウザ向けの画面を持たない。本文ではフレームワークのコントローラ型名やメソッド名を主説明としない。「利用者視点の入口」にHTTPメソッドとパスパターンを書く。

---

## 本書で扱うこと

- 指定フォーマット（複数指定可）のアーキタイプ別大会デッキ件数の集計
- アーキタイプごとの占有率（`rate`）の算出
- 集計範囲の開始日（`from_date`）の算出
- フォーマット指定なし・該当なし時の応答

---

## 本書で扱わないこと

以下は本書では仕様確定せず、実装または別APIの設計を正とする。

- 採用カードの枚数集計（採用枚数情報参照APIの設計を正とする）
- デッキ一覧検索・デッキ詳細参照（各デッキAPIの設計を正とする）
- アーキタイプそのものの管理・登録（アーキタイプ関連の設計を正とする）

## リニューアル移行時の扱い

デッキビルダー関連テーブルは、現行（deck-api）と移行先（ec-cube-enterprise）で同一スキーマであり、テーブル名も一致する。本機能の集計に関わる主な対応は次のとおり。

| 項目 | 現行（deck-api） | 移行先（ec-cube-enterprise） | 差分・注意 |
|------|------------------|------------------------------|-----------|
| フォーマットマスタ | `mtb_format`。集計範囲はメタゲーム分析日数（`meta_range`）で算出 | `mtb_format`・`meta_range` | 同一テーブル・列名。 |
| デッキ本体 | `dtb_deck`。フォーマット（`format_id`）・公開区分（`disp_id`）・イベント日（`event_date`）・デッキ種別（`deck_type_id`）・アーキタイプ（`archetype_id`） | 同一列名 | 集計対象は公開区分が公開かつデッキ種別が大会のデッキ。 |
| アーキタイプ | `dtb_archetype`。代表カード画像はカード画像（`card_image_id`）の結合で取得 | 同一。`dtb_archetype`・`card_image_id`・`mtb_card_image` | アーキタイプ自体に画像列は持たず、カード画像テーブルを結合する。 |

現行と移行先でスキーマに差はなく、移行時に追加・改廃する集計列は本書では確認していない。

| 用語 | 説明 |
|------|------|
| フォーマット | 対戦の構築ルール区分。メタゲーム集計の単位。 |
| アーキタイプ | デッキの型・分類。集計はアーキタイプ単位で行う。 |
| 大会デッキ | 大会由来として登録されたデッキ。集計対象はデッキ種別が大会のものに限る。 |
| 集計範囲 | フォーマットごとに設定された日数（メタ範囲）で区切る直近の期間。 |
| 占有率 | フォーマット内の全大会デッキ件数に対する各アーキタイプの件数の割合。`rate`として返す。 |

## 利用者視点の入口

| 入口 | URLエンドポイント | 期待されるふるまい |
|------|--------------------|--------------------|
| メタゲーム情報参照 | `GET /metagame` | クエリの`format_id`で指定したフォーマットについて、集計範囲内の大会デッキをアーキタイプ別に集計し、件数と占有率をコード200のJSONで返す。 |

応答形式はJSON。呼び出し元はデッキビルダーアプリ。

## 認証・認可

| 観点 | 内容 |
|------|------|
| 認証方式 | 本APIは認証を行わない。`jwt-token`ヘッダの検証・プレイヤーの特定をいずれも行わず、誰でも呼び出せる参照系である。 |
| 認証失敗時 | 認証処理を持たないため、認証起因のHTTP 401は返さない。 |
| 認可 | 公開デッキのみを集計対象とするため、利用者状態によらず同一の集計結果を返す。呼び出し可能なクライアントはデッキビルダーアプリ。 |

トークン原値・署名シークレットは本書に記載しない。

## 処理フロー

### メタゲーム情報を取得する（GET `/metagame`）

1. クエリの`format_id`と`count`を受け取る。`format_id`が未指定（null）の場合は入力不正（HTTP 400）とし、「invalid request parameter」を返す。
2. `format_id`に一致するフォーマットを取得する。単一値・複数値のいずれも指定できる。該当するフォーマットが1件も無い場合は該当なし（HTTP 404）とし、「format not found」を返す。
3. 各フォーマットについて、フォーマットのメタ範囲で区切った集計範囲内の公開・大会デッキを、アーキタイプ別に件数集計する。`count`を指定した場合は件数上位から最大`count`件のアーキタイプに絞る。
4. フォーマットごとに全アーキタイプの件数合計を求め、各アーキタイプの件数を合計で割って占有率（`rate`、小数第2位まで）を算出する。
5. フォーマットごとに識別子・名称・集計範囲開始日（`from_date`）・アーキタイプ別集計（`archetypes`）を組み立て、コード200のJSONで返す。

---

## 集計条件

| 指標 | 集計の要点 |
|------|------------|
| 対象データ | デッキのうち、対象フォーマットに属し、公開区分が公開で、デッキ種別が大会のものを対象とする。 |
| 集計範囲 | イベント日（`event_date`）が、現在からフォーマットのメタ範囲日数前の0時0分から本日23時59分59秒までの範囲にあるものを対象とする。 |
| 集計単位 | アーキタイプ（`archetype_id`）でグループ化し、デッキ件数（`deck_count`）を数える。 |
| 並び順 | デッキ件数の降順で並べる。 |
| 件数制限 | クエリ`count`を指定した場合、フォーマットごとに上位`count`件のアーキタイプに絞る。未指定の場合は全件を返す。 |
| 占有率 | フォーマット内の全アーキタイプの件数合計を分母とし、各アーキタイプの件数を100分率で算出する（小数第2位まで四捨五入）。 |
| キャッシュ | 集計結果はフォーマットと件数上限ごとにキャッシュキーを分けて結果キャッシュする。 |

## 入出力

### リクエスト

| パラメータ | 位置 | 型 | 必須／任意 | 説明 |
|------------|------|----|-----------|------|
| `format_id` | クエリ | integer または array | 必須 | 集計対象のフォーマット識別子。単一値または複数値で指定する。未指定の場合は入力不正（HTTP 400）となる。 |
| `count` | クエリ | integer | 任意 | フォーマットごとに返すアーキタイプの上限件数。未指定の場合は全件を返す。 |

本APIは認証用の`jwt-token`ヘッダを必要としない。

### レスポンス（成功）

HTTP 200。応答本体はラッパオブジェクトで、JSONキーはsnake_caseで組み立てる。

| フィールド | 型 | 説明 |
|------------|----|------|
| `code` | integer | 処理結果コード。成功時は200。 |
| `formats` | array | フォーマットごとの集計結果の配列。 |
| `formats[].id` | integer | フォーマット識別子。 |
| `formats[].name_jp` | string | フォーマットの日本語名。 |
| `formats[].name_en` | string | フォーマットの英語名。 |
| `formats[].from_date` | string | 集計範囲の開始日時。`Y/m/d h:m:s`書式の文字列。 |
| `formats[].archetypes` | array | アーキタイプ別の集計結果の配列。件数降順。 |
| `formats[].archetypes[].id` | integer | アーキタイプ識別子。 |
| `formats[].archetypes[].name_jp` | string | アーキタイプの日本語名。 |
| `formats[].archetypes[].name_en` | string | アーキタイプの英語名。 |
| `formats[].archetypes[].card_image` | string | アーキタイプを代表するカード画像のURL。未設定のときはnull。 |
| `formats[].archetypes[].deck_count` | integer | 集計範囲内のデッキ件数。 |
| `formats[].archetypes[].rate` | number | フォーマット内での占有率（百分率、小数第2位まで）。 |

### レスポンス（失敗）

| HTTPステータス | 条件 | 本文の形 |
|----------------|------|----------|
| 400 | `format_id`が未指定（null） | `{code, message}`（`message`は「invalid request parameter」） |
| 404 | `format_id`に一致するフォーマットが1件も無い | `{code, message}`（`message`は「format not found」） |
| 500 | 集計処理中の例外 | 共通例外処理に委ねる |

### 副作用

無し（参照のみ）。集計結果はフォーマットと件数上限ごとに結果キャッシュするが、業務データの更新は行わない。

応答はJSON応答整形を経て返す。本APIは連想配列を組み立てて返すため、JSONキーは実装で記述したsnake_case（`code`・`formats`・`name_jp`・`from_date`・`deck_count`・`rate`等）となる。`serialize_null`は有効で、未設定項目はnullで返す。

## バリデーション

| 項目 | 内容 |
|------|------|
| `format_id` | 必須。未指定（null）の場合は入力不正（HTTP 400）とし、「invalid request parameter」を返す。一致するフォーマットが無い場合は該当なし（HTTP 404）とし、「format not found」を返す。 |
| `count` | 任意。指定した場合はフォーマットごとの返却件数の上限となる。形式の追加検証は本APIでは行わない。 |

---

## 業務ルール・計算

- 検索・一覧・取得条件はリクエストパラメータ、ログイン状態、公開状態、店舗・支店条件、既存リポジトリの絞り込み順序を正とする。
- 件数、ページ番号、表示順は既存実装のデフォルトと上限に従い、取得後に業務値を再計算しない。
- 金額、ポイント、数量、ステータス、日時はDBまたは連携元の永続化済み値を返却し、レスポンス生成時の丸め・補正は行わない。
- 条件に一致しない、権限がない、または非公開のデータは空結果または既存のエラー形式で返す。

## データ整合性

| 観点 | 内容 |
|------|------|
| 参照時点 | 呼び出し時点の集計範囲・デッキ状況に基づく集計結果を返す。本APIはデータを更新しない。結果キャッシュの有効期間内は同一結果を返す場合がある。 |
| 一覧と詳細 | 本APIはアーキタイプ別の集計のみを返し、個々のデッキ詳細とは別管理とする。デッキ詳細の値との一致は保証しない。 |

## DBカラム

機能に直接関係する列のみ記載する。型や一覧の細部はスキーマを参照する。

| テーブル | 列 | メモ |
|----------|-----|------|
| フォーマットマスタ（`mtb_format`） | 識別子（`id`）・名称（`name_jp`・`name_en`）・メタゲーム分析日数（`meta_range`） | 集計対象の特定、応答の名称、集計範囲の算出に用いる。 |
| デッキ（`dtb_deck`） | フォーマット（`format_id`）・公開区分（`disp_id`）・イベント日（`event_date`）・デッキ種別（`deck_type_id`）・アーキタイプ（`archetype_id`） | 集計対象の絞り込みとグループ化に用いる。 |
| アーキタイプ（`dtb_archetype`） | 名称（`name_jp`・`name_en`）・カード画像（`card_image_id`） | 応答のアーキタイプ名称・代表カード画像に用いる。代表カード画像はカード画像（`mtb_card_image`）を結合する。 |

### DB操作

本機能は参照系（検索）であり、DBへの登録・更新・削除は行わない。テーブル名は ec-cube-enterprise を正典とする。

| 操作種別 | 対象テーブル | 契機・条件 |
|---------|--------------|------------|
| 検索 | dtb_archetype / dtb_deck / mtb_card_image / mtb_format | 検索条件に合致するレコードを抽出する。 |
