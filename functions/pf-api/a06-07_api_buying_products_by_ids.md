# API 店頭買取管理 — 商品IDリストから買取用商品情報を取得

## 業務ロジック

### 取得対象の決め方

商品IDリストはカンマ区切りの文字列で受け取り、カンマで分解してIDの配列とする。当該商品IDに紐づく買取用商品を取得する。

商品IDリストが空または未指定のときは、空文字を分解した配列で検索するため結果は0件になる。

### 値の取り方

取得した値をそのまま応答へ整形して返す。表示用の丸め・税計算・ポイント計算・在庫数量の再計算は行わない。件数や一覧を返す場合は、検索条件を適用したあとの対象を基準にする。

### エラー時の扱い

カード商品以外のIDだけで0件になった場合もエラーとせず、0件の結果を返す。該当0件に対する専用の失敗ステータスは持たない。

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | カンマ区切りの商品IDリスト（任意）。 |
| 成功時出力 | HTTP 200。カードIDをキーとする階層構造のJSON。0件のときは空配列。 |
| 失敗時出力 | 買取アプリの利用者が管理者アカウントでないときは認証エラーを返す。 |

### 入出力: 応答の構造

カードIDをキーとする最上位のオブジェクトを持ち、その配下にカード詳細ID、言語コード、状態コードの順で入れ子になる。

| 階層 | 内容 |
|------|------|
| カード | カードの日本語名、カードの英語名、カード画像のファイル名。 |
| カード詳細 | カードセットのコード、カードセットの日本語名、フォイルか否か、カード番号、プロモーションの日本語名、商品ID、商品の日本語名、商品の英語名、レアリティのコード、保管コードの名称。カードセット・プロモーション・保管コードが未設定のときは値なしとする。 |
| 言語 | 言語コードをキーとし、配下に状態コードごとの商品規格情報を持つ。 |
| 状態 | 商品規格ID、商品コード、買取価格（未設定のときは値なし）、販売価格、在庫数、部門ID（未設定のときは値なし）。 |

### 入出力: 永続化

参照のみで、買取用商品・商品規格・在庫のいずれも更新しない。
