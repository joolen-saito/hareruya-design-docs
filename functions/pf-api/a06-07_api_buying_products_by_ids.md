# API 店頭買取管理 — 商品IDリストから買取用商品情報を取得

## 業務ロジック

### 取得対象の決め方

商品画像・カード・カード詳細・レアリティ・言語・カード状態のいずれかが登録されていない商品は、削除済みでなくても結果に含まれない。カードセット・プロモーション・保管コードは未設定でも結果に含まれる。

商品IDリストが未指定・空文字のときも入力エラーとはせず、該当する商品が無いものとして扱う。

### 同じ組に複数の商品規格が該当したときの扱い

同じカードID・カード詳細ID・言語コード・状態コードの組に複数の商品規格が該当した場合、応答に残るのは1件だけで、後から取得したものが先のものを上書きする。取得順は指定していないため、どれが残るかは定まらない。

### 値の取り方

取得した値をそのまま応答へ整形して返す。表示用の丸め・税計算・ポイント計算・在庫数量の再計算は行わない。

### エラー時の扱い

カード商品以外のIDだけで0件になった場合もエラーとせず、0件の結果を返す。該当0件に対する専用の失敗ステータスは持たない。

## 入出力

| 種類 | 内容 |
|------|------|
| 成功時出力 | 最上位のカード一覧の配下をカードIDでキー付けした階層構造。該当が0件のときは空配列を返す。 |

### 入出力: 応答の構造

応答は最上位にカード一覧を1つ持ち、その配下がカードIDをキーとするオブジェクトになる。以下カード詳細ID、言語コード、状態コードの順で入れ子になる。

| 階層 | 内容 |
|------|------|
| カード | カードの日本語名、カードの英語名、カード画像のファイル名。 |
| カード詳細 | カードセットのコード、カードセットの日本語名、フォイルか否か、カード番号、プロモーションの日本語名、商品ID、商品の日本語名、商品の英語名、レアリティのコード、保管コードの名称。カードセット・プロモーション・保管コードが未設定のときは値なしとする。 |
| 言語 | 言語コードをキーとし、配下に状態コードごとの商品規格情報を持つ。 |
| 状態 | 商品規格ID、商品コード、買取価格（未設定のときは値なし）、販売価格、在庫数、部門ID（未設定のときは値なし）。 |

### 入出力: 永続化

参照のみで、買取用商品・商品規格・在庫のいずれも更新しない。
