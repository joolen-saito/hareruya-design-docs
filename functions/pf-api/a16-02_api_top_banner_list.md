# API データ管理 — 指定言語の設定済みトップバナー一覧を取得

## 概要

言語コードを指定して、設定済みのトップバナー一覧を取得するAPIである。pf-apiが提供するJSON APIである。TODOリストの「コンテンツ管理」（A08-02）と「データ管理」（A16-02）の同一エンドポイントをまとめる。

本書は実装手順ではなく、誰が・いつ・どの条件で・結果どうなるかを読むためのリバース詳細設計とする。確認値はpf-apiのトップバナー一覧取得処理、ルート定義、トップバナー・言語マスタを扱うリポジトリを正とする。本機能のカスタマイズ区分は現行踏襲であり、挙動はpf-apiの実装を参照し、DB関連（テーブル・列）の記述はec-cube-enterpriseを正とする。

対象はJSON APIエンドポイントであり、ブラウザ向けの画面を持たない。

---

## 本書で扱うこと

- 指定言語の設定済みトップバナー一覧の取得
- 言語が存在しない場合の応答

## リニューアル移行時の扱い

本機能は現行踏襲であり、挙動の参照は現行のpf-api、DB関連の正はec-cube-enterpriseとする。テーブル名・列名は現行と移行先で一致する。移行先ではトップバナーマスタと言語マスタに表示用の追加列があるが、本APIの絞り込み条件・応答項目には影響しない。

| 項目 | 現行（pf-api） | 移行先（ec-cube-enterprise） | 扱い |
|------|----------------|------------------------------|------|
| トップバナーマスタ | `mtb_top_banner`（id・image_url・link・disp_type） | `mtb_top_banner`（id・image_url・link・disp_typeに加え、image_alt・sort_no） | 同名テーブル。移行先は alt属性（`image_alt`）と表示順（`sort_no`）の列を持つ。設定状態・言語で絞り込む。 |
| 言語関連 | `dtb_top_banner_language`（top_banner_id・language_id） | `dtb_top_banner_language`（top_banner_id・language_id） | 同一スキーマ。トップバナーと言語の多対多関連。 |
| 言語マスタ | `mtb_language`（id・name_jp・name_en・code） | `mtb_language`（id・name_jp・name_en・code・sort_no） | 同名テーブル。移行先は並び順（`sort_no`）の列を持つ。言語コードの存在確認に用いる。 |

## 利用者視点の入口

| 入口 | URLエンドポイント | 期待されるふるまい |
|------|--------------------|--------------------|
| 指定言語の設定済みトップバナー一覧取得 | `GET /topBanners/{languageCode}` | 指定言語の設定済みトップバナー一覧をJSONで返す。言語が存在しない場合は404を返す。 |

応答形式はJSON。

---

## 処理フロー

### トップバナー一覧を取得する（GET `/topBanners/{languageCode}`）

1. パスの言語コードを受け取る。
2. 指定言語の設定済みトップバナー一覧を取得する。
3. 一覧が空、または当該言語コードが言語マスタに存在しない場合はコード404のJSONを返す。
4. 取得できた場合はトップバナー一覧をJSONで返す。

## 入出力

### リクエスト

| パラメータ | 位置 | 型 | 必須／任意 | 説明 |
|------------|------|----|-----------|------|
| `languageCode` | パス | string | 必須 | 絞り込み対象の言語コード。 |

### レスポンス（成功）

HTTP 200。本APIはトップバナーオブジェクトの配列をそのまま返す（ラップオブジェクトを持たない）。各要素のフィールドは次のとおり。

| フィールド | 型 | 説明 |
|------------|----|------|
| `id` | integer | トップバナーID。 |
| `imageUrl` | string | 画像URL。 |
| `link` | string | リンク先URL。 |
| `dispType` | integer | 表示タイプ。 |
| `languages` | array | 関連する言語の配列。要素はオブジェクトで、子フィールドは`id`（integer、言語ID）、`nameJp`（string、言語名・日本語）、`nameEn`（string、言語名・英語）、`code`（string、言語コード）。 |

### レスポンス（失敗）

| HTTPステータス | 条件 | 本文の形 |
|----------------|------|----------|
| 404 | 一覧が空かつ当該言語コードが言語マスタに存在しない | `{code, message}`（"Language code is not found"） |

### サンプルレスポンス

成功時の応答例（実装確認値に基づく代表値）。

```json
[
  {
    "id": 1,
    "imageUrl": "https://example.com/banner/top_001.png",
    "link": "https://example.com/campaign",
    "dispType": 1,
    "languages": [
      { "id": 1, "nameJp": "日本語", "nameEn": "Japanese", "code": "ja" }
    ]
  }
]
```

### 副作用

無し（参照のみ）。

応答はJSON応答整形を経て返す。プロパティはcamelCase、日時はISO8601とする。

- 検索・一覧・取得条件はリクエストパラメータ、ログイン状態、公開状態、店舗・支店条件、既存リポジトリの絞り込み順序を正とする。
- 件数、ページ番号、表示順は既存実装のデフォルトと上限に従い、取得後に業務値を再計算しない。
- 金額、ポイント、数量、ステータス、日時はDBまたは連携元の永続化済み値を返却し、レスポンス生成時の丸め・補正は行わない。
- 条件に一致しない、権限がない、または非公開のデータは空結果または既存のエラー形式で返す。

## DBカラム

機能に直接関係する範囲のみ記載する。テーブル名・列名はec-cube-enterpriseを正とする。

| テーブル | 列 | メモ |
|---------|-----|------|
| トップバナーマスタ（`mtb_top_banner`） | id・image_url・link・disp_type | 指定言語の設定済みトップバナーの取得・応答に用いる。 |

| 操作種別 | 対象テーブル | 契機・条件 |
|---------|--------------|------------|
| 検索 | dtb_top_banner_language / mtb_language / mtb_top_banner | 検索条件に合致するレコードを抽出する。 |
