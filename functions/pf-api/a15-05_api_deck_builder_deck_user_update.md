# API デッキビルダー — ユーザー情報変更

## 業務ロジック

### 更新対象

認証トークンの利用者識別子に対応する顧客からプレイヤーを特定し、そのプレイヤー自身の情報のみを更新する。他プレイヤーの情報は更新できない。トークンを検証できないとき、該当するプレイヤーが無いときは認証拒否（HTTP 401）とする。

### 更新する内容

プレイヤーのニックネームを受け取ったユーザー名で、プロフィールを受け取った値で更新する。ユーザー名が未指定のときは入力不正（HTTP 400）とし、更新しない。プロフィールが未指定のときはnullとして保存する。更新中に例外が発生したときは更新を取り消し、処理失敗（HTTP 500）として例外メッセージを返す。

金額・税・ポイント・在庫数量の再計算や丸めは行わない。トークン原値・署名シークレットは本書に記載しない。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| 認証不可 | 認証拒否（HTTP 401）とし、処理結果コードとメッセージを返す |
| ユーザー名未指定 | 入力不正（HTTP 400）とし、「Invalid request parameters」を返す |
| 更新中の例外 | 更新を取り消し、処理失敗（HTTP 500）として例外メッセージを返す |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 認証トークン、ユーザー名、プロフィール |
| 成功時出力 | HTTP 200。処理結果コード200とメッセージ「Update user information」 |
| 失敗時出力 | HTTP 401（認証不可）、HTTP 400（ユーザー名未指定）、HTTP 500（更新中の例外） |

### 入出力: エンドポイント

エンドポイントは PUT /user とする。

### 入力: リクエスト

| パラメータ | 位置 | 型 | 必須／任意 | 説明 |
|------------|------|----|-----------|------|
| `jwt-token` | ヘッダ | string | 必須 | 認証用のトークン。利用者識別子の顧客IDからプレイヤーを引く |
| `user_name` | ボディ | string | 必須 | 設定するニックネーム。未指定（null）の場合は入力不正（HTTP 400）となる |
| `profile` | ボディ | string | 任意 | 設定するプロフィール。未指定の場合はnullとして保存する |

### 出力: レスポンス（成功）

応答本体のJSONキーはスネークケースで組み立てる。

| フィールド | 型 | 説明 |
|------------|----|------|
| `code` | integer | 処理結果コード。成功時は200 |
| `message` | string | 結果メッセージ。成功時は「Update user information」 |

```json
{
  "code": 200,
  "message": "Update user information"
}
```

### 出力: レスポンス（失敗）

| HTTPステータス | 条件 | 本文の形 |
|----------------|------|----------|
| 401 | 認証トークンの欠落・署名不正・該当するプレイヤーなし | メッセージは「Access Token is incorrect」または「Authentication failed」 |
| 400 | ユーザー名が未指定（null） | メッセージは「Invalid request parameters」 |
| 500 | 更新中に例外が発生（保存失敗） | メッセージは例外メッセージ。更新は取り消す |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 更新 | ユーザー情報変更時に、プレイヤーのニックネームとプロフィールを更新する |

## 表示メッセージ

| メッセージID | 表示位置 | 画面上の文言 | 表示条件 | 後続処理 |
|---|---|---|---|---|
| — | API応答JSON | Update user information | ユーザー情報の更新に成功したとき | HTTP 200を返して終了する |
| — | API応答JSON | Invalid request parameters | ユーザー名が未指定のとき | HTTP 400を返し、更新しない |
| — | API応答JSON | Access Token is incorrect | 認証トークンを検証できないとき | HTTP 401を返し、更新しない |
| — | API応答JSON | Authentication failed | 認証トークンに該当するプレイヤーが無いとき | HTTP 401を返し、更新しない |
