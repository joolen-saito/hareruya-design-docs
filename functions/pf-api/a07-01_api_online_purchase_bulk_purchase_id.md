# API ネット買取管理 — まとめて買取商品IDの取得

## 業務ロジック

### 認証と呼び出し元

認証用トークンを検証し、トークンが持つ利用者IDから管理者会員を特定する。トークン欠落・署名不正・該当する管理者会員なしのいずれの場合も認証拒否とする。呼び出せるクライアントは買取アプリに限る。トークン原値・署名シークレットは本書に記載しない。

### 取得する値

まとめ買取商品IDのキーに対応するオプション設定があるときだけ、その値を応答本体とする。応答本体は値そのものであり、包む構造を持たない。

取得した値をそのまま返し、金額・税・ポイント・在庫数量の再計算と丸めはどの場合も行わない。表示のための加工は呼び出し元のクライアントを正とする。

このAPIはリクエストパラメータを持たないため、条件による絞り込みも行わない。

### エラー時の扱い

| エラー内容 | 処理 |
| --- | --- |
| 認証できない | 認証拒否（HTTP 401）とする |
| まとめ買取商品IDの設定がオプション設定に無い | 設定値の参照で例外となり、共通の例外処理に委ねる（HTTP 500 相当） |

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | 認証用トークンだけを必要とし、ほかのパラメータを持たない |
| 成功時出力 | HTTP 200。応答本体はまとめ買取商品IDの文字列 |
| 失敗時出力 | 認証できないときは HTTP 401 で本文を持たない。設定が無いときは HTTP 500 相当 |

### 入出力: 永続化

この機能ではデータを更新しない。

## 表示メッセージ

本APIは画面へ文言を表示しない。
