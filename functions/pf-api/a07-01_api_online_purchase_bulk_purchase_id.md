# API ネット買取管理 — まとめて買取商品IDの取得

## 概要

買取アプリ（MTGバイヤー）が、まとめ買取（まとめて買取）で用いる商品IDを取得するためのAPIである。pf-api（買取連携用のAPIアプリケーション）が提供するJSON APIで、オプションマスタに設定されたまとめ買取商品IDの値を返す。

本書は実装手順ではなく、誰が・いつ・どの条件で・結果どうなるかを読むためのリバース詳細設計とする。確認値はpf-apiのまとめ買取商品ID取得処理、ルート定義（`config/routes.yaml`）、オプションマスタ、共通の認証処理を正とする。

本機能のカスタマイズ区分は現行踏襲であり、挙動の参照リポはpf-api、DB関連（テーブル名・列名・永続化先）の記述はec-cube-enterpriseを正とする。

対象はJSON APIエンドポイントであり、ブラウザ向けの画面を持たない。本文ではフレームワークのコントローラ型名やメソッド名を主説明としない。「利用者視点の入口」にHTTPメソッドとパスパターンを書く。

## リニューアル移行時の扱い

現行（pf-api）と移行先（ec-cube-enterprise）の差を記録する。挙動は現行（pf-api）を正とし、DB関連はec-cube-enterpriseを正とする。

| 観点 | 現行（pf-api） | 移行先（ec-cube-enterprise） |
|------|----------------|------------------------------|
| 保存先テーブル | オプションマスタ `mtb_option`。オプションキー `option_key`・オプション値 `option_value`。 | 同一スキーマ。`mtb_option` のオプションキー `option_key`・オプション値 `option_value`。 |
| 設定キー | まとめ買取商品IDのキー（実装定数 `BULK_PURCHASE_ID_KEY`）。 | 同等のキー定数（`MtbOption::BULK_PURCHASE_ID`）。キー文字列の同一性は移行データで要確認。 |
| 設定が無い場合の挙動 | 設定値の参照で例外となり処理が失敗する（HTTP 500相当）。 | オプション未設定時は空文字列を返す（HTTP 200）。例外とはしない。移行後はこの挙動に変わる。 |
| エンドポイントの配置 | サイトルート直下 `/admin/optionBulkPurchaseId.json`。 | APIバージョンのルートプレフィックス（設定キー `eccube_api_v1_route`）配下に配置される。パス末尾の `optionBulkPurchaseId.json` は同じ。 |

| 入口 | URLエンドポイント | 期待されるふるまい |
|------|--------------------|--------------------|

## 認証・認可

| 観点 | 内容 |
|------|------|
| 認証方式 | `jwt-token`ヘッダのJWTを検証し、ペイロードの利用者IDから管理者会員を引く。署名方式はHS256。 |
| 認証失敗時 | ヘッダ欠落・署名不正・該当する管理者会員なしのいずれも認証拒否（HTTP 401）とする。 |
| 認可 | 呼び出し可能なクライアントは買取アプリ。 |

トークン原値・署名シークレットは本書に記載しない。

---

## 処理フロー

### まとめ買取商品IDを取得する（GET `/admin/optionBulkPurchaseId.json`）

1. `jwt-token`ヘッダのトークンを検証し、管理者会員を特定する。検証できない場合は認証拒否（HTTP 401）とする。
2. オプションマスタからまとめ買取商品IDのキーに対応する設定を取得し、その値を応答本体として返す。

## 入出力

### リクエスト

本APIはリクエストパラメータを持たない。認証用の`jwt-token`ヘッダのみを必要とする。

### レスポンス（成功）

HTTP 200。応答本体はまとめ買取商品IDの値そのものであり、ラッパオブジェクトを持たない。

| フィールド | 型 | 説明 |
|------------|----|------|
| （応答本体） | string | まとめ買取商品ID。オプションマスタの設定値（文字列）。 |

### レスポンス（失敗）

| HTTPステータス | 条件 | 本文の形 |
|----------------|------|----------|
| 401 | トークン欠落・署名不正・該当する管理者会員なし | 認証拒否（本文を持たない） |
| 500 | まとめ買取商品IDの設定がオプションマスタに存在しない（設定値の参照で例外） | 共通例外処理に委ねる |

### サンプルレスポンス

成功時の応答例（応答本体は単一の文字列値）。

```json
"2000001"
```

### 副作用

無し（参照のみ）。

応答はJSON応答整形を経て返す。
