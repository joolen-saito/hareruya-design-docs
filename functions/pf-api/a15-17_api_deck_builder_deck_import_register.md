# API デッキビルダー — デッキ登録インポート

## 業務ロジック

### 登録対象

パスにデッキ識別子を持たないときは新規デッキを対象とする。既存デッキの取得と所有者の照合は行わない。認証したプレイヤーを新規デッキの所有者として登録する。

### カードリストの解読

フォーマットの識別子からフォーマットを取得し、そのフォーマットの統率者使用設定に応じてカードリストを解読する。カードリストは枚数とカード名の行を並べた形式とする。未指定または空のときは空のカード配列として扱う。

カードリストの行数が500行を超えるときは入力不正（HTTP 400）とする。

カード名が一致せず解読できない行があるときは、登録は完了させたうえで処理結果コードを206に切り替え、該当行の行番号を返す。行番号は0から数える。

### 登録の可否

解読したカードとデッキ名・公開区分・アーキタイプ等で新規デッキを組み立て、検証を通過したときだけ保存する。検証エラーは入力不正（HTTP 400）、その他の例外は処理失敗（HTTP 500）とする。

保存したときは、当該デッキの下書きとして保持している一時保存も削除する。

### 応答の内容

新規デッキの識別子を返す。公開区分が限定公開のときだけ、表示用トークンをあわせて返す。限定公開以外のときは表示用トークンを返さない。

### 他機能との境界

認証用トークンを検証し、トークンに含まれる顧客IDからプレイヤーを引く。署名方式はHS256とする。トークンが無い、署名が不正、該当するプレイヤーが無いときは、いずれも認証拒否（HTTP 401）とする。呼び出し可能なクライアントはデッキビルダーアプリとする。トークンの原値と署名シークレットは本書に記載しない。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| トークンが無い、署名が不正、該当するプレイヤーが無い | 認証拒否（HTTP 401）とし、処理結果コードとメッセージ（「Access Token is incorrect」または「Authentication failed」）を返す |
| 必須項目不足・不正値、またはカードリストが500行を超える | 入力不正（HTTP 400）とし、処理結果コードと検証エラーメッセージを返す |
| 解読できない行がある | 登録は完了させ、処理結果コード206として該当行の行番号を返す |
| 保存処理中のその他の例外 | 処理失敗（HTTP 500）とし、処理結果コードと例外メッセージを返す |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 認証用トークン（ヘッダ・必須）とフォーマットの識別子（必須）。カードリスト・デッキ名・公開区分・アーキタイプの識別子・デッキ画像に用いるカードの識別子・キャンペーンタグの識別子は、いずれも指定が無いときは扱わない |
| 成功時出力 | 全行を解読できたときはHTTP 200、解読できない行があるときはHTTP 206。処理結果コード・処理結果メッセージ（「Deck registration success by import」）・登録したデッキの識別子。限定公開のときだけ表示用トークン、解読できない行があるときだけ該当行の行番号 |
| 失敗時出力 | 認証できないときはHTTP 401、入力が不正なときはHTTP 400、その他の例外のときはHTTP 500。処理結果コードとメッセージ |

キャンペーンタグの識別子は、単一値と配列のどちらのときも受け取る。

### 入出力: 永続化

| 操作 | 契機 |
|------|------|
| 追加 | 検証を通過したとき。新規デッキと採用カードを登録する |
| 削除 | 登録したとき。当該デッキの下書きの一時保存を削除する |

## 表示メッセージ

本APIは画面を持たない。応答本文の処理結果メッセージは入出力の節を正とする。
