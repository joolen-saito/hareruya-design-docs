# API デッキビルダー — デッキ情報参照

## 業務ロジック

### 参照元の優先順位

| 順序 | 参照元 | 扱い |
| --- | --- | --- |
| 1 | 一時保存された下書き | デッキIDに対応する下書きがあれば、それを参照対象とする |
| 2 | 保存済みのデッキ情報 | 下書きが無いときに、デッキIDで取得する |

下書きから返すときは、フォーマット名・アーキタイプ名・代表カード画像をマスタから補完する。

### 参照できる条件

公開範囲ごとに参照の可否を判定する。判定は下書き・保存済みのどちらでも同じである。

| 公開範囲 | 参照できる条件 |
| --- | --- |
| 公開 | 誰でも参照できる |
| 非公開 | 所有者本人と確認できるときだけ参照できる |
| 限定公開 | 限定公開トークンが一致するとき、または所有者本人のときだけ参照できる |

所有者の判定は、認証トークンの検証で得た顧客IDからプレイヤーを引いて行う。トークンが無い、または有効でないときは所有者扱いにしない。トークンが無くても公開デッキは参照できるため、トークン欠落だけを理由に認証拒否を返すことはない。

トークン原値・署名シークレット・限定公開トークン原値は本書に記載しない。

### 件数

1件のデッキを参照する機能であり、ページングの指定と件数の応答を持たない。

### 値の取り方

金額・ポイント・数量・ステータス・日時は永続化済みの値をそのまま返し、応答生成時の丸め・補正を行わない。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| デッキが存在しない | 該当なし（HTTP 404、「Deck is not found」）とする |
| 公開範囲の判定で参照不可 | 該当なし（HTTP 404、「Deck is not found」）とし、存在の有無を区別しない |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | デッキID（パス・必須）、限定公開デッキの閲覧用トークン（任意）、認証トークン（任意。非公開・限定公開デッキを所有者として参照するときに必要） |
| 成功時出力 | HTTP 200。処理結果コード200と「Get deck success」、デッキ情報 |
| 失敗時出力 | HTTP 404。処理結果コードとメッセージ「Deck is not found」 |

### 出力: デッキ情報の項目

| フィールド | 型 | 説明 |
|------------|----|------|
| デッキ名 | string | デッキ名。 |
| フォーマット | integer/string | 識別子、日本語名、英語名。 |
| アーキタイプ | integer/string | 識別子、日本語名、英語名。 |
| 代表カード | integer/string | カードIDと画像URL。 |
| デッキ種別 | string | デッキ種別。 |
| 公開範囲 | integer | 1・2・3。 |
| 非公開フラグ | boolean | 非公開フラグ。 |
| 大会情報 | string | 大会名（日本語・英語）・大会日付・プレイヤー名・成績・順位・出典URL。大会デッキのときに値を持つ。 |
| 作成日時・更新日時 | string | 作成日時と更新日時。 |
| 限定公開トークン | string | 限定公開トークン。 |
| 所有プレイヤー | string | デッキ利用者IDと、ユーザーデッキのときのニックネーム。 |
| デッキタグ | array | 識別子・日本語名・英語名。タグがあるときに含める。 |
| キャンペーンタグ | array | 識別子・日本語名・英語名・開催状態（開催前0・開催中1・開催後2）。 |
| 採用カード | array | 識別子・日本語名・英語名・日本語画像・英語画像・カードタイプ・色・マナ総量・枚数・ボード区分・ステッカー可否・アトラクション可否・不明カード可否。 |

## 表示メッセージ

| メッセージID | 表示位置 | 画面上の文言 | 表示条件 | 後続処理 |
| --- | --- | --- | --- | --- |
| — | API応答JSON | Get deck success | 参照できる条件を満たしてデッキ情報を返すとき | 処理結果コード200で応答する |
| — | API応答JSON | Deck is not found | デッキが存在しない、または公開範囲の判定で参照不可のとき | HTTP 404で応答する |
