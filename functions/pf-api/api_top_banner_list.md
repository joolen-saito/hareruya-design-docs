# API データ管理 — 指定言語の設定済みトップバナー一覧を取得

## 業務ロジック

### 取得対象

パスで指定した言語コードの、設定済みトップバナー一覧を取得する。

一覧が空で、かつ当該言語コードが言語マスタに存在しないときは、該当なしとして返す。

### 値の取り方

金額・ポイント・数量・ステータス・日時は永続化済みの値をそのまま返し、応答を作るときの丸め・補正は行わない。件数・ページ番号・表示順は既存の既定と上限に従い、取得後に業務値を計算し直さない。

条件に一致しない、権限が無い、非公開のデータは、空の結果または既存のエラー形式で返す。

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 絞り込み対象の言語コード（必須）。 |
| 成功時出力 | HTTP 200。トップバナーの配列。包むオブジェクトは持たない。 |
| 失敗時出力 | HTTP 404。結果コードとメッセージ。 |

### 入出力: 応答の項目

| 単位 | 項目 |
|------|------|
| トップバナー | トップバナーID、画像URL、リンク先URL、表示タイプ、関連する言語の配列。 |
| 言語 | 言語ID、言語名（日本語）、言語名（英語）、言語コード。 |

### 入出力: 永続化

参照のみを行い、データを更新しない。

## 表示メッセージ

| メッセージID | 表示位置 | 画面上の文言 | 表示条件 | 後続処理 |
| --- | --- | --- | --- | --- |
| — | API応答JSON | Language code is not found | 一覧が空で、かつ当該言語コードが言語マスタに存在しないとき | 一覧を返さずHTTP 404で返す |
