# API デッキビルダー — アーキタイプ検索

## 概要

デッキビルダーアプリが、指定したフォーマットに属するアーキタイプ（デッキの型）の一覧を取得するためのAPIである。deck-api（デッキビルダー用のAPIアプリケーション）が提供するJSON APIで、URLのパスで指定したフォーマットIDに紐づくアーキタイプの識別子と日英の名称を返す。

本書は実装手順ではなく、誰が・いつ・どの条件で・結果どうなるかを読むためのリバース詳細設計とする。確認値はdeck-apiのアーキタイプ取得処理、ルート定義（`config/routes.yaml`）、フォーマットマスタおよびアーキタイプのリポジトリを正とする。本機能のカスタマイズ区分は現行踏襲であり、挙動はデッキビルダーAPI（deck-api）の実装を参照し、DB関連の記述はec-cube-enterpriseを正とする。

対象はJSON APIエンドポイントであり、ブラウザ向けの画面を持たない。本文ではフレームワークのコントローラ型名やメソッド名を主説明としない。「利用者視点の入口」にHTTPメソッドとパスパターンを書く。

---

## 本書で扱うこと

- フォーマットIDからアーキタイプ一覧を取得するふるまい
- 指定フォーマットが存在しない場合のふるまい
- 応答に含めるアーキタイプの項目

---

## 本書で扱わないこと

以下は本書では仕様確定せず、実装または別APIの設計を正とする。

- アーキタイプIDから単一アーキタイプを取得する処理（本APIの入口に含めない）
- フォーマットマスタそのものの取得（マスタ検索の設計を正とする）
- アーキタイプの登録・更新（管理側の設計を正とする）

---

## リニューアル移行時の扱い

DB関連の記述はec-cube-enterpriseを正とする。挙動の参照元であるデッキビルダーAPI（deck-api）は提供リポジトリに含まれないため、現行deck-apiと移行先ec-cube-enterpriseでスキーマが異なる場合はec-cube-enterpriseを正とし、確認できない差異はec-cube-enterprise実装で要確認とする。ec-cube-enterpriseでは、アーキタイプ（`dtb_archetype`）が識別子（`archetype_id`／`id`）・日本語名（`name_jp`）・英語名（`name_en`）・所属フォーマット（`format_id`）を持ち、フォーマット（`mtb_format`）でフォーマットの実在を判定する。

| 観点 | 現行（deck-api） | 移行先（ec-cube-enterprise） |
|------|------------------|------------------------------|
| アーキタイプテーブル | deck-api実装で要確認 | アーキタイプ（`dtb_archetype`） |
| 日本語名・英語名列 | 応答`name_jp`・`name_en` | `name_jp`・`name_en` |
| フォーマット紐づけ | フォーマットIDで絞り込み | `format_id`（`mtb_format`を参照） |

## 用語

| 用語 | 説明 |
|------|------|
| フォーマット | 使用可能なカード範囲を定めるルール区分。フォーマットマスタで識別子を持つ。 |
| アーキタイプ | 同一フォーマット内のデッキの型・分類。日本語名と英語名を持つ。 |

## 利用者視点の入口

| 入口 | URLエンドポイント | 期待されるふるまい |
|------|--------------------|--------------------|
| アーキタイプ検索 | `GET /archetypes/{formatId}` | 指定フォーマットに属するアーキタイプ一覧を、ラッパとともに返す。フォーマットが存在しない場合は該当なし（HTTP 404）とする。 |

応答形式はJSON。呼び出し元はデッキビルダーアプリ。

---

## 認証・認可

| 観点 | 内容 |
|------|------|
| 認証方式 | 認証を行わない。本APIは`jwt-token`ヘッダを参照せず、トークン検証もプレイヤーの照合も行わない。共通基底のプレイヤー認証処理を呼び出さない。 |
| 認証失敗時 | 認証処理を持たないため、認証起因の拒否（HTTP 401）を返さない。 |
| 認可 | 呼び出し可能なクライアントはデッキビルダーアプリ。利用者の状態によらず参照できる。 |

トークン原値・署名シークレットは本書に記載しない。

---

## 処理フロー

### アーキタイプ一覧を取得する（GET `/archetypes/{formatId}`）

1. パスのフォーマットIDを受領し、フォーマットマスタから該当フォーマットを取得する。
2. フォーマットが存在しない場合は、該当なし（HTTP 404）として`{code, message}`形式のJSONを返す。
3. 該当フォーマットに紐づくアーキタイプを取得し、識別子・日本語名・英語名を選択する。
4. 取得結果を`code`と`archetypes`のラッパに包んで返す（HTTP 200）。

---

## 集計条件

本APIは指定フォーマットに属するアーキタイプの全件取得であり、件数集計・ページングを行わない。対象範囲は次のとおり。

| 指標 | 集計の要点 |
|------|------------|
| 取得対象 | パスのフォーマットに紐づくアーキタイプの全件。 |
| 抽出項目 | アーキタイプ識別子・日本語名・英語名のみを選択する。 |
| 並び順 | 取得クエリに明示の並び替えは無く、既定順で返す。 |
| ページング | 行わない。全件を一括で返す。 |

---

## 入出力

### リクエスト

| パラメータ | 位置 | 型 | 必須／任意 | 説明 |
|------------|------|----|-----------|------|
| formatId | パス | integer | 必須 | フォーマットの識別子。フォーマットマスタに存在する識別子を指定する。 |

### レスポンス（成功）

HTTP 200。応答はラッパオブジェクトを持つ。

| フィールド | 型 | 説明 |
|------------|----|------|
| code | integer | 処理結果コード。成功時は200。 |
| archetypes | array | アーキタイプ行の配列。 |
| archetypes[].id | integer | アーキタイプの識別子。 |
| archetypes[].name_jp | string | アーキタイプの日本語名。 |
| archetypes[].name_en | string | アーキタイプの英語名。 |

応答配列要素のキーは`id`・`name_jp`・`name_en`であり、取得クエリのエイリアスのままsnake_caseで返す。

### レスポンス（失敗）

| HTTPステータス | 条件 | 本文の形 |
|----------------|------|----------|
| 404 | 指定フォーマットIDに該当するフォーマットが存在しない | `{code: 404, message: "The format does not exist"}` |
| 500 | 取得処理中の例外 | 共通例外処理に委ねる |

### サンプルレスポンス

成功時の応答例（実装確認値に基づく代表値）。

```json
{
  "code": 200,
  "archetypes": [
    {
      "id": 1,
      "name_jp": "白単アグロ",
      "name_en": "Mono White Aggro"
    },
    {
      "id": 2,
      "name_jp": "青黒コントロール",
      "name_en": "Dimir Control"
    }
  ]
}
```

### 副作用

無し（参照のみ）。取得クエリにはフォーマット単位の結果キャッシュ（既定の保持時間つき）を用いるが、業務データの更新・履歴・通知は行わない。

応答はJSON応答整形を経て返す。プロパティはcamelCase、日時はISO8601、`serialize_null`は有効とする。本APIの配列要素キーは取得クエリのエイリアス（snake_case）に従う。

## 業務ルール・計算

- 検索・一覧・取得条件はリクエストパラメータ、ログイン状態、公開状態、店舗・支店条件、既存リポジトリの絞り込み順序を正とする。
- 件数、ページ番号、表示順は既存実装のデフォルトと上限に従い、取得後に業務値を再計算しない。
- 金額、ポイント、数量、ステータス、日時はDBまたは連携元の永続化済み値を返却し、レスポンス生成時の丸め・補正は行わない。
- 条件に一致しない、権限がない、または非公開のデータは空結果または既存のエラー形式で返す。

## データ整合性

| 観点 | 内容 |
|------|------|
| 参照時点 | 呼び出し時点のアーキタイプを返す。結果キャッシュの保持時間内は同一内容を返すことがある。本APIはデータを更新しない。 |
| 一覧と詳細 | 本APIは一覧のみを返す。単一アーキタイプの詳細取得は本書で扱わない。 |

## DBカラム

機能に直接関係する列のみ記載する。型や一覧の細部はスキーマを参照する。

テーブル名・列名はec-cube-enterpriseの定義を正とする。

| テーブル | 列 | メモ |
|----------|-----|------|
| アーキタイプ（`dtb_archetype`） | アーキタイプ識別子（`archetype_id`／`id`） | 応答`id`に対応。 |
| アーキタイプ（`dtb_archetype`） | 日本語名（`name_jp`） | 応答`name_jp`に対応。 |
| アーキタイプ（`dtb_archetype`） | 英語名（`name_en`） | 応答`name_en`に対応。 |
| アーキタイプ（`dtb_archetype`） | フォーマット（`format_id`） | 指定フォーマットでの絞り込みに用いる。 |
| フォーマットマスタ（`mtb_format`） | 識別子 | パスのフォーマットIDで実在を判定する。 |

### DB操作

本機能は参照系（検索）であり、DBへの登録・更新・削除は行わない。テーブル名は ec-cube-enterprise を正典とする。

| 操作種別 | 対象テーブル | 契機・条件 |
|---------|--------------|------------|
| 検索 | dtb_archetype / mtb_format | 検索条件に合致するレコードを抽出する。 |
