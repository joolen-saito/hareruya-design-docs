# API デッキビルダー — アーキタイプ検索

## 業務ロジック

### 取得対象

パスで指定したフォーマットに紐づくアーキタイプを返す。返す値は識別子・日本語名・英語名である。指定したフォーマットがフォーマットマスタに存在しないときは、該当なし（HTTP 404）とする。

### 認証

本APIは認証を行わない。認証用トークンのヘッダを参照せず、利用者の照合もしない。認証起因の拒否（HTTP 401）は返さない。呼び出し可能なクライアントはデッキビルダーアプリで、利用者の状態によらず参照できる。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| 指定フォーマットが存在しない | コード404・メッセージ「The format does not exist」を返す |
| 取得処理中の例外 | 共通例外処理に委ねる（HTTP 500相当） |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | パスのフォーマット識別子（必須、整数）。フォーマットマスタに存在する識別子を指定する |
| 成功時出力 | HTTP 200。処理結果コードとアーキタイプ配列を含むラッパオブジェクト |
| 失敗時出力 | 該当フォーマットが無いときはHTTP 404でコードとメッセージ。取得中の例外は共通例外処理に委ねる |

### 出力: フィールド

| フィールド | 型 | 説明 |
|------------|----|------|
| code | integer | 処理結果コード。成功時は200。 |
| archetypes | array | アーキタイプ行の配列。 |
| archetypes[].id | integer | アーキタイプの識別子。 |
| archetypes[].name_jp | string | アーキタイプの日本語名。 |
| archetypes[].name_en | string | アーキタイプの英語名。 |

配列要素のキーは id・name_jp・name_en であり、取得時のまま区切り記号付きの小文字で返す。

成功時の応答例（実装確認値に基づく代表値）。

```json
{
  "code": 200,
  "archetypes": [
    {
      "id": 1,
      "name_jp": "白単アグロ",
      "name_en": "Mono White Aggro"
    },
    {
      "id": 2,
      "name_jp": "青黒コントロール",
      "name_en": "Dimir Control"
    }
  ]
}
```

## 表示メッセージ

本APIは画面メッセージを扱わない。
