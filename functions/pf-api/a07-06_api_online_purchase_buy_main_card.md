# API ネット買取管理 — 複数ネット買取IDからネット買取受注の商品一覧を取得

## 業務ロジック

### 取得する対象

該当する買取代表カードが1件も無いときは、エラーとせず空配列を返す。ネット買取受注IDを1件も指定しなかったときや空文字を指定したときも、該当0件として空配列を返す。

### 申込時買取価格の付与

一致する申込時買取価格が1件も無い買取代表カードには、申込時買取価格の項目そのものを付けない（空のオブジェクトも返さない）。

査定金額・申込時買取価格の再計算や表示用の丸めは行わず、取得した値をそのまま応答へ返す。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| 認証不可 | 認証拒否（HTTP 401）とする |
| 該当0件 | エラーとせず空配列を返す |
| 取得処理中の例外 | 処理失敗（HTTP 500）とする |

## 入出力

### 入力: リクエスト

| パラメータ | 位置 | 説明 |
|------------|------|------|
| 認証トークン | ヘッダ | 認証用のトークン。ヘッダに無いときは認証拒否とする |

### 出力: レスポンス（成功）

枚数・査定金額・言語ID・Foilフラグ・カード状態ID・売却フラグは、未設定のとき null をそのまま返す（既定値で補わない）。買取代表カードID・ネット買取受注ID・商品ID・買取カテゴリは常に値を持つ。

### 出力: レスポンス（失敗）

| HTTPステータス | 条件 | 本文の形 |
|----------------|------|----------|
| 401 | トークン欠落・署名不正・該当する管理者なし | 認証拒否（本文を持たない） |
| 500 | 取得処理中の例外 | 処理失敗として返す |

## 表示メッセージ

| メッセージID | 表示位置 | 画面上の文言 | 表示条件 | 後続処理 |
|--------------|----------|--------------|----------|----------|

本APIは画面へ表示するメッセージを返さない。
