# API ネット買取管理 — 複数ネット買取IDからネット買取受注の商品一覧を取得

## 概要

複数のネット買取受注IDを指定して、それらの受注に紐づく買取代表カードの一覧をまとめて取得するAPIである。pf-api（買取連携用のAPIアプリケーション）が提供するJSON APIで、受注IDごとの代表カード（商品ID・言語・状態・査定金額・枚数など）と、各代表カードの状態別の申込時買取価格を返す。

本書は実装手順ではなく、誰が・いつ・どの条件で・結果どうなるかを読むためのリバース詳細設計とする。確認値はpf-apiの買取代表カード一括取得処理、ルート定義（`config/routes.yaml`）、買取代表カードと申込時価格を扱うリポジトリ・エンティティ、共通の認証処理を正とする。本機能のカスタマイズ区分は現行踏襲であり、挙動はpf-apiの実装を参照し、DB関連（テーブル・列）の記述はec-cube-enterpriseを正とする。

対象はJSON APIエンドポイントであり、ブラウザ向けの画面を持たない。本文ではフレームワークのコントローラ型名やメソッド名を主説明としない。「利用者視点の入口」にHTTPメソッドとパスパターンを書く。

---

## 本書で扱うこと

- 複数のネット買取受注IDによる買取代表カード一覧の一括取得
- 各代表カードへの状態別の申込時買取価格の付与
- 認証、該当0件時の応答

---

## 本書で扱わないこと

以下は本書では仕様確定せず、実装または別APIの設計を正とする。

- 個別入力商品の一覧取得（複数ネット買取IDからの個別入力商品一覧取得APIの設計を正とする）
- ネット買取受注そのものの登録・査定・ステータス更新（各ネット買取APIの設計を正とする）
- 店頭買取の代表カード取得（店頭買取の各APIの設計を正とする）
- トークンの発行（買取アプリ用ログインの設計を正とする）

| 入口 | URLエンドポイント | 期待されるふるまい |
|------|--------------------|--------------------|
| 複数ネット買取IDから買取代表カード一覧取得 | `POST /admin/buyMainCard.json` | カンマ区切りのネット買取受注IDリストに紐づく買取代表カードの配列をJSONで返す。各要素に状態別の申込時買取価格を付与する。該当0件のときは空配列を返す。 |

## 認証・認可

| 観点 | 内容 |
|------|------|
| 認証方式 | `jwt-token`ヘッダのJWTを検証し、ペイロードの利用者IDから管理者会員を引く。署名方式はHS256。 |
| 認証失敗時 | ヘッダ欠落・署名不正・該当する管理者会員なしのいずれも認証拒否（HTTP 401）とする。 |
| 認可 | 認証した管理者会員のみ呼び出せる。呼び出し可能なクライアントは買取アプリ。 |

トークン原値・署名シークレットは本書に記載しない。

## 処理フロー

### 複数ネット買取IDから買取代表カード一覧を取得する（POST `/admin/buyMainCard.json`）

1. `jwt-token`ヘッダのトークンを検証し、管理者会員を特定する。検証できない場合は認証拒否（HTTP 401）とする。
2. リクエストのネット買取受注IDリスト（`ids`、カンマ区切り文字列）を受け取り、カンマで分解してIDの配列とする。
3. 買取代表カードのリポジトリから、当該買取受注IDリストに紐づく買取代表カードの一覧を取得する。
4. 取得した買取代表カードの代表カードIDを集め、申込時価格のリポジトリから当該代表カードIDに紐づく申込時買取価格を取得する。
5. 各買取代表カードに、代表カードIDが一致する申込時買取価格を、カード状態コードをキーとする`applicationPrice`として付与する。
6. 付与後の買取代表カードの配列をJSONで返す。該当0件のときは空配列を返す。

## 入出力

### リクエスト

| パラメータ | 位置 | 型 | 必須／任意 | 説明 |
|------------|------|----|-----------|------|
| `ids` | ボディ | string | 任意 | カンマ区切りのネット買取受注IDリスト。カンマで分解してIDの配列とし、当該買取受注IDに紐づく買取代表カードを取得する。未指定・空文字のときは空文字を分解した配列で検索するため、結果は0件となる。 |
| `jwt-token` | ヘッダ | string | 必須 | 認証用のJWTトークン。 |

### レスポンス（成功）

HTTP 200。

買取代表カードの配列を返す。各要素は1件の買取代表カードを表し、状態別の申込時買取価格を`applicationPrice`として持つ。

| フィールド | 型 | 説明 |
|------------|----|------|
| （ルート） | array | 買取代表カードの配列。0件のときは空配列。 |
| `[].buyMainCardId` | integer | 買取代表カードID。 |
| `[].buyOrderId` | integer | ネット買取受注ID。 |
| `[].productId` | integer | 商品ID。 |
| `[].languageId` | integer | 言語ID。未設定のときはnull。 |
| `[].foilFlg` | boolean | フォイルか否か。未設定のときはnull。 |
| `[].count` | integer | 枚数。未設定のときはnull。 |
| `[].price` | integer | 査定金額。未設定のときはnull。 |
| `[].cardConditionId` | integer | カード状態ID。未設定のときはnull。 |
| `[].saleFlg` | boolean | 売却フラグ。未設定のときはnull。 |
| `[].purchaseCategory` | integer | 買取カテゴリ。 |
| `[].applicationPrice` | object | カード状態コードをキーとするオブジェクト。値は当該状態の申込時買取価格（integer）。一致する申込時価格が無い代表カードでは付与されない。 |
| `[].applicationPrice.<conditionCode>` | integer | カード状態コードに対応する申込時買取価格。 |

### レスポンス（失敗）

| HTTPステータス | 条件 | 本文の形 |
|----------------|------|----------|
| 401 | トークン欠落・署名不正・該当する管理者会員なし | 認証拒否（本文を持たない） |
| 500 | 取得処理中の例外 | 共通例外処理に委ねる |

該当0件はエラーとせず、HTTP 200で空配列を返す。
