# API 店頭買取管理 — カード詳細IDから買取用商品情報を取得

## 業務ロジック

### 取得対象

パスで受け取ったカード詳細IDが属するカードに紐づく買取用商品を取得する。取得結果が空のときはページが見つからない扱い（HTTP 404）とする。

### 応答の構成

応答はカードIDをキーとする階層構造とする。各カードの配下に、カード詳細ID・言語コード・状態コードの順で入れ子にする。

### 値の取り方

金額・在庫数量の再計算や丸めは行わない。取得時点の値をそのまま応答へ整形して返す。表示用の加工は呼び出し元クライアントの設計を正とする。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| 該当する買取用商品が無い | ページが見つからない扱い（HTTP 404）とし、メッセージを含む標準の例外応答を返す |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | カード詳細ID（パス・必須） |
| 成功時出力 | HTTP 200。カードIDをキーとする買取用商品情報 |
| 失敗時出力 | 該当が無いときはHTTP 404 |

本APIは参照だけを行い、データを更新しない。

### 出力: 応答項目

| フィールド | 型 | 説明 |
|------------|----|------|
| カード | object | カードIDをキーとする。 |
| カードの日本語名 | string | カードの日本語名。 |
| カードの英語名 | string | カードの英語名。 |
| カード画像のファイル名 | string | カード画像のファイル名。 |
| カード詳細 | object | カード詳細IDをキーとする。 |
| カードセットのコード | string | カードセットが未設定のときは値を持たない。 |
| カードセットの日本語名 | string | カードセットが未設定のときは値を持たない。 |
| フォイル区分 | boolean | フォイルのときは真、そうでないときは偽。 |
| カード番号 | string | カード番号。 |
| プロモーションの日本語名 | string | プロモーションが未設定のときは値を持たない。 |
| 商品ID | integer | 商品ID。 |
| 商品の日本語名 | string | 商品の日本語名。 |
| 商品の英語名 | string | 商品の英語名。 |
| レアリティのコード | string | レアリティのコード。 |
| 保管コードの名称 | string | 未設定のときは値を持たない。 |
| 言語区分 | object | 言語コードをキーとする。 |
| 状態区分 | object | 状態コードをキーとする。値は商品規格単位の情報。 |
| 商品規格ID | integer | 商品規格ID。 |
| 商品コード | string | 商品コード。 |
| 買取価格 | integer | 未設定のときは値を持たない。 |
| 販売価格 | string | 販売価格。 |
| 在庫数 | string | 在庫数。 |
| 部門ID | integer | 未設定のときは値を持たない。 |

## 表示メッセージ

本APIは画面を持たず、応答本文に定型の文言を持たない。
