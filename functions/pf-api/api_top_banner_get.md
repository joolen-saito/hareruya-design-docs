# API データ管理 — トップバナーIDのトップバナー情報を取得

## 業務ロジック

### 取得の判定

指定されたトップバナーIDに一致するトップバナーだけを対象とする。該当が無いときはコード 404 を返す。該当があるときはトップバナー情報を返す。

### 値の取り方

取得時点の値をそのまま返し、金額・税・ポイント・在庫数量の再計算と丸めは行わない。表示のための加工と表示の制御は呼び出し元のクライアントを正とする。

関連する言語は配列で返す。各要素は言語ID・言語名（日本語）・言語名（英語）・言語コードを持つ。

### エラー時の扱い

| エラー内容 | 処理 |
| --- | --- |
| 指定したIDのトップバナーが無い | コード 404 とメッセージ「Not Found」を返す |

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | 取得対象のトップバナーID |
| 成功時出力 | HTTP 200。トップバナー情報 |
| 失敗時出力 | 該当が無いときは 404。本文はコードとメッセージ「Not Found」 |

### 入出力: 応答の項目

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `id` | integer | トップバナーID |
| `imageUrl` | string | 画像URL |
| `link` | string | リンク先URL |
| `dispType` | integer | 表示タイプ |
| `languages` | array | 関連する言語の配列。各要素は `id`・`nameJp`・`nameEn`・`code` |

## 表示メッセージ

本APIは画面へ文言を表示しない。
