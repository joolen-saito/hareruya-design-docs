# API ネット買取管理 — ネット買取受注一覧取得

## 業務ロジック

### 取得できる条件

| 順序 | 判定 | 結果 |
| --- | --- | --- |
| 1 | 認証トークンが無いとき、署名が不正なとき、または該当する管理者会員がないとき | 認証拒否（HTTP 401） |
| 2 | 上記以外のとき | 査定対象のネット買取受注の配列を返す |

認証は要求ヘッダのトークンを検証し、その利用者IDに対応する管理者会員を特定する。署名方式はHS256とする。トークンの原値と署名の秘密値は本書に記載しない。呼び出せるのは買取アプリだけである。認証した管理者会員による絞り込みは行わず、査定対象の受注を一律に返す。

### 取得する受注

買取受注ステータスが商品到着・査定中・保留・再開のいずれかであるネット買取受注を対象とする。受注IDの昇順で取得する。該当する受注が無いときは空の配列を返す。

### 値の取り方

取得した受注を受注単位に整形し、受注の基本情報と申込者情報を入れ子にした配列を組み立てる。件数・並び順は現行実装の既定と上限に従い、取得後に業務値を再計算しない。金額・ポイント・数量・ステータス・日時は保存済みの値をそのまま返し、応答の生成時に丸めや補正を行わない。

申込者の住所は、都道府県名・住所1・住所2を半角空白区切りで連結した文字列とする。条件に一致しないとき、権限がないとき、または非公開のときは、空の結果か既定のエラー形式で返す。

### エラー時の扱い

| 事象 | 扱い |
| --- | --- |
| 認証できないとき | 認証拒否（HTTP 401）とする。本文は持たない |
| 受注の取得または整形の処理中に例外が発生したとき | 共通の例外処理に委ねる（HTTP 500相当） |

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | 認証トークン（ヘッダ）だけを受け取る。ほかのリクエストパラメータを持たない |
| 成功時出力 | HTTP 200。受注ごとのオブジェクトを要素とする配列。ラッパオブジェクトと件数の項目を持たない |
| 失敗時出力 | HTTP 401（本文を持たない）、またはHTTP 500相当 |

### 出力: 受注1件の項目

| 項目 | 型 | 内容 |
| --- | --- | --- |
| ネット買取受注ID | integer | 受注の識別子 |
| 申込日時 | string | ISO8601形式の日時文字列 |
| フリーコメント | string | 受注に付与されたフリーコメント。未設定のときはnull |
| 会員名 | string | 申込者を登録した会員名。紐づく会員が無いときはnull |
| 買取受注ステータスID | integer | 受注の買取受注ステータス |
| 申込者情報 | object | 申込者の名・姓・電話番号・郵便番号・住所を持つ |

### 入出力: 永続化

本APIはデータを更新しない。

## 表示メッセージ

本APIは画面の文言を持たない。
