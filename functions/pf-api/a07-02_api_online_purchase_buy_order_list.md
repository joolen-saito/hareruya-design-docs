# API ネット買取管理 — ネット買取受注一覧取得

## 業務ロジック

### 認証と呼び出しの可否

| 順序 | 判定 | 結果 |
| --- | --- | --- |
| 1 | 要求ヘッダに認証トークンが無いとき | 認証拒否（HTTP 401） |
| 2 | トークンの署名が不正なとき | 認証拒否（HTTP 401） |
| 3 | トークンが指す利用者に対応する管理者会員が無いとき | 認証拒否（HTTP 401） |
| 4 | 認証を通過したとき | 一覧を返す |

トークンは要求ヘッダで受け取る。署名方式はHS256とする。トークンの原値と署名の秘密値は本書に記載しない。

認証した管理者会員による絞り込みは行わない。どの管理者会員のトークンで呼び出しても、同じ一覧を返す。

### 件数と並び順

ネット買取受注IDの昇順で返す。件数の上限と頁分割を持たず、対象の受注をすべて1回の応答で返す。対象の受注が1件も無いときは、空の配列を返す。

### 値の作り方

住所は、都道府県名・住所1・住所2を半角空白1個で区切って連結した1つの文字列として返す。

査定申込日はISO8601形式の日時文字列で返す。

フリーコメントが未設定の受注、および査定担当者が紐づいていない受注では、その項目を空値として返す。項目そのものを応答から省かない。

### エラー時の扱い

| 事象 | 扱い |
| --- | --- |
| 認証できないとき | 認証拒否（HTTP 401）とする |
| トークンが復号できない形式のとき（許可外の署名方式を含む） | 共通の異常応答（HTTP 500相当）とする。認証拒否（HTTP 401）とはしない |
| 受注の取得または整形の途中で処理が失敗したとき | 共通の異常応答（HTTP 500相当）とする |

## 入出力

### 入出力: 永続化

本APIはデータを更新しない。

## 表示メッセージ

本APIは画面の文言を持たない。
