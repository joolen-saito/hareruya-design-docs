# API デッキビルダー — 直近大会情報取得

## 概要

デッキビルダーアプリが、直近に開催された大会の一覧情報を取得するためのAPIである。deck-api（デッキビルダー用のAPIアプリケーション）が提供するJSON APIで、最新大会デッキのマスタから、大会日・フォーマット・大会名・参加者数を一覧で返す。

本書は実装手順ではなく、誰が・いつ・どの条件で・結果どうなるかを読むためのリバース詳細設計とする。確認値はdeck-apiの直近大会取得処理、ルート定義（`config/routes.yaml`）、最新大会デッキを扱うリポジトリを正とする。

本機能のカスタマイズ区分は現行踏襲とする。挙動はdeck-api（デッキビルダー用APIアプリケーション）の実装を確認値とし、DB関連の記述（テーブル名・列名・永続化先）はec-cube-enterpriseの実装を正とする。

対象はJSON APIエンドポイントであり、ブラウザ向けの画面を持たない。本文ではフレームワークのコントローラ型名やメソッド名を主説明としない。「利用者視点の入口」にHTTPメソッドとパスパターンを書く。

---

## 本書で扱うこと

- 直近大会の一覧（大会日・フォーマット・大会名・参加者数）の取得
- 大会日・大会名が有効な行のみを返すこと

---

## 本書で扱わないこと

以下は本書では仕様確定せず、実装または別APIの設計を正とする。

- 大会に紐づく個々のデッキ内容・順位の参照（デッキ関連APIの設計を正とする）
- 大会情報そのものの登録・更新（最新大会デッキマスタの生成バッチ・管理機能の設計を正とする）
- メタゲームの集計（メタゲーム情報参照APIの設計を正とする）

---

## リニューアル移行時の扱い

デッキビルダー関連テーブルは、現行（deck-api）と移行先（ec-cube-enterprise）で同一スキーマであり、テーブル名も一致する。本機能の参照に関わる主な対応は次のとおり。

| 項目 | 現行（deck-api） | 移行先（ec-cube-enterprise） | 差分・注意 |
|------|------------------|------------------------------|-----------|
| 最新大会デッキマスタ | `mtb_latest_event_deck`。大会日（`event_date`）・大会名（`event_name_jp`・`event_name_en`）・参加人数（`participants`） | 同一テーブル・列名 | 大会日が設定済みかつ大会名が空でない行のみを対象とする。 |
| フォーマットマスタ | `mtb_format`。識別子（`id`）・名称（`name_jp`・`name_en`） | 同一テーブル・列名 | 結合してフォーマット名を取得する。 |

現行と移行先でスキーマに差はなく、移行時に追加・改廃する列は本書では確認していない。

| 用語 | 説明 |
|------|------|
| 直近大会 | 最新大会デッキのマスタに記録された大会。大会日・大会名が設定されているものを対象とする。 |
| フォーマット | 大会の構築ルール区分。識別子と名称（日本語・英語）を返す。 |
| 参加者数 | 大会の参加者の人数。 |

## 利用者視点の入口

| 入口 | URLエンドポイント | 期待されるふるまい |
|------|--------------------|--------------------|
| 直近大会情報取得 | `GET /recent_event` | 最新大会デッキのマスタから、大会日・大会名が有効な大会の一覧をコード200のJSONで返す。 |

応答形式はJSON。呼び出し元はデッキビルダーアプリ。

---

## 認証・認可

| 観点 | 内容 |
|------|------|
| 認証方式 | 本APIは認証を行わない。`jwt-token`ヘッダの検証・プレイヤーの特定をいずれも行わず、誰でも呼び出せる参照系である。 |
| 認証失敗時 | 認証処理を持たないため、認証起因のHTTP 401は返さない。 |
| 認可 | 公開向けの一覧であり、利用者状態によらず同一の結果を返す。呼び出し可能なクライアントはデッキビルダーアプリ。 |

トークン原値・署名シークレットは本書に記載しない。

---

## 処理フロー

### 直近大会情報を取得する（GET `/recent_event`）

1. リクエストパラメータを受け取らない。
2. 最新大会デッキのマスタから、大会日が設定済みかつ大会名（日本語・英語）が空でない行を抽出し、識別子の昇順で並べる。
3. 大会日・フォーマット識別子・フォーマット名（日本語・英語）・大会名（日本語・英語）・参加者数を一覧（`events`）にまとめ、コード200のJSONで返す。

---

## 集計条件

| 指標 | 集計の要点 |
|------|------------|
| 対象データ | 最新大会デッキのマスタの行を対象とする。大会日が設定済みで、大会名（日本語・英語）がいずれも空でない行に限る。 |
| 結合 | フォーマットマスタと結合し、フォーマット名を取得する。 |
| 並び順 | マスタの識別子の昇順で並べる。 |
| 件数制限 | 上限件数の指定はなく、条件に合致する全行を返す。 |
| キャッシュ | 一覧は結果キャッシュする。 |

---

## 入出力

### リクエスト

本APIはリクエストパラメータを持たない。認証用の`jwt-token`ヘッダも必要としない。

### レスポンス（成功）

HTTP 200。応答本体はラッパオブジェクトで、JSONキーはsnake_caseで組み立てる。

| フィールド | 型 | 説明 |
|------------|----|------|
| `code` | integer | 処理結果コード。成功時は200。 |
| `events` | array | 直近大会の一覧。識別子の昇順。 |
| `events[].event_date` | string | 大会日。日時文字列（ISO8601形式）。 |
| `events[].format_id` | integer | フォーマット識別子。 |
| `events[].format_name_jp` | string | フォーマットの日本語名。 |
| `events[].format_name_en` | string | フォーマットの英語名。 |
| `events[].event_name_jp` | string | 大会の日本語名。 |
| `events[].event_name_en` | string | 大会の英語名。 |
| `events[].participants` | integer | 参加者数。 |

### レスポンス（失敗）

| HTTPステータス | 条件 | 本文の形 |
|----------------|------|----------|
| 500 | 一覧取得処理中の例外 | 共通例外処理に委ねる |

条件に合致する大会が無い場合も失敗とはせず、`events`を空配列としたコード200のJSONを返す。

### サンプルレスポンス

成功時の応答例（実装確認値に基づく代表値）。

```json
{
  "code": 200,
  "events": [
    {
      "event_date": "2026-05-30T00:00:00+09:00",
      "format_id": 1,
      "format_name_jp": "スタンダード",
      "format_name_en": "Standard",
      "event_name_jp": "サンプル選手権",
      "event_name_en": "Sample Championship",
      "participants": 128
    }
  ]
}
```

### 副作用

無し（参照のみ）。一覧は結果キャッシュするが、業務データの更新は行わない。

応答はJSON応答整形を経て返す。本APIは連想配列を組み立てて返すため、JSONキーは実装で記述したsnake_case（`code`・`events`・`event_date`・`format_name_jp`等）となる。日時はISO8601文字列とし、`serialize_null`は有効とする。

## バリデーション

本APIは入力パラメータを持たないため、入力検証を行わない。

---

## 業務ルール・計算

- 検索・一覧・取得条件はリクエストパラメータ、ログイン状態、公開状態、店舗・支店条件、既存リポジトリの絞り込み順序を正とする。
- 件数、ページ番号、表示順は既存実装のデフォルトと上限に従い、取得後に業務値を再計算しない。
- 金額、ポイント、数量、ステータス、日時はDBまたは連携元の永続化済み値を返却し、レスポンス生成時の丸め・補正は行わない。
- 条件に一致しない、権限がない、または非公開のデータは空結果または既存のエラー形式で返す。

## データ整合性

| 観点 | 内容 |
|------|------|
| 参照時点 | 呼び出し時点の最新大会デッキのマスタの内容を返す。本APIはデータを更新しない。結果キャッシュの有効期間内は同一結果を返す場合がある。 |
| 一覧と詳細 | 本APIは大会の概要一覧のみを返し、大会に紐づくデッキ詳細は別APIで参照する。 |

## DBカラム

機能に直接関係する列のみ記載する。型や一覧の細部はスキーマを参照する。

|----------|-----|------|

| 操作種別 | 対象テーブル | 契機・条件 |
|---------|--------------|------------|
| 検索 | mtb_format / mtb_latest_event_deck | 検索条件に合致するレコードを抽出する。 |
