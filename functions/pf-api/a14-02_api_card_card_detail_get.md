# API カード管理 — カード詳細IDからカード詳細情報を取得

## 業務ロジック

### 関連マスタが揃っていないカード詳細の扱い

カード詳細に紐づくレイアウト・レアリティ・カードセット・イラストレーター・プロモ種別のうち、いずれか1つでも紐づけが無いカード詳細は、カード詳細IDが一致していても取得の対象にしない。このときの応答は、一致するカード詳細が無いときと同じになる。

## 入出力

### 入出力: 該当が無いときの応答本文

該当のカード詳細が無いときの応答本文は、コードとメッセージの2項目を持つJSONとする。コードには応答のステータスコードと同じ値を入れ、メッセージには "Not Found" を入れる。

## 表示メッセージ

本APIは画面へ文言を表示しない。
