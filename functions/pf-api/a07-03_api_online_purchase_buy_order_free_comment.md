# API ネット買取管理 — ネット買取受注コメント更新

## 業務ロジック

### 更新の判定順序

| 順序 | 判定 | 結果 |
| --- | --- | --- |
| 1 | 認証トークンから管理者を特定できない | 認証拒否（HTTP 401）とする |
| 2 | 指定した受注IDのネット買取受注が無い | 該当なし（HTTP 404）とする |
| 3 | コメントが未指定 | 入力不正（HTTP 400）とし、エラーメッセージを返す |
| 4 | 上記のいずれにも該当しない | コメントを更新する |

### 更新する内容

ネット買取受注のメモ（フリーコメント）を指定値で上書きし、更新担当者に認証した管理者を設定する。保存は一括で確定し、途中で例外が発生したときは取り消す。

金額・税・ポイント・在庫数量の再計算や丸めは行わない。応答は保存結果を返し、独自の集計は行わない。

### 認証

認証トークンを検証し、その内容から管理者を特定する。トークンが無い、署名が不正、該当する管理者が無いときは、いずれも認証拒否（HTTP 401）とする。呼び出し元は買取アプリである。トークン原値・署名シークレットは本書に記載しない。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| 認証不可 | 認証拒否（HTTP 401）とする |
| 受注が存在しない | 該当なし（HTTP 404）とする |
| コメント未指定 | 入力不正（HTTP 400）とし、「コメントを入力してください」を返す |
| 保存処理中の例外 | 処理失敗（HTTP 500）とし、例外メッセージを返す。保存は取り消す |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | ネット買取受注ID（必須）、設定するフリーコメント（必須）、認証トークン（必須） |
| 成功時出力 | HTTP 200。処理結果コード200 |
| 失敗時出力 | HTTP 401（本文なし）、HTTP 404（本文なし）、HTTP 400・HTTP 500（処理結果コードとエラーメッセージ） |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 更新 | ネット買取受注のメモ（フリーコメント）と更新担当者を、コメント更新の成功時に上書きする |
