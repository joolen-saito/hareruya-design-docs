# API ネット買取管理 — ネット買取受注コメント更新

## 業務ロジック

### 更新の判定順序

| 順序 | 判定 | 結果 |
| --- | --- | --- |
| 1 | 認証トークンが無い、署名が不正、またはトークンが示す管理者が存在しない | 認証拒否（HTTP 401）とする |
| 2 | 指定した受注IDのネット買取受注が無い | 該当なし（HTTP 404）とする |
| 3 | コメントが未指定 | 入力不正（HTTP 400）とし、「コメントを入力してください」を返す |
| 4 | 上記のいずれにも該当しない | コメントを更新する |
| 5 | 更新の保存中に例外が発生 | 処理失敗（HTTP 500）とし、例外メッセージを返す。更新は取り消し、コメントは更新前のままにする |

コメントが空文字で送られたときは未指定として扱わず、コメントを空にして更新する。

### 更新する内容

コメントの更新とあわせて、更新担当者に、認証したトークンが示す管理者を設定する。

金額・税・ポイント・在庫数量の再計算や丸めは行わない。

## 入出力

### 失敗時の応答

| 種類 | 内容 |
|------|------|
| 失敗時出力 | HTTP 401、HTTP 404、HTTP 400、HTTP 500。HTTP 400 と HTTP 500 では処理結果コードとエラーメッセージを返す |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 更新 | ネット買取受注のメモ（フリーコメント）と更新担当者を、コメント更新の成功時に上書きする |
