# API データ管理 — トップバナーIDのトップバナー情報を取得

## 業務ロジック

### 取得の対象

指定されたトップバナーIDのトップバナーを取得する。該当が無いときはコード404のJSONを返す。

### 応答の値

取得時点の値をそのまま返し、金額・税・ポイント・在庫数量の再計算や丸めは行わない。表示用の加工は呼び出し元の設計に委ねる。

### エラー時の扱い

| 事象 | 扱い |
| --- | --- |
| 該当IDのトップバナーが存在しない | コード404と「Not Found」を含むJSONを返す |

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | トップバナーID |
| 成功時出力 | HTTP 200。トップバナー情報のJSON |
| 失敗時出力 | HTTP 404。該当IDのトップバナーが存在しないとき |

### 入出力: リクエスト

| パラメータ | 位置 | 型 | 必須／任意 | 説明 |
| --- | --- | --- | --- | --- |
| `id` | パス | integer | 必須 | 取得対象のトップバナーID |

### 入出力: 応答フィールド

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `id` | integer | トップバナーID |
| `imageUrl` | string | 画像URL |
| `link` | string | リンク先URL |
| `dispType` | integer | 表示タイプ |
| `languages` | array | 関連する言語の配列。要素の子フィールドは`id`（言語ID）、`nameJp`（言語名・日本語）、`nameEn`（言語名・英語）、`code`（言語コード） |

### 入出力: 永続化

本機能はデータを更新しない。

## 表示メッセージ

この機能は画面を持たないためメッセージを扱わない。
