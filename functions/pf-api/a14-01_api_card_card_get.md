# API カード管理 — カードIDからカード情報を取得

## 業務ロジック

### 応答に含めない関連情報

カードに紐づく情報のうち、カードタグ・キーワード能力・記事・デッキ収録カードは応答の対象ではなく、応答に一切現れない。カードIDで該当するカードが見つかった場合、応答対象の情報は条件を付けずにすべて返す。

## 入出力

### 値が無い項目の扱い

値が設定されていない項目も応答から省略せず、項目名を残したまま「値なし」として返す。関連情報が1件も無い場合も項目自体は残り、空の一覧として返る。

### 該当するカードが無いときの応答本文

該当するカードが存在しないときの応答本文は、コードとメッセージの2項目だけを持つJSONで、メッセージは「Not Found」の固定文字列。カード情報の項目は1つも含まれない。
