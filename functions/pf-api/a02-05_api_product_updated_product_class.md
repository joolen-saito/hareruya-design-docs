# 商品管理 — 更新商品規格取得（API）

## 業務ロジック

### 取得対象の絞り込み

削除済みの商品、および削除済みの商品規格は取得対象に含めない。公開・非公開といった商品ステータスによる絞り込みは行わず、期間の条件に合致するものはステータスによらず取得する。

### 応答の組み立て

商品画像ファイル名は、同一の値を重ねずにカンマ区切りで連結する。カテゴリIDとカテゴリ名は、同一の値を重ねずカテゴリIDの昇順でカンマ区切りに連結する。取得した値は丸め・補正をせずそのまま返す。行の並び順は定めない。

### 該当が無いとき

指定期間に該当する商品規格が1件も無いときも取得の失敗として扱わず、件数0・空の結果を返す。

## 入出力

### 入出力: 値が無い項目の扱い

保管コード、言語コード、カードセットコード、カード状態コード、商品画像、カテゴリは、商品または商品規格に設定されていなくてもその商品規格を取得対象から外さない。設定が無い項目は値なしとして返す。

## 表示メッセージ

この機能は画面を持たないためメッセージを扱わない。
