# API 商品管理 — ポップアップ用カード情報取得（旧商品ID）

## 業務ロジック

### 取得する対象

指定された旧商品IDと言語に対応するポップアップ用商品情報を、商品規格から1件取得する。旧商品IDはカードの旧商品IDまたは旧英語商品IDと突き合わせる。言語は言語優先順の判定に用いる。取得できないときはコード404・「Not Found」のJSONを返す。

### 応答値の扱い

金額・税・ポイント・在庫数量の再計算や丸めは行わない。取得時点の値をそのまま応答へ整形して返す。表示用の加工や表示制御は呼び出し元クライアントの設計を正とする。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| 該当商品情報なし | コード404・「Not Found」のJSONを返す |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 言語区分、旧商品ID |
| 成功時出力 | HTTP 200。条件に合致する商品規格1件 |
| 失敗時出力 | HTTP 404。該当する商品規格が無いとき |

### 入力: リクエスト

| パラメータ | 位置 | 型 | 必須／任意 | 説明 |
|------------|------|----|-----------|------|
| `lang` | パス | string | 必須 | 言語区分。`jp`または`en`を想定する（言語優先順の判定に用いる） |
| `oldProductId` | パス | integer | 必須 | 旧商品ID。カードの旧商品IDまたは旧英語商品IDと突き合わせる |

### 出力: レスポンス（成功）

| フィールド | 型 | 説明 |
|------------|----|------|
| `productId` | integer | 商品ID |
| `name` | string | 商品名 |
| `productClassId` | integer | 商品規格ID |
| `price01` | string | 通常価格。小数値のため数値文字列で返す |
| `price02` | string | 販売価格。小数値のため数値文字列で返す |
| `stock` | string | 在庫数。小数値のため数値文字列で返す |
| `nameEn` | string | 英語商品名 |
| `subFileName` | string | 商品規格画像のファイル名。該当が無い場合はnull |
| `fileName` | string | 商品画像のファイル名。該当が無い場合はnull |
| `weeklySold` | string | 週間販売数。合計値のため数値文字列で返す |

```json
{
  "productId": 100001,
  "name": "サンプルカード",
  "productClassId": 200001,
  "price01": "500.00",
  "price02": "480.00",
  "stock": "12.00",
  "nameEn": "Sample Card",
  "subFileName": "sub_sample.jpg",
  "fileName": "sample.jpg",
  "weeklySold": "3"
}
```

### 出力: レスポンス（失敗）

| HTTPステータス | 条件 | 本文の形 |
|----------------|------|----------|
| 404 | 該当する商品規格が無い | 処理結果コードと "Not Found" のメッセージ |

## 表示メッセージ

| メッセージID | 表示位置 | 画面上の文言 | 表示条件 | 後続処理 |
|---|---|---|---|---|
| — | API応答JSON | Not Found | 該当する商品規格が無いとき | HTTP 404を返して終了する |
