# API 商品管理 — ポップアップ用カード情報取得（旧商品ID）

## 業務ロジック

### 対象カードの引き当て

旧商品IDは、カードに登録された旧商品IDと旧英語商品IDの両方と突き合わせ、どちらか一方に一致すれば対象とする。対象になるのは、削除済みでない商品と削除済みでない商品規格に限る。

カードとの対応を持たない商品、および商品画像を1件も持たない商品は、旧商品IDが一致しても該当なしとして扱う。

### 複数一致したときの扱い

旧商品IDが複数の商品規格に一致した場合でも、返すのは1件だけである。どの1件を返すかを決める優先順は定めておらず、一致したもののうち1件が返る。

### 応答値の加工

金額と在庫数の再計算や丸めは行わず、保持している値をそのまま返す。

## 入出力

### 出力: 該当データが無いときの応答本文

該当する商品が無いときの応答本文は、処理結果コードとメッセージ「Not Found」の2項目を持つ。
