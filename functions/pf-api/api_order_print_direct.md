# API 受注管理 — 注文印刷（印刷情報送信・印刷済み更新）

## 業務ロジック

### 動作の分岐

接続種別が印刷情報送信のときは印刷情報を返す。印刷済み更新のときは印刷結果を受け取って受注を更新する。いずれにも一致しないときは処理を行わず、応答を組み立てない。接続種別はGET・POSTのいずれの要求からも受け取る。

### 印刷対象の受注

| 対象 | 条件 |
|------|------|
| 店頭受取の受注 | 注文受領のとき |
| スムーズ店頭受取の受注 | 所定の支払方法で、未確定・未出荷・未取消・未受領・店頭予約日なし・スマレジコードありのとき |
| ブラウザ印刷指定の受注 | ブラウザ印刷フラグが立つとき |

1回の要求で取得するのは最大10件とする。

### 印刷情報の組み立て

受注ごとに、注文日・合計金額・店頭注文番号・スマレジコード・問い合わせ有無・注文詳細URLを組み立て、受注1件分の印刷情報とする。配送がスムーズ店頭受取のときは、合計金額欄を「スムーズ店頭受取」とする。全受注分を束ねてスタック用紙の印刷情報とする。対象受注が無いときは印刷情報を組み立てず、空のまま返す。

### 印刷結果による受注の更新

受け取った印刷結果を解析する。解析に失敗したとき、直接印刷結果が偽のとき、印刷結果要素が1件も無いときは、いずれも更新しない。

印刷結果要素ごとに、印刷ジョブIDの先頭部分から受注IDを取り出して対象受注を特定する。該当する受注が無いときはその要素を飛ばし、次の要素へ進む。

| 対象受注の状態 | 更新内容 |
|----------------|----------|
| ブラウザ印刷フラグが立っているとき | フラグを倒すだけとし、受注のステータスは変えない |
| ブラウザ印刷フラグが立っていないとき | 受注のステータスをピック中へ更新し、確定日時に現在時刻を設定する |

### 他機能との境界

本機能は認証を行わない。管理系の他機能が用いる認証を通らないため、認証起因の拒否（HTTP 401）を返さない。呼び出し可能なクライアントは店頭のスタック用紙プリンタであり、利用者の照合は行わない。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| 接続種別が印刷情報送信・印刷済み更新のいずれにも一致しない | 処理を行わず、応答を組み立てない |
| 印刷情報送信で対象受注が無い | 空のデータを返す |
| 印刷済み更新で印刷結果の解析に失敗した | 更新を行わずに戻る |
| 印刷済み更新で直接印刷結果が偽、または印刷結果要素が無い | 更新を行わずに戻る |
| 印刷済み更新で受注が見つからない | 当該要素を飛ばし、次の要素へ進む |
| 印刷情報の生成・データ取得の例外 | 共通例外処理に委ねる（HTTP 500） |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 接続種別（必須。印刷情報送信または印刷済み更新）、印刷結果（印刷済み更新のときは必須。直接印刷結果の真偽と印刷ジョブIDを含む） |
| 成功時出力 | 印刷情報送信のときはHTTP 200でスタック用紙の印刷情報を送信する。印刷済み更新のときはHTTP 200で本文を持たない応答を返す |
| 失敗時出力 | 更新できないときも本文を持たない応答を返す。接続種別が一致しないときは応答を組み立てない |

応答は文書形式であり、JSONではない。

### 出力: 印刷情報の構成

| 要素 | 説明 |
|------|------|
| ルート要素 | バージョンを持ち、配下に受注ごとの印刷情報を並べる。 |
| 受注1件分の印刷情報 | 印刷先・タイムアウト・印刷ジョブID（受注ID）と印字レイアウトを持つ。 |
| 印刷ジョブID | 受注IDを用いる。印刷済み更新での受注特定に対応する。 |
| 印字レイアウト | 店頭注文番号・注文詳細URLのQRコード・注文日・注文番号・お客様名・合計金額・スマレジコードのバーコード・各種チェック欄を含む。 |

### 入出力: 永続化

| 操作 | 契機 |
|------|------|
| 更新 | 印刷済み更新で受注を特定でき、ブラウザ印刷フラグが立っていないとき。受注のステータスをピック中とし、確定日時に現在時刻を設定する |
| 更新 | 印刷済み更新で受注を特定でき、ブラウザ印刷フラグが立っているとき。当該フラグを倒す |

印刷情報送信では受注を更新しない。

## 表示メッセージ

本機能は画面を持たず、利用者向けの文言を持たない。
