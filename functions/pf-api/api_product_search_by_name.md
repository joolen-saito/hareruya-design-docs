# API 店頭買取管理 — 商品名から商品詳細の情報を取得

## 業務ロジック

### 検索条件

商品名で商品を検索する。商品名が未指定のときは該当なしとする。商品名から得た商品IDに該当が無いとき、その商品サブクラス情報に該当が無いときも該当なしとする。

### まとめ方

商品ID・言語・高額商品コードの組み合わせを単位に商品をまとめる。商品ごとにカテゴリ・地域制限・商品名を設定する。カード詳細を持つ商品は、商品名の先頭に言語コードを付す。

### 返す商品規格

商品規格は、良品（NM）であるか、価格が表示下限以上のものだけを加える。画像はファイル名からURLへ変換して並べる。

その他コンディションを表示しない商品では、良品（NM）の規格だけに絞る。

### 件数の上限

商品の件数が100件に達した時点で打ち切る。

### 値の取り方

金額・ポイント・数量・ステータス・日時は永続化済みの値をそのまま返し、応答を作るときの丸め・補正は行わない。並び順と件数は既存の既定と上限に従い、取得後に業務値を計算し直さない。

### 認証

本APIは認証を行わない。商品検索の参照に限定する。呼び出し元は買取アプリである。アクセス経路の制御はAPIの外の範囲とし、本書では仕様を確定しない。

### エラー時の扱い

商品名が未指定のとき、該当する商品または商品サブクラスが無いときは、該当なしとして「Not Found」を返す。

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 検索する商品名（必須）。 |
| 成功時出力 | HTTP 200。処理結果コード200と、該当した商品の配列（最大100件）。 |
| 失敗時出力 | HTTP 404。処理結果コードとメッセージ「Not Found」。 |

### 入出力: 応答の項目

| 単位 | 項目 |
|------|------|
| 商品 | 商品ID、商品名、言語コード、高額商品コード、カテゴリ名の配列、地域制限の名称、商品規格の配列。 |
| 商品規格 | 商品規格ID、商品コード、カードコンディションコード、販売価格、在庫数、商品規格画像のURLの配列。 |
