# API カード管理 — 検索クエリに一致するカード情報1件を取得

## 業務ロジック

### 検索条件

カード名は日本語名・英語名・「日本語名/英語名」・「英語名/日本語名」のいずれの形でも受け取る。分割カードは `+` でつないだ入力を想定し、内部で `/` に置き換えて突き合わせる。カード名が空のときは該当なしとして扱う。

カード言語が `ja` のときは日本語、それ以外のときは英語を並び順の優先言語とする。

### 取得の判定

条件に一致するカードのうち 1 件だけを返す。1 件も一致しないとき、およびカード名が空に相当するときはコード 404 とメッセージ「Not Found」を返す。

取得した値をそのまま返し、金額・ポイント・数量・ステータス・日時の再計算と補正は行わない。

### エラー時の扱い

| エラー内容 | 処理 |
| --- | --- |
| 条件に一致するカードが無い、またはカード名が空 | コード 404 とメッセージ「Not Found」を返す |

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | カード名（必須）とカード言語（任意） |
| 成功時出力 | HTTP 200。条件に一致するカード 1 件 |
| 失敗時出力 | 該当が無いときは 404。本文はコードとメッセージ「Not Found」 |

### 入出力: 応答の項目

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `id` | integer | カードID |
| `nameJp` | string | カード名（日） |
| `nameEn` | string | カード名（英） |
| `image_url` | string | カード画像のURL |

### 入出力: 永続化

この機能ではデータを更新しない。

## 表示メッセージ

本APIは画面へ文言を表示しない。
