# API ネット買取管理 — ネット買取注文の査定終了処理

## 業務ロジック

### 処理できる条件

| 順序 | 判定 | 結果 |
| --- | --- | --- |
| 1 | 認証トークンが無いとき、署名が不正なとき、または該当する管理者会員がないとき | 認証拒否（HTTP 401） |
| 2 | パスの受注IDに一致するネット買取受注がないとき | 該当なし（HTTP 404） |
| 3 | 入力検証に1件以上失敗したとき | エラーメッセージの配列を返す |
| 4 | 上記以外のとき | 査定終了処理を実行する |

認証は要求ヘッダのトークンを検証し、その利用者IDに対応する管理者会員を特定する。署名方式はHS256とする。トークンの原値と署名の秘密値は本書に記載しない。認証した管理者会員を受注の更新担当者として記録し、ステータス変更時の履歴にも記録する。

### 入力検証

明細の配列は1件以上あること。空のとき、および配列でないときは入力不正とする。入力検証は明細をすべて検査し、失敗したものを1件ずつエラーメッセージの配列に積んで一括で返す。1件目で打ち切らない。

### 明細の処理

明細は1件ずつ処理する。商品規格IDが0の明細は個別入力商品として扱い、同名の既存があるときは更新し、無いときは新規に作る。それ以外の明細は商品規格から買取代表カードを特定し、同一条件の既存があるときは更新し、無いときは新規に作り、同一受注内で商品・言語・フォイル区分が一致するえらんで買取の既存買取代表カードから、状態ごとの申込時買取価格を引き継ぐ。既存の状態が未設定のカードはNM相当として突合する。

各明細の単価×数量を合計額に加算する。

受注に既存登録されているカードのうち、まとめて買取の商品のものは申込時買取価格を削除する。カード詳細IDが未設定の明細はサプライ・パック相当として単価×数量を合計額に加算する。単価が未設定のものは加算しない。

### 合計額と受注の更新

合計額は10円単位で切り上げる。

削除する既存の買取代表カードに紐づく申込時買取価格も、併せて削除する。

ステータス履歴を登録するのは、更新前後でステータスが変わったときだけである。変わらないときは登録しない。

本処理では金額・税・ポイントの再計算や丸めを、上記の合計額の切り上げを除いて行わない。

### エラー時の扱い

受注の更新から履歴登録までは一括で確定し、途中で失敗したときは全体を取り消す。更新処理中に例外が発生したときは、確定していない更新内容をすべて取り消したうえで、例外メッセージの配列を応答に含める。

## 入出力

### 入出力: リクエスト

| 項目 | 位置 | 型 | 必須／任意 | 内容 |
| --- | --- | --- | --- | --- |
| ネット買取受注ID | パス | integer | 必須 | 該当が無いときは該当なし（HTTP 404） |
| 認証トークン | ヘッダ | string | 必須 | 検証して利用者IDから管理者会員を特定する |
| 明細の配列 | ボディ | array | 必須 | 空のとき、配列以外のときは入力不正 |

### 入出力: レスポンス

認証拒否（HTTP 401）と該当なし（HTTP 404）は本文を持たない。入力不正と内部エラーのときはエラーメッセージの配列を返す。

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 削除 | 今回保持しない既存の買取代表カードに紐づく申込時買取価格 |
| 削除 | まとめて買取の商品に紐づく申込時買取価格 |
