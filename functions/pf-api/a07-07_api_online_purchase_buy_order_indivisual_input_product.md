# API ネット買取管理 — 複数ネット買取IDから個別入力商品の一覧を取得

## 概要

複数のネット買取受注IDを指定して、それらの受注に紐づく個別入力商品の一覧をまとめて取得するAPIである。pf-api（買取連携用のAPIアプリケーション）が提供するJSON APIで、受注IDごとに手入力で登録された商品（商品名・査定金額・個数・売却フラグ）を返す。

本書は実装手順ではなく、誰が・いつ・どの条件で・結果どうなるかを読むためのリバース詳細設計とする。確認値はpf-apiの個別入力商品一括取得処理、ルート定義（`config/routes.yaml`）、ネット買取注文個別入力商品を扱うリポジトリ・エンティティ、共通の認証処理を正とする。本機能のカスタマイズ区分は現行踏襲であり、挙動はpf-apiの実装を参照し、DB関連（テーブル・列）の記述はec-cube-enterpriseを正とする。

対象はJSON APIエンドポイントであり、ブラウザ向けの画面を持たない。本文ではフレームワークのコントローラ型名やメソッド名を主説明としない。「利用者視点の入口」にHTTPメソッドとパスパターンを書く。

---

## 本書で扱うこと

- 複数のネット買取受注IDによる個別入力商品一覧の一括取得
- 認証、該当0件時の応答

## 利用者視点の入口

| 入口 | URLエンドポイント | 期待されるふるまい |
|------|--------------------|--------------------|
| 複数ネット買取IDから個別入力商品一覧取得 | `POST /admin/buyOrderIndivisualInputProduct.json` | カンマ区切りのネット買取受注IDリストに紐づく個別入力商品の配列をJSONで返す。該当0件のときは空配列を返す。 |

応答形式はJSON。呼び出し元は買取アプリ（MTGバイヤー）。

## 認証・認可

| 観点 | 内容 |
|------|------|
| 認証方式 | `jwt-token`ヘッダのJWTを検証し、ペイロードの利用者IDから管理者会員を引く。署名方式はHS256。 |
| 認証失敗時 | ヘッダ欠落・署名不正・該当する管理者会員なしのいずれも認証拒否（HTTP 401）とする。 |
| 認可 | 認証した管理者会員のみ呼び出せる。呼び出し可能なクライアントは買取アプリ。 |

トークン原値・署名シークレットは本書に記載しない。

---

## 処理フロー

### 複数ネット買取IDから個別入力商品一覧を取得する（POST `/admin/buyOrderIndivisualInputProduct.json`）

1. `jwt-token`ヘッダのトークンを検証し、管理者会員を特定する。検証できない場合は認証拒否（HTTP 401）とする。
2. リクエストのネット買取受注IDリスト（`ids`、カンマ区切り文字列）を受け取り、カンマで分解してIDの配列とする。
3. 個別入力商品のリポジトリから、当該買取受注IDリストに紐づく個別入力商品の一覧を取得する。
4. 取得した個別入力商品の配列をJSONで返す。該当0件のときは空配列を返す。

## 入出力

### リクエスト

| パラメータ | 位置 | 型 | 必須／任意 | 説明 |
|------------|------|----|-----------|------|
| `ids` | ボディ | string | 任意 | カンマ区切りのネット買取受注IDリスト。カンマで分解してIDの配列とし、当該買取受注IDに紐づく個別入力商品を取得する。未指定・空文字のときは空文字を分解した配列で検索するため、結果は0件となる。 |
| `jwt-token` | ヘッダ | string | 必須 | 認証用のJWTトークン。 |

### レスポンス（成功）

HTTP 200。

個別入力商品の配列を返す。各要素は1件の個別入力商品を表す。

| フィールド | 型 | 説明 |
|------------|----|------|
| （ルート） | array | 個別入力商品の配列。0件のときは空配列。 |
| `[].buyOrderIndivisualInputProductId` | integer | ネット買取注文個別入力商品ID。 |
| `[].buyOrderId` | integer | ネット買取受注ID。 |
| `[].name` | string | 商品名。 |
| `[].price` | integer | 査定金額。未設定のときはnull。 |
| `[].count` | integer | 個数（個別入力商品の個数列に対応する値）。未設定のときはnull。 |
| `[].saleFlg` | boolean | 売却フラグ。未設定のときはnull。 |

### レスポンス（失敗）

| HTTPステータス | 条件 | 本文の形 |
|----------------|------|----------|
| 401 | トークン欠落・署名不正・該当する管理者会員なし | 認証拒否（本文を持たない） |
| 500 | 取得処理中の例外 | 共通例外処理に委ねる |

該当0件はエラーとせず、HTTP 200で空配列を返す。

### サンプルレスポンス

成功時の応答例（実装確認値に基づく代表値）。

```json
[
  {
    "buyOrderIndivisualInputProductId": 7001,
    "buyOrderId": 5001,
    "name": "サンプル個別入力商品",
    "price": 800,
    "count": 1,
    "saleFlg": false
  }
]
```

該当0件時の応答例。

```json
[]
```

### 副作用

無し（参照のみ）。

応答はJSON応答整形を経て返す。プロパティはcamelCase、日時はISO8601とし、`serialize_null`は有効とする。
