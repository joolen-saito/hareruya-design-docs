# API 店頭買取管理 — 部門一覧を取得

## 業務ロジック

### 取得対象

公開対象の部門だけを取得する。非公開の部門は含めない。

| 部門の状態 | 応答 |
| --- | --- |
| 公開対象の部門が1件以上あるとき | 当該部門を配列で返す |
| 公開対象の部門が0件のとき | 空の配列を返し、エラーとしない |

### 並び順

部門コードの昇順とする。取得した後は、いずれの場合も並び順を組み替えない。

### 値の取り方

金額・ポイント・数量・対応状況・日時は、永続化済みの値または連携元の値をそのまま返す。応答を組み立てるときの丸め・補正は行わない。件数・ページ番号・表示順は既定と上限に従い、取得後に業務値を再計算しない。

### エラー時の扱い

| 事象 | 扱い |
| --- | --- |
| 公開対象の部門が0件のとき | 空の一覧を返す。失敗のステータスは返さない |
| 権限が無いとき、または非公開のデータのとき | 空の結果、または既存のエラー形式で返す |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | パラメータを持たない。 |
| 成功時出力 | HTTP200。処理結果コード、処理結果メッセージ、部門の配列。 |
| 失敗時出力 | 失敗のステータスを返さない。 |

### 出力: 応答フィールド

| フィールド | 型 | 内容 |
|------------|----|------|
| `code` | integer | 処理結果コード。成功のときは200 |
| `message` | string | 処理結果メッセージ。成功のときは "get sections success" |
| `sections` | array | 部門の配列。公開対象が無いときは空配列 |
| `sections[].section_id` | integer | 部門ID |
| `sections[].name` | string | 部門名 |
| `sections[].code` | string | 部門コード。並び順はこのコードの昇順とする |

### 入出力: 永続化

いずれの場合もデータを更新しない。

## 表示メッセージ

この機能は、いずれの場合もメッセージを扱わない。
