# 店舗設定 — 追加システム設定（HareruyaEcプラグイン）

## 業務ロジック

### 画面の位置づけ

追加システム設定は、ハレルヤ向け拡張が管理画面へ追加する設定画面で、サイドメニューでは「データ管理」配下に「追加システム設定」として並ぶ。設定はキーと値の組で保持し、この画面が一覧・編集の窓口になる。

店舗設定の基本情報設定（SHOPマスター）とは別画面・別入力であり、本機能では基本情報の内容を書き換えない。

### 画面表示

画面は単一の入力フォームで、左側の枠に設定項目を縦に並べ、右側に「設定」ボタンを置く。モーダルや確認ダイアログは使わない。当画面専用の画面内スクリプトも持たない。

項目はラベルと入力欄を横に並べる。入力欄の幅は項目の種別で変わり、整数の項目が最も狭く、選択肢の項目が中間、文字列の項目が最も広い。検証に通らなかった項目は、その行をエラー表示にする。

### 初期表示

設定のマスタを全件読み、設定キーと設定値の組を入力欄の初期値とする。読み込んだ中に該当キーが無い項目は、下表の初期値を入力欄に出す。

### 保存の対象

保存はなりすまし対策トークンの検証を通ったときだけ行う。保存では再度設定のマスタを全件読み、送信内容に同じキーがあり、かつ文字列として比較した送信値が現在の設定値と異なる項目だけを更新する。更新した項目には、更新した管理者の識別子を記録する。値が同じ項目は更新せず、更新した管理者の識別子も書き換えない。

入力値は検証後に文字列として保存する。整数や選択肢の項目も、保存時は文字列として比較する。そのため 0 と 00 のように文字列として異なる値が入力経路で生じた場合だけ、内容が同じでも更新扱いになる。

送信内容にあるキーが設定のマスタに1行も無いときは、その項目は保存の対象外となり、新しい行を追加しない。

保存が成立したときは完了メッセージを表示し、追加システム設定画面へ戻す。戻った先の入力欄は保存後の値から組み立て直す。検証に通らないときは保存せず、同じ画面を再表示して項目のエラーを表示する。

複数の管理者が続けて保存したときは、後から保存した内容が残る。先に開いていた画面の内容が古いことを検知する仕組みは無い。設定の最終更新日時を進める処理も当画面の保存には無い。

### 設定値の利用先

当画面で保存した値を参照する代表的な領域は下表のとおりである。値ごとの分岐の詳細は、参照する側の機能を正とする。

| 設定項目 | 効く領域 |
|----------|----------|
| 買取専用メールアドレス | 買取関連メールの宛先 |
| 入荷通知メールの許可 | 入荷通知メールを送るかどうか |
| 配送日指定が繰上る時刻(hh:mm) | 配送日指定と購入タイミングの境界 |
| スマレジの各項目 | スマレジ連携の接続に使うパラメータ |
| 注文詳細商品一覧分割しきい値価格(1)(2) | 管理画面の注文詳細・一覧での表示分割 |
| スタック用紙の判定価格としきい値価格 | ピッキング・印刷での高額商品の判定 |
| Small packetが選択可能な合計金額の閾値 | 配送方法として選べるかどうか |
| 英語サイト専用タグID | フロントの表示ブロックが参照するタグ |
| タイトルを変更する商品ID( , 区切り) | 商品タイトルの表示を変換する対象 |

参照する側の多くはリクエストごとに設定を読み直すため、保存した値は次のリクエストから反映される。

### 計算

本機能では商品点数や金額の業務計算を行わない。一覧件数や合計などの集計表示も行わず、外部との通信やバッチ実行も行わない。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| 入力の検証エラー | 項目の近くにエラーを表示する。保存は行わない |
| なりすまし対策トークンの不正 | アクセス拒否（HTTP 403）とする |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 追加システム設定の各項目となりすまし対策トークン |
| 成功時出力 | 完了メッセージと、追加システム設定画面の再表示 |
| 失敗時出力 | 同じ画面での項目エラーの表示 |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 更新 | 送信値が現在の設定値と異なる項目の保存 |

更新するのは設定値と、更新した管理者の識別子だけである。設定の行を新しく追加したり削除したりはしない。
