# バッチ 商品管理 — 週間在庫履歴更新

## 業務ロジック

### 集計する内容

商品在庫から全商品規格IDの一覧を取得し、商品規格ごとに週次の在庫を求める。

| 項目 | 内容 |
|------|------|
| 集計単位 | 商品規格単位。全商品規格を対象とする |
| 週の範囲 | 1週前から11週前までの11週分 |
| 集計値 | 各週末時点の在庫数。当日から対象週数を引いた日付以前で、最も新しい在庫履歴の在庫を用いる |
| 在庫履歴が無い週 | その週の在庫を0とする |

商品規格ごとに、商品規格IDと週次在庫を1行にまとめて集計結果に積む。

### 出力

集計が終わったときは、出力先のCSVファイルを書き込みモードで開き、ヘッダ行に続けて集計結果の各行を書き込む。ヘッダは商品規格IDと週ごとの在庫の列である。

再実行したときは書き込みモードで開き直し、毎回最新の集計内容で全件を上書きする。追記はしない。

実行の間はメモリと実行時間の制限を解除する。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| コマンド名が未指定・不一致のとき | 処理を行わずに終了する |
| 週の在庫履歴が無いとき | その週の在庫を0として扱う |
| ファイル書き込みで例外が発生したとき | エラーメッセージをコンソールに出力する |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | コマンド名。引数は取らない |
| 実行条件 | 商品在庫に商品規格が登録されていること |
| 成功時出力 | 設定された出力パス（既定は`/html/csv/weekly_stock_history.csv`）への週間在庫履歴CSVの書き出し |
| 失敗時出力 | エラーメッセージのコンソール出力。途中で止まったときは不完全なCSVが残る |

### 入出力: 永続化

本バッチはデータを更新しない。

## 表示メッセージ

本バッチは画面メッセージを持たない。失敗したときにエラーメッセージをコンソールへ出力する。
