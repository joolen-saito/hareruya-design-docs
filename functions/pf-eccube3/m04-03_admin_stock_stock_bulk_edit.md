# 在庫管理 — 在庫一括編集

## 業務ロジック

### 編集対象の絞り込み

在庫一括編集は、在庫一覧で選択した在庫を対象とする。選択した在庫の規格を1件1行に展開して表示する。

選択した在庫が同一店舗のものでない場合は編集できない。対象店舗の在庫を編集する権限が無い場合も編集できない。

在庫を選択せずに開いた場合は編集できない。

### 在庫数の更新

新しい在庫数は、現在の在庫数に増減させる在庫数を加えて求める。増減させる在庫数が0の行は更新しない。

新しい在庫数が0を下回る更新はできない。在庫数の上限を超える更新もできない。上限は9桁（999999999）とする。入庫では入庫後の在庫数が8桁を超えられない。

在庫変動区分が入庫の場合は増減させる在庫数を1以上とし、仕入単価を入力する。廃棄の場合は増減させる在庫数を-1以下とする。

### 入荷通知の対象

更新前の在庫数が0だった規格を入荷通知の対象とする。対象が1件以上ある場合は入荷通知メールを送る。

### 入荷数の集計

在庫変動理由が入荷またはマスタ更新で、増減させる在庫数が正の場合に限り、規格の入荷集計に増減させる在庫数を加える。

### 在庫変更履歴の記録

更新した規格ごとに在庫変更履歴を1件記録する。記録する内容は変更前の在庫数・変更後の在庫数・在庫変動理由の区分・在庫変動理由・操作した管理者とする。

在庫変動理由が未入力のまま更新が成立した場合は「価格・在庫一括更新による在庫数更新」を在庫変動理由として記録する。

### 検証に失敗した場合

検証に失敗した行がある場合は在庫を更新せず、入力値を保持したまま同一画面を再表示する。

### 他機能との境界

在庫の選択は「在庫検索/一覧」を正とする。1件ずつの編集は「在庫編集」を正とする。

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 選択した在庫、各規格の増減させる在庫数・在庫変動理由区分・在庫変動理由・仕入単価、承認通知先メンバー |
| 成功時出力 | 在庫数の更新、完了メッセージ、在庫一覧への遷移 |
| 失敗時出力 | 項目ごとのエラー、保存失敗メッセージ |

### 入出力: 永続化

在庫数の更新は規格の在庫と規格本体の在庫数を更新し、在庫変更履歴を1件追加する。

| 操作 | 契機 |
| --- | --- |
| 更新（在庫数） | 在庫一括編集の登録 |
| 追加（在庫変更履歴） | 在庫数を更新したとき |
| 更新（入荷集計） | 在庫変動理由が入荷・マスタ更新で増減させる在庫数が正のとき |

支店へ本店在庫の更新を通知する。入荷通知の対象がある場合は入荷通知メールを送る。
