# 受注管理 — 納品書印刷（英語）

## 業務ロジック

### 印刷対象

一覧で選択した受注だけを対象とする。選択した受注が 1 件も存在しないときは、納品書を作らず未検出として応答する。同じ受注を複数回選んだときも、その受注の納品書は 1 回だけ出す。

国外配送かどうかは配送方法に設定した区分だけで決まり、受注や配送先の国では変わらない。この区分を持たない配送方法の受注は、英語・日本語のどちらの納品書にも出ない。

会員情報・プレイヤー情報・配送先のいずれかを持たない受注は納品書に出ない。商品・商品規格・商品サブ情報・商品規格サブ情報のいずれかを持たない明細も納品書に出ない。注文者の都道府県が未設定の受注も納品書に出ない。配送先の国が未設定のときは納品書に出て、国の欄だけが空になる。

### お届け先・送り主・自社情報

お届け先の欄には配送先の情報を、送り主の欄には注文者の情報を出す。会社の欄に出す自社の情報は納品書に固定で持ち、受注の内容では変わらない。

郵便番号は、上 3 桁と下 4 桁がどちらも登録されているときだけ `-` でつなぐ。どちらかが欠けているときは、登録されている郵便番号をそのまま使う。電話番号は 3 つの電話番号値を区切り文字なしで連結する。氏名は名・空白 1 個・姓の順で出す。

### 金額と明細の表示

| 欄 | 出す値 |
| --- | --- |
| お買い上げ額 | 受注の小計 |
| 送料 | 受注の送料 |
| 手数料 | 受注の手数料 |
| ポイント使用 | 受注の値引き額に単位を添えたもの。ポイント数として計算した値ではない |
| 発送方法 | 配送方法の名称 |
| 請求金額 | 受注の合計。消費税額は併記しない |

明細行の合計は、価格に数量を掛けた金額とする。商品情報には受注したときの商品名を出す。受注のあとに商品名を変えたときも、納品書に出る商品名は変わらない。

金額は通貨記号 `¥` と空白 1 個を前に置き、3 桁ごとに区切って出す。ポイント使用の欄には通貨記号も桁区切りも付けず、値引きが 0 のときも 0 と出す。

### 改ページ

ページの先頭では、見出し・注文番号・お届け先・送り主・自社情報・金額の欄を出し直す。

## 入出力

### 出力: 納品書

選択した受注の納品書を 1 つの印刷文書にまとめて出す。受注を複数選んだときは、受注ごとの納品書を続けて出す。

## 表示メッセージ

本機能は画面メッセージを持たない。
