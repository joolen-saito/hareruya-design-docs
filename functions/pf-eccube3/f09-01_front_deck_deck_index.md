# フロント デッキ検索 — デッキ検索TOP

## 業務ロジック

### メタゲーム上位の集計

集計対象はランキング表示の対象に設定されたフォーマットだけで、表示順の昇順に並べる。フォーマットごとに、大会デッキかつ公開のデッキを集計期間で絞り、アーキタイプ単位のデッキ数を多い順に上位3件まで示す。

| 観点 | 扱い |
| --- | --- |
| 対象フォーマット | ランキング表示の対象が有効なフォーマットだけを対象とする |
| 対象デッキ | デッキ種別が大会デッキ、かつ表示区分が公開のものだけを対象とする |
| 集計期間の開始 | 当日からフォーマットごとのメタ集計日数を引いた日の`00:00:00` |
| 集計期間の終了 | 当日の`23:59:59` |
| 期間判定に使う日付 | 大会の開催日 |
| 集計単位 | アーキタイプ |
| 並び順 | デッキ数の降順 |
| 表示件数 | 上位3件。4位以下はメタゲーム一覧が受け持つ |
| ユーザーデッキ | 集計に含めない |

### その他フォーマットの案内

その他メタゲームの対象に設定されたフォーマットを表示順の昇順に並べ、各フォーマットのメタゲーム一覧への入口とする。対象が1件も無いときは何も並べない。

### 直近の大会

直近大会マスタのうち、開催日が設定され、日本語名と英語名がどちらも空でない大会を識別子の昇順に並べ、開催日・フォーマット名・大会名・参加人数を示す。条件を満たす大会が1件も無いときは直近の大会の区画そのものを表示しない。

### 画面から引き継ぐ検索条件

| 起点 | 遷移先 | 引き継ぐ条件 |
| --- | --- | --- |
| メタゲーム上位のアーキタイプ | デッキ検索結果 | アーキタイプIDと、開催日時の開始＝当該フォーマットの集計期間の開始日 |
| 4位以下を見る | メタゲーム一覧 | フォーマットID |
| フォーマット名の見出し | メタゲーム一覧 | フォーマットID |
| その他 | その他デッキ一覧 | 引き継がない |
| 直近の大会の1件 | デッキ検索結果 | 開催日時の開始と終了＝その大会の開催日、大会名＝その大会の日本語名 |

### 検索条件

検索条件はデッキ検索結果へGETで渡す。デッキ検索TOP・デッキ検索結果・メタゲーム一覧・デッキリスト詳細は同一の検索条件の様式を共有する。

| 画面上の項目 | 画面上の項目（英語） | 検索条件 |
| --- | --- | --- |
| フォーマット | Format | 受け取ったフォーマットIDのいずれかに一致。選択肢を検索対象の設定で絞るのは画面側で、受け取ったID自体は再判定しない |
| アーキタイプ | Archetype | 選択したアーキタイプIDのいずれかに一致。カンマ区切りの文字列で渡す |
| 開催日時（開始） | Date | 大会の開催日が、指定日の`00:00:00`以上 |
| 開催日時（終了） | Date | 大会の開催日が、指定日の`23:59:59`以下 |
| 参加人数（下限） | Participants | 参加人数が指定値以上 |
| 参加人数（上限） | Participants | 参加人数が指定値以下 |
| タグ | Tag | 選択したデッキタグIDのいずれかを持つデッキだけを対象とする |
| カード名 | Card | 採用カードの日本語名または英語名に完全一致するカードを含むデッキだけを対象とする |
| プレイヤー名 | Player | プレイヤー名への部分一致 |
| 大会名 | Tournament | 大会の日本語名または英語名への部分一致 |
| 成績 | Result | 優勝デッキのみ（Winning deck only）は順位が1位、TOP8以上のみ（Top 8 decks only）は順位が1位以上8位以下。掲載デッキすべて（List All Decks）は絞り込まない |
| 公開/非公開 | Viewable/Private | 公開リストのみ（Viewable Only）はデッキリストが公開のものだけを対象とする。非公開リストを含む（Private List Included）は絞り込まない |

### 検索条件の初期値と入力の扱い

開催日時の開始の初期値は当日の6か月前、成績の初期値は「掲載デッキすべて」、公開/非公開の初期値は「非公開リストを含む」とする。他の項目の初期値は空とする。日付は`Y/m/d`の形式で解釈し、この形式に合わない値は条件にしない。カード名の入力に含まれる`+`は`/`へ置き換えてから突き合わせる。プレイヤー名と大会名は入力値のワイルドカード文字`%`と`_`をエスケープして文字そのものとして扱う。

アーキタイプの選択は、フォーマットと色による絞り込みとアーキタイプ名の入力補助を備えた選択画面で行い、選択結果をカンマ区切りの識別子として検索条件に載せる。カード名の入力補助にはカード名の一覧ファイルを用いる。

### 集計に用いるデータ

| データ | 用途 |
| --- | --- |
| デッキ | 大会デッキで表示区分が公開のものだけを数える |
| アーキタイプ | 集計の単位とし、区画に出す名称と画像にも用いる |
| フォーマット | ランキング表示の対象かどうかと、メタ集計日数と表示順を持つ |
| 直近大会マスタ | 直近の大会の区画に出す大会だけを持つ |
| デッキリストの公開状態 | 集計の条件にしない。デッキリストが非公開でも数える |

### 検索条件の送信様式

| 画面上の項目 | 送信の形 |
| --- | --- |
| フォーマット | 選択したフォーマットごとに、その識別子を鍵にした配列の要素として送る |
| アーキタイプ | 選択した識別子をカンマで連ねた1つの値として送る |
| タグ | 選択したタグの識別子を配列として送る |
| 大会名 | 入力欄の値のほかに、同じ名前の隠し項目も送る |
| 表示件数 | デッキ検索TOPからは値を入れずに送る。値が入るのはデッキ検索結果で件数を変えたときだけ |
| 検索の実行 | 入力値の妥当性を判定せずに送る。形式を判定するのは日付だけで、参加人数などは形式を判定せず、空でなければそのまま条件にする |

### エッジケース

| ケース | 扱い |
| --- | --- |
| ランキング表示の対象フォーマットが0件のとき | メタゲームの区画を1つも出さない |
| あるフォーマットの集計結果が0件のとき | そのフォーマットの首位のアーキタイプの区画を出さず、4位以下への入口だけを残す |
| その他メタゲームの対象が0件のとき | その他フォーマットの区画にはその他デッキ一覧への入口だけが残る |
| その他フォーマットが多いとき | フォーマットの識別子が8のものの直後で区画を分けて折り返す |
| 直近大会の登録が0件のとき | 直近の大会の区画そのものを出さない |
| 集計期間の開始日 | `Y/m/d`の形式の文字列として検索条件へ引き継ぐ |

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | なし。検索条件を伴わずに開く |
| 成功時出力 | メタゲーム上位・その他フォーマット・直近の大会・検索条件の入力欄を載せた画面 |
| 失敗時出力 | なし。集計結果が0件でも同じ画面を返す |

### 入出力: 永続化

デッキ情報を登録・更新・削除しない。

| 操作 | 契機 |
| --- | --- |
| キャッシュへの保存 | メタゲーム上位の集計結果をフォーマットごとに保存する。保持時間は3600秒 |
| キャッシュへの保存 | 同じ集計結果を、フォーマットと上限件数を鍵とする結果キャッシュにも保存する。保持時間は60秒 |
