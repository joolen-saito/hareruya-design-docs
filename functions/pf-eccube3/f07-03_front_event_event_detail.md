# F07-03（大会詳細）

イベント詳細1件の開催情報・事前予約情報を表示し、申込・キャンセル申込・デッキ登録への導線を出し分ける、フロントのイベント詳細参照画面である。

## 概要

大会詳細は、利用者が選択したイベント詳細1件について、開催店舗・大会名・開催日時・受付時間・フォーマット・定員・参加費・賞品・備考と、事前予約情報（事前予約期間・残り予約数・事前予約参加費）を表示する機能である。ログイン会員かつ申込可能なときは申込ボタンを、申込済みのときはキャンセル申込ボタンを、デッキ登録可能なときはデッキ登録・編集ボタンを出し分ける。

本書は実装手順ではなく、誰が・いつ・どの条件で・結果どうなるかを読むためのリバース詳細設計とする。確認値はpf-eccube3（EC-CUBE3系）のHareruyaEcプラグインのイベント詳細処理、テンプレート（`Event/show.twig`）、イベント詳細エンティティの申込可否・デッキ登録可否・残り予約数の判定を正とする。本機能のカスタマイズ区分はカスタマイズであり、挙動の参照リポはpf-eccube3、DB関連はec-cube-enterpriseを正とする。

対象はブラウザ経由のフロントに限定する。フロントのルートはロケールを先頭に持つ`/{_locale}`配下にあり、イベントは`/{_locale}/events`配下にまとまる。

本文ではフレームワークのコントローラ型名やメソッド名を主説明としない。本文ではルートbind名の網羅は主説明とせず、「利用者視点の入口」にHTTPメソッドとサイトルートからのパスパターンを書く。コード探索でbind名が必要なときだけ「調査補助」へ書く。

## リニューアル移行時の扱い

本機能はカスタマイズ区分がカスタマイズである。現行挙動はpf-eccube3のHareruyaEcプラグインを正とし、DBスキーマと移行後の扱いはec-cube-enterpriseを正とする。イベント関連テーブルはec-cube-enterpriseに移行済みであり、現行と移行先で次の差がある。

| 観点 | 現行（pf-eccube3） | 移行先（ec-cube-enterprise） |
|------|----------------------|--------------------------------|
| チーム人数 | `dtb_event.team_member_count`（チーム人数の数値、既定1）。残り予約数の除数に用いる。 | `dtb_event`は`team_member_count`を持たず`is_team_battle`（チーム戦フラグ、真偽）を持つ。残り予約数のチーム人数換算をどの値で行うかはec-cube-enterprise実装で要確認。 |
| 大会名・備考 | `dtb_event.name_jp`（大会名）・`detail_jp`（備考）。 | `dtb_event`は`name_jp`を持つが`detail_jp`を持たない。移行先での備考の保存先はec-cube-enterprise実装で要確認。 |
| イベント詳細の各列 | `dtb_event_detail`の受付・事前予約・定員・参加費・賞品・デッキ登録列。 | 同一スキーマ。`entry_start_date`・`entry_end_date`・`online_entry_start_date`・`online_entry_end_date`・`entry_flg`・`capacity`・`entry_fee`・`prize_jp`・`deck_regist_flg`・`deadline_flg`・`deck_regist_deadline`が存在する。 |
| 申込・申込状況 | `dtb_event_entry`・申込状況マスタ`mtb_entry_status`。 | 同一スキーマ。`dtb_event_entry`・`mtb_entry_status`が存在する。 |

## 利用者視点の入口

| 入口 | URLエンドポイント | 期待されるふるまい |
|------|--------------------|--------------------|
| イベント詳細を開く | `GET /{_locale}/events/{eventDetailId}/detail` | 当該イベント詳細の開催情報・事前予約情報と、状態に応じたボタンを表示する。 |
| 申込ボタンを押下 | `GET /{_locale}/events/{eventDetailId}/entry` | イベント申込（F07-04）へ遷移する。 |
| キャンセル申込ボタンを押下 | `GET /{_locale}/contact?eventDetailId={eventDetailId}` | キャンセル申込（問い合わせ機能）へ遷移する。 |
| デッキ登録・編集ボタンを押下 | `GET /{_locale}/deckentry/edit?eventDetailId={eventDetailId}` | デッキ登録（デッキ登録機能）へ遷移する。 |
| 戻るボタンを押下 | `GET /{_locale}/events`（または日別画面） | 一覧側へ戻る。遷移元のクエリにより戻り先を切り替える。 |

存在しないイベント詳細IDを指定した場合は、ページが見つからない（HTTP404）として扱う。

## 処理フロー

### イベント詳細を表示する（GET `/{_locale}/events/{eventDetailId}/detail`）

1. パスのイベント詳細IDで詳細を取得する。無ければページが見つからない（HTTP404）として扱う。
2. 詳細から親イベント・店舗・会場・フォーマットを取得する。
3. ログイン会員のとき、選手情報を取得する。選手情報があり、当該イベント詳細でデッキ登録済みなら、デッキ登録状況をデッキ編集として扱えるようデッキIDを保持する。
4. 開催情報・事前予約情報を表示し、申込可否・申込済み・デッキ登録可否の判定でボタンを出し分ける。

## 集計条件

| 指標 | 集計の要点 |
|------|------------|
| 残り予約数 | 定員から申込済み人数（取消を除く集計対象の申込）を引き、イベントのチーム人数で割った値。事前予約期限前のときのみ表示する。 |
| 申込済み人数 | 当該イベント詳細の申込のうち集計対象ステータスの件数に、チーム人数を掛けた人数。 |
| デッキ登録状況 | ログイン会員の選手情報と当該イベント詳細でデッキを照合し、登録済みかどうかを判定する。 |

---

## `ボタン出し分け` 時の判定順序

| 順序 | 判定 | 結果 |
|------|------|------|
| 1 | 申込可能か（事前予約フラグが真、事前予約開始日時以降、事前予約終了日時以前、定員未満） | 可能ならボタン領域を表示する |
| 2 | 申込可能かつログイン会員が未申込か | 該当なら申込ボタンを表示する |
| 3 | ログイン会員が申込済みか | 該当ならキャンセル申込ボタンを表示する |
| 4 | デッキ登録可能か（デッキ登録フラグが真、締切フラグが偽、デッキ登録締切が現在以降） | 該当ならデッキ登録（登録済みは編集）ボタンを表示する |
| 5 | 申込不可だがデッキ登録可能 | デッキ登録ボタンのみ表示する |

申込可否・申込済み・デッキ登録可否の判定は、いずれも当該イベント詳細とログイン会員の選手情報に基づく。未ログインでは申込済み判定は偽となる。

---

## 業務ルール・計算

| 項目 | 内容 |
|------|------|
| 申込可能の条件 | 事前予約フラグが真、現在が事前予約開始日時以降かつ事前予約終了日時以前、申込済み人数が定員未満であること。 |
| 申込済みの判定 | ログイン会員の選手情報が、当該イベント詳細の取消以外の申込に含まれること。未ログインは偽。 |
| デッキ登録可能の条件 | デッキ登録フラグが真、締切フラグが偽、デッキ登録締切が現在以降であること。 |
| 残り予約数の表示 | 事前予約期限前のときのみ表示する。値は定員から申込済み人数を引き、チーム人数で割る。 |
| 参加費表示 | 0円は「無料」、それ以外は桁区切りの「（金額）円」。 |
| 受付時間表示 | 受付開始・受付終了の双方が設定されている場合のみ表示する。 |
| 事前予約情報表示 | 事前予約フラグが真のとき、事前予約期間・事前予約参加費を表示する。 |

本機能は詳細表示のみで入力フォームを持たないため、`### 入力項目`の表は持たない。ボタン押下による遷移のみを受け付ける。

### エッジケース

| ケース | 扱い |
|--------|------|
| イベント詳細IDが存在しない | ページが見つからない（HTTP404）として扱う。 |
| 未ログインで詳細を開く | 開催情報を表示する。申込済み判定は偽となり、申込可能なら申込ボタンを表示する。 |
| 定員に達している | 申込可能の条件を満たさず、申込ボタン領域を表示しない。デッキ登録可能ならデッキ登録ボタンのみ表示する。 |
| 事前予約期限後 | 残り予約数を表示しない。申込可能の条件も満たさない。 |
| デッキ登録済み | デッキ登録ボタンをデッキ編集として表示する。 |
| バナー画像が未設定 | バナー画像を表示しない。 |

## データ整合性

| 観点 | 内容 |
|------|------|
| 参照時点 | 表示は要求時点で取得した詳細・親イベント・申込済み人数に基づく。表示後の申込・取消は自動反映しない。 |
