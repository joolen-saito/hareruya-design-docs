# 商品 — お気に入り（登録・解除・一覧）

## 業務ロジック

### お気に入り登録の判定順序

| 順序 | 判定 | 結果 |
|------|------|------|
| 1 | ログイン会員（選手情報）が特定できるか | できないなら未ログインの応答（お気に入りを追加する場合ログインしてください。） |
| 2 | 登録件数が上限未満か | 上限以上なら上限超過の応答（お気に入り登録は100件までです。） |
| 3 | 当該商品・言語が未登録か | 既登録なら作成しない |
| 4 | 上記を通過 | お気に入りを作成し成功の応答（お気に入りに追加しました。） |

### お気に入り解除

商品IDと言語を受け取り、ログイン会員と選手情報を特定する。選手情報が無いときは不正要求（HTTP400）として処理し、画面文言は返さない。当該商品・言語のお気に入りがあるときは削除し、解除成功の応答を返す。

### 保持と上限

| 項目 | 内容 |
|------|------|
| 言語別保持 | お気に入りは商品と言語の組で保持する。同一商品でも言語が異なれば別のお気に入りとして扱う |
| 登録上限 | 1会員あたり100件まで。上限以上では新規登録しない |
| 重複防止 | 当該商品・言語が既登録のときは新規作成しない |
| セール通知 | お気に入り商品がセール対象になると、登録メールアドレスへ通知する（通知バッチを正とする） |

### 一覧

会員ログインを要求し、会員と選手情報を特定したうえで、当該会員のお気に入り商品を取得する。一覧には見出し「お気に入り登録商品一覧」、会員氏名、セール通知の案内、商品数、セール対象商品のみ表示する切替、お気に入り商品を表示する。

セール絞り込みは`sale=1`でセール対象のみに絞り込み、`sale=0`で絞り込みを解除する。

商品詳細では言語ごとに登録済みかを判定して表示する。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| 未ログインで登録したとき | 未ログインの応答（ログインを促す文言）を返し、登録しない |
| 未ログインで解除したとき | 不正要求（HTTP400）とする |
| 登録上限を超過したとき | 上限超過の応答（100件までの文言）を返し、登録しない |
| 未ログインで一覧を開いたとき | 会員ログインへ誘導する（会員ログイン機能を正とする） |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 登録・解除は商品IDと言語。一覧はセール絞り込み等の検索条件 |
| 成功時出力 | 登録・解除は状態（成功・失敗・未ログイン）と文言の応答。一覧は画面表示 |
| 失敗時出力 | 未ログイン・上限超過の応答、または不正要求（HTTP400） |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 追加 | 未登録の商品・言語をお気に入りに登録したとき |
| 削除 | お気に入りを解除したとき |
