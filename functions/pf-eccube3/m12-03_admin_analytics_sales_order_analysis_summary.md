# M12-03（受注/売上分析 集計一覧表示）

## 概要

分析・集計メニューの受注/売上分析は、管理者が指定した集計日・使用日付・集計単位・各種絞り込みに従い、注文明細を集計単位ごとに集計し、平均単価・数量・合計・件数とその割合を一覧表で提示する機能である。

本書は実装手順ではなく、誰が・いつ・どの条件で・結果どうなるかを読むためのリバース詳細設計とする。確認値はpf-eccube3（EC-CUBE3系）のHareruyaEcプラグインの受注/売上分析処理、注文明細の集計用リポジトリ、検索フォーム種別、一覧テンプレートを正とする。本機能のカスタマイズ区分はカスタマイズであり、挙動は現行リポpf-eccube3を参照し、DB関連の記述はec-cube-enterpriseを正とする。現行と移行先でテーブル名・列の所在が異なる箇所は「リニューアル移行時の扱い」に集約する。

対象はブラウザ経由の管理画面に限定する。本文ではフレームワークのコントローラ型名やメソッド名を主説明としない。管理画面プレフィックスは環境により変わる（`admin_route`）。「利用者視点の入口」にHTTPメソッドとサイトルートからのパスパターンを書く。

CSVダウンロードはM12-04で扱う。本書は集計一覧の表示までを扱う。

---

## 本書で扱うこと

- 受注/売上分析の初期表示時に設定される検索条件の既定値
- 検索条件（集計日・使用日付・集計単位・各種絞り込み）の指定による集計結果一覧の表示
- 集計の対象データ・結合・除外条件・集計単位・期間の取り扱い
- 一覧に表示する列と割合・合計行の算出

---

## 本書で扱わないこと

以下は本書では仕様確定せず、実装または別機能の設計を正とする。

- 集計結果のCSVダウンロード（M12-04を正とする）
- 日次/月次集計、入荷通知依頼、フォーマット売上分析の各集計（M12-01・M12-02・M12-05〜M12-08を正とする）
- 管理画面へのアクセス制御・ログイン・権限設定の詳細
- 受注・会員・商品の各台帳の更新業務（各機能を正とする）

## リニューアル移行時の扱い

挙動は現行リポpf-eccube3を正とし、DB関連はec-cube-enterpriseを正とする。現行（pf-eccube3）と移行先（ec-cube-enterprise）でスキーマが異なる箇所を記録する。

### Excel基本設計により廃止された仕様（刷新後は実装不要）

本書は現行実装からのリバースであり、以下は現行挙動として記述しているが、Excel基本設計が廃止を宣言している。刷新後は実装しない。

- 集計単位の選択肢（※Excel基本設計 0211 識別ID:9 により廃止。刷新後は実装しない）。変更。 刷新後は商品・カテゴリの2択のみ（支払方法・購入グループ・都道府県・性別・利用端末・年代(会員)を削除）。

| 観点 | 現行（pf-eccube3） | 移行先（ec-cube-enterprise） |
|------|--------------------|------------------------------|
| 注文明細テーブル | `dtb_order_detail` | `dtb_order_item`（列 `price`・`quantity`・`product_code`・`product_name` は同名） |
| 使用日付の日付列 | 注文日・入金日は `dtb_order`（`order_date`・`payment_date`）、注文確定日・出荷日・売上確定日・キャンセル日は補助表 `dtb_order_sub` の各日付列 | `dtb_order` に集約。`order_date`・`payment_date` に加え `confirm_date`・`shipping_date`・`commit_date`・`cancel_date` 等の日付列を直接保持する。補助表 `dtb_order_sub` は移行先に存在しない。各使用日付と移行先列の正確な対応は ec-cube-enterprise 実装で要確認。 |
| 誕生日の絞り込み | `dtb_order.birth` | `dtb_order.birth`（同名） |
| 都道府県・性別 | 会員の都道府県・性別 | `dtb_order.pref_id`・`dtb_order.sex_id` 等。集計時の参照元の正確な対応は ec-cube-enterprise 実装で要確認。 |

DB列に言及する箇所は移行先（ec-cube-enterprise）の名称を主とし、現行名を括弧で添える。移行先に該当が見当たらない箇所は推測でスキーマ化せず「ec-cube-enterprise 実装で要確認」と残す。

## 処理フロー

### 検索画面初期表示（`/{admin_route}/analysis/sales`）

1. 管理画面の認証・権限を通過する。
2. 検索条件セッションを破棄する。
3. 集計日Fromに当月初日、集計日Toに当月末日、使用日付に注文日、集計単位に商品、並び順に昇順を設定する。
4. 検索フォームを表示する。集計結果は無しとする。

### 集計実行・一覧表示（`/{admin_route}/analysis/sales/result`）

1. 検索フォームへ送信値を取り込む。
2. 検索条件を検索条件セッションへ保存する。
3. 注文明細の集計用リポジトリへ検索条件を渡し、集計結果と合計を取得する。
4. 集計結果一覧と合計行、割合を同一画面に表示する。

## 集計条件

| 指標 | 集計の要点 |
|------|------------|
| 対象データ | 注文明細を注文・商品と結合し集計する。注文日が未設定の注文は対象外とする。 |
| 除外条件 | 使用日付がキャンセル日以外のときは、受注ステータスがキャンセルの注文を結合条件で除外する。 |
| 集計単位 | 集計単位の指定に応じてグループ化キーを切り替える。商品なら商品コード、カテゴリならカテゴリ名、支払方法なら支払方法、購入グループなら購入グループ、都道府県・性別・利用端末はそれぞれのマスタ、年代（会員）は誕生年。 |
| 期間 | 集計日Fromから集計日To未満まで、使用日付で選んだ日付列で絞り込む。注文日・入金日は注文の日付列、それ以外は注文サブの対応する日付列で絞り込む。 |
| 集計値 | 集計単位ごとに、金額（単価×数量の合計）、数量（数量の合計）、平均単価（金額合計÷数量合計）、件数（注文の重複なし件数）を算出する。 |
| 絞り込み | 汎用ワード（商品名日/英・カード名・商品コード・備考）、カテゴリ、都道府県、性別、誕生日、利用端末、売上分析タグ、カードセット、状態を指定すると、対応する結合・条件を追加する。 |
| 平均単価・数量の範囲 | 平均単価From・To、数量From・Toは集計後の値（HAVING）に対する絞り込みとして適用する。 |

割合（数量割合・合計割合・件数割合）は合計に対する各行の比率を100倍し小数点以下を切り捨てて算出する。平均単価は表示時に小数点以下を切り捨てる。

## 業務ルール・計算

| 項目 | 内容 |
|------|------|
| 平均単価 | 金額合計を数量合計で割る。表示時に切り捨てる。 |
| 数量割合・合計割合・件数割合 | 各行の値を全体合計で割り100倍し、小数点以下を切り捨てる。合計が0の場合は0とする。 |
| 件数 | 注文の重複なし件数を数える。 |
| 合計行 | 表示中の集計結果について、数量・合計・件数を合算する。 |
| 並べ替え | 並べ替えで集計単位を選んだ場合は集計単位キーで、注文数・金額・販売数を選んだ場合はその列で、昇順/降順に並べる。 |
| 表示件数 | 一覧は表示件数の上限で打ち切る。 |

### エッジケース

| ケース | 扱い |
|--------|------|

## データ整合性

| 観点 | 内容 |
|------|------|
| 参照時点 | 集計結果は検索実行時にデータベースから読み取った値である。表示後の更新は自動反映しない。 |

| 更新との整合性 | 本機能は参照のみで台帳を更新しない。 |

## DBカラム

機能に直接関係する列のみ記載する。型や一覧の細部はスキーマを参照する。テーブル名・列名はec-cube-enterpriseを正とし、現行（pf-eccube3）と異なる場合は現行名を括弧で添える。

| テーブル | 列 | メモ |
|---------|-----|------|
| dtb_order_item（現行 dtb_order_detail） | price, quantity | 金額・数量・平均単価の算出。 |
| dtb_order_item（現行 dtb_order_detail） | product_code, product_name | 商品単位の集計・絞り込み。 |
| dtb_order | order_date, payment_date | 使用日付による期間絞り込み。 |

### DB操作

本機能は参照系（検索）であり、DBへの登録・更新・削除は行わない。テーブル名は ec-cube-enterprise を正典とする。

| 操作種別 | 対象テーブル | 契機・条件 |
|---------|--------------|------------|
| 検索 | dtb_order / dtb_order_detail / dtb_order_item / dtb_order_sub | 検索条件に合致するレコードを抽出する。 |
