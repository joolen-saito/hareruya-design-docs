# 商品管理 — 部門登録/編集

## 業務ロジック

### 画面の構成

上部に登録・編集フォーム、下部に部門一覧を表示する。一覧は部門を部門コード昇順で全件取得したものである。

新規モードでは空の部門にフォームを結び付ける。編集モードでは指定IDの部門にフォームを結び付け、当該IDが存在しないときは404応答とする。編集モードのときだけ「新規登録に戻る」への導線を表示する。

### 保存の判定順序

| 順序 | 判定 | 結果 |
|------|------|------|
| 1 | 編集対象の主キーが存在するか | 存在しないなら404（表示側）。保存では対象の部門を特定するのに用いる |
| 2 | なりすまし対策トークンが有効か | 無効なら権限エラー（HTTP403）とする |
| 3 | 必須・最大長・選択肢の範囲を満たすか | 満たさないなら「登録できませんでした。」を表示し、一覧を取り直して同一画面を再表示する |
| 4 | 上記を通過 | 部門を保存し、スマレジ連携へ当該部門の登録・更新を投入する。成功メッセージを表示して部門一覧へ戻る |

保存はパスに主キーがあるときは当該部門の更新、無いときは新規登録として扱う。スマレジ連携への投入で例外が発生したときは成功応答に至らない。

### 更新する項目

更新するのはフォームに現れる4項目に対応する項目だけである。スマレジ連携用の分類IDなどフォームに無い項目は、編集時は既存の値のまま残り、新規時は未設定のままとする。

免税区分の選択肢と保存値の対応は次のとおりである。

| 画面上の意味 | 保存値 |
|----------------|----------|
| 対象外 | 0 |
| 一般品 | 1 |
| 消耗品 | 2 |

MTGBuyer表示は、チェックしたときは真、チェックしていないときは偽として保存する。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| フォーム検証に失敗したとき | 「登録できませんでした。」を表示し、同一内容を再表示する |
| なりすまし対策トークンが不正なとき | 権限エラー（HTTP403）とする |
| 編集表示で主キーが存在しないとき | 404応答とする |
| 削除で参照が存在するとき | 該当するエラーメッセージを表示し、一覧へ戻る |
| 削除がその他の理由で失敗したとき | 削除失敗のエラーを表示する |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 部門の入力項目一式、編集時は対象の部門ID、なりすまし対策トークン |
| 成功時出力 | 部門一覧への遷移と成功メッセージ |
| 失敗時出力 | フォームエラー時は同一画面の再表示。トークン不正は権限エラー（HTTP403）。主キー不正な表示要求は404応答 |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 追加 | 新規登録の保存 |
| 更新 | 編集の保存 |
| 削除 | 部門の削除 |
