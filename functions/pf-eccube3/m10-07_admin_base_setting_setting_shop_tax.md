# 店舗設定 — 税率設定（共通税率・商品別税率オプション）

## 業務ロジック

### 一覧画面の初期表示

新規追加のときは、課税規則を四捨五入にした未登録の共通税率を編集対象として画面を組み立てる。税率一覧の「編集」から開いたときは、指定されたIDの共通税率を編集対象として読み込む。指定されたIDの共通税率が無いときは、ページが見つからない扱い（404）になる。編集対象が基本税率設定のときは、適用日時の入力項目を画面に出さない。

### 税率一覧の内容

一覧に出すのは商品・商品規格に紐づかない共通税率だけで、論理削除した行は出さない。並びは適用日時の降順である。列はID・消費税率・課税規則・適用日時と、行ごとの操作（編集・削除）である。消費税率は末尾に % を付けて表示する。適用日時の列は、基本税率設定の行では日時ではなく「基本税率設定」と表示し、それ以外の行は 年/月/日 時:分 の書式で表示する。基本税率設定の行の「削除」は選んでも何も起こらない。

### 共通税率の入力条件

消費税率は必須で、0以上100以下でなければならない。保持するのは整数で、小数点以下は保持しない。課税規則は必須である。適用日時は必須だが、基本税率設定の編集では入力項目が無いため、登録済みの適用日時をそのまま保つ。適用日時の入力欄は日時選択の補助が付いた1行入力で、年-月-日 時:分 の書式で入力する。

### 共通税率の保存

入力の検証に通り、かつ同じ適用日時の税率が他に無いときだけ保存する。重複の確認は共通税率だけでなく、商品・商品規格に紐づく税率も対象にする。編集のときは、編集対象の行を除いて適用日時の重複を確かめる。保存後は税率設定画面へ戻る。検証に通らないときは同じ画面を再表示し、完了メッセージを表示しない。適用日時が重複するときは、適用日時の項目にエラーを付けて保存しない。

### 商品別税率機能の保存

個別税率設定の「登録」は共通税率設定と同じ入力欄一式をまとめて送るが、反映するのは商品別税率機能の値だけで、同時に入力されていた消費税率・課税規則・適用日時は共通税率にも店舗基本情報にも反映しない。反映したときは保存完了を通知する。商品別税率機能の入力が検証に通らないときは、店舗基本情報を更新せず、完了も通知しない。いずれの場合も税率設定画面へ戻る。

### 共通税率の削除

税率一覧の「削除」は、なりすまし対策トークンを検証したうえで対象行を取得する。指定されたIDの共通税率が無いときは、削除を行わず、既に削除されている旨の警告を出して税率設定画面へ戻る。基本税率設定の行は削除を行わず、完了メッセージを出さずに税率設定画面へ戻る。基本税率設定以外の行は論理削除して税率設定画面へ戻る。

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 編集対象の共通税率ID、削除対象の共通税率ID、なりすまし対策トークン |
| 成功時出力 | 共通税率の登録・更新・論理削除、店舗基本情報の商品別税率機能の更新、税率設定画面への戻り |
| 失敗時出力 | 入力検証エラー、適用日時重複エラー。編集対象の共通税率が存在しないときは404 |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 追加・更新 | 共通税率の保存が検証に通ったとき |
| 更新 | 商品別税率機能の入力が検証に通ったとき、店舗基本情報の同項目を更新する |
| 論理削除 | 基本税率設定以外の共通税率を削除したとき |
