# 店舗設定 — 税率設定（共通税率・商品別税率オプション）

## 業務ロジック

### 一覧画面の初期表示

管理画面の認証・権限・IP制限の各ルールを通過した場合に表示する。編集対象は、新規追加のときは既定の課税規則・税端数調整0・未削除の状態で組み立て、既存行の編集のときは指定されたIDの共通税率を読み込む。指定されたIDの共通税率が存在しないときは、フレームワーク設定に従うエラーページへ縮退する。編集対象が基本税率のときは適用日時の入力項目を画面から除く。あわせて店舗基本情報の「商品別税率機能」の現在値を画面に設定し、共通税率の一覧を表示する。

### 共通税率の保存

入力の検証に通り、かつ同じ適用日時の共通税率が他に存在しないときだけ保存する。基本税率は適用日時の入力項目を持たないため、重複の確認は他行の適用日時との突き合わせだけになる。保存後は税率設定画面へ戻る。検証に通らないときは同じ画面を再表示し、完了メッセージは表示しない。適用日時が重複するときは適用日時の項目にエラーを付けて保存しない。

### 商品別税率機能の保存

「商品別税率機能」の入力だけが有効なときに限り、店舗基本情報の同項目を更新する。無効なときは店舗基本情報を更新しない。いずれの場合も税率設定画面へ戻る。

### 共通税率の削除

なりすまし対策トークンを検証したうえで対象行を取得する。対象のIDに該当する共通税率が存在しないときは、ページが見つからない扱い（404）へ縮退する。基本税率の行は削除処理を行わず、メッセージを出さずに一覧へ戻る。基本税率以外の行は論理削除して一覧へ戻る。

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 共通税率の税率・適用日時、商品別税率機能の設定値、削除対象の共通税率ID、なりすまし対策トークン |
| 成功時出力 | 共通税率の登録・更新・論理削除、商品別税率機能の更新、完了メッセージ、税率設定画面への戻り |
| 失敗時出力 | 入力検証エラー、適用日時重複エラー。削除対象が存在しないときは404 |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 追加・更新 | 共通税率の保存が検証に通ったとき |
| 更新 | 商品別税率機能の入力が有効なとき、店舗基本情報の同項目を更新する |
| 論理削除 | 基本税率以外の共通税率を削除したとき |

## 表示メッセージ

| メッセージID | 表示位置 | 画面上の文言 | 表示条件 | 後続処理 |
| --- | --- | --- | --- | --- |
| M10-07-MSG-001 | 管理画面上部 | 保存しました | 新しい税率を登録したとき | 税率設定画面に遷移する |
| M10-07-MSG-002 | 管理画面上部 | 保存しました | 登録済みの税率を編集して保存したとき | 税率設定画面に遷移する |
| M10-07-MSG-003 | 管理画面上部 | 削除しました | デフォルト以外の税率を削除したとき | 税率設定画面に遷移する |
| M10-07-MSG-004 | 画面中央(ダイアログ) | 削除します | デフォルト以外の税率の削除を選び、確認画面を開いたとき | 削除確認モーダルを表示する |
| M10-07-MSG-005 | 画面中央(ダイアログ) | この操作はあとから取り消すことができません。「%name%」を削除してよろしいですか？ | デフォルト以外の税率の削除を選び、確認画面を開いたとき | 削除時は税率設定画面に遷移し、キャンセル時は税率設定画面に留まる |
| M10-07-MSG-006 | 入力項目直下 | 数字と小数点のみ入力できます。 | 税率に数字と小数点以外を入力したとき | 税率設定画面に留まる |
| M10-07-MSG-007 | 入力項目直下 | 同時刻の適用日時を設定できません。 | 既存の共通税率と同じ適用日時を設定したとき | 税率設定画面に留まる |
| M10-07-MSG-008 | 入力項目直下 | 数字と小数点のみ入力できます。 | 税率に数字と小数点以外を入力して送信したとき | 税率設定画面に留まる |
| M10-07-MSG-009 | 入力項目直下/フォーム上部 | 同時刻の適用日時を設定できません。 | 既存の共通税率と同じ適用日時で登録・更新しようとしたとき | 税率設定画面に留まる |

削除対象が存在しないときの専用メッセージは無い。本画面の完了メッセージは税率の登録・更新・削除の3か所だけである。
