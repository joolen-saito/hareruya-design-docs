# F08-03（店頭買取査定申込登録確認〜完了）

## 業務ロジック

### 確認・登録の判定順序

| 順序 | 判定 | 結果 |
|------|------|------|
| 1 | 店舗識別名から店舗を特定できるか | 特定できなければページが見つからない扱い（404）とする |
| 2 | 適格請求書発行事業者が「はい」のとき、登録番号が妥当か | 不正なら店頭買取査定申込情報入力画面を再表示する |
| 3 | 申込開始の状態で申込フォームから送信されたか、または登録番号が未入力のまま適格請求書発行事業者の入力が送信されたか | どちらにも当たらなければ店頭買取査定申込前ログイン画面へ戻す |
| 4 | 入力メールアドレスが既登録か、メールアドレスとパスワードが同一か | いずれかに該当すれば会員登録フォーム画面を該当の状態で再表示する |
| 5 | 確認モードか | 確認モードなら確認画面を表示する |
| 6 | 会員登録モードか | 会員仮登録を実行し、成功・失敗の結果を完了画面へ引き継ぐ |
| 7 | 上記を通過した | 申込みを登録し、査定番号を採番して完了画面へ移る |

### 入力データの引き継ぎ

保持している入力データと今回送信された入力データを併合して、確認と登録に用いる。入力項目の一覧と各検証はF08-02を正とする。

### 申込みの登録内容

| 項目 | 内容 |
| --- | --- |
| 状態 | 完了前の状態を設定する |
| 成年フラグ | 生年月日から成年・未成年を判定して設定する |
| 適格請求書発行事業者 | 登録番号が入力されているときは、その登録番号を申込みに紐づけて保存する |
| 会員 | ログイン中のときは当該会員を紐づける |
| 査定番号 | 申込日（年月日）・店舗ID（2桁）・その日その店舗の連番（4桁・ゼロ埋め）を「-」で連結した文字列を採番する |
| 店舗・申込日・更新日 | 登録時に設定する |

### 会員仮登録

会員登録モードのときに実行する。会員仮登録が失敗しても査定申込みは登録する。会員を仮登録したときは、支店システムへ会員情報の更新を連携する。連携に失敗しても会員仮登録と査定申込みは成立し、失敗した連携は連携エラーとして記録する。

### 完了画面

保持している査定IDから申込みを取得して表示する。査定IDを保持していないときは店頭買取査定申込前ログイン画面へ戻す。査定IDの保持は完了画面の表示時に解除するため、完了画面を再度開いたときも店頭買取査定申込前ログイン画面へ戻る。

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 併合した申込入力データ、適格請求書発行事業者の入力、送信モード（確認・会員登録） |
| 成功時出力 | 確認画面、または申込登録後の完了画面 |
| 失敗時出力 | 店舗なしの404、店頭買取査定申込前ログイン画面への戻し、店頭買取査定申込情報入力画面の再表示、会員登録フォームへの差し戻し |
