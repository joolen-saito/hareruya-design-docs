# バッチ 商品管理 — 入荷通知キャンセル

## 業務ロジック

### 対象の入荷通知リクエスト

削除日時が未設定の入荷通知リクエストのうち、次のいずれかに当てはまるものを対象とする。対象が無いときは更新件数0件で完了する。

- 紐づく商品規格が削除済みである
- 紐づく商品が存在しない
- 紐づく商品が削除済みである

### 反映の内容

対象の入荷通知リクエストへ、実行した時点の日時を削除日時として一括で設定する。削除日時が未設定の行だけを対象とするため、既に論理削除済みの行が再び対象になることはなく、重複して削除することもない。

### エラー時の扱い

| 事象 | 扱い |
| --- | --- |
| 起動時の指定が不正 | 処理を行わずに終了する |
| 対象なし | 更新件数0件で完了する |
| 一括更新時の例外 | 更新は反映されず、エラーの内容を実行結果として出力する |

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | 起動時の指定のみで、引数は取らない |
| 成功時出力 | 対象の入荷通知リクエストへの削除日時の設定 |
| 失敗時出力 | 更新を反映せず、エラーの内容を出力する |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 更新 | 対象と判定した入荷通知リクエストへ、実行時点の日時を削除日時として設定する |

## 表示メッセージ

この機能は画面を持たないためメッセージを扱わない。
