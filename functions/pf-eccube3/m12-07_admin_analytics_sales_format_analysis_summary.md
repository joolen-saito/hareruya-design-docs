# M12-07（フォーマット売上分析 集計一覧表示）

## 概要

分析・集計メニューのフォーマット売上分析は、管理者が指定した集計月について、売上分析タグ（フォーマット）ごとの日別売上金額を集計し、折れ線グラフと日別の表、フォーマットごとの合計・平均の表で提示する機能である。

本書は実装手順ではなく、誰が・いつ・どの条件で・結果どうなるかを読むためのリバース詳細設計とする。確認値はpf-eccube3（EC-CUBE3系）のHareruyaEcプラグインのフォーマット売上分析処理、売上分析タグ集計用リポジトリ、検索フォーム種別、一覧テンプレートを正とする。本機能のカスタマイズ区分はカスタマイズであり、挙動は現行リポpf-eccube3を参照し、DB関連の記述はec-cube-enterpriseを正とする。現行と移行先でテーブル名・列の所在が異なる箇所は「リニューアル移行時の扱い」に集約する。

対象はブラウザ経由の管理画面に限定する。本文ではフレームワークのコントローラ型名やメソッド名を主説明としない。管理画面プレフィックスは環境により変わる（`admin_route`）。「利用者視点の入口」にHTTPメソッドとサイトルートからのパスパターンを書く。

CSVダウンロードはM12-08で扱う。本書は集計一覧（グラフ・表）の表示までを扱う。

---

## 本書で扱うこと

- フォーマット売上分析の初期表示と集計月の指定による集計表示
- フォーマット（売上分析タグ）ごとの日別売上金額の集計の対象データ・結合・除外条件・集計単位・期間
- 日別合計・フォーマットごとの合計と平均の算出
- 売上分析タグに紐づかない売上（その他・その他カード）の取り扱い

---

## 本書で扱わないこと

以下は本書では仕様確定せず、実装または別機能の設計を正とする。

- 集計結果のCSVダウンロード（M12-08を正とする）
- 日次/月次集計、受注/売上分析、入荷通知依頼の各集計（M12-01〜M12-06を正とする）
- 売上分析タグ（フォーマット）マスタの管理（マスタ管理機能を正とする）
- 管理画面へのアクセス制御・ログイン・権限設定の詳細

---

## リニューアル移行時の扱い

挙動は現行リポpf-eccube3を正とし、DB関連はec-cube-enterpriseを正とする。現行（pf-eccube3）と移行先（ec-cube-enterprise）でスキーマが異なる箇所を記録する。

| 観点 | 現行（pf-eccube3） | 移行先（ec-cube-enterprise） |
|------|--------------------|------------------------------|
| 注文明細テーブル | `dtb_order_detail`（`price`・`quantity`） | `dtb_order_item`（`price`・`quantity` は同名） |
| 明細と売上分析タグの紐づき | `dtb_order_detail_sub_tag_sales_analysis`（`tag_sales_analysis_id`・`order_detail_id`） | `dtb_order_item_tag_sales_analysis`（`tag_sales_analysis_id`・`order_item_id`） |
| カード明細の判別列 | 規格サブ `dtb_product_sub.card_detail_id` | `dtb_product.card_detail_id`（商品本体に統合。規格サブは移行先に存在しない） |
| フォーマットの並び順 | `mtb_tag_sales_analysis.rank` | `mtb_tag_sales_analysis.rank`（同名。並び順は `rank` を保持） |
| フォーマット名 | `mtb_tag_sales_analysis.name` | `mtb_tag_sales_analysis.name`（同名） |

DB列に言及する箇所は移行先（ec-cube-enterprise）の名称を主とし、現行名を括弧で添える。移行先に該当が見当たらない箇所は推測でスキーマ化せず「ec-cube-enterprise 実装で要確認」と残す。

## 処理フロー

### 検索画面初期表示（`/{admin_route}/analysis/format_sales`）

1. 管理画面の認証・権限を通過する。
2. 集計月入力欄を持つ検索フォームを表示する。集計結果は無しとする。

### 集計実行・一覧表示（`/{admin_route}/analysis/format_sales/result`）

1. 検索フォームへ送信値を取り込み、集計月を取得する。
2. 集計月をもとに、売上分析タグごと、および売上分析タグに紐づかない区分ごとの日別売上を集計する。
3. 売上の無い日を0で補完し、日別の売上表・日別合計・フォーマットごとの合計と平均を算出する。
4. グラフと表を同一画面に表示する。

---

## 集計条件

| 指標 | 集計の要点 |
|------|------------|
| 期間 | 集計月の1日から翌月の1日未満まで。注文日（`order_date`）で抽出する。 |
| 集計単位 | 注文日を日（`%e`）でグループ化し、フォーマット（売上分析タグ）ごとに日別の売上金額を集計する。 |
| 売上金額 | 注文明細の単価×数量の合計とする。 |
| 除外条件 | 受注ステータスがキャンセルの注文を除外する。 |
| タグ別売上 | 注文・注文明細・明細サブの売上分析タグ紐づきを結合し、指定の売上分析タグIDに一致する明細の売上を日別に集計する。 |
| その他(カード) | 売上分析タグが紐づかない明細のうち、規格サブのカード明細が紐づく売上を日別に集計する。 |
| その他 | 売上分析タグが紐づかない明細のうち、規格サブのカード明細が紐づかない売上を日別に集計する。 |
| 日別合計 | 各日について全フォーマットの売上を合算する。 |
| フォーマット合計・平均 | フォーマットごとに月内売上の合計と、合計を当月日数で割った平均（小数点以下切り捨て）を算出する。合計行は各フォーマットの合計・平均をさらに合算する。 |

売上の無い日は0で補完し、当月日数分の日付を一覧に並べる。

---

## 業務ルール・計算

| 項目 | 内容 |
|------|------|
| フォーマットの並び | 売上分析タグを`rank`の昇順で並べ、その後に「その他(カード)」「その他」を加える。 |
| 平均 | フォーマットごとの月内売上合計を当月日数で割り、小数点以下を切り捨てる。 |
| 合計行 | 各フォーマットの合計を合算した値、各フォーマットの平均を合算した値を「合計」として算出する。 |
| 日数 | 集計月の末日の日付を当月日数とする。 |
| 金額表示 | 表・グラフの金額は金額表示の整形を適用する。 |

### 入力項目

| 項目名 | 必須／任意 | 最大長 | 初期値 | 保存先・扱い |
|--------|------------|--------|--------|----------------|
| 集計月 | 必須 | 年月 | 空（初回表示時は未設定） | フォームキー `month`。年月（`yyyy-MM`）。当月から翌月未満を対象期間とする。空欄では送信不可。 |

本フォームの集計月は未入力不可とする。集計結果はセッションへ保存しない。

### エッジケース

| ケース | 扱い |
|--------|------|
| 売上の無い日 | 当該日の各フォーマットの売上を0で補完する。 |
| 売上分析タグが紐づかない売上 | 「その他(カード)」「その他」の2区分に集計する。 |
| 集計月のフォーマット売上が全て0 | 各日・各フォーマットを0として表示し、合計・平均も0となる。 |

## データ整合性

| 観点 | 内容 |
|------|------|
| 参照時点 | 集計結果は検索実行時にデータベースから読み取った値である。表示後の更新は自動反映しない。 |
| CSVとの整合性 | 本機能はCSV出力時に検索条件をセッションから読まず、CSVダウンロードの送信に含まれる集計月で再集計する。同一の集計月であれば集計結果は一致する。 |
| 一覧と合計の整合性 | 日別合計・フォーマット合計・平均は、表示中の集計結果から算出した値である。 |
| 更新との整合性 | 本機能は参照のみで台帳を更新しない。 |

## DBカラム

機能に直接関係する列のみ記載する。型や一覧の細部はスキーマを参照する。テーブル名・列名はec-cube-enterpriseを正とし、現行（pf-eccube3）と異なる場合は現行名を括弧で添える。

| テーブル | 列 | メモ |
|---------|-----|------|
| dtb_order | order_date | 集計期間の抽出・日別の集計単位。 |
| dtb_order | status | キャンセル注文の除外。 |
| dtb_order_item（現行 dtb_order_detail） | price, quantity | 売上金額の算出。 |
| dtb_order_item_tag_sales_analysis（現行 dtb_order_detail_sub_tag_sales_analysis） | tag_sales_analysis_id, order_item_id（現行 order_detail_id） | 明細と売上分析タグの紐づき。 |
| dtb_product（現行 dtb_product_sub） | card_detail_id | その他(カード)・その他の判別。 |
| mtb_tag_sales_analysis | rank, name | フォーマットの並び順・列名。 |

### DB操作

本機能は参照系（検索）であり、DBへの登録・更新・削除は行わない。テーブル名は ec-cube-enterprise を正典とする。

| 操作種別 | 対象テーブル | 契機・条件 |
|---------|--------------|------------|
| 検索 | dtb_order / dtb_order_detail / dtb_order_detail_sub_tag_sales_analysis / dtb_order_item / dtb_order_item_tag_sales_analysis / dtb_product 等 | 検索条件に合致するレコードを抽出する。 |
