# 会員管理 — ポイント付与・ポイント履歴

## 業務ロジック

### ポイント履歴の表示

パスの会員IDで会員を取得する。存在しないときはページが見つからない扱い（404）とする。当該会員のポイント履歴を新しい順に取得し、各履歴に関連する注文番号を取得して表示する。履歴はポイント種別ごとに表示する。あわせてポイント付与の入力欄を表示する。

### ポイントの付与

会員と選手情報を取得する。いずれも無いときはページが見つからない扱い（404）とする。入力内容の検証に失敗したときはポイント履歴画面を再表示する。検証に成功したときは、入力したポイント変動・備考でポイント履歴を追加し、ポイント履歴画面へ戻る。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| 会員・選手情報が存在しない | ページが見つからない扱い（404）とする |
| 入力内容の検証失敗 | ポイント履歴画面を再表示する |
| なりすまし対策トークン不正 | 付与を行わない |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 会員ID、ポイント種別、ポイント変動、備考、なりすまし対策トークン |
| 成功時出力 | ポイント履歴の追加、履歴画面への遷移 |
| 失敗時出力 | 会員・選手情報が無いときは404、検証失敗時は履歴画面を再表示 |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 追加 | ポイント付与の成立時のポイント履歴 |

## 表示メッセージ

本機能に固有の表示メッセージは、正本に記載が無い。
