# F04-03（注文時の配送先登録・変更）

## 業務ロジック

### 入力項目と必須

入力項目は配送先名称・配送先氏名（姓名）・配送先氏名カナ（姓名）・電話番号（3分割）・国・郵便番号・住所（都道府県と住所2行）・会社名である。配送先名称・配送先氏名・電話番号・国・郵便番号・住所を必須とし、配送先氏名カナと会社名は必須としない。

配送先氏名カナの扱いは、英語ページなどカナが無い場合を含めて入力項目の定義に従う。

### 国による住所項目の切替

国の選択に応じて郵便番号欄を分割表示と単一表示で切り替え、都道府県の表示・非表示も切り替える。郵便番号からの住所自動入力と郵便番号検索の導線を置く。

### 登録上限

新規登録では、アドレス帳の件数が登録上限（確認値20）以上のとき登録できない。上限を超えているときはエラーを表示してご注文方法指定へ戻す。既存編集（識別子ありの経路）では上限を判定しない。

### 国と都道府県の整合

国が日本で都道府県が国外、または国が日本以外で都道府県が国外でないときは不整合とし、国にエラーを付ける。

### 登録後の配送先反映

登録が成立したときは配送先名称とともに住所を保存し、登録したお届け先の識別子を当該注文の最初の配送に引き継いで、配送先選択へ遷移する。戻るの送信、または検証に通らないときは編集画面を再表示する。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| 新規登録の上限超過 | 上限超過のエラーを表示してご注文方法指定へ戻す |
| 国と都道府県の不整合 | 国にエラーを付けて編集画面を再表示する |
| 入力の検証不備 | 編集画面を再表示する |
| 編集対象の住所が存在しない | お届け先が見つからない扱いとする |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 配送先名称・氏名・氏名カナ・電話番号・国・郵便番号・住所・会社名。確認への送信指定と戻るの指定 |
| 成功時出力 | 確認画面の表示、または登録後の配送先選択への遷移 |
| 失敗時出力 | 上限超過はご注文方法指定への戻り。検証不備は編集画面の再表示 |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 登録・更新 | 確認画面からの登録確定（住所と配送先名称） |
