# デッキ管理 — デッキ検索・一覧

## 業務ロジック

### 初期表示

一覧の初期表示では、保持していた検索条件・ページ番号・表示件数を破棄し、空の検索条件・空の一覧・ページ番号 1・既定の表示件数で表示する。ソートキーと並び順は破棄しない。

### 検索条件

入力した検索条件は保持し、次に同じ画面へ戻ったときの検索に使う。

| 項目 | 検索条件 |
| --- | --- |
| デッキ名・イベント名・成績・プレイヤー名 | 半角空白・全角空白・カンマで語に分割し、語ごとに対象項目のいずれかへ部分一致。語どうしは AND、同じ語の中の複数項目は OR（イベント名は日本語名と英語名のどちらかに一致すればよい） |
| デッキID | 同様に分割し、数値だけを取り出して一致するものに限る。数値でない語は条件にしない |
| フォーマット・アーキタイプ・公開状態 | 選択したいずれかに一致 |
| カラー | 選択したいずれかの色を持つアーキタイプのデッキに限る |
| デッキリスト公開状態 | 選択がちょうど 1 件のときだけ、その真偽で一致させる。未選択または両方選択のときは条件にしない |
| イベント開催日 | 開始のみのときはその日の 0 時以上、終了のみのときはその日の 23 時 59 分 59 秒以下、両方あるときはその範囲 |
| 順位 | 開始側に整数があるときは下限、終了側に整数があるときは上限を付ける |
| 開催店舗 | イベント詳細を経由したイベントの店舗が選択値と一致するデッキに限る。この条件を指定すると、イベント詳細を持たないデッキは対象から外れる |
| 最終更新者 | デッキを最後に更新した管理者が選択値と一致するデッキに限る。この記録は、新規登録・編集・複製・一括編集で保存するたびに、その操作を行った管理者へ置き換わる |

### 選択肢の並び

フォーマットは表示順、表示順が同じときは登録の古い順に並べる。開催店舗と最終更新者は表示順に並べる。アーキタイプは、アーキタイプ名にそのフォーマット名を添えて示す。

### 大会開始前のデッキの扱い

イベント詳細に紐づかないデッキは、大会開始時刻による除外の対象にならず、検索結果に残る。

### 表示件数と並び順

表示件数は、保持していた値があるときはそれを使い、無いときは既定値とする。要求で指定された表示件数は、件数の選択肢と一致するときだけ採用して保持する。

並び順は要求の指定、無いときは保持していた値、それも無いときは既定値（デッキIDの降順）とする。昇順・降順のいずれでもない指定のときは、検索を行わずエラーを表示し、初期表示と同じ状態へ戻す。このとき検索条件とページ関連の保持値だけを破棄し、ソートキーと並び順の保持値は破棄しない。

検索条件を受け取れないときは、保持していた検索条件で検索する。保持していた検索条件も無いときは初期表示へ戻す。

最終ページで件数とページ番号の関係がずれるときは、ページ番号を 1 減らして調整する。

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | 検索条件、ソートキー、並び順、ページ番号、表示件数 |
| 成功時出力 | 検索条件の入力欄と、該当があるときは一覧とページ送りを含む画面 |
| 失敗時出力 | 並び順が不正のときはエラー表示と初期画面 |

### 入出力: 永続化

デッキのデータは更新しない。
