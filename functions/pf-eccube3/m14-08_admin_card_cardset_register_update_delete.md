# カード管理 — カードセット新規登録・編集・削除

## 業務ロジック

### 編集の初期表示

編集で対象のカードセットを取得できないときは、見つからない扱い（HTTP 404）とする。

### 保存の判定順序

| 順序 | 判定 | 結果 |
| --- | --- | --- |
| 1 | なりすまし対策の検証に失敗 | 保存せずアクセスを拒否する |
| 2 | 入力の検証に失敗 | 保存に失敗した旨のメッセージを表示し、入力画面を再表示する。収録カードは送信されたカードセットIDで取り直し、IDが無いときは空とする |

既存のカードセットの保存では、該当のカードセットを読み直し、入力された項目をすべて上書きする。

保存後は、保存したカードセットの編集画面へ戻る。

### シンボル画像

シンボル画像が送信されたときだけ、シンボル画像の値を更新する。送信されなかったときは値を変更しないため、編集では既存の画像が残る。

同じ名称の画像が既に置かれているときは、古いものを削除してから置き換える。

### 削除の可否

当該カードセットに紐づくカード詳細が1件でも存在するときは削除しない。削除できない旨のメッセージを表示し、直前の画面へ戻る。

削除の対象を指定していない、または該当のカードセットが存在しないときは、見つからない扱い（HTTP 404）とする。

削除後に戻るカードセット一覧のページ番号は、直前に一覧で開いていたページとする。保持していないときは1ページ目とする。

## 入出力

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 登録 | 新規のカードセットとして保存したとき。カードセットIDは登録時に採番する |
| 更新 | 既存のカードセットを保存したとき。シンボル画像は送信されたときだけ更新する |
| 削除 | 紐づくカード詳細が無いカードセットの削除 |
