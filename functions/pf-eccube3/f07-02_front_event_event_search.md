# F07-02（大会詳細検索）

キーワード・開催日時・フォーマット・開催場所・平日休日過去の条件で、フロントのイベントを検索し、結果を一覧表示する機能である。

## 概要

大会詳細検索は、利用者が検索フォームで条件を指定し、その条件に一致するイベント詳細を一覧で参照するための機能である。検索フォーム画面で条件を入力し、検索結果一覧画面でページングつきの一覧を表示する。検索条件はフォームのGET送信でクエリへ載せ、結果一覧はそのクエリを解釈して抽出する。結果が0件の場合はページが見つからない（HTTP404）扱いの応答とする。

本書は実装手順ではなく、誰が・いつ・どの条件で・結果どうなるかを読むためのリバース詳細設計とする。確認値はpf-eccube3（EC-CUBE3系）のHareruyaEcプラグインのイベント検索処理・検索結果処理、テンプレート（`Event/search.twig`・`Event/list.twig`）、イベント詳細リポジトリの検索クエリ組み立てを正とする。本機能のカスタマイズ区分はカスタマイズであり、挙動の参照リポはpf-eccube3、DB関連はec-cube-enterpriseを正とする。

対象はブラウザ経由のフロントに限定する。フロントのルートはロケールを先頭に持つ`/{_locale}`配下にあり、イベントは`/{_locale}/events`配下にまとまる。

本文ではフレームワークのコントローラ型名やメソッド名を主説明としない。本文ではルートbind名の網羅は主説明とせず、「利用者視点の入口」にHTTPメソッドとサイトルートからのパスパターンを書く。コード探索でbind名が必要なときだけ「調査補助」へ書く。

## リニューアル移行時の扱い

本機能はカスタマイズ区分がカスタマイズである。現行挙動はpf-eccube3のHareruyaEcプラグインを正とし、DBスキーマと移行後の扱いはec-cube-enterpriseを正とする。イベント関連テーブルはec-cube-enterpriseに移行済みであり、現行と移行先で次の差がある。

| 観点 | 現行（pf-eccube3） | 移行先（ec-cube-enterprise） |
|------|----------------------|--------------------------------|
| キーワード検索対象列 | `dtb_event.name_jp`・`name_en`・`short_name_jp`・`short_name_en`・`detail_jp`・`detail_en`の部分一致。 | `dtb_event`は`name_jp`・`name_en`を持つが、`short_name_jp`・`short_name_en`・`detail_jp`・`detail_en`列を持たない。移行先での検索対象列はec-cube-enterprise実装で要確認。 |
| フォーマット・会場 | フォーマット`mtb_format`、会場`mtb_venue`。 | 同一スキーマ。`mtb_format`・`mtb_venue`が存在する。 |
| 平日・休日 | `dtb_event_detail.holiday_flg`。 | 同一スキーマ。`dtb_event_detail`に`holiday_flg`が存在する。 |
| 表示区分・開催日 | 表示区分`disp_id`、開催日`start_date`。 | 同一スキーマ。`disp_id`・`start_date`が存在する。 |

## 利用者視点の入口

| 入口 | URLエンドポイント | 期待されるふるまい |
|------|--------------------|--------------------|
| 検索フォームを開く | `GET /{_locale}/events/search` | キーワード・開催日時・フォーマット・開催場所・詳細条件の入力フォームを表示する。 |
| 検索を実行する | `GET /{_locale}/events/list?term=…&from=…&to=…&formats[]=…&venues[]=…&isWeekday=…&isHoliday=…&isPast=…` | 条件に一致するイベント詳細をページングつきで一覧表示する。 |
| 結果一覧のページ送り | `GET /{_locale}/events/list?…&page={ページ番号}` | 同一条件で指定ページの一覧を表示する。 |
| 検索フォームへ戻る | `GET /{_locale}/events`（戻るリンク） | イベント大会TOPへ戻る。 |

検索結果が0件の場合は、ページが見つからない（HTTP404）として一覧画面の本文を返す。

## フロント挙動

| 観点 | 内容 |
|------|------|
| 表示要素 | 検索フォームは見出し「イベント検索」、キーワード欄、開催日時の開始・終了欄、フォーマットのチェックボックス群、開催場所のチェックボックス群、詳細条件のチェックボックス群、検索・リセット・戻るのボタン。結果一覧は検索結果と件数・ページングを表示する。 |
| JS挙動 | 開催日時の開始・終了欄は日付ピッカーで日付を選択する。カレンダーアイコンからもピッカーを開く。 |
| CSS・レイアウト | フォームは項目ラベルと入力域を行で並べる。フォーマット・会場・詳細条件はチェックボックスのラベルを横並びにする。 |
| モーダル・ポップアップ | 日付ピッカー以外のモーダル・ポップアップ・トーストは表示しない。 |

詳細条件の「平日のイベントを表示する」「休日のイベントを表示する」は初期状態でチェック済み、「過去のイベントを表示する」は初期状態で未チェックとする。

## 処理フロー

### 検索フォームを表示する（GET `/{_locale}/events/search`）

1. フォーマット一覧を表示順で取得する。
2. 会場一覧を取得する。
3. キーワード・開催日時・フォーマット・開催場所・詳細条件の入力フォームを表示する。

### 検索結果を表示する（GET `/{_locale}/events/list`）

1. ページ番号をクエリから取得する。無ければ1ページ目とする。
2. クエリ全体を検索条件として、一致するイベント詳細の件数を集計する。
3. 件数が1件以上なら、1ページ25件で該当ページのイベント詳細を取得する。0件なら一覧を空とする。
4. クエリに会場指定があれば、検索条件の店舗・会場リストを取得して表示に用いる。
5. クエリにフォーマット指定があれば、指定フォーマットを表示順で取得して表示に用いる。
6. 一覧・件数・ページ番号・ページサイズ・検索条件を渡して結果一覧を表示する。件数が0件なら、ページが見つからない（HTTP404）として本文を返す。

## 集計条件

| 指標 | 集計の要点 |
|------|------------|
| 検索件数 | イベント詳細とイベントを内部結合し、双方の表示区分が表示であることを前提に、後述の各条件で絞り込んだイベント詳細IDの重複なし件数を数える。 |
| 検索結果一覧 | 同じ条件で抽出したイベント詳細を開催日昇順に並べ、1ページ25件・指定ページ分を取得する。 |
| キーワード | キーワードがあれば、イベントの名称・略称・備考の日本語・英語のいずれかに部分一致するものを対象とする。 |
| 開催日時 | 開始日があれば当日0時以降、終了日があれば当日23時59分59秒以前の開催日に絞る。 |
| フォーマット | 指定があれば、イベントのフォーマットが指定フォーマットのいずれかに含まれるものに絞る。 |
| 開催場所 | 指定があれば、イベントの会場が指定会場のいずれかに含まれるものに絞る。 |
| 平日・休日 | 平日のみ指定なら休日フラグでない日程に絞る。休日のみ指定なら休日フラグの日程に絞る。両方指定または両方未指定なら平日休日の絞り込みをしない。 |
| 過去 | 過去を表示する指定が無ければ、開催日が現在時刻以降の日程に絞る。 |

## 業務ルール・計算

| 項目 | 内容 |
|------|------|
| ページング | 1ページ25件。ページ番号はクエリ`page`、無ければ1。表示開始位置は25×(ページ-1)。 |
| 並び順 | 検索結果は開催日昇順で並べる。 |
| 表示区分 | イベント・イベント詳細とも表示区分が表示の日程のみを対象とする。 |
| 平日休日の組合せ | 平日のみ・休日のみで絞り込み、両方指定・両方未指定では絞り込まない。 |
| 過去の既定 | 過去表示の指定が無ければ現在時刻以降に限定する。 |
| 0件時 | 件数0件のとき、ページが見つからない（HTTP404）として一覧本文を返す。 |

### 入力項目

| 項目名 | 必須／任意 | 最大長 | 初期値 | 保存先・扱い |
|--------|------------|--------|--------|----------------|
| キーワード検索 | 任意 | フォーム上限なし | 空 | クエリ`term`。現行はイベントの名称・略称・備考（日本語・英語）への部分一致で絞り込む。移行先`dtb_event`は名称（`name_jp`・`name_en`）を持つが略称・備考列を持たないため、移行先での対象列はec-cube-enterprise実装で要確認。送信先は結果一覧。 |
| 開催日時（開始） | 任意 | フォーム上限なし | 空 | クエリ`from`。`Y/m/d`形式として解釈し当日0時以降に絞る。解釈できない値は条件に用いない。日付ピッカーで入力する。 |
| 開催日時（終了） | 任意 | フォーム上限なし | 空 | クエリ`to`。`Y/m/d`形式として解釈し当日23時59分59秒以前に絞る。解釈できない値は条件に用いない。日付ピッカーで入力する。 |
| フォーマット | 任意 | — | 全て未選択 | クエリ`formats[]`（フォーマットID）。複数選択。いずれかに含まれるイベントへ絞る。 |
| 開催場所 | 任意 | — | 全て未選択 | クエリ`venues[]`（会場ID）。複数選択。いずれかに含まれるイベントへ絞る。 |
| 平日のイベントを表示する | 任意 | — | チェック済み | クエリ`isWeekday`。平日のみ指定で休日フラグでない日程に絞る。チェックボックス。 |
| 休日のイベントを表示する | 任意 | — | チェック済み | クエリ`isHoliday`。休日のみ指定で休日フラグの日程に絞る。チェックボックス。 |
| 過去のイベントを表示する | 任意 | — | 未チェック | クエリ`isPast`。未指定なら現在時刻以降に限定する。チェックボックス。 |

リセットボタンはフォームを初期状態へ戻す。戻るボタンはイベント大会TOPへ遷移する。

### エッジケース

| ケース | 扱い |
|--------|------|
| 全条件未指定で検索 | 表示区分が表示で現在時刻以降のイベント詳細を、平日休日とも初期チェック前提で抽出する。 |
| 開始・終了が不正な日付 | `Y/m/d`として解釈できない値は当該条件に用いない。 |
| 平日・休日とも未チェック | 平日休日の絞り込みをしない（両方表示）。 |
| 件数0件 | ページが見つからない（HTTP404）として一覧本文を返す。 |
| ページ番号が件数を超過 | 該当ページのイベント詳細が空になり一覧を表示しない。 |

## データ整合性

| 観点 | 内容 |
|------|------|
| 参照時点 | 検索結果は要求時点で取得したイベント詳細に基づく。表示後の更新は自動反映しない。 |
| 件数と一覧 | 件数は重複なしのイベント詳細IDで数える。一覧は同条件で抽出した同単位の行を並べる。フォーマット・会場の複数結合による行の重複は件数側で重複なし集計とする。 |
| 詳細との整合 | 一覧から遷移した詳細（F07-03）の内容は遷移先の取得結果を正とする。一覧表示と詳細の完全一致は保証しない。 |
