# F07-02（大会詳細検索）

キーワード・開催日時・フォーマット・開催場所・平日休日過去の条件でイベントを検索し、結果を一覧表示する。

## 業務ロジック

### 検索条件

| 画面上の項目 | 検索条件 |
| --- | --- |
| キーワード | 入力した語で検索する |
| 開催日時 | 開始と終了を日付で指定する |
| フォーマット | チェックしたフォーマットに限定する |
| 開催場所 | チェックした会場に限定する |
| 平日のイベントを表示する／休日のイベントを表示する | 平日のみ・休日のみのときだけ絞り込む。両方を指定したときと両方を指定しないときは絞り込まない |
| 過去のイベントを表示する | 指定が無いときは現在時刻以降に限定する |

「平日のイベントを表示する」「休日のイベントを表示する」は初期状態でチェック済み、「過去のイベントを表示する」は初期状態で未チェックとする。

イベントとイベント詳細のいずれも、表示区分が表示の日程だけを対象とする。

### 検索フォームの表示

フォーマット一覧を表示順で取得し、会場一覧とあわせて選択肢として表示する。

### 並び順と表示件数

検索結果は開催日の昇順に並べる。1ページは25件とし、ページ番号の指定が無いときは1ページ目とする。表示開始位置は25×(ページ番号-1)である。

### 検索結果の表示

件数が1件以上のときは該当ページのイベント詳細を取得して一覧に表示する。件数が0件のときは一覧を空とし、ページが見つからない（HTTP404）として一覧の本文を返す。

会場の指定があるときは検索条件の店舗・会場一覧を、フォーマットの指定があるときは指定フォーマットを表示順で取得し、いずれも表示に用いる。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| 件数0件 | ページが見つからない（HTTP404）として一覧の本文を返す |
| 不正な日付条件 | 当該条件を無視して検索を続ける |

利用者向けの個別のエラー文言は専用に定義せず、結果一覧の表示で扱う。

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | キーワード、開催日時の開始と終了、フォーマット、会場、平日休日過去の指定、ページ番号 |
| 成功時出力 | 検索フォーム、または件数1件以上の検索結果一覧。件数とページングをあわせて表示する |
| 失敗時出力 | 件数0件のときはページが見つからない（HTTP404）として一覧の本文を返す |
