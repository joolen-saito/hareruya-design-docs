# F07-02（大会詳細検索）

キーワード・開催日時・フォーマット・開催場所・平日休日過去の条件でイベントを検索し、結果を一覧表示する。

## 業務ロジック

### 検索条件

| 画面上の項目 | 検索条件 |
| --- | --- |
| 平日のイベントを表示する／休日のイベントを表示する | 平日のみ・休日のみのときだけ絞り込む。両方を指定したときと両方を指定しないときは絞り込まない |

「平日のイベントを表示する」「休日のイベントを表示する」は初期状態でチェック済み、「過去のイベントを表示する」は初期状態で未チェックとする。

イベントとイベント詳細のいずれも、表示区分が表示の日程だけを対象とする。

### 検索フォームの表示

フォーマットの選択肢は表示順に並べる。開催場所の選択肢は会場を全件表示する。

### 並び順とページ送り

検索結果は開催日の昇順に並べる。

ページ送りは、現在のページ番号を挟んで前後4ページ分までのページ番号と、先頭・前・次・末尾への移動を表示する。表示できないページ番号がさらに続くときは省略記号を出す。移動先は現在の検索条件を引き継ぐ。

### 検索結果の表示

件数が1件以上のときは該当ページのイベント詳細を一覧に表示する。開催日時は年月日と時までを表示する。フォーマットは、1件だけ設定されているときはその名称を表示し、それ以外のときは「混合フォーマット」と表示する。

件数が0件のときは一覧を空とし、ページが見つからない（HTTP404）として一覧の本文を返す。

### 表題と説明文

キーワード・開催日時の期間・平日休日過去の別・指定したフォーマットのいずれかが指定されているときは、それらを連ねた文字列からページの表題と説明文を組み立てる。フォーマットは表示順に連ねる。いずれの指定も無いときは、表題と説明文を差し替えない。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| 不正な日付条件 | 当該条件を無視して検索を続ける |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | ページ番号。指定が無いときは1ページ目とする |
| 失敗時出力 | 件数0件のときはページが見つからない（HTTP404）として一覧の本文を返す |
