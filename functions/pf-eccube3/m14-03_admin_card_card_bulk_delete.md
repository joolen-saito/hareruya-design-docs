# カード管理 — 一括削除

## 業務ロジック

### 削除の判定順序

| 順序 | 判定 | 結果 |
| --- | --- | --- |
| 1 | 要求が正当か | 正当でなければアクセス拒否（HTTP 403）とする |
| 2 | 削除対象のカードIDが送られているか | 送られていなければメッセージを出さず、カード検索結果またはカード一覧へ戻す |
| 3 | 各IDが空でなく、該当するカードが存在するか | 満たさないときはHTTP 404として打ち切る |
| 4 | デッキで採用されているか | 1件でも採用されていれば削除できないとして、エラーを表示する |
| 5 | 論理削除されていない商品がカード詳細を経由して存在するか | 存在すれば削除できないとして、エラーを表示する |
| 6 | 上記を通過 | カードに紐づく商品規格の紐付けを外したうえで、カードとその子データを削除する |

判定と削除は、送られたカードIDの並び順に1件ずつ行う。削除できないカードに当たった時点で、そこまでに削除できたIDだけを支店へ通知してから元の画面へ戻す。

### 削除できない条件

デッキに採用されている行が1件でもあるとき、または論理削除されていない商品がカード詳細を経由して存在するときは削除しない。後者は、カード・カード詳細・商品サブ・商品をたどって論理削除されていない商品が1件でもあるかで判定する。買取に関するデータはこの判定に含めない。

### 削除の内容

削除できるカードは、まず当該カードのカード詳細に結び付いていた商品規格から、その紐付けだけを外す。販売商品の親子関係は維持する。続いて当該カードにぶら下がる子データを深いものから順に削除し、最後にカード自体を削除する。数量計算や料金計算は行わない。

### 支店への通知

すべてのIDを削除できたときは、受け取ったID配列を支店へ渡して更新を通知する。通知の結果はログに残し、失敗したときは支店連携エラーとして記録する。通知の失敗は画面上の成功表示を取り消さない。

### 処理後の戻り先

カード検索結果のページが保持されているときはそのページへ、保持されていないときはカード一覧へ戻す。

### エラー時の扱い

| 事象 | 扱い |
| --- | --- |
| 要求が正当でない | アクセス拒否（HTTP 403）とする |
| 対象のカードが存在しない | HTTP 404として打ち切る |
| デッキ採用または論理削除されていない商品がある | エラーを表示し、そこまでに削除できた分だけ支店へ通知して元の画面へ戻す |
| 支店への通知が失敗 | ログと支店連携エラーに記録する。画面は成功の表示のまま終わり得る |

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | 削除対象のカードID群。検索条件は同じ画面から送られるが、この処理では参照しない |
| 成功時出力 | カード検索結果またはカード一覧へ戻し、削除完了を表示する |
| 失敗時出力 | 要求が正当でないときはHTTP 403、カードが存在しないときはHTTP 404。削除できないときはエラーを表示して元の画面へ戻す |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 更新 | 削除できるカードごとに、そのカード詳細に結び付いていた商品規格の紐付けを外す |
| 削除 | 同じ契機で、カードにぶら下がる子データとカード自体を削除する |
| 追加 | 支店への通知に失敗したとき、支店連携エラーを記録する |

| メッセージID | 表示位置 | 画面上の文言 | 表示条件 | 後続処理 |

| M14-03-MSG-001 | 管理画面上部 | 削除に失敗しました | カードを選択せずに一括削除したとき | カード管理画面に遷移する |
| M14-03-MSG-002 | 管理画面上部 | 削除に失敗しました | 選択したカードの一括削除中にエラーが起きたとき | カード管理画面に遷移する |
| M14-03-MSG-003 | 管理画面上部 | 削除しました | 選択したカードのうち1件以上を削除できたとき | カード管理画面に遷移する |
| M14-03-MSG-004 | 管理画面上部 | デッキまたは商品にカードが登録されているため、%card_name% カード情報を削除することができません。 | 選択したカードがデッキまたは商品で使用されていて削除できないとき | カード管理画面に遷移する |
