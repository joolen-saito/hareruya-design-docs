# 商品管理 — カード商品CSV登録

## 業務ロジック

### 取込の前提

アップロード画面は、カード商品CSVの取込履歴だけを一覧に出す。表示件数は許容値のいずれかに一致するときだけ切り替え、一致しないときは既定の 10 件とする。

雛形は列見出しだけを 1 行書いたファイルとして出力する。見出しの並びは画面のフォーマット表と同じである。

取り込むファイルはCSVで、拡張子がタブ区切りのときだけタブを区切り文字として扱う。

### 行数上限

ダブルクォート内の改行を除いた改行数が `5010` 以上のときは取り込まない。

### 判定順序

| 順序 | 判定 | 結果 |
| --- | --- | --- |
| 1 | ヘッダ行とデータ行があるか | 不備のときは取込前にエラーとし、商品データは変更しない |
| 2 | 各行の列数とヘッダ名が定義どおりか | 不一致または未定義の列名があるときは全体を中断する |
| 3 | 各列の必須・型・マスタ存在・複数値の形式 | いずれかを満たさないときは全体を中断する |
| 4 | 販売価格と買取価格の大小 | 買取価格が販売価格を上回るときは全体を中断する |
| 5 | 更新かつ公開ステータスを廃止に変える行の在庫 | 在庫が 1 件でも残っているときは全体を中断する |
| 6 | カード詳細IDの該当件数 | 不存在のときも複数件に該当するときも全体を中断する |
| 7 | 更新対象の商品IDの実在 | 指定があるのに存在しないときは全体を中断する |
| 8 | 同一のカード詳細を別の商品が既に持つか | 持つときは当該行だけを取り込まない |
| 9 | 新規行の商品コードが全ステータスの商品に重複するか | 重複するときは当該行だけを取り込まない |
| 10 | 規格の一意制約 | 違反したときは取込全体を取り消す |

エラーが 1 件も無いときだけ、取り込んだ内容を確定し、取込履歴を 1 件加える。エラーがあるときは取込内容を取り消す。

### 商品削除フラグの扱い

商品削除フラグに 1 を指定した行は、商品を削除済みにする。商品の行は消さず、削除済みの区分を立てる。商品を削除済みにした行では、商品規格の追加と更新を行わない。既存の商品規格の削除済みの区分は変えない。

### Excel基本設計により廃止された仕様

以下は Excel基本設計 0204 識別ID:29 により廃止された。現行のふるまいとして残すが、刷新後の実装とテストの対象外とする。

#### 価格と規格の扱い

販売価格・買取価格・基準価格は取込時に小数を切り捨てて整数にする。

カード状態ごとに、既存の規格があるときは更新し、無いときは追加する。追加したときは全店舗と在庫場所の組み合わせぶんの在庫を数量 0 で作る。

既存の規格がセール中でないときは、CSVの基準価格をそのまま販売価格に反映する。セール中のときはCSVの値より既存の販売価格を優先する。

販売価格または買取価格が変わった規格だけ価格履歴を追加する。新規の規格は常に価格履歴を追加する。

高額品コードが付いた規格は、規格を集める対象から外す。

### エラー時の扱い

| エラー内容 | 処理 |
| --- | --- |
| ファイル未選択・許容サイズ超過 | 取込を行わず、アップロード画面へ戻す |
| ファイルを読み込めない | 取込を行わず、アップロード画面へ戻す |
| 行数が上限以上 | 取込を行わず、アップロード画面へ戻す |
| ヘッダのみ・列数不一致などの事前検証の失敗 | 取込を行わず、検出したメッセージをすべて表示する |
| 行ごとの検証エラー・業務エラー | 検出したメッセージをすべて表示する。取込内容の確定可否は判定順序に従う |

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | カード商品CSVのファイル 1 件 |
| 成功時出力 | アップロード画面へ戻り、取り込んだ件数ぶんの商品と規格を反映する |
| 失敗時出力 | アップロード画面へ戻り、検出したエラーメッセージを表示する |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 追加・更新 | 商品・規格・商品カテゴリ・商品タグ・売上分析タグ・規格画像を、取込ファイルの行ごとに反映したとき |
| 追加 | 新規の規格を作ったときの在庫、および価格が変わったときの価格履歴 |
| 追加 | エラーが 1 件も無く取込を確定したときの取込履歴 |
