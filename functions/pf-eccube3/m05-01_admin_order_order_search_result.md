# 受注管理 — 受注情報検索・一覧 検索結果

検索条件の入力・保存とその判定は「受注情報検索・一覧」に書く。本書は検索したあとの一覧の内容と、一覧から起こる受注の更新を対象とする。

## 業務ロジック

### 一覧の表示有無

該当が 0 件のときは一覧を表示しない。1 件以上のときだけ一覧を表示する。

### 該当件数

該当件数は、ページング処理が返す総件数である。ページ番号の補正に使う件数は、これとは同じ値とは限らない。補正に使う件数は別に求める。

### 表示件数

表示件数の候補は表示件数マスタに登録された値である。候補に無い値を指定したときは、その値を無視し、現在の表示件数のまま検索する。表示件数を変えたときはページ番号 1 から検索し直す。

### 並び順 [乖離]

一覧の並びは注文日の降順に固定である。指定したソートキーと並び順は、並びに反映されない。並び順が昇順・降順のいずれの表記にも一致しないときは、エラーを出して一覧の初期表示に戻る。

### ページ番号の補正

ページ番号が 2 以上で、かつ件数照会の結果が 1 つ前のページまでの表示件数の合計と厳密に一致するときだけ、ページ番号を 1 減らす。最終ページのデータが削除されて表示対象が無くなったとき、1 つ前のページを表示する。

補正に使う件数照会は、保存済み検索条件の該当件数と同じ数え方であり、明細が複数ある受注を重複して数える。補正は、重複を含む件数が合計と等しいときだけ成立する。重複が起きる検索では、補正すべき場面で成立しない。補正が不要な場面で成立することもある。

この比較は値だけでなく型も一致することを求める。補正が実際に発動するかどうかは確認できない。件数照会が返す値の型が正本コードから読み取れない。

### 当日受取の表示

当日受取の受注には、注文日の横にラベルを表示する。ラベルの文言は「当日」である。判定は受注に紐づく当日受取の区分による。判定の対象は表示中のページの受注だけである。

### 警告の表示 [乖離]

次の 2 種類のいずれかに該当する受注は、注文番号を赤字で表示する。両方に該当する受注は、警告文言を 2 行とも表示する。

| 種類 | 該当条件 |
| --- | --- |
| 決済の警告 | 対応状況が注文受領で、かつキャンセル日または出荷日のいずれかが設定済みのとき |
| 連携の警告 | スマレジ連携エラーの区分が立っているとき |

判定の対象は表示中のページの受注だけである。前後のページに該当する受注が在っても、そのページを表示するまで警告は出ない。

### 一括操作の対象範囲

対象の決め方は操作ごとに異なる。対象を選ばずに実行できるものと、選ばないと実行できないものが混在する。

| 操作 | 対象 | 対象が 0 件のとき |
| --- | --- | --- |
| CSVダウンロード（受注・配送） | 検索条件に一致する全件 | そのまま実行する |
| カスタムCSVダウンロード（受注・配送） | 検索条件に一致する全件 | そのまま実行する |
| メール一括通知 | 選んだ受注 | 警告を出して実行しない |
| スタック用紙印刷 | 選んだ受注 | 警告を出して実行しない |
| 納品書印刷（日本語・英語） | 選んだ受注 | 警告を出して実行しない |
| 送り状CSV | 選んだ受注 | 確かめずに実行する |

対象にできるのは表示中のページの受注だけである。カスタムCSVダウンロードの選択肢は、受注用・配送用のそれぞれに登録済みの出力項目の組み合わせである。登録が無いときは出力項目設定への導線だけが残る。

### 送り状CSVの未選択送信 [乖離]

送り状CSVだけは対象が 0 件でも実行する。見出し行だけのCSVを出力する。

### 納品書印刷の対象

日本語の納品書は国外配送でない受注だけ、英語の納品書は国外配送の受注だけを対象にする。国内外は配送方法の海外配送の区分で決まる。選んだ受注のうち対象外のものは、印刷内容に含まれない。

### 受注の削除

受注は消さずに削除済みの区分を立てる。削除要求には偽造防止のトークンを付け、受注を探す前に検証する。トークンが不正なときは削除しない。削除しようとした受注が見つからないときも削除しない。

削除した受注の注文者が会員のときは、その会員の購入実績を数え直す。数え直す対象は、注文受領・入金待ち・取寄せ中・出荷完了・対応済みのいずれかの対応状況にある受注だけである。

数え直す対象の受注が残り、会員の初回購入日時が未設定のときは、削除を実行した日時を初回購入日時に設定する。初回購入日時が設定済みのときは変更しない。残った受注の注文日は初回購入日時に使わない。

### スタック用紙印刷による更新

スタック用紙印刷は受注を更新することがある。更新の条件と、注文番号が未採番の受注があるときに更新せず終わる分岐は、スタック用紙印刷の設計書に書く。

### Excel設計書との乖離

[乖離] を付けた記述は、現行ソースにあって Excel設計書に無いふるまいである。

| 現行ソースのふるまい | Excel設計書の記載 |
| --- | --- |
| 警告に該当する受注は注文番号を赤字にし、警告文言を併記する | 警告表示の記載が無い |
| 並びは注文日の降順に固定で、並び替えできない | 並び順の記載が無い |
| 送り状CSVだけは対象が 0 件でも実行できる | 選択したデータを対象とする操作として、他の一括操作と同じ扱いで記載 |

## 入出力

### 出力: 一覧の表示規則

列の構成は基本設計の画面項目定義による。書式が実装で決まる列だけを挙げる。

| 列 | 書式 |
| --- | --- |
| 注文日 | 年/月/日 時:分。未設定のときは空欄 |
| 注文番号 | 警告に該当するときは赤字にし、下に警告文言を出す |
| お名前 | 注文者の姓と名を半角空白で連結 |
| 購入金額(円) | 桁区切り、右寄せ |
| 出荷指示日 | 年/月/日。未設定のときは空欄 |

### 入出力: 永続化

受注が更新されるのは、受注の削除と、スタック用紙印刷による更新の 2 つである。

| 操作 | 契機 |
| --- | --- |
| 受注の削除区分の更新 | 受注の削除 |
| 注文者が会員のときの購入回数・購入金額の再計算と、初回購入日時が未設定のときの設定 | 受注の削除 |
| 注文者に購入実績の集計対象となる対応状況の受注が 1 件も残らないときの初回購入日時・最終購入日時の消去と、購入回数・購入金額の 0 化 | 受注の削除 |
| ブラウザ印刷フラグ・対応状況・注文確定日・担当者の更新 | スタック用紙印刷。担当者は要求で渡されたメンバーIDが実在するときだけ更新し、実在しないときは変更しない |
