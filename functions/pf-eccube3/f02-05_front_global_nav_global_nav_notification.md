# F02-05（通知）

## 概要

通知は、フロントの共通ヘッダ・ナビゲーション上で、特定の条件を満たすときだけ利用者向けの状態表示（通知）を出し分ける機能である。共通ヘッダはログイン状態に応じて保有ポイント表示の有無とマイページ隠しメニューの導線内容を切り替え、カートの内容に応じてカート個数を非同期に表示する。これらは利用者が「ログインしているか」「カートに商品があるか」を、画面遷移せずヘッダ上で把握するための通知表示である。

本書は実装手順ではなく、誰が・いつ・どの条件で・結果どうなるかを読むためのリバース詳細設計とする。確認値はpf-eccube3（EC-CUBE3系）のHareruyaEcプラグインの共通ヘッダテンプレート（`Block/base_header.twig`）、保有ポイントヘッダ表示処理、ヘッダのカート個数取得スクリプト（`Block/js/header_js.twig`）を正とする。本機能のカスタマイズ区分はカスタマイズであり、画面挙動の参照リポはpf-eccube3、DB関連の記述はec-cube-enterpriseを正とする。

対象はブラウザ経由のフロント共通ヘッダ・ナビの通知表示に限定する。

本文ではフレームワークのコントローラ型名やメソッド名を主説明としない。「利用者視点の入口」にHTTPメソッドとサイトルートからのパスパターンを書く。フロントのページであり管理画面プレフィックスは付かない。フロントのルートはロケール接頭辞`/{_locale}`の下に置かれる。本書でいう通知は、ヘッダ・ナビ上の条件付き状態表示を指し、メール送信・プッシュ通知・入荷通知依頼は対象外とする。

---

## 本書で扱うこと

- ログイン状態による保有ポイント表示の有無
- ログイン状態によるマイページ隠しメニューの導線（ログイン／会員登録の出し分け）
- カートの内容によるカート個数の表示
- 言語切替リンクの表示有無
- 各通知表示が満たすべき条件と、判定の順序

---

## 本書で扱わないこと

以下は本書では仕様確定せず、実装または別機能の設計を正とする。

- 本店・支店の各ナビゲーション本体（F02-01〜F02-04を正とする）
- 保有ポイントの集計（ポイント機能を正とする）
- カート個数の算定・カート処理（カート機能を正とする）
- ログイン認証そのもの（会員ログイン機能を正とする）
- 入荷通知依頼・お気に入りセール通知などのメール／一覧系通知（各機能を正とする）

## リニューアル移行時の扱い

本機能は共通ヘッダの通知表示であり、テーブル更新を行わない参照機能のため、移行に伴うデータ移送はない。画面挙動はpf-eccube3を確認値とし、DB関連はec-cube-enterpriseを正とする。

- 通知機能（※Excel基本設計 0302「通知機能」はフェーズ2対応。フェーズ1では実装しない）。機能まるごとフェーズ2対応。Excel原文: 「フェーズ2以降で設計予定とする」（0302 通知）

| ログイン状態の判定 | 会員の認証情報で判定 | 同一（会員ログイン機能を正とする）。 |
| カート個数の取得 | カート情報の非同期取得 | 同一（カート機能を正とする）。 |

## 利用者視点の入口

| 入口 | URLエンドポイント | 期待されるふるまい |
|------|--------------------|--------------------|
| 共通ヘッダを含む各画面を開く | `GET /{_locale}/`ほかフロントの各URL | ログイン状態に応じて保有ポイント表示・マイページ導線を出し分け、カート個数を非同期取得して表示する。 |
| 保有ポイントヘッダ表示（部分描画の境界） | `GET|POST /{_locale}/mypage/point_in_header` | ログイン会員のとき、保有ポイントの部分テンプレートを返す。 |
| カート個数の非同期取得 | `GET /{_locale}/cart/get` | カート情報を取得し、ヘッダのカート個数表示へ反映する（カート機能を正とする）。 |

通知表示は利用者が直接URLで開くより、各画面のヘッダの一部として描画・更新される。

## フロント挙動

| 観点 | 内容 |
|------|------|
| 表示要素 | ログイン会員のとき保有ポイント表示を出す。マイページアイコンと隠しメニュー（マイページへの導線、未ログイン時はログイン／会員登録）を出す。カートのアイコンにカート個数を表示する。条件により言語切替リンクを出す。 |
| JS挙動 | 画面読込時にカート情報を非同期取得し、取得値をカート個数表示へ反映する。マイページアイコン押下で隠しメニューを開閉する。 |
| CSS・レイアウト | 保有ポイント表示・隠しメニュー・カート個数はヘッダ右側に配置する。隠しメニューは重ね表示する。 |
| モーダル・ポップアップ | 通知表示自体は専用モーダルを持たない。 |
| 入力項目 | 通知表示は入力フォームを持たない。 |

保有ポイント表示・カート個数・隠しメニューの導線はいずれも条件で有無が変わる通知表示である。

## 処理フロー

### ヘッダの通知表示を出し分ける

1. 共通ヘッダの描画時に、利用者がログイン会員か判定する。
2. ログイン会員のとき、保有ポイントヘッダ表示を組み込む。未ログインのときは保有ポイント表示を出さない。
3. マイページ隠しメニューに、未ログインのときはログイン／会員登録の導線を加え、いずれの状態でもマイページへの導線を出す。
4. 言語切替リンクが無効化されていない画面では言語切替リンクを出す。
5. 画面読込後、カート情報を非同期取得し、カート個数をヘッダのカート表示へ反映する。

---

## ヘッダ通知表示の判定順序

| 順序 | 判定 | 結果 |
|------|------|------|
| 1 | 利用者がログイン会員か | 会員なら保有ポイント表示を出す。未ログインなら出さない。 |
| 2 | 利用者がログイン会員か | 未ログインなら隠しメニューにログイン／会員登録の導線を加える。会員ならログイン／会員登録の導線を出さない。 |
| 3 | 言語切替リンクが無効化されているか | 無効化されていなければ言語切替リンクを出す。 |
| 4 | カート情報の非同期取得 | 取得したカート数量をカート個数表示へ反映する。 |

## 表示メッセージ

### 常時表示（条件付き・静的）

| 種別 | 表示文言（日本語） | 表示文言（英語） | 条件 |
|------|-------------------|-----------------|------|
| 保有ポイント | ポイント（と保有ポイント数） | Points（と保有ポイント数） | ログイン会員のとき |
| マイページ導線 | マイページ | My page | ヘッダ表示時（ログイン状態を問わず） |
| ログイン導線 | ログイン／会員登録 | Login / Register | 未ログインのとき |
| カート個数 | カート（アイコンと数量表示） | 同左（テキストラベルなし、数量のみ） | カート情報の非同期取得後、取得した数量を反映 |
| 言語切替 | EN | JP | 日本語ページではENを、英語ページではJPを表示。言語切替リンクが無効化されていないとき |

英語文言は英語ヘッダテンプレート（`Block/base_header.en.twig`・`Mypage/point_in_header.en.twig`）の確認値とする。利用者は言語切替リンクで英語ヘッダへ到達する。

通知表示は状態の有無を示すのみで、エラー文言・フラッシュは持たない。

## 業務ルール・計算

| 項目 | 内容 |
|------|------|
| 保有ポイント表示の条件 | ログイン会員のときだけ表示する。未ログインでは表示しない。集計はポイント機能を正とする。 |
| ログイン／会員登録導線の条件 | 未ログインのときだけ隠しメニューへ加える。 |
| カート個数の更新 | 画面読込後にカート情報を非同期取得し、取得した数量を反映する。算定はカート機能を正とする。 |
| 言語切替リンクの条件 | 画面側の無効化指定が無いときに表示する。 |
| 本店・支店共通 | 本通知表示は共通ヘッダ部品の挙動であり、本店・支店いずれのヘッダでも同じ条件で出し分ける。 |

本機能は金額計算・税計算・丸めを行わない。通知表示は入力フォームを持たないため、入力項目に紐づく表を持たない。

### エッジケース

| ケース | 扱い |
|--------|------|
| 未ログインで表示 | 保有ポイント表示を出さない。隠しメニューにログイン／会員登録を出す。 |
| ログイン会員で表示 | 保有ポイント表示を出す。隠しメニューにログイン／会員登録を出さない。 |
| カート情報の非同期取得が完了する前 | カート個数表示は取得完了まで初期状態のままとなる。 |
| 言語切替リンクが無効化された画面 | 言語切替リンクを出さない。 |

## データ整合性

| 観点 | 内容 |
|------|------|
| 参照時点 | 保有ポイント表示・隠しメニューの導線はヘッダ描画時点のログイン状態に従う。カート個数は非同期取得した時点の値であり、ヘッダ描画時点とは別時点となり得る。 |
| ログイン状態との整合 | 保有ポイント表示・ログイン／会員登録導線の有無は、描画時点のログイン状態と一致する。 |

## DBカラム

機能に直接関係する列のみ記載する。型や一覧の細部はスキーマを参照する。

| テーブル | 列 | メモ |
|---------|-----|------|

### DB操作

永続化の正は ec-cube-enterprise（テーブル名・操作は ec-cube-enterprise を正典）。当ドメインは承認ワークフローを介さず persist/flush で直接確定する（承認ワークフローは在庫機能固有）。

| 操作種別 | 対象テーブル | 契機・条件 |
|---------|--------------|------------|
| 登録/更新 | dtb_player | 当機能が行う登録・更新で対象テーブルを直接保存する（不要な削除は含まない）。確定は persist/flush による即時反映。DB=ec-cube-enterprise を正典とする。 |
