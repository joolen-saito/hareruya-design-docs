# データ管理 — トップバナー管理

## 業務ロジック

### 画面の表示

トップバナーを主キー昇順で全件取得し、バナー設定フォームに載せて表示する。トップバナーモードでは表示タイプの選択肢が「非表示」「表示」の2値になる。

画像アップロード用のフォームは、ファイル入力・テキスト項目（送信時は参照しない）・店舗の単一選択を持つ。店舗で絞り込んで開いたときは当該店舗が既定選択になる。

画像一覧は、店舗の指定が無いときは`banner/`、あるときは`banner/{店舗の識別名}/`のファイル一覧を取得し、更新日時の降順に並べ替えたうえで先頭から最大2000件だけを表示する。

### バナー設定の保存

| 判定 | 結果 |
|------|------|
| なりすまし対策トークンが不正なとき | アクセス拒否（HTTP 403）とする |
| フォームの検証に失敗したとき | リンク先URLの上限文字数（既定255）を埋め込んだ文字数超過のエラーを表示し、同一画面を再表示する。このとき画像一覧は`banner/`直下だけを取り直すことがあり、店舗で絞り込んだ表示とは一致しないことがある |
| フォームの検証に成功したとき | 各スロットの「並び順」の数値で並べ替えた結果に従って、画像URL・リンク・表示タイプ・言語・altをどのトップバナー行へ書き込むかを決める |

書き込む値の扱いは次のとおりである。

| 項目 | 扱い |
|------|------|
| 言語 | 選択したID群から言語を取得して関連を置き換える |
| リンク | 値が欠けているときは空文字を保存する |
| 店舗との関連 | トップバナーでは更新しない |

保存後は、店舗で絞り込んでいないときはトップバナー画面へ、絞り込んでいるときは当該店舗のトップバナー画面へ戻る。この経路では完了メッセージを表示しない。

### 入力の制約

| 項目 | 内容 |
|------|------|
| 表示からの除外 | 画像URLを空にすると、URLが空でないことを条件とするフロントの抽出対象から外れることがある |
| リンク先URL | 最大255文字。許容文字種は実装の検証規則による |
| 画像URL | 最大255文字。admin.hareruyamtg.com を含む文字列は不正とする |
| 画像ファイル | 520000バイト以下かつGIF・JPEG・PNGのみ |

本機能では金額計算や税率計算を行わない。

### 画像のアップロード

| 判定 | 結果 |
|------|------|
| フォームの検証に失敗したとき | バナー設定の失敗と同様に同一画面を再表示する |
| ファイルが未選択のとき | ファイル未選択のエラーを表示する |
| ファイルサイズが520000バイトを超えるとき | 上限値を埋め込んだサイズ超過のエラーを表示する |
| 画像種別がGIF・JPEG・PNGのいずれでもないとき | 画像でない旨のエラーを表示する |
| 上記を通過したとき | 店舗が未選択なら`banner/`、選択済みなら`banner/{店舗の識別名}/`へ、推定した拡張子でファイルを保存する |

保存後は、店舗が未選択のときは絞り込み無しの画面へ、選択済みのときは当該店舗の画面へ戻り、アップロード欄の位置を表示する。

### 画像の削除

なりすまし対策トークンを検証する。指定されたファイル名をサーバー側のエンコーディング規則に従って変換したうえで、対象が存在するときは削除する。存在しないときもエラー画面にはせず、アップロード欄の位置を表示して画面へ戻る。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| なりすまし対策トークンが不正なとき | アクセス拒否（HTTP 403）とする |
| バナー設定フォームの検証に失敗したとき | 文字数超過を基にした文言を表示し、同一画面を再表示する |
| ファイル未選択・サイズ超過・非画像のとき | 各エラーを表示し、同一画面を再表示する |
| 削除対象のファイルが存在しないとき | 削除を行わず画面へ戻る |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 表示は店舗の識別名の有無。保存はバナー設定フォーム本体、またはファイルと店舗選択。削除は対象ファイル名。いずれもなりすまし対策トークンを伴う |
| 成功時出力 | 画面への遷移または画面表示。バナー設定の保存成功時は完了メッセージを付けず遷移だけを行う |
| 失敗時出力 | 同一画面の再表示とエラー表示。なりすまし対策トークン不正のときはアクセス拒否（HTTP 403） |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 更新 | バナー設定の保存（画像URL・リンク・表示タイプ・言語・alt） |

## 表示メッセージ

| メッセージID | 表示位置 | 画面上の文言 | 表示条件 | 後続処理 |
| --- | --- | --- | --- | --- |
| M16-02-MSG-001 | 本文 | 画像がありません。 | トップバナー画像一覧に表示対象の画像がないとき | 画像なしの一覧を表示し、同一画面に留まる |
