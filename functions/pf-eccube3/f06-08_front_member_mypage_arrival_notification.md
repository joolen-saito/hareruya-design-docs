# F06-08（入荷待ち商品一覧）

## 概要

入荷待ち商品一覧は、ログイン済み会員が在庫無し商品で入荷通知（再入荷のお知らせ）を登録した商品を確認する機能である。会員に紐づく入荷通知依頼から、対象商品の名称・言語・状態（コンディション）・価格などを集約して一覧表示する。入荷時に登録メールアドレスへ通知を送る旨を案内する。一覧の各商品から商品詳細やカード検索へ遷移できる。

本書は実装手順ではなく、誰が・いつ・どの条件で・結果どうなるかを読むためのリバース詳細設計とする。確認値はpf-eccube3（EC-CUBE3系）のHareruyaEcプラグインの入荷通知依頼一覧処理、入荷待ち商品一覧テンプレート（`Mypage/notify_request_list.twig`）、入荷通知依頼・選手情報・商品情報を扱うリポジトリを正とする。

本機能のカスタマイズ区分はカスタマイズであり、画面・処理フローの挙動はpf-eccube3を参照リポとする。DB関連（テーブル名・列名・保存先）はec-cube-enterpriseを正とする。

対象はブラウザ経由のフロント（会員マイページ）に限定する。フロントのページは言語別パスセグメント`/{_locale}`を前提とし、本書のパスは`/{_locale}`配下の確認値として記載する。`/mypage`配下は会員ログインを要する。

本文ではフレームワークのコントローラ型名やメソッド名を主説明としない。ルートbind名の網羅は主説明とせず、「利用者視点の入口」にHTTPメソッドとサイトルートからのパスパターンを書く。

---

## 本書で扱うこと

- 入荷待ち商品一覧の入口・表示要素・一覧の集約条件
- 入荷通知の対象（在庫無し商品で入荷通知登録した商品）の抽出
- 一覧からの商品詳細・カード検索への遷移
- 未ログイン・0件時の扱い

---

## 本書で扱わないこと

以下は本書では仕様確定せず、実装または別機能の設計を正とする。

- 入荷通知の登録・解除の操作（商品詳細・カート機能を正とする）
- 入荷時の通知メール送信（入荷通知メール機能を正とする）
- 商品詳細・カード検索画面そのものの仕様（商品機能を正とする）
- 会員ログイン認証そのもの（会員ログイン機能を正とする）

## リニューアル移行時の扱い

DB関連の記述はec-cube-enterpriseを正とする。入荷通知依頼テーブル（`dtb_product_request`）は移行先（ec-cube-enterprise）にも存在し、`player_id`（選手情報）・`product_class_id`（商品規格）で会員の依頼を保持する。選手情報テーブル（`dtb_player`）の`customer_id`からログイン会員を特定する点も移行先と現行で同じである。

商品の状態（コンディション）・言語の保持先が現行と移行先で異なる。現行は補助テーブル`dtb_product_sub_class`に`product_id`・`product_class_id`・`card_condition_id`・`language_id`を保持して集約する。移行先（ec-cube-enterprise）では補助テーブルを持たず、商品規格テーブル（`dtb_product_class`）が`card_condition_id`・`language_id`を直接保持する。本書のDB記述は移行先の保持先（`dtb_product_class`の同名列）を主とし、現行の補助テーブル名（`dtb_product_sub_class`）を括弧で添える。価格は商品規格の`price02`で表示する。

移行先の入荷通知依頼は論理削除（`deleted_at`）を持つ。一覧表示は参照のみで業務データを更新しないため、移行に伴う保存処理の差分は生じない。

## 用語

| 用語 | 説明 |
|------|------|
| 会員 | フロントにログインしている顧客。 |
| 選手情報 | 会員に1対1で紐づく拡張情報。入荷通知依頼は選手情報に紐づく。 |
| 入荷通知依頼 | 在庫無し商品の再入荷時に通知を受けるための登録。 |
| 商品規格 | 商品の規格（コンディション・言語等の組）。一覧の集約キーに用いる。 |
| 言語 | 商品の言語区分。商品規格に含まれる。 |

## 利用者視点の入口

| 入口 | URLエンドポイント | 期待されるふるまい |
|------|--------------------|--------------------|
| マイページの「入荷待ち商品一覧」ブロック | `GET /{_locale}/mypage/notifylist` | 会員ログインを要し、会員が入荷通知登録した商品を集約して一覧表示する。 |
| 一覧の商品リンク | `GET /{_locale}/products/detail/{id}`（言語・規格を指定） | 当該商品の商品詳細へ遷移する（商品機能を正とする）。 |
| 一覧のカード検索リンク | `GET /{_locale}/products/search`（カードIDを指定） | 当該カードの検索結果へ遷移する（商品機能を正とする）。 |
| 「戻る」リンク | `GET /{_locale}/mypage` | マイページトップへ戻る。 |

`/mypage`配下は会員ログインを要する。一覧は当該会員の入荷通知依頼のみを対象とする。

## フロント挙動

| 観点 | 内容 |
|------|------|
| 表示要素 | 見出し「入荷待ち商品一覧」、入荷時に登録メールアドレスへ通知する旨の案内、入荷通知登録の上限拡張の案内、入荷通知登録した商品の一覧（商品名・言語・状態・価格、商品詳細リンク、カード検索リンク）、マイページへ戻るリンク。 |
| JS挙動 | 本機能ではJSによる非同期取得や動的な表示切替を主目的としない。 |
| CSS・レイアウト | 商品ごとに状態・価格などをまとめて表示する。 |
| モーダル・ポップアップ | 本画面専用のモーダルは無い。 |

入荷通知の登録上限が拡張された旨の案内を、一覧がある場合・無い場合のいずれでも表示する。

---

## 処理フロー

### 入荷待ち商品一覧を表示する（GET `/{_locale}/mypage/notifylist`）

1. 会員ログインを要求する。未ログインの場合は会員ログインへ誘導する（会員ログイン機能を正とする）。
2. ログイン会員を特定する。
3. 当該会員の選手情報に紐づく入荷通知依頼から、対象の商品規格・商品・状態・言語・価格を取得する。
4. 同一商品・言語・価格区分のまとまりで集約し、商品ごとに状態・価格の明細を束ねる。
5. 件数とともに一覧を表示する。0件の場合は入荷待ち商品が無い旨を表示する。

## 集計条件

| 指標 | 集計の要点 |
|------|------------|
| 一覧対象 | ログイン会員の選手情報に紐づく入荷通知依頼の商品規格。 |
| 結合 | 入荷通知依頼を商品規格・商品・商品クラス・状態・言語に結合し、選手情報で会員を絞り込む。 |
| 集約単位 | 商品・言語・価格区分（高額コードを含む）のまとまりで集約し、商品ごとに状態・価格の明細を束ねる。 |
| 件数 | 取得した依頼の件数を一覧の件数として表示する。 |

---

## 業務ルール・計算

| 項目 | 内容 |
|------|------|
| 抽出対象 | 在庫無し商品で入荷通知登録した商品（当該会員の入荷通知依頼）を対象とする。 |
| 集約 | 同一商品・言語・価格区分でまとめ、状態・価格の明細を商品ごとに束ねて表示する。 |
| 通知案内 | 対象商品が入荷した際に登録メールアドレスへ通知する旨を案内する。 |
| 登録上限 | 入荷通知登録の上限が拡張された旨を案内する（登録・解除の上限制御は商品詳細・カート機能を正とする）。 |
| 業務計算 | 価格は商品クラスの価格を表示する。集計の再計算は行わない。 |

本機能は一覧表示が主で、利用者入力のフォームを持たない。商品詳細・カード検索への遷移はリンクのパラメータで受け渡す。

### エッジケース

| ケース | 扱い |
|--------|------|
| 入荷通知依頼が0件 | 入荷待ち商品が無い旨を表示する。 |
| 同一商品で言語・価格区分が異なる | 集約キーが異なるため別のまとまりとして表示する。 |
| 高額コードを持つ商品規格 | 商品詳細リンクに規格を含めて遷移する。 |
| 未ログイン | 会員ログインへ誘導する。 |

## DBカラム

機能に直接関係する列のみ記載する。型や一覧の細部はスキーマを参照する。

| テーブル | 列 | メモ |
|---------|-----|------|
| `dtb_product_request` | `player_id` / `product_class_id` / `deleted_at` | 会員（選手情報）ごとの入荷通知依頼。一覧の抽出キー。移行先は`deleted_at`による論理削除を持つ。 |
| `dtb_player` | `customer_id` | ログイン会員から選手情報を特定する。 |
| `dtb_product_class`（現行は補助表 `dtb_product_sub_class`） | `card_condition_id` / `language_id` | 商品・状態・言語の集約に用いる。移行先では商品規格テーブルが状態・言語を直接保持する。 |
| `dtb_product_class` | `price02` | 価格の表示。 |

### DB操作

本機能は参照系（検索）であり、DBへの登録・更新・削除は行わない。テーブル名は ec-cube-enterprise を正典とする。

| 操作種別 | 対象テーブル | 契機・条件 |
|---------|--------------|------------|
| 検索 | dtb_player / dtb_product_class / dtb_product_request / dtb_product_sub_class | 検索条件に合致するレコードを抽出する。 |
