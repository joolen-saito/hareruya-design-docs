# F06-08（入荷待ち商品一覧）

## 業務ロジック

### 廃止された仕様

Excel基本設計 0306 入荷待ち商品一覧 識別ID:2 により廃止する。刷新後は実装しない。現行実装のふるまいは本書に残すが、刷新後の実装とテストの対象からは外す。

### 画面の構成

| 表示要素 | 内容 |
|------|------|
| 見出し | 入荷待ち商品一覧。一覧が0件のときも表示する |
| 案内 | 対象商品が入荷したときに、登録メールアドレスへ通知する旨を案内する |
| 案内 | 入荷通知登録の上限が拡張された旨を案内する。一覧があるときも0件のときも表示する |
| 一覧 | 入荷通知登録した商品の商品名・言語・状態・価格。登録があるときだけ表示する |
| 一覧の遷移 | 商品詳細リンクとカード検索リンク。遷移の値はリンクのパラメータで受け渡す |
| 画面下部 | マイページへ戻るリンク。一覧の件数によらず表示する |
| モーダル | 本画面専用のモーダルは無い。非同期取得と動的な表示切替は主目的としない |

### 一覧の取得

会員ログインを要求する。未ログインのときは会員ログインへ誘導する。判定は会員ログイン機能を正とする。

| 観点 | 内容 |
| --- | --- |
| 抽出対象 | ログイン会員の選手情報に紐づく入荷通知依頼。在庫無し商品で入荷通知登録した商品だけを対象とする |
| 取得する値 | 対象の商品規格・商品・状態・言語・価格 |
| 集約 | 同一商品・同一言語・同一価格区分でまとめ、商品ごとに状態・価格の明細を束ねる |
| 件数 | 件数とともに一覧を表示する |
| 0件のとき | 入荷待ち商品が無い旨を表示する |

価格は商品規格の価格だけをそのまま表示する。集計の再計算は、いずれの場合も行わない。

登録・解除の上限の制御は、商品詳細とカートの機能を正とする。

本機能は一覧表示が主であり、利用者が入力するフォームを持たない。入力項目が無いので、入力の検証も行わない。

### エラー時の扱い

| 事象 | 扱い |
|------------|------|
| 未ログインで開いたとき | 会員ログインへ誘導する。判定は会員ログイン機能を正とする |
| 入荷通知登録した商品が0件のとき | 入荷待ち商品が無い旨を表示する |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 会員のログイン状態だけを用いる。 |
| 成功時出力 | 入荷待ち商品一覧の表示。件数と商品ごとの明細を含む。 |
| 失敗時出力 | 未ログインのときは会員ログインへの誘導。 |

### 入出力: 永続化

いずれの場合もデータを更新しない。
