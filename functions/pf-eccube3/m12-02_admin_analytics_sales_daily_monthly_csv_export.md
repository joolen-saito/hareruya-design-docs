# 分析 — 日別/月別集計CSVダウンロード

## 業務ロジック

### 出力対象の確定

本機能は画面上の入力フォームを持たない。日別/月別集計 集計一覧で検索を実行したときに保持された検索条件だけを入力として出力する。保持された検索条件は集計一覧の画面を開き直すと破棄される。集計の内容は日別/月別集計 集計一覧（M12-01）と同一である。検索条件が保持されていない状態でダウンロードすると、集計期間が定まらないため集計結果は出力されない。ダウンロードの応答は集計より先に確定するため、この場合もエラー画面へは遷移しない。

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 保持された検索条件 |
| 成功時出力 | 集計結果のCSVファイル。ファイル名は `report_summary_` に出力日時（`YmdHis`）を付けた `.csv`。文字コード判別用のBOMを付与する |
