# コンテンツ管理 — ブロック管理

## 業務ロジック

### 一覧に並べるブロック

PC向けに登録されたブロックだけを一覧の対象とし、ブロックIDの降順で並べる。

### 編集画面のブロックデータ初期表示

既存ブロックの編集画面では、そのブロックのテンプレートファイルの内容をブロックデータ欄に初期表示する。指定されたブロックが存在しないときは、見つからない扱い（HTTP 404）とする。

### ファイル名の一意性

同じ端末種別にすでに同じファイル名のブロックがあるときは登録・更新できず、ファイル名欄にエラーを表示する。編集では自分自身を除いて重複を判定するため、ファイル名を変えないまま保存できる。

### ファイル名の編集可否

ファイル名を編集できるかは、ブロックの削除可否だけで決まる。削除できるブロックではファイル名の入力欄を表示する。削除できないブロックではファイル名を表示するだけで入力欄を出さず、編集できない。ファイル名の文字列を `/user_data` と照合する判定は行わない。

### ファイル名変更時の旧ファイル

ファイル名を変更して更新したときは、変更前のファイル名で保存されていた同じ言語のテンプレートファイルが残っていれば、そのファイルを削除する。

### 削除できないブロックへの削除要求

削除できないブロックに対して削除要求が届いても、ブロック情報は削除せず、削除完了のメッセージも出さずに一覧画面へ戻る。

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 一覧・登録・編集画面の表示要求。登録・編集の保存はフォームの入力内容、削除は対象ブロックの指定 |
| 成功時出力 | 登録・編集は編集画面へ戻る。削除は一覧画面へ戻る |
| 失敗時出力 | 対象のブロックが存在しないとき、編集は見つからない扱い（HTTP 404）、削除は一覧画面へ戻る |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 登録・更新 | ブロックの新規登録・編集の保存 |
| 削除 | 削除できるブロックの削除 |
