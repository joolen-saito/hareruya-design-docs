# M13-08（デッキ表示）

## 業務ロジック

### 表示の対象

イベント申込一覧で最後に指定された申込の検索条件に該当するイベントの登録デッキを対象とする。本画面では検索条件を入力させない。検索条件が保持されていないときは空の条件として扱い、登録デッキの取得結果に従う。並び順は指定があればその値、無ければ既定の並びとする。表示は印刷向けのデッキリストとして新しい画面で開く。

### プレイヤー名の決め方

デッキに登録されたプレイヤー名から前後の空白を除いて用いる。プレイヤー名が空のときは、会員のカナ姓とカナ名を半角空白で連結して表示する。

### カードリストの組み立て

デッキのメイン・サイドの符号化された文字列を、カード名と枚数の並びに復号する。メインとサイドそれぞれの枚数を合計し、各見出しに表示する。金額計算・税計算・丸めは行わず、枚数の合計だけを行う。

### ページの分割

メインのカード一覧を1ページ40枚で分割し、デッキ単位でページを構成する。サイドボードは先頭ページにだけ載せ、2ページ目以降のサイドは空とする。ページごとにプレイヤー名・DCIナンバー・日程・メインカード・メイン枚数・サイド枚数を並べる。

### Excel基本設計により廃止された仕様

- Excel基本設計 0214 識別ID:5 により廃止。刷新後は実装しない。現行実装のふるまいは本書に残すが、刷新後の実装・テストの対象外とする
- Excel基本設計 0214 識別ID:9-11 により廃止。刷新後は実装しない。現行実装のふるまいは本書に残すが、刷新後の実装・テストの対象外とする

### エラー時の扱い

| 事象 | 扱い |
| --- | --- |
| 申込の検索条件が保持されていない | 空の条件として扱い、登録デッキの取得結果に従う |
| データの読み取り障害 | 共通の例外処理に委ねる。本画面固有の利用者向けメッセージは設けない |

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | 利用者が入力する項目は無い。対象は申込一覧で最後に指定された検索条件から決まる |
| 成功時出力 | 印刷向けのデッキリストの表示 |
| 失敗時出力 | 本画面固有のエラー画面は持たない |

### 入出力: 永続化

本機能はデータを更新しない。

## 表示メッセージ

この機能はメッセージを表示しない。画面はデッキ情報と印刷の導線だけで、操作結果を知らせる文言を出さない。
