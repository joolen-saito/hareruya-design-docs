# フロント アクセス解析 — 会員IDの連携

## 業務ロジック

### 連携の仕組み

| 担い手 | 範囲 |
| --- | --- |
| 当機能 | 会員IDを、ページ内の受け渡し領域（`dataLayer`）へ積むところまでを担う |
| タグの管理サービス（Googleタグマネージャ） | 受け渡し領域を読み、アクセス解析（Googleアナリティクス）へ送る。送る内容はタグの管理サービス側の設定だけで決まる |
| 受け渡し領域がまだ無いとき | 空の領域を用意してから積む |
| 受け渡し領域がすでにあるとき | 既存の内容を残し、末尾へ足す |

### 会員IDを積む条件

| 順序 | 判定 | 結果 |
| --- | --- | --- |
| 1 | 会員としてログインしているとき | 会員IDを1件積む |
| 2 | ログインしていないとき | 何も積まない。受け渡し領域の用意も行わない |

### 積む値

| 項目名 | 値 |
| --- | --- |
| `uid` | ログインしている会員の会員ID。数値のまま積む。積むのはこの1項目だけで、氏名・メールアドレスなどは積まない |

### 積む位置と対象ページ

当機能は、ページの先頭部（head）へ置くブロック「GoogleAnalytics用会員ID連携スクリプト」として提供する。ページごとのレイアウト設定で、このブロックを先頭部へ置いているページだけが会員IDを積む。

| 観点 | 扱い |
| --- | --- |
| 導入時の配置 | 導入時点で存在したPC向けの全ページについて、先頭部の1番目へ置く |
| 導入時に先頭部の1番目に他のブロックがあるとき | そのブロックを2番目へ下げる。下げる対象はPC向けのページに限らず、先頭部の1番目にあるブロックすべてである |
| 導入後にページを追加したとき | 自動では置かれない。ページごとに先頭部へ置く設定をした場合だけ積む |
| 本人確認の3ページ | オンライン本人確認の入力・撮影・完了の各ページに限り、ページの追加と同時に先頭部の1番目へ置く |
| ブロックを削除しようとしたとき | 管理画面から削除できないブロックとして登録してあるため、削除できない |

### エッジケース

| ケース | 扱い |
| --- | --- |
| レイアウト設定で先頭部からブロックを外したページを開いたとき | ログインしている場合でも会員IDを積まない |
| 同じページの他の箇所が先に受け渡し領域へ値を積んでいるとき | 既存の値を残し、会員IDを末尾へ足す |
| 仮会員・退会済みの会員のとき | ログインできないため、会員IDを積まない |
| 英語サイトのとき | 日本語サイトと同じ条件・同じ値で積む |

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | ログイン中の会員の情報 |
| 出力 | ページの先頭部に埋め込むスクリプト。会員としてログインしているときだけ出力し、ログインしていない場合は何も出力しない |

### 入出力: 永続化

会員・受注などの業務データを登録・更新・削除しない。

| 操作 | 契機 |
| --- | --- |
| ブロックの登録 | 機能の導入時に、ブロックの一覧へ1件登録する |
| ブロックの配置 | 機能の導入時、および本人確認の3ページの追加時に、ページのレイアウト設定へ配置を登録する |

## 表示メッセージ

本機能は画面へ文言を表示しない。
