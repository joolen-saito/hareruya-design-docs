# カード管理 — カード検索（一覧・条件抽出）

## 業務ロジック

### 初期表示

保持している検索条件・ページ番号・表示件数を破棄し、空の検索フォームで表示する。一覧は表示しない。

### 検索条件

| 画面上の項目 | 検索条件 |
|--------------|----------|
| カード名・テキスト | 入力値を半角空白・全角空白・カンマで語に分割し、語ごとに部分一致で絞り込む。語どうしはAND |
| カードタイプ・サブタイプ・特殊タイプ・カードセット・レアリティ・レイアウト・イラストレーター・プロモ種別・使用可能フォーマット | 選んだ値のいずれかに一致 |

異なる項目どうしはANDとする。値が空・未選択の項目は検索条件に加えない。

### 並び順と表示件数

| 項目 | 決め方 |
|------|--------|
| ソートキー | 要求の指定があればそれを用い、無いときは保持している値、それも無いときは既定のソートキーとする |
| ソートキーの選択肢 | カードの識別子、マナ・コスト、カード名（和文）、カード名（英文）の4つ |
| 並び順 | 要求の指定があればそれを用い、無いときは保持している値、それも無いときは既定の並び順とする |
| 表示件数 | 保持している値があればそれを用い、無いときは設定の既定値とする。要求された値が表示件数の選択肢と一致するときだけ採用して保持する |

並び順の指定が昇順・降順のいずれでもないときは、エラーを表示して初期表示へ戻す。

### 検索の成立条件

検索条件を受け取れないときは、保持している検索条件から復元する。保持している検索条件も欠けるときは初期表示に戻す。

件数を数え直した結果、最終行の削除などで現在ページが空になるときは、ページ番号を1つ減らして取得する。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| 並び順の指定が昇順・降順のいずれでもない | 並び順が不正である旨のエラーを表示し、初期表示と同じ状態の一覧へ戻す |
| 該当が0件 | 該当なしの見出しを表示する |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 検索条件、ページ番号、表示件数、ソートキーと並び順 |
| 成功時出力 | 検索結果の一覧。該当が0件のときは該当なしの見出し |
| 失敗時出力 | 並び順が不正なときはエラーを表示し、初期状態の一覧を表示する |

画面へ渡すのは、検索フォーム、検索結果の一覧、表示件数の選択肢、ソートキーの一覧、現在のページ番号と並び順である。

本機能は参照だけを行い、検索した内容をデータとして登録・更新しない。検索条件は画面をまたいで保持する。
