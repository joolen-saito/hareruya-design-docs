# フロント デッキ検索 — デッキリスト詳細

## 業務ロジック

### 表示できるデッキの条件

| 条件 | 結果 |
| --- | --- |
| デッキの識別子が空のとき | HTTP 404 |
| 識別子に一致するデッキが無いとき | HTTP 404 |
| 表示区分が非公開のとき | HTTP 404 |
| デッキ種別がユーザーデッキのとき | HTTP 404 |
| 表示区分が限定公開のとき | 詳細を表示する。限定公開用の値の一致は求めない |
| デッキリストが非公開のとき | 詳細の情報欄だけを表示し、カードリストは空とする |

### カードリストの分類

採用カードを次の順序で判定し、最初に一致した分類へ入れる。分類ごとの枚数は、その分類に入ったカードの採用枚数の合計とする。

| 順序 | 判定 | 分類 |
| --- | --- | --- |
| 1 | 配置がサイドボード | サイドボード |
| 2 | 配置が統率者 | 統率者 |
| 3 | カードが土地 | 土地 |
| 4 | カードがクリーチャー | クリーチャー |
| 5 | カードの識別子を持つ | 呪文 |
| 6 | 上のいずれにも当たらない | Unknown |

メインボードの枚数は、統率者・呪文・クリーチャー・土地・Unknownの枚数を合計した値とする。統率者は枚数が0のとき区画ごと表示せず、Unknownは枚数が1以上のときだけ区画を表示する。

### カード画像

分類ごとに、その分類のカードの識別子を集めて表側の画像を1枚ずつ選ぶ。選ぶ優先順は、特殊セットでないもの、プロモーションでないもの、カードセットの発売日が新しいもの、Foilでないもの、表示中の言語に一致するもの、カード詳細の識別子が小さいものとする。

### 情報欄に載せる内容

| 表示項目 | 表示項目（英語） | 値 |
| --- | --- | --- |
| デッキ名 | Deck name | デッキ名 |
| 大会名 | Tournament | 大会の日本語名。大会名を条件にしたデッキ検索結果への入口を兼ねる |
| フォーマット | Format | フォーマットの日本語名。フォーマットが未設定のときは空 |
| アーキタイプ | Archetype | アーキタイプの日本語名。アーキタイプを条件にしたデッキ検索結果への入口を兼ねる |
| プレイヤー | Player | プレイヤー名。プレイヤー名を条件にしたデッキ検索結果への入口を兼ねる |
| タグ | Tag | デッキタグの名称を`, `で連ねる。各タグを条件にしたデッキ検索結果への入口を兼ねる |
| 成績 | Score | 勝数と敗数がそろうときは`勝-敗`。引分が0でないときは`-引分`を、勝敗の表記の有無と関わりなく成績の文字列の前に置く |
| 開催日 | Date | 大会の開催日を`Y/m/d`の形式で表す |
| 引用元URL | Source URL | 引用元のURL |

### デッキリストの書き出し

デッキリストが公開のときだけ書き出しの入口を出す。

| 入口 | 条件 | 引き渡す値 |
| --- | --- | --- |
| Magic Online用テキスト | デッキリストが公開のとき | デッキID |
| アリーナ用インポートテキスト | デッキリストが公開で、フォーマットがアリーナ対応のとき | デッキIDと言語`en` |
| 日本語テキスト | デッキリストが公開で、フォーマットがアリーナ対応のとき | デッキIDと言語`jp`。取得先の経路は表示言語を英語にする |

書き出しの内容はデッキリスト書き出し（F09-07）を正とする。

### 画面から引き継ぐ検索条件

| 起点 | 遷移先 | 引き継ぐ条件 |
| --- | --- | --- |
| 同じ大会のデッキを見る | デッキ検索結果 | 大会名＝大会の英語名と、開催日 |
| 同じアーキタイプのデッキを見る | デッキ検索結果 | アーキタイプID |
| このデッキを一括購入する | デッキ一括購入 | デッキID |
| 戻る | デッキ検索TOP | 引き継がない |

同じ大会のデッキを見るが引き渡す開催日は、検索条件として解釈されない。開催日時の絞り込みに使う条件名と一致しないため、大会名だけで絞り込んだ結果になる。

### 旧URLからの引き継ぎ

旧デッキIDを伴う入口は、次の順序で遷移先を決める。

| 順序 | 判定 | 結果 |
| --- | --- | --- |
| 1 | 旧デッキIDに一致するデッキがある | そのデッキの詳細へHTTP 301で転送する |
| 2 | 現デッキIDに一致するデッキがある | そのデッキの詳細へHTTP 301で転送する |
| 3 | どちらにも一致しないとき | デッキ検索TOPへHTTP 302で転送する |

旧デッキIDは英数字だけを受け付ける。転送先の判定では表示区分もデッキ種別も見ないため、転送先で404になることがある。

### エッジケース

| ケース | 扱い |
| --- | --- |
| 統率者の枚数が0のとき | 統率者の区画を出さない |
| Unknownの枚数が0のとき | Unknownの区画を出さない |
| デッキタグが0件のとき | タグの欄を空にする |
| 引用元URLが未設定のとき | 引用元URLの欄を空にする |
| 勝数と敗数のいずれかが未設定のとき | 勝敗の表記を出さない。引分が0でなければ`-引分`は出す |
| 引分が0のとき | 引分の表記を出さない |
| カードの画像を選べなかったとき | 画像なし用の画像を出し、商品への入口を付けない |
| 同じカードの組で別の言語のキャッシュがあるとき | キャッシュの鍵はカードの識別子だけなので、言語を判定し直さずキャッシュの内容を使う |
| デッキリストが非公開のとき | カードリストの枚数はすべて0になる |

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | デッキの識別子。旧URLからの入口では旧デッキID |
| 成功時出力 | カードリストと情報欄を載せた詳細画面 |
| 失敗時出力 | 表示できる条件を満たさないときはHTTP 404。旧URLで該当が無いときはデッキ検索TOPへの転送 |

### 入出力: 永続化

デッキ情報を登録・更新・削除しない。

| 操作 | 契機 |
| --- | --- |
| キャッシュへの保存 | カード画像の選択結果をカード識別子の組ごとに保存する。保持時間は600秒 |
