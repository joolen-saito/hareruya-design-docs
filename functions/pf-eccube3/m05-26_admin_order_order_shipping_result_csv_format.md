# 受注管理 — 出荷実績登録CSVフォーマット

## 業務ロジック

### 項目の構成

出荷実績入力用CSV出力と出荷実績インポート登録は、同じ 63 項目だけを使う。注文番号で始まり、お届け時間の名称で終わる。出力したファイルに出荷日と送り状No.を書き込んだときは、そのまま取り込める。

お届け希望日は項目一式に含まれない。実装では定義が無効にしてあるため、取り込み画面の項目一覧にも出ない。

取り込み画面には、この 63 項目を定義した順に見出しとして表示する。

### 必須と任意

必須の項目は注文番号だけである。注文番号で受注を特定するため、値が空のときはその行でエラーになる。

それ以外の 62 項目は任意で、ヘッダ行に無いときも取り込める。

### ヘッダ行の扱い

| 条件 | 扱い |
| --- | --- |
| 想定の 63 項目に無い項目名があるとき | 取り込まない |
| 必須の注文番号がヘッダ行に無いとき | 取り込まない |
| 想定の項目だけで並び順が違うとき | 並び順は問わず取り込む |
| データ行が 1 行も無いとき | 取り込まない |

### 受け付けるファイル形式

カンマ区切りとタブ区切りの両方を受け付ける。拡張子が `tsv` のときはタブ区切りとして読み、それ以外のときは設定の区切り文字で読む。
