# バッチ 会員管理 — ポイント差分発生通知

## 業務ロジック

### 対象と補正

保有ポイントとポイント履歴の合計に差分がある会員を対象とする。会員ごとに保有ポイントを履歴合計へ合わせ、補正をまとめて確定する。差分が無いときは補正も通知も行わずに完了する。

### 通知

補正した会員について、会員ID・履歴合計・補正前の保有ポイント・差分を一覧にし、管理者へ通知する。差分が無いときは通知しない。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| コマンド名が未指定・不一致 | 処理を行わずに終了する |
| 差分なし | 補正・通知を行わず完了する |
| 取得・送信時のエラー | エラーメッセージをコンソールに出力する |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | コマンド名 |
| 成功時出力 | 保有ポイントの補正と、差分一覧の管理者への通知 |
| 失敗時出力 | エラーメッセージのコンソール出力 |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 更新 | 差分がある会員の保有ポイントを履歴合計へ合わせる補正 |

## 表示メッセージ

本バッチは画面メッセージを扱わない。
