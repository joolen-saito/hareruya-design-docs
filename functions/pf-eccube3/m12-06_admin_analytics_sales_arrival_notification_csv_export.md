# 分析 — 入荷通知依頼CSVダウンロード

## 業務ロジック

### 出力する対象

保持した検索条件を取り込み、確定した条件で入荷通知依頼を抽出する。抽出は入荷通知依頼の一覧（M12-05）と同じとする。保持した検索条件が無いときは空の条件として扱い、その条件で抽出して出力する。抽出のときは論理削除の除外を無効にする。

本機能は画面上の入力欄を持たない。出力する検索条件は保持した検索条件の値による。

### 出力する列

列は商品コード・商品名・言語・状態・販売金額・在庫数・会員名・依頼日・購入日・通知日/通知設定削除日の順とする。抽出結果が0件のときもヘッダ行だけを出力する。

### 値の取り方

抽出した依頼を1件ずつ、列の順で出力する。依頼日は年/月/日 時:分の形式とする。通知日/通知設定削除日は論理削除の日時を年/月/日 時:分の形式で出力し、未設定のときは空とする。件数が多いときも、抽出結果を1件ずつたどりながら出力する。

### エラー時の扱い

| 事象 | 扱い |
| --- | --- |
| 保持した検索条件が無いとき | 空の検索条件で抽出し、出力する |
| データ読み取りに障害があったとき | 共通の例外処理に委ねる |
| 権限が足りないとき | 出力しない |

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | 保持した検索条件。無いときは空の条件として扱う |
| 成功時出力 | 入荷通知依頼の出力ファイル。ファイル名は request_report_ に出力日時（年月日時分秒）を付けた .csv とする。文字コード判別用のBOMを付ける |
| 失敗時出力 | データ取得に失敗したときは共通の例外処理に委ねる |

### 入出力: 永続化

本機能はデータを更新しない。
