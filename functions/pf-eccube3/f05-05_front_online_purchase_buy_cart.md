# F05-05（ネット買取カート）

## 業務ロジック

### カートの表示

買取希望品カートは、保持している買取カートの商品と税込小計を表示する。買取カートが無いときは商品なし・合計なしで表示する。

合計は買取価格に数量を掛けた総和を税込小計とし、対象データが無い商品は合計から除く。

数量の入力欄は商品の規格ごとに持つ。再計算で合計を更新する。

### カートへの追加

追加では規格と数量を受け取り、数量の指定が無いときは 1 とする。規格の指定が空のときはエラー応答とする。

同じ規格が既に買取カートにあるときは数量を加算する。加算後の数量が同一商品の上限である 20 点を超えるときは、上限超過として扱い数量を保存しない。上限以内のときだけ規格ごとの数量を保持する。

### 数量の更新と削除

更新では入力された数量の一覧で各商品の数量を書き換える。数量が数字でないとき、または 1 未満のときは当該商品を買取カートから外す。いずれかの数量が 20 点を超えるときは更新を中断する。

削除はなりすまし対策トークンを検証したうえで行う。買取カートに当該商品が無いときは何もせずカート表示へ戻る。

### まとめて買取の扱い

「まとめて買取」が買取カートに含まれるときは、カート用の画面制御を読み込まず、案内に従う扱いとする。買取カートに 1 件以上の商品があり、かつ「まとめて買取」が含まれないときだけカート用の画面制御を読み込む。

### エラー時の扱い

| エラー内容 | 処理 |
| --- | --- |
| 規格の指定が空のまま追加した | エラー応答（HTTP500 相当）を返す |
| 追加で数量が 20 点を超える | 上限超過を示す応答（HTTP400、状態 `overlimit`）を返し、数量を保存しない |
| 更新で数量が 20 点を超える | 上限超過を要求エラーとして積み、更新を中断する |
| 削除対象が買取カートに無い | 何もせずカート表示へ戻る |

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | 追加は規格と数量、削除は規格、更新は数量の一覧 |
| 成功時出力 | 買取希望品カートの表示、または追加成功を示す応答 |
| 失敗時出力 | 追加の上限超過は HTTP400、規格の指定が空のときは HTTP500 相当 |

### 入出力: 永続化

買取カートの内容は買取手続きの完了まで保持するだけで、この機能では受注や商品のデータを更新しない。
