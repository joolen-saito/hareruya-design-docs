# カード管理 — 新規登録・編集・削除（詳細フォーム）

## 業務ロジック

### フォームの初期表示

新規のフォームは、データを持たない状態で開く。編集のフォームは、指定されたカードIDのカードで開く。

| 状態 | 初期表示 |
| --- | --- |
| 新規のとき | 削除できないカード詳細は無い（空とする） |
| 編集で当該カードがあるとき | 商品規格と結びついているカード詳細のIDの一覧を、削除できないカード詳細として画面へ渡す |
| 編集でカードIDが空のとき、または該当カードが無いとき | 見つからない扱い（HTTP404）とする |

### 入力項目の制約

| 項目 | 必須／任意 | 制約 |
| --- | --- | --- |
| カードID（新規） | — | 登録時に採番する |
| カードID（編集） | — | 画面が保持するIDで既存のカードを識別する |
| 点数で見たマナコスト | 必須 | 半角数字と任意の小数点以下だけを許す。整数または小数の形式に一致すること |
| 忠誠度 | 任意 | 最大長の制限に収まること |
| 忠誠度の形式 | 任意 | パワー・タフネスに似た記号表現の形式に一致すること |
| 旧商品ID（日） | 任意 | 英数字・ハイフン・アンダースコアだけを許す |
| 旧商品ID（英） | 任意 | 英数字・ハイフン・アンダースコアだけを許す |
| リーガリティのフォーマット | 必須 | リーガリティのブロックごとに指定すること |
| リーガリティの制限区分 | 必須 | リーガリティのブロックごとに指定すること。空の選択肢を持たない |
| リーガリティの重複 | — | 同一フォーマットを重複して選んだときは画面上で拒む |
| 画像の言語 | 必須 | 画像の行ごとに指定すること |
| 画像の表面・裏面 | 必須 | 画像の行ごとに指定すること |
| 画像のファイル | — | 最大 5MB とする |
| 画像の形式 | — | JPEG・GIF・PNG だけを許す |

### 保存の判定順序

| 順序 | 判定・処理 | 内容 |
|------|------|------|
| 1 | 入力内容の検証 | 必須・長さ・形式・ファイルの種類とサイズを検証する。外れたときは保存せず、同一画面にエラーを表示する |
| 2 | 対象カードの特定 | パスにIDが無いときは新規のカードを用意する。IDがあり該当カードが無いときはアクセス拒否（HTTP403）とする |
| 3 | 画像行の整理 | ファイルが無く、かつ既存のURLも空の画像行は送信データから除く。画像が1件も残らないカード詳細は、画像の指定ごと除く |
| 4 | 画像の配置 | ファイルがあるときは一時領域へ保存したうえでオブジェクトストレージへ配置し、返却されたパスを当該画像行のURLへ書き込む |
| 5 | 反映対象の限定 | 画面に無い関連（商品規格、買取メインカード、デッキ、デッキ明細、メイビーカード、アーキタイプ、商品サブ）は反映の対象から除く |
| 6 | 子の整理 | 画面のコレクションに現れない子のIDは、保存時に当該の子と孫ごと削除する |

保存できたときは、当該カードの編集画面へ戻る。

### 支店連携への通知

| 契機 | 渡すもの |
| --- | --- |
| 保存できたとき | 当該カードIDの配列 |
| すべての指定IDで削除できたとき | 今回のIDの一覧 |
| 削除できないカードがあり、それまでに削除できたIDがあるとき | 削除できたIDの一覧 |

通知が失敗したときも、画面の表示は保存成功・削除成功のままとする。

### 削除の判定順序

| 順序 | 判定・処理 | 内容 |
|------|------|------|
| 1 | 対象の特定 | 単体削除の対象はパスで指定した1件だけとする。IDが空のとき、または該当カードが無いときは見つからない扱い（HTTP404）とする |
| 2 | 削除の可否 | 当該カードにデッキ明細が1件以上あるとき、または当該カードのカード詳細を経由する未削除の商品が1件以上あるときは削除しない |
| 3 | 結びつきの解除 | 削除するときは、当該カード配下のカード詳細に紐づく商品サブの規格行について、カード詳細の指定を一括で未設定にする |
| 4 | 削除 | 親のカードとその子を再帰的に削除する |

一括削除は別の機能とする。

削除しないときは、カードの表示名を差し込んだエラーメッセージを表示する。

すべての指定IDで削除できたときは、完了メッセージを表示する。

削除後の戻り先は次のとおりとする。

| 状態 | 戻り先 |
| --- | --- |
| 削除しなかったとき | 直前の画面 |
| 直前のカード検索のページ番号があるとき | 当該ページのカード検索結果 |
| 直前のカード検索のページ番号が無いとき | カード一覧 |

### エラー時の扱い

| 事象 | 扱い |
|------------|------|
| 入力内容の検証に外れたとき | 保存せず、同一画面に項目ごとのエラーを表示する |
| 保存で対象カードが存在しないとき | アクセス拒否（HTTP403）とする |
| 編集の表示で対象カードが存在しないとき | 見つからない扱い（HTTP404）とする |
| 削除で対象カードが存在しないとき | 見つからない扱い（HTTP404）とする |
| デッキまたは商品に登録されていて削除できないとき | カードの表示名を差し込んだエラーメッセージを表示し、直前の画面へ戻る |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | カードの詳細フォーム（ファイル添付を含む）。削除のときはカードID。 |
| 成功時出力 | 保存のときは編集画面への遷移（302）と完了メッセージ。削除のときは検索結果またはカード一覧への遷移（302）と完了メッセージ。 |
| 失敗時出力 | 検証に外れたときはフォームの再表示。対象が無いときはアクセス拒否（HTTP403）または見つからない扱い（HTTP404）。削除できないときはエラーメッセージと直前の画面への戻り。 |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 追加 | カードを新規登録したとき。カード詳細と画像も同時に追加する |
| 更新 | カードを編集して保存したとき。削除の直前に、商品サブの規格行のカード詳細の指定を未設定にするときも更新する |
| 削除 | カードを削除したとき。子と孫を再帰的に削除する。保存時に画面のコレクションから消えた子も削除する |
