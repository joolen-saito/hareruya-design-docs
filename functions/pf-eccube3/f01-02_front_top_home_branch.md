# F01-02（支店トップページ表示）

## 概要

支店トップページ表示は、店舗ページのパスへ店舗識別名を付けて開いた利用者へ、当該支店（実店舗）の店舗紹介ページを表示する機能である。店舗識別名から店舗を特定し、表示言語に対応する店舗ページ要素を取得して、店舗ヘッダ画像・店舗一覧（左カラム）・右カラムの店舗案内／初心者講習会／取り扱い商品／買取／スタッフ／その他／アクセスを、登録された要素の有無に応じて並べる。店舗が見つからない場合、または当該言語のページ要素が無い場合は見つからない（HTTP404）として扱う。

本書は実装手順ではなく、誰が・いつ・どの条件で・結果どうなるかを読むためのリバース詳細設計とする。本機能のカスタマイズ区分はカスタマイズである。画面・処理フロー・JS等の挙動はpf-eccube3（EC-CUBE3系）のHareruyaEcプラグインの店舗ページ処理、テンプレート（`ShopPage/index.twig`・`default_frame.twig`）を正とし、DB関連（テーブル名・列名・保存先）はリニューアル先のec-cube-enterpriseを正とする。

対象はブラウザ経由のフロント支店TOP（店舗紹介ページ）に限定する。

本文ではフレームワークのコントローラ型名やメソッド名を主説明としない。ルートbind名の網羅は主説明とせず、「利用者視点の入口」にHTTPメソッドとサイトルートからのパスパターンを書く。フロントのページであり管理画面プレフィックスは付かない。フロントのルートはロケール接頭辞`/{_locale}`の下に置かれる。

---

## 本書で扱うこと

- 支店TOP（店舗紹介ページ）の入口と、店舗の特定方法
- 店舗ページ要素の取得と、右カラム項目の表示順・表示有無の判定
- 表示言語（ja／en）による店舗ページ要素の出し分け
- 店舗・ページ要素が見つからない場合の扱い
- 本店TOPと支店TOPの境界

## 本書で扱わないこと

以下は本書では仕様確定せず、実装または別機能の設計を正とする。

- 本店トップページ表示（F01-01を正とする）
- 支店PC版・スマホ版ナビゲーションの詳細（F02-03・F02-04を正とする）

- イベントトップの店舗切替・店舗選択ボタン（イベント機能を正とする）
- 店舗一覧ページ（店舗一覧の利用者データページを正とする）

## リニューアル移行時の扱い

本機能のカスタマイズ区分はカスタマイズである。店舗の特定・404判定・右カラムの表示順等の挙動はpf-eccube3（HareruyaEcプラグイン）の実装を正とし、DB関連（テーブル名・列名・保存先）はリニューアル先のec-cube-enterpriseを正とする。現行と移行先の主な差は次のとおり。移行先名を主とし、現行名を括弧で添える。

| 観点 | 現行（pf-eccube3） | 移行先（ec-cube-enterprise） |
|------|--------------------|------------------------------|
| 店舗マスタ | `mtb_shop`（HareruyaEcプラグインの独自テーブル） | `dtb_base_info`（複数ショップを行として保持。BaseInfoへ統合） |
| 店舗ID | `mtb_shop.id` | `dtb_base_info.id` |
| 店舗識別名（HTMLクラス名） | `mtb_shop.html_class_name` | `dtb_base_info.html_class_name`（コメント「支店URL」） |
| 店舗名（日・英） | `mtb_shop.name_jp`／`name_en` | `dtb_base_info.shop_name`／`shop_name_eng` |
| 短縮店舗名（日・英） | `mtb_shop.short_name_jp`／`short_name_en` | `dtb_base_info.short_name_jp`／`short_name_en`（同名） |
| 全店舗一覧の並び順 | `mtb_shop.rank`（並び順列） | `dtb_base_info`に`rank`／`sort_no`列が見当たらず、並び順キーはec-cube-enterprise実装で要確認 |
| 店舗ページ要素 | `dtb_shop_page_element`（PKは`shop_page_element_id`、店舗参照は`shop_id`） | `dtb_shop_page_element`（同一テーブル名。PKは`id`、店舗参照は`base_info_id`） |
| 言語コード・要素名・値 | `language_code`（jaはjp、それ以外en）・`element`・`value` | 同名`language_code`（length 2）・`element`・`value` |

挙動の説明でDB列に触れるときは移行先（ec-cube-enterprise）の列名を主とする。

## 用語

| 用語 | 説明 |
|------|------|
| 支店 | 実店舗。店舗マスタの1行に対応する。 |
| 店舗識別名 | 店舗ページのパスに用いる店舗の識別文字列。店舗マスタのHTMLクラス名に対応する。 |
| 店舗ページ要素 | 店舗ごと・言語ごとに登録される、店舗ヘッダ画像や各セクション本文・画像・リンクの集合。要素名と値の対で保持する。 |
| 右カラム項目 | 店舗案内・初心者講習会・取り扱い商品・買取・スタッフ・その他・アクセスの各セクション。 |
| 表示言語 | 表示ロケール。jaのとき店舗ページ要素の言語コードはjp、それ以外はenを用いる。 |

## 利用者視点の入口

| 入口 | URLエンドポイント | 期待されるふるまい |
|------|--------------------|--------------------|
| 店舗紹介ページを開く | `GET /{_locale}/shoppage/{name}` | 店舗識別名から店舗を特定し、表示言語に対応する店舗ページを描画する。 |
| 店舗一覧（左カラム・SP）内のリンク | `GET /{_locale}/shoppage/{name}` | 選択した店舗の店舗紹介ページへ遷移する。 |
| 店舗未存在・当該言語のページ要素なし | `GET /{_locale}/shoppage/{name}` | 見つからない（HTTP404）として扱う。 |

店舗識別名は英数字とアンダースコアからなる。ロケール接頭辞はjaまたはenをとる。

---

## フロント挙動

| 観点 | 内容 |
|------|------|
| 表示要素 | 店舗ヘッダ画像（PC用・タブレット用）、大会情報リンク、店舗一覧（左カラム・SP用）、ポイント確認バナー、Twitterタイムライン、右カラムのナビゲーションと各セクション（店舗案内・初心者講習会・取り扱い商品・買取・スタッフ・その他・アクセス）。表示中の店舗は店舗一覧で選択状態を付与する。 |
| JS挙動 | 店舗ページ用スクリプトを読み込む。ポイント確認バナー押下でポイント確認用モーダルを開く。 |
| CSS・レイアウト | 店舗ページ用スタイルシートを読み込む。本文クラスを店舗ページ用に設定する。PC用とタブレット用で店舗一覧・バナーの表示を切り替える。 |
| モーダル・ポップアップ | ポイント確認用モーダル（外部の確認ページを枠内に表示）を持つ。閉じると元の店舗ページに戻る。 |
| 入力項目 | 支店TOPは入力フォームを持たない。 |

右カラムのナビゲーションは、登録済みの右カラム項目だけをリンクとして並べ、定義された出力順の末尾要素へは末尾用のクラスを付与する。

---

## 処理フロー

### 支店TOPを表示する（GET `/{_locale}/shoppage/{name}`）

1. 店舗識別名から店舗を特定する。見つからない場合は見つからない（HTTP404）として扱う。
2. 当該店舗・表示言語（jaはjp、それ以外はen）の店舗ページ要素を取得する。要素が無い場合は見つからない（HTTP404）として扱う。
3. 取得した店舗ページ要素を要素名をキーとした連想配列へ整理する。
4. 右カラム項目について、定義された出力順に沿って、値を持つ項目だけを表示対象として抽出し、出力順上の末尾要素を求める。
5. 並び順付きの全店舗一覧を取得する。
6. 店舗ページのテンプレートを描画する。

---

## 業務ルール・計算

| 項目 | 内容 |
|------|------|
| 店舗の特定 | パスの店舗識別名（店舗マスタのHTMLクラス名）で店舗を特定する。 |
| 表示言語の対応 | 表示ロケールがjaのとき店舗ページ要素の言語コードはjp、それ以外はenを用いる。 |
| 右カラムの表示有無 | 右カラム項目は、対応する店舗ページ要素に値があるものだけを表示する。値が無いセクションは描画しない。 |
| 右カラムの表示順 | 店舗案内・初心者講習会・取り扱い商品・買取・スタッフ・その他・アクセスの定義順で表示する。出力順上の末尾要素へ末尾用のクラスを付与する。 |
| 店舗一覧 | 並び順付きの全店舗一覧を左カラム・SP用に表示し、表示中の店舗を選択状態にする。 |
| 本店と支店の境界 | 支店TOPは店舗ページのパス配下であり、サイトルート直下の本店TOP（F01-01）とは別画面である。 |

支店TOPは入力フォームを持たないため、入力項目に紐づく表を持たない。本機能では金額計算・税計算・丸めを行わない。

### エッジケース

| ケース | 扱い |
|--------|------|
| 店舗識別名に該当する店舗が無い | 見つからない（HTTP404）として扱う。 |
| 当該言語の店舗ページ要素が無い | 見つからない（HTTP404）として扱う。 |
| 右カラム項目の値が空 | 当該セクションを描画しない。ナビゲーションにも当該項目を出さない。 |
| 店舗ヘッダ画像・大会情報リンク等が未登録 | 当該要素を描画しない。ページ全体の表示は継続する。 |

## データ整合性

| 観点 | 内容 |
|------|------|
| 参照時点 | 店舗・店舗ページ要素・全店舗一覧は画面表示時点で取得・描画する。 |
| 店舗一覧との整合 | 左カラム・SP用の店舗一覧は並び順付きの全店舗を表示する。表示中の店舗の選択状態は、特定した店舗と一致する。 |
| 言語別 | 同一店舗でも言語ごとに別の店舗ページ要素を参照する。一方の言語にしか要素が無い場合、他方の言語では見つからない（HTTP404）になり得る。 |

## DBカラム

機能に直接関係する列のみ記載する。型や一覧の細部はスキーマを参照する。

| テーブル | 列 | メモ |
|---------|-----|------|
| `dtb_base_info`（現行 `mtb_shop`） | 店舗ID（`id`） | 店舗ページ要素の取得・店舗一覧の選択状態判定に用いる。 |
| `dtb_base_info`（現行 `mtb_shop`） | HTMLクラス名（`html_class_name`、コメント「支店URL」） | パスの店舗識別名に対応。店舗の特定に用いる。 |
| `dtb_base_info`（現行 `mtb_shop`） | 店舗名・短縮店舗名（`shop_name`／`shop_name_eng`／`short_name_jp`／`short_name_en`） | 店舗一覧・店舗切替の表示に用いる。現行は`name_jp`／`name_en`。 |
| `dtb_base_info`（現行 `mtb_shop`） | 並び順 | 全店舗一覧の表示順に用いる。移行先に`rank`／`sort_no`列が見当たらず、並び順キーはec-cube-enterprise実装で要確認。現行は`mtb_shop.rank`。 |
| `dtb_shop_page_element` | 店舗ID（`base_info_id`、現行`shop_id`）・言語コード（`language_code`） | 当該店舗・言語の店舗ページ要素の抽出条件。 |
| `dtb_shop_page_element` | 要素名（`element`）・値（`value`） | 各セクションの本文・画像・リンク等。値の有無で表示を判定する。PKは`id`（現行`shop_page_element_id`）。 |

### DB操作

本機能は参照系（検索）であり、DBへの登録・更新・削除は行わない。テーブル名は ec-cube-enterprise を正典とする。

| 操作種別 | 対象テーブル | 契機・条件 |
|---------|--------------|------------|
| 検索 | dtb_base_info / dtb_shop_page_element / mtb_shop | 検索条件に合致するレコードを抽出する。 |
