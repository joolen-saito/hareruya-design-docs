# F01-02（支店トップページ表示）

## 業務ロジック

### タイルに載せる商品の抽出条件

タイルに載せる商品規格は、次をすべて満たすものに限る。

| # | 条件 |
|---|------|
| 1 | 商品の公開ステータスが「公開」であること |
| 2 | 表示している支店の在庫が1以上であること |
| 3 | 商品規格が表示対象であること |
| 4 | カードの状態がNMのものは販売価格が1円以上、NM以外の状態のものは販売価格が100円以上であること |
| 5 | 高額商品コードが設定されていないこと |
| 6 | 同一商品では、条件2・4を満たすもののうち、言語とカードの状態が最も上位の1件だけを残すこと |
| 7 | 同一商品・同一言語に、状態NMかつ販売価格1円以上の商品規格が、表示している支店の在庫として登録されていること（在庫数は問わない） |

並び順は表示のたびに無作為とし、1区画あたり最大3件を表示する。タイル属性がピックアップ商品のタイルだけはタイルタグではなく、表示している支店の在庫にピックアップの指定がある商品規格を対象とする。

### 区画に割り当てが無いときの表示

タイルの割り当てが無い区画は、空のままにせずタイル属性がフォーマット別特集のタイルを補って表示する。補うタイルの対象タグは表示のたびに変わる。

### タイルの商品表示

価格は「￥{販売価格}～」の形式で、桁区切りを入れて表示する。商品画像が登録されていない商品規格には代替画像を表示する。

### お取り寄せサービス・高額買取バナーの表示位置

お取り寄せサービスと高額買取のバナーは、タイル群より後ろに表示する。PCではタイル群の最後の区画として並べ、スマートフォン・タブレットではタイル群の後ろへ差し込む。

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 画面固有の入力は無い（支店サイトのルートURLを開く） |
| 成功時出力 | 共通レイアウト枠へ差し込んだ支店トップページの画面 |

本機能はデータを更新しない。
