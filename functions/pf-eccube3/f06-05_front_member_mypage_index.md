# F06-05（マイページ）

## 概要

マイページは、ログイン済み会員がフロントの各会員機能（購入履歴、入荷待ち商品、お気に入り、ポイント、買取履歴、本人確認、イベント・大会、会員情報変更、配送先、退会、問い合わせ等）へ移動するための入口画面である。会員の保有ポイントと期限の近いポイントを表示し、各機能へのリンク（ブロック）を一覧する。直前に商品検索からの戻り先がセッションにある場合は、マイページを表示せずその検索画面へ戻す。

本書は実装手順ではなく、誰が・いつ・どの条件で・結果どうなるかを読むためのリバース詳細設計とする。確認値はpf-eccube3（EC-CUBE3系）のHareruyaEcプラグインのマイページ処理、マイページテンプレート（`Mypage/index.twig`）、保有ポイント取得処理、選手情報・ポイント履歴を扱うリポジトリを正とする。

本機能のカスタマイズ区分はカスタマイズであり、画面・処理フローの挙動はpf-eccube3を参照リポとする。DB関連（テーブル名・列名・保存先）はec-cube-enterpriseを正とする。

対象はブラウザ経由のフロント（会員マイページ）に限定する。フロントのページは言語別パスセグメント`/{_locale}`を前提とし、本書のパスは`/{_locale}`配下の確認値として記載する。`/mypage`配下は会員ログインを要する。

本文ではフレームワークのコントローラ型名やメソッド名を主説明としない。ルートbind名の網羅は主説明とせず、「利用者視点の入口」にHTTPメソッドとサイトルートからのパスパターンを書く。

## 本書で扱うこと

- マイページトップの入口・表示要素・各機能ブロックへの遷移
- 保有ポイント・期限の近いポイントの表示
- 商品検索からの戻り先がある場合のリダイレクト
- 未ログイン時の扱い

---

## 本書で扱わないこと

以下は本書では仕様確定せず、実装または別機能の設計を正とする。

- 各遷移先機能（購入履歴・入荷待ち商品一覧・お気に入り・ポイント履歴・買取履歴・本人確認・イベント・会員情報変更・配送先・退会・問い合わせ等）の仕様（それぞれの機能を正とする）
- 会員ログイン認証そのもの（会員ログイン機能を正とする）
- ポイント計算・付与・失効のロジック（ポイント機能を正とする）

---

## リニューアル移行時の扱い

DB関連の記述はec-cube-enterpriseを正とする。保有ポイントは選手情報テーブル（`dtb_player`）の`point`列、期限の近いポイントの算出はポイント履歴テーブル（`dtb_point_history`）を参照する。これらのテーブル名・列名は現行（pf-eccube3）と移行先（ec-cube-enterprise）で同一スキーマであり、同名で扱う。マイページは参照のみで業務データを更新しないため、移行に伴う保存先の差分は生じない。

## 用語

| 用語 | 説明 |
|------|------|
| 会員 | フロントにログインしている顧客。 |
| 選手情報 | 会員に1対1で紐づく拡張情報。マイページのポイント表示に用いる。 |

## 利用者視点の入口

| 入口 | URLエンドポイント | 期待されるふるまい |
|------|--------------------|--------------------|
| マイページトップ | `GET /{_locale}/mypage` | 会員ログインを要し、保有ポイントと各機能ブロックを表示する。商品検索の戻り先がある場合はそこへリダイレクトする。 |
| 各機能ブロックのリンク | 各機能のURL（購入履歴・入荷待ち商品一覧・お気に入り・ポイント履歴等） | 押下した機能の画面へ遷移する。各遷移先は対応する機能を正とする。 |
| ヘッダー用保有ポイント | `GET /{_locale}/mypage/point_in_header` | ヘッダー表示用の保有ポイントを返す。 |

`/mypage`配下は会員ログインを要する。マイページは会員機能のハブであり、各ブロックは個別機能の入口である。

## フロント挙動

| 観点 | 内容 |
|------|------|
| 表示要素 | 見出し「マイページ」、現在のポイント、期限の近いポイント、ポイント履歴リンク、および各機能ブロック（購入履歴、入荷待ち商品一覧、お気に入り登録商品一覧、購入手続きへ、ポイント履歴、ネット買取履歴、オンライン本人確認、予約済み大会一覧、チーム情報変更、大会デッキ登録、マイデッキ、会員情報変更、配送先の新規登録・変更、退会、お問い合わせ、お問い合わせ履歴、ログアウト）。 |
| JS挙動 | 本機能ではJSによる非同期取得や動的な表示切替を主目的としない。ヘッダーの保有ポイントは別エンドポイントで取得する。 |
| CSS・レイアウト | 各機能ブロックはアイコン画像とタイトルで構成する。利用者の挙動理解に影響する分岐表示はない。 |
| モーダル・ポップアップ | 本画面専用のモーダルは無い。 |

ブロックは大きな見出し（過去の購入・入荷待ち商品の確認、晴れる屋ポイントの確認、ネット買取申込みの確認・本人確認、イベント・大会の予約確認・デッキ登録、会員情報の変更、その他）でグループ化する。

## 処理フロー

### マイページトップを表示する（GET `/{_locale}/mypage`）

1. 会員ログインを要求する。未ログインの場合は会員ログインへ誘導する（会員ログイン機能を正とする）。
2. セッションに商品検索の戻り先がある場合は、戻り先を取得・消去してそこへリダイレクトし、マイページは表示しない。
3. ログイン会員の選手情報を取得する。
4. 期限の近いポイント履歴を取得する。
5. 保有ポイント・期限の近いポイントと各機能ブロックを表示する。

### ヘッダー用保有ポイントを返す（GET `/{_locale}/mypage/point_in_header`）

1. ログイン会員の選手情報を取得する。
2. ヘッダー表示用に保有ポイントを返す。

## 業務ルール・計算

| 項目 | 内容 |
|------|------|
| 表示対象 | マイページは常にログイン中の会員自身の情報・機能ブロックを表示する。 |
| 商品検索の戻り先 | セッションに商品検索の戻り先がある場合、マイページを表示せずその検索画面へ戻す。 |
| 保有ポイント | 会員の選手情報からポイントを表示する。 |
| 期限の近いポイント | 次に失効期限を迎えるポイント履歴から失効間近のポイントを求めて表示する。 |
| 業務計算 | ポイントの計算・付与・失効ロジックはポイント機能を正とし、本機能では表示のみを行う。 |

本機能は利用者入力のフォームを持たないため入力項目は無い。

### エッジケース

| ケース | 扱い |
|--------|------|
| 商品検索からの戻り先がある | マイページを表示せず戻り先へリダイレクトし、戻り先を消去する。 |
| 期限の近いポイントが無い | 期限の近いポイント欄は対象なしとして表示する。 |
| 未ログイン | マイページを表示せず会員ログインへ誘導する。 |

## DBカラム

機能に直接関係する列のみ記載する。型や一覧の細部はスキーマを参照する。

| テーブル | 列 | メモ |
|---------|-----|------|
| `dtb_player` | `customer_id` / `point` | ログイン会員に紐づく選手情報。`point`が保有ポイントの表示値。 |
| `dtb_point_history` | `customer_id` / `point_change` / `issue_date` | 期限の近いポイントの算出に用いる。詳細はポイント機能を正とする。 |

### DB操作

本機能は参照系（検索）であり、DBへの登録・更新・削除は行わない。テーブル名は ec-cube-enterprise を正典とする。

| 操作種別 | 対象テーブル | 契機・条件 |
|---------|--------------|------------|
| 検索 | dtb_player / dtb_point_history | 検索条件に合致するレコードを抽出する。 |

## 画面遷移

| 条件 | 遷移先 |
|------|--------|
| マイページトップへアクセス（戻り先なし） | マイページ（`GET /{_locale}/mypage`） |
| 商品検索の戻り先がある | 戻り先の商品検索画面（リダイレクト） |
| 購入履歴ブロック | 購入履歴一覧（`/{_locale}/mypage/shopping_history`） |
| 入荷待ち商品一覧ブロック | 入荷待ち商品一覧（`/{_locale}/mypage/notifylist`） |
| お気に入り登録商品一覧ブロック | お気に入り一覧（`/{_locale}/mypage/favorite/list`） |
| ポイント履歴ブロック | ポイント履歴（`/{_locale}/mypage/point_history`） |
| 各機能ブロック | 各機能の画面（会員情報変更・配送先・退会・買取履歴・本人確認・イベント・問い合わせ等） |
| ログアウト | トップ（ログアウト経由） |

### 遷移時に引き継ぐ状態

| 起点 | 遷移前の処理 | 遷移後の初期状態 |
|------|--------------|------------------|
| 商品検索から会員機能へ遷移していた場合 | セッションの商品検索の戻り先を取得・消去する | マイページを表示せず直前の商品検索画面を再表示する |
