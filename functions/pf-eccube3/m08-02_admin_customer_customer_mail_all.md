# 会員管理 — メール一括送信

## 業務ロジック

### 確認画面

配信対象者の会員名は、姓と名を空白 1 個でつないだ値で表示する。

引き継いだ会員IDのうち、一致する会員が無いIDは配信対象者に出ない。そのため引き継いだIDの件数と配信対象者の行数は一致しないときがある。

確認画面から入力画面へ戻ったときは、入力したタイトルと本文のまま再表示する。

### 送信

会員 1 人につき 1 通だけ送信する。タイトルと本文は全員に同じ値を使い、会員ごとに差し込む値は無い。テンプレートは使わず、入力した本文をそのまま送る。

引き継いだ会員IDの順に 1 件ずつ送信する。同じ会員IDを重ねて引き継いだときは、その回数だけ送信する。重複は取り除かない。

一致する会員が無いIDが含まれるときは、そのIDに達するまでに処理した会員へ送信したあと、処理が中断する。中断したときは、残りのIDへ送信しない。先に送信した分は取り消せない。

会員を 1 件も選ばずに要求したときは、1 通も送信せずに中断する。

### 完了画面

配信完了の案内だけを表示する。送信できた件数も失敗した件数も、宛先の一覧も出さない。

### 検索結果へ戻る導線

セッションに保持した会員検索のページ番号へ戻る。保持していないときは 1 ページ目へ戻る。入力画面と完了画面のどちらの導線も同じ扱いとする。

## 入出力

### 出力: メール

| 項目 | 内容 |
| --- | --- |
| 宛先 | 会員のメールアドレス |
| 差出人 | 基本情報のメールアドレス1。表示名は基本情報の店名 |
| BCC | 基本情報のメールアドレス1 |
| 返信先 | 基本情報のメールアドレス3 |
| 送信エラーの戻り先 | 基本情報のメールアドレス4 |
| 件名 | 入力したタイトル |
| 本文 | 入力した本文。ヘッダ・フッタの付加も差し込みもしない |

メールの文字コード設定が iso-2022-jp のときは、本文を iso-2022-jp へ変換し、転送方式を 7bit にする。設定していないときは変換も転送方式の指定もしない。

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 送信履歴の登録 | 1 通送信するたび。件名・本文・送信日時・宛先の会員を記録する |

送信履歴にはテンプレートも作成者も記録しない。宛先に届かなかったときも送信履歴を登録し、送信の成否は履歴に持たない。記録する本文は文字コードを変換したあとの値とし、変換しない設定のときは入力したままの値になる。会員そのものは更新しない。
