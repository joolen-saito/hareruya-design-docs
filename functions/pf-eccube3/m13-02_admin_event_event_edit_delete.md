# イベント管理 — イベント編集/削除

## 業務ロジック

### 編集画面の表示

登録済みイベントの編集画面は、当該イベントの日程を開始日時の降順で並べ、日程ごとの申込人数を集計して表示する。申込が1件も無い日程は0件として表示する。

支払方法の選択肢は、イベント申込で利用できる支払方法に絞り、ランク昇順で並べる。

### 更新の判定順序

| 順序 | 判定 | 結果 |
|------|------|------|
| 1 | パスの識別子のイベントが存在するか | 存在しなければアクセス拒否とする |
| 2 | 入力の検証 | 失敗なら登録失敗のエラーを表示し、編集画面を再表示する |
| 3 | 保存 | 成功なら完了メッセージを表示し、当該イベントの編集画面へ戻す |

新規登録は、検証に成功した場合にイベントを登録し、登録したイベントの編集画面へ遷移する。

### イベント削除の判定順序

| 順序 | 判定 | 結果 |
|------|------|------|
| 1 | パスの識別子のイベントが存在するか | 存在しなければアクセス拒否とする |
| 2 | なりすまし対策トークン | 不正なら共通のアクセス拒否として扱う |
| 3 | 削除 | 完了メッセージを表示し、検索結果ページへ戻す。ページ番号は保持した検索ページ番号、無ければ1ページ目とする |

### 日程一括削除の判定順序

| 順序 | 判定 | 結果 |
|------|------|------|
| 1 | 削除対象の日程識別子が空でないか | 空なら該当なしとして扱う |
| 2 | 当該イベントに該当する日程が存在するか | 無ければ該当なしとして扱う |
| 3 | なりすまし対策トークン | 不正なら共通のアクセス拒否として扱う |
| 4 | 削除 | 日程削除の完了メッセージを表示し、編集画面へ戻す |

判定は選択された日程を1件ずつ順に見て、削除できない日程に当たった時点で中止する。中止したときは、同じ要求で選択した他の日程も削除しない。

### 登録者と入力値の扱い

新規登録・更新の保存前に、ログイン中の管理者を登録者として設定する。参加費・定員は入力値をそのまま整数として保存し、金額計算・税計算・丸めは行わない。定員の入力欄は1を、参加費の入力欄は0を下限とする。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| 更新対象が削除済み | アクセス拒否とする |
| 削除対象が存在しない | アクセス拒否とする |
| 日程一括削除で対象識別子が空・該当無し | 該当なしとして扱う |
| 入力の検証失敗 | 登録失敗のエラーを表示し、編集画面を再表示する |
| なりすまし対策トークン不正 | 共通のアクセス拒否として扱う |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 編集画面・新規登録画面の表示要求、イベント登録・更新の送信（なりすまし対策トークンを含む）、イベント削除の送信、日程一括削除の送信 |
| 成功時出力 | 更新・登録は編集画面への遷移と成功メッセージ。イベント削除は検索結果ページへの遷移と成功メッセージ。日程一括削除は編集画面への遷移と成功メッセージ |
| 失敗時出力 | 検証失敗は該当のエラーメッセージと編集画面の再表示。処理を中止したエラーは該当のエラーメッセージと直前画面への復帰。存在しない識別子はアクセス拒否または該当なし |
