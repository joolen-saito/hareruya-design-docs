# 受注管理 — 出荷指示：納品書印刷（英語）

## 業務ロジック

### 印刷対象

指定した出荷指示リストが存在しないときは、納品書を作らず未検出として応答する。受注を 1 件も選択していないときも画面は開くが、納品書は 1 件も出ない。

出荷指示リストに含まれない受注を選択したときも、その受注の納品書を出す。選択した受注が出荷指示リストに属するかどうかは確かめない。

海外向けかどうかは配送方法に設定した海外区分だけで決まり、受注や配送先の国では変わらない。配送方法に海外区分の設定が無い受注は、日本語・英語のどちらの納品書にも出ない。

会員情報・プレイヤー情報・配送先のいずれかを持たない受注、および注文者の都道府県が未設定の受注は、納品書に出ない。選択したにもかかわらず納品書が作られず、警告も出ない。配送先の都道府県または国が未設定でも、その受注は納品書に出る。国が未設定のときは、国の欄が空になる。

商品・商品規格・商品サブ情報・商品規格サブ情報のいずれかを持たない明細は、納品書の明細行に出ない。

### 納品書の組み立て

お届け先の欄には配送先の情報を、送り主の欄には注文者の情報を出す。

郵便番号は、上 3 桁と下 4 桁がどちらも登録されているときだけ `-` でつなぐ。どちらかが欠けているときは、登録されている郵便番号をそのまま使う。電話番号は 3 つの電話番号値を区切り文字なしで連結する。氏名は名・姓の順に空白 1 個を挟んで出し、敬称は付けない。

見出しと項目名だけを英語で出し、氏名・住所・商品名などの値は登録されているとおりに出す。英語に訳した値は持たない。

会社の名称・郵便番号・住所・電話番号・URL・メールアドレスは英語表記で納品書に固定で持ち、受注の内容では変わらない。英語の納品書には、消費税額も適格請求書発行事業者の登録番号も出さない。

### 金額の表示

| 欄 | 出す値 |
| --- | --- |
| お買い上げ額 | 受注の小計 |
| 送料 | 受注の送料 |
| 手数料 | 受注の手数料 |
| ポイント使用 | 受注の値引き額。ポイント数として計算した値ではないが、値の後ろに `Points` と添えて出す |
| 発送方法 | 配送方法の名称 |
| 請求金額 | 受注の合計。内税額は併記しない |

明細行の合計は、価格に数量を掛けた金額とする。金額は 3 桁ごとに区切って出す。ポイント使用の欄だけは桁を区切らず、値引きが 0 のときも 0 と出す。

商品情報には受注したときの商品名を出す。受注のあとに商品名を変えたときも、納品書に出る商品名は変わらない。

### ページの繰り返し

ページが変わるたびに、見出し・ページ数・注文番号・お届け先・送り主・会社・金額の欄を出し直す。

## 入出力

### 出力: 納品書

選択した受注の納品書を英語のレイアウトで表示する。受注を複数選んだときは、受注ごとに納品書を続けて出す。

## 表示メッセージ

本機能は画面メッセージを持たない。
