# デッキ管理 — デッキ CSV 出力

## 業務ロジック

### 出力対象の決め方

| 選択の状態 | 扱い |
| --- | --- |
| デッキIDを1件も選択せずに実行したとき | 出力せず、必須のエラーを表示して直前の画面へ戻す。ダウンロードは始めない。画面側でも未選択の送信を既定で止める |
| 該当するデッキが1件も無いとき | 出力せず、未登録のエラーを表示して直前の画面へ戻す。ダウンロードは始めない |
| 指定したIDの一部だけが存在しないとき | 該当が1件以上あれば処理を続ける。該当しないIDは出力に現れない |

並び順は、利用者が一覧で選択したときの表示順と一致するとは限らない。

一覧の一括編集フォームの他の項目もあわせて送信されるが、この出力では読まない。

### 出力の構成

見出し行に論理キーを出力し、続けてデータ行を出力する。デッキ1件につき1行とする。

| 順序 | 出力 |
| --- | --- |
| 1 | UTF-8のBOM。文字コードの設定がどの値のときも先頭に出力する |
| 2 | 論理キーの見出し行。1行だけ出力する |
| 3 | データ行。該当するデッキが複数あるときは、件数分を出力する |

区切り文字は設定に従う。本文の文字コードは設定によらずUTF-8とし、先頭のBOMと合わせる。
応答が示す文字集合は設定から決まるため（「応答とファイル名」）、設定がUTF-8以外のときは
応答の表記と本文の文字コードが一致しない。

### 列の値の作り方

| 列 | 値の作り方 |
| --- | --- |
| フォーマット | 紐づくフォーマットがあるときはその英語名、無いときは空文字とする |
| アーキタイプ | 紐づくアーキタイプがあるときはその日本語名、無いときは空文字とする |
| 統率者名 | 統率者ボードに紐づくカードがあるときはその英語名、無いときは空文字とする |
| 代表カード名 | 代表カード画像に紐づくカードがあるときはその英語名、無いときは空文字とする |
| メインリスト・サイドリスト | 登録されているデッキリストのテキストをそのまま出力する |
| イベント開催日 | 日時が無いときは空文字、あるときは `Y-m-d H:i:s` の書式とする |
| 表示フラグ | 公開のときは 1、非公開のときは 0 を出力する。限定公開には対応する値が無く、空欄になる |

### 応答とファイル名

接頭辞 `deck_`、出力時点の日時（`YmdHis`）、拡張子 `.csv` を連結した名前とし、添付ファイルとして返す。

文字コードの設定が SJIS-win のときは、応答の文字集合の表記だけを windows-31j に読み替える。

| 応答ヘッダ | 値 |
| --- | --- |
| 内容の種別 | 設定の文字コードに基づく `text/csv;charset=…` とする |
| 内容の配置 | 添付ファイルとし、ファイル名を付ける |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 一覧で選択したデッキIDの配列。 |
| 成功時出力 | CSVファイル。ファイル名は接頭辞と日時から作る。 |
| 失敗時出力 | エラーメッセージと直前の画面への戻り。ダウンロードは始まらない。 |

## 表示メッセージ

出力に成功したときは画面にメッセージを出さず、ファイルの応答だけを返す。未選択のときと、選択したデッキが
1件も見つからないときのエラー文言は、デッキ検索・一覧（M15-01）の表示メッセージ一覧に含める。
