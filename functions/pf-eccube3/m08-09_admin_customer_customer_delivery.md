# 会員管理 — 配送先一覧表示/編集

## 業務ロジック

### 配送先一覧

会員IDに該当する会員が無いときは、ページが見つからない扱い（404）とする。

一覧は会員に紐づく配送先を1件ずつ枠で並べ、配送先ごとに配送先名称・郵便番号・配送先都道府県・住所・配送先氏名・配送先氏名カナ・電話番号・配送先会社名を表示する。配送先都道府県が海外のとき、および配送先都道府県が登録されていないときは、郵便番号と配送先都道府県の代わりに配送先海外用郵便番号と国名を表示する。配送先名称が登録されていない配送先は「名称未設定」と表示する。

既定の配送先として印が付いた配送先には編集・削除の操作を出さない。それ以外の配送先にだけ編集と削除の操作を出す。

### 配送先の編集

配送先IDが無い、または該当する配送先が無いときは、ページが見つからない扱い（404）とする。

入力チェックに通ったときだけ保存し、成功メッセージを表示したうえで同じ配送先の編集画面を再表示する（配送先一覧へは戻らない）。入力チェックに失敗したときは保存せず、入力した内容とエラー内容を付けて編集画面を再表示する。

郵便番号から自動入力ボタンを押すと、入力済みの郵便番号に対応する配送先都道府県と配送先住所1を自動で埋める。

### 配送先の削除

削除の操作は、対象の配送先名称を含む確認を出し、了承したときだけ実行する。

配送先を削除すると、その配送先に付けた配送先名称も併せて削除する。削除後は同じ会員の配送先一覧を表示する。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| 会員IDに該当する会員が無い | ページが見つからない扱い（404）とする |
| 配送先IDが無い・該当なし | ページが見つからない扱い（404）とする |
| 入力チェックの失敗 | 保存せず編集画面を再表示する |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 会員ID、配送先ID、なりすまし対策トークン |
| 成功時出力 | 配送先の保存・削除、成功メッセージ |
| 失敗時出力 | 会員・配送先が無いときは404、入力チェック失敗時は編集画面の再表示 |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 削除 | 配送先を削除したとき。その配送先に付けた配送先名称も併せて削除する |
