# 会員 — お問い合わせ送信

## 業務ロジック

### 画面の構成

| 区分 | 内容 |
|------|------|
| 見出し・案内 | 見出し「お問い合わせ」と、下記フォームへの記入を促す案内を表示する |
| 入力欄: 件名 | 選択に応じて他の欄の表示を切り替える |
| 入力欄: お問い合わせ詳細 | 件名が店舗・イベント関連のときに表示する |
| 入力欄: 付帯情報 | 件名ごとに表示有無とラベルが決まる |
| 入力欄: 店舗 | 件名ごとに表示有無とラベルが決まる |
| 入力欄: 氏名 | 姓と名に分ける |
| 入力欄: 電話番号 | ページの言語で欄の数が変わる |
| 入力欄: メールアドレス | 未ログインのときの会員特定にも用いる |
| 入力欄: 内容 | 複数行入力とする |
| 必須表示 | 必須項目には必須マークを表示する |
| 操作 | 入力画面は「確認画面へ」ボタンと「戻る」リンク。確認画面は入力内容と「送信をする」「戻る」を表示する |
| カナ欄 | 画面上は非表示のまま保持する |
| 電話番号欄 | 日本語ページのときは3分割の欄、海外言語ページのときは1欄（数値） |
| 内容・アンケート欄 | 複数行入力とする |
| モーダル | 本画面専用のモーダルは無い。イベントキャンセルで必須欄が未入力のときはブラウザのアラートで警告する |
| レイアウト | お問い合わせ用のレイアウトを用いる |

### 初期表示

| 条件 | 初期値 |
| --- | --- |
| クエリでイベント詳細を指定し、対象のイベント詳細が表示中のとき | 件名・お問い合わせ詳細・イベント名・開催日・開始時間・実施店舗に初期値を設定する |
| ログイン会員のとき | 氏名・カナ・郵便番号・都道府県・住所・メール・電話番号を初期表示する |
| 海外言語ページのとき | 日本語用の電話番号欄を除いてフォームを組み立てる |

### 件名による表示切替

件名ごとに、付帯情報欄と店舗欄の表示有無とラベルが決まる。店舗・イベント関連の件名のときはお問い合わせ詳細を表示する。

### イベントキャンセルの内容転記

お問い合わせ詳細がイベントキャンセルのときだけ、次の欄を表示する。

| 欄 | 送信時の扱い |
| --- | --- |
| イベント名 | 必須の入力を確認し、内容欄へ転記する |
| 実施店舗 | 必須の入力を確認し、内容欄へ転記する |
| 開催日 | 必須の入力を確認し、内容欄へ転記する |
| 開始時間 | 必須の入力を確認し、内容欄へ転記する |
| キャンセル理由 | 必須の入力を確認し、内容欄へ転記する |
| その他理由 | 内容欄へ転記する |
| アンケート | 内容欄へ転記する。複数行入力とする |

イベントキャンセル以外のときは、イベント関連の欄を消す。

### 送信の判定順序

| 順序 | 判定・処理 | 内容 |
| --- | --- | --- |
| 1 | 入力内容の検証 | 妥当でないときは送信せず、入力画面を再表示する |
| 2 | 会員の特定 | ログイン会員のときはその会員とする。未ログインのときは入力メールアドレスから最も適合する会員を特定する。特定できないときは会員の紐づけを行わない |
| 3 | メール送信 | お問い合わせメールを送信する |
| 4 | 保存 | 件名・お問い合わせ詳細区分・付帯情報・氏名・電話番号・メール・店舗・内容を保存し、特定できた会員を紐づける |
| 5 | 遷移 | お問い合わせ完了画面へ遷移する |

確認画面は、入力内容の検証を通ったときだけ表示する。妥当でないときは入力画面を再表示する。

### エラー時の扱い

| 事象 | 扱い |
|------------|------|
| 入力の検証に外れたとき | 各項目直下にエラーを表示し、入力画面を再表示する |
| イベントキャンセルで必須欄が未入力のとき | 送信を止め、アラートで警告する |

件名・氏名・メール・内容など各項目の必須・形式のエラーは、各項目の直下に表示する。本機能はフラッシュ・トーストを生成しない。

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 件名・お問い合わせ詳細・付帯情報・店舗・氏名・電話番号・メール・内容などの入力値。確認と送信の区別。クエリのイベント詳細ID。 |
| 成功時出力 | お問い合わせメールの送信、お問い合わせ内容の保存、お問い合わせ完了画面への遷移。 |
| 失敗時出力 | 検証に外れたときは入力画面の再表示。 |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 追加 | お問い合わせを送信したとき。特定できた会員を紐づける |
