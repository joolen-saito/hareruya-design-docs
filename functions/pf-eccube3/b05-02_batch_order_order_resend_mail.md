# バッチ 受注管理 — 購入完了手続き再処理

## 業務ロジック

### 実行できる条件

同名のバッチが実行中のときは、未完了である旨を出力して終了する。開始時に排他の取得を試み、取得できないときは異常として終了する。二重に実行しない。

### 対象の受注

メールが未送信の受注を取得する。対象が無いときは何もせずに完了する。

### 受注1件ごとの処理

| 順序 | 判定 | 結果 |
| --- | --- | --- |
| 1 | 受注サブに消費ポイントがあり、かつポイント履歴が無いとき | ポイント処理を行う |
| 2 | 受注サブに消費ポイントがあり、かつポイント履歴があるとき | ポイント処理を重ねて行わない |
| 3 | 消費ポイントがあるとき | スマレジのポイント連携を別プロセスで実行する |
| 4 | ポイントの処理を終えたとき | 8桁の受注番号を取得し、在庫履歴と販売数を更新して確定する |
| 5 | 更新を確定したとき | 注文完了メールを再送信する |
| 6 | 処理中に例外が発生したとき | 当該受注の更新を巻き戻し、エラーメッセージを出力して次の受注へ進む |

受注ごとに処理をまとめて確定し、1件の失敗を他の受注へ波及させない。

### 再送するメールの言語

会員の都道府県が海外のときは英語、それ以外のときは日本語で再送する。

### エラー時の扱い

| 事象 | 扱い |
| --- | --- |
| 同名のバッチが実行中のとき | 未完了である旨を出力して終了する |
| 排他を取得できないとき | 異常として終了する |
| 受注の処理で例外が発生したとき | 当該受注を巻き戻し、エラーメッセージを出力して次の受注へ進む |

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | コマンド名 |
| 成功時出力 | ポイント処理、在庫の更新、注文完了メールの再送信。対象が無いときは何もせず完了する |
| 失敗時出力 | 受注ごとのエラーメッセージの出力（当該受注は巻き戻す） |

### 出力: メール

| 宛先 | 契機 |
| --- | --- |
| 受注の注文者 | 受注1件の更新を確定したときに、注文完了メールを再送信する |

### 出力: 外部連携

消費ポイントがあるときは、スマレジのポイント連携を別プロセスのコマンドで実行する。

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 追加 | 消費ポイントがあり、履歴が無いときのポイント処理 |
| 更新 | 受注1件ごとの在庫履歴と販売数 |
| 更新 | 8桁の受注番号の設定 |

## 表示メッセージ

本バッチは画面の文言を持たない。出力するのは未完了である旨と、受注ごとのエラーメッセージである。
