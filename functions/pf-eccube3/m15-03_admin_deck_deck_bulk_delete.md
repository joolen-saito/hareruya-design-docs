# デッキ管理 — 一括削除

## 業務ロジック

### 削除の判定順序

| 順序 | 判定 | 結果 |
| --- | --- | --- |
| 1 | なりすまし対策トークンが有効か | 無効のときはアクセス拒否（HTTP 403）とする |
| 2 | 削除対象のデッキが送られているか | 送られていないときはメッセージを出さず、デッキ検索・一覧へ戻して終える |
| 3 | 各デッキを取り出せるか | 取り出せないときは 404 として打ち切る。後続のデッキは処理しない |
| 4 | 当該デッキを使う記事が 1 件でもあるか | あるときは削除せず、エラーを表示して元の画面へ戻して終える |
| 5 | いずれの記事にも使われていないとき | デッキに含まれるカードを削除し、更新者をログイン中の管理者にしてから、デッキを削除する |

送られたデッキは配列の先頭から順に処理する。すべてのデッキを打ち切りなく処理できたときだけ、削除完了のメッセージを出す。

同じ識別子が重複して送られたときは、先に削除したデッキを後の要素で再びたどるため、手順 3 で 404 となることがある。

### 記事に使われているかの判定

デッキに紐づく記事の件数を見る。件数が 0 より大きいときは削除しない。

打ち切りより前に削除できたデッキは、その時点で削除済みとなる。

### 戻り先

保持していた一覧のページ番号があるときはデッキ検索・一覧の当該ページへ、無いときはデッキ一覧の先頭へ戻す。

数量の計算と料金の計算はこの機能では行わない。

### エラー時の扱い

| エラー内容 | 処理 |
| --- | --- |
| なりすまし対策トークンが不一致 | アクセス拒否（HTTP 403）とする |
| 対象のデッキが無い | 404 として打ち切る |
| 記事で使われているデッキが含まれる | 当該デッキを削除せず、エラーを表示して元の画面へ戻す |

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | 削除対象のデッキの配列となりすまし対策トークン。同じ送信に含まれる検索条件と一括編集の入力は参照しない |
| 成功時出力 | デッキ検索・一覧またはデッキ一覧の先頭へ戻し、削除完了のメッセージを出す |
| 失敗時出力 | トークンが不一致のときは HTTP 403、対象のデッキが無いときは 404。記事で使われているときはエラーメッセージを伴って元の画面へ戻す |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 削除 | デッキに含まれるカードを、当該デッキを削除できる条件を満たしたとき |
| 更新 | デッキの更新者を、削除の直前にログイン中の管理者へ書き換えたとき |
| 削除 | デッキ本体を、更新者の書き換えの後 |

## 表示メッセージ

| メッセージID | 表示位置 | 画面上の文言 | 表示条件 | 後続処理 |
| --- | --- | --- | --- | --- |
| — | 管理画面上部 | 記事に紐付いているデッキがあるため削除できません。 | 記事で使われているデッキを一括削除しようとしたとき | 削除せず、元の画面へ戻す |
| — | 管理画面上部 | 削除しました | 選択したデッキをすべて削除できたとき | デッキ検索・一覧またはデッキ一覧の先頭へ戻す |
