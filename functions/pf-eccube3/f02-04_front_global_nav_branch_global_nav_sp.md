# F02-04（支店スマホ版ナビゲーション）

## 業務ロジック

### ログイン状態による導線

画面下部の固定ナビのメニューは、会員ログイン済みのときマイページとログアウトの2つの導線を出す。未ログインのときは会員ログインへの導線だけを出す。ログアウトを選ぶと、支店のトップページへ戻る。

### カートの個数表示

カートの個数は、画面を表示したあとに取得し直して表示する。画面上部の帯と画面下部の固定ナビのカートには同じ個数を出す。取得できなかったときは、画面を組み立てた時点の個数を表示したままとする。

### サイトマップの導線の遷移先

サイトマップに並ぶ当サイトについて・プライバシーポリシー・特定商取引法に基づく表記・お問い合わせは、いずれも支店サイト内の画面ではなく、本店サイトの該当ページを開く。

### フッタの表示

フッタには、サイトマップの導線に続けて支店の店舗名を出し、その下に店舗名を用いた著作権表示を出す。店舗名は支店のトップページへの導線を兼ねる。

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | 支店サイト各画面の表示要求（会員のログイン状態を含む） |
| 成功時出力 | 画面上部の帯・画面下部の固定ナビ・フッタの表示 |
| 失敗時出力 | 描画に失敗したときは共通の例外処理に委ねる |
