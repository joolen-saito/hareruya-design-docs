# F02-04（支店スマホ版ナビゲーション）


### フェーズ2対応（フェーズ1では実装しない）

## 業務ロジック

### 店舗の決まり方

店舗紹介ページではパスの店舗識別名で店舗を決める。イベントの店舗文脈ではクエリの店舗IDで店舗を決める。本店のようにサイトルート直下では店舗を決めない。

イベントの店舗文脈で指定した店舗が見つからないときは表示しない。店舗紹介ページでの店舗の特定と見つからないときの扱いは支店トップ（F01-02）を正とする。

### 表示する要素

店舗紹介ページのスマホ表示では、タブレット用店舗一覧（「閲覧店舗を選択」付き、表示中の店舗を選択状態にする）、右カラムのセクションナビ、ポイント確認バナーを表示する。イベントの店舗文脈では店舗切替のセレクトを表示する。

店舗ヘッダは共通レイアウトの隠しメニュー（ショップ・買取・記事・デッキ検索・デッキ構築・選手一覧・店舗一覧・イベント・ヘルプ・お問い合わせ）と、マイページ導線・言語切替・カートを持つ。隠しメニューの項目構成と言語別の出し分けは、本店スマホ版ナビ（F02-02）と同じ部品を用いる。

カートの個数は表示後に取得して表示する。

### 右カラムのセクションナビ

登録済みの右カラム項目だけを並べる。値の無いセクションはナビにも出さない。

順序は店舗案内・初心者講習会・取り扱い商品・買取・スタッフ・その他・アクセスの定義順とする。出力順の末尾の要素には末尾用の体裁を付ける。

### 店舗名の表示

タブレット用店舗一覧は店舗名を表示する。イベントの店舗文脈の店舗切替セレクトは短縮店舗名を表示する。いずれも言語に応じて日本語名・英語名を用いる。

店舗一覧・店舗切替セレクトはいずれも並び順付きの全店舗を対象とし、表示中の店舗を選択状態にする。店舗切替セレクトで店舗を選ぶと、その店舗のイベント店舗文脈へ遷移する。

### 表示の出し分け

スマートフォン・タブレットの幅ではPC用の要素を隠し、店舗一覧・店舗切替セレクト・ポイントバナーのスマートフォン用の要素を表示する。

### 他機能との境界

本書のナビは支店文脈のスマートフォン向けの導線である。本店スマホ版ナビ（F02-02）とは別である。ポイント確認用のモーダルは支店トップ（F01-02）を正とする。ナビ自体は専用のモーダルを持たない。

### Excel基本設計との関係

支店スマホ版ナビゲーション上の通知はフェーズ2対応であり、フェーズ1では実装しない。Excel原文は「※通知はフェーズ2以降で設計予定とする」である。

### 計算

金額計算・税計算・丸めを行わない。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| イベントの店舗文脈で店舗IDに該当が無い | 見つからない扱いとする |
| カート個数の取得に失敗 | 取得できないときの表示は本書では仕様を確定せず、実装を確認値とする |
| 描画の障害 | 共通の例外処理に委ねる |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 支店各画面の表示要求。店舗識別名またはイベントの店舗IDと、言語の指定。ナビ自体は入力フォームを持たない。 |
| 成功時出力 | タブレット用店舗一覧・右カラムセクションナビ・店舗切替セレクト・店舗ヘッダの表示。 |
| 失敗時出力 | 店舗が存在しないときは見つからない扱いとする。描画に失敗したときは共通の例外処理に委ねる。 |

### 入出力: 永続化

表示のみを行い、データを更新しない。
