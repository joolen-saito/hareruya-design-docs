# 店頭買取管理 — 買取一覧 CSV ダウンロード（買取商品明細ほか）

## 業務ロジック

### 出力の共通処理

買取一覧で選択した査定IDの配列と出力種別を受け取る。査定IDが空または未設定のときは「1つ以上の商品を選択してください」を表示し、直前の画面へ戻す。出力種別に応じて、定義済みのヘッダ配列と行生成処理をひもづける。生成した行はダウンロード応答として返す。処理中に異常が起きたときはエラーメッセージを表示し、直前の画面へ戻す。

出力種別は、古物台帳入力用、ECインポート用、支店インポート用、TC東京インポート用、新支店インポート用、支店伝票インポート用である。

### 古物台帳入力用

ステータスと店舗単一の確認は行わない。指定された査定IDの申込情報を集約し、1査定につき1行を出力する。列は、査定ID、査定完了日の和暦風フォーマット、買取総額、数量（詳細・個別入力の有無により式で割る集約）、氏名結合、身分証種別名、住所（国情報により都道府県と住所の並びが切り替わる）、年齢、電話、職業、適格請求書発行事業者か否か、その番号とする。氏名結合は姓と名の間に全角空白を入れる。年齢は申込年月日から生年月日を差し引いた年数とし、8桁の日付の差を 10000 で割って小数を切り捨てる。電話はExcelで文字列として扱わせるため、先頭に `'` と `=` を付した形式とする（実装確認値）。

文字コードは共通の既定に従い、ヘッダ行の前に UTF-8 の BOM を付ける。ファイル名は接頭語 `old_goods_account_` に現在時刻ベースの接尾を付ける。

### ECインポート用および在庫系

対象は、ECインポート用、支店インポート用、TC東京インポート用、新支店インポート用、支店伝票インポート用である。出力前に、選択した査定のステータスがすべてダブルチェック済みであること、および紐づく店頭買取の店舗が単一であることを確認する。

在庫の抽出は種別により分かれる。

| 出力種別 | 抽出条件 |
| --- | --- |
| ECインポート用 | カード状態がニアミントの明細のみを対象とする。同じ商品規格IDについて数量を合計し、合計が正のグループのみ行を返す |
| 支店インポート用・TC東京インポート用・新支店インポート用 | カード状態の制限を設けず、数量が正の明細のみで行を構成する |
| 支店伝票インポート用 | 店頭買取IDと商品規格IDの組でグループ化し、販売価格は明細側の売価、数量は在庫行の値を用いる。出力前に商品コード単位で数量を足し込むため、同一商品コードの複数グループが1行にまとまることがある |

出力する列は次のとおりとする。

| 出力種別 | 列 |
| --- | --- |
| ECインポート用 | 商品コード、在庫増減数 |
| 支店インポート用 | 商品コード、商品名（言語コードを角括弧で前置した商品名）、在庫数 |
| TC東京インポート用 | 商品コード、在庫増減数 |
| 新支店インポート用 | 商品コード、在庫増減数、ピックアップ商品（データは常に空） |
| 支店伝票インポート用 | 商品コード、在庫増減数、販売価格、状態コード |

支店インポート用はSJISとして扱われるよう出力設定を一時的に切り替え、BOMを付けない。ファイル名は、ECインポート用のみ複数査定の査定IDをアンダースコアで連結した接頭に `.csv` を付ける。連結の順序は取得した配列の順に依存する。他の種別は種別ごとの接頭語と日時の接尾を付ける。

### 出力後の更新

在庫系の行データを生成した後、対象の店頭買取を一括で更新する。ステータスを入力済みに、データ出力日と更新日を現在日時に、更新者を操作者に更新する。ECインポート用では、入力済みへ遷移していたものにステータス履歴を追加しない。その他の種別では、入力済みへ遷移した旨のステータス履歴を追加する。

### 在庫系の判定順序

| 順序 | 判定 | 結果 |
|------|------|------|
| 1 | 選択した査定IDの配列が空か | 空なら商品未選択のメッセージを表示し直前の画面へ戻す |
| 2 | ステータスがすべてダブルチェック済みか | 否ならステータス不一致のメッセージを表示し直前の画面へ戻す |
| 3 | 対象査定が単一店舗に収まるか | 複数店舗なら店舗混在のメッセージを表示し直前の画面へ戻す |
| 4 | 上記を通過 | 抽出結果に基づき行データを組み、店頭買取とステータス履歴を更新する |

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| 選択した査定IDが空 | 商品未選択のメッセージを表示する |
| ステータス不一致 | ステータス不一致のメッセージを表示する |
| 店舗混在 | 店舗混在のメッセージを表示する |
| その他の異常 | 異常の内容をそのままメッセージとして表示する |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 出力種別、選択した査定IDの配列、任意で直前の画面のURL（失敗時の戻り先として使う） |
| 成功時出力 | CSVファイルのダウンロード応答 |
| 失敗時出力 | エラーメッセージを表示し、直前の画面へ戻す |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 追加 | 在庫系の出力時に入力済みへ遷移した店頭買取のステータス履歴（ECインポート用で既に入力済みだったものを除く） |
| 更新 | 在庫系の出力時の店頭買取のステータス・データ出力日・更新日・更新者 |

## 表示メッセージ

| メッセージID | 表示位置 | 画面上の文言 | 表示条件 | 後続処理 |
| --- | --- | --- | --- | --- |
| — | 管理画面上部 | 1つ以上の商品を選択してください | 査定を1件も選択せずにCSVダウンロードを実行したとき | 出力せず直前の画面へ戻る |
| — | 管理画面上部 | 出力対象にダブルチェック済以外のステータスが設定されています。 | 在庫系の出力で、ダブルチェック済み以外のステータスの査定が含まれるとき | 出力せず直前の画面へ戻る |
| — | 管理画面上部 | 出力対象が単一の店舗ではありません。 | 在庫系の出力で、対象の査定が複数店舗にまたがるとき | 出力せず直前の画面へ戻る |

日本語の文言は環境の翻訳リソースに従う。その他の異常では、異常の内容がそのままメッセージとして表示される。
