# ネット買取 — 買取手続き〜完了

## 業務ロジック

### 手続きの前提

買取カートに商品があり、会員としてログイン済みであることを、記入・確認・確定の前提とする。買取カートが無いときはカート画面へ戻す。ログイン済みでないときは買取ログイン画面へ戻す。買取ログイン画面では、自動ログイン記憶状態のとき、ログインメール欄に会員のメールアドレスを初期表示する。ログイン済みの状態で買取ログイン画面を開いたときは記入画面へ移す。

### 記入画面

入力された数量で買取カートを更新したうえで、カート内商品と合計買取価格を表示する。見出しは「買取依頼内容の確認」、進捗はSTEP2として示す。入力させるのは、振込口座情報（銀行名・支店名・口座種別・口座番号・口座名義）、個口数、自動承諾の選択、適格請求書発行事業者登録の確認である。会員に職業・生年月日が未登録のときだけ、その入力欄を追加する。振込口座情報と適格請求書発行事業者口座は、会員に既存のものがあればそれを初期値とし、無ければ新規入力とする。口座名義は全角カタカナで入力する旨を案内する。数量を更新すると買取カートを再計算する。

### 自動承諾

選択肢は「査定結果を確認してから承諾する」「自動承諾を利用する」である。「自動承諾を利用する」が選ばれたときは、買取受注の自動承諾を有効として設定する。

### 適格請求書発行事業者

「はい」を選んだときだけ登録番号を入力させ、適格請求書発行事業者口座と発行事業者の区分を設定する。選択に応じて登録番号入力欄の検証対象を切り替える。適格請求書発行事業者についての説明を画面上で案内する。

### 個口数

選択できる箱数の既定範囲は1〜20である。選択した値を買取受注に設定する。

### 依頼の確定

確定時は次を1つのまとまりとして登録し、途中で例外が起きたときは登録内容をすべて取り消す。

- 会員に職業が未登録なら職業を登録する。生年月日が未登録なら生年月日を登録する。
- 振込口座情報を登録する。適格請求書発行事業者口座があれば登録する。
- 買取受注を状態「注文」で登録し、会員情報・住所・電話・送金方法（買取用の送金方法）を設定する。
- 自動承諾の選択と個口数を買取受注へ設定する。
- 買取受注ステータス履歴を登録する。
- 買取カートに商品があれば、買取メインカード（商品・言語・状態・数量・適用価格）を登録する。

会員情報を更新したときは、支店システムへ会員更新を通知する。登録後はオーダーIDを組み立てて保持し、買取メインカードを商品ID順に読み直して買取受注へ設定したうえで、買取受注完了の自動返信メールを送信し、完了画面へ移す。

### メモへの保存

カード詳細IDを持たず、まとめて買取でもない商品（パック・サプライなど）は、「名称x数量」を改行区切りでメモへ保存する。

### オーダーID

「PU」と年月日6桁、受注IDの10桁ゼロ詰めを連結した文字列とする。

### 確定時の判定順序

| 順序 | 判定 | 結果 |
| --- | --- | --- |
| 1 | 買取カートがあるか | 無ければカート画面へ戻す |
| 2 | ログイン済みか | 未ログインなら買取ログイン画面へ戻す |
| 3 | 入力（確認内容、該当時は登録番号）が妥当か | 不備があれば記入画面を再表示する |
| 4 | 上記を通過 | 買取受注・口座・履歴・買取メインカードを登録し、メール送信のうえ完了画面へ移す |

### 完了画面

オーダーIDを表示する。見出しは「買取依頼完了」、進捗はSTEP3として示し、御礼と発送案内、オンライン本人確認の案内、「買取TOPへ」「マイページ」への導線を表示する。表示時に買取カートと保持したオーダーIDを破棄する。

### エラー時の扱い

| 事象 | 扱い |
| --- | --- |
| 買取カートが無い | カート画面へ戻す |
| 未ログイン | 買取ログイン画面へ戻す |
| 入力不備 | 記入画面を再表示する |
| 登録中の例外 | 登録内容を取り消し、例外として扱う |

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | 買取カートの内容、会員情報、確認入力（振込口座・職業・生年月日・個口数・自動承諾）、適格請求書発行事業者の登録番号（該当時） |
| 成功時出力 | オーダーIDを表示した完了画面、買取受注完了の自動返信メール |
| 失敗時出力 | 入力不備時は記入画面の再表示、買取カートが無いときや未ログイン時は各画面への移動 |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 追加 | 買取依頼の確定時に、買取受注・買取受注ステータス履歴・買取メインカード・振込口座情報・適格請求書発行事業者口座を登録する |
| 更新 | 買取依頼の確定時に、会員の職業・生年月日が未登録であればそれを登録する |
