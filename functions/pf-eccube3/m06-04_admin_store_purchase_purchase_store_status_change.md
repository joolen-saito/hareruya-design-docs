# 店頭買取管理 — 買取ステータス変更

## 業務ロジック

### ステータス変更画面

指定された店頭買取受注が無いときは404応答とする。変更後ステータスは空の状態で表示し、初期選択値を持たない（プレースホルダは「ステータスを選択」）。

変更後ステータスの選択肢は、店頭買取ステータスマスタのうち廃止IDを除き、ID昇順で表示する。

保存に成功したときは店頭買取詳細へ遷移する。業務上の理由で更新を拒否したときは、メッセージを表示して同一店頭買取IDのステータス変更画面へ戻す（詳細には戻さない）。フォームが未送信または妥当でないときは、同一画面を再表示して項目ごとのエラーを表示する。

### ステータス変更の判定順序

| 順序 | 判定 | 結果 |
|------|------|------|
| 1 | 編集可能店舗と買取店舗の一致 | 不一致なら拒否（画面別に戻り先と例外種別が異なる） |
| 2 | 現在が入庫済みか | 入庫済みなら次が管理者取消でなければ拒否 |
| 3 | 次が入庫済みか | 明細・個別入力の商品規格必須チェックを行う |
| 4 | 次が買取成立か | 成立なら続けて入庫待ち系の最終ステータスへ2回目の更新を行う |
| 5 | 入庫待ちから入庫済みか | 条件を満たせば在庫入庫処理を行う |

次が入庫済みのときの必須チェックは、数量が正の明細に未紐付けの商品規格が無いか、個別入力商品に商品規格未紐付けの実在庫が無いかを見る。違反したときは拒否する。

### ステータス更新で行うこと

更新は一連の処理としてまとめて行い、途中で失敗したときはすべて取り消す。

| 更新対象 | 内容 |
| --- | --- |
| 店頭買取受注の更新日時 | 現在時刻に更新する |
| ステータスに紐づく日付 | 買取成立・キャンセル・入庫のうち、受注側の対応表に載るものだけをステータス遷移に応じて埋める。同一ステータスへの更新と買取成立の重複上書きは抑止する |
| ステータス本体 | 次ステータスへ更新し、店頭買取ステータス履歴に1件追記する |
| 買取成立後の自動遷移 | 個別入力商品が空なら入庫待ち（ID13）、空でなければ未登録在庫あり（ID12）へ、同じ処理の中で再度更新し履歴を追記する |
| 在庫反映 | 入庫待ちから入庫済みへ移すときだけ、店頭買取実在庫を商品在庫へ反映し在庫履歴を残す（変更種別は店頭買取入庫） |
| 集計サマリ | 新旧ステータスが買取集計データ対象ステータスの集合の内外に跨り、かつ買取成立日時が既に入っているときだけ、買取成立日の日付単位で集計サマリを再計算する |

入庫待ちから入庫済みへ移すときは、先に入庫済みへ更新して二重入庫を抑止し、その更新が実際に行われたときだけ在庫反映を行う。

本機能では金額再計算や税計算を行わない。

### 詳細画面からのステータス変更

| 操作 | 内容 |
| --- | --- |
| 経理払出し済 | なりすまし対策トークンを検証する。ログイン利用者が管理者アカウントでなければ認証エラーとする。店頭買取受注の店舗と利用者の編集可能店舗が一致しないときはエラーとし、利用者向け表現はアプリケーション全体のエラー表示に従う。現在ステータスが経理払出し待ちでないときはエラーを表示して詳細へ戻る。条件を満たすときは次ステータスを買取成立（ID1）として更新する |
| 入庫済みにする | なりすまし対策トークンを検証する。ログイン利用者が管理者アカウントでなければ認証エラーとする。店舗が一致しないときはエラーとする。次ステータスを入庫済み（ID11）として更新する |

いずれも成功時は保存完了、失敗時は拒否の理由を表示し、詳細へ戻る。詳細画面の操作は常に表示される。「入庫済みにする」は現在ステータスの事前確認を行わず、店舗一致・入庫済みの前提・マスタ紐付けの検査で拒否する。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| 対象IDが無いとき | 404応答とする |
| なりすまし対策トークン不一致 | エラーを表示して詳細へ戻る |
| 店舗不一致（フォーム経由） | メッセージを表示してステータス変更画面へ戻る |
| 店舗不一致（詳細画面からの実行） | エラーとし、利用者向け表現はアプリケーション全体のエラー表示に従う |
| 入庫済みからの違反遷移 | 業務上の拒否として扱う |
| 入庫済み化で商品規格が未登録のとき | メッセージを表示して拒否する |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 店頭買取受注ID、フォームまたは詳細画面の操作による次ステータス、なりすまし対策トークン、ログイン利用者 |
| 成功時出力 | 画面遷移と保存完了またはエラーのメッセージ |
| 失敗時出力 | 妥当性エラーはフォーム再表示、業務上の拒否はメッセージ付きの画面遷移、トークン不一致はメッセージ付きの画面遷移、存在なしは404応答 |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 更新 | ステータス変更（ステータス本体・更新日時・ステータスに紐づく日付） |
| 更新 | 入庫時の商品在庫反映 |
| 更新 | 買取成立日の集計サマリ再計算 |
| 追加 | ステータス履歴の追記、在庫履歴の追記 |
