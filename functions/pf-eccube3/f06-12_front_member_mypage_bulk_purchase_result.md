# 会員 — まとめて買取査定結果

## 業務ロジック

### 表示の対象

会員としてログインしていることを前提とする。買取依頼IDが指定されていないときは、ページが見つからない扱い（404）とする。ログイン会員の買取依頼で、指定された買取依頼IDに一致するものを取得する。取得できないときもページが見つからない扱いとする。他会員の買取依頼IDを指定したときは取得できない。

### 一覧の内容

取得した買取依頼のまとめて買取の商品明細を、商品ごとに商品名・言語・状態・査定価格・数量・小計として一覧に表示する。見出しは「まとめて買取査定結果」とする。買取履歴詳細からは新しい画面として開く。利用者が入力する項目は持たない。

### 表示する値の決め方

| 項目 | 決め方 |
| --- | --- |
| 小計 | 査定価格と数量を掛けた金額とする |
| 状態 | 状態コードがPLDに相当する集合に含まれるときはPLDの表示文言に置き換え、それ以外は状態コードをそのまま表示する |
| 査定価格・小計 | 金額の書式で表示する |
| 削除済み商品 | 査定後に削除された商品・商品規格も、査定結果として表示する |

### エラー時の扱い

| 事象 | 扱い |
| --- | --- |
| 買取依頼IDが指定されていない | ページが見つからない扱い（404）とする |
| 対象の買取依頼が存在しない、または他会員の買取依頼ID | ページが見つからない扱い（404）とする |
| 未ログインでの参照 | 会員ログインへ誘導する |

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | 買取依頼ID（数字のみ） |
| 成功時出力 | まとめて買取査定結果の一覧表示 |
| 失敗時出力 | ページが見つからない扱い（404） |

### 入出力: 永続化

本機能はデータを更新しない。

## 表示メッセージ

この機能は閲覧のみで、メッセージを表示しない。対象が無いときはページが見つからない扱いとする。
