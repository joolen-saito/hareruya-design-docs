# イベント管理 — イベント新規申込登録

## 業務ロジック

### 新規申込フォームの初期表示

新規申込の支払金額には、対象イベントの参加費を初期表示する。

### プレイヤー検索

- プレイヤー名は、会員の姓・名・姓カナ・名カナと、プレイヤーの和名（姓・名）・英名（姓・名）のいずれかへ部分一致で照合する。
- 検索語を半角スペース・全角スペース・カンマで区切って入力すると、区切った語すべてに一致するものへ絞り込む。
- 検索結果の「決定」は、次の場合は押せない状態で表示する。

| 状態 | 決定欄の表示 |
| --- | --- |
| 同じイベント日程へ既に申し込み済みのプレイヤー | 登録済（選択できない） |
| 編集中の申込へ既に選んであるプレイヤー | 選択済（選択できない） |

- 該当が0件のときは、検索結果の一覧に代えて、該当データが無い旨の案内を表示する。

### 登録

登録に成功したときは、登録した申込の編集画面へ移る。

### エラー時の扱い

| 事象 | 扱い |
| --- | --- |
| イベント日程が存在しない | ページが見つからない扱い（404）とし、画面上のメッセージは出さない |
| 未送信 | 登録失敗を表示し、新規申込画面へ戻す |
| 支払金額が不正 | 金額のメッセージを表示し、新規申込画面へ戻す |
| 参加者重複 | 申込重複のメッセージを表示し、新規申込画面へ戻す |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | イベント日程ID、なりすまし対策トークン、支払金額、参加者として選んだプレイヤー |
| 成功時出力 | 申込・申込プレイヤーの新規登録、申込履歴の追加、完了メッセージ、編集画面への移動 |
| 失敗時出力 | 未送信・検証NGはエラーを表示のうえ新規申込画面へ戻す。イベント日程が無い場合は404 |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 追加 | 検証に通った新規申込の登録時に、申込・申込プレイヤー・申込履歴を記録する |
