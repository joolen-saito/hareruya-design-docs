# 商品管理 — カテゴリ一覧

## 業務ロジック

### 一覧の構成

画面は指定した親カテゴリの直下にあるカテゴリの一覧と、ルートから5階層までのカテゴリツリーを表示する。親を指定しない場合はルート直下を一覧に表示する。

編集を開いた場合は、対象カテゴリの兄弟カテゴリを一覧に表示し、祖先をたどったパンくずを表示する。

指定した親カテゴリが存在しない場合はページが見つからない扱いとする。

### 登録と更新

カテゴリは親カテゴリの配下にのみ新規登録できる。ルート直下への新規登録は画面から行わない。

階層の深さは5階層までとする。5階層を超える登録・更新はできない。

カテゴリ画像は画像ファイルだけを受け付ける。許可した拡張子以外は登録できない。

### 表示順

新規登録したカテゴリは、親カテゴリの直下で既存カテゴリより手前に入る位置に表示順を割り当てる。既存カテゴリの表示順は繰り下げる。

一覧で並べ替えを確定すると、画面の並びどおりに表示順を割り当て直す。

### 削除

削除は対象カテゴリを削除し、同じ親を持つ後続カテゴリの表示順を1つ繰り上げる。

関連するデータから参照されているカテゴリは削除できない。すでに削除済みのカテゴリを削除しようとした場合は、その旨を表示して一覧へ戻る。

削除後は、対象がルート直下なら一覧へ、それ以外なら親カテゴリの一覧へ遷移する。

### CSV出力

カテゴリ一覧はCSVで出力できる。出力する列はCSV出力項目設定で有効にした項目とし、表示順の降順で全カテゴリを出力する。商品数の列は各カテゴリの商品件数を出力する。

### エラー時の扱い

| エラー内容 | 扱い |
|------------|------|
| 入力に不備がある | 同一画面にエラーを表示する。登録・更新はしない。 |
| 階層の深さが5階層を超える | 登録・更新しない。 |
| 画像の形式・拡張子が許可外、または保存できない | エラーを表示して再入力を求める。保存済みの一時ファイルは残さない。 |
| 削除対象が関連データから参照されている | 削除せず、その旨を表示する。 |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 親カテゴリの指定、カテゴリ名などの入力項目、カテゴリ画像、並べ替えの結果 |
| 成功時出力 | カテゴリの一覧とツリー、登録・更新・削除の完了メッセージ、CSVファイル |
| 失敗時出力 | 入力の不備によるエラー、削除できない場合のエラー |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 追加 | カテゴリの新規登録 |
| 更新 | カテゴリの編集、並べ替え、削除に伴う表示順の繰り上げ |
| 削除 | カテゴリの削除 |

### 出力: CSVファイル

ヘッダ行を先頭に出力し、続けてカテゴリを1件1行で出力する。
