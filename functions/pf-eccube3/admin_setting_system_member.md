# メンバー管理（システム情報設定／設定）

## 業務ロジック

### 一覧の表示

管理者アカウントを全件、表示順の降順で並べる。絞り込みの条件は持たない。一覧に入力欄は表示しない。

### 登録・編集の表示

編集権限を持たないメンバーは登録・編集を実行できない。

編集で指定した管理者アカウントが存在しないときは表示しない。編集のときは登録済みのパスワードを退避し、入力欄には設定の既定パスワード値を表示する。新規のときは空のアカウントを用意する。

入力欄は標準項目に加えて、所属店舗、メールアドレス、デフォルト検索表示店舗、編集可能店舗、二段階認証、自動ログアウト設定、スマレジ用アカウントを持つ。所属は自由入力ではなく所属マスターデータからの単一選択とする。

### 保存

編集権限を持たないときは保存しない。入力に不備があるときは保存せず、同じ画面に項目エラーを表示する。成功メッセージは出さない。

編集で、入力されたパスワードが既定パスワード値のままのときは、退避していた登録済みパスワードへ戻す。それ以外のときは、ソルトが未設定なら乱数でソルトを作り、パスワードをハッシュ化して保存する。

所属、デフォルト検索表示店舗、編集可能店舗、二段階認証、自動ログアウト設定、スマレジ用アカウントを入力値のとおり保存する。編集可能店舗は複数登録できる。

保存に成功したときは、新規は作成したアカウントの編集画面、編集は同じ編集画面へ戻る。保存に失敗したときは、新規は同じ入力内容の画面を再表示し、編集は同じ編集画面へ戻る。

### 表示順の変更

「上へ」は自身の表示順より1大きい行と表示順を入れ替える。「下へ」は自身の表示順より1小さい行と入れ替える。送信情報が不正なときは変更しない。対象のアカウントが存在しないときも変更しない。入れ替える相手が存在しないなど変更できないときはエラー文言を表示する。変更のあとは一覧へ戻る。

### 削除

送信情報が不正なときは削除しない。対象のアカウントが存在しないときも削除しない。

削除対象より大きい表示順の行をすべて1つ繰り下げたうえで、対象のアカウントを削除する。他のデータから参照されているときは削除できず、エラー文言を表示する。削除のあとは一覧へ戻る。

### 計算

金額の集計や税率の計算は行わない。

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 登録・編集の各入力項目。表示順変更・削除は対象のアカウント。 |
| 成功時出力 | 成功メッセージと、一覧または編集画面の再表示。 |
| 失敗時出力 | 項目エラー、またはエラーメッセージ。対象が存在しないときと送信情報が不正なときは処理しない。 |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 管理者アカウントの登録 | 新規登録の保存 |
| 管理者アカウントの更新 | 編集の保存 |
| 管理者アカウントの表示順の更新 | 「上へ」「下へ」、および削除に伴う繰り下げ |
| 管理者アカウントの削除 | 削除 |
