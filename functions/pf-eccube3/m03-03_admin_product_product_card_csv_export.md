# 商品管理 — カード商品CSV出力

## 業務ロジック

### 出力対象の決定

商品一覧で選択した商品IDの配列を受け取る。配列でないときは空配列とみなす。各要素を整数に変換し、0より大きいIDだけを残す。

有効なIDが1件も無いときは出力せず、エラーメッセージを表示して商品一覧へ戻る。戻り先のページ番号には直前の商品検索のページ番号を用い、保持していないときは1とする。

指定されたIDに一致する商品を取得する。1件も得られないときは出力せず、エラーメッセージを表示する。

商品のうち、カード詳細を持たないものと規格が0件のものは出力対象から外す。除外の結果として出力行が1行も無いときは、エラーメッセージを表示する。

出力処理には処理時間の上限を設けない。

### 出力行の作り方

商品ごとに商品単位の列を組み立て、その商品の規格ごとに行を複製して規格依存の列を埋める。1規格につき1行となる。

タグIDは重複を除いたうえでカンマ連結する。カテゴリIDと売上分析タグIDはカンマ連結する。規格画像はファイル名をカンマ連結し、ファイル名が未設定のものは除く。

ヘッダ行の並びは、カード商品登録CSVのヘッダ定義のキー順による。データ行は同じ順で値を並べる。

### ファイルの体裁

ファイル名は product_card_ に出力日時（年月日時分秒）と .csv を連結したものとする。出力文字コードは設定に従う。UTF-8のときは先頭にBOMを付ける。値は設定の出力文字コードへ変換して書き出す。区切り文字は設定に従い、囲み文字とエスケープ文字はCSV出力の既定に従う。応答には出力文字コードに応じた形式種別と、ダウンロードとして扱う指定を付ける。設定値が SJIS-win のときは、形式種別上は windows-31j として扱う。

### 刷新後に実装しない仕様

Excel基本設計 0204 識別ID:29 により廃止された。現行実装のふるまいを次に残すが、刷新後の実装とテストの対象外とする。

| 項目 | 内容 |
| --- | --- |
| 行の複製単位 | 商品につき規格の反復ごとに1行。規格の並び順は現行実装に依存し、一覧の表示順と一致するとは限らない |
| 一部のIDが登録されていないとき | 取得できた商品だけが出力対象となり、存在しないIDは無視される。すべて無効なときは存在しない旨のエラーとなる |
| カード詳細だけが欠ける商品が混在するとき | その商品を除外する。すべて除外されたときはカードデータが無い旨のエラーとなる |

### エラー時の扱い

| 事象 | 扱い |
| --- | --- |
| 有効な商品IDが1件も無いとき | 商品一覧へ戻る。ページ番号は直前の商品検索のページ番号を用いる |
| 指定IDに対応する商品が1件も無いとき | 出力せず、直前の画面へ戻る。直前の画面が不明なときは商品一覧へ戻る |
| 変換後の行が0行のとき（カード詳細または規格の条件に一致しない） | 同上 |
| その他の実行時の異常 | 同上 |

本機能は入力項目の最大長・必須の検証を持たない。

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | 商品IDの配列 |
| 成功時出力 | CSVのストリーム。ファイル名は product_card_ と出力日時（年月日時分秒）と .csv の連結 |
| 失敗時出力 | エラーメッセージを表示し、直前の画面または商品一覧へ戻る |

### 入出力: 永続化

本機能はデータを更新しない。

### 出力: 商品単位の列

同一商品の複数規格の行で繰り返される。

| 列名 | 内容 |
| --- | --- |
| 商品ID | 商品の識別子 |
| 商品公開ステータス | 公開ステータスマスタのID |
| 支店の商品公開ステータス | 支店公開の真偽を整数に変換した値 |
| 商品名(日) | 商品名（日本語） |
| 商品名(英) | 商品名（英語） |
| サイズ | サイズ文字列 |
| 重量 | 重量 |
| 商品説明(日) | 詳細説明（日本語） |
| 商品説明(英) | 詳細説明（英語） |
| 買取商品説明(日) | 買取向け説明（日本語） |
| 買取商品説明(英) | 買取向け説明（英語） |
| 検索ワード | 検索ワード |
| 商品カテゴリ(ID) | 関連カテゴリIDをカンマ連結 |
| 購入グループ名称 | 購入グループマスタの名称。未設定のときは空文字 |
| 割引率(ID) | 割引マスタのID。未設定のときは空文字 |
| 買取減額率(ID) | 買取減額マスタのID。未設定のときは空文字 |
| 略称タグ(ID) | 略称タグマスタのID。未設定のときは空文字 |
| 売上分析タグ(ID) | 売上分析タグIDをカンマ連結 |
| タグ(ID) | タグIDを一意にしたうえでカンマ連結 |
| 地域別販売制限 | 地域別販売制限マスタのID。未設定のときは空文字 |
| フリーエリア | フリーエリア文字列 |

### 出力: 規格ごとの列

1規格につき1データ行を出力する。

| 列名 | 内容 |
| --- | --- |
| 言語(ID) | 規格の言語マスタID。未設定のときは空文字 |
| 規格画像 | 規格に紐付く商品画像のファイル名をカンマ連結。ファイル名が未設定のものは除く |
| 発送日目安(ID) | 規格の発送日目安マスタID。未設定のときは空文字 |
| 販売制限数 | 規格の販売制限数 |
| 基準価格 | 規格の基準価格 |
| 販売価格 | 規格の販売価格 |
| 買取価格 | 規格の買取価格 |
| 原価単価 | 規格の原価単価 |
| カード詳細(ID) | 商品に紐付くカード詳細の識別子。規格行でも商品側と同一の値 |

## 表示メッセージ

| メッセージID | 表示位置 | 画面上の文言 | 表示条件 | 後続処理 |
| --- | --- | --- | --- | --- |
| M03-03-MSG-001 | 管理画面上部 | 存在しないカードIDが含まれています。 ／ カードデータが存在しないためエクスポートできません。 | カード商品登録CSVをエクスポートしたとき、選択したカードIDに該当する商品がない、またはエクスポート可能なカードデータがない場合 | エラーを表示して、操作元の画面に戻る（操作元が不明な場合は商品一覧画面に遷移する） |
