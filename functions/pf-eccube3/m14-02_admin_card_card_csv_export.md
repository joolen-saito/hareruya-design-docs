# カード管理 — カード情報 CSV 出力

## 業務ロジック

### 出力対象

カード検索一覧で選択したカードIDの集合を出力対象とする。指定IDのうち存在するものだけを取得し、存在しないIDが混ざっていてもエラーにしない。1件も取得できないときは出力せず、メッセージを表示して直前の画面へ戻る。

出力対象のカードIDが空のときは出力せず、メッセージを表示してカード検索一覧へ戻る。戻り先のページ番号は直前のカード検索のページ番号を引き継ぎ、保持していないときは既定のページとする。

### 行の作り方

カード1件につき、カード単位の共通列を組み立てる。カード詳細ごとに行を複製し、詳細固有の列を末尾に連結する。すなわち1つのカード詳細が1データ行になり、共通列の値は同じカードの行に繰り返し出る。

カード詳細が1件も無いカードの扱いは、現行実装から確定できない。

### 出力する列（カード単位で共通）

| 列 | 内容 |
|----------|------|
| カード名（日本語） | 登録値をそのまま出力する。 |
| カード名（英語） | 同上。 |
| アリーナ表示名（日本語） | 同上。 |
| アリーナ表示名（英語） | 同上。 |
| ルールテキスト（日本語） | 同上。 |
| ルールテキスト（英語） | 同上。 |
| マナコスト | マナコスト文字列。 |
| 点数で見たマナコスト | 点数で見たマナコスト。 |
| パワー | パワー。 |
| タフネス | タフネス。 |
| 忠誠度 | 忠誠度。 |
| 色 | 関連する色を英名で読み、コンマで連結する。単一値のときはコンマを付けない。 |
| カードタイプ | 英名をコンマで連結する。 |
| サブタイプ | 英名をコンマで連結する。 |
| 特殊タイプ | 英名をコンマで連結する。 |
| キーワード能力 | 現行実装では空文字を固定で出力する。 |
| フォーマット | カードに紐付くフォーマットを英名でコンマ連結する。 |

### 出力する列（カード詳細ごと）

| 列 | 内容 |
|----------|------|
| セット | セットの英名。未設定なら空文字。 |
| レアリティ | レアリティの英名。 |
| イラストレータ | イラストレータの英名。 |
| レイアウト | レイアウトの英名。 |
| フレーバー（日本語） | フレーバー（日本語）。 |
| フレーバー（英語） | フレーバー（英語）。 |
| カード番号 | カード番号。 |
| プロモーション | プロモーションの英名。 |
| Foilフラグ | Foilフラグを整数にした値。 |
| プロモフラグ | プロモフラグを整数にした値。 |
| 画像（日本語） | 画像のうち、言語が日本語かつ表側の最初の要素のURL。無ければ空文字。 |
| 画像（英語） | 言語が英語かつ表側の最初の要素のURL。無ければ空文字。 |
| カード詳細ID | カード詳細の識別子。 |
| 裏面カード詳細ID | 裏面のカード詳細の識別子。 |
| 色順 | 色順マスタがあればその名前。無ければ値なしとなりうる。 |
| 固有色 | 固有色を英名でコンマ連結する。カード単位の値が各行に繰り返される。 |

ヘッダ行は上表の並びで出力し、データ行も同じ並びで値を並べる。

### 値の取り方

金額・数量・日時・ステータスは参照時点の永続化済みの値をそのまま出力し、出力時に再計算・補正しない。該当値が無い項目は空欄とする。出力途中で対象データが更新されても読み直しによる整合の補正は行わない。

出力対象は画面で確定した検索条件・権限・店舗・支店の条件に一致するものに限る。件数上限とページングの有無は呼び出し元の検索条件に従う。

### 出力ファイル

先頭にUTF-8のBOMを書き、ヘッダ行・データ行の順に書き込む。ファイル名は「cards_」に日時（年月日時分秒）と拡張子「.csv」を連結したものとする。文字コードと区切り文字は店舗のCSV出力設定に従い、設定が SJIS-win のときは windows-31j として扱う。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| 出力対象のカードIDが空 | メッセージを表示してカード検索一覧へ戻る |
| 対象カードが1件も存在しない | メッセージを表示して直前の画面へ戻る |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 出力対象のカードIDの配列 |
| 成功時出力 | CSVファイルのダウンロード。ファイル名は「cards_年月日時分秒.csv」、先頭にUTF-8のBOMを付ける |
| 失敗時出力 | メッセージを表示してカード検索一覧または直前の画面へ戻る |
