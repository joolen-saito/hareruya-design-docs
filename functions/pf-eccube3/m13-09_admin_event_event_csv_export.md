# M13-09（CSVダウンロード）

## 業務ロジック

### 出力対象の抽出

申込一覧で保持している検索条件をそのまま出力条件に用いる。並び順は既定キーの昇順に固定する。検索条件を保持していないときは既定の検索条件で全件を対象とする。イベント詳細を指定して呼び出したときは、そのイベント詳細の申込を対象とする。

検索モードがデッキ登録済みのときはデッキ起点で、それ以外のときは申込プレイヤー起点で対象データを取得する。会員は論理削除済みでも対象に含める。プレイヤーは論理削除の除外を無効化して対象に含める。

### 出力する列と値

出力項目と並びは申込CSV種別の定義に従う。各出力項目の値は、申込プレイヤー・イベント申込・プレイヤー・イベント詳細・デッキ・イベントのいずれかから最初に得られた非NULLの値を採用する。本機能では金額計算・件数の丸めを行わない。

### ファイルの形式

先頭にBOMを付与し、区切り文字はカンマ（確認値）とする。ヘッダ行に続けて対象行を1行ずつストリーミング出力する。ファイル名は一覧・イベント詳細指定とも event_entry_<出力日時YmdHis>.csv とし、出力したファイル名を記録する。

### 雛形CSV

一括登録用ヘッダ定義の見出し行だけをBOM付きで1行出力する。ファイル名は event_entry.csv、区切り文字はカンマ（確認値）とする。

### エラー時の扱い

管理画面の認証・権限を通過しないときは出力しない。

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 申込一覧で保持している検索条件。イベント詳細指定時はイベント詳細ID |
| 成功時出力 | イベント申込情報のCSVファイル（申込CSV種別の項目）、または一括登録用の雛形CSVファイル |
| 失敗時出力 | 認証・権限不足のときは出力しない |

本機能は画面上の入力フォームを持たない。
