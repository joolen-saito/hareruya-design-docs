# M13-09（CSVダウンロード）

## 概要

イベント管理のイベント申込一覧から、申込済みのイベント申込情報をCSVファイルとしてダウンロードする機能である。管理者がイベント申込一覧で絞り込んだ検索条件（セッション保持）に従い、申込・プレイヤー情報をストリーミングでCSV出力する。

本書は実装手順ではなく、誰が・いつ・どの条件で・結果どうなるかを読むためのリバース詳細設計とする。確認値はpf-eccube3（EC-CUBE3系）のHareruyaEcプラグインのイベント申込CSV出力処理、申込CSV種別の出力項目定義、コアのCSV出力サービスを正とする。

本機能のカスタマイズ区分はカスタマイズである。挙動の参照リポはpf-eccube3（HareruyaEcプラグイン）の現行実装とし、DB関連（永続化先のテーブル名・列名、DBカラム節）はec-cube-enterpriseを正とする。現行と移行先でスキーマが異なる箇所はリニューアル移行時の扱いに集約する。

対象はブラウザ経由の管理画面に限定する。

本文ではフレームワークのコントローラ型名やメソッド名を主説明としない。管理画面プレフィックスは環境により変わり、プラグイン設定の`admin_route`で決まる。「利用者視点の入口」にHTTPメソッドとサイトルートからのパスパターンを書く。

---

## 本書で扱うこと

- イベント申込一覧のCSV出力（全件・検索条件適用）
- イベント詳細指定でのCSV出力
- 出力対象データ、出力項目、文字コード、ファイル名、抽出条件
- 雛形（テンプレート）CSVのダウンロードとの区別

---

## 本書で扱わないこと

以下は本書では仕様確定せず、実装または別機能の設計を正とする。

- イベント申込一覧の検索フォーム・絞り込み条件の業務定義（イベント申込一覧機能を正とする）
- CSV出力項目の設定・編集（申込CSV出力項目設定を正とする）
- 一括CSV登録（取込）の仕様（M13-13を正とする）
- 雛形CSVの列内容そのものの妥当性（M13-13の取込仕様を正とする）

## リニューアル移行時の扱い

CSV出力の抽出・出力項目の挙動は現行（pf-eccube3）を正とし、出力元の列名は移行先（ec-cube-enterprise）を正とする。出力項目は申込CSV種別の定義に従い、移行で論理的な出力項目は変わらない。

| 観点 | 現行（pf-eccube3） | 移行先（ec-cube-enterprise） |
|------|---------------------|------------------------------|
| 論理削除 | `dtb_event_entry`・`dtb_entry_player`とも`deleted_at`による論理削除 | 同一方式（`deleted_at`による論理削除を維持） |
| 申込の主キー列 | `dtb_event_entry.event_entry_id` | `dtb_event_entry.id`（主キー列名を`id`に統一。参照列`event_detail_id`・`payment_id`・`entry_status_id`・`paying_customer_id`は同名維持） |
| 申込プレイヤーの主キー列 | `dtb_entry_player`の識別列 | `dtb_entry_player.id`（参照列`event_entry_id`・`player_id`は同名維持） |
| 支払期限 | 列の有無は実装による | `dtb_event_entry.payment_limit`を保持 |

会員・プレイヤーの論理削除済みデータを出力対象に含めるソフトデリート無効化の挙動は現行を正とする。移行先でも論理削除（`deleted_at`）を維持するため同じ方針で扱える。

## 用語

| 用語 | 説明 |
|------|------|
| イベント申込 | プレイヤーがイベント日程へ申し込んだ1件の申込。支払会員・支払方法・支払金額・申込状況を持つ。 |
| 申込CSV種別 | イベント申込の出力項目・並びを定義したCSV種別。本機能の出力項目はこの種別で決まる。 |
| 検索条件セッション | イベント申込一覧が保持する検索条件。CSV出力はこの条件を適用する。 |
| デッキ登録検索モード | 申込一覧の検索モードの一種。出力時は申込ではなくデッキ情報を起点に対象を取得する。 |

## 利用者視点の入口

| 入口 | URLエンドポイント | 期待されるふるまい |
|------|--------------------|--------------------|
| イベント申込一覧のCSVダウンロード | `GET /%eccube_admin_route%/entry/export` | 申込一覧の検索条件セッションに従い、イベント申込情報をCSVとしてダウンロードする。 |
| イベント詳細指定のCSVダウンロード | `GET /%eccube_admin_route%/entry/{eventDetailId}/export` | 指定したイベント詳細を対象に、申込情報をCSVとしてダウンロードする。 |
| 雛形ファイルダウンロード | `GET /%eccube_admin_route%/entry/entry_csv_template` | 一括登録用CSVのヘッダのみのひな型をダウンロードする（取込用、本書では区別のみ扱う）。 |

管理画面プレフィックスは環境により変わるためプレースホルダで示す。`{eventDetailId}`はイベント詳細の識別子。

## 処理フロー

### イベント申込CSVを出力する（`/%eccube_admin_route%/entry/export`、`/%eccube_admin_route%/entry/{eventDetailId}/export`）

1. 管理画面の認証・権限を通過する。
2. ソフトデリートフィルタを調整し、会員は論理削除済みでも対象に含め、プレイヤーはソフトデリート無効化で対象に含める。
3. 実行時間制限を無効化し、SQLロガーを無効化してストリーミング出力に備える。
4. 申込CSV種別で出力サービスを初期化し、BOMとヘッダ行を出力する。
5. 申込一覧の検索条件セッション`admin.event_entry.search`をフォームに流し込み、ソートを`default`・並び順を`ASC`に固定する。
6. 検索モードが`registedDeck`でなければプレイヤー（申込プレイヤー）起点のクエリ、`registedDeck`であればデッキ起点のクエリで対象データを取得する。
7. 対象行ごとに、申込プレイヤー・イベント申込・プレイヤー・イベント詳細・デッキ・イベントの関連を解決し、CSV出力項目に合致する値を1行ずつ出力する。
8. ファイル名`event_entry_<YmdHis>.csv`を添付名としてレスポンスを送出し、ファイル名をログに記録する。

### 雛形CSVを出力する（`/%eccube_admin_route%/entry/entry_csv_template`）

1. 一括登録用ヘッダ定義の見出し行のみをBOM付きで1行出力する。
2. 添付名`event_entry.csv`でダウンロードする。区切り文字は`csv_export_separator`（確認値カンマ）を用いる。

## 集計条件

| 指標 | 集計の要点 |
|------|------------|
| 出力対象 | 申込一覧の検索条件セッションで絞り込んだイベント申込（申込プレイヤー単位）。イベント詳細指定時は当該詳細に絞る。 |
| 検索モード`registedDeck` | デッキ情報を起点に対象を取得する（申込プレイヤー起点ではない）。 |
| 並び順 | 出力時はソート`default`・昇順に固定する。 |
| 出力項目 | 申込CSV種別の出力項目定義に従う。 |

---

## 業務ルール・計算

| 項目 | 内容 |
|------|------|
| 出力項目の適用 | 申込CSV種別の定義に従って出力項目・並びを決める。各出力項目は申込プレイヤー・イベント申込・プレイヤー・イベント詳細・デッキ・イベントのいずれかから最初に非NULLで得られた値を採用する。 |
| 文字コード | BOMを先頭に付与する。区切り文字は`csv_export_separator`（確認値カンマ）。 |
| ファイル名 | 一覧・詳細指定とも`event_entry_<YmdHis>.csv`。雛形は`event_entry.csv`。 |

本機能は画面上の入力フォームを持たない。出力項目は申込CSV種別の定義による。本機能では金額計算・件数の丸めを行わない。

---

## データ整合性

| 観点 | 内容 |
|------|------|
| 一覧表示とCSV | CSVは申込一覧の検索条件セッションを再適用するため、直前に一覧で確定した絞り込みと同じ母集合を対象とする。並び順のみ出力用に固定する。 |
| 論理削除データ | 会員・プレイヤーはソフトデリート無効化により論理削除済みでも出力対象に含める。これは画面一覧の表示条件と異なり得る。 |
| 出力中の更新 | ストリーミング出力中の他者更新は保証しない。出力開始時点のクエリ結果を正とする。 |

---

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 申込一覧の検索条件セッション。イベント詳細指定時はパスの`{eventDetailId}`。 |
| 成功時出力 | イベント申込情報のCSVファイル（申込CSV種別の項目）。 |
| 失敗時出力 | 認証・権限不足時は出力しない。 |
| 副作用 | ファイル名の情報ログ出力のみ（参照・出力）。 |

## DBカラム

機能に直接関係する列のみ記載する。型や一覧の細部はスキーマを参照する。列名はec-cube-enterpriseを正とし、現行（pf-eccube3）と異なる場合は現行名を括弧で添える。

| テーブル | 列 | メモ |
|---------|-----|------|
| `dtb_event_entry` | `id`（現行`event_entry_id`）、`event_detail_id`、`payment_id`、`price`、`payment_no`、`entry_status_id`、`paying_customer_id` | 申込の出力元。 |
| `dtb_entry_player` | `id`（識別列）、`event_entry_id`、`player_id`、`confirm_flg`、`seat_order` | 申込プレイヤーの出力元。出力は申込プレイヤー単位。 |
| 申込CSV種別の出力項目定義 | 出力項目・並び | 出力対象の列・順序を決める。 |

### DB操作

本機能は参照系（検索・出力）であり、DBへの登録・更新・削除は行わない。テーブル名は ec-cube-enterprise を正典とする。

| 操作種別 | 対象テーブル | 契機・条件 |
|---------|--------------|------------|
| 検索 | dtb_entry_player / dtb_event_entry | 検索条件に合致するレコードを抽出する。抽出結果を所定フォーマットでファイル出力する。 |

## 排他制御・トランザクション

本機能は参照・出力のみであり、楽観ロック・悲観ロックの対象は持たない。出力中はSQLロガーを無効化する。
