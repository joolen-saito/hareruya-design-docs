# イベント管理 — 日程追加

## 業務ロジック

### 追加の判定順序

| 順序 | 判定 | 結果 |
| --- | --- | --- |
| 1 | パスのイベントIDに一致するイベントが存在しないとき | ページが見つからない扱い（404）とする |
| 2 | なりすまし対策トークンが一致しないとき | アクセス拒否として処理を打ち切り、登録しない |
| 3 | 日程の入力検証に失敗したとき | 日程入力画面を、入力した値を保った状態で再表示する |
| 4 | 上記以外のとき | 追加した日程の日程編集画面を開く |

### 登録時に記録する値

入力欄では指定しないが、登録時に日程へ記録される。

| 記録する値 | 決め方 |
| --- | --- |
| 受付開始時間・受付終了時間の日付 | 開始時間の日付と、入力された時刻を組み合わせて記録する |
| 祝日かどうか | 開始時間の日付が祝日にあたるときは、祝日として記録する |
| 登録者 | 操作した管理ユーザを登録者として記録する |

## 入出力

### 受け取るものと返すもの

| 種類 | 内容 |
| --- | --- |
| 入力 | 追加先のイベントIDはパスで受け取る。日程の各項目となりすまし対策トークンは送信内容で受け取る |
| 成功時出力 | 追加した日程の日程編集画面 |
| 失敗時出力 | イベントが無いときは404。トークンが一致しないときはアクセス拒否。検証に失敗したときは日程入力画面の再表示 |

## 表示メッセージ

| メッセージID | 表示位置 | 画面上の文言 | 表示条件 | 後続処理 |
| --- | --- | --- | --- | --- |
| M13-03-MSG-001 | 管理画面上部 | 保存しました | 日程追加の内容を保存したとき | 日程編集画面に遷移する |
| M13-03-MSG-002 | 管理画面上部 | 保存に失敗しました | 日程追加の保存中にエラーが起きたとき | 日程入力画面に留まる |
