# イベント管理 — 日程追加

## 業務ロジック

### 追加の判定順序

| 順序 | 判定 | 結果 |
| --- | --- | --- |
| 1 | パスのイベントIDに一致するイベントが存在しないとき | ページが見つからない扱い（404）とする |
| 2 | 日程の入力検証に失敗したとき | 日程入力画面を再表示する |
| 3 | 上記以外のとき | 当該イベントの日程を新規に作成して保存し、日程編集画面へ遷移する |

対象はパスで指定したイベントとする。登録するのは検証に通った内容だけとする。保存中にエラーが起きたときは、日程入力画面に留まる。

### エラー時の扱い

| 事象 | 扱い |
| --- | --- |
| イベントが存在しないとき | ページが見つからない扱い（404）とする |
| 日程の入力検証に失敗したとき | 日程入力画面を再表示する |
| 保存中にエラーが起きたとき | 保存に失敗した旨を表示し、日程入力画面に留まる |

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | イベントID、日程の各項目、なりすまし対策トークン |
| 成功時出力 | 日程の登録と、日程編集画面への遷移 |
| 失敗時出力 | イベントが無いときは404。検証に失敗したときは入力画面を再表示する |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 追加 | 検証に通ったときの、対象の催しに紐づく日程1件 |

## 表示メッセージ

| メッセージID | 表示位置 | 画面上の文言 | 表示条件 | 後続処理 |
| --- | --- | --- | --- | --- |
| M13-03-MSG-001 | 管理画面上部 | 保存しました | 日程追加の内容を保存したとき | 日程編集画面に遷移する |
| M13-03-MSG-002 | 管理画面上部 | 保存に失敗しました | 日程追加の保存中にエラーが起きたとき | 日程入力画面に留まる |
