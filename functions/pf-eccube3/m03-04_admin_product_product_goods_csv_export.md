# 商品管理 — グッズ商品CSV出力

## 概要

管理画面の「商品管理」商品一覧でチェックした商品 ID を対象に、グッズ商品登録 CSV と同一レイアウトの列（日本語ヘッダ名・データ列）を並べた CSV をダウンロード応答として返す機能である。カスタム CSV（店舗設定の列並び）とは別経路であり、列集合はコントローラ内のヘッダー定義で固定される。出力対象は「カード詳細が紐付いていない商品」に限り、各商品の規格が 1 件以上ある場合に規格行として展開する。

本書は実装手順ではなく、誰が・いつ・どの条件で・結果どうなるかを読むためのリバース詳細設計とする。ec-cube-enterprise のコア実装を確認値とする。

本機能のカスタマイズ区分は「カスタマイズ」であり、出力挙動・列構成の参照は現行リポ（pf-eccube3）、DB関連（テーブル名・列名・参照元）は ec-cube-enterprise を正とする。

対象はブラウザ経由の管理画面に限定する。

コントローラのメソッド名は本文の主題としない。本文ではルートbind名やSymfonyのルートnameの網羅は主説明としない。「利用者視点の入口」にHTTPメソッドとサイトルートからのパスパターンを書く。コード探索でbind名が必要なときだけ「調査補助」へ書く。

## リニューアル移行時の扱い

現行（pf-eccube3）と移行先（ec-cube-enterprise）で、CSV列の取得元となる永続化スキーマに次の差がある。出力挙動・列構成は現行を正とし、DB列名・参照元は移行先を正とする。

| 対象 | 現行（pf-eccube3） | 移行先（ec-cube-enterprise） |
|------|----------------------|--------------------------------|
| 商品名(英)・各説明(英・買取)・略称タグ・購入グループ・サイズ・重量・カードセット(ID) | 別テーブル `dtb_product_sub` から取得 | `dtb_product` 本体へ統合（`name_en`・`description_detail_en`・`buy_description_detail`・`buy_description_detail_en`・`storage_code_id`・`sell_group_id`・`size`・`weight`・`cardset_id`）。`dtb_product_sub` は存在しない |
| 出力対象の判定（カード詳細の有無） | `dtb_card_detail` の関連有無で判定 | `dtb_product.card_detail_id`（カード詳細マスタ `mtb_card_detail` 参照）の有無で判定 |
| タグ(ID) | `dtb_product_tag.tag` | `dtb_product_tag.tag_id` |
| 部門ID | 規格に紐づく部門参照 | `dtb_product_class.section_id`（部門マスタ `mtb_section`） |

商品コード（`dtb_product_class.code`）・各価格列・スマレジ連携フラグ（`smaregi_alignment_flg`）・スマレジ商品コード（`smaregi_product_code`）は現行と移行先で同一スキーマである。

|------|--------------------|---------------------|

## 処理フロー

### CSV をダウンロードする（POST `m03-04_admin_product_product_goods_csv_export`）

1. 管理画面の認証・共通制約を通過する。
2. リクエストボディから `ids` を取得する。配列でない場合は空配列とみなす。各要素を整数化し、0 より大きい ID だけを残してインデックスを振り直す。
3. 有効な ID が 1 件も無いとき、`responseNoProductIdError` を返す。セッションキー `eccube.admin.product.search.page_no` があればその値をページ番号として `admin_product_page` へリダイレクトし、無ければ既定値 1 を使う。フラッシュは `addError` の基底実装どおり、`eccube.` +（第 2 引数として渡された文字列）+ `.error` を種類キー、第 1 引数文字列を本文とする。この呼び出しでは第 1 引数が `eccube.admin.error` であり、第 2 引数が `admin.product.not_select` の翻訳文言である（表示上の読みどおりとは逆順に見えるが、実装を確認値とする）。
4. PHP の実行時間制限を無効にする（`set_time_limit(0)`）。
5. ORM の SQL ロガーを無効にする。
6. リポジトリで `id` が指定集合に含まれる商品を取得する。リクエスト配列が空でないときに取得結果も空ならば、翻訳キー `admin.csv.error.export.not_registered` をメッセージとする実行時例外を送出する。（`empty($productIds)` は手順 2 で弾かれているため、この分岐は主にすべて存在しない ID のときである。）
7. 取得した各行データをコンバートする。カード詳細が関連付けられている商品はスキップする。規格が 0 件の商品もスキップする。
8. スキップの結果、出力行が 1 行も無ければ、翻訳キー `admin.csv.error.export.no_goods_data` をメッセージとする実行時例外を送出する。
9. 残った商品ごとに共通列を組み立て、各規格について行を複製し規格依存列を上書きする。タグ ID は一意化後にカンマ連結、カテゴリ ID もカンマ連結（`StringUtil::meldStrings`）、売上分析タグは ID をカンマ連結、商品画像ファイル名はカンマ連結する。「規格画像」列には商品側の画像コレクションのファイル名が入り、一覧の規格単位画像とは異なるソースである。
10. `StreamedResponse` のコールバック内で CSV 出力サービスを開き、ヘッダ行（手順 9 より前に渡しているヘッダー定義のキー順）、続いてデータ行を `fputcsv` で書き、閉じる。欠損キーがあるセルは空文字とする。
11. ファイル名は接頭辞 `product_goods_` と日時（`YmdHis`）と拡張子 `.csv` を連結する。
12. 応答ヘッダに CSV 向けの `Content-Type`（設定 `eccube_csv_export_encoding` に応じた charset。値が `SJIS-win` のときは MIME 上は `windows-31j` に読み替え）と `Content-Disposition: attachment` を付与する。
13. ストリーム送信後（コールバック内で送信処理が走ったあと）、情報ログにメッセージ「グッズ商品CSV出力ファイル名」とファイル名が記録される。

### 実行時例外が送出されたとき（手順 6・8・その他）

1. コントローラは例外メッセージのみをフラッシュに積み、フラッシュ名前空間の第 2 引数は付けない。基底実装では名前空間の既定があるため、その既定に従う（実装を確認値とする）。
2. `Referer` ヘッダが空でなければその URL へリダイレクトする。
3. `Referer` が空なら `redirectToRoute('admin_product_page')` でリダイレクトする（ルート生成時の `page_no` はコントローラから渡していない）。

## 集計条件

本機能では売上集計や件数サマリは行わない。出力対象は POST で明示された商品 ID のうち、リポジトリで取得でき、かつカード詳細が無く、かつ規格が 1 件以上ある商品である。

## 出力列とデータの対応（業務ルール）

## 業務ルール・計算

| 項目 | 内容 |
|------|------|
| 行の複製単位 | 商品につき `getProductClasses()` の反復ごとに 1 行。規格コレクションの順序は実装に依存し、一覧の表示順（言語・状態で絞った表示用サブセット）とは一致しない。画面は言語・カード状態が揃った規格だけ一覧に出すが、CSV は全規格を走査する。 |
| 一部 ID が DB に無い場合 | 取得できた商品だけが出力対象となり、存在しない ID は静かに無視される。すべて無効・または取得結果が空なら `admin.csv.error.export.not_registered` となる。 |
| カード詳細が付いた商品のみを選んだ場合 | コンバート結果が空となり `admin.csv.error.export.no_goods_data` となる。カード詳細ありと無しが混在すれば後者のみ行が出力される。 |
| 規格 0 件のみ選んだ場合 | 同様に `admin.csv.error.export.no_goods_data` に至りうる。 |

本機能では永続フォームの入力項目検証（最大長・必須）は持たない。POST で渡る論理入力は次のとおり整理する。

### 入力項目

| 項目名 | 必須／任意 | 最大長 | 初期値 | 保存先・扱い |
|--------|------------|--------|--------|----------------|
| 商品一覧のチェックボックス | 実質必須（1 件以上の正の商品 ID がサーバに残ること） | — | 一覧の選択状態 | POST パラメータ `ids[]`。整数化後 0 以下は破棄。DB やセッションには書き込まない。 |

### エッジケース

| ケース | 扱い |
|--------|------|
| `ids` 未送信・空・文字列のみ | 商品一覧へリダイレクト（ページ番号はセッションの検索ページ）。 |
| 存在しない ID のみ | `admin.csv.error.export.not_registered`。 |
| カード詳細あり、または規格 0 件のみ | 変換結果が空になり `admin.csv.error.export.no_goods_data`。混在時は該当商品だけスキップ。 |
| 複数規格 | 同一商品 ID で行が複製される。 |
| Referer 欠落かつエラー | `redirectToRoute('admin_product_page')`。生成 URL はルータ定義に依存する。 |

| 観点 | 内容 |
|------|------|
| 一覧との対応 | 出力対象は一覧でチェックした商品 ID のみである。検索ヒット全件を自動では出力しない。 |

| 商品の並び | `findBy(['id' => $productIds])` の戻り順に依存し、利用者が一覧で選んだ順序の再現は保証しない。 |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | `POST`。ボディに `ids[]`（商品 ID の配列）。 |
| 成功時出力 | `text/csv` のストリーム。ファイル名は `product_goods_YmdHis.csv`。エンコーディングが UTF-8（大文字区別なく比較）のとき BOM を先頭に付与する。フィールド値は UTF-8 から設定の出力エンコーディングへ変換したうえで `fputcsv` により出力され、区切り文字は設定 `eccube_csv_export_separator`、エンクロージャは `"`、エスケープは `\` とする実装である。 |
| 失敗時出力 | フラッシュメッセージ付きで商品一覧または Referer へ HTTP リダイレクト。 |
| 副作用 | 読み取りクエリとログ出力のみ。商品や規格を更新しない。 |

## DBカラム

出力はエンティティ経由であり、参照される主な論理テーブルは次のとおりである。列の網羅と型はマッピングを参照する。

| テーブル | 列（概念） | メモ |
|---------|------------|------|
| `dtb_product` | 名称、商品名(英)、説明、検索ワード、ステータス、カードセット（`cardset_id`）、各種マスタ FK、画像・カテゴリ・タグ関連など | 商品共通列の源泉。カード詳細 FK（`card_detail_id`）が無いことを出力条件として用いる。移行先は現行 `dtb_product_sub` の付加情報を本体へ統合している。 |
| `dtb_product_class` | 言語（`language_id`）、商品コード（`code`）、価格、販売制限、発送目安（`delivery_duration_id`）、スマレジ関連（`smaregi_alignment_flg`・`smaregi_product_code`）、部門（`section_id`）など | 行複製単位。 |
| 関連マスタ・中間 | カテゴリ、タグ（`tag_id`）、売上分析タグ、画像など | ID 連結や名称解決に利用。 |

### DB操作

本機能は参照系（検索・出力）であり、DBへの登録・更新・削除は行わない。テーブル名は ec-cube-enterprise を正典とする。

| 操作種別 | 対象テーブル | 契機・条件 |
|---------|--------------|------------|
| 検索 | dtb_product / dtb_product_class / dtb_product_sub | 検索条件に合致するレコードを抽出する。抽出結果を所定フォーマットでファイル出力する。 |

## 画面遷移

| 条件 | 遷移先 |
|------|--------|

## ログ・監査

| タイミング | 記録内容 |
|------------|----------|
| CSV 出力ストリーム送信後 | 情報ログに「グッズ商品CSV出力ファイル名」と生成ファイル名。 |

### ログに出してはいけないもの

- パスワード
- CSRF トークン原値
- セッション ID の完全値
- クッキー値

---

## セッション

### 本機能におけるセッション

| 観点 | 内容 |
|------|------|
| 読み取り | 商品 ID 未選択時のリダイレクト先ページ番号として `eccube.admin.product.search.page_no` を参照する。 |
| 書き込み | CSV 出力処理はセッションを更新しない。 |

### セッションへ保存しない情報

出力 CSV の本文や全行バッファをセッションに載せない。

---

## Cookie

本機能専用の Cookie を新設しない。管理画面のセッション Cookie に従う。

---

## 排他制御・トランザクション

参照クエリとストリーム出力のみであり、本機能単体ではトランザクションを開始しない。

---

## 調査補助（grep・参照用）
