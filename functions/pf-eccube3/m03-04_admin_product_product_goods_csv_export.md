# 商品管理 — グッズ商品CSV出力

## 業務ロジック

### 出力対象の決め方

商品一覧で選択した商品IDを受け取る。各値を整数として扱い、0より大きい値だけを対象とする。有効な商品IDが1件も無いときは出力せず、商品一覧へ戻す。戻り先のページ番号は保持している商品検索のページ番号、無ければ1とする。

指定した商品IDのうち存在しないものは無視し、取得できた商品だけを出力する。指定が1件以上あるのに商品を1件も取得できないときは出力せずエラーとする。

### 出力しない商品

カード詳細が関連付けられている商品と、規格が0件の商品は出力しない。この除外の結果、出力行が1行も無いときはエラーとする。カード詳細ありと無しが混在するときは、カード詳細が無い商品だけが出力される。

### 行の単位

1商品につき規格の数だけ行を複製し、規格ごとに規格依存列を上書きする。規格の並びは一覧の表示順とは一致しない。画面は言語・カード状態が揃った規格だけを一覧に出すが、CSVは全規格を出力する。

### 値の作り方

タグIDは重複を除いたうえでカンマ連結する。カテゴリID・売上分析タグID・商品画像ファイル名もカンマ連結する。「規格画像」列には商品側の画像のファイル名が入り、一覧の規格単位画像とは別の値である。欠損しているセルは空文字とする。

### ファイル名

接頭辞 product_goods_ と実行日時（年月日時分秒）と拡張子 .csv を連結する。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| 有効な商品IDが1件も無い | 出力せず商品一覧へ戻す（ページ番号は保持値） |
| 指定IDに対応する商品が1件も無い | 出力せずエラーとし、直前画面があればそこへ、無ければ商品一覧へ戻す |
| 除外の結果、出力行が0行 | 同上 |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 商品IDの配列 |
| 成功時出力 | CSVのダウンロード。ファイル名は product_goods_（実行日時）.csv。出力エンコーディングがUTF-8のときは先頭にBOMを付ける。区切り文字と囲み文字は出力設定に従う |
| 失敗時出力 | エラーメッセージを表示し、商品一覧または直前画面へ戻す |

### 出力: 商品単位で共通し、同一商品の複数規格行で繰り返される列

| 列名（ヘッダ） | 内容 |
|----------------|------|
| 商品ID | 商品の識別子。 |
| 商品公開ステータス | 公開ステータスマスタのID。 |
| 支店の商品公開ステータス | 支店公開の真偽を整数化した値。 |
| 商品名(日) | 商品名（日本語）。 |
| 商品名(英) | 商品名（英語）。 |
| サイズ | サイズ文字列。 |
| 重量 | 重量。 |
| 商品説明(日) | 詳細説明（日本語）。 |
| 商品説明(英) | 詳細説明（英語）。 |
| 買取商品説明(日) | 買取向け説明（日本語）。 |
| 買取商品説明(英) | 買取向け説明（英語）。 |
| 検索ワード | 検索ワード。 |
| 規格画像 | 商品に紐付く商品画像のファイル名をカンマ連結。列名は規格画像だが、値は商品側の画像から取る。 |
| 商品カテゴリ(ID) | 関連カテゴリIDをカンマ連結した文字列。 |
| 購入グループ名称 | 購入グループマスタの名称。未設定なら空文字。 |
| 略称タグ(ID) | 略称タグのID。未設定なら空文字。 |
| 売上分析タグ(ID) | 売上分析タグのIDをカンマ連結。 |
| タグ(ID) | タグIDを一意化のうえカンマ連結。 |
| カードセット(ID) | 商品のカードセットID。 |
| 地域別販売制限 | 地域別販売制限マスタのID。未設定なら空文字。 |
| フリーエリア | フリーエリア文字列。 |

### 出力: 規格ごとに変わる列（1規格につき1行）

| 列名（ヘッダ） | 内容 |
|----------------|------|
| 商品コード | 規格の商品コード。 |
| 言語(ID) | 規格の言語マスタID。未設定なら空文字。 |
| 発送目安(ID) | 規格の発送日目安マスタID。未設定なら空文字。 |
| 販売制限数 | 規格の販売制限数。 |
| 基準価格 | 規格の基準価格。 |
| 販売価格 | 規格の販売価格。 |
| 買取価格 | 規格の買取価格。 |
| 原価単価 | 規格の原価単価。 |
| スマレジ連携フラグ | 規格の連携フラグが真なら 1、偽なら 0。 |
| スマレジ商品コード | 規格のスマレジ商品コード。未設定は空文字。 |
| 部門ID | 規格に紐付く部門マスタID。未設定なら空文字。 |

ヘッダ行の並びはグッズ商品登録CSVのヘッダ定義の順であり、データ行も同じ順で値を並べる。

### 入出力: 永続化

本機能は業務データを更新しない。
