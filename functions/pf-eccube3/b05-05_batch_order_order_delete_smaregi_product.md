# バッチ 受注管理 — スマレジ商品削除

## 業務ロジック

### 起動時の指定

| 判定 | 結果 |
|------|------|
| コマンド名が未指定、または本バッチのコマンド名と一致しないとき | 連携を行わずに終了する。実行日時を添えて、引数またはコマンドが無い旨をコンソールへ出力し、異常終了として扱う |

起動するコマンドは `order:batch` で、第1引数にバッチ名 `deleteSmaregiProduct` を指定する。バッチ名が未指定・不一致のときにコンソールへ出す文言は「Nothing args or command.」で、このときの終了コードは1である。

### 対象が無いとき・連携が失敗したときの続き

| 状況 | ふるまい |
|------|----------|
| 対象が1件も無いとき | 連携を行わずに完了する |
| スマレジから応答が返らない、または応答に結果が含まれないとき | その受注の連携を失敗として扱う |
| ある受注の連携が失敗したとき | その受注は連携済みとして扱わないまま次の受注へ進み、残りの受注の連携は続ける |
| 連携に失敗した受注 | 対象の条件に当てはまる限り、次回以降の実行でも再び対象になる |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | コマンド名 |

### 入出力: 永続化

| 対象 | 内容 |
|------|------|
| 連携が失敗したとき | 何も更新しない。失敗した事実を残す更新も行わないため、後から失敗した受注を抽出することはできない |

### 連携失敗の通知

| 状況 | 内容 |
|------|------|
| 通知先のメールアドレスが設定されていないとき | 通知を行わない（連携の失敗は誰にも伝わらない） |
| 通知するとき | 注文番号・処理名・エラーコード・スマレジから返ったエラーの内容を載せる |
| 通知するとき | エラーコードの先頭の数字で、認証の失敗・設定の失敗・データの誤り・それ以外の例外を区別して知らせる |

通知するときの本文の先頭の文は、エラーコードの先頭1桁が次の値のとき、それぞれ次の文になる。

| エラーコードの先頭1桁 | 本文の先頭の文 |
| --- | --- |
| 1 | スマレジとの認証に失敗しました。 |
| 2 | スマレジの設定に失敗しました。 |
| 3・4 | データエラーが発生しました。 |
| 上記以外 | 例外エラーが発生しました。 |

## 表示メッセージ

本バッチは画面を持たず、利用者向けの文言を持たない。
