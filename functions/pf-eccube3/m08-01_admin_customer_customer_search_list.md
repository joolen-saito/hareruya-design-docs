# 会員管理 — 会員検索/一覧

## 業務ロジック

### 検索条件

| 画面上の項目 | 検索条件 |
| --- | --- |
| フリーワード | 会員ID・メールアドレス・お名前を横断して検索する。最大255文字 |
| 退会区分 | 会員の退会理由への部分一致。最大256文字 |
| 都道府県（複数）・MTG Companion登録本名・DCIナンバー・DCI確認フラグ・国・買取総額範囲・買取件数範囲・本人確認ステータス | 標準の会員検索に追加する条件 |

### 初期表示と検索条件の保持

初期表示でページ番号の指定も再開指定も無いときは、保持していた検索条件・ページ番号・表示件数を破棄する。ページ番号の指定または再開指定があるときは、保持した検索条件を復元して該当ページを表示する。会員編集から検索画面へ戻る導線は、保持したページ番号と再開指定を使う。

検索を実行したときは、検索条件とページ番号を保持する。

### 表示件数

指定された表示件数は、表示件数マスターに存在する値のときだけ採用し、以降のページ送りに引き継ぐ。存在しない値は無視する。

### 検索パターン

検索パターンは会員一覧の画面キーで区別する。保存では、パターン名が空のときは保存しない。パターンの識別子の指定があれば既存パターンを更新し、無ければ新規に作成する。保存後は保存した条件で一覧を表示する。

呼び出しでは、保存済みの条件を復元して保持し、1ページ目の一覧を表示する。指定したパターンが存在しないときは該当なし（404）として扱う。

削除では、なりすまし対策トークンを検証する。指定したパターンが無いときは削除せずエラーを表示し、検索結果を再表示する。削除できたときは会員一覧へ戻る。

### 一覧の操作導線

| 一覧上の導線 | 遷移先 |
| --- | --- |
| 会員IDと編集 | 会員編集 |
| 削除 | 会員削除 |
| メール通知 | 手動メール通知 |
| メール履歴 | メール送信履歴 |
| CSVダウンロード | 会員CSV出力 |
| 仮会員メール再送 | 仮登録メールの再送。会員種別が仮会員（ステータスID1）のときだけ出す |

### フェーズ2対応（フェーズ1では実装しない）

- Excel基本設計 0207「顧客分析タグ（検索条件・一覧表示）」はフェーズ2対応。フェーズ1では実装しない（この項目だけ）。Excel原文: 「※顧客分析タグ登録はPh2で対応するため、Ph1では実装しない」

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| 検索条件の検証失敗 | 一覧を空で再表示する |
| 検索パターン名未入力で保存 | エラーを表示し、検索結果を再表示する |
| 削除対象のパターンなし | エラーを表示し、検索結果を再表示する |
| 存在しないパターンの呼び出し | 該当なし（404）として扱う |
| 並び順の不正値 | 並び順のエラーを表示し、初期表示へ戻す |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 検索条件、ページ番号、表示件数、検索パターンの識別子 |
| 成功時出力 | 検索結果一覧と該当件数。検索パターンの保存・削除の完了メッセージ |
| 失敗時出力 | 検証失敗時は空の一覧の再表示。パターン名未入力・削除対象なしはエラー表示。存在しないパターンの呼び出しは該当なし（404） |

### 入出力: 永続化

会員データは更新しない。検索パターンは保存・削除の対象である。

| 操作 | 契機 |
| --- | --- |
| 登録・更新 | 検索パターンの保存 |
| 削除 | 検索パターンの削除 |
