# m03-34_admin_product_product_discount_csv_import（管理画面_商品管理_割引率変更CSV登録）

## 業務ロジック

### 画面の初期表示

割引率変更用のヘッダ（「商品ID」「割引率(ID)」および説明）を画面に示す。取込履歴は、取込種別が割引率変更の履歴だけを作成日時の降順で最大100件表示する。削除済みの履歴も表示対象に含める。

### 雛形

雛形は割引率変更用のヘッダのキー名だけを1行書いたCSVを返す。区切り文字は出力設定に従い、先頭にUTF-8のBOMを付ける。ファイル名は product_discount.csv とする。

### 取込の前提

CSVは1行目をヘッダ、2行目以降をデータとする。ファイルは必須である。囲み文字の中を除いて改行を数え、行数が5010以上のときは取り込まず件数超過のエラーとする。この数え方はヘッダ行を含む。

### 取込時の判定順序

| 順序 | 判定 | 結果 |
|------|------|------|
| 1 | 入力（なりすまし対策トークン・ファイルの必須・種類・サイズ上限） | 失敗時はエラーを表示し、同じ画面を再表示する |
| 2 | 行数が5010以上か | 該当時はエラーを表示し、同じ画面を再表示する |
| 3 | ヘッダ行とデータ行の有無 | 失敗時は取込結果のエラーを表示する（完了メッセージは出さない） |
| 4 | 各行の列数が2で、ヘッダ名の列があるか | 失敗時はエラーを蓄積して取込を打ち切り、更新を取り消す |
| 5 | 商品IDと割引率IDの形式、割引率がマスタに存在するか | 同上 |
| 6 | 商品が未削除で存在するか | 同上 |

### 更新の内容

CSVの1データ行が1商品に対応する。規格単位の分割は無い。更新するのは割引率だけで、他の項目は既存値を維持する。移行先では商品の割引率を、現行では商品サブ情報の割引率を更新する。価格は再計算しない。

同一ファイル内で同じ商品IDが複数回出たときは順に上書きし、最終行の値が残る。支店への通知に載せる商品IDの一覧は重複を除く。

エラーが無いときだけ確定し、完了メッセージを表示して取込履歴を1件残す。履歴にはファイル名と取込種別と実行した管理者を記録する。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| 入力の不正 | エラーを表示し、同じ画面を再表示する |
| 行数超過 | エラーを表示し、同じ画面を再表示する |
| CSV形式・ヘッダ・列・マスタ不一致・商品不存在 | エラーを表示し、更新を取り消す |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | CSVファイル（必須）。1行目ヘッダ、2行目以降データ |
| 成功時出力 | 同じ画面の再表示、完了メッセージ、取込履歴1件、支店への通知 |
| 失敗時出力 | 同じ画面の再表示とエラー。更新は取り消され、取込履歴は増えない |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 更新 | 取込した行の商品の割引率の上書き |
| 登録 | エラーなく取込が完了したときの取込履歴 |
