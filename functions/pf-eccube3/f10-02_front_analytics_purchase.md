# フロント アクセス解析 — 購入完了の売上連携

## 業務ロジック

### 連携の仕組み

| 担い手 | 範囲 |
| --- | --- |
| 当機能 | 注文完了画面で売上の値を、ページ内の受け渡し領域（`dataLayer`）へ積むところまでを担う |
| タグの管理サービス（Googleタグマネージャ） | 受け渡し領域を読み、アクセス解析（Googleアナリティクス）へ送る。送る内容はタグの管理サービス側の設定だけで決まる |
| 受け渡し領域がまだ無いとき | 空の領域を用意してから積む |
| 受け渡し領域がすでにあるとき | 既存の内容を残し、末尾へ足す |

### 積む契機

| 観点 | 扱い |
| --- | --- |
| 契機 | 購入処理が完了し、注文完了画面を表示するときだけ積む。購入処理が途中で止まった場合は積まない |
| 回数 | 注文完了画面の表示1回につき1件 |
| 言語 | 日本語サイトのときも英語サイトのときも、同じ項目名で積む |
| 積む位置 | ページの先頭部（head）。ページごとのレイアウト設定で先頭部へ置くブロックより前に積む |

### 積む値

| 項目名 | 値 | 形式 |
| --- | --- | --- |
| `transactionId` | 受注ID。8桁に満たないときは、8桁になるまで左を0で埋める。8桁を超えるときはそのまま | 文字列 |
| `transactionAffiliation` | 受注の1件目のお届け先に設定された配送方法の名称。お届け先が複数ある場合も1件目だけを使う | 文字列 |
| `transactionTotal` | 受注の商品小計。税込単価に数量を掛けた金額を、受注明細の全行について合計した金額 | 文字列 |
| `transactionTax` | 常に0。消費税がかかる注文のときも0のまま | 数値 |
| `transactionShipping` | 受注の送料合計 | 文字列 |
| `transactionMailaddress` | 注文完了画面を表示した時点でログインしている会員のメールアドレス。受注に保存されたメールアドレスは使わない | 文字列 |
| `transactionProducts` | 受注明細ごとの商品の値の並び。下表のとおり | 配列 |

上の7項目は、1つの要素にまとめて積む。項目ごとに別の要素へ分けない。入れ子になるのは `transactionProducts` だけである。

`transactionTotal` は税込の商品小計だけを積む。送料・手数料・値引き・ポイント利用があるときも、それらを反映した支払合計にはしない。

### 商品の値

`transactionProducts` は、受注明細1行につき1件を、受注明細の並び順で並べる。1件は下表の5項目を持つ要素である。

| 項目名 | 値 | 形式 |
| --- | --- | --- |
| `sku` | 受注明細の商品コード | 文字列 |
| `name` | 受注明細の商品名 | 文字列 |
| `category` | 常に空文字。商品にカテゴリが設定されている場合も空のまま | 文字列 |
| `price` | 受注明細の税抜の単価 | 文字列 |
| `quantity` | 受注明細の数量。同じ商品が別の行にあるときも、行ごとの数量のまま積む | 文字列 |

`price` は税抜、`transactionTotal` は税込である。消費税がかかる注文のときは、`price` に `quantity` を掛けた金額の合計と `transactionTotal` は一致しない。

商品名などに日本語を含むときは、文字コードの置き換え表記（`\uXXXX`）にせず、そのままの文字で出力する。

### エッジケース

| ケース | 扱い |
| --- | --- |
| 受注明細が複数行のとき | 明細の行数ぶん、商品の値を並べる。同じ商品が別の行にあるときもまとめない |
| お届け先が複数あるとき | 1件目のお届け先の配送方法の名称だけを積む |
| 送料が0円のとき | `transactionShipping` は0を積む |
| ポイントを利用した注文 | `transactionTotal` は商品小計のままで、利用ポイントを差し引かない |
| 注文完了画面を再読み込みしたとき | 注文完了画面を1回表示した時点で購入処理中の受注の控えを消すため、再読み込みするとTOP画面へ移動し、値を積まない |
| 会員としてログインしていない状態で注文完了画面を表示したとき | `transactionMailaddress` は空文字を積む。注文時に入力したメールアドレスは積まない |
| 消費税 | 税額にかかわらず `transactionTax` は0を積む |

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | 購入処理が完了した受注（受注ID、商品小計、送料合計、1件目のお届け先の配送方法、受注明細）と、ログインしている会員のメールアドレス。購入処理が完了した受注が無いときは受け取らない |
| 出力 | 注文完了画面の先頭部に埋め込むスクリプト。注文完了画面を表示するときだけ出力する |

### 入出力: 永続化

受注・会員などの業務データを、当機能としては登録・更新・削除しない。受注の確定は注文の機能（F04-04）が行う。

## 表示メッセージ

本機能は画面へ文言を表示しない。
