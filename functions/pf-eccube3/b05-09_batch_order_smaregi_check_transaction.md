# バッチ 受注管理 — スマレジ取引連携エラー再連携

## 業務ロジック

### 取引情報の取得

スマレジ接続設定（接続先URL等）をオプションマスタから取得する。現在時刻を基準に取引参照のパラメータを組み立て、スマレジの取引参照を呼び出す。取得に失敗したときは失敗内容をログとコンソールに出力し、異常終了（戻り値1）する。取得結果が空のときは何もせず正常終了する。

### 連携の更新

取得結果があるときは、取引情報をもとに対応するスマレジ取引の連携を更新する。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| 実行時の指定が本バッチと一致しない | 処理を行わずに終了する |
| 取引情報の取得失敗 | 失敗内容をログ・コンソールに出力し異常終了する |
| 取得結果が空 | 何もせず正常終了する |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | バッチの実行指定、スマレジ接続設定 |
| 成功時出力 | 取引連携の更新。結果が空のときは更新なし |
| 失敗時出力 | 取得失敗内容のログ・コンソール出力（異常終了） |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 更新 | 取引情報を取得できたとき、対応するスマレジ取引の連携を更新する |
