# バッチ 受注管理 — スマレジ取引連携エラー再連携

## 概要

スマレジの取引情報を取得し、連携エラーが起きているスマレジ取引の連携をやり直すバッチである。コマンドライン（コンソールコマンド）から実行する。スマレジの取引参照APIを呼び出し、取得した取引情報をもとに連携状態を更新する。

本書は実装手順ではなく、誰が・いつ・どの条件で・結果どうなるかを読むためのリバース詳細設計とする。確認値はpf-eccube3（EC-CUBE3系）のHareruyaEcプラグインのスマレジバッチ（取引連携エラー再連携処理）、スマレジ接続設定のオプションマスタ、取引参照APIの呼び出し処理を正とする。

カスタマイズ区分は現行踏襲であり、挙動はpf-eccube3を参照し、DB関連の記述はec-cube-enterpriseを正とする。

対象はコンソールコマンドであり、ブラウザ経由の画面を持たない。

本文ではフレームワークのコマンド型名やサービス型名を主説明としない。実行はコンソールのバッチコマンドで行う。

## リニューアル移行時の扱い

取引取得・更新の挙動は現行pf-eccube3を踏襲し、DB関連の永続化先はec-cube-enterpriseを正とする。取得した取引情報はポイント履歴と会員ポイントへ反映する。

| 観点 | 現行（pf-eccube3） | 移行先（ec-cube-enterprise） |
|------|--------------------|------------------------------|
| 取引取得・更新の挙動 | スマレジ取引参照APIで取得し、取引IDに対応するポイント履歴・会員ポイントを登録・取消する。 | 同等の挙動を踏襲する（挙動はpf-eccube3を正とする）。 |
| スマレジ接続設定の保持 | オプションマスタ（`mtb_option` の `option_key`・`option_value`）。 | 同一スキーマ（`mtb_option` の `option_key`・`option_value`）。 |
| ポイント履歴・会員ポイントの永続化先 | `dtb_point_history`（`transaction_id`・`point_change` 等）・`dtb_player`（`point`）。 | 同一スキーマ。 |

---

## 処理フロー

### スマレジ取引連携エラー再連携を実行する（`smaregi:batch checkSmaregiTransaction`）

1. スマレジ接続設定（接続先URL等）をオプションマスタから取得する。
2. 現在時刻を基準に取引参照のパラメータを組み立て、スマレジの取引参照APIを呼び出す。
3. 取得に失敗した場合は、失敗内容をログとコンソールに出力して異常終了する。
4. 取得結果が空の場合は正常終了する。
5. 取得結果がある場合は、取引情報をもとにスマレジ取引の連携を更新する。

## API/バッチ結果

| 種類 | 内容 |
|------|------|
| バッチ | 入力はコマンド名。成功時は取得した取引で連携を更新する。結果が空なら何もせず完了する。取得失敗時は異常終了（戻り値1）する。 |
| API | スマレジの取引参照APIを呼び出し、取引情報を取得する。 |

---

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | コマンド名、スマレジ接続設定。 |
| 成功時出力 | 取引連携の更新。結果が空のときは更新なし。 |
| 失敗時出力 | 取得失敗内容のログ・コンソール出力（異常終了）。 |
| 副作用 | スマレジ取引連携の更新。 |

## DBカラム

機能に直接関係する列のみ記載する。型や一覧の細部はスキーマを参照する。

| テーブル | 列 | メモ |
|---------|-----|------|
| `mtb_option`（オプションマスタ） | `option_key`・`option_value` | スマレジ接続設定（接続先URL・契約ID・アクセストークン等）を保持し、API呼び出しに使用する。 |
| `dtb_point_history`（ポイント履歴） | `transaction_id`・`point_change`・`point_type_id` | 取得した取引でポイント履歴を登録・取消する。 |
| `dtb_player`（選手情報） | `point` | 取引に応じて会員ポイント残高を更新する。 |

### DB操作

本機能は参照系（検索）であり、DBへの登録・更新・削除は行わない。テーブル名は ec-cube-enterprise を正典とする。

| 操作種別 | 対象テーブル | 契機・条件 |
|---------|--------------|------------|
| 検索 | dtb_player / dtb_point_history / mtb_option | 検索条件に合致するレコードを抽出する。 |

## エラー処理

| エラー内容 | 処理 |
|------------|------|
| コマンド名が未指定・不一致 | 処理を行わずに終了する。 |
| 取引情報取得失敗 | 失敗内容をログ・コンソールに出力し異常終了する。 |
| 取得結果が空 | 何もせず正常終了する。 |
