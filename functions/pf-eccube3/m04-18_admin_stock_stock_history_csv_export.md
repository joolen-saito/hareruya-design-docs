# 在庫管理 — 在庫履歴CSV出力

価格・在庫一覧で保持した検索条件で、在庫変更履歴をCSVファイルとしてダウンロードする機能。

## 概要

在庫履歴CSV出力は、価格・在庫一覧画面（M04-17）の在庫一覧に表示している検索条件を再利用し、在庫変更履歴を1行1件のCSVとしてストリーム出力する機能である。検索条件はセッションに保持された在庫履歴検索条件から復元する。固定のヘッダ行を先頭に書き、文字化け防止のためBOMを付与する。

本書は実装手順ではなく、誰が・いつ・どの条件で・結果どうなるかを読むためのリバース詳細設計とする。HareruyaEc プラグインの実装を確認値とする。

本機能のカスタマイズ区分はカスタマイズであり、挙動は現行リポ pf-eccube3（HareruyaEc プラグイン）を参照し、DB関連は ec-cube-enterprise を正とする。

対象はブラウザ経由の管理画面に限定する。管理画面プレフィックスは HareruyaEc プラグインの設定キー `admin_route` で決まるため、本書では `%eccube_admin_route%` で示す。

本書の本文ではコントローラのメソッド名は主題としない。ルート bind 名は調査補助へ退避する。

## リニューアル移行時の扱い

挙動は現行リポ pf-eccube3 を正とし、永続化に関わるテーブル・列は移行先 ec-cube-enterprise を正とする。在庫変更履歴のスキーマは現行と移行先で差があるため、移行先名を主とし現行名を括弧で添える。

| 観点 | 現行（pf-eccube3 / HareruyaEc） | 移行先（ec-cube-enterprise） |
|------|--------------------------------|------------------------------|
| 在庫変更履歴の主キー | stock_history_id | id（在庫履歴ID） |
| 備考列 | memo | stock_change_reason（在庫変動理由(備考)） |
| 在庫変更理由区分の参照 | stock_change_type_id | stock_change_type_detail_id（理由名は mtb_stock_change_type を参照） |
| 状態列のメモ元 | dtb_product_sub_class.memo | ec-cube-enterprise に dtb_product_sub_class 相当が見当たらない（ec-cube-enterprise 実装で要確認） |
| 規格コード列 | dtb_product_class.code | dtb_product_class の列名は product_code（プロパティ code） |

CSVの出力列・並び・文字コード（BOM）・ファイル名規則は現行 pf-eccube3 を正とし、上記スキーマ差は移行時に ec-cube-enterprise へ合わせる。移行先で対応列を確認しきれない箇所は推測でスキーマ化せず「ec-cube-enterprise 実装で要確認」とする。

## 処理フロー

### 在庫履歴CSVを出力する

1. 利用者が在庫一覧のCSVダウンロードを押す。
2. 在庫履歴の検索条件セッション（`admin.history.search`）から保持中の検索条件を読む。
3. 在庫履歴検索フォームを生成し、保持値を流し込んで検索条件を復元する。
4. 復元した検索条件で在庫変更履歴の検索用クエリを組み立てる。
5. ストリーム応答を用意し、応答本文の出力時にCSVを書き出す。
6. CSV出力ではファイルを開き、BOMを書き、固定ヘッダ行を書く。
7. クエリ結果を1件ずつ走査し、1件を在庫履歴の行形式に変換して書く。
8. 出力を閉じ、ファイル名を付けてダウンロードさせる。

## 集計条件

| 指標 | 集計の要点 |
|------|------------|
| 出力対象 | 在庫変更履歴に、保持中の在庫履歴検索条件を適用したレコード。一覧画面と同じ検索用クエリを用いる。ページングは適用せず、該当する全件を反復取得する。 |
| 並び順 | 検索条件に応じた並び順（共通の履歴クエリ補助による）。商品ID指定時などは登録日降順・状態昇順となる。 |

ページ番号・表示件数は出力では使わない。在庫一覧の表示はページ単位だが、CSVは検索条件に一致する全件を対象とする。

## 業務ルール・計算

| 項目 | 内容 |
|------|------|
| 出力単位 | 在庫変更履歴1件を1行に出力する。 |
| 文字コード | UTF-8。先頭にBOMを付与する。 |
| ファイル名 | `product_stock_history_` に出力時刻（年月日時分秒）を付け、拡張子 `.csv`。 |
| 状態列の値 | 規格拡張のメモがあればメモ、無ければ状態名を出力する。 |
| 値の変換 | 履歴に記録済みの値をそのまま出力する。集計・再計算は行わない。 |

本機能は入力フォームを持たないため、入力項目に紐づく表を持たない。出力列は次のとおり。

CSVヘッダ列（左から）。

列名は移行先 ec-cube-enterprise を正とし、現行（pf-eccube3）と異なる場合は括弧で現行名を添える。

| 列 | 値の元 |
|----|--------|
| 商品コード | 規格コード `dtb_product_class.product_code`（プロパティ code）。 |
| 商品名 | `dtb_product.name`。 |
| 言語 | 言語名 `mtb_language.name_jp`。 |
| 状態 | 規格拡張メモ `dtb_product_sub_class.memo`（ec-cube-enterprise 実装で要確認）。無ければ状態名。 |
| 変更前在庫数 | `dtb_stock_history.old_stock`。 |
| 変更後在庫数 | `dtb_stock_history.stock`。 |
| 備考 | `dtb_stock_history.stock_change_reason`（現行 memo）。 |
| 在庫変動理由 | `mtb_stock_change_type.name`。 |
| 登録日 | `dtb_stock_history.create_date`（`Y/m/d H:i` 書式）。 |
| 登録者 | 操作者名 `dtb_member.name`。 |

### エッジケース

| ケース | 扱い |
|--------|------|
| 検索条件が未保持（直前に検索していない） | セッションに検索条件が無い状態でクエリを組み立てる。一覧で検索済みの条件が無ければ条件無しに近い対象となる。条件の正は在庫履歴検索（M04-17）に従う。 |
| 該当0件 | ヘッダ行のみのCSVを出力する。 |
| 大量件数 | 結果を1件ずつ反復しながらストリームに書く。 |

## データ整合性

| 観点 | 内容 |
|------|------|
| 一覧とCSV | CSVは在庫一覧と同じ検索条件を用いるが、ページングを適用しない全件である。一覧の表示ページとは件数が異なる。 |
| 出力時点 | 出力開始時点で在庫変更履歴を読み取った結果である。出力中の更新は反映しない。 |
| 履歴と現在値 | 履歴は変更時点の値であり、商品の現在在庫との一致は保証しない。 |

## DBカラム

当機能の出力が参照する列を示す。型の細部はスキーマを参照する。テーブル・列名は移行先 ec-cube-enterprise を正とし、現行（pf-eccube3）と異なる場合は括弧で現行名を添える。

| テーブル | 列 | メモ |
|----------|-----|------|
| dtb_stock_history | old_stock, stock, stock_change_reason（現行 memo）, create_date, stock_change_type_detail_id（現行 stock_change_type_id）, member_id | 在庫履歴の出力値・絞り込み。 |
| dtb_product_class | product_code（プロパティ code） | 商品コード列。 |
| dtb_product | name | 商品名列。 |
| dtb_product_sub_class | memo | 状態列のメモ。ec-cube-enterprise に該当テーブルが見当たらない（ec-cube-enterprise 実装で要確認）。 |
| mtb_stock_change_type | name | 在庫変動理由列。 |
| mtb_language | name_jp | 言語列。 |
| dtb_member | name | 登録者列。 |

### DB操作

本機能は参照系（検索・出力）であり、DBへの登録・更新・削除は行わない。テーブル名は ec-cube-enterprise を正典とする。

| 操作種別 | 対象テーブル | 契機・条件 |
|---------|--------------|------------|
| 検索 | dtb_stock_history（商品・規格・操作者・区分マスタを結合） | 検索条件に合致する在庫変更履歴を抽出し、CSV出力する。 |
