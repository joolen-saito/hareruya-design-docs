# F04-01（買い物かご）

## 業務ロジック

### 商品行の表示

商品画像は登録が無いときノーイメージ画像を出す。商品画像と商品名はどちらも当該商品の商品詳細ページへのリンクで、別のタブで開く。数量の入力欄は3桁までとする。

### 操作の改ざん防止

数量の増減、数量の直接指定、商品の個別削除は、なりすまし対策のトークンを検証してから実行する。トークンが一致しない要求は実行せず、アクセス拒否として扱う。

### 金額の算出と送料無料の案内

| 項目 | 内容 |
| --- | --- |
| 商品ごとの金額 | 単価×数量 |
| 送料無料の案内を出す条件 | 送料無料金額の設定があるとき。設定が無いときは送料無料の案内も不足額の案内も出さない |
| 送料無料と判定する条件 | 合計が送料無料金額以上、または合計個数が送料無料個数以上 |
| 送料無料に達していないとき | 送料無料金額と合計の差額を不足額として案内する |

### 購入手続きへ進めるかどうか

購入手続きへのボタンは、カートに商品が1件以上あり、かつ購入グループが単一のときだけ出す。購入グループが複数のときはボタンを出さず、購入手続きへ進めない。ボタンはスマートフォン用とPC用の2か所に同じものを置く。

購入手続きへ進むとき、販売個数制限の超過などでメッセージが出た場合は購入手続きへ進まず、買い物かごへ戻ってそのメッセージを表示する。

### カートへの追加

商品規格と数量を受け取ってカートへ追加する。数量の指定が無いときは1とする。要求はJSON本文でもフォームの値でも受け付ける。複数商品をまとめて追加する要求も受け付け、追加する商品の並びが渡されないときは追加せず失敗として扱う。追加に失敗したときはエラーメッセージを出す。

非同期の追加は追加後のカート内容（商品明細と合計）を返し、画面遷移を伴う追加は買い物かご画面を表示する。カート内容の取得だけを求める要求にも同じカート内容を返す。

要求の送信先と受け取る値は、方式ごとに次のとおりとする。

| 方式 | 送信先 | 受け取る値 | 応答 |
| --- | --- | --- | --- |
| 1件の追加（非同期） | POST /cart/add | JSON本文の product_class_id・quantity、またはフォーム値 product_class_id・quantity | 追加後のカート内容 |
| 複数件の追加（非同期） | POST /cart/add_bulk | フォーム値 cart_list（要素ごとに product_class_id・quantity） | 追加後のカート内容 |
| 1件の追加（画面遷移あり） | POST /cart/add_show | フォーム値 product_class_id・quantity | 成否にかかわらず買い物かご画面へ遷移する |
| カート内容の取得 | GET /cart/get | なし | カート内容 |

JSON本文を読むのは、フォーム値に product_class_id も quantity も無いときである。複数件の追加で cart_list が無い、または並びでないときは、1件も追加しない。カート内容の応答は、カートの内容（cart）と、カートを識別する値（cookie）を持つJSONとする。

### 入荷通知依頼

| 条件 | 結果 |
| --- | --- |
| 対象の商品規格が存在しない | 依頼を受け付けず失敗を返す |
| 未ログイン | 依頼を受け付けずログインを促す。ログイン後に戻れるよう直前の画面を覚えておく |
| すでに同じ商品規格の依頼がある | その依頼を取り消す |
| 依頼件数が上限に達している | 依頼を登録せず、上限値を添えて失敗を返す |
| 上記以外 | 依頼を登録する |

依頼の送信先は POST /cart/pushReceive で、商品規格をフォーム値 product_class_id で渡す。取消では依頼に削除日時を記録し、依頼の行は残す。依頼件数の上限値は、オプションマスタの入荷通知上限件数で決まる。上限と比べる依頼件数は、その会員の依頼のうち削除日時が記録されていないものの件数である。

### カートが空のとき

商品が1件も無いときは、商品行・集計欄・購入手続きへのボタン・カート一括削除を出さず、買い物かごが空である案内だけを出す。他の商品を見るボタンは空のときも出す。

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | カートへ追加する商品規格と数量、入荷通知を依頼する商品規格 |
| 成功時出力 | 買い物かご画面の表示、カート内容（商品明細と合計）の返却、入荷通知依頼の結果 |
| 失敗時出力 | カート追加のエラーメッセージ、入荷通知依頼のエラーメッセージ |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 登録 | 入荷通知依頼の受付 |
| 削除 | 入荷通知依頼の取消 |
