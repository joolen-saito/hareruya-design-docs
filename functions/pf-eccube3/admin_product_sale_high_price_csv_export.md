# admin_product_sale_high_price_csv_export（管理画面_商品管理_セール用高額商品価格変更CSV雛形出力）

## 業務ロジック

### 出力内容

ヘッダー定義の列名を左から順に並べた見出し行を1行だけ出力する。画面の説明欄の文言はファイルへ書き込まない。データ行は出力しない。ファイルとしてダウンロードさせる応答を返し、添付ファイル名は sale_high_price_template.csv とする（自動テストがこの組み合わせを確認値とする）。

### ヘッダ列

列順は画面上のフォーマット表の行順と一致する。

| 列名（ヘッダ） | 画面上の説明欄の内容（確認値） |
|----------------|--------------------------------|
| 商品コード | （空欄。取込側で必須） |
| 販売価格 | （空欄。取込側で必須） |
| 買取価格 | （空欄。取込側で必須） |
| セールフラグ | 0: セールではない, 1: セールあり |
| 帯URL | （空欄） |
| タグ(ID) | カンマ区切りで複数指定可能。 |
| スマレジ連携フラグ | 0: 連携しない/ 1: 連携する（取込側で必須列として扱われる） |

必須バッジは 商品コード・販売価格・買取価格・セールフラグ・スマレジ連携フラグ に付く。帯URL と タグ(ID) には付かない。

### 文字コードと区切り

各セルは配布設定の文字コード（確認値 UTF-8）へ変換して書き出す。文字コードが UTF-8 のときはファイル先頭に UTF-8 の BOM を書く。区切り文字は配布設定の値（確認値カンマ）、フィールド囲みは二重引用符、エスケープはバックスラッシュとする。

### エラー時の扱い

管理画面として未認証・無権限のときは管理画面共通の扱いに従う（詳細は別設計）。雛形生成中の入出力失敗に対する個別の捕捉は無く、フレームワーク既定のエラーハンドリングに委ねる。

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | なし（画面からの指定を受け取らない） |
| 成功時出力 | 見出し行のみの雛形CSVファイル（sale_high_price_template.csv） |
| 失敗時出力 | 未認証・無権限のときは管理画面共通の扱いに従う |

本機能ではフォーム入力の保存やファイルアップロード検証を行わない。取込画面の入力は別ルートとする。
