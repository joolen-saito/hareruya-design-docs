# o01-02_other_mtg_buyer_mtg_buyer_online_purchase（その他_MTGバイヤー_ネット買取）

## 業務ロジック

### 査定対象の取得

認証トークンを検証し、無効なら認証エラーを返す。条件に基づきネット買取受注を取得してJSONで返す。

### 査定結果の確定

認証トークンを検証し、対象受注が存在しなければ該当なしを返す。送信された明細（メインカード）・個別入力商品で対象受注の既存明細を作り直す。明細から買取合計金額を再計算して受注へ反映し、ステータス・査定担当者・更新日時などを保存する。検証エラー時は更新を行わない。成功時は保存後データまたは成功コードをJSONで返す。

買取合計金額は明細（メインカード）・個別入力商品の単価×数量等から査定確定時に再計算して受注へ保存する。MTGバイヤー本体の表示値は確認値とせず、この再計算結果を正とする。金額の丸めや部門別の集計細部は、ネット買取APIおよびM07系の実装を正とする。

### ステータスの更新

認証トークンを検証し、ステータス・査定担当者・更新日時を保存して、ステータス変更履歴を登録する。

### フリーコメント／個別入力商品／メインカード

それぞれ対象受注のメモ更新、個別入力商品の登録、メインカード明細の登録を行う。

### 他機能との境界

MTGバイヤーが利用する接続点は、ログイン、受注一覧取得、査定確定、ステータス更新、コメント更新、個別入力商品・メインカード登録である。参照は最新データを返し、査定確定は明細を全置換するため再送で上書きされる。ネット買取成立後の在庫登録（入庫）は本機能では行わず、入庫処理は O01-03 を正とする。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| 認証失敗 | 認証エラーのJSON応答を返す |
| 対象受注なし | 該当なしのJSON応答を返す |
| 入力検証エラー | エラー応答を返し、更新を行わない |
| 保存例外 | 失敗応答を返す。HTTPステータスは各接続点の設計に従う |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 認証トークン、ネット買取受注ID、ステータスID、査定明細（メインカード）、個別入力商品、コメント、商品検索条件など |
| 成功時出力 | JSON応答、ネット買取受注の更新、明細・個別入力商品の作成、ステータス変更履歴の作成 |
| 失敗時出力 | 認証拒否・該当なし・入力不正・処理失敗のJSON応答。検証エラー時は更新を行わない |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 追加 | 査定確定時に、送信された明細（メインカード）・個別入力商品を作り直す |
| 更新 | 査定確定時に、受注の買取合計金額・ステータス・査定担当者・更新日時を保存する |
| 追加 | ステータス更新時に、ステータス変更履歴を登録する |
| 更新 | フリーコメント更新時に、対象受注のメモを更新する |
