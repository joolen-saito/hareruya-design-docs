# 商品管理 — 棚番号登録/編集

## 業務ロジック

### 一覧の並び順

棚番号は並び順の昇順で取得して一覧に表示する。一覧行のドラッグによる並べ替えは無い。

### 編集対象の指定

編集対象の指定が無いときは新規登録として空の入力欄を表示する。指定されたIDの棚番号が存在しないときはページが見つからない扱い（404）とする。

編集対象を指定しているあいだは、見出しを編集とし、新規登録へ切り替える導線を併せて表示する。

### 登録・更新の判定順序

| 順序 | 判定 | 結果 |
|------|------|------|
| 1 | 入力値の検証 | 失敗のときは登録できなかった旨を表示し、一覧を伴う同じ画面をそのまま返す |
| 2 | 保存時の一意制約（名称は他の棚番号と重複できない） | 違反のときは値が重複している旨を表示し、編集対象を指定しない棚番号一覧へ戻る |
| 3 | 上記を満たす | 登録完了を表示し、保存した棚番号を編集対象とした画面へ戻る |

### 削除の可否

なりすまし対策トークンの検証を通らない要求は受け付けない。対象の棚番号が存在しないときはページが見つからない扱い（404）とする。当該棚番号を使用している商品規格が1件でもあるときは削除せず、使用中である旨を表示する。1件も無いときは削除する。いずれの場合も棚番号一覧へ戻る。

### CSV出力の内容

棚番号を全件、並び順の昇順で出力する。見出し行に続けて各行を出力し、ファイルの先頭には文字コードの目印を付ける。文字コードの目印はUTF-8のBOM（バイト列 EF BB BF）で、ファイル先頭に1回だけ付ける。出力の文字コードの設定にかかわらず、同じ3バイトを付ける。ファイル名は shelf_number_YYYYMMDDHHmmss.csv の形式とし、ファイルとしてダウンロードさせる。

### CSV取込の受付

取込ファイルの見出しが定義と一致しないとき、および明細行が1行も無いときは、エラーを表示して棚番号登録CSVアップロード画面へ戻る。

### CSV取込の行ごとの検査

各行について、見出しの数と値の数が一致すること、必須の見出しに値があること、名称が所定の形式であること、IDを指定した行はその棚番号が存在すること、名称が他の棚番号と重複しないことを確認する。いずれかに反する行があると、その行番号を示すエラーを表示して取込を打ち切り、その取込では1件も登録・更新されない。エラーが無ければ登録完了を表示する。いずれの場合も棚番号登録CSVアップロード画面へ戻る。

IDが空または 0 の行は新規登録とする。IDを指定した行は、当該棚番号の名称と並び順を書き換える。

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 編集対象の棚番号ID、名称、並び順、取込するCSVファイル、なりすまし対策トークン |
| 成功時出力 | 棚番号の登録・更新・削除、CSVファイルの出力、完了メッセージ、棚番号一覧への戻り |
| 失敗時出力 | 同じ画面の再表示とエラーメッセージ、または棚番号登録CSVアップロード画面への戻り。対象が存在しないときは404 |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 追加 | 新規登録の入力が検証に通ったとき、およびCSV取込でIDが空または 0 の行を読み込んだとき |
| 更新 | 編集の入力が検証に通ったとき、およびCSV取込で既存の棚番号IDを指定した行を読み込んだとき |
| 削除 | 商品規格に使用されていない棚番号を削除したとき |
