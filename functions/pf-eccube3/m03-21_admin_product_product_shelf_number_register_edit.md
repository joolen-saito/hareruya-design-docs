# 商品管理 — 棚番号登録/編集

## 業務ロジック

### 一覧の表示

棚番号を並び順の昇順で取得し、ページ分割して表示する。一覧行のドラッグによる並べ替えは無い。

ページ番号は、指定があればその値、無ければ直前に保持した値、いずれも無ければ 1 とする。表示件数は、指定があれば整数として扱った値、無ければ直前に保持した値、いずれも無ければ 10 とする。ページ番号と表示件数はいずれも次回の表示のために保持する。

### 編集対象

編集対象の指定が無いときは新規登録として空の入力欄を表示する。指定されたIDの棚番号が存在しないときはページが見つからない扱い（404）とする。

### 入力項目

| 項目 | 内容 |
| --- | --- |
| 名称 | 大文字アルファベット1文字、ハイフン、数字3桁の形式に一致する必要がある |
| 並び順 | 整数で入力する。入力定義に上下限や符号の検証は無く、実際の許容値は整数の範囲と保管側の符号なし定義に合わせる運用とする |

### 登録・更新の判定順序

| 順序 | 判定 | 結果 |
|------|------|------|
| 1 | 送信の有無と入力値の検証 | 失敗のときは登録できなかった旨を表示し、保持しているページ番号・表示件数で一覧を組み直して同じ画面を返す |
| 2 | 保存時の一意制約（主に名称の重複） | 違反のときは値が重複している旨を表示し、棚番号一覧へ戻る（URLに対象のIDは付けない） |
| 3 | 上記を満たす | 登録完了を表示し、棚番号一覧へ戻る |

登録完了時の戻り先URLには保存した棚番号のIDがクエリとして付く。一覧のパスにIDの指定が無いため、編集フォームが当該行を自動で開くとは限らず、利用者が一覧から当該行を開き直す必要が生じ得る。

### 削除

なりすまし対策トークンの検証を通過したうえで対象行を取得する。対象行が存在しないときはページが見つからない扱い（404）とする。当該棚番号を使用している商品規格が1件でもあるときは削除せず、使用中である旨を表示する。1件も無いときは削除する。いずれも棚番号一覧へ戻る。

### CSV出力

棚番号を全件、並び順の昇順で取得し、見出し行「ID,名称,並び順」に続けて各行をストリーミング出力する。ファイル名は shelf_number_YYYYMMDDHHmmss.csv の形式とし、ファイルとしてダウンロードさせる。

### CSV取込

アップロードされたファイルを検証する。検証に失敗したとき、ファイルが選択されていないとき、行数が上限（確認値 5010 行）以上のときは、エラーを表示して棚番号登録CSVアップロード画面へ戻る。取込の途中でエラーがあれば行ごとのメッセージを表示し、エラーが無ければ登録完了を表示する。いずれも棚番号登録CSVアップロード画面へ戻る。

取込ファイルの見出しは「名称」と「並び順」が必須で、「ID」は任意とする。IDが空または 0 の行は新規登録とする。正の整数のIDが指定された行は、値の妥当性と該当する棚番号の存在を確認したうえで当該行を更新する。名称の形式チェックは画面の入力にはあるが取込にはなく、取込では一意制約と文字列長だけに依存し得る。

本機能では売上計算や税計算を行わない。

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 一覧のページ番号・表示件数、編集対象の棚番号ID、名称、並び順、取込するCSVファイル、なりすまし対策トークン |
| 成功時出力 | 棚番号の登録・更新・削除、CSVファイルの出力、完了メッセージ、棚番号一覧への戻り |
| 失敗時出力 | 同じ画面の再表示とエラーメッセージ、または棚番号登録CSVアップロード画面への戻り。対象が存在しないときは404 |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 追加 | 新規登録の入力が検証に通ったとき、およびCSV取込でIDが空または 0 の行を読み込んだとき |
| 更新 | 編集の入力が検証に通ったとき、およびCSV取込で既存の棚番号IDを指定した行を読み込んだとき |
| 削除 | 商品規格に使用されていない棚番号を削除したとき |
