# m03-25_admin_product_product_duplicate_product_code_check（管理画面_商品管理_重複商品コード確認）

## 概要

管理画面の「商品管理」から開き、`dtb_product_class.product_code` が同一文字列で 2 件以上存在する規格を一覧し、各行から規格編集画面へ別タブで遷移できる参照専用機能である。ナビのラベルはロケールキー `admin.product.duplicate_code`（日本語メッセージ確認値は「重複コード確認」）であり、前ページのページ見出し・ボタン文言とは異なる。

本書は実装手順ではなく、誰が・いつ・どの条件で・結果どうなるかを読むためのリバース詳細設計とする。ec-cube-enterprise のコア実装を確認値とする。

本機能のカスタマイズ区分は現行踏襲である。現行挙動は pf-eccube3 を参照し、永続化に関わるテーブル名・列名などのDB関連は ec-cube-enterprise を正とする。

対象はブラウザ経由の管理画面に限定する。

コントローラのメソッド単位の解剖は本文の主題としない。実装へ入る起点として「利用者視点の入口」を書く。

---

## リニューアル移行時の扱い

DB関連の記述は ec-cube-enterprise の実装を正とする。重複判定の対象列・結合は現行（pf-eccube3）と移行先（ec-cube-enterprise）で同一スキーマである。

| 観点 | 現行（pf-eccube3） | 移行先（ec-cube-enterprise） |
|------|---------------------|-------------------------------|
| 重複判定キー | `dtb_product_class.product_code`（Doctrine プロパティ `code` が列 `product_code` にマップ） | 列名は `product_code`。重複判定キーは移行先でも `dtb_product_class.product_code`。 |
| 結合先 | `dtb_product.id`、`dtb_product_class.product_id` | 同一スキーマ。 |

前ページ・結果ページの参照挙動と URL 生成は現行（pf-eccube3）を参照し、移行先でも同等の標準実装が ec-cube-enterprise に取り込まれている。

## 処理フロー

### 前ページを開く（`admin_product_pre_doubling_check`）

1. 管理画面の認証・共通制約を通過する。
2. サーバーは空の表示用コンテキストで Twig を描画する（サーバー側で追加の DB 問い合わせは無い）。
3. 利用者は「重複確認する」を押下して結果ページへ GET で遷移する。

### 結果ページを開く（`admin_product_doubling_check`）

1. 管理画面の認証・共通制約を通過する。
2. サーバーは商品規格ストレージに対し raw SQL で「重複している `product_code` に属する全規格行」を取得する。
3. 取得した各行について、商品 ID と規格 ID から規格編集ルートの URL を生成する。同一コードに複数行がある場合は URL の配列にまとめる。
4. 連想配列 `products` が空なら「重複なし」用 Twig 分岐を使い、空でなければ表分岐でコードごと・行ごとにリンクを描画する。

---

## 集計条件

| 指標 | 集計の要点 |
|------|------------|
| 重複コードの集合 | `dtb_product_class` を `product_code` でグループ化し、件数が 2 超のコードだけを残す。`product_code IS NOT NULL` かつ空文字列でない行だけがグループ化対象。 |
| 一覧に載せる行 | 上記コードに該当する全規格行。`dtb_product` と内部結合し、商品が存在しない孤立行は結果に含まれない。 |
| 並び | `product_code` 昇順、その後 `dtb_product.id` 昇順、その後規格 ID 昇順。 |

---

## 重複判定時の条件（実装順）

| 順序 | 判定 | 結果 |
|------|------|------|
| 1 | `product_code` が NULL | 重複判定の母集団から除外される。 |
| 2 | `product_code` が空文字列 | 重複判定の母集団から除外される。 |
| 3 | それ以外で同一値が 2 行以上 | その値は「重複」とみなされ、該当する全行が一覧に載る。 |

---

### エッジケース

| ケース | 扱い |
|--------|------|
| 重複が 1 件も無い | 結果ページはテーブルを出さず、固定メッセージのみ表示する。 |
| 同一コードが N 件ある | 同一コードのテキストが N 行並び、各行のリンク先 URL は規格ごとに異なる。 |
| `product_code` が NULL または空文字のみの環境 | 重複集合は空になり、「重複なし」メッセージになる。 |
| 空白のみや制御文字のみのコード | SQL はトリムしないため、値が完全一致する複数行があれば重複として載る。 |

| 観点 | 内容 |
|------|------|
| 一覧と DB | 一覧はリクエスト処理中の読み取り時点のコミット済みデータを反映する。同一セッション内のキャッシュ再利用による一覧の長期固定は本機能固有には無い。 |
