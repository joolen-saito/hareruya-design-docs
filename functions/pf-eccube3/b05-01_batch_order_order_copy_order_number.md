# バッチ 受注管理 — 注文番号登録

## 概要

注文番号テーブルに採番された注文番号を、受注サブテーブルへコピーするバッチである。コマンドライン（コンソールコマンド）から実行する。コピー対象の受注のうち店頭受取の注文については、スマレジ用の商品コード（バーコード）を生成して登録し、スマレジへ商品・在庫を連携する。

本書は実装手順ではなく、誰が・いつ・どの条件で・結果どうなるかを読むためのリバース詳細設計とする。確認値はpf-eccube3（EC-CUBE3系）のHareruyaEcプラグインの受注バッチ（注文番号コピー処理）、注文番号・受注サブを扱うリポジトリ、スマレジ連携処理を正とする。カスタマイズ区分は現行踏襲であり、挙動の参照リポはpf-eccube3、DB関連はec-cube-enterpriseを正とする。

対象はコンソールコマンドであり、ブラウザ経由の画面を持たない。

本文ではフレームワークのコマンド型名やサービス型名を主説明としない。実行はコンソールのバッチコマンドで行う。

## リニューアル移行時の扱い

現行（pf-eccube3）の挙動と移行先（ec-cube-enterprise）の差を記録する。挙動は現行リポを正とし、DB関連はec-cube-enterpriseを正とする。

| 観点 | 現行（pf-eccube3） | 移行先（ec-cube-enterprise） |
|------|--------------------|------------------------------|
| 受注の拡張情報の持ち方 | 受注サブテーブル`dtb_order_sub`が注文番号・スマレジ用コード等を保持する補助表として存在する。 | 補助表`dtb_order_sub`を持たず、注文番号（`order_number`）・スマレジ用商品コード（`smaregi_code`）・スマレジ各連携フラグを受注`dtb_order`の列へ統合している。 |
| コピー先の列 | `dtb_order_sub.order_number`へ注文番号をコピーする。 | `dtb_order.order_number`（文字列・桁11）へ反映する。 |
| スマレジ用商品コードの列 | `dtb_order_sub.smaregi_code`へ生成・登録する。 | `dtb_order.smaregi_code`（桁20）へ登録する。 |
| コピー元の注文番号テーブル | `dtb_order_number`が注文番号（`order_number`、自動採番）と`order_id`を持つ。 | `dtb_order_number`が`id`・`base_info_id`・`value`・`update_date`を持つ構造で、現行のコピー機構と差がある（ec-cube-enterprise実装で要確認）。 |

## 用語

| 用語 | 説明 |
|------|------|
| 注文番号 | 受注に採番される番号。注文番号テーブルに保持する。 |
| 受注サブ | 受注の拡張情報。注文番号・スマレジ用コード等を保持する。 |
| 店頭受取 | 店頭で受け取る配送区分の注文。 |
| スマレジ用商品コード | スマレジ連携用に生成するバーコード。 |

| 入口 | 実行方法 | 期待されるふるまい |
|------|----------|--------------------|

## 処理フロー

### 注文番号登録を実行する（`order:batch copyOrderNumber`）

1. 注文番号テーブルから受注サブテーブルへ注文番号をコピーし、対象の受注IDの一覧を得る。
2. 対象が無い場合は処理を終了する。
3. メール送信用の経路を準備する。
4. 対象の受注ごとに受注サブを取得する。
5. 当該注文が店頭受取の配送区分に該当する場合、スマレジ用商品コード（バーコード）を生成して受注サブへ登録し保存する。
6. 店頭受取の注文についてスマレジへ商品・在庫を連携する。

## DBカラム

機能に直接関係する列のみ記載する。型や一覧の細部はスキーマを参照する。

テーブル・列名はec-cube-enterpriseを正とする。現行（pf-eccube3）と異なる場合は移行先名を主とし現行名を括弧で添える。

| テーブル | 列 | メモ |
|---------|-----|------|
| `dtb_order_number` | コピー元の注文番号 | コピー元（移行先は`id`・`base_info_id`・`value`構造のためコピー機構は要確認）。 |
| `dtb_order`（現行は`dtb_order_sub`） | `order_number` | コピー先の注文番号。 |
| `dtb_order`（現行は`dtb_order_sub`） | `smaregi_code` | 店頭受取注文に生成・登録するスマレジ用商品コード。 |

### DB操作

永続化の正は ec-cube-enterprise（テーブル名・操作は ec-cube-enterprise を正典）。当ドメインは承認ワークフローを介さず persist/flush で直接確定する（承認ワークフローは在庫機能固有）。

| 操作種別 | 対象テーブル | 契機・条件 |
|---------|--------------|------------|
| 登録/更新 | dtb_order / dtb_order_number / dtb_order_sub | 当機能が行う登録・更新で対象テーブルを直接保存する（不要な削除は含まない）。確定は persist/flush による即時反映。DB=ec-cube-enterprise を正典とする。 |
