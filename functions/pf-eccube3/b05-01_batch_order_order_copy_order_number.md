# バッチ 受注管理 — 注文番号登録

## 業務ロジック

### 処理対象と処理順序

採番済みの注文番号が受注サブへ未反映の受注を対象とし、注文番号の昇順に処理する。1回の実行で処理する件数は最大30件で、対象がそれを超えるときは残りを次回以降の実行へ持ち越す。対象が無いときは何も行わずに終了する。

### 起動引数の扱い

起動時のバッチ名が指定されていない、または受け付けるバッチ名のいずれにも一致しないときは、実行日時を添えたメッセージをコンソールへ出力し、処理を行わずに異常終了する。

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 起動時のバッチ名 |
| 出力 | バッチ名が不正なときの、実行日時を添えたコンソールメッセージ |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 更新 | 採番済み注文番号の受注サブへの反映 |

## 表示メッセージ

本バッチは画面メッセージを扱わない。
