# バッチ 受注管理 — 注文番号登録

## 業務ロジック

### コピー対象

注文番号として採番済みで、受注サブへ未反映の受注を対象とする。対象が無いときは何もせず終了する。

### 店頭受取の扱い

配送区分が店頭受取グループに含まれる注文について、注文番号をもとにスマレジ用のバーコードを生成して受注サブに登録する。登録後、店頭受取の注文の商品・在庫をスマレジへ連携する。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| コマンド名が未指定・不一致 | 処理を行わずに終了する |
| コピー対象なし | 何もせず完了する |
| 連携時のエラー | エラーメッセージをコンソールに出力する |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | コマンド名 |
| 成功時出力 | 受注サブへの注文番号の反映と、店頭受取注文のスマレジ用コード登録およびスマレジ連携 |
| 失敗時出力 | エラーメッセージのコンソール出力 |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 更新 | 注文番号の受注サブへのコピー |
| 更新 | 店頭受取注文のスマレジ用コードの登録 |

## 表示メッセージ

本バッチは画面メッセージを扱わない。
