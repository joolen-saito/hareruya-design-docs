# M13-15（画像設定）

## 概要

イベントバナー管理画面において、イベント用バナーに使う画像をアップロードして保管し、保管済み画像の一覧表示・画像URLコピー・削除を行う機能である。画面上の「画像設定」枠が本書の対象で、同画面のバナーのリンク・並び順設定（バナー設定）とは区別する。

本書は実装手順ではなく、誰が・いつ・どの条件で・結果どうなるかを読むためのリバース詳細設計とする。確認値はpf-eccube3（EC-CUBE3系）のHareruyaEcプラグインのバナー管理画面のアップロード処理、画像ストレージアクセス処理を正とする。本機能のカスタマイズ区分はカスタマイズであり、挙動の確認はpf-eccube3を参照する。本機能の画像アップロード・削除はストレージ操作でありDBを更新しないため、永続化に関する記述は持たない（バナーのDB列の正はec-cube-enterprise、扱いは同画面のバナー設定を正とする）。

対象はブラウザ経由の管理画面に限定する。

本文ではフレームワークのコントローラ型名やメソッド名を主説明としない。管理画面プレフィックスは環境により変わり、プラグイン設定の`admin_route`で決まる。「利用者視点の入口」にHTTPメソッドとサイトルートからのパスパターンを書く。

---

## 本書で扱うこと

- イベントバナー画像のアップロード（店舗の指定を含む）
- 受理する画像種別・サイズ上限・保管先
- 保管済み画像の一覧表示・画像URLコピー・削除
- 店舗での絞り込み表示

---

## 本書で扱わないこと

以下は本書では仕様確定せず、実装または別機能の設計を正とする。

- バナーのリンク先・表示種別・並び順の設定（同画面の「バナー設定」を正とする）
- トップバナー管理（イベントバナーと同コントローラだが対象が異なる）
- イベント・イベント申込の登録（M13-10・M13-12・M13-13を正とする）
- 画像ストレージ（S3等）の基盤設定・資格情報

---

## リニューアル移行時の扱い

本機能は現行（pf-eccube3のHareruyaEcプラグイン）の挙動を踏襲する。本機能の画像アップロード・削除はストレージ操作であり、DBの列を直接更新しない。

| 観点 | 現行（pf-eccube3） | 移行先（ec-cube-enterprise） |
|------|--------------------|------------------------------|
| 画像の保管先 | 画像ストレージの`banner/`配下（店舗指定時は`banner/{html_class}/`配下） | 保管先のパス規約はec-cube-enterprise実装で要確認。 |
| バナーDB列との関係 | アップロード・削除はストレージのみを変更し、バナーのDB情報（リンク・並び順・画像URL）は更新しない | バナー本体は`mtb_banner`に対応する。DB列の正はec-cube-enterprise、更新は同画面のバナー設定（M13-14）を正とする。 |

本機能はDBへ書き込まないため、移行時に読み替えるテーブル名・列名は無い。画像ストレージの保管先パス規約は移行先で要確認とする。

## 用語

| 用語 | 説明 |
|------|------|
| イベントバナー画像 | イベントバナーに表示する画像。本機能でアップロード・保管する。 |
| 画像設定枠 | バナー管理画面下部のアップロード・一覧・削除を行う領域（`#upload_wrap`）。 |
| 店舗 | アップロード時に指定できる対象店舗。指定すると店舗別ディレクトリへ保管する。 |
| 画像ストレージ | 画像の保管先（`banner/`配下）。一覧・削除はこの保管先を参照する。 |

## 利用者視点の入口

| 入口 | URLエンドポイント | 期待されるふるまい |
|------|--------------------|--------------------|
| イベントバナー管理（全店舗） | `GET /%eccube_admin_route%/banner/event` | バナー設定とアップロード枠・保管済み画像一覧を表示する。 |
| イベントバナー管理（店舗絞り込み） | `GET /%eccube_admin_route%/banner/event/{html_class}` | 指定店舗のディレクトリ配下の画像一覧を表示する。 |
| 画像アップロード・バナー設定の送信 | `POST /%eccube_admin_route%/banner/event` | 画像ファイル送信時はアップロード、そうでなければバナー設定を保存する。 |
| 画像アップロード・バナー設定の送信（店舗絞り込み） | `POST /%eccube_admin_route%/banner/event/{html_class}` | 上と同様で、店舗絞り込み状態を保つ。 |
| 画像削除 | `DELETE /%eccube_admin_route%/banner/event/delete` | 指定した保管済み画像を削除する。 |
| 画像削除（店舗絞り込み） | `DELETE /%eccube_admin_route%/banner/event/delete/{html_class}` | 指定店舗の絞り込みを保ったまま削除する。 |

管理画面プレフィックスは環境により変わるためプレースホルダで示す。`{html_class}`は店舗のHTMLクラス名。アップロードとバナー設定は同一URLへPOSTし、ファイル送信の有無で処理を振り分ける。

## フロント挙動

| 観点 | 内容 |
|------|------|
| 表示要素 | 画像設定枠に、店舗セレクト・画像ファイル選択・アップロードボタン・エラー文言。店舗絞り込みドロップダウン（全て／各店舗）。保管済み画像の一覧表（サムネイル＋画像URL・更新日付・画像URLコピー・削除）。 |
| JS挙動 | 画像URLコピーのリンクで画像URLをクリップボードへコピーする。バナー設定側は並び順の空・重複をアラートで弾いてから送信する（バナー設定の挙動で、画像設定とは別系統）。 |
| CSS・レイアウト | 標準の管理画面フレーム上にバナー設定枠とアップロード枠（`#upload_wrap`）を縦に配置する。アップロード成功時は`#upload_wrap`へアンカー遷移する。 |
| モーダル・ポップアップ | 本機能専用のモーダルは無い。削除はアンカーの確認メッセージで実行する。 |

画像のアップロード欄は画面ラベル単位で入力項目に記載する。アップロードフォームは画像ファイルと店舗の指定を持つ。

---

## 処理フロー

### バナー管理画面を表示する（`GET …/banner/event`、`GET …/banner/event/{html_class}`）

1. イベントバナー一覧を読み込み、バナー設定フォームを組む。
2. アップロード用フォーム（画像ファイル・店舗）を組む。店舗絞り込み時は対象店舗を初期選択する。
3. 画像ストレージから`banner/`配下（絞り込み時は`banner/{html_class}/`配下）の画像一覧を取得し、更新日付で降順整列して表示する（上限2000件）。

### 画像をアップロードする（`POST …/banner/event` でファイル送信あり）

1. 送信にファイルが含まれるかでアップロードかバナー設定かを判定する。ファイルがあればアップロードへ進む。
2. アップロードフォームを検証する。検証NGなら画面を再描画する。
3. ファイルが空なら「ファイルが選択されていません。」を表示する。
4. ファイルサイズが上限（確認値520000バイト）を超えるならサイズ超過を表示する。
5. 画像種別がGIF・JPEG・PNGのいずれかであることを確認する。該当しなければ「ファイルがGIF・JPG・PNGではありません。」を表示する。
6. 店舗未指定なら`banner/`、店舗指定なら`banner/{店舗HTMLクラス名}/`へ、推測した拡張子でファイルを保管する。
7. 成功時はアップロード枠（`#upload_wrap`）へアンカー付きでリダイレクトする。

### 画像を削除する（`DELETE …/banner/event/delete`、店舗絞り込み版）

1. なりすまし対策トークンを検証する。
2. 指定ファイルが保管先に存在すれば削除する。
3. 全店舗一覧または店舗絞り込み一覧へ、アップロード枠アンカー付きでリダイレクトする。

## 業務ルール・計算

| 項目 | 内容 |
|------|------|
| 受理する画像種別 | GIF・JPEG・PNG。画像種別判定で先頭3種のみ許可する。 |
| サイズ上限 | 1ファイル520000バイト（確認値）。超過はエラー。 |
| 保管先 | 店舗未指定は`banner/`、店舗指定は`banner/{店舗HTMLクラス名}/`。 |
| ファイル名 | 推測した拡張子を付与して保管する。 |
| 一覧の整列 | 画像一覧は更新日付の降順で表示し、上限2000件で切る。 |
| DB登録 | アップロード自体はストレージへの保管のみで、バナーのDB情報（リンク・並び順等）は更新しない。 |

本機能は金額計算・件数集計を行わない。

### 入力項目

| 項目名 | 必須／任意 | 最大長 | 初期値 | 保存先・扱い |
|--------|------------|--------|--------|----------------|
| 店舗 | 任意 | 選択（店舗マスタの単一選択） | 店舗絞り込み時は当該店舗、未絞り込みは未選択 | 保管ディレクトリの決定にのみ使用。フォームキー`shops`。指定で`banner/{店舗HTMLクラス名}/`へ保管。 |
| 画像のアップロード | 必須（送信時） | 画像ファイル。GIF・JPEG・PNGのみ。520000バイト以下（確認値） | 未選択 | ストレージの`banner/`配下へ保管。フォームキー`file`。推測拡張子を付与。DBには登録しない。 |

最大長・サイズの数値は実装確認値とする。一覧・削除で参照する画像URLや更新日付は表示専用であり入力項目ではない。

### エッジケース

| ケース | 扱い |
|--------|------|
| ファイル未選択 | 「ファイルが選択されていません。」を表示。 |
| サイズ超過 | サイズ超過メッセージを表示。 |
| 画像種別がGIF・JPEG・PNG以外 | 種別不正メッセージを表示。 |
| 削除対象が存在しない | 削除は行わず一覧へ戻る。 |
| ファイル送信なしの送信 | バナー設定として扱う（本書の対象外、同画面のバナー設定を正とする）。 |

## データ整合性

| 観点 | 内容 |
|------|------|
| アップロードと一覧 | アップロード成功後はリダイレクト先の一覧で保管先を再取得して表示する。一覧は更新日付降順・上限2000件。 |
| 保管先と絞り込み | 店舗絞り込み表示は`banner/{html_class}/`配下のみを参照する。全店舗表示は`banner/`配下を参照する。 |
| 画像とバナー設定 | 画像のアップロード・削除はストレージのみを変更し、バナーのDB情報は変えない。バナーに画像URLを反映するのは同画面のバナー設定で行う。 |

---

## API/バッチ結果

本機能ではバッチ実行を扱わない。画像の保管・取得・削除は画像ストレージアクセス処理を通じて行う。

---

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | アップロードは画像ファイルと店舗（`multipart`）。削除は対象ファイルキーとなりすまし対策トークン。 |
| 成功時出力 | アップロード・削除の反映と一覧の再表示（アンカー付きリダイレクト）。 |
| 失敗時出力 | 未選択・サイズ超過・種別不正は画面にエラー文言を表示。 |
| 副作用 | 画像ストレージへのファイル保管・削除。 |

---

## DBカラム

本機能の画像アップロード・削除はストレージ操作であり、DBの列を直接更新しない。バナーのDB列（リンク・並び順・画像URL等）の更新は同画面のバナー設定で扱う。

| テーブル | 列 | メモ |
|---------|-----|------|
| イベントバナー | 画像URL等 | 本機能では更新しない（バナー設定で更新）。 |

## 画面遷移

| 条件 | 遷移先 |
|------|--------|
| 管理画面表示 | イベントバナー管理画面 |
| アップロード成功 | アップロード枠アンカー付きで同画面へリダイレクト |
| アップロード失敗 | 同画面を再描画（エラー表示） |
| 削除実行 | 一覧（全店舗または店舗絞り込み）へアンカー付きリダイレクト |
| 店舗絞り込み選択 | 当該店舗の一覧へ |

---

## エラー処理

| エラー内容 | 処理 |
|------------|------|
| ファイル未選択 | エラー文言を表示し再描画。 |
| サイズ超過 | サイズ超過メッセージを表示し再描画。 |
| 画像種別不正 | 種別不正メッセージを表示し再描画。 |
| 削除のトークン不正 | 処理しない（なりすまし対策）。 |
| 削除対象不在 | 削除せず一覧へ戻る。 |

---

## ログ・監査

本機能では画像アップロード・削除に固有の業務監査ログは記録しない。

### ログに出してはいけないもの

- Cookie値
- セッションIDの完全値
- なりすまし対策トークン
- アップロード画像のバイナリ原データ

---

## 排他制御・トランザクション

本機能はストレージ操作が中心で、楽観ロック・悲観ロックの対象は持たない。同一ファイル名の同時アップロード・削除の競合制御は対象としない。
