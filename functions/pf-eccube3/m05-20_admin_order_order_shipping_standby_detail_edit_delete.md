# 受注管理 — 出荷指示リスト詳細編集/削除

## 業務ロジック

### 操作の種類

| 操作 | 出荷指示リストIDの制限 | 結果 |
| --- | --- | --- |
| 詳細の表示 | 数字だけを受け付ける | 出荷指示リストと含まれる受注を表示する |
| 更新 | 数字だけを受け付ける | 備考と最終更新者を書き換え、同じ詳細画面へ戻る |
| 削除 | 数字だけを受け付ける | 出荷指示リストを削除し、検索結果へ戻る |
| ピッキングリスト印刷 | 数字だけを受け付ける | ピッキングリスト印刷の設計書を正とする |
| 納品書印刷 | 数字だけを受け付け、言語は日本語と英語のいずれかに限る | 出荷指示：納品書印刷の設計書を正とする |
| 取込用CSV出力・送り状CSV出力 | 制限なし | それぞれの設計書を正とする |

削除だけは削除専用の要求方法を用い、なりすまし対策トークンを検証する。トークンが不正なときは削除しない。

### 詳細の表示

指定した出荷指示リストが見つからないときは、見つからない旨の応答を返して画面を出さない。

最終更新者は、削除済みの担当者であっても名前を表示できるように、削除済みを除外する絞り込みを外して読み出す。担当者が見つからないときは名前欄を空にする。

含まれる受注は、受注IDから注文番号をまとめて引き直して表示する。注文番号を持たない受注が含まれるときは、その行の注文番号だけが空になる。登録日と更新日は `年/月/日 時:分:秒` で表示し、値が無いときは空にする。

### 更新

備考の入力値でそのまま置き換え、最終更新者を操作した本人に付け替える。更新できたときは同じ出荷指示リストの詳細画面へ戻る。

備考は複数行の入力で、最大長の制限を設けていない。値が空のときも登録できる。

備考と最終更新者以外は更新しない。含まれる受注の構成も変わらない。指定した出荷指示リストが見つからないときは更新しない。

### 削除

削除は次の順で行う。

1. 指定した出荷指示リストを読み出す。IDが無いか見つからないときは、見つからない旨の応答を返して削除しない。
2. 含まれる受注の出荷指示日をすべて消す。
3. 出荷指示リストを削除する。

受注そのものは削除しない。対応状況も元に戻さないため、削除した出荷指示リストに紐づいていた受注は、対応状況が出荷指示のまま出荷指示日だけが空になる。

削除後の戻り先は、検索時のページ番号をセッションに保持しているかどうかで決まる。

| --- | --- |
| 保持している | そのページ番号の出荷指示リスト検索結果 |
| 保持していない | 出荷指示リスト検索の初期表示 |

## 入出力

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 出荷指示リストの備考・最終更新者の更新 | 更新 |
| 出荷指示リストの削除 | 削除 |
| 受注の出荷指示日の消去 | 削除。出荷指示リストを消す前に、含まれる受注すべてを対象に行う |

受注そのもの、受注明細、対応状況は更新しない。
