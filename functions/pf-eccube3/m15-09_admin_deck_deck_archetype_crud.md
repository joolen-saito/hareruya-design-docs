# デッキ管理 — アーキタイプ登録・編集・削除

## 業務ロジック

### 画面の初期表示

| 場面 | 初期表示 |
| --- | --- |
| 新規登録のとき | 空の状態でフォームを開く。代表カードの画像と名称は空とする |
| 新規登録のとき | 代表カードを探すための検索用フォームをあわせて用意する |
| 編集で対象のアーキタイプがあるとき | 既存の値をフォームに載せ、代表カードの画像URLと名称を画面へ渡す |
| 編集で対象のアーキタイプが無いとき | 見つからない扱い（HTTP404）とする |

### 保存の判定順序

| 順序 | 判定・処理 | 内容 |
| --- | --- | --- |
| 1 | 操作の有効期限 | 期限が切れているときは保存しない |
| 2 | 入力内容の検証 | 外れたときは保存せず、詳細画面をエラー付きで再表示する |
| 3 | 再表示時の代表カード | 送信された代表カードの画像IDを解決できるときだけ、その画像を表示する |
| 4 | 保存 | 代表カードの画像を紐づけて保存する |

新規登録で保存できたときは、採番されたIDの編集画面へ戻る。編集で保存できたときは、同じIDの編集画面へ戻る。

### 削除の判定順序

| 順序 | 判定・処理 | 内容 |
| --- | --- | --- |
| 1 | 操作の有効期限 | 期限が切れているときは削除しない |
| 2 | 対象の特定 | IDが不正なとき、または該当のアーキタイプが無いときは見つからない扱い（HTTP404）とする |
| 3 | 削除の可否 | 当該アーキタイプに紐づくデッキが1件以上あるときは削除しない。エラーメッセージを表示し、アーキタイプ検索の1ページ目へ戻る |
| 4 | 削除 | 紐づくデッキが0件のときだけ削除する。削除は論理削除とし、削除日時を設定する。物理削除は行わない |

削除できたときの戻り先は、直前のアーキタイプ検索のページ番号があるときは当該ページの検索結果、無いときはアーキタイプ一覧とする。

### 登録デッキ数の数え方

| 場面 | 数える対象 |
| --- | --- |
| 削除の可否の判定 | 当該アーキタイプに紐づくデッキ。デッキ種別で絞らない |
| 検索一覧の登録デッキ数 | デッキ種別がイベントのデッキだけ |

### 代表カードの検索

代表カードは非同期の呼び出しで検索する。

| 呼び出し | ふるまい |
| --- | --- |
| 検索語を送ったとき | 検索語と表示ページを保持し、カード画像の検索結果をページ単位で返す |
| ページを切り替えたとき | 保持した検索語で検索し、表示ページを更新する |
| 非同期以外で呼び出したとき | ページ送りの情報が空のままとなり、描画の差は限定的である |
| 画像IDを指定して代表カードを確定するとき | カードの和英混合名と画像URLを返す |
| 指定した画像IDが存在しないとき | 見つからない扱い（HTTP404）と空の応答を返す |

### エラー時の扱い

| 事象 | 扱い |
|------------|------|
| 操作の有効期限が切れているとき | 保存・削除を行わず、アクセス拒否（HTTP403）に相当する扱いとする |
| 入力内容の検証に外れたとき | 保存せず、同一画面にエラーを表示する |
| 編集・更新・削除で対象IDのアーキタイプが無いとき | 見つからない扱い（HTTP404）とする |
| 紐づくデッキがあるアーキタイプを削除しようとしたとき | 削除せず、エラーメッセージを表示してアーキタイプ検索の1ページ目へ戻る |
| 代表カードの画像IDを解決できないとき | 見つからない扱い（HTTP404）と空の応答を返す |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | アーキタイプの登録・編集の入力値、削除の対象ID、代表カード検索の検索語とページ番号、代表カードの画像ID。 |
| 成功時出力 | 登録・編集・削除のときは画面の遷移（302）と完了メッセージ。代表カード検索のときは一覧の画面断片、代表カード確定のときはカード名と画像URL。 |
| 失敗時出力 | 検証に外れたときは同一画面の再描画とエラー表示。対象が無いときはアクセス拒否（HTTP403）または見つからない扱い（HTTP404）。削除できないときはエラーメッセージ付きで検索の1ページ目へ戻る。 |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 追加 | アーキタイプを新規登録したとき |
| 更新 | アーキタイプを編集して保存したとき |
| 削除 | 紐づくデッキが0件のアーキタイプを削除したとき。論理削除とし、削除日時を設定する |
