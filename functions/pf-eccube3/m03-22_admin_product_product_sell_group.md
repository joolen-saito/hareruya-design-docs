# 商品管理 — 購入グループ管理

## 業務ロジック

### 一覧に出す範囲

削除済みの購入グループは一覧に出さない。編集対象として指定されたIDの購入グループが存在しないとき、および既に削除済みのときは、ページが見つからない扱い（404）とし、画面を開かない。

### 支払方法の選択肢

削除済みでない支払方法から旧・大会専用の2件を除いたものを、表示順の降順でチェックボックスとして並べ、複数選べるようにする。

### 配送方法の選択肢

削除済みでない配送方法をチェックボックスとして並べ、複数選べるようにする。並び順は定めていない。

### 保存

入力値の検証に通ったときだけ保存する。新規登録では作成日時に現在日時を入れ、更新では作成日時を変えない。いずれも更新日時を現在日時にし、ログイン中の管理者を更新者として記録する。保存後は、保存した購入グループを編集対象とした状態の同じ画面へ戻る。

検証に通らないときは保存せず、一覧を伴う同じ画面を再表示して項目ごとのエラーを見せる。削除済みの購入グループへ保存を送信したときはページが見つからない扱い（404）とする。なりすまし対策トークンの検証に失敗したときはアクセスを拒否する（403）。

### 削除

購入グループの削除は削除日時を設定する論理削除とし、行そのものは残す。当該購入グループを使用している商品が1件でもあるときは、購入グループ名を含むエラーを表示して削除しない。なりすまし対策トークンの検証に失敗したときはアクセスを拒否する（403）。削除の可否にかかわらず一覧へ戻る。

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 編集・削除対象の購入グループID、購入グループの入力項目、支払方法・配送方法の選択、なりすまし対策トークン |
| 成功時出力 | 購入グループの登録・更新・論理削除、登録・更新時の完了メッセージ、更新後の画面 |
| 失敗時出力 | 検証失敗は一覧を伴う同じ画面の再表示。トークン不正は403。IDが解決できないとき（削除済みを含む）は404 |

### 入出力: 一覧の表示内容

一覧の支払方法欄・配送方法欄には、その購入グループに登録されている方法の名称を、カンマ区切りで1つの欄に連ねて表示する。登録が無いときは空欄とする。

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 追加 | 新規登録の入力が検証に通ったとき |
| 更新 | 編集の入力が検証に通ったとき |
| 論理削除 | 商品に使用されていない購入グループを削除したとき |
