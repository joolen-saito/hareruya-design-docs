# 店頭買取 — 店頭買取査定申込情報入力

## 業務ロジック

### 店舗の特定

エントリー・申込フォーム・会員登録フォームのいずれも、経路に含まれる店舗識別名から店舗を特定する。該当する店舗が無いときは 404 とする。

ログイン中にエントリーへ来たときはログアウトへ誘導する。

### 画面の進み方

| 画面 | 進める条件 | 満たさないとき |
| --- | --- | --- |
| エントリー | 店舗が特定できるとき | 404 とする |
| 申込フォーム | エントリー開始済み、または申込フォームが送信済みのとき | エントリーへ戻す |
| 会員登録フォーム | エントリー開始済みかつ申込フォームが送信済みのとき | エントリーへ戻す |

エントリーの表示で、入力データを空で初期化する。申込フォームの送信は、未ログインのときは会員登録フォームへ、ログイン中のときは確認へ向かう。会員登録フォームでは、申込フォームの入力内容と適格請求書発行事業者の入力内容を保持したうえで表示する。

申込フォーム・会員登録フォームのキャンセルは、エントリーへ戻る。会員登録フォームは会員登録をスキップして確認へ進む導線も持つ。

### 入力の初期値と検証

| 項目 | 扱い |
| --- | --- |
| 氏名・氏名カナ・郵便番号・住所・生年月日・電話番号・職業 | ログイン中のときは会員の登録情報を反映する |
| 適格請求書発行事業者の登録番号 | 設問が「はい」のときだけ入力欄を扱う。ログイン中で登録済みの番号があるときは反映する |
| 返却希望サプライ | 選択肢はスリーブとストレージボックスの2つ（英語表示では Sleeves と Storage Box） |
| 氏名・氏名カナ | 空白文字を含む入力は受け付けない |
| 会員登録の入力 | 会員登録をスキップするときは入力を求めない |

### 他機能との境界

この機能は入力までを扱う。申込みの確定と査定番号の付与は店頭買取査定申込確認で行い、登録内容の重複判定もそこを正とする。

### エラー時の扱い

| エラー内容 | 処理 |
| --- | --- |
| 店舗識別名に該当する店舗が無い | 404 とする |
| エントリー未開始で申込フォームへ直接来た | 未送信のときはエントリーへ戻す |
| 入力の必須・形式を満たさない | 当該入力欄の直下にエラーを表示する |
| エントリーのログインに失敗した | ログインフォームの直下に最終エラーを表示する |

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | エントリーのログイン情報、査定申込情報の入力一式、会員登録の入力一式 |
| 成功時出力 | エントリー・申込フォーム・会員登録フォームのいずれかの表示 |
| 失敗時出力 | 店舗が無いときの 404、エントリー未開始のときのエントリーへの戻し |
