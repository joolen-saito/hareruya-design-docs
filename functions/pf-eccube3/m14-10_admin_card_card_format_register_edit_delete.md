# カード管理 — フォーマット新規登録・編集・削除

## 業務ロジック

### 一覧と編集の対象

一覧はフォーマットを並び順の昇順、並び順が同じときは識別子の昇順で全件表示する。

編集では、指定したフォーマットが無いときは 404 とする。当該フォーマットに紐づくカード制限のうち、禁止のものから禁止カードの一覧を、制限のものから制限カードの一覧を組み立てる。リーガルのものはどちらの一覧にも載せない。

新規登録では禁止カードと制限カードをいずれも空とする。統率のボードが無いときは、統率をメインに含めるかの判定をフォーマットの算出結果に従う。

### 保存の判定順序

| 順序 | 判定 | 結果 |
| --- | --- | --- |
| 1 | 更新のとき、指定したフォーマットがあるか | 無いときは 404 とする |
| 2 | なりすまし対策トークンが有効か | 無効のときはアクセス拒否（HTTP 403）とする |
| 3 | 入力の検証を満たすか | 満たさないときは保存せず、入力した値のまま編集画面を再表示する |
| 4 | 検証を満たしたとき | フォーマットを保存し、識別子を確定する |
| 5 | 保存の後 | カード制限とフォーマットボードを次のとおり置き換える |

### カード制限の置き換え

入力にある禁止カードと制限カードを合わせた集合を求め、当該フォーマットに紐づくカード制限のうち次のいずれかに当たるものを削除する。

- 制限の種別がリーガル以外である。
- カードが上記の集合に含まれる。

リーガルであり、かつ集合に含まれないものは残す。削除の後、禁止カードと制限カードそれぞれに対応する種別を付けたカード制限を新たに作る。

### フォーマットボード

メインとサイドのフォーマットボードは、入力の上限と下限で作成または更新する。枚数の数え先となるボードは持たせない。

| 統率でカードを使用する | 統率のカードをメインボード枚数に含む | 結果 |
| --- | --- | --- |
| 真 | 真 | 統率のボードを作成または更新し、メインのフォーマットボードへの参照を持たせる |
| 真 | 偽 | 統率のボードを作成または更新し、メインのフォーマットボードへの参照を持たせない |
| 偽 | — | 統率のボードが既にあるときは削除する |

登録と更新のいずれも、保存した後は当該フォーマットの編集画面へ戻す。

### 削除の判定順序

| 順序 | 判定 | 結果 |
| --- | --- | --- |
| 1 | なりすまし対策トークンが有効か | 無効のときはアクセス拒否（HTTP 403）とする |
| 2 | 指定したフォーマットがあるか | 無いときは 404 とする |
| 3 | 大会・デッキ・アーキタイプのいずれかが当該フォーマットに紐づくか | 1 件でも紐づくときは削除せず、元の画面へ戻す |
| 4 | いずれも紐づかないとき | 当該フォーマットのカード制限をすべて削除し、フォーマットを削除して一覧へ戻す |

### エラー時の扱い

| エラー内容 | 処理 |
| --- | --- |
| なりすまし対策トークンが無効 | アクセス拒否（HTTP 403）とする |
| 対象のフォーマットが無い | 404 とする |
| 入力の検証を満たさない | 保存せず、入力した値のまま編集画面を再表示する |
| 削除時に大会・デッキ・アーキタイプのいずれかが紐づく | 削除せず、元の画面へ戻す |

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | 一覧と編集は対象のフォーマット。保存は入力欄一式となりすまし対策トークン。削除はなりすまし対策トークン |
| 成功時出力 | 一覧・新規登録・編集の各画面、または保存後の編集画面と削除後の一覧 |
| 失敗時出力 | 検証を満たさないときは同じ入力のまま編集画面を再表示する。削除できないときは元の画面へ戻す |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 追加・更新 | フォーマットを、入力の検証を満たして保存したとき |
| 削除・追加 | カード制限を、保存のたびに置き換えたとき |
| 追加・更新 | メインとサイドのフォーマットボードを、保存のたびに入力の上限と下限で反映したとき。既にあるときは更新し、無いときは作る |
| 削除 | 統率でカードを使用しない設定に変え、統率のボードが既にあるとき |
| 削除 | フォーマットと、それに紐づくカード制限を、削除できる条件を満たしたとき |

## 表示メッセージ

| メッセージID | 表示位置 | 画面上の文言 | 表示条件 | 後続処理 |
| --- | --- | --- | --- | --- |
| M14-10-MSG-001 | 入力項目直下 | 半角英数字、アンダースコア、ハイフン、スペースのみ入力できます。 | フォーマット名（英字）に使用できない文字を入力して保存したとき | フォーマット新規登録・編集画面に留まる |
| M14-10-MSG-002 | 入力項目直下 | 半角英数字、アンダースコア、ハイフン、スペースのみ入力できます。 | フォーマットコードに使用できない文字を入力して保存したとき | フォーマット新規登録・編集画面に留まる |
