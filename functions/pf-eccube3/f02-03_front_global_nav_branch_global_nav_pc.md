# F02-03（支店PC版ナビゲーション）

## 概要

支店PC版ナビゲーションは、支店（実店舗）の店舗紹介ページおよびイベントの店舗文脈のPC表示で、利用者が店舗を切り替え、店舗ページ内のセクションへ移動するための導線を表示する機能である。店舗紹介ページのPC表示では、店舗ヘッダ（店舗一覧への導線とカート）、左カラムの店舗一覧、右カラムのセクションナビ（店舗案内・初心者講習会・取り扱い商品・買取・スタッフ・その他・アクセスのうち登録済みのもの）を表示する。イベントの店舗文脈では、店舗選択ボタン列・店舗切替セレクトにより店舗を切り替える。

本書は実装手順ではなく、誰が・いつ・どの条件で・結果どうなるかを読むためのリバース詳細設計とする。本機能のカスタマイズ区分はカスタマイズである。画面・処理フロー・JS等の挙動はpf-eccube3（EC-CUBE3系）のHareruyaEcプラグインの店舗ヘッダブロック処理・店舗選択ブロック処理、テンプレート（`Block/shop_header.twig`・`ShopPage/index.twig`・`Block/events_shop_buttons.twig`・`Block/events_top_buttons.twig`）を正とし、DB関連（テーブル名・列名・保存先）はリニューアル先のec-cube-enterpriseを正とする。

対象はブラウザ経由の支店フロント（店舗紹介ページ・イベント店舗文脈）のPC表示に限定する。

本文ではフレームワークのコントローラ型名やメソッド名を主説明としない。「利用者視点の入口」にHTTPメソッドとサイトルートからのパスパターンを書く。コード探索でbind名が必要なときだけ「調査補助」へ書く。フロントのページであり管理画面プレフィックスは付かない。フロントのルートはロケール接頭辞`/{_locale}`の下に置かれる。

---

## 本書で扱うこと

- 支店PC版の店舗ヘッダの表示要素と導線
- 店舗紹介ページの左カラム店舗一覧と右カラムセクションナビの表示・出し分け
- イベント店舗文脈の店舗選択ボタン列・店舗切替セレクトによる店舗の切り替え
- 言語（ja／en）による表示の出し分け
- 本店ナビと支店ナビの境界、店舗の決まり方

---

## 本書で扱わないこと

以下は本書では仕様確定せず、実装または別機能の設計を正とする。

- 本店PC版・本店スマホ版ナビゲーション（F02-01・F02-02を正とする）
- 支店スマホ版ナビゲーション（F02-04を正とする）
- ヘッダの通知有無表示の判定（F02-05を正とする）
- 支店トップページ本体の表示（F01-02を正とする）
- イベントトップ・イベント検索・イベント一覧の本体（イベント機能を正とする）

## リニューアル移行時の扱い

本機能のカスタマイズ区分はカスタマイズである。店舗の決まり方・店舗切替・右カラムナビの表示順等の挙動はpf-eccube3（HareruyaEcプラグイン）の実装を正とし、DB関連（テーブル名・列名・保存先）はリニューアル先のec-cube-enterpriseを正とする。現行と移行先の主な差は次のとおり。移行先名を主とし、現行名を括弧で添える。

### フェーズ2対応（フェーズ1では実装不要）

本書は現行実装からのリバースであり、以下は現行挙動として記述しているが、Excel基本設計がフェーズ2対応としている。フェーズ1では実装・テストの対象外とする。

- 支店PC版ナビゲーション上の通知（※Excel基本設計 0302「支店PC版ナビゲーション上の通知」はフェーズ2対応。フェーズ1では実装しない）。フェーズ2対応。Excel原文: 「※通知はフェーズ2以降で設計予定とする」（0302 支店PC版ナビゲーション）

| 観点 | 現行（pf-eccube3） | 移行先（ec-cube-enterprise） |
|------|--------------------|------------------------------|
| 店舗マスタ | `mtb_shop`（HareruyaEcプラグインの独自テーブル） | `dtb_base_info`（複数ショップを行として保持。BaseInfoへ統合） |
| 店舗ID | `mtb_shop.id` | `dtb_base_info.id` |
| 店舗識別名（HTMLクラス名） | `mtb_shop.html_class_name` | `dtb_base_info.html_class_name`（コメント「支店URL」） |
| 店舗名・短縮店舗名 | `mtb_shop.name_jp`／`name_en`／`short_name_jp`／`short_name_en` | `dtb_base_info.shop_name`／`shop_name_eng`／`short_name_jp`／`short_name_en` |
| 全店舗一覧・店舗選択列の並び順 | `mtb_shop.rank`（並び順列） | `dtb_base_info`に`rank`／`sort_no`列が見当たらず、並び順キーはec-cube-enterprise実装で要確認 |
| 店舗ページ要素 | `dtb_shop_page_element`（PKは`shop_page_element_id`、店舗参照は`shop_id`） | `dtb_shop_page_element`（同一テーブル名。PKは`id`、店舗参照は`base_info_id`） |

挙動の説明でDB列に触れるときは移行先（ec-cube-enterprise）の列名を主とする。

## 用語

| 用語 | 説明 |
|------|------|
| 支店 | 実店舗。店舗マスタの1行に対応する。店舗の特定はパスの店舗識別名またはイベントの店舗選択で行う。 |

| 左カラム店舗一覧 | 店舗紹介ページの左カラムに並ぶ全店舗の一覧。表示中の店舗を選択状態にする。 |
| 右カラムセクションナビ | 店舗紹介ページの右カラムで、登録済みセクションへページ内移動するナビ。 |
| 店舗選択ボタン列・店舗切替セレクト | イベント店舗文脈で店舗を切り替える導線。短縮店舗名を表示する。 |

## 利用者視点の入口

| 入口 | URLエンドポイント | 期待されるふるまい |
|------|--------------------|--------------------|
| 店舗紹介ページをPCで開く | `GET /{_locale}/shoppage/{name}` | 店舗ヘッダ・左カラム店舗一覧・右カラムセクションナビを描画する。 |
| 左カラム店舗一覧の店舗リンク押下 | `GET /{_locale}/shoppage/{name}` | 選択した店舗の店舗紹介ページへ遷移する。 |
| 右カラムセクションナビ押下 | （同一ページ内アンカー） | 当該セクションへページ内移動する。 |
| 店舗ヘッダブロック単体（部分描画の境界） | `GET|POST /{_locale}/block/shop_header` | 店舗ヘッダの部分テンプレートを返す。 |
| イベント店舗文脈の店舗選択 | `GET /{_locale}/events?shop={店舗ID}` | 選択した店舗のイベント店舗文脈へ遷移する。 |
| イベント店舗選択ブロック単体（部分描画の境界） | `GET|POST /{_locale}/block/events/shop_buttons`、`GET|POST /{_locale}/block/events/top_buttons` | 店舗選択ボタン列・店舗切替セレクトの部分テンプレートを返す。 |

ナビは利用者が直接URLで開くより、支店各画面の一部として描画される。

## フロント挙動

| 観点 | 内容 |
|------|------|
| 表示要素 | 店舗ヘッダはロゴ、店舗一覧への導線（左上テキストと右側リンク）、マイページ、言語切替、カート（個数表示付き）を表示する。店舗紹介ページの左カラムは全店舗一覧（表示中を選択状態）とポイント確認バナー・Twitter、右カラムは登録済みセクションのナビと各セクションを表示する。イベント店舗文脈は店舗選択ボタン列（PC）と店舗切替セレクト（SP）を表示する。 |
| JS挙動 | 店舗切替セレクトの選択で対象店舗のイベント店舗文脈へ遷移する。カート個数は非同期取得した値で表示する。 |
| CSS・レイアウト | 支店文脈用にコンパクトなヘッダのスタイルを追加する。PC表示で店舗選択ボタン列を、SP表示で店舗切替セレクトを切り替える。右カラムナビは出力順の末尾要素へ末尾用クラスを付与する。 |
| モーダル・ポップアップ | 店舗紹介ページはポイント確認用モーダルを持つ（F01-02を正とする）。ナビ自体は専用モーダルを持たない。 |
| 入力項目 | 支店PC版ナビは商品検索フォームを持たない。店舗切替セレクトは導線であり入力保存を行わない。 |

店舗ヘッダの左上テキスト・右側リンクはいずれも店舗一覧（店舗一覧の利用者データページ）への導線とする。

## 処理フロー

### 店舗紹介ページのナビを描画する

1. 店舗識別名から店舗を特定する（特定・404の扱いはF01-02を正とする）。
2. 並び順付きの全店舗一覧を取得し、左カラム店舗一覧へ表示する。表示中の店舗を選択状態にする。
3. 登録済みの右カラム項目だけをセクションナビへ並べ、出力順の末尾要素へ末尾用クラスを付与する。
4. 店舗ヘッダをヘッダ領域へ描画し、カート個数を非同期取得して表示する。

### イベント店舗文脈の店舗を切り替える

1. 店舗選択（クエリの店舗ID）から対象店舗を決定する。店舗が見つからない場合は見つからない（HTTP404）として扱う。
2. 並び順付きの全店舗一覧を取得し、店舗選択ボタン列・店舗切替セレクトへ短縮店舗名で表示する。表示中の店舗を選択状態にする。
3. 店舗選択・切替セレクトの操作で、選択した店舗のイベント店舗文脈へ遷移する。

## 業務ルール・計算

| 項目 | 内容 |
|------|------|
| 店舗の決まり方 | 店舗紹介ページではパスの店舗識別名で、イベント店舗文脈ではクエリの店舗IDで店舗を決める。本店のようにサイトルート直下では決めない。 |
| 右カラムナビの表示有無 | 登録済みの右カラム項目だけをナビへ並べる。値の無いセクションはナビにも出さない。 |
| 右カラムナビの順序 | 店舗案内・初心者講習会・取り扱い商品・買取・スタッフ・その他・アクセスの定義順とし、末尾要素へ末尾用クラスを付与する。 |
| 店舗名表示 | 左カラム店舗一覧は店舗名を、イベント店舗文脈の選択導線は短縮店舗名を表示する。言語に応じて日本語名・英語名を用いる。 |
| 本店と支店の境界 | 本書のナビは支店文脈の導線である。本店のECヘッダ・グローバルナビ（F02-01）とは別部品である。 |

本機能は金額計算・税計算・丸めを行わない。

支店PC版ナビは入力フォームを持たないため、入力項目に紐づく表を持たない。

### エッジケース

| ケース | 扱い |
|--------|------|
| 店舗紹介ページで全右カラム項目が未登録 | 右カラムセクションナビ・各セクションを描画しない（F01-02を正とする）。 |
| イベント店舗文脈で店舗IDが該当なし | 見つからない（HTTP404）として扱う。 |
| 全店舗一覧が空 | 店舗一覧・店舗選択導線を描画しない。 |
| ロケールがja以外 | 英語名・英語表示で導線を構成する。 |

本機能は参照系（検索）であり、DBへの登録・更新・削除は行わない。テーブル名は ec-cube-enterprise を正典とする。

| 操作種別 | 対象テーブル | 契機・条件 |
|---------|--------------|------------|
| 検索 | dtb_base_info / dtb_shop_page_element / mtb_shop | 検索条件に合致するレコードを抽出する。 |

## バリデーション

支店PC版ナビは入力フォームを持たない。パスの店舗識別名は英数字とアンダースコアに限定する。イベントの店舗IDが該当しない場合は見つからない（HTTP404）として扱う。

## 排他制御・トランザクション
