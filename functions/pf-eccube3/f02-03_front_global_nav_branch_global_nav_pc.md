# F02-03（支店PC版ナビゲーション）

## 業務ロジック

### 店舗の決まり方

店舗紹介ページのときはパスの店舗識別名で店舗を決める。イベント店舗文脈のときはクエリの店舗IDで店舗を決める。本店のようにサイトルート直下のときは店舗を決めない。店舗の特定と該当なしの扱いは店舗紹介ページ（F01-02）を正とする。イベント店舗文脈で店舗が見つからないときは、見つからない（HTTP404）として扱う。

### 表示する要素

| 領域 | 内容 |
| --- | --- |
| 店舗ヘッダ | 支店の画面を表示したときに、ロゴ、店舗一覧への導線（左上のテキストと右側の導線）、マイページ、言語切替、カート（個数表示付き）を出す。左上のテキストと右側の導線は、いずれのときも店舗一覧へ向かう |
| 店舗紹介ページの左カラム | 店舗紹介ページのときに、全店舗一覧（表示中の店舗を選択状態にする）、ポイント確認バナー、Twitter を出す |
| 店舗紹介ページの右カラム | 登録済みのセクションだけを、ナビと本文に出す |
| イベント店舗文脈 | PC表示のときは店舗選択の並び、SP表示のときは店舗切替の選択欄 |
| ポイント確認用のモーダル | 店舗紹介ページのときに持つ（F01-02を正とする）。ナビ自体は専用のモーダルを持たない |

支店文脈のヘッダにはコンパクトな体裁を用いる。カートの個数は非同期で取得した値を表示する。

### 右カラムのセクションナビ

登録済みの右カラム項目だけをナビへ並べる。値の無いセクションはナビにも出さない。順序は店舗案内・初心者講習会・取り扱い商品・買取・スタッフ・その他・アクセスの定義順とする。出力順の末尾の要素には末尾用の体裁を付す。

### 店舗名の表示

左カラムの全店舗一覧は店舗名を表示する。イベント店舗文脈の選択導線は短縮店舗名を表示する。言語に応じて日本語名と英語名を使い分ける。全店舗一覧は並び順付きで取得し、表示中の店舗を選択状態にする。

イベント店舗文脈で店舗を選び直したときは、選択した店舗のイベント店舗文脈へ遷移する。

### 本店との境界

本書のナビは支店文脈の導線とする。本店のECヘッダとグローバルナビ（F02-01）は別の部品とする。本機能は金額計算・税計算・丸めを行わず、入力欄を持たない。

### フェーズ2対応（フェーズ1では実装しない）

Excel基本設計 0302「支店PC版ナビゲーション上の通知」はフェーズ2対応とし、フェーズ1ではこの項目だけ実装しない。Excel原文は「※通知はフェーズ2以降で設計予定とする」である。

### エラー時の扱い

| 事象 | 扱い |
| --- | --- |
| イベント店舗文脈の店舗IDが該当なしのとき | 見つからない（HTTP404）として扱う |
| カート個数の非同期取得に失敗したとき | 取得できないときの表示は本書では確定せず、実装を確認値とする |
| 描画に障害があったとき | 共通の例外処理に委ねる |

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | 支店各画面の表示要求（店舗識別名またはイベントの店舗ID、ロケール付き） |
| 成功時出力 | 店舗ヘッダ、店舗一覧、右カラムのセクションナビ、店舗選択の導線 |
| 失敗時出力 | 店舗が存在しないときは見つからない（HTTP404）。描画に失敗したときは共通の例外処理に委ねる |

### 入出力: 永続化

本機能はデータを更新しない。

## 表示メッセージ

本機能は固有の文言を持たない。表示するのは店舗名・短縮店舗名とセクション名である。
