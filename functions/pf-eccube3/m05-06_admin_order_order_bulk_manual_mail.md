# 受注管理 — メール一括送信

## 業務ロジック

### 送信対象の受け取り

一覧で選択した受注を対象とする。受注が 1 件も選択されていないときは、画面を作らず未検出として応答する。

指定した受注IDのうち受注が存在しないものがあるときは、その注文IDごとにエラーを出す。存在する受注だけを送信対象として残し、存在しない受注があっても画面は表示する。

### テンプレートの選択

テンプレートを指定していないときは本文が空になる。指定したときは、そのテンプレートの本文を読み込み、テンプレート内の差し込み箇所を置き換えたうえで編集欄に展開する。

指定できるのは受注向けの基本テンプレートで、日本語版と英語版の 2 系統だけである。自動送信メールのテンプレートは指定できない。

### 送信

入力に不備があるときは 1 通も送信せず、同じ画面に留まる。不備が無いときだけ送信する。

送信は対象受注ごとに 1 通ずつ行う。本文は受注ごとに差し込みを解決して組み立てるため、受注ごとに内容が変わる。

差し込む値は、受注・注文番号・配送サブ情報・消費税額とする。消費税額は、小計に送料と手数料を足し値引きを引いた金額から算出する。

件名は入力した値をそのまま使い、受注ごとに変えることはできない。送信が終わったときは、操作の起点になった画面へ戻る。送信前に内容を確かめる画面は無い。

## 入出力

### 出力: メール

| 項目 | 内容 |
| --- | --- |
| 宛先 | 受注のメールアドレス |
| 差出人 | 基本情報のメールアドレス1。表示名は基本情報の店名 |
| BCC | 基本情報のメールアドレス1 |
| 返信先 | 基本情報のメールアドレス3 |
| 送信エラーの戻り先 | 基本情報のメールアドレス4 |
| 件名 | 入力した件名 |
| 本文 | 受注ごとに差し込みを解決した本文 |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 送信履歴の登録 | 1 通送信するたび。件名・本文・送信日時・使用したテンプレート・受注・注文者の会員を記録し、作成者は設定しない |

宛先に届かなかったときも送信履歴を登録する。送信の成否は履歴に持たない。受注そのものは更新しない。

| M05-06-MSG-001 | 管理画面上部 | メールを送信しました。 | 手動メール（一件分）送信を完了したとき | メールを送信し、受注情報編集画面に遷移する |
| M05-06-MSG-002 | 管理画面上部 | 注文ID %s の注文情報を取得できませんでした。 | メール一括送信で、対象の注文情報を取得できないとき | エラーを表示し、受注情報検索・一覧画面に遷移する |
| M05-06-MSG-003 | 管理画面上部 | メールを送信しました。 | メール一括送信を完了したとき | メールを送信し、受注情報検索・一覧画面に遷移する |
| M05-06-MSG-004 | 入力項目直下 | 入力されていません。 | 必須項目が未入力のまま確認または送信したとき | 送信せず手動メール通知画面に留まる |
| M05-06-MSG-005 | 入力項目直下 | 入力されていません。 | テンプレートまたは件名が未入力のまま確認または送信したとき | 送信せず一括手動メール通知画面に留まる |
| M05-06-MSG-006 | 画面中央(ダイアログ) | お客様にメールを送信します。よろしいですか？ | メール一括送信の実行ボタンを押したとき（送信前確認） | キャンセル時は確認画面に留まり、OK時は送信処理を継続する |
