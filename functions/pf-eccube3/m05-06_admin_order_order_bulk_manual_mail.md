# 受注管理 — メール一括送信

## 業務ロジック

### 送信対象の受け取り

受注が 1 件も選択されていないときは、画面を作らず未検出として応答する。

指定した受注IDのうち受注が存在しないものがあるときは、その注文IDごとにエラーを出す。存在する受注だけを送信対象として残し、存在しない受注があっても画面は表示する。

### テンプレートの選択

テンプレートを選ぶまでは本文が表示されず、空欄のままになる。

テンプレートを選び直して画面を読み込み直しても、送信対象の受注はそのまま引き継がれる。

### 送信

入力に不備があるときは 1 通も送信せず、同じ画面に留まる。不備が無いときだけ送信する。

送信は対象受注ごとに 1 通ずつ行う。本文は受注ごとに差し込みを解決して組み立てるため、受注ごとに内容が変わる。

入力したヘッダーとフッターのほかに差し込む値は、受注・注文番号・配送サブ情報・消費税額・基本情報とする。消費税額は、小計に送料と手数料を足し値引きを引いた金額から算出する。

件名は入力した値をそのまま使い、受注ごとに変えることはできない。送信が終わったときは、操作の起点になった画面へ戻る。

## 入出力

### 出力: メール

| 項目 | 内容 |
| --- | --- |
| 宛先 | 受注のメールアドレス |
| 差出人 | 基本情報のメールアドレス1。表示名は基本情報の店名 |
| BCC | 基本情報のメールアドレス1 |
| 返信先 | 基本情報のメールアドレス3 |
| 送信エラーの戻り先 | 基本情報のメールアドレス4 |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 送信履歴の登録 | 1 通送信するたび。件名・本文・送信日時・使用したテンプレート・受注・注文者の会員を記録し、作成者は設定しない |

宛先に届かなかったときも送信履歴を登録する。送信の成否は履歴に持たない。受注そのものは更新しない。
