# F06-03（本店・支店で会員ログイン）

## 業務ロジック

### 認証の対象

本会員としてログインできる会員だけを認証の対象とする。

### 初期表示

既に会員としてログイン済みのときは、ログイン画面を表示せずマイページへ遷移する。ログイン状態の保持中は、メールアドレス欄に保持中の会員のメールアドレスを初期表示する。直近の認証失敗があるときは認証エラーの文言を、ログイン制限中は制限の文言を表示する。

ログイン制限中、すなわち制限解除日時が現在より後のときは、入力欄を表示せず制限の文言だけを表示する。店舗基本情報でログイン状態の保持が有効かつ既に保持状態のときは、保持の選択を有効として送る。

画面には見出し、会員向けの入力欄（メールアドレス、パスワード、ログイン状態の保持）、認証エラーまたは制限状態の文言、パスワード再設定の案内、初めて利用する人向けの会員登録の案内、旧サイト会員向けのパスワード再設定案内を表示する。

送信前に、メールアドレスとパスワードが入力されているかを画面上で確認する。認証の可否はサーバ側で判定する。

### ログインの判定順序

| 順序 | 判定 | 結果 |
| --- | --- | --- |
| 1 | ログイン制限中（制限解除日時が現在より後） | 制限の文言を表示し、入力欄を出さない |
| 2 | なりすまし対策トークンが不整合 | 認証せずログイン画面へ戻す |
| 3 | メールアドレスに一致する会員が存在しない | 認証エラーとして扱う |
| 4 | パスワードが不一致 | 認証エラーとして扱う |
| 5 | 認証成功 | ログイン失敗回数と制限解除日時を初期化し、共有トークンを発行して遷移先へ進む |

会員の存在有無とパスワード不一致は画面上で区別しない。認証に失敗するたびにログイン失敗回数を加算し、上限に達したときに制限解除日時を設定してログイン失敗回数を初期化する。

### 本店・支店の連携

本店でログインが成立したとき、本店と支店で共有するトークンを発行し、共有トークン用のCookieに設定する。

支店の画面表示時は、共有トークン用のCookieからトークンを取得する。トークンがあり、かつ未ログインのときにトークンを検証する。署名が不正なとき、会員の識別子が空のときは何もしない。検証に成功し会員が存在するときは、その会員でログイン状態を再確立する。

### ログイン状態の保持

店舗基本情報でログイン状態の保持が有効なときに、保持の選択欄を表示する。保持を有効にした場合はログイン状態を一定期間保持する。

### ログイン後の遷移

遷移先の指定があればその指定先へ、無ければ既定の遷移先へ進む。ログアウトすると会員の認証状態を終了し、トップへ戻す。

### エラー時の扱い

| 事象 | 扱い |
| --- | --- |
| メールアドレスまたはパスワードが未入力 | 認証を成立させずログイン画面へ戻す。認証失敗として扱う |
| なりすまし対策トークンが不整合 | 認証せずログイン画面へ戻す |
| メールアドレスに一致する会員が存在しない | 認証エラーとして扱う |
| パスワードが不一致 | 認証エラーとして扱う。ログイン失敗回数を加算する |
| ログイン失敗が上限を超えた | 制限解除日時を設定する。制限中は送信を受けても入力欄を出さない |
| 支店側でのトークン検証に失敗 | ログイン状態を再確立しない。エラーは表示しない |

本機能では金額・件数・在庫の計算を行わない。

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | メールアドレス、パスワード、ログイン状態の保持、なりすまし対策トークン。支店側は共有トークン用のCookie |
| 成功時出力 | 認証状態の確立、共有トークン用Cookieの発行、遷移先への遷移 |
| 失敗時出力 | ログイン画面に留まり、認証エラーまたは制限状態を表示する |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 更新 | 認証失敗時の、会員のログイン失敗回数の加算 |
| 更新 | ログイン失敗回数が上限に達したときの、制限解除日時の設定とログイン失敗回数の初期化 |
| 更新 | 認証成功時の、ログイン失敗回数と制限解除日時の初期化 |
