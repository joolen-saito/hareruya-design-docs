# コンテンツ管理 — ページ管理

## 業務ロジック

### 一覧の対象

PC端末種別のページをID昇順で表示する。IDが 0 のページは一覧から除く。

### 新規作成の初期表示

新規のページは、端末種別をPC、編集可否区分を利用者作成として生成する。

### 編集の初期表示

ページIDに該当するページが無いときは、編集画面を表示せず、システムエラーの画面を表示する。テンプレート本文欄には、該当ページのテンプレートファイルの内容を初期表示する。

URLとファイル名を編集できるかは、ページの編集可否区分だけで決まる。編集可否区分が既定（初期投入）のページでは、URLとファイル名を表示するだけで入力欄を出さず、編集できない。それ以外のページでは、URLとファイル名の入力欄を表示する。URL・ファイル名の文字列を `/user_data` と照合する判定は行わない。

### 保存時のふるまい

編集でファイル名を変えて保存したときは、変更前の名前のテンプレートファイルが残っていればそれを削除する。

保存を終えたときは、登録したページの編集画面へ戻る。

### URLの一意性

同一端末種別でURLが重複するときは検証エラーとする。重複の判定では、新規はIDを除外せず、編集は自身のIDだけを除外する。

### 削除

削除しようとしたページが既に存在しないときは、削除対象なしのメッセージを表示して一覧へ戻る。削除するときは、ページ情報に加えて、テンプレートファイルが存在すればそれも削除する。

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 一覧・フォームの表示要求。新規・編集はページ属性とテンプレート本文。削除はページID。 |
| 成功時出力 | 新規・編集のときは編集画面への遷移（302）と登録完了メッセージ。削除のときは一覧への遷移（302）と削除完了メッセージ。 |
| 失敗時出力 | 検証に外れたときは同一フォームの再描画。編集で対象ページが無いときはシステムエラーの画面。削除で対象ページが無いときは削除対象なしのメッセージ。 |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 追加 | ページを新規登録したとき |
| 更新 | ページを編集して保存したとき |
| 削除 | 利用者作成ページを削除したとき |
