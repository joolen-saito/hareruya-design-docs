# イベント管理 — バナー設定

## 業務ロジック

### 一覧の対象

イベントバナーの一覧と設定の入力欄を表示する。店舗の指定があるときは、当該店舗のバナーに絞り込む。

### 設定・更新

送信内容を検証し、通過したときにイベントバナーを設定・更新する。検証に失敗したときは保存せず、設定画面を再表示する。

### 削除

指定したバナーを削除する。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| 検証に失敗 | 保存せず、設定画面を再表示する |
| 認証・権限が不足 | アクセスできない |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | バナーの設定内容、店舗、削除対象、なりすまし対策の検証値 |
| 成功時出力 | イベントバナーの設定・更新・削除を行い、完了のメッセージを表示する |
| 失敗時出力 | 検証に失敗したときは設定画面を再表示する |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 登録・更新 | バナー設定の保存 |
| 削除 | 指定したバナーの削除 |
