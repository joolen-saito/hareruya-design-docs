# 商品管理 — 略称タグCSV入力

## 業務ロジック

### 取り込むCSV

取り込み画面には、受け付けるヘッダの説明を表示する。

取り込みは、ヘッダに必須の項目がそろっている場合だけ実行する。ヘッダが想定と異なる場合は取り込まない。

### 登録の扱い

取り込んだ内容で略称タグを登録する。

### エラー時の扱い

| エラー内容 | 扱い |
|------------|------|
| ヘッダが想定と異なる、または入力に不備がある | 取り込まず、取り込み画面を再表示する。 |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | CSVファイル |
| 成功時出力 | 略称タグの登録 |
| 失敗時出力 | ヘッダの不正・入力の不備によるエラーと取り込み画面の再表示 |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 追加 | 略称タグCSVの取り込み |
