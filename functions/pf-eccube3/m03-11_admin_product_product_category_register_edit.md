# 商品管理 — カテゴリ登録・編集

## 業務ロジック

### 刷新後は実装しない（廃止）
- Excel基本設計 0204 識別ID:12 により廃止。刷新後は実装しない。

### 新規登録フォームの表示

親カテゴリを指定して子カテゴリの一覧から開く。指定した親カテゴリが存在しないときは表示しない。

### 編集フォームの表示

対象のカテゴリを指定して開く。指定したカテゴリが存在しないときは表示しない。保存ボタンの文言は更新側にする。

### 入力欄の表示条件

新規登録・編集のどちらも、入力欄と保存ボタンは対象の階層がカテゴリ階層の上限（確認値 5）未満のときだけ表示する。上限と同じ階層になるカテゴリは、編集も子カテゴリの作成も本画面から行えない。ルート直下への新規登録も本画面では提供しない。

### 保存の判定順序

| 順序 | 判定 | 結果 |
|------|------|------|
| 1 | 入力が妥当か | 不備があれば保存せず、同じ画面に項目エラーを表示する |
| 2 | 階層がカテゴリ階層の上限（確認値 5）以下か | 超えるときは保存せず、要求が不正なものとして処理を中止する |

### 表示順の決まり方

新規登録では、親カテゴリの表示順に応じて新規カテゴリの表示順を決め、それより大きい表示順を持つカテゴリを先にまとめて繰り上げてから登録する。

### 兄弟カテゴリ一覧の操作

編集中のカテゴリは、兄弟カテゴリの一覧で編集への入口を持たず、編集中である旨を示す。

### CSV出力項目設定

CSV出力項目設定は、システム設定のCSV出力項目設定画面を、カテゴリCSVを対象とした状態で開く。カテゴリCSVのダウンロードとは別の操作である。

### 保存後の遷移

保存に成功したときは、新規登録・編集のいずれも、保存したカテゴリの編集画面へ遷移する。

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 新規登録は親カテゴリ、編集は対象カテゴリ。保存時は入力項目。 |
| 成功時出力 | 保存したカテゴリの編集画面へ遷移する。 |
| 失敗時出力 | 入力の検証に失敗したときは同じ画面を再表示し、項目エラーを表示する。階層の上限を超えるときは保存しない。 |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| カテゴリの登録 | 新規登録の保存 |
| カテゴリの更新 | 編集の保存 |
| 兄弟カテゴリの表示順の更新 | 新規登録の保存 |
