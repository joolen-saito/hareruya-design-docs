# バッチ 会員管理 — ポイント有効期限通知

## 業務ロジック

### 通知の対象

設定された2段階の事前通知日数のそれぞれについて、当該日数で失効対象となる会員だけを抽出する。

| 段階 | 対象 |
| --- | --- |
| 1段階目の事前通知日数 | 当該日数で失効対象となる会員だけ |
| 2段階目の事前通知日数 | 当該日数で失効対象となる会員だけ |

対象の会員が1件も無いときは通知しない。

### 通知の内容

| 項目 | 求め方 |
| --- | --- |
| 失効予定日 | 現在日に事前通知日数を加えた日とする |
| 失効予定ポイント | 保有ポイント、集計値、対象ポイントのうち最小の値だけを採る |

会員ごとに、失効予定ポイントと失効予定日を含む通知メールを送信する。段階ごとに対象を抽出したときだけ送信する。

### エラー時の扱い

| 事象 | 扱い |
|------------|------|
| コマンド名が未指定・不一致のとき | 処理を行わずに終了する |
| 対象の会員が無いとき | 通知メールを送らない |
| 送信でエラーが起きたとき | エラーメッセージをコンソールに出力する |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | コマンド名と、事前通知日数の設定。 |
| 成功時出力 | 各段階の対象会員への有効期限通知メールの送信。対象が無いときは送信しない。 |
| 失敗時出力 | エラーメッセージのコンソール出力。 |

本バッチでは、いずれの場合も他のAPIを呼び出さない。

### 出力: メール

| 項目 | 内容 |
| --- | --- |
| 宛先 | 当該段階で失効対象となる会員だけ。対象が無いときは送らない |
| 内容 | 失効予定ポイントと失効予定日だけ |

### 入出力: 永続化

いずれの場合もデータを更新しない。

## 表示メッセージ

この機能は、いずれの場合も画面のメッセージを扱わない。
