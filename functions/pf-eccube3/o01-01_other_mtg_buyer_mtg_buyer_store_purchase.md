# o01-01_other_mtg_buyer_mtg_buyer_store_purchase（その他_MTGバイヤー_店頭買取）

## 業務ロジック

### 店頭買取の受付

フロントの店頭買取申込で、会員または非会員が申込情報を入力する。申込確定時に店頭買取受注を作成し、査定番号を採番する。店頭買取ステータスは査定前として登録する。受付時の本人確認、買取品の預かり、身分証コピーなどの実作業は運用で行う。

### 査定対象の抽出

店頭買取受注一覧取得は、商品到着・査定中・振込前・保留・査定再開の状態にある受注を対象にする。成立・キャンセル・ダブルチェック済・データ出力済などは査定対象一覧から外れる。認証した管理者に所属店舗があるときは、その店舗に一致する店頭買取受注だけを返す。所属店舗が無いときは店舗で絞り込まない。

### 査定の開始

MTGバイヤーはログインで認証トークンを取得し、店頭買取受注一覧で査定対象を取得する。査定開始時はステータスを査定中へ更新する。受注のステータス、査定担当者、更新日時、ステータス変更履歴を保存する。

### 査定結果の確定

MTGバイヤーは商品検索・商品取得で査定対象の商品情報を取得し、査定明細として商品規格ID・商品名・数量・買取単価・販売価格・部門などを送信する。受注IDで店頭買取受注を特定し、該当が無いときは該当なしとして返す。ステータス・明細配列・明細各項目を検証し、検証エラーがあれば保存せず入力不正を返す。

既存の明細・個別入力商品・在庫・在庫履歴を削除して、送信された明細で作り直す。送信されなかった既存明細は残らない。商品規格IDが空の明細は個別入力商品として登録し、商品規格に紐づかないため商品規格単位の在庫集計には含めない。商品規格に紐づく明細は商品規格ごとに数量を合算し、店頭買取受注在庫と在庫履歴を作成する。

買取合計金額は送信明細の買取単価×数量を合算し、10円単位へ切り上げる。MTGバイヤー側の表示値ではなく、この再計算した値を保存する。ステータス・買取合計金額・査定担当者・更新日時・成立日時またはキャンセル日時を保存する。更新前後でステータスが異なるときだけステータス変更履歴を登録する。同じステータスへの詳細更新では明細・在庫は作り直すが、ステータス変更履歴は追加しない。

### 査定後の店頭買取業務

査定結果を顧客と確認する。買取キャンセルのときはステータスを買取キャンセルへ、買取成立のときはステータスを買取成立へ更新する。管理画面では買取一覧・買取詳細・買取商品履歴・買取集計・古物台帳用CSV・在庫登録用CSVなどで確定済みデータを参照・出力する。

### 他機能との境界

査定表印刷、本人確認の実作業、出金、バーコード印刷、Backlog起票、スマレジ、仕入れ統合作業は、本書で確認できる範囲外の運用を正とする。店頭買取集計は店頭買取集計バッチで実行される。MTGバイヤー本体が直接バッチを起動する仕様は確認できない。

参照は実行時点の最新データを返す。詳細更新は明細・在庫を全置換するため、同じ受注に再送すると送信内容で上書きされる。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| 認証不可 | 認証拒否を返し、店頭買取データを返さず更新しない |
| 受注が存在しない | 該当なしとして返し、更新しない |
| ステータス不正 | 入力不正として返し、更新しない |
| 明細不正 | 入力不正として返し、既存明細・在庫を削除しない |
| 保存処理中の例外 | 共通例外処理に従う。未確定の更新は取り消す |
| 外部運用の失敗 | Backlog、スマレジ、Excelマクロ、バーコード印刷などは本書では処理結果を保証しない。各運用を正とする |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 認証トークン、店頭買取受注ID、ステータスID、査定明細、コメント、本人確認情報、商品検索条件など |
| 成功時出力 | JSON応答、店頭買取受注の更新、明細・個別入力商品・在庫・在庫履歴の作成、ステータス変更履歴の作成 |
| 失敗時出力 | 認証拒否、該当なし、入力不正、処理失敗のJSON応答。保存前の検証エラーでは更新を行わない |

MTGバイヤーが利用する接続点は、ログイン、店頭買取受注一覧取得、詳細更新、コメント更新、ステータス更新、本人確認更新、商品検索・商品取得である。参照はJSONで対象データを返し、更新は対象データを保存して成功コードまたは更新結果を返す。認証不可・対象なし・入力不正・保存例外は各接続点の設計を正とする。

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 追加 | 店頭買取申込の確定時に、店頭買取受注を作成し査定番号を採番する |
| 削除 | 査定結果の確定時に、既存の明細・個別入力商品・在庫・在庫履歴を削除する |
| 追加 | 査定結果の確定時に、送信明細から明細・個別入力商品・在庫・在庫履歴を作成する |
| 更新 | 査定開始・査定結果確定・買取成立／キャンセル時に、受注のステータス・買取合計金額・査定担当者・更新日時・成立日時またはキャンセル日時を更新する |
| 追加 | 更新前後でステータスが異なるときに、ステータス変更履歴を登録する |
