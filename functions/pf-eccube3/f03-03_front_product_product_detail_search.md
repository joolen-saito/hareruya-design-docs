# F03-03（商品詳細検索）

## 概要

フロントの商品詳細検索は、利用者が商品名・カテゴリ・カードセット・色・レアリティ・カードタイプ・フォーマット・価格帯・フォイル・言語・在庫・マナコスト・サブタイプといった条件を組み合わせて入力し、商品一覧へ検索条件を送る詳細検索フォームの機能である。フォームはGETで商品一覧の検索エンドポイントへ送信し、入力値はクエリ文字列として一覧（F03-01）へ引き渡される。

本書は実装手順ではなく、誰が・いつ・どの条件で・結果どうなるかを読むためのリバース詳細設計とする。確認値はpf-eccube3（EC-CUBE3系）のHareruyaEcプラグインの商品検索フォーム種別（`front_product_search`）、商品一覧処理、テンプレート（`Product/search.twig`・`Product/product_list_unisearch.twig`内の検索フォーム表示）を正とする。本機能のカスタマイズ区分はカスタマイズであり、画面挙動の参照リポはpf-eccube3、DB関連の記述はec-cube-enterpriseを正とする。

対象はブラウザ経由のフロントに限定する。フロントのルートはロケールを先頭に付けた`/{_locale}`配下に配置される。

本文ではフレームワークのコントローラ型名やメソッド名を主説明としない。本文ではルートbind名の網羅は主説明とせず、「利用者視点の入口」にHTTPメソッドとサイトルートからのパスパターンを書く。コード探索でbind名が必要なときだけ「調査補助」へ書く。

- 詳細検索フォームの入力項目とその選択肢・初期値
- フォーム送信先と送信方式（GET）と、検索条件のクエリへの引き渡し
- 各入力項目が商品の抽出・絞り込みにどう作用するか（一覧側の抽出はF03-01を正とする）
- 並び順・タグ等の隠しパラメータの引き継ぎ

- カテゴリ一覧画面（F03-04 を正とする）

## リニューアル移行時の扱い

本機能は検索フォームの表示と送信のみで、入力値を永続化しない。画面挙動はpf-eccube3を確認値とし、選択肢提示に参照するマスタのスキーマはec-cube-enterpriseを正とする。現行と移行先で次の点を確認する。

| 観点 | 現行（pf-eccube3） | 移行先（ec-cube-enterprise） |
|------|--------------------|------------------------------|
| カテゴリの除外判定 | フロント検索非表示の親カテゴリ配下を除外 | カテゴリ`dtb_category`の`front_search_hide_flg`（フロント検索非表示）で判定。同等スキーマ。 |
| カードセットの並び | カードセットのリリース日降順 | `mtb_cardset`の`release_date`降順。 |
| カードタイプ・フォーマットの限定 | 商品検索対象フラグ・ランクで限定 | `mtb_cardtype`・`mtb_format`に同等の対象フラグ・並び順を保持。対象フラグの列名はec-cube-enterprise実装で要確認。 |
| 送信先・送信方式 | GETで商品一覧の検索エンドポイントへ送信 | 同一（一覧側の経路に依存。F03-01を正とする）。 |

本フォームは保存処理を持たないため、移行に伴うデータ移送はない。

## 用語

| 用語 | 説明 |
|------|------|
| 詳細検索フォーム | 複数条件を組み合わせて商品一覧へ送る検索フォーム。フォーム種別`front_product_search`。 |
| 展開選択 | 複数の選択肢をチェックボックス・ラジオとして展開表示する形式。色・レアリティ・カードタイプ・言語・フォイル・在庫・マナコスト等で用いる。 |
| カードセット | 商品が属するセット区分。リリース日の降順で選択肢を提示する。 |
| フォーマット | 大会フォーマット区分。商品検索対象のフォーマットのみを選択肢とする。 |
| マナコスト | カードのコスト。0から上限の数値と「上限+」を選択肢とする。 |

## 利用者視点の入口

| 入口 | URLエンドポイント | 期待されるふるまい |
|------|--------------------|--------------------|
| 詳細検索フォームを表示する | `GET /{_locale}/products/search`（検索条件なし） | 商品結果を表示せず、詳細検索フォームを表示する。 |
| 詳細検索フォームを送信する | `GET /{_locale}/products/search?（入力値）` | 入力値をクエリとして商品一覧の検索エンドポイントへ送り、検索結果一覧を表示する。 |

フロントのページであり管理画面プレフィックスは付かない。ロケールは`/{_locale}`の先頭区切りで決まる。フォームは検索条件が空のときに表示され、送信先・表示先ともに商品一覧の検索エンドポイントである。

## フロント挙動

| 観点 | 内容 |
|------|------|
| 表示要素 | 商品名入力、カテゴリ選択、カードセット選択、色・色アイデンティティ・レアリティ・カードタイプの展開選択、フォーマット選択、リーガル絞り込み、イラストレーター選択、価格帯（下限・上限）選択、フォイル展開選択、言語展開選択、在庫展開選択、マナコスト展開選択、サブタイプ選択、色・カードタイプのAND／OR切替。 |
| JS挙動 | フォームはGETで商品一覧の検索エンドポイントへ送信する。並び順・カードID・タグ・セールフラグ等は隠しパラメータとして引き継ぐ。商品名入力には入力補助（ユニサジェスト）を併用する。 |
| CSS・レイアウト | 展開選択は選択状態を画像・クラスで示す。PC用とスマートフォン用で並びを切り替える。 |

商品名入力欄はオートコンプリートを無効にし、プレースホルダを表示する。

## 処理フロー

### フォームを表示する

1. 検索条件が空のとき、詳細検索フォームと共通要素のみを表示する。
2. カテゴリの選択肢は、フロント検索で非表示とする親配下を除いて提示する。
3. カードセットはリリース日の降順、イラストレーター・サブタイプは名称順で選択肢を提示する。

### フォームを送信する

1. 利用者が条件を入力・選択して送信する。
2. 入力値をクエリ文字列として商品一覧の検索エンドポイントへGETで送る。
3. 並び順（`sort`・`order`）・カードID・タグ・セールフラグがある場合は隠しパラメータとして引き継ぐ。
4. 一覧側で条件に合致する商品を抽出して表示する（抽出はF03-01を正とする）。

## 業務ルール・計算

| 項目 | 内容 |
|------|------|
| 送信方式 | フォームはGETで商品一覧の検索エンドポイントへ送る。入力値はクエリ文字列として一覧へ引き渡される。 |
| 未入力条件 | 未入力・未選択の条件は抽出条件に加えない。 |
| AND／OR切替 | 色・カードタイプはAND／ORの切替を持ち、複数選択時の結合条件を指定する。 |
| 価格帯 | 下限・上限は所定の価格区切りの選択肢から選ぶ。 |
| カテゴリ選択肢の除外 | フロント検索で非表示とする親カテゴリ配下の項目は選択肢から除外する。 |
| 隠しパラメータ | 並び順・カードID・タグ・セールフラグは入力欄ではなく隠しパラメータとして送信に引き継ぐ。 |

### 入力項目

| 項目名 | 必須／任意 | 最大長 | 初期値 | 保存先・扱い |
|--------|------------|--------|--------|----------------|
| 商品名 | 任意 | 商品名の最大長（`HareruyaEc.const.product.length.name`の確認値。テキスト入力） | 未入力 | クエリ`product`。商品名での絞り込みに用いる。保存しない。 |
| カテゴリ | 任意 | — | 未選択 | クエリ`category`。単一選択。非表示親配下を除いた選択肢。保存しない。 |
| カードセット | 任意 | — | 未選択 | クエリ`cardset`。単一選択。リリース日降順の選択肢。保存しない。 |
| 色 | 任意 | — | 未選択 | クエリ`colors`。複数選択（展開）。色の絞り込み。保存しない。 |
| 色アイデンティティ | 任意 | — | 未選択 | クエリ`colorIdentities`。複数選択（展開）。保存しない。 |
| レアリティ | 任意 | — | 未選択 | クエリ`rarity`。複数選択（展開）。保存しない。 |
| カードタイプ | 任意 | — | 未選択 | クエリ`cardtypes`。複数選択（展開）。商品検索対象のカードタイプのみ。保存しない。 |
| フォーマット | 任意 | — | 未選択 | クエリ`format`。単一選択（展開）。商品検索対象のフォーマットのみ、ランク順。保存しない。 |
| リーガル | 任意 | — | 未選択（オフ） | クエリ`legalFlg`。チェックボックス。保存しない。 |
| イラストレーター | 任意 | — | 未選択 | クエリ`illustrator`。単一選択。名称順の選択肢。保存しない。 |
| 価格帯（下限） | 任意 | — | 未選択 | クエリ`priceFrom`。所定の価格区切りから単一選択。保存しない。 |
| 価格帯（上限） | 任意 | — | 未選択 | クエリ`priceTo`。所定の価格区切りから単一選択。保存しない。 |
| フォイル | 任意 | — | 未選択 | クエリ`foilFlg`。複数選択（展開）。ノーマル・フォイルの値。保存しない。 |
| 言語 | 任意 | — | 未選択 | クエリ`language`。複数選択（展開）。日本語・英語・その他。保存しない。 |
| 在庫 | 任意 | — | すべて表示 | クエリ`stock`。単一選択（展開）。すべて表示／在庫ありのみ。保存しない。 |
| マナコスト | 任意 | — | 未選択 | クエリ`manaCost`。複数選択（展開）。0から上限の数値と「上限+」。保存しない。 |
| サブタイプ | 任意 | — | 未選択 | クエリ`subtype`。単一選択。ロケールに応じた名称表示、名称順。保存しない。 |
| 色のAND／OR | 必須（既定値で送信） | — | OR | クエリ`colorsType`。ラジオ。複数選択時の結合条件。保存しない。 |
| カードタイプのAND／OR | 必須（既定値で送信） | — | OR | クエリ`cardtypesType`。ラジオ。複数選択時の結合条件。保存しない。 |

各項目は商品の永続化先を持たず、検索条件のクエリとして一覧（F03-01）へ引き渡すためのものである。最大長は商品名のみテキスト最大長を持ち、その他は選択肢からの選択であるため最大長を持たない。

### エッジケース

| ケース | 扱い |
|--------|------|
| すべて未入力で送信 | 全件相当となり一覧側で結果を組み立てない（F03-01 の全件判定を正とする）。 |
| 価格帯の下限が上限を上回る | 一覧側の抽出条件として扱う（結果は一覧の抽出を正とする）。 |
| 非表示親配下のカテゴリ | 選択肢に出さない。 |

## DBカラム

機能に直接関係する列のみ記載する。型や一覧の細部はスキーマを参照する。本機能は入力値を商品テーブルへ保存しない。選択肢の提示に次のマスタを参照する。

| テーブル | 列 | メモ |
|---------|-----|------|
| `dtb_category` | `front_search_hide_flg` | 選択肢から除外する親配下の判定に用いる。 |
| `mtb_cardset` | `release_date` | 選択肢の並び順に用いる。 |
| `mtb_cardtype` / `mtb_format` | 商品検索対象フラグ・並び順 | 商品検索対象の選択肢の限定・並びに用いる。対象フラグの列名はec-cube-enterprise実装で要確認。 |

### DB操作

本機能は参照系（検索）であり、DBへの登録・更新・削除は行わない。テーブル名は ec-cube-enterprise を正典とする。

| 操作種別 | 対象テーブル | 契機・条件 |
|---------|--------------|------------|
| 検索 | dtb_category / mtb_cardset / mtb_cardtype / mtb_format | 検索条件に合致するレコードを抽出する。 |
