# F03-04（カテゴリ一覧）

## 概要

フロントのカテゴリ一覧は、商品をたどるための入口として、カードセットやカテゴリを見出しとリンクで一覧表示し、利用者が選んだ区分に対応する商品一覧（検索結果）へ誘導する画面である。表示はカードセット・レアリティ・カテゴリ等のマスタから組み立て、各リンクは商品一覧の検索エンドポイントへ検索条件付きで遷移する。

本書は実装手順ではなく、誰が・いつ・どの条件で・結果どうなるかを読むためのリバース詳細設計とする。確認値はpf-eccube3（EC-CUBE3系）のHareruyaEcプラグインのカテゴリ一覧処理、テンプレート（`Product/category.twig`）、カードセット・レアリティ・カテゴリの各マスタ取得を正とする。本機能のカスタマイズ区分はカスタマイズであり、画面挙動の参照リポはpf-eccube3、DB関連の記述はec-cube-enterpriseを正とする。

対象はブラウザ経由のフロントに限定する。フロントのルートはロケールを先頭に付けた`/{_locale}`配下に配置される。

本文ではフレームワークのコントローラ型名やメソッド名を主説明としない。本文ではルートbind名の網羅は主説明とせず、「利用者視点の入口」にHTTPメソッドとサイトルートからのパスパターンを書く。コード探索でbind名が必要なときだけ「調査補助」へ書く。

## リニューアル移行時の扱い

本機能は閲覧専用で台帳を更新しない。画面挙動はpf-eccube3を確認値とし、見出し・リンク組み立てに参照するマスタのスキーマはec-cube-enterpriseを正とする。現行と移行先で次の点を確認する。

| 観点 | 現行（pf-eccube3） | 移行先（ec-cube-enterprise） |
|------|--------------------|------------------------------|
| 表示カードセット | 特殊セットを除きリリース日順 | `mtb_cardset`の`release_date`順。特殊セット除外条件は同等。 |
| レアリティ名 | レアリティの日本語・英語名 | `mtb_rarity`の`name_jp`・`name_en`。 |

| カードセット見出しのリンク化 | レアリティ表示フラグの有無で切替 | `mtb_cardset`に同等の表示フラグを保持。列名はec-cube-enterprise実装で要確認。 |

本画面は導線提供のみのため、移行に伴うデータ移送はない。

## 用語

| 用語 | 説明 |
|------|------|
| カードセット | 商品が属するセット区分。特殊セットを除き、リリース日順に表示する。 |
| レアリティ | カードの希少度区分。カードセット配下のリンクの絞り込みに用いる。 |
| カテゴリ（フロント用） | フロント表示用のカテゴリ区分。表示フラグを持つ。 |
| 予約販売 | リリース前のカードセットに付す表示。 |

## 利用者視点の入口

| 入口 | URLエンドポイント | 期待されるふるまい |
|------|--------------------|--------------------|
| カテゴリ一覧を開く | `GET /{_locale}/products/category` | カードセット・レアリティ・カテゴリの見出しとリンクの一覧を表示する。 |
| カテゴリ一覧内のリンクを押下 | `GET /{_locale}/products/search?（検索条件）` | 当該区分の検索条件付きで商品一覧へ遷移する。 |

フロントのページであり管理画面プレフィックスは付かない。ロケールは`/{_locale}`の先頭区切りで決まる。

## フロント挙動

| 観点 | 内容 |
|------|------|
| 表示要素 | 「商品カテゴリ一覧」の見出し、カードセットごとの見出し（記号画像・名称・予約販売表示）、カードセット配下のレアリティ別・パック／ボックス等のリンク、表示対象カテゴリのリンク。 |
| JS挙動 | 各リンクは商品一覧の検索エンドポイントへ検索条件付きで遷移する。本画面固有の非同期取得は持たない。 |
| CSS・レイアウト | カードセット見出しに記号画像を背景表示する。レアリティ表示フラグの有無で見出し自体をリンクにするか配下リンクを展開するかを切り替える。 |
| モーダル・ポップアップ | 本画面固有のモーダルは持たない。 |

リリース前のカードセットには予約販売の表示を付す。

---

## 処理フロー

### カテゴリ一覧を表示する

1. 特殊セットを除いたカードセットをリリース日順に取得する。
2. 全レアリティと、レア・神話レアの区分を取得する。
3. フロント表示用カテゴリの英語名一覧と、表示対象の親カテゴリ配下のカテゴリを取得する。
4. これらを見出しとリンクへ組み立てて表示する。

### カテゴリ一覧のリンクを押下する

1. 利用者がカードセット・レアリティ・パック／ボックス等のリンクを押す。
2. 当該区分に対応する検索条件（カードセット・レアリティ・タグ・並び順等）を付与して商品一覧の検索エンドポイントへ遷移する。
3. 以降の抽出・件数・並び替えは商品一覧（F03-01）の実装に従う。

## 集計条件

| 指標 | 集計の要点 |
|------|------------|
| 表示カードセット | 特殊セットを除き、リリース日順に取得する。 |
| 表示レアリティ | 全レアリティを取得し、レア・神話レアを別途取得してリンクの絞り込みに用いる。 |
| 表示カテゴリ | 表示対象の親カテゴリ配下のフロント用カテゴリを取得する。 |

## 業務ルール・計算

| 項目 | 内容 |
|------|------|
| カードセットの並び | リリース日順で表示する。 |
| 予約販売表示 | リリース前のカードセットには予約販売の表示を付す。 |
| 見出しのリンク化 | カードセットのレアリティ表示フラグが有効なら見出し自体をリンクにし、無効なら配下のレアリティ別・パック／ボックスのリンクを展開する。 |
| リンクの検索条件 | レアリティ別リンクはカードセットとレアリティ、パック／ボックスリンクはセットコードとパック・ボックスのタグを検索条件に付与する。並び順は色順を既定とする。 |

本機能は閲覧と導線が主であり、業務計算・データ更新は行わない。

### エッジケース

| ケース | 扱い |
|--------|------|
| 特殊セット | カードセット一覧から除外する。 |
| レアリティ表示フラグ無効のカードセット | 見出しをリンクにせず、配下のリンクを展開する。 |
| 表示対象外の親配下カテゴリ | 一覧に出さない。 |
