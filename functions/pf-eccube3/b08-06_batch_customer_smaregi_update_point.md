# バッチ 会員管理 — スマレジ使用ポイント連携

## 業務ロジック

### 実行の条件

引数の受注IDが未指定、または数値でないときは何もせずに終了する。

### 連携する内容

受注IDから受注サブと会員を特定し、会員のスマレジIDに対して、受注の消費ポイントを負の値として連携する。すなわちスマレジ側の会員ポイントを消費ポイント分だけ減らす。

### 失敗時の記録

連携に失敗したときは、受注サブにエラーメッセージと連携エラーの区分を記録する。記録した受注サブは後続の再連携の対象となる。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| 受注IDが未指定・数値でない | 処理を行わずに終了する |
| 連携失敗 | エラーメッセージと連携エラーの区分を受注サブに記録する |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | コマンド名と受注ID |
| 成功時出力 | スマレジの会員ポイントへ減算を反映する |
| 失敗時出力 | 受注サブへエラーメッセージと連携エラーの区分を記録する |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 更新 | 連携に失敗したときに、受注サブのエラーメッセージと連携エラーの区分を記録する |
