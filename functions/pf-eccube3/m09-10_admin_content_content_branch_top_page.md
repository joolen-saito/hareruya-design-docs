# コンテンツ管理 — 支店トップページ管理

## 業務ロジック

### バナー画像の差し替え

新しいバナー画像を指定して保存したときは、登録済みのバナー画像を保管領域から削除したうえで新しい画像を保管領域へ保存する。差し替え前の画像は残らない。

画像を指定せずに保存したときは、登録済みのバナー画像をそのまま引き継ぐ。

### タイル入力欄の補完

登録済みのタイルがタイル位置の数に満たないときは、不足分のタイル入力欄を画面側で追加する。追加した入力欄に入力して保存すると、編集中の支店のタイルとして新規に登録する。

### 支店トップページへの反映

支店トップページの各タイルには商品を最大3件表示する。タイル属性がピックアップ商品のタイルはピックアップ商品から、それ以外のタイルはタイルタグに紐づく商品から、いずれも表示のたびに無作為に選ぶ。タイルタグが登録されていないタイルは商品を表示しない。

タイルが1件も登録されていないタイル位置には、フォーマットのタグ（スタンダード・レガシー・統率者）から1つを無作為に選び、そのタグに紐づく商品を表示する。

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 編集対象の支店の識別子、画面の入力値、なりすまし対策トークン |
| 成功時出力 | 編集していた支店の支店トップページ管理画面へ戻り、完了メッセージを表示する |
| 失敗時出力 | 編集していた支店の支店トップページ管理画面へ戻り、エラーメッセージを表示する |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 更新 | 支店共通設定の区分の保存 |
| 登録・更新 | 支店固有設定（バナー画像・バナータグ・タイル）の保存 |
