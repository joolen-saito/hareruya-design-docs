# コンテンツ管理 — 支店トップページ管理

## 業務ロジック

### 支店共通設定の優先

支店共通設定が有効な状態で保存したときは、共通設定の区分だけを保存する。バナー画像・バナータグ・タイル設定は検証も保存もしない。

支店トップの表示では、支店共通設定が有効な支店は共通店舗の支店情報を表示元とする。

### バナー画像

支店共通設定が無効のときは、既存画像を維持するか新規画像を指定する必要がある。既存画像も新規画像も無いときは保存しない。新規画像を指定したときは、既存画像があれば削除してから新規画像を保存し、保存後のパスを保持する。画像の保存に失敗したときはエラーを表示し、保存せず同じ画面へ戻す。

画像の保存先は、支店の省略名で分けたトップバナー用の領域とする。

### タイル

画面は4つのタイル位置を扱う。既存のタイルが4件未満のときは不足分を画面側で補う。

| 判定 | 結果 |
| --- | --- |
| 4つのタイルの位置が重複する | 保存せずエラーを表示して戻す |
| タイル属性がピックアップ商品以外で、タイルタグが空 | 保存せずエラーを表示して戻す |
| タイル属性がピックアップ商品 | タイルタグを使わない |

新規のタイルには対象支店を設定する。

### 支店トップ表示への反映

表示元支店のタイルを読み、タイル属性がピックアップ商品のタイルはピックアップ商品を3件取得する。ピックアップ商品以外のタイルは、タイルタグがあればタグに紐づく商品規格を3件取得し、タグが無ければ空とする。

未設定のタイル位置は、リニューアル後の4枠（上段左、上段右、下段左、下段右）を対象に補う。リニューアル後の支店トップページではタイル配置のランダム化を行わない。現行のランダム配置の区分は移行後の表示制御の対象にしない。

### 計算

本機能では金額・税・ポイントの計算を行わない。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| バナー画像が空 | エラーを表示し、保存せず同じ画面へ戻す |
| バナー画像の保存に失敗 | エラーを表示し、保存せず同じ画面へ戻す |
| タイル位置の重複 | エラーを表示し、保存せず同じ画面へ戻す |
| ピックアップ商品以外でタイルタグが未設定 | エラーを表示し、保存せず同じ画面へ戻す |
| 入力項目の制約違反 | 項目のエラーとして表示する |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 支店の識別子、支店共通設定の区分、バナー画像・バナータグ・タイルの入力値、なりすまし対策トークン |
| 成功時出力 | 同じ支店のトップページ管理画面への遷移と保存完了メッセージ |
| 失敗時出力 | 同じ支店のトップページ管理画面への遷移とエラーメッセージ。入力項目の検証エラーは項目のエラーとして表示する |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 更新 | 支店共通設定の区分の保存 |
| 登録・更新 | 支店固有設定（バナー画像パス・バナータグ・タイル）の保存 |

## 表示メッセージ

| メッセージID | 表示位置 | 画面上の文言 | 表示条件 | 後続処理 |
| --- | --- | --- | --- | --- |
| M09-10-MSG-001 | 管理画面上部 | セッションがタイムアウトしました。もう一度やり直してください。 | 共通設定を使用していて、操作期限が切れた状態で保存しようとしたとき | 保存せず支店トップページ管理画面に留まる |
| M09-10-MSG-002 | 管理画面上部 | 保存しました | 共通設定を使用して、設定を保存したとき | 共通設定の区分だけを保存し、支店トップページ管理画面に留まる |
| M09-10-MSG-003 | 管理画面上部 | 保存に失敗しました | 共通設定を使用せず、入力内容に不備があるまま保存しようとしたとき | 保存せず支店トップページ管理画面に留まる |
| M09-10-MSG-004 | 管理画面上部 | 保存しました | 共通設定を使用せず、入力内容に問題がない状態で設定を保存したとき | トップページ設定を保存し、支店トップページ管理画面に留まる |
| M09-10-MSG-005 | 管理画面上部 | バナー画像の登録に失敗しました。 | バナー画像を指定して保存しようとしたが、画像を登録できなかったとき | 保存せず支店トップページ管理画面に留まる |
| M09-10-MSG-006 | 管理画面上部 | バナー画像の登録に失敗しました。 | バナー画像を指定せずに保存しようとし、登録済みのバナー画像もないとき | 保存せず支店トップページ管理画面に留まる |
| M09-10-MSG-007 | 管理画面上部 | バナー画像の登録に失敗しました。 | バナー画像を指定せずに変更しようとし、バナー画像が未設定のとき | 保存せず支店トップページ管理画面に留まる |
| M09-10-MSG-008 | 管理画面上部 | タイル位置に重複があります。すべてのタイルは異なる位置を選択してください。 | 複数のタイルに同じ表示位置を設定したとき | 保存せず支店トップページ管理画面に留まる |
| M09-10-MSG-009 | 管理画面上部 | タイルタグを設定してください。（※タイル属性がピックアップ商品の場合を除く） | ピックアップ商品以外のタイルで、タイルタグを設定せずに保存しようとしたとき | 保存せず支店トップページ管理画面に留まる |
