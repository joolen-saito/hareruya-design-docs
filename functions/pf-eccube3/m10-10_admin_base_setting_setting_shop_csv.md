# 店舗設定 — CSV出力項目設定

## 業務ロジック

### 画面の対象

指定されたCSV種別が存在しないときは対象なしとする。

当該種別に紐づく出力項目のうち、無効なものだけを並び順の昇順で左のリストに、有効なものだけを同じ並びで右のリストにする。CSV種別の選択を変えた時点で、切り替え先の種別の画面を開き直す。開き直す前に画面上で行った移動・並び替えは残らない。

### 項目の移動と並び替え

操作項目のボタンで項目を移すと、移した項目は選択が外れた状態になる。

項目順序のボタンは右のリストにだけ効き、左のリストの並びは動かせない。項目を選んでいないときは押しても動かない。

これらのボタンは画面上のリストを動かすだけで、設定を押すまで保存しない。

### 保存

設定を押したときは、左右それぞれのリストの全項目が、画面に並んでいる順で送られる（画面で選んでいる項目だけではない）。

左のリストが送られたときだけ、その配列の順に各出力項目を取り出し、並び順を 1 から振り直したうえで無効にする。右のリストが送られたときだけ、同じ手順で並び順を振り直したうえで有効にする。送られなかったリストについては、その出力項目の並び順と有効・無効を変更しない。右のリストの配列の順序が、画面の上から下への順に対応する。

保存の後は同じCSV種別の画面へ戻す。

### 有効な出力項目と出力の対応

CSVの出力は、種別を指定したうえで有効な出力項目だけを並び順の昇順で使う。ヘッダ行には各出力項目の表示名だけを並べ、データ行は定義に応じた値で埋める。この画面で無効にした列は、出力に現れない。

### エラー時の扱い

| エラー内容 | 処理 |
| --- | --- |
| 指定したCSV種別が無い | 対象なしとする |

入力の検証を経ないため、この画面の保存では検証エラーの画面を出さない。送られた識別子が実在するかだけが保存の可否を分ける。

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | CSV種別、左と右のリストの出力項目の識別子の配列、なりすまし対策トークン |
| 成功時出力 | 同じCSV種別の設定画面へ戻し、保存の完了メッセージを出す |
| 失敗時出力 | CSV種別が無いときは対象なしとする |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 更新 | 出力項目の並び順と有効・無効を、左と右のリストが送られたとき配列の順に振り直す |
