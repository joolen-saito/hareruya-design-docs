# 商品 — 商品リコメンド（おすすめ商品ブロック）

## 概要

マイページ・購入完了・商品詳細・買い物かごの各ページに、おすすめ商品をスライダー表示するブロック機能である。ブロックはページ表示後に非同期で読み込み、表示中のページ種別に応じて基準となる商品を1つ決め、その商品とよく一緒に購入されている商品を一定期間の注文実績から抽出して並べる。会員がログイン済みの場合は、その会員が既に購入した商品をおすすめから除外する。

本書は実装手順ではなく、誰が・いつ・どの条件で・結果どうなるかを読むためのリバース詳細設計とする。確認値はpf-eccube3（EC-CUBE3系）のHareruyaEcプラグインのおすすめ商品ブロック処理、おすすめ抽出クエリ、テンプレート（`Block/user_recommend_product.twig`・`Block/recommend_detail.twig`）、オプションマスタ（おすすめ抽出対象期間）を正とする。本機能のカスタマイズ区分は現行踏襲であり、画面挙動の参照リポはpf-eccube3、DB関連の記述はec-cube-enterpriseを正とする。

対象はブラウザ経由のフロントに限定する。

本文ではフレームワークのコントローラ型名やメソッド名を主説明としない。本文ではルートbind名の網羅は主説明とせず、「利用者視点の入口」にHTTPメソッドとサイトルートからのパスパターンを書く。コード探索でbind名が必要なときだけ「調査補助」へ書く。

## 本書で扱うこと

- おすすめ商品ブロックを表示するページと非同期読み込み
- ページ種別ごとの基準商品の決め方
- おすすめ商品の抽出条件（対象期間・除外・在庫・公開・並び）
- 該当が無い場合の表示

## 本書で扱わないこと

以下は本書では仕様確定せず、実装または別機能の設計を正とする。

- 各ページ（マイページ・購入完了・商品詳細・買い物かご）そのものの仕様
- スライダーUI（外部スクリプト）の内部仕様
- 外部向けおすすめ取得API（記事内ポップアップ等の別API）の仕様
- おすすめ抽出対象期間の運用値の決定（オプションマスタの管理を正とする）

## リニューアル移行時の扱い

本機能は参照のみで台帳を更新しない。画面挙動はpf-eccube3を確認値とし、おすすめ抽出に参照するDBのスキーマはec-cube-enterpriseを正とする。現行と移行先で次の差がある。

| 観点 | 現行（pf-eccube3） | 移行先（ec-cube-enterprise） |
|------|--------------------|------------------------------|
| 注文明細の参照元 | 注文`dtb_order`と注文明細`dtb_order_detail` | 注文`dtb_order`と注文明細`dtb_order_item`。EC-CUBE4系では明細テーブル名が`dtb_order_item`に変わる。 |
| 商品の公開・削除 | 商品`dtb_product`に公開状態`status`と論理削除フラグ`del_flg` | `dtb_product`に`del_flg`は無く、公開状態は商品ステータス`product_status_id`（区分`mtb_product_status`）で表す。 |
| 在庫 | `dtb_product_class`の`stock` | 同一スキーマ。 |
| 抽出対象期間 | おすすめ抽出対象期間（オプションマスタ） | `mtb_option`の`option_key`に対応する値として保持。 |

おすすめ抽出ロジック（共購入集計・自己購入除外）の現行挙動はpf-eccube3を正とする。

| 用語 | 説明 |

## 利用者視点の入口

| 入口 | URLエンドポイント | 期待されるふるまい |
|------|--------------------|--------------------|
| マイページ表示時のおすすめブロック | 非同期のおすすめ取得（種別`mypage`） | 会員の最新注文商品を基準におすすめを表示する。 |
| 購入完了表示時のおすすめブロック | 非同期のおすすめ取得（種別`complete`） | 会員の最新注文商品を基準におすすめを表示する。 |
| 商品詳細表示時のおすすめブロック | 非同期のおすすめ取得（種別`detail`、`product_id`付き） | 表示中の商品を基準におすすめを表示する。 |
| 買い物かご表示時のおすすめブロック | 非同期のおすすめ取得（上記以外の種別） | カート内で最も高額な商品を基準におすすめを表示する。 |

ブロックはページ内に埋め込まれ、ページ表示後に非同期で内容を取得する。利用者が直接たどるURLではなく、各ページに付随して表示される。リクエスト処理の冒頭でセッション書き込みを閉じ、他リクエストをブロックしない。

---

## フロント挙動

| 観点 | 内容 |
|------|------|
| 表示要素 | おすすめ商品のスライダー。各商品は画像（遅延読み込み）・商品名・商品詳細へのリンク。前後送りのボタンを持つ。 |
| JS挙動 | ブロックはページ表示後に非同期でおすすめ内容を取得して描画する。画像は遅延読み込みする。 |
| CSS・レイアウト | フォイル商品は画像にフォイル用の装飾を付す。 |
| モーダル・ポップアップ | 本ブロック専用のモーダルは無い。 |

おすすめが0件の場合はスライダーを出さず、おすすめが無い旨のメッセージを表示する。

---

## 処理フロー

### 基準商品を決める

1. ページ種別が`mypage`または`complete`の場合、ログイン会員の最新注文の商品を基準商品とする。最新注文が無ければ基準商品なしとする。
2. ページ種別が`detail`の場合、リクエストの商品IDを基準商品とする。
3. 上記以外（買い物かご）の場合、カート内商品を価格の高い順に並べ、最も高額な商品規格の商品を基準商品とする。カートが空なら基準商品なしとする。

### おすすめを抽出して表示する

1. 基準商品が無い場合は、おすすめ0件として描画する。
2. 基準商品がある場合、おすすめ抽出対象期間内の注文実績から、基準商品と関連する商品を集計して抽出する。
3. ログイン会員の場合は、その会員が過去に注文した商品をおすすめから除外する。
4. 抽出結果をスライダーで表示する。0件のときはおすすめが無い旨を表示する。

### 常時表示

|------|-------------------|-----------------|------|------|

## 集計条件

| 指標 | 集計の要点 |
|------|------------|
| 抽出対象期間 | 注文日が直近のおすすめ抽出対象期間（オプションマスタの日数）内の注文を対象とする。 |
| 対象注文 | 取消（処理中ステータス）の注文を除外する。 |
| 対象商品 | 公開中かつ削除されていない商品で、在庫がある商品規格を持つものに限る。 |
| 会員の購入除外 | ログイン会員の場合、当該会員が過去に注文した商品をおすすめから除外する。 |
| 並び | 期間内の販売数量を集計し、その多い順に並べる。 |
| 商品名 | ロケールが英語の場合は英語名、それ以外は商品名を表示する。 |

## 業務ルール・計算

| 項目 | 内容 |
|------|------|
| 基準商品の選定 | ページ種別により、最新注文商品・表示中商品・カート最高額商品のいずれかを基準にする。 |
| 自己購入除外 | ログイン会員が購入済みの商品はおすすめに含めない。 |
| 在庫・公開条件 | 在庫があり公開中の商品のみおすすめ対象とする。 |

本機能は利用者入力のフォームを持たないため入力項目は無い。

### エッジケース

| ケース | 扱い |
|--------|------|
| 最新注文が無い（マイページ・購入完了） | 基準商品なしとしておすすめ0件を表示する。 |
| カートが空（買い物かご） | 基準商品なしとしておすすめ0件を表示する。 |
| 抽出結果が0件 | おすすめが無い旨を表示する。 |
| 未ログイン | 自己購入除外を行わずおすすめを抽出する（最新注文を基準とする種別では基準商品が得られない）。 |

## DBカラム

機能に直接関係する列のみ記載する。型や一覧の細部はスキーマを参照する。

| テーブル | 列 | メモ |
|---------|-----|------|
| `dtb_order` / `dtb_order_item` | 注文日・ステータス・商品・数量 | 期間内の販売数量集計とおすすめ抽出に使用する。注文明細はec-cube-enterpriseでは`dtb_order_item`（現行の`dtb_order_detail`に相当）。 |
| `dtb_product` | `product_status_id` | 公開中の商品に限定する。ec-cube-enterpriseは論理削除列`del_flg`を持たず、公開状態は商品ステータスで表す（現行の`del_flg`・`status`は移行先で`product_status_id`に統合）。 |
| `dtb_product_class` | `stock` | 在庫がある商品規格に限定する。 |
| `mtb_option` | おすすめ抽出対象期間に対応する`option_key` | 集計対象の直近日数。 |

### DB操作

本機能は参照系（検索）であり、DBへの登録・更新・削除は行わない。テーブル名は ec-cube-enterprise を正典とする。

| 操作種別 | 対象テーブル | 契機・条件 |
|---------|--------------|------------|
| 検索 | dtb_order / dtb_order_detail / dtb_order_item / dtb_product / dtb_product_class / mtb_option | 検索条件に合致するレコードを抽出する。 |
