# 分析 — フォーマット売上分析CSVダウンロード

## 業務ロジック

### 出力対象

ダウンロードするときは、送信された集計月をもとに、フォーマット（売上分析タグ）ごと、および売上分析タグに紐づかない区分ごとの日別売上を集計する。集計はM12-07と同一とする。

### 出力する列

| 行 | 内容 |
|----|------|
| ヘッダ行 | 先頭を「日」とし、各フォーマットの名称を続け、末尾に「合計」を置く。名称は集計の対象となるフォーマットの数だけ並ぶ |
| データ行 | 日ごとに1行とし、日に続けて各フォーマットの売上、末尾に当日の日別合計を出力する。行は集計月の日ごとに並ぶ |

フォーマットの並びは、M12-07と同じく売上分析タグの順位の昇順とし、そのあとに「その他(カード)」「その他」を置く。日別売上と日別合計を算出するときの規則は、M12-07の集計と同一とする。

### 出力の形式

文字コードの判別用にBOMを付ける。ファイル名は `format_sales_report_` に、出力したときの日時（`YmdHis`）を付けた `.csv` とする。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| 検索を実行せずにダウンロードしたとき | エラーを表示し、フォーマット売上分析 集計一覧表示画面へ遷移する。出力しない |
| 集計月が未入力のとき | 集計月は必須であり、未入力のときは送信できない。出力もしない |
| データベース読み取りの障害 | アプリケーションの共通例外処理に委ねる |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 送信された集計月。集計月は必須とする |
| 成功時出力 | 検索を実行済みのときは、日別の売上表のCSVファイル |
| 失敗時出力 | 検索条件が無いときはエラーを表示し、集計一覧表示画面へ遷移する |

本機能は参照だけを行い、CSVを出力するときもデータを更新しない。
