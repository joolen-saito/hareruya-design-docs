# 分析 — フォーマット売上分析CSVダウンロード

## 業務ロジック

### 出力対象

ダウンロードするときは、送信された集計月をもとに、その月の1日から末日までの日別売上を集計する。集計はM12-07と同一とする。

画面に表示済みの集計結果を保存して出すのではなく、ダウンロードを受け付けたときに集計をやり直す。検索してから時間が空くと、画面の表とCSVの値が食い違うことがある。

### 出力する列

| 行 | 内容 |
|----|------|
| データ行 | 日ごとに1行とし、日に続けて各フォーマットの売上、末尾に当日の日別合計を出力する。行は集計月の日ごとに並ぶ |

フォーマットの並びは、M12-07と同じく売上分析タグの順位の昇順とする。日別売上と日別合計を算出するときの規則は、M12-07の集計と同一とする。

画面に表示するフォーマット別の合計・平均の表は出力しない。CSVに出るのはヘッダ行と日別の行だけとする。

### 出力の形式

文字コードの判別用にBOMを付ける。ファイル名は `format_sales_report_` に、出力したときの日時（`YmdHis`）を付けた `.csv` とする。売上の金額は、画面の表と違い桁区切りを付けず数値のまま出力する。

### エラー時の扱い

CSVダウンロードの操作は、集計結果を表示しているときだけ行える。集計結果が無い状態では操作の入口を出さない。

| エラー内容 | 処理 |
|------------|------|
| 集計月が未入力のとき | 集計月は必須であり、未入力のときは送信できない。出力もしない |
| データベース読み取りの障害 | アプリケーションの共通例外処理に委ねる |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 送信された集計月。集計月は必須とする |
| 成功時出力 | 日別の売上表のCSVファイル |
| 失敗時出力 | データ取得に失敗したときはアプリケーションの共通例外処理に委ねる |

本機能は参照だけを行い、CSVを出力するときもデータを更新しない。
