# デッキ管理 — 検索一覧からの一括編集

## 業務ロジック

### 一括更新の判定順序

| 順序 | 判定 | 結果 |
|------|------|------|
| 1 | なりすまし対策トークンが有効か | 無効なときはアクセス拒否（HTTP 403）とする |
| 2 | 送信フォームの検証に通るか（全項目。変更フラグは検証対象の絞り込みに使わない） | 失敗したときはエラーメッセージを表示し、直前の画面へ戻す |
| 3 | 各デッキIDが空でなく半角数字のみか | 1件でも不正なときはHTTP 404で打ち切る |
| 4 | 上記を通過したとき | 変更フラグが付いた項目だけをフォームの値で上書きし、まとめて保存する |

保存に成功したときは登録完了のメッセージを表示し、直前の画面へ戻す。

デッキ検索一覧の表示時には、入力が未送信の状態の一括編集フォームを一覧へ載せる。

### 更新する項目

変更フラグが送信された項目だけを、対象のすべてのデッキへ同じ値で適用する。変更フラグが無い項目は既存の値を保持する。

| 対象項目 |
|------|
| フォーマット、アーキタイプ、表示区分、非公開フラグ、大会名（日本語）、大会名（英語）、大会日、順位、成績、勝ち数、負け数、引き分け数、DCI番号、プレイヤー名、デッキタグ、参照元URL |

| 項目 | 扱い |
|------|------|
| フォーマット | 未選択の状態で上書きしたときは、保存側では参照なしとして解釈されうる |
| アーキタイプ | アーキタイプと代表カード画像を同時に設定する経路で更新する。アーキタイプに代表カード画像が無いときは画像の参照を更新しない |
| デッキタグ | 多値選択とし、変更フラグが付いたときはその値で既存のタグ紐付けを置き換える。空選択のときは空として解釈されうる |
| 最終更新者 | 対象の各デッキに、操作した管理者アカウントのIDを記録する |

本機能では売上・順位計算などの業務計算は行わない。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| なりすまし対策トークンが無効なとき | アクセス拒否（HTTP 403）とする |
| フォーム検証に失敗したとき | 各エラーを表示し、直前の画面へ戻す |
| デッキIDが半角数字でないとき | HTTP 404とする |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 一括編集の各項目、なりすまし対策トークン、変更フラグ、対象のデッキID群 |
| 成功時出力 | 直前の画面への遷移と登録完了のメッセージ |
| 失敗時出力 | 検証失敗のときはエラーメッセージと直前の画面への遷移。ID形式不正のときはHTTP 404。なりすまし対策トークン失敗のときは共通の拒否応答 |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 更新 | 一括編集の実行（変更フラグが付いた項目と最終更新者） |

## 表示メッセージ

本機能は一括編集の登録完了メッセージと、フォーム検証のエラーメッセージだけを表示する。
