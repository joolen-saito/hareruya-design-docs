# 受注管理 — スタック用紙印刷

## 業務ロジック

### 印刷対象の受け取り

一覧で選択した受注のIDと、操作した担当者のIDを、印刷用の別画面から受け取る。受注IDが 1 件も無いときは、印刷内容を組み立てず未検出として応答する。

### 印刷内容の組み立て

レシートプリンタIPアドレス、スタック用紙高額商品判定価格、スタック用紙高額商品しきい値価格の 3 つの設定値を読む。設定が無いときの既定値はそれぞれ空・販売価格・`5000` とする。

対象受注ごとに、受注日・注文番号・注文者名・注文者フリガナ・購入金額・対応状況・スマレジ用商品コード・注文備考の有無を組み立てる。

高額かどうかの判定に使う金額は、高額商品判定価格の設定で変わる。設定が販売価格のときは受注明細の販売価格の最大値、買取価格のときは受注明細に紐づく商品の買取価格の最大値を使う。

しきい値価格と比べた結果は記号として持つが、しきい値以上のときと未満のときで同じ記号になるため、印刷内容からは区別が付かない。

組み立てた内容は応答に含めない。応答に載るのはメッセージだけである。

### 注文番号が未採番のときの扱い

対象受注に注文番号が未採番のものが 1 件でもあるときは、その旨を返して終了する。このときは受注を 1 件も更新しない。未採番の受注が見つかるまでに調べた受注も更新しない。

### 受注の更新

印刷対象の受注すべてにブラウザ印刷フラグを立てる。

対応状況が注文受領の受注だけ、対応状況をピック中に更新し、注文確定日に現在日時を設定する。それ以外の対応状況のときは、対応状況も注文確定日も変更しない。

担当者IDに一致する担当者が存在するときだけ、受注の担当者に設定する。存在しないときは担当者を変更しない。

### 呼び出し元の動き

呼び出しは印刷用の別画面から行い、5 秒で応答が無いときは打ち切る。

応答にメッセージがあるときはそれを表示して画面を閉じる。応答が得られないとき、応答の内容にメッセージが無いときは、システムエラーである旨を表示して画面を閉じる。

用紙への印刷そのものを行う処理は、現行ソースに無い。

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 一覧で選択した受注のID、操作した担当者のID |
| 成功時出力 | 受注の更新と、印刷予約を受け付けた旨のメッセージ |
| 失敗時出力 | 受注を更新せず、対象未指定・注文番号未採番・システムエラーのいずれかのメッセージ |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| ブラウザ印刷フラグの更新 | 印刷対象の受注すべて |
| 対応状況と注文確定日の更新 | 対応状況が注文受領の受注だけ |
| 担当者の更新 | 受け取った担当者IDに一致する担当者が存在するときだけ |
