# 商品管理 — 略称タグ登録/編集

## 業務ロジック

### 一覧と入力欄

画面は略称タグの一覧と入力欄を同時に出す。一覧は並び順の昇順で並べ、ページ番号と表示件数を保持する。要求にページ番号または表示件数の指定があるときは、その値を優先する。

編集の対象を指定したときは当該の略称タグを入力欄に読み込む。対象が無いときは 404 とする。対象を指定しないときは新規の入力欄とする。

一覧の「並び順」列は、アルファベットかどうかのラベルを表示する。並び順の数値とは別の項目である。

### 保存の判定順序

| 順序 | 判定 | 結果 |
| --- | --- | --- |
| 1 | 入力の検証を満たすか | 満たさないときは保存せず、一覧の先頭へ戻す。入力した値は復元せず、入力欄の直下にもエラーを出さない |
| 2 | 検証を満たしたとき | 略称タグを登録または更新し、一覧の先頭へ戻す |

保存後は一覧の先頭へ戻り、入力欄は新規の状態で表示する。続けて同じ略称タグを編集するときは、一覧から当該の略称タグを選び直す。

名称の重複と並び順の重複について、画面側の確認は行わない。

### 削除の判定順序

| 順序 | 判定 | 結果 |
| --- | --- | --- |
| 1 | なりすまし対策トークンが有効か | 無効のときはアクセス拒否（HTTP 403）とする |
| 2 | 当該の略称タグを使う商品が 1 件でもあるか | あるときは削除せず、一覧の先頭へ戻す |
| 3 | 使う商品が 1 件も無いとき | 削除し、一覧の先頭へ戻す |

### エラー時の扱い

| エラー内容 | 処理 |
| --- | --- |
| 入力の検証を満たさない | 保存せず、一覧の先頭へ戻す |
| 削除しようとした略称タグを商品が使っている | 削除せず、一覧の先頭へ戻す |
| 削除でなりすまし対策トークンが無効 | アクセス拒否（HTTP 403）とする |

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | 一覧はページ番号と表示件数、編集は対象の略称タグ。保存は入力欄一式となりすまし対策トークン。削除はなりすまし対策トークン |
| 成功時出力 | 一覧と入力欄の画面、または一覧の先頭への戻り。完了または失敗のメッセージを伴う |
| 失敗時出力 | 検証を満たさないときも一覧の先頭へ戻す。対象が無いときは 404、トークンが無効のときは HTTP 403 |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 追加・更新 | 入力の検証を満たして保存したとき |
| 削除 | 当該の略称タグを使う商品が 1 件も無いとき |
