# F03-07（入荷時通知）

## 業務ロジック

### 依頼の単位と対象

入荷通知の依頼は商品規格単位で行い、ログイン会員に限る。依頼は会員に紐づく選手情報に対して記録する。未ログインのときは登録せず、検索の戻り先を保持したうえで未ログインの応答を返す。

### 依頼と取り消しの判定順序

| 順序 | 判定 | 結果 |
| --- | --- | --- |
| 1 | 商品規格が特定できるか | できないなら対象商品が削除済みの応答（状態`fail`）を返す |
| 2 | ログイン会員か | 会員でないなら戻り先を保持し、未ログインの応答（状態`nologin`）を返す |
| 3 | 同一商品規格の依頼が既にあるか | あるならその依頼を削除し、取り消しの応答（状態`cancel`）を返す |
| 4 | 依頼件数が上限未満か | 上限以上なら上限超過の応答（状態`fail`）を返す |
| 5 | 上記を通過 | 依頼を作成して保存し、依頼成功の応答（状態`success`）を返す |

### 重複依頼の扱い

同一会員・同一商品規格の依頼が既にあるときは、再度の依頼で当該依頼を削除する。重複した依頼は作成しない。

### 件数上限

1会員あたりの依頼件数が依頼上限値以上のときは、新規の依頼を作成しない。上限値はオプションで設定する依頼上限を参照する。件数は論理削除されていない依頼だけを数えて上限と比較する。

### 依頼一覧

会員ログインを前提とし、ログイン会員の入荷通知依頼の対象商品を一覧として表示する。

### エラー時の扱い

| 事象 | 扱い |
| --- | --- |
| 対象商品規格が特定できない | 対象商品が削除済みの応答を返す |
| 未ログインで依頼 | 戻り先を保持し、未ログインの応答を返す。登録しない |
| 依頼件数が上限超過 | 上限件数を含む上限超過の応答を返す。登録しない |
| 未ログインで一覧 | 会員ログインへ誘導する |

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | 登録・取り消しは商品規格ID。一覧は会員ログイン情報 |
| 成功時出力 | 登録・取り消しは状態と文言を含む応答。一覧は対象商品の一覧表示 |
| 失敗時出力 | 未ログイン・上限超過・対象商品削除済みの応答 |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 追加 | 依頼が無く、依頼件数が上限未満のときに入荷通知依頼を作成する |
| 削除 | 同一商品規格の依頼済みの状態で再度依頼したとき、当該依頼を削除する |
