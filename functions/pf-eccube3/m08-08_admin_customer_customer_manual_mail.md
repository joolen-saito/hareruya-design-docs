# 会員管理 — 手動メール通知

## 業務ロジック

### 対象会員とテンプレート

対象会員は指定された会員IDで特定する1名とする。会員IDの指定が無いとき、および該当する会員が存在しないときは、ページが見つからない扱い（404）とする。

テンプレートを指定したときは、会員向けベース（会員・会員英語・ベースなし）に該当するテンプレートのみを選択対象とする。該当しないテンプレートを指定したときはページが見つからない扱い（404）とする。

### 作成画面の初期表示

テンプレートの件名を件名欄に設定する。本文はテンプレートのヘッダ・フッタ・会員・店舗基本情報を差し込んで組み立てる。組み立てた内容と選択中テンプレートを設定したメール作成フォームを表示する。

### 送信

入力の検証に通ったときだけ対象会員へ手動メールを送信する。検証に通らないときは送信せず作成画面へ戻す。宛先は会員のメールアドレス、差出人と控え（Bcc）は店舗基本情報のメールアドレス、返信先・返送先も店舗基本情報のメールアドレスとする。件名と本文は送信内容を用いる。送信後は同じ会員・テンプレートの作成画面へ戻る。

### 送信履歴

送信のたびにメール送信履歴を1件記録する。記録する内容は会員・テンプレート・件名・本文・送信日時である。手動メールでは作成者の記録は持たない。

会員データ自体は更新しない。

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 会員ID、テンプレートID、件名、本文、ヘッダ・フッタ、なりすまし対策トークン |
| 成功時出力 | メール送信、メール送信履歴の記録、送信完了の通知、作成画面の再表示 |
| 失敗時出力 | 検証失敗時は作成画面の再表示。会員・テンプレート不正は404 |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 追加 | 手動メールの送信成功時にメール送信履歴を1件記録する |
