# 会員管理 — 会員登録/編集


### フェーズ2対応（フェーズ1では実装しない）

- 顧客分析タグ登録、およびフロントでの会員のオプトイン・オプトアウト（※Excel基本設計 0207「顧客分析タグ登録、およびフロントでの会員のオプトイン・オプトアウト」はフェーズ2対応。フェーズ1では実装しない）。フェーズ2対応。Excel原文: 「・フロントで会員がオプトイン・オプトアウトできるようにする要件はPh2とする」（0207 会員登録編集）

## 業務ロジック

### 画面の初期表示

未完了受注を隠す絞り込みを有効にしたうえで表示する。

| 場面 | 初期表示 |
| --- | --- |
| 新規のとき | 購入回数と購入金額を 0 で初期化する |
| 編集で対象の会員があるとき | 会員の値をフォームに載せ、購入履歴と買取履歴をあわせて表示する |
| 編集で対象の会員があるとき | パスワード欄に既定パスワードを表示し、元のパスワードを退避する |
| 編集で対象の会員が無いとき | ページが見つからない扱い（404）とする |
| 新規のとき | 会員IDを持たない状態でフォームを開く |

### 標準の会員登録フォームに加える欄

| 欄 | 扱い |
| --- | --- |
| DCIナンバー | 入力できる |
| DCI登録本名 | 入力できる |
| 国 | 入力できる |
| 本人確認ステータス | 入力できる |
| DCI確認フラグ | 入力できる |
| 本人確認フラグ | 入力できる |
| 身分証有効期限 | 入力できる |
| 会員グループ | 入力できる |
| メールマガジン配信フラグ | 入力できる |
| スマレジID | 読み取り専用とする |
| 氏名カナ | 必須を解除する |
| 郵便番号 | 必須を解除する |

### 入力値の制約

| 項目 | 制約 |
| --- | --- |
| 生年月日 | 今日以降の日付は不正な日付として扱う |
| パスワード | メールアドレスと同じ値は設定できない |
| メールアドレス | 既に別の会員へ登録されているものは使えない |
| FAX番号 | 先頭の欄が空欄のまま、後ろの欄だけを入力することはできない |
| 海外用郵便番号 | 最大文字数の検証がある |
| 住所1・住所2 | 現行ではSJIS換算の上限検証がある。リニューアル後のExcel仕様は住所1・住所2・住所3を各200文字とするが、移行先の確認値は各90文字である |
| お届け先 | 登録済みの件数が上限に達しているときは追加できない |

### 保存の判定順序

| 順序 | 判定・処理 | 内容 |
| --- | --- | --- |
| 1 | 入力内容の検証 | 外れたときは保存せず、同一画面に項目ごとのエラーを表示する |
| 2 | 新規のときの採番 | ソルトとシークレットキーを採番する |
| 3 | 新規のときの会員住所 | 入力した会員情報を写した会員住所を1件生成する |
| 4 | パスワードの判定 | 送信値が既定パスワードのままのときは、退避した既存のパスワードを維持する |
| 5 | パスワードの更新 | 送信値が変更されているときは、必要に応じてソルトを生成し、暗号化して保存する |
| 6 | 保存 | 会員を保存する。新規のときは会員住所もあわせて保存する |

保存できたときは、保存した会員の編集画面へ遷移する。

パスワードの原値とハッシュは設計書に書かない。不可逆の値として扱う。

金額・税の計算は行わない。

### 新規登録で会員住所へ写す項目

| 会員の項目 | 会員住所への反映 |
| --- | --- |
| 氏名 | 同じ値を写す |
| カナ | 同じ値を写す |
| 会社名 | 同じ値を写す |
| 郵便番号 | 同じ値を写す |
| 都道府県 | 同じ値を写す |
| 住所 | 同じ値を写す |
| 電話番号 | 同じ値を写す |
| FAX番号 | 同じ値を写す |

編集のときは会員住所を生成しない。

### 本人確認ステータスの自動降格

| 変更した項目 | 本人確認用情報の変更とみなす会員の状態 |
| --- | --- |
| 国 | 確認済み、または簡易書留確認済みのとき |
| 郵便番号 | 確認済み、または簡易書留確認済みのとき |
| 海外用郵便番号 | 確認済み、または簡易書留確認済みのとき |
| 都道府県 | 確認済み、または簡易書留確認済みのとき |
| 住所1 | 確認済み、または簡易書留確認済みのとき |
| 住所2 | 確認済み、または簡易書留確認済みのとき |
| お名前 | 確認済みのときだけ |
| お名前（フリガナ） | 確認済みのときだけ |
| 生年月日 | 確認済みのときだけ |

本人確認用情報の変更があるときは、登録の前に確認を求める。

続行を選んだときだけ、本人確認ステータスの送信値を未確認へ書き換えてから送信する。

取り消したときは送信しない。

### 編集のときにあわせて表示するもの

| 表示 | 内容 |
| --- | --- |
| 購入履歴 | 対象の会員の購入履歴を表示する。0件のときは購入履歴が無い旨を表示する |
| 買取履歴 | 対象の会員の買取履歴を表示する |
| お届け先一覧 | 登録済みのお届け先を表示する。件数が上限に達しているときは追加できない |

### フェーズ2の扱い

顧客分析タグ登録と、フロントでの会員のオプトイン・オプトアウトはフェーズ2の対応とする。

フェーズ1では実装しない。

この扱いはこの項目だけに適用する。

Excel原文は「・フロントで会員がオプトイン・オプトアウトできるようにする要件はPh2とする」である。

### エラー時の扱い

| 事象 | 扱い |
|------------|------|
| 入力内容の検証に外れたとき | 保存せず、同一画面に項目ごとのエラーを表示する |
| 住所がSJIS換算の上限を超えたとき | 住所欄に超過のエラーを表示する |
| 海外用郵便番号が最大文字数を超えたとき | 海外用郵便番号欄に超過のエラーを表示する |
| お届け先の登録済み件数が上限に達しているとき | お届け先を追加できない |
| 存在しない会員IDを指定したとき | ページが見つからない扱い（404）とする |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 会員登録フォームの入力値。 |
| 成功時出力 | 会員情報の保存と保存成功のメッセージ。保存した会員の編集画面への遷移。 |
| 失敗時出力 | 検証に外れたときは同一画面に項目ごとのエラー。存在しない会員IDのときはページが見つからない扱い（404）。 |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 追加 | 会員を新規登録したとき。会員住所も1件追加する |
| 更新 | 会員を編集して保存したとき |
