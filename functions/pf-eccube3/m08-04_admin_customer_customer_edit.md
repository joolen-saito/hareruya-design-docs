# 会員管理 — 会員登録/編集

## 業務ロジック

### フェーズ2対応（フェーズ1では実装しない）
- Excel基本設計 0207「顧客分析タグ登録、およびフロントでの会員のオプトイン・オプトアウト」はフェーズ2対応。フェーズ1では実装しない。

### 画面の初期表示

| 場面 | 初期表示 |
| --- | --- |
| 新規のとき | 会員IDを持たない状態でフォームを開く |
| 新規のとき | 累計注文回数と累計注文金額を 0 で初期化する |
| 編集で対象の会員が無いとき | ページが見つからない扱い（404）とする |

### 購入履歴・買取履歴の表示範囲

| 表示 | 範囲 |
| --- | --- |
| 購入履歴 | 決済処理中・購入処理中の受注は含めない |
| 購入履歴 | 先頭100件までを表示する |
| 買取履歴 | 先頭100件までを表示する |

発送日が無い受注は、発送日の欄に「未発送」と表示する。

受注番号を持たない受注は、受注番号の欄に「-」と表示する。

買取番号は7桁のゼロ埋めで表示する。

購入履歴・買取履歴とも、新しく登録されたものから順に並べる。

### 入力値の制約

| 項目 | 制約 |
| --- | --- |
| 生年月日 | 今日以降の日付は不正な日付として扱う |
| メールアドレス | 既に別の会員へ登録されているものは使えない |
| FAX番号 | 3つの欄のうち一部だけを入力することはできない。すべて入力するか、すべて空にする |

### 新規登録で会員住所へ写す項目

| 会員の項目 | 会員住所への反映 |
| --- | --- |
| 氏名 | 同じ値を写す |
| カナ | 同じ値を写す |
| 会社名 | 同じ値を写す |
| 郵便番号 | 同じ値を写す |
| 都道府県 | 同じ値を写す |
| 住所 | 同じ値を写す |
| 電話番号 | 同じ値を写す |
| FAX番号 | 同じ値を写す |

編集のときは会員住所を生成しない。

### 本人確認ステータスの自動降格

| 変更した項目 | 本人確認用情報の変更とみなす会員の状態 |
| --- | --- |
| 国 | 確認済み、または簡易書留確認済みのとき |
| 郵便番号 | 確認済み、または簡易書留確認済みのとき |
| 海外用郵便番号 | 確認済み、または簡易書留確認済みのとき |
| 都道府県 | 確認済み、または簡易書留確認済みのとき |
| 住所1 | 確認済み、または簡易書留確認済みのとき |
| 住所2 | 確認済み、または簡易書留確認済みのとき |
| お名前 | 確認済みのときだけ |
| お名前（フリガナ） | 確認済みのときだけ |
| 生年月日 | 確認済みのときだけ |

本人確認用情報の変更があるときは、登録の前に確認を求める。

続行を選んだときだけ、本人確認ステータスの送信値を未確認へ書き換えてから送信する。

取り消したときは送信しない。

### エラー時の扱い

| 事象 | 扱い |
|------------|------|
| 入力内容の検証に外れたとき | 保存せず、同一画面に項目ごとのエラーを表示する |
| 存在しない会員IDを指定したとき | ページが見つからない扱い（404）とする |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 会員登録フォームの入力値。 |
| 成功時出力 | 会員情報の保存と保存成功のメッセージ。保存した会員の編集画面への遷移。 |
| 失敗時出力 | 検証に外れたときは同一画面に項目ごとのエラー。存在しない会員IDのときはページが見つからない扱い（404）。 |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 追加 | 会員を新規登録したとき。会員住所も1件追加する |
| 更新 | 会員を編集して保存したとき |

## 表示メッセージ

| メッセージID | 表示位置 | 画面上の文言 | 表示条件 | 後続処理 |
| --- | --- | --- | --- | --- |
| M08-04-MSG-001 | 管理画面上部 | 保存しました | 会員情報を登録または更新して保存に成功したとき | M08-04（会員登録/編集）画面に遷移する |
| — | ブラウザ標準の確認ダイアログ | 本人確認用情報に変更があるため本人確認ステータスを未確認に変更します。よろしいですか？\n本人確認用情報：お名前、お名前(フリガナ)、住所、生年月日 | 確認済み・簡易書留確認済みの会員で本人確認用情報を変更し登録ボタンを押したとき | 続行で本人確認ステータスを未確認へ書き換えて送信する |
| M08-04-MSG-002 | 入力項目直下 | 生年月日が不正な日付です。 | 生年月日に今日以降の日付を入力して登録または更新したとき | M08-04（会員登録/編集）画面に留まる |
| M08-04-MSG-003 | 入力項目直下/フォーム上部 | パスワードはメールアドレスと同じ値を設定できません。 | メールアドレスと同じパスワードを入力して登録または更新したとき | M08-04（会員登録/編集）画面に留まる |
| M08-04-MSG-004 | 入力項目直下/フォーム上部 | このメールアドレスは利用できません。 | すでに別の会員に登録されているメールアドレスを入力して登録または更新したとき | M08-04（会員登録/編集）画面に留まる |
| M08-04-MSG-005 | 入力項目直下/フォーム上部 | すべて入力してください | FAX番号の先頭欄を空欄のまま、後ろの欄を入力して登録または更新したとき | 保存へ進まず、M08-04（会員登録/編集）画面に留まる |
| M08-04-MSG-006 | お届け先一覧末尾 | お届け先登録の上限の%eccube_deliv_addr_max%件に達しています。お届け先を入力したい場合は、削除か変更を行ってください。 | 会員編集画面で登録済みお届け先数が上限に達したとき | お届け先を追加できず、会員編集画面に留まる |
| M08-04-MSG-007 | 購入履歴欄 | この会員の購入履歴がありません | 会員登録・編集画面で、表示対象の会員の購入履歴が0件のとき | 会員登録・編集画面に購入履歴なしとして表示したまま留まる |

各項目の必須・形式のエラーは、各欄の直下に表示する。

本人確認ステータスの確認は、登録の操作をしたときにブラウザ標準の確認で行う。
