# 商品管理 — 売上分析タグ登録/編集

## 業務ロジック

### 一覧と入力欄

画面は売上分析タグの一覧と入力欄を同時に出す。一覧は並び順の昇順で並べる。並び順の値が小さいものほど先に来る。一覧を並べ替える操作は持たない。

ページ番号は要求の指定があるときはその値、無いときは保持していた値、それも無いときは 1 とする。表示件数は要求の指定があるときはその値、無いときは保持していた値、それも無いときは 10 件とする。

編集の対象を指定したときは当該の売上分析タグを入力欄に読み込む。対象を指定しないときは新規の入力欄とする。

### 保存の判定順序

| 順序 | 判定 | 結果 |
| --- | --- | --- |
| 1 | 送信済みで、かつ入力の検証を満たすか | 満たさないときは保存せず、保持していたページ番号と表示件数で一覧を組み直して再表示する |
| 2 | 保存できるか | 登録済みの値と重複するときは保存せず、一覧を組み直して再表示する |
| 3 | 上記をすべて満たしたとき | 売上分析タグを登録または更新し、一覧へ戻す |

### 削除の判定順序

| 順序 | 判定 | 結果 |
| --- | --- | --- |
| 1 | なりすまし対策トークンが有効か | 無効のときはアクセス拒否（HTTP 403）とする |
| 2 | 当該の売上分析タグを使う商品が 1 件でもあるか | あるときは削除せず、一覧へ戻す |
| 3 | 購入済みの商品として注文明細に紐づくか | 紐づくときは削除せず、一覧へ戻す |
| 4 | いずれにも紐づかないとき | 削除し、一覧へ戻す |

### 入力の制限

| 項目 | 制限 |
| --- | --- |
| 名称 | 必須。64 文字以下 |
| 並び順 | 必須。1 以上 65535 以下 |

税率と売上の集計はこの機能では行わない。

### エラー時の扱い

| エラー内容 | 処理 |
| --- | --- |
| 入力の検証を満たさない | 保存せず、一覧を組み直して再表示する |
| 登録済みの値と重複する | 保存せず、一覧を組み直して再表示する |
| 削除しようとした売上分析タグを商品が使っている | 削除しない |
| 削除しようとした売上分析タグが購入済みの商品に紐づく | 削除しない |
| 削除でなりすまし対策トークンが無効 | アクセス拒否（HTTP 403）とする |

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | 一覧はページ番号と表示件数、編集は対象の売上分析タグ。保存は入力欄一式となりすまし対策トークン。削除はなりすまし対策トークン |
| 成功時出力 | 一覧と入力欄の画面、または一覧への戻り。完了のメッセージを伴う |
| 失敗時出力 | 一覧と入力欄を含む画面にエラーを表示する。削除できないときはメッセージだけを伴って一覧へ戻す |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 追加・更新 | 入力の検証を満たし、登録済みの値と重複しないとき |
| 削除 | 商品にも購入済みの商品にも紐づかないとき |
