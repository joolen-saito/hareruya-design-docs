# データ管理 — トップバナー管理（バナー設定）

## 業務ロジック

### 画面の表示

トップバナーをID昇順で全件取得し、バナー設定の入力欄として表示する。あわせて画像アップロード用のファイル入力と店舗選択を表示する。パスで店舗を指定して開いたときは、その店舗を既定の選択とし、店舗選択を必須とする。

画像一覧は、店舗の指定が無いときはバナー用フォルダ直下、指定があるときはその店舗別フォルダ配下のファイルを取得し、更新日時の降順に並べて先頭2000件までを表示する。

### バナー設定の保存

各枠の並び順の値を昇順に並べ、その順で入力の束に 1 から始まる連番を割り当てる。トップバナーの各行について、連番が行のIDと一致する束から画像URL・リンク・表示タイプ・言語ID群・画像の代替テキストを読み取り、当該行へ設定する。言語は指定された言語IDで引き直した結果に置き換える。リンクが未入力のときは空文字を設定する。保存後は完了メッセージを表示せずトップバナー管理画面へ戻る（店舗を指定して開いていたときは同じ店舗の画面へ戻る）。

入力値の検証に失敗したときは、バナー用フォルダ直下の画像一覧だけを取得し直した状態で同じ画面を再表示する（店舗を指定して開いていた場合も直下のみとなる）。文字数超過のメッセージには上限値 255 を埋め込む。

### 画像のアップロード

| 判定 | 結果 |
| --- | --- |
| ファイルが未選択 | 画像ファイルを選ぶよう促すエラーを表示する |
| ファイルサイズが 520000 バイトを超える | サイズ超過のエラーを表示する。メッセージには上限値を埋め込む |
| 画像種別が GIF・JPEG・PNG 以外 | 画像ではない旨のエラーを表示する |
| 上記に当たらない | 店舗を選んでいなければバナー用フォルダ直下、選んでいればその店舗別フォルダへ拡張子付きで格納する |

アップロードが成功してもトップバナーの登録内容は更新しない。処理後はアップロード欄の位置へ戻る。

### 画像の削除

指定されたファイル名をサーバー側の文字コードへ変換したうえで、該当するファイルが保管先に存在すれば削除する。存在しないときは削除を行わない。いずれの場合もアップロード欄の位置へ戻る。なりすまし対策トークンが不正なときはアクセスを拒否する（403）。

本機能では金額計算や件数集計を行わない。トップバナーの属性更新とファイルの入出力が中心である。

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 対象店舗の指定、バナー設定の入力項目（並び順・画像URL・リンク・表示タイプ・言語・代替テキスト）、アップロードする画像ファイルと店舗選択、削除するファイル名、なりすまし対策トークン |
| 成功時出力 | トップバナーの更新、画像ファイルの保存・削除、トップバナー管理画面への戻り |
| 失敗時出力 | 同じ画面の再表示とエラーメッセージ。トークン不正は403 |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 更新 | バナー設定の保存時に、トップバナーの各行の画像URL・リンク・表示タイプ・言語・代替テキストを更新する |
| 追加 | 画像アップロードの検証に通ったときに、画像ファイルを保管先へ格納する |
| 削除 | 指定したファイルが保管先に存在するときに削除する |
