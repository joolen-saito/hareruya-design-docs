# F02-02（本店スマホ版ナビ）

## 業務ロジック

### 表示する要素

| 領域 | 内容 |
| --- | --- |
| 上段のナビ | 日本語のときはショップ・買取・記事・デッキ検索・デッキ構築・店舗一覧・イベント・ヘルプを表示する |
| 上段のナビ | 英語のときはショップ・記事・選手一覧・デッキ検索・店舗一覧・イベント・ヘルプを表示する。英語のときは買取とデッキ構築を表示せず、選手一覧を加える |
| 下段 | いずれの言語のときも、商品カテゴリの導線と、キーワード入力欄を持つ商品検索を表示する |
| モーダル | スマホ版ナビ自体は専用のモーダルを持たない |

スマホ表示のときはスマホ用の体裁を適用する。デッキ検索とデッキ構築の項目は、スマホ表示のときに改行を入れて表示する。検索欄向けの体裁を読み込む。

### 遷移先の受け渡し

商品カテゴリと商品検索の遷移先は、呼び出し元から渡された値を用いる。検索を送信したときは、呼び出し元から渡された遷移先へキーワードを送る。以降の検索結果の表示は商品機能に従う。

### 候補リスト

キーワード入力欄には、カード名一覧とサプライ名一覧の取得元を持たせ、入力中に候補リストを表示する。サジェスト版のときはサジェスト用の体裁を付す。候補リスト用のデータを取得できないときは候補リストを表示せず、検索の送信は続けられる。

### 本店と支店の境界

本書のスマホ版ナビは本店の導線とする。支店スマホ版ナビ（F02-04）とは別の部品とする。本機能はいずれのときも金額計算・税計算・丸めを行わない。

### フェーズ2対応（フェーズ1では実装しない）

Excel基本設計 0302「スマホ版ナビゲーション上の通知」はフェーズ2対応とし、フェーズ1ではこの項目だけ実装しない。Excel原文は「※通知はフェーズ2以降で設計予定とする」である。

### エラー時の扱い

| 事象 | 扱い |
| --- | --- |
| 候補リスト用のデータを取得できないとき | 候補リストを表示しない。検索の送信は続けられる |
| 描画に障害があったとき | 共通の例外処理に委ねる |

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | 本店各画面の表示要求（ロケール付き）、呼び出し元から渡される遷移先、検索キーワード |
| 成功時出力 | スマホ版ナビと商品検索の表示 |
| 失敗時出力 | 描画に失敗したときは共通の例外処理に委ねる |

### 入出力: 永続化

本機能はデータを更新しない。

## 表示メッセージ

本機能は固有の文言を持たない。表示するのはナビの項目名である。
