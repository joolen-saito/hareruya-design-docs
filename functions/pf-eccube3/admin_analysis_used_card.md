# 分析集計 — デッキ採用枚数集計（出力条件変更・特集タグ編集用CSVダウンロード）

## 業務ロジック

### 出力条件の保持

初期表示では、保持していた出力条件を消去して検索フォームだけを表示する。検索を実行すると、受け取った出力条件を保持したうえで集計結果を表示する。CSV出力は保持した出力条件で集計する。

### 出力形式

特集タグ編集用などの出力形式ごとに、集計方法と出力列を切り替える。指定形式のヘッダと各行をCSVとしてストリーミング出力する。ファイル名には形式と日時を含める。

### エラー時の扱い

管理画面の認証・権限を通過しないときはアクセスできない。

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 出力条件、CSVの出力形式、なりすまし対策トークン |
| 成功時出力 | 集計結果の画面、指定形式のCSVファイル |
| 失敗時出力 | 認証・権限不足のときはアクセス不可 |
