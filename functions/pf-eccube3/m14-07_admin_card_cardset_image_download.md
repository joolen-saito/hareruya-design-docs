# カードセット管理 — 収録カード画像 ZIP ダウンロード（セット別／言語別）

## 業務ロジック

### 共通の前処理

対象のカードセットIDを受け取る。指定が無いときはID `0` の1件を指定したものとして扱う。実行時間の制限は無効にする。

作業用の`download`ディレクトリが無いときは作成し、あるときは配下のファイルとサブディレクトリをすべて削除して空にする。画像の取得元はオブジェクトストレージの`set/`配下である。

言語別のときは、この時点でカード画像が1件以上存在する言語をすべて列挙し、各言語コード名のサブディレクトリを`download`直下に作成する。

### セット別の作成

| 判定 | 結果 |
|------|------|
| 指定IDが実在するカードセットのとき | `download/{セット略称コード}`を作成し、保存先とする |
| 指定IDが実在しないとき | ダミーのプロモーション集合として扱い、プロモーション名（英字）ごとに`download/{その英字}`を作成する |
| 対象のカード詳細が0件のとき | 対象セットにカードが無い旨を表示し、保持したページ番号（無いときは1）のカードセット一覧へ戻って終了する |
| カード詳細に画像が無いとき | そのカード詳細を飛ばす |
| 指定IDが `0` のとき | 保存先を`download/{当該カード詳細のプロモーション英名}`に差し替える |
| 画像の保存に成功したとき | 圧縮ファイルへ追加し、同一カード詳細の残りの画像は処理しない |
| いずれの画像も保存に至らなかったとき | 当該カード詳細のIDを埋め込んだ画像なしのメッセージを表示し、処理は続ける |

カード画像はカード詳細ごとに言語ID昇順で取得する。日本語のIDは英語のIDより小さいため、昇順では日本語側が先に列挙される。実装のコメントには「英語優先」とあるが並べ替えは昇順のみであり、コメントとコードが一致しないときは実装を確認値とする。

同一カード詳細に複数言語の画像があっても、先に保存に成功した1枚だけが圧縮ファイルに載る。

### 言語別の作成

対象のカード詳細はセット別と同じ経路で取得する。カード詳細が0件のセットはエラーとせず、次のIDへ進む。

保存先は`download/{画像の言語コード}`とし、ファイル名の規則はセット別と同じである。保存に成功したファイルはすべて圧縮ファイルへ追加し、セット別のような1枚での打ち切りは行わない。

### 対象と命名

| 項目 | 内容 |
|------|------|
| 対象カード詳細 | 指定したカードセットに属するカード詳細。IDが `0` のときはカードセットが未設定のカード詳細に限り、カード画像とプロモーションが無いものは対象から外れる |
| ローカルファイル名 | 「カード詳細ID + `.jpg`」。ホイル相当のときは先頭に `F` を付ける。拡張子は取得元のキーの拡張子によらず`.jpg`で固定する |
| デッドリンク | 画像の保存に成功しなかったときは真へ、成功して真だったときは偽へ更新する。セット別は画像ごとに即時反映し、言語別は全IDの処理後にまとめて反映する。言語別で同じ画像が複数回対象になったときは後の判定が残る |
| ホイル除外の有無 | 実装のコメントには「非プロモ、プレリプロモのフォイルは除外する」とあるが、ホイルのときにファイル名へ `F` を付けるだけで、画像を除外する条件は無い。実装を確認値とする |

### 応答

圧縮ファイル`download/card_image.zip`が存在しないときは、画像が存在しない旨を表示し、保持したページ番号のカードセット一覧へ戻る。存在するときは本体を返す。`Content-Type`は`aplication/octet-stream;`（表記は実装どおり）、`Content-Disposition`はファイル名をUTF-8でエンコードした形式で付与する。

セット別では、応答を返した後に`download`配下の内容を再度すべて削除する。言語別にはこの後処理が無い。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| セット別で対象セットにカード詳細が無いとき | 対象セットにカードが無い旨を表示し、カードセット一覧へ戻る |
| セット別で画像取得に一切成功しないカード詳細があるとき | 当該カード詳細の画像なしを表示し、処理は続行しうる |
| 圧縮ファイルが最終的に存在しないとき | 画像が存在しない旨を表示し、カードセット一覧へ戻る |
| オブジェクトストレージが例外を返したとき | 例外は握りつぶされて取得結果が空になり、上位で失敗として扱う |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | カードセットIDの配列（省略時はID `0` の1件とみなす）、なりすまし対策トークン |
| 成功時出力 | HTTP 200と`card_image.zip`の本体、前述の`Content-Type`と`Content-Disposition` |
| 失敗時出力 | エラーメッセージとカードセット一覧への遷移、またはなりすまし対策トークン失敗時の共通応答 |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 更新 | カード画像のデッドリンク（セット別は画像ごとに即時、言語別は全ID処理後にまとめて） |
