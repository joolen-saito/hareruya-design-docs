# イベント管理 — イベント申込一括編集

## 業務ロジック

### 一括編集の判定順序

| 順序 | 判定・処理 | 内容 |
| --- | --- | --- |
| 1 | 呼び出しの形式 | 非同期の呼び出しでないときは更新せず、失敗メッセージを返す |
| 2 | 入力内容の検証 | 外れたときは更新せず、エラー内容を返す |
| 3 | 対象の取得 | 指定された申込IDの申込だけを取得する |
| 4 | 更新 | 申込ごとに、申込ステータスを指定された値へ揃える |
| 5 | 履歴 | 申込ごとに申込履歴を記録する |
| 6 | 確定 | 変更を確定し、完了メッセージを返す |

対象の行を1件も選ばずに実行したときは、一括更新を中止する。

### エラー時の扱い

| 事象 | 扱い |
|------------|------|
| 非同期でない呼び出しのとき | 更新せず、失敗メッセージを返す |
| 入力内容の検証に外れたとき | 更新せず、エラー内容を返す |
| 対象の行を1件も選んでいないとき | 一括更新を中止し、イベント申込一覧に留まる |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 申込ステータスと、対象の申込ID群。 |
| 成功時出力 | 申込ステータスの一括更新、申込履歴の記録、完了メッセージ。 |
| 失敗時出力 | 非同期でないとき、検証に外れたときのエラー内容。 |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 更新 | 一括編集で、対象の申込の申込ステータスを指定値へ更新するとき |
| 追加 | 申込ステータスを更新した申込ごとに、申込履歴を1件記録する |

| — | 一括更新の応答 | 失敗メッセージ | 非同期でないとき、または検証に外れたとき | 更新せず、応答として返す |
| — | 一括更新の応答 | 完了メッセージ | 一括更新が完了したとき | 応答として返す |
