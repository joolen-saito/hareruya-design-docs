# イベント管理 — イベント申込一括編集

## 業務ロジック

### 一括編集の受け付け条件

| 順序 | 判定 | 満たさないときの扱い |
| --- | --- | --- |
| 1 | 対象の行が1件以上選ばれていること | 一括更新を要求せず中止し、イベント申込一覧に留まる |
| 2 | 非同期の呼び出しであること | 更新せず、失敗メッセージを応答として返す |
| 3 | 入力内容の検証を満たすこと | 更新せず、エラー内容を応答として返す |

判定はこの順に行い、満たさない判定が出た時点で以降の更新を行わない。

順序3の検証は、申込状況が選ばれていることを求める。申込状況が「申込状況選択」のままのときは申込を1件も更新せず、「申込状況は必須です。」を応答として返す。

### 一括更新後の一覧表示

一括更新の結果はメッセージとして応答に返すだけで、イベント申込一覧の再読み込みも一括編集の入力領域の閉じ込みも行わない。一覧に表示中の申込状況は、一覧を再表示するまで更新前の値のまま残る。

## 入出力

| 種類 | 内容 |
|------|------|
| 成功時出力 | 完了メッセージを応答として返す。画面遷移は行わない。 |
| 失敗時出力 | 非同期でない呼び出しのときは失敗メッセージを、検証に外れたときは検証エラーの内容を、応答として返す。 |
