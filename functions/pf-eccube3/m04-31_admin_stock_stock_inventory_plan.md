# 在庫管理 — 棚卸計画

## 業務ロジック

### 棚卸計画の特定

対象の棚卸計画が存在しない場合はページが見つからない扱いとする。

### 一覧の表示

登録された棚卸計画が1件も無い場合は、一覧・該当件数・ページングを表示せず、その旨の見出しだけを表示する。

表示件数は選択した値を保持し、次に一覧を表示したときも前回選んだ件数で表示する。

指定したページの対象が無くなり、直前のページまでで全件が収まる場合は、1つ前のページを表示する。

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 棚卸名、備考 |
| 失敗時出力 | 入力項目ごとのエラー内容 |

### 入出力: 入力値の制限

棚卸名は255文字以内とする。既に同じ棚卸名の棚卸計画が存在する場合は登録・更新できない。

備考は1024文字以内とする。

### 入出力: 永続化

棚卸計画は棚卸計画テーブルに棚卸名・備考・作業者・在庫反映日を保持する。作業者には、その保存を行った管理者を記録する。

| 操作 | 契機 |
| --- | --- |
| 追加 | 棚卸計画の新規登録 |
| 更新 | 棚卸計画の更新 |
