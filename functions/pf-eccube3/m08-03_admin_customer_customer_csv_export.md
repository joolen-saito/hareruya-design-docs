# 会員管理 — 顧客情報CSV出力

## 業務ロジック

### 出力の対象

出力の対象は、保持している会員検索の条件で絞り込んだ会員だけとする。この機能は入力の欄を持たず、検索条件を画面から受け取らない。

出力する列は会員のCSV出力項目の設定に従う。設定に無い項目は、値を持つときも出力しない。

### 出力する内容

会員ごとに、CSV出力項目の設定に合う標準の項目だけと、次の拡張項目を並べる。拡張項目は会員IDが一致するものを各行に付ける。

| 拡張項目 | 内容 |
| --- | --- |
| ポイント | 当該会員の保有ポイント |
| 本人確認ステータス | 当該会員の本人確認ステータスの識別子と名称 |
| スマレジID | 当該会員のスマレジID |

件数が多いときに備え、タイムアウトを無効にして順に書き出す。ヘッダ行を先に出力し、続けて検索結果の会員ごとに 1 行を出力する。

### エラー時の扱い

| エラー内容 | 処理 |
| --- | --- |
| 認証と権限を満たさない | 出力しない |

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | 保持している会員検索の条件と、会員のCSV出力項目の設定 |
| 成功時出力 | 会員情報のCSV。先頭行はヘッダ、以降は会員ごとのデータ行 |
| 失敗時出力 | 認証と権限を満たさないときは出力しない |

## 表示メッセージ

この機能はエラーメッセージを表示しない。
