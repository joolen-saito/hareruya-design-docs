# イベント管理 — 繰り返し日程登録

## 業務ロジック

### 登録の判定順序

| 順序 | 判定 | 結果 |
| --- | --- | --- |
| 1 | パスのイベントIDに一致するイベントが存在しないとき | ページが見つからない扱い（404）とする |
| 2 | 入力の検証に失敗したとき | 保存に失敗した旨を表示し、入力画面を再表示する |
| 3 | 申込受付を有効にする指定で、当該イベントに支払方法が設定されていないとき | 申込受付ができない旨を表示し、入力画面を再表示する |
| 4 | 上記以外のとき | 指定期間内の該当日について日程を一括作成する |

### 日程の作り方

選択した曜日を取得し、指定期間内にその曜日に該当する日があるときは、その日の日程を作成する。

該当する日が複数あるときは、作成した日程を一括で登録する。

作成の対象は、指定期間内で選択した曜日に該当する日だけとする。

### 申込受付の前提

申込受付を有効にするときは、イベントに支払方法が設定されている必要がある。オンライン受付ありで参加費が有料のときも、支払方法の設定が必要となる。

### エラー時の扱い

| 事象 | 扱い |
| --- | --- |
| イベントが存在しないとき | ページが見つからない扱い（404）とする |
| 入力の検証に失敗したとき | 保存に失敗した旨を表示し、入力画面を再表示する |
| 申込受付を有効にした状態で支払方法が未設定のとき | 申込受付ができない旨を表示し、入力画面を再表示する |
| 対象イベントの店舗情報が無いとき、またはその店舗を編集できないとき | 不正な要求として扱い、繰り返し日程登録画面へ戻す |

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | イベントID、期間、曜日、申込受付の指定、なりすまし対策トークン |
| 成功時出力 | 該当日の日程の一括作成と、イベント編集画面への遷移 |
| 失敗時出力 | イベントが無いときは404。検証に失敗したとき、支払方法が未設定のときはエラーを表示し、入力画面を再表示する |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 追加 | 検証を通ったときの、指定期間内で該当する曜日の日程 |
