# イベント管理 — 繰り返し日程登録

## 業務ロジック

### 登録の判定順序

| 順序 | 判定 | 結果 |
| --- | --- | --- |
| 1 | パスのイベントIDに一致するイベントが存在しないとき（入力画面の表示時・登録時とも） | ページが見つからない扱い（404）とする |
| 2 | 入力の検証に失敗したとき | 保存に失敗した旨を表示し、入力画面を再表示する |
| 3 | 「受付あり」を有効にした指定で、対象イベントに支払方法が設定されていないとき | 申込受付ができない旨を表示し、入力画面を再表示する |

### 作成した日程に設定される値

作成した日程が土曜・日曜に当たるとき、または休日マスタに登録された日に当たるときは、その日程を休日として扱う。

作成した日程の登録者には、操作した担当者を記録する。

オンライン受付の開始・終了とデッキ登録締切の日時は、その日程の日付から指定の前日数を引いた日に、指定の時刻を組み合わせたものとする。

### 該当する日が無いとき

指定期間内に、選択した曜日に該当する日が1日も無いときは、日程を1件も作成しないまま登録完了として扱う。

## 入出力

### 入力

| 種類 | 内容 |
| --- | --- |
| 入力 | なりすまし対策トークン。値が一致しないときは日程を作成せず、アクセス拒否として扱う |
