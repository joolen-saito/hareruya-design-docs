# F03-01（商品一覧）

## 概要

フロントの商品一覧は、利用者が入力・選択した検索条件に基づいて、晴れる屋の取扱商品（カード商品）を絞り込み、ページングしながら一覧表示する機能である。検索条件はURLのクエリ文字列で受け取り、条件に合致する商品規格を抽出して、商品数・並び順・ページ送り・各商品のサムネイルと価格・在庫を表示する。

本書は実装手順ではなく、誰が・いつ・どの条件で・結果どうなるかを読むためのリバース詳細設計とする。確認値はpf-eccube3（EC-CUBE3系）のHareruyaEcプラグインの商品一覧処理（商品検索）、商品検索の共通処理、検索条件の組み立て、テンプレート（`Product/product_list_unisearch.twig`・`Product/product_list.twig`・`Block/product_list.twig`）、オプション（`product_search_limit`）を正とする。本機能のカスタマイズ区分はカスタマイズであり、画面挙動の参照リポはpf-eccube3、DB関連の記述はec-cube-enterpriseを正とする。

対象はブラウザ経由のフロントに限定する。フロントのルートはロケールを先頭に付けた`/{_locale}`配下に配置される。

本文ではフレームワークのコントローラ型名やメソッド名を主説明としない。本文ではルートbind名の網羅は主説明とせず、「利用者視点の入口」にHTTPメソッドとサイトルートからのパスパターンを書く。コード探索でbind名が必要なときだけ「調査補助」へ書く。

---

## 本書で扱うこと

- 商品一覧画面の入口（検索結果一覧と、検索条件が空のときの初期表示）
- 検索条件（商品名・カテゴリ・カードセット・色・レアリティ・カードタイプ・フォーマット・価格帯・フォイル・言語・在庫・マナコスト・サブタイプ等）による商品の抽出と出し分け
- 並び順（色順・価格高い順・価格安い順）とページング
- 商品数の表示と、検索結果が多すぎる場合・0件の場合の表示
- 商品一覧に並ぶ各商品の価格・在庫・コンディションの出し分けの考え方
- 検索エンジン（ユニサーチ）を用いる経路と用いない経路の出し分け

## リニューアル移行時の扱い

本機能は参照のみで台帳を更新しない。画面挙動はpf-eccube3を確認値とし、DB関連はec-cube-enterpriseを正とする。現行と移行先で次の差がある。

| 観点 | 現行（pf-eccube3） | 移行先（ec-cube-enterprise） |
|------|--------------------|------------------------------|
| 商品の公開・削除 | 商品`dtb_product`に公開状態`status`と論理削除フラグ`del_flg`を持つ | `dtb_product`に`del_flg`は無く、公開状態は商品ステータス`product_status_id`（区分`mtb_product_status`）で表す。論理削除列は廃止。 |
| 在庫・価格 | `dtb_product_class`の`stock`・`price02` | 同一スキーマ（`stock`・`price02`を保持）。 |
| 商品規格の拡張属性 | 言語・コンディション・フォイル・高額コード | `dtb_product_class`の`language_id`・`card_condition_id`・`high_price_code`等として保持。フォイル区分の列名はec-cube-enterprise実装で要確認。 |
| 検索件数上限 | オプション`product_search_limit` | `mtb_option`の`option_key`=`product_search_limit`として保持。同一。 |

検索エンジン（ユニサーチ）経由の本店一覧経路の有無は移行方針に依存するため、本書では移行差を確定しない。

## 用語

| 用語 | 説明 |
|------|------|
| 商品規格 | 商品とコンディション・言語・フォイル等の組で在庫・価格を持つ単位。一覧の抽出・件数はこの単位を起点とする。 |
| コンディション | カードの状態区分。状態コード`NM`（良品）や`HP`等がある。 |
| 言語 | 商品規格の言語区分。日本語（`JP`）・英語（`EN`）・その他。 |
| 高額コード | 商品規格に付く別在庫区分の識別子（`highPriceCode`）。通常一覧の抽出では原則として高額コードなしの規格を対象とする。 |
| ユニサーチ | 商品検索に用いる外部検索エンジン。本店の商品一覧はユニサーチ経由の検索を既定とする。 |
| 本店一覧 | ユニサーチを用いる通常の商品一覧経路（`Product/product_list_unisearch.twig`）。 |
| 支店一覧 | ユニサーチを用いずデータベース検索で組み立てる経路（`Product/product_list.twig`）。 |

## 利用者視点の入口

| 入口 | URLエンドポイント | 期待されるふるまい |
|------|--------------------|--------------------|
| 検索条件なしで商品一覧を開く | `GET /{_locale}/products/search` | 検索フォームのみを表示し、商品結果は表示しない（初期表示）。 |
| 検索条件付きで商品一覧を開く | `GET /{_locale}/products/search?（検索条件）` | 条件に合致する商品を抽出し、商品数・並び順・ページ送りとともに一覧表示する。 |
| 並び順を切り替える | `GET /{_locale}/products/search?...&sort=price&order=ASC`（色順は`sort=default`） | 同じ検索条件で並び順を変えて一覧を再表示する。 |
| ページを移動する | `GET /{_locale}/products/search?...&page=（番号）` | 同じ検索条件で指定ページの一覧を表示する。 |
| 一覧の商品サムネイルの遅延読み込み | `GET /{_locale}/products/search/lazy` ・ `GET /{_locale}/products/search/unisearch/lazy` | 一覧に並ぶ商品規格の表示用HTMLを非同期で取得して描画する。 |

フロントのページであり管理画面プレフィックスは付かない。ロケールは`/{_locale}`の先頭区切りで決まる。本店一覧はユニサーチ経由の検索（`/products/search`）を既定とし、ユニサーチを用いない支店一覧経路（`Product/product_list.twig`）は同一の商品一覧テンプレート群の別系統として用意される。

## フロント挙動

| 観点 | 内容 |
|------|------|
| 表示要素 | パンくず、検索条件の見出し（条件語の連結）、商品数、絞り込みアイコン群（言語・フォイル・レアリティ・色・カードタイプ・マナコスト・在庫）、並び替えリンク、商品一覧、ページ送り。 |
| JS挙動 | 一覧の商品サムネイルは遅延読み込みで取得する。絞り込みアイコンの押下で検索条件を変えて再検索する。スクロールによる次ページ追記用の要素を持つ。 |
| CSS・レイアウト | PC用とスマートフォン用で絞り込み・並び替えの並びを切り替える。選択中の絞り込みは選択状態の画像・クラスで示す。 |
| モーダル・ポップアップ | ログイン用モーダルを内包する。商品一覧自体の操作で開く確認ダイアログは持たない。 |

検索条件が空のとき（初期表示）は検索フォームのみを表示する。商品数は検索結果件数を表示し、件数が上限を超える場合は上限値に`+`を付けて表示する。

## 処理フロー

### 検索条件なしで一覧を開く

1. クエリ文字列が空のとき、検索フォームと（ログインフォーム等の）共通要素のみを表示する。
2. 商品結果・商品数・ページ送りは表示しない。

### 検索条件付きで一覧を開く（本店一覧・ユニサーチ経由）

1. 検索フォームへリクエストを反映し、クエリ文字列を検索条件として受け取る。
2. タグ指定が1件のときは、対応する説明文表示用の情報を取得する。
3. ページ番号・1ページ件数を確定する。未指定時は1ページ目・規定件数とする。
4. カードセット指定がある場合は対応するカードセットを取得する。
5. 英語ページが不在である旨を設定する（検索一覧は英語ページを持たない）。
6. ユニサーチ用のリクエストパラメータを組み立て、一覧テンプレートへ渡して描画する。商品規格の具体的な内容はサムネイルの遅延読み込みで取得する。

### 検索条件付きで一覧を組み立てる（支店一覧・データベース検索）

1. クエリ文字列を検索条件として受け取り、ページ番号・1ページ件数を確定する。
2. 検索条件から該当商品規格を抽出して件数を数える。
3. 件数が`product_search_limit`を超える場合は、結果内容を取得せず件数のみを設定し、検索負荷の通知用エンドポイントへ件数とURLを送信する。
4. 件数が上限以内の場合は、現在ページ・1ページ件数・総件数・該当ページの商品規格を一覧へ設定して描画する。
5. 抽出件数が0件の場合は、本文を組み立てたうえで応答ステータスを404として返す。

### 並び替え・ページ送り

1. 並び替えリンク・ページ送りリンクは、現在の検索条件に並び順（`sort`・`order`）またはページ番号（`page`）を上書きして同一の一覧URLへ遷移する。
2. 遷移後は同じ抽出条件で並び順・ページのみを変えて再表示する。

## 集計条件

| 指標 | 集計の要点 |
|------|------------|
| 商品数 | 検索条件に合致する商品規格を抽出した件数。条件なしの全件相当（後述の全件判定に該当）では結果を組み立てない。 |
| 抽出対象 | 商品名・カテゴリ・カードセット・色・色アイデンティティ・レアリティ・カードタイプ・フォーマット・価格帯・フォイル・言語・在庫・マナコスト・サブタイプ・タグ・カードIDのいずれかが指定された検索。 |
| 全件判定 | 上記の主要条件がいずれも未指定で、在庫条件が「すべて表示」相当のときは全件検索とみなし、結果を組み立てず空の一覧を返す。 |
| 在庫条件 | 在庫条件が「在庫ありのみ」のときは在庫がある商品規格に限定する。「すべて表示」のときは在庫の有無で絞り込まない。 |
| 上限超過 | 抽出件数が`product_search_limit`（確認値 9999）を超える場合は、商品内容を取得せず件数のみ扱い、画面では件数に`+`を付ける。 |
| 並び順 | 色順（既定）、価格の高い順、価格の安い順のいずれか。 |

## 業務ルール・計算

| 項目 | 内容 |
|------|------|
| 価格の出し分け | 一覧の各商品の価格は、抽出された商品規格の販売価格を表示する。 |
| 在庫の出し分け | 在庫条件が「在庫ありのみ」のときは在庫がある商品規格に限定する。在庫数は商品規格の在庫数量を表示する。 |
| コンディション・高額コードの出し分け | 通常の商品検索の抽出では高額コードなしの商品規格を対象とする。高額コード付きの別在庫はカードID等の特定条件の経路で扱う。 |
| 本店・支店の出し分け | 本店一覧はユニサーチ経由の検索結果を用いる。ユニサーチを用いない支店一覧経路はデータベース検索で抽出し、上限超過時は件数のみを扱う。いずれも同一の検索条件クエリで動作する。 |
| 並び順の確定 | `sort`が`price`のときは価格順（`order`が`DESC`で高い順、それ以外で安い順）、`sort`が`default`または不正値のときは色順とする。 |
| ページング | 1ページ件数は`pageSize`、未指定時は規定件数（確認値 60）とする。総ページ数は総件数を1ページ件数で割って切り上げる。 |
| 検索結果が多すぎる場合 | 件数が上限超過のときは商品内容を表示せず、さらに絞り込みを促すメッセージを表示する。 |

### 入力項目

| 項目名 | 必須／任意 | 最大長 | 初期値 | 保存先・扱い |
|--------|------------|--------|--------|----------------|
| 並び順 | 任意 | — | 色順（`default`） | クエリ`sort`（`default`／`price`）と`order`（`ASC`／`DESC`）。抽出結果の並び替えにのみ用い、保存しない。 |
| 表示ページ | 任意 | — | 1ページ目 | クエリ`page`。表示位置の指定にのみ用い、保存しない。 |
| 在庫絞り込み | 任意 | — | すべて表示（`0`） | クエリ`stock`。`1`で在庫ありのみに限定。保存しない。 |

検索条件の各入力欄（商品名・カテゴリ・色・レアリティ等）の項目定義は詳細検索フォーム（F03-03）を正とする。一覧画面はそれらの条件をクエリとして受け取り、抽出・絞り込みアイコンの選択状態の表示に用いる。

### エッジケース

| ケース | 扱い |
|--------|------|
| 検索条件が空 | 検索フォームのみを表示し、結果を組み立てない。 |
| 主要条件が未指定で在庫もすべて表示 | 全件検索とみなし空の一覧を返す。 |
| 抽出件数が0件（支店一覧経路） | 本文を組み立てたうえで応答ステータスを404とし、該当商品が見つからない旨を表示する。 |
| 抽出件数が0件（本店一覧経路） | 該当商品が見つからない旨を表示する。 |
| 抽出件数が上限超過 | 商品内容を取得せず、さらに絞り込みを促すメッセージを表示する。 |
| 不正な並び順値 | 色順として扱う。 |

## データ整合性

| 観点 | 内容 |
|------|------|
| 参照時点 | 商品数・一覧は表示時点のデータベースまたはユニサーチの検索結果である。表示後の在庫・価格・公開状態の変動は一覧へ自動反映しない。 |
| 件数と一覧の一致 | 本店一覧はユニサーチの件数を用い、商品サムネイルは遅延読み込みでデータベースから取得するため、検索エンジンとデータベースの反映タイミング差により件数と表示商品が一致しない場合がある。 |
| 一覧と詳細の一致 | 一覧の価格・在庫は表示時点の値であり、商品詳細（F03-02）の表示値との一致は各表示時点を正とする。 |
