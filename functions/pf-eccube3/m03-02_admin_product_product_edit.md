# 商品管理 — 商品編集機能

## 業務ロジック

### 刷新後は実装しない（廃止）
- Excel基本設計 0204 識別ID:26 により廃止。刷新後は実装しない。

### 商品編集画面を表示する

1. 指定された商品IDに対応する商品付加情報が無い場合は、見つからない（HTTP404）とする。
2. 登録済みの画像・商品カテゴリ・タグ・売上分析タグを、それぞれの欄の初期値として表示する。
3. カード名は、カード名（複数の名前を持つカードは「 / 」で連結）のうしろに、セットコードとプロモーション名をそれぞれ角括弧で括って続けた文字列を表示する。
4. 商品規格が1件も登録されていない商品では、商品公開ステータスの欄を表示しない。規格を登録するまで公開の操作はできない。

### 入力の検証

1. 次の項目は、空・未選択のままでは登録できない。商品名、商品名(英)、商品カテゴリ（1件以上）、購入グループ、サイズ、重量、割引率、販売制限、商品公開ステータス。
2. サイズと重量は9桁を超える値を登録できない。入力欄が受け付ける範囲は0以上999999999以下とする。
3. 割引率と買取減額率は、未選択のとき選択肢に「割引率を選択してください」「買取減額率を選択してください」を表示する。
4. 上に挙げた以外の項目は、空・未選択のままでも登録できる。

### 商品を更新する

1. 入力値の検証に失敗した場合は、同じ編集画面を再表示する（入力値と項目ごとのエラーを保持する）。
2. 検証に合格した場合、カード検索でカードが選択されていれば、そのカードを当該商品のカードとして設定する。選択されていないときは、当該商品のカードを変えない。
3. 商品カテゴリは、既存の登録を一度すべて削除したうえで、選択したカテゴリとその上位カテゴリを重複なく採番して登録し直す。
4. 商品タグは、既存の登録を一度すべて削除したうえで、選択したタグを重複を除いて登録し直す。
5. 売上分析タグは、選択した内容で既存の登録を置き換える。1件も選択しなかったときは、登録済みの売上分析タグをすべて解除する。
6. 追加した画像とカードから引き継いだ画像を当該商品の画像として登録し、画面で指定された並び順を各画像に与える。
7. 更新日を更新時点の日時にする。
8. 更新が完了すると、同じ商品の編集画面へ戻る。
9. 本画面では販売価格・在庫の計算や丸めを行わない。価格・在庫は商品規格（M03-09）で扱う。

### 支店システムへの更新通知

1. 商品の更新が完了すると、当該商品が更新されたことを支店システムへ通知する。
2. 通知に失敗しても商品の更新自体は成功として扱い、画面にエラーは出さない。失敗した商品は再連携の対象として記録し、後から送り直せるようにする。

### 商品画像を追加する（非同期）

1. 非同期でない要求は不正要求（HTTP400）とする。
2. アップロードされたファイルが1件も無い場合は不正要求（HTTP400）とする。
3. 画像以外の種別のファイルが含まれる場合は、対応していないメディア種別（HTTP415）とする。
4. 受け付けた画像は元の拡張子のまま一意な名前で預かり、その名前の一覧を返す。画像が当該商品に登録されるのは、商品を更新したときである。

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 表示・更新とも対象の商品ID。更新はこれに編集画面の入力値と、追加した画像・並び順の指定を伴う。 |
| 成功時出力 | 商品情報・商品付加情報と、商品カテゴリ・タグ・売上分析タグ・画像の更新。成功メッセージを表示し、同じ商品の編集画面へ遷移する。 |
| 失敗時出力 | 検証に失敗したときは同じ編集画面を再表示し、項目ごとのエラーを表示する。対象の商品が無いときは見つからない（HTTP404）。 |
