# 商品管理 — 商品編集機能

## 業務ロジック

### 商品編集画面を表示する

1. 利用者が商品編集画面を開く。
2. 商品IDから商品付加情報を読み込み、見つからなければ見つからない（HTTP404）とする。
3. 商品本体・商品付加情報を編集フォームへ束ね、登録済みの画像ファイル名・カテゴリ・タグ・売上分析タグを各欄の初期値として設定する。
4. 商品に規格があるかを判定し、商品ステータス欄の表示・非表示に用いる。
5. 商品付加情報のカード詳細から日本語のカードラベルを組み立てて表示する。
6. 検索フォーム・カード詳細検索モーダル用フォームを併せて生成し、画面を表示する。

### 商品を更新する

1. 利用者が商品を登録（更新）ボタンを押下する。
2. 編集フォームへ入力値を受け取り、検証する。
3. 検証に失敗した場合は、同じ編集画面を再表示する（入力値とエラーを保持）。
4. 検証に合格した場合、カード詳細IDの指定があれば該当カード詳細を商品付加情報へ設定する。
5. 商品本体と商品付加情報を永続化対象にする。
6. 商品カテゴリを一度全削除してから、選択カテゴリとその上位カテゴリを採番付きで再登録する。
7. 追加画像をS3へアップロードし、カード由来画像をコピーし、画像レコードを登録し、削除対象画像を除去する。
8. 画像の並び順を登録する。
9. 商品タグを一度全削除してから、選択タグを重複排除して再登録する。
10. 売上分析タグを選択内容で置き換える。
11. 商品本体の更新日時を現在時刻にし、永続化を確定する。
12. 支店システムへ当該商品の更新を通知する。
13. 「登録が完了しました。」の成功フラッシュを設定し、同じ商品の編集画面へリダイレクトする。

### 商品画像を追加する（非同期）

1. XHR以外の要求は不正要求（HTTP400）とする。
2. アップロードファイルが配列で存在しない、または0件なら不正要求（HTTP400）とする。
3. 各ファイルのMIMEが画像以外なら対応していないメディア種別（HTTP415）とする。
4. 元拡張子を保ったユニークなファイル名で一時ディレクトリへ移動し、ファイル名一覧をJSONで返す。

### Excel基本設計により廃止された仕様（刷新後は実装不要）

- Excel基本設計 0204 識別ID:26 により廃止。刷新後は実装しない。現行実装のふるまいは本書に残すが、刷新後の実装・テストの対象外とする

| 項目 | 内容 |
|------|------|
| カテゴリ再登録 | 更新のたびに既存の商品カテゴリを全削除し、選択カテゴリと各上位カテゴリを一意化して採番付きで登録し直す。 |
| タグ再登録 | 更新のたびに既存の商品タグを全削除し、選択タグを重複排除して登録し直す。 |
| 売上分析タグ | 選択された売上分析タグの集合で既存内容を置き換える。 |
| 画像並び順 | 送信された並び順情報をもとに各画像レコードの並び順を更新する。 |
| 商品ステータス表示 | 規格が1件以上ある商品のみステータス欄を表示する。規格が無い間は公開操作をさせない。 |
| 金額・在庫計算 | 本画面では販売価格・在庫の計算や丸めを行わない。価格・在庫は商品規格（M03-09）で扱う。 |
| 新規登録 | 編集と同一の更新処理を新規登録ルートが共有するが、運用では新規登録を廃止している。 |

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| 商品が存在しない | 見つからない（HTTP404）。 |
| フォーム検証失敗 | 同じ編集画面を200で再表示し、フィールドエラーを表示する。 |
| 画像追加がXHR以外 | 不正要求（HTTP400）。 |
| 画像追加でファイルなし | 不正要求（HTTP400）。 |
| 画像追加で非画像MIME | 対応していないメディア種別（HTTP415）。 |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | GETは商品ID。POSTはフォーム名`m03-02_admin_product_product_edit`、CSRFトークン、`multipart`の画像関連隠しフィールド。 |
| 成功時出力 | 商品本体・付加情報・関連の更新、成功フラッシュ、同じ編集画面への302リダイレクト。 |
| 失敗時出力 | 検証失敗時は200で同じ編集画面を再描画する。 |

## 表示メッセージ

| メッセージID | 表示位置 | 画面上の文言 | 表示条件 | 後続処理 |
| --- | --- | --- | --- | --- |
| — | 画面上部のフラッシュ領域 | `登録が完了しました。` | 商品更新が成功し、編集画面へリダイレクトしたとき。メッセージキー。 | — |
| M03-02-MSG-004 | 管理画面上部 | 保存に失敗しました | 登録済みでない商品を保存しようとしたとき | 商品新規登録画面に遷移する |
| M03-02-MSG-005 | 管理画面上部 | 保存しました | 商品編集を保存したとき | 戻り先画面に遷移し、戻り先が無効または未指定の場合は商品編集画面に遷移する |
| M03-02-MSG-006 | 管理画面上部 | 商品を複製しました | 商品の複製が完了したとき | 複製した商品の商品編集画面に遷移する |
| M03-02-MSG-007 | 管理画面上部 | 商品の複製に失敗しました | 存在しない商品を複製しようとしたとき | 商品一覧画面に遷移する |
| M03-02-MSG-008 | 管理画面上部 | 商品の複製に失敗しました | 商品を指定せずに複製しようとしたとき | 商品一覧画面に遷移する |
| M03-02-MSG-001 | 画面中央(モーダル) | 削除中... | 商品の完全削除を開始したとき | モーダルは開いたまま |
| M03-02-MSG-002 | 画面中央(モーダル) | 商品の削除処理が完了しました | 商品の完全削除の処理が終わったとき（成功・失敗を問わず） | 成功時のみ、モーダルを閉じる完了操作後に商品一覧画面へ遷移する。失敗時はモーダル内にエラーを表示する |
| M03-02-MSG-003 | 入力項目直下/フォーム上部 | 画像のパスが不正です。 | 商品画像を保存するとき、指定した画像ファイルが見つからないとき | エラーを表示して商品編集画面に留まる |
