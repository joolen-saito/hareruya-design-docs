# 会員管理 — 会員登録仮登録完了メール再送

## 業務ロジック

### フェーズ2対応（フェーズ1では実装しない）
- Excel基本設計 0207「顧客分析タグ登録」はフェーズ2対応。フェーズ1では実装しない。

### 再送の可否

| 事象 | 扱い |
| --- | --- |
| なりすまし対策トークンが一致しないとき | 再送せず、アクセスを拒否する扱い（403）とする |
| 指定した会員が存在しないとき | 再送せず、ページが見つからない扱い（404）とする |
| 指定した会員が退会済みのとき | 退会済みの会員は取得できないため、ページが見つからない扱い（404）とする |
| 指定した会員が仮会員でないとき | 会員の登録状態は判定しないため、そのまま再送する |

本機能は画面上の入力フォームを持たない。入力の検証は、いずれの場合も行わない。

### 再送後の遷移

再送が完了したときは、成功メッセージを表示して会員一覧へ戻る。

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | 会員IDだけを受け取る。 |
| 成功時出力 | 成功メッセージと、会員一覧への遷移。 |
| 失敗時出力 | 会員が存在しない、または退会済みのときはページが見つからない扱い（404）。 |

### 出力: メール

| 項目 | 内容 |
| --- | --- |
| 宛先 | 対象の会員のメールアドレスだけとし、他の会員を宛先から除く |
| 控え（Bcc） | 店舗基本情報の送信元メールアドレス。受信者に見える宛先からは除く |
| 差出人 | 店舗基本情報の返信受付メールアドレス。表示名は店舗基本情報の店名 |
| 返信先・返送先 | 返信先は店舗基本情報の返信受付メールアドレス、返送先は店舗基本情報の送信エラー受付メールアドレス |
| 件名 | メールテンプレート「【販売/日】仮会員登録」に登録されている件名。テンプレートを編集したときは編集後の件名で送る |
| 本文 | 会員の氏名と、当該会員の本登録用URL（アクティベートURL）を含む |
| 言語 | 画面の表示言語が英語のときも、日本語のテンプレートで送る。英語のテンプレートを用いる場合は無い |

### 入出力: 永続化

| 対象 | 内容 |
| --- | --- |
| 会員の送信履歴 | 再送を行ったときに1件追加する。記録するのは、対象会員・用いたテンプレート・送信した件名・本文・送信日時だけとする。操作した管理者は記録しない |

会員データ自体は、いずれの場合も更新しない。

## 表示メッセージ

| メッセージID | 表示位置 | 画面上の文言 | 表示条件 | 後続処理 |
| --- | --- | --- | --- | --- |
| — | 管理画面上部 | 再送完了メッセージ | メール再送が完了したとき | 会員一覧へ戻る |
