# バッチ 会員管理 — 必須項目が空欄の会員発生通知

## 業務ロジック

### 対象の判定

必須項目が空欄である会員の一覧を取り出す。空文字・値なし・未設定のいずれかのときを不備の候補として扱う。項目ごとの許容条件は、会員の必須項目の定義に従う。

空欄の判定は会員のデータの現在値だけを見る。画面の入力補正と既定値の付与は行わない。

コマンド名が未指定のとき、または一致しないときは処理を行わずに終える。

### 通知

該当する会員が 1 件でもあるときは、その一覧で管理者へアラートを通知する。該当が 1 件も無いときは通知せずに終える。

このバッチは検出と通知だけを行い、会員情報を補ったり更新したりしない。

### エラー時の扱い

| エラー内容 | 処理 |
| --- | --- |
| コマンド名が未指定・不一致 | 処理を行わずに終える |
| 該当が 1 件も無い | 何もせずに終える |
| 取得または送信でエラーが起きた | エラーメッセージを出力する |

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | コマンド名 |
| 成功時出力 | 該当する会員があるときの管理者へのアラート通知 |
| 失敗時出力 | エラーメッセージの出力 |

このバッチは外部APIを呼び出さない。

### 入出力: 永続化

このバッチでは会員情報を更新しない。

## 表示メッセージ

このバッチは画面へ文言を表示しない。
