# F01-01（本店トップページ表示）

## 業務ロジック

### 画面構成

共通レイアウト枠の外枠（ヘッダ・本文・フッタ）と、ページ設定で割り当てられたブロックを表示する。本文本体（メイン領域）はTOPテンプレート側では空とし、TOP掲載物はページ設定ブロックで構成する。TOP用に追加のスタイルシートを読み込み、本文クラスをTOP用に設定する。タイトル末尾へ店名を付けない設定とする。TOPではスライダー用スクリプト、画像の遅延読込、商品一覧用スクリプト、商品ブロック用スクリプトを読み込む。ヘッダのカート個数は非同期取得した値で表示する。

### TOPの中身の決まり方

本店TOPの掲載物は、管理画面のページ設定で各領域へ割り当てられたブロックで決まる。共通レイアウト枠が、現在のページに割り当てられたページ設定ブロックを各領域へ差し込む。TOP掲載商品ブロックは、ロケールに応じた対象タグの商品を取得し、短時間キャッシュを併用してから描画する。ブロックごとの抽出条件は商品ブロック機能を正とする。商品ブロックが0件のときは当該ブロックを0件として描画し、TOP全体の表示は継続する。

### 言語別の出し分け

ロケールがjaのときは日本語の掲載物・モーダルを、enのときは英語の掲載物・モーダルを表示する。商品ブロックの対象タグもロケールで切り替える。ログイン用モーダルは未ログイン・ログインを問わずページ内に用意する。

### タグログ送信

画面読込時に検索ワード解析用タグログを送信する。ログイン会員のときはハッシュ化した会員識別子を、画面幅に応じてpc／spの表示種別を併せて送る。

### 本店と支店の境界

本店TOPはサイトルート直下のTOPである。支店ページはサイトルートからの店舗ページとして別に扱う。

本店TOPは入力フォームを持たない。金額計算・税計算・丸めは行わない。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| 描画・データ取得の障害 | 共通例外処理に委ねる。本機能専用の利用者向けメッセージは設けない |
| 商品ブロックが0件 | 当該ブロックを0件として描画し、TOP全体の表示は継続する |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 本店TOPの表示要求（ロケール付き） |
| 成功時出力 | 共通レイアウト枠へブロックを差し込んだ本店TOPの画面、およびログイン用モーダル |
| 失敗時出力 | 描画失敗時は共通例外処理に委ねる。本機能固有のフォールバック文言は持たない |

本機能はデータを更新しない。
