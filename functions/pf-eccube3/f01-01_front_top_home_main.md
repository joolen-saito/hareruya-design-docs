# F01-01（本店トップページ表示）

## 概要

本店トップページ表示は、フロントのサイトルート直下を開いた利用者へ、本店（オンラインショップ本体）のトップページを表示する機能である。ロケール付きパスの直下をTOP画面として描画し、共通レイアウト枠のなかへ管理画面のページ設定で割り当てられたブロック（スライドバナー・新着商品・おすすめ商品・値下げ商品・特集・カテゴリ・お知らせ等）を配置し、未ログイン時のログイン用モーダルを併せて出力する。

本書は実装手順ではなく、誰が・いつ・どの条件で・結果どうなるかを読むためのリバース詳細設計とする。本機能のカスタマイズ区分はカスタマイズである。画面・処理フロー・JS等の挙動はpf-eccube3（EC-CUBE3系）のHareruyaEcプラグインの本店TOP処理、テンプレート（`index_top.twig`・`default_frame.twig`）、TOP用商品ブロック処理、ブロックレイアウトを正とし、DB関連（テーブル名・列名・保存先）はリニューアル先のec-cube-enterpriseを正とする。

対象はブラウザ経由のフロント本店TOPに限定する。

本文ではフレームワークのコントローラ型名やメソッド名を主説明としない。ルートbind名の網羅は主説明とせず、「利用者視点の入口」にHTTPメソッドとサイトルートからのパスパターンを書く。コード探索でbind名が必要なときだけ「調査補助」へ書く。フロントのページであり管理画面プレフィックスは付かない。フロントのルートはロケール接頭辞`/{_locale}`の下に置かれる。

## リニューアル移行時の扱い

本機能のカスタマイズ区分はカスタマイズである。画面・処理フロー・JS等の挙動はpf-eccube3（HareruyaEcプラグイン）の実装を正とし、DB関連（テーブル名・列名・保存先）はリニューアル先のec-cube-enterpriseを正とする。現行と移行先の差は次のとおり。

| 観点 | 現行（pf-eccube3） | 移行先（ec-cube-enterprise） |
|------|--------------------|------------------------------|
| 本店TOPの外枠表示 | HareruyaEcプラグインのTOP処理・テンプレートで描画 | 標準のページ設定ブロック構成で描画。挙動はpf-eccube3を正とする |
| 掲載商品ブロックの抽出元 | 商品・商品規格テーブル | 商品（`dtb_product`）・商品規格（`dtb_product_class`）。抽出条件の詳細は商品ブロック機能を正とする |
| 永続化 | 本店TOPの外枠表示自体はテーブルを更新しない | 同一（参照のみ） |

本店TOPの外枠表示はDB更新を伴わないため、移行に伴うスキーマ差分は商品ブロック側に限られる。確認できない追加仕様はec-cube-enterprise実装で要確認とする。

## 用語

| 用語 | 説明 |
|------|------|
| 本店TOP | サイトルート直下に表示されるオンラインショップ本体のトップページ。 |
| 共通レイアウト枠 | 全フロント画面の外枠を定義するテンプレート。ヘッダ・本文・フッタの各領域へブロックを差し込む。 |
| ページ設定ブロック | 管理画面のページ設定で各領域へ割り当てられる部品。TOP画面の中身はこの割り当てで決まる。 |
| 商品ブロック | 新着・おすすめ・値下げ等のTOP掲載用の商品一覧部品。 |
| ロケール | 表示言語区分。日本語はja、英語はen。フロントのパスはこの区分を接頭辞に持つ。 |

## 利用者視点の入口

| 入口 | URLエンドポイント | 期待されるふるまい |
|------|--------------------|--------------------|
| サイトルート直下を開く | `GET /{_locale}/` | 本店TOP画面を描画する。共通レイアウト枠へページ設定ブロックを差し込み、未ログイン時はログイン用モーダルを併せて出力する。 |
| ロゴ・ショップ導線からの遷移 | `GET /{_locale}/` | 同上。 |

ロケール接頭辞はjaまたはenをとる。ホスト名・クエリ・資格情報を含む具体URLは扱わない。

## フロント挙動

| 観点 | 内容 |
|------|------|
| 表示要素 | 共通レイアウト枠の外枠（ヘッダ・本文・フッタ）と、ページ設定で割り当てられたブロックを表示する。本文本体（メイン領域）はTOPテンプレート側では空とし、TOP掲載物はページ設定ブロックで構成する。 |
| JS挙動 | TOPでスライダー用スクリプト、画像の遅延読込、商品一覧用スクリプト、商品ブロック用スクリプトを読み込む。検索ワード解析用のタグログを画面読込時に送信し、ログイン会員のときはハッシュ化した会員識別子を、画面幅に応じてpc／spの表示種別を送信する。ヘッダのカート個数は非同期取得した値で表示する。 |
| CSS・レイアウト | TOP用に追加のスタイルシートを読み込む。本文クラスをTOP用に設定する。 |
| モーダル・ポップアップ | 未ログイン・ログインを問わずログイン用モーダルをページ内に用意する。ロケールがjaのときは日本語版、それ以外は英語版のモーダルを出力する。 |
| 入力項目 | 本店TOP自体は入力フォームを持たない。ログイン用モーダル・ヘッダ検索欄はそれぞれの機能の範囲とする。 |

TOPテンプレートはタイトル末尾へ店名を付けない設定とする。

---

## 処理フロー

### 本店TOPを表示する（GET `/{_locale}/`）

1. 利用者がサイトルート直下を開く。
2. ログイン用フォームの表示用データを組み立て、TOPテンプレートへ渡す。
3. 共通レイアウト枠が、現在のページに割り当てられたページ設定ブロックを各領域へ差し込む。
4. ロケールに応じてログイン用モーダル（ja版またはen版）を出力する。
5. 画面読込時に検索ワード解析用タグログを送信し、ヘッダのカート個数を非同期取得して表示する。

### TOP掲載商品ブロックの取得（ページ設定ブロック経由）

1. ページ設定で割り当てられた商品ブロックが、ロケールに応じた対象タグの商品を取得する。
2. 取得結果は短時間キャッシュを併用してから描画する。
3. ブロックごとの抽出条件は商品ブロック機能を正とする。

## 業務ルール・計算

| 項目 | 内容 |
|------|------|
| TOPの中身の決まり方 | 本店TOPの掲載物は、管理画面のページ設定で各領域へ割り当てられたブロックで決まる。TOPテンプレートのメイン本体は空とし、ブロック割り当てを正とする。 |
| 本店と支店の境界 | 本店TOPはサイトルート直下のTOPであり、支店ページはサイトルートからの店舗ページ（`/{_locale}/shoppage/{name}`）として別に扱う。 |
| 言語別の出し分け | ロケールがjaのときは日本語の掲載物・モーダルを、enのときは英語の掲載物・モーダルを表示する。商品ブロックの対象タグもロケールで切り替える。 |
| タグログ送信 | 画面読込時に検索ワード解析用タグログを送信する。会員のときはハッシュ化した会員識別子を、画面幅に応じてpc／spの表示種別を併せて送る。 |

本店TOPは入力フォームを持たないため、入力項目に紐づく表を持たない。本機能では金額計算・税計算・丸めを行わない。

### エッジケース

| ケース | 扱い |
|--------|------|
| 未ログインで開く | TOPを表示し、ログイン用モーダルを用意する。ヘッダのマイページ部にはログイン／会員登録への導線を出す。 |
| ログイン済みで開く | TOPを表示し、ヘッダに保有ポイント表示を出す（F02-05を正とする）。 |
| 商品ブロックの対象商品が0件 | 当該ブロックは0件として描画する。TOP全体の表示は成立する。 |
| ロケールがja以外 | 英語の掲載物・モーダルを表示する。商品ブロックの対象タグを英語向けへ切り替える。 |

## データ整合性

| 観点 | 内容 |
|------|------|
| 参照時点 | TOPの掲載物は画面表示時点で取得・描画する。商品ブロックは短時間キャッシュを併用するため、キャッシュ有効中は直近の取得結果を表示する。 |
| カート個数 | ヘッダのカート個数は非同期取得した時点の値であり、TOP本文の描画時点とは別時点となり得る。 |
| ブロック割り当てとの整合 | TOPの掲載物は管理画面のページ設定の割り当てに従う。割り当ての変更反映タイミングはページ設定機能を正とする。 |

## API/バッチ結果

| 種類 | 内容 |
|------|------|
| API | TOPの商品ブロックは内部の商品取得処理を呼び、短時間キャッシュを併用して描画する。ヘッダのカート個数取得は非同期リクエストで行う。検索ワード解析用タグログは外部へ送信する。 |

タグログ送信・カート個数取得の個別失敗時の扱いは本書では仕様確定せず実装を確認値とする。
