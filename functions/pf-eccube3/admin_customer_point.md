# 会員管理 — ポイント付与・ポイント履歴

## 業務ロジック

### ポイント履歴の表示

パスの会員IDで会員を取得する。会員が存在しないときはページが見つからない扱い（404）とする。

| 項目 | 内容 |
|------|------|
| 種別ごとの履歴 | ポイント種別ごとにポイント履歴を表示する |
| 並び順 | 新しい履歴を先頭にする |
| 注文番号 | 各履歴に関連する注文番号を取得して表示する |
| 付与フォーム | 履歴一覧とあわせてポイント付与フォームを表示する |

### ポイントの付与

| 順序 | 判定 | 結果 |
|------|------|------|
| 1 | なりすまし対策トークンが有効か | 無効なときは付与を行わない |
| 2 | 会員と選手情報を取得できるか | いずれも無いときはページが見つからない扱い（404）とする |
| 3 | ポイント付与フォームの検証に通るか | 失敗したときはポイント履歴画面を再表示する |
| 4 | 上記を通過したとき | 入力したポイント変動と備考でポイント履歴を追加し、ポイント履歴画面へ戻る |

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| 会員・選手情報が存在しないとき | ページが見つからない扱い（404）とする |
| 付与フォームの検証に失敗したとき | ポイント履歴画面を再表示する |
| なりすまし対策トークンが不正なとき | 付与を行わない |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 会員ID、ポイント種別、ポイント変動・備考、なりすまし対策トークン |
| 成功時出力 | ポイント履歴の追加と、履歴画面への遷移 |
| 失敗時出力 | 会員・選手情報が無いときは404、検証に失敗したときは履歴画面の再表示 |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 追加 | ポイント付与（ポイント変動と備考の履歴） |

## 表示メッセージ

本機能はポイント付与フォームの検証エラー以外に、利用者向けの通知メッセージを表示しない。
