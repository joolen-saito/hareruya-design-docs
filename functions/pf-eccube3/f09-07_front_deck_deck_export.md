# フロント デッキ検索 — デッキリスト書き出し

## 業務ロジック

### 書き出しの2経路

デッキリストの書き出しには、ファイルとして受け取る経路と、画面が写し取るためのテキストを受け取る経路がある。

| 経路 | 受け取り方 | 応答の形式 |
| --- | --- | --- |
| Magic Online用テキスト | ファイルとして受け取る | 添付ファイルの`text/plain` |
| アリーナ形式のテキスト | 画面が受け取り、クリップボードへ写す | JSON |
| 公開状態の判定 | ファイル経路だけが表示区分とデッキリストの公開状態を見る | — |
| デッキ種別の判定 | どちらの経路も、ユーザーデッキのときは応じない | — |

### ファイルとして受け取る経路の条件

| 順序 | 判定 | 結果 |
| --- | --- | --- |
| 1 | デッキの識別子が空のとき | HTTP 404 |
| 2 | 識別子に一致するデッキが無いとき | HTTP 404 |
| 3 | 表示区分が非公開のとき | HTTP 404 |
| 4 | デッキリストが非公開のとき | HTTP 404 |
| 5 | デッキ種別がユーザーデッキのとき | HTTP 404 |
| 6 | 上のいずれにも当たらないとき | デッキリストのファイルを返す |

限定公開のデッキは、限定公開用の値の一致を求めずに書き出せる。

### ファイルの名称と内容

ファイル名はアーキタイプの英語名の空白文字を`_`へ置き換え、`.txt`を付けた文字列とする。内容は英語カード名の`枚数 カード名`を1行ずつ並べたもので、サイドボードの前に`Sideboard`の行を挟む。統率者とメインボードの見出し行は入れない。カード名はアリーナで通る名称への対応表で置き換え、対応表に無い名称はそのまま残す。

### テキストとして受け取る経路の条件

| 順序 | 判定 | 結果 |
| --- | --- | --- |
| 1 | デッキの識別子が空のとき | HTTP 404。本文はJSONで、処理結果は失敗、内容は`Not Found` |
| 2 | 識別子に一致するデッキが無いとき | HTTP 404。本文は同上 |
| 3 | デッキ種別がユーザーデッキのとき | HTTP 404。本文は同上 |
| 4 | 上のいずれにも当たらないとき | HTTP 200。処理結果は成功、デッキリストのテキストを返す |

この経路は表示区分とデッキリストの公開状態を判定しないため、非公開のデッキでも識別子を指定すればテキストを受け取れる。

### 言語の指定による内容の違い

| 言語の指定 | カード名 | 見出し行 |
| --- | --- | --- |
| `en` | 英語名をアリーナで通る名称へ置き換えた値 | 統率者があるときは`Commander`、続けて`Deck`、サイドボードの前に`Sideboard` |
| `en`以外 | 日本語名 | 統率者があるときは`統率者`、続けて`デッキ`、サイドボードの前に`サイドボード` |

どちらの言語でも、カード名に含まれる`/`は` // `へ置き換える。デッキリスト詳細からの入口は、アリーナ用インポートテキストが`en`、日本語テキストが`jp`を言語として渡す。言語の指定が無いときのふるまいは正本コードからは確認できない。

### デッキリストの組み立て

| 観点 | 扱い |
| --- | --- |
| 行の形 | `枚数 カード名`を1行とする |
| 区画の順序 | 統率者、メインボード、サイドボードの順に並べる。この3つ以外の配置は書き出さない |
| 区画の区切り | サイドボードがあるときだけ、その前に空行と見出し行を挟む |
| 改行 | 復帰と改行の2文字を用いる |
| 末尾 | 末尾の空白と改行を落とす |
| デッキリストがキャッシュにあるとき | キャッシュの内容から指定の言語で組み立てる |
| デッキリストがキャッシュに無いとき | 採用カードから組み立てる |

### 応答の形式

| 観点 | ファイルとして受け取る経路 | テキストとして受け取る経路 |
| --- | --- | --- |
| 内容の種別 | `text/plain` | `application/json` |
| 添付の指定 | ファイル名を指定した添付として返す | 添付にしない |
| 本文の作り | デッキリストのテキストだけを流し込む | 処理結果とデッキリストのテキストを組にする |
| 会員の状態 | ログインの有無を問わない | ログインの有無を問わない |
| 失敗したとき | HTTP 404。共通のエラー画面を返す | 処理結果が失敗であることを示すJSONとHTTP 404 |

### エッジケース

| ケース | 扱い |
| --- | --- |
| アーキタイプの英語名に空白を含むとき | 空白を`_`へ置き換えたファイル名にする |
| 対応表に無いカード名のとき | 置き換えずに元の名称のまま書き出す |
| サイドボードが0枚のとき | サイドボードの見出し行を入れない |
| 統率者が0枚のとき | 統率者の見出し行を入れない |
| 分割カードのとき | 名称の`/`を` // `へ置き換える |
| デッキリストが非公開のとき | ファイル経路はHTTP 404、テキスト経路は書き出しに応じる |
| 表示区分が限定公開のとき | 限定公開用の値の一致を求めずに書き出す |
| 採用カードが0件のとき | 中身のないテキストを返す |
| メインボード・サイドボード・統率者以外の配置にカードがあるとき | 書き出しに含めない |
| アーキタイプが未設定のとき | ファイル名の組み立てに使う値が無く、ふるまいは正本コードからは確認できない |
| 言語の指定が`en`以外のとき | 対応表による置き換えを行わない |
| 会員でないとき | どちらの経路も同じ結果を返す |

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | デッキの識別子。テキストとして受け取る経路では言語の指定も伴う |
| 成功時出力 | ファイル経路は添付ファイルとしてのデッキリスト。テキスト経路はJSONで、処理結果が成功であることとデッキリストのテキスト |
| 失敗時出力 | ファイル経路はHTTP 404の共通のエラー画面。テキスト経路はHTTP 404で、処理結果が失敗であることと`Not Found` |

### 入出力: 永続化

デッキ情報を登録・更新・削除しない。

| 操作 | 契機 |
| --- | --- |
| キャッシュへの保存 | 行わない。デッキリストのテキストは、デッキIDを鍵にしたキャッシュに保存済みのときだけそこから組み立てる |

## 表示メッセージ

本機能は画面へ文言を表示しない。書き出しの入口と完了の通知はデッキリスト詳細（F09-06）を正とする。
