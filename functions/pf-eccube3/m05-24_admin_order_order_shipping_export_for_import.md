# 受注管理 — 出荷実績入力用CSV出力

## 業務ロジック

### 出力対象

一覧で選択した受注だけを対象とする。検索条件は使わず、選択していない受注は条件に一致していても出力しない。

受注を 1 件も選択していないときは出力せず、操作の起点になった画面へ戻る。起点が分からないときは受注一覧へ戻る。

選択した受注から出力行を 1 行も作れなかったときも出力せず、操作の起点になった画面へ戻る。

選択した受注のうち、受注サブ情報・都道府県・会員・会員の都道府県・会員の国・支払方法・対応状況・配送先の都道府県・配送方法・配送方法サブ情報のいずれかを持たない受注は出力しない。性別・職業・お届け時間・国は持たない受注も出力する。

受注 1 件につき 1 行を出力する。配送先を複数持つ受注でも 1 行にまとめるため、2 件目以降の配送先は出力されない。

### 出力する値

注文者の氏名・住所・連絡先は、受注に記録した値ではなく会員の現在の値を出力する。受注のあとに会員情報を変えたときは、変えた後の値が出る。日時は `Y/m/d H:i:s` の形式で出力し、未設定のときは空欄とする。

性別(ID)・性別(名称)と職業(ID)・職業(名称)は、会員に登録された性別・職業から出力する。会員に性別・職業が未設定のときは空欄とする。

小計・値引き・送料合計・税金・合計・支払合計は、受注の値をそのまま出力する。通貨記号と桁区切りは付けない。

### 出力する列

出力する列は固定で、出力項目を選ぶことはできない。列の構成は基本設計の出荷実績登録CSVによる。出力したファイルに出荷日と送り状No.を書き込むと、そのまま出荷実績インポート登録に取り込める。

## 入出力

### 出力: CSVファイル

| 項目 | 内容 |
| --- | --- |
| 文字コード | CSV出力の設定に従う。応答に載せる文字コード名は、設定が `SJIS-win` のときだけ `windows-31j` へ読み替える |
| 区切り文字 | `,` |
| 引用符 | 値が `,`・`"`・改行のいずれかを含むときだけ、値全体を `"` で囲む。値の中の `"` は 2 個続けて出力する |
| ファイル名 | `order_` に出力日時を `YmdHis` の形式でつなぎ、`.csv` を付けた名前 |
| 応答 | ダウンロードとして返す |

ファイルの先頭にバイトオーダーマークを 1 個出力する。バイトオーダーマークは文字コードの設定に関わらず `0xEF 0xBB 0xBF` の 3 バイトで、設定が `SJIS-win` のときも変わらない。見出し行の次の行からデータ行を出力する。
