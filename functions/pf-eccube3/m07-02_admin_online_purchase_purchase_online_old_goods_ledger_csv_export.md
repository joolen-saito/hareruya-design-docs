# ネット買取管理 — 古物台帳入力用CSV出力

## 業務ロジック

### 出力対象の決め方

| 順序 | 判定 | 結果 |
|------|------|------|
| 1 | 選択された買取注文IDを整数として読み、0を除いたときに1件も残らないとき | エラーを表示し、保持している検索ページの買取一覧へ戻す |
| 2 | 残ったIDに該当する買取注文が1件も無いとき | エラーを表示し、買取一覧へ戻す |
| 3 | 1件以上該当するとき | 該当した買取注文だけを識別子の昇順で出力する |

選択したIDのうち存在しないものは、エラーとせずに出力対象から除く。1件でも存在するときはエラーにならないため、選択したID本数と出力行数が一致しないことがある。

### 出力する列

| CSV列名 | 値の取り方 |
|---------|------------|
| 日付 | 買取注文の注文日を`Y/m/d`とする。無いときは空 |
| 受注番号 | 買取注文の識別子 |
| 氏名 | 姓と名を連結する。あいだにスペースを入れない |
| 住所 | 都道府県名・住所1・住所2をそれぞれ半角スペース1つで区切って連結し、住所3があるときは末尾にそのまま連結する。住所2と住所3のあいだにスペースを入れない |
| 年齢 | 生年月日があるときは、サーバの現在の年と生年の差の整数とする。無いときは空 |
| 職業 | 職業マスタの名称。無いときは空 |
| 電話番号 | 買取注文の電話番号。無いときは空 |
| 身分証 | 身分証種別マスタの名称。無いときは空 |
| 点数 | 買取注文ごとに集計した点数 |
| 金額 | 査定合計を文字列にする。値が無いときは空 |
| 区別 | 固定文字列「買受」 |
| 品目 | 固定文字列「トレーディングカード」 |
| 特徴 | 固定文字列「マジック・ザ・ギャザリング」 |
| 利用回数 | 出力対象の買取注文に含まれる会員の利用回数 |
| 前回利用日 | 買取注文ごとに集計した前回利用日を`Y/m/d`とする。無いときは空 |

年齢はサーバの現在日付を基準とするため、申込日時点の年齢とは限らない。利用回数は、会員をプレイヤー経由で本人確認の情報と結合して取得する。

### 出力の形式

ヘッダ行は日本語ラベルを定義順に出力し、データ行も同じ順に並べる。文字コードは設定値へ変換し、UTF-8のときは判別用のBOMを先頭に付ける。区切り文字と囲み文字は設定値に従う。

ファイル名は、`purchase_` に、選択した買取注文IDの最小値を7桁ゼロ埋めした番号、アンダースコア、出力日時（`YmdHis`）、拡張子 `.csv` を連結したものとする。

### 値の取り方

金額・数量・日時・ステータスは、参照した時点の保存済みの値をそのまま出力し、出力時に再計算・補正しない。該当する値が無い項目は空欄とする。出力の途中で対象データが更新されても、読み直しによる整合の補正は行わない。

対象データは出力の要求を受けた時点で1回だけ読み、全行をその時点の値で書き出す。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| 買取注文を1件も選択していないとき | エラーを表示し、買取一覧へ戻す。CSVを出力しない |
| 選択したIDに該当する買取注文が1件も無いとき | エラーを表示し、買取一覧へ戻す。CSVを出力しない |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 買取一覧で選択した買取注文IDの集合 |
| 成功時出力 | 古物台帳入力用のCSVファイル |
| 失敗時出力 | エラーを表示し、買取一覧へ戻す |

本機能は参照だけを行い、データを更新しない。
