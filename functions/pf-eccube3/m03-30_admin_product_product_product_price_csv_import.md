# 商品管理 — セール用価格変更CSV登録

## 業務ロジック

### アップロード画面

商品価格取込の履歴を日付降順で一覧表示する。ページ件数の許容値は `10, 50, 100, 300, 500, 1000, 2000, 10000, 12000` のいずれかで、許容値以外のときは既定の50件とする。画面には雛形と同じ列見出しと必須列の一覧を表示する。

### 雛形CSV

1行目に列見出しだけを出力し、データ行を持たない。ファイル名は`product_price_template.csv`とする。見出しの順序は「商品ID」「言語(ID)」「販売価格」「買取価格」「セールフラグ」「帯URL」「タグ(ID)」である。

### CSVデータ列

ヘッダ行は雛形と同じ日本語ラベルである必要がある。データ列は7列ちょうどで、余分な列があるときは列数エラーとする。

| 列見出し（画面表記） | 必須／任意 | 最大長・形式 | 空欄時 | 扱い |
|----------------------|------------|--------------|--------|----------------|
| 商品ID | 必須 | 0以上の数値 | 不可 | 商品の存在を検証する。存在しないときは全行を打ち切る |
| 言語(ID) | 必須 | 言語マスタに存在するID | 不可 | 更新対象の規格を絞る条件に使う |
| 販売価格 | 必須 | 9桁までの非負整数 | 不可 | セール区分の組み合わせにより実際に反映されないことがある |
| 買取価格 | 必須 | 9桁までの非負整数 | 不可 | 規格ごとに換算して規格の買取価格に反映する。同じ行の販売価格を超えてはならない |
| セールフラグ | 任意 | 0または1 | 空は「無効」と同義として読み取る | 規格のセール区分の更新に使う |
| 帯URL | 任意 | 文字列列の一般ルール（長さ上限の設定は無いことを確認値とする） | 空は未設定 | 規格の帯URLに反映する |
| タグ(ID) | 任意 | カンマ区切りの非負整数。各IDはタグマスタに存在する必要がある | 空は無タグ相当 | 商品ID単位でタグ付けを全置換する |

### 取込前の検証

| 検証 | 内容 |
|------|------|
| ファイルの有無 | アップロードファイルが無いときはフォーマット不一致のエラーとし、アップロード画面へ戻る |
| 行数上限 | ファイルの改行の個数（引用符内の改行は除く）が5010以上のときは上限超過のエラーとし、アップロード画面へ戻る |
| ヘッダ・データ行 | 1行目をヘッダとして解釈できるか、2行目以降にデータがあるかを取込開始前に検証する。失敗したときはエラーを返す |

### 行ごとの検証

列数がヘッダの列数と一致しない行があるときはフォーマットエラーとし、処理を打ち切る。各行では、必須列の入力、言語IDのマスタ存在、数値と桁数、セールフラグが0または1であること、タグIDの存在を順に検証する。同じ行の買取価格が販売価格を超えるときはエラーとする。商品IDが商品に存在しないときはエラーとし、全件を打ち切る。

### 更新する内容

検証を通過した行では、商品タグを指定されたID一覧で全置換する。続いて、該当商品かつ該当言語かつ高額商品コードが未設定の規格をすべて対象に更新する。

| 更新項目 | 決め方 |
|------|------|
| 販売価格 | CSVのセールフラグと現在のセール状態の組み合わせに応じて決める |
| 買取価格 | CSVの買取価格を小数切り捨てで整数化した値を基に、規格のカード状態・特価区分・買取割引から規格単位に換算する。換算できないときは基の値をそのまま使う |
| 帯URL | CSVが空のときは未設定、空でないときはその文字列とする |
| セール区分 | CSVのセールフラグの値をそのまま反映する |
| 価格履歴 | 販売価格・買取価格・基準価格のいずれかが変わったときに履歴を1件追加する。本取込は基準価格を変えないため、基準価格の新旧は同一値になる |

対象となる規格が0件でも、そのデータ行は成功として数え、商品タグの置換だけが行われることがある。

条件を満たす規格は、スマレジ連携の送信対象として後送りの一覧に載せる。

セールフラグを無効にしたため販売価格が反映されない行と、通常商品のため販売価格が変更されない行では、注意喚起のメッセージがエラーと同じ経路で表示される。

### 取込の確定

全行の処理後、エラーが無く打ち切りも無いときに確定する。それ以外は取込内容を取り消す。取込を確定したときは、成功メッセージを表示し、取込履歴へファイル名と操作者を1件追加する。エラーがあるときは各メッセージをエラーとして表示する。いずれの場合もアップロード画面へ戻る。

取込中は行ロック待ちのタイムアウトを規定の秒数（確認値は5秒前後）に設定し、処理後に元へ戻す。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| フォーム不正 | エラーを表示し、アップロード画面へ戻る |
| ファイル未選択扱い | CSVのフォーマット不一致として表示し、アップロード画面へ戻る |
| 行数上限超過 | 上限行数超過として表示し、アップロード画面へ戻る |
| CSV形式・列・値・商品不存在 | 取込結果のメッセージをエラーとして表示する。取込内容は取り消されうる |
| 予期せぬ例外 | 取込内容の取り消しを試みたうえで例外を送出する（呼び出し側の扱いは共通制御に従う） |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | CSVファイル（拡張子に応じてタブ区切りとしても解釈する）。区切り文字と囲み文字は取込用の設定値による |
| 成功時出力 | アップロード画面への遷移と成功メッセージ。条件を満たすとき取込履歴を1件追加 |
| 失敗時出力 | アップロード画面への遷移とエラーメッセージ。内容はフォームエラー・取込前検証エラー・取込結果のメッセージ |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 更新 | 検証を通過した行の規格（販売価格・買取価格・帯URL・セール区分） |
| 追加・削除 | 商品タグの全置換 |
| 追加 | 価格が変わった規格の価格履歴 |
| 追加 | 取込確定時の取込履歴 |
