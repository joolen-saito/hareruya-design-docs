# イベント管理 — イベント申込一括CSV登録

## 業務ロジック

### 取込の判定順序

| 順序 | 判定 | 結果 |
| --- | --- | --- |
| 1 | 入力の検証に失敗したとき（ファイル未選択、サイズ上限超過） | 各エラーを表示し、同じ画面を再表示する |
| 2 | 行数が上限（確認値5000行）以上のとき | 上限超過のエラーを表示し、同じ画面を再表示する |
| 3 | 1行目にヘッダが無いとき | ヘッダ形式のエラーを返し、取込を行わない |
| 4 | 2行目にデータが無いとき | データ無しのエラーを返し、取込を行わない |
| 5 | 行の検証で全体中断の指示が出たとき | その時点で打ち切る |
| 6 | 行の検証でスキップの指示が出たとき | その行を飛ばす |
| 7 | 上記以外のとき | 1行をイベントとして登録する |

### 取込ファイルの読み方

アップロードされたファイルを一時領域へ退避し、文字コードをUTF-8へそろえ、改行とゼロ幅スペースを正規化する。拡張子が tsv のときは区切り文字をタブとし、それ以外のときは設定の区切り文字で読む。取込の終了後に一時ファイルを削除する。

取込処理には処理時間の上限を設けない。

### 行ごとの登録

行の検証では、受付ありのときに受付時間を必須とするなどの条件を確認する。検証を通った行を1件のイベントとして登録し、開始時間があるときはイベント日程も作る。一定件数ごとに登録内容を反映する。

店舗・会場・ルール適用度・公開状態・フォーマットは、名称で対応するマスタを引いて設定する。支払方法の列が「あり」のときだけクレジット支払を有効にする。開始時間がある行だけイベント日程を作り、受付・デッキ登録・オンライン受付の各時刻を設定する。

取込件数は登録に成功した行数とする。本機能では金額の丸めと合計の計算を行わない。

### エラー時の扱い

| 事象 | 扱い |
| --- | --- |
| ファイル未選択、またはサイズ上限を超過したとき | エラーを表示し、同じ画面を再表示する |
| 行数が上限以上のとき | 上限超過のエラーを表示し、同じ画面を再表示する |
| ヘッダが一致しないとき、またはデータ行が無いとき | 前提の検証エラーを表示し、取込を行わない |
| 行ごとの取込でエラーが出たとき | エラーの一覧を表示し、登録内容を全件取り消す |
| 取込中に例外が発生したとき | 登録内容を取り消し、例外を呼び出し元へ伝える |

エラーが1件も無く中断もないときだけ登録を確定する。

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | アップロードファイル、なりすまし対策トークン |
| 成功時出力 | イベントとイベント日程の一括登録、完了の表示、取込画面への遷移 |
| 失敗時出力 | エラー一覧の表示、登録内容の取り消し |

取込画面には、取込フォーマットのヘッダ定義を渡して表示する。

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 追加 | 取込ファイルの検証を通った1行ごとの登録 |
| 追加 | 開始時間がある行の、日程の登録 |

エラーがあるとき、または中断したときは、登録内容をすべて取り消す。

| — | アップロード欄付近 | CSVデータが存在しません。 | データ行が無いとき | 取込を行わない |
| — | アップロード欄付近 | （行・列に応じた取込エラー） | 必須の未入力、マスタに存在しない値、形式の不正などがあるとき | 行番号と列名を含むメッセージを行ごとに列挙し、登録内容を全件取り消す |
