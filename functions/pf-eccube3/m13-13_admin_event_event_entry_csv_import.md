# M13-13（イベント申込一括CSV登録）

## 概要

イベント管理において、所定フォーマットのCSVファイルをアップロードし、イベント情報（およびイベント日程）を一括登録する機能である。アップロード画面でファイルを選び、雛形フォーマットに沿って行ごとに取り込み、エラーがあれば画面に一覧表示する。

本書は実装手順ではなく、誰が・いつ・どの条件で・結果どうなるかを読むためのリバース詳細設計とする。確認値はpf-eccube3（EC-CUBE3系）のHareruyaEcプラグインの一括登録CSVアップロード処理、CSV取込サービス、一括登録の取込ハンドラ、列定義・行検証を正とする。本機能のカスタマイズ区分はカスタマイズであり、挙動の確認はpf-eccube3を参照し、永続化先のテーブル・列名などDB関連の記述はec-cube-enterpriseを正とする。

対象はブラウザ経由の管理画面に限定する。

本文ではフレームワークのコントローラ型名やメソッド名を主説明としない。管理画面プレフィックスは環境により変わり、プラグイン設定の`admin_route`で決まる。「利用者視点の入口」にHTTPメソッドとサイトルートからのパスパターンを書く。

## 処理フロー

### アップロード画面を表示する（`GET …/entry/bulkentry`）

1. CSV取込フォームと取込フォーマットのヘッダ定義をテンプレートに渡して表示する。

### CSVを取り込む（`POST …/entry/bulkentry/upload`）

1. 実行時間制限を無効化する。
2. CSV取込フォームを送信として処理する。フォーム検証NGのとき、各エラーを表示し同画面を再描画する。
3. アップロードファイルの行数が上限（確認値5000行）以上のとき、上限超過エラーを表示し同画面を再描画する。
4. 取込開始を情報ログに記録する。
5. 取込サービスに一括登録の取込ハンドラを渡してファイルを取り込む。
6. 取込結果にエラーがあれば、異常終了を情報ログに記録し、同画面にエラー一覧を表示する（DBはロールバックする）。
7. エラーがなければ完了を表示し、取込件数を情報ログに記録し、アップロード画面へリダイレクトする。

### 取込サービス内の処理

1. アップロードファイルを一時ディレクトリへ退避し、文字コードをUTF-8へ寄せ、改行・ゼロ幅スペースを正規化する。拡張子がtsvならタブ、それ以外は設定の区切り文字で読む。
2. 前提検証として、1行目にヘッダが無ければヘッダ形式エラー、2行目にデータが無ければデータ無しエラーを返し、取込を行わない。
3. トランザクションを開始し、行ロックタイムアウトを設定する。
4. 行ごとに、行検証（受付ありなら受付時間必須など）を行い、検証で全体中断指示があれば打ち切り、スキップ指示があればその行を飛ばす。
5. 取込ハンドラで1行をイベント（開始時間があればイベント日程も）として登録する。一定件数ごとにDBへ反映する。
6. エラーが無く中断もなければコミットし、そうでなければロールバックする。
7. 取込件数とエラーメッセージを取込結果として返す。一時ファイルは削除する。

## 取込フォーマット

| 観点 | 内容 |
|------|------|
| ヘッダ行 | 1行目に列見出しを持つ。雛形の見出し名と一致する必要がある。不一致はフォーマットエラー。 |
| 区切り・囲み | 拡張子tsvはタブ区切り、それ以外は設定の区切り文字（確認値カンマ）。囲み文字は設定値（確認値ダブルクォート）。 |
| 文字コード | アップロード後にUTF-8へ変換して取り込む（Windows環境はSJIS-win考慮）。BOM・ゼロ幅スペースは除去する。 |
| 行数上限 | 5000行以上は登録不可（上限超過エラー）。 |
| 登録単位 | 1行＝イベント1件。開始時間が入っている行はイベント日程も同時に登録する。 |

### 列（論理名と必須・選択肢の要点）

| 列（論理名） | 必須／任意 | 値の要点 |
|--------------|------------|----------|
| イベント名（日）・イベント名（英） | 必須 | 文字列。 |
| 店舗・会場 | 必須 | 日本語名でマスタを引く。 |
| フォーマット | 必須 | 日本語名でマスタを引く。複数指定はカンマ区切り。 |
| ルール適用度・公開状態 | 必須 | 名称でマスタを引く。 |
| バナーURL（日）・バナーURL（英） | 任意 | URL文字列。 |
| 定員・チーム人数 | 必須 | 数値。 |
| 支払方法（クレジットカード支払い） | 任意 | 「あり」でクレジット支払を有効化、空・なしは無効。 |
| 参加費 | 必須 | 半角数値。 |
| 賞品（日）・賞品（英）・備考（日）・備考（英） | 任意 | 文字列。 |
| 開始時間 | 任意（日程登録の起点） | `YYYY-MM-DD HH:MM`。値があるとイベント日程を登録する。 |
| 受付・受付時間From・受付時間To | 受付ありの場合From・Toが必須 | 受付は「あり」で有効。時刻は`HH:MM`。 |
| デッキ登録・デッキ登録締切 | 任意 | デッキ登録は「あり」で有効。締切は`YYYY-MM-DD HH:MM`。 |

| 定員_日程・参加費_日程 | 任意 | 半角数値。 |
| 公開状態_日程 | 任意 | 名称でマスタを引く。 |
| 賞品_日程（日）・賞品_日程（英） | 任意 | 文字列。 |

行検証として、受付ありなら受付時間From・To、オンライン受付ありならオンライン受付時間From・Toを必須とする。

| 操作種別 | 対象テーブル | 契機・条件 |
|---------|--------------|------------|
| 登録/更新 | dtb_event / dtb_event_detail / dtb_event_entry | 当機能が行う登録・更新で対象テーブルを直接保存する（不要な削除は含まない）。確定は persist/flush による即時反映。DB=ec-cube-enterprise を正典とする。 |

## 排他制御・トランザクション

取込は単一トランザクションで行い、行ロックタイムアウトを設定する。エラーまたは中断があれば全件ロールバックする。取込中はDBへ一定件数ごとに反映しつつ、最終的な確定はコミットで行う。
