# 会員 — 会員情報変更

## 業務ロジック

### 画面に入れる条件

自動ログイン（次回から自動でログインする指定）で復帰しただけの状態では会員情報変更画面を開けない。会員ログインで改めて認証したときだけ開ける。未ログインでのアクセスも会員ログインへ誘導する。

### 初期表示

ログイン会員の現在の登録内容を初期表示する。パスワード欄にはマスク用の既定値を載せる。MTG Campaign 登録名（姓・名）には、選手情報として保持している英字姓・名を初期表示する。クエリで支店の指定があるときは、支店指定を保持する。

検証エラーや国の切り替えで編集フォームを再表示するときは、入力済みの英字姓・名を保持する。

### 更新の条件

会員IDとパスワードが同一のときは、入力の検証に通っていても更新せず、編集フォームを再表示する。

国が日本で都道府県が海外のとき、国が海外で都道府県が国内のときは、送信後の検証で拒否し、国の項目にエラーを付して再表示する。

### 更新内容

パスワード欄がマスク用の既定値のままのときは、従前のパスワードを維持する。変更されているときは暗号化して再設定する。

選手情報のメールアドレス・英字氏名・和文氏名・更新日時を更新する。既定とする配送先へ、会員の氏名・カナ・郵便番号・住所・国・都道府県・会社名・電話番号を反映する。

### 本人確認ステータスの扱い

| 変更した項目 | 変更前のステータス | 結果 |
|--------------|--------------------|------|
| 国・郵便番号・都道府県・住所 | 確認済みまたは簡易書留確認済みのとき | 未確認へ戻す |
| 氏名・カナ・生年月日 | 確認済みのとき | 未確認へ戻す |

### 他機能との境界

スマレジへの会員情報更新が成功したときだけ、変更を確定する。失敗したときは更新を中止し、編集フォームを再表示する。確定したあとに、支店システムへ当該会員の更新を通知する。

## 入出力

### 入出力: 受け渡し

| 種類 | 内容 |
|------|------|
| 入力 | 会員情報の編集値、なりすまし対策トークン、再描画時の国の選択、クエリの支店指定 |
| 成功時出力 | 会員情報を更新し、会員情報変更完了画面へ遷移する |
| 失敗時出力 | 編集フォームを再表示する。検証エラー、または連携失敗のメッセージを添える |

### 入出力: 永続化

| 操作 | 契機 |
|------|------|
| 更新 | 変更が確定したとき。会員情報（パスワードは変更されたときだけ）、国 |
| 更新 | 変更が確定したとき。選手情報の連絡先アドレス・英字氏名・和文氏名・更新日時 |
| 更新 | 変更が確定したとき。既定とする配送先の氏名・カナ・郵便番号・住所・国・都道府県・会社名・電話番号 |
| 更新 | 住所系または氏名・カナ・生年月日を変更し、変更前のステータスが該当するとき。本人確認ステータスを未確認へ戻す |
