# 商品管理 — 売上分析タグ更新CSV登録

## 業務ロジック

### 取込履歴の一覧

アップロード画面には、売上分析タグ更新CSVの取込履歴だけを一覧で表示する。表示件数は指定値が許容リストに含まれるときだけ採用して保持し、含まれないときは保持値または既定の10件とする。ページ番号は指定値または保持値から決め、保持し直す。

### 雛形

雛形は列見出しだけを1行書いたCSVを返す。ファイル名は product_tag_sales_analysis_template.csv とする。

### 取込の前提

CSVは「商品ID」「売上分析タグ(ID)」の2列とする。ファイルの行数は、囲み文字の中の改行を除いた改行数で数え、5010以上のときは取り込まず件数超過のエラーとする。ファイルが選択されていないときは形式エラーとする。

拡張子が tsv のときはタブ区切り、それ以外は取込設定の区切り文字と囲み文字（配布値はカンマと二重引用符）で読む。

### 取込時の判定順序

| 順序 | 判定 | 結果 |
|------|------|------|
| 1 | ヘッダ行が解釈できるか | できなければ取込を中止する |
| 2 | ヘッダ直下にデータ行が1行以上あるか | 無ければ取込を中止する |
| 3 | データ行の列数が2か | 一致しなければエラーを記録し、全体を中断する |
| 4 | 各セルの検証（商品IDは必須の符号なし整数、売上分析タグは未入力可。入力時は要素ごとに数値であることとマスタに存在すること） | 満たさなければエラーを記録し、全体を中断する |
| 5 | 商品IDの商品が存在するか（公開状態による除外はしない） | 存在しなければエラーを記録し、全体を中断する |
| 6 | 売上分析タグの置換 | 確定するまで取り消し可能な状態で反映する |

### タグの置換

CSVで指定した売上分析タグIDの集合が、その商品の最終的な紐付けになる。既存の紐付けをいったんすべて削除してから指定IDを登録する。タグ列が空または未入力相当のときは紐付けをすべて削除する。

「売上分析タグ(ID)」はカンマ区切りで複数の整数を指定できる。検証の開始時点でマスタに存在するIDの一覧を読み、それと照合する。並行してマスタが変化した場合の整合は本書では確定しない。

同じ商品IDが同一CSVに複数回現れるときは、行ごとに置換が走り最終行の内容が残る。成功件数として数えるのは、そのCSVで初めて処理した商品IDだけである。

エラーが1件でもあるときは反映を取り消す。エラーが無いときだけ確定し、完了メッセージを表示して取込履歴を1件残す。取込履歴にはファイル名と取込種別と実行した管理者を記録する。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| 入力の検証失敗 | エラーを表示し、アップロード画面へ戻す |
| ファイル未選択 | 形式エラーを表示し、アップロード画面へ戻す |
| 行数が5010以上 | 件数超過のエラーを表示し、アップロード画面へ戻す |
| ヘッダ不正・データ行なし | エラーを表示し、アップロード画面へ戻す |
| 行の検証失敗・商品が存在しない | エラーを表示し、反映を取り消してアップロード画面へ戻す |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | CSVまたはTSVファイルの送信となりすまし対策トークン |
| 成功時出力 | アップロード画面へ戻り、完了メッセージを表示する |
| 失敗時出力 | アップロード画面へ戻り、エラーを表示する（複数になることがある） |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 削除・登録 | 取込した行ごとの売上分析タグの紐付けの置換 |
| 登録 | エラーなく取込が完了したときの取込履歴 |
