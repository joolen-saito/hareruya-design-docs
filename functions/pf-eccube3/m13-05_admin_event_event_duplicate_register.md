# M13-05（複製新規）

## 業務ロジック

### Excel基本設計により廃止された仕様（刷新後は実装不要）

- Excel基本設計 0214 識別ID:1-13 により廃止。刷新後は実装しない。現行実装のふるまいは本書に残すが、刷新後の実装・テストの対象外とする

### 複製新規画面の表示

複製元IDで複製元イベントを読む。該当するイベントが無いときは404とする。

複製新規はイベントIDを渡さないときの経路であり、日程の読み込みと申込人数の集計を行わない。イベントIDを持たないときは新規登録として表示し、送信先も新規登録とする。

### 複製する項目

| 項目名 | 複製時の扱い |
|--------|--------------|
| イベント名・略称（日・英） | 複製新規画面を開いたときに、複製元の値を初期値として載せる |
| 店舗・会場・フォーマット・ルール適用度・公開状態 | 複製新規画面を開いたときに、複製元の値を初期値として載せる |
| バナーURL（日・英） | 複製新規画面を開いたときに、複製元の値を初期値として載せる |
| 定員・チーム人数・参加費 | 複製新規画面を開いたときに、複製元の値を初期値として載せる。チーム人数は Excel基本設計 0214 識別ID:1-12 により廃止のため、刷新後は複製対象に含めない |
| 賞品（日・英）・備考（日・英） | 複製新規画面を開いたときに、複製元の値を初期値として載せる |
| 支払方法 | 複製新規画面を開いたときに、複製元の値を初期値として載せる |
| イベントID | 載せない。保存したときに新規採番する |
| 登録者ID | 載せない。保存したときにログイン中の管理者を設定する |
| 日程（イベント詳細）・申込・デッキ登録 | 複製新規画面を開いたときも引き継がない |

複製元の登録者は引き継がない。日程を読み込まないときは画面に日程一覧を表示せず、保存しても新規のイベントに日程は紐づかない。

各項目の最大長・必須／任意・検証・保存先はM13-02を正とする。複製新規が新規登録と異なるのは、初期値が複製元の値になる点だけである。

### 保存

保存は新規登録の送信経路に入る。検証を通過したときだけ、登録者にログイン中の管理者を設定して新規に登録する。完了メッセージを表示し、登録したイベントの編集画面へ遷移する。複製元は更新しない。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| 複製元イベントが存在しないとき | 404とする |
| 保存時の検証に失敗したとき | M13-02のエラー時の扱いに従う |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 複製元のイベントID。保存するときはM13-02の新規登録の入力 |
| 成功時出力 | 複製元の値を載せた新規登録フォーム。保存に成功したときは新規イベントの編集画面へ遷移し、成功メッセージを表示する |
| 失敗時出力 | 複製元IDが存在しないときは404。保存時の検証失敗はM13-02に従う |

### 入出力: 永続化

| 操作 | 契機 |
|------|------|
| 追加 | 保存したとき。複製した内容を新規の1件として登録する。識別子は新規採番とし、登録者はログイン中の管理者とする |

複製元は更新しない。日程・申込・デッキ登録は登録しない。

## 表示メッセージ

本機能に固有のメッセージは無い。保存時のメッセージはM13-02を正とする。
