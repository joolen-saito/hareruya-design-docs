# 受注管理 — 出荷指示リスト作成

## 業務ロジック

### 範囲指定の境界

| 範囲 | 境界に指定した値の受注 |
| --- | --- |
| 注文番号の開始 | 指定した番号以上のとき対象になる |
| 注文番号の終了 | 指定した番号以下のとき対象になる |
| 注文日時の開始 | 指定した日時以上のとき対象になる |
| 注文日時の終了 | 指定した日時ちょうどのときは対象にならない（指定した日時より前だけが対象） |

### 抽出対象の判定

| 受注の状態 | 出荷指示リスト作成の対象 |
| --- | --- |
| 受注サブ情報を持たないとき | ほかの条件をすべて満たす場合でも対象にならない |
| 配送先を複数持ち、その一部だけが除外対象の配送方法のとき | 除外対象でない配送方法の配送先が 1 つでもあれば対象になる |

### 注文区分の判定に使う商品名

| 受注の内容 | 注文区分 |
| --- | --- |
| 先頭の明細の商品名に「予約」を含むとき | 予約。購入種類数が閾値以上の場合でも大量にはならない |
| 先頭の明細の商品名に「予約」を含まないとき | 2 件目以降の明細に「予約」を含む商品がある場合でも、予約にはならない |

## 入出力

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 追加 | 出荷指示リストの作成時に、リスト生成を実行した担当者を記録する |
