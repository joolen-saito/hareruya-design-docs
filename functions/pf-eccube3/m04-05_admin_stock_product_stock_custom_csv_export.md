# 在庫管理 — 在庫情報カスタムCSV出力

## 業務ロジック

### 出力するCSVの決まり方

出力する列と並びは、指定したカスタムCSV定義に従う。画面上の入力項目は持たない。

出力対象のデータは、カスタムCSV定義が持つCSV種別に応じて取得する。

### 対象が存在しない場合

指定したカスタムCSV定義が存在しない場合は出力せず、ページが見つからない扱いとする。

### 他機能との境界

カスタムCSV定義の登録・編集は「CSV出力項目設定」を正とする。

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | カスタムCSV定義の指定 |
| 成功時出力 | 在庫情報のCSVファイル（カスタム項目） |
| 失敗時出力 | 指定したカスタムCSV定義が存在しない場合はページが見つからない扱い |

### 出力: CSVファイル

ヘッダ行を先頭に出力し、続けて対象データを1件1行で出力する。列と並びはカスタムCSV定義のとおりとする。
