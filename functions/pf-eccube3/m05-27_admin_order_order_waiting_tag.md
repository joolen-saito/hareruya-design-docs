# 受注管理 — 店頭注文番号札管理

## 業務ロジック

### 一覧の表示

登録済みの店頭注文番号札をすべて表示する。絞り込みも並び替えもページ送りも無いため、登録した件数だけ行が並ぶ。

### 登録

店頭注文番号札を 1 件ずつ登録する。入力できるのは番号札の値だけで、空のときは登録しない。

値は半角英字だけを受け付ける。半角英字以外の文字が 1 文字でも含まれるときは登録せず、同じ画面に留まる。数字・記号・空白・全角英字のいずれも受け付けない。

同じ値がすでに登録されているときも重ねて登録できる。値の重複は確かめない。

登録できたときは一覧へ戻る。登録できなかったときは一覧へ戻らず、入力した値を残したまま同じ画面を表示する。

### 削除

一覧から 1 件ずつ削除する。削除の要求には偽造防止のトークンを付け、番号札を探す前に検証する。トークンが不正なときは削除しない。

指定した番号札が存在しないときは削除しない。IDの指定が無いときも削除しない。

削除しても、その番号札を使っている受注には影響しない。受注が持つ店頭注文番号は変わらない。

## 入出力

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 店頭注文番号札の登録 | 入力に不備が無いときだけ |
| 店頭注文番号札の削除 | トークンが正しく、指定した番号札が存在するときだけ |

受注側のデータは更新しない。
