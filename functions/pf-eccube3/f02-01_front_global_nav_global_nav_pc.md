# F02-01（本店PC版グローバルナビ）

## 概要

本店PC版グローバルナビは、本店（オンラインショップ本体）のPC表示で画面上部に並ぶグローバルナビゲーションと、ロゴ・検索・マイページ・言語切替・カートを含むECヘッダの導線を表示する機能である。ナビゲーションブロックは買取・記事・デッキ検索・選手一覧・店舗一覧・イベント・ヘルプの各導線を、ECヘッダブロックはロゴ・商品検索フォーム・詳細検索・マイページ・言語切替・カート個数を表示する。これらは管理画面のページ設定で本店の各画面のヘッダ領域へ割り当てられて表示される。

本書は実装手順ではなく、誰が・いつ・どの条件で・結果どうなるかを読むためのリバース詳細設計とする。本機能のカスタマイズ区分はカスタマイズである。画面・処理フロー・JS等の挙動はpf-eccube3（EC-CUBE3系）のHareruyaEcプラグインのナビゲーションブロック処理・ECヘッダブロック処理、テンプレート（`Block/ec_navigator.twig`・`Block/ec_header_unisuggest.twig`・`Block/base_header.twig`）を正とし、DB関連（テーブル名・列名・保存先）はリニューアル先のec-cube-enterpriseを正とする。

対象はブラウザ経由の本店フロントのPC表示に限定する。

本文ではフレームワークのコントローラ型名やメソッド名を主説明としない。ルートbind名の網羅は主説明とせず、「利用者視点の入口」にHTTPメソッドとサイトルートからのパスパターンを書く。コード探索でbind名が必要なときだけ「調査補助」へ書く。フロントのページであり管理画面プレフィックスは付かない。フロントのルートはロケール接頭辞`/{_locale}`の下に置かれる。

---

## 本書で扱うこと

- 本店PC版のグローバルナビ（ナビゲーションブロック）の表示項目と遷移先
- 本店PC版のECヘッダ（ロゴ・検索・詳細検索・マイページ・言語切替・カート）の表示要素
- ログイン状態による表示の出し分け（保有ポイント・ログイン導線）
- 言語（ja／en）による表示項目の出し分け
- 本店ナビと支店ナビの境界

- 本店スマホ版ナビゲーション（F02-02を正とする）

## リニューアル移行時の扱い

本機能のカスタマイズ区分はカスタマイズである。ナビ・ECヘッダの表示・言語切替・出し分け等の挙動はpf-eccube3（HareruyaEcプラグイン）の実装を正とし、DB関連（テーブル名・列名・保存先）はリニューアル先のec-cube-enterpriseを正とする。現行と移行先の差は次のとおり。

| 観点 | 現行（pf-eccube3） | 移行先（ec-cube-enterprise） |
|------|--------------------|------------------------------|
| ナビ・ECヘッダの描画 | HareruyaEcプラグインのブロック処理・テンプレートで描画 | 標準のページ設定ブロック構成で描画。挙動はpf-eccube3を正とする |
| 保有ポイント参照 | 会員テーブルの保有ポイント | 会員（`dtb_customer`）の保有ポイント。集計の詳細はポイント機能を正とする |
| 永続化 | ナビ・ヘッダの導線表示自体はテーブルを更新しない | 同一（参照のみ） |

ナビ・ヘッダの導線表示はDB更新を伴わない。保有ポイント参照列・カート個数取得の保存先はそれぞれポイント機能・カート機能を正とする。確認できない点はec-cube-enterprise実装で要確認とする。

## 利用者視点の入口

| 入口 | URLエンドポイント | 期待されるふるまい |
|------|--------------------|--------------------|
| 本店の各画面を開く（ヘッダ・ナビは画面の一部として描画） | `GET /{_locale}/`ほか本店フロントの各URL | ページ設定の割り当てに従い、ECヘッダとグローバルナビを画面上部へ描画する。 |
| ナビゲーションブロック単体（ページ設定が部分描画する境界） | `GET|POST /{_locale}/block/ec_navigator` | ナビゲーションの部分テンプレートを返す。 |
| ECヘッダブロック単体（同上） | `GET|POST /{_locale}/block/ec_header` | 言語に応じた言語切替先を組み立て、ECヘッダの部分テンプレートを返す。 |

ナビ・ヘッダは利用者が直接URLで開くより、本店各画面の一部として描画される。ブロック単体URLは部分描画の境界として実装上存在する。

## フロント挙動

| 観点 | 内容 |
|------|------|
| 表示要素 | グローバルナビは買取・記事・デッキ検索・選手一覧・店舗一覧・イベント・ヘルプを横並びで表示する。ECヘッダはロゴ、商品検索フォーム（検索対象の種別選択・キーワード入力・検索ボタン）、詳細検索リンク、マイページ、言語切替、カート（個数表示付き）を表示する。ログイン会員のときは保有ポイント表示を併せて出す。 |
| JS挙動 | 商品検索フォームはサジェスト用スクリプトを読み込み、入力中に候補を表示する。マイページのアイコンは隠しメニュー（ログイン／会員登録・マイページ）を展開する。カート個数は非同期取得した値で表示する。 |
| CSS・レイアウト | PC表示用のヘッダレイアウトを適用する。マイページの隠しメニュー・サジェスト候補は重ね表示する。言語切替リンクが無効化されている画面では言語切替を表示しない。 |
| モーダル・ポップアップ | グローバルナビ・ECヘッダ自体は専用モーダルを持たない。ログイン用モーダルは各画面側の責務とする。 |
| 入力項目 | ECヘッダの商品検索フォーム（検索対象の種別選択・キーワード入力欄）を持つ。検索処理は商品機能を正とする。 |

検索対象の種別は全商品・カード・パック／サプライから選ぶ。商品検索の送信先・サジェストの仕様は商品機能を正とする。

## 処理フロー

### グローバルナビを描画する

1. ページ設定の割り当てに従い、ナビゲーションブロックがヘッダ領域へ差し込まれる。
2. ナビゲーションの部分テンプレートを描画する。追加データの取得は行わない。

### ECヘッダを描画する

1. ページ設定の割り当てに従い、ECヘッダブロックがヘッダ領域へ差し込まれる。
2. 現在URLのロケール接頭辞を反対言語へ置き換えた言語切替先を組み立てる。日本語ページで対象画面に英語版が無い場合は、言語切替先を英語TOPへ差し替える。
3. ログイン会員のときは保有ポイント表示を組み込む（F02-05を正とする）。
4. ECヘッダの部分テンプレートを描画し、カート個数を非同期取得して表示する。

## 業務ルール・計算

| 項目 | 内容 |
|------|------|
| ナビ項目（ja） | 買取・記事・デッキ検索・選手一覧・店舗一覧・イベント・ヘルプを表示する。 |
| ナビ項目（en） | 記事・デッキ検索・選手一覧・店舗一覧・イベント・ヘルプを表示する。英語表示では買取の導線を表示しない。 |
| 言語切替先 | 現在URLのロケール接頭辞を反対言語へ置き換える。日本語ページで対象画面に英語版が無い場合は英語TOPへ切り替える。 |
| ログイン状態の出し分け | ログイン会員のとき保有ポイント表示を出す。未ログインのときマイページ隠しメニューにログイン／会員登録の導線を出す。 |
| 本店と支店の境界 | 本書のナビは本店（ECヘッダ系）の導線である。支店ページのヘッダ・ナビ（F02-03）とは別部品である。 |

本機能は金額計算・税計算・丸めを行わない。保有ポイントの集計はポイント機能を正とする。

### 入力項目

| 項目名 | 必須／任意 | 最大長 | 初期値 | 保存先・扱い |
|--------|------------|--------|--------|----------------|
| 検索対象の種別 | 任意 | 選択肢のいずれか | クエリ`suggest_type`の現在値（無指定時は全商品相当） | 商品検索フォームの選択（フォームキー`suggest_type`、値`all`／`card`／`supply`）。検索処理は商品機能を正とする。 |
| 商品検索キーワード | 任意 | フォーム上限なし（DB上限に依存しない自由入力） | クエリ`product`の現在値 | 商品検索フォームの入力（フォームキー`product`）。サジェスト・検索結果は商品機能を正とする。 |

検索フォームの送信はECヘッダから商品検索画面へ向かう。ナビ・ヘッダ自体は入力値を保存しない。

### エッジケース

| ケース | 扱い |
|--------|------|
| 未ログインで表示 | 保有ポイント表示を出さず、マイページ隠しメニューにログイン／会員登録の導線を出す。 |
| ログイン会員で表示 | 保有ポイント表示を出す（F02-05を正とする）。 |
| 日本語ページで対象画面に英語版が無い | 言語切替先を英語TOPへ差し替える。 |
| 言語切替リンクが無効化された画面 | 言語切替を表示しない。 |

## 排他制御・トランザクション
