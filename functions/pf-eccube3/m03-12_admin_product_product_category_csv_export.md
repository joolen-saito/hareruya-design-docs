# 商品管理 — カテゴリ CSV 出力

## 業務ロジック

### 出力する列

出力する列は、カテゴリCSV種別かつ有効なCSV出力項目設定で、表示順の昇順に並べたものである。1行目には各項目の表示名を並べる。

| 項目 | 内容 |
|------|------|
| セル値（一般列） | 項目定義のエンティティ名が出力中のカテゴリと一致し、かつ項目名がカテゴリの保持する項目に存在するときだけ値を取り出す。関連する情報は参照する項目名で単一値にする。真偽は1／0の文字列、日時は出力用の日付書式、複数値は出力用の区切り文字で連結する。一致しないとき、または存在しないときは空セルにする |
| セル値（対象商品数） | 項目名が対象商品数のときは、カテゴリごとの商品数の集計値を書く。集計に無いカテゴリは0とする |
| 対象商品数の集計 | 出力対象のカテゴリIDについて、商品カテゴリの紐付けからカテゴリごとに重複を除いた商品数を数える |
| 値の正規化 | 取り出した値が未設定または空文字のときは空セルにする |

### 出力する対象

全カテゴリを条件なしで取得し、表示順の降順だけで並べる。検索条件やツリーの親IDは、画面で指定されたときも出力には渡らない。対象は常に全カテゴリである。

| 場合 | 結果 |
|------|------|
| カテゴリが0件のとき | ヘッダ行だけを書き、データ行が無いファイルとなる |
| 有効なCSV出力項目が1件も無いとき | ヘッダが空となり、データ行はカテゴリの件数分だけ空列が並ぶ（運用上は店舗設定で有効項目を残す前提） |

### 出力ファイル

ファイル名は`category_YYYYMMDDhhmmss.csv`とし、ダウンロードとして応答する。文字コードは出力エンコーディングの設定に従いUTF-8から変換し、UTF-8を指定したときはBOMを先頭に書く。フィールドの区切り文字も出力用の設定値に従う。

出力の間は実行時間の制限を無効にする。

本機能ではフォーム入力の保存を行わないため、保存対象の項目は無い。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| 未ログイン・権限不足のとき | 管理画面共通のログイン案内や拒否に従う |
| 出力の途中で例外が発生したとき | 利用者向けの専用メッセージの分岐は無い |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 無し。検索条件やツリーの親IDは渡らない |
| 成功時出力 | CSVファイル。1行目はヘッダ、2行目以降がデータ |
| 失敗時出力 | 本処理に完了メッセージや遷移の分岐は無い。認可失敗やサーバ例外は管理画面共通の扱いに従う |

### 入出力: 永続化

本機能はデータを更新しない。

## 表示メッセージ

本機能は画面メッセージを表示しない。
