# o01-03_other_mtg_buyer_mtg_buyer_stock_inbound（その他_MTGバイヤー_入庫モード）

MTGバイヤー（買取端末のアプリ）の「入庫モード」は、手元のカードを読み取って商品コードと枚数の一覧を作り、在庫登録用のCSVファイルとして端末へ出力する機能である。受注やお客様にはひも付かない。商品の情報はECCUBEのAPIから取得する。ECCUBEの在庫をアプリから直接は更新しない。

本書はアプリ側のふるまいを定める。呼び出すAPIの応答内容は、各APIの設計書（A06-01、A06-06、A06-08、A06-11、A06-12）を正とする。

## 業務ロジック

### 入口

| 観点 | 扱い |
| --- | --- |
| 入口 | ログイン後の業務選択画面にある「入庫モード」 |
| 利用できる店舗 | 所属店舗による制限は無い。どの店舗の利用者の場合も利用できる |
| 実行したとき | お客様選択画面を経ずに、査定画面（見出しは「入庫モード」）へ直接移る |

### 呼び出すAPI

すべての呼び出しで、ログイン時に受け取った認証トークンを要求ヘッダ `jwt-token` に付ける。

| 場面 | メソッド | パス | 送る内容 | 対応する設計書 |
| --- | --- | --- | --- | --- |
| カードを読み取ったとき、一覧の行を編集するとき、カード1種の商品情報を取得 | GET | `api/v1/buying/{カード詳細ID}.json` | なし | A06-06 |
| カード名で検索したとき、商品を検索 | POST | `api/v1/search` | `name`（カード名） | A06-08 |
| 入庫モードの画面を開くとき、部門一覧を取得 | GET | `api/v1/admin/sections.json` | なし | A06-11 |
| 入庫モードの画面を開くとき、固定価格部門を取得 | GET | `api/v1/admin/fixedPriceSection.json` | なし | A06-12 |

受注の取得・状態の更新・査定結果の登録は呼び出さない。

### 画面の構成

入庫モードの査定画面は、店頭買取・ネット買取の査定画面と次の点が違う。

| 画面部品 | 入庫モードでの扱い |
| --- | --- |
| お客様情報欄（お客様名、フリーコメント、「お客様切り替え」） | 入庫モードの場合は出さない |
| 「CSV形式で出力する」 | 入庫モードの場合だけ出す |
| 「査定表を印刷する」 | 入庫モードの場合は出さない |
| 「個別入力する」 | 入庫モードの場合は出さない |
| 「1円」「2円」「5円」「10円」 | 入庫モードの場合は出さない |
| 買取カテゴリ・基準価格・基準小計・部門の列 | 入庫モードの場合は出さない |

### 一覧への行の追加

カードを読み取った場合、またはカード名で検索した場合に「登録する」を実行したとき、一覧へ1行を足す。

| 行の項目 | 値 |
| --- | --- |
| 商品コード・商品規格ID・商品名・基準価格・レアリティ・略称タグ | 取得した商品情報のうち、画面で選んでいる言語・状態・フォイル区分に一致する規格の値。基準価格はその規格の販売価格。入庫モードの場合、商品コード・商品規格ID・基準価格・レアリティ・略称タグは一覧には出さないが行に持ち、CSVファイルへ出力する |
| プロモ | プロモーションのあるカードの場合は「○」、無い場合は「-」 |
| 言語・状態・フォイル | 「登録する」を実行したときに画面で選んでいる値。言語は言語コード（JP、ENなど）で表す。フォイルは、フォイルの場合は「○」、ノーマルの場合は「-」と表示する |
| 枚数 | 新しく足す行の場合は1。一覧の行を編集して登録し直す場合は、編集前の枚数 |
| 買取価格 | 「登録する」を実行したときのカード情報の欄の買取価格 |

カード情報が無い状態で「登録する」を実行したときは行を足さず、メッセージを表示する。

### 作業途中のデータ

| 観点 | 扱い |
| --- | --- |
| 保存の契機 | 行を追加・複製・削除したとき、枚数や買取価格を変えたとき、一覧を初期化したとき |
| 保存先 | 端末内の1ファイル。利用者ごとに分ける（ファイル名は「u{利用者のメンバーID}.csv」） |
| 復元 | 入庫モードの画面を開いたとき、その利用者の作業途中のデータが端末にあれば読み込む。削除済みの行は削除済みのまま持ち、一覧には表示しない |
| 端末の外への保管 | 行わない。別の端末でログインした場合は引き継がれない |
| 削除 | CSVファイルを出力したときだけ消す |

「査定を中断する」を実行したときは、「査定を中断します。現在の査定データを記録しました。」と表示して業務選択画面へ戻る。この場合、ECCUBEへは何も送らない。「ログアウト」を実行したときと、ウィンドウを閉じたときも、ECCUBEへは何も送らない。

### CSVファイルの出力

「CSV形式で出力する」を実行したとき、出力方法と保存先のフォルダを指定させ、指定されたフォルダへファイルを1つ作る。保存先のフォルダを指定せずに取りやめた場合は何も出力しない。

| 出力方法 | ファイル名 | 既定 |
| --- | --- | --- |
| 通販/支店システム用を指定した場合 | 「通販_支店システム用{出力日時の年月日時分秒14桁}.csv」 | 既定で選ばれている |
| ネット買取用を指定した場合 | 「ネット買取用{出力日時の年月日時分秒14桁}.csv」 | — |

2つの出力方法に共通する形式は次のとおり。

| 観点 | 扱い |
| --- | --- |
| 文字コード | Shift_JIS |
| 区切り | カンマ。見出し行と明細行のすべての値を二重引用符で囲む |
| 見出し行 | 1行目に出す。出力する行が1行も無い場合も、見出し行だけのファイルを作る |
| 明細行 | 一覧の1行につき1行。同じ商品が複数行にある場合もまとめない |
| 商品名の値 | 「【{言語}】{商品名}」の形にする（例：【JP】稲妻） |
| 出力したとき | 作業途中のデータを消し、保存先のフォルダを開く |

通販/支店システム用は、ログインした利用者の所属店舗名で列が変わる。

| 所属店舗名 | 列（左から） |
| --- | --- |
| 「トーナメントセンター 東京」の場合 | 商品コード、在庫増減数 |
| 上記以外の場合 | 商品コード、商品名、在庫数 |

「在庫増減数」「在庫数」の値は、どちらも一覧の枚数である。

| 出力方法 | 出力しない行 |
| --- | --- |
| 通販/支店システム用の場合 | 削除済みの行、商品コードが空の行 |
| ネット買取用の場合 | 削除済みの行だけ |

ネット買取用の列は、左から次の9列である。

| 列 | 値 |
| --- | --- |
| 商品コード | 商品コード |
| 在庫増減数 | 枚数 |
| 商品名 | 「【{言語}】{商品名}」 |
| 基準価格 | 基準価格。行に基準価格が無い場合は空 |
| 買取価格 | 買取価格 |
| 言語ID | 言語ID |
| 略称タグ | 略称タグ |
| レアリティ | レアリティ |
| 状態 | 状態（NM・SP・MP・HP） |

出力したCSVファイルをどのシステムのどの機能へ取り込むかは、アプリでは定めていない。

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | ログイン利用者の認証トークン・メンバーID・所属店舗名、ECCUBEから取得する商品情報、端末にある利用者別の作業途中のデータ、作業者の操作（カードの登録、枚数の変更、行の削除、出力方法と保存先の選択） |
| 成功時出力 | 一覧を変更するたびに、端末にある利用者別の作業途中のデータ。出力を実行したときだけ、在庫登録用のCSVファイル |
| 失敗時出力 | カード情報が無い場合などに、メッセージの表示 |

### 入出力: 永続化

アプリはECCUBEのデータを登録・更新・削除しない。

| 操作 | 契機 |
| --- | --- |
| 更新しない | 商品情報・部門を取得したとき |
| 更新しない | 一覧へ行を足したとき、一覧を変更したとき |
| 更新しない | 出力を実行したとき |

## 表示メッセージ

| メッセージID | 表示位置 | 画面上の文言 | 表示条件 | 後続処理 |
| --- | --- | --- | --- | --- |
| — | ダイアログ | 査定を中断します。現在の査定データを記録しました。 | 「査定を中断する」を押したとき | 業務選択画面へ戻る |
| — | ダイアログ | カード情報がありません。登録に失敗しました。 | カード情報が無い状態で「登録する」を押したとき | 行を足さない |
| — | ダイアログ | 指定されたカードが見つかりませんでした。 | カード名での検索に失敗したとき、検索結果が0件のとき、画面で選んでいる言語・状態・フォイル区分に一致する規格が無いとき | 一覧を変えない |
| — | ダイアログ | 1文字以上入力してください。 | カード名を空白だけで検索したとき | 検索しない |
| — | 確認ダイアログ | システムを終了しますか？ | アプリの終了を選んだとき | 「いいえ」で終了しない |
| — | 確認ダイアログ | 査定表を初期化しますか？ | 一覧の初期化を選んだとき | 「はい」で一覧を空にする |
| — | ダイアログ | 中断された査定データの読み込みに失敗しました。査定表を初期化して表示します。 | 作業途中のデータを読み込めなかったとき | 読み込めた行までを表示する |

メッセージIDは未採番である。文言はアプリの設定ファイルに定義されている。「1文字以上入力してください。」だけは設定ファイルに無く、アプリに直接定義されている。
