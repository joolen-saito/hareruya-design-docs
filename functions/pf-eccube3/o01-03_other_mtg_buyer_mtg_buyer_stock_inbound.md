# o01-03_other_mtg_buyer_mtg_buyer_stock_inbound（その他_MTGバイヤー_入庫モード）

## 業務ロジック

### 入庫の対象と契機

ステータスが入庫待ちの買取受注を対象とする。入庫は、管理画面での受注詳細の更新、買取のステータス更新、または入庫待ちの受注をまとめて処理するバッチのいずれかを契機に起動する。入庫専用の外部インタフェースは持たない。入庫の対象でないステータスのときは入庫処理を行わない。ステータスによる判定があるため、入庫済みの受注を再度入庫することはない。未登録の在庫があるときは、その旨をステータスで表す。

### 入庫の内容

当該受注の買取在庫の数量を商品在庫へ加算する。商品在庫の最終的な在庫数の求め方は在庫管理の仕様に従う。在庫数の変化は、更新前数量・更新後数量・登録者・登録日時を持つ在庫履歴として記録する。反映が終わったらステータスを入庫済みとして保存する。例外が起きたときは一連の更新を取り消し、当該受注を入庫待ちのまま残す。

### 一括入庫

入庫待ちの受注をすべて対象とし、1件ずつ入庫の処理を行って入庫済みへ移す。

### エラー時の扱い

| 事象 | 扱い |
| --- | --- |
| 入庫の対象でないステータス | 入庫処理を行わない |
| 在庫反映時の例外 | 更新を取り消し、当該受注を入庫待ちのまま残す |

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | 入庫待ちの買取受注、ステータスの更新、または一括入庫の起動 |
| 成功時出力 | 商品在庫の増加、在庫履歴の作成、ステータスの入庫済みへの更新 |
| 失敗時出力 | 入庫を行わず、入庫待ちのまま残す |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 更新 | 入庫時に、買取在庫の数量を商品在庫へ加算する |
| 追加 | 同じ契機で、更新前数量・更新後数量・登録者・登録日時を持つ在庫履歴を記録する |
| 更新 | 在庫の反映が終わったとき、買取受注のステータスを入庫済みにする |

## 表示メッセージ

この機能は画面を持たないためメッセージを扱わない。
