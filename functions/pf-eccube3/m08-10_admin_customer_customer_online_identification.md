# 会員管理 — オンライン本人確認

## 業務ロジック

### 表示の条件

オンライン本人確認は会員編集画面の中で扱う。

| 場面 | 表示 |
| --- | --- |
| 会員IDがある編集のとき | オンライン本人確認の操作とモーダルを表示する |
| 会員IDが無い新規のとき | オンライン本人確認を表示しない |

### モーダルの表示内容

| 表示 | 条件 |
| --- | --- |
| 身分証画像 | 本人確認の閲覧権限があるときだけ、当該会員の現在の身分証画像を種別ごとに表示する |
| 閲覧不可の文言 | 本人確認の閲覧権限が無いとき、各画像枠に表示する |
| 登録データなしの文言 | 身分証画像が未登録の種別の枠に表示する |
| 身分証画像の拡大表示 | 表示されている身分証画像を押すと、その種別の画像だけを大きく表示する。閲覧不可の枠と未登録の枠には拡大表示を設けない |
| 身分証有効期限の初期表示 | 選手情報に保存済みの身分証有効期限を初期値として表示する。保存が無いときは空欄とする |

### 確認済への変更の判定順序

| 順序 | 判定・処理 | 内容 |
| --- | --- | --- |
| 1 | 会員IDの指定 | 指定が無いときはページが見つからない扱い（404）とする |
| 2 | 選手情報の取得 | 会員IDから選手情報を取得する。存在しないときはページが見つからない扱い（404）とする |
| 3 | 身分証有効期限の解釈 | 入力があるときは日付として解釈する。解釈できないときはエラーを表示し、ステータスを更新せず会員編集画面へ戻す |
| 4 | 身分証有効期限の未入力 | 入力が無いときは身分証有効期限を未設定にする |
| 5 | 遷移 | 保存できたときは会員編集画面へ戻す |

### 他機能との境界

確認済み・簡易書留確認済みの会員で本人確認用情報を変更したときに未確認へ戻す判定は、会員登録/編集の側で行う。

### エラー時の扱い

| 事象 | 扱い |
|------------|------|
| 会員IDの指定が無いとき、または選手情報が無いとき | ページが見つからない扱い（404）とする |
| 身分証有効期限が日付として解釈できないとき | エラーを表示し、ステータスを更新せず会員編集画面へ戻す |
| 本人確認の閲覧権限が無いとき | 身分証画像を表示せず、閲覧不可の文言を表示する |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 会員ID、身分証有効期限。 |
| 成功時出力 | 身分証有効期限の保存、保存成功のメッセージ、会員編集画面の再表示。 |
| 失敗時出力 | 会員IDが無いとき、選手情報が無いときはページが見つからない扱い（404）。身分証有効期限が不正なときはエラーを表示して会員編集画面へ戻す。 |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 更新 | 確認済へ変更したとき、入力された身分証有効期限を選手情報へ保存する |

身分証有効期限の入力欄は会員編集画面の登録操作の対象外で、確認済へ変更したときだけ送られて保存される。

## 表示メッセージ

| メッセージID | 表示位置 | 画面上の文言 | 表示条件 | 後続処理 |

| — | モーダル内の身分証画像枠 | 登録データなし | 身分証画像が未登録の種別のとき | 当該種別の画像を表示しない |

| M08-10-MSG-002 | 管理画面上部 | システムエラーが発生しました | 本人確認を確認済みに変更しようとしたとき、確認済みのステータスを取得できない場合 | 会員編集画面に遷移する |
| M08-10-MSG-003 | 管理画面上部 | システムエラーが発生しました | 本人確認を確認済みに変更しようとしたとき、会員の選手情報がない場合 | 会員編集画面に遷移する |
| M08-10-MSG-004 | 管理画面上部 | 保存しました | 本人確認を確認済みに変更して保存したとき | 会員編集画面に遷移する |
