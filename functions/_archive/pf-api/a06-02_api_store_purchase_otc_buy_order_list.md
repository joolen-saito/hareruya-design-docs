## 用語

| 用語 | 説明 |
|------|------|
| 店頭買取受注 | 店頭で受け付けた買取の受注。受注IDで一意に特定する。 |
| 査定対象 | 商品到着・査定中・振込前・保留・査定再開のいずれかの状態にある受注。本APIの抽出対象。 |
| 申込者情報 | 受注ごとの氏名・生年月日・電話番号・郵便番号・職業・住所をまとめた情報。 |
| 店頭買取ステータス | 受注の進行状態を表すマスタ値。 |
| 所属店舗 | 認証した管理者会員に紐づく店舗。会員サブ情報から引く。 |

### データ整合性
| 観点 | 内容 |
|------|------|
| 参照時点 | 呼び出し時点で査定対象の状態にある店頭買取受注を返す。本APIはデータを更新しない。 |
| 抽出範囲 | 店頭買取ステータスが商品到着・査定中・振込前・保留・査定再開の受注のみを返す。状態が変わった受注は次回以降の取得結果から外れる。所属店舗で絞り込む場合は他店舗の受注を含まない。 |
| 一覧と詳細 | 本APIは一覧の受注基本情報と申込者情報のみを返し、受注明細（買取代表カード・個別入力商品・在庫）は含まない。明細の整合は店頭買取受注詳細更新APIの設計を正とする。 |

### 権限・認可
| 利用者状態 | 店頭買取受注一覧取得 |
|------------|----------------------|
| 認証済みで店舗に紐づく管理者会員 | その店舗の査定対象の店頭買取受注一覧を取得できる。 |
| 認証済みで店舗に紐づかない管理者会員 | 店舗による絞り込みなしで査定対象の店頭買取受注一覧を取得できる。 |
| 未認証・トークン不正 | 認証拒否（HTTP 401）となり、取得できない。 |
