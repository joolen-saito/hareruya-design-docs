## 副作用（設計書からは削除・2026-08-19）

### 副作用
無し（参照のみ）。検索クエリには検索条件に応じたキーの結果キャッシュ（既定の保持時間つき）を用いるが、業務データの更新・履歴・通知は行わない。
応答はJSON応答整形を経て返す。プロパティはcamelCase、日時はISO8601、`serialize_null`は有効とする。本APIの配列要素キーは取得クエリのエイリアス（snake_case）に従う。

### データ整合性
| 観点 | 内容 |
|------|------|
| 参照時点 | 呼び出し時点のカードを返す。結果キャッシュの保持時間内は同一条件で同一内容を返すことがある。本APIはデータを更新しない。 |
| 一覧と総件数 | `total_count`はページングを除いた重複排除後の総件数であり、`cards`は対象ページの分のみを返す。両者は同一の絞り込み条件に基づく。 |
| 画像 | 各カードの画像URLは、言語・カードセット・付随条件の優先順位で選んだ最新の一枚を付与する。該当が無い場合はnull。 |
