## 用語

| 用語 | 説明 |
|------|------|
| デッキビルダーアプリ | デッキ作成・共有で利用するクライアント。本APIの呼び出し元。 |
| 会員 | デッキビルダーの利用者。メールアドレスとパスワードで認証する。 |
| アクセストークン | 認証成功時に発行する署名付きトークン。以降のdeck-apiの認証に用いる。 |
| プレイヤー | 会員に紐づくデッキビルダー上の利用者。以降のAPI認証で会員IDから引く対象。 |

## 副作用（設計書からは削除・2026-08-19）

### 副作用
アクセストークンを有効期限付きのCookieに設定する。Cookie名は設定キー`cookie_name`と`token_name`を結合した名称とし、有効期限は設定キー`jwt_expire_days`の日数に基づく。セッションを開始する。会員・プレイヤー等の業務データは更新しない。
応答はJSON応答整形を経て返す。プロパティはcamelCase、日時はISO8601、`serialize_null`は有効とする。

### ログ・監査
#### ログに出してはいけないもの
- パスワード
- アクセストークンの原値
- 署名シークレット（`auth_magic`）

---
### 権限・認可
| 利用者状態 | ログイン |
|------------|----------|
| 未認証のクライアント | ログインのために呼び出せる。資格情報が正しい場合のみアクセストークンを取得できる。 |
| 資格情報が誤りのクライアント | 認証拒否（HTTP 401）となり、トークンを取得できない。 |
| 入力が不正なクライアント | 入力不正（HTTP 400）となり、照合に進まない。 |
