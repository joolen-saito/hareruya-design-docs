## 副作用（設計書からは削除・2026-08-19）

### 副作用
無し（参照のみ）。取得クエリには結果キャッシュ（既定の保持時間つき）を用いるが、業務データの更新・履歴・通知は行わない。
応答はJSON応答整形を経て返す。プロパティはcamelCase、日時はISO8601、`serialize_null`は有効とする。

### データ整合性
| 観点 | 内容 |
|------|------|
| 参照時点 | 呼び出し時点のマスタを返す。結果キャッシュの保持時間内は同一内容を返すことがある。本APIはデータを更新しない。 |
| 一覧と詳細 | 本APIは一覧（全件）のみを返し、単一マスタ行の詳細取得は持たない。 |
