### 権限・認可
| 利用者状態 | 店頭買取受注コメント更新 |
|------------|--------------------------|
| 認証済みの管理者会員 | コメントと更新担当者を更新できる。 |
| 未認証・トークン不正 | 認証拒否（HTTP 401）となり、更新できない。 |
---
### 排他制御・トランザクション
本APIはフリーコメントと更新担当者の更新を行う。楽観ロック・悲観ロックの対象は持たず、同一受注への同時更新は後勝ちとなる。
