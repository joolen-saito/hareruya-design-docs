## 副作用（設計書からは削除・2026-08-19）

### 副作用
プレイヤーのニックネームとプロフィールを更新する（DB更新）。参照のみではない。更新はトランザクション内で行い、例外時はロールバックする。
応答はJSON応答整形を経て返す。本APIは連想配列を組み立てて返すため、JSONキーは実装で記述したsnake_case（`code`・`message`）となり、エンティティのプロパティ名（camelCase）はそのままは現れない。`serialize_null`は有効とする。

### ログ・監査
#### ログに出してはいけないもの
- JWTトークンの原値
- 署名シークレット（`auth_magic`）
- パスワード
- Cookie値・セッションIDの完全値
---
### 権限・認可
| 利用者状態 | ユーザー情報変更 |
|------------|------------------|
| 認証済みのプレイヤー | 自分のニックネームとプロフィールを更新できる。 |
| 未認証・トークン不正 | 認証拒否（HTTP 401）となり、更新できない。 |
---
### 排他制御・トランザクション
本APIはニックネームとプロフィールの更新を1つのトランザクション内で行い、例外時はロールバックする。楽観ロック・悲観ロックの対象は持たず、同一プレイヤーへの同時更新は後勝ちとなる。
