## 用語

| 用語 | 説明 |
|------|------|
| 売上状況カード | ホーム画面のダッシュボード上部右側に配置される`chart-statistics`領域。見出し文言はロケールにより「売上状況」となる。本書はこのカード内のグラフ部分を対象とする。 |
| 売上グラフ | 週間・月間・年間タブに応じた縦棒グラフ。ブラウザが非同期で取得したデータから描画される。 |
| 週間グラフ | 当日を含む過去約一週間の区間を日単位バケットに分けた棒グラフ。canvas`chart-0`に描画される。 |
| 月間グラフ | 当月1日から現在までの区間を日単位バケットに分けた棒グラフ。canvas`chart-1`に描画される。 |
| 年間グラフ | 現在から過去約一年の区間を年月単位バケットに分けた棒グラフ。canvas`chart-2`に描画される。 |
| バケット | 集計区間を区切る単位。週間・月間は日単位、年間は年月単位のキーで売上金額と件数を累積する箱。 |
| 売上対象外ステータス | 売上集計から除外する受注ステータスの集合。既定値と拡張差し替えは m02-02_admin_home_home_sales_status.md を正とする。 |
| ホーム画面 | 管理者認証後に表示されるダッシュボード。売上状況グラフはその一部である。 |

## 0203に無い定型節（設計書からは削除・2026-08-19）

#### エッジケース
| ケース | 扱い |
|--------|------|
| 該当受注が0件 | 各区間のバケットはすべて0で埋まる。横軸ラベルは区間内の各日（年間は各月）が残り、棒の高さは0になる。 |
| 売上対象外ステータスの受注 | バケットへ加算しない。除外集合の確定は m02-02_admin_home_home_sales_status.md を正とする。 |
| `payment_total`が0の受注 | ステータスと期間条件に一致する場合、バケットの件数を1増やし、売上金額には0を加算する。棒グラフでは高さ0として扱う。 |
| 売上が無い日・月 | 0で初期化済みのバケットが残り、横軸ラベルが欠けない。 |
| 月末・月またぎ | 週間・月間は日単位のためバケットが日ごとに並ぶ。年間は年月単位のため、同一月内の受注が同一バケットへ集約される。 |
| 表示後に受注が更新された | 描画済みのグラフは自動更新しない。ホーム画面再表示時に再度非同期取得した結果に従う。 |
| グラフ用JSONに件数が含まれる | 棒グラフ描画では売上金額のみを使う。件数は当該グラフの表示系列として扱わない。 |

### データ整合性
| 観点 | 内容 |
|------|------|
| 参照時点 | グラフ用データはホーム画面表示後のAjaxで読み取った結果である。三つの区間は同一リクエスト内で順に集計され、終了境界はいずれも取得処理開始時の現在時刻に基づく。 |
| サマリとグラフ | 今月・今日・昨日の売上サマリはホーム画面HTML表示時に読み取り、グラフは別リクエストで読み取る。両者を同一トランザクションで固定せず、表示直後に受注が更新された場合は値が一致しないことがある。 |
| 区間間の整合性 | 週間・月間・年間は同一リクエスト内で順に集計するが、それぞれ独立した問い合わせ結果であり、スナップショットを固定しない。重なる期間（例: 当月の各日）の合計が区間間で厳密に一致することは保証しない。 |
| 一覧・レポートとの整合性 | 受注一覧、売上レポート、会計上の売上定義との完全一致は本グラフでは保証しない。それぞれの機能の検索条件、対象ステータス、集計定義を正とする。 |
| 更新との整合性 | 本グラフは参照のみであり、受注台帳やマスタを更新しない。受注更新との排他制御や再集計タイミングは各更新機能の設計を正とする。 |
| 外部連携との整合性 | 外部連携やバッチにより受注が更新される場合の反映タイミングは、外部連携機能またはバッチ機能の設計を正とする。本グラフは読み取り時点の永続化済みデータだけを読む。 |
