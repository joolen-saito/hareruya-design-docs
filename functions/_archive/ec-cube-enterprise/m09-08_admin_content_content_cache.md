## 用語

| 用語 | 説明 |
|------|------|
| キャッシュ削除 | 本画面のボタン押下で起動する、アプリケーションキャッシュの一括削除。実体はレスポンス送出後にキャッシュ削除コマンドを実行する処理である。 |
| メンテナンスモード許可設定 | キャッシュ削除時に自動でメンテナンスモードへ切り替えるかどうかを決める設定。設定キーは`eccube_allow_maintenance_mode`で、環境変数`ECCUBE_ALLOW_MAINTENANCE_MODE`で与える。既定値は無効である。 |
| 自動メンテナンスモード | キャッシュ削除中に一時的に有効化するメンテナンス状態。識別子は`auto_maintenance`である。 |
| メンテナンス解除エンドポイント | 自動メンテナンスモードを解除するための管理側POSTエンドポイント。本画面は削除完了後にこのエンドポイントへ非同期で要求する。 |

## 副作用（設計書からは削除・2026-08-19）

| 副作用 | レスポンス送出後にアプリケーションキャッシュを削除し、opcache等のリセットを行う。メンテナンスモード許可設定が有効な場合は削除前後で自動メンテナンスモードの切り替え・解除を行う。 |

## 0203に無い定型節（設計書からは削除・2026-08-19）

#### エッジケース
| ケース | 扱い |
|--------|------|
| なりすまし対策トークンが不正・欠落 | キャッシュ削除を予約せず、メンテナンスモードも操作しない。削除完了のフラッシュも登録せず画面を再表示する。 |
| メンテナンスモード許可設定が無効 | メンテナンスモードへの切り替え・解除を行わず、キャッシュ削除のみ予約する。解除用JSも動作しない。 |
| opcache等の拡張が無効な環境 | 利用できないリセット関数は呼ばず、キャッシュ削除コマンドの実行のみ行う。 |
| 連続してボタンを押下 | 押下のたびに削除を予約し、各レスポンス送出後に削除コマンドを実行する。 |
---
### データ整合性
| 観点 | 内容 |
|------|------|
| 参照時点 | 本画面は削除ボタンと説明文を表示するのみで、業務データを読み取って集計・表示しない。 |
| 削除反映の時点 | 削除完了の応答が返った時点ではキャッシュ削除コマンドはまだ実行中または未実行のことがある。実際の削除はレスポンス送出後に完了する。 |
| 業務データとの整合性 | 本機能はアプリケーションキャッシュのみを操作し、商品・会員・受注などの業務データは変更しない。 |

## 0203に無い定型節（設計書からは削除・2026-08-19）

### 権限・認可
| 利用者状態 | キャッシュ管理画面 |
|------------|--------------------|
| 未認証 | 利用不可。管理領域の認証要件に従いログインへ誘導される。 |
| 管理者として認証済み | キャッシュ管理画面を閲覧し、キャッシュ削除ボタンを操作できる。 |
管理画面は`/%eccube_admin_route%/`配下を認証必須とするファイアウォールで保護する。本画面固有の追加権限は設けない。
---
### セッション
#### 本機能におけるセッション
| 観点 | 内容 |
|------|------|
| キャッシュ削除ボタン押下時 | 削除完了のフラッシュメッセージをフラッシュ領域へ登録する。メンテナンスモード許可設定が有効な場合はメンテナンス解除フラグのフラッシュも登録する。 |
| 画面表示のみ | フラッシュ以外の独自のセッション更新は行わない。 |
#### セッションへ保存しない情報
キャッシュの削除対象や削除結果の詳細はセッションへ保存しない。
