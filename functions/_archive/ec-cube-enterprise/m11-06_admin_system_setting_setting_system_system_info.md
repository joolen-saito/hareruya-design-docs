## 用語

| 用語 | 説明 |
|------|------|
| システム情報カード | 画面本体の先頭カード。見出しはロケールにより「システム情報」等。Bootstrapの折りたたみ領域を持ち、既定では本文が開いた状態で表示される。 |
| PHP情報カード | `eccube_phpinfo_enabled` が真のときのみ表示されるカード。見出しはロケールにより「PHP情報」等。本文は高さ500pxのiframe。 |
| 権限別拒否URL | `dtb_authority_role` に保存され、ログイン中メンバーの権限に紐付く。要求パスが管理ルート接頭辞および拒否URLパターンと先頭一致すれば認可で拒否される。 |
