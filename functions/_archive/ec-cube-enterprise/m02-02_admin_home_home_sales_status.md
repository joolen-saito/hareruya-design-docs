## 用語

| 用語 | 説明 |
|------|------|
| 売上状況カード | ホーム画面右側上部に配置される、`chart-statistics` 領域。見出し文言はロケールにより「売上状況」等となる。 |
| 売上サマリ | 「今月」「今日」「昨日」の売上金額と売上件数を並べたブロック。サーバ側で HTML 生成される。 |
| 売上グラフ | 週間・月間・年間タブに応じた棒グラフ。ブラウザが非同期で取得したデータから描画される。 |
| 売上対象外ステータス | 売上金額・件数の集計から除外する受注ステータス識別子の集合。既定実装ではキャンセル、決済処理中、購入処理中、返品を指す。拡張で書き換える場合があるため、受注状況カードの除外集合とは一致しない。 |
| 売上件数 | 条件を満たす受注台帳行を数えた件数。 |
| 売上金額 | 条件を満たす受注について、`payment_total` を合計した値として集計される。 |
| ホーム画面 | 管理者認証後に表示されるダッシュボード。売上状況はその一部ブロックである。 |

---

## 既定実装における売上集計対象

| 扱い | 受注ステータス |
|------|----------------|
| 売上集計に含める | 注文受領、入金待ち、対応中、出荷完了、入金済み、出荷指示、ピック中、店頭予約、ピック完了、引渡し済み |
| 売上集計から除外する | キャンセル、決済処理中、購入処理中、返品 |

この表は既定実装の確認値である。拡張処理が売上対象外リストを書き換えた場合、最終的な集計対象は差し替え後のリストに従う。

---

## 受注状況カードとの除外の違い

| 観点 | 受注状況カード | 売上状況 |
|------|----------------|----------|
| 出荷完了相当のステータス | 既定の除外に含まれ、件数からもマスタ表示からも外れる | 既定の売上対象外には含まれず、該当受注は売上に含まれる |
| 決済処理中・購入処理中・キャンセル・返品相当 | 除外に含まれる | 除外に含まれる |

## 0203に無い定型節（設計書からは削除・2026-08-19）

#### エッジケース
| ケース | 扱い |
|--------|------|
| 該当受注が 0 件 | サマリは金額・件数とも 0 として表示する。グラフは期間内の各バケットを 0 で埋める。 |
| 売上対象外ステータスの受注 | 金額・件数のいずれにも含めない。 |
| `payment_total` が 0 の受注 | ステータスと期間条件に一致する場合、売上件数には含め、売上金額には 0 として加算する。 |
| 表示後に受注が更新された | 表示中のサマリとグラフは自動更新しない。ホーム画面再表示またはグラフ再取得時の読み取り結果に従う。 |
| サマリ取得時点とグラフ取得時点の間に受注が変わった | サマリとグラフは別リクエストで取得されるため、同一スナップショットで一致することは保証しない。 |
| グラフ用 JSON に件数が含まれる | 画面の棒グラフ描画では売上金額のみを使う。件数は当該グラフの表示系列として扱わない。 |
---
### データ整合性
| 観点 | 内容 |
|------|------|
| 参照時点 | 売上サマリはホーム画面 HTML 表示時に読み取った結果である。グラフ用データはページ表示後の Ajax で別途読み取る。 |
| サマリとグラフ | サマリとグラフは同一トランザクションで固定しない。表示直後に受注が更新された場合、両者の値が一致しない場合がある。 |
| 一覧・レポートとの整合性 | 受注一覧、売上レポート、会計上の売上定義との完全一致は本ブロックでは保証しない。それぞれの機能の検索条件、対象ステータス、集計定義を正とする。 |
| 更新との整合性 | 本ブロックは参照のみであり、受注台帳やマスタを更新しない。受注更新との排他制御や再集計タイミングは各更新機能の設計を正とする。 |
| 外部連携との整合性 | 外部連携やバッチにより受注が更新される場合の反映タイミングは、外部連携機能またはバッチ機能の設計を正とする。本ブロックは読み取り時点の永続化済みデータだけを読む。 |

### 権限・認可
| 利用者状態 | 売上状況ブロック |
|------------|------------------|
| 未認証 | 利用不可。管理領域の認証要件に従う。 |

| より細かいロールで売上閲覧を制限する要件 | ホーム実装単体では個別の売上閲覧権限分岐は設けず、管理領域への到達可否に依存する。追加制御が必要な場合は別設計とする。 |
