## 用語

| 用語 | 説明 |
|------|------|
| カスタマイズ用JavaScript | フロント全ページの共通テンプレートから読み込まれる利用者定義のJavaScript。実体はファイル `customize.js` である。 |
| 編集対象ファイル | 管理サーバ上の `eccube_html_dir` 配下 `/user_data/assets/js/customize.js`。本画面の読み込み元かつ保存先。 |
| フロント公開先 | フロントのテーマ公開ディレクトリ `eccube_theme_front_dir` 配下 `/html/user_data/assets/js/customize.js`。保存後にファイルアダプタ経由で配置される。 |

| ファイルアダプタ | 保存済みファイルを公開先へ配置する出力部品。既定アダプタはローカルファイルアダプタまたはS3アダプタが設定により選ばれる。 |

## 0203に無い定型節（設計書からは削除・2026-08-19）

#### エッジケース
| ケース | 扱い |
|--------|------|
| 編集対象ファイルが存在しない | エディタは空で表示する。登録すると新規にファイルを作成して書き込む。 |
| 編集対象ファイルが存在するが書き込み不可 | 既存内容を初期表示しない（空表示）。登録時の書き込みで入出力例外となればエラーメッセージを表示する。 |
| コードを空文字で登録 | フォーム検証を通過し、空内容でファイルを上書きする。フロント公開先も空内容で配置する。 |
| ブラウザ側でJavaScript構文エラーを検知 | 登録ボタンが非活性となり送信できない。サーバ側では構文の妥当性を検証しない。 |
| ファイル書き込み中の入出力例外 | 保存完了メッセージを積まず、保存失敗メッセージを表示し、アプリケーションログにエラーを記録する。 |
---
### データ整合性
| 観点 | 内容 |
|------|------|
| 編集対象ファイルとフロント公開先 | 登録成功時は編集対象ファイルへ書き込んだ後にフロント公開先へ配置する。配置段階で例外が発生した場合、編集対象ファイルは更新済みでフロント公開先が未更新となる不一致が起き得る。 |
| 画面表示と保存値 | 画面初期表示は編集対象ファイルの内容を読む。保存後はリダイレクトで再表示し、保存後の内容を読み直す。 |
| 同時編集 | 複数管理者が同時に登録した場合、最後に書き込んだ内容がファイルに残る。版管理・楽観ロックは持たない。 |
| フロント反映タイミング | フロントは各ページ表示時にフロント公開先のアセットを読み込む。ブラウザキャッシュやCDNの反映遅延は本機能の管理範囲外とする。 |

| 項目名 | 必須／任意 | 最大長 | 初期値 | 保存先・扱い |
