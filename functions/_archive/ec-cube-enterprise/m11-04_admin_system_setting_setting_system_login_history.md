## 用語

| 用語 | 説明 |
|------|------|
| ログイン履歴 | 管理画面ログインの各試行を1行として記録した履歴。`dtb_login_history`に保存する。 |
| ログインID | 試行に用いられたユーザー名文字列。一覧では「ログインID」列、列ヘッダは`user_name`に対応する。 |
| IPアドレス | 試行時のクライアントIP。一覧では「IPアドレス」列、`client_ip`に対応する。 |
| ログイン試行日時 | 履歴行の作成日時。一覧では「ログイン試行日」列として日時付きで表示する。 |
| 成功失敗区分 | ログイン試行が成功したか失敗したかの区分。`mtb_login_history_status`の値で、失敗が0、成功が1。 |
| キーワード検索 | ログインIDとIPアドレスを横断して部分一致で絞り込む入力。 |
| 詳細検索 | ログインID単独・IPアドレス単独・期間・成功失敗区分による絞り込み。初期は折りたたみ表示。 |

## 0203に無い定型節（設計書からは削除・2026-08-19）

#### エッジケース
| ケース | 扱い |
|--------|------|
| 検索条件をすべて空で検索 | 全件を対象に並び順で表示する。 |
| キーワードに前後・途中のスペースを含む | スペースを除去した連結文字列で部分一致する。 |
| ステータスを未チェック | 区分での絞り込みをせず、成功・失敗の双方を表示する。 |
| 期間の終了のみ指定 | ログイン試行日時が終了指定値より前の行を対象とする。 |
| 期間の開始のみ指定 | ログイン試行日時が開始指定値以上の行を対象とする。 |
| 検索結果が0件 | 一覧表を出さず、0件メッセージを表示する。 |
| 表示件数に不正値を渡す | 表示件数マスタに一致しないため採用せず、保存済みまたは既定の件数で表示する。 |
| 管理者削除済みの履歴行 | 履歴行のログインID・IPアドレス・区分は保持されるため一覧に表示する。管理者参照は削除時にNULLとなる。 |

### データ整合性
| 観点 | 内容 |
|------|------|
| 参照時点 | 一覧は表示要求時点で`dtb_login_history`から読み取った行である。表示後に新たな試行が記録されても表示中の一覧は自動更新しない。 |
| 記録との整合性 | 表示する履歴は認証処理側が記録した行であり、本機能は更新しない。記録の有無・内容は認証機能の設計を正とする。 |
| 失敗履歴の保存失敗 | 失敗履歴の書き込みに失敗した場合は履歴行が作られず、認証機能側でサーバログに記録される。本機能はその場合に該当行を表示しない。 |
| 表示列との整合性 | 一覧の各列は履歴行の保存値をそのまま表示する。ログインIDは試行時の入力文字列であり、現在の管理者レコードのログインIDと一致するとは限らない。 |
| 件数との整合性 | 検索結果件数はページネーション部品が数えた総件数であり、表示中ページの行数とは別である。 |

## 0203に無い定型節（設計書からは削除・2026-08-19）

#### 入力項目
| 項目名 | 必須／任意 | 最大長 | 初期値 | 保存先・扱い |
|--------|------------|--------|--------|----------------|
| ログインID・IPアドレス | 任意 | 255文字 | 空 | 検索フォームのキー`multi`。スペース除去後の値で`dtb_login_history.user_name`または`client_ip`に部分一致。永続化はしない。`eccube_stext_len`（255）でLength検証。 |
| ログインID | 任意 | 255文字 | 空 | 検索フォームのキー`user_name`。`dtb_login_history.user_name`に部分一致。永続化はしない。`eccube_stext_len`（255）でLength検証。 |
| IPアドレス | 任意 | 255文字 | 空 | 検索フォームのキー`client_ip`。`dtb_login_history.client_ip`に部分一致。永続化はしない。`eccube_stext_len`（255）でLength検証。 |
| ログイン試行日(開始) | 任意 | 日時 | 空 | 検索フォームのキー`create_datetime_start`。`dtb_login_history.create_date`の下限（以上）。単一テキストの日時ピッカー。下限`0003-01-01`の範囲検証。 |
| ログイン試行日(終了) | 任意 | 日時 | 空 | 検索フォームのキー`create_datetime_end`。`dtb_login_history.create_date`の上限（未満）。単一テキストの日時ピッカー。下限`0003-01-01`の範囲検証。 |
| ステータス | 任意 | — | 全解除 | 検索フォームのキー`Status`。複数選択チェックボックス。選択した区分（失敗0／成功1）のいずれかに一致で絞り込む。 |
最大長の255は`eccube.yaml`の`eccube_stext_len`の確認値であり、環境で上書きされる場合はその値に従う。期間欄はカレンダー付き日時入力であり、文字数ではなく日時値として扱う。

## 0203に無い定型節（設計書からは削除・2026-08-19）

### 権限・認可
| 利用者状態 | ログイン履歴一覧 |
|------------|------------------|
| 未認証 | 利用不可。管理画面の認証要件に従いログイン等へ誘導される。 |
| 管理者として認証済みかつ閲覧権限あり | 一覧を閲覧し、検索・ページ送りができる。 |
| 管理者だがアクセスURL制御で不許可 | 管理画面の認可設定に従い利用不可となる。 |
本機能は参照のみで、履歴の編集・削除操作を持たない。具体的な閲覧可否はメンバーの権限設定とアクセスURL管理の設計を正とする。
---
### セッション
#### 本機能におけるセッション
| 観点 | 内容 |
|------|------|
| 検索実行時 | 検証成功時に`eccube.admin.login_history.search`へ検索条件を保存し、`eccube.admin.login_history.search.page_no`を1へ初期化して保存する。 |
| ページ送り時 | `eccube.admin.login_history.search.page_no`にURLのページ番号を保存する。 |
| 表示件数変更時 | `eccube.admin.login_history.search.page_count`にマスタ一致の件数を保存する。 |
| 初回・条件なし表示時 | 検索条件を空にして保存し、ページ番号を1にする。 |
キー名は現行実装の確認値であり、名称一致を確認する場合はソースコードを確認する。
#### セッションへ保存しない情報
パスワード・Cookie値・秘匿値は保存しない。保存するのは検索条件・ページ番号・表示件数のみとする。
