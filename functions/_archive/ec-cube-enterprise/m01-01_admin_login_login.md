## 用語

| 用語 | 説明 |
|------|------|
| 管理者 | 管理メンバー。ログインにより管理画面への業務操作が許される主体。 |

### 権限・認可
| 利用者状態 | ログイン画面 | 管理画面の保護機能 |
|------------|--------------|--------------------|
| 未ログイン | 利用可 | 利用不可。ログイン画面へ誘導する。 |
| 管理者としてログイン済み | 表示せずホーム画面へ誘導する。 | 利用可。 |
| 管理者だが二段階認証未完了 | 追加認証画面へ誘導する。 | 追加認証完了まで利用不可。 |
| 停止中・ログイン不可の管理者 | ログイン画面を表示する。 | 認証失敗のため利用不可。 |
| 一般フロント会員のみ | 管理ログイン画面は開ける。 | 管理者ではないため利用不可。 |
---
### 試行制限
試行制限は、ログイン失敗などの条件によりログイン送信を一時的に拒否または遅延させる制御である。
管理ログインは Symfony Security の `login_throttling` を使用する。
固定窓方式で 5 回 / 30 分の上限を持ち、Redis の rate limiter cache に状態を保存する。
| 観点 | 扱い |
|------|------|
| 判定タイミング | ログイン送信時、認証成立前に評価する。 |
| 判定単位 | ログイン ID と IP アドレスの組み合わせ、および IP アドレス単体。 |
| 制限時の結果 | ログインを成立させず、ログイン画面で制限状態を表示する。 |
| 解除条件 | 固定窓の 30 分経過により消費済みトークンが解消される。 |
| 成功時リセット | ログイン成功時に対象リミッターをリセットする。 |
