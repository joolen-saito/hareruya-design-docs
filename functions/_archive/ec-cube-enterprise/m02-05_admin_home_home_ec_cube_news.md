## 用語

| 用語 | 説明 |
|------|------|
| EC-CUBEお知らせカード | ホーム画面に配置される、`#ec-cube-news` をルートとするカード。見出しはロケールにより「お知らせ」等となる。 |
| 情報iframe | カード本体に埋め込まれる `name="information"` の iframe。読み込み先は `eccube_info_url` の値。 |
| eccube_info_url | アプリケーション設定に保持される文字列。Twig から参照され iframe の `src` にそのまま出力される。 |

## 0203に無い定型節（設計書からは削除・2026-08-19）

#### エッジケース
| ケース | 扱い |
|--------|------|
| `eccube_info_url` が空文字になる運用設定 | iframe の `src` が空になり、ブラウザは空の文書を読み込む。本カードはエラー文言を補わない。 |
| `eccube_info_url` が運用設定で別 URL に差し替えられる | iframe は設定された文字列をそのまま `src` に使う。スキームやホストの妥当性検証、許可リストによる制限は本カードの Twig では行わない。 |
| 外部サイトが iframe 埋め込みを拒否する | ブラウザがコンテンツを表示しない、またはエラー表示にする。サーバ側では検知・代替 HTML は出さない。 |
| ネットワーク不通・タイムアウト | ブラウザのエラー表示に委ねる。サーバ側ではリトライしない。 |
| ホーム画面を開いたまま時間が経過する | 情報iframe 内のコンテンツは自動では更新されない。最新表示にはページ全体の再読込または iframe 内での操作が必要になる。 |
---
### データ整合性
| 観点 | 内容 |
|------|------|
| 参照時点 | 情報iframe の内容は、ブラウザが `eccube_info_url` を取得した時点の応答である。サーバ側でキャッシュしたお知らせリストは持たない。 |
| 設定との関係 | ページレンダリング時の `eccube_info_url` が iframe の `src` に反映される。実行中に設定だけが変わっても、開いたままのホーム HTML は自動では書き換わらない。 |
| サイト内 DB の新着情報との関係 | 本カードはサイト内 `News` エンティティやその公開状態と連動しない。両者の内容一致は保証しない。 |
