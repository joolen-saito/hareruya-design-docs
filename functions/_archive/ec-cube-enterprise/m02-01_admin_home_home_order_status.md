## 用語

| 用語 | 説明 |
|------|------|
| 受注状況カード | ホーム画面左側に配置される、ステータス別件数を並べた領域。画面文言はロケールにより「注文状況」等となる。 |
| 除外ステータス | 受注状況カードの「表示対象マスタ行」と「件数集計」の双方から除く受注ステータス識別子の集合。既定値があり、拡張で書き換える場合がある。 |
| 受注ステータスマスタ | 受注に付くステータスの定義。名称・並び順はマスタデータに従い、識別子は定数としてコード側にも存在する。 |
| ステータス別件数 | 受注台帳を受注ステータス識別子で集約した件数。本機能では全件を対象とし、期間・会員・店舗などの絞り込みは行わない。 |
| ホーム画面 | 管理者認証後に表示されるダッシュボード。受注状況はその一部ブロックである。 |
| 受注一覧 | 受注を検索・一覧表示する管理画面。受注状況から遷移して特定ステータスで絞り込んだ初期表示がされることがある。 |

## 0203に無い定型節（設計書からは削除・2026-08-19）

#### エッジケース
| ケース | 扱い |
|--------|------|
| マスタに存在し、該当受注が 0 件のステータス | 除外リストに含まれなければ、行を表示し、件数は 0 とする。 |
| 除外リストに含まれるステータス | 件数集計にも表示対象ステータスにも含めない。 |
| 受注台帳に存在するがマスタ一覧に出ないステータス | カードの行として表示されないため、利用者は本ブロックから当該ステータス件数を確認できない。 |
| ステータス行押下前に受注一覧の検索条件が残っている | 本ブロックはクエリでステータスを渡すだけであり、既存検索条件の上書きやマージは受注一覧機能の実装に従う。 |
| 表示後に受注ステータスが更新された | 表示中の件数は自動更新しない。ホーム画面再表示時に再集計される。 |
---
### データ整合性
| 観点 | 内容 |
|------|------|
| 参照時点 | 受注状況の件数は、ホーム画面表示時にデータベースから読み取った結果である。表示後に受注が作成・更新されても、表示中の数値は自動更新しない。 |
| 件数とマスタ | 件数集計と表示対象ステータスは同一の除外リストを使う。ただし、受注台帳の読み取りとマスタの読み取りを単一の業務トランザクションで固定する要件は持たない。 |
| 一覧との整合性 | ステータス行から受注一覧へ遷移した後の検索条件、一覧件数、ページング、セッション復元は受注一覧機能の実装に従う。本ブロックの件数と一覧上の件数の完全一致は保証しない。 |
| 更新との整合性 | 本ブロックは参照のみであり、受注やステータスマスタを更新しない。受注更新との排他制御や再集計タイミングは各更新機能の設計を正とする。 |
| 外部連携との整合性 | 外部連携やバッチにより受注が更新される場合の反映タイミングは、外部連携機能またはバッチ機能の設計を正とする。本ブロックは表示時点の永続化済みデータだけを読む。 |
