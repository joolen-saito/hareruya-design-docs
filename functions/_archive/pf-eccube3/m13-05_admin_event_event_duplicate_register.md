## 0203に無い定型節（設計書からは削除・2026-08-19）

#### エッジケース
| ケース | 扱い |
|--------|------|
| 存在しない複製元IDで複製新規を開く | 404。 |
| 複製元ID指定が1未満や非整数 | ルートの制約（1以上の整数）に一致せず到達しない。 |
| 複製新規画面で入力を変更せず保存 | 複製元と同じ入力値で新規イベントを1件登録する。複製元は変更しない。 |
| 複製新規画面の保存で検証失敗 | 新規登録と同様に登録失敗エラーを表示し、テンプレートを再描画する。 |
---
### データ整合性
| 観点 | 内容 |
|------|------|
| 参照時点 | 複製新規画面の初期値は、画面表示時に読み取った複製元イベントの値である。 |
| 複製元との独立性 | 複製新規画面の保存は新規イベントを作るため、複製元イベントは更新されない。 |
| 日程の独立性 | 新規イベントには日程が紐づかないため、複製元の日程・申込との関連を持たない。 |
