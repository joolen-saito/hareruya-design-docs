## 用語

| 用語 | 説明 |
|------|------|
| 支店 | 実店舗。店舗マスタの1行に対応する。店舗の特定はパスの店舗識別名またはイベントの店舗選択で行う。 |
| 店舗ヘッダ | 支店文脈で用いるヘッダ部品。店舗一覧への導線とカートを並べる。 |
| 左カラム店舗一覧 | 店舗紹介ページの左カラムに並ぶ全店舗の一覧。表示中の店舗を選択状態にする。 |
| 右カラムセクションナビ | 店舗紹介ページの右カラムで、登録済みセクションへページ内移動するナビ。 |
| 店舗選択ボタン列・店舗切替セレクト | イベント店舗文脈で店舗を切り替える導線。短縮店舗名を表示する。 |
