## 用語

| 用語 | 説明 |
|------|------|
| 買取希望品カート | 買取を希望する商品をセッションに保持する入れ物。 |
| 商品クラス | カートに保持する単位（数量を持つ）。 |
| 買取価格 | 商品（言語・状態の組）ごとの買取単価。 |
| 合計買取価格 | カート内商品の買取価格×数量の総和（税込小計として表示）。 |
| まとめて買取 | 個別査定でなく一括で買い取る商品。カートに含まれると案内を出す。 |

## 0203に無い定型節（設計書からは削除・2026-08-19）

#### エッジケース
| ケース | 扱い |
|--------|------|
| 商品クラスID未指定で追加 | エラー応答（HTTP500相当）を返す。 |
| 既存商品の再追加 | 数量を加算し、上限超過なら上限超過応答を返す。 |
| 数量を0・非数値に更新 | 当該商品をカートから外す。 |
| 数量更新で上限超過 | 上限超過メッセージを要求エラーに積み、更新を中断する。 |
| 削除対象がカートに無い | カート表示へ戻す（変更しない）。 |
| 合計算出時に対象データ無し | 当該商品をカートから除外して算出する。 |
---
### データ整合性
| 観点 | 内容 |
|------|------|
| カートと商品データ | カートは商品クラスIDと数量のみを保持する。表示・合計は参照時点の商品サブクラスの買取価格を参照する。 |
| 合計と明細 | 小計は表示される各明細（買取価格×数量）の総和に一致する。 |
| 手続きとの引き継ぎ | カートの内容は買取手続き（F05-06）へセッションで引き継ぐ。 |

## 0203に無い定型節（設計書からは削除・2026-08-19）

#### 入力項目
| 項目名 | 必須／任意 | 最大長 | 初期値 | 保存先・扱い |
|--------|------------|--------|--------|----------------|
| 数量（カート追加） | 任意 | 同一商品20点まで（上限超過はHTTP400） | 1 | 追加リクエストのキー`quantity`。商品クラス（`product_class_id`）ごとにセッションの買取カートへ保存。 |
| 数量（カート内更新） | 必須 | 同一商品20点まで（超過は更新中断） | カート現在値 | 更新リクエストのキー`qty[商品クラスID]`。数字以外・1未満は当該商品をカートから外す。表示は3桁。 |
カートはセッションに保持し、削除はなりすまし対策トークン付きのリンクで行う。

## 0203に無い定型節（設計書からは削除・2026-08-19）

### ログ・監査
本機能は固有の監査ログを主目的としない。
### 権限・認可
| 利用者状態 | 買取カート表示・追加・更新・削除 |
|------------|----------------------------------|
| 未ログイン | カートの表示・追加・更新・削除が可能 |
| ログイン済み会員 | 同上 |
買取カートの操作に会員ログインは要しない。買取手続きでログインを要する点はF05-06を正とする。
---
### セッション
#### 本機能におけるセッション
| 観点 | 内容 |
|------|------|
| 買取カート | カート追加・更新・削除・合計算出時に、商品クラスIDと数量の組をセッションへ保存・更新する。 |
| 合計算出時の整理 | 対象データが取得できない商品はカートから除外して保存し直す。 |
#### セッションへ保存しない情報
買取価格・商品名などの商品データはセッションへ保存せず、表示・合計の都度に参照する。
