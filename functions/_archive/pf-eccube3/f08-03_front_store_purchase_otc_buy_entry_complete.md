## 用語

| 用語 | 説明 |
|------|------|
| 査定申込み | 店頭買取の査定を申し込む手続き。確定すると査定番号が付く。 |
| 査定番号 | 申込みに付与する番号。申込日・店舗ID・連番から組み立てる。 |
| 会員仮登録 | 申込みに伴い任意で行う仮会員の登録。 |
| ブラックリスト | 会員登録を不可とする該当条件。 |
| 適格請求書発行事業者 | インボイス制度の登録事業者。登録番号を任意で入力する。 |
| 状態 | 査定申込みのステータス。登録時は完了前の状態を付ける。 |

## 0203に無い定型節（設計書からは削除・2026-08-19）

#### エッジケース
| ケース | 扱い |
|--------|------|
| 店舗識別名が該当なし | 404とする。 |
| エントリー前提を満たさない | エントリーへ戻す。 |
| メール既登録／メールとパスワード同一 | 会員登録フォームへ差し戻す。 |
| ブラックリスト該当 | 会員登録は行わず、申込みは登録する。完了画面で登録不可を案内する。 |
| 完了画面に査定IDが無い | エントリーへ戻す。完了後の自動再遷移はこの経路でエントリーへ戻る。 |
| 氏名カナ未入力 | 氏名で補完する。 |
---
### データ整合性
| 観点 | 内容 |
|------|------|
| 入力とセッション | 確認・登録は、F08-02でセッションへ保存した入力データとリクエストをマージして用いる。 |
| 査定IDの一回性 | 登録時に査定IDをセッションへ保存し、完了画面で取得後に除去する。再表示時は査定IDが無くエントリーへ戻る。 |
| 査定番号の一意性 | 採番は申込テーブルのロック下で行い、連番の整合を取る。 |
| 状態履歴 | 申込登録と同時に完了前の状態を履歴へ記録する。 |
| 会員登録と連携 | 会員仮登録が成功した場合、関連情報の登録と支店システムへの連携、確認メール送信を行う（詳細は別機能）。 |

## 0203に無い定型節（設計書からは削除・2026-08-19）

### ログ・監査
| タイミング | 記録内容 |
|------------|----------|
| 会員登録開始・完了 | 会員登録の開始・完了の情報ログ。 |
| ブラックリスト該当 | 該当タグ・キーワードと登録不可の情報ログ。 |
#### ログに出してはいけないもの
- パスワード原値
- なりすまし対策トークン
- Cookie値
- セッションIDの完全値
---
### 権限・認可
| 利用者状態 | 確認・登録・完了 |
|------------|------------------|
| 未ログイン | 会員登録の有無を選んで申込みを登録できる。会員仮登録はブラックリスト判定に従う。 |
| 会員ログイン | 会員IDを申込みへ紐づけて登録できる。 |
---
### セッション
#### 本機能におけるセッション
| 観点 | 内容 |
|------|------|
| 入力データ | F08-02で保存した申込入力データと適格請求書発行事業者データを参照する。 |
| エントリーフラグ | 申込登録時に除去する。 |
| 査定ID | 申込登録時に保存し、完了画面で取得後に除去する。 |
#### セッションへ保存しない情報
決済の機微情報・パスワードの原値はセッションへ保存しない方針で扱う。
