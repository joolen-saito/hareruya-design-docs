## 用語

| 用語 | 説明 |
|------|------|
| 仮会員 | 入会申込はしたが本会員化前の会員。ログイン不可の状態。 |
| 本会員 | アクティベート済みでログイン可能な会員。 |
| 秘密キー | 会員ごとに発行される一意のキー。アクティベートURLに含む。 |
| 選手情報 | 会員に1対1で紐づく拡張情報。会員登録時に同時作成する。 |
| 仮会員設定 | 店舗基本情報の設定。有効な場合は仮会員登録完了メールを送り完了画面を表示し、無効な場合は登録後すぐ本会員化URLへ遷移させる。 |
| ブラックリスト | 会員登録を拒否する対象を登録したリスト。該当時は登録エラー画面へ遷移する。 |

#### エッジケース
| ケース | 扱い |
|--------|------|
| メールアドレスとパスワードが同一 | 登録へ進めず会員登録画面を再表示する。 |
| ブラックリストに該当 | 会員を作成せず登録エラー画面へリダイレクトする。 |

| 海外の国を選択 | 3分割郵便番号欄に代えて単一郵便番号欄を表示し、会員住所へ郵便番号を設定する。 |

| `mode`が`confirm`・`complete`・`back`以外 | いずれの分岐にも入らず会員登録画面を表示する。 |

## 0203に無い定型節（設計書からは削除・2026-08-19）

#### 入力項目
| 項目名 | 必須／任意 | 最大長 | 初期値 | 保存先・扱い |
|--------|------------|--------|--------|----------------|
| お名前 | 必須 | 姓名各欄は氏名用フォーム部品の上限に従う | 空 | `dtb_customer`の姓（`name01`）・名（`name02`）。フォームキー`name`。選手情報の日本語姓名にも設定する。 |
| お名前（フリガナ） | 必須 | カナ用フォーム部品の上限に従う | 空 | `dtb_customer`のカナ（`kana01`／`kana02`）。フォームキー`kana`。 |
| 電話番号 | 必須 | 電話番号3分割用フォーム部品の各欄上限に従う | 空 | `dtb_customer`の電話番号。フォームキー`tel`。 |
| FAX | 任意 | 電話番号3分割用フォーム部品の各欄上限に従う | 空 | `dtb_customer`のFAX番号。フォームキー`fax`。 |
| メールアドレス | 必須 | メール用フォーム部品の上限に従う（再入力一致を要する） | 空 | `dtb_customer`のメールアドレス（`email`）。フォームキー`email`（確認再入力を含む）。選手情報のメールにも設定する。 |
| メールアドレス（確認） | 必須 | 同上 | 空 | メールアドレスとの一致を検証する。不一致は「同じメールアドレスを入力してください。」。 |
| 国 | 必須 | 選択（国マスタ） | 日本語表示時は日本、英語表示時は未選択 | フォームキー`country`。都道府県との整合を検証する。海外の場合は単一郵便番号欄を表示する。 |
| 郵便番号 | 必須 | 日本は3＋4桁の分割欄、海外は郵便番号欄（住所サブの郵便番号長設定に従う） | 空 | フォームキー`zip`（日本）または`zipcode`（海外）。海外時は会員住所の郵便番号へ設定する。 |
| 住所 | 必須 | 住所用フォーム部品の上限に従う | 空 | `dtb_customer`の都道府県（`pref_id`。現行は`pref`）・住所（`addr01`／`addr02`）。フォームキー`pref`・`addr01`・`addr02`。 |
| パスワード | 必須 | パスワード用フォーム部品の上限に従う（再入力一致を要する） | 空 | `dtb_customer`のパスワード（`password`）・ソルト（`salt`）。フォームキー`password`。ソルトで暗号化した不可逆値のみ保存する。原値を記載しない。 |
| パスワード（確認） | 必須 | 同上 | 空 | パスワードとの一致を検証する。不一致は「同じパスワードを入力してください。」。 |
| 生年月日 | 必須 | 年・月・日の選択（年は当年から所定年数前まで） | 未選択 | `dtb_customer`の生年月日（`birth`）。フォームキー`birth`。未来日を不可とする。 |
| 性別 | 任意 | 選択（性別マスタ） | 未選択 | `dtb_customer`の性別（`sex_id`。現行は`sex`）。フォームキー`sex`。 |
| 会社名 | 任意 | 短文用の最大長（`stext_len`の確認値、既定255文字） | 空 | `dtb_customer`の会社名（`company_name`）。フォームキー`company_name`。 |
| 職業 | 任意 | 選択（職業マスタ） | 未選択 | `dtb_customer`の職業（`job_id`。現行は`job`）。フォームキー`job`。 |
| MTG Companion登録名 | 任意 | 各欄128文字 | 空 | 会員本体には保存せず、選手情報の英語姓名（`first_name_en`／`last_name_en`）として保存する。フォームキー`first_name_en`・`last_name_en`。 |
最大長は各共通フォーム部品の上限に従う。具体文字数は`src/Eccube/Resource/config/constant.yml.dist`の該当キー（`stext_len`・`mtext_len`等）を確認値とする。MTG Companion登録名は会員登録フォーム拡張で追加され、各128文字の上限を持つ。

### ログ・監査
| タイミング | 記録内容 |
|------------|----------|
| 確認画面表示 | 会員登録確認の開始・完了の情報ログ。 |
| 仮登録実行 | 会員登録開始・完了の情報ログ。 |
| ブラックリスト該当 | 該当タグ・キーワードと登録不可の情報ログ。 |
| 完了後リダイレクト | 仮会員登録完了画面または本会員登録画面へのリダイレクトの情報ログ。 |
| 完了メール送信 | メール送信の情報ログ・送信履歴の保存（仮会員設定有効時）。 |
#### ログに出してはいけないもの
- パスワード
- 秘密キーの完全値
- なりすまし対策トークン
- Cookie値
- セッションIDの完全値
---
### 権限・認可
| 利用者状態 | 会員登録画面・仮登録処理 |
|------------|--------------------------|
| 未ログイン | 利用可。会員登録を行える。 |
| ログイン済み会員 | 会員登録画面へアクセスは可能だが、本機能は新規登録用のため通常は会員情報変更を利用する。 |
会員登録はログイン前のアクセスを前提とする。本機能は管理画面プレフィックスを持たないフロント機能である。
---
### セッション
#### 本機能におけるセッション
| 観点 | 内容 |
|------|------|
| 支店用店舗名 | クエリ`shop`がある場合、店舗名を支店用セッションキーに記録する。完了画面のトップへ戻る先の切替に用いる。 |
| なりすまし対策トークン | 確認・仮登録の各送信で検証し、検証通過時に再生成する。 |
#### セッションへ保存しない情報
入力パスワードはセッションへ保存しない。暗号化して会員に保存し、照合・登録に用いるのみとする。
