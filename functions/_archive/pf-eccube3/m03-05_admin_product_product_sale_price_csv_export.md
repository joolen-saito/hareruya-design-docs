| ケース | 扱い |
|--------|------|
| `ids` 未送信・空・文字列のみ | 商品一覧へリダイレクト（ページ番号はセッションの検索ページ）。 |

---
### データ整合性
| 観点 | 内容 |
|------|------|
| 一覧との対応 | 出力対象は一覧でチェックした商品 ID のみである。検索ヒット全件を自動では出力しない。 |
| 一覧表示との差 | 一覧テンプレートが言語・状態などで規格を絞って表示する場合でも、CSV は `getProductClasses()` の全要素を走査する。画面に現れない規格が CSV に含まれうる（実装を確認値とする）。 |
| 商品の並び | `findBy(['id' => $productIds])` の戻り順に依存し、利用者が一覧で選んだ順序の再現は保証しない。 |
| 取込 CSV 雛形との差 | 商品価格 CSV アップロード画面向けの雛形ヘッダは「基準価格」「原価単価」を含まない。エクスポート CSV はそれらの列を追加で持つ。丸ごと取込に流用するとヘッダ不一致で取込が失敗する。 |
| 取込時の更新単位との差 | 取込は同一 CSV 1 行が同一商品 ID・言語 ID に対する「高額商品コード無し」の規格複数へ伝播しうる。エクスポートは規格ごとに 1 行である。編集した CSV をそのまま返すラウンドトリップは行単位で一致しない。 |
| 高額商品コード付き規格 | エクスポートには含まれる。取込ハンドラの更新対象 SQL は高額商品コードが NULL の規格に限定されるため、そのような行を編集して取り込んでも当該規格へは影響が及ばない場合がある。 |
