## 用語

| 用語 | 説明 |
|------|------|
| 商品本体 | 商品ID・商品名・商品説明・カテゴリ・タグ・検索ワード・ステータス・ショップ用メモなど、コア商品テーブルが持つ基本データ。 |
| 商品付加情報 | 本プラグインが商品に付与する拡張データ。商品名（英）、各説明（英・買取）、カード詳細情報、購入グループ、サイズ、重量、割引率、買取減額率、販売制限、略称タグ、売上分析タグなどを持つ。現行（pf-eccube3）は別テーブル `dtb_product_sub` に対応し、移行先（ec-cube-enterprise）は `dtb_product` 本体へ統合する。 |
| カード詳細情報 | 商品に紐づくカードの版・レアリティ等を指す参照。商品編集画面ではモーダルで指定し、隠しフィールドにIDを保持する。 |
| SHOP専用備考欄 | 画面右下のショップ用メモ欄。フロントへ出さない管理用メモを保存する。 |
| 規格設定 | 商品規格（規格単位の価格・在庫・状態）の編集導線。本画面からは別画面へ遷移する。 |

## 0203に無い定型節（設計書からは削除・2026-08-19）

#### エッジケース
| ケース | 扱い |
|--------|------|
| 規格を持たない商品 | 商品ステータス欄を隠す。基本情報の保存自体は可能。 |
| 商品カテゴリ未選択 | `NotBlank`違反として検証失敗。同じ編集画面を再表示する。 |
| 追加直後に削除した画像 | 削除対象として送信されても対応する画像レコードが無いため、その画像はスキップする。 |
| カード詳細ID未指定 | 商品付加情報のカード詳細を更新しない。 |
| 売上分析タグを空で送信 | 送信内容（空集合）で置換する。 |
---
### データ整合性
| 観点 | 内容 |
|------|------|
| 参照時点 | 編集画面表示時にDBから読み取った商品本体・付加情報・関連（カテゴリ・タグ・画像・売上分析タグ）の現行値を初期表示する。 |
| カテゴリ・タグの整合性 | 更新時は全削除後に再登録するため、送信内容が確定値となる。送信に含まれない既存カテゴリ・タグは残らない。 |
| 画像との整合性 | 追加・コピー・削除・並び順の各操作を反映後に永続化する。S3への保存と画像レコード登録は同一更新処理内で行う。 |
| 一覧・規格との整合性 | 一覧の表示値、規格単位の価格・在庫・状態との一致は本画面の責務外であり、商品検索一覧・M03-09を正とする。 |
| 支店連携との整合性 | 更新確定後に支店システムへ更新通知する。支店側への反映タイミングは支店連携機能の設計を正とする。 |

#### 入力項目
| 項目名 | 必須／任意 | 最大長 | 初期値 | 保存先・扱い |
|--------|------------|--------|--------|----------------|
| カード詳細情報 | 任意 | 整数（桁制約なし） | DB現行のカード詳細ID | `dtb_product`の（現行 `dtb_product_sub`）カード詳細参照。フォームキー`productSub[cardDetailId]`。隠しフィールドで保持し、指定時に該当カード詳細を商品付加情報へ設定する。 |
| 商品名 | 必須 | フォーム上限なし（`NotBlank`のみ。DB上限に依存） | DBの商品名 | 商品本体の商品名。フォームキー`product[name]`。 |
| 商品名(英) | 必須 | フォーム上限なし（`NotBlank`のみ） | DBの商品名（英） | `dtb_product`の（現行 `dtb_product_sub`）英語商品名。フォームキー`productSub[nameEn]`。 |
| 商品画像 | 任意 | 画像ファイル（複数可） | 登録済み画像のファイル名一覧 | コア商品画像テーブル。フォームキー`product[product_image]`（`mapped`偽）。追加・コピー・削除・並び順は隠しフィールド群（`add_images`/`copy_images`/`delete_images`/`rank_images`）で制御し、S3へ保存する。 |
| 商品説明 | 任意 | フォーム上限なし（DB text依存）。複数行入力 | DBの商品説明 | 商品本体の商品説明。フォームキー`product[description_detail]`。 |
| 商品説明(英) | 任意 | フォーム上限なし（DB依存）。複数行入力 | DBの英語商品説明 | `dtb_product`の（現行 `dtb_product_sub`）英語商品説明。フォームキー`productSub[descriptionDetailEn]`。 |
| 買取商品説明 | 任意 | フォーム上限なし（DB依存）。複数行入力 | DBの買取商品説明 | `dtb_product`の（現行 `dtb_product_sub`）買取商品説明。フォームキー`productSub[buyDescriptionDetail]`。 |
| 買取商品説明(英) | 任意 | フォーム上限なし（DB依存）。複数行入力 | DBの英語買取商品説明 | `dtb_product`の（現行 `dtb_product_sub`）英語買取商品説明。フォームキー`productSub[buyDescriptionDetailEn]`。 |
| 商品カテゴリ | 必須 | 複数選択（`NotBlank`） | DBの登録カテゴリ一覧 | コア商品カテゴリテーブル。フォームキー`product[Category]`（`mapped`偽）。送信内容で全置換する。 |
| タグ | 任意 | 複数選択 | DBの登録タグ一覧 | コア商品タグテーブル。フォームキー`product[Tag]`（`mapped`偽）。送信内容で全置換する。 |
| 略称タグ | 任意 | 単一選択 | DBの略称タグ | `dtb_product`の（現行 `dtb_product_sub`）略称タグ参照。フォームキー`productSub[storageCode]`。 |
| 売上分析タグ | 任意 | 複数選択 | DBの売上分析タグ一覧 | 商品と売上分析タグの関連。フォームキー`productSub[tagSalesAnalyses]`（`mapped`偽）。送信内容で置換する。 |
| 検索ワード | 任意 | フォーム上限なし（DB依存）。複数行入力 | DBの検索ワード | 商品本体の検索ワード。フォームキー`product[search_word]`。 |
| 購入グループ | 必須 | 単一選択 | DBの購入グループ | `dtb_product`の（現行 `dtb_product_sub`）購入グループ参照。フォームキー`productSub[sellGroup]`。 |
| サイズ | 必須 | 9桁、0以上999999999以下（`NotBlank`・`Length max 9`） | DBのサイズ | `dtb_product`の（現行 `dtb_product_sub`）サイズ。フォームキー`productSub[size]`。 |
| 重量 | 必須 | 9桁、0以上999999999以下（`NotBlank`・`Length max 9`） | DBの重量 | `dtb_product`の（現行 `dtb_product_sub`）重量。フォームキー`productSub[weight]`。 |
| 割引率 | 必須 | 単一選択（`NotBlank`） | DBの割引率 | `dtb_product`の（現行 `dtb_product_sub`）割引率参照。フォームキー`productSub[discount]`。未選択時は「割引率を選択してください」を表示する。 |
| 買取減額率 | 任意 | 単一選択 | DBの買取減額率 | `dtb_product`の（現行 `dtb_product_sub`）買取減額率参照。フォームキー`productSub[buyDiscount]`。未選択時は「買取減額率を選択してください」を表示する。 |
| 販売制限 | 必須 | 単一選択（ラジオ・`NotBlank`） | DBの販売制限 | `dtb_product`の（現行 `dtb_product_sub`）販売制限参照。フォームキー`productSub[regionRestriction]`。 |
| フリーエリア（サブ情報） | 任意 | フォーム上限なし（DB依存）。複数行入力（WYSIWYG） | DBのサブ情報 | 商品本体のサブ情報。フォームキー`product[free_area]`。 |
| 商品ステータス | 必須 | 単一選択（`NotBlank`） | DBの公開状態 | 商品本体の公開状態。フォームキー`product[Status]`。規格が無い間は欄を隠す。 |
| ショップ用メモ欄 | 任意 | フォーム上限なし（DB依存）。複数行入力 | DBのメモ | 商品本体のメモ（フォームラベルは「ショップ用メモ帳」。画面見出しは「ショップ用メモ欄」）。フォームキー`product[note]`。 |
最大長の桁数値はサイズ・重量がフォーム定義の`Length max 9`、商品コード等の規格側はM03-09を正とする。文字列項目はフォームに`Length`を持たない場合があり、その場合の上限はDBのカラム型に依存する。

### 権限・認可
| 利用者状態 | 商品編集画面のGET／POST |
|------------|--------------------------|
| 未ログイン | 管理画面共通のログイン誘導に従う。利用不可。 |
| 管理メンバーでログイン済み | アクセス制御リストがURLを許可するときのみ到達する。 |
| 権限のない主体 | 商品管理のアクセス制御に従い拒否される。 |
---
### セッション
商品編集画面では検索条件等の一覧状態を本機能から更新しない。成功フラッシュは管理画面共通の仕組みに依存する。商品検索に戻るリンクは検索一覧のページ番号セッションを参照する。
---
### Cookie
管理画面のセッションCookieのみを正とし、本機能用の追加Cookieは定義しない。
