## 用語

| 用語 | 説明 |
|------|------|
| イベント申込 | プレイヤーがイベント日程へ申し込んだ1件の申込。支払会員・支払方法・支払金額・申込状況を持つ。 |
| 申込CSV種別 | イベント申込の出力項目・並びを定義したCSV種別。本機能の出力項目はこの種別で決まる。 |
| 検索条件セッション | イベント申込一覧が保持する検索条件。CSV出力はこの条件を適用する。 |
| デッキ登録検索モード | 申込一覧の検索モードの一種。出力時は申込ではなくデッキ情報を起点に対象を取得する。 |

| 観点 | 内容 |
|------|------|
| 一覧表示とCSV | CSVは申込一覧の検索条件セッションを再適用するため、直前に一覧で確定した絞り込みと同じ母集合を対象とする。並び順のみ出力用に固定する。 |
| 論理削除データ | 会員・プレイヤーはソフトデリート無効化により論理削除済みでも出力対象に含める。これは画面一覧の表示条件と異なり得る。 |
| 出力中の更新 | ストリーミング出力中の他者更新は保証しない。出力開始時点のクエリ結果を正とする。 |
