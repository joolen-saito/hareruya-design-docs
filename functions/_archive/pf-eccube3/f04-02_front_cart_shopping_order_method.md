## 用語

| 受注情報 | 購入処理中の注文1件。注文確定前の処理中ステータスで作成する。 |

| ケース | 扱い |
|--------|------|
| 未ログインかつ非会員未登録 | ログイン画面へ誘導する。 |

### データ整合性
| 観点 | 内容 |
|------|------|
| カートと受注 | ロック済みカートから受注情報を作成し、注文確定でカートを空にする。 |
| 受注とセッション | 受注IDをセッションに保持し、各部分送信・確認で同一受注を参照する。 |
| お届け先選択 | セッションとCookieに直近のお届け先IDを保存し、お届け先選択入口で参照する。 |
| 合計再計算 | 配送業者・お支払い方法・ポイント・お届け先の変更ごとに合計を再計算して保存する。 |
| 確定後 | 注文確定で受注は確定し、購入完了処理（別機能）が当該受注を参照する。 |

#### 入力項目
| 項目名 | 必須／任意 | 最大長 | 初期値 | 保存先・扱い |
|--------|------------|--------|--------|----------------|
| お届け先 | 必須 | 選択（会員のアドレス帳から1件） | セッション・Cookieの直近選択、または受注の現配送先 | 配送先（`dtb_shipping`）へ反映。選択IDは`hareruya_ec.shopping.customer_address_id`（セッション）とお届け先IDのCookieに保存。 |
| 配送業者 | 必須 | 選択（お届け先地域などで変動） | 受注の現配送方法 | 配送方法を受注へ設定。配送料と合計を再計算する。 |
| 配送日時 | 任意 | 選択 | 未選択 | 配送指定として受注へ反映する。都道府県と配送方法から指定可能な時間帯を求める。 |
| お支払い方法 | 必須 | 選択（合計金額により変動） | 受注の現支払方法 | 受注の支払方法・手数料へ反映（`dtb_order`）。無効選択時は未設定・手数料0。 |
| ポイント利用有無 | 任意 | チェック | なし | ポイント使用量の登録に用いる。論理キー `pointpay`。 |
| 利用ポイント数 | 任意 | 数値 | 0 | ポイント利用ありのとき使用量として登録する。論理キー `pointpay_num`。合計を再計算する。 |
| 要望欄 | 任意 | メッセージ欄（実装上の上限はフォーム種別に依存） | 空 | 受注のメッセージへ保存（`dtb_order`）。論理キー `message`。 |
最大長の具体値はフォーム種別と`constant.yml.dist`等の確認値を正とする。お届け先・配送業者・お支払い方法は選択肢であり、選択肢の母集合は受注の地域・金額条件で変わる。

### ログ・監査
| タイミング | 記録内容 |
|------------|----------|
| 購入処理開始・完了 | 受注IDの情報ログ。 |
| 配送業者・お支払い方法の変更開始・完了 | 受注IDや支払IDの情報ログ。 |

| カート異常・受注情報なし・購入エラー | エラー内容の情報・エラーログ。 |
#### ログに出してはいけないもの
- 決済の機微情報
- なりすまし対策トークン
- Cookie値
- セッションIDの完全値

### 権限・認可
| 利用者状態 | ご注文方法指定 |
|------------|----------------|
| 未ログインかつ非会員未登録 | ログイン画面へ誘導する。 |
| 非会員登録済み | 受注情報を作成し、購入手続きを進められる。 |
| 会員ログイン | ログイン顧客で受注情報を作成し、お届け先一覧から選択できる。 |
ゲスト購入（非会員）の可否は購入手続き内のログイン・非会員入口の設定に従う。本書はその認証仕様を正としない。

### セッション
#### 本機能におけるセッション
| 観点 | 内容 |
|------|------|
| 表示ロケール | ご注文方法指定表示時に保存し、注文確定時に復元する。 |
| 受注ID | 受注作成・取得時に保存し、各部分送信・確認で参照する。 |
| 複数配送案内 | 案内を一度だけ表示するためのフラグを保存する。 |
| お届け先ID | お届け先選択時に保存し、次回表示で参照する。 |
| 非会員情報 | 非会員購入のための情報をセッションに保持する。 |
#### セッションへ保存しない情報
決済の機微情報はセッションへ保存しない。
