## 用語

| 用語 | 説明 |
|------|------|
| 会員マスター | 会員一覧の画面。検索条件と検索結果一覧で構成する。 |
| フリーワード | 会員ID・メールアドレス・お名前を横断して検索する一行入力。 |
| 検索パターン | 検索条件を名前を付けて保存し、後で再利用できる仕組み。会員用は表示キー`customer`で区別する。 |
| 本人確認ステータス | 会員（選手情報）の本人確認の状態。未確認・確認中・確認済み・簡易書留確認済みのいずれか。 |
| DCI関連情報 | MTG Companion登録本名・DCIナンバー・DCI確認フラグ。会員一覧の絞り込みに使う。 |

## 0203に無い定型節（設計書からは削除・2026-08-19）

#### エッジケース
| ケース | 扱い |
|--------|------|
| 検索結果0件 | 「検索条件に該当するデータがありませんでした。」を表示する。 |
| 初回表示でセッション条件なし | 一覧は表示しない（空）。検索条件入力後に検索する。 |
| 表示件数に不正値 | 表示件数マスターに無い値は採用せず、既定または保持値を使う。 |
| 検索パターン名が空で保存 | エラーを表示し保存しない。 |
| 存在しない検索パターンを適用 | ページが見つからない扱い（404）。 |
| MTG Companion登録本名に空白あり | 検索時に空白を除去して条件にする。 |
---
### データ整合性
| 観点 | 内容 |
|------|------|
| 参照時点 | 一覧はリクエスト時点の永続化済み会員を読む。表示後に会員が更新されても自動更新しない。 |
| 件数と一覧 | 該当件数とページ内行はクエリ結果に基づく。会員編集・削除後はセッションのページ番号と再開指定で一覧へ戻り得る。 |
| 検索条件の引き継ぎ | 会員ホームのショップ状況から本会員条件で遷移した場合、その条件を会員検索用セッションに保存して一覧を開く（ホームショップ状況機能を正とする）。 |

## 0203に無い定型節（設計書からは削除・2026-08-19）

#### 入力項目
| 項目名 | 必須／任意 | 最大長 | 初期値 | 保存先・扱い |
|--------|------------|--------|--------|----------------|
| 会員ID・メールアドレス・お名前 | 任意 | 255文字 | 未入力 | 会員検索条件のフリーワード（フォームキー`multi`）。会員検索クエリへ反映する。永続化しない。Excel基本設計とec-cube-enterpriseの`eccube_stext_len`が一致する。 |
| 会員種別 | 任意 | 選択（複数可） | 未選択 | フォームキー`customer_status`。会員ステータスで絞り込む。 |
| 性別 | 任意 | 選択 | 未選択 | フォームキー`sex`。 |
| 誕生月 | 任意 | 選択 | 未選択 | フォームキー`birth_month`。 |
| 誕生日 | 任意 | 日付範囲（開始・終了） | 未入力 | フォームキー`birth_start`・`birth_end`。 |
| 国 | 任意 | 選択 | 未選択 | フォームキー`country`（プラグイン拡張、国名昇順）。 |
| 都道府県 | 任意 | 選択（複数可） | 未選択 | フォームキー`prefMulti`（プラグイン拡張、複数選択）。 |
| 電話番号 | 任意 | コアの会員検索フォームに準ずる | 未入力 | フォームキー`tel`。 |
| 登録日 | 任意 | 日付範囲（開始・終了） | 未入力 | フォームキー`create_date_start`・`create_date_end`。 |
| 更新日 | 任意 | 日付範囲（開始・終了） | 未入力 | フォームキー`update_date_start`・`update_date_end`。 |
| 購入金額 | 任意 | 数値範囲（開始・終了） | 未入力 | フォームキー`buy_total_start`・`buy_total_end`。 |
| 購入回数 | 任意 | 数値範囲（開始・終了） | 未入力 | フォームキー`buy_times_start`・`buy_times_end`。 |
| 購入商品名・コード | 任意 | コアの会員検索フォームに準ずる | 未入力 | フォームキー`buy_product_code`。 |
| 最終購入日 | 任意 | 日付範囲（開始・終了） | 未入力 | フォームキー`last_buy_start`・`last_buy_end`。 |
| 買取総額 | 任意 | 整数（最小1）。数字のみ | 未入力 | フォームキー`sellTotalStart`・`sellTotalEnd`（プラグイン拡張、`mapped`偽、検索拡張で評価）。 |
| 買取件数 | 任意 | 整数（最小1）。数字のみ | 未入力 | フォームキー`sellTimesStart`・`sellTimesEnd`（プラグイン拡張、`mapped`偽）。 |
| DCIナンバー | 任意 | 16 文字。数字のみ | 未入力 | フォームキー`dciNo`（プラグイン拡張、`mapped`偽）。 |
| MTG Companion登録本名 | 任意 | 64 文字。半角英字と半角空白のみ（検索時に空白除去） | 未入力 | フォームキー`dciName`（プラグイン拡張、`mapped`偽）。 |
| DCI確認フラグ | 任意 | チェック（複数可） | 未選択 | フォームキー`dciConfirmFlg`（プラグイン拡張、DCI確認マスタ、`mapped`偽）。 |
| 本人確認ステータス | 任意 | チェック（複数可） | 未選択 | フォームキー`identityConfirmStatus`（プラグイン拡張、本人確認ステータスマスタ）。 |
| 退会区分 | 任意 | 256文字 | 未入力 | フォームキー`close_reason`。`dtb_customer.close_reason`を部分一致検索する。Excel基本設計、フォーム制約、DB列長がいずれも256文字で一致する。 |
| 検索パターン名 | 必須（検索パターン保存時。通常検索時は未入力可） | コア標準テキスト | 未入力 | フォームキー`pattern_name`。検索パターン保存時のみ使用。空のとき保存はエラー。Excelの必須指定は保存操作時の条件付き必須を表す。 |
| 検索パターン（保存済み） | 任意 | 選択 | 未選択 | フォームキー`search_patterns`（表示キー`customer`のパターン）。 |
最大長の文字数はフォーム拡張の確認値とする。範囲条件は開始と終了で1条件を構成する。買取総額・買取件数・DCIナンバー・登録本名は`mapped`偽で検索拡張側が条件に変換する。

### ログ・監査
| タイミング | 記録内容 |
|------------|----------|
| 検索・一覧表示 | 本機能では業務監査ログを追加で書かない。 |
#### ログに出してはいけないもの
- 会員のメールアドレス・電話番号・住所等の個人情報
- なりすまし対策トークン
- Cookie値・セッションIDの完全値
---
### 権限・認可
| 利用者状態 | 会員マスター |
|------------|--------------|
| 未ログイン管理者 | アクセス不可。 |
| ログイン済み管理者 | 検索・一覧閲覧、各操作導線の利用が可能。アクセス制御リストが許可する範囲に従う。 |
一覧から遷移する編集・削除・メール通知・本人確認等の可否は各機能の権限設計に従う。
---
### セッション
#### 本機能におけるセッション
| 観点 | 内容 |
|------|------|
| 検索実行時 | 会員検索用の検索条件・ページ番号・表示件数を保存する。 |
| 初期表示（条件なし・再開なし） | 会員検索用セッションを削除する。 |
| 検索パターン適用時 | 復元した検索条件をセッションへ保存する。 |
セッションキーの正確な文字列は実装（コアの会員検索キー`eccube.admin.customer.search`系）を確認値とする。
