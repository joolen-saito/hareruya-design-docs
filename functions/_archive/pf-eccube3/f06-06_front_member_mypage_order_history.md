## 用語

| 用語 | 説明 |
|------|------|
| 会員 | フロントにログインしている顧客。 |
| 注文 | 会員の購入1件に対応する。一覧の1行に対応する。 |
| 処理状態 | 注文の処理状態（注文ステータス）。一覧では状態に応じた画像で表す。 |
| 注文番号 | 注文を識別する表示用番号。詳細遷移のリンクに用いる。 |
| 再購入 | 過去の注文内容を再びカートへ投入する操作。 |

## 0203に無い定型節（設計書からは削除・2026-08-19）

#### エッジケース
| ケース | 扱い |
|--------|------|
| 注文が0件 | 件数0として一覧を空表示する。 |
| 処理中の注文のみ | 処理中を除外するため一覧に表示しない。 |
| 再購入で注文IDが無い | 不正要求（HTTP404）とする。 |
| 再購入で他会員の注文IDを指定 | 当該会員の注文として特定できず不正要求（HTTP404）とする。 |
| 未ログイン | 会員ログインへ誘導する。 |
---
### データ整合性
| 観点 | 内容 |
|------|------|
| 一覧対象会員 | 一覧は当該会員の注文のみを参照する。 |
| 一覧と詳細 | 注文番号リンクから遷移する詳細は同一注文を表示する。詳細の表示内容は購入履歴詳細機能を正とする。 |
| 処理中注文 | 処理中の注文は一覧に出さない。確定済みの注文のみを履歴として扱う。 |
| 再購入 | 再購入は注文時点の明細を基にカート投入内容を返す。在庫・価格の最新反映はカート・購入機能を正とする。 |

## 0203に無い定型節（設計書からは削除・2026-08-19）

### ログ・監査
本機能は固有の監査ログを主目的としない。
### 権限・認可
| 利用者状態 | 購入履歴一覧 | 再購入 |
|------------|--------------|--------|
| 未ログイン | アクセス不可（会員ログインへ誘導） | 不正要求（HTTP404相当） |
| ログイン済み会員 | 自分の注文のみ閲覧可能 | 自分の注文のみ再購入可能 |
