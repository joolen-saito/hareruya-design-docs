## 用語

| 用語 | 説明 |
|------|------|
| 商品規格 | 1商品の中の、言語と状態（カード状態）の組み合わせ単位の販売明細。価格・在庫・コード・画像などを持つ。 |
| 言語 | 規格を識別する言語区分。新規登録時は選択でき、編集時は変更しない読み取り表示になる。 |
| 状態 | カードの状態区分。新規登録時は選択でき、編集時は変更しない読み取り表示になる。 |
| 在庫変動区分 | 在庫数を変更した理由の区分。在庫数が変わったときに在庫履歴へ記録する。 |
| 在庫予約数 | 段階的な在庫の予約数量。入荷区分・マスタ更新区分での在庫増加時に増分を各予約数へ加算する。 |
| 代表画像 | 規格に紐づける商品画像。商品本体に登録済みの画像から選択する。 |
| 高額商品 | 価格変更CSVの取込対象外となる高額商品。本画面では高額商品コード欄で扱う。 |

## 0203に無い定型節（設計書からは削除・2026-08-19）

#### エッジケース
| ケース | 扱い |
|--------|------|
| 在庫数も在庫無制限も未設定 | 検証エラー「在庫数を入力、もしくは在庫無制限を設定してください。」を表示する。 |
| 在庫数を変更しない | 在庫履歴を記録しない。 |
| 価格を変更しない | 価格履歴を記録しない。 |
| 在庫を0から正数へ増やす | 入荷通知メールを送る。 |
| 最後の1規格を削除 | 不正要求（HTTP400）。 |
| 入荷・マスタ更新で在庫増加 | 増分を各段階の在庫予約数へ加算する。 |
---
### データ整合性
| 観点 | 内容 |
|------|------|
| 参照時点 | 編集画面表示時にDBから読み取った規格の現行値を初期表示する。 |
| 在庫レコードとの整合性 | 更新時に規格の在庫数を在庫レコードへ反映する。 |
| 履歴との整合性 | 在庫・価格の変更があった場合のみ各履歴を記録する。変更なしでは履歴を作らない。 |
| 代表画像との整合性 | 既存の画像関連を削除してから送信内容で作り直す。送信に含まれない画像は関連から外れる。 |
| 支店連携との整合性 | 更新確定後に支店へ在庫・商品更新を通知する。反映タイミングは支店連携機能の設計を正とする。 |
| CSVとの整合性 | 価格変更CSV取込（M03-31）による更新と本画面の更新は別経路であり、最後に確定した内容が現行値となる。 |

#### 入力項目
| 項目名 | 必須／任意 | 最大長 | 初期値 | 保存先・扱い |
|--------|------------|--------|--------|----------------|
| 言語 | 必須（新規のみ選択） | 単一選択 | 新規は未選択、編集は現行の言語 | `dtb_product_class`（現行は補助表 `dtb_product_sub_class`）の言語参照。フォームキー`productSubClass[language]`。編集時は読み取り表示し隠しフィールドで保持。 |
| 状態 | 必須（新規のみ選択） | 単一選択 | 新規は未選択、編集は現行の状態 | `dtb_product_class`（現行は補助表 `dtb_product_sub_class`）の状態参照。フォームキー`productSubClass[cardCondition]`。編集時は読み取り表示し隠しフィールドで保持。 |
| 商品コード | 任意 | フォーム上限なし（DB依存） | 新規は空、編集はDBの商品コード | `dtb_product_class`の商品コード。フォームキー`productClass[code]`。 |
| 在庫数 | 任意（在庫数か在庫無制限のいずれか必須） | 数値（正の整数。`Regex`数値） | 新規は0、編集はDBの在庫数 | `dtb_product_class`の在庫数。フォームキー`productClass[stock]`。在庫数も在庫無制限も未設定なら「在庫数を入力、もしくは在庫無制限を設定してください。」を表示。 |
| 販売制限数 | 任意 | 10桁、1以上（`Length max 10`・`GreaterThanOrEqual 1`・`Regex`数値） | 新規は空、編集はDBの販売制限数 | `dtb_product_class`の販売制限数。フォームキー`productClass[sale_limit]`。 |
| 在庫変動区分 | 必須 | 単一選択 | 既定の区分 | 在庫履歴記録に用いる。フォームキー`stock_change_type_id`。 |
| 在庫変動理由 | 任意 | フォーム上限なし（DB依存） | 空 | 在庫履歴のメモ。フォームキー`stock_change_memo`。 |
| 販売価格 | 必須 | 10桁（`NotBlank`・`Length max 10`・`Regex`数値） | 新規は空、編集はDBの販売価格 | `dtb_product_class`の販売価格（`price02`）。フォームキー`productClass[price02]`。 |
| 買取価格 | 必須 | 9桁（`NotBlank`・`Length max 9`・`Regex`数値。桁区切り入力欄） | 新規は空、編集はDBの買取価格 | `dtb_product_class`（現行は補助表 `dtb_product_sub_class`）の買取価格。フォームキー`productSubClass[buyPrice]`。 |
| 代表画像 | 必須 | 複数選択 | 編集時は現行の代表画像 | 規格と商品画像の関連。フォームキー`productSubClass[productSubClassImages]`（`mapped`偽）。送信内容で関連を作り直す。 |
| 帯URL | 任意 | フォーム上限なし（DB依存） | DBの帯URL | `dtb_product_class`（現行は補助表 `dtb_product_sub_class`）の帯URL。フォームキー`productSubClass[beltUrl]`。 |
| セールフラグ | 任意 | チェック（論理値） | DBのセールフラグ | `dtb_product_class`（現行は補助表 `dtb_product_sub_class`）のセールフラグ。フォームキー`productSubClass[saleFlg]`。 |
| 高額商品コード | 任意 | フォーム上限なし（DB依存） | DBの高額商品コード | `dtb_product_class`（現行は補助表 `dtb_product_sub_class`）の高額商品コード。フォームキー`productSubClass[highPriceCode]`。 |
| 下代 | 任意 | 9桁（`Length max 9`・`Regex`数値。桁区切り入力欄） | DBの下代 | `dtb_product_class`（現行は補助表 `dtb_product_sub_class`）の下代（卸価格）。フォームキー`productSubClass[wholesalePrice]`。 |
| 備考 | 任意 | フォーム上限なし（DB依存） | DBの備考 | `dtb_product_class`（現行は補助表 `dtb_product_sub_class`）の備考。フォームキー`productSubClass[memo]`。 |
| 部門 | 必須 | 単一選択（未選択の選択肢あり） | DBの部門 | `dtb_product_class`（現行は補助表 `dtb_product_sub_class`）の部門参照。フォームキー`productSubClass[section]`。 |
| 棚番号 | 必須 | 単一選択（未選択の選択肢あり） | DBの棚番号 | `dtb_product_class`（現行は補助表 `dtb_product_sub_class`）の棚番号参照。フォームキー`productSubClass[shelfNumber]`。 |
買取価格・下代の最大桁はプラグイン設定（`product_sub_class.length.buy_price` 確認値9）に従う。販売価格・販売制限数の桁はコア規格フォームの`Length max 10`を確認値とする。文字列項目はフォームに`Length`を持たないため、上限はDBのカラム型に依存する。

### 権限・認可
| 利用者状態 | 規格の登録・編集のGET／POST |
|------------|------------------------------|
| 未ログイン | 管理画面共通のログイン誘導に従う。利用不可。 |

### セッション
本機能では検索条件等の一覧状態を更新しない。成功・エラーフラッシュは管理画面共通の仕組みに依存する。
---
### Cookie
管理画面のセッションCookieのみを正とし、本機能用の追加Cookieは定義しない。
