## 0203に無い定型節（設計書からは削除・2026-08-19）

#### エッジケース
| ケース | 扱い |
|--------|------|
| 編集でパスワード欄を変更しない | 既定パスワードのままなら既存パスワードを維持する。 |
| 新規登録 | 会員と会員住所を同時に生成し、シークレットキー・ソルトを採番する。 |
| 確認済み会員の本人確認用情報を変更 | 画面側の確認ダイアログで続行すると本人確認ステータスを未確認へ書き換えて送信する。 |
| 存在しない会員IDで編集 | ページが見つからない扱い（404）。 |
| 住所1・住所2がSJIS換算で上限超過 | 該当欄に超過エラーを付ける。 |
---
### データ整合性
| 観点 | 内容 |
|------|------|
| 会員と会員住所 | 新規登録時、会員情報を写した会員住所を同時に保存する。以後の配送先の追加・編集は配送先機能を正とする。 |
| パスワード | 既定パスワードと一致するかで再暗号化の要否を判定する。原値は保持・表示しない。 |
| 本人確認ステータス | 画面側で未確認へ降格する判定は確認済み・簡易書留確認済みの会員に限る。確認済への変更はM08-10を正とする。 |
| 購入履歴・買取履歴 | 編集画面の履歴は表示時点の永続化済みデータを各100件まで読む。 |
