## 用語

| 用語 | 説明 |
|------|------|
| イベント | 大会の親情報。店舗・会場・フォーマット・定員・参加費・賞品・備考などを持つ。 |
| イベント詳細 | イベントの開催日程1件。詳細画面はイベント詳細IDで参照する。 |
| 事前予約 | オンライン申込。事前予約期間内かつ定員未満で申込可能となる。 |
| 残り予約数 | 定員から申込済み人数を引き、チーム人数で割った値。事前予約参加可能な枠数を示す。 |
| 選手情報 | 会員に紐づく拡張情報。デッキ登録状況・申込状況の判定に用いる。 |

#### エッジケース
| ケース | 扱い |
|--------|------|
| イベント詳細IDが存在しない | ページが見つからない（HTTP404）として扱う。 |
| 未ログインで詳細を開く | 開催情報を表示する。申込済み判定は偽となり、申込可能なら申込ボタンを表示する。 |
| 定員に達している | 申込可能の条件を満たさず、申込ボタン領域を表示しない。デッキ登録可能ならデッキ登録ボタンのみ表示する。 |
| 事前予約期限後 | 残り予約数を表示しない。申込可能の条件も満たさない。 |
| デッキ登録済み | デッキ登録ボタンをデッキ編集として表示する。 |
| バナー画像が未設定 | バナー画像を表示しない。 |

### データ整合性
| 観点 | 内容 |
|------|------|
| 参照時点 | 表示は要求時点で取得した詳細・親イベント・申込済み人数に基づく。表示後の申込・取消は自動反映しない。 |
| 申込可否と申込画面 | 詳細画面で申込可能でも、申込画面（F07-04）側で受付期間・定員・重複申込を再判定する。詳細表示時点と申込実行時点の差は申込側を正とする。 |
| 残り予約数 | 表示時点の申込済み人数に基づく概算であり、申込確定時の在庫を保証しない。 |

### 権限・認可
| 利用者状態 | イベント詳細表示 | 申込ボタン | キャンセル申込・デッキ登録 |
|------------|------------------|------------|----------------------------|
| 未ログイン | 閲覧できる | 申込可能なら表示するが、申込実行は別機能の認可に従う | 申込済み判定が偽のためキャンセル申込は出ない。デッキ登録は可否条件のみで判定する |
| ログイン済み会員 | 閲覧できる | 申込可能かつ未申込なら表示する | 申込済みならキャンセル申込、デッキ登録可能ならデッキ登録・編集を表示する |
詳細表示は会員ログインを要しない公開画面である。申込・キャンセル申込・デッキ登録の認可は各遷移先機能を正とする。
