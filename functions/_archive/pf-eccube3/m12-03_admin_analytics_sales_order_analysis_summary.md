## 用語

| 用語 | 説明 |
|------|------|
| 集計日 | 集計対象の期間（開始・終了）。どの日付列で絞り込むかは使用日付による。 |
| 使用日付 | 集計日の絞り込みに使う日付列。注文日・注文確定日・入金日・出荷日・売上確定日・キャンセル日から選ぶ。 |
| 集計単位 | 集計の軸。商品・カテゴリ・支払方法・購入グループ・都道府県・性別・利用端末・年代（会員）から選ぶ。指定なしも可。 |
| 検索条件セッション | 集計実行時に検索条件を保存するセッション領域。CSVダウンロードが同じ条件で集計するために参照する。 |

## 0203に無い定型節（設計書からは削除・2026-08-19）

#### エッジケース
| ケース | 扱い |
|--------|------|
| 集計対象が0件 | 該当データが無い旨の見出しを表示する。 |
| 集計単位が指定なし | グループ化を行わず、集計単位の見出し・キーを設定しない。 |
| 合計が0 | 各割合を0とする。 |
| 使用日付がキャンセル日 | キャンセル注文を除外する結合を行わない。 |
---
### データ整合性
| 観点 | 内容 |
|------|------|
| 参照時点 | 集計結果は検索実行時にデータベースから読み取った値である。表示後の更新は自動反映しない。 |
| CSVとの整合性 | 集計実行で検索条件をセッションへ保存する。CSVダウンロードは同じセッションの検索条件で再集計する。ただしCSVは表示件数の上限を適用しない点が異なる。 |
| 一覧と合計の整合性 | 合計行は表示中（表示件数上限内）の集計結果を合算した値である。 |
| 更新との整合性 | 本機能は参照のみで台帳を更新しない。 |

#### 入力項目
| 項目名 | 必須／任意 | 最大長 | 初期値 | 保存先・扱い |
|--------|------------|--------|--------|----------------|
| 汎用ワード | 任意 | フォーム上限なし | 空 | フォームキー `multi`。商品名日/英・カード名・商品コード等の部分一致絞り込み。検索条件セッションへ保存。 |
| 集計日From | 任意 | 日時 | 当月初日 | フォームキー `date_from`。使用日付で選んだ列の下限。 |
| 集計日To | 任意 | 日時 | 当月末日（初期値は翌月初日相当） | フォームキー `date_to`。使用日付で選んだ列の上限（未満）。 |
| 使用日付 | 必須 | — | 注文日 | フォームキー `date_type`。注文日/注文確定日/入金日/出荷日/売上確定日/キャンセル日。 |
| 集計単位 | 任意 | — | 商品 | フォームキー `summary_type`。商品/カテゴリ/支払方法/購入グループ/都道府県/性別/利用端末/年代（会員）。指定なし可。 |
| 並べ替え | 必須 | — | 集計単位 | フォームキー `sort`。集計単位/注文数/金額/販売数。 |
| 昇順/降順 | 必須 | — | 昇順 | フォームキー `asc_desc`。`asc`/`desc`。 |
| 表示件数 | 必須 | — | ページ表示件数マスタの値 | フォームキー `limit`。一覧の最大件数。 |
| カテゴリ | 任意 | — | 未選択 | 商品検索フォーム配下の`category_id`。自身と子孫カテゴリで絞り込む。 |
| 都道府県 | 任意 | — | 未選択 | 会員検索フォーム配下の`pref`。 |
| 性別 | 任意 | — | 未選択 | 会員検索フォーム配下の`sex`。複数選択。 |
| 誕生日From・To | 任意 | 日付 | 空 | フォームキー `birth_from`・`birth_to`。注文の誕生日で絞り込む。 |
| 利用端末 | 任意 | — | 未選択 | フォームキー `device_type`。複数選択。 |
| 売上分析タグ | 任意 | — | 未選択 | フォームキー `tagSalesAnalyses`。複数選択。明細のタグで絞り込む。 |
| カードセット | 任意 | — | 未選択 | フォームキー `cardsets`。複数選択。 |
| 平均単価From・To | 任意 | 数値 | 空 | フォームキー `price_from`・`price_to`。集計後の平均単価（HAVING）で絞り込む。 |
| 数量From・To | 任意 | 数値 | 空 | フォームキー `sales_from`・`sales_to`。集計後の数量（HAVING）で絞り込む。 |
| 状態 | 任意 | — | 未選択 | フォームキー `card_condition`。複数選択。規格の状態で絞り込む。 |
本フォームはなりすまし対策トークンを使わない（`csrf_protection`を無効化）。
