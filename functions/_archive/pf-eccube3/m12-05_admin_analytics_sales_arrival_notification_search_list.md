## 0203に無い定型節（設計書からは削除・2026-08-19）

#### エッジケース
| ケース | 扱い |
|--------|------|
| 検索結果が0件 | 該当データが無い旨の見出しを表示する。 |
| 通知設定が削除済みの依頼 | 論理削除フィルタを無効化するため抽出対象に含める。 |
| 購入実績が無い依頼 | 購入日列は空となる。未購入のみ選択時に抽出される。 |
| 通知設定削除日が未設定 | 通知日/通知設定削除日列は空。行操作に削除を表示する。 |
---
### データ整合性
| 観点 | 内容 |
|------|------|
| 参照時点 | 一覧は検索実行時にデータベースから読み取った値である。表示後の更新は自動反映しない。 |
| 論理削除フィルタ | 検索時に論理削除フィルタを無効化する。同一リクエスト内のその後の処理での扱いは共通機能の設計を正とする。 |
| CSVとの整合性 | 検索実行で検索条件をセッションへ保存する。CSVダウンロードは同じセッションの検索条件で再抽出する。 |
| 更新との整合性 | 本機能は参照のみで台帳を更新しない。削除・規格編集は遷移先機能の範囲とする。 |
