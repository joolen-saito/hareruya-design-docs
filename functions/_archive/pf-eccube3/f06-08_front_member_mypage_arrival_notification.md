| 用語 | 説明 |
|------|------|
| 会員 | フロントにログインしている顧客。 |

| 言語 | 商品の言語区分。商品規格に含まれる。 |

## 0203に無い定型節（設計書からは削除・2026-08-19）

#### エッジケース
| ケース | 扱い |
|--------|------|
| 入荷通知依頼が0件 | 入荷待ち商品が無い旨を表示する。 |
| 同一商品で言語・価格区分が異なる | 集約キーが異なるため別のまとまりとして表示する。 |
| 高額コードを持つ商品規格 | 商品詳細リンクに規格を含めて遷移する。 |
| 未ログイン | 会員ログインへ誘導する。 |
---
### データ整合性
| 観点 | 内容 |
|------|------|
| 一覧対象会員 | 一覧は当該会員の選手情報に紐づく入荷通知依頼のみを参照する。 |
| 商品情報 | 商品名・状態・言語・価格は表示時点の商品・商品クラス・状態・言語マスタを参照する。 |
| 通知 | 入荷時の通知送信は別機能で行う。一覧は登録済みの依頼を参照するのみとする。 |
