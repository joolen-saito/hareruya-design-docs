## 用語

| 用語 | 説明 |
|------|------|
| 店舗 | イベントを開催する晴れる屋の店舗。TOPは1店舗を選択して表示する。 |
| イベント | 大会の親情報。店舗・会場・フォーマット・定員・参加費などを持つ。 |
| イベント詳細 | イベントの開催日程1件。同一イベントが複数の開催日を持つことがある。 |
| 月間表示 | 選択中の店舗・選択中の月（`Ym`）に開催日が含まれるイベント詳細の集合。 |
| 複数日程イベント | 同一日に同一イベントの日程が2件以上あるもの。日別画面へ誘導する。 |
| TOP判定 | クエリの`shop`・`date`がいずれも無い初回アクセスかどうかの判定。画面タイトル等の出し分けに用いる。 |

## 0203に無い定型節（設計書からは削除・2026-08-19）

#### エッジケース
| ケース | 扱い |
|--------|------|
| 店舗IDが存在しない | ページが見つからない（HTTP404）として扱う。 |
| 当月にイベントが0件 | カレンダーは表示し、日付リストにイベントを表示しない。 |
| 日別表示で該当1件 | その詳細画面（F07-03）へリダイレクトする。 |
| 日別表示で該当0件 | 当該イベントの最新日程の詳細画面へリダイレクトする。最新日程も無ければHTTP404。 |
| 日別の`eventDate`が不正 | `Ymd`でも`all`でもなければHTTP404とする。 |
| 同一日・同一イベントが複数 | 複数日程として束ね、日別画面へ誘導する。 |
---
### データ整合性
| 観点 | 内容 |
|------|------|
| 参照時点 | 月間表示は要求時点で取得したイベント詳細・祝日に基づく。表示後の更新は自動反映しない。 |
| キャッシュ | 月間表示は店舗ごとのキーで一定時間キャッシュされ、有効期間内はキャッシュ時点の集合を返すことがある。 |
| 詳細・日別との整合 | TOPから遷移した詳細（F07-03）・日別画面は遷移先の取得結果を正とする。TOPの表示と遷移後の内容の完全一致は保証しない。 |
| 店舗切替とクッキー | クッキー`shop`は最後にクエリ指定した店舗を保持する。クッキーと表示店舗の一致は次回以降のTOPアクセスで反映する。 |

- セッションIDの完全値
---
### 権限・認可
| 利用者状態 | イベント大会TOP・日別表示 |
|------------|---------------------------|
| 未ログイン | 閲覧できる。会員専用の表示（選手情報）は付かない。 |
| ログイン済み会員 | 閲覧できる。日別表示では選手情報を画面へ渡す。 |
TOP・日別表示は会員ログインを要しない公開画面である。申込（F07-04）の権限は別機能を正とする。
---
### セッション
本機能はTOP・日別表示のためにセッションを更新しない。表示店舗の保持はセッションではなくクッキー`shop`で行う。
---
### Cookie
#### イベント大会TOPのクッキー
| 項目 | 内容 |
|------|------|
| クッキー名 | `shop`（確認値）。表示店舗IDを保持する。 |
| 更新条件 | クエリで店舗が指定され、現在のクッキー値と異なる場合に更新する。クエリ指定が無いときは更新しない。 |
| 既定 | クエリ・クッキーともに無ければ既定店舗（ID＝1）を表示する。 |
クッキーの属性・有効期間の正確な値は実装を確認値とする。
