### 明細の並び
明細は次の順で並べる。上の条件が同じときだけ、下の条件で比べる。
| 順 | 並べる条件 | 向き |
| --- | --- | --- |
| 1 | カード情報を持つかどうか | 持つものが先 |
| 2 | 棚番号の並び順 | 昇順 |
| 3 | 言語 | 昇順 |
| 4 | 状態 | 昇順 |
| 5 | Foil | 昇順。Foilの指定が無い明細は `0` として扱う |
| 6 | 略称の並び順 | 昇順 |
| 7 | レアリティを持つかどうか | 持つものが先 |
| 8 | レアリティ | 降順。レアと神話レアは同じ順位として扱う |
| 9 | 色 | 昇順。色の指定が無い明細は `0` として扱う |
| 10 | カード番号を持つかどうか | 持つものが先。略称に英字並びの指定があるとき、カード番号が空のときは持たない扱いとする |
| 11 | カード番号 | 昇順。略称に英字並びの指定があるときは `0` として扱う |
| 12 | 英字表記 | 昇順。略称に英字並びの指定が無いときは `zzz` として扱う |
| 13 | カードNo. | 昇順 |
