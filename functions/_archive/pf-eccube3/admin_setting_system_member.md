## 用語

| 用語 | 説明 |
|------|------|
| メンバー | 管理画面へログインするアカウント。`dtb_member` に保存される。フロントの会員（顧客）とは別物である。 |
| 表示順 | `dtb_member.sort_no` によるメンバー一覧の表示順。一覧は `sort_no` の降順で並べ、値が大きい行が先頭に来る。 |
| 稼働 | `mtb_work` のマスタ項目。ログイン可否の判定に利用される値（`Work::WORK_ACTIVE_ID`）がコアに定義されている。一覧ではマスタ名称を「稼働」列に表示する。 |
| 権限 | `mtb_authority` のマスタ項目。パス単位の拒否リストと組み合わせて管理画面のアクセスを制御する（詳細は権限管理機能を正とする）。 |
| 所属店舗 | メンバーの所属店舗。登録・編集画面では単一選択で指定する。 |
| デフォルト検索表示店舗 | 店舗絞り込みを持つ検索一覧画面で、当該メンバーの初期絞り込みとして利用する店舗。 |
| 編集可能店舗 | 在庫・受注・店頭買取・イベントのデータを編集できる店舗範囲。複数店舗を選択できる。 |
| 自動ログアウト設定 | ログイン後に無操作状態が続いた場合、時間経過で自動ログアウトさせるためのメンバー単位設定。制限時間は追加システム設定で管理する。 |
| スマレジ用アカウント | スマレジ連携時の更新ユーザーとして利用する管理者アカウントを識別する設定。 |
| 削除 | `dtb_member` の行を削除し、削除対象より大きい `sort_no` の行を繰り下げる。 |

## 保存処理（リポジトリ）の成否

| 順序 | 判定 | 結果 |
|------|------|------|
| 1 | 新規登録時、最大 `sort_no` + 1 を設定し、パスワードをハッシュ化して `dtb_member` を保存する | 例外なく完了すればコミット。例外時はロールバックし、呼び出し元でエラーメッセージを表示する。 |
| 2 | 編集時、パスワードが既定プレースホルダと異なる場合のみ再ハッシュし、`dtb_member` と編集可能店舗を保存する | 例外なく完了すればコミット。例外時はロールバックし、呼び出し元でエラーメッセージを表示する。 |
| 3 | 上へ・下へで隣接 `sort_no` 行が見つからない | 例外となり、呼び出し元でエラーメッセージを表示する。 |

一覧や編集画面のメッセージは、上表の true/false と、フォーム検証・CSRF の結果に応じて積まれる。

#### エッジケース
| ケース | 扱い |
|--------|------|
| 編集でパスワードを `default_password` のまま送信 | 退避した暗号化パスワードをそのまま保存する。ソルトの新規生成と再ハッシュは行わない。 |
| 新規でログインIDが既存と重複 | フォーム検証でエラーとなり保存処理へ進まない。 |
| 編集権限を保持しないメンバー | 登録・編集はできない。画面上では登録ボタンを押せない状態とする。 |
| 削除後の一覧 | 削除は物理削除であり、削除済み行は一覧結果に含まれない。 |
| 削除対象が存在しない | ルート引数のエンティティ解決に失敗し、404 応答となる。 |
| 「自分」と同一IDの行の削除 | 一覧ではリンクを出さない。サーバ側で同一IDを特別拒否するコードはコアに無い。 |

### データ整合性
| 観点 | 内容 |
|------|------|
| 一覧とDB | 一覧表示は取得直前の `dtb_member` の内容を反映する。並びは `sort_no` 降順のみ。 |
| 編集画面とDB | 編集GETではパスワード列をプレースホルダで上書きしたあとフォームに載せるため、画面上のパスワード欄はDBの暗号文と一致しない。 |
| 表示順の一意性 | 入れ替え・削除は隣接または全行更新で整合を取る設計だが、同時操作による競合時の保証は本書では切らない。 |
| 認証情報との関係 | ログイン中トークンのユーザー実体は編集画面描画前に元のログインメンバーへ戻すため、編集対象の一時エンティティがトークンに残らない。 |
| 一覧とログイン可否 | 認証時のメンバー読込は稼働マスタの定数IDと組み合わせて絞る。一覧は条件なし取得のため、非稼働メンバーも表示され得る。 |
| 編集可能店舗 | 在庫・受注・店頭買取・イベントの各データは、ログイン中メンバーに紐づく編集可能店舗の範囲で編集可能とする。店舗参照範囲の制御はサイト全体で共通とする。 |
| デフォルト検索表示店舗 | メンバーにデフォルト検索表示店舗が登録されている場合、店舗絞り込みを持つ検索一覧画面の初期表示条件として利用する。 |

## 0203に無い定型節（設計書からは削除・2026-08-19）

### ログ・監査
本コントローラ内では専用の監査ログ出力を行わない。汎用アプリケーションログやアクセスログへの記録は基盤設定を正とする。
#### ログに出してはいけないもの
- パスワードの平文
- CSRF トークンの原値
- Cookie 値
- セッション ID の完全値
- Remember Me トークンの原値
---
### 権限・認可
| 利用者状態 | メンバー一覧・登録・編集・削除・順序変更 |
|------------|------------------------------------------|
| 未ログイン | 管理画面の認証フローへ誘導される（詳細は管理画面ログインを正とする）。 |
| ログイン済み（編集権限あり） | メンバー一覧、登録、編集、削除、順序変更を操作できる。さらに権限マスタにより特定パスが拒否されている場合は当画面も含め拒否され得る（権限管理の設定を正とする）。 |
| ログイン済み（編集権限なし） | 一覧参照は到達経路の認可に従うが、登録・編集の実行はできない。登録ボタンは押せない状態とする。 |
| ネットワーク制限外のクライアント | 管理画面全体の拒否ポリシーに従う。 |

### セッション
#### 本機能におけるセッション
| 観点 | 内容 |
|------|------|
| フラッシュメッセージ | 保存・削除・上下移動の結果を管理画面向けキーで積む。削除対象不在時はルート引数のエンティティ解決に失敗するため、本機能側で削除済み警告キーは積まない。 |
| 編集画面の表示・検証失敗後の再表示 | セキュリティトークン上のユーザーが編集対象エンティティで上書きされないよう、描画直前にログイン中メンバーを復元する。 |
#### セッションへ保存しない情報
本機能が新たにセッションキーを定義して検索条件などを保存する処理は持たない。
