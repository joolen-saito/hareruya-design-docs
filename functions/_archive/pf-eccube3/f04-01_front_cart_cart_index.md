## 用語

| 用語 | 説明 |
|------|------|
| カート | 購入前に商品をためておく入れ物。セッションに保持する。 |
| カートアイテム | カート内の1明細。商品規格ごとに数量を持つ。 |
| 商品規格 | 商品の販売単位。`product_class_id`で識別する。 |
| 購入グループ | 同時に注文できる商品のまとまり。複数になると同時注文できない。 |
| カートロック | 購入手続きへ進む直前にカートを確定状態へ移す処理。 |

## 0203に無い定型節（設計書からは削除・2026-08-19）

#### エッジケース
| ケース | 扱い |
|--------|------|
| カートが空 | 空カートの案内を表示し、購入手続きボタンを出さない。 |
| 数量に0以下を入力して再計算 | 当該商品を削除する。 |
| 購入グループが複数 | 同時注文不可のエラーを表示する。購入手続きでメッセージがあれば買い物かごへ戻す。 |
| 入荷通知依頼が既登録 | 同一依頼が存在する場合は取消（削除）として扱う。 |
---
### データ整合性
| 観点 | 内容 |
|------|------|
| カートとセッション | カートはセッションに保持し、追加・更新・削除のたびに保存する。 |
| 画面表示と保存値 | 数量更新・増減・削除の結果は保存後の買い物かご再表示で一致する。 |
| XHRとセッション | XHRのカート追加・取得は同一セッションのカートを参照する。レスポンスにセッション識別の値を含む。 |
| 購入手続きへの引き継ぎ | 購入手続きへ進む際にカートをロックし、注文情報入力側がロック済みカートを参照する。 |

## 0203に無い定型節（設計書からは削除・2026-08-19）

### ログ・監査
| タイミング | 記録内容 |
|------------|----------|
| カート追加・加算・減算・削除の開始と完了 | 商品規格IDと数量の情報ログ。 |
| カート追加・増減のエラー | エラーメッセージの情報ログ。 |
#### ログに出してはいけないもの
- なりすまし対策トークン
- Cookie値
- セッションIDの完全値
---
### 権限・認可
| 利用者状態 | 買い物かご |
|------------|-----------|
| 非ログイン | カートの表示・数量更新・削除・一括削除・購入手続きへの導線を利用できる。入荷通知依頼は未ログインのためログインを促す。 |
| 会員ログイン | 同上。入荷通知依頼はプレイヤー情報をもとに登録・取消する。 |
購入手続き以降の会員・非会員の扱いはF04-02を正とする。
---
### セッション
#### 本機能におけるセッション
| 観点 | 内容 |
|------|------|
| カート | 追加・更新・削除のたびに保存する。 |
| 購入グループ情報 | 複数購入グループ検出時にフラッシュへ保存する。 |
| 入荷通知依頼の参照元 | 未ログイン時に参照元URLを保存する。 |
#### セッションへ保存しない情報
決済の機微情報はセッションへ保存しない。
