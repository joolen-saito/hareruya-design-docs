## 重複判定時の条件（実装順）

| 順序 | 判定 | 結果 |
|------|------|------|
| 1 | `product_code` が NULL | 重複判定の母集団から除外される。 |
| 2 | `product_code` が空文字列 | 重複判定の母集団から除外される。 |
| 3 | それ以外で同一値が 2 行以上 | その値は「重複」とみなされ、該当する全行が一覧に載る。 |

## 0203に無い定型節（設計書からは削除・2026-08-19）

#### エッジケース
| ケース | 扱い |
|--------|------|
| 重複が 1 件も無い | 結果ページはテーブルを出さず、固定メッセージのみ表示する。 |
| 同一コードが N 件ある | 同一コードのテキストが N 行並び、各行のリンク先 URL は規格ごとに異なる。 |
| `product_code` が NULL または空文字のみの環境 | 重複集合は空になり、「重複なし」メッセージになる。 |
| 空白のみや制御文字のみのコード | SQL はトリムしないため、値が完全一致する複数行があれば重複として載る。 |
---
### データ整合性
| 観点 | 内容 |
|------|------|
| 一覧と DB | 一覧はリクエスト処理中の読み取り時点のコミット済みデータを反映する。同一セッション内のキャッシュ再利用による一覧の長期固定は本機能固有には無い。 |
| 一覧と規格編集 | リンク先は編集画面の初期表示であり、別タブで開いたあとの同時更新との整合は保証しない。 |
| マルチテナント・接続先 | アプリケーションが用いる既定接続上の `dtb_product_class` / `dtb_product` を対象とする。接続切り替えプラグインがある環境ではその設定を正とする。 |

## 0203に無い定型節（設計書からは削除・2026-08-19）

### ログ・監査
本機能は一覧表示のみであり、専用の監査ログ出力はコード上は設けていない。HTTP アクセスログ等はインフラ設定に従う。
#### ログに出してはいけないもの
- パスワード
- なりすまし対策トークン
- Cookie 値
- セッション ID の完全値
- Remember Me トークンの原値
---
### 権限・認可
| 利用者状態 | 前ページ・結果ページの GET |
|------------|---------------------------|
| 管理画面にログインしており、ファイアウォール上パス `/{admin_route}/` へのアクセスが許可される管理者 | 画面を表示できる。 |
| 未ログインまたは管理画面として認証されない | 管理画面の共通ルールに従いログイン画面等へ誘導される。 |
当ルートに個別のロールアノテーションは無く、商品一覧など他の商品管理画面と同一ファイアウォール配下として扱われる。
