## 用語

| 用語 | 説明 |
|------|------|
| 会員 | フロントにログインしている顧客。 |
| 選手情報 | 会員に1対1で紐づく拡張情報。イベント申込は選手情報に紐づく。 |
| イベント申込 | 会員が大会に申し込んだ1件。申込状態とイベント詳細を持つ。 |
| イベント詳細 | 大会の開催回。開催日時・フォーマットを持つ。 |
| フォーマット | 大会で用いる構築区分。アイコンで表示する。 |

#### エッジケース
| ケース | 扱い |
|--------|------|
| 申込0件 | 「予約済みの大会はありません。」を表示する。 |
| 申込状態がキャンセル | 一覧に含めない。 |
| 申込状態が決済中 | 「決済中」と決済案内のヘルプリンクを表示する。 |
| 開催日時が過去 | イベントが終了済みなら「イベント終了」と表示する。 |

| イベント詳細 | イベント名・開催日時・フォーマットはイベント詳細を参照する。詳細側の仕様はイベント機能を正とする。 |
