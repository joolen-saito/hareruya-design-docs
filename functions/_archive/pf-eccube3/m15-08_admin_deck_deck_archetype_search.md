#### エッジケース
| ケース | 扱い |
|--------|------|
| アーキタイプを 1 つも選ばない | `archetypes` が空集合のため、アーキタイプによる追加の WHERE は付かない。 |
| アーキタイプを複数選ぶ | `IN` により、いずれかに一致するデッキがヒットする。 |
| 色のみ指定しアーキタイプは未指定 | アーキタイプへの結合は色条件のために行われ、その色を持つアーキタイプのデッキに限定される。 |
| フォーマットで絞った結果と、アーキタイプ選択がクライアント表示上矛盾 | サーバーは送信されたアーキタイプ ID とフォーマット ID の両方を適用する。0 件になり得る。 |

## 0203に無い定型節（設計書からは削除・2026-08-19）

### ログ・監査
アーキタイプ条件固有のログ出力は設計の対象としない。デッキ検索全体で共通のログがあればそれに従う。
#### ログに出してはいけないもの
- パスワード
- なりすまし対策トークン
- Cookie 値
- セッション ID の完全値
- Remember Me トークンの原値
---
### 権限・認可
| 利用者状態 | デッキ一覧検索（アーキタイプ条件を含む） |
|------------|------------------------------------------|
| 管理画面にログインし当ルートへ到達できる者 | 検索フォームの利用と結果閲覧が可能である。 |
| 未到達の者 | アプリケーションの管理画面共通の制約により、当画面の処理は実行されない。 |
---
### セッション
#### 本機能におけるセッション
| 観点 | 内容 |
|------|------|
| 検索ビューデータ | キー `admin.deck.search`。アーキタイプを含むフォームの表示復元に使う。 |
| ページ・ソート | `admin.deck.search.page_no`、`admin.deck.sort`、`admin.deck.order`、`admin.deck.search.page_count` が更新される。 |
#### セッションへ保存しない情報
パスワードやトークン類は検索フォームの対象外である。
