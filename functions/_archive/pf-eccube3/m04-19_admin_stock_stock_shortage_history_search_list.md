#### エッジケース
| ケース | 扱い |
|--------|------|
| 初回表示（検索前） | セッションを消去し、一覧を空で表示する。 |
| 日付未指定で検索 | 日付帯の絞り込みを付けず、検索条件に一致する欠品履歴を表示する。 |
| 並び順が想定外の値 | 並び順エラーを表示し初期表示へ戻す。 |
| 検索結果0件 | 「検索条件に該当するデータがありませんでした。」を表示する。 |

### データ整合性
| 観点 | 内容 |
|------|------|
| 表示時点 | 一覧は表示時点で欠品履歴テーブルを読んだ結果である。表示後の更新は自動反映しない。 |
| 履歴と現在値 | 欠品履歴は欠品発生時点の記録であり、商品の現在在庫・受注の現在状態との一致は保証しない。 |
| リンク先との整合 | 規格編集・受注編集のリンク先で値が変わっても、一覧は再読込まで履歴時点の表示を保つ。 |
