## 用語

| 用語 | 説明 |
|------|------|
| 顧客グループ | 会員（選手情報）に紐づく区分。通常・店内アカウント等を持つ。 |
| 店頭PC用アカウント | 顧客グループが店内アカウントの会員。店頭PCでの利用を前提とする。 |
| 店頭フロント区分 | 顧客グループが持つフラグ。立っている場合に対象フロント機能を遮断する。 |
| 許可IPリスト | 店頭用アカウントのアクセスを許可するIPアドレスの一覧。設定値で保持する。 |
| 番号札 | 店頭注文確定時に採番する店内モニター表示用の番号。 |

## 0203に無い定型節（設計書からは削除・2026-08-19）

#### エッジケース
| ケース | 扱い |
|--------|------|
| 未ログイン・非会員 | IP判定・機能遮断とも何もしない。 |
| 店内アカウントだが許可IPリストが空 | 即時ログアウトする。 |
| 店内アカウントで許可IP内から遮断対象外の機能へアクセス | 通常どおり利用できる。 |
| 店内アカウントが遮断対象機能へアクセス | 共通エラー画面を返す。 |
---
### データ整合性
| 観点 | 内容 |
|------|------|
| 顧客グループ判定 | 会員に紐づく選手情報の顧客グループを参照する。判定はアクセス時点のDB状態に依存する。 |
| 許可IPリスト | 設定値（カンマ区切り）を参照する。設定変更は次回アクセスから反映される。 |
| 番号札 | 店内アカウントの受注確定時に採番・保存する。表示は店頭呼び出し番号表示機能が参照する。 |

## 0203に無い定型節（設計書からは削除・2026-08-19）

### ログ・監査
本機能ではログ・監査の追記を扱わない。
#### ログに出してはいけないもの
- 端末IPアドレスの不要な記録
- Cookie値
- セッションIDの完全値
---
### 権限・認可
| 利用者状態 | フロントアクセスの可否 |
|------------|------------------------|
| 未ログイン・非会員 | 本機能の制御対象外。通常の認可に従う。 |
| 通常会員 | IP判定・機能遮断の対象外。受注確定で番号札を採番しない。 |
| 店頭PC用アカウント（許可IP内・非遮断機能） | 利用できる。受注確定で番号札を採番する。 |
| 店頭PC用アカウント（許可IP外） | 即時ログアウトする。 |
| 店頭PC用アカウント（遮断対象機能） | 共通エラー画面を返し利用できない。 |
遮断対象には会員情報変更・退会・配送先登録・お問い合わせ・パスワード再発行・入荷通知一覧・ポイント履歴・購入履歴・配送変更・購入手続き・デッキ登録・買取などのフロント機能が含まれる（コントローラ実行前処理で遮断）。
---
### セッション
#### 本機能におけるセッション
| 観点 | 内容 |
|------|------|
| 認証トークン | 許可IP外の店内アカウントはログアウト処理へ誘導し、認証状態を解除する。 |
#### セッションへ保存しない情報
許可IPリスト・端末IPはセッションへ業務データとして保存しない。判定のために参照するのみとする。
