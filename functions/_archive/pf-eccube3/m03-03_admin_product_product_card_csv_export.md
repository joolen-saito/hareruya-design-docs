## 0203に無い定型節（設計書からは削除・2026-08-19）

#### エッジケース
| ケース | 扱い |
|--------|------|
| `ids` 未送信・空・文字列のみ | 商品一覧へリダイレクト（ページ番号はセッションの検索ページ）。 |
| 存在しない ID のみ | `admin.csv.error.export.not_registered`。 |
| カード詳細なし、または規格 0 件のみ | 変換結果が空になり `admin.csv.error.export.no_card_data`。 |
| 複数規格 | 同一商品 ID・同一カード詳細 ID で行が複製される。 |
| Referer 欠落かつエラー | `redirectToRoute('admin_product_page')`。生成 URL はルータ定義に依存する。 |
---
### データ整合性
| 観点 | 内容 |
|------|------|
| 一覧との対応 | 出力対象は一覧でチェックした商品 ID のみである。検索ヒット全件を自動では出力しない。 |
| 一覧表示との差 | 一覧テンプレートは言語・状態が揃った規格だけを表示するロジックがあるが、CSV は `getProductClasses()` の全要素を走査する。画面に現れない規格が CSV に含まれうる（実装を確認値とする）。 |
| 商品の並び | `findBy(['id' => $productIds])` の戻り順に依存し、利用者が一覧で選んだ順序の再現は保証しない。 |
