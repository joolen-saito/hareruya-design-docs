## 0203に無い定型節（設計書からは削除・2026-08-19）

#### 入力項目（モーダル）
プラグイン定数 `deck_tag.length.name` は 32。`deck_tag.max.rank` は 999999。Twig とメッセージは翻訳リソース環境により文言が異なりうる。
| 項目名 | 必須／任意 | 最大長 | 初期値 | 保存先・扱い |
|--------|------------|--------|--------|----------------|
| 日本語名 | 必須 | 入力 32 文字（Symfony Length と HTML maxlength、設定ファイルの名前長定数による） | 編集開始時は行の現在値または空 | `mtb_deck_tag.name_jp`。空白不可。フォーム種別は一行テキスト。 |
| 英語名 | 必須 | 同上 | 同上 | `mtb_deck_tag.name_en`。同上。 |
| 表示順 | 必須 | 整数。上限 999999（LessThanOrEqual と HTML max）、下限 1 より大きい（Symfony GreaterThan と HTML min）の両方により 1〜999999 | 編集開始時は行の現在順位。新規時は画面上「現リストの順位最大 +1」（データが無いとき基準順位からの加算となる Twig 側の単純規則） | `mtb_deck_tag.sort_no`（現行 `rank`）。既存または新規とも、自分以外で同一順位があるとカスタム制約によりエラーとなる。別メッセージキーにより「表示順が他と重複」旨を文言化。 |
| 識別子（非画面） | 任意 | hidden | 新規では空または未設定相当 | DB 自動採番主キー。更新時のみ既存検索キーとなる。送信時のみ意味を持ち、一覧表示のみの GET には含まれない。 |

### ログ・監査
専用の業務ログは見ておらず、フラッシュのみで利用者へのフィードバックとする構成である。共通 HTTP ログ等は環境側。
#### ログに出してはいけないもの
- パスワードやトークンの原値
- CSRF シークレットやセッション完全値など、なりすましに直結する生データ

| 利用者状態 | `/deckTag` 系 |

| 管理画面ログイン済で当プレフィックスへ到達可 | GET・POST・DELETE の各ルート定義により操作可能となる前提。未到達状態は共通ログイン処理に依存。 |
