## 用語

| 用語 | 説明 |
|------|------|
| 支払方法 | 支払い手段の1件。`dtb_payment`の1行。画面上は「支払方法」列に支払方法名（`payment_method`に相当する属性）が出る。 |
| 手数料 | 当該支払方法に紐づく手数料金額。`charge_flg`が手数料設定可のときフォームで必須。不可のとき保存直前に0に正される。 |
| 利用条件 | 購入金額の下限・上限。フォームでは金額2欄。未入力や片方のみ入力が許容される。両方入力かつ上限が下限未満のときエラー。 |
| 表示順（ランク） | 一覧の並びとフロントでの支払候補の並びに使われる整数。大きい値ほど一覧の先頭に近い並びで取得する実装である。 |
| 固定フラグ | `fix_flg`。値が1の行だけ、一覧のドロップダウンから編集・削除への通常リンクが有効になる。1以外は遷移しない見た目の錨になる。 |
| 手数料設定可否フラグ | `charge_flg`。値1なら手数料を金額入力として編集する。値2なら手数料欄はhiddenとなり、保存時に手数料0を保存する。 |
| 論理削除 | `del_flg`を削除済み値に更新し、一覧取得から除外する。物理削除は当機能では行わない。 |
| 管理者 | 管理画面にログイン可能な管理者アカウント。保存時イベントで作成者に設定されるのはトークンがあり`ROLE_ADMIN`が付与されている場合に限る。 |

#### エッジケース
| ケース | 扱い |
|--------|------|
| 固定フラグが編集不可の行 | 一覧では編集・削除リンクが無効化される。識別子を直接指定して編集画面へ来た場合でもサーバは固定フラグだけを理由に保存を拒否しない。 |
| 利用条件の上限が0以下または未入力で上限のみ | 一覧の利用条件列では上限側の「〜上限円」「無制限」が付かないことがある。 |
| 削除対象が存在しない | 削除用フラッシュを積み一覧へ戻る。永続化はしない。 |
| 表示順入替で隣接行が存在しない | エラーフラッシュを積み、ランクは変えない。 |
| 画像ファイルが一時領域に無いまま登録 | 画像移動は行われず、hiddenの値だけがそのまま保存され得る。 |

### データ整合性
| 観点 | 内容 |
|------|------|
| 一覧と編集 | 編集は識別子で読んだ行を正とする。一覧後に他管理者が変更した場合、編集画面は古い値から上書きし得る。 |
| 論理削除と配送 | 論理削除は支払行のフラグのみ更新する。配送方法側の中間テーブル参照の整合は別機能の責務である。 |
| 手数料一覧表示 | 一覧は保存値をそのまま表示する。グルーピングや通貨記号は当テンプレートでは付けない。 |
| 時刻・作成者 | 新規挿入時に作成日時・更新日時を現在時刻で埋め、管理者トークンがあれば作成者を現在の管理者にする。更新時は更新日時のみ自動更新する。 |
