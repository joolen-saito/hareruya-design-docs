## 用語

| 用語 | 説明 |
|------|------|
| 仮会員 | 入会申込はしたが本会員化前の会員。ログイン不可の状態。 |
| 本会員 | アクティベート済みでログイン可能な会員。会員ステータスが本会員。 |
| 秘密キー | 仮会員ごとに発行される一意のキー。アクティベートURLに含む。 |
| 選手情報 | 会員に1対1で紐づく拡張情報。スマレジIDを持つ。 |
| スマレジ | 店舗POSの外部サービス。本会員化時に会員登録を連携する。 |

## 0203に無い定型節（設計書からは削除・2026-08-19）

#### エッジケース
| ケース | 扱い |
|--------|------|
| 既に本会員化済みのURLを再度開く | 未本会員を取得できない、またはスマレジID保有のため「完了済みです。」を表示する。 |
| 改ざん・期限切れ等で秘密キーが不正 | 「アクセスできません。」を表示する。 |
| スマレジ連携が一時的に失敗 | 本会員化を確定せず「有効化に失敗しました。」を表示する。利用者は再度URLを開くことで再試行できる。 |
| 仮登録時に商品検索からの遷移があった | 本会員化後、完了画面ではなく直前の商品検索画面へ戻す。 |
---
### データ整合性
| 観点 | 内容 |
|------|------|
| 会員と選手情報 | 本会員化時、会員ステータスと選手情報のスマレジIDを同一トランザクションで確定する。 |
| スマレジ | スマレジ会員登録の成功を本会員化確定の前提とする。失敗時はDBを変更しないため、画面表示とDBは本会員化前のまま一致する。 |
| 支店システム | 本会員化確定後に更新通知を行う。支店側反映の時点整合は本書では保証しない。 |

## 0203に無い定型節（設計書からは削除・2026-08-19）

### ログ・監査
| タイミング | 記録内容 |
|------------|----------|
| 本会員登録画面へのリダイレクト | 情報ログ（仮登録処理側）。 |
| 完了メール送信 | メール送信の情報ログ・送信履歴の保存。 |
#### ログに出してはいけないもの
- 秘密キーの完全値
- Cookie値
- セッションIDの完全値
---
### 権限・認可
| 利用者状態 | 本会員化 |
|------------|----------|
| 秘密キー保有の仮会員 | URLを開くことで本会員化できる（未本会員かつスマレジID未保有のときのみ）。 |
| 本会員化済み | 「完了済みです。」を表示し、再度の本会員化は行わない。 |
本機能はログイン前のアクセスを前提とし、成功時に自動ログインする。
---
### セッション
#### 本機能におけるセッション
| 観点 | 内容 |
|------|------|
| 自動ログイン | 本会員化成功時に当該会員で認証トークンを設定する。 |
| セッション再生成 | 自動ログイン時にセッションを再生成する（固定化対策）。 |
| 商品検索の戻り先 | セッションに戻り先があれば取得・消去し、そこへリダイレクトする。 |
| 店舗指定 | セッションの店舗指定に応じて完了画面の「ホームへ戻る」先を支店／本店で切り替える。 |
#### セッションへ保存しない情報
秘密キーはセッションへ保存しない。URLのパス値として受け取り照合に用いるのみとする。
