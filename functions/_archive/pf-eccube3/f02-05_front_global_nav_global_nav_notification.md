## 用語

| 用語 | 説明 |
|------|------|
| 通知表示 | ヘッダ・ナビ上で、特定条件を満たすときだけ出す利用者向けの状態表示。 |
| 保有ポイント表示 | ログイン会員のときヘッダに出すポイントの導線。 |
| マイページ隠しメニュー | マイページアイコン押下で開く導線。ログイン状態でログイン／会員登録の有無が変わる。 |
| カート個数 | カートに入っている数量を示すヘッダ上の表示。非同期取得した値で更新する。 |
| 言語切替リンク | 反対言語の対応URLへ移る導線。画面側の無効化指定で表示有無が変わる。 |

## 0203に無い定型節（設計書からは削除・2026-08-19）

#### エッジケース
| ケース | 扱い |
|--------|------|
| 未ログインで表示 | 保有ポイント表示を出さない。隠しメニューにログイン／会員登録を出す。 |
| ログイン会員で表示 | 保有ポイント表示を出す。隠しメニューにログイン／会員登録を出さない。 |
| カート情報の非同期取得が完了する前 | カート個数表示は取得完了まで初期状態のままとなる。 |
| 言語切替リンクが無効化された画面 | 言語切替リンクを出さない。 |
---
### データ整合性
| 観点 | 内容 |
|------|------|
| 参照時点 | 保有ポイント表示・隠しメニューの導線はヘッダ描画時点のログイン状態に従う。カート個数は非同期取得した時点の値であり、ヘッダ描画時点とは別時点となり得る。 |
| ログイン状態との整合 | 保有ポイント表示・ログイン／会員登録導線の有無は、描画時点のログイン状態と一致する。 |
| カートとの整合 | カート個数はカート機能の取得結果に従う。表示値の正はカート機能とする。 |
