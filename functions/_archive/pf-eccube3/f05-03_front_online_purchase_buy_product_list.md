## 用語

| 用語 | 説明 |
|------|------|
| 商品サブクラス | 言語・状態などで区分した買取対象の商品単位。一覧の行となる。 |
| 状態NM | カードの状態区分のうち「NM」。買取一覧はこの状態を対象とする。 |
| 高額商品コード | 高額専用の区分。買取一覧の対象から除外する。 |
| 検索結果上限 | 一覧で実体を取得する件数の上限（`product_search_limit`＝9999）。 |
| 買取最低価格 | カート追加ボタンを出す下限の買取価格（`purchase_min_price`＝500）。 |

## 0203に無い定型節（設計書からは削除・2026-08-19）

#### エッジケース
| ケース | 扱い |
|--------|------|
| 0件 | 一覧をHTTP404とし、見つからなかった旨と買取最低保証・ヘルプ案内を表示する。 |
| 上限（9999）超過 | 実体を取得せず、条件を追加するよう案内し、外部へ件数を通知する。 |
| 買取価格が買取最低価格未満 | 当該商品はカート追加ボタンを表示しない。 |
| 買取特集タグが複数 | タグ説明文の表示は1件のときに限る。 |
---
### データ整合性
| 観点 | 内容 |
|------|------|
| 検索条件と表示 | 一覧の件数・絞り込みフィルタ選択状態・並び順は引き継いだ検索条件と一致する。 |
| 価格・在庫 | 表示は参照時点の商品サブクラスの買取価格に一致する。 |
| 詳細との整合 | 一覧の各商品は買取商品詳細と同じ商品サブクラスを参照する。 |

## 0203に無い定型節（設計書からは削除・2026-08-19）

### ログ・監査
本機能は固有の監査ログを主目的としない。上限超過時の外部通知はAPI/バッチ結果節を正とする。
### 権限・認可
| 利用者状態 | 買取商品一覧 |
|------------|--------------|
| 未ログイン | 閲覧可能 |
| ログイン済み会員 | 閲覧可能 |
一覧の閲覧に会員ログインは要しない。
---
### セッション
本機能は一覧表示でセッションを更新しない。検索条件はGETクエリで引き継ぐ。買取カートのセッション更新はF05-05を正とする。
