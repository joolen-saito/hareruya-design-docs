## 用語

| 用語 | 説明 |
|------|------|
| 店舗基本情報 | ショップ全体で共有する設定の集合。永続化先は `dtb_base_info`（Doctrine上は店舗基本情報エンティティ）。通常1行を想定し、識別子固定で取得する。 |
| 旧ショップマスター | 画面サブタイトルおよび歴史的呼称。本機能はその「基本設定」編集に相当する。 |
| 管理者 | 管理画面にログイン可能な管理者アカウント。管理画面パス配下では `ROLE_ADMIN` が前提。さらに権限マスタにより特定パスが拒否される場合がある。 |
| 利用者 | 本機能では管理者を指す。来店顧客向け画面は「フロント」と書き分ける。 |

## 参考（フロントへの影響の読み取りガイド）

本節は当画面が保持するオプションがフロントでどのような論理に接続されやすいかのガイドである。個別の分岐の正典は各画面・サービス実装とする。

| 設定 | 利用者（来店客）視点で効きやすい領域 |
|------|--------------------------------------|
| 送信元メールアドレス（From） | 件名・本文テンプレート、送信元ヘッダ。 |
| 問い合わせ・返信・エラー受付メール（各項目） | 問い合わせ・返信・バウンス等の宛先・Reply-To・Return-Path。詳細はメール送信処理を正とする。 |
| 店名 | サイト表示名・メール件名プレフィックス等。 |
| 送料無料（金額・個数） | カート・購入フローの送料表示・無料化判定。 |
| 商品ごとの送料 | 規格単位の送料加算の有無。 |
| 複数配送 | カートの配送分割・商品種別混在可否・チェックアウト画面の流れ。 |
| 仮会員 | 会員登録後のメール確認フローの要否。 |
| マイページ注文状況表示 | 注文履歴まわりの表示。 |
| お気に入り | 商品詳細・マイページでのお気に入り機能の可否。 |
| 自動ログイン（Remember Me） | ログイン画面の「記憶する」の扱い。Cookie 詳細は管理画面ログイン・フロントログイン設計を正とする。 |
| 在庫切れ非表示 | 商品一覧・検索での在庫なし商品の扱い。 |

#### エッジケース
| ケース | 扱い |
|--------|------|
| いずれかのメール項目が空、他は入力 | 4項目とも NotBlank のためエラー。複数項目エラーが同時に表示される（E2E で明示）。 |
| 電話の一部のみ入力 | 「3分割の一部だけ入力」になりエラー（専用メッセージ）。 |
| 郵便番号の片方だけ入力 | 各フィールドの Type/Length によりエラーになる。 |
| 送料無料金額に負数・非数 | エラー。 |
| バリデーション失敗中にヘッダ等で店名を表示 | グローバルは編集前スナップショットのため、フォーム内の店名とずれることがある。 |
| 店舗基本情報の結果キャッシュ | 取得クエリは結果キャッシュを使う。設定で結果キャッシュクリアが有効なら、店舗基本情報の更新後に結果キャッシュ全削除が走る場合がある。無効なら TTL 内は古いスナップショットが読まれる可能性がある（実装・設定を確認値とする）。 |

### データ整合性
| 観点 | 内容 |
|------|------|
| 一覧と詳細 | 当画面は単一レコード編集のみ。一覧との突合は不要。 |
| 全画面の店舗名など | 通常リクエストでは Twig グローバル用に店舗基本情報を読み込む。表示値は読み込み時点の値。 |
| 保存直後 | 同一管理者がリダイレクト後に開き直した画面では、永続化後の値が読み込まれる。キャッシュ設定により、別ワーカー・別リクエストで一瞬古い値が読まれる可能性は否定しない（実装を確認値とする）。 |
| 同時更新 | 楽観ロックは持たない。後勝ちで実体が上書きされる。 |

### 権限・認可
| 利用者状態 | 画面表示・保存 |
|------------|----------------|
| 管理画面未認証 | 管理画面の認証フローへ。 |
| `ROLE_ADMIN` を持つ管理者で、拒否 URL に該当しない | 表示・保存とも可能。 |
| `ROLE_ADMIN` を持つが、権限マスタの拒否パターンに現在パスが一致 | 拒否。 |
| 管理画面 IP 許可リストが設定されており、クライアント IP が含まれない | 拒否（設定がある場合のみ）。 |
注: メニューでリンクが非表示でも、パスを直接指定した要求に対しては Voter によりアクセス拒否となる場合がある。非表示と拒否は別レイヤで判定する。
