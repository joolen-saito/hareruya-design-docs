## 用語

| 用語 | 説明 |
|------|------|
| 店頭買取 | 店頭で商品を買い取る取引。店頭買取テーブルと明細に記録する。 |
| 集計日 | 集計対象とする1日。引数で指定するか、未指定なら前日を用いる。 |
| 部門 | 商品を分類する区分。集計の単位の一つ。 |
| 買取金額 | 買い取った金額。単価と数量から算出する。 |
| 売価金額 | 販売予定の金額。単価と数量から算出する。 |
| 買取集計 | 店舗・部門・集計日ごとに買取金額・売価金額を合算した結果。買取集計テーブルへ登録する。 |
| 部門未設定商品 | 集計対象の明細のうち部門が設定されていない商品。 |

## 通知

| 観点 | 内容 |
|------|------|
| 送信条件 | 集計対象に部門未設定商品があるとき部門未設定商品通知メールを送る。集計・登録途中で例外が発生したとき集計エラー通知メールを送る。 |
| 宛先 | オプションに設定された買取集計通知用メールアドレス（カンマ区切り）を宛先とする。宛先が未設定の場合は送信しない。宛先の決まり方はオプション管理を正とする。 |
| 本文 | 部門未設定商品通知メールは商品名・商品コードの一覧を載せる。集計エラー通知メールは例外メッセージを載せる。 |

## 0203に無い定型節（設計書からは削除・2026-08-19）

### データ整合性
| 観点 | 内容 |
|------|------|
| 多重実行 | ロックファイル等による多重起動防止は行わない。同じ集計日を同時に実行すると、双方が削除と登録を行い当日分が重複し得る。 |
| 途中失敗・再実行 | 削除と登録を1トランザクションで行い、例外時はロールバックする。再実行で同じ集計日の集計を入れ替えるため重複しない。 |
| 参照時点 | 実行時点の店頭買取データを集計対象とする。 |
| 削除と登録の範囲 | 削除・登録の対象は指定集計日の当日分に限る。他日の集計は変更しない。 |

## 0203に無い定型節（設計書からは削除・2026-08-19）

### ログ・監査
| タイミング | 記録内容 |
|------------|----------|
| 起動 | バッチコマンドの起動時に日時付きのコンソール出力を行う。 |
| 部門未設定商品通知メール | 送信開始・送信完了・件数、宛先未設定時の送信せず終了をログに記録する。 |
| 集計エラー通知メール | 送信開始・送信完了、宛先未設定時の送信せず終了をログに記録する。 |
#### ログに出してはいけないもの
- パスワード
- トークン・接続秘密値
- メール送信の認証情報
- Cookie値・セッションIDの完全値
