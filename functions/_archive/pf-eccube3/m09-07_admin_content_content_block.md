## 用語

| 用語 | 説明 |
|------|------|
| ブロック | レイアウト上に配置する部品。ブロック名・ファイル名の属性と、テンプレート本文を持つ。テーブルは `dtb_block`。 |
| 削除可否区分 | ブロックが削除・編集できるかを示す区分。`dtb_block.deletable`（現行 `deletable_flg`）が削除可能か削除不可かを表す。新規作成時は削除可能で生成する。 |
| テンプレート本文 | ブロックの Twig ファイルの中身。フォーム上はブロックデータ入力欄に対応し、保存時にブロックファイルへ書き出す。 |
| 端末種別 | 表示端末の区分。本機能では PC 端末種別を取得して対象とする。 |

## 0203に無い定型節（設計書からは削除・2026-08-19）

#### エッジケース
| ケース | 扱い |
|--------|------|
| 削除不可ブロックの編集・更新 | アクセス拒否（HTTP 403）。 |
| 削除不可ブロックの削除 | レコード・ファイルとも削除しない。 |
| 編集でファイル名を変更 | 新ファイルへ書き出し、旧ファイルが存在すれば削除する。 |
| 削除対象が存在しない ID | 削除対象なしメッセージを出して一覧へ戻る。 |
| 削除でテンプレートが変更済み | レコードは削除するが、ファイル名が一致しない場合は対象ファイルが残る場合がある。 |
---
### データ整合性
| 観点 | 内容 |
|------|------|
| 属性とファイルの整合 | ブロック属性はデータベース、テンプレート本文はファイルへ分けて保存する。保存はデータベース更新のあとにファイル書き出しを行う。両者の整合は保存処理の成否に依存する。 |
| 一覧と編集の整合 | 一覧は保存後の最新レコードを ID 降順で読む。本文の表示は読込先ファイルの現行内容を反映する。 |
| キャッシュ | 保存・削除のあとキャッシュを破棄する。テンプレートのキャッシュが古いまま残り続ける設計にはしない。 |

## 0203に無い定型節（設計書からは削除・2026-08-19）

#### 入力項目
| 項目名 | 必須／任意 | 最大長 | 初期値 | 保存先・扱い |
|--------|------------|--------|--------|----------------|
| ブロック名 | 必須 | 255文字（`NotBlank` と `Length`） | 新規は空、編集は現行値 | `dtb_block.block_name`（現行 `name`）。キー `name`。 |
| ファイル名 | 必須 | 255文字（`NotBlank`・`Length`・正規表現） | 新規は空、編集は現行値 | `dtb_block.file_name`。キー `file_name`。半角英数字と `_ /` のみ許可。テンプレート本文の書き出しファイル名になる。 |
| ブロックデータ | 任意 | フォーム上限なし。ファイルへ書き出す | 新規は既定テンプレート内容、編集は読込先ファイル内容 | テーブルには保存せず Twig ファイルへ書き出す。キー `block_html`（`mapped` 偽）。改行コードを変換して書き込む。 |
最大長の数値は `src/Eccube/Resource/config/constant.yml.dist` の確認値とする。運用環境で上書きされている場合はその環境の値が正とする。端末種別とブロック ID は隠し項目として送信し、ブロック ID はキー `id`、端末種別はキー `DeviceType` で扱う。

## 0203に無い定型節（設計書からは削除・2026-08-19）

### ログ・監査
| タイミング | 記録内容 |
|------------|----------|
| 保存・削除 | 本機能固有の業務監査ログは追加しない。登録完了・削除完了は画面フラッシュで通知する。 |
#### ログに出してはいけないもの
- なりすまし対策トークンの完全値
- セッション識別子の完全値
- Cookie の原値
---
### 権限・認可
| 利用者状態 | ブロック管理の一覧・フォーム・削除 |
|------------|----------------------------------|
| 未ログイン | 管理画面共通のログイン誘導に従う。 |
| 管理メンバーでログイン済み | アクセス制御リストが URL を許可するときに到達する。削除不可ブロックの編集・更新はアクセス拒否（HTTP 403）。 |
---
### セッション
本機能は一覧の検索条件をセッションに載せない。検索ボックスの入力はGETリクエスト内で部分一致条件として扱い、成功・失敗メッセージは管理画面共通のフラッシュ機構に依存する。
---
### Cookie
管理画面のセッション Cookie のみを正とし、本機能用の追加 Cookie は定義しない。
