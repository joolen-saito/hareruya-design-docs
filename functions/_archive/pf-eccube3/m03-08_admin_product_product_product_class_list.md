## 一覧表示時の列と値の対応（閲覧専用）

画面上の項目名と永続データの読み筋を表で示す。ラベルの正確な和文・英訳はロケールのメッセージリソースが正であり、一覧で翻訳キーを直接表示していない項目（スマレジの ON と OFF）は字形がソース字面に従う。

| 列の見出し（ロケール上の論理ラベル） | ソース上の読み筋 |
|--------------------------------------|------------------|
| 公開状態（アクティブ表のみ） | 規格の公開状態関連があれば名前、無ければ空文字連結。マスタ未定義との組合せにより空セルになりうる。 |
| 言語 | 言語マスタがあれば `nameJp`。無ければ空。 |
| 状態 | カード状態マスタがあれば `code`。無ければ空だがクエリは非 NULL で寄せている。 |
| スマレジ連携フラグ（アクティブ表のみ） | フラグが真なら Twig 字面で `ON`、偽なら `OFF`。 |
| 商品コード | 規格のコード列値。未設定または空値相当ならセル空白。 |
| 在庫数 | `stock_unlimited` が真ならロケールの「無制限」短文。偽なら在庫数を表示するが Twig は null または偽値相当を 0 数字に読み替えているため、画面上は 0 以上の整数になる。 |
| 販売制限数 | 設定があれば数値として表示するが、 Twig は偽評価のとき空文字となる。 |
| 基準価格・販売価格・買取価格（円系ラベル） | それぞれ規格側の標準価格、売価、買取列。 Twig は未設定または偽相当のとき空セルとなり、それ以外は `number_format`。 |

## ログと秘匿情報

画面上にパスワードや決済情報を載せず、一覧のためだけのクエリログがどの程度詳細になるかは運用側のログ設定による。本機能は CSRF を伴う一覧内フォーム送信をしない。

## アクセス可否（概要）

詳細ロール一覧は共通の権限モデルを正とする。状態と当ページとの関係を概略のみ示す。

| 利用者状態 | `admin_product_product_class` での一覧表示 |
|------------|-----------------------------------------------|
| 管理画面へ未ログインまたはセッション失効 | 管理画面共通のログインまたは拒否処理に委ねられる。一覧本文には到達しない。 |
| 管理画面ログイン済みであり、アクセス制御により当パスへ到達可能な場合 | 上記クエリにもとづく一覧テンプレートが返る。 |

### 副作用

## 0203に無い定型節（設計書からは削除・2026-08-19）

### データ整合性
- リストの両表は一覧表示時点のクエリ結果にのみ依拠し、画面上で数値や名称をユーザーが編集する手段は無い。そのため一覧表示中は永続データと表示のずれは、他セッションの更新または同一利用者による別タブ・別画面の変更があった場合にのみ生じうる。
- アクティブと廃止に二重計上しない。各行は規格側の公開状態値がマスタ値 3 と等しいか否かにより一方のみに載るクエリとなる。
- 規格側の公開状態または言語またはカード状態がクエリ要件を欠く行は両表ともに載らず、画面上も件数にも含まれない。
