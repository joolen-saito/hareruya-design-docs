## 0203に無い定型節（設計書からは削除・2026-08-19）

#### エッジケース
| ケース | 扱い |
|--------|------|
| タグ ID に重複を書く | 置換前に ID 配列を一意化するため、結果として重複は残らない。 |
| タグ列のみ空 | 検証は通り、その商品の紐付けはすべて削除される。 |
| 存在しない売上分析タグ ID | マスタ不存在エラーとなり全体ロールバック。 |
| 存在しない商品 ID | 商品不存在エラーとなり全体ロールバック。 |
| 改行カウントが閾値以上 | 取込処理に入らず、`ADMIN_CSV_IMPORT_MAX_ROWS` を上限としてエラーフラッシュのみ。 |
---
### データ整合性
| 観点 | 内容 |
|------|------|
| 一覧との一致 | 取込成功後、商品詳細や一覧検索が参照する売上分析タグは置換結果と一致する（同一トランザクション内でコミットされた場合）。 |
| 履歴との関係 | 取込履歴は成功時のみ 1 件追加される。失敗時は履歴を増やさない。履歴のファイル名はアップロード時のオリジナル名。 |
| 部分成功 | 実装はファイル単位でコミットまたはロールバックする。途中まで成功した行だけを残す動きにはしない。 |

### ログ・監査
| タイミング | 記録内容 |
|------------|----------|
| 取込開始直後（コントローラ） | 情報ログに開始文言を書く。 |
| 取込完了（コントローラ、エラー無し） | 情報ログに完了文言と件数コンテキストを書く。 |
| 取込異常終了（コントローラ、エラーあり） | 情報ログに異常終了文言を書く。 |
#### ログに出してはいけないもの
- パスワード
- なりすまし対策トークン
- Cookie 値
- セッション ID の完全値
- Remember Me トークンの原値
---
### 権限・認可
| 利用者状態 | アップロード画面 GET・雛形 GET・取込 POST |
|------------|-------------------------------------------|
| 管理画面にログイン済みで当パスへ到達できる管理者 | 実装されている処理を実行できる。ルート属性による個別の細かな認可キーは付けない確認値である。 |
| 未ログインまたは共通ファイアウォールで拒否される主体 | 管理画面の共通ルールに従い当機能には到達しない。 |
---
### セッション
#### 本機能におけるセッション
| 観点 | 内容 |
|------|------|
| アップロード画面 GET | `admin.product.tag_sales_analysis_csv.page_count` と `admin.product.tag_sales_analysis_csv.page_no` を読み書きする（クエリが許容リストに合う場合）。 |
#### セッションへ保存しない情報
アップロードファイルの実体や CSV のデータ行本文はセッションに載せない。

### Cookie
本機能単体で新種の Cookie を定義しない。セッション Cookie は管理画面共通の設定に従う。
