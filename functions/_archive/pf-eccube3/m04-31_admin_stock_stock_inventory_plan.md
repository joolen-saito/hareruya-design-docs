## 用語

| 用語 | 説明 |
|------|------|
| 棚卸計画 | 棚卸作業の計画。テーブル `dtb_inventory_plan`。棚卸名・備考・商品数・計上済み商品数・差異あり商品数・在庫反映日などを持つ。 |
| 棚卸名 | 計画を識別する名称。列 `name`。重複不可。 |
| 備考 | 計画に付ける自由記述。列 `memo`。 |
| 在庫反映日 | 棚卸結果を在庫へ反映した日時。列 `stock_reflectioned_date`。設定済みの計画は更新不可となる。 |
| 作業者 | 計画を保存した管理者。列 `member_id`。 |

## 0203に無い定型節（設計書からは削除・2026-08-19）

#### エッジケース
| ケース | 扱い |
|--------|------|
| 棚卸名が同名で既存 | 名称重複エラーを表示し登録・更新しない。 |
| 在庫反映済みの計画を更新 | 在庫反映済みエラーを表示し更新しない。 |
| 更新対象IDが存在しない | 404として扱う。 |
| 新規登録の検証エラー | 新規登録画面を再表示する。 |
| 更新の検証エラー | 編集画面へリダイレクトしエラー内容を表示する。 |
---
### データ整合性
| 観点 | 内容 |
|------|------|
| 登録後の遷移 | 新規登録の成立後は登録した計画の編集画面を表示し、保存値を反映する。 |
| 反映済みとの整合 | 在庫反映日が設定済みの計画は更新できないため、反映後の棚卸名・備考は固定される。 |
| 一覧との整合 | 一覧の商品数・計上済み・差異あり件数は計画保持値であり、棚卸詳細やCSV登録の反映タイミングは各機能の設計を正とする。 |

## 0203に無い定型節（設計書からは削除・2026-08-19）

### 入力項目
| 項目名 | 必須／任意 | 最大長 | 初期値 | 扱い |
|--------|------------|--------|--------|------|
| 棚卸名 | 必須 | 255文字 | 新規は空、編集は現行値 | 同じ棚卸名の計画が既にある場合は登録・更新できない。 |
| 備考 | 任意 | 1024文字 | 新規は空、編集は現行値 | 複数行で入力する。 |
