## ec-cube-enterprise（Symfony側）での差分読みポイント

同一業務でもリポジトリ統合側ではパスや副作用がプラグイン版と異なりうる。

| 観点 | 確認の目安 |
|------|-------------|
| POSTパス名 | Symfony版は `shipping_result_csv/import` と `upload` の同一系統でありうるので、環境ごとのルート定義ファイルを確認する。 |
| ロック実装 | PostgreSQL向け名前付き方法に寄せている構成もあり、MySQLロックと論理構造が同じとは限らない。 |
| 成功後処理 | メール送信等がコメントアウトされていてプラグイン版と異なる並びになりうる。 |
| CSV列数 | 親リポジトリのクエリ側にだけ存在する住所系列により、プラグインテンプレの列リストと桁が食い違うリスクがある。 |
