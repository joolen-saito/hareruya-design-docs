## 用語

| 用語 | 説明 |
|------|------|
| 商品規格 | 商品とコンディション・言語・フォイル等の組で在庫・価格を持つ単位。一覧の抽出・件数はこの単位を起点とする。 |
| コンディション | カードの状態区分。状態コード`NM`（良品）や`HP`等がある。 |
| 言語 | 商品規格の言語区分。日本語（`JP`）・英語（`EN`）・その他。 |
| 高額コード | 商品規格に付く別在庫区分の識別子（`highPriceCode`）。通常一覧の抽出では原則として高額コードなしの規格を対象とする。 |
| ユニサーチ | 商品検索に用いる外部検索エンジン。本店の商品一覧はユニサーチ経由の検索を既定とする。 |
| 本店一覧 | ユニサーチを用いる通常の商品一覧経路（`Product/product_list_unisearch.twig`）。 |
| 支店一覧 | ユニサーチを用いずデータベース検索で組み立てる経路（`Product/product_list.twig`）。 |

## 0203に無い定型節（設計書からは削除・2026-08-19）

#### エッジケース
| ケース | 扱い |
|--------|------|
| 検索条件が空 | 検索フォームのみを表示し、結果を組み立てない。 |
| 主要条件が未指定で在庫もすべて表示 | 全件検索とみなし空の一覧を返す。 |
| 抽出件数が0件（支店一覧経路） | 本文を組み立てたうえで応答ステータスを404とし、該当商品が見つからない旨を表示する。 |
| 抽出件数が0件（本店一覧経路） | 該当商品が見つからない旨を表示する。 |
| 抽出件数が上限超過 | 商品内容を取得せず、さらに絞り込みを促すメッセージを表示する。 |
| 不正な並び順値 | 色順として扱う。 |
---
### データ整合性
| 観点 | 内容 |
|------|------|
| 参照時点 | 商品数・一覧は表示時点のデータベースまたはユニサーチの検索結果である。表示後の在庫・価格・公開状態の変動は一覧へ自動反映しない。 |
| 件数と一覧の一致 | 本店一覧はユニサーチの件数を用い、商品サムネイルは遅延読み込みでデータベースから取得するため、検索エンジンとデータベースの反映タイミング差により件数と表示商品が一致しない場合がある。 |
| 一覧と詳細の一致 | 一覧の価格・在庫は表示時点の値であり、商品詳細（F03-02）の表示値との一致は各表示時点を正とする。 |

## 0203に無い定型節（設計書からは削除・2026-08-19）

#### 入力項目
| 項目名 | 必須／任意 | 最大長 | 初期値 | 保存先・扱い |
|--------|------------|--------|--------|----------------|
| 並び順 | 任意 | — | 色順（`default`） | クエリ`sort`（`default`／`price`）と`order`（`ASC`／`DESC`）。抽出結果の並び替えにのみ用い、保存しない。 |
| 表示ページ | 任意 | — | 1ページ目 | クエリ`page`。表示位置の指定にのみ用い、保存しない。 |
| 在庫絞り込み | 任意 | — | すべて表示（`0`） | クエリ`stock`。`1`で在庫ありのみに限定。保存しない。 |
検索条件の各入力欄（商品名・カテゴリ・色・レアリティ等）の項目定義は詳細検索フォーム（F03-03）を正とする。一覧画面はそれらの条件をクエリとして受け取り、抽出・絞り込みアイコンの選択状態の表示に用いる。
