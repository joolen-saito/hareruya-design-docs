## データ取得クエリの要点

- 受注を起点に、都道府県マスタ・会員・受注明細・商品・出荷・配送方法を結合する。
- 出荷の主キーが `ids` に含まれる行に限定する。
- 受注 ID でグループ化するため、同一受注に複数の出荷が `ids` に含まれる場合、SQL 上は 1 行に畳み込まれる。データ行の配送先などは受注に紐づく出荷コレクションの先頭要素を参照する実装であり、どの出荷 ID に対応する行かと一致しない場合がある（実装を確認値とする）。
- 受注明細と商品の内部結合のため、該当する明細が存在しない受注は結果に現れない。

## 出力列と値の対応（業務ルール）

ヘッダ行の並びは送り状CSV用エクスポータ内の固定配列どおりである。データ行は取得処理が同じ順序で `row` に値を追加する。

| 列名（ヘッダ） | 内容 |
|----------------|------|
| 注文番号 | 受注の注文番号。 |
| 注文金額合計 | 受注合計。 |
| 注文者氏名〜注文者電話番号 | 受注の注文者情報。電話は `tel01`〜`tel03` の連結。部署列は空文字固定。 |
| 贈り主氏名〜贈り主電話番号 | 注文者と同一の文字列を繰り返し立てる。部署列は空文字固定。 |
| 注文コメント | 受注メッセージ。 |
| 注文備考(社内用) | 受注備考。 |
| 備考(内部用) | 空文字固定。 |
| 注文確定日〜配送希望時間帯 | 注文日時、確定日時、受注に紐づく出荷日時、配送日・時間帯。日時は `Y/m/d H:i:s`、無ければ空。 |
| 商品金額合計 | 受注小計。 |
| 送料・送料(税抜) | いずれも受注の送料合計と同一値。 |
| 手数料・手数料(税抜) | いずれも受注の手数料と同一値。 |
| のし・ラッピング手数料、のし・ラッピング手数料(税抜)、送料・手数料税率 | 空文字固定。 |
| 配送先番号 | 数値リテラル `1` 固定。 |
| 荷物問い合わせURL | 空文字固定。 |
| 送り状No. | 空文字固定（追跡番号列はヘッダに存在するが値は埋めない）。 |
| 配送先氏名〜配送先電話番号 | 出荷のお届け先。部署名は空文字固定。電話は連結。 |
| 郵便種別 | 配送方法マスタの主キーがリポジトリ定義に存在するときだけマッピング値を立てる。例として ID `3` は `0`、ID `4` は `8`。それ以外は空。 |
| 発送方法 | 配送方法名。 |
| 発送先国コード | 出荷の国があれば 2 文字の国コード、無ければ空。 |
| 商品総重量 | クエリで集計した重量。 |
| 発送方法コード | 配送方法 ID がリポジトリの別マップに存在するときコード文字列、それ以外は空。例として ID `8` は `111`、`9` は `521`、`11` は `321`。 |

マップのキーはソース上は文字列だが、取得 ID は整数でも参照される（実装を確認値とする）。

## 関連機能との違い（混同防止）

| 項目 | 送り状CSV（本書） | 出荷CSVダウンロード（別） |
