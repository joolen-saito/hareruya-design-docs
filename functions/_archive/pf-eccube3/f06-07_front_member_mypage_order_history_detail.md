## 0203に無い定型節（設計書からは削除・2026-08-19）

#### エッジケース
| ケース | 扱い |
|--------|------|
| 注文IDが無い | 見つからない（HTTP404）。 |
| 注文が取得できない | 見つからない（HTTP404）。 |
| 注文の会員がログイン会員と不一致 | 見つからない（HTTP404）。 |
| 使用ポイント・発生ポイントが0 | 0ポイントとして表示する。 |
| 未ログイン | 会員ログインへ誘導する。 |
---
### データ整合性
| 観点 | 内容 |
|------|------|
| 所有者一致 | 表示は注文の会員がログイン会員と一致する場合に限る。 |
| 一覧と詳細 | 一覧の注文番号リンクから遷移する詳細は同一注文を表示する。 |
| 金額表示 | 金額内訳は注文・注文サブの保持値を参照する。税額は表示時に計算する。 |
| 決済情報 | 支払方法に応じた決済情報を表示時点のデータから表示する。決済連携の整合は決済機能を正とする。 |

### ログ・監査
本機能は固有の監査ログを主目的としない。
#### ログに出してはいけないもの
- Cookie値
- セッションIDの完全値
- 決済の機微番号の完全値

### 権限・認可
| 利用者状態 | 購入履歴詳細 |
|------------|--------------|
| 未ログイン | アクセス不可。会員ログインへ誘導する。 |
| ログイン済み会員 | 自分の注文のみ閲覧可能。他会員の注文は見つからない（HTTP404）。 |
