## 用語

| 用語 | 説明 |
|------|------|
| 商品サブクラス | 言語・状態などで区分した買取対象の商品単位。 |
| 商品クラス | 詳細の選択単位（カート追加の対象キー）。 |
| 状態 | カードの状態区分（NM等）。 |
| 同名カード | 同じカードに紐づく別バージョンの商品。買取価格一覧として表示する。 |
| 買取最低価格 | 数量指定・カート追加を出す下限の買取価格（`purchase_min_price`＝500）。 |

## 0203に無い定型節（設計書からは削除・2026-08-19）

#### エッジケース
| ケース | 扱い |
|--------|------|
| 商品IDの商品が無い | ページなし（HTTP404）とする。 |
| クエリ`lang`が無効・未指定 | 先頭言語を初期選択とする。 |
| クエリ`class`が無効・未指定 | 当該言語の先頭クラスを初期選択とする。 |
| 基本土地 | 同名カードの買取価格一覧を取得しない。 |
| 旧コードに対応が無い | トップページへリダイレクトする。 |
---
### データ整合性
| 観点 | 内容 |
|------|------|
| 一覧・詳細 | 詳細の商品サブクラスは一覧・検索と同じデータを参照する。買取価格は参照時点の値に一致する。 |
| 同名カード一覧 | 詳細に表示する同名カード一覧は買取検索の条件（状態NM・高額除外）に従う。 |
