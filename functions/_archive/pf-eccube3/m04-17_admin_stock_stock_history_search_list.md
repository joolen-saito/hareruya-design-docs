## 0203に無い定型節（設計書からは削除・2026-08-19）

#### エッジケース
| ケース | 扱い |
|--------|------|
| 初回表示（検索前） | セッションを消去し、価格一覧・在庫一覧とも空で表示する。 |
| 表示件数・ページ番号がセッションに無い状態で在庫一覧を作ろうとする | 在庫一覧を空配列として扱う。 |
| 並び順が想定外の値 | 並び順エラーを表示し初期表示へ戻す。 |
| 検索結果0件 | 「検索条件に該当するデータがありませんでした。」を各表で表示する。 |
| 他画面から商品ID・状態コード・言語が渡る | その条件だけで絞り、通常の検索フォーム条件は適用しない。 |

### データ整合性
| 観点 | 内容 |
|------|------|
| 価格一覧と在庫一覧 | 同一画面の2表は同じ検索条件をもとにするが、別クエリ・別ページネーションである。件数・ページは表ごとに独立する。 |
| 表示時点 | 各一覧は表示時点で履歴テーブルを読んだ結果である。表示後の更新は自動反映しない。 |
| 履歴と現在値 | 履歴は変更時点の値を記録したもので、商品の現在在庫・現在価格との一致は保証しない。 |
