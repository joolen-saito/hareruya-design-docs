## 一覧・検索の抽出・並べ替え（業務ルール）

対象エンティティは店頭買取受注で、ステータスマスタと内部結合する。

| 条件 | 扱い |
|------|------|
| ステータス指定なし | キャンセルステータス（リポジトリ定数 `CANCEL_STATUS_ID`、マスタ定数 `STATUS_CANCEL` と一致）以外に限定する。 |
| ステータス指定あり | 選択されたステータスに完全一致。フォームの選択肢から非推奨IDは除外されている。 |
| 査定ID | 完全一致。空なら条件にしない。 |
| 買取店舗 | 選択された `BaseInfo` のIDと受注の店舗が一致。未選択なら条件にしない。 |
| 買取金額（下限・上限） | `totalPrice` の範囲。両方入力かつ下限が上限より大きい文字列比較になる場合は値を入れ替えてから適用する。いずれか片方のみでも適用する。 |
| 査定申込日時 | `applyDate` が下限以上、上限以下。片側のみでも適用する。 |
| 買取日時 | キャンセルステータスなら `cancelDate`、それ以外なら `completeDate` が指定範囲に入るよう OR で組む。From・To はそれぞれ独立。 |
| 申込者名 | 半角・全角スペースまたはカンマで分割した各キーワードについて、姓・名・姓カナ・名カナのいずれかに部分一致（LIKE）を要求し、キーワード間は AND。 |
| 商品名（最大3キーワード） | 入力された各欄ごとに明細→規格→商品へ結合し、`name` または `name_en` に部分一致。キーワード間はラジオで AND か OR。LIKE のため `%` と `_` はエスケープして渡す。 |
| 会員ID | 紐付く会員のIDが一致。 |
| 棚戻し未完了のみ | `restocked_flg` が偽のみ。 |
| 並べ替え | ソートキーは現状マップに `default` のみがあり、列は受注の主キー（エイリアス `obo.id`）。順序はセッションまたは既定で `DESC`。 |

## 一覧列と表示値の対応

| 列 | 内容 |
|----|------|
| チェックボックス | `name="otcBuyOrderIds[]"`、値は受注の数値ID。 |
| 査定ID | `assessmentId`。詳細へのリンク。 |
| 申込者 | 姓と名を空白結合。 |
| 買取金額 | `totalPrice` を価格フィルタ表示。 |
| 買取店舗 | 紐付く `BaseInfo` の `shop_name`。 |
| 査定担当者 | `getLatestUpdaterByStatus(買取完了ステータスID)` の名前を優先するテンプレート式だが、移行先 ec-cube-enterprise 実装の当該メソッドは常に null を返すため、実質 `Member.name` が表示される（Twig の null セーフな評価に依存）。 |
| 最終更新者 | `Member.name`。 |
| ステータス | ステータスマスタの表示名。 |

### 入力項目

検索条件はDBに永続化せず、セッションにシリアライズ可能な形で保持する。フォーム名は `admin_otc_buy_order` で、CSRF保護は無効である。

| 項目名 | 必須／任意 | 最大長 | 初期値 | 保存先・扱い |
|--------|------------|--------|--------|----------------|
| 査定ID | 任意 | フォーム型に明示なし（実装確認値） | 空 | `assessment_id`。完全一致検索。セッション検索条件に含まれる。 |
| 申込者名 | 任意 | 同上 | 空 | `name_multi`。空白・カンマ分割の複数キーワード AND。セッションに含まれる。 |
| 会員ID | 任意 | 整数型 | 空 | `customer_id`。セッションに含まれる。 |
| 商品名（1〜3） | 任意 | 同上 | 空 | `product_name1`〜`product_name3`。セッションに含まれる。 |
| AND/OR選択 | 任意 | 選択肢2件 | フォーム生成時の既定は明示なし（送信値または既定の選択肢順に依存） | `product_name_select`。0 が AND、1 が OR（定数実装値）。 |
| ステータス | 任意 | マスタ選択 | プレースホルダ「ステータスを選択」 | `otc_buy_order_status`。非推奨ID除外済みクエリ。セッションに含まれる。 |
| 買取店舗 | 任意 | マスタ選択 | ログイン中管理者のデフォルト検索店舗（取得できなければ未選択） | `shop`。セッションに含まれる。 |
| 査定申込日時（開始） | 任意 | `datetime` 単一行、`0003-01-01` 以降の Range | 前月1日 00:00:00 | `application_date_from`。セッションに含まれる。 |
| 査定申込日時（終了） | 任意 | 同上（Range は開始側のみ明示） | 空 | `application_date_to`。 |
| 買取日時（開始） | 任意 | 同上 | 空 | `complete_date_from`。キャンセル時は取消日時列で判定。 |
| 買取日時（終了） | 任意 | 同上 | 空 | `complete_date_to`。 |
| 買取金額（下限） | 任意 | テキスト型 | 空 | `price_from`。数値比較はリポジトリ実装に従う。 |
| 買取金額（上限） | 任意 | テキスト型 | 空 | `price_to`。 |
| 棚戻し未完了のみ表示 | 任意 | チェックボックス | オフ | `restock_incomplete_only`。真のとき `restocked_flg` 偽のみ。 |

### エッジケース

| ケース | 扱い |
|--------|------|
| 検索結果0件 | 「検索条件に該当するデータがありませんでした。」見出しのみ。CSVブロックは検索結果があり件数が正のときだけ出るため、0件時はCSV操作も出ない。 |
| 商品名を1つも入れずに OR を選ぶ | 商品名による結合・絞り込みは付与されない。 |
| ステータスでキャンセルを選ぶ | フォームでは選べるが、指定時はキャンセル除外のデフォルト条件が上書きされ、キャンセルだけが対象になりうる。 |

### ログ・監査
一覧の表示・検索のみでは専用の業務ログ出力は設けていない。CSV出力時のログは別サービス。
#### ログに出してはいけないもの
- パスワード
- なりすまし対策トークン
- Cookie 値
- セッション ID の完全値
- Remember Me トークンの原値
---
### 権限・認可
当コントローラに固有のアノテーションによるロール制限はソース上は見えない。管理画面領域に入れた認証済み管理者が利用する前提とする。一覧から実行される CSV のうち戻しリスト系は別サービスで追加検証がある。
