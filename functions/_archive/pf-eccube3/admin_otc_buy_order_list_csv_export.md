#### エッジケース
| ケース | 扱い |
|--------|------|
| 選択 ID が空 | メッセージ `admin.csv.error.export.product`、リファラへリダイレクト。 |
| 非ダブルチェック済が混在 | メッセージ `admin.csv.error.export.not_export_status`。 |
| 複数店舗の査定が同時選択 | メッセージ `admin.csv.error.export.not_export_shop`。 |
| クエリ結果ゼロ行 | ヘッダのみの CSV になり得る。副作用の UPDATE と `flush` は条件を通過していれば実行される。 |
| 個別入力品目のみで在庫行が無い査定 | 在庫系クエリの結合により行に載らず、結果 CSV にそれら SKU は出現しない可能性がある（実装を確認値）。 |

| 観点 | 内容 |
|------|------|
| 一覧チェック状態と送信 | 画面上のチェックのみが POST の対象。ページングにより別ページの行は自動では含まれない。 |

| CSV データと詳細画面 | CSV はクエリタイミングでの在庫・明細の写し。並行編集していた場合との一致は保証しない。 |

## 0203に無い定型節（設計書からは削除・2026-08-19）

### ログ・監査
| タイミング | 記録内容 |
|------------|----------|
| 本処理 | ソース上、本機能用の専用 `log_info` 等は読み取り対象コードに明示されていない（コア共通ログに任せる）。 |
| EC インポート用成功時 | ステータス履歴テーブルへ操作者／時刻付きで状態遷移が残る経路がある。 |
#### ログに出してはいけないもの
- パスワード
- なりすまし対策トークン
- Cookie 値
- セッション ID の完全値
- Remember Me トークンの原値

### 権限・認可
| 利用者状態 | 本機能への到達 |
|------------|----------------|
| 未認証 | 管理画面の共通ログインにより到達しない。 |
| 管理画面の認証済み利用者 | 本ルートにルーティング登録されていれば画面上の一覧から送信できる。細部は管理画面共通の権限モデルを正とする。 |
---
### セッション
#### 本機能におけるセッション
| 観点 | 内容 |
|------|------|
| 検索条件キー `admin.otc_buy_order.*` | 一覧の検索・ページング維持に使われるが、CSV 送信フォームとは別であり、結果フォーム送信ではテンプレート上セッションを直接書き換えない（実装を確認値）。 |
#### セッションへ保存しない情報
CSV 送信は店頭買取 ID と種別のみを載せ、CSV ファイル本体や明細キャッシュはセッションに載せない。
---
### Cookie
| 観点 | 内容 |
|------|------|
| `shopId` | 検索フォーム POST 時に「買取店舗」選択と Cookie `shopId` の不一致を直すため `setcookie` が呼ばれる経路がある。CSV 送信そのものはこの Cookie を書き換えない（実装を確認値）。 |
---
### 排他制御・トランザクション
楽観ロックや明示的な悲観ロックは本 CSV 処理内では読み取り対象に現れない。複数管理者が同一査定に対して同時出力する場合、`executeUpdate` 後勝ちの状態になり得る（実運用は別検討）。
