## 1. 在庫警戒リストCSV出力

### 機能の目的と役割

在庫数が指定閾値を下回った（在庫切れしそうな）商品規格を抽出してCSV出力する機能。トレードチームが補充判断に用いる帳票で、商品規格単位（NM対象）で毎朝8時時点の直近データを出力する。在庫切れリスト（M04-06）と異なり、店舗指定を持たずデータをそのまま出力する。

本機能はExcel設計書上「Ph2で対応するため、Ph1では実装しない」と明記されており（在庫切れ、在庫警戒リストCSV出力シートの注記）、**現時点の ec-cube-enterprise 実装には在庫警戒リスト専用の Controller・Route・CSV出力Serviceは存在しない**（`src/` および `templates/` を `warning`／`在庫警戒` で横断検索して未検出）。本書は基本設計仕様書を正とし、出力列・抽出条件はExcel設計書（在庫警戒バッチを含む）を出典とする。実装はPh2着手時に確定する。

### 本書で扱うこと

- 在庫警戒リストCSV出力の業務要件（Excel設計書）と出力列定義
- 「店舗指定なしでそのまま出力」「商品規格単位・NM対象」「毎朝8時集計（バッチ）」という基本設計上の条件
- Ph1未実装である旨と、Ph2実装時の確定方針

### 本書で扱わないこと

- 在庫警戒の閾値・抽出条件・毎朝の集計の詳細（Excel上「在庫警戒バッチのシートの処理内に記載」とされ、当該バッチ設計を正とする）
- 在庫切れリストCSV出力（M04-06。同一画面に並ぶ別ボタン）
- URLエンドポイント・DBアクセス層・整形ロジック（Ph2実装で確定）

Excel設計上は「在庫切れ、在庫警戒リストCSV出力」画面に在庫切れリストCSV出力ボタン（識別ID 2）と並び、在庫警戒リストCSV出力ボタン（識別ID 3）として配置される。M04-06と異なり出力対象店舗による絞り込みは行わない。Ph1では画面・ルートとも未実装。

### CSV出力仕様（Excel設計書を出典）

| 項目 | 内容 |
|------|------|
| 対象データ | 指定閾値を下回った在庫の商品規格（NM対象）。店舗指定が存在しないためそのまま出力。直近のデータを出力。 |
| 抽出条件 | 在庫警戒バッチの処理仕様に従う（毎朝8時時点で条件に当てはまる商品規格を集計。当該バッチ設計を正とする。Ph1未実装のため実装要確認）。 |
| 出力単位 | 商品規格単位（NM対象） |
| 出力列 | 下表16列（Excel識別ID順）。 |
| 文字コード／ファイル名 | 実装要確認（Ph2実装で確定。本プロジェクトのCSV出力共通方式は `CsvExportService` 経由で `eccube_csv_export_encoding`／既定 `SJIS-win`）。 |

### プロセスフロー（Excel設計上の想定）

1. 在庫警戒バッチが毎朝8時時点で、閾値を下回った商品規格（NM対象）を集計する。
2. 在庫切れ・在庫警戒リスト出力画面で「在庫警戒リストCSV出力」ボタンを押下。
3. 店舗指定なしで直近の集計データをそのまま、上記16列でCSVダウンロードする。

> 上記はExcel設計上の想定フロー。実処理順・集計タイミング・エラー扱いはPh2実装および在庫警戒バッチ設計で確定（実装要確認）。

### 状態・データ更新

| 対象 | 内容 |
|------|------|
| 主データ | **参照のみ（出力）** の想定。集計済みの在庫警戒データを参照してCSV化するのみで業務データは更新しない。集計自体はバッチが担う。 |
| 在庫の参照元 | 移行先では商品規格 `dtb_product_class.stock` および規格在庫 `dtb_product_stock.stock` を参照する想定（バックヤード在庫数を含む。実装要確認）。 |

### 関連設計への接続点

- 出力列・出力単位（商品規格・NM対象）・店舗指定なし出力・直近データという要件はExcel設計書（在庫警戒リストCSV出力シート）を正とする。
- 閾値・抽出条件・毎朝8時集計は在庫警戒バッチの設計シートを正とする。
- URLエンドポイント・DBカラム・整形・文字コードはPh2実装着手時にec-cube-enterprise実装で確定する。

## リニューアル移行時の扱い

- 本機能は新規実装であり、対応する現行（pf-eccube3）の同等機能は存在しない。基本設計上はPh2対応の機能であり、Ph1では実装しない（Excel注記）。仕様は基本設計仕様書（在庫管理機能・在庫警戒バッチ）を正とする。
- 在庫数の参照先は、移行先のec-cube-enterpriseでは商品規格（`dtb_product_class.stock`）および商品在庫（`dtb_product_stock.stock`）であり、いずれもec-cube-enterprise実装に実在する。バックヤード在庫数の取得元カラムはPh2実装で確定する（実装要確認）。
- 抽出閾値・対象（商品規格単位・NM対象）・毎朝8時の集計はバッチで行う前提のため、抽出条件と集計仕様は基本設計仕様書（在庫警戒バッチ）を正とする。

### フェーズ2対応（フェーズ1では実装不要）

本書は現行実装からのリバースであり、以下は現行挙動として記述しているが、Excel基本設計がフェーズ2対応としている。フェーズ1では実装・テストの対象外とする。

- 在庫警戒リストCSV出力（※Excel基本設計 0202「在庫警戒リストCSV出力」はフェーズ2対応。フェーズ1では実装しない）。機能まるごとフェーズ2対応。Excel原文: 「在庫警戒リストCSV出力はPh2で対応するため、Ph1では実装しない」（0202 在庫警戒リストCSV出力）
