# m05-17_admin_order_order_shipping_memo（管理画面_受注管理_配達用メモ登録）

## 業務ロジック

### 保存の単位

出荷用メモは出荷ごとに1つ持つ。1受注に複数の出荷があるときは、出荷の数だけ独立してメモを持つ。任意項目とし、未入力のまま保存したときは保存先の値を未設定とする。出荷用メモに対する金額計算・税計算・丸めは行わない。

### 受注編集画面での入力範囲

受注が複数お届け先でないときに限り、先頭の出荷を対象とした出荷の入力欄を受注の入力に加える。複数お届け先の受注のときは、受注編集画面に出荷用メモ欄を表示しない。出荷用メモ欄には、対象の出荷に保存済みのメモを初期値として表示する。新規登録のときは空とする。

### 出荷編集画面での入力範囲

受注に紐づく出荷をすべて取得し、出荷ごとの入力欄を並べる。各欄には当該出荷に保存済みのメモを初期値として表示する。複数お届け先を含む全出荷の出荷用メモは、この画面で出荷ごとに編集する。

### 保存の判定順序

| 画面 | 判定 | 結果 |
| --- | --- | --- |
| 受注編集画面 | 検証に成功したとき | 出荷用メモを含む出荷情報を受注の保存に同梱して保存する。出荷が新規のときは作成日時と更新日時を設定する |
| 受注編集画面 | 検証に失敗したとき | 同じ画面を再表示し、入力値とエラーを表示する。出荷用メモは保存しない |
| 出荷編集画面 | 購入フローの検証に成功し、かつ登録の要求のとき | 各出荷を保存する。新規の出荷のときは作成日時と更新日時を設定する |
| 出荷編集画面 | 保存に成功したとき | 出荷登録と保存完了のメッセージを表示し、出荷編集画面へ遷移する |
| 出荷編集画面 | 検証または保存に失敗したとき | エラーのメッセージを表示し、同じ画面を再表示する。出荷用メモは保存しない |

出荷用メモだけを保存する経路は持たない。受注編集画面では受注の保存に、出荷編集画面では出荷の保存に同梱して保存する。

### 保存後の参照

保存した出荷用メモは、出荷用および受注用の出力ファイルの項目「配達用メモ」として参照できる。

### エラー時の扱い

| 事象 | 扱い |
| --- | --- |
| 出荷用メモが最大長を超えたとき | 該当項目にエラーを表示し、同じ画面を再表示する。保存しない |
| 出荷情報全体の検証に失敗したとき | 同じ画面を再表示する。出荷用メモを含めて保存しない |
| 出荷編集の保存処理で例外が発生したとき | エラーのメッセージを表示し、同じ画面を再表示する |

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | 受注編集画面または出荷編集画面の送信に含まれる出荷用メモの文字列 |
| 成功時出力 | 出荷用メモを含む出荷情報の保存と、保存完了のメッセージを伴う画面の再表示または遷移 |
| 失敗時出力 | 同じ画面の再表示、入力値とエラーの表示。出荷用メモは保存しない |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 更新 | 受注編集画面で検証に成功したときの、先頭の出荷の出荷用メモ |
| 更新 | 出荷編集画面で検証に成功し登録の要求のときの、各出荷の出荷用メモ |
| 追加 | 出荷が新規のときの、作成日時と更新日時の設定 |
