# m02-03_admin_home_home_sales_chart（管理画面_トップ売上状況グラフ）

## 業務ロジック

### 画面の構成と描画

管理画面ホームの売上状況カードに、週間・月間・年間のタブと、各タブに対応する空のグラフ領域、読み込み中の表示を出す。ホーム表示の時点ではグラフを描画しない。

ページの読み込みが終わったときにグラフ用データを非同期で取得し、返された3つの集計を週間・月間・年間の順に対応づけて描画する。取得が完了したときは読み込み中の表示を消す。取得に失敗したときも読み込み中の表示は消えるが、グラフは描画されない。

### 集計する区間

| 区間 | 集計範囲 | 集計単位 |
|------|----------|----------|
| 週間 | 当日から過去へ約一週間さかのぼった日の0時から現在時刻まで | 日単位（`Y/m/d`） |
| 月間 | 当月1日0時から現在時刻まで | 日単位（`Y/m/d`） |
| 年間 | 現在時刻から過去へ約一年さかのぼった月の1日0時から現在時刻まで | 年月単位（`Y/m`） |

各区間は開始日から終了日まで1日ずつ進めて集計単位を用意し、売上金額と件数を0で初期化する。売上が無い期間も横軸のラベルとして残る。年間は集計単位が年月のため、同一月の各日が同一の単位へ集約され、月単位の棒になる。

範囲内の各受注は、受注日を集計単位の書式へ変換して該当する単位へ加算する。売上金額は加算し、件数は1増やす。範囲外の受注は数えない。

### 集計と表示の規則

| 項目 | 内容 |
|------|------|
| 集計対象 | 売上対象外の受注ステータスを拡張フックで確定したうえで、確定後に売上集計の対象となる受注だけを数える |
| 売上金額の累積 | 集計単位ごとに、条件に一致するときだけ受注の支払合計金額を加算する。税・送料・値引・手数料の内訳は本グラフで再計算しない |
| グラフ系列 | 棒グラフの縦棒は売上金額だけを用いる。件数は応答に含まれるが、系列としては使わない |
| 表示形式 | ツールチップと縦軸目盛りは通貨記号を前置し、3桁区切りのカンマを付す。縦軸目盛りは整数値のときだけラベルを表示する。横軸ラベルは集計単位のキーをそのまま用いる |

本グラフは入力フォームを持たない。タブを切り替えたときは表示領域が変わるだけで、サーバへ送る入力値を生成しない。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| グラフ用の要求が非同期要求でないとき、またはなりすまし対策トークンが妥当でないとき | 集計を行わず、HTTP400でステータスNGの応答を返す。フロントは失敗時の処理を持たないため、利用者向けのメッセージは出ない |
| データベース読み取りに障害があるとき | アプリケーションの共通例外処理に委ねる。本グラフ専用の利用者向けメッセージは設けない |
| 表示直後にデータが変化したとき | 描画済みのグラフは同一瞬間のスナップショットではない。リアルタイムに更新しない |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | ホーム画面を開いたときの表示要求と、グラフ用データの非同期要求。グラフ用データは利用者入力を受け取らず、認証済みの状態となりすまし対策トークンを前提とする |
| 成功時出力 | 週間・月間・年間の集計を並べた応答。各集計は単位ごとに売上金額と件数を持ち、売上が無い単位のときは0を返す |
| 失敗時出力 | 非同期要求またはなりすまし対策トークンの条件を満たさないときは、HTTP400でステータスNGの応答 |

## 表示メッセージ

本グラフは利用者向けの画面メッセージを表示しない。読み込み中の表示以外に、正常・エラー・完了の文言を生成しない。
