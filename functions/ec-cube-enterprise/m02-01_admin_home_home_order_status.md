# m02-01_admin_home_home_order_status（管理画面_トップ受注状況）

## 業務ロジック

### 除外するステータス

既定では、キャンセル・出荷完了・決済処理中・購入処理中・返品に相当する受注ステータスを、件数の集計と表示の両方から除く。拡張処理が除外の一覧を差し替えたときは、差し替え後の一覧を件数の取得とマスタ行の取得の両方に用いる。拡張処理がホームへ渡す値を上書きしたときは、以降の画面表示は上書き後の値に従う。

### ステータス別件数

除外に含まれない受注ステータスだけを対象に、受注データを識別子ごとに数える。除外されたステータスに属する受注は件数に含めない。期間・会員・宛先・支払方法・店舗などの条件は課さず、登録されている受注を対象とする。金額計算・税計算・丸めは行わない。

### 表示する行

除外に含まれない受注ステータスをマスタから取得し、マスタの表示順の昇順で並べる。件数の多い順には並べ替えない。各行に件数を表示し、集計結果に当該識別子が無いときは0を表示する。マスタに存在して除外もされていないステータスは、受注が1件も無いときも行として残る。

### 組み立ての判定順序

| 順序 | 判定 | 結果 |
| --- | --- | --- |
| 1 | 除外の一覧を確定する | 拡張処理が書き換えたときは、確定後の一覧を以降すべてに用いる |
| 2 | 件数を集計する | 除外に含まれるステータスの受注は集計から除く |
| 3 | 表示行をマスタから取得する | 除外に含まれるステータスはマスタ行としても出さない |
| 4 | 行と件数を合成する | マスタ行の識別子ごとに集計結果を参照し、無いときは0とする |

### 受注一覧への遷移

| 遷移元 | 一覧へ渡す条件 |
| --- | --- |
| 受注状況カードの見出し | 見出しから遷移したときは、ステータスの条件を渡さない |
| ステータスの行 | 行から遷移したときは、当該ステータスの識別子を渡す |

ステータスの識別子を渡したときは、受注一覧の初回表示で、そのステータスを含む検索条件が組み立てられる。その条件が受注一覧の検索条件として保持されることがある。以降のページ送りと戻りは受注一覧の規則に従う。

### エラー時の扱い

| 事象 | 扱い |
| --- | --- |
| データ読み取りに障害があったとき | 共通の例外処理に委ねる。本ブロック専用の文言は設けない |
| 表示直後に受注が更新されたとき | 表示した件数と受注一覧の件数が一致しないことがある。本ブロックは常時更新ではない |

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | ホーム画面の表示要求。ボディの入力を持たず、ステータスをクエリで受け取ることもしない |
| 成功時出力 | 受注状況カードに、ステータス名と件数を表示する |
| 失敗時出力 | データ取得に失敗したときは共通の例外処理に委ね、ホーム画面全体が表示できないことがある。本ブロック単体の代替文言は持たない |

## 表示メッセージ

本機能は固有の文言を持たない。表示するのはステータス名と件数である。
