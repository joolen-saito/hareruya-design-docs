# m11-06_admin_system_setting_setting_system_system_info（管理画面_設定_システム設定_システム情報）

## 業務ロジック

### 表示する情報

画面には実行時に取得した文字列を並べるだけであり、件数の集計や業務判定は行わない。要求に付いたクエリの有無やキーは表示内容に影響しない。

| 行 | 表示する値 |
|------|------|
| EC-CUBE | 製品が定数として保持するバージョン文字列 |
| サーバーOS | 稼働しているOSの情報をそのまま表示する |
| DBサーバー | SQLiteのときは接頭辞「SQLite version 」、MySQLのときは接頭辞「MySQL 」を付け、いずれでもないときは接頭辞を付けずに、データベースのバージョン文字列を連結する |
| WEBサーバー | 要求のサーバ情報から取得する。取得できないときは未設定に相当する表現になる |
| PHP | PHPのバージョン文字列の後に、読み込まれている拡張の一覧をカンマ区切りで並べ、全体を丸括弧で包んで連結する |
| User Agent | 要求のUser-Agentを表示する。取得できないときは未設定に相当する表現になる |

各行の見出しは翻訳済みのラベルとする。

### PHP情報の表示

PHP情報の表示可否の設定が真のときだけ、PHP情報のカードと埋め込み枠を出力する。既定の環境設定値は文字列の「0」であり、真偽に変換すると偽になるため、既定ではPHP情報を出力しない。

表示可否が真のときは、埋め込み枠の中でPHP情報の出力をそのまま応答本文とする。管理画面の共通フレームは通さない。

本機能は参照専用であり、入力フォームを持たない。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| 権限に紐づく拒否対象のパスが、現在の要求パス（クエリを除く）と管理ルートの接頭辞付きで先頭一致するとき | 画面本文を描画せずアクセス拒否（HTTP 403）とする。システム情報の本体と、より長いパスを持つPHP情報側の要求は、同一の拒否パターンで両方とも拒否されうる |
| データベースの読み取りに失敗したとき | 共通の例外処理に委ねる |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | システム情報画面の表示要求。クエリは表示内容に影響しない |
| 成功時出力 | システム情報の画面。表示可否の設定が真のときはPHP情報の埋め込みを含む |
| 失敗時出力 | 認可拒否のときはアクセス拒否（HTTP 403）。読み取り失敗のときは共通の例外処理 |

## 表示メッセージ

本機能は情報の表示だけを行い、利用者向けの通知メッセージを表示しない。
