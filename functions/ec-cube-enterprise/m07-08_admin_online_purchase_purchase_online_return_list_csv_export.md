# ネット買取管理 — 戻しリストCSV

## 業務ロジック

### 出力対象

ネット買取の棚戻し業務で使うリストを出力する。対象は買取検索/一覧で選択した買取注文で、選択したものだけを出力する。店頭買取の買取注文は別系統として扱い、本機能では対象にしない。

参照するのは、選択した買取注文に紐づく実在庫と、その規格・棚番、および本店の店舗基本情報に設定された金額の閾値である。

出力できるのは、選択した買取注文がすべて存在し、かつステータスが入庫待ちまたは入庫済みのときに限る。次のいずれかに当たるときは出力せず、エラーを表示して買取検索/一覧の検索結果画面へ戻す。

| 条件 | 扱い |
| --- | --- |
| 買取注文を1件も選択していない | 出力せず、買取検索/一覧画面へ戻す |
| 選択した買取番号が1件も存在しない | 出力せず、対象が見つからない旨を表示する |
| 選択した中に存在しない買取番号がある | 出力せず、その買取番号を示して表示する |
| 選択した中に入庫待ち・入庫済み以外のステータスがある | 出力せず、その買取番号を示して表示する |

### ピッキング区分の決め方

ピッキング区分は、店舗に設定された金額の閾値による3区分と、サプライの計4通りとする。区分は「●●円未満」「●●円以上▲▲円未満」「■■円以上」で、サプライ品は「サプライ」とする。

ネット買取管理では店舗が本店しかないため、使う閾値は常に本店の閾値である。閾値の表示も基準価格を参照して行う。セール中で金額が変わっても棚を移動することはないためである。

### サプライ品かどうかによる出し分け

同じ行でも、対象がサプライ品かどうかで3つの項目の内容が変わる。

| 項目 | サプライ品のとき | サプライ品でないとき |
| --- | --- | --- |
| 言語/状態 | 「サプライ品」と表示する | 言語/状態の形式で出力する。Foilのときは先頭にFoilを付ける（例: FoilJP/NM） |
| 略称 | 表示しない | 略称を出力する |
| 商品名 | 取り除きの規定を適用しない | 商品名から略称・言語・状態・色・レアリティを取り除いた文字列を出力する |

### 色とレアリティ

色/Rは、商品名から取り出した色とレアリティを並べて出力する（例: 金R）。

### 棚番号

棚番号は本店のものだけを出力する。

### データの更新

本機能は参照だけを行い、買取注文・在庫のデータを更新しない。

## 入出力

### 入力

| 項目 | 内容 |
| --- | --- |
| 対象の指定 | 買取検索/一覧で選択した買取注文 |
| 開始操作 | 買取検索/一覧画面で戻しリストCSVの出力を実行する |

### 出力: CSVファイル

| 識別ID | 項目名 | 備考 |
| --- | --- | --- |
| 1 | ピッキング区分 | 本店の金額閾値による区分（●●円未満／●●円以上▲▲円未満／■■円以上）、またはサプライ |
| 2 | 棚番号 | 本店の棚番号 |
| 3 | 言語/状態 | 言語/状態の形式。Foilのときは先頭にFoilを付ける。サプライ品は「サプライ品」 |
| 4 | 略称 | 略称。サプライ品では出力しない |
| 5 | 色/R | 商品名から取り出した色とレアリティ |
| 6 | 数 | — |
| 7 | 商品名 | サプライ品でないときは、略称・言語・状態・色・レアリティを取り除いた商品名 |
| 8 | 基準価格 | — |

出力に成功したときはCSVファイルのダウンロードとして返す。出力できないときはファイルを返さず、買取検索/一覧の画面へ戻す。
