# 在庫管理 — 在庫移動・振替登録/編集

## 業務ロジック

### 在庫移動と在庫振替

在庫検索一覧でチェックした商品在庫を引き継いで開き、店舗間の在庫「移動」または同一店舗内の在庫区分間の「振替」を登録・編集する。

- 移動: 出庫元の店舗・在庫区分から入庫先の店舗・在庫区分へ在庫を動かす。登録した時点で移動元の在庫を減らし、ステータスを「新規登録」とする。以降はピック・出庫承認申請 → 出庫承認 → 入庫承認申請 → 入庫承認の各段階を経て入庫先の在庫を増やす。出庫元と入庫先が同一店舗のときは承認を要さず、出庫承認申請を更新した時点で入庫完了とする。
- 振替: 同一店舗内の在庫区分間で、1対1の商品移動（状態変更による移動。例: ショーケース品＝スマレジ在庫からEC在庫＝EC-CUBEへの移動）を登録する。登録した時点で振替元の在庫を減らし、ステータスを「振替承認待ち」として在庫承認一覧へ載せる。

### 初期表示

| 画面 | 表示するもの |
| --- | --- |
| 移動 初期登録 | 受け取った商品在庫IDから商品在庫をID昇順で取得し、先頭の在庫の店舗名・在庫区分名を出庫元として表示する。出庫元の店舗・在庫区分と、明細ごとの移動元商品在庫IDを初期値に置く |
| 移動 ピック・出庫承認申請（編集） | 現在のステータスからこの画面が適切かを判定し、適切でなければ対応する画面へ移す。明細をID昇順、ステータス履歴を更新日の降順で表示し、欠品点数・メモ・承認通知先を編集させる |
| 振替 初期登録 | 受け取った商品在庫IDから商品在庫を取得し、本店ECと先頭の在庫の在庫区分名を表示する。明細ごとの振替元商品在庫IDを初期値に置き、振替先を選ぶ商品検索モーダルを備える |

対象の在庫移動・振替データを指定して開く画面は、IDが数字でないときと該当データが無いときは見つからない扱いとする。

### 入力項目（在庫移動の登録）

| 画面上の項目 | 必須 | 内容・制約 |
| --- | --- | --- |
| 出庫元店舗 | 必須 | 先頭の商品在庫の店舗で初期化する隠し項目。店舗名を画面に表示する |
| 出庫元在庫区分 | 必須 | 先頭の商品在庫の在庫区分で初期化する隠し項目。在庫区分名を画面に表示する |
| 入庫先店舗 | 必須 | 店舗から選ぶ。未指定の選択肢を先頭に置く |
| 入庫先在庫区分 | 必須 | EC-CUBE在庫／スマレジ在庫から選ぶ |
| メモ | 任意 | 在庫移動・振替のメモ |
| 移動点数 | 必須 | 対象の商品在庫ごとに入力する。1以上で、設定で定めた在庫変更点数の上限以下 |

入力を受け取った後に次を追加で確かめる。

- 出庫元（店舗と在庫区分）と入庫先（店舗と在庫区分）が完全に一致するときは、入庫先在庫区分の項目に「出庫元と入庫先が同じです。」を表示する。
- 明細の移動点数がその商品在庫の現在の在庫数を超えるときは、その明細に「移動点数が現在の在庫数を超えています。」を表示する。

### 入力項目（在庫振替の登録）

| 画面上の項目 | 必須 | 内容・制約 |
| --- | --- | --- |
| メモ | 任意 | 在庫移動・振替のメモ |
| 振替元商品在庫 | 必須 | 在庫検索一覧から引き継いだ商品在庫を明細ごとに保持する隠し項目 |
| 振替先商品コード | 必須 | 商品検索モーダルで選ぶか直接入力する |
| 振替点数 | 必須 | 1以上で、設定で定めた在庫変更点数の上限以下 |
| 承認通知先部署 | 任意 | 対象店舗に所属するメンバーの部署から選択肢を作る |
| 承認通知先メンバー | 必須 | 複数選択。1件以上選ぶ |

振替は出庫元・入庫先とも本店ECの同一店舗・同一在庫区分を前提とする。

### 登録の判定順序（在庫移動）

| 順序 | 判定 | 結果 |
| --- | --- | --- |
| 1 | 引き継いだ商品在庫IDから対象在庫を取得できるか | 取得した在庫と入力された移動点数を突き合わせて登録内容を組み立てる |
| 2 | 送信された内容か、入力の検証を通るか | 通らなければ保存せず、同じ登録画面を再表示する |
| 3 | 明細ごとに、商品規格・入庫先店舗・入庫先在庫区分が一致する移動先の商品在庫があるか | 無ければ登録できない（移動先の商品在庫が見つからない） |
| 4 | 3までを通ったか | ステータス「新規登録」の在庫移動振替と明細を作り、在庫を減らして確定する |

確定するときの内容は次のとおり。

- 移動として在庫移動振替を新規に作り、ステータスを「新規登録」とする。
- 明細ごとに基準総額（基準価格×移動点数）と出庫総原価を計算して記録する。
- 変動種別を移動出庫、変動元を在庫移動の編集、変動元IDを在庫移動振替のIDとして在庫変動履歴を作る。
- 移動元の商品在庫の在庫数と総原価を移動点数分だけ減らす。

これらは一括で確定し、途中で失敗したときは在庫の減算を含め一切確定しない。確定できたときは保存しましたを表示してピック・出庫承認申請画面へ移し、失敗したときは保存に失敗しましたを表示して同じ登録画面を再表示する。

### 更新の判定順序（ピック・出庫承認申請）

| 順序 | 判定 | 結果 |
| --- | --- | --- |
| 1 | 出庫元店舗と入庫先店舗が同じか | 同じなら次のステータスを「入庫完了」、違うなら「出庫承認待ち」とする |
| 2 | 明細の欠品点数が0より大きいか | 大きい明細は欠品登録者を記録する |
| 3 | 店舗内移動か | 店舗内移動のときだけ入庫先の在庫を増やす（次項） |

店舗内移動のときは、入庫数（移動点数から欠品点数を引いた数）を明細に反映し、入庫先の商品在庫の在庫数と総原価を入庫数分だけ増やし、変動種別を移動入庫として在庫変動履歴を作る。入庫数が0の明細は在庫を動かさない。

あわせて未承認の在庫承認一覧（出庫の承認）を作る。更新は一括で確定する。確定できたときは保存しましたを表示し、店舗内移動なら在庫移動完了画面、店舗間移動なら移動出庫承認画面へ移す。

### 登録の判定順序（在庫振替）

| 順序 | 判定 | 結果 |
| --- | --- | --- |
| 1 | 送信された内容か、入力の検証を通るか | 通らなければ保存せず、同じ登録画面を再表示する |
| 2 | 明細の振替点数が0以下、または振替先商品コードが空か | 該当する明細は登録の対象から外す |
| 3 | 振替元の商品在庫、振替先商品コードに一致する商品規格、振替先の商品在庫（商品規格・本店・在庫区分で特定）がそろうか | いずれかが無ければ登録できない（振替先の商品コードが見つからない） |
| 4 | 登録できた明細が1件以上あるか | 0件なら登録できない（登録可能な振替明細がない） |

確定するときの内容は次のとおり。

- 振替として在庫移動振替を新規に作り、出庫元と入庫先をともに本店EC・同一在庫区分、ステータスを「振替承認待ち」とする。
- 明細を作り、変動種別を振替出庫、変動元を在庫振替の編集として在庫変動履歴を作る。
- 振替元の商品在庫の在庫数と総原価を振替点数分だけ減らす。
- 未承認の在庫承認一覧（振替出庫の承認、件数は登録できた明細数）を作る。

これらは一括で確定し、途中で失敗したときは在庫の減算を含め一切確定しない。確定できたときは保存しましたを表示して在庫振替承認画面へ移し、失敗したときは保存に失敗しましたを表示して同じ登録画面を再表示する。

### ステータスと画面の対応

| ID | ステータス | 表示する画面 |
| --- | --- | --- |
| 1 | 新規登録（移動の登録直後） | ピック・出庫承認申請 |
| 2 | 出庫承認待ち | 出庫承認 |
| 3 | 却下 | 完了 |
| 4 | 出庫承認済み | 完了 |
| 5 | 移動中 | 入庫承認申請 |
| 6 | 入庫承認待ち | 入庫承認 |
| 7 | 入庫完了（店舗内移動の更新確定先・入庫承認の確定先） | 完了 |
| 8 | 振替承認待ち（振替の登録直後） | 振替の承認 |

振替は「振替承認待ち」で承認画面、「却下」「入庫完了」で完了画面に対応する。現在開いている画面が対応先と同じときは移さずそのまま表示し、画面の移し合いが続かないようにする。移動・振替の区分が振替でないデータや、対応の無いステータスのデータを振替の画面で扱おうとしたときは、エラーを表示して在庫履歴の画面へ移す。

### 在庫の増減と履歴

- 登録時の減算: 移動の登録と振替の登録のどちらも、登録した時点で移動（振替）元の商品在庫の在庫数・総原価を点数分減らし、変動種別を移動出庫／振替出庫として在庫変動履歴を残す。
- 入庫時の加算: 店舗内移動は出庫承認申請の更新で入庫先の商品在庫に加算する（変動種別は移動入庫）。店舗間移動と振替は、以降の承認の段階で加算する。
- 在庫変動理由: 在庫変動理由は「在庫移動」「在庫振替」とし、理由の入力項目は設けない（理由は空で登録する）。
- ステータス履歴: 在庫移動振替を登録・更新したとき、ステータスが変わった場合にだけステータス履歴を追記する（更新者は更新したメンバー）。登録・更新の処理側で履歴を明示的に作ることはせず、ステータスの変化を契機に自動で記録する。

### エラー時の扱い

| エラー内容 | 処理 |
| --- | --- |
| 送信されていない、または入力の検証を通らない | 保存に失敗しましたを表示し、同じ登録・編集画面を再表示する。データは更新しない |
| 出庫元と入庫先の店舗・在庫区分がどちらも同じ | 入庫先在庫区分に「出庫元と入庫先が同じです。」を表示する |
| 移動点数が現在の在庫数を超える | 明細に「移動点数が現在の在庫数を超えています。」を表示する |
| 承認通知先メンバーを1件も選んでいない | 項目にエラーを表示し、保存しない |
| 振替先商品コードが未入力 | 「振替先の商品コードを入力してください。」を表示する |
| 振替先商品コードに該当する商品規格・在庫が無い、登録できる明細が0件 | 登録せず、保存に失敗しましたを表示して同じ登録画面を再表示する |
| 出庫承認の送信時に出庫承認待ちでない | 状態が違う旨を表示し、対応する画面へ移す |
| 振替の承認で移動・振替の区分が振替でない、または対応の無いステータス | エラーを表示し、在庫履歴の画面へ移す |
| 振替の承認・却下を登録者本人が行おうとした | 承認・却下させない |
| 指定した在庫移動・振替データが存在しない | 見つからない扱いとする |

### 他機能との境界

- 在庫検索一覧側の遷移可否の判定（複数店舗・複数在庫区分・編集権限なし・在庫0の警告）は在庫検索一覧の仕様であり、本機能はそれらを通過した在庫を受け取る前提とする。
- 出庫承認、入庫承認申請・入庫承認、振替承認における承認・却下・差し戻しと、それに伴う在庫の加算の確定は各機能の仕様とする。
- 在庫移動振替一覧、在庫移動実績インポート、在庫移動指示、在庫移動CSV出力、ピックリスト・戻しリストPDFの仕様は各機能の仕様とする。
- 欠品理由と廃棄理由の区別、差分商品の追加といった差し戻し・欠品登録の業務条件は本機能では確定しない。

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | 在庫検索一覧から引き継ぐ商品在庫ID、在庫移動・在庫振替の登録項目、編集時の欠品点数・メモ・承認通知先 |
| 成功時出力 | 保存しましたの表示と、次の段階の画面への遷移 |
| 失敗時出力 | 同じ画面の再表示と、項目ごとのエラー表示 |

### 出力: 振替先の商品情報

振替先の商品規格を指定すると、商品名・商品コード・言語・カード状態・Foil・基準価格を返す。振替明細の振替先欄の表示に使う。指定が0以下のときは不正な要求として扱い、該当する商品規格が無いときは見つからない扱いとする。

### 入出力: 永続化

| 対象 | 操作 | 内容 |
| --- | --- | --- |
| 在庫移動振替 | 登録・更新 | 移動・振替の区分、ステータス、出庫元の店舗と在庫区分、入庫先の店舗と在庫区分、メモ、却下メモ、登録メンバー、更新メンバー、各承認者と承認日時、送り状番号、在庫移動指示ID |
| 在庫移動振替の明細 | 登録・更新 | 移動元・移動先の商品在庫、移動点数、基準総額、出庫総原価、欠品点数、差分点数、入庫点数、欠品・差分の登録者 |
| ステータス履歴 | 登録 | 在庫移動振替、ステータス、更新メンバー。ステータスが変わったときに追記する |
| 商品在庫 | 更新 | 店舗と在庫区分ごとの在庫数・総原価を増減する |
| 在庫変動履歴 | 登録 | 変動種別（移動出庫／移動入庫／振替出庫）、変動元の種別（在庫移動の編集／在庫振替の編集）、変動元IDとしての在庫移動振替ID |
| 在庫承認一覧 | 登録 | 振替の登録と店舗内移動の更新で、未承認のデータを作る |

登録・更新は一括で確定し、失敗したときは在庫の減算を含め一切確定しない。
