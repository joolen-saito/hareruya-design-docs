# 在庫管理 — 欠品履歴CSV出力

## 業務ロジック

### 出力対象

欠品履歴検索一覧で欠品検索の状態で検索した結果を、そのままCSVとして出力する。管理者が一覧のCSVダウンロードを実行したときに動く。

対象は、在庫変動理由区分が廃棄系の在庫変動履歴である。親区分「廃棄」と、子区分「欠品減算（受注）」「欠品減算（移動）」が該当する。入庫承認待ちの在庫情報は一覧に出ないため対象にならない。

本店在庫・支店在庫・スマレジ（実店頭）在庫を横断し、1ファイルにまとめて出力する。

出力するのは検索結果の全件で、行を個別に選ぶ操作は無い。一覧の画面が検索結果全件の在庫履歴IDを自動で送る。送られたIDのうち整数として1以上のものだけを対象とし、0以下の値は捨てる。

### 出力順

一覧に表示されている順と同じ順で出力する。並べ替えは次の3段で行う。

1. 商品コードの降順
2. 店舗のIDの降順（在庫区分では並べ替えない）
3. 登録日時の降順（最新が先）

### 出力できないとき

| 条件 | 結果 |
| --- | --- |
| 有効な在庫履歴IDが1件も無い | CSVを出さず、欠品履歴検索一覧へ戻す。戻り先は直前に見ていたページ（記録が無ければ1ページ目） |
| 指定したIDに該当する在庫履歴が無い／出力する行が1件も作れない | CSVを出さず、エラーを表示して遷移元の画面へ戻す。遷移元が分からないときは在庫履歴一覧へ戻す |
| 上記以外 | CSVファイルをダウンロードとして返す |

有効な在庫履歴IDが1件も無いときのエラーメッセージ（M04-20-MSG-002）は、画面のアラート表示が読み取る領域とは別の領域に積まれるため、実際には画面に出ない可能性がある（要実機確認）。

### データの更新

本機能は参照だけを行い、在庫も履歴も更新しない。欠品理由の書き換え（欠品理由と更新日時・更新者の更新）は欠品履歴一覧側の機能であり、CSV出力では行わない。

### 他機能との境界

同じ在庫変動履歴の画面からは在庫履歴CSVも出力できる。そちらは廃棄系以外を含む在庫変動履歴が対象で、列の構成も本機能とは異なる。本機能が出すのは欠品（廃棄系）だけである。

欠品履歴の検索条件・一覧項目・欠品理由の編集は欠品履歴検索一覧の仕様による。本機能はその検索結果を受け取って出力するだけで、検索条件を自身で持たない。

## 入出力

### 出力: CSVの列

1行目に列名の見出し行を出し、在庫履歴1件につき1行を出力する。各行は商品在庫から商品規格・商品をたどって商品情報を補う。値を持たない列は空欄とする。

列は次の16列・この順とする。

| # | 列名 | 出力する値 |
| --- | --- | --- |
| 1 | 商品コード | 商品規格の商品コード |
| 2 | 商品名 | 商品の名称 |
| 3 | 言語 | 商品規格の言語の日本語名 |
| 4 | 状態 | 商品規格のカード状態のコード |
| 5 | Foil | 常に空欄。Foilのマスタが未整備のため値を持たない |
| 6 | 店舗 | 在庫の店舗 |
| 7 | 在庫区分 | EC-CUBE在庫 ／ スマレジ在庫 |
| 8 | 登録元 | 履歴の登録元 |
| 9 | 登録元ID | 登録元のID |
| 10 | 欠品点数 | 欠品登録された点数 |
| 11 | 欠品時販売価格 | 欠品登録した時点の販売価格。受注によるものは受注情報が、移動によるものは移動情報が持つ販売価格 |
| 12 | 欠品理由 | 履歴に登録された欠品理由 |
| 13 | 登録日 | `Y-m-d H:i` の形式。未設定のときは空欄 |
| 14 | 登録者 | 登録した管理者 |
| 15 | 最終更新日 | `Y-m-d H:i` の形式。未設定のときは空欄 |
| 16 | 最終更新者 | 最後に更新した管理者 |

うち 店舗・在庫区分・登録元・登録元ID・欠品時販売価格・欠品理由・最終更新日・最終更新者 の8列は、現行より追加する列である。

移行先の現状の出力は15列で、上表と2点食い違う。**上表（基本設計）を正とし、移行先の実装を合わせる。**

- 「在庫区分」を「在庫場所」という列名で出しており、値も EC-CUBE ／ スマレジ の在庫場所を出している。
- 「登録元ID」の列が無い（在庫履歴CSV側には登録元IDの列がある）。

### 出力: CSVファイル

| 項目 | 内容 |
| --- | --- |
| 文字コード | CSV出力の設定に従う（既定は `SJIS-win`）。各値を設定の文字コードへ変換して書き出す |
| 応答の文字コード名 | 設定が `SJIS-win` のときだけ `windows-31j` へ読み替える。それ以外は設定値をそのまま使う |
| ファイル名 | `stock_history_disposal_` に出力日時を `YmdHis` の形式でつなぎ、`.csv` を付けた名前 |
| 応答 | ダウンロードとして返す |
| 出力方式 | 1行ずつ書き出しながら返す。件数が多くても途中で打ち切られないよう、実行時間の上限を外して出力する |
