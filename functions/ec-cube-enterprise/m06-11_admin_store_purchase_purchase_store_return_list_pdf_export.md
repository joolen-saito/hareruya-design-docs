# 店頭買取管理 — 戻しリストPDF出力

## 業務ロジック

### 本機能の位置づけ

店頭買取の棚戻し業務で使うピッキングリストを、印刷に最適化したページとして表示し、PDF出力する。買取の一覧画面で買取情報を選び、ピッキングリスト印刷を実行したときに開く。

ネット買取管理の場合は店舗が本店しかないため、本店の閾値で仕分ける。

### カスタマイズする範囲

次の2点をカスタマイズ要件とする。

- 在庫指示リスト内の在庫移動データのピッキングリスト情報を、ポップアップで表示する。
- 本店3F・2F・B2Fや支店で閾値が異なるため、マスターデータ管理で店舗ごとに金額の閾値を分けられるようにする。フォーマットはそれぞれ3F・2F・B2Fで異なるものとなる。

カスタマイズ要件に記載の内容以外は現行踏襲とする。

### 印刷対象の取得

一覧画面で選択された買取情報に紐づく実在庫情報を対象とする。選択されていない買取情報は対象にしない。

取得した実在庫は、対象店舗ごとに指定された金額閾値と、サプライとに分けて取り出す。対象店舗ごとに指定された金額閾値とは、店舗登録（基本情報設定）で設定された高額商品閾値1〜3である。分けた結果の区切りは商品仕訳の欄に表示する。

閾値の表示も基準価格を参照して行う。セール中で金額が変わっても棚を移動することはないためである。

### 商品名の整形

サプライ品でない場合は、商品名から略称・言語・状態・色・レアリティがあれば取り除く。商品名から取り出した色とレアリティは色/Rの欄へ出す。

商品名内に[略称タグ]が含まれない場合は、[〜]（角括弧内にある文字を角括弧ごと）を削除する。

### 並び順

金額閾値の昇順が最優先で、サプライを最後に置く。

同じ金額閾値の中は次の順で並べる。

| 順位 | 並べる基準 | 向き |
| --- | --- | --- |
| 1 | 棚番 | 昇順。ただし支店の場合は棚番のソートを行わない |
| 2 | 言語 | 日→英→他言語 |
| 3 | 状態 | NM→HP |
| 4 | Foilフラグ | 非Foil→Foil |
| 5 | 略称タグ | 昇順 |
| 6 | レアリティ | M→C |
| 7 | 色 | マスターデータの色順による |
| 8 | コレクター番号／英語のカード名 | 設定されている略称タグがコレクター番号でのソートのときはコレクター番号の昇順、アルファベットでのソートのときは英語のカード名の昇順 |

### 印刷の実行

ページ内で印刷に最適化した状態でページを表示する。「印刷する」ボタンは印刷範囲に含まない。

「印刷する」ボタンを押すと、PC端末の印刷ダイアログが表示され、印刷を実行する。

### 現行運用での金額の閾値

3F在庫の現行運用における閾値は次のとおりである。

| 対象 | 区分 | 内容 |
| --- | --- | --- |
| シングルカード | 低額 | 4800円未満 |
| シングルカード | 高額 | 4800円以上 |
| シングルカード | 金庫 | 基本的にEC在庫で500万以上のものを保管する。あとは備品などを入れている |
| シングルカード以外 | 倉庫 | 2Fに置ききれない（商品化していない）サプライパックボックス等を保管する |

## 入出力

### 入力

| 種類 | 内容 |
| --- | --- |
| 対象の指定 | 一覧画面で選択された買取情報 |
| 操作 | ピッキングリスト印刷、印刷する |

### 出力: 画面の部品

| 部品 | 内容 |
| --- | --- |
| 印刷するボタン | 押下するとPC端末の印刷ダイアログが表示され、印刷を開始する。印刷範囲には含まない |

### 出力: 帳票の項目

| 項目 | 出す内容 |
| --- | --- |
| 商品仕訳 | 店舗ごとの閾値とサプライを出力する。●●円未満、●●円以上▲▲円未満、■■円以上、サプライ。ネット買取管理の場合は本店しかないため本店の閾値とする。閾値の表示も基準価格を参照して行う |
| ページング | 閾値ごとのページ数を表示する |
| 作成日時 | ピッキングリストを作成した日時。「ピッキングリスト印刷」ボタンを押した日時とする |
| 行番号 | 各ページごとに商品に割り振られる行番号 |
| 棚番号 | 本店の商品を棚戻しする場合のみ必要な項目で、買取店舗が本店の場合のみ出す |
| 言語 / 状態 | 言語/状態の形式で出力する。Foilの場合はFoilを付ける（例: FoilJP/NM）。サプライ品の場合は「サプライ品」と表示する |
| 略称 | 略称。サプライ品の場合は表示しない |
| 色 / R | 商品名から取り出した色とレアリティを出力する（例: 金R） |
| 数 | 商品点数 |
| 商品名 | サプライ品でない場合は、商品名から略称・言語・状態・色・レアリティを取り除いた名称 |
| 価格 | 基準価格を表示する |
| 備考 | 備考 |
| ページ内個数小計 | ページ内の商品個数の総計 |

帳票の項目はいずれも表示専用で、書式・制限、必須、最大値、初期値の指定を持たない。

## 表示メッセージ

本機能は画面メッセージを持たない。
