# 在庫管理 — 在庫分割結合登録/編集

## 業務ロジック

### 分割と結合の区別

在庫検索一覧で選択した1件の商品在庫を起点に、在庫を分割または結合する。

- 分割: 1件の分割元在庫を減算し、複数の分割先在庫へ振り分ける（分割元1 → 分割先複数）。
- 結合: 複数の結合元在庫を減算し、1件の結合先在庫へまとめる（結合元複数 → 結合先1）。結合元には欠品（不足点数）を登録できる。

分割・結合はいずれも同一の在庫分割結合情報として種別で区別して管理し、新規登録 →（結合は結合元登録・欠品入力）→ 承認申請 → 承認待ち → 承認（入庫済み）または却下、というステータス遷移を持つ。各操作時に在庫数・総原価を更新し、在庫変動履歴・ステータス履歴・承認リストへ記録する。

新規登録の画面には、在庫検索一覧で選択した商品情報・在庫情報を表示する。結合の新規登録画面では、一時保持している結合元の候補があればあわせて復元して表示する。

### ステータス区分

| ID | 名称 | 主な用途 |
| --- | --- | --- |
| 1 | 新規登録 | 分割登録直後／結合登録直後。分割先・結合元は確定せず一時保持する |
| 2 | 結合元登録 | 結合のみ。結合元明細を確定し結合元在庫を減算済み。欠品入力ができる |
| 3 | 分割承認待ち | 分割の承認申請後 |
| 4 | 結合承認待ち | 結合の承認申請後 |
| 5 | 入庫済み | 承認完了（分割先／結合先へ加算済み） |
| 6 | 却下 | 承認却下（分割は分割元へ戻し済み） |

### ステータス遷移

分割は、在庫検索一覧の「在庫分割登録」から新規登録へ入り、分割対象の商品在庫を減らす。分割先商品を登録して承認申請すると分割承認待ちとなり、承認で入庫済み（分割先の商品在庫を増やす）、却下で却下（分割元の商品在庫を戻す）になる。

結合は、在庫検索一覧の「在庫結合登録」から新規登録へ入る。結合作業として結合元を登録すると結合元登録となり、ピック作業の結果を欠品登録したうえで承認申請すると結合承認待ちになる。承認で入庫済み、却下で却下になる。

### 入力項目と検証

登録時に入力値チェックを行い、画面部品一覧表の必須・最大値・画面部品の説明に記載された条件に従ってエラーとする。必須列に「○」がある項目が未入力のとき、入力値が最大値を超えるとき、画面部品の説明にあるチェック条件に該当するときがエラーである。エラーが無ければ登録処理へ進む。

分割 新規登録

| 項目 | 必須 | 検証 |
| --- | --- | --- |
| 分割メモ | 任意 | — |
| 分割数 | 必須 | 1以上、かつ分割元の在庫数以下 |
| 店舗の編集権限 | — | ログインしたメンバーが対象店舗の在庫を編集できないときはエラー |

結合 新規登録

| 項目 | 必須 | 検証 |
| --- | --- | --- |
| 結合メモ | 任意 | — |
| 結合点数 | 必須 | 0より大きいこと。入力値は整数へ変換する |
| 店舗の編集権限 | — | ログインしたメンバーが対象店舗の在庫を編集できないときはエラー |

編集・承認申請の共通項目は、分割結合メモと承認通知先メンバー（複数選択）である。通知先の候補は当該店舗で承認権限を持つメンバーとする。承認申請が成功したとき、選択された通知先のうち承認権限を持つメンバーへ承認依頼メールを送信する。

承認・却下

| 項目 | 検証 |
| --- | --- |
| 承認モード | 承認・却下のいずれでもないときはエラー |
| 却下メモ | 却下時は必須。全角空白などを正規化した結果が空のときは却下理由の未入力エラー |
| 仕入価格（結合承認） | 数字以外を除去する。結合先の総原価への加算に使う |
| ステータス | 分割は分割承認待ち、結合は結合承認待ち以外のときは不整合エラー |

### 入力値を確定するタイミング

新規登録ステータスのあいだ、分割先・結合元・欠品点数の入力値は確定させず一時的に保持し、承認申請または欠品入力への遷移でまとめて確定する。登録メモだけはどのステータスでも即時に保存できる。

分割先は追加した時点では数量を0として保持し、編集画面で数量を入力する。結合元は追加の時点で数量とあわせて保持する。

分割先・結合元の在庫区分（EC-CUBE／スマレジ）の変更は、分割では即時に確定し、結合では新規登録のあいだは一時保持の付け替え、それ以外のステータスでは即時確定とする。

### 分割の登録

分割元の在庫を最新の値で取り込み、次の順で処理する。処理順は在庫減算処理 → 在庫変動履歴登録 → 分割ステータス履歴登録 → 在庫分割情報登録である。ただし在庫変動履歴が在庫分割結合の識別子を参照するため、在庫分割情報を先に確定してから履歴を登録する。

1. 在庫不足の判定。分割数が現在庫を超えるときは処理を中断し、在庫数を超える旨のエラーとする（在庫は操作せず、途中までの更新も取り消す）。
2. 在庫減算。新しい在庫数は「現在の在庫数 − 分割数」で、0を下回るときは0とする。新しい総原価は「現在の総原価 − 出庫分の総原価」とし、原価単価を再計算する。
3. 在庫分割情報の登録。種別は分割、ステータスは新規登録とする。減算前の在庫数・総原価・原価単価・基準価格をスナップショットとして保持し、出庫分の総原価を記録する。基本情報として在庫分割結合IDの自動採番、処理タイプ、ステータス、登録日・更新日、登録者・更新者を記録する。
4. 在庫変動履歴の登録。種別は分割出庫、履歴の発生元は在庫分割編集、変動数は分割数の符号を反転した値とし、減算前後の在庫数と原価を記録する。
5. ステータス履歴の登録。新規登録ステータスを記録する。

成功時は登録した旨を表示して編集画面へ移る。この時点では分割先は登録されていない。

### 分割の承認申請

編集画面で保持した分割先と各数量から明細を作成する。明細には分割先の原価単価、原価単価に数量を掛けた総原価、分割先の在庫数のスナップショットを記録する。

- 検証: 分割数が1以上であること、分割先が1件以上あること、分割先の数量合計が1以上であること。
- ステータスを分割承認待ちへ変更し、承認申請の日時と申請者を記録して、ステータス履歴を追加する。
- 承認リストを未承認で1行作成する。対象在庫数は分割先の件数に分割元の1件を加えた数、変動数は分割先の数量合計、移動総原価は分割元の原価単価に分割数を掛けた値とする。
- 却下済みからの再申請はできない。

### 分割の承認・却下

承認は分割承認待ちのときだけ実行できる。移動総原価（分割元の総原価 × 分割数 ÷ 分割元の在庫数）を、分割先ごとの買取金額と個数の積の比で按分して加算する。分割先の在庫数を数量分だけ増やし、総原価を加算して原価単価を再計算し、分割入庫の在庫変動履歴を記録する。ステータスを入庫済みへ、承認リストを承認済みへ更新する。すでに入庫済みのときは何もせず成功として扱い、それ以外のステータスのときはステータス不整合のエラーとする。

却下も分割承認待ちのときだけ実行できる。分割登録時に減算した在庫（分割数）と原価（原価単価 × 分割数）を分割元へ戻し、分割却下の在庫変動履歴を記録する。ステータスを却下へ更新し、却下メモを保存して、承認リストを却下へ更新する。

### 結合の登録

結合点数が0より大きいことを確かめ、種別を結合、ステータスを新規登録として在庫分割結合情報を作成する。在庫数と結合数量には結合点数を、原価単価と総原価には結合先在庫の現在値を記録し、ステータス履歴を追加する。**この時点では在庫を操作しない**（結合先への加算は承認時に行う）。

### 結合元の登録（欠品入力への遷移）

編集画面で保持した結合元と数量をもとに、新規登録ステータスのときは次を実行する。

1. 検証: 結合元が1件以上あること、計画している結合数が1以上であること。
2. 各結合元の在庫を最新の値で取り込む。数量は入力値と在庫数の小さいほうへ丸め、0以下になる行は処理をとばす。
3. 明細を作成する。基準価格・原価単価・総原価・在庫数のスナップショットと結合数量を記録する。
4. 結合元の在庫数を数量分だけ減らし、総原価を減算して原価単価を再計算し、結合出庫の在庫変動履歴を記録する。
5. 在庫分割結合情報側の派生原価を明細から再計算する。
6. ステータスを結合元登録へ変更し、ステータス履歴を追加する。

すでに結合元登録のときは、確定済みの明細を検証するだけで欠品入力へ進む。新規登録でも結合元登録でもないときはエラーとする。

### 結合の欠品入力と承認申請

欠品入力画面は結合元登録ステータス専用で、ステータスが一致しないときはエラーとする。結合数が0の明細は表示対象から外す。欠品点数は入力時点では確定させず一時保持し、承認申請で確定する。

承認申請は結合元登録ステータスを前提とし、各結合元の欠品点数を確定する。有効結合数（結合量 − 欠品量）の合計が1未満のときはエラーとする。欠品が0より大きい明細は次の手順で在庫を調整する。

- 欠品加算: 結合出庫で出庫した全量を結合元の在庫へ戻す。
- 欠品減算: 有効数量（結合量 − 欠品量）だけをあらためて減算する。
- 欠品分は欠品履歴として記録し、明細に欠品点数と欠品を登録したメンバーを記録する。

在庫調整のあと、ステータスを結合承認待ちへ変更し、承認リストを未承認・種別は結合入庫として作成する。

### 結合の承認・却下

承認は結合承認待ちのときだけ実行できる。結合先の在庫数を結合数量分だけ増やし、総原価に仕入価格を加算して原価単価を再計算し、結合入庫の在庫変動履歴を記録する。ステータスを入庫済みへ更新する。結合数量が0以下のときは入庫数量が無いものとして処理を中断する。却下は分割と同じく承認画面からの操作で処理する。

### 計算方法

- 在庫数（分割元）: 現在の在庫数 − 分割数。0を下回るときは0とする。
- 在庫数（結合元）: 現在の在庫数 − 結合数量。結合数量は入力値と在庫数の小さいほうへ丸めるため、在庫数が負にはならない。
- 在庫数（分割先・結合先）: 現在の在庫数 + 数量。
- 総原価（出庫時）: 現在の総原価 − 出庫分の総原価。
- 総原価（分割先への入庫時）: 移動総原価を、分割先ごとの買取金額と個数の積の比で按分した額を加算する。
- 総原価（結合先への入庫時）: 承認時に入力した仕入価格を加算する。
- 移動総原価: 分割元の総原価 × 分割数 ÷ 分割元の在庫数。
- 原価単価: 総原価 ÷ 在庫数（在庫・総原価を更新するたびに再計算する）。
- 有効結合数: 結合量 − 欠品量。

### 分岐と例外

| 状況 | 扱い |
| --- | --- |
| 店舗の編集権限が無い | 編集できない旨を表示して元の画面へ戻る |
| 分割数が1未満／在庫数を超える | エラーとし、在庫を操作せず新規登録画面へ戻る |
| 結合点数が0以下 | エラーとし、結合の新規登録画面へ戻る |
| 分割先が未登録／数量合計が0 | 承認申請せず編集画面へ戻る |
| 分割先・結合元に同じ在庫を重ねて追加した | 追加済みである旨のエラーとし、追加しない |
| 対象の在庫分割結合が見つからない／種別が一致しない | 見つからない旨のエラーとし、一覧または元の画面へ戻る |
| 分割の識別子で結合の画面を開くなど種別を取り違えた | 対応する側の編集画面へ移す |
| 編集対象が承認待ちのステータス | 編集内容を保存せず承認画面へ移す |
| 承認モードが承認・却下のいずれでもない | 保存に失敗した扱いとする |
| 却下メモが未入力 | 却下理由が必要である旨のエラーとし、却下しない |
| 承認時のステータスが承認待ちでない | ステータス不整合のエラーとする |
| メモ保存の入口を別の種別で呼び出した | 対象なしとして処理しない |
| ステータス・変動種別・履歴の発生元のマスタが未整備 | 処理を中断する |
| CSV取込でファイルが不正、またはステータスが取込不可 | 取り込まずエラーを返す（申請済み・入庫済みは変更できない） |

## 入出力

### 出力: 分割先CSV雛形

分割先を一括入力するための雛形を出力する。列は商品コードと分割先在庫数の2列である。

### 出力: 結合元CSV雛形

結合元を一括入力するための雛形を出力する。列は商品コードと結合元数量の2列である。

### 出力: 欠品入力用CSV

結合元登録ステータスのときだけ、欠品を入力するためのCSVを出力する。結合元の登録が完了していないステータスでは出力しない。

### 入力: 分割先CSV取込

新規登録ステータスのときだけ、分割先の明細をCSVの内容で全置換する。取り込んだ内容は確定させず一時保持し、承認申請で確定する。対象が分割種別でないとき、ファイルが送信されていないときは取り込まない。

### 入力: 結合元CSV取込

新規登録画面からの取込は保存を伴わず、読み取った行の内容を画面へ返すだけとする。編集画面からの取込は、結合元の明細をCSVの内容で全置換し、一時保持へ反映する。対象が結合種別でないときは取り込まない。

### 入力: 欠品CSV取込

結合元登録ステータスのときだけ、各結合元の欠品点数をCSVから取り込み、一時保持へ反映する。対象が結合種別でないときは取り込まない。

### 出力: 承認依頼メール

承認申請が成功したとき、選択された承認通知先のうち承認権限を持つメンバーへ承認依頼メールを送信する。

### 入出力: 永続化

| 対象 | 保持する内容 |
| --- | --- |
| 在庫分割結合情報 | 分割・結合の基本情報。種別（分割／結合）、ステータス、対象の商品在庫（分割元／結合先）、基準価格、原価単価、総原価、在庫数、分割結合数量、分割結合メモ、出庫総原価、承認申請者と承認申請日時、却下メモ、登録者・更新者・登録日・更新日 |
| 在庫分割結合明細 | 分割先／結合元の明細。対象の商品在庫、基準価格、原価単価、総原価、在庫数、分割結合数量、欠品点数、欠品を登録したメンバー |
| 在庫分割結合ステータス履歴 | ステータス遷移の履歴。対象の在庫分割結合、ステータス、更新したメンバー、更新日 |
| 商品在庫・商品規格 | 在庫数と総原価を更新する |
| 在庫変動履歴 | 変動種別（分割出庫／分割入庫／分割却下／結合出庫／結合入庫／欠品加算／欠品減算）、履歴の発生元（在庫分割編集／在庫結合編集）、発生元の識別子として在庫分割結合の識別子を記録する |
| 在庫承認リスト | 承認申請時に未承認で作成し、承認・却下時に状態を更新する |
| 欠品履歴 | 結合の欠品確定時に欠品点数を記録する |

| 操作 | 契機 |
| --- | --- |
| 登録 | 分割登録、結合登録、承認申請、欠品入力からの遷移 |
| 更新 | 分割先・結合元の編集、メモ保存、在庫区分変更、承認、却下 |
| 削除 | 分割先・結合元の削除（新規登録ステータスのみ。在庫は操作しない） |
