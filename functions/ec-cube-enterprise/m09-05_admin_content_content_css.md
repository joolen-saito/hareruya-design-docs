# コンテンツ管理 — CSS管理

管理画面のコンテンツ管理配下で、店舗フロント向けのカスタマイズ用CSSを1ファイル単位で編集・保存し、保存後にファイルストレージへ反映する機能である。

## 業務ロジック

### 保存対象

対象は単一のカスタマイズ用CSSファイルのみとする。複数ファイルの編集や差分保存は行わない。入力されたコードは解釈・整形せず、全文をそのまま保存する。既存内容とのマージは行わない。金額計算・集計・丸めなどの業務計算は行わない。

### 初期表示

ファイルアップロード制限が有効で当画面が制限の対象のときは、アクセス拒否（HTTP403）として画面を開かない。画面表示時に、ファイルアップロード制限に関する案内を情報メッセージとして一度だけ表示する。編集欄はコード入力1項目で、入力は任意とする。対象ファイルが存在し、かつ書き込み可能なときに限り、現行内容をコードエディタへ初期表示する。存在しない、または書き込み不可のときは空表示とする。

### 保存

送信されたコード値で対象ファイルの全文を上書きする。ファイルが無いときは作成する。書き込みに成功したときのみ、既定のファイルストレージへ同名で配信用のパスへアップロードする。保存に成功したときは成功メッセージを表示し、同じCSS管理画面へ戻る。

### 構文検証

サーバー側ではCSS構文の妥当性検証を行わない。編集画面のエディタが示すエラー注釈は「登録」ボタンの活性制御にのみ用いる。入力が空でも検証は妨げられない。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| ファイル書き込みの入出力異常 | 保存失敗メッセージを表示し、対象パスと異常内容をログへ記録し、同じ画面に留まる |
| ファイルストレージへのアップロード失敗 | 当画面では個別に捕捉せず、共通の異常処理に委ねる |
| ファイルアップロード制限が有効 | アクセス拒否（HTTP403）として遮断する |
| 入力内容の検証不成立 | 保存せず同じ画面を再描画する |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 画面表示の要求、および編集したコード値の送信 |
| 成功時出力 | 成功メッセージを表示し、同じCSS管理画面へ戻る |
| 失敗時出力 | 書き込み失敗時はエラーメッセージを表示し同じ画面に留まる。アップロード制限時はアクセス拒否（HTTP403） |
