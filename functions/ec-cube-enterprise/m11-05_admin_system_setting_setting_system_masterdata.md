# システム設定 — マスタデータ管理

## 業務ロジック

### 選択できるマスタ

管理画面の「設定」に属し、名称に「Master」を含み、ID・名称・表示順の3項目を持つマスタデータを選択候補とする。抽象的な定義のものと、除外に指定されたものは候補から外す。

### 一覧の表示

選択したマスタが選択候補として妥当なときだけ、そのマスタの全行を表示順の昇順で読み込み、ID・名称を一覧に並べる。一覧の末尾には、ID・名称が空の入力行を1行加える。マスタの定義を解釈できないときは、行を読み込まず編集表を空に近い状態で表示する。編集する行が無いときは編集表を表示しない。

画面には、IDを重複させられないこと、IDを空にした行は削除されること、設定を誤るとサイトが動かなくなり得ることを説明として表示する。

### 保存時の行の扱い

| 行の状態 | 扱い |
| --- | --- |
| IDと名称の両方に値がある | 同じIDの既存行があればその行の名称を更新し、無ければ新規に登録する |
| IDと名称の両方が空で、その行のIDが送信中の他の行で使われていない | その行のIDを持つ既存行があれば削除する |
| 上記以外 | 何も反映しない |

表示順は、送信された行の並び順で0から順に付け直す。

### 保存の可否

マスタが未選択のとき、IDの形式が不正なとき、IDを入力した行で名称が空のとき、同じIDが複数行にあるときは保存しない。保存に失敗したときは、失敗した旨を表示して同じマスタの一覧へ戻す。保存できたときは保存完了を表示して同じマスタの一覧へ戻す。

### エラー時の扱い

| 事象 | 扱い |
| --- | --- |
| マスタ未選択・IDの形式不正・名称が空・IDの重複 | 保存せず、項目ごとのエラーを同じ画面に表示する |
| 要求が正当でないとき | 共通の拒否処理に従う |
| 権限が無いとき | 共通の認可エラー応答に従う |
| 保存時の例外 | 保存に失敗した旨を表示し、同じマスタの一覧へ戻す |

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | 編集対象のマスタの選択、各行のID・名称と行の並び |
| 成功時出力 | 保存完了を表示し、選択中のマスタの一覧へ戻す |
| 失敗時出力 | 検証エラーは同じ画面に項目ごとのエラーを表示する。保存に失敗したときは失敗の表示とともに一覧へ戻す |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 追加 | IDと名称がそろい、同じIDの既存行が無い行を保存したとき |
| 更新 | IDと名称がそろい、同じIDの既存行がある行を保存したとき。名称と表示順を更新する |
| 削除 | IDと名称が空で、そのIDが送信中の他の行で使われていない行を保存したとき |

## 表示メッセージ

| メッセージID | 表示位置 | 画面上の文言 | 表示条件 | 後続処理 |
| --- | --- | --- | --- | --- |
| M11-05-MSG-001 | 管理画面上部 | 保存しました | マスタデータの編集内容を保存したとき | マスタデータ管理画面に遷移する |
| M11-05-MSG-002 | 管理画面上部 | 保存に失敗しました | マスタデータの保存中にエラーが起きたとき | マスタデータ管理画面に遷移する |
| M11-05-MSG-003 | 入力項目直下 | 数字で入力してください。 | IDに数字以外を入力して保存したとき | マスタデータ管理画面に留まる |
| M11-05-MSG-004 | 入力項目直下/フォーム上部 | 入力されていません。 | IDを入力した行で名称を入力せずに保存したとき | マスタデータ管理画面に留まる |
| M11-05-MSG-005 | 入力項目直下/フォーム上部 | 重複したIDを登録することはできません。 | 同じIDを複数行に入力して保存したとき | マスタデータ管理画面に留まる |
