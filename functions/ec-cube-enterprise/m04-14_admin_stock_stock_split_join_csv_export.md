# 在庫管理 — 在庫分割結合情報CSV出力

## 業務ロジック

### 出力対象

在庫分割結合一覧（M04-12）が保持している検索条件に一致する在庫分割・結合情報を、全件CSVとして出力する。一覧画面の在庫分割結合CSV出力ボタンから呼び出す。

一覧を一度も検索していないときも出力する。在庫検索一覧（M04-01）と違って検索の実行を必須とするガードは持たず、検索条件が無いときは条件なし＝全件を出力する。

出力は参照だけを行う。在庫分割・結合の登録情報とその明細を読み出してCSVへ整形するだけで、登録内容を更新せず、取込履歴のような記録も残さない。

### 出力する列

出力する列は固定の12列で、カスタムCSV出力（M04-15）のように出力フォーマットを選ぶことはできない。

| # | 列 | 出力する値 |
| --- | --- | --- |
| 1 | ID | 在庫分割結合ID |
| 2 | タイプ | 分割／結合の別を表すラベル |
| 3 | 店舗 | 在庫が属する店舗の会社名。持たないときは `-` |
| 4 | 在庫区分 | 在庫のロケーション名（EC-CUBE在庫／スマレジ在庫） |
| 5 | 分割元・結合先商品名 | 商品名に規格分類1・規格分類2を ` - ` で連結したもの |
| 6 | 分割元・結合先点数 | 分割数（結合のときは結合数） |
| 7 | 分割元・結合先商品の基準価格の合計 | 分割元・結合先商品の基準価格に上記の点数を掛け、四捨五入して整数にした値 |
| 8 | 分割先・結合元点数 | 明細の点数の合計 |
| 9 | 分割先・結合元商品の基準価格の合計 | 明細ごとに基準価格と点数を掛け、合計した値 |
| 10 | ステータス | ステータス名 |
| 11 | 登録日時 | 登録日時を `Y/m/d H:i` の形式にした文字列 |
| 12 | 登録者 | 登録した担当者の氏名。持たないときは `-` |

各列の業務定義はExcel設計書の出力項目（識別ID 1〜12）を正とする。1〜6・8・10〜12は在庫分割・結合登録編集（分割／結合）画面の同じ項目に、7と9は在庫分割結合一覧の「基準価格の合計」に対応する。

### 行の並び

在庫分割結合IDの昇順に並べる。一覧表示は登録日時の降順だが、出力するときはID昇順へ並べ直す。Excel設計書の「在庫分割結合IDの昇順で出力」と同じ並びである。

### 対象が0件のとき

エラーにはしない。見出し行だけのファイルを出力する。

## 入出力

### 入力: 検索条件

一覧が保持している検索条件を検索欄の形式へ戻してから、出力対象を絞り込む。戻せない形式の条件は無視されるため、その分だけ結果は条件なしに近づく（旧い形式の条件が残っていたときの扱いは要確認）。

### 出力: 在庫分割結合情報CSV

| 項目 | 内容 |
| --- | --- |
| 内容 | 見出し行に続けて、対象データを1件1行で出力する |
| ファイル名 | `stock_split_join_` に出力日時を `YmdHis` の形式でつなぎ、`.csv` を付けた名前 |
| 文字コード | CSV出力の設定に従う（既定は `SJIS-win`）。UTF-8から変換して出力する |
| 応答 | ダウンロードとして返す |

## 表示メッセージ

本機能は画面メッセージを持たない。
