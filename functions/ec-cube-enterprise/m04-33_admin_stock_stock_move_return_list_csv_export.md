# 在庫管理 — 戻しリストCSV

## 業務ロジック

### 出力の目的と対象

在庫移動・振替一覧でチェック選択した在庫移動・振替情報をもとに、入庫先（移動先）店舗で棚へ戻すための戻しリストをCSVファイルとして出力する。入庫先の在庫を商品規格単位に集計し、入庫先店舗ごとに設定された金額閾値（3段階）とサプライ品で「ピッキング区分」に振り分けて出力する。現行に同等の機能は無く、リニューアルで新規に設ける。

出力対象データの取得・整形・並び順と出力前の検証は戻しリストPDF（M04-34）と共通で、出力する列・整形ルール・並び順は店頭買取／ネット買取の棚戻しリストと共通の整形を用いる。その他、基本的な仕様は在庫移動指示リストのピッキングリスト印刷に準じる。

### 出力対象の抽出

一覧画面で選択された情報に紐づく実在庫情報を、対象店舗ごとに指定された金額閾値＋サプライで分けて取得する。

起点は在庫移動・振替の明細で、そこから在庫移動・振替、入庫先の在庫、商品規格、商品をたどる。金額閾値は入庫先店舗に登録されたものを参照する。数量は商品規格単位で移動点数を合計する（1対多の結合で数量が重複しないよう、サプライ品の判定は結合ではなく存在判定で行う）。日時は日本時間で扱う。

- サプライ品でない場合は、商品名から略称・言語・状態・色・レアリティを取り除く。
- 商品名内に略称タグが含まれない場合は、[～]（角括弧内にある文字を角括弧ごと）を削除する。
- サプライ品かどうかは、商品が物販カテゴリまたは予約物販カテゴリに属するかで判定する。

### 金額閾値とピッキング区分

閾値は入庫先店舗ごとに3段階を登録する。本店の3F・2F・B2Fや支店で閾値が異なるため、マスターデータ管理で店舗ごとに金額の閾値を分けられるようにし、結果としてフォーマットも3F・2F・B2Fでそれぞれ異なるものとなる。ネット買取管理の場合は本店しかないため本店の閾値を用いる。閾値の表示も基準販売価格を参照して行う（セール中で金額が変わっても棚を移動することはないため）。

区分は閾値を昇順に整列したうえで、基準価格が最小閾値未満なら「〇〇円未満」、閾値と閾値の間なら「〇〇円以上▲▲円未満」、最大閾値以上なら「■■円以上」とし、数値は3桁区切りで表す。サプライ品は「サプライ」とする。基準価格が無いとき、または閾値が未設定のときは空欄とする。

現行運用での本店3F在庫の閾値は、シングルカードが低額（4,800円未満）と高額（4,800円以上）で、金庫は基本的にEC在庫で500万円以上のものを保管し、あとは備品などを入れている。シングルカード以外では、2Fに置ききれない（商品化していない）サプライ・パック・ボックス等を倉庫へ保管する。

### 出力する列

見出し行とデータ行からなる8列を出力する。

| # | CSVヘッダ | 値の取り方 |
| --- | --- | --- |
| 1 | ピッキング区分 | 入庫先店舗の金額閾値と基準価格から求めた区分。サプライ品は「サプライ」、基準価格または閾値が無いときは空欄 |
| 2 | 棚番号 | 商品がしまってある場所番号。入庫先が本店のときだけ棚番を出力し、支店では空欄とする |
| 3 | 言語/状態 | 言語コードと状態コードを「言語/状態」の形式で出力し、Foilの場合は先頭にFoilを付ける（例: FoilJP/NM）。状態コードが無いときは「/状態」を付けない。サプライ品の場合は「サプライ品」とする |
| 4 | 略称 | 商品の略称（略称タグ）の名称。サプライ品の場合は空欄とする |
| 5 | 色/R | 商品名から取り出した色とレアリティ（例: 金R）。色はカードに紐づく色の名称を順に連結し、レアリティはそのコードを出力する。シングルカード以外は色に該当するデータがないため色情報は付かない。サプライ品は空欄とする |
| 6 | 数 | 商品規格単位に集計した移動点数 |
| 7 | 商品名 | サプライ品はそのまま出力する。サプライ品でない場合は、商品名から略称・言語・状態・色・レアリティを取り除いたもの |
| 8 | 基準価格 | 商品規格の基準価格。未設定のときは空欄とする |

### 出力順

金額閾値の昇順（最後にサプライ）が最優先となる。金額閾値内の並び順は次のとおり。

| 順序 | 並び |
| --- | --- |
| 1 | ピッキング区分（〇〇円未満→〇〇円以上▲▲円未満→■■円以上→サプライ。サプライは最後） |
| 2 | 棚番の昇順。本店のみで、支店の場合は棚番のソートを行わない |
| 3 | 言語（日→英→他言語） |
| 4 | 状態（NM→HP） |
| 5 | Foilフラグ（非Foil→Foil） |
| 6 | 略称タグの昇順 |
| 7 | レアリティ（M→C） |
| 8 | 色（マスターデータの色順を参照する） |
| 9 | 設定されている略称タグがアルファベットでのソートのときは英語のカード名の昇順、コレクター番号でのソートのときはコレクター番号の昇順 |

### 出力前の検証と分岐

選択されたIDから入庫先店舗とステータスを取得して検証する。エラーは1件で打ち切らず、該当するものをすべてまとめて返す。

| 条件 | 扱い |
| --- | --- |
| 対象を1件も選択せずに実行した | 出力せず、選択が無い旨を表示して在庫移動・振替一覧へ戻す |
| 選択したIDに該当するデータが1件も無い | 出力せず、対象が見つからない旨を表示して一覧へ戻す |
| 指定したIDが存在しない | 出力せず、そのIDが存在しない旨を表示して一覧へ戻す |
| 入庫先店舗が設定されていない | 出力せず、そのIDに入庫先店舗が無い旨を表示して一覧へ戻す |
| 入庫先店舗が実行者の担当店舗に含まれない | 出力せず、そのIDが権限のない店舗のデータである旨を表示して一覧へ戻す |
| ステータスが対象外 | 出力せず、そのIDが対象外のステータスである旨を表示して一覧へ戻す |
| 複数店舗の入庫先が混在している | 出力せず、同時に処理できない旨を表示して一覧へ戻す |
| 送信内容の正当性を確認できない | 要求を受け付けず例外とする |
| 検証を通過した | 抽出・整形した内容をCSVファイルとして送出する |

対象にできるステータスは出庫承認済み以降、すなわち出庫承認済み・移動中・入庫承認待ち・入庫承認済みの4つとする。新規や差戻しなどは対象外とする。

一覧へ戻すときの遷移先は、直前に表示していた在庫移動・振替一覧のページ番号（既定は1ページ目）とする。

### ファイルの形式

ファイル名は「stock_move_transfer_return_list_」に、選択したIDのうち最小のもの（7桁の左0埋め）と出力日時（年月日時分秒）、拡張子 .csv を連結したものとする（例: stock_move_transfer_return_list_0012345_20260101120000.csv）。文字コードと区切り文字はCSV出力の設定に従い、既定の文字コードはSJIS-winとする。UTF-8を設定しているときは先頭にバイトオーダーマークを付ける。1行目に列の見出しを出力する。処理時間の上限を設けずに実行する。

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | 在庫移動・振替一覧で選択した在庫移動・振替情報のID（複数可）と、送信内容の正当性を確認するための値 |
| 成功時出力 | 見出し行と抽出したデータ行からなるファイルの送出（ダウンロード）。成功を知らせる文言は表示しない |
| 失敗時出力 | 在庫移動・振替一覧への遷移先と、原因を示すメッセージ |

### 入出力: 永続化

本機能はデータを更新しない。選択されたIDから集計してファイルを作るだけで、書き込みは行わない。CSV取込履歴・在庫履歴も更新しない。

参照するのは、在庫移動・振替とその明細、入庫先の在庫・商品規格・商品、入庫先店舗に登録された金額閾値（3段階）、および棚番・略称・言語・カード状態・カード詳細・レアリティ・カード・色・色順の各マスタである。
