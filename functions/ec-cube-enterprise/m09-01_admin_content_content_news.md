# m09-01_admin_content_content_news（管理画面_新着情報管理）

## 業務ロジック

### 一覧の対象と並び

| 項目 | 内容 |
|------|------|
| 一覧の対象 | 公開・非公開を問わず登録済みの全新着情報。管理画面側では公開日時による絞り込みを行わない |
| 一覧の並び | 公開日時の降順を主、識別子の降順を従とする |
| ページング単位 | 1ページ10件 |
| 一覧の表示列 | 公開日時、公開状態、タイトル |

### 登録・編集

新規登録画面では、公開日時に現在日時を設定した新着情報を初期表示する。既存編集画面では識別子で新着情報を取得し、取得できないときは見つからない扱い（HTTP404）とする。

| 項目 | 内容 |
|------|------|
| 公開状態 | 公開（保存値は真）／非公開（保存値は偽）の2択。新規の初期選択は公開 |
| 新規の公開日時初期値 | 新規登録画面を表示したときの現在日時 |
| 別ウィンドウで開くの整合 | リンクURLが空のとき、保存直前に「別ウィンドウで開く」を無効（偽）へ揃える |
| 本文のHTML | 本文は保存時にHTML浄化を通す。HTMLタグの利用は可能だが、浄化により一部の記述は除去・整形される |
| 計算 | 金額計算・税計算・丸めは行わない |

保存に成功したときは、当該新着情報の編集画面へ遷移する。新規のときは保存時に識別子を採番する。検証に失敗したときは同一の編集画面を再表示し、項目ごとのエラーを表示する。

### 削除

なりすまし対策トークンを検証し、失敗したときはアクセス拒否とする。識別子で対象の新着情報を取得できないときは見つからない扱い（HTTP404）とする。削除に成功したときは一覧へ戻る。削除中に例外が発生したときは、対象タイトルを差し込んだ関連データ存在エラーを表示し、一覧へ戻る。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| フォーム検証エラー | 同一編集画面を再表示し、項目ごとのエラーを表示する |
| 編集・削除対象が存在しないとき | 見つからない扱い（HTTP404）とする |
| なりすまし対策トークン不正（削除） | アクセス拒否とする |
| 削除中の例外（関連データ存在等） | 対象タイトルを差し込んだエラーメッセージを表示し、一覧へ戻る |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 一覧・ページング・編集の表示要求、登録の送信、削除の実行要求 |
| 成功時出力 | 画面表示または遷移。登録成功時は編集画面へ、削除成功時は一覧へ遷移し、成功メッセージを表示する |
| 失敗時出力 | フォーム検証失敗時は同一編集画面にエラー表示。削除失敗時は一覧にエラーメッセージ。トークン不正時はアクセス拒否。対象不存在は見つからない扱い（HTTP404） |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 追加 | 新規登録の保存 |
| 更新 | 既存編集の保存 |
| 削除 | 削除の実行 |
