# B06-01（買取自動入庫バッチ）

## 業務ロジック

### 起動と処理対象

買取を行った商品を入庫するバッチである。スケジュール起動により毎日15:00に開始する。入力元も出力先もデータベースで、ファイルの受け渡しは行わない。

対象は買取情報のうちステータスが入庫待ちのものだけで、店頭買取とネット買取の2系統を扱う。

| 対象データ | 抽出条件 |
|------|------|
| 店頭買取情報 | ステータスが 12: 入庫待ち |
| ネット買取情報 | ステータスが 16: 入庫待ち |

どちらの系統も、対象の取得 → 実在庫情報の在庫登録 → 在庫履歴の登録 → ステータスの入庫済み更新 → 入荷通知処理、の順に処理する。

### 店頭買取の自動入庫

入庫待ちの店頭買取情報を取得し、その実在庫情報を、**その店頭買取を行った店舗**の在庫へ登録する。登録にあわせて総在庫・総原価・原価単価を更新する。

続いて在庫履歴を登録し、店頭買取情報のステータスを「入庫済み」へ更新する。このとき店頭買取情報の最終更新者は更新しない。

最後に入荷通知処理を実行する。入荷通知処理の内容は在庫管理機能の共通処理「3.入荷通知処理」を正とする。

### ネット買取の自動入庫

入庫待ちのネット買取情報を取得し、その実在庫情報を**本店**の在庫へ登録する。買取を行った店舗ではなく本店の在庫が対象になる点が店頭買取と異なる。登録にあわせて総在庫・総原価・原価単価を更新する。

続いて在庫履歴を登録し、ネット買取情報のステータスを「入庫済み」へ更新する。このときネット買取情報の最終更新者は更新しない。

最後に、店頭買取と同じく入荷通知処理を実行する。

### 在庫履歴に記録する値

在庫履歴は系統を問わず次の値で登録する。

| 項目 | 記録する値 |
|------|------|
| 仕入単価 | 買取単価と同じ値 |
| 登録元機能 | 「買取自動入庫バッチ」 |
| 登録元ID | 店頭買取は査定ID、ネット買取は買取番号 |
| 操作者 | 「システム」の固定文字列 |

### 対象外とするもの

ステータスが入庫待ち以外の買取情報は取得しない。取得しないので、在庫の更新も在庫履歴の登録も行わない。入庫済みへ更新した買取情報は、次回以降の実行では抽出条件に合わないため対象にならない。

## 入出力

| 種類 | 内容 |
|------|------|
| 起動 | スケジュール起動。毎日15:00 |
| 入力 | ステータスが入庫待ちの店頭買取情報、ステータスが入庫待ちのネット買取情報 |
| 出力 | データベースの更新。店頭買取情報・ネット買取情報のステータスを入庫済みにし、在庫情報を更新し、在庫履歴を登録する |
| 終了条件 | 対象データの入庫処理と記録が完了したとき |

### 入出力: 永続化

店頭買取とネット買取は、それぞれ別の入庫情報・在庫履歴として記録する。

| 操作 | 対象 | 契機 |
|------|------|------|
| 登録 | 入庫情報・在庫履歴 | 実在庫情報を在庫へ登録したとき |
| 更新 | 在庫数（商品規格・商品在庫）、総在庫・総原価・原価単価 | 実在庫情報を在庫へ登録したとき |
| 更新 | 店頭買取情報・ネット買取情報のステータス | 入庫済みへ変更するとき |

買取情報の最終更新者は、ステータスを入庫済みへ変更しても更新しない。

## 表示メッセージ

本機能は画面を持たないバッチであり、表示メッセージは無い。
