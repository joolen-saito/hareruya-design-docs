# A06-15（店頭買取情報同一所属店舗メンバー取得）

## 業務ロジック

### 取得する対象

MTGバイヤーからの呼び出しを受け、同一所属店舗に属するメンバーの候補を取得して返す。取得した候補は、店頭買取のダブルチェック者を選ぶために用いる。

### 同一所属店舗の判定

同一所属店舗の絞り込みには、メンバーが持つ所属店舗と、デフォルトで検索表示する店舗を用いる想定とする。どちらを絞り込みのキーとするかは確定していない。

### 処理の流れ

1. MTGバイヤーまたは外部システムが本機能を呼び出す。
2. 入力値、リクエスト本文、検索条件を受け付ける。
3. 対象となるメンバーを取得し、入力値の検証と状態による条件を適用する。
4. 取得・更新・連携のうち該当する主処理を実行する。
5. 成功したときは結果をレスポンスとして返す。失敗したときはエラーの内容を返し、更新を伴う処理では不整合が残らないようにする。

### 条件に合わないときの扱い

| 条件 | 扱い |
| --- | --- |
| 必須項目、リクエスト本文、検索条件、CSVの見出し行または行が不正なとき | エラーとして扱い、登録・更新の対象を確定しない |
| 検索条件や対象のIDに該当するデータが無いとき | 空の一覧、空のCSV、または該当なしのエラーレスポンスとして扱う |
| 既に処理済み、キャンセル済み、承認不可、在庫不足など状態の条件に合わないとき | 処理の対象外とするか、エラーとする |
| スマレジなどの外部連携に失敗したとき | 再連携、エラーの記録、エラーメールの送信、ステータスの更新のいずれかで扱う |

### 開始と終了

API呼び出しを受け取った時点で開始し、レスポンスを返して、必要なデータ更新または非同期処理の投入が完了した時点で終了する。

## 入出力

### 入力: APIリクエスト

| 項目 | 内容 |
| --- | --- |
| 呼び出し元 | 外部システムまたはMTGバイヤー |
| 受け取るもの | 入力値、リクエスト本文、検索条件 |

本機能を呼び出す入口（エンドポイント）は確定していない。

### 出力: APIレスポンス

成功したときは同一所属店舗のメンバー候補を、失敗したときはエラーの内容を、いずれもレスポンスとして返す。

応答に載せる項目は確定していない。

### 更新するデータ

| 対象 | 内容 |
| --- | --- |
| 主データ | 買取、在庫、スマレジの連携通知に関わるデータを作成・更新・参照する |
| 履歴 | 必要に応じて、CSV取込履歴、在庫履歴、ステータス履歴、API受信履歴を作成・更新する |
| 連携の記録 | 対象データを更新したときは、外部連携履歴または受信履歴を記録する |

## 表示メッセージ

本機能はAPIであり、画面へ表示するメッセージを持たない。
