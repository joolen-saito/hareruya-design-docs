# 在庫管理 — 在庫移動実績 インポート

## 業務ロジック

### 入口とモーダル

在庫移動指示の一覧画面のモーダルでCSVファイルを選び、「在庫移動実績CSV登録」ボタンを押すと取込を実行する。モーダルには「既に在庫移動実績を登録している場合、上書きされます」「1ファイルの登録上限は10,000件です」の注記がある。取込の成否にかかわらず、処理後は検索状態を引き継いで一覧画面へ戻し、結果をメッセージで表示する。

### 何を登録する機能か

在庫移動実績入力用CSV（M04-27で出力した雛形に記入したもの）を取り込み、移動指示ごとに送り状No.を一括登録する。取り込んだ送り状No.は在庫移動指示と、それに紐づく在庫移動・振替の双方へ反映する。1行＝1移動指示として処理し、行ごとに検証して不正な行はスキップしながら処理を続ける。

この取込が更新するのは送り状No.だけである。在庫数の増減と移動ステータスの遷移はこの取込では行わない。基本設計の表題は「在庫移動実績」だが、実現されているのは送り状No.の一括登録である。

### 取込CSVの列

見出し行は1行目に必須とする。文字コードの先頭に付く印は読み飛ばし、列数が見出し行と一致しない行は不足分を補い余剰分を切り詰めて見出しの順に整列する。

| 列 | 必須 | 検証 | 用途 |
|------|------|------|------|
| 移動指示ID | ○ | 整数へ変換したうえで数値であること | 取込先の在庫移動指示を特定する照合キー |
| 出庫元店舗(名称) | − | − | 値があれば指示の出庫元店舗名と照合する（不一致はエラー） |
| 入庫先店舗(名称) | − | − | 値があれば指示の入庫先店舗名と照合する（不一致はエラー） |
| 送り状No. | ○ | 空でないこと | 登録する送り状No.（空はエラー） |

区切り文字と囲み文字はCSV取込の設定値に従い、拡張子がtsvのときの区切り文字はタブとする。データ行が0件（見出し行のみ）であっても見出しの検証としてはエラーとせず、結果として「有効な行がありません。」となる。

### 取込の手順

1. 送信された要求の正当性が確認できないとき、およびファイルが送信されていない・壊れているときは取込を始めず、ファイル不正のメッセージを表示して一覧画面へ戻す。
2. 見出し行を読み取る。見出し行が取得できないときは見出しの形式不正として扱う。
3. データ行ごとに検証する。列数が定義と一致しない行、および移動指示ID（数値必須）・送り状No.（必須）の検証を満たさない行は、その行をスキップする。
4. 検証を通った行を次の順で判定し、いずれかに当たれば当該行を失敗として行番号付きで記録する。
   1. 移動指示IDが0以下、または該当する移動指示が存在しない → 「移動指示が見つかりません」
   2. 出庫元店舗(名称)に値があり、指示の出庫元店舗名と一致しない → 「出庫元店舗が一致しません」
   3. 入庫先店舗(名称)に値があり、指示の入庫先店舗名と一致しない → 「入庫先店舗が一致しません」
   4. 送り状No.が前後の空白を除くと空 → 「送り状Noが空欄です」
5. すべて通過した行は、在庫移動指示へ送り状No.・更新日時・更新者を設定し、その指示に紐づく全ての在庫移動・振替の送り状No.にも同じ値を上書きする。
6. 成功件数とエラーメッセージの一覧を取込結果として返す。

### エラー行・不正行の扱い

行単位のエラーは収集して処理を継続する。ファイル内の正常な行だけを反映し、不正な行はスキップする。行ごとのエラーは行番号付きで一件ずつ表示する。

成功件数が1件以上のときは一括登録の完了メッセージを表示する。成功件数が0件でエラーも0件のとき（見出し行だけの場合など）は「有効な行がありません。」を表示する。

取込処理そのものが失敗したときは、内容に応じてメッセージを振り分ける。見出しの形式不正は「CSVのヘッダーが不正です。」、ファイル不正は「ファイルが不正です。」、一時ディレクトリの不正はその設定の確認を促すメッセージ、それ以外は失敗の詳細を差し込んだメッセージを表示する。いずれの場合も最後は一覧画面へ戻す。

### 他機能との境界

取込対象CSVの列は、在庫移動実績入力用CSV雛形（M04-27）の出力列と一致する。雛形に記入して本機能で取り込む運用とする。

送り状No.は在庫移動指示詳細（M04-25）画面からも1件ずつ登録でき、本機能はその一括版にあたる。送り状No.を登録した後の移動指示は削除できない。

在庫数の増減と移動ステータスの遷移は、在庫移動・振替の登録／承認系の機能を正とする。

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 在庫移動実績入力用CSVファイル（移動指示ID／出庫元店舗(名称)／入庫先店舗(名称)／送り状No.） |
| 成功時出力 | 一括登録の完了メッセージ。検索状態を引き継いで一覧画面へ戻る |
| 失敗時出力 | 行ごとのエラーメッセージ、または取込全体の失敗メッセージ。いずれも一覧画面へ戻る |

### 入出力: 永続化

| 操作 | 対象 | 契機 |
| --- | --- | --- |
| 更新 | 在庫移動指示の送り状No.・更新日時・更新者 | 検証を通った行の取込時 |
| 更新 | 在庫移動指示に紐づく全ての在庫移動・振替の送り状No.（同じ値で上書き） | 検証を通った行の取込時 |

既に登録済みの送り状No.も上書きする。在庫数と移動ステータスはこの取込では更新しない。取込の実行者はログインしているメンバーとして取込基盤へ渡すが、CSV取込履歴への本機能固有の記録の有無は要確認とする。
