# m09-02_admin_content_content_file（管理画面_コンテンツ管理_ファイル管理）

## 業務ロジック

### 操作対象の領域

全操作の対象は公開ファイル領域に固定する。カレントディレクトリ・移動先・アップロード先・削除対象・表示対象・ダウンロード対象は、いずれもこの領域の配下であることを確認してから処理する。パスに `..` を含む場合、および実パスが公開ファイル領域の実パスで始まらない場合は領域外として拒否する。

領域外を指定したときの扱いは操作ごとに異なる。フォルダ移動とフォルダ作成は公開ファイル領域のトップを起点に戻す。アップロードはアップロード先不正のエラーを表示して中止する。表示・ダウンロードは見つからない（HTTP404）として扱う。削除は何も行わない。

### 一覧の組み立て

カレントディレクトリは、指定された相対パスが公開ファイル領域の配下であればそのディレクトリ、そうでなければ領域のトップとする。一覧はカレントディレクトリ直下のフォルダとファイルを名前順に並べる。フォルダには空かどうかの判定を付ける。ファイルにはサイズ・更新日時・拡張子を付ける。ファイルサイズは人が読める単位へ整形して表示する。一覧とあわせて、公開ファイル領域配下のフォルダ階層のツリーとパンくずを表示する。

フォルダ移動の指定元は、ツリーのフォルダ名・パンくず・一覧のフォルダ名である。移動先をカレントディレクトリとして一覧とツリーを再表示する。

### 名前の検証

| 対象 | 使用できる文字 | 先頭のピリオド | 空 |
| --- | --- | --- | --- |
| フォルダ名 | 英数字・アンダースコア・ピリオド・ハイフン | 使用できない | 使用できない |
| アップロードファイル名 | 英数字・半角スペース・アンダースコア・ハイフン・ピリオド・丸括弧 | 使用できない | — |

### アップロード

保存先はカレントディレクトリとする。ファイルを1件も選択していないときは中止する。

選択ファイルごとに、同名フォルダの存在、使用できる文字、先頭のピリオド、拡張子の許可の順に検証する。いずれかに外れたファイルはエラー文言を記録してスキップし、他の選択ファイルの処理を続ける。同一文言は重複して表示しない。検証を通ったファイルはカレントディレクトリへ保存し、あわせて外部ストレージへも保存する。保存に失敗したファイルはアップロード失敗の文言を記録する。成功件数が1件以上のとき、成功件数と選択件数を表示する。

拡張子は小文字化した値が許可一覧に含まれるファイルだけを受け付ける。許可一覧の既定は jpg, jpeg, png, gif, webp, svg, ico, html, htm, js, css, txt, pdf であり、設定で上書きできる。アップロードファイル名と同名のフォルダがカレントディレクトリに存在するとき、そのファイルはアップロードしない。

### フォルダ作成

作成先はカレントディレクトリとする。フォルダ名が空・使用できない文字を含む・ピリオドで始まるのいずれかに当たるときは作成しない。同名のファイルまたはフォルダが既に存在するときも作成しない。重複が無ければ作成する。ディレクトリの作成に失敗したときはアップロード失敗と同じ文言を表示する。

### 削除

削除は確認操作を経て実行する。空でないフォルダは画面上で削除を選べない。対象パスが空・未指定・`/` のときは削除しない。

対象が公開ファイル領域の配下に実在するときは、外部ストレージ上の実体とファイルシステム上の実体の双方を削除する。削除後は対象の親ディレクトリをカレントディレクトリとしてファイル管理画面へ戻る。

### ファイルの表示とダウンロード

表示は別画面で行い、公開ファイル領域配下のファイルであれば内容をそのまま返す。

ダウンロードは、対象が公開ファイル領域配下かつディレクトリでないファイルのとき、添付ファイルとして返す。ファイル名は UTF-8 でエンコードして付ける。記号類を除去した結果が空になる名前のときは、ファイル名の指定なしの添付として返す。対象がフォルダのとき、および領域外のときは見つからない（HTTP404）として扱う。

### エラー時の扱い

| 事象 | 扱い |
| --- | --- |
| アップロードでファイル未選択 | 保存しない |
| フォルダ名の検証違反（使用できない文字・先頭のピリオド・空・重複） | 作成しない |
| アップロードファイルの検証違反（同名フォルダ・使用できない文字・先頭のピリオド・許可外の拡張子） | 当該ファイルをスキップし、他の選択ファイルの処理を継続する |
| 保存・ディレクトリ作成の失敗 | アップロード失敗の文言を表示する |
| アップロード先が領域外 | アップロード先不正を表示し、アップロードしない |
| 表示・ダウンロード・削除の対象が領域外 | 見つからない（HTTP404）として扱う、または何も行わない |
| アップロード制限が有効な状態でのアクセス | ファイル管理画面に到達せず、アクセス拒否（HTTP403）として扱う |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | ファイル管理画面の表示要求、フォルダ移動・アップロード・フォルダ作成の送信、削除の要求、表示・ダウンロードの要求。アップロードはmultipart形式でファイルを受け取る。 |
| 成功時出力 | 一覧・ツリー・パンくずを含むファイル管理画面の再描画と成功メッセージ。表示はファイル内容、ダウンロードは添付ファイルのレスポンス。 |
| 失敗時出力 | 検証エラー文言、アップロード失敗文言、または見つからない（HTTP404）・アクセス拒否（HTTP403）。 |

### 入出力: 永続化

公開ファイル領域と外部ストレージの双方に反映する。

| 操作 | 契機 |
| --- | --- |
| 追加 | ファイルのアップロード、フォルダの作成 |
| 削除 | ファイル・フォルダの削除 |
