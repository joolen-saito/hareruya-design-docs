# M04-26（ピッキングリスト印刷）

## 業務ロジック

### 表示の対象

在庫移動指示リスト詳細画面で在庫移動を選び「ピッキングリスト作成」ボタンを押すと、ダイアログを表示する。ダイアログには、その在庫移動で実際に出庫される商品を一覧にしたピッキングリスト（ピック表）のPDFを印刷用に表示する。

対象は出庫処理が行われる商品だけとする。欠品数や実際の移動点数が0枚の商品は表示しない。

商品に棚番号が含まれない場合は表示しない。商品名に略称タグが含まれない場合も表示しない。

本機能は選択した在庫移動の情報を表示するだけで、業務データの更新は行わない。

### 金額閾値によるページ振り分け

表示対象のすべての商品を、金額閾値に応じたページへ振り分ける。閾値は出庫元店舗ごとに定め、選択した在庫移動に含まれる商品ごとの基準価格を参照して振り分ける。

閾値の区分は「●●円未満」「●●円以上▲▲円未満」「■■円以上」として商品閾値に表示し、閾値ごとに商品を振り分けた際の各グループのページ数を表示する。

ページ全体の並び順は金額閾値の昇順とする。

### 同一閾値内の並び順

| 順序 | キー | 並び |
|------|------|------|
| 1 | 棚番 | 昇順。支店の場合は棚番によるソートを行わない |
| 2 | 言語 | 日 → 英 → 他言語 |
| 3 | 状態 | NM → HP |
| 4 | Foilフラグ | 非Foil → Foil |
| 5 | 略称タグ | 昇順 |
| 6 | レアリティ | M → C |
| 7 | 色 | マスターデータの色順を参照する |
| 8 | コレクター番号／英語のカード名 | 略称タグの設定がコレクター番号でのソートならコレクター番号の昇順、アルファベットでのソートなら英語のカード名の昇順 |

### 印刷の実行

「印刷する」ボタンを押すと、PC端末の印刷ダイアログ（印刷プレビュー）を表示する。「印刷する」ボタン自体は印刷範囲に含めない。

### 他機能との境界

在庫移動指示の一覧・検索・詳細・送り状No.登録・削除は「在庫移動指示リスト作成/検索」（M04-24）を正とする。送り状CSVと実績CSV雛形の出力は「在庫移動指示リストエクスポート」（M04-25）を正とする。在庫移動そのものの登録・承認はM04-09系を正とする。

本機能は新規実装であり、現行（pf-eccube3）に同等の機能はない。

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 在庫移動指示リスト詳細画面で選択した在庫移動 |
| 出力 | 選択した在庫移動の出庫対象商品を、金額閾値ごとのページへ振り分けたピッキングリストのPDFをダイアログに印刷用表示 |
| 操作 | 「印刷する」ボタンの押下によるPC端末の印刷ダイアログの表示 |

### 出力: ピッキングリストの項目

| No. | 項目 | 内容 |
|-----|------|------|
| 1 | 印刷するボタン | 押下するとPC端末の印刷ダイアログを表示する。印刷範囲には含めない |
| 2 | 商品閾値 | 出庫元店舗ごとの金額閾値に応じて商品を振り分けた区分（●●円未満／●●円以上▲▲円未満／■■円以上） |
| 3 | ページング | 閾値ごとに商品を振り分けた各グループのページ数 |
| 4 | 作成日時 | ピックリストのPDFを作成した日時 |
| 5 | 行番号 | 各グループ内で商品に割り振る行番号 |
| 6 | 棚番号 | 商品がしまってある場所番号 |
| 7 | 言語 / 状態 | 「言語/状態」の形式。Foilの場合は先頭にFoilを付ける（例: FoilJP/NM） |
| 8 | 略称 | 商品の略称 |
| 9 | 色 / R | 商品情報から取り出した色とレアリティ（例: 赤R）。シングルカード以外は色に該当するデータがないため色は表示しない |
| 10 | 数 | 商品点数 |
| 11 | 商品名 | 商品名から略称・言語・状態・色・レアリティを取り除いた名称 |
| 12 | 価格 | 基準価格 |
| 13 | 備考 | 備考 |
| 14 | ページ内個数小計 | ページ内の商品個数の総計 |

## 表示メッセージ

本機能は画面メッセージを持たない。
