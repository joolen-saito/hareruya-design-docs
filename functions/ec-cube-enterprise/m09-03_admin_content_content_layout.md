# コンテンツ管理 — レイアウト管理

## 業務ロジック

### 一覧の対象と並び

プレビュー用の固定レイアウト（識別子0）を除く全レイアウトを一覧に出す。並びは端末種別の降順、識別子の昇順で、PCはモバイルより前に並ぶ。各レイアウトの割り当て済みページは折りたたみ内に表示する。既定レイアウト（識別子0・1・2）は一覧から削除できない。

### 編集画面の初期表示

新規作成は空のレイアウトを用意する。編集は指定識別子のレイアウトを配置とブロックごと取得し、見つからなければ存在しない（HTTP404）として扱う。配置済みブロックを除いた残りを未使用ブロックとし、配置が無いときは全ブロックを未使用ブロックとする。名称・端末種別・プレビュー対象ページの入力欄とともに、各セクションへ配置済みブロックを、未使用欄へ未使用ブロックを並べる。

### 保存時のブロック配置の作り直し

保存では、まずレイアウト本体（名称・端末種別）を保存し、当該レイアウトの既存ブロック配置をすべて削除したうえで、送信されたブロックごとの値（ブロック識別子・配置先・行番号）から配置を作り直す。差分更新はしない。配置先が未使用の行と、ブロック識別子が取れない行は配置として保存しない。

各セクション内の並び順は、画面側が0始まりで振り直した行番号として送信し、そのまま保存する。表示時はこの行番号の昇順で並べる。

レイアウトは端末種別としてPCまたはモバイルのいずれかを持つ。新規時は選択し、既存編集時は変更せず保持する。

### 名称の必須

名称が未入力なら検証エラーとし、保存しない。

### プレビュー

プレビューでは保存と同じ流れでレイアウトとブロック配置を更新したうえで、選択ページを表示する。選択ページが見つからなければ存在しない（HTTP404）として扱う。

| 選択ページ | 表示先 |
| --- | --- |
| 編集種別が既定以上で、URLが商品詳細のページ | 表示中の商品を1件取り、その商品詳細をプレビュー付きで開く。表示商品が無ければ存在しない（HTTP404）として扱う |
| 編集種別が既定以上の商品詳細以外のページ | そのページURLをプレビュー付きで開く |
| 上記以外のページ | 利用者データ用の経路へ、対象ページURLとプレビュー指定を付けて開く |

プレビューでは保存完了のメッセージを出さない。

### 削除可否

割り当てページが1件でもあるレイアウトは削除しない。削除しなかったときは警告を表示して一覧へ戻す。削除できるときは削除し、完了メッセージを表示して一覧へ戻す。

### ブロックのコードプレビュー取得

画面がコードプレビューを開いたときに、ブロック識別子を非同期で送る。非同期でない要求とブロック識別子が無い要求は不正な要求（HTTP400）として扱う。ブロックが見つからなければ存在しない（HTTP404）として扱う。取得できたときはブロック識別子とテンプレートのソースを返す。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| 編集・プレビュー対象のレイアウト／ページが見つからない | 存在しない（HTTP404）として扱う |
| プレビュー対象が商品詳細で表示商品が無い | 存在しない（HTTP404）として扱う |
| コードプレビューが非同期以外、またはブロック識別子無し | 不正な要求（HTTP400）として扱う |
| コードプレビュー対象のブロックが見つからない | 存在しない（HTTP404）として扱う |
| 名称・端末種別の未入力 | 編集画面を再表示し、名称欄の直下にエラーを出す |
| 削除不可（割り当てページあり） | 削除せず警告を表示して一覧へ戻す |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 一覧・編集画面の表示要求、保存・プレビュー・削除の送信、コードプレビューの非同期取得要求 |
| 成功時出力 | 一覧・編集画面の表示、保存・削除後の遷移と完了メッセージ、プレビューでのフロント画面、コードプレビューのブロック識別子とソース |
| 失敗時出力 | 検証エラーは編集画面の再表示と項目直下のエラー。対象未検出は存在しない（HTTP404）、不正な非同期要求は不正な要求（HTTP400） |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 登録・更新 | レイアウトの保存（本体の保存とブロック配置の作り直し） |
| 削除 | 割り当てページが無いレイアウトの削除 |
