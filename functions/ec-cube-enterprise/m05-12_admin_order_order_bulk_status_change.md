# m05-12_admin_order_order_bulk_status_change（管理画面_受注管理_対応状況一括変更）

## 業務ロジック

### 変更の単位と対象

変更の単位は出荷である。選択した出荷ごとに、その出荷が属する受注をたどって対応状況を変更する。1 件の受注に複数の出荷があるときは、選択した出荷の数だけ処理が走る。

対象件数は選択した出荷の件数とする。変更先は全対象に同じものを適用する。

出荷は先頭から 1 件ずつ順に処理し、1 件の結果が返ってから次の 1 件を処理する。進捗の割合は処理済み件数を対象件数で割って求める。

### 変更先ごとの判定順序

| 順序 | 判定 | 結果 |
| --- | --- | --- |
| 1 | 受注の現在の対応状況が変更先と同一か | 同一のときは変更せず、スキップとして扱う |
| 2 | 状態遷移ルールで変更先へ遷移できるか | 遷移できないときは変更しない |
| 3 | 変更先が配送完了か | 配送完了でないときは受注へ変更先の対応状況を適用する |
| 4 | 配送完了で、当該出荷がまだ出荷済みでないか | 出荷済みでないときは当該出荷の出荷日に現在日時を設定する |
| 5 | 配送完了で、受注配下の全出荷が出荷済みか | 全出荷が出荷済みのときだけ受注へ配送完了を適用する。1 件でも未出荷の出荷が残るときは受注を配送完了へ進めない |

配送完了への一括変更では、複数出荷を持つ受注に対して選択した出荷の出荷日を順に設定していく。全出荷が出荷済みになった時点の出荷で、受注の対応状況が配送完了へ進む。状態遷移ルール上、配送完了へ遷移できるのは新規受付・入金済み・対応中からに限り、それ以外の対応状況からは遷移できない。

### 在庫と会員集計

変更先が対応中またはキャンセルのときは、在庫の戻しと引き当てを伴うため対象の商品規格と在庫情報を更新する。在庫とポイントの調整は状態遷移の処理で行う。

受注に会員が紐づくときは、変更後に会員の購入回数と購入金額などの集計を更新する。

### 他機能との境界

一括の対応状況変更では出荷お知らせメールの送信指定を送らない。メールを送らず、メール送信日も更新しない。

件数と金額の集計表示はこの機能では行わない。

### エラー時の扱い

| エラー内容 | 処理 |
| --- | --- |
| 変更先が未選択 | 送信せずに中断する |
| 非同期要求でない、またはなりすまし対策トークンが不正 | 当該出荷の更新を HTTP400 とする |
| 変更先の対応状況が存在しない | 当該出荷の更新を HTTP400 とする |
| 現在の対応状況と変更先が同一 | スキップとして扱い、他の出荷の処理は続ける |
| 遷移できない組み合わせ | 変更せず、他の出荷の処理は続ける |
| 処理中の想定外の例外 | 当該出荷の更新を HTTP500 とする |

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | 選択した出荷の集合と変更先の対応状況。1 件ごとの要求では出荷IDと変更先の対応状況IDを送る。なりすまし対策トークンと非同期要求であることを伴う |
| 成功時出力 | 出荷ごとに正常を示す応答。スキップまたは遷移不可のときは正常に加えてメッセージを含む |
| 失敗時出力 | トークン不正・非同期要求以外・変更先不存在のときは HTTP400、想定外の例外のときは HTTP500 |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 更新 | 受注の対応状況を変更できたとき |
| 更新 | 配送完了への変更で、未出荷の出荷に出荷日を設定したとき |
| 更新 | 変更先が対応中またはキャンセルのときの商品規格と在庫情報 |
| 更新 | 受注に会員が紐づくときの購入回数・購入金額の集計 |

## 表示メッセージ

| メッセージID | 表示位置 | 画面上の文言 | 表示条件 | 後続処理 |
| --- | --- | --- | --- | --- |
| — | 一括操作領域 | 一括操作 | 出荷を 1 件以上選択したとき | 一括操作領域を表示する |
| — | 一括操作領域の対応状況選択欄 | 対応状況の変更 | 変更先が未選択のとき | 変更先の選択を待つ |
| — | 一括操作領域 | 決定 | 一括操作領域の表示中は常に表示する | 変更先が選択済みのとき確認へ進む |
| — | ブラウザ標準の警告 | 対応状況を選択してください | 変更先が未選択のまま決定したとき | 送信せず中断する |
| — | 確認モーダル本文 | 処理中... | 一括変更の送信中 | 全件の送信が終わるまで表示する |
| — | 確認モーダル本文 | 完了しました。 | 全件の送信が終わったとき | 閉じる操作で受注一覧へ戻り、検索条件を復元して再表示する |
| — | 確認モーダル | 閉じる | 全件の送信が終わったとき | 受注一覧へ戻る |
| — | 確認モーダル内の結果一覧（注意） | %name%: ステータス変更をスキップしました | ある出荷の受注の現在の対応状況が変更先と同一のとき | 当該出荷を変更せず、残りの出荷の処理を続ける |
| — | 確認モーダル内の結果一覧（注意） | %name%: %from% から %to% にはステータス変更できません | ある出荷の受注を変更先へ遷移できないとき | 当該出荷を変更せず、残りの出荷の処理を続ける |
| — | 確認モーダル内の結果一覧（エラー） | システムエラーが発生しました | ある出荷の更新で応答が HTTP400 や HTTP500 などの失敗となったとき | 当該出荷を変更せず、残りの出荷の処理を続ける |

全件を正常に変更できたときは、個別の成功メッセージを出さない。この機能はフラッシュメッセージを生成しない。
