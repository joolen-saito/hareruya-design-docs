# 在庫管理 — 在庫検索/一覧

## 業務ロジック

### 初期表示

メンバー管理で設定されたデフォルト検索表示店舗で絞り込んだ在庫一覧を初期表示する。

検索を伴わない初回表示では、保持していた検索条件・ページ番号・選択中の検索パターンを破棄し、空の一覧を返す（検索前の状態）。

### 検索条件

| 区分 | 項目 |
| --- | --- |
| 基本検索 | 商品名（部分一致）／カード名（部分一致）／商品ID／商品コード（部分一致）／店舗／在庫区分（EC-CUBE在庫・スマレジ在庫） |
| 詳細検索 | カテゴリ／カードセット／言語／Foil／プロモーション／タグ／高額区分／基準価格の下限〜上限（在庫一覧のみ）／発注日／更新日の下限〜上限／セクション／棚番／状態／レアリティ／カード状態／フレーム／保管コード／売上分析タグ／販売価格の下限〜上限／発注数の下限〜上限／在庫数の下限〜上限 |

商品名・カード名・商品ID・商品コードは部分一致で検索する。

### 検索処理

- 在庫を商品情報・商品規格情報から検索し、一覧表示する。店舗・在庫区分別に商品規格の一覧を取得する。本店のほか支店・バックヤード店の在庫、スマレジの在庫を横断して検索する。全店舗とスマレジの在庫をEC-CUBEのデータベースが保持しているため、横断検索も通常の検索処理で行う。
- 一覧の表示順はID降順とする。
- 検索を実行すると入力内容を検証する。基準価格や販売価格の範囲で下限が上限を超えるなど検証エラーがあるときは、画面遷移せずエラーを示したまま空の一覧を返す。検証を通ったときは検索条件を保持し、ページ番号を1に戻し、選択中の検索パターンを解除して1ページ目を表示する。
- ページ送りでは保持している検索条件を復元し、同じ条件で指定ページを表示する。保持していた検索条件が現在の検索フォームの構造と合わないときは、その条件を破棄して空の一覧に戻す。

### 表示件数

表示件数の初期値は10件で、選択肢は10件・50件・100件・300件・500件・1000件・2000件・10000件・12000件である。指定された表示件数は表示件数マスタに登録された値と一致するときだけ採用して以後も保持し、一致しないときは既定の件数に丸める。

### 一覧の表示項目

商品に紐づくかたちで、商品規格単位に在庫数を一覧表示する。商品検索と同様に販売数も一覧に表示する。

| --- | --- |
| 販売数ラベル | — |
| チェックボックス | 在庫分割結合登録・在庫移動振替登録・在庫一括編集の対象を選択する |
| ID | 商品ID |
| 商品名 | 在庫編集へのリンク |
| 商品コード | — |
| 店舗 | — |
| 在庫区分 | — |
| 言語 | — |
| 状態 | — |
| 基準価格 | — |
| 販売価格 | — |
| 買取価格 | — |
| 在庫数 | — |
| 原価単価 | — |
| 総原価 | — |
| 各期間の販売数 | — |
| 在庫変動履歴 | 押下すると「在庫変動履歴」「価格履歴」のリンクを表示する。各リンクを押下すると、選択した行のデータだけに絞り込んだ画面へ遷移する |
| ページング | 検索結果件数と表示件数から算出したページ数分のリンクを表示する |

一覧上部には在庫一括編集・在庫移動振替登録・在庫結合登録・在庫分割登録・在庫情報CSV出力の各ボタンと、在庫情報カスタムCSV出力のリンク、表示件数の選択を置く。

### 一覧からの遷移と遷移可否

チェックボックスで選択した商品規格の在庫を持って各画面へ遷移する。遷移させない条件に当てはまるときはアラートを表示し、遷移せず一覧に留まる。

| 操作 | 遷移先 | 遷移させない条件 |
| --- | --- | --- |
| 在庫一括編集 | 在庫一括編集（M04-03） | 編集権限を持っていない店舗の在庫が選択されている／複数店舗の商品規格が選択されている |
| 在庫移動・振替登録 | 在庫移動・振替登録（M04-09） | 編集権限を持っていない店舗の在庫が選択されている／複数店舗の在庫が選択されている／複数の在庫区分の在庫が選択されている／在庫数が0の在庫が選択されている |
| 在庫結合登録・在庫分割登録 | 在庫分割結合登録（M04-13） | 複数店舗の商品規格が選択されている |
| 在庫変動履歴 | 在庫変動履歴（選択行で絞り込んだ状態） | — |

一括編集の遷移要求を受け取った側は、対象の商品規格が指定されていれば在庫一括編集へ送り、指定が無ければ一覧へ戻す。選択内容そのものの判定は一覧画面側で行う。

### 検索パターンの保存・削除・適用

- 検索パターン名を入力すると検索条件保存ボタンが活性化する。押下すると、その時点で設定されている検索条件を在庫一覧の画面区分として保存し、同名の検索パターンがあれば上書きする。ログインしているメンバーの店舗情報を設定する。**店舗は検索条件の保存に含めない。**
- 保存時に検索フォームが未送信または無効のとき、および検索パターン名が未入力のときは保存しない。
- 検索パターンを選択していると検索条件削除ボタンが活性化する。押下すると選択中の検索パターンを削除する。削除対象が存在しないとき、画面の有効期限が切れているときは削除しない。
- 検索パターンを選択すると、その検索条件を一覧へ適用する。

### CSV出力の入口

| 入口 | ふるまい |
| --- | --- |
| 在庫情報CSV出力ボタン | 保持している検索条件に該当する全件を在庫情報CSV（M04-04）として出力する |
| 在庫情報カスタムCSV出力リンク | 押下すると「カスタムCSVで作成した各種出力フォーマット」と「出力項目設定」のリンクを表示する。フォーマット名を押下すると設定した項目のCSVを出力し、「出力項目設定」を押下するとカスタムCSV出力設定へ遷移する |
| 在庫リコメンドCSV出力 | 同じ検索条件で在庫リコメンドCSV（M04-16）を出力する |

- 検索条件を保持していない状態でCSV出力・カスタムCSV出力・リコメンドCSV出力を要求したときは、エラーを表示して一覧へ戻す。保持していた検索条件が現在の検索フォームの構造と合わないときも、その条件を破棄して同様にエラーを表示する。
- 指定されたカスタムCSVのフォーマットが存在しない、または在庫向けの種別でないときは、出力せず該当なしとして扱う。

## 入出力

### 入出力: 永続化

検索パターンは検索条件・検索パターン名・画面区分（在庫一覧）を保持する。

| 操作 | 契機 |
| --- | --- |
| 登録・更新 | 検索条件保存 |
| 削除 | 検索条件削除 |

在庫一覧は在庫データを参照するだけで、業務データを更新しない（検索・表示・CSV出力）。検索条件・ページ番号・表示件数・選択中の検索パターンは画面をまたいで保持する。

### 入出力: 参照するデータ

- 在庫数は、店舗と在庫区分ごとの規格在庫と、商品規格そのものが持つ在庫数として保持されているものを参照する。
- 在庫変動履歴は店舗・在庫区分ごとの規格在庫に紐づけて保持されており、一覧の在庫変動履歴リンクからは店舗・在庫区分を横断して参照する。
