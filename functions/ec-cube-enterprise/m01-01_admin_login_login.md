# m01-01_admin_login_login（管理画面_認証機能）

## 業務ロジック

### 認証対象

管理者として登録され、ログイン可能な状態の管理アカウントだけを認証対象とする。フロント会員は管理画面の認証主体ではない。金額・件数・在庫などの業務計算は行わない。

### ログイン画面の表示

管理ログインURLへのアクセス時、管理者としてログイン済みならログイン画面を表示せずホーム画面へ遷移する。未ログインならログインID・パスワードの入力画面を表示する。未ログインで保護された管理URLへ来たときもログイン画面へ誘導する。

### ログイン成立の判定順序

| 順序 | 判定 | 結果 |
|------|------|------|
| 1 | ログインIDまたはパスワードが未入力 | ログインを成立させずログイン画面に戻す。入力項目ごとの検証エラーではなく認証失敗として扱う |
| 2 | なりすまし対策トークンが不整合 | 認証せずログイン画面に戻す |
| 3 | 試行回数の制限に該当 | ログインを成立させず、制限状態を表示する |
| 4 | ログインIDに一致する管理者が存在しない | 認証エラーとして扱う |
| 5 | 管理者が停止中またはログイン不可 | 認証エラーとして扱う |
| 6 | パスワードが不一致 | 認証エラーとして扱う |
| 7 | ID・パスワード認証成功、かつ追加認証が必要 | 追加認証画面へ誘導する |
| 8 | ID・パスワード認証成功、かつ追加認証が不要 | 管理セッションを確立し、ホーム画面へ遷移する |

管理者の存在有無、停止状態、ログイン不可状態、パスワード不一致は画面上で区別しない。内部的な失敗理由の区分はログイン履歴またはサーバログで扱う。

### 認証成立後の扱い

ログイン成功・失敗はログイン履歴に残る。成功時は最終ログイン日時も更新する。二段階認証が必要なときは業務画面へ入る前に追加認証へ誘導する。ログイン状態を保持する情報を持つ状態で管理画面へアクセスしたときは、管理ログイン画面へ戻して認証状態を再確立する。無操作時間が設定値を超えたときは自動ログアウト扱いとし、再ログインが必要になる。明示ログアウト時は管理セッションを終了し、ログイン画面へ戻る。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| 入力不足 | 認証を成立させずログイン画面に戻す。入力項目ごとの検証エラーではなく認証失敗として扱う |
| なりすまし対策トークン不整合 | 認証しない。ログイン画面に戻す |
| 管理者が存在しない | 認証エラーとして扱う |
| 停止中・ログイン不可 | 認証エラーとして扱う |
| パスワード不一致 | 認証エラーとして扱う |
| 試行回数超過 | 一時的に送信を拒否または遅延する |
| 二段階認証未完了 | 業務画面へ進めず、追加認証画面へ誘導する |
| ログイン履歴の保存失敗 | 失敗履歴の保存失敗はサーバログへ記録する。成功履歴や最終ログイン日時更新の失敗は握りつぶさず、異常として扱う |
| 予期しないシステムエラー | 汎用エラー画面またはHTTPエラー応答とする。ログイン画面のエラー欄には出さない |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | ログインID、パスワード、なりすまし対策トークン |
| 成功時出力 | 管理セッション作成、ホーム画面または追加認証画面への遷移 |
| 失敗時出力 | ログイン画面に留まり、認証エラーまたは制限状態を表示 |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 追加 | ログイン成功時とログイン失敗時のログイン履歴 |
| 更新 | ログイン成功時の最終ログイン日時 |
