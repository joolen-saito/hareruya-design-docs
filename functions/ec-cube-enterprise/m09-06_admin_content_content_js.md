# コンテンツ管理 — JavaScript管理

管理画面のコンテンツ管理配下で、店舗フロント全ページへ読み込まれるカスタマイズ用JavaScriptファイル（customize.js）の内容を編集画面のエディタで編集し、保存する機能である。

## 業務ロジック

### 初期表示

編集対象ファイルが存在し、かつ書き込み可能なときに限り、その内容をエディタへ初期表示する。書き込み不可・不存在のときは初期値を設定せず空のまま表示し、例外は発生させない。画面表示時、ファイルアップロードの利用頻度に関する案内を未表示であれば1回だけ情報メッセージとして表示する。

### 保存の単位

コード入力1つの内容をそのまま1ファイルへ書き出す。差分管理・履歴は持たない。常に全文上書きである。

### 保存の経路

まず管理サーバ上の編集対象ファイルへ書き出し（ファイルが無ければ作成、あれば上書き）、続いてフロント公開先 `/html/user_data/assets/js/customize.js` へファイル名 `customize.js` で配置する2段の経路である。書き込みに成功したときは保存完了メッセージを表示し、同一のJavaScript管理画面へ遷移する。

### 必須表示と検証の差

画面のコード見出しには必須バッジを表示するが、入力側では必須指定を付与しない。空文字でも検証を通過し、空内容で上書き保存され得る。

### 構文チェックの扱い

構文エラーの検知と登録ボタン非活性はブラウザ側のエディタ機能である。サーバ側ではJavaScript構文の妥当性を検証しない。

### フロントへの反映

フロント共通テンプレートがフロント公開先のJavaScriptアセットを読み込む。保存とフロント公開先への配置が成功すれば、以後フロント全ページの読み込み対象が更新後の内容になる。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| 編集対象ファイルへの書き込み入出力例外 | 保存失敗メッセージを画面に表示し、同一画面を再描画する。保存完了メッセージは表示しない |
| 編集対象ファイルが不存在・書き込み不可 | 画面表示時は初期値を設定せず空表示とする。例外は発生させない |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | コード入力1つ、なりすまし対策トークン |
| 成功時出力 | 保存完了メッセージを伴う同一画面への遷移。編集対象ファイルとフロント公開先のファイル更新 |
| 失敗時出力 | 書き込み失敗時は保存失敗メッセージ付きの同一画面 |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 更新 | 登録時に編集対象ファイルの内容を全文上書きし、フロント公開先へ配置する |
