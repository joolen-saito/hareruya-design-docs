# 受注管理 — 受注詳細メール通知

受注1件に対し、メールテンプレートを選んで件名・本文を編集し、確認画面を経て注文者へメールを送信する。

## 業務ロジック

### 対象受注

URLで指定した受注1件のみを対象とする。複数受注・配送単位の束ねは行わない。受注を特定できないときはアクセスできない。

### 初期表示

対象受注に紐づく送信履歴を取得し、テンプレート未選択・件名空・本文空の編集画面を表示する。

### テンプレート選択時の読み込み

テンプレート選択の検証に成功したときだけ読み込む。

- 本文は、選択テンプレートの本文を対象受注の値で差し込んで作る。選択テンプレートに本文の指定が無いときは既定の受注メールを用いる。
- 件名は、選択テンプレートの件名をそのまま件名欄へ入れる。
- 本文の読み込みに失敗したときは本文を空のままとし、エラーメッセージを表示する。読み込み以外の例外は画面に出さず、本文は空となる。

選択しただけでは件名・本文を保存せず、入力欄へ反映するだけである。

### 確認

送信済みかつ検証に成功したときだけ、件名・本文を編集できない状態にして確認画面を表示する。本文は改行を反映して表示する。検証に失敗したときは確認画面へ進まず、編集画面に留まって項目のエラーを表示する。

テンプレート変更・確認・送信のいずれにも該当しない指定では分岐処理を行わず、現在の入力内容のまま編集画面を再表示する。

### 送信内容

| 項目 | 値 |
| --- | --- |
| 件名 | 「[ショップ名] 入力件名」の形に組み立てる。ショップ名は店舗基本情報から取る |
| 宛先 | 対象受注のメールアドレス |
| 差出人 | 店舗基本情報の送信元アドレスとショップ名 |
| BCC | 店舗基本情報の送信元アドレス |
| 返信先・Return-Path | 店舗基本情報の該当アドレス |
| 本文 | 編集後の本文をプレーンテキストとして送る。HTML本文は組み立てない |

送信後は受注編集画面へ戻る。

### 他機能との境界

受注ステータス・在庫・金額は更新しない。副作用は送信履歴の追加だけである。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| 件名未入力・本文の記法不正 | 編集画面を再表示し、項目ごとのエラーを表示する。確認・送信へ進まない |
| 本文の読み込みに失敗 | 本文を空のまま編集画面を再表示し、エラーメッセージを表示する |
| 本文の差し込み時のその他の例外 | 画面には出さない。本文は空となる |
| メールの送達に失敗 | 画面には専用の文言を出さず、成功扱いで受注編集画面へ戻る。送達保証はメール基盤の範囲とする |
| 受注が存在しない | 受注を特定できずアクセスできない。本機能では専用の文言を持たない |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 受注識別子（URL）、テンプレート選択、件名、本文、および操作の種別（テンプレート変更・確認・送信・戻る） |
| 成功時出力 | 編集画面または確認画面。送信後は受注編集画面へ戻り、成功メッセージを表示する |
| 失敗時出力 | 検証に失敗したときは同一の編集画面にエラーを表示する。本文の読み込みに失敗したときはエラーメッセージ付きで編集画面を再表示する |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 追加 | 送信完了時に、件名・本文・送信日時・宛先会員・受注を送信履歴へ記録する |
