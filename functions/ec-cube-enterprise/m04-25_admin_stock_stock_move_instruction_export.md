# M04-25（在庫移動指示リストエクスポート）

## 業務ロジック

### 出力の種類

在庫移動指示一覧から、外部参照用に 2 種類の CSV を出力する。

| 種類 | 用途 |
| --- | --- |
| 送り状CSV | 一覧で選んだ移動指示について、出庫元店舗を注文者、入庫先店舗を配送先とした送り状（配送ラベル）形式で出力する |
| 在庫移動実績入力用CSV雛形 | 送り状No.の一括登録（M04-24 のCSV登録）へ取り込むための入力用CSVを、見出し行だけで出力する |

送り状CSVは一覧で移動指示を選んで出力する。雛形は一覧のダウンロードリンクを押して出力し、移動指示の選択は伴わない。

### 送り状CSVの出力対象

一覧のチェックボックスで選んだ移動指示だけを対象とする。検索条件は使わず、選んでいない移動指示は条件に一致していても出力しない。

対象の移動指示に、出庫元店舗・入庫先店舗とそれぞれの都道府県を併せて取得し、移動指示IDの昇順で並べる。移動指示 1 件につき 1 行を出力する。

移動指示を 1 件も選ばずに実行したときは出力せず、ページが見つからない扱いとする。選んだIDに該当する移動指示が 1 件も無いときは、見出し行だけのファイルを出力し、エラーは表示しない。

送り状CSVは在庫移動の明細を参照せず、移動指示そのものが持つ金額合計と店舗だけから作る。明細単位の出力は本機能では行わない。

### 送り状CSVの値の作り方

| 出力する値 | 作り方 |
| --- | --- |
| 注文番号 | 移動指示ID |
| 注文金額合計・商品金額合計 | いずれも基準価格の合計 |
| 注文者氏名 | 出庫元店舗の会社名と店名を連結する |
| 注文者カナ | 出庫元店舗の会社名カナと店名カナを連結する |
| 注文者郵便番号・都道府県・住所・住所2・電話番号 | 出庫元店舗の同名の値 |
| 配送先氏名 | 入庫先店舗の会社名と店名を連結する |
| 配送先カナ | 入庫先店舗の会社名カナと店名カナを連結する |
| 配送先郵便番号・都道府県・住所・住所2・電話番号 | 入庫先店舗の同名の値 |
| 送料・送料(税抜)・手数料・手数料(税抜) | いずれも `0` 固定 |
| 郵便種別 | `0` 固定（0：ゆうパック） |
| 発送方法 | `ゆうパック` 固定 |

氏名・カナの連結は、会社名と店名の前後の空白を除いたうえで、両方あれば半角空白 1 個でつなぎ、片方だけならその値、両方とも空なら空欄とする。

### 出力する列

送り状CSVの列は 23 列で固定とし、出力する項目を選ぶことはできない。

## 入出力

### 出力: 送り状CSVファイル

| 項目 | 内容 |
| --- | --- |
| 文字コード | CSV出力の設定に従う（既定は `SJIS-win`）。UTF-8 のときはバイトオーダーマークを付ける |
| 区切り文字 | CSV出力の設定に従う |
| ファイル名 | `stock_move_instruction_labels_` に出力日時を `YmdHis` の形式でつなぎ、`.csv` を付けた名前 |
| 応答 | ダウンロードとして返す |

### 出力: 在庫移動実績入力用CSV雛形

| 項目 | 内容 |
| --- | --- |
| 出力する列 | `移動指示ID` / `出庫元店舗(名称)` / `入庫先店舗(名称)` / `送り状No.` の 4 列。見出し行だけを出力し、データ行は出力しない |
| 文字コード | CSV出力の設定に従う（既定は `SJIS-win`）。UTF-8 のときだけバイトオーダーマークを付ける |
| 区切り文字 | CSV出力の設定に従う（既定は `,`） |
| ファイル名 | `stock_move_instruction_record_template_` に出力日時を `YmdHis` の形式でつなぎ、`.csv` を付けた名前 |
| 応答 | ダウンロードとして返す。応答に載せる文字コード名は、設定が `SJIS-win` のときだけ `windows-31j` へ読み替える |

この 4 列は、送り状No.一括登録のCSV取込が要求する列と一致する。

### 更新するデータ

在庫移動指示と、その出庫元店舗・入庫先店舗を参照するだけで、出力によって業務データは更新しない。

## 表示メッセージ

本機能は画面メッセージを持たない。
