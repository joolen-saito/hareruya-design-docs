# 受注管理 — 受注対応状況の変更

受注編集（詳細）画面で、受注の対応状況（受注ステータス）を別のステータスへ変更し、変更後の状態と関連する日時を保存する処理。

## 業務ロジック

### 遷移先の絞り込み

対応状況プルダウンの選択肢は、受注ステータス遷移の許可規則で現在のステータスから到達できる遷移先に限る。到達できないステータスおよび現在のステータス自身は選択肢から除外する。画面には「現在のステータス」として現在の対応状況の表示名を表示する。

### 変更の成立条件

変更前ステータスと変更後ステータスがともに取得でき、両者が異なり、受注フォームが妥当であることを成立条件とする。いずれかを満たさないときは何も変更せず受注編集（詳細）画面へ戻す。取消への変更または取消からの変更にあたるときは、送信前に確認ダイアログを表示し、取り消されたときは送信しない。

### 日時のセットと遷移の判定順序

変更前ステータスと変更後ステータスが異なり、かつ受注フォームが妥当なときに、現在日時を一度だけ取得し、次の順で処理する。各日時は条件を満たすときだけ更新する。

| 順序 | 判定 | 結果 |
|------|------|------|
| 1 | 変更後が発送済みかつ変更前が発送済みでない | 受注の出荷日に現在日時をセットし、受注配下の各配送の出荷日にも現在日時をセットする |
| 2 | 変更後が取消かつ変更前が取消でなく、取消日が未設定 | 受注の取消日に現在日時をセットする |
| 3 | 変更後が入金済みかつ変更前が入金済みでなく、入金日が未設定 | 受注の入金日に現在日時をセットする |
| 4 | 変更後がピック中かつ変更前がピック中でなく、確認日が未設定 | 受注の確認日に現在日時をセットする |
| 5 | 上記の日時セット後 | 受注のステータスを変更前ステータスへ戻す |
| 6 | 一連の更新の開始後 | 受注ステータス遷移の許可規則に従い変更後ステータスへ遷移を適用する。許可されない遷移のときは遷移適用が失敗する |
| 7 | 遷移適用後 | 受注の更新者を操作中の管理者、更新日時を現在日時としてセットし保存する |
| 8 | 変更後が発送済みかつ変更前が発送済みでない場合のみ | 付与ポイントを会員残高へ反映し、外部在庫連携サービスへ発生ポイントを連携する |
| 9 | 受注に外部連携コードがあり、変更後ステータスが取消でない場合のみ | 外部連携サービスへ商品情報を連携する |

順序1から4の日時セットは、遷移可否の判定より前に行う。遷移が許可されず一連の更新を巻き戻したときは、これらの日時セットは保存されない。入金日は受注ステータス遷移側でも入金遷移時にセットされる。本操作では遷移適用の前に未設定時の入金日を補完する。

取消日・入金日・確認日は既設定のときは上書きしない。出荷日は受注と各配送の双方にセットする。

### ポイントと外部連携

出荷完了へ新たに遷移したときのみ、付与ポイントを会員残高へ反映し、外部在庫連携へ発生ポイントを連携する。本操作ではポイントの入力欄を持たず、ポイント値の再計算は行わない。受注に外部連携コードがあり変更後ステータスが取消でない場合のみ、外部連携サービスへ商品情報を連携する。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| 許可されない遷移先の指定 | 受注ステータス項目にステータス変更不可のエラーを表示する。確定処理側でも遷移適用が失敗すれば一連の更新を巻き戻す |
| 変更前後が同一・ステータス取得不可 | 変更せず受注編集（詳細）画面へ戻す。専用の利用者向けメッセージは出さない |
| 購入処理上の異常 | エラーメッセージを表示し、受注編集（詳細）画面を再表示する |
| 指定IDの受注が存在しない | 受注が見つからない（HTTP 404）として扱う |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | 受注編集（詳細）画面からの対応状況変更の送信。対応状況プルダウンの選択値を含む受注フォーム |
| 成功時出力 | 受注ステータスと関連日時・更新者・更新日時を保存し、受注編集（詳細）画面へ戻ってメッセージを表示する |
| 失敗時出力 | 変更せずに受注編集（詳細）画面へ戻す、または受注ステータスの検証エラーや購入処理の異常メッセージを表示して画面を再表示する |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 更新 | 対応状況変更の成立時の受注ステータス・出荷日・取消日・入金日・確認日・更新者・更新日時、および受注配下の各配送の出荷日 |
| 更新 | 出荷完了へ新たに遷移したときの会員のポイント残高 |
