# ネット買取管理 — 戻しリストPDF

## 業務ロジック

### 機能の位置づけ

ネット買取の棚戻し業務で使うリストを、印刷に適した体裁のPDFとして出力する。買取一覧で選択した買取注文が対象で、出力するデータの源は戻しリストCSV（M07-08）と同じである。

参照するのは実在庫・買取注文・規格・棚番と、本店の店舗基本情報に設定された3段の金額閾値である。店頭買取のデータは別系統であり、本機能では参照しない。本機能は参照だけを行い、買取注文・在庫のデータを更新しない。

### 出力対象

買取一覧で選択された買取注文に紐づく実在庫情報を取得する。対象を決めるのは選択であって、一覧の検索条件ではない。

出力できないのは次の場合で、いずれも出力せずに買取一覧へ戻す。

| 条件 | 扱い |
| --- | --- |
| 買取注文を1件も選ばずに出力を実行した | 選択を促し、送信しない（ブラウザダイアログ）。送信された場合は買取一覧へ戻す |
| 選択した買取番号に対応するデータが無い | 該当する買取番号を示して買取一覧へ戻す |
| 選択に入庫待ち・入庫済み以外のステータスの買取注文が含まれる | 該当する買取番号を示して買取一覧へ戻す |

### 商品仕訳と金額閾値

取得した実在庫は、対象店舗ごとに指定された金額の閾値とサプライとに分けて出力する。ネット買取管理では対象店舗が本店だけであるため、本店の閾値を使う。

金額の閾値は店舗ごとに分けて設定できる（マスターデータ管理）。本店3F・2F・B2Fや支店で閾値が異なり、帳票のフォーマットは3F・2F・B2Fそれぞれで異なるものとなる。仕訳の見出しは「●●円未満」「●●円以上▲▲円未満」「■■円以上」「サプライ」の形式で出力する。

閾値の判定と表示はいずれも基準価格を参照する。セール中で金額が変わっても棚を移動することはないためである。

現行運用の閾値（本店3F在庫）は次のとおり。シングルカードは低額が4800円未満、高額が4800円以上。金庫には基本的にEC在庫で500万円以上のものを保管し、ほかは備品などを入れている。シングルカード以外では、2Fに置ききれない（商品化していない）サプライパックボックス等を倉庫に保管する。

カスタマイズ要件に記載の内容以外は現行踏襲とする。

### 商品名の整形

サプライ品でない商品は、商品名から略称・言語・状態・色・レアリティを取り除いて出力する。

商品名に略称タグが含まれない場合は、角括弧で囲まれた部分を角括弧ごと削除する。

### 並び順

最優先は金額閾値の昇順で、サプライを最後に置く。同じ金額閾値の中では次の順で並べる。

| 順序 | キー | 並び |
| --- | --- | --- |
| 1 | 棚番 | 昇順。支店の場合は棚番の並べ替えを行わない |
| 2 | 言語 | 日→英→他言語 |
| 3 | 状態 | NM→HP |
| 4 | Foilかどうか | 非Foil→Foil |
| 5 | 略称タグ | 昇順 |
| 6 | レアリティ | M→C |
| 7 | 色 | マスターデータの色順に従う |
| 8 | コレクター番号／英語のカード名 | 略称タグにコレクター番号での並べ替えが設定されているときはコレクター番号の昇順、アルファベットでの並べ替えが設定されているときは英語のカード名の昇順 |

### 表示と印刷

リストはポップアップで表示する（カスタマイズ要件。在庫指示リスト内の在庫移動データのピッキングリスト情報をポップアップで表示する）。ページは印刷に最適化した状態で表示し、「印刷する」ボタンは印刷範囲に含めない。

「印刷する」ボタンを押すと、利用者の端末の印刷ダイアログが開き、印刷を実行する。

ポップアップがブロックされてPDFを開けなかったとき、およびPDF用データの取得に失敗したときは、PDFを表示せず買取一覧に留まる。

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | 買取一覧で選択した買取注文 |
| 成功時出力 | 戻しリストのPDF。別ウィンドウで開き、印刷できる |
| 失敗時出力 | 選択なし・対象なし・ステータス不一致のメッセージと買取一覧への遷移、ポップアップブロック時と取得失敗時のダイアログ |

参照のみの機能であり、登録・更新するデータは無い。

### 出力: 帳票の項目

| 識別ID | 項目 | 出力する内容 |
| --- | --- | --- |
| 1 | 印刷するボタン | 押下すると利用者の端末の印刷ダイアログが表示され、印刷を開始する。ボタン自体は印刷範囲に含めない |
| 2 | 商品仕訳 | 店舗ごとの閾値とサプライ。ネット買取管理では本店しかないため本店の閾値を使う。「●●円未満」「●●円以上▲▲円未満」「■■円以上」「サプライ」の形式で、閾値の表示も基準価格を参照して行う |
| 3 | ページング | 閾値ごとのページ数 |
| 4 | 作成日時 | ピッキングリストを作成した日時（「ピッキングリスト印刷」ボタンを押した日時） |
| 5 | 行番号 | 各ページごとに商品へ割り振る行番号 |
| 6 | 棚番号 | 本店のみ出力する |
| 7 | 言語 / 状態 | 「言語/状態」の形式。Foilの場合はFoilを付ける（例: FoilJP/NM）。サプライ品の場合は「サプライ品」と表示する |
| 8 | 略称 | 商品の略称。サプライ品の場合は表示しない |
| 9 | 色 / R | 商品名から取り出した色とレアリティ（例: 金R） |
| 10 | 数 | 商品点数 |
| 11 | 商品名 | 商品名。サプライ品でない場合は略称・言語・状態・色・レアリティを取り除いた名称 |
| 12 | 価格 | 基準価格 |
| 13 | 備考 | 備考 |
| 14 | ページ内個数小計 | そのページ内の商品個数の総計 |
