# m11-04_admin_system_setting_setting_system_login_history（管理画面_ログイン履歴）

## 業務ロジック

### 表示対象

ログイン履歴のうち検索条件に一致する行を表示する。成功と失敗の双方を含む。列はID・ログインID・IPアドレス・ログイン試行日時・成功失敗区分とする。

### 並び順

ログイン試行日時の降順とし、同一日時内はID降順とする。

### 初期表示

ページ番号の指定も再表示の指定もないときは、検索条件を空にして保持し、1ページ目を全件対象で表示する。ページ番号付きの表示、または再表示のときは、保持した検索条件と保持したページ番号で絞り込む。

### 検索

| 順序 | 判定 | 結果 |
| --- | --- | --- |
| 1 | 入力値の検証に成功したとき | 検索条件とページ番号1を保持し、1ページ目と検索結果件数を表示する |
| 2 | 入力値の検証に失敗したとき | 一覧を出さず、詳細検索の欄を開いた状態で再表示する。検索条件は保持しない |

キーワード検索では、入力中の半角スペースと全角スペースを除いてから部分一致の条件を組み立てる。ログインID欄とIPアドレス欄だけの検索ではスペースを除かない。

### 表示件数

保持した表示件数を用い、保持していないときは既定の表示件数を用いる。要求で指定された表示件数は、表示件数マスタの値と一致するときだけ採用して保持する。一致しないときは採用せず、保持済みまたは既定の件数を用いる。

ページ番号は要求の値を保持し、保持した検索条件のまま指定ページ・指定件数で表示する。

### 成功失敗区分

保存値は失敗が0、成功が1とする。一覧では区分名をバッジで示し、色で成功と失敗を区別する。

### エラー時の扱い

| 事象 | 扱い |
| --- | --- |
| 検索条件の検証に失敗したとき | 一覧を出さず、詳細検索の欄を開いた状態で再表示する。検索条件は保持しない |
| 検索結果が0件のとき | 一覧表を出さず、0件の文言を表示する |
| 表示件数が不正な値のとき | 採用せず、保持済みまたは既定の件数で表示する |
| データ読み取りに障害があったとき | 共通の例外処理に委ねる。本機能専用の文言は設けない |

本機能では金額・在庫などの業務計算を行わない。件数の表示はページ表示部品の総件数に従う。

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | 一覧表示の要求、検索条件、ページ番号、表示件数 |
| 成功時出力 | 検索条件に一致する履歴行を、ID・ログインID・IPアドレス・ログイン試行日時・成功失敗区分の列でページ表示する |
| 失敗時出力 | 検索条件の検証に失敗したときは一覧を出さず、詳細検索の欄を開いた状態で見直しの文言を表示する |

### 入出力: 永続化

本機能はデータを更新しない。
