# 店舗設定 — 受注対応状況設定

## 業務ロジック

### 画面の位置づけと表示

管理画面の「店舗設定」から辿る画面で、画面のサブタイトルは日本語では「基本情報設定」と表示する。受注対応状況ごとに、名称（受注管理）・名称（マイページ）・色・受注管理画面でのステータス別件数表示の有無をまとめて編集する。

一覧は受注対応状況を表示順の昇順で列挙する。名称（受注管理）と件数表示は受注対応状況そのものの値を初期表示とする。名称（マイページ）と色は、同じIDのマイページ用対応状況・対応状況の色があるときだけ、その値を初期表示とする。

### 識別子と並び順

受注対応状況のIDは参照表示のみで編集できない。画面上の行順は保存時にも変更せず、一覧の並びは表示順の昇順だけで決まる。

### 保存の内容

各行の入力が妥当なときは、受注対応状況へ名称（受注管理）と件数表示を反映する。名称（マイページ）は同じIDのマイページ用対応状況があるときだけ上書きし、色は同じIDの対応状況の色があるときだけ上書きする。いずれも該当する行が無いときは保存しない。保存後は同じ画面を開き直し、更新後の内容を読み直して表示する。

いずれかの項目が未入力、または最大長を超えるときは保存せず、同じ画面に該当項目のエラーを表示する。金額・税率などの業務計算は行わない。

### エラー時の扱い

| 事象 | 扱い |
| --- | --- |
| 入力必須違反・最大長超過 | 保存せず、項目ごとのエラーを画面に表示する |
| 要求が正当でないとき | 共通の拒否処理に従う |
| 権限が無いとき | 共通の認可エラー応答に従う |
| 保存時の障害 | 共通の例外処理に委ねる。本機能固有の利用者向け補足は表示しない |

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | 受注対応状況ごとの名称（受注管理）・名称（マイページ）・色・件数表示の有無 |
| 成功時出力 | 保存完了を表示し、更新後の内容を再表示する |
| 失敗時出力 | 同じ画面に項目ごとのエラーを表示する。権限が無いときは共通の認可エラー応答 |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 更新 | 保存時に、受注対応状況の名称（受注管理）と件数表示を更新する |
| 更新 | 保存時に同じIDのマイページ用対応状況があるとき、名称（マイページ）を更新する |
| 更新 | 保存時に同じIDの対応状況の色があるとき、色を更新する |
