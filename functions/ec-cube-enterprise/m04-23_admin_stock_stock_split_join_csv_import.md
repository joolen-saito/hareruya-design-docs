# 在庫管理 — 在庫分割結合CSV登録

## 業務ロジック

### 登録の単位

在庫分割結合検索/一覧画面のモーダルからCSVをアップロードし、在庫分割または在庫結合をファイル単位で一括登録する。分割と結合は別のモーダル・別のCSVで、登録の入口も分かれている。

分割は登録に続けて承認申請まで行い、ステータスは分割承認待ちになる。登録処理完了後、分割対象の店舗の対象商品の在庫が分割数分減る。結合は登録に続けて欠品入力への遷移まで行い、ステータスは結合元登録になる。登録処理完了後、結合対象の店舗の対象商品の在庫が結合元在庫数分減る。

分割・結合そのものの登録／承認の内容は、在庫分割・結合登録（M04-13）の新規登録・分割先登録・結合元登録に従う。

### 登録前の検証

分割・結合とも、取込を始める前に次の順で確認する。いずれかで止まったときは登録せず、エラーを表示して在庫分割結合検索/一覧画面へ戻る。

1. セッションが期限切れでないこと。
2. アップロードファイルが選択されており、正常にアップロードできていること。
3. 店舗が特定できること。店舗の指定があればその店舗、指定が無ければ既定の店舗を用いる。
4. 在庫区分が正しいこと。分割はEC-CUBE在庫・スマレジ在庫のいずれかだけを許可する。結合は在庫区分の選択を必須とし、結合元の在庫区分はCSVの行ごとの値から別に特定する。
5. 管理者としてログインしていること。

取込の途中で想定外の障害が起きたときも、登録せずエラーを表示して一覧画面へ戻る。

### 取込の単位と取り消し

ファイル全体を1つの取引として処理する。**1件でもエラーがあれば全件を取り消し、部分的な登録は残さない。** 形式のエラーでも業務のエラーでも扱いは同じで、全行が成功したときだけ登録を確定し、成功件数を表示する。

### 行の検証

- 1ファイルに登録できるのは2,000行までとする。超えた時点で以降の行を読まずに中断し、エラーとする（上限は性能試験により確定する）。
- 列数が既定と違う行（分割は4列、結合は5列でない行）は、その行を読み飛ばしてエラーとする。
- 必須の見出しが欠けているときは取込を中断し、エラーとする。CSV以外のファイルや、既定の列と異なるCSVはフォーマット不一致となる。
- 各項目について、未入力でないこと・数値であること・正の数であることを確認する。分割は分割数が0より大きく、分割先在庫数が1以上であること。結合は結合数が0より大きく、結合元在庫数が1以上であること。
- 不正な行は読み飛ばし、エラーとして記録する。

検証を通った行だけを蓄えておき、全行を読み終えてから業務の登録に進む。エラーがある・有効な行が1件も無いときは、登録に進まず取り消す。

### 分割の登録

- 分割元商品コードと分割数の組でグループにまとめる。
- 分割元の在庫を、商品コード・店舗・在庫区分の組で特定する。見つからなければエラーとする。
- 分割先の在庫も同じ組で特定する。見つからない、または分割元と同じ在庫を指しているときはエラーとする。同じ分割先が複数行にあるときは数量を合算する。
- 分割元商品コードが1つであることを確認する。
- 分割元の在庫数が分割数以上であることを確認する。足りなければエラーとする。
- グループごとに分割を登録し、続けて承認申請を行ってステータスを分割承認待ちにする。登録できなかったグループはエラーとする。
- 全グループが成功したときだけ確定し、登録した件数を成功メッセージに出す。

### 結合の登録

- 結合先商品コードと結合数の組でグループにまとめる。
- 結合先の在庫を、商品コード・店舗・在庫区分の組で特定する。見つからなければエラーとする。
- 結合元の在庫は、CSVの行が持つ結合元在庫区分から特定する。区分の値は「1」「EC-CUBE」「自社」などをEC-CUBE在庫、「2」「スマレジ」などをスマレジ在庫として読み替える。区分が正しくない、在庫が見つからない、結合先と同じ在庫を指しているときはエラーとする。
- 結合先商品コードが1つであることを確認する。
- 結合元の在庫数が結合元在庫数以上であることを確認する。足りなければエラーとする。
- グループごとに結合を登録してステータスを結合元登録にし、続けて欠品入力へ進める。欠品入力へ進められないときはエラーとする。
- 全グループが成功したときだけ確定し、登録した件数を成功メッセージに出す。

### エラー時の挙動

- 行単位の形式エラー（列数・未入力・数値の不正）も、業務のエラー（商品コードが特定できない・在庫数が足りない・分割元と分割先が同一など）も、いずれもモーダルを表示していた元画面、すなわち在庫分割結合検索/一覧画面の上部のエラー表示エリアに出す。
- エラーが1件でもあれば登録は一切確定しない。
- エラーが起きたとき、モーダルの選択内容はリセットされる。一覧の検索条件と状態は保たれる。

### Excel設計書との乖離

CSVの見出しはExcel設計書の「結合数」「結合元在庫数」を正とする。現状の実装は雛形の出力・取込のいずれも「結合数量」「結合元数量」を用いており、Excel設計書の表記と食い違う。実装側の是正対象で、Excel設計書の表記のCSVを取り込めるよう見出しの定義を直す必要がある。

## 入出力

### 入力: アップロードフォーム

| 画面上の項目 | 内容 |
| --- | --- |
| 店舗 | 単一選択（セレクトボックス）。必須。在庫分割・結合登録 編集の店舗選択と同じ選び方をする |
| 在庫区分 | 単一選択（ラジオボタン）。必須。EC-CUBE在庫またはスマレジ在庫 |
| 承認通知先（所属選択） | 単一選択（セレクトボックス）。任意。分割だけが持つ。編集している在庫を保持している店舗の所属から選択肢を作る |
| 承認通知先（メンバー選択） | 複数選択（セレクトボックス）。分割だけが持つ。承認を行う担当者へメール通知するために選ぶ。承認通知が必要なときは必須 |
| ファイルを選択 | 必須。押下するとファイル選択のダイアログが開き、CSVファイルをアップロードできる。受け付けるのはCSV形式（text/csv・text/plain・application/csv）のファイルだけ |
| 登録 | 押下でCSV登録処理を実行する |
| 雛形をダウンロード | 押下で見出しだけのCSVファイルを出力する |

結合のフォームは承認通知先の2項目を持たない。

### 入力: 登録CSV（分割）

見出しは4列で、順序は次のとおり。いずれも必須。

| 見出し | 内容 |
| --- | --- |
| 分割元商品コード | 在庫分割元の商品コード。255文字まで |
| 分割数 | 在庫分割元の分割数。数値で0~999999999 |
| 分割先商品コード | 在庫分割先の商品コード。255文字まで |
| 分割先在庫数 | 在庫分割先の商品の点数。数値で0~999999999 |

### 入力: 登録CSV（結合）

見出しは5列で、順序は次のとおり。いずれも必須。

| 見出し | 内容 |
| --- | --- |
| 結合先商品コード | 在庫結合先の商品コード。255文字まで |
| 結合数 | 在庫結合先の結合数。数値で1~999999999 |
| 結合元商品コード | 在庫結合元の商品コード。255文字まで |
| 結合元在庫区分 | 在庫結合元の在庫区分（1: EC-CUBE、2: スマレジ） |
| 結合元在庫数 | 在庫結合元の商品の点数。数値で1~999999999 |

### 出力: CSV雛形ファイル

見出しだけを書いたCSVファイルをダウンロードとして返す。文字コードはUTF-8で、バイトオーダーマークを付ける。列は登録CSVと同じで、分割は4列、結合は5列である。

### 出力: 承認通知先メンバー

分割CSV登録モーダルからの求めに応じて、選択した店舗で承認権限を持つメンバーの一覧を返す。承認通知先（メンバー選択）の選択肢に使う。

### 出力: 承認アラートメール

取込が成功したときだけ、選択された承認通知先メンバーへ承認を促すメールを送信する。取込が失敗したときは送信しない。

### 入出力: 永続化

| 対象 | 内容 |
| --- | --- |
| 在庫分割結合 | タイプ・基準価格・原価単価・総原価・在庫数・分割結合数・ステータスなどを登録する |
| 在庫分割結合明細 | 基準価格・原価単価・在庫数・欠品点数などを登録する |
| ステータス | 分割は分割承認待ち、結合は結合元登録とする。状態の移り変わりは履歴として残す |
| 在庫 | 分割元・結合元の在庫が、分割数・結合元在庫数の分だけ確保・更新される |
| 取込履歴 | 本機能の取込では取込の履歴を残さない |

登録は取込1回につき1つの取引で行うため、エラーがあれば上記のいずれも残らない。
