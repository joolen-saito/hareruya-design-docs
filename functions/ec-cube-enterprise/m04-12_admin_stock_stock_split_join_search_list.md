# 在庫管理 — 在庫分割結合検索/一覧

## 業務ロジック

### 一覧の役割と検索前の状態

在庫分割・在庫結合の登録情報を、商品名・商品コード・店舗・在庫区分・タイプ・ステータス・登録日・承認日・登録者・承認者などの条件で検索し、一覧表示する。一覧からは在庫分割・在庫結合のCSV一括登録（モーダル）、検索結果に対する在庫分割結合情報CSV出力、結合新規画面への遷移ができる。

一覧を検索せずに開いたときは検索前の状態とし、空の一覧と、在庫分割CSV登録・在庫結合CSV登録それぞれのモーダル入力欄だけを表示する。

### 検索の実行と検索条件の保持

- 検索ボタンを押すと検索を実行し、完了後にページを再描画して検索結果の件数と一覧を表示する。
- 入力に不備が無いときだけ、実行した検索条件を保持する。不備があるときは条件を保持しない。
- 検索条件クリアを指定したときは、保持している検索条件を破棄して一覧の初期表示へ戻す。
- 検索条件の復元を指定したときは、保持している検索条件を検索欄へ戻して再検索する。
- 検索と一覧表示は参照だけを行い、在庫分割・結合の登録内容を更新しない。保持するのは検索条件だけである。

### 検索条件

| 区分 | 画面上の項目 | 絞り込み |
| --- | --- | --- |
| 検索対象切替 | 商品名・商品コード検索対象（二者択一、初期値「分割元・結合先」） | 商品名・商品コードの照合先を「分割元・結合先」か「分割先・結合元」かで切り替える |
| 基本検索 | 商品名 | 商品名への部分一致 |
| 基本検索 | 商品コード | 商品コードへの部分一致 |
| 基本検索 | 店舗 | 数値を入れたときは店舗の識別値に一致、文字列を入れたときは店舗名への部分一致 |
| 基本検索 | 在庫区分（チェックボックス複数：EC-CUBE在庫／スマレジ在庫） | 選択したいずれかの在庫区分に一致。未選択のときは全件 |
| 基本検索 | タイプ（チェックボックス複数：分割／結合） | 選択したいずれかのタイプに一致。未選択のときは全件 |
| 基本検索 | ステータス（チェックボックス複数） | 選択したいずれかのステータスに一致。未選択のときは全件 |
| 詳細検索 | 登録日(From)／登録日(To)（yyyy/mm/dd、カレンダー選択あり） | 登録日時の範囲 |
| 詳細検索 | 承認日(From)／承認日(To)（yyyy/mm/dd、カレンダー選択あり） | 承認・却下日時の範囲 |
| 詳細検索 | 更新日(From)／更新日(To) | 更新日時の範囲 |
| 詳細検索 | 登録者 | 登録した担当者に一致 |
| 詳細検索 | 承認者 | 承認した担当者に一致 |

各検索条件は、在庫分割・結合登録編集（分割／結合）画面の同じ項目を検索対象とする。

登録日・承認日・更新日は、開始が終了より後の日付のときは終了側の入力欄へ日付範囲のエラーを付け、検索条件を保持しない。

タイプとステータスは、チェックを付けずに送ると空の選択が渡って結果が0件になりうるため、「未選択＝全件」として扱う。

### 検索対象の切替

商品名・商品コードの照合先は、検索対象切替の選択で決まる。

- 分割元・結合先を選んだとき: 分割は分割元、結合は結合先にあたる在庫の商品名・商品コードを照合する。
- 分割先・結合元を選んだとき: 分割は分割先、結合は結合元にあたる明細の商品名・商品コードを照合する。

### ステータスの選択肢

ステータスは 新規登録／結合元登録／分割承認待ち／結合承認待ち／入庫済み／却下 の6種で、この順（識別値の昇順）で並べる。

画面ではタイプごとに表示する選択肢を分ける。分割は 新規登録・分割承認待ち・却下・入庫完了、結合は 新規登録・結合元登録・結合承認待ち・却下・入庫完了 である。

### 一覧の並びと件数

- 一覧は登録日時の降順に並べる。Excel設計書の「ID（実質は登録日）を降順」と同じ並びである。
- 検索結果はページ分割せず全件を返す。表示件数を選ぶ手段は持たない（画面側での件数制御の有無は要確認）。

### CSV一括登録の入口

- 在庫分割CSV登録ボタンを押すと在庫分割CSV登録モーダルを表示する。登録されると、対象の在庫分割のステータスは分割承認待ちになる。
- 在庫結合CSV登録ボタンを押すと在庫結合CSV登録モーダルを表示する。登録されると、対象の在庫結合のステータスは結合元登録になる。
- 取り込みの本体（必須ヘッダ・検証・登録処理）はM04-23を正とする。取り込み後は一覧へ戻る。
- CSV登録でエラーがあり登録されなかったときは、一覧画面上部のエラー表示エリアにエラー内容を表示する。検索項目と一覧の選択状態は失われないが、モーダルの選択内容はリセットされる。

### 各種出力ボタンの活性

検索結果一覧で分割・結合をチェックすると、各種出力ボタンが押せるようになる。在庫分割結合CSV出力の出力列・整形はM04-14、カスタムCSV出力はM04-15を正とする。

### 結合新規への遷移

一覧から在庫結合の新規登録を開くときは、指定された在庫から対象を解決して結合新規画面へ移る。在庫が指定されていないとき、または指定した在庫が存在しないときは、在庫が見つからない旨を表示して一覧へ戻す。

### Excel設計書との乖離

検索条件の入力形式は、Excel設計書の記載と実装で確認したふるまいが食い違う。本書は検索条件のふるまいを実装で確認した内容で記述する。

| 本書の記載 | Excel設計書の記載 |
| --- | --- |
| 商品名・商品コード検索対象は二者択一（ラジオ相当）で、初期値は「分割元・結合先」 | 書式は「チェックボックス」、初期値は「分割元・結合先」 |
| 店舗は自由入力で、数値のときは店舗の識別値に一致、文字列のときは店舗名への部分一致 | 書式は「複数選択(セレクトボックス)」 |

## 入出力

### 出力: 一覧の列

一覧には、タイプ（分割／結合）、店舗（在庫の会社名）、在庫区分（EC-CUBE在庫／スマレジ在庫）、分割元・結合先の商品名（商品名に規格1・規格2を添えたもの）、分割元・結合先の点数、分割先・結合元の点数（明細の合計）、基準価格の合計、ステータス、登録日時、登録者を出す。画面上の列の詳細はExcel設計書（識別ID 5-1〜5-14）を正とする。

### 出力: ステータス照会

指定した在庫分割結合1件のステータスを読み直して返す。別のタブで更新を行ったあと、一覧を軽く読み直すための経路である。

### 出力: CSV登録の雛形

在庫分割CSV登録の雛形はヘッダ4列だけ、在庫結合CSV登録の雛形はヘッダ5列だけのCSVで、いずれもUTF-8（BOM付き）で出力する。

### 出力: 承認通知先メンバー

在庫分割CSV登録モーダルのために、指定した店舗に紐づく承認権限を持つ担当者を、所属別のマトリクスと選択肢の形で返す。店舗が特定できないときは空で返し、編集権限の無い店舗では取得できない。

### 出力: 在庫分割結合情報CSV

保持している検索条件で在庫分割結合情報CSVを出力する。出力列と整形はM04-14を正とする。
