# 在庫管理 — 戻しリストPDF

## 業務ロジック

### 出力の目的と対象

在庫移動・振替一覧でチェック選択した在庫移動・振替情報をもとに、入庫先（移動先）店舗で棚へ戻すための戻しリストを、印刷用レイアウトで表示する。印刷用に整形したHTMLを別ウィンドウ（ポップアップ）へ表示し、ブラウザの印刷ダイアログから印刷する方式で、ファイルのダウンロードは行わない。現行に同等の機能は無く、リニューアルで新規に設ける。

出力対象データの取得・整形・並び順・出力前の検証は戻しリストCSV（M04-33）と共通で、列の意味と整形ルールの詳細はM04-33を正とする。本機能に固有なのは、ピッキング区分（金額閾値）ごとのグループ化とページ分割、および帳票レイアウトである。基本的な仕様は在庫移動指示リストのピッキングリスト印刷に準じる。

### 出力対象の抽出

一覧画面で選択された情報に紐づく実在庫情報を、対象店舗ごとに指定された金額閾値＋サプライで分けて取得する。

- サプライ品でない場合は、商品名から略称・言語・状態・色・レアリティを取り除く。
- 商品名内に略称タグが含まれない場合は、[～]（角括弧内にある文字を角括弧ごと）を削除する。

### 金額閾値

閾値は入庫先店舗ごとに登録する。本店の3F・2F・B2Fと支店で閾値が異なるため、店舗ごとに金額の閾値を分けられるようにし、結果としてフォーマットも3F・2F・B2Fで異なるものとなる。閾値の表示は基準価格を参照して行う（セール中で金額が変わっても棚を移動することはないため）。

現行運用での本店3F在庫の閾値は、シングルカードが低額（4,800円未満）と高額（4,800円以上）、金庫は基本的にEC在庫で500万円以上のものを保管し、あとは備品などを入れている。シングルカード以外では、2Fに置ききれない（商品化していない）サプライ・パック・ボックス等を倉庫へ保管する。

### 出力順

金額閾値の昇順（最後にサプライ）が最優先となる。金額閾値内の並び順は次のとおり。

| 順序 | 並び |
| --- | --- |
| 1 | 棚番の昇順。ただし支店の場合は棚番のソートを行わない |
| 2 | 言語（日→英→他言語） |
| 3 | 状態（NM→HP） |
| 4 | Foilフラグ（非Foil→Foil） |
| 5 | 略称タグの昇順 |
| 6 | レアリティ（M→C） |
| 7 | 色（マスターデータの色順を参照する） |
| 8 | 設定されている略称タグがコレクター番号でのソートのときはコレクター番号の昇順、アルファベットでのソートのときは英語のカード名の昇順 |

### 出力の単位とページ分割

整形済みの行を、ピッキング区分（金額閾値のラベル、またはサプライ）ごとのグループへまとめる。グループ内は取得した行の順序をそのまま維持する。各グループを1ページ30行で分割し、ページごとに現在ページ・総ページ数・ページ内の数量合計を持たせる。行番号は各ページ内で1から振り直す。1ページに満たないグループは30行まで空行を補ってレイアウトを揃える。

出力する構造は、戻しリストを作成した日時（日本時間、年/月/日 時:分:秒 の形式。戻しリストPDFを選択した日時）と1ページの最大行数、およびグループの一覧からなる。対象が1件も選択されていないときは、グループを持たない構造を返す。

### 帳票レイアウト

| 識別ID | 要素 | 内容 |
| --- | --- | --- |
| 1 | 印刷するボタン | 押下するとPC端末の印刷ダイアログが表示され、印刷を開始する。このボタンは印刷範囲に含めない |
| 2 | 商品仕訳 | グループの見出し。サプライのグループは「戻しリスト（サプライ）」、それ以外は「戻しリスト（商品単位〈閾値のラベル〉）」。閾値のラベルは ●●円未満／●●円以上▲▲円未満／■■円以上 と サプライ |
| 3 | ページング | 見出し横に「現在ページ／総ページ数」を出す。ページ数は閾値のグループごとに数える |
| 4 | 作成日時 | 戻しリストを作成した日時 |
| 5 | 行番号 | 各ページごとに商品へ割り振られる行番号 |
| 6 | 棚番 | 商品がしまってある場所番号。本店のみで、支店では表示しない |
| 7 | 言語／状態 | 言語／状態の形式で出力し、Foilの場合はFoilを付ける（例: FoilJP/NM）。サプライ品の場合は「サプライ品」と表示する |
| 8 | 略称 | 商品の略称。サプライ品の場合は表示しない |
| 9 | 色／R | 商品情報から取り出した色とレアリティ（例: 赤R）。シングルカード以外は色に該当するデータがないため、色情報は表示しない。サプライ品と色を持たない商品は空欄とする |
| 10 | 数 | 商品点数。3桁区切りで表示し、数量が1以外のときは太字にする |
| 11 | 商品名 | サプライ品でない場合は、商品名から略称・言語・状態・色・レアリティを取り除いたもの |
| 12 | 価格 | 基準価格を表示する |
| 13 | 備考 | 備考。実装では常に空欄となる |
| 14 | ページ内個数小計 | 表の末尾に、そのページ内の商品個数の総計を出す |

ページのタイトルは「戻しリスト」とする。スタイルは受注のピッキングリストと共通のものを用いる。

### 表示制御

ページ内で印刷に最適化した状態で表示する。「印刷する」ボタンは印刷範囲に含めない。ボタンを押下するとPC端末の印刷ダイアログが表示され、印刷を実行する。

### 出力前の検証と分岐

検証の内容は戻しリストCSV（M04-33）と同一で、対象が選択されていない、存在しないIDが含まれる、対象外のステータスである、実行者が対象を扱える権限を持たない、入庫先が設定されていない、複数店舗が混在している、といった場合にエラーとする。

| 事象 | 扱い |
| --- | --- |
| 対象を1件も選択せずに実行した | 帳票を作らず、選択が無い旨を表示して在庫移動・振替一覧へ戻す |
| 対象の検証でエラーになった | 帳票を作らず、エラーの内容ごとにメッセージを表示して在庫移動・振替一覧へ戻す。このとき出力対象データの取得は行わない |
| 検証を通過した | 印刷用レイアウトのHTMLを返す |
| 送信内容の正当性を確認できない | 要求を受け付けず例外とする |
| 別ウィンドウがブロックされた／データの取得に失敗した | 画面側でその旨のメッセージを表示する |

一覧へ戻すときの遷移先は、直前に表示していた在庫移動・振替一覧のページ番号（既定は1ページ目）とする。検証でエラーになった場合も要求自体は正常終了として扱い、画面側が受け取った遷移先へ移動する。

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | 在庫移動・振替一覧で選択した在庫移動・振替情報のID（複数可）と、送信内容の正当性を確認するための値 |
| 成功時出力 | 印刷用レイアウトのHTML。画面側が別ウィンドウへ書き込んで表示し、印刷ボタンから印刷ダイアログを起動する |
| 失敗時出力 | 在庫移動・振替一覧への遷移先と、原因を示すメッセージ |

### 入出力: 永続化

本機能はデータを更新しない。選択されたIDから帳票の内容を組み立てて表示するだけで、書き込みは行わない。CSV取込履歴・在庫履歴・ステータス履歴も更新しない。

参照するのは、在庫移動・振替とその明細、入庫先の在庫・商品規格・商品、入庫先店舗に登録された金額閾値（3段階）、および棚番・略称・言語・カード状態・カード詳細・レアリティ・カード・色・色順の各マスタである。
