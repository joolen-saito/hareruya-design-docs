# 在庫管理 — 在庫分割結合情報カスタムCSV出力

## 業務ロジック

### 出力対象と入口

カスタムCSV共通設定で作成した出力フォーマットに従い、在庫分割結合情報の出力項目・並びを変更してCSV出力する。在庫分割結合一覧（M04-12）の「在庫情報カスタムCSV出力」相当の入口から、保存済みのフォーマットを選んで出力する。

出力する対象データは固定列CSV出力（M04-14）と同じ在庫分割結合情報で、一覧が保持している検索条件で取得する。固定列CSV出力との違いは、出力する列とその並びを保存済みフォーマットで変えられる点である。

本機能は新規実装であり、現行（pf-eccube3）に対応する機能は無い。出力項目変更・出力条件の業務要件は基本設計仕様書（在庫分割結合情報CSV出力シート、識別ID 1-6「在庫情報カスタムCSV出力」）を正とする。

### フォーマットを選んでから出力するまで

1. 一覧画面でカスタムCSV出力のリンクを押すと、保存済みのフォーマット名（または「出力項目設定」）を表示する。
2. フォーマット名を選ぶと、そのフォーマットに対応する在庫分割結合向けのCSV設定を指定して出力を呼び出す。
3. 一覧が保持している検索条件で在庫分割結合データを取得する（M04-14と同じ対象データ）。
4. カスタムCSV設定の選択列・並びに従って列を組み替えて出力する。

### 選択できる列

カスタムCSVで選べる列の母集合は、固定出力（M04-14）の12列を基準とする。ID／タイプ／店舗／在庫区分／分割元・結合先商品名／分割元・結合先点数／分割元・結合先基準価格合計／分割先・結合元点数／分割先・結合元基準価格合計／ステータス／登録日時／登録者の12項目である。

選択できる列の最終的な定義（追加列の有無・表示名）は、カスタムCSV共通設定側（CSV種別「在庫分割結合」＝12）の実装で要確認とする。推測で列を確定させない。

### 行の並び

カスタムCSVで変えられるのは出力する列とその並びであり、行の並びは固定出力（M04-14）と同じ在庫分割結合IDの昇順となる。

### 対象が0件のとき・フォーマットが不正のとき

- 対象が0件でもエラーにはせず、固定出力（M04-14）と同様に見出し行だけを出力する。
- 指定されたフォーマットが存在しない、または在庫分割結合のCSV種別でないときは、在庫一覧のカスタムCSVに倣ってページが見つからない扱い（404）とする。

### 実装状況

在庫分割結合専用のカスタムCSV出力の入口と出力処理は、移行先で未提供である。固定列のCSV出力（M04-14）はあるが、フォーマットIDを受け取る入口が無く、固定12列の出力処理はカスタムCSV設定によるフォーマット選択を適用する分岐を持たない。一方、CSV種別マスタには在庫分割結合向けのカスタムCSV枠（種別12）が定義されており、枠だけは用意されている。

在庫一覧側にはフォーマットIDを受け取るカスタムCSV出力があり、在庫分割結合へ同等機能を追加するときはこの方式に倣う。本書のフォーマット適用・選択の流れは、基本設計の要件を正とし、在庫一覧のカスタムCSV方式に倣う前提で書いている。最終的な入口と出力列のカスタム適用は要確認。

## 入出力

### 入力: 出力フォーマットの指定

保存済みのカスタムCSVフォーマットを1つ指定する。指定できるのは在庫分割結合のCSV種別（種別12）で作成したフォーマットに限る。

### 入力: 検索条件

一覧が保持している検索条件をそのまま使い、出力対象の在庫分割結合データを取得する（M04-14と同じ対象データ）。

### 出力: 在庫分割結合情報カスタムCSV

| 項目 | 内容 |
| --- | --- |
| 内容 | 選んだフォーマットの選択列・並びで、対象データを出力する |
| 出力列の決まり方 | 出力列の選択と並びはカスタムCSV共通設定（CSV種別「在庫分割結合」＝12）に従う |
| 対象データ | 在庫分割・結合の登録情報とその明細を結合した在庫分割結合情報 |

### 更新するもの

無い。在庫分割・結合の登録情報とその明細を読み出して出力するだけで、登録内容は更新しない。
