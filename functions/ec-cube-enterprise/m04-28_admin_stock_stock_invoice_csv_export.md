# M04-28（送り状CSV出力）

## 業務ロジック

### 出力対象

在庫移動指示一覧でチェックした在庫移動指示だけを対象とする。チェックした指示のIDを受け取り、そのIDに一致する指示を移動元店舗・移動先店舗とそれぞれの都道府県とあわせて取得し、指示ID昇順に並べて出力する。

対象のIDが1件も渡されなかったとき（未指定・空を含む）は出力せず、対象が見つからないものとして扱う。指定したIDに該当する指示が存在しないときは、見出し行だけのファイルを出力する。

### 行の作り方

在庫移動指示1件につき1行を出力する。複数の指示をチェックすれば複数行になる。1行には送り元（移動元店舗）と送り先（移動先店舗）の店舗情報を並べて出力する。

出力するのは配送業者（ゆうプリR）が取り込める送り状フォーマットである。列の名前は受注管理の送り状CSVに合わせているため「注文者」「配送先」と表記するが、**注文者は移動元店舗、配送先は移動先店舗**を指す。

### 出力する列

列は固定の23列で、出力する項目を選ぶことはできない。

| # | 見出し | 値 |
|---|--------|----|

| 2 | 注文金額合計 | 移動する商品の基準価格合計 |
| 3 | 注文者氏名 | 移動元店舗の会社名と店名 |

| 9 | 注文者電話番号 | 移動元店舗の電話番号 |

列の並びは基本設計の出力項目の識別ID 1〜23 と一致する。1列目の見出しは受注管理の送り状CSVに合わせた「注文番号」で、基本設計の項目名「オーダーID」に対応する。

### 値の作り方

氏名・カナの4列（3・4・15・16）は、会社名と店名それぞれの前後の空白を除いたうえで、双方に値があるときだけ半角空白1個で連結する。片方しか値が無いときはその値だけを、両方とも空のときは空欄を出力する（例: 株式会社 晴れる屋 大宮 / カブシキガイシャ ハレルヤ オオミヤ）。

会社名・会社名カナ・店名・店名カナ・郵便番号・都道府県・住所1・住所2・電話番号は店舗管理で登録した値を使う。未登録の項目は空欄として出力する（都道府県も未設定なら空欄）。

### 更新するもの

本機能は参照だけを行う。在庫移動指示と店舗情報を読んでCSVを組み立てるだけで、業務データは更新しない。取込履歴・在庫履歴なども作らない。

## 入出力

### 入力

一覧でチェックした在庫移動指示のIDを受け取る。検索条件は使わず、チェックしていない指示は条件に一致していても出力しない。

### 出力: CSVファイル

| 項目 | 内容 |
|------|------|
| 文字コード | CSV出力の設定に従って変換する（既定は `SJIS-win`） |
| 区切り文字 | CSV出力の設定に従う |
| 囲み文字 | `"` |
| 構成 | 先頭に23列の見出し行を出力し、続けて対象の指示を1件1行で出力する |
| ファイル名 | `stock_move_instruction_labels_` に出力日時を `YmdHis` の形式でつなぎ、`.csv` を付けた名前 |
| 応答 | ダウンロードとして返す |
