# f06-19_front_member_mypage_credit_card（フロント_会員_クレジットカード情報登録・変更）

## 業務ロジック

### 操作できる会員

完全認証済みの会員だけが操作できる。完全認証済みでないときは画面を表示せずマイページ入口へ移す。カード会員登録を使わない設定のときは、ページを未検出（HTTP404）として扱う。対象はログイン中の会員自身のカードだけで、他会員のカードは扱わない。

### 画面の表示

見出しは「マイページ/登録済クレジットカード」である。表示のたびに決済代行へ会員照会を送り、会員枠が有効な状態のときは、その内容を登録済みカードとしてマスクしたカード番号と有効期限を表示し、カード情報の削除も選べる状態にする。会員照会で例外が出たときは、登録済みカード無しとして表示を続ける。入力欄はカード番号、カード有効期限（月・年）、カード名義（姓・名）、セキュリティコード、生月日、電話番号下4桁である。カード名義・セキュリティコード・生月日・電話番号の各欄は、設定により表示するかどうかを切り替える。購入時だけに要る項目（カード登録の指定、支払方法、請求者の氏名・メール）は本画面では扱わない。

### 入力の検査

登録の送信前に、画面上で各欄を次の順に検査する。カード番号は未入力・数字以外・14桁未満または16桁超のとき不可とする。カード有効期限は月または年が未選択のとき不可とする。カード名義は未入力・カタカナ以外のとき不可とする。セキュリティコードは未入力・数字以外・3桁未満のとき不可とする。生月日は未入力・数字以外・4桁以外のとき不可とする。電話番号下4桁は未入力・数字以外・4桁以外のとき不可とする。不可のときは当該欄の直下に文言を出し、欄の枠を赤くする。

送信後のサーバ側でも、数字で入力すべき項目、生月日の月日、有効期限が現在より過去でないことを検査する。

### カードの登録・差し替え

画面上の検査をすべて通ったときは、入力欄をいったん画面上で空にし、処理中の表示へ切り替えたうえで、外部のトークン生成の仕組みを呼んでトークンを得る。得たトークンを添えて送信する。トークン生成の読み込み失敗や呼び出し時の例外のときは、決済通信障害を知らせてマイページへ戻す。

送信を受けた側は、トークンが削除の指示でないこと、入力の検証を通ることを確かめたうえで、決済代行へ会員照会し、その登録状況で登録先を決める。

| 会員照会の結果 | カードの登録先 |
| --- | --- |
| 有効、またはカード無効 | 会員枠のカードを変更する |
| ログイン回数無効、または会員無効 | 無効を解除してからカードを変更する。解除に失敗したときは会員枠を無効化する |
| 会員削除済み | 会員枠を新規に作成する |
| 会員枠が無い | 会員枠を新規に作成する |

登録に成功したときはカード編集画面へ戻し、更新した旨を知らせる。検証に失敗したときはカード登録を行わず、入力項目の確認を促してカード編集画面へ戻す。検証を通ってもトークンが空のときは、カード登録を行わずカード編集画面へ戻す。

### カードの削除

削除の指示はトークン欄に削除を表す固定文字列を入れて送る。この文字列を受け取ったときは決済代行の会員枠を無効化し、無効化に成功したときだけ自社側の会員枠識別子の枝番を進める。完了後はカード編集画面へ戻し、更新した旨を知らせる。送信の受付後に再度削除を指示したときは、処理中である旨を知らせて送信を止める。

### 送信時の判定順序

| 順序 | 判定 | 結果 |
| --- | --- | --- |
| 1 | 完全認証済みでない | 画面を表示せずマイページ入口へ移す |
| 2 | カード会員登録を使わない設定 | 未検出（HTTP404）として扱う |
| 3 | トークン欄が削除の指示 | 会員枠を無効化し、会員枠識別子の枝番を進めてカード編集画面へ戻す |
| 4 | 検証が成功し、トークンに値がある | トークンで会員枠へカードを登録・差し替え、カード編集画面へ戻す |
| 5 | 検証が成功し、トークンが空 | カード登録を行わずカード編集画面へ戻す |
| 6 | 検証が失敗 | 入力項目の確認を促し、カード編集画面へ戻す |

### 会員枠識別子とカード情報の扱い

会員枠識別子は、会員ごとの枝番と会員IDから組み立てる。枝番は会員枠を作り替えるたびに進める。会員枠のパスワードに相当する値は会員IDとアプリ固有値から導出し、画面・設計書・記録に原値を出さない。カード原番号・有効期限・セキュリティコード・トークンは、画面入力と決済代行への送信のためだけに一時的に扱い、自社では保持しない。自社側にカード明細は持たない。金額計算・与信金額の算出は本機能では行わず、決済代行の会員枠管理に委ねる。

### エラー時の扱い

| 事象 | 扱い |
| --- | --- |
| 完全認証済みでない | カード編集画面を表示せずマイページ入口へ移す |
| カード会員登録を使わない設定 | 未検出（HTTP404）として扱う |
| 入力の検証に失敗 | カード登録を行わず、検証不備を知らせてカード編集画面へ戻す |
| 決済代行との業務エラー | エラー内容を知らせ、決済通知の記録とエラーの記録へ残す。システムエラー区分のときは管理者宛にエラーメールを送る。カード編集画面へ戻す |
| 通信などの想定外エラー | 通信エラーを知らせ、記録に残してカード編集画面へ戻す |
| 表示時の会員照会に失敗 | 登録済みカード無しとして表示を続ける |

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | カード編集画面の表示要求、カード入力とトークン、削除の指示を表すトークン |
| 成功時出力 | カード編集画面の再表示と更新した旨の通知。登録済みカードはマスクして表示する |
| 失敗時出力 | カード編集画面の再表示と、検証不備・通信エラー・業務エラーに応じた通知 |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 更新 | 決済代行の会員枠の無効化に成功したとき、会員ごとの会員枠識別子の枝番を進める |
