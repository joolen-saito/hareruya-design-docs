# m02-05_admin_home_home_ec_cube_news（管理画面_EC-CUBEお知らせ）

管理画面ホームに配置される「お知らせ」カードであり、設定された外部情報ページを iframe で埋め込んで表示する機能である。

## 概要

管理画面ホームの EC-CUBE お知らせは、運用担当がログイン後にダッシュボードを開いたとき、パッケージまたは環境で設定した URL を iframe の `src` に出力し、ブラウザがその URL のコンテンツを読み込んで表示する機能である。お知らせ本文の取得・整形・一覧化はアプリケーションのサーバ側では行わず、埋め込み先の応答に依存する。

本書は実装手順ではなく、誰が・いつ・どの条件で・結果どうなるかを読むためのリバース詳細設計とする。
既存実装のふるまい、参照する設定、画面構成、副作用の有無を確認し、仕様の確からしさを把握することを目的とする。

対象はブラウザ経由の管理画面ホームの「お知らせ」カード（`#ec-cube-news`）である。サイト内の「新着情報」コンテンツ管理・フロント表示、推奨プラグインカード、売上グラフ、受注状況は別機能として切り離す。

本書では Symfony の route 名、URL パス、Controller クラス名・メソッド名の一覧は扱わない。
利用者がたどる境界として、「利用者視点の入口」に HTTP メソッドとサイトルートからのパスパターン（実装確認値）を記載する。

本機能のカスタマイズ区分は標準であり、挙動・画面とも移行先のec-cube-enterpriseの実装を正とする。本カードはサイト内DBを読み書きせず、設定値`eccube_info_url`の参照のみで成立するため、DB関連の正典指定は対象としない。

- ホーム画面を組み立てるサーバ側処理が、本カード専用のデータベース読み取り・API 呼び出し・テンプレート変数の追加を行わないこと
- 本カードに固有の Ajax、フォーム POST、セッション更新、監査ログ出力が無いこと

## 処理フロー

### ホーム画面表示・お知らせカードの出力

1. 管理者として認証済みの利用者がホーム画面を開くとする。
2. サーバはホーム画面用テンプレートをレンダリングする。お知らせカード用に追加の問い合わせ結果や専用の配列変数を渡さない。
3. テンプレートは設定から `eccube_info_url` を読み取り、その文字列を情報iframe の `src` 属性値として出力する。
4. ブラウザは `src` の URL へリクエストを送り、応答ボディを情報iframe 内に描画する。再読込や失敗表示はブラウザおよび応答ヘッダに従う。

### 情報iframe 内での閲覧

1. 利用者が情報iframe 内のリンクやスクロールを操作する。
2. 遷移・ポップアップ・フォーム送信は読み込み先ドキュメントのマークアップとスクリプトに従う。
3. アプリケーションのサーバは iframe 内のナビゲーション要求を受け取らない（別オリジンの場合は同一オリジンポリシーにより読み取りも行わない）。

## 業務ルール・計算

本機能では業務計算を行わない。画面に表示される情報は、設定値で指定した URL の応答に依存する。

### エッジケース

| ケース | 扱い |
|--------|------|
| `eccube_info_url` が空文字になる運用設定 | iframe の `src` が空になり、ブラウザは空の文書を読み込む。本カードはエラー文言を補わない。 |
| `eccube_info_url` が運用設定で別 URL に差し替えられる | iframe は設定された文字列をそのまま `src` に使う。スキームやホストの妥当性検証、許可リストによる制限は本カードの Twig では行わない。 |
| 外部サイトが iframe 埋め込みを拒否する | ブラウザがコンテンツを表示しない、またはエラー表示にする。サーバ側では検知・代替 HTML は出さない。 |
| ネットワーク不通・タイムアウト | ブラウザのエラー表示に委ねる。サーバ側ではリトライしない。 |
| ホーム画面を開いたまま時間が経過する | 情報iframe 内のコンテンツは自動では更新されない。最新表示にはページ全体の再読込または iframe 内での操作が必要になる。 |

## データ整合性

| 観点 | 内容 |
|------|------|
| 参照時点 | 情報iframe の内容は、ブラウザが `eccube_info_url` を取得した時点の応答である。サーバ側でキャッシュしたお知らせリストは持たない。 |
| 設定との関係 | ページレンダリング時の `eccube_info_url` が iframe の `src` に反映される。実行中に設定だけが変わっても、開いたままのホーム HTML は自動では書き換わらない。 |
| サイト内 DB の新着情報との関係 | 本カードはサイト内 `News` エンティティやその公開状態と連動しない。両者の内容一致は保証しない。 |
