# m02-05_admin_home_home_ec_cube_news（管理画面_EC-CUBEお知らせ）

## 業務ロジック

### 表示の内容

管理画面ホームの「お知らせ」カードは、設定で指定した情報ページのURLを枠内に埋め込んで表示する。カード用に追加のデータは渡さない。埋め込み先の内容の描画・再読込・失敗表示は、閲覧側と応答ヘッダに従う。

### 埋め込み先での操作

枠内の遷移・別画面の呼び出し・送信は、読み込み先の内容に従う。枠内の遷移要求はこの機能では受け取らない。別オリジンのときは枠内の内容を読み取らない。

### 計算

本機能では業務計算を行わない。画面に出る情報は、設定値で指定したURLの応答に依存する。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| ホーム画面の生成に失敗 | 共通の例外処理に委ねる。本カード専用のメッセージは設けない |
| 埋め込み先の読み込み失敗・拒否 | 閲覧側の表示に委ねる。この機能では検知しない |
| TLS証明書エラー等 | 閲覧側の警告表示に委ねる |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | ホーム画面の表示要求。本カード専用の入力は無い |
| 成功時出力 | お知らせカードを含むホーム画面。埋め込み枠に設定のURLを出力する |
| 失敗時出力 | ホーム画面を生成できないときは共通の例外処理に委ねる。埋め込みの読み込み失敗は閲覧側の表示に委ね、本カード専用の代替文言は設けない |

## 表示メッセージ

本機能は本カード専用の画面メッセージを持たない。
