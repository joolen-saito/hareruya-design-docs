# 店頭買取管理 — 戻しリストCSV出力

## 業務ロジック

### 本機能の位置づけ

店頭買取の棚戻し業務で使うリストをCSV出力する。管理画面にログイン済みの利用者が、店頭買取管理の対象メニューまたは画面操作からCSV出力を実行したときに動く。

店頭買取の戻しリストは、ネット買取の戻しリストとは別の機能である。本機能が対象にするのは店頭買取の受注・実在庫・在庫履歴であり、ネット買取の受注・在庫は対象にしない。

### 出力対象の取得

利用者が指定した検索条件に該当する店頭買取の対象データを取得し、検証と状態条件を適用したうえで出力対象を確定する。

条件や対象の指定に該当するデータが無いときの扱いは、空の一覧、空のCSV、エラーのいずれかとする（どれを採るかは未確定）。

### ピッキング区分の仕分け

出力対象は、店舗ごとに定めた金額の閾値と、サプライとに分けて出す。区分は「●●円未満」「●●円以上▲▲円未満」「■■円以上」「サプライ」とする。ネット買取管理の場合は店舗が本店しかないため、本店の閾値で仕分ける。

閾値の判定と表示は基準価格を参照して行う。セール中で金額が変わっても棚を移動することはないため、セール後の価格では判定しない。

### 商品名と付随項目の整形

サプライ品でない場合は、商品名から略称・言語・状態・色・レアリティを取り除いたものを商品名として出す。色とレアリティは商品名から取り出して色/Rの項目へ出す（例: 金R）。

言語と状態は言語/状態の形式で出し、Foilの場合はFoilを付ける（例: FoilJP/NM）。サプライ品の場合は言語/状態の項目に「サプライ品」と表示し、略称は表示しない。

棚番号は本店のみ出す。

### 出力できないときの扱い

| 事象 | 扱い |
| --- | --- |
| 入力不備 | 必須項目や検索条件が不正な場合はエラーとし、出力対象を確定しない |
| 対象なし | 検索条件や対象の指定に該当するデータが無い場合は、空の一覧、空のCSV、エラーのいずれかとして扱う（どれを採るかは未確定） |
| 状態不整合 | 既に処理済み、キャンセル済み、承認不可、在庫不足など、状態条件に合わないデータは処理対象外またはエラーとする |
| 外部連携失敗 | スマレジ等の外部連携に失敗した場合は、再連携・エラー記録・エラーメール送信・ステータス更新の扱いに従う |

出力に失敗した場合も、対象データに不整合が残らないようにする。

## 入出力

### 入力

| 種類 | 内容 |
| --- | --- |
| 検索条件 | 店頭買取管理の画面で指定した検索条件・フォーム入力 |
| 操作 | 画面操作によるCSV出力の実行 |

### 出力: CSVファイル

| 項目 | 内容 |
| --- | --- |
| 応答 | ダウンロードとして返す |
| 失敗時 | エラー内容を画面に表示し、ファイルを返さない |

### 出力: CSVの項目

| 識別ID | 項目名 | 出す内容 |
| --- | --- | --- |
| 1 | ピッキング区分 | 店舗ごとの閾値とサプライを出力する。●●円未満、●●円以上▲▲円未満、■■円以上、サプライ。ネット買取管理の場合は本店しかないため本店の閾値とする。閾値の表示も基準価格を参照して行う（セール中で金額が変わっても棚を移動することはないため） |
| 2 | 棚番号 | 本店のみ |
| 3 | 言語/状態 | 言語/状態の形式で出力する。Foilの場合はFoilを付ける（例: FoilJP/NM）。サプライ品の場合は「サプライ品」と表示する |
| 4 | 略称 | サプライ品の場合は表示しない |
| 5 | 色/R | 商品名から取り出した色とレアリティを出力する（例: 金R） |
| 6 | 数 | — |
| 7 | 商品名 | サプライ品でない場合は、商品名から略称・言語・状態・色・レアリティを取り除いた名称 |
| 8 | 基準価格 | — |

出力対象の店頭買取の受注・実在庫・在庫履歴を参照して出力する。出力に伴う在庫履歴・ステータス履歴の記録は必要に応じて行う。

## 表示メッセージ

本機能は画面メッセージを持たない。
