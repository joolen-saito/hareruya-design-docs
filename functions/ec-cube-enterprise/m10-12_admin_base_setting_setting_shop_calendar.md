# 店舗設定 — 定休日カレンダー設定

定休日のタイトルと日付を登録・一覧表示・行単位編集・削除する。登録した日付は、フロントのカレンダー表示など別機能から参照される。

## 業務ロジック

### 一覧の対象

対象の店舗基本情報に紐づく定休日だけを一覧に読み込む。店舗で絞らない取得もあるが、この画面の一覧はいずれも店舗で絞る。

一覧の日付は日の粒度で表示する。保持している値は日時である。

### 新規登録

画面上部の入力欄でタイトルと日付を受け取る。検証を通過したときは、画面で解決した店舗を紐づけて登録し、管理画面ホームへ遷移する。この遷移先は暫定である。

### 行単位の編集

一覧の各行を編集状態にして、タイトルと日付を更新する。更新の対象は、送信された対象行の識別子と一致する行だけである。一致する行の入力だけを検証し、通過したときは店舗を紐づけ直して更新し、管理画面ホームへ遷移する。

送信の無い行は検証せず、入力欄だけを表示する。検証に失敗した行は編集表示のまま残す。

### 同一日の禁止

同じ店舗・同じ日付の定休日が既に存在するときは、日付の入力にエラーを付けて保存しない。新規登録と編集で共通の判定である。ただし編集では店舗の指定を判定へ渡していないため、編集時の店舗条件の扱いは現行実装から確定できない。

### 削除

なりすまし対策の検証を通過したときに削除する。削除後は成功可否だけを返し、画面の遷移先を指定しない。

### エラー時の扱い

| エラー内容 | 処理 |
|------------|------|
| タイトル未入力 | 入力欄の近傍にエラーを表示する。一覧の当該行は編集表示のまま残る |
| 日付が範囲外 | 日付の入力にエラーを付けて保存しない |
| 同一日の重複 | 日付の入力にエラーを付けて保存しない |
| なりすまし対策の検証に失敗 | アクセスを拒否する。本機能専用の文言は設けない |

## 入出力

| 種類 | 内容 |
|------|------|
| 入力 | タイトルと日付。行単位の編集では対象行の識別子と編集モードの指定を伴う。削除は対象行の識別子。いずれもなりすまし対策の検証値を伴う |
| 成功時出力 | 新規登録と行単位の編集は管理画面ホームへ遷移し、完了のメッセージを表示する。削除は成功可否を返す |
| 失敗時出力 | 同一画面に入力欄近傍のエラーを表示する。削除でなりすまし対策の検証に失敗したときは共通の拒否処理による |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 登録 | 定休日の新規登録 |
| 更新 | 一覧の行単位の編集 |
| 削除 | 定休日の削除 |

## 表示メッセージ

| メッセージID | 表示位置 | 画面上の文言 | 表示条件 | 後続処理 |
| --- | --- | --- | --- | --- |
| M10-12-MSG-001 | 管理画面上部 | 保存しました | 定休日を新規登録して保存したとき | 管理画面ホームに遷移する |
| M10-12-MSG-002 | 管理画面上部 | 保存しました | 登録済みの定休日を編集して保存したとき | 管理画面ホームに遷移する |
| M10-12-MSG-003 | 表示なし（応答のみ） | 削除しました | 定休日を削除したとき | 定休日を削除し、成功を示す応答を返す |
| — | 日付入力欄下のエラー表示 | 同日の定休日が既に存在しているため、設定できません。 | 同一店舗・同一日付の別行が既に存在する状態で送信したとき | — |
| M10-12-MSG-004 | 入力項目直下/フォーム上部 | 同日の定休日が既に存在しているため、設定できません。 | 定休日の登録で、同じ店舗の同じ日付がすでに登録されているとき | 定休日カレンダー設定画面に留まる |
