# 在庫管理 — 在庫移動・振替検索/一覧

## 業務ロジック

### 画面の役割

在庫移動・振替の登録情報を、ID・送り状No・出庫元/入庫先の店舗・在庫区分・移動タイプ・ステータス・各日付・承認者/登録者などの条件で検索し、一覧表示する。一覧からは次の3つを行う。

- 在庫移動・在庫振替を、CSVを利用してそれぞれ一括登録する。
- 選択した移動・振替を対象に、各種CSV・PDFを出力する。
- 選択した移動を対象に、在庫移動指示を作成する。

### 一覧の表示と並び

検索を実行すると、検索完了後にページを再描画し、検索結果の件数と検索結果一覧を表示する。一覧は在庫移動振替IDの降順で表示する。

各行には移動点数合計・基準価格合計・ステータスを表示する。移動点数合計と基準価格合計は、表示中のページに含まれる在庫移動振替の明細を集計して求める。

表示件数は既定値を用いる。画面から指定された表示件数は、表示件数マスタに登録された値のいずれかと一致するときだけ採用し、以降の表示のために保持する。

一覧画面には在庫移動CSV登録モーダルと在庫振替CSV登録モーダル、および両モーダルが用いる店舗一覧と移動タイプ（在庫移動／在庫振替）の区分を備える。

### 検索条件

| 画面上の項目 | 絞り込み |
| --- | --- |
| 在庫移動・振替ID | 数字だけのときは完全一致。数字以外を含むときはID文字列への部分一致 |
| 移動指示ID | 移動指示IDが設定されている在庫移動・振替に限り、部分一致 |
| 送り状No | 部分一致 |
| 出庫元店舗 | 店舗の複数選択。選択したいずれかに一致 |
| 入庫先店舗 | 店舗の複数選択。選択したいずれかに一致 |
| 出庫元在庫区分 | EC-CUBE在庫／スマレジ在庫の複数選択。選択したいずれかに一致 |
| 入庫先在庫区分 | EC-CUBE在庫／スマレジ在庫の複数選択。選択したいずれかに一致 |
| 移動タイプ | 在庫移動／在庫振替の複数選択。選択したいずれかに一致 |
| ステータス | 在庫移動振替ステータスのマスタ（ID昇順で並べる）の複数選択。選択したいずれかに一致 |
| 登録日 | 開始は以上、終了は終了日の翌日未満 |
| 出庫日 | 開始日から終了日までの範囲 |
| 入庫日 | 開始日から終了日までの範囲 |
| 出庫承認 所属／担当者名 | 出庫承認者が設定されているものに限る。所属名は一致、担当者名は部分一致 |
| 登録者 所属／氏名 | 登録者の所属名は一致、氏名は部分一致 |
| 入庫承認 所属／担当者名 | 入庫承認者が設定されているものに限る。所属名は一致、担当者名は部分一致 |

在庫移動・振替IDは数値で入力する項目である。この項目は、在庫移動・振替登録/編集（振替）の「在庫移動・振替ID」を検索するために使う。

### 検索入力の検証

登録日・出庫日・入庫日の3つの期間について、開始日が終了日より後のときは検索せず、終了日の項目にエラーを表示して同じ画面を再表示する。このとき一覧は描画しない。

### 検索条件の保持と復元

| 契機 | ふるまい |
| --- | --- |
| 検索実行 | 入力された検索条件を保持し、ページ番号を1として一覧を表示する |
| ページ送り | 指定されたページ番号を保持し、保持した検索条件を復元して一覧を表示する。保持した条件が無いときは検索フォームの初期値を保持して使う |
| 一覧の再開指定 | 保持したページ番号と検索条件を復元し、その条件で検索し直す |
| 初回表示 | ページ番号を1、検索フォームの初期値を検索条件として保持し、その条件で一覧を表示する |

在庫移動振替CSV出力は、このとき保持している検索条件を用いる。

### CSV登録

- 在庫移動CSV登録ボタンを押すと在庫移動CSV登録モーダルを表示する。在庫振替CSV登録ボタンを押すと在庫振替CSV登録モーダルを表示する。取り込む内容と項目は在庫移動・振替CSV登録（M04-22）を正とする。
- 在庫移動が登録されると、対象の在庫移動のステータスは新規登録となる。
- 在庫振替が登録されると、対象の在庫振替のステータスは振替承認待ちとなる。
- 取込でエラーがあり登録が行われなかったときは、一覧画面上部のエラー表示エリアにエラー内容を表示する。検索項目および一覧の選択状態は失われず、CSV登録モーダルの選択内容はリセットされる。
- 取込に用いる雛形として、在庫移動CSVは「商品コード／移動点数」、在庫振替CSVは「振替元商品コード／振替先商品コード／振替点数」を見出しに持つファイルをダウンロードできる。

### 移動指示作成

検索結果一覧で移動・振替を選択し、選択した移動・振替を対象に移動指示作成を行う。作成条件は次のとおりで、すべてを満たすときに、選択した移動をまとめて在庫移動指示を作成し、在庫移動指示一覧画面へ遷移する。

1. 移動タイプが移動であること
2. 選択した移動の出庫元店舗がすべて同一であること（在庫区分は同一でなくてよい）
3. 選択した移動の入庫先店舗がすべて同一であること（在庫区分は同一でなくてよい）
4. ステータスが出庫承認済みであること
5. 移動指示IDが未登録の移動であること

移動を選択していないとき、選択した移動が見つからないとき、上の条件を満たさない移動が含まれるときは作成しない。

### 各種出力

検索結果一覧で移動・振替を選択し、選択した移動・振替を対象に出力する。

| 出力 | 対象と条件 |
| --- | --- |
| 在庫移動振替CSV出力（M04-10） | 保持している検索条件に該当する全件を出力する |
| 戻しリストCSV出力（M04-33） | 選択した在庫移動振替IDを対象とする。在庫移動である場合にのみ出力でき、入庫先の閾値を元に作成する |
| 戻しリストPDF出力（M04-34） | 選択した在庫移動振替IDを対象とする。在庫移動である場合にのみ出力でき、入庫先の閾値を元に作成する。出力用データを取得したうえで別画面に表示する |
| バーコード印刷用CSV出力 | 選択した移動について、バーコード貼替リストCSV出力（M04-30）と同じ形式で出力する。移動かつ入庫先がスマレジ在庫である場合にのみ出力できる。列のレイアウトはM04-30を正とする |

戻しリストは、対象を選択していないとき、対象のデータが見つからないとき、入庫先店舗が未設定のとき、対象外のステータスのとき、編集できない店舗のデータを含むとき、複数店舗の在庫移動・振替を同時に選んだときは出力しない。バーコード印刷用CSVは、対象を選択していないとき、対象のデータが見つからないとき、移動でないデータや入庫先がスマレジ在庫でないデータを含むとき、入庫先店舗が未設定のとき、編集できない店舗のデータを含むとき、複数店舗の在庫移動・振替を同時に選んだときは出力しない。

### Excel設計書との差異

一覧の並び順はExcel設計書の「在庫移動振替ID降順」を正とする。ec-cube-enterprise の実装は登録日降順を第1キーとし、次に在庫移動振替ID降順で並べるためキーが異なる。実IDは登録日順に採番されるため結果は概ね一致するが、実装側の是正対象とする。

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | 検索条件、ページ番号、表示件数、一覧での在庫移動・振替の選択、在庫移動CSV／在庫振替CSVのファイル |
| 成功時出力 | 検索結果の件数と一覧（移動点数合計・基準価格合計・ステータスを含む）、在庫移動振替CSV、戻しリストCSV、戻しリストPDF用データ、バーコード印刷用CSV、CSV登録の雛形ファイル、CSV登録完了と在庫移動指示作成完了のメッセージ |
| 失敗時出力 | 検索条件の入力エラー、CSV取込エラー、出力対象や選択内容の不備を知らせるメッセージ |

検索と一覧は参照のみで、業務データを更新しない。保持するのは検索条件・ページ番号・表示件数だけである。CSV登録で登録される在庫移動・在庫振替の内容は在庫移動・振替CSV登録（M04-22）を、移動指示作成で作られる在庫移動指示の内容は在庫移動指示一覧を正とする。
