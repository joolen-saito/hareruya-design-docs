# 在庫管理 — 在庫移動・振替情報CSV出力

## 業務ロジック

### 出力対象

在庫移動・振替検索/一覧（M04-08）で検索した結果を、そのままCSVとして出力する。管理者が一覧のCSV出力を実行したときに動く。

対象は検索条件に一致する在庫移動・振替情報の全件で、ページ単位に区切らず出力する。行を個別に選ぶ操作は無く、検索条件そのものは在庫移動・振替検索/一覧の仕様による。本機能は直前の検索条件を引き継いで出力するだけで、条件を自身で持たない。

検索を実行していないときは、条件なし（検索項目の既定値）として全件を対象とする。エラーにはならない。

### 出力順

一覧に表示されている順と同じ順で出力する。登録日の降順、同じ登録日のときは在庫移動振替IDの降順とする。

### 集計する値

移動点数と基準価格合計は、在庫移動・振替情報が持つ明細を集計して求める。件数が多い場合に備え、100件ずつ区切って集計しながら出力する。明細が無いときの移動点数は0とする。基準価格合計は四捨五入した整数とする。

### データの更新

本機能は参照だけを行い、在庫移動・振替情報も明細も更新しない。

### 現行との関係

本機能は新規実装であり、現行（pf-eccube3）に同等の機能は無い。出力する項目とその順序は基本設計仕様書のCSV出力項目を正とする。

## 入出力

### 出力: CSVの列

1行目に列名の見出し行を出し、在庫移動・振替情報1件につき1行を出力する。列は次の14列・この順で固定とし、カスタムCSVのように項目を選ぶことはできない。

| # | 列名 | 出力する値 |
| --- | --- | --- |
| 1 | 在庫移動振替ID | 在庫移動・振替情報のID |
| 2 | 移動指示ID | 移動指示が登録済みのときだけ出力する。未登録のときは空欄 |
| 3 | 移動タイプ | 在庫移動・振替情報の移動タイプ名（1:在庫移動 ／ 2:在庫振替） |
| 4 | 出庫元店舗 | 出庫元の店舗名 |
| 5 | 出庫元在庫区分 | 出庫元の在庫区分名（1:EC-CUBE ／ 2:スマレジ） |
| 6 | 入庫先店舗 | 入庫先の店舗名。振替のときは出庫元と同一になる |
| 7 | 入庫先在庫区分 | 入庫先の在庫区分名（1:EC-CUBE ／ 2:スマレジ）。振替のときは出庫元と同一になる |
| 8 | 移動点数 | 移動または振替する商品の点数の合計。明細が無いときは0 |
| 9 | 基準価格合計 | 移動または振替する商品の基準価格の合計を四捨五入した整数 |
| 10 | ステータス | 在庫移動・振替情報の現在のステータス名 |
| 11 | 出庫日 | 移動のときはステータスが移動中になった日時、振替のときはステータスが出庫承認済みになった日時。`Y/m/d H:i` の形式。未設定のときは空欄 |
| 12 | 入庫日 | ステータスが入庫完了になった日時。`Y/m/d H:i` の形式。未設定のときは空欄 |
| 13 | 登録者 | 新規登録した管理者の氏名 |
| 14 | 登録日 | 新規登録した日時。`Y/m/d H:i` の形式 |

13列目・14列目について、基本設計の備考は「登録者＝新規作成された日時」「登録日＝新規登録した管理画面ユーザ」と入れ替えて書かれているが、これは備考の記載ゆれである。列の定義（13列＝登録者、14列＝登録日）を正とし、上表のとおり出力する。

### 出力: CSVファイル

| 項目 | 内容 |
| --- | --- |
| 文字コード・区切り文字・囲み | CSV出力の共通の扱いに従う。本機能では個別に指定しない |
| ファイル名 | `stock_move_transfer_list_` に出力日時を `YmdHis` の形式でつなぎ、`.csv` を付けた名前 |
| 応答 | ダウンロードとして返す |
| 出力方式 | 全件をメモリに保持せず、1行ずつ書き出しながら返す。件数が多くても途中で打ち切られないよう、実行時間の上限を外して出力する |

検索条件に一致する在庫移動・振替情報が1件も無いときは、見出し行だけのファイルを出力する。

## 表示メッセージ

本機能は画面メッセージを持たない。
