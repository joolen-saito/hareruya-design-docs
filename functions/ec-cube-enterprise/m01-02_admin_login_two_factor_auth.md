# 管理画面ログイン — 二段階認証

## 業務ロジック

### 追加認証を要求する条件

管理画面のリクエストに対し、次の順で追加認証の要否を判定する。

| 順序 | 判定 | 結果 |
| --- | --- | --- |
| 1 | 管理画面のリクエストでない、またはシステム全体の二段階認証が無効 | 追加認証へ誘導しない |
| 2 | 追加認証画面へのリクエスト | 誘導せず後続処理を実行する |
| 3 | 初回設定画面へのリクエストかつ秘密鍵が未設定 | 誘導せず後続処理を実行する |
| 4 | 初回設定画面へのリクエストかつ秘密鍵が設定済み | 追加認証画面へ誘導する |
| 5 | 利用者が管理者でない、または当該管理者の二段階認証が無効 | 追加認証へ誘導しない |
| 6 | 認証済み状態を示すCookieが有効 | 追加認証へ誘導しない |
| 7 | 秘密鍵が設定済み | 追加認証画面へ誘導する |
| 8 | 秘密鍵が未設定 | 初回設定画面へ誘導する |

秘密鍵が設定済みの管理者を初回設定画面の対象外とすることで、初回設定経路による追加認証の迂回を防ぐ。

### 追加認証

システム全体の二段階認証が無効、または認証済み状態を示すCookieが有効なときは、ホーム画面へ送る。秘密鍵が未設定のときは初回設定画面へ送る。

入力された6桁トークンを当該管理者の秘密鍵と照合する。成功時はホーム画面へ遷移し、認証済み状態を示すCookieを付与する。失敗時と入力形式が不正なときは同画面に留まる。追加認証画面では、トークン不一致・未入力・桁数不正を画面上で区別しない。

### 初回設定

当該管理者の二段階認証が有効かつ秘密鍵が未設定のときに行う。システム全体の二段階認証が無効、または認証済み状態を示すCookieが有効なときはホーム画面へ送り、秘密鍵が設定済みのときは追加認証画面へ送る。

画面表示時に秘密鍵の候補を生成し、QRコードとして表示する。送信された6桁トークンをその候補と照合し、一致したときに秘密鍵を保存し、認証済み状態を示すCookieを付与してホーム画面へ遷移する。初回設定では、入力形式の不正とトークン不一致で文言が分かれる。

### 本人による再設定

認証済み状態を示すCookieが有効な管理者だけが秘密鍵を付け替えられる。無効なときはホーム画面へ送る。初回設定と同じく秘密鍵の候補とQRコードを表示し、送信された6桁トークンと照合する。表示・遷移は管理画面の標準レイアウトによる。

秘密鍵を更新すると、更新前の秘密鍵で登録した認証アプリのトークンは使用できない。認証アプリの再登録が必要になる。画面表示時に秘密鍵が既に登録されているときは、再設定になる旨の警告を表示する。

### 認証済み状態

トークン照合または秘密鍵登録に成功すると認証済み状態を示すCookieを付与し、その有効期間内は追加認証を要求しない。

### 管理者ごとの有効・無効

二段階認証の有効・無効は管理者アカウントごとに保持する。無効の管理者には追加認証を要求しない。メンバー一覧では、当該管理者の設定完了・未完了をアイコンで示す。

### エラー時の扱い

| 事象 | 扱い |
| --- | --- |
| 追加認証でトークンが空・6桁以外・照合失敗 | 追加認証画面に留まる。理由を画面上で区別しない |
| 初回設定・本人再設定でトークンが空・6桁以外 | 同画面に留まり、形式不正の文言を表示する |
| 初回設定・本人再設定で照合失敗 | 同画面に留まり、再入力を促す文言を表示する |
| 追加認証の送信が試行回数の上限を超過 | リクエストを拒否する |
| システム全体の二段階認証が無効な状態で各画面へ直接アクセス | ホーム画面へ送る。専用メッセージは出さない |
| 秘密鍵が設定済みの管理者が初回設定画面へアクセス | 追加認証画面へ送る。専用メッセージは出さない |
| 本人再設定で認証済み状態を示すCookieが無効 | ホーム画面へ送る。専用メッセージは出さない |

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | 6桁トークン、なりすまし対策トークン。初回設定と本人再設定では秘密鍵の候補も送る |
| 成功時出力 | ホーム画面への遷移と認証済み状態を示すCookieの付与。初回設定と本人再設定では秘密鍵の保存と完了メッセージ |
| 失敗時出力 | 同画面に留まり、トークンの誤りまたは形式不正のメッセージを表示する |

### 入出力: 永続化

| 操作 | 契機 |
| --- | --- |
| 更新 | 初回設定または本人再設定でトークン照合に成功したときの、管理者アカウントの秘密鍵 |
| 更新 | メンバー編集での、管理者アカウントごとの二段階認証の有効・無効 |

追加認証の成功では秘密鍵を更新しない。
