# A01-02（スマレジwebhook連携エラー再連携）

## 業務ロジック

### 再連携の目的

スマレジ連携処理のうち、スマレジ → EC-CUBE（Webhook方式）で連携に失敗したものをリトライする。

スマレジ側のWebhookにはリトライ処理が実装されていないため、失敗した分はスマレジ側からは再送されない。EC-CUBE側で在庫変動履歴が連携済みかどうかを確認し、連携されていないものを見つけて再連携する必要がある。

### 起動と実行タイミング

| 項目 | 内容 |
| --- | --- |
| 実行トリガー | スケジュール起動（AWS Step Functions） |
| 実行タイミング | 毎時16分 |
| 入力データ元 | スマレジプラットフォームAPI |
| 出力先 | DB |

サーバ構成が変わるため、バッチプログラムの起動方法を変更し、AWS Step Functionsを利用して実装する。使用するAPIも、廃止予定のスマレジAPIからプラットフォームAPIへ変更する。

バッチの実行時間は、閉店時間などを見て可変的に実行する運用とする。

- 取得する期間は可変で実装する。実行タイミング（1時間あたりの実行回数）、バッチの実行時間、APIでのエラー発生率、テスト結果等を踏まえて検討する。
- 全店舗閉店後はスマレジが稼働しないので、閉店後のバッチ処理は1回のみとする。
- 取引のスマレジ再連携バッチと処理時間が被らないように設定する。

### 処理範囲

本店・支店の処理を統合し、全店舗のデータをともに処理対象とする。

### 未連携データの抽出

1. バッチ駆動時間から一定時間前までの間の、スマレジの在庫変動履歴データをAPIで取得する（基本設計上の値は5時間前まで。取得する期間は可変とする）。
2. 取得したデータのうち、在庫変動区分が「02: 取引」もしくは「12: 返品」のものを対象とする。
3. その在庫変動履歴IDがEC-CUBE側の在庫変動履歴に保存されているかを検索し、保存されていないIDを抽出する。

抽出の条件は次のとおり。いずれかを満たさないデータは再連携の対象としない。

| 対象 | 条件 |
| --- | --- |
| 取引更新時間 | バッチ駆動時間（X）から、バッチ駆動時間よりY時間前（X-Y hours）までの間 |
| 在庫変動区分 | 「02: 取引」もしくは「12: 返品」 |
| 連携状態 | スマレジ在庫変動履歴IDがEC-CUBE側に登録されていない |
| 店頭受取 | 店頭受取のデータではない |

### 再連携処理

抽出した、スマレジ在庫と連携されていないデータを再連携処理する。処理内容はスマレジ連携処理（A01-01）の処理概要1-2と同様の処理を実行する。

### 開始条件と終了条件

| 種類 | 内容 |
| --- | --- |
| 開始条件 | スケジュールによる起動を受け付ける |
| 終了条件 | 結果を返し、必要なデータ更新または非同期処理の投入が完了する |

### 例外の扱い

| 区分 | 扱い |
| --- | --- |
| 入力不備 | スマレジプラットフォームAPIから取得したデータが不正な場合はエラーとして処理し、登録・更新対象を確定しない |
| 対象なし | 検索条件や対象IDに該当するデータがない場合は処理対象なしとして扱う |
| 状態不整合 | 既に処理済み、キャンセル済み、在庫不足など状態条件に合わない場合は処理対象外またはエラーとする |
| 外部連携失敗 | スマレジ等の外部連携で失敗した場合は、再連携・エラーログ・エラーメール・ステータス更新の対象とする |

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | スマレジプラットフォームAPIから取得する、Webhook連携に失敗したスマレジ取引情報（在庫変動履歴データ） |
| 出力 | 再連携結果のDBへの反映。成功・失敗はバッチの実行結果として返す |

### 入出力: 入力データ

Webhookが何らかの理由で失敗したスマレジ取引情報を、スマレジプラットフォームAPIから取得する。取得するのは在庫変動履歴データで、取引更新時間で期間を絞り込む。

### 入出力: 実行結果

Webhookに失敗した処理が、スマレジ連携処理の処理概要1-2と同等の処理が完了した状態になる。

### 入出力: 永続化

再連携の対象となる在庫・買取およびスマレジ連携対象のデータを作成・更新・参照する。

Webhookの受信履歴には、再連携の状態管理として処理の開始日時・完了日時・ステータスを記録する。あわせて、在庫履歴・ステータス履歴・API受信履歴を必要に応じて作成・更新する。
