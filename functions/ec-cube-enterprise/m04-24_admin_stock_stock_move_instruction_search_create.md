# 在庫管理 — 在庫移動指示リスト作成/検索

## 業務ロジック

### 画面の位置づけ

在庫移動指示は、在庫移動振替一覧から作成された、複数の在庫移動を1件にまとめた指示リストである。本画面はその在庫移動指示を検索・一覧表示し、各指示の詳細を参照・更新する。一覧からは送り状No.の登録、在庫移動実績CSV（送り状No.一括登録）の取込、指示の削除、送り状CSV出力を行える。

この画面へは在庫管理の在庫移動指示から遷移する。一覧の移動指示IDから在庫移動指示詳細へ遷移する。

在庫移動指示そのものの新規作成は本画面では行わない。作成は在庫移動振替一覧（M04-09 系）を正とする。

在庫移動振替一覧から作成した在庫移動指示に対して送り状No.を登録することで、まとめられている在庫移動のステータスは移動中となる。送り状No.の変更は在庫移動指示詳細からのみ可能である。

店舗間移動フローの状態遷移は在庫移動のものを転用する。アクションは 新規登録・ピック・欠品登録・出庫承認・発送手続き・着荷・入庫承認・入庫先NG・差分通知、ステータスは 新規登録・出庫承認待ち・却下・出庫承認済み・移動中・入庫済み・入庫承認待ち・NG・差分登録 で、両者が交互に並ぶ。遷移は 新規登録→新規登録、新規登録→ピック、ピック→欠品登録、欠品登録→ピック、欠品登録→出庫承認待ち、出庫承認待ち→出庫承認、出庫承認→却下、出庫承認済み→発送手続き、発送手続き→移動中、移動中→着荷 をたどる。本画面の送り状No.登録は、在庫移動のステータスを移動中とする発送手続きにあたる。

本機能は新規実装であり、現行（pf-eccube3）に在庫移動指示の作成・検索の相当機能は無い。

### 一覧の対象と並び

一覧は検索条件に一致する在庫移動指示を登録日の降順で並べる。

ページングは持たない。条件に一致する全件を取得して表示し、あわせて件数を表示する。

初回表示では検索条件を初期化し、検索フォームだけを表示する。一覧は空とする。

一覧の項目は次のとおり。

| 一覧の列 | 内容 |
| --- | --- |
| チェックボックス | 送り状CSV出力の対象を選択する |
| 移動指示ID | 登録後に自動採番された値。押下で在庫移動指示詳細へ遷移する |
| 出庫元店舗 | 移動指示リストにまとめられている在庫移動の出庫元店舗 |
| 入庫先店舗 | 移動指示リストにまとめられている在庫移動の入庫先店舗 |
| 在庫移動 | 移動指示リストに含まれる在庫移動の件数 |
| 移動点数 | 移動指示リストに含まれる移動する商品の点数 |
| 基準価格合計 | 各在庫移動が持つ商品の基準価格の合計金額 |
| 移動原価合計 | 各在庫移動が持つ移動原価の合計金額 |
| 登録日 | 移動指示リストの登録日 |
| 更新日 | 移動指示リストの更新日 |
| 送り状No. | 登録済みの送り状No.。未登録の行には「送り状No.登録」ボタンを表示し、モーダルで登録する |
| 発送状況 | 送り状No.が登録済みなら「済」、未登録なら「未」 |

### 検索条件

| 画面上の項目 | 検索条件 |
| --- | --- |
| 出庫元店舗 | 選択した店舗に一致 |
| 入庫先店舗 | 選択した店舗に一致 |
| 移動指示ID | 移動指示IDへの部分一致。入力値のワイルドカード文字はエスケープして文字そのものとして扱う |
| 在庫移動振替ID | 指示に紐づく在庫移動の振替IDに完全一致。重複する指示は1件に寄せる |
| 登録日 | 開始は以上、終了は終了日の翌日未満 |
| 更新日 | 開始は以上、終了は終了日の翌日未満 |
| 発送状況・未 | 送り状No.が未設定または空文字の指示に限定 |
| 発送状況・済 | 送り状No.が設定済みかつ空文字でない指示に限定 |

発送状況は「未」だけ、または「済」だけを選んだときに絞り込む。両方を選んだとき、および両方を選ばないときは送り状No.の条件を付けない。

登録日・更新日は開始が終了より後のとき、該当する終了の入力欄に日付範囲のエラーを付けて検証エラーとする。

### 検索の成立条件と検索条件の保持

- 検索実行では、検証エラーがあるときは検索せず、一覧を空にしたまま検索条件を入力済みの状態として再表示する。画面遷移は行わない。
- 検証を通ったときは入力された検索条件をセッションへ保持したうえで検索する。
- 一覧へ戻る操作（送り状No.登録後・削除後・CSV登録後）では、保持した検索条件を復元して再検索する。
- 初回表示では検索条件を初期化するため、保持していた条件は残らない。

### 在庫移動指示詳細

詳細は対象の在庫移動指示を表示し、送り状No.と備考を編集する。対象のIDが存在しないときは対象なしとして扱う。

読み取り専用で表示する項目は次のとおり。

| 表示項目 | 内容 |
| --- | --- |
| 在庫移動指示ID | 登録後に自動採番された値 |
| 発送状況 | 送り状No.の登録有無による「済」「未」 |
| 出庫元店舗 / 入庫先店舗 | 移動指示リストにまとめられている在庫移動の出庫元店舗・入庫先店舗 |
| 在庫移動数 | 移動指示リストに含まれる在庫移動の件数 |
| 移動点数 | 移動指示リストに含まれる移動する商品の点数 |
| 登録日 / 登録者 | 移動指示リストの登録日と登録した担当者 |
| 更新日 / 最終更新者 | 移動指示リストの更新日と最終更新者 |
| 総販売価格の合計（基準価格合計） | 各在庫移動が持つ全ての商品の販売価格の合計金額 |
| 総移動原価の合計（移動原価合計） | 各在庫移動が持つ総移動原価の合計金額 |
| ●●円以上の商品の合計（高額商品合計） | 出庫元店舗の高額商品閾値のうち最も高い価格を閾値とし、基準価格がその閾値以上の商品の合計金額。項目名にも閾値の値を使って表記する |
| ●●円未満の商品の合計（通常商品合計） | 同じ閾値を用い、基準価格が閾値未満の商品の合計金額。項目名にも閾値の値を使って表記する |

画面下部には当該指示に紐づく在庫移動の一覧を、在庫移動振替IDの昇順で表示する。紐づく在庫移動が1件も無いときはその旨を表示する。

| 在庫移動一覧の列 | 内容 |
| --- | --- |
| 在庫移動振替ID | 押下で対象の在庫移動情報（M04-09 在庫移動・振替登録 編集（移動））へ遷移する |
| 出庫元店舗 / 入庫先店舗 / 在庫区分 | 対象の在庫移動の値を用いる |
| 基準価格合計 | 対象の在庫移動が持つ全ての商品の基準価格の合計金額 |
| 移動原価合計 | 対象の在庫移動が持つ移動原価の合計金額 |
| ●●円以上の商品の合計 / ●●円未満の商品の合計 | 出庫元店舗の高額商品閾値を用いた、基準価格が閾値以上・未満の商品の合計金額 |
| 移動点数 | 対象の在庫移動に含まれる商品点数の合計 |
| 登録日 | 対象の在庫移動の登録日 |

### 在庫移動指示詳細の更新

- 送り状No.が登録されている場合、その値がフォームに表示される。送り状No.は数値だけでなく全角・半角を許容する。備考も全角・半角を許容する。
- 送り状No.または備考の内容が変更された場合にのみ登録ボタンを活性化する。登録すると値が保存される。
- 保存すると更新日と最終更新者（ログイン中の担当者）を更新し、フォームの送り状No.を紐づく在庫移動へ同じ値で同期する。保存完了を表示し、同じ詳細画面へ戻る。
- 送り状No.の変更時、未入力（空白のみ）での更新は許可しない。送り状番号を空に戻して発送状況を「未」へ、移動ステータスを「出庫承認済み」へ戻すことはできないためである。空文字のみのときはフォームにその旨のエラーを表示する。
- 備考情報の登録は、まとめられている在庫移動のステータスが出庫承認済みまたは移動中のときのみ可能とする（メモの入力は入庫完了以外で可能）。

送り状No.・備考の最大文字数は基本設計では 16384 文字だが、実装上の送り状No.は 255 文字までであり、備考には文字数の制約が置かれていない。空白のみの禁止と、備考のステータスによる入力可否も、実装側では確認できていない（実装要確認）。

### 一覧からの送り状No.登録

一覧では、送り状No.が未登録の在庫移動指示に限り、一覧から送り状No.を登録できる。

登録すると指示の送り状No.（空文字は未設定として扱う）・更新日・最終更新者を設定し、紐づく在庫移動へ同じ送り状No.を同期する。登録完了を表示し、検索条件を復元した一覧へ戻る。対象のIDが存在しないときは対象なしとして扱う。

### 在庫移動実績CSV登録（送り状No.一括登録）

一覧からCSVをアップロードし、送り状No.を一括登録する。取込時はBOMを除去し、行の列数がヘッダに足りない場合は補って読み込む。

必須のヘッダは 移動指示ID（必須・数値）／出庫元店舗(名称)／入庫先店舗(名称)／送り状No.（必須）で、並び順は問わない。ヘッダ行が取得できない場合はヘッダの書式エラーとする。

行ごとの検証は次のとおりで、不正な行はその行だけ読み飛ばし、残りの行の取込は続ける。

| 検証 | 不成立時の扱い |
| --- | --- |
| 行の列数がヘッダの列数と一致するか | 列数不整合のエラーとし、当該行を読み飛ばす |
| 各列の存在・必須・数値の形式 | 該当するエラーとし、当該行を読み飛ばす |
| 移動指示IDが1以上で、該当する在庫移動指示が存在するか | 移動指示が見つからない旨のエラー |
| 出庫元店舗(名称)が指定されている場合、指示の出庫元店舗名と一致するか | 出庫元店舗が一致しない旨のエラー |
| 入庫先店舗(名称)が指定されている場合、指示の入庫先店舗名と一致するか | 入庫先店舗が一致しない旨のエラー |
| 送り状No.が前後の空白を除いて空でないか | 送り状Noが空欄である旨のエラー |

取込に成功した行は、在庫移動指示と紐づく在庫移動へ送り状No.を反映する。

結果は、成功が1件以上あれば一括登録の完了を表示し、成功が0件でかつ行のエラーも無い（ヘッダのみなど）ときは有効な行が無い旨を表示する。行のエラーはそれぞれのメッセージを表示し、表示は20件までとする。

在庫移動実績入力用のCSV雛形をダウンロードできる。

### 削除

- 削除できるのは、発送済みでなく送り状No.が登録されていない在庫移動指示だけである（削除ボタンは出庫待ち状態の場合のみ押せる）。在庫移動指示詳細で送り状No.が登録済みのときは削除を受け付けない。
- 削除は実行前に確認を挟み、確認したときだけ在庫移動指示を削除して一覧へ遷移する。取りやめたときは削除しない。
- 送り状No.が登録済みの指示を削除しようとしたときは削除せず、登録後は削除できない旨を表示して詳細へ戻す。
- 削除するときは、紐づく在庫移動から移動指示との関連と送り状No.を外したうえで在庫移動指示を削除する。削除後は検索条件を復元した一覧へ戻る。

### 対象なし・エラー時の扱い

- 詳細表示・送り状No.登録・削除で対象の在庫移動指示が存在しないときは 404 とする。
- 送り状CSV出力で対象の指示IDが1件も指定されていないときは 404 とする。画面では対象を選ばないまま出力しようとしたときに警告し、送信しない。
- CSVファイルが未指定、またはファイルとして妥当でないときは、ファイルが不正である旨を表示して一覧へ戻す。
- CSV取込中に想定外のエラーが発生したときは、内容を添えたアップロード失敗の表示を行う。ヘッダ不正・ファイル不正・一時ディレクトリ不正には固有のメッセージへの振り分けがあるが、それらを発生させる処理は現行ソースに無く、実機での確認を要する。実際のヘッダ不正は、形式が一致しない旨のエラーとして表示される。

## 入出力

### 入出力: 画面と操作

| 種類 | 内容 |
| --- | --- |
| 入力 | 検索条件、詳細の送り状No.・備考、一覧からの送り状No.、在庫移動実績CSVファイル、送り状CSV出力の対象指示の選択、削除の指示ID |
| 成功時出力 | 検索結果の一覧（全件・登録日降順）と件数、在庫移動指示詳細と紐づく在庫移動の一覧、保存・送り状No.登録・一括登録・削除の完了メッセージ、CSV雛形、送り状CSV |
| 失敗時出力 | 日付範囲・文字数・空欄の入力エラー、CSVのファイル不正・ヘッダ不正・行単位のエラー、送り状No.登録済みの指示に対する削除不可の表示、対象不在の 404 |

### 出力: CSV

- 送り状CSV: 一覧で選択した在庫移動指示を対象に出力する。
- 在庫移動実績入力用CSV雛形: 送り状No.一括登録に用いる雛形を出力する。

いずれも出力列と整形の仕様は M04-25（在庫移動指示リストエクスポート）を正とする。

### 入出力: 永続化

在庫移動指示は、送り状No.・備考・更新日・最終更新者を保持する。

| 操作 | 契機 |
| --- | --- |
| 更新（送り状No.・備考・更新日・最終更新者） | 在庫移動指示詳細の保存 |
| 更新（送り状No.・更新日・最終更新者） | 一覧からの送り状No.登録、送り状No.の一括取込 |
| 更新（在庫移動の送り状No.） | 送り状No.の登録・更新時に、紐づく在庫移動へ同じ値を同期 |
| 更新（在庫移動の移動指示との関連・送り状No.の解除） | 在庫移動指示の削除 |
| 削除 | 在庫移動指示の削除 |

在庫移動そのものの登録・承認・ステータス遷移は本機能では行わない。
