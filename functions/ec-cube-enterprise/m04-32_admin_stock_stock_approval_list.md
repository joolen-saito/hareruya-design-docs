# 在庫管理 — 承認一覧

## 業務ロジック

### 一覧の対象

在庫編集・在庫一括編集・在庫変更CSV登録・在庫移動・在庫振替・在庫分割・在庫結合で発生した在庫変動の承認待ち情報を一覧に表示し、検索条件で絞り込んだうえで一括承認・一括却下を行う。

| 観点 | 内容 |
| --- | --- |
| 初期表示 | 検索条件を保持していない場合、ログインメンバーのデフォルト検索表示店舗を店舗条件の初期値として検索した状態を表示する |
| 表示順 | 承認日の降順 → 登録日の昇順 → 承認一覧IDの昇順 |
| 承認状態による並び | 承認日が空の行（未承認など）が最上位に来る。承認日が空の行どうしは登録日が古い順に並ぶ。承認済・却下済は承認日が新しい順に並ぶ |
| 同一日時の扱い | 登録日または承認日が同じ行がある場合でも表示順が不定にならないよう、承認一覧ID（レコード登録順）の昇順を副条件とする |
| 該当件数 | 検索処理の実行後に「検索結果：N件が該当しました」として件数を表示する |
| 表示件数 | 既定の表示件数設定に従う（確認できた値は10件）。選択肢は表示件数マスタに登録された表示件数とする。Excel設計書は初期値を100件とする（「Excel設計書との乖離」参照） |

### 一覧項目

| 項目 | 内容 |
| --- | --- |
| 選択欄 | 一括承認・一括却下の対象を選ぶチェックボックス。表示条件は「一括操作の対象になる行」に示す |
| 承認状態 | 未承認 / 承認済 / 却下済 |
| 承認対象 | 承認対象になっている在庫変更手続きを作成した機能名。押下したときの動きは種別ごとに分かれる |
| 店舗 / 在庫区分 | 承認対象の在庫の店舗・在庫区分 |
| 対象商品規格数 | 承認対象の対象商品規格数 |
| 合計在庫増減数 | 承認対象が在庫編集・在庫一括編集・在庫変更CSV登録・在庫分割・在庫結合の場合は合計在庫増減数を表示する。在庫移動・在庫振替の場合は `-` を表示する |
| 合計総原価増減数 | 表示条件は合計在庫増減数と同じ。値は `¥` を付けた金額書式で表示する |
| 在庫変動区分 | 親区分と子区分を表示する。承認対象が在庫移動・在庫振替の場合は `-` を表示する（承認時に2種類以上の在庫変動が発生し、表で表現できない） |
| 登録日 / 登録者 | 承認対象を登録した日時とメンバー |
| 承認日 / 承認者 | 承認または却下を行った日時とメンバー |

### 承認対象を押下したときの動き

| 承認対象 | 動き | 開き方 |
| --- | --- | --- |
| 在庫編集 / 在庫一括編集 / 在庫変更CSV登録 | 押下した承認対象に紐づく在庫変動履歴を確認できる確認モーダルを開く | 同一タブ |
| 在庫移動 | 押下した在庫移動の登録元IDを指定して在庫移動の承認画面を開く | 別タブ |
| 在庫振替 | 在庫振替の承認画面を開く | 別タブ |
| 在庫分割 | 在庫分割の承認画面を開く | 別タブ |
| 在庫結合 | 在庫結合の承認画面を開く | 別タブ |

### 一括操作の対象になる行

| 観点 | 内容 |
| --- | --- |
| 選択欄を表示する条件 | 承認対象が在庫編集・在庫一括編集・在庫変更CSV登録であり、承認状態が未承認であり、かつ登録者がログインしているユーザー以外である行に限る |
| スマレジ連携失敗の行 | 選択欄を表示する扱いは未実装である |
| ヘッダ行での一括選択 | ヘッダ行のチェックボックスを押下すると、表示中のページの全行にチェックを入れる。もう一度押下すると全て外す |
| ヘッダ行の判定 | 全行にチェックがある場合でも、ヘッダ行が未チェックのときはチェックを入れる動作になる。ヘッダ行にチェックがあるときは外す動作になる |

### 検索条件

在庫項目同士の条件はAND条件とする。例として、店舗にA店舗、在庫区分にEC-CUBEを入力した場合は、A店舗かつEC-CUBEの情報だけに絞り込む。同じ項目で複数の値を選択した場合はOR条件とする。

| 画面上の項目 | 書式 | 検索条件 |
| --- | --- | --- |
| 店舗 | 複数選択 | 店舗のいずれかに一致。未指定の場合はログインメンバーのデフォルト検索表示店舗を初期値とする |
| 在庫区分 | チェックボックス（複数。EC-CUBE / スマレジ） | 在庫区分のいずれかに一致 |
| 承認対象の絞り込み | チェックボックス（選択肢は「承認可能な在庫のみ表示」） | チェックがある場合、選択した店舗のうちログインメンバーが承認権限を持つ承認対象で、かつ承認状態が未承認の行だけに絞り込む。このとき承認ステータスは選択できないようにし、検索条件から除外する |
| 承認ステータス | チェックボックス（複数。未承認 / 承認済 / 却下済） | 承認ステータスのいずれかに一致。複数チェックした場合はOR条件とする。全てにチェックがある状態は、全てにチェックが無い状態と同じ条件になる |
| 在庫変動区分 | 複数選択 | 親区分が入庫・廃棄である子区分を選択肢とし、在庫変動区分のいずれかに一致 |
| 登録者（所属選択） | 単一選択 | 登録者メンバーの選択肢を所属で絞る画面上の補助項目とし、検索条件そのものには使わない |
| 登録者（メンバー選択） | 複数選択 | 登録者のいずれかに一致 |
| 承認者（所属選択） | 単一選択 | 承認者メンバーの選択肢を所属で絞る補助項目とし、検索条件そのものには使わない |
| 承認者（メンバー選択） | 複数選択 | 承認者のいずれかに一致 |
| 登録日（from） | 日時（YYYY/MM/DD HH:mm。上限 9999/12/31 23:59） | 登録日が開始日の 00:00:00 以上。入力した日時も検索対象に含む |
| 登録日（to） | 日時（YYYY/MM/DD HH:mm。上限 9999/12/31 23:59） | 登録日が終了日の 23:59:59 未満。入力した日時以前を検索対象に含む |
| 承認日（from） | 日時（YYYY/MM/DD HH:mm。上限 9999/12/31 23:59） | 承認日が開始日の 00:00:00 以上。入力がある場合、承認日が空の行は検索結果に出力されない |
| 承認日（to） | 日時（YYYY/MM/DD HH:mm。上限 9999/12/31 23:59） | 承認日が終了日の 23:59:59 未満。入力がある場合、承認日が空の行は検索結果に出力されない |
| 検索条件をクリア | リンク | 画面側の制御とし、上記の検索条件の入力内容を空にする |

登録日は「登録日(from) > 登録日(to)」の場合、承認日は「承認日(from) > 承認日(to)」の場合にエラーとし、検索を行わない。

承認ステータスの選択肢は未承認・承認済・却下済の3値とする。Excel設計書の検索結果側にはスマレジ連携中・スマレジ連携失敗を前提とした表示条件・処理説明が残るが、この2状態は実装済みとして扱わない。

### 検索の成立条件と表示件数

- 検索実行時は入力内容を検証する。妥当な場合はページ番号を1に戻し、検索条件を保持したうえで検索する。
- 検証エラーの場合は画面遷移せず、エラーがある旨・空の一覧・件数0で同じ画面を再表示する。
- 一覧を開き直した場合は、保持した検索条件を復元して検索する。保持が無い場合は、デフォルト検索表示店舗による初期検索条件を作って検索する。
- 表示件数の指定は、表示件数マスタに登録された値と一致する場合だけ採用して保持する。一致しない値の場合は既定件数に丸める。
- ページ番号も保持する。

### 一括承認・一括却下の可否

一覧で選択した承認対象（正の整数のIDだけを取り出す）と、承認か却下かの区分を受け取って処理する。次のいずれかに当たる場合は処理を実行せず、在庫編集の承認権限が無い旨を表示して承認一覧へ戻る。

| 判定 | 実行しない条件 |
| --- | --- |
| 対象の有無 | 承認対象が1件も選択されていない場合 |
| 自己承認・自己却下 | ログインしているメンバー自身が登録者である行が1件でも含まれる場合 |
| 承認権限 | 承認できる件数（登録者本人でない・対象店舗に所属している・承認権限を持つ）が、選択した件数と一致しない場合 |

承認・却下を実行できるのは、ログインしているメンバーが承認権限を所持している店舗の在庫に限る。

### 一括承認・一括却下の処理

1. 一連の更新をひとまとまりの処理として開始する。
2. 選択した承認対象のうち、在庫編集・在庫一括編集・在庫変更CSV登録のものだけを処理し、それ以外は読み飛ばす。
3. 承認一覧の承認ステータス・承認日（現在時刻）・承認者（ログインしているメンバー）を更新する。対応する在庫編集承認の承認ステータス・承認者・承認日も同じ内容へ更新する。
4. 在庫編集承認の明細ごとに、承認の場合は承認処理、却下の場合は却下処理を行い、在庫数・総原価・在庫変動履歴を更新する。更新の細部は別添「在庫変動時の履歴作成について」を正とする。
5. すべて成功した場合は更新を確定し、保存した旨を表示して承認一覧へ戻る。途中で失敗した場合は一連の更新を取り消し、入荷通知の保留分を破棄したうえで、保存に失敗した旨を表示して承認一覧へ戻る。

### 承認・却下による在庫の扱い

| 区分 | 在庫変更理由の親区分 | 内容 |
| --- | --- | --- |
| 承認 | 入庫 | 承認対象の在庫情報を更新する。現在庫数は「登録時点での在庫数 + 在庫増減数」で計算して登録する。総原価は別添「在庫変動時の履歴作成について」の入庫時・出庫時の計算式で計算して登録する。処理の完了後に在庫変動履歴を更新し、更新日とログインしているメンバー（更新者）も併せて更新する。処理済みの入庫承認待ち在庫情報は論理削除する |
| 承認 | 廃棄 | 承認対象の在庫情報履歴を更新する。承認押下時の承認日とログインユーザーを承認者として更新し、あわせて更新日とログインしているメンバー（更新者）を更新する |
| 承認 | 在庫区分がスマレジの場合 | 更新後の在庫数をスマレジへ連携する。EC-CUBEとの在庫差異がある場合は、在庫情報の更新前にスマレジ在庫修正処理を行う。連携に失敗した場合は承認ステータスをスマレジ連携失敗とする。連携処理そのものはAPI在庫管理の設計を正とする |
| 却下 | 入庫 | 承認対象の在庫情報は更新しない。承認待ちから却下となった在庫の入庫承認待ち在庫情報の承認状態を却下へ更新する。承認一覧の情報は操作ステータスを却下の状態に変更して残す |
| 却下 | 廃棄 | 承認対象の在庫情報を更新する。現在庫数は「却下時点での在庫数 + (在庫増減数 × -1)」、総原価は「却下時点での在庫の総原価 + (総原価増減数 × -1)」で計算して登録する。処理の完了後に在庫変動履歴を更新し、更新日とログインしているメンバー（更新者）も併せて更新する |

ステータス変更時は、登録者に紐づくメールアドレス宛に、承認ステータス変更時用のメールテンプレートで通知を送付する。却下の場合は却下理由をメール本文に加える（表示位置はテンプレート内でタグ指定する）。却下理由の保存と通知メールは実装が未対応であり、Excel設計書を正とする。

### 在庫編集系明細の確認

| 観点 | 内容 |
| --- | --- |
| 表示の契機 | 一覧で在庫編集・在庫一括編集・在庫変更CSV登録の承認対象を押下したとき、選択した承認対象と明細の総件数を保持し、明細の1ページ目を表示する |
| ページ切替 | 保持した承認対象に対して、指定ページの明細を表示する |
| 対象 | 承認対象が在庫編集・在庫一括編集・在庫変更CSV登録のものだけとする |
| 取得の絞り込み | モーダル表示上限で件数を絞ったうえで、1ページあたりの表示件数で区切る |
| 表示項目 | 商品名/商品コード・言語・状態（カードコンディション）・Foil・店舗/在庫区分・編集前在庫・編集後在庫・在庫増減数・仕入単価・総原価増減・編集前総原価・編集後総原価・在庫変動区分・在庫変更理由 |
| 金額の書式 | `¥` と桁区切りを付ける。仕入単価は小数2桁とする |

### 分岐・遷移・例外

| 状況 | ふるまい |
| --- | --- |
| 登録日または承認日で、開始が終了より後 | 入力エラーとし、検索を行わず、同じ画面をエラー表示・空の一覧・件数0で再表示する |
| 一括承認・一括却下の権限が無い（自己承認・承認権限なしを含む） | 在庫編集の承認権限が無い旨を表示して承認一覧へ戻る |
| 一括承認・一括却下が途中で失敗 | 一連の更新を取り消し、入荷通知の保留分を破棄したうえで、保存に失敗した旨を表示して承認一覧へ戻る |
| 明細の確認要求が画面由来でない | 何も返さない |
| 明細CSV出力時に、保持した承認対象が無い | 選択情報が無い旨を表示して承認一覧へ戻る |
| 表示件数に登録外の値が指定された | 既定件数に丸める |

### 他機能との境界

- 承認対象を登録する機能（在庫編集・在庫一括編集・在庫変更CSV登録・在庫移動振替・在庫分割結合）と、在庫移動・在庫振替・在庫分割・在庫結合の各承認画面の仕様は、それぞれの機能の設計を正とする。
- 承認確定後の在庫数・総原価・在庫変動履歴の再計算の詳細は、別添「在庫変動時の履歴作成について」を正とする。
- 在庫区分がスマレジの場合の連携処理・在庫差異の修正・連携失敗時の扱いは、API在庫管理の設計を正とする。
- 画面項目・一覧の列・CSVの列・確認モーダルの配置の詳細は、参照元のExcel設計書（在庫編集承認一覧の検索入力・検索結果、承認一覧CSV出力）を正とする。

### Excel設計書との乖離

Excel設計書の記載と、実装で確認したふるまいが食い違う箇所がある。本書は下表の「本書の記載」を採る。

| 本書の記載 | Excel設計書の記載 |
| --- | --- |
| 表示件数は既定の表示件数設定に従う（確認できた値は10件） | 表示件数の初期値は100件 |
| 検索条件の在庫変動区分は複数選択 | 在庫変動区分は単一選択（セレクトボックス） |

次の2点は仕様上の正否が未確定であり、要確認とする。

- 合計在庫増減数・合計総原価増減数・在庫変動区分について、一覧は在庫分割・在庫結合でも値を表示し、検索結果CSVは `-` を出力する。Excel設計書は承認対象が在庫編集・在庫一括編集・在庫変更CSV登録以外なら `-` と定めており、一覧とCSVで扱いが分かれている根拠は確認できていない。
- 検索結果CSVの最終更新日・最終更新者は常に `-` である。Excel設計書が値の出力を求める場合はExcel設計書を正とし、是正の対象とする。

## 入出力

### 出力: 検索結果CSV

一覧から実行すると、保持している検索条件に一致する承認一覧を、一覧のページングに依らず全件出力する。

| 観点 | 内容 |
| --- | --- |
| ファイル名 | `stock_approval_list_` に出力日時（年月日時分秒）を続けたもの。添付ファイルとしてダウンロードさせる |
| 文字コード・区切り | 共通のCSV出力設定に従う（既定はSJIS-win） |
| 出力列（15列） | 承認状態 / 承認対象 / 店舗 / 在庫区分 / 対象商品規格数 / 合計在庫増減数 / 合計総原価増減数 / 在庫変動区分（親区分） / 在庫変動区分（子区分） / 登録日 / 登録者 / 承認日 / 承認者 / 最終更新日 / 最終更新者 |
| 日付の書式 | 登録日・承認日は「年/月/日 時:分」で出力する。承認日が空の場合は `-` を出力する |
| 承認者が空の場合 | 「承認待ち」を出力する |
| 承認対象による差 | 承認対象が在庫編集・在庫一括編集・在庫変更CSV登録以外の場合、合計在庫増減数・合計総原価増減数・在庫変動区分（親区分・子区分）に `-` を出力する。一覧では在庫分割・在庫結合にも値を表示するので、一覧とCSVで分割・結合の扱いが異なる（「Excel設計書との乖離」参照） |
| 最終更新日・最終更新者 | 常に `-` を出力する（値を出力する仕様かは要確認。「Excel設計書との乖離」参照） |

### 出力: 明細CSV

直前に開いた明細の確認で保持した承認対象に紐づく在庫編集明細を、表示上限を超えた件数も含めて全件出力する。保持した承認対象が無い場合は出力せず、選択情報が無い旨を表示して承認一覧へ戻る。

| 観点 | 内容 |
