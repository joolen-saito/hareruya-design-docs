# m02-06_admin_home_home_recommend_plugins（管理画面_トップおすすめプラグイン）

## 業務ロジック

### おすすめ一覧の取得

管理画面ホームの表示を組み立てたあとで、おすすめプラグインの一覧を外部のプラグインAPIから取得する。取得先は設定値の基底URLに、おすすめ取得用の経路を連結したものとする。実URLは環境値を正とし、本書では固定しない。

外部APIへはプラグイン認証キー・現在のサイトURL・EC-CUBEバージョンだけを送る。認証キーの原値はどの場合も表示せず記録もしない。

外部APIの応答は配列として読み込み、推薦順と絞り込みを変えない。取得と加工に成功したときだけ、おすすめプラグインの一覧を画面へ渡す。外部APIとの通信または応答の処理で例外が起きたときは、例外を握りつぶして空の一覧を画面へ渡す。

通信にはタイムアウトを設ける。タイムアウトしたとき、および HTTP 200 以外のときは、取得の失敗として扱う。

### 表示状態の判定順序

| 順序 | 判定 | 結果 |
| --- | --- | --- |
| 1 | 外部APIから取得したプラグインを処理対象にする | 初期状態を「未インストール・未購入扱い」とする |
| 2 | ローカルに登録済みのプラグインの取得元IDが、外部APIのプラグインIDと一致するか | 一致するときは「インストール済み」とする |
| 3 | 手順 2 に一致し、ローカルのバージョンが外部APIのバージョンより古いか | 古いときは「アップデートあり」とする |
| 4 | 外部APIの上で未購入、かつ購入が必要か | 該当するときは「未購入の有料プラグイン」とし、手順 2・3 の判定を上書きする |
| 5 | 現在のEC-CUBEバージョンが対応バージョンの一覧に含まれるか | 含まれるときは対応バージョンの警告を表示しない |
| 6 | 現在のEC-CUBEバージョンが対応バージョンの一覧に含まれないか | 含まれないときは詳細に非対応の警告を表示する |

### 表示状態ごとの導線

| 表示状態 | 主導線 |
| --- | --- |
| 未インストール・未購入扱い | 「入手する」。無料または入手できるときはインストール確認へ進む |
| インストール済み | 「インストール済み」。更新が不要なときは状態表示だけとする |
| アップデートあり | 「アップデート」。アップデート確認へ進む |
| 未購入の有料プラグイン | 「購入する」。プラグインIDと公開鍵を外部ストアへ送る |

問い合わせURLまたはマニュアルURLがあるときだけ、詳細に外部の参照先を示す。

詳細の表示と終了は同じ画面の中で完結し、そのあいだサーバとの通信を行わない。

### 価格の表示

詳細では価格を税込の表記とする。無料のプラグインのときは、価格に加えてダウンロード数も表示する。

### エラー時の扱い

| エラー内容 | 処理 |
| --- | --- |
| 外部APIとの通信に失敗した | 例外を捕まえ、おすすめプラグインの一覧を空にする。この領域にエラー文言を出さない |
| HTTP 200 以外、または通信結果が偽 | 取得の失敗として扱い、空の一覧で表示する |
| 応答の項目が欠けている | この領域での補いは定めない。共通の例外処理の結果を正とする |
| インストール確認の遷移先での失敗 | 遷移先の機能を正とする |
| 購入先での失敗 | 外部ストアと購入機能を正とする |

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | ホーム画面の表示要求、外部APIのおすすめプラグインの応答、ローカルに登録済みのプラグイン、認証キー、サイトURL、EC-CUBEバージョン |
| 成功時出力 | おすすめプラグインの一覧と、プラグインごとの詳細および表示状態に応じた導線 |
| 失敗時出力 | 外部APIの取得に失敗したときはおすすめプラグインを 1 件も表示しない。ホーム画面全体の表示は続ける。この領域専用のエラーメッセージは出さない |

## 表示メッセージ

この機能はエラーメッセージを表示しない。表示状態ごとの文言は業務ロジックの導線の表に示す。
