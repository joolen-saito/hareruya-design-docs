# M04-27（在庫移動実績入力用CSV出力）

## 業務ロジック

### 出力の契機と対象

在庫移動指示一覧画面の「在庫移動実績入力用CSVダウンロード」を押すと、在庫移動実績（送り状No.）を記入するためのCSV雛形をダウンロードする。検索条件の指定も対象の選択も要らず、出力する内容は固定である。

出力するのは見出し行だけで、データ行は出力しない。利用者はこの雛形に移動指示IDと送り状No.等を記入し、在庫移動実績CSV登録（M04-29）でアップロードして送り状No.を一括登録する。

### 参照・更新するもの

在庫移動指示のデータは参照しない。見出しだけの雛形を生成して返すだけで、業務データの抽出も更新も行わない。取込履歴・在庫履歴の類も作成しない。

### 各列の記入要領

雛形の各列には、画面のCSVフォーマット説明のとおり次を記入する。

| 列 | 記入内容 |
| --- | --- |
| 移動指示ID | 移動指示リストのIDを記入する。取込時の照合キーになる |
| 出庫元店舗(名称) | 出庫元店舗の名称を記入する。取込時に指示の出庫元店舗名と照合される |
| 入庫先店舗(名称) | 入庫先店舗の名称を記入する。取込時に指示の入庫先店舗名と照合される |
| 送り状No. | 送り状No.を入力する。複数ある場合はカンマ（,）区切りとし、スペースは入れない |

### 取込側との対応

出力する4列は、在庫移動実績CSV登録（M04-29）が必須とする見出しと一致する。すなわち本機能は、M04-29で取り込める形式の空の雛形を提供する位置付けである。記入後CSVの取込・送り状No.の一括登録・在庫移動実績の反映はM04-29の仕様による。

送り状（ゆうプリR）用CSVは別機能（M04-28 送り状CSV出力）であり、列構成・対象・出力の契機が異なる。

### 失敗する分岐

固定の見出しだけを出す雛形出力であり、入力値にも対象データにも依存しないため、通常のダウンロードで失敗する分岐は無い。一時領域などのインフラ起因の失敗は、共通の実行時エラーとして扱う。

## 入出力

### 出力: CSVファイル

| 項目 | 内容 |
| --- | --- |
| 出力列 | 移動指示ID / 出庫元店舗(名称) / 入庫先店舗(名称) / 送り状No. の4列固定 |
| データ行 | 出力しない。見出し1行だけのファイルになる |
| 文字コード | CSV出力の設定に従う（既定は `SJIS-win`）。`UTF-8` の設定のときだけ先頭にバイトオーダーマークを付け、Excelでの文字化けを防ぐ |
| 区切り文字 | CSV出力の設定に従う（既定は `,`） |
| ファイル名 | `stock_move_instruction_record_template_` に出力時刻を `YmdHis` の形式でつなぎ、`.csv` を付けた名前 |
| 応答 | ダウンロードとして返す。応答に載せる文字コード名は、設定が `SJIS-win` のときだけ `windows-31j` へ読み替える |

## 表示メッセージ

本機能は画面メッセージを持たない。
