# 在庫管理 — バーコード貼替リストCSV出力

## 業務ロジック

### 出力の目的と対象

指定した期間に価格変更が発生し、かつ対象店舗のスマレジ在庫にある商品の商品コードリストを、スマレジのバーコードシール貼り替え用に出力する。現行に同等の機能は無く、リニューアルで新規に設ける。

### 画面の入力項目

| 項目 | 必須 | 初期値 | 説明 |
| --- | --- | --- | --- |
| 出力対象店舗 | 必須 | ログイン者のデフォルト検索表示店舗 | 1店舗だけ選べる |
| 価格変更発生期間（開始） | 必須 | 前日 | 出力時は時刻を 00:00:00 として扱う |
| 価格変更発生期間（終了） | 必須 | 当日 | 出力時は時刻を 23:59:59 として扱う |

期間は最大1か月まで選べる。開始日が終了日より後のときはエラーとし、出力しない。必須項目が未入力のときも出力しない。1か月を超える期間を指定したときの検証は、現時点の実装では行っていないため追加を要する。

### 出力対象の抽出条件

価格変更履歴を起点に、商品規格ごとに最も新しい価格変更1件を採り、次をすべて満たすものを出力する。

- 価格変更の発生日時が、指定した期間（開始日の 00:00:00 から終了日の 23:59:59 まで）に含まれる
- 対象店舗のスマレジ在庫が存在し、その在庫数が0以上である
- 商品規格のスマレジ連携が有効である
- スマレジ商品IDが登録済みで、空でない
- 商品と商品規格のステータスがいずれも廃止でない。非公開は含む

条件に該当する商品規格が1件も無いときは、見出し行だけのファイルを出力する。

### 出力順

| 順序 | 並び |
| --- | --- |
| 1 | 色の並び順の昇順。並び順が無いものは最後に置く |
| 2 | カードタイプの並び順の昇順。複数あるときは最小の並び順を用い、無いものは最後に置く |
| 3 | 点数で見たマナコストの昇順。値が無いものは最後に置く |
| 4 | 基準価格の降順。未設定は最後に置く |
| 5 | 商品規格IDの昇順 |

### 出力する列

見出し行とデータ行からなる6列を出力する。

| # | CSVヘッダ | 値の取り方 |
| --- | --- | --- |
| 1 | 商品名 | 商品名のうち、末尾にある `]` までを残し、それ以降（色・レアリティなどの略称）を除く。`]` が無いときは全文を出力する |
| 2 | 言語・状態 | 「言語の日本語名・状態のコード」の形式（例: 英語・NM）。商品またはグッズ予約のカテゴリに属するときは「サプライ品」とする。言語・状態の片方が無いときは、ある方だけを出力する |
| 3 | 販売価格 | 見出しは「販売価格」だが、値は基準価格を用いる。3桁区切りに整形して「円」を付ける（例: 1,200円）。未設定のときは空文字とする |
| 4 | スマレジ商品ID | 商品規格のスマレジ商品ID |
| 5 | スマレジ商品コード | 商品規格のスマレジ商品コード |
| 6 | スマレジバーコード | 「22」とスマレジ商品コード（6桁・左0埋め）と販売価格（基準価格、7桁・左0埋め）を連結する。桁数を超えるときは下位の桁を採る。商品コードが空のときは空文字とする |

既存のバーコードに出力済みの状態記号は出力しない。

### ファイルの形式

ファイル名は「barcode_replacement_list_」に出力日時（年月日時分秒）と拡張子 .csv を連結したものとする。文字コードは設定された出力用の文字コード（既定はSJIS-win）に変換する。全件をメモリに保持せず、1行ずつ書き出して送出する。送出が完了した時点で、完了した旨をログに残す。

### エラー時の扱い

| 事象 | 扱い |
| --- | --- |
| 出力対象店舗または価格変更発生期間が未入力 | 出力せず、エラーを表示してバーコード貼替リスト画面へ戻す |
| 開始日が終了日より後 | 出力せず、エラーを表示してバーコード貼替リスト画面へ戻す |
| 要求が正当でない | アクセス拒否（HTTP 403）とする。エラー表示と画面への遷移は行わない |
| 該当0件 | 見出し行だけのファイルを出力する |

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | 出力対象店舗、価格変更発生期間の開始日と終了日 |
| 成功時出力 | 見出し行と抽出したデータ行からなるファイルの送出。成功を知らせる文言は表示しない |
| 失敗時出力 | バーコード貼替リスト画面へ戻し、入力内容のエラーを表示する |

### 入出力: 永続化

本機能はデータを更新しない。価格変更履歴・スマレジ在庫・商品規格・商品・カテゴリ・区分の各情報を参照するだけである。
