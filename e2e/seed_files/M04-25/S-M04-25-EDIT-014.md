# S-M04-25-EDIT-014 空白送状データ014

- 機能: M04-25／区分: 在庫移動指示・在庫移動／共有: ケース専用／分類: ケースで登録／形式: 画面入力（手順書）

## 状態・属性（シード表の文）

在庫移動指示IDは登録時に画面が振る（控える。以下〔在庫移動指示ID-M0425-014〕）／東京店→大阪店／送状No.=TRACK-BEFORE-014／発送状況=済／備考=変更前備考／在庫移動IDは登録時に画面が振る（控える。以下〔在庫移動ID-M0425-014〕）／ステータス=移動中／登録者・更新者=管理者ID 42590003

## 用途（シード表の文）

IT-M04-25-014専用。空白だけの送状No.で更新前の状態を保持する

## 投入方法（シード表の文）

東京店と大阪店を店舗登録画面で登録した後に行う。①グッズ商品CSV登録画面で、商品コード「M0425-014-G1」・基準価格と販売価格に任意の金額を入れた1行のCSVを登録する（ほかの必須列には任意の有効な値を入れる。登録すると両店舗にEC-CUBEとスマレジの商品在庫が在庫数0でできる）。②在庫変更CSV登録画面で対象の店舗に東京店、在庫区分にEC-CUBEを選び、商品コード「M0425-014-G1」・在庫増減数1のCSVを登録し（変動の種別・理由・承認通知先は任意の有効な値）、登録者とは別の、所属店舗と編集可能店舗が東京店で承認権限を持つ管理者（以下、承認用管理者）が在庫編集承認一覧でこの申請を承認する。③M04-25試験管理者（ログインID m0425_admin）でログインし、在庫検索一覧で東京店・EC-CUBEの商品コード「M0425-014-G1」の行を選んで在庫移動登録ボタンを押し、在庫移動・振替登録画面で入庫先店舗に大阪店、入庫先在庫区分にEC-CUBE、移動点数に1を入れて登録する。④続けて表示されるピック・出庫承認申請画面で承認通知先に承認用管理者を選び、承認申請ボタンを押す。⑤承認用管理者でログインし、この在庫移動の出庫承認画面で承認ボタンを押す（ステータスが出庫承認済みになる）。⑥M04-25試験管理者（ログインID m0425_admin）でログインし、在庫移動振替一覧でこの在庫移動の行に表示された在庫移動・振替IDを控え（〔在庫移動ID-M0425-014〕）、その行にチェックを入れて在庫移動指示作成ボタンを押す。⑦在庫移動指示検索画面で在庫移動IDに控えた番号を入れて検索し、結果の行に表示された在庫移動指示IDを控える（〔在庫移動指示ID-M0425-014〕）。⑧その行の送状No.欄の登録ボタンを押し、送り状ナンバー登録モーダルの送状No.に「TRACK-BEFORE-014」を入れて登録する（発送状況が済、在庫移動のステータスが移動中になる）。⑨在庫移動指示IDを押して在庫移動指示詳細画面を開き、備考に「変更前備考」を入れて登録ボタンを押す。
