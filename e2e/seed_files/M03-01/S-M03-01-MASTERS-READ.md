# S-M03-01-MASTERS-READ 検索参照マスタ

- 機能: M03-01／区分: 各種マスタ／共有: 共有可／分類: マスタ

## 状態・属性（シード表の文）

カテゴリID 〔カテゴリID-M0301-共有A〕=名称「M03カテゴリA」・カテゴリID 〔カテゴリID-M0301-共有B〕=名称「M03カテゴリB」／カードセットID 〔カードセットID-M0301-共有A〕=名称「M03セットA」・カードセットID 〔カードセットID-M0301-共有B〕=名称「M03セットB」／部門ID 〔部門ID-M0301-共有〕=名称「M03部門A」／カテゴリID・カードセットID・部門IDは登録時に画面が振る（控える。以下〔カテゴリID-M0301-共有A〕・〔カテゴリID-M0301-共有B〕・〔カードセットID-M0301-共有A〕・〔カードセットID-M0301-共有B〕・〔部門ID-M0301-共有〕）

## 用途（シード表の文）

候補表示、クリア確認、複合検索および未設定検索で参照する。各ケースは開始時の値を確認し、レコードを変更しない

## 投入方法（シード表の文）

カテゴリ登録でグッズのカテゴリを開き、カテゴリ名(日)に「M03カテゴリA」、カテゴリ名(英)に「M03 Category A」を入れて「子カテゴリ作成」を押す。同じ操作でカテゴリ名(日)「M03カテゴリB」・カテゴリ名(英)「M03 Category B」を登録する。カテゴリ登録の一覧で「M03カテゴリA」「M03カテゴリB」の編集を開き、表示されたカテゴリIDを控える（〔カテゴリID-M0301-共有A〕・〔カテゴリID-M0301-共有B〕）。カードセット詳細の新規登録で、カードセット名日本語に「M03セットA」、カードセット名英語に「M03 Set A」、略称に「M3A」、リリース日に登録日の日付を入れて「登録」を押す。同じ操作でカードセット名日本語「M03セットB」・カードセット名英語「M03 Set B」・略称「M3B」を登録する。カードセット管理(一覧)で「M03セットA」「M03セットB」の行に表示されたIDを控える（〔カードセットID-M0301-共有A〕・〔カードセットID-M0301-共有B〕）。部門登録で部門名に「M03部門A」、部門コードに他の部門と重ならない数字、免税区分に「対象外」を入れて「登録」を押し、一覧の「M03部門A」の行に表示されたIDを控える（〔部門ID-M0301-共有〕）。

## 登録するときの注意

- このシードはマスタ（ダンプに入っている）。マスタの登録そのものを試すときは、上の文のとおりに画面から入力する。文にない操作は足さない。
- 画面が振る番号は登録した場所で控える。控える呼び名: 〔カテゴリID-M0301-共有A〕、〔カテゴリID-M0301-共有B〕、〔カードセットID-M0301-共有A〕、〔カードセットID-M0301-共有B〕、〔部門ID-M0301-共有〕
- 承認・削除・取込などで状態が変わるシードは、一度使うと元に戻らない。もう一度試すときは同じ内容で登録し直す（商品コードなどが重なって登録できないときは、前のものが残っていないか確かめる）。
