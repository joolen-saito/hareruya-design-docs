# S-M13-02-BASE-002 基本表示イベント(002)

- 機能: M13-02／区分: イベント／共有: ケース専用／分類: ケースで登録／形式: 画面入力（手順書）

## 状態・属性（シード表の文）

イベントIDは登録時に画面が振る（控える。以下〔イベントID-M1302-002〕）／イベント名(日)=編集前イベント-002／イベント名(英)=Before Event-002／店舗A／会場A／スタンダード／初心者歓迎／公開／おすすめイベント／バナーURL(日)=https://example.com/before-jp／バナーURL(英)=https://example.com/before-en／定員16／チーム戦オフ／クレジットカード決済オン／参加費500／賞品(日)=編集前賞品／賞品(英)=Before Prize／フリー入力エリア1〜3は項目名(日)=項目1〜3・項目名(英)=Item1-002・Item2-002・Item3-002・内容(日)=内容1〜3・内容(英)=Content1-002・Content2-002・Content3-002・アコーディオンオフ／日程0件

## 用途（シード表の文）

IT-M13-02-002専用。保存値の初期表示

## 投入方法（シード表の文）

店舗Aに編集権限を持つM13-02の試験管理者で管理画面にログインし、メニューの「イベント管理」→「イベント一覧」で「新規作成」を押してイベント登録画面を開く。イベント名(日)に「編集前イベント-002」、イベント名(英)に「Before Event-002」を入れ、店舗で「店舗A」、フォーマットで「スタンダード」、ルール適用度で「初心者歓迎」、公開状態で「公開」、イベント規模で「おすすめイベント」を選び、バナーURL(日)に「https://example.com/before-jp」、バナーURL(英)に「https://example.com/before-en」、定員に「16」、参加費に「500」を入れ、チーム戦フラグはチェックを入れないままにし、支払方法の「クレジットカード決済」にチェックを入れ、賞品(日)に「編集前賞品」、賞品(英)に「Before Prize」を入れ、フリー入力エリア1〜3の項目名(日)に順に「項目1」「項目2」「項目3」、項目名(英)に順に「Item1-002」「Item2-002」「Item3-002」、内容(日)に順に「内容1」「内容2」「内容3」、内容(英)に順に「Content1-002」「Content2-002」「Content3-002」を入れ、フリー入力エリア1〜3のアコーディオン表示（初期表示は閉じる）はチェックを入れないままにし、ここに書いていない項目は初期表示のままにして「登録」を押す。会場はイベント登録画面に入力項目が無いので設定しない。イベント一覧でイベント名「編集前イベント-002」の行に表示されたイベントIDを控える（〔イベントID-M1302-002〕）。日程は追加しない。

## 登録するときの注意

- 上の文のとおりに、画面から（または下のCSVで）登録する。文にない操作は足さない。
- 画面が振る番号は登録した場所で控える。控える呼び名: 〔イベントID-M1302-002〕
- 承認・削除・取込などで状態が変わるシードは、一度使うと元に戻らない。もう一度試すときは同じ内容で登録し直す（商品コードなどが重なって登録できないときは、前のものが残っていないか確かめる）。
