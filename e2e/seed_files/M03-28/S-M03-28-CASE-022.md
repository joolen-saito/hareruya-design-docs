# S-M03-28-CASE-022 5010件遷移データ(022)

- 機能: M03-28／区分: 商品・商品タグ・CSV／共有: ケース専用／分類: ケースで登録／形式: CSV等のファイル候補

## 状態・属性（シード表の文）

商品ID=328220001〜328225010の5010件／商品タグ紐付けID=329220001〜329225010／全商品が通常公開でタグID 281だけ／limit-5010-022.csvは当該5010商品を1件ずつタグID 282へ更新する5010データ行

## 用途（シード表の文）

IT-M03-28-022専用。上限超過後の画面遷移を確認する

## 投入方法（シード表の文）

DBシードで5010商品とタグ紐付けを登録し、生成後にデータ行数を検査したUTF-8 CSVフィクスチャを配置する

## 登録するときの注意

- 上の文のとおりに、画面から（または下のCSVで）登録する。文にない操作は足さない。
- 画面が振る番号は無い。
- 承認・削除・取込などで状態が変わるシードは、一度使うと元に戻らない。もう一度試すときは同じ内容で登録し直す（商品コードなどが重なって登録できないときは、前のものが残っていないか確かめる）。
- 取込用のファイル（e2e/seed_files/M03-28/ の下。シード表の文から tools/csv_make.py が組んだもの）:
- S-M03-28-CASE-022/limit-5010-022.csv
  - S-M03-28-CASE-022/limit-5010-022.csv で担当が決めた値・出どころ: 5010行: 文の範囲指定（商品コード/商品ID 328220001〜328225010）を、シード表の状態・属性から展開した




## DBへ直接設定する部分（SQL）

- この手順書のDB直接設定の文は、すべて SQL を作っていない（理由は下）。
- SQLを作っていない文と理由:
