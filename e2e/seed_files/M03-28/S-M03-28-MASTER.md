# S-M03-28-MASTER 商品タグCSV試験タグ

- 機能: M03-28／区分: タグマスタ／共有: 共有可／分類: マスタ

## 状態・属性（シード表の文）

タグIDは登録時に画面が振る（控える。以下〔タグID-M0328-共有A〕・〔タグID-M0328-共有B〕・〔タグID-M0328-共有C〕）／3件のタグが登録済み

## 用途（シード表の文）

CSV取込時に参照するだけで、タグマスタ自体は変更しない

## 投入方法（シード表の文）

タグ登録画面で名称(日)に「M0328試験タグA」、名称(英)に「M0328 Test Tag A」、並び順に他のタグと重ならない値を入れて登録ボタンを押す。同じ操作を名称(日)「M0328試験タグB」・名称(英)「M0328 Test Tag B」、名称(日)「M0328試験タグC」・名称(英)「M0328 Test Tag C」で繰り返す。タグ登録画面の一覧で各名称の行のID列に表示された番号を控える（M0328試験タグAは〔タグID-M0328-共有A〕、M0328試験タグBは〔タグID-M0328-共有B〕、M0328試験タグCは〔タグID-M0328-共有C〕）

## 登録するときの注意

- このシードはマスタ（ダンプに入っている）。マスタの登録そのものを試すときは、上の文のとおりに画面から入力する。文にない操作は足さない。
- 画面が振る番号は登録した場所で控える。控える呼び名: 〔タグID-M0328-共有A〕、〔タグID-M0328-共有B〕、〔タグID-M0328-共有C〕
- 承認・削除・取込などで状態が変わるシードは、一度使うと元に戻らない。もう一度試すときは同じ内容で登録し直す（商品コードなどが重なって登録できないときは、前のものが残っていないか確かめる）。
