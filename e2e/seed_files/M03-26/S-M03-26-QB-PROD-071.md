# S-M03-26-QB-PROD-071 カード商品CSV更新の確認商品(001)

- 機能: M03-26／区分: カード・商品・規格／共有: ケース専用／分類: ケースで登録／形式: 画面入力（手順書）

カード詳細IDは登録時に画面が振る（控える。以下〔カード詳細ID-M0326-001〕）／商品IDは登録時に画面が振る（控える。以下〔商品ID-M0326-001〕）／商品名=カード連携商品-M0326QB001／商品名(英)=Card Link M0326QB001／商品説明(日)=更新前説明-M0326QB001／カード商品・日本語・規格1件（状態NM・基準価格300・販売価格300・買取価格100・セールフラグなし・未廃止・表示対象）／本店の商品公開ステータス=公開・支店の商品公開ステータス=公開／本店の在庫（在庫区分EC-CUBE）=2

## 用途（シード表の文）

IT-M03-26-071専用。カード商品CSVの更新で商品名と商品説明が商品詳細に反映される対象

## 投入方法（シード表の文）

【画面1 カード】管理画面のカード登録画面で、カード名(英)に「M0326QB-001」で始まる任意の名前、点数で見たマナ・コストに任意の数値を入れ、「詳細情報を追加」を押して詳細情報を1件足し、そのレアリティ・レイアウト・プロモ種別・Foil・フレームに任意の有効な値を選んで「登録」を押す。登録後に開くカード編集画面の詳細情報の見出し「カード詳細ID: 」に表示された番号を控える（〔カード詳細ID-M0326-001〕）。【画面2 商品】グッズ商品CSV登録で雛形ファイルをダウンロードし、1行を書いたCSVをCSVファイル選択で選んで「CSVファイルのアップロード」を押し、表示された確認モーダルでアップロードを確定する（商品IDは空・商品コードは「M0326-001-CODE」・商品名(日)は「カード連携商品-M0326QB001」・商品名(英)は「Card Link M0326QB001」・言語(ID)は1・商品公開ステータスは2（公開）・支店の商品公開ステータスは1（公開）・サイズ1・重量1・商品カテゴリ(ID)はサプライ・グッズのカテゴリID（カテゴリ登録/編集画面の最上位の一覧で「サプライ・グッズ」の行のID欄に表示された値）・購入グループ名称は「通常商品」・商品説明(日)は「更新前説明-M0326QB001」・基準価格300・販売価格300・買取価格100・原価単価100・地域別販売制限は0・スマレジ連携フラグは0・スマレジ商品コードと部門IDは空）。グッズ商品は状態ニアミントの規格が商品ごとに1件作られる。商品マスター(検索入力)で商品コードに「M0326-001-CODE」を入れて「検索する >」を押し、商品マスター(検索結果)の行の商品IDに表示された番号を控える（〔商品ID-M0326-001〕）。商品マスター(検索結果)の行から商品登録編集画面（既存の商品の編集）を開き、「カード指定 >」ボタンを押し、カード検索ポップアップで画面1で登録したカードをカード名で検索して〔カード詳細ID-M0326-001〕のカード詳細の行の決定ボタンを押す。続けて商品名(日)に「カード連携商品-M0326QB001」、商品名(英)に「Card Link M0326QB001」を入れ（カード指定で自動で入った値は書き換える）、商品カテゴリはサプライ・グッズの選択を外してカテゴリID1とカテゴリID177のカテゴリを選び、割引率にID5の割引率を選び、公開状態は「公開」のまま「商品を登録」ボタンを押す。【画面3 商品規格】商品登録編集画面の「規格設定」ボタンから商品規格一覧を開く。商品規格一覧で言語が言語ID1に当たる言語・状態NMの規格（取り込みで作られた規格。基準価格300・販売価格300・買取価格100）の公開ステータスが「公開」であることを確かめる（異なるときは規格の行を開き、公開ステータスに「公開」を選んで「商品規格を登録」ボタンを押す）。【在庫】在庫検索一覧(検索入力)で商品名に「カード連携商品-M0326QB001」を入れて「検索」ボタンを押し、在庫検索一覧(検索結果)で店舗が本店・在庫区分EC-CUBEの行の商品名を押して在庫編集画面を開き、在庫変動区分に「入庫/その他」、在庫変動理由に「試験データ」、在庫増減数に2、仕入単価に600を入れて「登録」ボタンを押す。登録した管理者とは別の、在庫編集の承認権限を持つ管理者（m0326qb-approver）でログインし直し、在庫編集承認一覧(検索結果)を開いて、その行のチェックボックスにチェックを入れ、「一括承認」ボタンを押し、「承認する」ボタンを押す。
