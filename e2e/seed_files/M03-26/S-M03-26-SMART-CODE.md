# S-M03-26-SMART-CODE スマレジ商品コード採番

- 機能: M03-26／区分: 採番設定／共有: 共有可／分類: マスタ

## 状態・属性（シード表の文）

開始時の最終採番値=130000／商品コード130001は未使用

## 用途（シード表の文）

採番値を1件に分割できないため共有する。各ケースが開始時に必要な値を自分で設定する

## 投入方法（シード表の文）

DBフィクスチャで採番値を130000に設定し、商品コード130001を持つ商品規格を削除する

## 登録するときの注意

- このシードはマスタ（ダンプに入っている）。マスタの登録そのものを試すときは、上の文のとおりに画面から入力する。文にない操作は足さない。
- 画面が振る番号は無い。
- 承認・削除・取込などで状態が変わるシードは、一度使うと元に戻らない。もう一度試すときは同じ内容で登録し直す（商品コードなどが重なって登録できないときは、前のものが残っていないか確かめる）。
