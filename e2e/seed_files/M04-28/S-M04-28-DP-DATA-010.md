# S-M04-28-DP-DATA-010 住所2が空の店舗の指示データ010

- 機能: M04-28／区分: 在庫移動指示・在庫移動／共有: ケース専用／分類: ケースで登録／形式: 画面入力（手順書）

## 状態・属性（シード表の文）

移動指示IDは在庫移動指示の作成時に画面が振る（控える。以下〔移動指示ID-M0428-010〕）／移動元店舗ID=〔店舗ID-M0428-010〕／移動先店舗ID=〔店舗ID-M0428-共有B〕／基準価格合計=3500／送り状No.なし／発送状況=未／在庫移動IDは登録時に画面が振る（控える。以下〔在庫移動ID-M0428-010〕）。この在庫移動が1件紐づきステータス=出庫承認済み

## 用途（シード表の文）

IT-M04-28-010専用。移動元の住所2が空でも送り状CSVの注文者住所2が空になり並びが崩れないことを確かめる

## 投入方法（シード表の文）

店舗登録後に行う。1. 管理者 m0428-010-a でログインし、グッズ商品CSV登録画面で、商品コード「M0428-010-G1」・基準価格3500の1行のCSVを登録する（ほかの必須列には任意の有効な値を入れる）／2. 在庫変更CSV登録画面で対象の店舗に元店M0428-010、在庫区分にEC-CUBEを選び、商品コード「M0428-010-G1」・在庫増減数1のCSVを登録し（変動の種別・理由は任意の有効な値、承認通知先に m0428-010-b）、m0428-010-b が在庫編集承認一覧でこの申請を承認する／3. m0428-010-a でログインし、在庫移動振替一覧の在庫移動CSV登録で、出庫元店舗に元店M0428-010・出庫元在庫区分にEC-CUBE・入庫先店舗に大阪店・入庫先在庫区分にEC-CUBEを選び、「M0428-010-G1」を移動点数1で書いたCSVを登録する／4. ピック・出庫承認申請画面で承認通知先に m0428-010-b を選び承認申請ボタンを押す。m0428-010-b でログインし、出庫承認画面で承認ボタンを押す／5. m0428-010-a でログインし、在庫移動振替一覧でこの在庫移動の行の在庫移動・振替IDを控え（〔在庫移動ID-M0428-010〕）、チェックを入れて在庫移動指示作成ボタンを押す。在庫移動指示検索画面で在庫移動IDに控えた番号を入れて検索し、結果の行の移動指示IDを控える（〔移動指示ID-M0428-010〕）。送り状No.は登録しない

## 登録するときの注意

- 上の文のとおりに、画面から（または下のCSVで）登録する。文にない操作は足さない。
- 画面が振る番号は登録した場所で控える。控える呼び名: 〔移動指示ID-M0428-010〕、〔店舗ID-M0428-010〕、〔店舗ID-M0428-共有B〕、〔在庫移動ID-M0428-010〕
- 承認・削除・取込などで状態が変わるシードは、一度使うと元に戻らない。もう一度試すときは同じ内容で登録し直す（商品コードなどが重なって登録できないときは、前のものが残っていないか確かめる）。
