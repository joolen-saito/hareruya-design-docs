# S-M03-33-TAGS 取込用タグ

- 機能: M03-33／区分: 商品タグ／共有: 共有可／分類: ケースで登録／形式: 画面入力（手順書）

## 状態・属性（シード表の文）

ID 1=取込前タグ／ID 2=取込後タグA／ID 3=取込後タグB／ID 999は未登録

## 用途（シード表の文）

参照だけのマスタ。各ケースが開始時にID 1〜3の名称とID 999が未登録であることを設定する

## 投入方法（シード表の文）

DBシードでID 1〜3を登録し、ID 999を削除する

## 登録するときの注意

- 上の文のとおりに、画面から（または下のCSVで）登録する。文にない操作は足さない。
- 画面が振る番号は無い。
- 承認・削除・取込などで状態が変わるシードは、一度使うと元に戻らない。もう一度試すときは同じ内容で登録し直す（商品コードなどが重なって登録できないときは、前のものが残っていないか確かめる）。





## DBへ直接設定する部分（SQL）

- この手順書のDB直接設定の文は、すべて SQL を作っていない（理由は下）。
- SQLを作っていない文と理由:
  - [1] DBシードでID 1〜3を登録し、ID 999を削除する → 文の形が個別で、表・列・値を文から機械的に決められない
