# S-M03-23-CONFIG 表示件数既定値

- 機能: M03-23／区分: 設定／共有: 共有可／分類: マスタ

## 状態・属性（シード表の文）

表示件数の設定値=50

## 用途（シード表の文）

初期表示およびエラー後の既定表示件数確認。各ケースが開始時に必要な値を自分で設定する

## 投入方法（シード表の文）

試験環境の設定管理機能で表示件数既定値を50に設定する
