# S-M03-38-QB-BRANCH M03-38連携用の支店

- 機能: M03-38／区分: 店舗／共有: 共有可／分類: マスタ

## 状態・属性（シード表の文）

支店店舗=店舗IDは登録時に画面が振る（控える。以下〔店舗ID-M0338-QB〕）・店舗種別=支店・支店URL=qbbranchpub・公開・開店・支店サイト公開中／この支店で在庫を持つ商品は各ケースが作る商品だけ

## 用途（シード表の文）

支店ECTOPの「SALE中の商品」確認用。各ケースは参照だけを行う

## 投入方法（シード表の文）

店舗登録画面で支店URLに「qbbranchpub」、店舗種別に「支店」、公開に「公開」、開店に「開店」を選び、会社名・店名・住所・電話番号・各メールアドレス・管理者情報などの必須項目に有効な値を入れて登録する。店舗の一覧でその行に表示された店舗IDを控え（〔店舗ID-M0338-QB〕）、支店サイトのTOPが表示されることを確認する。

## 登録するときの注意

- このシードはマスタ（ダンプに入っている）。マスタの登録そのものを試すときは、上の文のとおりに画面から入力する。文にない操作は足さない。
- 画面が振る番号は登録した場所で控える。控える呼び名: 〔店舗ID-M0338-QB〕
- 承認・削除・取込などで状態が変わるシードは、一度使うと元に戻らない。もう一度試すときは同じ内容で登録し直す（商品コードなどが重なって登録できないときは、前のものが残っていないか確かめる）。
