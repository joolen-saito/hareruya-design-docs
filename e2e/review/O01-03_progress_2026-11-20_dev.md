- 対象：テストがまだ無い26件（項目表の仕分けの区分D。003〜007・010〜025・028〜032）。026・027 は流せない一覧の区分E。

## 判断：書かない（26件）
- **全件がアプリの画面の操作**：どのケースも、MTGバイヤーの試験端末のアプリ（デスクトップのアプリ）の画面を操作する手順です。
  - 手順の例：カード名の検索、「登録する」、一覧の行の編集・削除・初期化、「CSV形式で出力する」と出力方法・保存先のフォルダの指定、「査定を中断する」、「ログアウト」、窓を閉じる。
  - 確かめる例：端末の保存先のフォルダに出たファイル（Shift_JIS の明細行・ファイル名の日時）、端末の作業途中データの置き場所。
- **Playwright で操作できない**：Playwright は、ブラウザの画面しか操作できません。試験端末のアプリの画面は操作できず、端末のフォルダも読めません。
- **API に置き換えても確かめられない**：
  - CSV の出力・作業途中データの保存は、端末の中だけの処理で、サーバーの API を呼びません。API へ要求を送っても、ケースが確かめたい「端末が作るファイルの形」「端末の中の置き場所」は確かめられません。
  - 013〜015・031・032 は、端末の操作（査定の中断・ログアウト・窓を閉じる・一覧の初期化・出力）のあとに、管理画面の在庫検索一覧で在庫が変わらないことを確かめます。ただ、肝心の端末の操作を E2E で行えません。在庫を見るだけでは、ケースの意味（端末の操作がサーバーの在庫に触れないこと）を確かめたことになりません。
- **試験端末の準備との関係**：10/23 の依頼者の決定「試験端末は準備できる」（メモリ it-decisions-1023-sitemap-mtgbuyer）は、人が端末で試すための前提です。E2E（Playwright）で流す手段にはなりません。
