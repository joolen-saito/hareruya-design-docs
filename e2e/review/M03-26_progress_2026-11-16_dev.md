# M03-26 — 項目表の不合格の起票のための判定（2026-11-16・開発環境）

項目表で実施者を「齋藤」に変えた行（手元の環境の結果）のうち、開発環境のエビデンスがあって判定が古いままだったものを判定した（依頼者指示 2026-11-16「不具合はバックログに起票して、URLを備考欄に」）。

- 030（一覧のテストID IT-M03-26-028）: 不合格・設計と実装の差異。開発環境（2026-11-11 02:04 の実施）でも、ファイルを選ばずに「CSVファイルをアップロード」を押すとブラウザの入力チェック（「Please select a file.」）が送信を止め、確認モーダルも開かず、取込の要求が送られない。設計書は送信を受けてエラーを出し画面へ戻すと定める（前回の手元の判定と同じ）。
