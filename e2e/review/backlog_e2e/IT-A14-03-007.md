# 期待される挙動【必須】
- 「+」が「/」へ置き換えられ、name_en が Fire-007/Ice のカード情報1件が返る（項目表 IT-A14-03-002）。
- URLデコード後の「%2B」が「+」として解釈されて「/」へ置き換えられ、name_jp が火/氷のカード情報1件が返る（項目表 IT-A14-03-003）。

# 現在の挙動【必須】
- どちらも HTTP 404・本文 {"code":404,"message":"Not Found"}（2026-11-24 開発環境）。
- 原因: 要求の name は PHP が「+」を空白に読み替えて渡す。さらに処理が urldecode を掛けるので、「%2B」から戻った「+」も空白になる。そのあと「+」を「/」へ置き換える処理に「+」が残らず、「Fire-007 Ice」「火 氷」で検索して該当なしになる。

ec-cube-enterprise カード名の読み取り: `ec-cube-enterprise/src/Eccube/Repository/Master/MtbCardRepository.php:906-918`
```php
        $cardNames = explode('/', urldecode($name));
        ...
        foreach ($cardNames as $cardName) {
            $cardName = str_replace('+', '/', $cardName);
```

- ec-cube-enterprise: 上の抜き書き
- ベース実装（pf-api）: `pf-api/src/Repository/MtbCardRepository.php:28-39`（同じ処理。コメントは「%2Bを+にデコード」）
