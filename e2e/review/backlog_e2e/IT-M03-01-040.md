# 再現手順【必須】
1. 開発環境（https://replace-dev.hareruyamtg.com:8443）の管理画面で、商品管理＞商品一覧（商品マスター(検索入力)）を開く
2. IDに、規格を1件持ち、削除を妨げる関連データが無い商品のIDを入力して「検索する >」を押す
3. 検索結果の商品を選択し、一括操作の「削除」（ケースの手順の「完全に削除」）を押す
4. 確認モーダル（「商品を削除してよろしいですか？」）の「削除」（同じく「完全に削除」）を押し、削除処理の完了を待つ
5. 削除の完了後のモーダルと画面を確認する（モーダルは開いたまま「商品の削除処理が完了しました」と「完了」ボタンが出る。「完了」を押すまで画面は再読み込みされない）

# 期待される挙動【必須】
- ケースの期待結果は「モーダルが閉じ、商品マスター(検索結果)画面が再読み込みされること」。設計書の表示メッセージ（M03-01-MSG-004）は、一括削除処理が完了したときに「モーダルを閉じて商品検索・一覧画面を再読み込みする」と定めている。
- 一方で同じ設計書の M03-01-MSG-005 は「完了操作で一覧を再読込する」、MSG-006・008 は「完了操作後に商品一覧へ遷移（再読込）する」と定めており、完了後に利用者が完了操作をするのか、自動でモーダルが閉じて再読み込みされるのかが設計書の中で食い違う。どちらを正とするか設計側で決め、設計書とケースの期待結果をそろえる。
