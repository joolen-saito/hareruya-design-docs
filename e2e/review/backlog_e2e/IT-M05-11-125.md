# 期待される挙動【必須】
- 商品コードのプルダウンには「商品コード/言語/状態/基準価格/(あれば)高額商品コード」を表示する（設計書 6-17-6）。設計書の画面イメージでは、言語・状態は名称でなく略称のコード（例「EOE-BF00355ENNM/EN/NM/¥3000/#1234」の EN・NM）で出る
- 高額商品コードを持つ商品では、基準価格のあとに高額商品コードが続く

# 現在の挙動【必須】
- 「商品コード/日本語/ニアミント/¥1000」と、言語は「日本語」、状態は「ニアミント」の名称で表示される。略称（言語のコード・状態のコード）では出ない。
- ベース実装のプルダウンは商品コードだけを表示しており、「言語/状態/基準価格/高額商品コード」はこの案件で新しく追加する項目（現行に該当なし）。
- 同じ表示の確認で、高額商品コードを持つはずの商品（IT-M05-11-092）では高額商品コードが出なかったが、シードで高額商品コードが設定済みかを確かめられていないため、この起票には含めない。
