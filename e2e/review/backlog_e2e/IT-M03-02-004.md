# 期待される挙動【必須】
- ケースの期待結果は「商品公開ステータス欄が表示されないこと」。商品編集画面が開き（応答200）、そのうえで商品公開ステータスの欄だけが出ないこと。

- 設計書の Excel 由来の部分（処理概要「商品公開ステータスについて」・機能仕様処理概要）には、規格が0件のときの定めは無い。上の定めは現行仕様の節にだけあり、Excel 由来の部分と食い違う記述も見当たらない（設計書の中の優先順位は Excel 由来＞表示メッセージの節＞現行仕様の節。2026-10-16 決定）。

# 現在の挙動【必須】
- 商品編集画面が開かず、応答は404「お探しのページが見つかりません。」になる（応答 期待200／実際404、画面のフォームなし）。公開ステータスの欄を隠す以前に、画面が出ない。
- 原因は、編集画面が商品を取り出す検索が商品規格を内部結合し、廃止の規格を除いていること。廃止でない規格が1件も無い商品は検索結果が空（null）になり、編集の処理が見つからない扱いで404を投げる。
- 規格が0件の商品で公開ステータスの欄を隠す処理は、新しいアプリに見当たらない（画面の部品は、商品自体の公開ステータスが廃止のときだけ欄と登録ボタンを隠す。規格の件数では隠さない）。

- 「廃止の規格だけの商品」と「本当に規格が0件の商品」の扱い: 検索の条件は「規格を内部結合し、廃止でない規格だけ」なので、どちらも検索結果が空になり同じ経路で404になる（ソースの読みで確かめた）。シードの代え方（唯一の規格を廃止にして表示を外す）は結果に効いていないと見る。ただし本当に規格が0件の商品の編集画面を開いての確認はしていない（行を消すシードは作らない決まりのため）。

- ベース実装（pf-eccube3）は、編集画面の商品を規格の結合なしの主キー検索で取り出し、規格が無くても見つからない扱いにはしない（`pf-eccube3/src/Eccube/Controller/Admin/Product/ProductController.php:268-272`）。規格が0件の商品は、規格なし商品の分岐（同 273-282）で規格の先頭要素（無い）を参照し、画面を出さずに実行時エラーになる見込み（ソースの読み。実機では確かめていない）。つまり現行でも、規格0件の商品の編集画面が設計書の言う「欄だけ隠して開く」動きにはならない。画面の部品に、規格の件数で公開ステータスの欄を隠す条件も無い（`pf-eccube3/src/Eccube/Resource/template/admin/Product/product.twig:386-387`）。

# 根拠
- 設計：
  - 現行仕様（商品編集画面を表示する）: 商品付加情報が無い場合のみ404。商品規格が1件も登録されていない商品では商品公開ステータスの欄を表示しない: `hareruya-design-docs/excel_to_html/output/0204_基本設計仕様書(商品管理).html:1631`
  - Excel 由来（処理概要「商品公開ステータスについて」）: 公開ステータスが廃止のあと編集できない・本店と支店の2種類。規格0件のときの定めは無い: `hareruya-design-docs/excel_to_html/output/0204_基本設計仕様書(商品管理).html:1540・1556`
- ec-cube-enterprise：
  - 編集画面の商品の検索が規格を内部結合し廃止の規格を除く: `ec-cube-enterprise/src/Eccube/Repository/ProductRepository.php:94-107`
  - 検索結果が空なら404: `ec-cube-enterprise/src/Eccube/Controller/Admin/Product/ProductController.php:381-386`
  - 公開ステータスの欄を隠す条件は商品の公開ステータスが廃止のときだけ: `ec-cube-enterprise/src/Eccube/Resource/template/admin/Product/product.twig:831`
- ベース実装：
  - 規格の結合なしで商品を取り出し404にしない。規格0件では規格なし商品の分岐で先頭の規格を参照する（画面は出ない見込み）: `pf-eccube3/src/Eccube/Controller/Admin/Product/ProductController.php:268-282`
  - 探した範囲: pf-eccube3 の ProductController（edit）・商品編集の画面部品・Product エンティティ（hasProductClass）。規格0件で公開ステータスの欄を隠す記述は無い
