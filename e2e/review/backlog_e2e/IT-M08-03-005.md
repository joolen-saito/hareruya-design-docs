# 現在の挙動【必須】
- CSVの会員の行は、第26項目が「弁護士/Lawyer」、第36〜38項目が「27」「1」「1」（期待どおり）。ケースの確かめは第26項目で落ちる（会員の行が見つかることなど、ほかの確かめは合格）。出力項目の並びは設計書の識別ID順で設定してあり、並びのずれではない。
