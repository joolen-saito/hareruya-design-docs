# 期待される挙動【必須】
- 項目表のケースの期待結果は、手順3で一覧の行頭チェックボックスを選び、手順4で送り状CSVダウンロードを押して「選択した在庫移動指示の送り状CSVが1ファイルダウンロードされること」（項目表 IT-M04-28-001）。そのためには、手順2 の検索が実行されて対象の行が一覧に出る必要がある。
- 設計書の在庫移動指示検索の画面項目定義は、出庫元店舗（識別ID 2-1・初期値は「ユーザーのデフォルト検索店舗」）と入庫先店舗（識別ID 2-2・初期値は「未選択」）を、どちらも必須（○）としている。検索ボタン（識別ID 2-8）は識別ID 2-1〜2-7 の値を使って検索する。したがって、入庫先店舗が未選択のまま検索を実行できないことは設計どおりで、画面の挙動に不具合は無い。
- 食い違いはケースの手順にある。項目表の IT-M04-28-001・002・003・004・005・007 の手順2 は「移動指示IDに〔…〕を入力して「検索する」を押す」だけで、必須の入庫先店舗を選ぶ操作が無い（同じ機能の IT-M04-28-006 の手順2 は「出庫元店舗に「東京店」、入庫先店舗に「大阪店」を選択して「検索する」を押す」と書いてあり、そちらは検索できる）。この6件の手順2 に、IT-M04-28-006 と同じ型で「出庫元店舗に「東京店」、入庫先店舗に「大阪店」を選択し、移動指示IDに〔…〕を入力して「検索する」を押す」と店舗の選択を足す案（事前準備のとおり、移動元店舗が東京店、移動先店舗が大阪店）。
