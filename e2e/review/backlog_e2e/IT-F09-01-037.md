# 再現手順【必須】
1. 検索対象かつランキング表示の対象のフォーマットに、公開の大会デッキ（開催日が集計期間内）を登録しておく（ケースのシード S-F09-01-CARRYHEAD-037）
2. スマートフォンの画面幅（幅 390px・iPhone の利用者エージェント）で、日本語表示のブラウザを新しく開き、開発環境（https://replace-dev.hareruyamtg.com:8443）のデッキ検索TOP画面（/ja/deck/）を開く
3. 「<フォーマット名>メタゲーム」の区画の見出し（フォーマット名の文字）を押す
4. 60秒待っても画面が移らず、アドレスが /ja/deck/ のままであることを確認する

# 期待される挙動【必須】
- ケースの期待結果（項目表 IT-F09-01-034。E2E のテストID IT-F09-01-037）は、そのフォーマットのメタゲーム一覧（/ja/deck/<フォーマットID>/metagame/）が開くこと。
- 設計書（0309 F09-01 業務ロジック「画面から引き継ぐ検索条件」）は、遷移元「フォーマット名の見出し」から遷移先「メタゲーム一覧」へフォーマットIDを引き継ぐと定める。
- 現行（ベース実装）は、見出しの中のリンクを、スマートフォン幅（767px 以下）では見出し全体を覆う形で表示し、見出しを押せばメタゲーム一覧へ移る。

# 現在の挙動【必須】
- 見出しを押しても画面は移らず、/ja/deck/ のまま（2026-11-18 開発環境で確認）。見出しの文字は表示されているが、押せるリンクが付いていない。
- 新アプリは、見出しの中のリンクの表示指定が「表示しない」だけで、スマートフォン幅で見出し全体を覆う指定が無い。見出し自体にも押下の処理は無い。
- 開発環境のデータの都合ではない（シードのフォーマットの区画・見出しは表示され、リンクの先のアドレスも作られている）。
- 同じ画面の「4位以下を見る」などのボタンからはメタゲーム一覧へ行けるため、迂回はできる（確かめたのは見出しの導線のみ）。
