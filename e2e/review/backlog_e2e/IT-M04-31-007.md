# 期待される挙動【必須】

# 現在の挙動【必須】
- 手順3の検索で、「棚卸計画データがありません。」の見出しは出て、一覧の行・ページングは出ない。ただし検索ボタンの右に「検索結果 0 件が該当しました」が出る（期待は該当件数が出ない。実施は 2026-11-13、開発環境）。ケースの確かめ4項目のうち、見出しが出る・一覧が出ない・ページングが出ないは期待どおりで、不合格は該当件数だけ。
- アプリは、検索を実行していれば（初期表示を除き）一覧の件数に関わらず該当件数を出す作りで、0件のときの見出しは別の分岐で出している。件数の文言のメッセージキーは「一覧に計画があるとき」の文言（「検索結果 %count% 件が該当しました」）のまま、0件でも使われる。
- 前提の補い：ケースの前提は「全棚卸計画が0件」だが、棚卸計画を削除する画面が無く作れていない。ケースが見る試験支店（依頼者決定 2026-11-13 で、シード表の「店舗A」を試験支店 店舗ID 1574 に読み替えた）・EC-CUBE の棚卸計画が0件であることを画面で確かめて流した。上のとおり件数の表示は検索結果の件数や登録された全件数に依らず検索すれば出る作りなので、この補いは不合格の結論に影響しない（前回までの流しも同じ落ち方）。

# 関連
- 結合テスト：結合試験項目表「テストケース」シート IT-M04-31-006（E2E のテストID IT-M04-31-007）。E2E（Playwright）で開発環境にて実施（2026-11-13）。依頼者決定（2026-11-13）で試験店舗は試験支店（店舗ID 1574）と本店に読み替えた条件付きの結果。この読み替えは件数の表示の分岐に関わらない。
- 完了済みの同じ型の課題（開け直さず、この課題で扱う）：ECCUBE_HARERUYA-3025（完了。ネット買取管理の買取一覧で、0件のときも「検索結果：0件が該当しました」が出たうえで該当データなしのメッセージが出る件。要求元は現行踏襲で Excel に同じ文言が無く、2026-09-03 に不具合解析結果「現行踏襲不要」・「実害がないため対応しない」で完了）。この課題は、リニューアル後の仕様の表示メッセージ節が0件のとき件数を出さない読み方になる点が違う。
- 逆向きの課題（参考）：ECCUBE_HARERUYA-3766（完了。在庫検索一覧は、Excel の識別ID 4-2「検索処理実行後の件数を表示する」により、0件でも「検索結果：0件が該当しました」を出す仕様）。画面ごとに設計書の定めが違う。
- 決め方の案：棚卸計画一覧は、表示メッセージ節（リニューアル後の仕様）と現行仕様が同じ向きなので、まず「0件のときは見出しだけ」を正とし、0件のときは件数を出さないように直す案。3025 と同じく「実害が無く対応しない」とする場合は、設計書の表示メッセージ節の「検索結果 N 件 が該当しました」の表示条件に「0件のときも出す」と書き足し、ケースの期待結果を合わせる。
