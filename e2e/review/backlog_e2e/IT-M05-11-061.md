# 再現手順【必須】
1. 姓・名・ふりがな・会社名・海外用郵便番号がいずれも50文字未満の受注を用意する
2. 開発環境（https://replace-dev.admin.hareruyamtg.com:8443）の管理画面で、その受注の受注情報編集画面（/admin/order/<受注ID>/edit）を開く
3. 注文者とお届け先の姓・名・ふりがな、注文者の会社名に全角「あ」を50文字、注文者とお届け先の海外用郵便番号に「1」を50文字入れて「受注情報を登録」を押す
4. 画面の入力エラーを確認する

# 期待される挙動【必須】
- 設計書の画面項目定義では、お名前（姓）（名）は16文字、お名前ふりがな（姓）（名）は25文字、会社名は255文字、海外用郵便番号は100文字が最大。50文字の姓・名・ふりがなは設計書の最大を超えるため、保存できないのが設計どおり
- ケース（50文字で保存される期待）は、同じ項目を最大文字数の16文字・25文字で保存する別のケース（IT-M05-11-112・IT-M05-11-114）と食い違う。ケースの文字数を設計書に合わせて直す

# 現在の挙動【必須】
- 姓・名は「長すぎます。この値は16文字以下で入力してください。」、ふりがなは「長すぎます。この値は25文字以下で入力してください。」と出て保存できない。これは設計書の最大（16・25文字）どおりの動き。
- 新アプリの注文者情報の姓・名・ふりがなの上限は、設計書の値に合わせた専用の設定（16・25）を使っている。ベース実装も姓・名16文字・ふりがな25文字。
