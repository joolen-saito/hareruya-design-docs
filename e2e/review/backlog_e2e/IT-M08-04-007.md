# 期待される挙動【必須】
- 設計書の画面項目定義では、顧客グループ（識別ID 30）の必須は「-」（必須でない）。項目表どおりなら、ほかの任意項目と同じく空で保存できる
- ベース実装も顧客グループを空にできないため、項目表（必須でない）と現行（必須）のどちらを正とするかの確認が要る

# 現在の挙動【必須】
- 顧客グループの選択肢に空（未選択）が無く、空にできない。登録すると「保存しました」になり、ほかの任意項目は空で保存されるが、顧客グループは「標準顧客」のまま残る。
- アプリの顧客グループは必須で、空の選択肢を持たない。ベース実装も必須・空の選択肢なし（placeholder なし）で、同じく空にできない。
