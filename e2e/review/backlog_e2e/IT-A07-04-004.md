# 現在の挙動【必須】
- HTTP 401 で、本文は {"code":401,"errors":["認証エラー"]}（2026-11-19 開発環境）。
- 新しいアプリは、MTGバイヤー向けの API の認証の失敗を UnauthenticatedException（既定の文言「認証エラー」）で投げ、共通の例外の受け口が code と errors の JSON を組み立てて返す。同じコントローラの他の API や、店頭買取管理（BuyingController）の API も同じ作り。
