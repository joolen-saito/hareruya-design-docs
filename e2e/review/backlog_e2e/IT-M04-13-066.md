# 期待される挙動【必須】
- ケースの期待結果（項目表 IT-M04-13-059。E2E のテストID IT-M04-13-066）は「欠品点数1000000では欠品登録ボタンが押下可能となり、1000001では押下可能にならないこと」。
- 設計書の画面項目 7-18 欠品点数は「数値（整数）・最大値 1～1000000」で、「結合元在庫数よりも大きい数を登録した場合はエラーとする」と定める。
- したがって、1000000 までは登録でき、1000001 は上限を超えるため欠品登録ボタンが押せない（登録できない）。

# 現在の挙動【必須】
- 1000000 では欠品登録ボタンが押せる（期待どおり）。1000001 でも欠品登録ボタンが押せる（実施は 2026-11-13、開発環境）。
- 画面もサーバー側も、確かめるのは「1以上で、結合元在庫数より小さい」ことだけで、設計書の上限 1000000 の確認が無い。結合元在庫数が1000002の商品では、1000001 が通る。
- 在庫移動の移動点数は、同じ上限 1000000 の確認が入っている（ECCUBE_HARERUYA-2660。完了）。
