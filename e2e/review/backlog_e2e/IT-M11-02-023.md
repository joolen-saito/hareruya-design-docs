# 再現手順【必須】
1. 開発環境（https://replace-dev.hareruyamtg.com:8443）の管理画面でシステム設定＞メンバー管理を開き、新規登録状態にする

3. 登録ボタンを押す（ログインID・パスワード・パスワード(確認)に「値が長すぎます。50文字以内でなければなりません。」が出て保存されない。名前とメールアドレスは255文字で受け付けられている）

# 期待される挙動【必須】
- ケースの期待結果は「名前・ログインID・メールアドレスが255文字で保存される」（出典は項目の最大文字数の旧い集計値255）。
- 設計書の画面項目定義は、ログインID（識別ID 1-4）とパスワード（1-6）・パスワード(確認)（1-7）の最大を50文字、名前（1-1）とメールアドレス（1-5）を255文字と定める。実装の50文字は設計書どおりで、ケースの期待が設計書と合っていない。

# 現在の挙動【必須】
- ログインIDとパスワードの最大文字数は50文字で、255文字では保存できない（設計書どおり）。

ec-cube-enterprise メンバーのログインIDの長さ検証: `ec-cube-enterprise/src/Eccube/Form/Type/Admin/MemberType.php:201-206`
```php
                    new Length([
                        'min' => $this->eccubeConfig['eccube_id_min_len'],
                        'max' => $this->eccubeConfig['eccube_id_max_len'],
                        'minMessage' => 'form_error.member.too_short',
                        'maxMessage' => 'form_error.member.too_long',
                    ]),
```

ec-cube-enterprise 設定値: `ec-cube-enterprise/app/config/eccube/packages/eccube.yaml:116-117,226-227`
```yaml
    eccube_id_max_len: 50
    eccube_id_min_len: 4
    eccube_password_min_len: 12
    eccube_password_max_len: 50
```

- ベース実装も、ログインID・パスワードの最大を設定値 id_max_len（50文字）にしている。

ベース実装 pf-eccube3 メンバーの長さ検証: `pf-eccube3/src/Eccube/Form/Type/Admin/MemberType.php:66-69`
```php
                    new Assert\Length(array(
                        'min' => $this->config['id_min_len'],
                        'max' => $this->config['id_max_len'],
                    )),
```
