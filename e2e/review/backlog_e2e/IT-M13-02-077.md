分類：イベント管理
機能：イベント編集 / イベント削除

課題：【実装乖離】イベント管理_イベント編集_デッキ登録または申込のある日程の行メニューに「削除」が出ず、設計書の「押して削除できない旨のメッセージを出す」流れにならない
設計書：0214_基本設計仕様書(イベント管理).xlsx

# 再現手順【必須】
1. 開発環境（https://replace-dev.hareruyamtg.com:8443）の管理画面で、デッキ登録のある日程（または申込のある日程）を持つ、編集権限のある店舗のイベントのイベント編集画面を開く
2. 日程一覧の該当行の右端の「…」（編集ボタン）を押してポップアップメニューを開く
3. メニューには「編集」しか無く、「削除」が出ない

# 期待される挙動【必須】
- ポップアップメニューの選択肢は「編集」「削除」で、削除は権限を保持している店舗のイベントのみ表示する（設計書の項目 4-8）
- デッキ登録済み・申込済みの日程を削除しようとしたときは、削除できない旨のメッセージ（「デッキ登録済みの場合、イベント情報を削除することができません。」「申込済みの場合、イベント情報を削除することができません。」）を表示して拒否する

# 現在の挙動【必須】
- 編集権限があり、かつデッキ・申込が無い日程のときだけ「削除」を出す。デッキ登録・申込のある日程の行メニューは「編集」だけになる。

# 根拠
- 設計：
  - 4-8 編集ボタン: ポップアップメニュー（選択肢 編集・削除）。削除はメンバーが権限を保持している店舗のイベントのみ表示: `hareruya-design-docs/excel_to_html/output/0214_基本設計仕様書(イベント管理).html:1485`
  - 表示メッセージ「デッキ登録済みの場合、イベント情報を削除することができません。」「申込済みの場合、イベント情報を削除することができません。」: `hareruya-design-docs/excel_to_html/output/0214_基本設計仕様書(イベント管理).html:1528`
- ec-cube-enterprise：
  - 削除メニューを条件付きで非表示: `ec-cube-enterprise/src/Eccube/Resource/template/admin/Event/edit.twig:438-448`
- ベース実装：
  - 削除メニューは常時表示・サーバーが拒否: `pf-eccube3/app/Plugin/HareruyaEc/Resource/template/admin/Event/eventdetail.twig:238-245`, `pf-eccube3/app/Plugin/HareruyaEc/Controller/Admin/EventController.php:208-224`
