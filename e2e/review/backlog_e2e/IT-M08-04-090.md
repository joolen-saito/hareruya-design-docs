# 再現手順【必須】
1. 姓「更新前」・名「太郎」（カナ「コウシンマエ」「タロウ」）の本会員と、その会員の買取（買取状況「注文」）を1件用意する
2. 開発環境（https://replace-dev.admin.hareruyamtg.com:8443）の管理画面で、買取検索一覧から買取番号で検索し、その買取の買取情報編集画面（/admin/purchase/<買取番号>/edit）で買取依頼者氏名・氏名カナを確認する
3. 会員の会員登録/編集画面で、お名前を「更新後」「次郎」、お名前（カナ）を「コウシンゴ」「ジロウ」に変えて登録する（「保存しました」）
4. 手順2と同じ買取情報編集画面を開き直し、買取依頼者氏名・氏名カナを確認する

# 期待される挙動【必須】
- 買取情報編集の買取依頼者氏名・氏名カナは「当該会員の氏名（漢字）・氏名（カナ）を表示」（0206 買取情報編集 画面項目定義 識別ID 4・5）。ケースはこれを、会員の氏名を変えたら買取の画面にも変更後の氏名が出ると読んでいる
- ベース実装は買取に写した氏名を表示しており、「当該会員の氏名」が会員の今の氏名なのか、買取の依頼時に写した氏名なのかの確認が要る

# 現在の挙動【必須】
- 手順4でも買取依頼者氏名は「更新前 太郎」、氏名カナは「コウシンマエ タロウ」のままで、会員の変更後の氏名は出ない（画面下部の買取依頼者情報の氏名も同じ）。
- 買取情報編集は、会員でなく買取の情報に持つ氏名・氏名カナを表示している。ベース実装も同じく買取の情報に持つ氏名を表示する。
- 補足: E2E では買取を画面で作れないため、シードの買取は DB で会員に足しており、買取の氏名にはその時点の会員の氏名を入れている。
