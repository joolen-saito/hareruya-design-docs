# 再現手順【必須】
1. 開発環境（https://replace-dev.hareruyamtg.com:8443）の管理画面でカード新規登録画面 /admin/card/new を開く
2. 「詳細情報を追加」で詳細情報を3件追加する
3. 追加した各詳細情報の入力欄を確認する（コレクターNo・裏面カード詳細ID・ルールテキスト・パワー・タフネス・フレーバーテキスト・カードセット・レアリティ・レイアウト・イラストレーター・プロモ種別・Foil・フレームは出るが、「カードの言語」「表示面」は出ない）

# 期待される挙動【必須】
- テストケースは、追加した3件の詳細情報にカードの言語（日本語・英語・中国語簡体字）を設定して保存できることを期待している
- 設計書では、カードの言語（識別ID 2-22）と表示面（2-23）は「カード詳細(編集・削除)」のレイアウトにあり、「カード詳細(登録)」のレイアウト（2-1〜2-18）には無い。新規登録でも言語を設定できるべきか、設計書とケースのどちらを正とするかを確定する必要がある

# 現在の挙動【必須】

# 根拠
- 設計：
  - Excel 編集・削除のレイアウトの項目 2-22 カードの言語（単一選択）・2-23 表示面: `hareruya-design-docs/excel_to_html/output/0208_基本設計仕様書(カード管理).html:1620-1621`
  - Excel カスタマイズ要件「画像アップロード機能は廃止する（画像はS3にアップロードし、カードと紐づける）」: `hareruya-design-docs/excel_to_html/output/0208_基本設計仕様書(カード管理).html:1590`
  - 登録のレイアウトの詳細情報は 2-1〜2-18 で、2-22 を含まない: `hareruya-design-docs/excel_to_html/output/0208_基本設計仕様書(カード管理).html:1425-1442`
- ec-cube-enterprise：
  - 言語は画像情報の中で、保存済みの詳細情報にだけ出る: `ec-cube-enterprise/src/Eccube/Resource/template/admin/Card/detail_row.twig:5-23`
  - 追加した詳細情報は show_images=false: `ec-cube-enterprise/src/Eccube/Resource/template/admin/Card/edit.twig:199-204`
- ベース実装：
  - 追加した詳細情報にも画像追加・言語の欄がある: `pf-eccube3/app/Plugin/HareruyaEc/Resource/template/admin/Card/card_detail.twig:430-446`
  - 探した範囲: pf-eccube3 の Card/card_detail.twig・assets/js/card-detail.js
- 補足: ケースの期待（新規登録で言語を設定して保存）は設計書のレイアウトに無い操作のため、ケース側の見直しを依頼する。表示面（2-23）も同じ。
