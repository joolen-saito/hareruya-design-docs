課題：【要確認】商品管理_部門登録_一覧の部門コードから編集モードを開けない。設計書の中で、一覧のID・部門名・部門コードの扱いが「ラベル」（Excel由来の画面項目定義）と「押すと編集モードになる導線」（現行仕様の節）で食い違い、新アプリはIDと部門名だけがリンクでどちらとも一致しない

# 再現手順【必須】
1. 開発環境（https://replace-dev.hareruyamtg.com:8443）の管理画面で、商品管理＞部門登録/編集を開く（ケースでは部門名「編集前部門-004」・部門コード63の部門を使う）
2. 一覧のその部門のIDを押し、編集モードの入力値を確認する
3. 部門登録/編集画面を開き直し、一覧のその部門の部門名を押して、編集モードの入力値を確認する
4. 部門登録/編集画面を開き直し、一覧のその部門の部門コード（63）を押そうとする（項目表 IT-M03-18-004）

# 期待される挙動【必須】
- ケースの期待結果（項目表 IT-M03-18-004）は「ID、部門名、部門コードの各導線から ID の値を入力した編集モードになること」。出典は設計書の現行仕様の節 業務ロジック 画面の構成の「一覧の ID・部門名・部門コードは、押すと当該部門の編集モードになる導線である。」
- 一方、Excel 由来の画面項目定義は、一覧の識別ID 8「ID」・9「部門名」・10「部門コード」の3つとも種類を「ラベル」とし、編集モードへ移る導線は識別ID 13「編集ボタン」（クリックすると編集モードになり、選択した部門が登録フォームに入力された状態となる）だけとしている。同じ設計書で、押すと画面が移る一覧の項目には種類「リンク」が使われている（商品一覧の識別ID 16「商品名」は「リンク押下時、商品詳細/編集画面へ遷移する」）。レイアウト図の一覧の3列も、リンクの見た目でなく文字だけで、操作の列は「編集」「削除」のボタンだけが描かれている。
- つまり同じ設計書の中で、一覧の3列が「ラベル（導線は編集ボタンだけ）」と「押すと編集モードになる導線」に分かれている。設計書の中の優先順位（Excel由来＞表示メッセージの節＞現行仕様の節。2026-10-16 決定）では Excel 由来の部分が先に立つので、現行仕様の節の記述を Excel 由来に合わせて直す（ケースの期待結果も「編集ボタンから編集モードになること」へ寄せる）案と、現行仕様のとおり3列を導線にするなら Excel 由来の画面項目定義の種類を「リンク」に直す案のどちらかに決める。

# 現在の挙動【必須】
- 手順2（IDを押す）は、アドレスが部門の編集のものに変わり、見出し「編集」・部門名「編集前部門-004」・部門コード63・免税区分「対象外」・MTGBuyer表示フラグONの入力欄が開く。手順3（部門名を押す）も同じ編集モードが開く。
- 手順4 の部門コードは、一覧の文字が青いリンクでなく黒い文字で、押しても編集モードへ移らない（キャプチャの一覧は、IDと部門名が青、部門コードの「0」が黒）。ケースの期待結果は、3つの導線のうち部門コードの導線で落ちる。
- 新しい画面は、ID と部門名だけをリンクにし、部門コードはリンクにしていない。Excel 由来の画面項目定義（3列ともラベル）とも、現行仕様の節（3列とも導線）とも一致しない中間の作りになっている。ベース実装（pf-eccube3）は3列とも編集モードへのリンク。
