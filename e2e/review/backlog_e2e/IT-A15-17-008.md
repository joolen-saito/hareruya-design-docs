# 確認したいこと
- 設計書の中で食い違っている。A15-17 の入出力は「解読できない行があるときは HTTP 206」とし、同じ A15-17 の業務ロジック・A15-18 の記述は「処理結果コードを 206 に切り替える」（HTTP は 200。A15-18 の出力は「HTTP 200。処理結果コード…」）としている。どちらが正かを決め、設計書とケースの期待結果を合わせてほしい（現行どおり HTTP 200・本文のコードのみ 206 なら、ケースの期待結果を直す）。
