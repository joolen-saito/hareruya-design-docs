# 再現手順【必須】
1. 開発環境（https://replace-dev.hareruyamtg.com:8443）の管理画面でカード管理＞カード一覧を開き、「詳細検索」を開く
2. 「イラストレーター」の入力欄に、マスターに登録済みの日本語名（例：試験イラストレーター。英語名は M1401 Test Illustrator）を入力する
3. 候補の一覧を確認する（候補は「No results found」になり、日本語名に一致する候補が出ない）
4. 同じ画面で、カードタイプ・サブタイプ・特殊タイプ・カードセット・使用可能フォーマット・プロモ種別の各入力欄に、登録済みの日本語名を入れると、日本語名の候補が出る

# 期待される挙動【必須】
- 11 カードタイプ・12 サブタイプ・13 特殊タイプ・14 カードセット・15 使用可能フォーマット・18 イラストレーター・19 プロモ種別（いずれも複数選択）: 名称入力のサジェスト機能あり
