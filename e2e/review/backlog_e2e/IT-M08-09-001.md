# 期待される挙動【必須】
- 一覧の国内の配送先は、郵便番号が3桁と4桁のあいだをハイフンでつないだ「100-0001」の形で出る。
- 設計書（0207 配送先編集 カスタマイズ説明）は、カスタマイズ要件（海外住所用に3カラム目を追加）に記載の内容以外は現行踏襲とする。一覧の表示項目は現行仕様の業務ロジック（配送先一覧）が定める。現行のアプリは、国内の郵便番号を3桁と4桁のあいだにハイフンを入れて出す。

# 現在の挙動【必須】
- 一覧の「国内配送先-001」の行は、住所の列が「〒1000001 東京都千代田区千代田1-1国内住所3」と出る。郵便番号は「〒」が付き、3桁と4桁のあいだのハイフンが無い（「100-0001」を含まない）。東京都・千代田区千代田・1-1・国内住所3・配送先氏名・氏名カナ・会社名は期待どおりに出る。
- 原因は、一覧の画面が郵便番号を保存された7桁の値のまま「〒」に続けて出していること。ベース実装（pf-eccube3）は、郵便番号の上3桁と下4桁のあいだにハイフンを入れて「100-0001」の形で出す。
- 電話番号は「0312345678」とハイフンなしで出る（項目表 IT-M08-09-001 の期待は「03-1234-5678」）。ベース実装も電話番号は区切りなしで出し（3つの欄を連結）、設計書にも形の定めが無いため、この部分は差異ではなく、ケースの期待の出典の問題として「関連」に書く。
