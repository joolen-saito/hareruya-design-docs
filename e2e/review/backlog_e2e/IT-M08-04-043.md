# 現在の挙動【必須】
- リンク先（/admin/order/<受注ID>/edit）が「404 Page Not Found」になり、受注編集画面が開かない（HTTPステータス 404）。
- 受注編集画面は、指定した受注が存在しないときに404にする。シードで作った受注の状態（受注ステータスなど）で見つからないのか、実装の問題なのか、データベースを読める方に切り分けてもらう必要がある（影響 1ケース、M08-04）。

