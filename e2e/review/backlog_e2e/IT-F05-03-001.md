# 期待される挙動【必須】

# 現在の挙動【必須】
- 商品が60件並び、商品数の表示とページ送り（上部・下部で12項目）が出る（全件検索の結果が表示される）。
- サーバーは条件が無いとき空のクエリを画面に渡すが、画面のスクリプトはクエリが空だと検索フォームの値を送り直してクエリを取り直す。検索フォームには色・カードタイプの AND/OR 指定の隠し項目（既定値 0）が常に含まれ、条件の有無の判定はこれを「条件あり」と数えるため、全件のクエリが返って一覧が出るとみられる。ベース実装は、クエリが空なら検索せずに検索フォームだけの画面を返していた。
