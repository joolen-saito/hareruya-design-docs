# 再現手順【必須】
1. 開発環境（https://replace-dev.hareruyamtg.com:8443）の管理画面でシステム設定＞メンバー管理を開き、新規登録状態にする
2. 名前・所属店舗・所属・ログインID・メールアドレス・権限・デフォルト検索表示店舗を入力し、パスワードとパスワード(確認)に英字・数字・記号を含む9文字の値を入力する
3. 登録ボタンを押す（同じ画面のまま、パスワードとパスワード(確認)の両方に「値が短すぎます。12文字以上でなければなりません。」が出て保存されない）

# 期待される挙動【必須】
- 設計書（現行仕様・入力の検証）は「ログインIDとパスワードは、4文字未満だと保存しない」と定めており、4文字以上であれば保存できる
- 設計書（機能仕様・入力制限について）は「EC-CUBEエンタプライズ、現行の項目は各システムの入力制限に準拠する」とだけ定め、最低文字数の数値は画面項目定義（パスワードは最大50文字）に無い。この二つの記述のどちらを正とするかが決まっていない

# 現在の挙動【必須】
- パスワードの最低文字数は12文字で、4〜11文字のパスワードは保存できない。

ec-cube-enterprise メンバーのパスワードの長さ検証: `ec-cube-enterprise/src/Eccube/Form/Type/Admin/MemberType.php:87-96`
```php
            ->add('plain_password', RepeatedPasswordType::class, [
                'invalid_message' => 'form_error.member.password_not_match',
                'options' => [
                    'constraints' => [
                        new Length([
                            'min' => $this->eccubeConfig['eccube_password_min_len'],
                            'max' => $this->eccubeConfig['eccube_password_max_len'],
                            'minMessage' => 'form_error.member.too_short',
                            'maxMessage' => 'form_error.member.too_long',
                        ]),
```

ec-cube-enterprise 最低文字数の設定値: `ec-cube-enterprise/app/config/eccube/packages/eccube.yaml:226-227`
```yaml
    eccube_password_min_len: 12
    eccube_password_max_len: 50
```

- ベース実装は、パスワードの最低文字数をログインIDと同じ4文字（設定値 id_min_len）にしている。

ベース実装 pf-eccube3 メンバーのパスワードの長さ検証: `pf-eccube3/src/Eccube/Form/Type/Admin/MemberType.php:82-85`
```php
                    new Assert\Length(array(
                        'min' => $this->config['id_min_len'],
                        'max' => $this->config['id_max_len'],
                    )),
```
