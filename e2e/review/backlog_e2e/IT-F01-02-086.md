# 根拠
- 設計：
  - カード状態IDが同じ商品規格は、言語が違ってもすべて載せる（SALE中の商品のカードの状態）: `hareruya-design-docs/excel_to_html/output/0301_基本設計仕様書(フロント_トップ).html:2677`
- ec-cube-enterprise：
  - 取得時に規格の言語を表示中の言語に絞る: `ec-cube-enterprise/src/Eccube/Repository/ProductRepository.php:424`
- ベース実装：
  - 言語で絞らず、同一商品に状態が小さい規格が無ければ載せる: `ec-cube/app/Customize/Repository/ProductClassRepository.php:147-159`
  - 探した範囲: ec-cube（支店）の Customize/Repository/ProductClassRepository.php の getSaleProductClasses。タグ系タイルの言語の絞り込み（設計書 条件6）との関係で、SALE中だけ言語で絞らない仕様かは要確認
  - 補足: 開発環境でこの商品のシードを作るとき、支店の登録で一度システムエラーの画面になった（登録自体は行われた）。表示の結果には影響していないが、別途確認が要る
