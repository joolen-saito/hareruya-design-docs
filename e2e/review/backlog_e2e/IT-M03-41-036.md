# 現在の挙動【必須】
- 手順2で押すと取込の要求は送られ（応答は302）、取込は打ち切られ、画面は同じアップロード画面のまま。画面上部の赤い帯に「カテゴリ名(日)(カテゴリ名(日)) は必須項目です。 3 行目のデータを確認してください。」が出る。行番号は見出し行を含めた3行目で期待どおり。一方、アップロードのフォームの下にエラーは1件も並ばない（エラー一覧は空）。ケースの判定項目のうち、不合格は「フォームの下のエラー一覧にエラーが示される」だけで、取込の要求が送られたことは合格。
- 手順4も同じで、画面上部の帯に「親カテゴリID(親カテゴリID) は必須項目です。 2 行目のデータを確認してください。」が出て、フォームの下は空（項目表 IT-M03-41-049 の判定項目のうち、画面に留まること・DBに追加されないこと・ほか1項目は期待どおり）。
- 原因は、カテゴリ登録CSVの取込が、取込結果のエラーを全部「管理画面上部」のメッセージへ積んで画面を作り直す作りで、フォームの下に並べるエラー一覧の値を画面へ渡していないこと。共通のアップロード画面のテンプレートにあるエラー一覧は、フォームの下ではなくフォームの上の帯で、この画面は値を渡さないので出ない。
- ベース実装（pf-eccube3）は、取込のエラーを一覧に溜めて画面へ渡し、ファイル選択欄のすぐ下に1件ずつ並べる。設計書の「アップロードフォーム下のエラー一覧」はこの作りに当たる。
