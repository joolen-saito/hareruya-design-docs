# 再現手順【必須】
1. 開発環境（https://replace-dev.admin.hareruyamtg.com:8443）の管理画面でイベント新規申込登録画面を開く（対象の日程を指定する）
2. プレイヤー検索で対象のプレイヤーを検索し、決定を押す
3. 「登録」を押す
4. 登録後に表示された画面を確認する

# 期待される挙動【必須】
- 設計書は、登録後の遷移先を「イベント申込検索画面」とする記載（表示メッセージ M13-12-MSG-002）と、「登録した申込の編集画面へ移る」とする記載の両方がある。どちらを正とするか決める

# 現在の挙動【必須】
- 登録後は、登録した申込の編集画面（/admin/event/entry/<申込ID>/edit）へ移る。申込検索画面には移らない。ベース実装も編集画面へ移る。

ec-cube-enterprise 登録成功後の遷移: `ec-cube-enterprise/src/Eccube/Controller/Admin/Event/EntryRegistrationController.php:203-205`
```php
                $this->addSuccess('admin.common.save_complete', 'admin');

                return $this->redirectToRoute('admin_event_entry_edit', ['eventEntry' => $RegisteredEventEntry->getId()]);
```

ベース実装 pf-eccube3 登録成功後の遷移: `pf-eccube3/app/Plugin/HareruyaEc/Controller/Admin/EntryController.php:479-481`
```php

        return $app->redirect($app->url('admin_entry_edit', ['eventEntryId' => $eventEntryId]));
```
