分類：商品管理

課題：【実装乖離】商品管理_カテゴリ登録_編集画面のカテゴリツリーが編集中のカテゴリの親までしか開かず、編集中のカテゴリの子カテゴリが一覧表示されない
設計書：0204_基本設計仕様書(商品管理).xlsx

# 再現手順【必須】
1. 開発環境（https://replace-dev.hareruyamtg.com:8443）の管理画面で、商品管理＞カテゴリ登録/編集を開き、階層3で子カテゴリを1件以上持つカテゴリ（ケースでは「編集前カテゴリ-002」。子は「サブカテゴリA」の1件）の編集画面（行の鉛筆アイコン）を開く
2. 画面右の「すべてのカテゴリ」のカテゴリツリーを確認する

# 期待される挙動【必須】
- 設計書の画面項目定義（識別ID 21「カテゴリツリー表示」）は「初期表示時に現在編集中のカテゴリまでのツリーと、紐づく子カテゴリを一覧表示する」と定めている。ケースの期待結果も「現在編集中の『編集前カテゴリ-002』までの階層と、子カテゴリ『サブカテゴリA』が一覧表示されること」。
- つまり編集画面を開いた時点で、最上位から編集中のカテゴリまでの枝が開き、編集中のカテゴリの子カテゴリ（ここでは「サブカテゴリA」）がツリーに見えている。

# 現在の挙動【必須】
- 最上位から編集中のカテゴリまでの3つ（全商品-002・カード-002・編集前カテゴリ-002）はツリーに出るが、編集中のカテゴリの枝は閉じたままで（行頭が「＋」。名称の後ろの「(1)」で子が1件あることだけが分かる）、子カテゴリ「サブカテゴリA」はツリーに見えない。子を見るには利用者が「＋」を押して開く必要がある。
- 同じ原因で、子カテゴリが3件ある場合（IT-M03-11-041、E2E のテストID IT-M03-11-047）も、編集中のカテゴリの枝が閉じていて3件とも見えない。
- 原因はツリーを開く対象が編集中のカテゴリの「親」までで、編集中のカテゴリ自身を含まないこと。画面に渡す「開く対象」を、編集画面でも親から作っている。

ec-cube-enterprise 編集画面の表示データ（開く対象は親から作る）: `ec-cube-enterprise/src/Eccube/Controller/Admin/Product/CategoryController.php:653-666`
```php
    private function buildBreadcrumbIds(?Category $Parent): array
    {
        $Ids = [];
        if ($Parent && $Parent->getParents()) {
            foreach ($Parent->getParents() as $item) {
                $Ids[] = $item['id'];
            }
        }
        if ($Parent !== null) {
            $Ids[] = (int) $Parent->getId();
        }

        return $Ids;
    }
```

- ベース実装（pf-eccube3・EC-CUBE 標準）も同じ作りで、編集中のカテゴリではなくその親までを開く。設計書の識別ID 21 の記述（現在編集中のカテゴリまで、紐づく子カテゴリも一覧表示）は、ベース実装の挙動より広い。

# 根拠
- 設計：
  - 画面項目定義 識別ID 21「カテゴリツリー表示」: 初期表示時に現在編集中のカテゴリまでのツリーと、紐づく子カテゴリを一覧表示する: `hareruya-design-docs/excel_to_html/output/0204_基本設計仕様書(商品管理).html:4109`
- ec-cube-enterprise：
  - 編集画面のツリーを開く対象は親までで、編集中のカテゴリの枝は閉じる: `ec-cube-enterprise/src/Eccube/Controller/Admin/Product/CategoryController.php:653-666`、`ec-cube-enterprise/src/Eccube/Resource/template/admin/Product/category.twig:530-541`
- ベース実装：
  - pf-eccube3 も EC-CUBE 標準も、現在地（親）までしか開かない: `pf-eccube3/src/Eccube/Resource/template/admin/Product/category.twig:77-88`、`ec-cube/src/Eccube/Resource/template/admin/Product/category.twig:325-345`
  - 探した範囲: pf-eccube3 の admin/Product/category.twig と ec-cube 標準の同名テンプレート。編集中のカテゴリ自身の子を開く処理は無い
