# 再現手順【必須】
1. 開発環境（https://replace-dev.hareruyamtg.com:8443）の管理画面で、検索条件を保持していない新しいブラウザセッションでログインし、イベント管理＞イベント一覧を開く
2. 「検索条件をクリア」を押す
3. 検索条件を何も入れずに「検索する」を押す
4. 検索結果の表に全イベント（検索結果：1732件が該当しました）が表示される。検索条件を保持した状態で同じ操作をしても、保持条件での再検索はされないが全イベントが表示される（IT-M13-01-040）

# 期待される挙動【必須】
- 検索条件が空で、保持している検索条件も無いときは、検索せず初期表示（検索結果の表が表示されない状態）へ戻る
- 設計書の現行仕様はイベント一覧で「検索条件が空で、保持している検索条件が残っているときは、それを復元して検索する」と書き、イベント申込一覧では「検索条件を受け取れないとき」と書いており、フォームを空で送信した場合の扱いが読み分けられない。空送信が「検索条件を受け取れない」に当たるかを設計書で確定する

# 現在の挙動【必須】
- フォームを空で送信すると妥当な送信として扱い、ページ番号を1にして全件を検索する。条件が空かどうかで初期表示へ戻す分岐は、初期表示（GET）とページ指定の復元の箇所にしか無い。
