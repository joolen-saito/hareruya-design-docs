# 期待される挙動【必須】
- ケースの期待結果（項目表 IT-F08-02-001。E2E のテストID IT-F08-02-001）は、共通の利用規約を表示するモーダルが開き、個人情報の取り扱いについてのボタンが表示されないこと。
- 設計書（Excel 由来）は、画面項目定義 識別ID 29「個人情報の取り扱いについて」を「カスタマイズ対応、項目を削除する」、識別ID 30「利用規約」を「共通の利用規約をモーダル表示する」と定める。機能仕様の「★利用規約について」も、個人情報の取り扱いについて利用規約を共通にまとめるため共通の利用規約のみ表示し、個人情報の取り扱いについてを削除すると定める。
- 現行は個人情報保護方針と利用規約を別々に表示していた。リニューアル後は共通の利用規約のみを表示する。
