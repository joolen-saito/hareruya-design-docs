# 現在の挙動【必須】
- HTTP 200・code 200 で、ニックネームとプロフィールの更新も期待どおり。合わないのは message だけで、「ユーザー情報を更新しました」（日本語）で返る（2026-11-17 開発環境）。
- 原因は、アプリがこのメッセージを翻訳の部品（trans）で出し、日本語の語彙に日本語の文が入っていること。英語（en）の語彙だけが設計どおりの「Update user information」になる。ECCUBE_HARERUYA-4125（他ユーザー情報参照の失敗時のメッセージ）と同じ作りで、別の窓口・別の文言。

```php

            'code' => Response::HTTP_OK,
            'message' => trans('api.deck_builder.user.update_success'),

```

ec-cube-enterprise 翻訳の語彙（日本語は日本語の文、英語だけが設計の文言）: `ec-cube-enterprise/src/Eccube/Resource/locale/messages.ja.yaml:6457`・`ec-cube-enterprise/src/Eccube/Resource/locale/messages.en.yaml:3995`

- ベース実装（deck-api）は、英語の固定文言「Update user information」を返す（言語の切り替えは無い）。
