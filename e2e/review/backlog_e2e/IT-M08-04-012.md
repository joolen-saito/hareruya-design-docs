# 再現手順【必須】
1. 開発環境（https://replace-dev.admin.hareruyamtg.com:8443）の管理画面で、既存の会員の会員登録/編集画面（/admin/customer/<会員ID>/edit）を開く
2. お名前姓・名に「姓Sei」「名Mei」、お名前姓（カナ）・名（カナ）に「カナKana」「メイMei」（カタカナと英字の混在）、会社名・住所1〜3・MTG Companion登録本名・退会区分にも全角・半角の混在値を入力する
3. 「登録」を押す
4. 画面の入力エラーと、保存後の会員情報を確認する

# 期待される挙動【必須】
- お名前（カナ）は全角・半角で入力できる（画面項目定義 識別ID 4・5）。混在値で登録でき、各項目が更新される

# 現在の挙動【必須】
- お名前（カナ）の姓・名の両方に「カタカナで入力してください。」のエラーが出て保存されず、ほかの項目も含めてどの項目も更新されない（姓・名・会社名・住所などは入力値のまま画面に残り、保存後の値は元のまま）。
- アプリのフリガナの入力規則はカタカナ（半角カナ含む）だけで、英字を受け付けない。ベース実装はカタカナに加えて英字（a-zA-Z）も許可する。

ec-cube-enterprise フリガナの入力規則: `ec-cube-enterprise/src/Eccube/Form/Type/KanaType.php:58-61`
```php
                    new Assert\Regex([
                        'pattern' => '/^[ァ-ヶｦ-ﾟー]+$/u',
                        'message' => 'form_error.kana_only',
                    ]),
```

ec-cube-enterprise 会員登録編集のお名前（カナ）の項目: `ec-cube-enterprise/src/Eccube/Form/Type/Admin/CustomerType.php:70-72`
```php
            ->add('kana', KanaType::class, [
                'required' => false,
            ])
```

ベース実装 pf-eccube3 フリガナの入力規則: `pf-eccube3/src/Eccube/Form/Type/KanaType.php:59-61`
```php
                    new Assert\Regex(array(
                        'pattern' => "/^[ァ-ヶｦ-ﾟーa-zA-Z]+$/u",
                    )),
```

- 設計：
  - 画面項目定義 識別ID 4「お名前姓（カナ）」・識別ID 5「お名前名（カナ）」の入力形式は「全角・半角」: `hareruya-design-docs/excel_to_html/output/0207_基本設計仕様書(会員管理機能).html:1732-1733`
- ec-cube-enterprise：
  - フリガナの入力規則はカタカナだけ（英字不可）: `ec-cube-enterprise/src/Eccube/Form/Type/KanaType.php:58-61`
  - 会員登録編集は同じフリガナの部品を使う: `ec-cube-enterprise/src/Eccube/Form/Type/Admin/CustomerType.php:70-72`
- ベース実装：
  - フリガナはカタカナ・半角カナ・長音に加えて英字（a-zA-Z）を許可: `pf-eccube3/src/Eccube/Form/Type/KanaType.php:59-61`
  - 探した範囲: pf-eccube3 の src/Eccube/Form/Type（KanaType・Admin/CustomerType）
