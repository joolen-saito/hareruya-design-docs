- foil が整数 2、frame が文字列「Usually」、promotion がプロモ種別のオブジェクトで返り、foil_flg・promotion_flg は応答に含まれない（項目表 IT-A14-02-004 の期待結果。設計書 A14-02 のレスポンスデータ表は frame を「文字型」、応答例は "Usually"）。

# 現在の挙動【必須】
- foil・promotion の形と、foil_flg・promotion_flg が無いことは期待どおり。
- frame だけが、文字列でなく整数の 0 で返る（2026-11-25 開発環境）。
- 原因は、フレームを整数のフラグ（0=通常・1=特殊）で保持し、その整数をそのまま応答に出していること。設計書が定める文字型の値（「Usually」）への変換が無い。

ec-cube-enterprise カード詳細の応答の組み立て: `ec-cube-enterprise/src/Eccube/Service/App/DeckBuilder/CardDetailResponseBuilder.php:129-130`
```php

            'frame' => $CardDetail->getFrameFlg(),
```

ec-cube-enterprise フレームの保持: `ec-cube-enterprise/src/Eccube/Entity/Master/MtbCardDetail.php:41-42`・`ec-cube-enterprise/src/Eccube/Entity/Master/MtbCardDetail.php:308-309`
```php
    public const FRAME_NORMAL = 0;
    public const FRAME_SPECIAL = 1;
    ...
    private ?int $frameFlg = 0;
```

- ベース実装（pf-api）には frame の項目が無い（カスタマイズで新規追加される項目）。現行に該当なし（新規）。pf-api の src 全体で frame を探したが、該当は無かった。
