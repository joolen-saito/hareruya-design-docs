# 再現手順【必須】
1. 開発環境（https://replace-dev.hareruyamtg.com:8443）の管理画面で、会員管理＞ブラックリスト管理を開く
2. 既存の氏名の行のキーワードを「 更　新 Space 値 」（前後・途中に半角スペースと全角スペース）に書き換える
3. 新規登録行で項目「住所」を選び、キーワードに「 東京都　港区 2 」を入れる
4. 「登録」を押す
5. 保存された一覧のキーワードを見る
（同じ原因で、新規登録行に氏名「重 複　氏名」を入れると、既にある氏名「重複氏名」と重複せず2行目として足される）

# 期待される挙動【必須】
- ケースの期待結果（項目表 IT-M08-13-009。E2E のテストID IT-M08-13-017）は、更新したキーワードが「更新Space値」、新規の住所キーワードが「東京都港区2」になること。
- 同じ原因のケース:
  - 項目表 IT-M08-13-013（E2E IT-M08-13-021）: 空白を除くと「重複氏名」と同じになる「重 複　氏名」は重複として追加されず、件数が増えないこと。
  - 項目表 IT-M08-13-039（E2E IT-M08-13-049）: 新規登録の住所「追加 住所　M0813CB049」が「追加住所M0813CB049」として1件追加されること。
  - 項目表 IT-M08-13-042（E2E IT-M08-13-052）: 空白入りの既存の氏名「基準 氏名　M0813CB052」が、何も変えずに登録を押すと「基準氏名M0813CB052」に直ること。
- 設計書（0207 ブラックリスト登録/編集/削除 の業務ロジック「キーワードの空白除去」）は、キーワードを保存する前に半角スペースと全角スペースをすべて取り除く（前後だけでなく途中も、新規登録・更新のどちらも）と定める。重複は、空白を除いて保存を反映したあとの一覧全体に対して判定する（「重複の判定範囲」）。
- 会員登録時のブラックリストの照合は、会員情報から空白を取り除いた文字列と、登録キーワードを完全一致で比べる（「会員登録時の照合方法」）。キーワードに空白が残ると、照合で当たらない。
