# 期待される挙動【必須】
- 機能設計書の表示メッセージ M04-09-MSG-022: 入庫承認申請画面で差分商品を追加し、追加条件を満たさないとき、管理画面上部に「差分CSV登録可能なステータスではありません。」「保存に失敗しました」「入庫先の商品在庫が見つかりません。」「この商品は既に一覧に登録されています。」「出庫元の商品在庫が見つかりません。」のどれかを出し、移動入庫承認申請画面に遷移する。
- ケースの期待結果は、管理画面上部に「差分CSV登録可能なステータスではありません。」が出て、選んだ商品が差分商品として明細に登録されないこと。

# 現在の挙動【必須】
- 明細には足されない（期待どおり）が、管理画面上部にはメッセージが1件も出ない。画面は入庫承認画面に移り、上部はデバッグの表示だけ。
- 同じ画面の差分商品の追加で、ほかの追加できない場合（出庫元の商品在庫が無い・同じ商品をもう一度追加する など）も、管理画面上部のメッセージは出ていない（項目表 IT-M04-09-037、E2E のテストID IT-M04-09-055 の実施で確認）。
- 原因の見立て:
  - 追加の処理は、条件を満たさないとエラーのメッセージを積み、入庫承認申請画面へ転送する。その画面は、ステータスに合わせて、さらに入庫承認画面へ転送する。
  - 一方、画面は決定を画面の裏の通信で送り、転送を最後まで追ってから、同じ転送先を開き直す。
  - 積んだメッセージは裏の通信が読んだ転送先の画面で使い切られるため、開き直した画面には出ない。
