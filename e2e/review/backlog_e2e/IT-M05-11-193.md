# 再現手順【必須】
1. お届け先の電話番号1〜3に値（例: 121・1211・1212）が入った受注を用意する
2. 開発環境（https://replace-dev.admin.hareruyamtg.com:8443）の管理画面で、その受注の受注情報編集画面（/admin/order/<受注ID>/edit）を開く

4. 「受注情報を登録」を押す

# 期待される挙動【必須】
- 設計書の画面項目定義では、お届け先の電話番号1〜3（識別ID 12-13〜12-15）の必須は「-」（必須でない）。注文者の電話番号（識別ID 10-16・10-17）は必須「〇」で、お届け先とは区別されている。項目表どおりなら、お届け先の電話番号は空で保存できる
- ベース実装もお届け先の電話番号を空では受け付けないため、項目表（必須でない）と現行（必須）のどちらを正とするかの確認が要る

# 現在の挙動【必須】
