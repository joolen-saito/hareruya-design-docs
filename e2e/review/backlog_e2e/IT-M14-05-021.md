# 基本情報【必須】
分類：カード管理
機能：カード登録CSVアップロード
課題カテゴリ：不具合_カード管理
課題：【実装乖離】カード管理_カード登録CSVアップロード_現行の日本語・英語の商品ID列を足したCSVが「CSVのフォーマットが一致しません。」で取り込めず、既存カードが更新されない
設計書：0208_基本設計仕様書(カード管理).xlsx

# 再現手順【必須】
1. 更新対象のカード（カード詳細ID付き）を登録しておく
2. 開発環境（https://replace-dev.hareruyamtg.com:8443）の管理画面でカード登録CSVアップロード画面を開く
3. ヘッダに、現行の日本語商品ID列と現行の英語商品ID列を余分に足したCSVを選択し、「CSVファイルをアップロード」を押す
4. 「CSVのフォーマットが一致しません。」が出て取り込まれず、既存カードの点数で見たマナコストなども更新されない

# 期待される挙動【必須】
- ヘッダの照合では、カード詳細ID・現行の日本語商品ID・現行の英語商品IDの3列を比べる対象から外す。現行の商品IDの列を余分に持つファイルもヘッダの検査を通り、取り込める（現行仕様 業務ロジック「取込の判定順序」）

# 現在の挙動【必須】
- ヘッダの照合で外す列は、カード詳細IDとキーワード能力の2つだけ。現行の商品ID列を持つCSVはヘッダが一致せず、エラーで中止する。

ec-cube-enterprise 必須でない列（ヘッダ照合から外す列）: `ec-cube-enterprise/src/Eccube/Service/Csv/CardCsv.php:142-149`
```php
    public static function getNotRequiredCsvHeaderKeys(): array
    {
        return [
            'card_detail_id',
            // TODO: キーワード能力の取り込みは現在未実装。
            'keyword_ability',
        ];
    }
```

- ベース実装は、現行の日本語・英語の商品ID列もヘッダ照合から外す。

ベース実装 pf-eccube3 必須でない列: `pf-eccube3/app/Plugin/HareruyaEc/Controller/Admin/CardCsvController.php:195-202`
```php
    private function getNotRequiredCsvHeader()
    {
        return [
            'old_product_id',
            'old_en_product_id',
            'card_detail_id'
        ];
    }
```

# 根拠
- 設計：
  - 現行仕様 業務ロジック「取込の判定順序」: ヘッダの照合で現行の商品ID列を余分に持つファイルも通る: `hareruya-design-docs/excel_to_html/output/0208_基本設計仕様書(カード管理).html:1755`
- ec-cube-enterprise：
  - 照合から外す列に商品ID列が無い: `ec-cube-enterprise/src/Eccube/Service/Csv/CardCsv.php:142-149`
  - 外す列以外の差はヘッダ不一致エラー: `ec-cube-enterprise/src/Eccube/Service/Csv/AbstractCsvService.php:242-249`
- ベース実装：
  - 商品ID列2つとカード詳細IDを外す: `pf-eccube3/app/Plugin/HareruyaEc/Controller/Admin/CardCsvController.php:195-202`
  - 探した範囲: pf-eccube3 の Admin/CardCsvController（取込）。Excel の項目表（識別ID 1〜）に商品ID列は無いが、この余分な列を許す記述は現行仕様の節にだけある
