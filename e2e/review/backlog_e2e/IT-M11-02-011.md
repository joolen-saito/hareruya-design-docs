# 期待される挙動【必須】
- ケースは編集画面でログインIDを変更でき、保存後のログインIDが更新される前提（手順2でログインIDを変更、期待結果で更新を確認）。
- 設計書にはログインIDを編集時に変更できる・できないの記載が無い。設計書の機能仕様は「EC-CUBEエンタプライズの標準機能をベースに」とし、ログインID（識別ID 1-4）は新規登録の項目としてだけ定義している。編集時に変更できることを正とするかどうかの確認が要る。
