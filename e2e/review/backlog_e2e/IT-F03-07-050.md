# 基本情報【必須】
分類：フロント_商品
機能：商品詳細（入荷時通知）
課題カテゴリ：不具合_フロント_商品
課題：【実装乖離】フロント_商品_商品詳細_入荷通知を取り消した後のボタンの文言が「入荷通知」で、設計書・現行の「入荷時に通知」と違う
設計書：0303_基本設計仕様書(フロント_商品).xlsx

# 再現手順【必須】
1. 本店公開・日本語・高額商品でなく、本店の在庫が0（SOLDOUT）の商品規格と、その商品規格に入荷通知を依頼済みの本会員を用意する
2. 開発環境（https://replace-dev.hareruyamtg.com:8443）の本店にその会員でログインし、商品詳細（/ja/products/detail/<商品ID>）を開く（ボタンは「通知待ち」）
3. 「通知待ち」のボタンを押して入荷通知を取り消す（「入荷通知を解除しました。」の通知が出る）
4. 同じ商品規格のボタンの文言を確認する

# 期待される挙動【必須】
- 取消に成功すると、入荷通知の表示を「入荷時に通知」に切り替える（商品詳細 現行仕様「入荷通知の依頼と取消」、入荷時通知 識別ID 1-1「入荷時に通知」）

# 現在の挙動【必須】
- 取消後のボタンの文言は「入荷通知」で、「入荷時に通知」にならない（取消そのものは成功し、通知待ちの状態は外れる）。
- 商品詳細の規格ごとのボタンは、未依頼のときの文言に「入荷通知」の訳語を使っている。ベース実装の同じボタンの文言は「入荷時に通知」。
- なお設計書の商品詳細の画面項目定義 識別ID 2-14 は項目名を「入荷通知/通知待ち」と書いており、同じ設計書の入荷時通知シート（識別ID 1-1「入荷時に通知」）・商品一覧（識別ID 3-20「入荷時に通知/通知待ち」）・現行仕様と表記が揃っていない。表示する文言は「入荷時に通知」とする記述が多数で、ベース実装もこれに合う。
