# 再現手順【必須】
1. 本人確認画像の閲覧権限が無い管理者（権限の拒否 URL に本人確認の項目がある）でログインする
2. 本人確認画像が4種類そろった本会員の会員編集画面を開く（項目表 IT-M08-10-005。E2E の IT-M08-10-006。同じ原因の IT-M08-10-009＝E2E の IT-M08-10-010 は、閲覧不可の枠を押しても拡大表示が開かないことの確認）
3. 「オンライン本人確認」ボタンを押す
4. 4つの身分証画像枠を確認する

# 期待される挙動【必須】
- 項目表 IT-M08-10-005 の期待結果は、4つの身分証画像が表示されず、各画像枠が閲覧不可の状態で表示されること。IT-M08-10-009 は、閲覧不可の枠を押しても拡大表示が開かないこと。
- 根拠は、設計書の現行仕様の節「モーダルの表示内容」（本人確認の閲覧権限が無いとき、各画像枠に閲覧不可の文言を表示する。閲覧不可の枠には拡大表示を設けない）、「エラー時の扱い」、およびリニューアル後の仕様の表示メッセージの節（モーダル内の各身分証画像枠に「閲覧不可」）。
- 同じシートの Excel 由来の部分（画面項目の表）は、モーダル内のボタン・項目の一覧で、閲覧権限が無いときの表示は定めていない。設計書内の優先順位（Excel 由来＞表示メッセージ＞現行仕様。2026-10-16 決定）では、Excel 由来に記述が無いため、この件は現行仕様の節と表示メッセージの節が根拠になる。それでよいかの確認が要る。

# 現在の挙動【必須】
- 閲覧権限が無い管理者の会員編集画面には、「オンライン本人確認」ボタンが出ない（添付のキャプチャは、ボタンが並ぶ行が「ポイント管理・履歴一覧」「ポイント確認」「送信履歴」「手動メール通知」だけの状態。2026-11-26 開発環境）。モーダルも出力されないため、手順3・4を実行できず、閲覧不可の枠も拡大表示の確認もできない。
- 原因は、新しいアプリが閲覧権限の有無でボタンとモーダルの両方を出し分けていること（機能ごと隠す）。現行は、ボタンとモーダルを常に出し、権限が無いときだけ各画像枠に閲覧不可の文言を出す。新しいアプリには、各画像枠に閲覧不可を表示する作りが無い。
