# 再現手順【必須】
1. 言語が日本語のグッズ商品（カード商品でない商品）を含む受注を用意する
2. 開発環境（https://replace-dev.admin.hareruyamtg.com:8443）の管理画面で、その受注の受注情報編集画面（/admin/order/<受注ID>/edit）を開く
3. 受注商品情報の、その商品の行を確認する

# 期待される挙動【必須】
- 設計書では、受注商品情報に「商品の言語・状態・Foil・フレームに応じたアイコン（アイコン風のラベル）」を表示する。Foil・フレーム・商品名の【言語/状態】は、カードの属性を前提とした記述で、グッズ商品に出すかは書かれていない
- ケースは言語が日本語のグッズ商品の行にアイコンが出ることを期待しているが、ベース実装は「カード以外の商品は商品名だけを出す」作り。グッズ商品に言語のアイコンを出すかを設計書で確定し、ケースの商品をカード商品にするか期待を直す

# 現在の挙動【必須】
- グッズ商品の行には、言語のアイコン（ラベル）が出ない。商品名・棚番号・商品コードだけが並ぶ。
- 言語・状態・Foil・フレームのラベルは、カードの詳細を持つ商品（カード商品）の明細にだけ出す作りで、カードの詳細を持たないグッズ商品は表示用の情報が取れず、商品名だけを出す。ベース実装も「カード以外の商品はsubinfoがないので商品名だけを格納」している。
