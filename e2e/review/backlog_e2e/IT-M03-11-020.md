設計書：0204_基本設計仕様書(商品管理).xlsx

# 再現手順【必須】
1. 開発環境（https://replace-dev.hareruyamtg.com:8443）の管理画面で、商品管理＞カテゴリ登録/編集から、階層3で検索パラメータに「rarity=old」が入っているカテゴリ（ケースでは「編集前カテゴリ-020」）の編集画面（行の鉛筆アイコン）を開く
2. 「検索パラメータ」に全角文字「レアリティ＝Ｒ」を入力する
3. 「カテゴリ更新」ボタンを押す
4. 保存後の画面を確認する（ケースの期待結果は「当該カテゴリの編集画面に留まること」）

# 期待される挙動【必須】
- 設計書の画面項目定義（識別ID 16「検索パラメータ」）の書式・制限は「半角英数記号」。全角文字は入力として妥当でないので、保存せず、入力項目の直下に項目エラーを出して同じ画面（当該カテゴリの編集画面）に留まる。
- 設計書の現行仕様（保存の判定順序）も「入力が妥当か: 不備があれば保存せず、同じ画面に項目エラーを表示する」と定めている。ケースの期待結果は「当該カテゴリの編集画面に留まること」。

# 現在の挙動【必須】
- 全角の「レアリティ＝Ｒ」を入力して保存しても入力エラーは出ず、画面上部に「保存しました」が出て、編集画面に留まらず親カテゴリの一覧画面（URLは親カテゴリのID指定）へ遷移する。
- 原因は、検索パラメータの入力値の検証が文字数の上限だけで、半角英数記号に限る検査が無いこと。

ec-cube-enterprise カテゴリ入力フォームの検索パラメータ（検証は文字数の上限のみ）: `ec-cube-enterprise/src/Eccube/Form/Type/Admin/CategoryType.php:151-159`
```php
            ->add('search_parameters', TextType::class, [
                'label' => 'admin.product.category_search_parameters',
                'required' => false,
                'constraints' => [
                    new Assert\Length([
                        'max' => $this->eccubeConfig['eccube_ltext_len'],
                    ]),
                ],
            ]);
```

- ベース実装には検索パラメータの項目が無い（新規の項目）。

ベース実装 pf-eccube3 カテゴリ入力フォーム（カテゴリ名の1項目のみ。検索パラメータは無い）: `pf-eccube3/src/Eccube/Form/Type/Admin/CategoryType.php:45-57`
```php
    {
        $builder
            ->add('name', 'text', array(
                'label' => 'カテゴリ名',
                'constraints' => array(
                    new Assert\NotBlank(),
                    new Assert\Length(array(
                        'max' => $this->config['stext_len'],
                    )),
                ),
            ))
        ;
    }
```

- 設計：
  - 画面項目定義 識別ID 16「検索パラメータ」: 書式・制限 半角英数記号（カスタマイズ対応、新規設置）: `hareruya-design-docs/excel_to_html/output/0204_基本設計仕様書(商品管理).html:4104`
  - 現行仕様 保存の判定順序（1 入力が妥当か: 不備があれば保存せず、同じ画面に項目エラーを表示する）: `hareruya-design-docs/excel_to_html/output/0204_基本設計仕様書(商品管理).html:4139`

  - 探した範囲: pf-eccube3 の src/Eccube/Form/Type/Admin/CategoryType.php とカテゴリのエンティティ（検索パラメータの項目は無い）
