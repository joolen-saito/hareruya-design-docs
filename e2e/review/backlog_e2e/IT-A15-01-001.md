# 現在の挙動【必須】
- ログイン: HTTP 200・code 200・アクセストークン・セッションIDは期待どおりで、message だけが「認証に成功しました」（日本語）（2026-11-17 開発環境）。
- ログアウト（署名が不正なトークン）: HTTP 401・結果コードは期待どおりで、message が「アクセストークンが正しくありません」（日本語）（2026-11-17 開発環境）。
- 原因は、デッキビルダーAPIが応答の文言を翻訳の部品（trans）で出しており、既定の日本語では日本語の文になること。英語（en）の語彙だけが設計どおりの文言になる。
- 同じ原因の不合格は、ECCUBE_HARERUYA-4125（他ユーザー情報参照の失敗時「Invalid request parameters」）と ECCUBE_HARERUYA-4238（ユーザー情報変更の成功時「Update user information」）でも起票済み。デッキビルダーAPIのコントローラーには、翻訳の部品を通す文言が55か所ある（DeckController 32・UserController 10・LoginController 8・CardController 3・ArchetypeController 1・MasterController 1）。窓口ごとに直すと漏れが出やすいので、デッキビルダーAPIの応答の文言を英語で返す作り（ロケールを en に固定する等）でまとめて直すことを提案する。
- 参考: ECCUBE_HARERUYA-2970（完了。メタゲーム情報参照の文言）は英語の語彙（messages.en.yaml）の値を直す対応だったため、既定の日本語では日本語の文のまま。
