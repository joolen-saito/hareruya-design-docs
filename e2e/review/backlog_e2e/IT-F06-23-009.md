# 期待される挙動【必須】
- ケースの期待結果（項目表 IT-F06-23-009。E2E のテストID IT-F06-23-009）は、問い合わせ件数に「3 Items」が表示されること。
- 設計書の表示メッセージの節は、「一覧の総件数欄（英語表示時）」を「N Items（Nは件数）」と定める（現行仕様の節。Excel の画面項目定義 識別ID 3 は「今まで問い合わせを行なった件数」とだけ書き、文言は定めない）。
- 現行（ベース実装）の英語ページは件数のあとに「Items」（先頭大文字）を出す。

# 現在の挙動【必須】
- 件数欄は「3 items」（先頭が小文字）で表示される（2026-11-18 開発環境）。
- 同じ原因で、0件の場合も「0 Items」でなく「0 items」になる（項目表 IT-F06-23-011。E2E のテストID IT-F06-23-011。手元の環境の結果で、開発環境ではまだ流していない）。
- 新アプリの英語の翻訳は「%count% items」（小文字）で、日本語表示は「%count%件」。英語の翻訳には先頭大文字の「Items」を持つ別の語（item_line）もあるが、件数欄では使われていない。

ec-cube-enterprise 件数欄は翻訳「front.contact_history.toolbar_count」を表示する: `ec-cube-enterprise/src/Eccube/Resource/template/default/Contact/history.en.twig:19-23`
```twig
                    <div class="p-hareruya-toolbar__count">
                        <p class="c-hareruya-text u-hareruya-font-bold">
                            <span>{{ 'front.contact_history.toolbar_count'|trans({ '%count%': contactHistories|length }) }}</span>
                        </p>
                    </div>
```

ec-cube-enterprise 英語の翻訳は小文字の「items」: `ec-cube-enterprise/src/Eccube/Resource/locale/messages.en.yaml:295,300`
```yaml
front.contact_history.item_line: Items
front.contact_history.toolbar_count: '%count% items'
```

ベース実装 pf-eccube3 英語ページの件数欄（「Items」）: `pf-eccube3/app/Plugin/HareruyaEc/Resource/template/default/Contact/history.en.twig:14-16`
