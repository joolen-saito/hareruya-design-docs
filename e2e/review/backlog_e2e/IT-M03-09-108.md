# 再現手順【必須】
1. 開発環境（https://replace-dev.hareruyamtg.com:8443）の管理画面で商品管理＞商品一覧から商品を開き、公開ステータスが公開の商品規格の編集画面を開く
2. 公開ステータスを「廃止」に変更する
3. 「商品規格を登録」ボタンを押す
4. 画面上部の完了メッセージを確認する（「保存しました」と表示される。公開ステータスは廃止で保存されている）

# 期待される挙動【必須】
- 規格の更新に成功して編集画面へ戻ったとき、画面上部のフラッシュ領域に「登録が完了しました。」を表示する（設計書の表示メッセージ）。
