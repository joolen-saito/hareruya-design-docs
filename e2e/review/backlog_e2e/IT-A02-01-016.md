# 期待される挙動【必須】
- ケースの期待（IT-A02-01-014）: goods_api/get_goods への要求に product_id が付き、応答の JSON の商品ID・商品規格IDが期待どおりで、商品情報のポップアップが表示される。IT-A02-01-016 は、要求に product_id と lang=jp が付き、応答が言語JP・状態HPの商品規格になること
