課題：【要確認】会員管理機能_ポイント付与（キャンペーン／返金）_ポイント追加フォームは画面を開いた時点で表示されていて、1回目の押下で非表示・2回目で表示になる（ケースの期待は初期非表示を前提にした逆の順で、設計書の画面イメージは初期表示）

# 再現手順【必須】
1. 開発環境（https://replace-dev.hareruyamtg.com:8443）の管理画面で、ポイント残高1000・ポイント履歴0件の会員のポイント付与（キャンペーン、特別対応）画面を開く（会員管理＞会員編集＞ポイント付与＞「キャンペーン、特別対応によるポイント付与」。項目表 IT-M08-05-006）
2. 開いた直後の「ポイント履歴追加（キャンペーン、特別対応）」のフォーム（注文番号・ポイント増減量・ポイント発行日・備考・保存）が表示されていることを確認する
3. 「ポイント履歴追加（キャンペーン、特別対応）」の見出し（ポイント追加フォーム表示制御エリア）を押す。フォームが非表示になる
4. もう一度押す。フォームが表示に戻る
5. 余剰入金へのご返金の画面（項目表 IT-M08-05-007。E2E のテストID IT-M08-05-007）でも、手順1〜4を同じように行う

# 期待される挙動【必須】
- ケースの期待結果（項目表 IT-M08-05-006・IT-M08-05-007）は「1回目の押下でポイント追加フォームが表示され、2回目の押下で非表示になること」。画面を開いた時点でフォームが非表示であることを前提にしている。
- 設計書（Excel 由来）の機能仕様 処理概要は、「ポイント追加フォーム表示制御エリア」押下時に「動的にポイント追加フォームの表示/非表示を切り替える」とだけ書き、初期の状態を文章では定めていない。
- 一方、同じシートの処理概要の画面イメージ（キャンペーン・特別対応、余剰入金へのご返金のどちらも）は、「ポイント履歴追加」の見出しの右に上向きの矢印（開いている印）を描き、フォームの全項目（注文番号・ポイント増減量・ポイント発行日・備考・保存ボタン）を表示した状態で描いている。したがって設計書の画面イメージが示す初期の状態は「表示」で、押下1回目は非表示、2回目は表示に戻るのが設計どおり。
- 優先順位（Excel 由来＞表示メッセージ節＞現行仕様節）でも、初期非表示とする定めはどこにも無い。ケースの期待結果（初期非表示の前提）を、画面イメージに合わせて「開いた時点で表示、1回目の押下で非表示、2回目の押下で表示」へ直す必要がある。

# 現在の挙動【必須】
- 開いた直後のフォームは表示されている。「ポイント履歴追加（キャンペーン、特別対応）」の見出しを1回押すと非表示になり（右の矢印が下向きに変わる）、2回目の押下で表示に戻る（実施は 2026-11-15、開発環境。IT-M08-05-006・007 とも同じ結果）。これは設計書の画面イメージ（初期表示）と合っていて、アプリの不具合ではない。
