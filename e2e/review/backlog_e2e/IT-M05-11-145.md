# 期待される挙動【必須】
- 設計書の改訂履歴 0.3（田中・2026-10-05）で「受注履歴画面 - 欠品登録ボタン活性 > 非活性に修正」とあり、履歴画面の受注商品情報の機能仕様は「欠品登録ボタンは非活性とする」。履歴画面では欠品登録ボタンも押せないのが現在の設計
- ケースの期待（欠品登録ボタンが非活性でなく、押下できる）は、改訂前の記述「欠品登録以外のボタンは非活性とする」に基づいており、改訂後の設計書と合わない。ケースを設計書の最新版に合わせて直す
- 設計書の中にも、履歴画面の画面項目定義 4-3「欠品登録」の説明が「-」（非活性の指定なし）のまま残っている。ここも改訂後の記述に合わせて直す

# 現在の挙動【必須】
- 履歴画面の「欠品登録」ボタンは非活性で押せない。削除・商品の追加・受注情報を登録の各ボタンも同じく非活性で、設計書の改訂後の仕様どおり。
- 新アプリは履歴表示のとき、欠品登録ボタンにも一律に非活性の指定を付けている。
