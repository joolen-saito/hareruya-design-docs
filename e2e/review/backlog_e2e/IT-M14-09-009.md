# 基本情報【必須】
分類：カード管理
機能：フォーマット一覧
課題カテゴリ：不具合_カード管理
課題：【要確認】カード管理_フォーマット一覧_行メニューの「編集」の遷移先が、画面項目定義の「カードセット詳細(編集・削除)画面」でなくフォーマット編集画面になっている（設計書の記載の食い違い）
設計書：0208_基本設計仕様書(カード管理).xlsx

# 再現手順【必須】
1. 開発環境（https://replace-dev.admin.hareruyamtg.com:8443）の管理画面でフォーマット一覧画面（/admin/format）を開く
2. 「スタンダード / Standard」の行の3点リーダーを押す
3. 「編集」を押す
4. 遷移した画面のアドレスと画面名を確認する

# 期待される挙動【必須】
- フォーマット一覧の「編集」の遷移先は、画面項目定義（識別ID 6）では「カードセット詳細(編集・削除)画面」だが、同じ設計書の他の箇所（新規登録は「フォーマット詳細(登録)画面」、表示メッセージは「フォーマット編集画面」）はフォーマットの画面を指す。どちらを正とするか決める

# 現在の挙動【必須】
- 「編集」を押すと、フォーマット編集画面（/admin/format/<フォーマットID>/edit）へ移る。カードセット詳細画面（/admin/cardset/<ID>/edit）には移らない。ベース実装も同じフォーマット編集画面へ移る。

ec-cube-enterprise 一覧の編集リンク: `ec-cube-enterprise/app/template/admin/Format/format_list.twig:64`
```twig
<li class="p-0"><a class="dropdown-item d-block py-2 px-3 text-center" href="{{ url('admin_format_edit', { 'id': Format.id}) }}"><i class="fa fa-pencil me-1"></i>{{ 'admin.common.edit'|trans }}</a></li>
```

ベース実装 pf-eccube3 一覧の編集リンク: `pf-eccube3/app/Plugin/HareruyaEc/Resource/template/admin/Format/format.twig:52`
```twig
<li><a href="{{ url('admin_format_edit', {formatId: format.id}) }}" >編集</a></li>
```

# 根拠
- 設計：
  - 画面項目定義 識別ID 6「編集」は「押下すると、カードセット詳細(編集・削除)画面へ遷移する」: `hareruya-design-docs/excel_to_html/output/0208_基本設計仕様書(カード管理).html:2533`
  - 同じシートの識別ID 1「新規登録」は「フォーマット詳細(登録)画面へ遷移する」: `hareruya-design-docs/excel_to_html/output/0208_基本設計仕様書(カード管理).html:2528`
  - 表示メッセージ M14-09-MSG-002（編集内容の保存）の後続処理は「フォーマット編集画面に遷移する」: `hareruya-design-docs/excel_to_html/output/0208_基本設計仕様書(カード管理).html:2564`
- ec-cube-enterprise：
  - 一覧の編集リンクの遷移先はフォーマット編集画面: `ec-cube-enterprise/app/template/admin/Format/format_list.twig:64`
- ベース実装：
  - 一覧の編集リンクの遷移先はフォーマット編集画面: `pf-eccube3/app/Plugin/HareruyaEc/Resource/template/admin/Format/format.twig:52`
  - 探した範囲: pf-eccube3 の admin/Format テンプレートとフォーマットの ServiceProvider。識別ID 6 の画面名は、カードセットの画面からの転記ミスの可能性が高い
