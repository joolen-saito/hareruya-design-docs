# 期待される挙動【必須】
- ケースの期待結果（項目表 IT-M14-08-005。E2E のテストID IT-M14-08-005）は、「シンボル画像の未登録状態が表示されること」。出典は画面項目定義の識別ID 17。
- 一方、設計書の画面項目定義（Excel 由来）は、登録画面の識別ID 17「画像未登録」を「※カスタマイズ対応、項目を除去する」とし、編集画面の識別ID 22-2「画像未登録」を「画像未登録の場合に表示」と定める。新規登録画面に「画像未登録」を出さないのが設計書どおりで、ケースの期待結果が設計書と食い違っている。
- 確認したいこと: ケースの期待結果を「新規登録画面には画像未登録の表示が無いこと」（または、編集画面の 22-2 の確認）に直してよいか。

# 現在の挙動【必須】
- 新規登録画面のシンボル画像の欄は、ファイルを選ぶ入力欄だけで、「画像未登録」の表示は無い（2026-11-17 開発環境）。
- 編集画面では、シンボル画像が未登録のカードセットに「画像未登録」と表示される（項目表 IT-M14-08-012 の流しの画面）。設計書の 22-2 どおり。
- 現行（ベース実装）は、登録画面にも「画像未登録」を出していた。設計書のカスタマイズ（項目を除去する）で、新アプリは登録画面から外している。

ec-cube-enterprise カードセット詳細の画面（カードセットIDがあるとき＝編集のときだけ、画像か「画像未登録」を出す）: `ec-cube-enterprise/app/template/admin/Cardset/edit.twig:105-117`
