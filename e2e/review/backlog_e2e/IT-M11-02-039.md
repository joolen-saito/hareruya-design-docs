# 再現手順【必須】
1. 開発環境（https://replace-dev.hareruyamtg.com:8443）の管理画面でメンバー編集権限のある管理者としてログインし、システム設定＞メンバー管理で既存のメンバーの編集画面を開く
2. デフォルト検索表示店舗を別の店舗に変更し、パスワード欄は初期表示のままにして登録ボタンを押す
3. 画面上部の完了メッセージを確認する（「保存しました」と表示される）

# 期待される挙動【必須】
- メンバー管理（M11-02）の表示メッセージ節は、登録・編集の保存完了時の文言を「メンバーを保存しました。」と定める。
- 一方、メンバー管理一覧（M11-01）の表示メッセージ節は、新しいメンバーの登録完了時（M11-01-MSG-001）・メンバー情報の編集完了時（M11-01-MSG-003）の文言を「保存しました」と定める。同じ保存完了の文言が設計書内で二通りあり、どちらを正とするかが決まっていない。

# 現在の挙動【必須】
- 保存後に「保存しました」が表示される。ケース（M11-02 の連携ケース）の手順4は「メンバーを保存しました。」の表示を確かめるため、ここで止まり、手順5以降（受注情報検索・在庫履歴検索の初期店舗の確認）に進めていない。

ec-cube-enterprise メンバー更新の完了メッセージ: `ec-cube-enterprise/src/Eccube/Controller/Admin/Setting/System/MemberController.php:236`


- ベース実装は「メンバーを保存しました。」を出している。
