# 期待される挙動【必須】
- 項目表の期待結果は、どのケースも HTTP 200 で、カード別採用枚数集計（配列）が返ること（001 は任意条件なし、002・003 は種別、004・010 はアーキタイプ、005 はボード、006 は認証の有無、007 は件数、009 は並び順、012 は項目の型）。
