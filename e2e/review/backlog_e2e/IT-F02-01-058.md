# 再現手順【必須】
1. 管理画面で本店の会員にカート商品を合計3点入れた状態にし、その会員でログインする
2. ブラウザの通信の差し止めで、パスが /block/cart で終わる要求を止める
3. 開発環境（https://replace-dev.hareruyamtg.com:8443）の本店トップ /ja/ を開き、読み込み完了後にヘッダのカートを確認する（商品数「3」が表示される。差し止めた /block/cart への要求は0件）

# 期待される挙動【必須】
- 設計書（現行仕様 業務ロジック「カート内商品数の取得」）: ヘッダのカートに出す商品数は、画面の読み込みが終わった後に取得して表示する。取得できなかったときは商品数を表示しない
- 取得の失敗時に商品数を出さない動きを、新しい実装で守るのか（商品数を最初から描く方式に改めるのか）を設計書で確定する必要がある

# 現在の挙動【必須】
- 商品数は画面を描く時点で埋め込む。画面の読み込み後の取得は行わない（/block/cart への要求も出ない）ため、取得できなかったときの扱いが成り立たず、商品数は常に表示される。/block/cart はカートの操作後にヘッダを描き直すときだけ使う。

ec-cube-enterprise ヘッダのカート商品数（描画時に埋め込む）: `ec-cube-enterprise/src/Eccube/Resource/template/default/Block/cart.twig:7-9`
```twig
            {% if totalQuantity > 0 %}
                <span class="p-hareruya-header__nav-right-badge">{{ totalQuantity|number_format }}</span>
            {% endif %}
```

- ベース実装は、画面の読み込みが終わってから取得用の窓口を呼び、商品数を埋める。

ベース実装 pf-eccube3 ヘッダのカート商品数の取得: `pf-eccube3/app/Plugin/HareruyaEc/Resource/template/default/Block/js/header_js.twig:1-20`
```twig
    window.addEventListener('load', function() {
        $(function () {
            setHeaderCartInfo();
        });
    }, false);
    function setHeaderCartInfo()
    {
        var options = {
                type: 'get',
                dataType: 'JSON',
                url: "{{ url('cart_get_info', {'_locale': app.locale}) }}",
            };
        $.ajax(options)
        .done(function (data, status, jqXHR) {
            $('.cartDisplayNumber').html(data.cart.totalQuantity);
        });
    }
```

# 根拠
- 設計：
  - 現行仕様 業務ロジック「カート内商品数の取得」: 読み込み後に取得して表示、取得できなかったときは表示しない: `hareruya-design-docs/excel_to_html/output/0302_基本設計仕様書(フロント_グローバルナビ).html:1621-1622`
- ec-cube-enterprise：
  - 商品数を描画時に埋め込む（取得失敗の分岐なし）: `ec-cube-enterprise/src/Eccube/Resource/template/default/Block/cart.twig:7-9`
  - /block/cart は描き直し用の窓口: `ec-cube-enterprise/src/Eccube/Controller/Block/CartController.php:41-56`
- ベース実装：
  - 読み込み後に取得窓口を呼んで商品数を埋める（取得できなければ空のまま）: `pf-eccube3/app/Plugin/HareruyaEc/Resource/template/default/Block/js/header_js.twig:1-20`
  - 探した範囲: pf-eccube3 の Block/header.twig・Block/js/header_js.twig、新アプリの Block/cart.twig・header.twig・CartController。なお、ベース実装が呼ぶ窓口は cart_get_info で、/block/cart ではない（ベース実装では /block/cart は未使用）。ケースの遮断対象（/block/cart）と設計書の取得の窓口が合っているかも合わせて確認したい
