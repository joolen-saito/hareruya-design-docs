# 期待される挙動【必須】
- 注文元番号には、統合された店頭受取注文の注文番号だけを表示する（1件なら1つ、複数件ならカンマ区切り）。
- 例: 店頭受取注文 00004839 を統合した場合は「00004839」。店頭受取注文 00004844・00004845 を統合した場合は「00004844, 00004845」。

# 現在の挙動【必須】
- 統合先（スマレジ取引の受注）自身の注文番号が先頭に加わって表示される。
  - IT-F06-06-041（店頭受取1件・購入済み）: 「00004838, 00004839」（00004838 は統合先自身）
  - IT-F06-06-042（店頭受取1件・キャンセル）: 「00004841, 00004842」（00004841 は統合先自身）
  - IT-F06-06-043（店頭受取2件・購入済み）: 「00004843, 00004844, 00004845」（00004843 は統合先自身）
- 購入日・店舗・支払方法・リンクなし・処理状態の非表示は期待どおり。
