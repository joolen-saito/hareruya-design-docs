# 期待される挙動【必須】

- 商品詳細の設計書（0303）は「本店、各支店に応じた商品公開ステータスを取得し、公開/非公開を制御する」とだけ書き、本店が非公開で支店が公開のときの表示は定めていない（`hareruya-design-docs/excel_to_html/output/0303_基本設計仕様書(フロント_商品).html:1645`）。
- 商品管理の設計書（0204 商品登録編集の処理概要。Excel 由来）は、両方とも「公開」のときだけ支店の画面に表示し、「商品公開ステータスが非公開の場合、支店の公開ステータスが公開であっても、支店の画面に商品は表示されない」と定める（`hareruya-design-docs/excel_to_html/output/0204_基本設計仕様書(商品管理).html:1559-1560`）。

  - A. 期待結果を「本店・支店とも表示されない（404）」に改める（0204 を正とする）。支店で表示される確認は「本店公開・支店公開」のケースに任せる。
  - B. 本店が非公開でも支店の公開ステータスだけで支店に表示する、が意図なら、0204 の記述と新アプリの両方を直す必要がある（設計の決裁が必要）。

# 現在の挙動【必須】
- 本店の商品詳細は404、支店（TC大阪支店）の商品詳細も404で、商品名の見出しは空（2026-11-18 開発環境）。
- 原因は、商品詳細の取得が本店の商品公開ステータスが「公開」の商品だけを対象にしており、そのうえで支店では支店の公開ステータスも見るため、本店が非公開なら支店の公開ステータスに関係なく404になること。0204 の定めと一致する。
