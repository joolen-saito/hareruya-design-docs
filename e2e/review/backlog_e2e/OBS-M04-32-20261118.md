# 現在の挙動【必須】
- 承認IDを付けたリンクで開くと、店舗の欄が空のまま必須の検索条件として送信され、「入力されていません。」のエラーが出て、検索結果は0件になる（2026-11-18 開発環境。全権の管理者で ?id=2081 を開いた画面）。店舗を選んで検索し直すまで対象の承認を確認できない。
- 原因は、ECCUBE_HARERUYA-4094（2026-11-17）の対応で、検索の店舗が必須（1件以上）になったこと。承認IDを付けたリンクの経路は、ログイン中のメンバーを渡さずに初期の検索条件を作るため、デフォルト検索表示店舗が入らず、どのメンバーでも店舗が空になる（デフォルト検索表示店舗が設定されたメンバーでもコード上は同じ）。通常の初期表示の経路はメンバーを渡して店舗を入れる。4094 より前は店舗が必須でなかったため、同じリンクで店舗が空でも承認IDで絞り込まれた一覧が出ていた。
- 関連して、一覧から「一括承認」を押すと、検索フォームの入力検証を通らないと確認モーダルが開かない（店舗が空だと止まる）。2026-11-18 の M04-33・34 の E2E では、承認待ちの入庫の承認がこれで24件止まった（E2E 側は店舗を選んでから承認する形に直した）。
