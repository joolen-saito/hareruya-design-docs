# 基本情報【必須】
分類：イベント管理
機能：イベント編集 / イベント削除
課題カテゴリ：不具合_イベント管理
課題：【要確認】イベント管理_イベント編集_日程一覧の受付時間が日付なしの時刻だけで表示される（ケースの期待は日付と時刻）が、設計書の項目表に表示形式の定めが無い
設計書：0214_基本設計仕様書(イベント管理).xlsx

# 再現手順【必須】
1. 開発環境（https://replace-dev.hareruyamtg.com:8443）の管理画面で、受付時間・オンライン受付時間・デッキ登録締切を設定した日程を持つイベントの編集画面を開く
2. 日程一覧の該当行の「受付時間」「オンライン受付時間」「デッキ登録締切」を見る
3. 受付時間は「09:00～09:50」（日付なし）、オンライン受付時間とデッキ登録締切は日付付きで表示される

# 期待される挙動【必須】
- 設計書の項目表（識別ID 4-3 受付時間・4-4 オンライン受付時間）は「ラベル」とあるだけで、表示形式（日付を含むか）の記述が無い。受付時間は時刻のみ、オンライン受付時間は日付付きという現状の表示で良いかを設計書で確定する
- イベント一括登録CSVの定義では受付時間 From/To は時刻のみ（例 13:00）、オンライン受付時間は日付付きの記載になっている

# 現在の挙動【必須】
- 日程一覧の受付時間は時刻（時:分）だけを出し、オンライン受付時間は日付と時刻を出す。

ec-cube-enterprise 日程一覧: `ec-cube-enterprise/src/Eccube/Resource/template/admin/Event/edit.twig:426-433`
```twig

                                                <td class="align-middle">

                                                </td>
                                                <td class="align-middle">
                                                    {% if EventDetail.onlineEntryStartDate and EventDetail.onlineEntryEndDate %}{{ EventDetail.onlineEntryStartDate|date('Y/m/d H:i') }}～<br>{{ EventDetail.onlineEntryEndDate|date('Y/m/d H:i') }}{% else %}-{% endif %}
                                                </td>
                                                <td class="align-middle">{% if EventDetail.deckRegistDeadline %}～{{ EventDetail.deckRegistDeadline|date('Y/m/d H:i') }}{% else %}-{% endif %}</td>
```

- ベース実装の受付時間も時刻（H:i）のみ。
