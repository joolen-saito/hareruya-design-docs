# 期待される挙動【必須】
- 遷移先の指定が無いときの既定の遷移先は、サイトのルート（/）とする（設計書）
- 新しいアプリのURLはすべて言語付き（/ja/ ・/en/）なので、設計書の「ルート」を言語付きのトップと読むかを設計書で確定する

# 現在の挙動【必須】
- ログイン後の既定の遷移先はトップ画面のルート名 homepage。このルートのURLは言語を前に付ける設定のため /ja/ になる。

ec-cube-enterprise ログインの既定遷移先: `ec-cube-enterprise/app/config/eccube/packages/security.yaml:80-86`
```yaml
                token_provider:
                  service: eccube.rememberme.redis_token_provider.customer
            form_login:
                enable_csrf: true
                check_path: mypage_login
                login_path: mypage_login
                default_target_path: homepage
```

ec-cube-enterprise 画面のURLに付く言語: `ec-cube-enterprise/app/config/eccube/routes.yaml:16-20`
```yaml
    type: attribute
    # NOTE:
    # 本店では'/{_locale}'、支店では'/{_locale}/{_shop}'となる。
    # front_controllers と同じ prefix にし、render(path('block_xxx')) 等で _shop が引き継がれて支店判定 (TopCategoryListBuilder::isBranchShopContext 等) が動くようにする。
    prefix: /{_locale}{_shop}
```

- ベース実装には言語付きのURLは無く、ログイン後・ログアウト後のトップは「/」。

ベース実装 pf-eccube3 ログアウトの遷移先: `pf-eccube3/src/Eccube/Application.php:570-573`
```php
                'logout' => array(
                    'logout_path' => '/logout',
                    'target_url' => '/',
                ),
```
