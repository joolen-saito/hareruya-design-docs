# 期待される挙動【必須】
- ケースの期待結果は、項目表 IT-M03-08-014（新規の登録）・IT-M03-08-015（既存の変更）とも「その商品の商品規格一覧画面へ遷移すること」。出典は設計書の M03-08 の表示メッセージ M03-08-MSG-002（新しい商品規格を保存したとき）・M03-08-MSG-004（商品規格の変更を保存したとき）で、後続処理を「管理画面_商品管理_商品規格一覧画面に遷移する」と定めている。
- 一方、M03-09（商品規格登録/編集）の現行仕様の節は、規格を更新する流れの最後を「『登録が完了しました。』の成功フラッシュを設定し、同じ規格の編集画面へリダイレクトする」と定め、入出力の成功時出力も「同じ規格の編集画面への302リダイレクト」としている。M03-09 の表示メッセージも、表示条件を「規格更新が成功し編集画面へリダイレクトしたとき」としている。M03-09 の Excel 由来の画面項目定義には、編集画面の最下部に「商品規格一覧に戻る」（識別ID 36。当該の商品規格一覧画面へ遷移）があり、保存のあとも編集画面に居続ける前提と合う。
- 設計書の中の優先順位（Excel由来＞表示メッセージの節＞現行仕様の節。2026-10-16 決定）では、M03-08 の表示メッセージと M03-09 の表示メッセージが同じ順位で、順位だけでは決まらない（保存後の遷移先は Excel 由来の部分に記述が無い）。
- この遷移先は、完了済みの課題 ECCUBE_HARERUYA-2572（登録・更新の成功後は一覧画面へ遷移していた実装を、同じ規格の編集画面へ直した。2026-09-18 にマージ）で、編集画面を正と決めている。新アプリはその決定どおりに動いている。M03-08 の表示メッセージ MSG-002・004 の後続処理の書き方と、それに沿ったケースが、その決定に追随していない。
- したがって実装は直さず、設計書の M03-08 の表示メッセージ MSG-002・004 の後続処理を「同じ商品規格の商品規格編集画面へ遷移する」に直し、ケース（項目表 IT-M03-08-014・015）の期待結果もそれに合わせる。M03-08 の表示メッセージの文言「保存しました」は新アプリの表示と一致している（M03-09 側の「登録が完了しました。」との食い違いは ECCUBE_HARERUYA-3953）。
