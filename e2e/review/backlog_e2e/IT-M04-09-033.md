# 期待される挙動【必須】
- ケースの期待（項目表 IT-M04-09-018。E2E のテストID IT-M04-09-033）は、欠品点数 1 を入力して「欠品登録」を押すと仮登録され、「取り消し」で取り消せること。同じ画面の入力で、項目表 IT-M04-09-019（E2E 034）は欠品点数 0・3・4（移動点数3）、IT-M04-09-034（E2E 050）は差分点数 1、IT-M04-09-096（E2E 126）は差分点数 1.5 と -2.5 を入れて、ボタンが押せる状態かを見る。
- 設計書（ピック・出庫承認申請画面）の機能仕様は、「入力された欠品点数が移動点数より少ない正の整数の場合に欠品登録ボタンは活性状態となり押下できる」「欠品登録ボタンを押下すると入力された欠品点数が仮登録され、欠品登録ボタンは取り消しボタンへ変化する」「取り消しボタンを押下すると入力された欠品点数削除され、取り消しボタンは欠品登録ボタンへ変化する」と定める。画面項目定義 3-16 の欠品点数は「数値（整数）」の入力項目、3-17 の「欠品登録・取り消し」ボタンは「欠品点数を仮登録または取り消しする」。
- 入庫承認申請画面の差分点数も同じ形で、「入力された差分点数が整数の場合に差分登録ボタンは活性状態となり押下できる」「差分登録ボタンを押下すると入力された差分点数が仮登録され、差分登録ボタンは取り消しボタンへ変化する」。画面項目定義 3-25 の差分点数は「入力」項目。
- したがって、欠品点数・差分点数の欄は、ボタンを押す前から入力でき、入力した値が条件を満たしたときにボタンが押せるようになる。

# 現在の挙動【必須】
- 欠品点数・差分点数の欄は、初期表示で読み取り専用。「欠品登録」「差分登録」を押すと欄が入力可能になり、ボタンの文言が「仮登録」に変わる。「仮登録」を押すと値が仮登録され、0以外なら「取り消し」に変わる。つまり、設計書の「入力→ボタンが活性→押下で仮登録」ではなく、「ボタン→入力→仮登録ボタン→(取り消し)」の3段階の操作になっている。
- E2E は、手順2（IT-M04-09-018 の手順2）で「欠品点数に1を入れられない: 入力欄が読み取り専用」で止まった（開発環境、2026-11-16 21:55）。同じ理由で IT-M04-09-019・034・096 も手順の入力ができず不合格（E2E 034・050・126）。
- 同じ画面のほかの操作（欠品・差分の仮登録、承認申請）が使えないわけではない。IT-M04-09-023（E2E 038）の実施では、「欠品登録」→ 1 を入力 →「仮登録」の順で仮登録でき、欠品点数1は保存された。
