# 期待される挙動【必須】
- ケースの期待結果（項目表 IT-B16-09-001。E2E のテストID IT-B16-09-003）は、控えたトップページのアドレスの掲載が1件あること。
- 設計書（Excel 由来・シート「サイトマップ生成処理」）は、晴れる屋のトップページにアクセスし、取得したページのリンクを辿ってアクセスできた URL のリストでサイトマップファイルを作るとしている。そのため、トップページと、トップページから辿れる既定のページは、サイトマップに載る。

# 現在の挙動【必須】
- /ja/sitemap_page.xml は HTTP 200 で、掲載は361件。すべて管理画面で作ったユーザーページ（/ja/user_data/…）で、トップページ /ja/ を含む既定のページは1件も載っていない（2026-11-20 07:18 開発環境）。
- 新しいアプリは、既定のページのうち「URL に変数を含むページ」をサイトマップから除いている。フロントの経路は、本店で /{_locale}、支店で /{_locale}/{_shop} を必ず頭に付ける作りなので、どの既定のページの経路にも変数が含まれ、すべて除かれていると見られる（ソースから読んだ見立て。画面で確かめたのは、既定のページが1件も載らないところまで）。
- 設計の方式（トップページからのクロールでファイルを作る）と、新しいアプリの方式（要求のたびに、ページの一覧からその場で XML を返す）も違う。この方式の違いは乖離監査でも確認されているが、Backlog には起票されていない。

ec-cube-enterprise 既定のページのうち、経路に変数を含むものを除く: `ec-cube-enterprise/src/Eccube/Controller/Front/SitemapController.php:164-191`
```php
    #[Route(path: '/sitemap_page.xml', name: 'sitemap_page_xml', methods: ['GET'])]
    public function page(): Response
    {
        $Pages = $this->pageRepository->getPageList("((p.meta_robots not like '%noindex%' and p.meta_robots not like '%none%') or p.meta_robots IS NULL)");

        // URL に変数が含まれる場合は URL の生成ができないためここで除外する
        $DefaultPages = array_filter($Pages, function (Page $Page) {
            // 管理画面から作成されたページは除外
            if ($Page->getEditType() === Page::EDIT_TYPE_USER) {
                return false;
            }

            $route = $this->router->getRouteCollection()->get($Page->getUrl());
            if (is_null($route)) {
                return false;
            }

            return count($route->compile()->getPathVariables()) < 1;
        });
```

ec-cube-enterprise フロントの経路は、言語区分（と支店の店舗コード）を必ず頭に付ける: `ec-cube-enterprise/app/config/eccube/routes.yaml:35-39`
```yaml
front_controllers:
    resource: '../../../src/Eccube/Controller/Front'
    type: attribute
    # NOTE:
    # 本店では'/{_locale}'、支店では'/{_locale}/{_shop}'となる。
```

- ベース実装（現行の晴れる屋のサイト）は、設計書のとおりサーバーの Sitemap-Generator-Crawler でトップページからクロールしてファイルを作る方式で、手元のリポジトリ（pf-eccube3・pf-api・pf-article）には該当するコードが無い（「sitemap」で検索した範囲では、フッターのテンプレートのリンクだけ）。現行に該当なし。
- 新しいアプリの元にした ec-cube の SitemapController（`ec-cube/src/Eccube/Controller/SitemapController.php:177-193`）も同じ除き方をしている。ec-cube の経路の頭は /{_shop} だけである。
