# 期待される挙動【必須】
- テストケースは、レイアウトが「Double Faced」の行をMeldとして照合し、Meldで登録されることを期待している
- 設計書（現行仕様 業務ロジック「列ごとの取り込み方」）は「レイアウト値が Double Faced,Meld のときは Meld として照合する」とある。これは「Double Faced,Meld」という1つの値（コンマを含む）を指すのか、「Double Faced」または「Meld」のどちらかを指すのかが読み取れない。一方 Excel の項目表（識別ID 24）は、レイアウト名(英)がマスターにあれば同じ値で登録する（なければエラー）とだけ定める。設計書で確定する必要がある
