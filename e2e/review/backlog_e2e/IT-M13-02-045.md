# 再現手順【必須】
1. 開発環境（https://replace-dev.hareruyamtg.com:8443）の管理画面で、日程が1件あるイベントのイベント編集画面を開く（日程のチェックは付けない）
2. 画面下部の「チェックした日程削除」を押そうとする（グレーのまま押せず、何も送られない）
3. 同じイベント編集画面の「削除」を押して確認画面を開き、確認画面の削除ボタンを押そうとする（日程情報が存在する旨の文言が出るが、削除ボタンは押せず、何も送られない）

# 期待される挙動【必須】
- 日程を選ばずに日程一括削除を押したときは、該当なしとして扱い、イベント編集画面へ戻る（設計書の判定順序）
- 日程が残るイベントの削除は、「日程情報が存在する場合、イベント情報を削除することができません。」のメッセージをイベント編集画面に表示して拒否する（設計書の表示メッセージ）。削除の操作自体は押せて、要求が送られる
