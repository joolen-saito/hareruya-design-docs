# 再現手順【必須】
1. 開発環境（https://replace-dev.hareruyamtg.com:8443）の管理画面で、編集権限のある店舗のイベントのイベント編集画面を開き、日程一覧の行の編集ボタンから「編集」を選んで日程編集画面を開く
2. 画面下部の操作ボタンを確認する（「削除」と「保存」が出る。「更新」は無い）

# 期待される挙動【必須】
- 既存の日程の更新時には「更新」ボタンと「削除」ボタンを表示し、「登録」ボタンは表示しない（設計書 識別ID 20〜22）

# 現在の挙動【必須】
- 新規のときは「登録」、既存日程の編集のときは「保存」の文言で出している。「更新」の表示は無い。

ec-cube-enterprise 日程編集の実行ボタン: `ec-cube-enterprise/src/Eccube/Resource/template/admin/Event/Schedule/edit.twig:259-259`
```twig
                                <button class="btn btn-ec-conversion px-5" type="submit" {% if not isEditableBaseInfo %}disabled{% endif %}>{{ isNew ? 'admin.common.registration'|trans : 'admin.common.save'|trans }}</button>
```

- ベース実装は既存日程のとき「日程更新」、新規のとき「日程登録」と表示する。

ベース実装 pf-eccube3 日程画面の実行ボタン: `pf-eccube3/app/Plugin/HareruyaEc/Resource/template/admin/Schedule/schedule.twig:224-224`
```twig
                                <button class="btn btn-primary btn-block btn-lg edit" type="submit">日程{{ eventDetailId ? '更新' : '登録' }}</button>
```
