# M03-18 の大量行 CSV

正本 `integration_test/casegen/cases/M03-18_seed_data.tsv:52-54`（`S-M03-18-CSV-050`〜`052`）は、見出し 5 列、全明細の連番規則、件数、UTF-8・カンマ区切りを指定する。`M0318-050-rows.csv` と `M0318-051-rows.csv` は各 5,009 データ行、`M0318-052-rows.csv` は 5,008 データ行。`node e2e/tools/verify-m03-18-fixtures.mjs` が正本の値と下記の LF 規約から期待バイト列を組み立てて照合し、`--write` は不足ファイルだけ作成する。

正本に改行種別の指定はないため、リポジトリ内の静的 CSV と同じ LF・末尾改行 1 個で保存した。列の値は追加していない。

同正本の `M0318-053-big.csv` は 5 MB + 1 バイトにする「末尾の充填文字」が未指定。`M0318-054-token.csv` と `M0318-055-extra.csv` は「見出し行 1 行」とだけあり、その見出し値が未指定。いずれも推測が要るため置かない。
