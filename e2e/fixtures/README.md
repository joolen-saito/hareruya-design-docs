# 結合テスト用ファイルの在庫

正本は `integration_test/casegen/cases/*_test_cases.tsv` と `*_seed_data.tsv`。このディレクトリには正本で列値・行数・形式が確定する入力ファイルを置く。改行種別が正本にない場合は LF・末尾改行 1 個を実装上の表現として採用し、個別の根拠に明記する。改行まで正本で指定された「全バイト確定」とは区別する。画面が振る番号や、画面から取得する雛形が必要なファイルは実行時に作る。

## 在庫表

`node e2e/tools/fixture-inventory.mjs` で次の表を再生成する。引用セルは `e2e/lib/catalog.ts` と同じ規則で復元し、正本の行番号を残す。

- [`named-file-references.tsv`](named-file-references.tsv): 拡張子が書かれたファイル名を機能ごとに 2,013 件（名前だけで重複をまとめると 1,996 種類）。CSV 1,159、TSV 78、画像 645、JSON 53、Twig 54、その他 24。拡張子の後ろに識別番号が続く `split_invalid.txt-022` のような名前も含む。入力候補は 1,526 件。作成済み 203 件、実行時生成 45 件、保留 32 件、正本矛盾 1 件、入力対象外 3 件、未判定 1,729 件。
- [`unnamed-file-operations.tsv`](unnamed-file-operations.tsv): ファイル名が書かれていない操作候補 3,629 行。同シードに実行時値の記述がある 1,904 行、画面雛形の記述がある 78 行を手掛かりとして記録した。これはファイル自体への要件とは限らず、ファイル出力なども含むので、実装時には正本の手順とシードの投入方法を読んで判定する。
- [`m03-function-summary.tsv`](m03-function-summary.tsv): 正本のある M03 全 40 機能を、名前付き入力候補・作成済み・未判定・名前未指定操作候補まで 0 件の機能も含めて集計したもの。入力候補が 0 件でも「ファイル不要」とは断定しない。
- [`m04-function-summary.tsv`](m04-function-summary.tsv): 正本のある M04 全 29 機能を同じ列で集計したもの。名前付き参照 195 件は作成済み 121、実行時生成 43、保留 28、出力のため入力対象外 3 に分類した。名前のない操作候補 487 行は完成扱いにしない。

`functions/todo-list.md` にある M03-34・M03-36 は対応する `*_test_cases.tsv`・`*_seed_data.tsv` がこの正本ディレクトリにないため、40 機能の集計対象外。正本 TSV が無い機能の入力内容はこの監査では確定できない。

M04-11・15・26・27・29 も `functions/todo-list.md` に機能があるが、対応する正本 TSV がないため、M04 の集計対象外。

在庫表の「入力候補」「出力・履歴候補」は文言による分類であり、実際にローカルファイルが必要と確定した件数ではない。行の出典と、ケース・シード ID を確認してからファイルを作る。正本に無い値や、画面が振る番号を固定値で補わない。

「内容根拠タグ」は、正本のシード属性・投入方法にある記述を機械で拾った手掛かりであり、完成可能という判定ではない。入力候補 1,526 件のうち、ファイル別仕様記述 391 件、見出し記述 181 件、行列条件記述 218 件、採番値参照 300 件、同シードの画面雛形使用 60 件、符号化形式記述 758 件、手掛かりなし 467 件。タグは重複する。特に画面雛形のタグは同じシード全体への記述であり、各ファイルへの直接指定とは限らない。
