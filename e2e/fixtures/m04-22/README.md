# M04-22 在庫移動・振替 CSV

正本 `integration_test/casegen/cases/M04-22_seed_data.tsv` の「投入方法」に、25 件の CSV のファイル名・UTF-8・見出し・全データ行が書かれている（6〜13、15〜21、23〜25、28〜34 行）。`transfer.txt` は 27 行に UTF-8 と内容 `x` が指定されている。`node e2e/tools/verify-m04-22-fixtures.mjs` は正本から値を復元して、この 26 ファイルを全バイト照合する。

CSV の改行種別は正本に指定がない。保存上の規約として LF・末尾改行 1 個を採用した。したがって、CSV は「値が確定し、改行は LF を採用したファイル」であり、正本で全バイトが指定されたものではない。`transfer.txt` は「ファイル内容=x」の指定どおり `x` だけで、改行を加えない。

`move.txt`（同シード 22 行）は UTF-8 と商品コード・移動点数という意味上の内容だけが指定され、文字列の配置・区切り・見出しの有無がない。ファイルは作らず保留する。
