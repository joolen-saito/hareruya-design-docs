# M09-10 支店トップページ管理の入力ファイル

正本: `integration_test/casegen/cases/M09-10_seed_data.tsv` の S-M09-10-IMAGES（「m0910-new-banner.png は5MB以下のPNGで、m0910-old-banner.png と内容を目視で識別できる」）。
シード表は大きさと見分けがつくことだけを決め、寸法や絵柄を決めないので、Node の標準の機能（zlib）で 573×389（支店トップページのバナーの表示の大きさ）の縞の絵を作った。

| ファイル | 中身 | 使い方 |
| --- | --- | --- |
| m0910-old-banner.png | 赤の横縞のPNG（約1.5KB） | シードが登録する「旧」のバナー画像。シード表の名前ごとの画像（m0910-old-banner-017.png など、試験者が選ぶ任意の画像）は、この中身をその名前で選ぶ |
| m0910-new-banner.png | 青の縦縞のPNG（約3KB） | ケースが選ぶ「新」のバナー画像。058・064 のシードの「m0910-new-banner.png」もこれ |

シード（`seeds/m09-10.ts` の S-M09-10-IMAGES）が、使う前に5MB以下のPNGであることと、2つの中身が違うことを確かめる。
