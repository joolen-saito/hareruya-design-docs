# M03-01 の商品・カード CSV

正本の `M03-01_seed_data.tsv` を確認した。52 ケースのうち 44 ケースが商品 CSV を使い、うち 7 ケースはカード CSV も使う。ファイル名は正本に無く、静的な CSV は配置していない。

| 種類 | 正本の指定 | 内容が実行時に決まる箇所 |
| --- | --- | --- |
| グッズ商品 CSV | 43 シードに「グッズ商品CSV登録で雛形ファイルをダウンロード」と記載。共通値と各明細の値はシードごとに指定 | 雛形の全列と列順、日本語などの言語 ID、公開状態の値、既存の商品カテゴリ ID、購入グループ名。カテゴリは画面で登録して採番するケースもある |
| カード登録 CSV | `S-M03-01-TEXT-008`・`TEXT-011`・`FLAGS-015`〜`018`・`TEXT-052` の 7 シード | 未使用のカード詳細 ID、既存カードセット・レアリティ・レイアウト・画像 URL、プロモ種別の既存値と CSV の列順 |

商品 CSV を使うケースの例は [`M03-01_test_cases.tsv:9`](../../../integration_test/casegen/cases/M03-01_test_cases.tsv) の `IT-M03-01-008`。その明細とカード CSV の指定は [`M03-01_seed_data.tsv:7`](../../../integration_test/casegen/cases/M03-01_seed_data.tsv) の `S-M03-01-TEXT-008` にある。カード CSV が 2 行必要な `S-M03-01-TEXT-011` は同シード表の 10 行目。12,001 商品を 5,000・5,000・2,001 行の 3 ファイルへ分ける `S-M03-01-PAGING-039` は 37 行目。

実装時はシードの開始時に画面から雛形をダウンロードして列を読み、画面で確認した選択肢と採番 ID を使って各ケース専用の CSV を生成する。商品名、商品コード、価格、行数などは正本のシード行から取る。ファイル名が無いのでケース専用の名前を実装側で付ける場合、その名前を仕様値や期待値にはしない。

`S-M03-01-DEPRECATED-007`・`DEPRECATED-019`・`TEXT-009`・`TEXT-010`・`TEXT-012`・`TEXT-013`・`RANGE-023` は、正本で商品 ID を空にし、固定の商品コードを新規登録する。初回実行の商品が残る同一環境で再実行すると、商品コード重複で CSV 取込が失敗する。特に3行の 007・009 と2行の 010・012・019・023 は、一部だけ既存の場合に残りだけが登録される部分投入の可能性もある。正本に既存商品の削除・再利用・コード変更の手順は無いため、これらは実装で補わず、各実行前に対象コードが未登録の環境を用意する。

`S-M03-01-DISPLAY-030`・`DISPLAY-031`・`DISPLAY-033`・`DISPLAY-034` も商品 ID 空・固定コード（031 は `LST3402-031`、034 は `LST3402-034`）だが、正本に限って登録前の同名商品検索と完全削除が指定されている。実装は既定の公開・NM・高額商品除外の絞り込みを画面で外し、その検索で見つかった表示行だけを削除し、削除エラー時は停止する。ただし商品検索自体が非表示・廃止の規格を除外するため、その商品まで含む「同名商品なし」は画面からは証明できない。共有環境では破壊的シードとしてケースをスキップする。別名で同じ商品コードが残っていた場合は正本に無い削除やコード変更をせず、CSV 取込の失敗として扱う。同じ環境で再実行する際は、正本の画面削除で該当商品を完全削除できることと、固定コードの別名商品が残っていないことを確認する。

`S-M03-01-TEXT-051` も商品 ID を空にして固定コード `M0301S-051A`・`M0301S-051B` を新規登録する。正本の事前削除は英語名「M0301-051-AzureWing」に一致する商品だけで、実装では検索結果の日本語名または商品編集画面の英語名を確認してから削除する。乙の商品 `M0301S-051B` はこの検索に一致しないため、同じ環境で再実行すると残留した固定コードと衝突する。正本外の乙の削除・コード変更は行わず、実行前に両コードが未登録（または正本が削除を許す甲だけが存在）である環境を用意する。

`S-M03-01-PAGECOUNT-056` は表示件数マスタを正本指定の9値にそろえる。正本が削除を指示する777以外の余分な値は消さず、シードを失敗させる。既定値10は管理画面から変更できないため画面で確認する。`S-M03-01-DISPLAY-056` は同名商品を画面で検索・完全削除してから固定コード `M0301S-056` を登録するが、非表示・廃止規格は商品検索に現れず、残存なしを画面だけでは保証できない。両シードとも削除を含むため、共有環境ではケースをスキップする。

`IT-M03-01-031` は正本手順に商品選択がないまま一括編集ボタンを押すテストを実装・実行した。現行画面は「1つ以上の商品を選択してください」と表示して一覧へ戻り、正本の遷移期待を満たさず不合格。正本外のチェック操作を補って合格扱いにはしていない。`IT-M03-01-024`・`032` はシードが棚番号の DB 直接設定を指定しており、「ブラウザのみ」と画面シード規約では実施しない。

カード CSV を使う `IT-M03-01-008`・`011` は未実装・未実施。正本は「未使用のカード詳細 ID」を CSV に書くよう指定するが、管理画面では既存カードの CSV 出力からセット・レアリティ・レイアウト・画像 URL は取得できても、未使用の詳細 ID を確実に判定できない。DB の SELECT で投入値を決める案は「ブラウザのみ」「DB は確認用」の規約に反するので採用しない。また 008 のカード名「稲妻魔法カード-008」は 011 の「稲妻　カード」検索にも一致し、同じ環境で 008 の後に 011 を実行すると、011 の「1件だけ」という期待を満たせない。正本やシードを変更せず、運用・仕様の判断を待つ。
