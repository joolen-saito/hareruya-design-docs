【指摘内容】
　（仕様）カテゴリの選択肢は、フロント検索で非表示とする親配下を除いて提示する（処理フロー・業務ルール「フロント検索で非表示とする親カテゴリ配下の項目は選択肢から除外する」・エッジケース「非表示親配下のカテゴリ→選択肢に出さない」・DBカラム「dtb_category.front_search_hide_flg を選択肢から除外する親配下の判定に用いる」の4箇所で明記）
　詳細検索フォームのカテゴリセレクト(f.category)の選択肢は SearchType.php:95 の `CategoryRepository::getList(null, true)` が返す全カテゴリを SearchType.php:107-111 でそのまま choices に渡している。getList (CategoryRepository.php:133-163) のクエリは `createQueryBuilder('c')->orderBy('c.sort_no','DESC')` のみで front_search_hide_flg の where 条件が無く、getSelfAndDescendants() で非表示親配下も含めて全件を返す。Twig(_product_search_form_fields.twig:36-38)も f.category.vars.choices を無条件ループするのみ。front_search_hide_flg(getFrontSearchHideFlg) は grep 全走査の結果 TopCategoryListBuilder.php / CategoryTreeResponseBuilder.php / Category.php / CategoryType.php / CSV系のみで使用され、本検索フォームのカテゴリ選択肢生成経路には未適用のため、非表示親配下のカテゴリも選択肢に出力される。確認お願いします。（設計根拠: excel_to_html/output/0303_基本設計仕様書(フロント_商品).html#sheet-5 ／ 実装: src/Eccube/Form/Type/Front/SearchType.php:95,107-111 / src/Eccube/Repository/CategoryRepository.php:133-163 / src/Eccube/Resource/template/default/Block/_product_search_form_fields.twig:36-38）
