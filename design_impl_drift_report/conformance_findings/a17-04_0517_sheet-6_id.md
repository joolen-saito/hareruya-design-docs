■API-A17-04 商品IDに紐づく商品詳細の情報を取得
【指摘カテゴリ】
　実装違い
【指摘内容】
　（仕様）パスの商品IDと、クエリの言語を受け取り、商品IDと言語で商品詳細を取得する。指定言語に対応する商品詳細を返し、未指定時は日本語（JP）を既定とする。
　ProductController は lang クエリを受け取り findProductById($productId, $languageCode) に渡すが、findProductById の SQL は mtb_language を `LEFT JOIN mtb_language lang ON pc.language_id = lang.id AND lang.code = :languageCode` と結合するだけで、WHERE 句に `lang.code = :languageCode` や `pc.language_id` の絞り込みがない。さらに `COALESCE(lang.code, :languageCode) AS languageCode` により、指定言語以外の商品規格も指定言語として応答に混入し得る。確認お願いします。（設計根拠: excel_to_html/output/0517_基本設計仕様書(API_その他).html#sheet-6:2049,2056,2111 ／ 実装: /home/y-saito/Developments/ec-cube-enterprise/src/Eccube/Repository/ProductRepository.php:225）
