機能名
検索クエリに一致するカード情報1件を取得
概要
検索クエリに一致するカード情報1件を取得できる
処理概要（★はカスタマイズ項目）
GET　POST　PUT　DELETE　PATCH　OPTIONS　HEAD　有　無　〇
エンドポイントURL
/card?name={name}&lang={lang}
プロトコル　HTTP　メソッド　GET　認証の有無　無　認証方式　無　リクエスト書式　クエリ　レスポンス書式　JSON
カスタマイズ説明
・現行踏襲のためカスタマイズ要件はなし
機能仕様処理概要（★はカスタマイズ項目）
・リクエストパラメータで指定された条件に基づき、データベースから検索したカード情報を1件を返す
・リクエストパラメータ「lang」が未指定の場合は、英語版(en)のカード情報を優先して返す
リクエストパラメータ
項目名	型	必須	最大文字数
または最大値	入力例	備考
name	文字型	〇	-	ゲイラキャット / Gaelicat	日本語、英語のカード名を「 / 」で区切り入力できる
半角英数の場合は英語、それ以外を日本語のカード名とする
lang	文字型	-	-	ja	優先して取得するカード情報の言語を入力できる
未指定の場合、英語版(en)のカード情報を優先して返す
リクエストパラメータサンプル
/card?name=ゲイラキャット / Gaelicat&lang=en
ステータスコード
コード　説明
200.0　正常終了
404.0　リクエストパラメータ「name」が未指定の場合
リクエストパラメータで指定された条件に該当するカード情報が存在しない場合
レスポンスデータ
名前	型	説明
id	数値(整数)	カードID
name_jp	文字型	カード名(日)
name_en	文字型	カード名(英)
image_url	文字型	画像URL

現行仕様
A14-03 検索クエリに一致するカード情報1件を取得 / API カード管理 — 検索クエリに一致するカード情報1件を取得
業務ロジック
検索条件
カード名は日本語名・英語名・「日本語名/英語名」・「英語名/日本語名」のいずれの形でも受け取る。分割カードは + でつないだ入力を想定し、内部で / に置き換えて突き合わせる。カード名が空のときは該当なしとして扱う。
カード言語が ja のときは日本語、それ以外のときは英語を並び順の優先言語とする。
取得の判定
条件に一致するカードのうち 1 件だけを返す。1 件も一致しないとき、およびカード名が空に相当するときはコード 404 とメッセージ「Not Found」を返す。
取得した値をそのまま返し、金額・ポイント・数量・ステータス・日時の再計算と補正は行わない。
エラー時の扱い
エラー内容	処理
条件に一致するカードが無い、またはカード名が空	コード 404 とメッセージ「Not Found」を返す
入出力
種類	内容
入力	カード名（必須）とカード言語（任意）
成功時出力	HTTP 200。条件に一致するカード 1 件
失敗時出力	該当が無いときは 404。本文はコードとメッセージ「Not Found」
入出力: 応答の項目
フィールド	型	説明
id	integer	カードID
nameJp	string	カード名（日）
nameEn	string	カード名（英）
image_url	string	カード画像のURL
入出力: 永続化
この機能ではデータを更新しない。
