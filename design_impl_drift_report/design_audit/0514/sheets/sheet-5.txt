概要
検索クエリに一致するカード情報1件を取得できる
処理概要（★はカスタマイズ項目）
GET　POST　PUT　DELETE　PATCH　OPTIONS　HEAD　有　無　〇
エンドポイントURL
/card?name={name}&lang={lang}
プロトコル　HTTP　メソッド　GET　認証の有無　無　認証方式　無　リクエスト書式　クエリ　レスポンス書式　JSON
カスタマイズ説明
・現行踏襲のためカスタマイズ要件はなし
機能仕様処理概要（★はカスタマイズ項目）
・リクエストパラメータで指定された条件に基づき、データベースから検索したカード情報を1件を返す
・リクエストパラメータ「lang」が未指定の場合は、英語版(en)のカード情報を優先して返す
リクエストパラメータ
項目名	型	必須	最大文字数
または最大値	入力例	備考
name	文字型	〇	-	ゲイラキャット / Gaelicat	日本語、英語のカード名を「 / 」で区切り入力できる
半角英数の場合は英語、それ以外を日本語のカード名とする
lang	文字型	-	-	ja	優先して取得するカード情報の言語を入力できる
未指定の場合、英語版(en)のカード情報を優先して返す
リクエストパラメータサンプル
/card?name=ゲイラキャット / Gaelicat&lang=en
ステータスコード

404.0　リクエストパラメータ「name」が未指定の場合
リクエストパラメータで指定された条件に該当するカード情報が存在しない場合

name_jp	文字型	カード名(日)
name_en	文字型	カード名(英)
image_url	文字型	画像URL

現行仕様
A14-03 検索クエリに一致するカード情報1件を取得 / API カード管理 — 検索クエリに一致するカード情報1件を取得
業務ロジック
カード名の突き合わせ
カード名は完全一致で突き合わせる。前方一致・部分一致では該当しない。日本語名と英語名の両方を受け取ったときは、いずれか一方だけに一致するカードも該当として扱う。
分割カードは + でつないだ入力を想定する。カード名はURLデコードしたうえで日英に分け、そのあと + を / に置き換えて突き合わせる。%2B は + として解釈する。
カード名が一致しても、カード詳細・カードセット・カード画像のいずれかを持たないカードは該当として扱わない。
複数一致したときの選び方
条件に一致するカードが複数あるとき、および同じカードがカード画像を複数持つときは、次の優先順で並べた先頭の1件だけを返す。応答のカード画像URLもこの並びで決まる。
優先言語のカード画像を持つもの
特殊版でないもの
発売日が新しいもの
フォイルでないもの
プロモーションでないもの
優先言語は日本語と英語の2つで、カード言語に ja 以外の値を指定したときも英語になる。
入出力
入出力: 該当が無いときの応答本文
該当が無いときの応答本文は、コードとメッセージ「Not Found」を持つ。
