A15-11 デッキ情報削除 ／ API デッキビルダー — デッキ情報削除
業務ロジック
削除の判定順序
順序	判定	結果
1	トークンからプレイヤーを特定できるか	できないなら認証拒否（HTTP 401）
2	デッキIDに該当するデッキがあるか	無ければ該当なし（HTTP 404）
3	対象デッキの所有者が認証したプレイヤーと一致するか	一致しないなら認証拒否（HTTP 401）
4	上記を通過	削除日時を設定して論理削除し、処理結果コード200を返す
認証と認可
トークンを検証し、その内容に含まれる顧客IDからプレイヤーを特定する。トークンの欠落・署名不正・該当するプレイヤーなしのいずれのときも認証拒否とする。削除できるのは対象デッキの所有者本人だけで、所有者でないときも認証拒否とする。呼び出し元はデッキビルダーアプリで、トークンの原値と署名の秘密値は本書に記載しない。
削除の内容
対象デッキに削除日時を設定して論理削除し、当該デッキの一時保存があれば併せて削除する。この一連の処理は1つのまとまりとして行い、例外が起きたときはすべて取り消して処理失敗（HTTP 500）とする。金額・税・ポイント・在庫数量の再計算は行わない。応答は本APIで集計せず、処理結果をそのまま返す。
エラー時の扱い
事象	扱い
認証できない	認証拒否（HTTP 401）とし、コードとメッセージを返す
デッキが存在しない	該当なし（HTTP 404）とする
他人のデッキ	認証拒否（HTTP 401）とする
削除処理中の例外	処理失敗（HTTP 500）とし、例外の内容をメッセージに含めて返す
入出力
種類	内容
入力	削除対象のデッキID、認証用トークン。ボディの値は持たない
成功時出力	HTTP 200。処理結果コードとメッセージ
失敗時出力	HTTP 401（認証不可・所有者不一致）、HTTP 404（デッキなし）、HTTP 500（削除処理中の例外）
入出力: リクエスト
パラメータ	位置	型	必須／任意	説明
id	パス	integer	必須	削除対象のデッキID
認証トークン	ヘッダ	string	必須	プレイヤーを特定するためのトークン
入出力: 応答フィールド
フィールド	型	説明
code	integer	処理結果コード。成功時は200
message	string	処理結果メッセージ。成功時は「Deck delete success」
入出力: 永続化
操作	契機
更新	判定をすべて通過したとき、対象デッキに削除日時を設定して論理削除する
削除	同じ契機で、当該デッキの一時保存があれば削除する
リニューアル後の仕様
表示メッセージ
メッセージID	表示位置	画面上の文言	表示条件	後続処理
—	APIレスポンス（JSON body・message）	Deck delete success	デッキの削除に成功したとき	HTTP 200を返す
—	APIレスポンス（JSON body・message）	The deck does not exist	デッキIDに該当するデッキが無いとき	HTTP 404を返し、削除しない
—	APIレスポンス（JSON body・message）	Access Token is incorrect	トークンの欠落・署名不正・該当するプレイヤーが無いとき	HTTP 401を返し、削除しない
—	APIレスポンス（JSON body・message）	Authentication failed	対象デッキの所有者でないとき	HTTP 401を返し、削除しない
