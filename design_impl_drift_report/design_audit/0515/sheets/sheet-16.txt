A15-16 直近大会情報取得 ／ API デッキビルダー — 直近大会情報取得
業務ロジック
取得対象
最新大会デッキのマスタから、大会日が設定済みで、かつ大会名（日本語・英語）が空でない行を抽出する。条件に合致する大会が無いときも失敗とせず、空の一覧を返す。
並び順
識別子の昇順に並べる。
値の取り方
数量・日時は永続化済みの値を返し、応答生成時の丸め・補正を行わない。
呼び出しの条件
リクエストのパラメータを受け取らない。認証も行わないため、認証を理由とするHTTP 401は返さない。公開向けの一覧であり、呼び出し元の状態によらず同一の結果を返す。呼び出し元はデッキビルダーアプリである。
エラー時の扱い
エラー内容	処理
該当大会なし	エラーとせず、空の一覧で処理結果コード200を返す
取得処理中の例外	共通の例外処理に委ねる（HTTP 500相当）
入出力
種類	内容
入力	なし
成功時出力	HTTP 200。処理結果コードと直近大会の一覧
失敗時出力	取得処理中の例外は共通の例外処理に委ねる（HTTP 500相当）
出力: 直近大会の項目
フィールド	型	説明
大会日	string	日時の文字列。
フォーマット識別子	integer	フォーマット識別子。
フォーマット名（日本語）	string	フォーマットの日本語名。
フォーマット名（英語）	string	フォーマットの英語名。
大会名（日本語）	string	大会の日本語名。
大会名（英語）	string	大会の英語名。
参加者数	integer	参加者数。
