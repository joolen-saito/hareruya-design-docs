A15-03 ユーザー情報参照 ／ API デッキビルダー — ユーザー情報参照
業務ロジック
取得対象
デッキユーザーIDの指定が無いときは、認証したプレイヤー自身の情報を返す。返す値はニックネーム・プロフィール・デッキユーザーIDで、いずれも未設定のときはnullとする。デッキユーザーIDの指定があるときは他ユーザー情報参照の分岐となり、本書では扱わない。
認証
認証用トークンのヘッダを検証し、対象者の顧客IDからプレイヤーを特定する。署名方式はHS256である。ヘッダ欠落・署名不正・該当するプレイヤーなしのいずれも認証拒否（HTTP 401）とする。認証を通ったのちに対象プレイヤーを取得できないときは入力不正（HTTP 400）とする。
呼び出し可能なクライアントはデッキビルダーアプリである。返すのは認証したプレイヤー自身の情報だけである。トークン原値・署名シークレットは本書に記載しない。
エラー時の扱い
エラー内容	処理
認証不可	認証拒否（HTTP 401）とし、コードとメッセージを返す
対象プレイヤーが取得できない	入力不正（HTTP 400）とし、「Invalid request parameters」を返す
入出力
種類	内容
入力	認証用トークンのヘッダ（必須）。デッキユーザーID（任意、指定すると他ユーザー情報参照の分岐となる）
成功時出力	HTTP 200。処理結果コードとニックネーム・プロフィール・デッキユーザーIDを含むラッパオブジェクト。キーは区切り記号付きの小文字で組み立てる
失敗時出力	認証できないときはHTTP 401で「Access Token is incorrect」または「Authentication failed」。対象プレイヤーを取得できないときはHTTP 400で「Invalid request parameters」
出力: フィールド
フィールド	型	説明
code	integer	処理結果コード。成功時は200。
user_name	string	プレイヤーのニックネーム。未設定の場合はnull。
profile	string	プレイヤーのプロフィール。未設定の場合はnull。
deck_user_id	string	プレイヤーのデッキユーザーID。未設定の場合はnull。
成功時の応答例（実装確認値に基づく代表値）。
{
"code": 200,
"user_name": "デッキ太郎",
"profile": "スタンダードを中心に遊んでいます。",
"deck_user_id": "AB12CD34"
}
入出力: 永続化
本APIは業務データを更新しない。
