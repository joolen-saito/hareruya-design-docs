A15-06 マスタ検索 ／ API デッキビルダー — マスタ検索
業務ロジック
取得するマスタの決定
受け取ったマスタ名はアンダースコア区切りの文字列とし、キャメルケースへ変換して先頭を大文字にしたマスタ識別名に読み替える。追加公開対象（カテゴリ・カテゴリ並び順・会員区分・割引カード条件・タグ並び順）のときは業務データ側のマスタを、それ以外のときは区分値のマスタを対象とする。マスタ識別名に対応するマスタが存在しないとき、または公開しないマスタ（権限・カード・カード詳細）を指定したときは、該当なしとして扱う。
取得の範囲
対象マスタ	取得する範囲
フォーマット	デッキビルダー対象の区分が立つものだけ
カテゴリ・タグ	サブテーブルを含めて取得する
上記以外	全件を取得する
認証
認証を行わない。トークンの検証も会員・プレイヤーの照合も行わないため、認証を理由とする拒否は返さない。呼び出し元はデッキビルダーアプリで、利用者の状態によらず参照できる公開マスタを返す。
応答の値
条件・公開状態・絞り込みの順序は取得元のマスタの定義に従う。件数・並び順は取得後に再計算しない。金額・ポイント・数量・ステータス・日時は保存済みの値をそのまま返し、応答生成時の丸め・補正は行わない。条件に一致しないデータは空の結果として返す。
エラー時の扱い
事象	扱い
公開対象でない、または存在しないマスタ名	コード404とメッセージを持つJSONを返す
取得処理中の例外	共通の例外処理に委ねる（HTTP 500相当）
入出力
種類	内容
入力	マスタ名
成功時出力	HTTP 200。処理結果コードとマスタ行の配列
失敗時出力	HTTP 404（公開対象でない・存在しないマスタ名）、HTTP 500（取得処理中の例外）
入出力: リクエスト
パラメータ	位置	型	必須／任意	説明
name	パス	string	必須	マスタ名。アンダースコア区切りの文字列を受け取り、キャメルケース化・先頭大文字化してマスタ識別名に変換する。対象は区分値マスタ全般（カード種別・サブタイプ・レアリティ・色・フォーマット・デッキタグ・キャンペーンタグ・特殊種別など）と、追加公開対象の業務データ側マスタ（カテゴリ・カテゴリ並び順・会員区分・割引カード条件・タグ並び順）。権限・カード・カード詳細は公開しない
入出力: 応答フィールド
フィールド	型	説明
code	integer	処理結果コード。成功時は200
results	array	マスタ行の配列。要素は対象マスタの公開プロパティで構成するオブジェクト
results[].（各プロパティ）	対象マスタ依存	各マスタで公開設定されたプロパティ。キー名はcamelCase。構成はマスタごとに異なり、フォーマットなら識別子・日本語名・英語名・デッキビルダー対象の区分、色なら識別子・名称などとなる
サブテーブルを持つマスタ（カテゴリ・タグ）では、要素内に子要素の配列を含む。
