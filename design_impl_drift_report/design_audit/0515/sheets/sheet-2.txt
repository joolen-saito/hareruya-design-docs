A15-02 ログアウト ／ API デッキビルダー — ログアウト
業務ロジック
認証の判定順序
順序	判定	結果
1	認証ヘッダのアクセストークンがあり、署名が正当か	欠落または署名が不正なときは認証拒否として返す
2	トークンの利用者ID（会員ID）に対応するプレイヤーがあるか	無いときは認証拒否として返す
3	上記を通過	トークンのCookieを空にする
署名方式はHS256とする。トークンの原値・署名シークレット・パスワードは本書に記載しない。
認可
有効なトークンを持つ会員だけがログアウトできる。
更新しないもの
会員・注文・ポイントなどの業務データは更新しない。金額・ポイント・在庫などの業務値は計算しない。
すでに無効な状態に対する要求のふるまいは、既存の認証エラーまたは冪等な成功応答の実装に従う。
入出力
種類	内容
入力	ログイン時に取得したアクセストークン（必須）。リクエストボディの項目は持たない。
成功時出力	HTTP 200。結果コード200と結果メッセージ。
失敗時出力	認証拒否のときはHTTP 401と結果コード・結果メッセージ。処理中の例外はデッキビルダーAPIの共通例外処理に委ねる。
入出力: 永続化
業務データは更新しない。
リニューアル後の仕様
表示メッセージ
メッセージID	表示位置	画面上の文言	表示条件	後続処理
—	API応答JSON	Logout success	ログアウトできたとき	トークンのCookieを空にして返す
—	API応答JSON	Access Token is incorrect	認証ヘッダのアクセストークンが欠落しているとき、または署名が不正なとき	ログアウトせずHTTP 401で返す
—	API応答JSON	Authentication failed	利用者ID（会員ID）に対応するプレイヤーが存在しないとき	ログアウトせずHTTP 401で返す
