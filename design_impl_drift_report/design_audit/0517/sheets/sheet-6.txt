現行仕様
A17-04 [任意門]商品IDに紐づく商品詳細の情報を取得 / API その他 — 商品IDに紐づく商品詳細の情報を取得
業務ロジック
取得対象
商品IDと言語で商品詳細を取得する。言語が未指定のときは日本語を既定とする。該当が無いときは該当なし（HTTP 404）とする。
商品本体の情報（商品名・言語・説明・カテゴリ・地域制限）は、取得した明細の先頭から取る。
カード商品の扱い
カード商品のときは商品名の先頭に言語コードを付し、カード情報を組み立てる。カード商品でないときはカード情報を返さない。
出力する商品規格
明細のうち、良品（NM）または価格が表示下限以上のものだけを商品規格として返す。画像はファイル名からURLへ変換して並べる。
週間販売数
各明細の週間販売数を合算した値を返す。
値の取り方
金額・税・ポイント・在庫数量の再計算や丸めは行わない。取得時点の値をそのまま応答へ整形して返す。表示用の加工は呼び出し元の設計による。
他機能との境界
本機能は認証を行わない。呼び出し元は外部連携先であり、アクセス経路の制御は本書の範囲外とする。
エラー時の扱い
エラー内容	処理
商品IDに該当する商品詳細が無い	該当なし（HTTP 404）・「Not Found」を返す
入出力
種類	内容
入力	商品ID（パス・必須）、言語区分（任意・未指定時は日本語）
成功時出力	HTTP 200。処理結果コード・週間販売数・商品情報・カード情報・商品規格の配列
失敗時出力	HTTP 404。処理結果コードとメッセージ（"Not Found"）
出力: 応答項目
フィールド	型	説明
処理結果コード	integer	成功時は200。
週間販売数	integer	商品規格ごとの数量を合算した値。
商品ID	integer	商品ID。
商品名	string	カード商品は先頭に言語コードを付す。
言語コード	string	言語コード。
商品説明	string	商品説明。
カテゴリ	array	カテゴリ名の配列。
地域制限	string	地域制限の名称。
カード情報	object	カード名・色・マナコスト・レアリティ名・カードタイプ・カードテキスト・フレーバーテキスト・パワー／タフネス・忠誠度・カードセット名・カードセットブロック名・イラストレーター名・フォーマット情報。カード商品でないときはnull。パワー／タフネスと忠誠度は該当が無いときnull。
商品規格	array	商品規格の配列。要素は商品規格ID・商品コード・高額商品コード・カードコンディションコード・販売価格・販売上限数（該当が無いときnull）・在庫数・商品規格画像URLの配列。
