現行仕様
A17-02 記事IDに関連する記事情報を取得 / API その他 — 記事IDに関連する記事情報を取得
業務ロジック
関連記事の抽出
指定された記事に関連する記事を取得する。同一デッキ・アーキタイプ・カード・イベント詳細のいずれかを共有する記事を関連とみなす。並び順は共有度の高い順である。取得上限件数は指定でき、未指定時は20件とする。
応答値の扱い
金額・ポイント・数量・ステータス・日時は永続化済みの値を返し、応答生成時の丸め・補正は行わない。取得後に業務値を再計算しない。
エラー時の扱い
エラー内容	処理
関連記事なし（結果が空）	コード404・「Not Found」のJSONを返す
入出力
種類	内容
入力	基準となる記事ID、取得上限件数（任意）
成功時出力	HTTP 200。関連記事の配列
失敗時出力	HTTP 404。関連記事が無いとき
入力: リクエスト
パラメータ	位置	型	必須／任意	説明
id	パス	integer	必須	基準となる記事のWP投稿ID。この記事に関連する記事を抽出する
limit	クエリ	integer	任意	取得上限件数。未指定時は20件
出力: レスポンス（成功）
フィールド	型	説明
wpPostId	integer	関連記事のWP投稿ID
hasSameDeck	integer	基準記事と同一デッキを共有するか（1／0）
hasSameArchetype	integer	基準記事と同一アーキタイプを共有するか（1／0）
hasSameCard	integer	基準記事と同一カードを共有するか（1／0）
hasSameEventDetail	integer	基準記事と同一イベント詳細を共有するか（1／0）
