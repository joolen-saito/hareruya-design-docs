現行仕様
A07-07 複数ネット買取IDから個別入力商品の一覧を取得 / API ネット買取管理 — 複数ネット買取IDから個別入力商品の一覧を取得
業務ロジック
取得対象
ネット買取受注IDリストをカンマで分解し、分解して得たIDに紐づく個別入力商品だけを取得する。
入力の状態	取得結果
1件以上のIDを指定したとき	当該のネット買取受注に紐づく個別入力商品の一覧
未指定・空文字のとき	空文字を分解した配列で検索する結果、0件となる
該当が1件も無いとき	空配列とし、エラーとしない
値の取り方
取得した値をそのまま応答へ整形する。金額・税・ポイント・在庫数量の再計算は行わない。表示用の丸めも行わない。件数を返す場合は、検索条件を適用した後の対象だけを基準にする。
エラー時の扱い
事象	扱い
トークンが欠落しているとき、署名が不正なとき、該当する管理者アカウントが無いとき	認証拒否（HTTP401）とし、本文を返さない
該当が0件のとき	エラーとせず、HTTP200で空配列を返す
取得処理中に例外が起きたとき	処理失敗（HTTP500）として共通例外処理に委ねる
入出力
種類	内容
入力	ネット買取受注IDリスト（ids、ボディ、任意、カンマ区切りの文字列）。認証用トークン（jwt-token、ヘッダ、必須、署名方式はHS256）。トークンのペイロードの利用者IDから管理者アカウントを引く。
成功時出力	HTTP200。個別入力商品の配列。該当が0件のときは空配列。
失敗時出力	認証できないときはHTTP401（本文なし）。例外のときはHTTP500。
出力: 応答フィールド
フィールド	型	内容
（ルート）	array	個別入力商品の配列。0件のときは空配列
buyOrderIndivisualInputProductId	integer	ネット買取注文個別入力商品ID
buyOrderId	integer	ネット買取受注ID
name	string	商品名
price	integer	査定金額。未設定のときはnull
count	integer	個数。未設定のときはnull
saleFlg	boolean	売却フラグ。未設定のときはnull
入出力: 永続化
いずれの場合もデータを更新しない。
