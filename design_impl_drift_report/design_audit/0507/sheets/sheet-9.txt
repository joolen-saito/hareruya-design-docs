現行仕様
A07-06 複数ネット買取IDからネット買取受注の商品一覧を取得 / API ネット買取管理 — 複数ネット買取IDからネット買取受注の商品一覧を取得
業務ロジック
取得する対象
指定されたネット買取受注IDリストをカンマで分解し、当該買取受注IDに紐づく買取代表カードの一覧を取得する。該当0件のときは空配列を返す。
申込時買取価格の付与
取得した買取代表カードの代表カードIDに紐づく申込時買取価格を引き当て、カード状態コードをキーとする申込時買取価格として各買取代表カードに付与する。一致する申込時価格が無い代表カードには付与しない。
金額・税・ポイント・在庫数量の再計算は行わない。取得した値をそのまま応答へ整形して返す。
エラー時の扱い
エラー内容	処理
認証不可	認証拒否（HTTP 401）とする
該当0件	エラーとせず空配列を返す
取得処理中の例外	処理失敗（HTTP 500）として共通例外処理に委ねる
入出力
種類	内容
入力	ネット買取受注IDリスト、認証トークン
成功時出力	HTTP 200。申込時買取価格を付与した買取代表カードの配列
失敗時出力	HTTP 401（認証不可）、HTTP 500（取得処理中の例外）
入力: リクエスト
パラメータ	位置	型	必須／任意	説明
ids	ボディ	string	任意	カンマ区切りのネット買取受注IDリスト。未指定・空文字のときは空文字を分解した配列で検索するため、結果は0件となる
jwt-token	ヘッダ	string	必須	認証用のトークン
出力: レスポンス（成功）
フィールド	型	説明
（ルート）	array	買取代表カードの配列。0件のときは空配列
[].buyMainCardId	integer	買取代表カードID
[].buyOrderId	integer	ネット買取受注ID
[].productId	integer	商品ID
[].languageId	integer	言語ID。未設定のときはnull
[].foilFlg	boolean	フォイルか否か。未設定のときはnull
[].count	integer	枚数。未設定のときはnull
[].price	integer	査定金額。未設定のときはnull
[].cardConditionId	integer	カード状態ID。未設定のときはnull
[].saleFlg	boolean	売却フラグ。未設定のときはnull
[].purchaseCategory	integer	買取カテゴリ
[].applicationPrice	object	カード状態コードをキーとするオブジェクト。値は当該状態の申込時買取価格
