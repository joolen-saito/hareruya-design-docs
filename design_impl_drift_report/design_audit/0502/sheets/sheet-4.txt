カスタマイズ説明
通販・記事画面内にあるカード画像の上にマウスカーソルを置いたときポップアップ表示する商品情報をJSON形式で出力する
機能仕様処理概要（★はカスタマイズ項目）
・言語・カードIDを元に商品ページURLを含む商品情報をJSON出力する。
・カード画像にマウスを置いた際に、AJAX(Javascript)を使用しEC-CUBE側のAPIへアクセスが行われ
EC-CUBEサーバを経由して間接的にAPIサーバにアクセスする
(外部からAPIサーバに直接アクセスはできない)
・EC-CUBE側通信URL例
https://www.hareruyamtg.com/ja/goods_api/get_goods?card_id=22&lang=jp
※ langはEC-CUBEサーバURLではjpで表記する(EC-CUBEサーバ→APIサーバ通信時にjaに差し替えられる)

現行仕様
A02-02 ポップアップ用カード情報取得 / API 商品管理 — ポップアップ用カード情報取得
業務ロジック
取得の対象
指定されたカードID・言語・フォイル有無・価格の条件に対応する商品規格を1件取得する。該当が無いときはコード404と「Not Found」を返す。
並びの決め方
指定	並び
フォイル有無に真値を指定	フォイル区分の降順
フォイル有無に偽値を指定	フォイル区分の昇順
フォイル有無が未指定	非フォイルを優先する
価格に high を指定	販売価格の降順
価格にそれ以外の値を指定	販売価格の昇順
価格が未指定	価格では並べ替えない
応答の値
取得時点の値をそのまま返し、金額・税・ポイント・在庫数量の再計算や丸めは行わない。表示用の加工は呼び出し元の設計に委ねる。
エラー時の扱い
事象	扱い
該当する商品規格が無い	コード404と「Not Found」を含むJSONを返す
入出力
種類	内容
入力	カードID、言語、フォイル有無（任意）、価格の並び指定（任意）
成功時出力	HTTP 200。条件に合致する商品規格を1件返す
失敗時出力	HTTP 404。該当する商品規格が無いとき
入出力: リクエスト
パラメータ	位置	型	必須／任意	説明
lang	パス	string	必須	言語区分。jpまたはenを想定し、言語の優先順の判定に用いる
cardId	パス	integer	必須	取得対象のカードID
foil_flg	クエリ	string	任意	フォイル優先の指定。フォイル区分の並び順に反映する
price	クエリ	string	任意	価格の並び指定
入出力: 応答フィールド
フィールド	型	説明
productId	integer	商品ID
name	string	商品名
productClassId	integer	商品規格ID
price01	string	通常価格。小数を持つ値のため数値文字列で返す
price02	string	販売価格。小数を持つ値のため数値文字列で返す
stock	string	在庫数。小数を持つ値のため数値文字列で返す
nameEn	string	英語商品名
subFileName	string	商品規格画像のファイル名。該当が無いときはnull
fileName	string	商品画像のファイル名。該当が無いときはnull
code	string	言語コード
conditionCode	string	カードコンディションコード
beltUrl	string	帯リンクのURL。該当が無いときはnull
weeklySold	string	週間販売数。合計した結果のため数値文字列で返す
入出力: 永続化
本機能はデータを更新しない。
