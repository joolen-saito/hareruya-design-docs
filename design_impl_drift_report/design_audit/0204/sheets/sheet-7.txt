現行仕様
M03-06 商品情報カスタムCSV出力 / 商品管理 — カスタムデータ CSV ダウンロード（商品情報）
業務ロジック
出力対象のカスタムCSV設定
指定されたIDのカスタムCSV設定を取得する。削除済みの設定、またはCSV種別が商品以外の設定は HTTP 404 とする。
出力する列
設定に紐づく出力列を、表示順（順位の昇順、並び順の昇順）で取得する。各列の列名は前後の空白を除き、空でないものだけを順に並べて出力列とする。有効な列名が1つも無いときは HTTP 404 とする。
出力列のうち、商品CSVの利用可能な列に存在するものだけを残す。残った列が1つも無いときは既定の列一式で出力する。
出力対象のデータ
商品一覧で保持している検索条件を用いて出力対象を絞り込む。検索結果が0件のときはデータ行を出力せず、ヘッダ行のみのCSVとなる。
金額の再計算や税率計算は行わない。保持している値と集計結果をそのまま出力する。
出力の形式
文字コードがUTF-8のときは先頭にBOMを付す。ヘッダ行に続いてデータ行を、設定の区切り文字と文字コードに従って出力する。データは規格ID単位で200行ごとに書き出す。ファイル名は product_custom に出力日時を続けた形式とする。
エラー時の扱い
エラー内容	処理
不正または削除済みのカスタムCSV設定、または列名が皆無	HTTP 404 とする
設定削除で外部キーエラー	エラーメッセージを表示し、編集画面へ遷移する
入出力
種類	内容
入力	カスタムCSV設定のID、商品一覧で保持している検索条件。列構成はカスタムCSV設定の列名のみで決まる
成功時出力	CSVのストリーム。ファイル名は product_custom に出力日時を続けた形式
失敗時出力	HTTP 404（不正な設定・列名皆無）
本機能はデータを更新しない。
