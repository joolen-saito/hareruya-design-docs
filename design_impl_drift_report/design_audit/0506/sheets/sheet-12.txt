現行仕様
A06-12 固定価格部門を部門情報を取得 / API 店頭買取管理 — 固定価格部門を取得
業務ロジック
取得する値
オプションマスタから固定価格部門の設定値（部門ID）を取得し、処理結果コードとともに返す。リクエストパラメータは受け取らない。
固定価格部門の設定値は文字列として保持されているため、応答でも文字列で返す。
取得時点の値をそのまま返し、金額・税・ポイント・在庫数量の再計算や丸めは行わない。表示用の加工は呼び出し元クライアントの設計を正とする。
エラー時の扱い
エラー内容	処理
オプションマスタに固定価格部門の設定が無いとき	参照できず例外となり、共通の例外応答（HTTP 500）を返す
入出力
種類	内容
入力	無し
成功時出力	HTTP 200。処理結果コードと固定価格部門の部門ID
失敗時出力	設定が存在しないときは共通の例外応答（HTTP 500）
出力: レスポンス
フィールド	型	説明
code	integer	処理結果コード。成功したときは200
section_id	string	固定価格部門の部門ID。設定値が文字列型のため文字列で返す
成功時の応答例（実装確認値に基づく代表値）。
{
"code": 200,
"section_id": "1"
}
入出力: 永続化
本APIはデータを更新しない。
